# SymDeo™ XPP 抑臭聚合物（SymDeo™ XPP Deo Polymer）

> 一句话定义：Symrise（德之馨）推出的**气味控制（odor control）聚合物添加剂**，用于个护/卫品中**抑制或中和异味**。

## 机理 / 结构拆解

1. **定位**：属于"主动气味管理"原料，与被动吸附（活性炭、咖啡炭）路线不同，多为**聚合物型**除臭活性物。
2. **应用**：卫品（纸尿裤/经期裤）的面层或无纺布整理、香氛协同等。
3. **具体机理/化学**：本次来源未给出产品级 TDS（化学结构、推荐用量、起效浓度），标 `[待验证]`。
