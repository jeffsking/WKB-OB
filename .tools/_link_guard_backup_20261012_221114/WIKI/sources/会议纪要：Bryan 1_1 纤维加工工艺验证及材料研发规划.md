# 会议纪要：Bryan 1_1 纤维加工工艺验证及材料研发规划

## 一句话定位

Bryan 1_1 会议：围绕 Liner 与扩散层的纤维加工温度与配方验证、SAP 材料选型、功能性母粒中长期平台规划三大块。

## 摘要

会议核心是**纤维加工温度与配方验证**（首要项）。配方方案上，最优解（验证对标）为上层 2D 10% 兰精莱赛尔（三叶草形）+ 90% ES 纤维，下层 50% 福地 ES + 50% 本身 ES——理论上增加比表面积效果最好、手感佳，但成本可能最高；过渡/备选方案为上层 3D 10% 福地 ES（三叶草形）+ 2D 90% ES 纤维，下层 50% 3D 福地三叶草 ES + 50% 4D 本身 ES，因苏州供应商量产排期不确定而备选，后续还可尝试上层 10% 3D 纺锤单组份 PET。**烘箱温度验证方案**明确：先在正常设定温度下取一批样，随后人为下调温度（如降 2–5 度，做 130℃、128℃、126℃ 等批次）连续走机取样，不需特意停机收卷。SAP 侧主力供应商为诺尔，国内市占率 60% 以上。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注（口径 Caliber） |
|---|---|---|
| 最优解上层 | 2D 10% 兰精莱赛尔（三叶草形）+ 90% ES | 增加比表面积效果最好、手感佳，成本可能最高 |
| 最优解下层 | 50% 福地 ES + 50% 本身 ES | — |
| 备选上层 | 3D 10% 福地 ES（三叶草形）+ 2D 90% ES | 苏州供应商量产排期不确定 |
| 备选下层 | 50% 3D 福地三叶草 ES + 50% 4D 本身 ES | — |
| 烘箱温度验证 | 130℃ / 128℃ / 126℃ 等批次 | 正常温度取一批后下调 2–5 度连续走机，不停机收卷 |
| 诺尔 SAP 地位 | 国内市占率 >60% | 打样快、工艺灵活性极强（表面交联/加粉末/加金属阳离子） |
| 待办 | 核算 10% 三叶草+90%ES 与 50/50 福地ES 的成本差异 | 负责人：徒弟 |

## 关键论断（key_claims）

- 最优解（验证对标）：上层 2D 10% 兰精莱赛尔（三叶草形）+ 90% ES 纤维，下层 50% 福地 ES + 50% 本身 ES；理论上增加比表面积效果最好、手感佳，但成本可能最高
- 过渡/备选方案：上层 3D 10% 福地 ES（三叶草形）+ 2D 90% ES 纤维，下层 50% 3D 福地三叶草 ES + 50% 4D 本身 ES；因苏州供应商量产排期不确定
- 烘箱温度验证方案：在正常设定温度下取一批样，随后人为下调温度（如降 2–5 度，做 130℃、128℃、126℃ 等批次）连续走机取样，不需特意停机收卷
- SAP 主力供应商为诺尔：国内市占率 60% 以上，打样快，工艺灵活性极强，可做表面交联、加粉末、加金属阳离子等
