# Preparation and Characterization of Light-Sensitive Microcapsules based on a Liquid Crystalline Polyester

> Chapter 2 (reprint of Bogdanowicz, Tylkowski, Giamberini, *Langmuir* 2013, 29, 1601–1608). ⚠️ Note: the batch task brief mis-titled this chapter as a "light-responsive LC membrane for pervaporation"; the actual source file establishes **light-sensitive microcapsules** (a flat P4 membrane is used only as a shell surrogate/model). Compiled strictly from the actual text.

## One-line Position 一句话定位

Demonstrates photo-triggered, controlled release from α-methylstilbene main-chain LCP microcapsules and proves the release mechanism is backbone conformational contraction under UV — the application pivot of the photoresponsive thread.
（演示了 α-甲基芪主链液晶聚酯微胶囊的光触发控释，并证明释放机理是 UV 下主链构象收缩，是光响应主线的应用落脚点。）

## Summary 摘要(3-6句忠实原文)

- Embedding a stilbene/azobenzene E–Z photoisomerizable unit in the polymer main chain grants remote, non-contact light control of shell morphology/permeability without destroying bulk structure.（将 E–Z 光异构单元嵌入主链即可远程、非接触地调控壳层形貌与渗透性。）
- A flat P4 membrane made by the same phase-inversion precipitation (PIP) process models the microcapsule shell; it shows an asymmetric dense-skin / spongy-support morphology matching the capsule wall.（用相同相转化沉淀（PIP）工艺制备的平面 P4 膜作为微胶囊壳模型，呈非对称致密皮层+海绵支撑结构。）
- E→Z isomerization shortens the molecule ~25% (9.1 Å→6.8 Å), lowering rms roughness ~24% (16.49→12.51 nm), mean height 133.6→100.1 nm, and water CA 120°→95° — the physical root of permeability increase.（E→Z 使分子缩短约 25%，rms 粗糙度降约 24%，平均膜高降约 25%，接触角 120°→95°，是壳层渗透性增强的物理根源。）
- Release is switch-like but has an induction period and is quasi-irreversible: no-light vanillin release is negligible (plateau ~8–10%); under 365 nm UV a rapid release follows ~20 min induction; Z-form is thermally stable >3 months at RT.（释放呈开关式但存在诱导期且准不可逆：无光可忽略，UV 下约 20 min 诱导后快速释放；Z 构型室温稳定>3 个月。）
- Vanillin (fragrance/preservative/antioxidant) was the model active; P4 capsules are 3–25 μm (mean 12±2 μm), wall 0.19–1.80 μm, PIP semi-continuous scalable; next step is visible/near-IR responsive materials.（香兰素为模型活性物；P4 微胶囊粒径 3–25 μm，壳厚 0.19–1.80 μm，半连续可放大；下一步研究可见光/近红外响应。）

## Key Claims 关键论断

- Phototriggered release = P4 backbone conformational change from α-methylstilbene E→Z isomerization (experimentally verified) — support page: [[Liquid Crystalline Polymers Smart Applications]].
- The flat P4 membrane is only a shell surrogate; the system is microcapsule-based, not a pervaporation membrane — see [[An Atomistic Insight into Light-sensitive Polymers with Methylstilbene Building Blocks]] for the atomistic confirmation.
