# Stimuli-Responsive Phase Change Materials: Optical and Optoelectronic Applications

*Vassalini, Alessandri, de Ceglia — Materials 2021, 14, 3396 · MDPI · 综述 · 2014 行*

## One-line Position 一句话定位

**阶段变材料（PCM）在光学/光电子领域的应用综述**——GST（非易失）与 VO₂（易失）两种核心 PCM 的晶相转变驱动折射率/消光系数急剧变化，实现主动光子学（动态显示、光子存储、光子突触、可重构超表面），为变色/智能材料技术提供非有机材料路径的参考。

## Summary 摘要

- **核心论点**：静态光子学（玻璃/硅）在强光/电刺激下光学性质几乎不变，调制依赖微弱机制（自由载流子注入、电光/非线性系数）；PCM 通过晶相转变实现折射率与消光系数的"rapid and drastic changes"，是主动光子学的关键使能材料。
- **两种核心 PCM**：
  - **GST（Ge-Sb-Te 硫化物）**：非易失性——晶/非晶态切换后保持，支持动态多色显示与光子存储
  - **VO₂（二氧化钒）**：易失性——升温相变后冷却恢复，支持可逆切换与 IR 成像
- **GST 多色动态显示**：多层干涉（ITO/GST225/反射器），GST225 层 <25 nm 才有效，<10 nm 时反射对比最大；精细调控结晶/非晶化程度实现多色动态显示。
- **超表面（metasurface）**：PCM 晶相转变→共振波长位移→ON/OFF 双色显示、IR/可见光成像、可重写"metacanvas"；Kerker 条件实现辐射图案切换。
- **光子计算与突触**：GST 波导模式转换器支持 64 级可区分电导态（in-memory optical computing）；突触可塑性模型 Δw = f(t_post − t_pre) = Ae^(−Δt/τ)。
- **柔性工艺**：Roll-to-roll 低温沉积在 boPET/Pt-boPET 柔性衬底——大面积柔性显示前景。
- **应用扩展**：传感器、主动显示、易失/非易失光子存储、光电与可重构器件、超表面、智能窗。

## Key Claims 关键论断

- **PCM 晶相转变是唯一能实现"rapid and drastic"光学性质变化的固态机制**——远超传统电光/非线性效应，是主动光子学的核心路径。
- **GST 非易失 vs VO₂ 易失**——两种特性互补：GST 适合存储/显示（保持态），VO₂ 适合传感/切换（恢复态）。
- **薄膜化是性能的物理边界**——GST225 <25 nm 才有效，<10 nm 对比最大；纳米级精度控制是核心工艺挑战。
- **Roll-to-roll 柔性沉积**——PCM 薄膜可在柔性衬底低温沉积，打开柔性显示与大面积器件的产业化路径。
- **64 级 GST 波导转换器**——直接对应光子计算与神经形态突触权重，是下一代光计算的基础。
