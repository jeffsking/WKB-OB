## Scope and Structure 范围与结构

本书是**反应工程视角**的聚合工艺专著（多作者合编）：以「微观结构 → 性能」为纲，逐类聚合工艺给出动力学、反应器构型、建模与放大方法，最终收于聚合反应器的控制。它不是配方书，而是把「给定目标分子量分布与结构，如何选反应器与操作条件」讲清楚。

## Relevance to Hygiene R&D 与卫材研发的关联

相关性评级：**P1（高，上游树脂/胶黏剂供应的工程侧）**。卫材两大聚合物原料——SAP（丙烯酸基自由基交联聚合）与聚烯烃（无纺布、背膜、热熔胶基体）——的**分子量分布、支化与共聚序列**由反应器与操作条件决定，本书正是连接「树脂规格书」与「反应器设计」的工程桥梁。

| 本书章节 Chapter | 卫材落点 Where it lands |
|---|---|
| Ch2 配位聚合（催化剂类型 / 多活性位动力学 / 长链支化 / 工业反应器） | 聚烯烃树脂（PP 均聚/共聚、PE）活性位分布与 MWD/LCB 的形成机理；牌号差异的工程根因，牌号数据见 [[Polypropylene Handbook Spunbond and Meltblown Nonwoven Resins]] |
| Ch3 均相自由基聚合（含 SFRP / ATRP / RAFT 与反应器类型） | 丙烯酸基 SAP 与胶黏剂聚合的速率控制、传热与 MWD 建模；受控自由基路线见 [[Controlled Radical Polymerization SAP（控制自由基聚合 SAP）]]，产品侧见 [[Acrylic-Based Superabsorbent Polymers]] |
| Ch5/Ch6 悬浮聚合与乳液聚合（含 PBE 建模、残单脱除、放大） | 珠状/粉状聚合与乳液体系的粒径分布控制、放大与 VOC 控制；SAP 水溶液/反相悬浮路线与乳液型胶黏剂的工艺参照，体系概念见 [[SAP（高吸水树脂）]] 与 [[Hydrogel-based Superabsorbent Polymers]] |
| Ch7 逐步聚合（最可几分布 / 非化学计量 / 非线性分子量发展 / PET 与聚酰胺） | 聚酯/聚酰胺类（弹性体、结构胶、纤维）缩聚的分子量控制与非化学计量封端逻辑 |
| Ch1 微观结构与性能（MWD / 支化 / 形态 / 加工复合影响） | 卫材用树脂「同一牌号不同批次差异」的分析语言：从 MWD/形态切入解释手感、强度与热封行为波动 |
| Ch8 反应器控制 | 供应商批次一致性与过程控制（PAT/在线控制）的评估框架，用于树脂与 SAP 来料稳定性谈判 |

诚实评价：**本书是工程书，不是产品书**。它回答「为什么这条工艺线的 MWD 更窄」「放大后为什么出现热点与失控」这类问题；聚合物反应机理的基础要回到 [[Principles of Polymerization]]，反应工程的教学级导览见 [[Ebewole Polymer Science Ch10 Polymer Reaction Engineering]]。
