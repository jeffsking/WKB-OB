# Diffusion in a Cylinder (Crank Ch.5)

*J. Crank — The Mathematics of Diffusion, 2nd ed., Clarendon Press 1975 · Ch.5 · 8 KB*

## One-line Position 一句话定位

**柱坐标扩散——纤维/圆柱颗粒的核心几何模型**——稳态对数分布 ln(r) 解释纤维端部与中心水含量差异；Bessel 函数 J₀ 级数是单纤维吸液动力学的解析工具；最优壁厚条件 b=1/h 指导纺粘纤维直径设计。

## Summary 摘要

- **稳态解**：C = A ln(r) + B——对数分布而非线性；解释纤维径向水含量梯度。
- **最优壁厚**：ah<1 时传质率先增后减，最大点在 b=1/h——指导纤维直径设计。
- **非稳态解**：C = ΣAₙJ₀(αₙr/a)exp(-Dαₙ²t/a²)，αₙ 为 J₀(αₙ)=0 的根。
- **小 t 近似**：erfc 表示，但收敛范围不如片层情形。

## Key Claims 关键论断

- **纤维径向水含量呈 ln(r) 分布**——解释纤维端部与中心的水含量差异。
- **最优壁厚 b=1/h 指导纤维设计**——纺粘纤维直径设计可最大化芯体导流效率。
- **Bessel 级数是单纤维吸液动力学的解析工具**——直接用于建模"单纤维吸液动力学"。
