# EP2456819B1 Olefin Block Copolymer Hot Melt Adhesive (Bostik)

## One-line positioning 一句话定位

European granted patent (B1) that defines the **OBC-based hot melt adhesive** formulation window used for **elastic attachment**（弹性粘合，即把氨纶/橡筋粘在膜或无纺布上） in disposable diapers — the reference formulation page for the "模块三：聚烯烃类热熔胶" patent cluster.

## Abstract 摘要

Bostik's EP 2 456 819 B1 claims a hot melt adhesive built on an **olefin block copolymer (OBC)** as the primary polymer, combined with a high-softening-point tackifying resin, a low-crystallinity secondary polymer (APAO or semi-crystalline polyolefin), an optional aromatic reinforcing resin, plasticizer, wax and stabilizer. The stated problem is that the disposable-industry standard for sprayability has been **styrene-isoprene-styrene (SIS)** block copolymers, and no olefinic polymer had matched SIS in sprayability + application window while also delivering elevated-temperature **creep resistance**（抗蠕变） for elastic attachment. The patent argues OBC — a chain-shuttling-catalysed linear block structure of hard ethylene-octene blocks alternating with soft amorphous blocks — gives a sprayable, olefin-based adhesive with SIS/SBS-level bond strength plus better **viscosity stability at elevated storage temperature**. The adhesive is applied below 170 ℃ (preferably ≤150 ℃) and must have viscosity ≤20,000 mPa·s at 163 ℃ (preferably ≤12,000). Claim 1 fixes the composition window; claims 2–7 narrow it; claims 8–10 cover the laminate/elastic laminate; claims 11–13 cover the manufacturing method (substrates fed, adhesive applied, pressed; elastomeric substrate stretched up to >500%).

## Key claims 关键论断

- **A polyolefin can match SIS/SBS for elastic attachment** — the patent's core assertion; sprayability + application window is the barrier being broken. → [[Polyolefin Hot Melt Adhesive（聚烯烃热熔胶）]]
- **OBC ≠ APAO** — block vs random architecture; DSC enthalpy-of-fusion boundary (>25 J/g) is used as the discriminator. → [[Olefin Block Copolymer (OBC) 烯烃嵌段共聚物]]、[[APAO（非晶态聚α-烯烃）]]
- **Low-crystallinity secondary polymer is a processing modifier, not filler** — it tunes viscosity, adhesion, low-temperature resistance and sprayability. → [[APAO（非晶态聚α-烯烃）]]
- **Aromatic reinforcing resin buys elevated-temperature creep resistance** — 2–15 wt% at ≥115 ℃ softening point. → [[Polyolefin Hot Melt Adhesive（聚烯烃热熔胶）]]
- **OBC supply is named as a single commercial source (Dow Infuse®)** in the source; no alternative OBC supplier is listed. → [[Dow Chemical Company]]
