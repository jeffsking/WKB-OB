# GB-T28004-2011 回渗渗漏.doc

## 一句话定位 One-line Positioning

**国标（GB/T 28004-2011）回渗量 + 渗漏量** 的作业方法：同一台斜面/平面两用装置上，先流注两次、再以 1.20 kg 压块压 1 min 读回渗，最后读样品下方滤纸增重作为渗漏。

## 摘要 Summary

本作业文件按 GB/T 28004-2011 测纸尿裤的回渗和渗漏量。测试前先将适量生理盐水倒入漏斗润湿并用测试溶液洗两遍、放掉漏斗中溶液后固定在支架上（漏斗下口开口面向操作者），并裁取多张直径 110 毫米的滤纸；样品从包装取出后可直接测试。步骤：把测试滑渗量所用的斜面放下使其成为平面，在平面上放几张已知重量的滤纸并在其上放一片样品（自然状态、置于漏斗下方），调整漏斗下口中心点的投影至测试样品内置吸收层的垂直距离为 5–10 毫米；用量筒准确量取测试溶液（婴儿纸尿裤小号 40 mL、中号 60 mL、大号与超大号 80 mL）倒入漏斗并迅速把节门打到最大，使溶液自由流到试样表面，同时开始计时并等待 5 分钟；等待过程中再次在漏斗中加入同量溶液，到 5 分钟时再次把节门打到最大并继续计时到 10 分钟；到 10 分钟时迅速把已知重量的若干层直径 110 毫米滤纸（以最上层滤纸无吸液为止）放在样品表面，将直径 100 毫米、重量 1.20 公斤的标准压块压在滤纸上并重新计时 1 分钟；1 分钟后移开压块称量滤纸，滤纸吸水前后重量差即为回渗量；随后移走样品，称量样品下面滤纸吸水前后的重量差即为渗漏量；最后擦净漏斗下口并将仪器复位。

## 测试方法要点 Method Specification

| 项目 | 口径 |
|---|---|
| 标准 | GB/T 28004-2011 |
| 装置 | 斜面/平面两用测试台 + 支架漏斗（下口开口面向操作者） |
| 滤纸 | 直径 110 mm（多张，以最上层无吸液为止） |
| 压块 | 直径 100 mm，重量 1.20 kg |
| 压合时间 | 1 min |
| 落液条件 | 漏斗下口中心投影至吸收层垂直距离 5–10 mm |
| 注液时序 | 0 min 第一次 → 5 min 第二次 → 10 min 读回渗 |
| 液量 · 小号 | 40 mL |
| 液量 · 中号 | 60 mL |
| 液量 · 大号 / 超大号 | 80 mL |
| 回渗量 | 滤纸吸液前后重量差 |
| 渗漏量 | 样品下方滤纸吸水前后重量差 |
| 前提条件 | 下面板水平；斜面放下成为平面 |
