# 德福伦高感性聚酯纤维简介（蜂窝微孔吸湿速干）

## Positioning 一句话定位

德福伦（Different®）**高感性聚酯纤维**产品册：以**表面成孔（蜂窝状孔洞）+ 纳米功能材料**实现的吸湿速干/远红外/抗紫外/抗菌四合一定位；在本库中是「成孔增表面积 → 吸湿速干」路线的国产供方样本（与 [[扁平形截面纤维（Flat Fibre）]] 的比表面积逻辑同源）。

## Summary 摘要

Product brochure. Technical approach: 融合表面成孔技术与纤维加工工艺，功能纳米材料与聚酯聚合技术结合，纤维表层形成「蜂巢」型孔洞 → 比表面积大幅扩增 → 「吸收水分 + 蒸发速干」双重功效；物理 + 化学改性纺丝，成品强度/伸长刻意偏低以获得极佳抗起球。CVC 面料（高感性短纤混纺比 40%）指标：吸水率 243%（洗 5 次 240%）；滴水扩散时间 <1 s（洗前后均 <1 s）；芯吸高度经向 148→152、纬向 158→174 mm（洗 5 次）；透湿量 10,600 → 10,100 g/(m²·d)。远红外功能（GB/T 30127-2013）：发射率 0.94（标准 ≥0.88）、辐射温升 1.8 ℃（标准 ≥1.4 ℃）。抗紫外：UPF50+、UVA 透射比 5%。抗菌：水洗 50 次后大肠杆菌 93%、金黄色葡萄球菌 99%、白色念珠菌 99%（AAA）。
