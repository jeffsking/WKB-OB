# Complex Core Landscape in China（2017-08-07 COCO F2F · 复合芯体格局与专利谱系）

> 一句话定位：**2017 年时点的一份"复合芯体世界地图"**——它回答了一个关键问题：**中国的复合芯体不是新发明，而是一场由设备（资产）驱动、被供应链重构放大、并被本土厂商持续改造的结构革命**。（中文：本页最大的价值是**把"复合芯体"拆成了材料、设备、供应链三条腿**，并给出**可检索的专利谱系**。）

## 提炼的数字与结论 Numbers & Conclusions

### 1. 结构演进（源文图注）

- **1986**：P&G 与 KC 引入 **SAP 芯体**概念（Ultra Pampers / Huggies）。
- **超薄 / 无绒毛浆**方向推进：**尿裤重量由 65 gsm 降到 32 gsm**。
- **ADL 演进**：**卷曲纤维与 ADL** → **结构化 ADL** → **无 ADL**。

### 2. 四种代表性芯体结构与机理

| 芯体 | 归属 | 结构 / 机理 | 配套 |
|---|---|---|---|
| **DryMax** | **P&G** | SAP 由**印刷辊的储料槽**沉积到**网格上的基材**；**热塑性胶形成纤维网覆盖 SAP，在干态与湿态均将其固定** | **化学粘合 ADL + 卷曲纤维素纤维**作为摄入与分布系统 |
| **Honeycomb / Hexacore** | **Fameccanica** | **两片层压元件**用热熔胶连接；**蜂窝构型优化"孔格面积 / 总面积"之比**；**吸收时 SAP 溶胀打开部分"不稳定键（labile bonds）" ⇒ 形成通道并为空隙腾出空间**供后续溶胀与液体分布 | **高定量热风粘合 ADL** |
| **Drylock** | **Drylock Technologies** | **载体层 + 辅助层 + 中间吸收材料**；**超声键合**形成**永久主粘合（primary）与临时次粘合（secondary）**；**吸收时 SAP 溶胀打开临时次粘合 ⇒ 产生新的空隙**以储存更多液体 | **140–150 gsm 热风粘合 ADL** |
| **Bostik（专利申请）** | **Bostik / BASF** | **第一片材层带吸收剂接收口袋阵列**；**SAP 施加于口袋内**；**第二片材层覆盖其上**；**口袋之间的珠状胶（bonding beads）保证芯体完整性**；**胶为非水溶性（not hydrosoluble）** | — |

### 4. 两条腿（源文明写）

- **材料创新**与**资产（设备）创新**是推进复合芯体的**两条腿**。
- **P&G / Drylock 是竞争对手；Fameccanica 是资产供应商；Bostik 是材料供应商**。

### 5. KC 的 Big Mac 工艺（2014）

- **2014 年开发，用于制造无浆（pulpless）吸收芯体**。
- 四个特征：**① 在线分层构筑（复合芯体）**、**② SAM 沉积/印花以提效**、**③ 不压实（no debulking）以获得柔软/柔韧手感**、**④ 通过效率与减蓬松最小化成本**。
- 结构示意：**非织造基材 / SAM 颗粒（抽吸）/ 热熔胶 / 非织造基材**。

### 6. 成本结构的迁移（源文原图）

| 组成 | 传统芯体 | 复合芯体 |
|---|---|---|
| Liner（面层） | $ | $$$ |
| Surge（导流层） | $ | $$$ |
| Absorbent core（吸收芯体） | $ | **$$** |
| Core wrap（芯体包覆） | — | **$** |
| Out cover（外覆层） | $ | $ |
| **Total** | **100%** | **120%+** |

- **判读**：**复合芯体把成本从"面层 + 导流层"转移到了"芯体本身 + 芯体包覆"**，**总成本更高**。
- 源文说明传统芯体的额外成本动因：**为解决摄入与分布，传统芯体要在 3D 面层、蓬松 surge、高渗透性 SAM 上叠加成本**。

### 7. 供应链重构（源文原图）

| | 传统芯体 | 复合芯体 |
|---|---|---|
| **工序归属** | **全部转换在纸尿裤生产商厂内**：绒毛浆成形 / SAM 混合 → 浆板纤维化 → 层压成垫 | **OEM 定制芯体 + 组件层压** |
| **芯体供应商承担** | — | **带胶的 SAM 添加**、**Airlaid / TABCW 复卷** |
| **纸尿裤生产商承担** | 全部 | **层压成垫（lamination to make pad）** |

### 8. 优劣势对照（源文原表，逐行直引）

| | **Traditional core（传统芯体）** | **Complex core（复合芯体）** |
|---|---|---|
| **PROS** | ✓ **毛细结构** —— 液体快速吸收与摄入 | ✓ **完整性** —— 卓越的垫体完整性 |
| **PROS** | ✓ **SAM/绒毛浆均匀混合** —— 机速快 | ✓ **加工** —— 用便宜设备即可轻松加工 |
| **PROS** | ✓ **柔软** —— SAM 颗粒混在绒毛浆中 | ✓ **薄且贴合** —— 明显更薄的垫体 |
| **PROS** | ✓ **SAM 选型灵活** —— 对不同渗透性适应性强 | ✓ **无浆** —— 供应链中无浆板/绒毛浆约束 |
| **PROS** | — | ✓ **SAM 灵活性** —— 可多牌号 SAM 与分层 SAM 设计（含 SAM% 设计） |
| **CONS** | □ **完整性** —— 高速成形下垫体完整性差 | □ **摄入/分布** —— 空隙体积与毛细更少 |
| **CONS** | □ **厚度** —— 更厚 | □ **保留容量** —— 长效吸收的 RC 更低 |
| **CONS** | □ **贴合** —— 厚度可能带来贴合问题 | □ **胶** —— 高施胶量影响吸收性能 |
| **CONS** | □ **加工** —— 浆板纤维化能耗高 | □ **成本/运输** —— 芯体成本高、运输成本高 |

### 9. 本土厂商的"learn by doing"方向（源文图注）

| 维度 | 本土厂商动作 |
|---|---|
| **产品重量 / 厚度** | 持续**增强薄与轻**，**宣称在夏季与南方市场击败全球玩家** |
| **吸收量** | 尝试**多层结构以增加 SAM 添加量与吸收容量** |
| **皮肤健康与干爽** | 研究**提升低压回渗（low pressure rewet）** |
| **液体摄入速度** | **3D 面层 + 昂贵 surge**；在新的复合芯体结构中**加入高蓬松 surge 与绒毛浆** |
| **完整性** | 通过**实证与演示在媒体上传播良好完整性** |

- **市场时点**：**近期的武汉 CIDPEX 展会**上，**高达 90% 的本土供应商**提供采用复合芯体的产品，并在**芯体特征上"玩出花样"（getting creative）**。
- **宣称现象**：**Y&Q 等系列**以 **4D / 5D / 7D** 等"维度"作为卖点；典型复合芯体叠构为 **Airlaid / SAM / TABCW / SAM / 硬挺非织造 / NW 芯体包覆**。

## 关键论断 Key Claims

1. **"复合芯体是新发明"这一前提被直接否定** —— 源文第一句即问 "**a brand new innovation? No!**"；**⇒ 立项时应先做先例与专利检索，而不是假设原创。**
2. **复合芯体的本质是"资产驱动的创新"** —— 源文把这些芯体统一归类为 **"Asset innovation orientated core formation"**；**⇒ 竞争壁垒主要在设备与工艺，不在配方。**
3. **三条腿必须同时看：材料 / 设备 / 供应链** —— **P&G、Drylock 是竞争对手（产品端），Fameccanica 是设备源，Bostik 是材料源**；**⇒ 只跟其中一类玩家对标会漏掉整条价值链。**
4. **四种结构共享同一个核心机理：让 SAP 溶胀"自己开路"** —— Honeycomb 打开 **labile bonds**，Drylock 打开**临时次粘合**，两者都是**用溶胀产生新的空隙与通道**。**⇒ 这是一类"可编程空隙"设计，而不是静态多孔结构。**
5. **固定方式决定成败** —— DryMax 用**热塑性纤维网在干湿两态固定 SAP**；Bostik 用**非水溶性胶 + 珠状胶**；Drylock 用**超声键合分级（永久 + 临时）**。**⇒ "胶是否水溶"与"粘合是否可打开"是两个独立的设计维度。**
6. **复合芯体更贵，这一点常被忽略** —— **Total 100% vs 120%+**；**⇒ "更薄"不等于"更便宜"，薄是把成本从材料层数转移到了芯体单价与运输。**
7. **供应链权力被重新分配** —— 从"纸尿裤厂内全工序"变为 **OEM 定制芯体 + 组件层压**；**⇒ 品牌商失去了芯体成形这一环节的直接控制，know-how 外移。**
8. **复合芯体的四项代价是结构性的** —— **摄入/分布差、保留容量低、施胶量大、成本与运输高**；**⇒ 这四项不是"待优化"，而是该路线固有的取舍，选型时应显式接受。**
9. **本土厂商的解法是在复合芯体里"往回加东西"** —— 为修摄入速度，**在新复合芯体结构中加入高蓬松 surge 与绒毛浆**。**⇒ 这事实上是在复合芯体里部分回归传统芯体的毛细结构，说明两条路线正在收敛。**
10. **"维度数"是营销产物而非技术维度** —— **4D / 5D / 7D** 系列宣称；**⇒ 面对这类宣称，应回到叠构（Airlaid/SAM/TABCW/SAM/硬挺 NW/包覆）判读实质。**
