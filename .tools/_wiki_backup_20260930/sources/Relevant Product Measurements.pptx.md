# Relevant Product Measurements.pptx（DEPEND/POISE 尺寸幻灯版）

## Positioning 定位

Slide-extracted subset（幻灯片提取，含 OCR 噪声）of the DEPEND/POISE product geometry tables — the presentation twin of [[Relevant Product Measurements.xlsx]]. Keep as a cross-check source only; the xlsx workbook is the primary dataset.（同族 xlsx 底表的幻灯版本，仅作交叉校验。）

## Summary 摘要

Two tables: (1) DEPEND garments（DPU2 / DPU3 / DPU-ULT）with pad crotch width (75 mm DPU2/DPU-ULT; 95 mm DPU3), surge width 74 mm, surge length 250/350/288 mm, pad length 396 mm, and P_F/P_B/S_F/S_B distance columns; (2) POISE Originals（4L–8L, crotch 65–85 mm, surge 135–225 mm）and UltraThins（3R–6L, crotch 57–100 mm）with flap apex-to-apex values. Several cells contain extraction artifacts（"Female e", "2280", blank surge widths for UltraThins 3R–5L）and some values differ from the xlsx version — flagged below.（DEPEND/POISE 两张几何汇总表的幻灯提取版。）

## Key Numbers & Conclusions 提炼的数字与结论

| 项目 Item | 数值 / 结论 Value | 备注 Notes |
|---|---|---|
| DPU2 crotch / surge | 75 / 74 mm；surge 250 (F) / 288 (M) mm | xlsx: female crotch blank |
| DPU3 crotch / surge | 95 / 74 mm；surge 350 mm | 一致 |
| DPU-ULT crotch / surge | 75 / 74 mm；250 (F) / 288 (M) mm | — |
| Pad length (Depend) | 396 mm（all） | — |
| POISE Originals crotch | 65 (4/5 滴)、80 (6/7 滴)、85 (8L) mm | xlsx 一致 |
| POISE surge length | 135–225 mm；surge width 49 mm（8L 62） | 一致 |

> ⚠️ **口径提示（2026-09-29）**：本幻灯版为 OCR/图片提取，存在明显噪声（"Female e"、"2280"、空值）；且与 xlsx 版存在单元格差异（如 DPU2 female crotch 75 vs 空白）。**以 [[Relevant Product Measurements.xlsx]] 为准**，本页仅作二级交叉参考；差异清单未逐一裁决。
