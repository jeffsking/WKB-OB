# Depend Rewet Update 2025-04-04（LUGH 与 GRIFFIN 回渗进展）

### 4. GRIFFIN 杠杆一：面层润湿性 Liner Wettability

- **机理**：**降低润湿性处理可改善回渗**——通过**降低毛细作用（reducing capillarity）**，阻止液体滞留在上层（discouraging fluid from hanging out in upper layers）。
- **风险**：**降低润湿性可能是渗漏风险**。
- **渗漏与防漏隔边（flaps）强相关**——这是本件最关键的边界条件：

| 条件 Condition | 结果 Result | 出处 HUT |
|---|---|---|
| **无隔边**（without flaps） | **未处理（no treatment）增加了渗漏** | **HUT 39840（ATACAMA）** |
| **有隔边**（with flaps） | **未处理未增加渗漏** | **HUT 39634（MOJAVE）** |
| GRIFFIN 计划 | 在**带隔边的 HUT** 中评估 | — |

- **润湿性梯度试验**：**1299m CD-Rod** 面层 + **Lertisan** 处理，梯度 **0.4 / 0.55 / 0.65 / 0.75 / 0.85%**（源文以图给出，未给逐档回渗数值）。

> ⚠️ **与库内既有结论的时序关系（并列记录，不裁决）**：`[[ADT Rewet Update 2026-03-31（回渗进展 ADT 版）]]` 记录**润湿性路线在 HUT 中失败**（渗漏 Control 3.1% < GRIFFIN 3.2% < AD 3.7% < Untreated 4.6%）。**本件（2025-04）是更早的"方向可行 + 渗漏待验"判断，后者（2026-03）是更晚的 HUT 结论**——两者**不矛盾，构成时间序列**，本页**不因此修改任何既有结论**。

### 5. GRIFFIN 杠杆二：ActivTech Hybrid（ATH）芯体诊断

- **已确认**：**ATH 芯体体系抬高回渗**——差异来自**不同的包覆层（wrapsheet）**与**不同的 SAM/绒毛浆配置**。
- **机理归因（本件最重要的机理陈述）**：
  - **在 ATH 体系中，绒毛浆成为摄入系统的一部分**（Fluff becomes part of the intake system in ATH system）；
  - **层数越多 = 液体可被滞留的位置越多**（More layers = more places fluid can be trapped）。
- **结构对比（源文图示）**：

| 体系 System | 层序（自上而下） |
|---|---|
| **SAM/Fluff System** | Liner → Surge → **Wrapsheet (Tissue)** → Fluff / SAM → **Intake System** → Retention System |
| **ActivTech Hybrid System** | Liner → Surge → **Wrapsheet (SMS)** → Fluff → SAM → SAM |

- **对策试验**：在**绒毛浆层少量加入 SAM**，促使该层**解吸（desorb）**（该层在 ATH 体系中被视为摄入层）。
- **诊断前提**：**需要不含 SAM 的产品**用于诊断。
