### ⚠️ 两处必须随数值同时记录的警示

**① 真空风量口径冲突（约 8–19×）**

| 口径 | 值 |
|---|---|
| 常量表「真空风量」 | 单段 **8,500 CFM** + 40% 缓冲 → 选 **~15,000 CFM（≈425 m³/min）** |
| COCO-v6 成型风机 | **9–14 m³/min/鼓**；设计点 **22 m³/min** |

> **判定**：二者**不是同一口径**——原表疑为**整线真空系统**（含芯体转移/折叠/输送吸附等多工位合计），源文件为**单鼓成型风机**（且论证了"保形从不是瓶颈"）。**不可直接比较或相加**；引用任一数值**必须携带其口径**。另：COCO-v6 侧风机 duty point 为**按床高线性缩放的模型值**，源文件明确要求替换为实测 ΔP 曲线（缺口 ⑪）。

**② SAP 与胶的工序顺序：两份 KC 内部资料相反**

| 来源 | 顺序 | 等级 |
|---|---|---|
| 常量表 §5「干态装配铁律」（拜科瑞纪要、FEI 纪要） | 真空成型须在 SAP 干燥态完成；**先喷胶 → 再落 SAP** | **A（一手会议）** |
| COCO-v6 源文件（P7 工位序 + P10 扇区序 + P15 叠层序） | NW 包裹 → **SAP 成型** → land 清洁 → **上胶保形** → 压合；叠层自外向内：skin 包覆 / skin SAP / HMA（双鼓）/ poly SAP / poly 包覆 → **落到鼓上时 SAP 先于胶** | **B（工程方案）** |

| | 先喷胶 | 先落 SAP |
|---|---|---|
| 优点 | SAP 被胶锚固，抗移位能力强 | 屏孔（Ø0.6–0.8 mm）始终洁净，真空效率稳定 |
| 缺点/风险 | 胶会先覆盖屏孔 → **堵孔 / 降真空风险**；需在成型段前增加喷胶工位 → **扇区角度必须重排** | SAP 落在裸包覆上，靠真空 + land 约束定位 |

> **处理要求（强制）**：① 两条顺序**必须并列记录，禁止静默取其一**；② 合并常量表时**必须加显式冲突标记**，否则后续读者会按 A 级直接采用「先喷胶」，与 COCO-v6 的机器设计矛盾；③ 待澄清：「先喷胶」是否仅适用于传统绒毛浆线 / 特定工位？是否已被 pattern 方案显式取代？④ 归口：向 FEI 项目组 + 拜科瑞确认适用范围。等级：**跨资料分歧，两侧各有出处，未做技术裁决，不得断言任一方有误**。
