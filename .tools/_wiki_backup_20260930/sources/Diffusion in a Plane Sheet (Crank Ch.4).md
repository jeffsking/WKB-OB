# Diffusion in a Plane Sheet (Crank Ch.4)

*J. Crank — The Mathematics of Diffusion, 2nd ed., Clarendon Press 1975 · Ch.4 · 12 KB*

## One-line Position 一句话定位

**一维有限域扩散——芯体/湿巾/SAP 片层的最直接几何模型**——稳态通量 F=D(C₁-C₂)/l、渗透常数 P=DS、复合膜串联阻力 Σ(lᵢ/Dᵢ)、时间滞后 L=l²/6D 是 SAP 行业测量扩散系数的行业标准方法。

## Summary 摘要

- **稳态解**：浓度线性分布，通量 F = D(C₁-C₂)/l（eqn 4.4）。
- **渗透常数**：P = DS——D 与溶解度 S 的乘积；MVTR 与液态阻隔率差异本质是 P 不同。
- **复合膜**：总阻力 = 各层阻力之和 Σ(lᵢ/Dᵢ)——芯体多层结构（顶表层/纺粘导流层/绒毛浆/SAP 层/PP 底膜）传质阻力建模基础。
- **时间滞后法**：L = l²/6D——测出湿流稳态段 t 轴截距 L，除以 6/l² 得 D。
- **非稳态解**：小 t 用误差函数，大 t 用傅里叶级数。

## Key Claims 关键论断

- **时间滞后法 L=l²/6D 是 SAP 行业 D 测量标准**——测出湿流稳态段 t 轴截距，除以 6/l² 即得扩散系数。
- **复合膜串联阻力公式是芯体建模的基础**——总 R = Σ(lᵢ/Dᵢ)，每层独立贡献传质阻力。
- **渗透常数 P=DS 解释 MVTR 与液态阻隔率差异**——DS 中 S 由材料亲/疏水性决定。
