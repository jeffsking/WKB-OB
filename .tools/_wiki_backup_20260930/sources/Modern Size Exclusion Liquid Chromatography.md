## Scope and Structure 范围与结构

本书是一部把**尺寸分离的物理原理、仪器实现与工程应用**三者串起来的操作性专著。结构主线清晰：前四章打理论基础（保留机理、谱带展宽、分辨率），中间六章讲仪器（泵、柱、方法开发、标定、检测器），最后五章讲应用（结构表征、水相、低聚物、二维联用、特殊操作模式）。第二版的增量集中在应用侧。

## Relevance to Hygiene R&D 与卫材研发的关联

相关性评级：**中（分析方法学专著，颗粒度到仪器与标定；非产品资料）**。SEC/GPC 是卫材三大聚合物原料——SAP（聚丙烯酸 Mw/MWD）、热熔胶（SBC/烯烃基嵌段共聚物）、聚烯烃与纤维树脂——**分子量及其分布的基准表征手段**，因此本书的价值落在来料检验与竞品解构的方法侧，而非配方侧。

| 本书章节 Chapter | 卫材落点 Where it lands |
|---|---|
| Ch11 SEC + 稀溶液热力学测聚合物结构 | 长链支化定量——聚烯烃无纺布树脂与热熔胶基体的支化度直接决定熔体强度与纺丝/涂布行为 |
| Ch13 低聚物分离（树脂与增塑剂） | 热熔胶中低分子组分、增塑剂与残留低聚物的定量，对应卫材迁移物与气味来源排查 |
| Ch12 水相 SEC | 水溶性聚合物（部分 SAP 前体、水溶胶）的分子量表征；蛋白/多肽分离口径对卫生与抗菌功能材料亦有参照 |
| Ch7 方法开发与优化（实验变量全梳理） | 建立 SAP/胶黏剂 GPC 方法时的变量清单，减少方法摸索时间 |
| Ch9 标定方法（含谱带展宽校正） | GPC 数据可信度的关键：相对标定 vs 绝对标定（光散射/粘度）的取舍，直接影响与供应商对分子量口径的争议 |
| Ch5/Ch6/Ch10 泵—柱—检测器 | 实验室 GPC 系统选型与改造的工程依据（含浓度敏感型检测器的选择） |
| Ch14 SEC 二维联用 | 复杂配方（如含多种聚合物的胶）正交分离策略，用于竞品逆向分析 |

诚实评价：**本书是分析人的工具书，不是材料工程师的产品依据**。它回答「怎么把分子量测准、怎么标定、谱带展宽如何校正」，但不给卫材可用的牌号或工艺窗口；若目标是「用 GPC 解决一个具体卫材争议」，本书的 Ch7/Ch9 是直接入口，其余章节按需检索。
