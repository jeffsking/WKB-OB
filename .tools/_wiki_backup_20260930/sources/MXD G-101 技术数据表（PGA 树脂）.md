# MXD™ G-101 技术数据表（PGA 树脂）

## 一句话定位

**美鑫达（XDM）MXD™ G-101 的官方技术数据表**（英文）：与 G-100 同族的**高流动性 PGA 牌号**，本库用于回答「PGA 树脂在家用牌号 / 不同流动性档位上的规格差异」。

## 摘要

G-101 同样被定义为可生物降解的**聚乙醇酸（PGA）树脂**，与 G-100 的定位差别在于加工方式：TDS 只写**注塑**（未提挤出），并同样可作为共混改性的基体以提升强度、阻隔与降解性。技术数据与 G-100 共用同一套 ISO 测试方法，规格上只有三项不同，其余完全一致。**三项差异**为：熔融指数 **20~40 g/10min**（230 ℃/2.16 kg，较 G-100 的 5~15 高一档）；拉伸强度 **≥90 MPa**（G-100 为 ≥100 MPa）；断裂伸长率 **≥3%**（G-100 为 ≥5%）与拉伸模量 **≥6000 MPa**（G-100 为 ≥6500 MPa）。**完全一致**的项目为：水分 ≤300 ppm、密度 1.5~1.6 g/cm³、熔点 220~225 ℃、弯曲强度 ≥160 MPa、缺口冲击 ≥2.5 kJ/m²。

包装、储运与加工要求与 G-100 相同：**铝箔袋密封**、建议储存 **25 ℃ 以下**；对水分敏感，须用除湿或真空干燥设备，**120 ℃ × 4 小时**。降解性能表述亦一致：可在工业堆肥、家庭堆肥、土壤掩埋与海洋环境降解，已取得工业堆肥与家庭堆肥认证（DIN Geprüft、BPI）。

## 提炼的数字与结论

| 项目 | G-101 规格 | 与 G-100 的差异 |
|---|---|---|
| 水分含量 | ≤ 300 ppm | 相同 |
| 密度 | 1.5 ~ 1.6 g/cm³ | 相同 |
| 熔融指数（230 ℃/2.16 kg） | **20 ~ 40 g/10min** | **更高（G-100：5~15）** |
| 熔点 | 220 ~ 225 ℃ | 相同 |
| 拉伸强度 | ≥ 90 MPa | **略低（G-100：≥100）** |
| 弯曲强度 | ≥ 160 MPa | 相同 |
| 断裂伸长率 | ≥ 3 % | **略低（G-100：≥5）** |
| 拉伸模量 | ≥ 6000 MPa | **略低（G-100：≥6500）** |
| 缺口冲击（23 ℃） | ≥ 2.5 kJ/m² | 相同 |
| 加工方式 | 注塑（TDS 未提挤出） | G-100 含注塑 + 挤出 |
| 密封包装 / 储存 | 铝箔袋 / < 25 ℃ | 相同 |
| 干燥条件 | 120 ℃ × 4 h | 相同 |
| 降解与认证 | 工业+家庭堆肥（DIN Geprüft、BPI）、土壤与海洋 | 相同 |

> ⚠️ **参数口径提示**：供应商自报典型值，未标注检测批次与第三方报告；同族两个牌号的规格差异仅体现在 MFR 与三项力学指标上。

## 关键论断（key_claims）

- **G-100 / G-101 是同一材料体系的两个流动性档**：熔点、密度、水分、弯曲与冲击规格完全相同，选型只在「MFR 与强度」之间做交换。支撑页：[[美鑫达（XDM）]]
- **高 MFR 换来的是强度与模量的小幅让步**：MFR 20~40 对应拉伸 ≥90 MPa / 模量 ≥6000 MPa。支撑页：[[PGA（聚乙醇酸）]]、[[熔融指数与化学降解]]
- **水敏感约束不因牌号而放宽**：两个牌号的干燥条件与水分上限一致。支撑页：[[聚酯水解与水分控制]]
