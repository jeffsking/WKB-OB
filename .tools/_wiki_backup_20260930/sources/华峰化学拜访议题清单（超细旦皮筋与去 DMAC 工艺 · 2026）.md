# 华峰化学拜访议题清单（超细旦皮筋与去 DMAC 工艺 · 2026）

> 一句话定位：**一份把"超细旦皮筋"和"去 DMAC"两件事绑在同一次供应商拜访里的作战提纲**——一边是**规格能不能做到**，一边是**2028Q4 的法规硬限能不能过**。（中文：它把氨纶从"弹性材料采购"变成了"合规倒计时下的路线选择"。）

---

## 摘要 Executive Summary

| 类别 | 内容 |
|---|---|
| **拜访对象** | **华峰化学股份有限公司（002064.SZ）**，重庆 / 温州 / 瑞安工厂 |
| **核心议题** | ① **超细旦氨纶皮筋供应可行性** ② **去 DMAC（免溶剂）工艺路线图与时间窗口** |
| **战略意图** | 评估华峰作为**国产替代 / 性价比线主力供应商**，同时**推动上游去 DMAC 技术协同** |
| **需求口径** | **490–840 dtex**（腿围/侧边约 490–620；腰围约 720–840） |
| **性能诉求** | **回缩率 ≤3%、弹性回复率 ≥92%、表面低/无化学残留** |
| **法规硬限** | **REACH (EU) 2025/1090**：DMAC **≥0.3% 即禁止**；过渡期 **48 个月（约 2028Q4）** |
| **内控目标** | **≤0.05%**（**而非 ≤0.3% —— 那是红线不是目标**） |

| **表面油剂** | **含油 ~6.5% + 滑石粉** | **无油无粉** | **莱卡安全性优势明显** |

### 3. 去 DMAC 三条技术路径（源文明确列出）

| 路径 | 技术 | 状态 / 代表 | 瓶颈 |
|---|---|---|---|
| **路径 1** | **熔纺氨纶（Melt-spun）** —— **完全无溶剂，全过程 VOCs 零排放、零耗水** | 代表：**河北邦泰**（全球最大熔纺氨纶基地，**10 万吨切片 / 1.8 万吨纤维**，通过 **OEKO-TEX / GRS / USDA** 认证） | **定型温域曾窄（现已拓展至 100–190 °C）**；**模量与弹性兼顾仍具挑战**；**华峰无此路线公开布局** |
| **路径 2** | **混合溶剂 / 共沸方案** —— 低沸点极性溶剂 + DMAC 混合，**利用"共沸效应"在甬道内快速脱溶剂**，降低 DMAC 残留 | **华峰有专利 CN202210037060.5**，**产业化状态未知** | 产业化未确认 |
| **路径 3** | **高效回收 + 深度净化** —— 高效 DMAC 溶剂回收系统（**华峰重庆灯塔工厂已实施**），成品残留降至 **≤0.05%** | **华峰目前的主要路径** | **REACH 2028Q4 硬限时可能不够** —— EU 限值 0.3% 为禁止线，**需留安全余量** |

### 4. 法规与限值对照（源文表）

| 法规 / 标准 | 限值 / 要求 | 状态 / 备注 |
|---|---|---|
| **(EU) 2025/1090（REACH Annex XVII）** | **≥0.3% 即禁止制造 / 上市 / 使用** | **已生效**，**人造纤维过渡期 48 个月（约 2028Q4）** |
| 专利 **CN116148299A** | **≤0.1%（1000 ppm）** | **氨纶成品不应超过**；过量致**粘连 + 健康风险** |
| **华峰灯塔工厂内控** | **通常 <0.05%** | 高效溶剂回收技改后 |
| **OEKO-TEX Standard 100** | 管控总 VOC，**氨纶列入需检测类别** | **莱卡已覆盖，华峰部分覆盖** |
| **GB/T 28004-2011（纸尿裤国标）** | **未设 DMAC 限值** | 仅甲醛、荧光增白剂等 |
| **GBZ 2.1（职业接触限值）** | **未单独列名**（参考 **ACGIH TWA 10 ppm**） | 职业防护层面，非消费品标准 |

### 6. 待向华峰追问的关键项（按源文议题顺序归纳）

**A. 超细旦能力**
- 千禧卫材氨纶超细旦产品线的**当前最低旦数 / 线密度**；
- 是否有 **≤20D / 30D 级**超细旦弹性纤维（参考**中柏实业细旦专精 20D–105D**）及其在卫材侧边 / 腿围的**实际应用案例**；
- **HDS 620 dtex 的回缩率 2.6%、弹性回复率 92.97% 需供应商书面确认 + 第三方检测报告**；
- **2026 年 4 月 CIDPEX** 展示的"**超细旦、环保炫彩、大卷装**"卫材氨纶系列的**具体 TDS**。

**B. 表面安全性（对标莱卡无油无粉）**
- 华峰是否已有 / 规划 **OEF-free（无表面油剂）**卫材氨纶产品线；
- **含油率 6.5% 方案中的油剂成分**、**是否含滑石粉**、有无**无滑石粉 / 低致敏配方**；
- **OEKO-TEX Standard 100 覆盖的具体规格与产线**，可否扩至卫材专用产品。

**C. 去 DMAC**
- 对 **(EU) 2025/1090** 的应对策略与 **48 个月过渡期内的具体行动计划**；
- 是否布局**非干法纺丝**（熔纺）替代工艺、有无技术储备或合作项目；
- **当前 DMAC 溶剂回收率**、能否**近零排放**、**重庆灯塔工厂回收技改经验是否可复制**；
- **混合溶剂 / 替代溶剂方案**与 **专利 CN202210037060.5 的产业化进展**；
- 是否考虑与**河北邦泰**等熔纺厂商对标或合作；如何看待**熔纺 vs 干法**。

**D. 产能 / 商务 / 合作**
- **2026 年 1 月公告的 36 亿元、20 万吨高性能低碳化氨纶扩建项目（瑞安）**的**产能释放时间线**与**卫材级专用产能占比**；
- 常规**交货周期、MOQ、是否支持定制规格**（特定旦数 / 回缩率）；
- **出口欧盟产品的 REACH 合规成本如何体现在报价中**（源文为待问项，**无数值**）；
- **联合开发卫材专用氨纶**的合作模式（定制化产品 / 联合实验室 / 技术授权）。

**E. 下一代技术**
- 是否有类似"**千禧 HDS**"的**下一代卫材氨纶在研项目**；**抗蠕变能否从 2.6% 进一步降低**；
- **透气氨纶专利 CN117845366B（2026 年 6 月授权，低旦数高回弹）**是否可用于卫材、如何**平衡透气性与弹性**；
- **再生氨纶 / 生物基氨纶**研发进展。

### 7. 拜访策略与索取清单（内部方法论）

**策略（源文明写，内部方法论）：**
1. **先建信任，再谈条件** —— 华峰是国产龙头、体量远超一般供应商，**不以"甲方压价"姿态出现**，**以"技术合作伙伴"身份切入**；
2. **去 DMAC 议题要"帮华峰想"而不是"考华峰"** —— 他们已在做回收技改与专利布局，讨论应聚焦**"我们作为下游客户能给什么样的需求拉动或联合开发激励"**；
3. **利用莱卡对标但不硬踩** —— **坦诚承认无油无粉上的差距**，请华峰说明**追赶路线与时间表**，比假装没差距更有说服力；
4. **价格讨论放在最后** —— 先谈技术与能力，确认技术匹配后再进入价格与商务条款。

**机理追问点**：**2.6% 回缩率来自提高 MDI 含量 → 增加硬段 → 氢键化**，可请其说明**分子量分布控制与批次稳定性数据**；**含油 6.5% 的油剂种类（酯类 / 胺类 / 硅油类？）与滑石粉替代方案**是与莱卡对标的核心差距。

**索取清单**：DMAC 残留**第三方检测报告（顶空-GC-FID）**，**目标 ≤0.05%**；**OEKO-TEX Standard 100 证书**及覆盖规格；**千禧 HDS 620 dtex 样线 5–10 kg** 用于内部台车验证（回缩率 / 弹性回复率 / 粘连性 / 高速线适配）；**TDS + COA**；申请参观**重庆灯塔工厂或瑞安在建工厂**（溶剂回收系统、纺丝甬道、检测实验室）。

## 关键论断 Key Claims

1. **2028Q4 是硬倒计时** —— REACH (EU) 2025/1090 已生效，**DMAC ≥0.3% 即禁止**，人造纤维过渡期 48 个月；**出口欧盟产品线必须在 2028Q4 前锁定合规供应商**。**这把"选哪家氨纶"从成本问题变成了合规生存问题。**
2. **"≤0.3% 是红线不是目标"** —— 源文明确把合规红线与内控目标分开：**内控目标 ≤0.05%**（华峰灯塔工厂回收技改后水平），**专利 CN116148299A 给出 ≤0.1%（1000 ppm）**。**只盯红线没有安全余量。**
3. **华峰的主路径（回收+净化）可能过不了硬限** —— 源文直言路径 3「**REACH 2028Q4 硬限时可能不够**」；**而真正的无溶剂路线（熔纺）华峰无公开布局**。**这意味着"国产替代首选"与"合规首选"可能不是同一家。**
4. **抗蠕变优势与表面安全性劣势来自同一处化学** —— **2.6% 回缩率来自提高 MDI 含量 → 更多硬段 → 氢键化**；而**含油 ~6.5% + 滑石粉**正是干法纺丝的配套处理。**性能领先与安全性落后是一枚硬币的两面**，不是可以分别修的两个问题。
5. **"无油无粉"是莱卡最深的护城河** —— 7 项对比中华峰只在**回缩率**与**性价比**上胜出，**弹性回复率相当**，而**表面安全性、高速线适配、品牌背书、出口合规**四项皆落后；**莱卡 T859 还能省 20% 弹性用量**。**国产替代的窗口在性价比线，不在高端出口线。**
6. **超细旦是华峰的待验证项** —— 需求侧要 **≤20D/30D 级**（参照中柏 20D–105D），而华峰公开主打的是 **620 dtex 的 HDS**；**"千禧"是否真能做到超细旦，需要 TDS 与第三方报告而不是展会说法**。
7. **检测能力要自建** —— **GB/T 28004-2011 未设 DMAC 限值**，国内线因此**没有强制检测驱动**；源文给出的解法是**主动建立来料检测（顶空-GC-FID）**，并争取把它写进**长期质量协议条款**。
8. **谈判姿态本身就是技术资产** —— 源文把"**以技术伙伴身份切入、帮对方想、坦诚承认差距、价格放最后**"写成明确策略；**对体量远超自己的龙头供应商，"甲方压价"是负效率姿势**。
9. **专利是判断路线成熟度的抓手** —— 源文用 **CN202210037060.5（混合溶剂，产业化未知）** 与 **CN117845366B（透气氨纶，2026-06 授权）** 分别定位"在研"与"已授权"；**问专利号比问"有没有技术"更能得到真实状态**。
