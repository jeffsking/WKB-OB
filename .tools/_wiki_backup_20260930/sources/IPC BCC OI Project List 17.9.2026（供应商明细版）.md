# IPC BCC OI Project List 17.9.2026（供应商明细版）

## One-line Positioning 一句话定位

The **supplier-level working ledger** of the IPC BCC Open Innovation portfolio as of 2026-09-17: one row per supplier × technology, with capability notes, legal status (NDA/NNN/JDA) and the procurement POC. It is the deepest supplier-detail view in this batch and the source of the OI-2 / OI-5 / OI-7 / OI-8 action lines.
（2026-09-17 版 OI 组合的**供应商级工作台账**：每行 = 一家供应商 × 一项技术，含能力备注、法务状态与采购 POC；是本批供应商细节最深的一份。）

## Summary 摘要

The sheet is an Excel extract headed "Open Innovation" with columns No. / BU / Category / Technology / Stage / Supplier / Website / Contact / Email / Exploration / Supplier Enabling / NDA-NNN-JDA / Resource needed / IP-Exclusivity / POC. All rows sit at **Stage = Exploration**. Numbered entries cover **OI-1 NanoCellules (Hainan Bairuike)**, **OI-2 PVA fibre for TABCW (Anhui Wanwei; two contact rows)**, **OI-3 PTT resin (C1 Life Biotech)**, **OI-4 PVA/PTT REL Coco V6 (Yanjan)**, and **OI-5/6/7/8 special-shape liner fibre (Jiangnan / Fudi / Emon Jiangsu / Lenzing)**. Further unnumbered rows add trilobal lyocell (Lenzing, Wangjin), zeolite odour control (ZhongKe Yi Ran), **functional NW – tourmaline (Minrui + Rengo Nonwoven, tripartite with a Japanese partner, exclusivity sought)**, nano volcanic stone / graphene (Zibo Lanjing, with Americhem proposed as compounding route), **PDA resin and marine-degradable SAP replacement (Guoke Haina / CAS)**, COCO V6 core engineering (various), colour-changing NW / film (BLOCLO, Matsui), moisture-sensitive fibre and biomass PP/PET (FENC), 3-carded REL + SAP (Dayuan, NNN signed), and PPC-P + PBAT (Lianxin). The file lists contact persons, e-mail addresses and mobile numbers throughout, plus a few supplier quotations with MOQ — both excluded from this page (see the manual_review block).
