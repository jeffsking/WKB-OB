# CI-06 COCO V6 第三轮试产测试结果

## 一句话定位

COCO V6 **第三轮试产（CI-06）的实测数据库**：把 Code 1–17 的码位设计、材料来料实测、SAP 五组实测与产品级测试结果（回渗 / STT / Cradle 摄入与扩散 / L-H）落到同一本 Excel——是本库 **COCO V6 唯一的实测级来源**（其余均为准备/设计材料）。

## 摘要

试产于 **9/21–9/30** 在天津进行，共 **19 个码位**（Code 1–17 + Control 1/2），所有测试**均在中间加 bonding**。码位设计上，Code 1/2 为面层对照（含亲水胶 3.5*4 与 2*4 两档），Code 3/4 为「Control-2 基底 + 面层 1 / 面层 2」，**Code 5–8 为 SAP 变体**（100% 610 / 100% 950 / 50%610+50%511 / 50%610+50%950），Code 9–17 回到 NR 511 对照位并对 LSN / PSN / REL 做单变量替换（Unikorn 200 mm、Wangjin 水刺、Unikorn 155 mm、Minrui 上机 REL）。**打印导出时只有 Code 1、Code 2、Control 1、Control 2、Code 5 有产品级数据**，Code 3/4 与 Code 6–17 仍为空——**本批实测结论尚不完整**。材料实测侧：Liner-1（Yanjan Code 1）基重 45.22 gsm（标称 50）、厚度 1.721 mm、STT 0.874 s、层间剥离 115.28 N、pH 7.11；REL（Minrui）基重 33.48 gsm（名义 28）、STT 1.232 s、pH 6.69；Code 2-A（川越）未到货未测。SAP 五组实测给出 CRC / AUL / GBP / Vortex / PSD / 水分 / pH / 白度全量（见下表），其中 **High GBP 试产码实测 GBP 37.92**，与准备会材料所记 Code X 的 55.3 **不一致**。试产现场还记录了三类工程问题（Pad 重量/宽度/channel 居中需确认、PSN+REL 需换 110 mm Pad 规格、胶宽需减窄）。
