# CN 218515875 U（一种吸水性强的婴幼儿用尿裤·福建三只小猪）

## One-line positioning 一句话定位

A granted utility model（实用新型）implementing a **speed-graded SAP particle ladder**（吸收速度梯度差）inside a high-bulk hot-air nonwoven carrier — i.e. a concrete, parameterised embodiment of what this library calls [[SAP错峰膨胀]]：上层慢吸保干爽、下层快吸提利用率，中间层限量（10–15%）留膨胀空间。实用新型无实审，技术方案以结构布局为主，数据为定性区间。

## Technical breakdown 技术拆解

1. **芯体叠层（自上而下）**：一号热风法非织造布 → 一号干法非织造布（热熔胶复合）→ 一号 SAP → 二号 SAP → 高蓬松无纺布（内部再嵌五号、六号 SAP，为上/下层组合）→ 三号 SAP → 四号 SAP → 二号热风法非织造布 → 二号干法非织造布。
2. **SAP 选型双体系**：锯齿状不规则低温釜式聚合颗粒（1–3 号，偏慢速、利结合）+ 反向悬浮聚合葡萄状颗粒（4 号，最底层、最快 25–35 s）。
3. **速度-粒径同步递减**：330–340 µm/55–60 s → 280–300 µm/25–35 s，形成自上而下逐层加速的梯度。
4. **工艺特征**：复合芯体产线引入振动装置提升撒粉均匀性；中间层 SAP 占比 10–15%。
