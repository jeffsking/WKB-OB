# IPC BCC OI Project List 2026-09-18（重构版·19 项）

## One-line Positioning 一句话定位

The **deduped, renumbered portfolio ledger** agreed at the 2026-09-18 review: 19 projects, five technology platforms plus Elastomer, with per-project supplier base, priority, status, key follow-ups and NDA/NNN/JDA state. It is the most operationally current list in this batch and the one that explicitly splits COCO V6 into four workstreams.
（2026-09-18 评审确定**去重并重编号**后的组合台账：19 个项目、五大平台 + Elastomer，逐项列出供应商、优先级、状态、下一步与法务状态；是本批操作性最强、并首次把 COCO V6 拆为四条工作流的一份。）

## Summary 摘要

Header line: **"Updated 2026-09-18 · 19 projects (deduped from 25) · Priority: High 8 / Medium 8 / Low 3 · Category-based tracking + PPT component 展示."** The 19 rows are grouped as Fiber/Staple Fiber (OI-1…OI-4), Resin/Fiber → NW (OI-5…OI-10), Core = COCO V6 (OI-11 REL, OI-12 Liner, OI-13 SAP, OI-14 3-carded REL + SAP), Chemical+Film/Indicator (OI-15 thermochromic, OI-16 hydrochromic, OI-17 mechanochromic), Odour Control (OI-18) and Elastomer/Adhesive (OI-19, marked ★NEW). COCO V6 REL (OI-11) is a **28 gsm TAB composite web, 2-card Z-stack, five fibres — 2D ES PE/PET 32%, 3.5D hollow ES 30%, 7D PTT/PET S×S 24%, 3D PE/PET 6%, 6D PVA 8%** with PTT/PET + PVA mandatory; measured **1st STT 1.02 s, thickness 1.01 mm, SAP capture 62%**, KPI "3rd-void rewet ≤ control, MD distribution ≥ +30% (target 34.9%)". COCO V6 Liner (OI-12) is an **ATB dual-layer PE/PET bico 50 gsm, 4 strata / 2 carding systems** with trilobal PET 30% (15 gsm, 5% at skin), CD tensile 9.3 N/50 mm vs an 8.0 N floor at 600 m/min and modelled +15% MD distribution. SAP (OI-13) is a **dual-SAP architecture** with the four-code comparison KC 511 / NR-610S / NR-950 / Code X. The summary sheet also publishes the **merge/dedup map** and the full **old→new renumbering** table, plus follow-ups by owner (Chris / Claire / Teng).
