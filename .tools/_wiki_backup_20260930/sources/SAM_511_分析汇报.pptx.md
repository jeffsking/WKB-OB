# SAM_511_分析汇报.pptx

## Basic Information 基本信息
- **Title**: 511 水刺布打样 · 三视角实验分析
- **性质**: 基于 SAM_511_分析数据.xlsx 的三 Agent（趋势/结构/异常）并行实算汇报层；配套原始数据审计页 [[SAM 511 Trial Dataset and Statistical Audit（打样原始数据与实验设计审计）]]
- **对象**: 诺尔 SAP 牌号体系（511/951/N8/959/610S/930/住友）在 511 水刺布打样中的搭配实验
- **Domain**: Material / SAM

## Overall Insights 整体洞察（整体洞察）
- **回渗最强趋势**: 随时间 1-2 个数量级攀升，25/34 min 无平台——单调急升、无饱和。
- **纯 511**: 综合排名前二，但 **3/7 留存三协议全最差**（≈最优 2.6×）——"可行但留不住"。
- **比率主导**: 5/5 vs 3/7 为第一主导轴，单指标摆动最大；3/7 提吸收/扩散但恶化留存（方向分裂大效应）。
- **N8 失效**: 511/951+N8 吸收速度双封顶（新国标 90s / 企标 60s）= 吸收未完成，配方整体失效；N8 全混淆无法孤立评估。

## Ranking 综合排名（综合排名 · 归一 23 项）
1. 全511（3/7） 2. 全511（5/5） 3. 511/951+959 4. 930/住友 …
- 添加剂效应: **959 净正（+0.08）**；610S 中性偏负；N8 不可孤立。
- 跨协议一致性: 前二与末段稳健；**中段（511/951、930/住友）排名剧烈翻转**。

## Anomalies 异常与风险（异常与风险）

| 级别 | 异常 |
| --- | --- |
| CRITICAL ×2 | 511/951+N8 新国标 90s、企标 60s 双封顶（吸收未完成） |
| WARN | 全511(3/7) 新国标回渗 5.312 g（z+3.11）——可解释的比率效应 |
| WARN | 全511(5/5) 测试日期错位（6/19 vs 7/16-18）→ 批次混淆 |
| INFO | 930/住友 结构性对照离群；扩散异常均回溯至 N8 与日期混淆 |

## Hypotheses 假设验证（假设验证）

| 假设 | 结论 |
| --- | --- |
| H1 纯 511 可行 | 部分支持（前二但留存差） |
| H2 复配优于纯 | 混合/弱（仅 959 有益） |
| H3 N8 有益 | 失败/倒置（归因不安全） |
| H4 比率影响 | **强支持（最稳健）** |

统计口径：无组内重复 → 无法做正式检验；以跨协议一致性 + 留一法 z 为代理。

## Limitations 局限性（局限性）
无组内重复；全511(5/5) 早测 1 个月（批次混淆）；上下层比例未受控；930/住友不同 SAP 基；N8 全混淆 + 封顶；协议构造不同致绝对值不可跨比。**未记录**: SAP 批号/粒径/交联度、布克重、湿度、操作员、凝胶强度。

## Next Steps 后续实验与行动（后续实验与行动）
- **PO**: 重构可统计设计（固定比率、纯 511 系 5/5 组 ≥3 次重复）；全511(5/5) 同批重测。
- **P1**: N8 孤立单元 + 比率扫描（5/5→2/8）。
- **P2**: 补协变量记录 + 统一主协议为企标。
- **P3**: 扩样本（n≥3）+ 正/负对照锚定量纲。
- **王总行动清单**: 立刻剔除 511/951+N8（配方失效非普通离群）；本周纯511 比率扫描 + N8 孤立打样；同步同批重测与模板补录（湿度/批号/克重）。
