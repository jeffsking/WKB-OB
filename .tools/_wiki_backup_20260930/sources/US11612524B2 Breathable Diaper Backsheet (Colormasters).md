# US11612524B2 Breathable Diaper Backsheet (Colormasters)

## 一句话定位

Granted US patent (Colormasters, LLC) on a **breathable diaper backsheet** — a backsheet-film construction patent in the "backsheet" cluster of this IP block.

## 摘要

The patent (title: "BREATHABLE DIAPER BACKSHEET") grants a breathable diaper backsheet. The bibliographic header lists assignee Colormasters, LLC (Albertville, AL, US), inventor Robert Estill Chambliss, and a classification set spanning A61F 13/514, A61F 13/49, A61L 15/18, A61L 15/26 and B32B (multilayer film constructions). It is a continuation of US 2021/0251819 A1 (filed Feb. 19, 2020). Detailed claim language on the breathable backsheet structure is in the full text; this summary captures the bibliographic and classification scope.
