key_claims:
  - **主流程六段**：原材料准备 → 混合（静态混合器 + 混合罐，搅拌 + 降温）→ **聚合反应（水状 → 凝胶）** → 干燥（滚筒热风）→ **研磨筛分** → **后处理（表面交联）** → 包装
  - **聚合**：混合液上料至聚合罐，**吹氮排空**后聚合；**造粒机造粒** → 滚筒**燃烧热风**烘干（**进风温度最高 500 ℃**，物料翻滚如糖炒栗子）→ 尾部**强磁磁选**除铁屑
  - **低温聚合、后中和**（先聚合后中和）：先中和会**大量放热**、**影响内部结构**、反应过快、易有**溶出物**；本工艺走**小罐慢跑**，靠**10 个聚合罐**（蓝湾）轮流实现连续生产
  - **研磨为干态闭环**：摇摆筛 + 磨机循环，粗料回粉碎机再磨，直到达到目标粒径；**色选机**剔除黑点/脏料；筛分三分类 —— **颗粒（回磨）/ 合格（进半成品罐）/ 细粉（回胶体二次混合）**
  - **后处理是"双层"**：**上层加表面交联剂**；**下层加抗静电、抗黄变与抑菌类原料**（对应前一日的**离子交换涂布/涂覆**）→ **130 ℃ 左右高温烘干**使表面交联更彻底
  - **加料为分步多次混料**：高速混合机（近百个小桨叶片）→ 膨料机 → **双轴搅拌**，**每台设备各加一种原料**（分步加料更均匀）；**绞龙只做计量**，与引发剂添加量**DCS 连锁**（1 吨按比例、2 吨按比例）
  - **固含**：进入后处理前约 **96%**；加入液体引发剂后表面带水、固含下降 → **浆液干燥机二次烘干**保证固含
  - **粒径**：成品 **300–600 μm**（"大概八十" 所指不明 [待验证]）；筛网目数固定，**30 目以下为合格**，**30–50 目也可以**；半成品粒径**刻意偏大**，因后处理三次搅拌会破碎
  - **过程控制是开环的**：**无在线粒径监测**，靠**每小时抽样检测**（成品/半成品/包装）与**经验**控制 PSD；本方当场指出这一点并追问"如何确保进成品罐的 PSD 最佳"，**未获实质答复**
  - **包装四道**：**色选机（黑点）→ 磁选器（铁屑）→ 过筛防结块 → 精检仪（金属；报警则对应产品剔除隔离）**
  - **二氧化硅已在使用**：在高速混料机加液处加入，目的是**改善颗粒流动性（flow rate）**；不加则颗粒粘连、流动性差、影响吸水性
  - **未来加纳米级粉末**：现场设备**全密封**，供应商口头认为可行（李振 [待验证]）；加入点与条件待定，需本方提供粉末条件

# SAP Production Process Walkthrough — Polymerisation, Grinding & Surface Treatment（I sap生产流程介绍）

> ASR 转写讹字说明：本稿为**供应商工厂会议室的工艺流程讲解**，中文口述、**时间戳乱序**，专业术语讹字较多。已识别的还原与存疑：
> - **「I sap / SAP」** = **高吸水树脂**；「丙酸 / 丙烯酸」= **丙烯酸（acrylic acid）**；「中水」= **自来水 / 净化后的去离子水**
> - **「综合 / 中合」** = **中和**；「氢氧化碳」= **氢氧化钠（加碱）** [待验证]；「前中和 / 后中和」= 中和在聚合前 / 后
> - **「造粒龙 / 绞龙」** = **造粒机 / 螺旋输送机（计量用）**；「摇摆开 / 摇摆筛 / 摇摆箱」= **摇摆筛（筛分）**
> - **「磨期 / 磨机」** = **研磨/粉碎机**；「色选机」= 剔除黑点与异色颗粒的光选设备；「磁选器 / 强磁磁感器 / 精检仪」= 除铁屑与金属检测
> - **「皂壳 / 浆液干燥机 / 胶原压动机」** = **表面处理后的干燥设备**（烘干使表面交联更彻底）[待验证]
> - **「引发剂」** 在文中既指聚合引发剂，也指**表面交联剂/后处理添加剂**，属一词多用 [待验证]
> - **「负四组 / 负六组 / 零五组」** = 混合罐降温后的温度口径（**数值与单位均 [待验证]**）
> - **「清水性」** = **亲水性/吸水性** [待验证]；「毒素…不会在一起」= 颗粒**粘连、结块** [待验证]
> - **「蓝湾」** = **山东蓝湾新材料**（诺尔系新厂区）；人名「销售 / 宋总 / 李振」均为**音转** [待验证]

## Key decisions 决策要点

**本次为工艺流程讲解与现场参观，会议本身未形成决策。** 以下仅记录**供应商在会上明确陈述的既有工艺事实**（非本轮决策）：

1. **主流程已定型为六段**：原材料准备 → 混合 → 聚合 → 干燥 → 研磨筛分 → 后处理（表面交联）→ 包装。
2. **采用低温聚合 + 后中和**（先聚合、后加碱中和）—— 供应商明确说明：先中和会大量放热、影响内部结构、反应过快、易产生溶出物；本工艺是"**小罐慢跑**"，靠 **10 个聚合罐**轮转实现连续。
3. **半成品粒径刻意做大**：因后处理段要经历**三次搅拌**，颗粒会被摩擦破碎 → 半成品粒径必须偏大，否则成品偏细。
4. **二氧化硅已在使用**（非新增）：在高速混料机加液处加入，用于改善颗粒流动性（flow rate）。
5. **现场设备全密封**：供应商据此认为后续添加纳米级粉末在安全与质量上可行。

9. **上下层表面处理的配方细节未展开**：上层为表面交联剂、下层为抗静电/抗黄变/抑菌类原料（对应"离子交换涂布"），**具体成分与加量未披露**。
10. **现场参观范围受限**：包装工序"挨着、可以看"，但部分区域因**防爆设计 + 隔离墙**，需现场确认可见性；本方"回头再请教"。

## Background 背景

本方访问诺尔系**蓝湾新材料**厂区，由 SAP 生产负责人按流程图讲解从丙烯酸 + 水到成品包装的完整工艺，随后现场参观中控 DCS 与展厅。讲解的重点在后处理段（表面交联 / 上下层分步加料）与质量控制方式（抽样检测、无在线监测），并与前一日的 GBP 提升方案讨论形成呼应。
