# STM-00497 Intake via Bladder Box（成人/女性护理产品压载摄入法·草案）

## 一句话定位 One-line positioning

K-C **Adult & Feminine Care（成人护理/女性护理）**条线的标准测试方法草案：**用充气泡（bladder box）对产品施加消费者相关压力，在该压力下测得 3 次摄入时间与随后的回渗**。本库回答「为什么摄入测试要在压力下做」「AFC（失禁/女性护理）与 BCC（婴儿护理）为何不能用同一套加液表」时应回到本页。

## 摘要 Summary

文件的 PURPOSE 段开宗明义：本方法用于**在消费者相关压力下测量产品的液体摄入时间**，摄入后按回渗方法学测量表面干爽度。适用范围为 Global QA、Corporate Research & Engineering 与合规性测试设施，覆盖 Personal Care 与 K-C International 的 Adult Care 与 Feminine Care 业务单元。实际操作分为三段：**试样制备**（去外包、称重到 0.01 g、测厚度到 0.1 mm、按几何规则找加液靶点；Depend 产品还需完全拉伸固定并剪除腰围橡筋，保留距吸收体边缘至少 1/4 英寸）、**加压摄入**（产品贴合并固定于 bladder box 顶部的进液口，夹紧后充气至 0.25 psi，按产品表设定泵的流速与加液时间，同时按停表与泵运行键，液体被完全吸收即停表记为该次 intake time；间隔 15 分钟重复，共 3 次，第 3 次后按 abort 泄压）、**回渗**（两张预称吸水纸 + 0.7 psi/25 mm 砝码压 2 分钟，称量吸水纸增重）。文件同时给出覆盖 **Poise（Liners / Ultra Thin / Moderate / Maximum / Ultimate Pad，Regular 与 Long）**与 **Depend（DAU / DPU1 / DPU2 / DSU1 / DSU2 / Maximum Protection Briefs）**的加液参数 Tables 2–6，并明确单次冲击量来自 **ULS 或 HUT 的第 95 百分位总载量**。

## 关键论断（key_claims）

- **压力是摄入测试的隐藏自变量**：低压/常压法会系统性高估产品摄入能力——本方法把 0.25 psi 显式写进步骤，正是为了消除这一偏差 —— 支撑页：[[Bladder Box Intake Test（膀胱箱压载摄入测试）]]
- **加液量不是实验室拍脑袋，而是 ULS/HUT 使用数据的第 95 百分位**：这使不同品类（护垫 vs 失禁裤）的加液量天然不可比 —— 支撑页：[[SAM Testing Methods（超级吸水材料测试方法）]]
- **Run-off failure 是终止条件而非数据点**：液体越过腿部橡筋流到 bladder 上即判 FAIL 并终止 —— 支撑页：[[Bladder Box Intake Test（膀胱箱压载摄入测试）]]
- **回渗段（0.7 psi / 2 min）与压力摄入段（0.25 psi）是两种不同压力 level**，引用时必须分别标明 —— 支撑页：[[Rewet Test（回渗测试）]]
