# Composite Core Channel Structure & Bonding Method — Patent Clearance Review（导流压槽区结构及压合方式探讨·专利排查）

## 一句话定位

一场围绕 **复合芯体导流压槽（channel / groove）结构与上下层压合方式** 的专利排查会：把竞品与同行已授权专利逐件拆到权利要求层，逐条确认我方产品「有/没有」该特征，输出规避结论与未决风险。

## Key decisions 决策要点

> 只记会上明确「确认/可以排除」的事项；**每项结论仅对当前产品结构成立**。

1. **确认我方无「独立胶层」**：胶与吸水粉（SAP）先混合，再一并铺到蓬松层（REL）上，靠外漏颗粒与上下包裹层粘合 —— 与「上覆盖层 / 上喷胶层 / 上高分子层严格分层」的写法**有实质区别**，可据此规避。（⚠️ 见 Open issues：分层施胶仍是保留选项）
2. **确认不使用无尘纸（air-laid paper）**：某实用新型把上层限定为无尘纸、下层为无纺布（两者不同）；我方上下包裹层（LLSN / PSN）非无尘纸 → 可规避。附带影响：**后续上层若改用无尘纸将重新落入风险，需提前绕开**。
3. **确认复合芯体之外不加额外木浆纤维层**：多件专利（含「125 层」「13 层」「7 层」变体）在芯体外包外再加一层木浆纤维层以提柔软/吸水，我方**当前产品没有**，可规避。
4. **确认 REL 上不开宏观槽填塞 SAP**：瑞光系专利的发明点是「开槽起毛装置」在蓬松层形成宏观槽并**塞入 SAP 颗粒**；我方若在 REL 上开槽，目的是**捏合上下层形成通道**，用途相反 → 可规避。
5. **确认无 REL 预复合步骤**：某专利为提升单层蓬松层强度，先把 REL 与一层无纺布粘合成复合层再承接 SAP；我方为 REL 直接进线 → 可规避。
6. **确认导流槽形成方式为「切割 / 挡板不铺粉」，而非对折机构**（某专利以折叠机构形成厚度差作为导流槽）→ 可规避。
7. **确认芯体无纺布本身不分层**：有专利限定无纺布分上层纤维/下层纤维且比值不同；我方为同一层 → 可规避。
8. **实用新型类专利整体按「可挑战」处理**：范围过大、未经实审，无效成功概率较高，不构成本轮主要风险。
9. **本轮方法论确定**：凡专利**背景技术中明确排除**我方所用方案（如「蓬松无纺布吸水差」而改用亲水纤维/植物纤维导流层）的，不必再比结构，属**极强排除**。

## Open issues 待决问题

- **孔隙率 91–99% 的数值限定（日本公司发明专利，2010 年申请 `[待验证]`）**：该专利以「孔隙度 91–99% 的纤维机制」替代蓬松无纺布。我方蓬松层原材料孔隙率大概率在此区间，**但成品经 SAP 填充与工艺压缩后会下降**；是否落在该范围**未算过**，需按其说明书给出的公式（含「一定负荷下的厚度 T」）实测复核。→ **本轮未排除**。
- **粘结剂 / SAP 质量比 0.05–2.0 倍**：我方现总施胶量约 14 g/m²、SAP 约 366 g/m²，**比值约 0.03–0.04**，低于下限 0.05，但「有点危险」——未来商业化提速、施胶量上升可能进入区间。→ **需留观**。
- **REL 本身是否算「开槽」**：某专利限定槽孔面积占芯体面积 **10–15%**、单位面积 **1–5 cm²**。若未来切割 REL，是否落入该区间**未定**；关键前提是该专利要求 **REL 自身开半槽/通槽**。
- **透光率 30–75% 限定**（反映吸水颗粒分布均匀性）：需确认我方是否有现成可测数据。
- **施胶方式未最终冻结**：混合施胶 vs 分层施胶仍是 option，若改成分层，上述第 1 条规避理由失效。
- **压合覆盖范围未验证**：理想设计是所有无 SAP 的凹槽位都压，但高速下能否 100% 覆盖、复杂花型是否只压主要区域，**尚待验证**；「狗骨头/哑铃形」侧边区域目前**不规划压**。
- **未来设计变化需重做评估**：上下层 SAP 宽度/长度减窄（saving 方向）、外层加木浆纤维层、三成型鼓工艺（REL 先包裹承接 SAP 再复合）——任一项落地都要**重新做 FTO**。
- **设备合作模式的专利定性**：我方基于**恒昌**设备做约 30% 升级改造后自产，是否构成「制造行为」而非「使用行为」→ **会后确认**。
- **权属核查**：某件专利申请人曾注册「多邦食品」（已注销），需确认是否已继承给「嘉邦」（离线芯体制造商）→ **会后确认**。

## Background 背景

复合芯体（蓬松无纺布 REL + 上下 SAP 层 + 上下包裹层）是行业主流路线，中日两国厂商（瑞光、恒安、黄山富田、贵州卡布、美佳爽、杭州豪瑞、嘉邦等）围绕「导流槽怎么形成」「上下层怎么压合」「中间层用什么材料」布局了大量已授权专利。本次会议即为 COCO V6 结构在当前专利地图下的逐件比对。

## 关键论断（key_claims）

- **我方相对竞品专利的主要规避支点是「胶与 SAP 混合、无独立胶层」与「不用无尘纸」两条结构差异** —— 支撑页：[[Composite Core Patent Clearance（复合芯体专利规避审查）]]
