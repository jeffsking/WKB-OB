# BNC 卫生用品技术可行性评估（访前尽调详细版）

## 一句话定位

本批**访前技术尽调版（2026-08-24，14 页 Slide 大纲）**：站在教科书与文献基础上对 BNC 做入口排序，并给出访厂必问清单。与 [[BNC 卫品技术可行性评估（Slide 大纲版，20260824）]] 内容基本同源（互为同一 deck 的两种导出），本页为 PDF 导出细节稍全的版本。

## 摘要

文档基于《Absorbent Technology》(Elsevier, 2002) Ch.12、EDANA AHPs 白皮书（2022）、SAP Research Advances（2024）与《Industrial Drying Handbook》分析，在访厂前给出判断。**材料部分**：BNC 由 Acetobacter xylinum（也有 Rhizobium、Agrobacterium）在简单葡萄糖培养基上产生，以 40–60 nm 宽、由 50–80 根 3–4 nm 微纤组成的组织化带条挤出，带条缠结成连续纳米网络（pellicle 膜）而非离散纤维；纯 Cellulose I、高分子量、无木质素与半纤维素；教科书评价其「具潜在工业重要性」，列为吸收性产品的第一生物技术路线。**性能含义**：纯度（无漂白残留）→ 低刺激宣称与「零化学处理」定位；纳米网络 → 巨大比表面积、持水与成膜强度；高结晶度 → 高模量，但**亲水 ≠ 超吸水**；天然纤维素靠氢键 + 微毛细（孔隙 <0.02 µm）持水，90% RH 下最高吸湿约 15%。**入口排序**：① 湿巾/高端面层基材（最佳匹配，含 HDI/IPDI 乳液浸渍 0.3–1.5% 上浆、100–130 ℃ 固化、湿强度保持 40–60%；E-beam 交联 10–50 kGy、湿强度 +30–60%、无化学残留两条成熟湿强路线）；② 气凝胶芯体/ADL 增强（干燥路线决定纳米结构）；③ BNC 接枝可降解 SAP（仅实验室，丙烯酸接枝纤维素 1,125 g/g DI 水、HEC-g-PAM 达 3,000 g/g；150 天 20% 湿度土壤中质量损失 46.7%；但 1% NaCl 中仅约 100 g/g）；④ 绒毛浆替代（**否决**）。**安全合规**：EDANA 保守迁移因子——纸尿裤 7%、湿巾更高，即便是「天然」BNC 也须做迁移评估；发酵与精制环节须控制纳米颗粒粉尘的吸入/经皮暴露。**访厂必问清单**与**推荐路线图**（短期 1 个月：湿巾基材 30–60 g/m² 打样 + 湿强验证 + 皮肤贴片预筛；中期 3–6 个月：气凝胶 ADL 中试；长期 12 个月+：接枝 SAP 联合开发）一并给出。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| 入口排序 | 湿巾/面层（高）> 气凝胶 ADL（中高）> 接枝 SAP（中）> 绒毛浆替代（否决） | 访前判断 |
| 纤维尺寸 | 40–60 nm 宽，由 50–80 根 3–4 nm 微纤组成 | 纯 Cellulose I |
| 天然纤维素持水上限 | 90% RH 下最高约 15% 吸湿；微毛细孔隙 <0.02 µm | 靠氢键 + 微毛细 |
| 湿强路线 A | HDI/IPDI 乳液浸渍，0.3–1.5% 上浆，100–130 ℃ 固化，湿强保持 40–60% | 教科书成熟 |
| 湿强路线 B | E-beam 交联，10–50 kGy，湿强 +30–60%，无化学残留 | 婴儿/医疗级 |
| 干燥路线决定结构 | 同配方：烘箱干燥 vs 乙醇置换 + 超临界 → 粒径 ×5、比表面积 ×23（4.88 → 113.8 m²/g） | Industrial Drying Handbook |
| 超临界条件 | Tc 31 ℃ / Pc 7.29 MPa | 零毛细应力 |
| 接枝纤维素吸水 | 丙烯酸接枝 1,125 g/g（DI 水）；HEC-g-PAM 达 3,000 g/g（DI 水） | 实验室 |
| 接枝 SAP 致命缺陷 | 1% NaCl 中约 100 g/g（尿液约 0.9% 盐） | 盐敏感性 |
| 接枝 SAP 降解性 | 150 天、20% 湿度土壤中质量损失 46.7% | — |
| 接枝 SAP 现实定位 | 替换 10–20% SAP 以支撑高端线「可堆肥芯体」宣称 | 教科书称未工业化 |
| 绒毛浆全球供应 | 约 24 Mt/年 | 发酵无法匹配其规模经济 |
| 芯体配比基准 | 纤维素/SAP 典型 80/20 – 90/10 | EDANA 2022 |
| 迁移因子 | 纸尿裤 7%，湿巾更高 | EDANA 保守值 |
| BNC pellicle 含水量 | 约 99% 水 | 脱水是所有路线的成本瓶颈 |
| 打样基重 | 30–60 g/m²（短期湿巾试验） | — |
