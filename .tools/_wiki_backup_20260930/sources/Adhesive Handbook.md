## Key Themes 核心主题

1. **粘接机理五大类**：WLB 湿润、表面能、渗透、锚定、静电——适用于所有粘接场景。
2. **工艺参数与胶料同等重要**（Ch47: "约50%性能取决于工艺参数"）——卫材粘接优化的双轨策略。
3. **Hot melt 体系**（EVA/APAO/polyamide/TPU/curing hot melt）——芯体复合、SMS 复合、湿巾封口的最常用胶种。
4. **UF/湿强剂化学**——UF 树脂 F/U 摩尔比、氨基亚甲基键水解、E1 甲醛排放——直接适用于湿强剂研发与合规。
5. **CWBL/MWBL 弱边界层**——浆粕表面蜡质覆盖与加工损伤是粘接性能核心变量，映射浆粕采购质量索赔。
6. **PMDI 渗透深度为 PF 的 5-10 倍**——MDI 类湿强剂性能优势的物理解释。
7. **生物胶黏剂 mesh size 与 SAP 凝胶网络动力学对应**——交联度→mesh size→吸收速度/倍率 trade-off 的概念桥梁。
8. **天然基胶黏剂**（tannin/lignin/laccase）——对应卫材"无胶复合"与"bio-based hot melt"研发方向。
9. **汽车包装封合技术**——direct glazing、PSA tapes、two-part acrylic 与湿巾软包/纸尿裤腰围胶带技术同宗。
