## Key decisions 决策要点

1. **材料伸长率不能按比例外推（本页最关键的工程判据）**：不同 PE 材料的伸长率差异极大 —— 有的 **>500%**，有的 **<200%**；因此**不能简单按比例放大**（"can't multiply one by eight"）。
2. **超薄芯体路线（婴儿护理线）**：采用 **绒毛浆（pulp）+ mesh（网材/成网技术）**组合 → **降低整体克重（BK/BW）同时保持性能**。
3. **绒毛浆分区分布（推荐项）**：替代"在整个芯体上均匀分布绒毛浆"，改为**把绒毛浆精确集中到需要的部位**（芯体/吸收区）→ 同时提升**性能、材料效率与舒适度**；供应商称已成功应用于 core 与 cover [待核对]。
4. **配比为混合体系但数值待确认**：本方问"是纯绒毛浆还是与 SAP 混合"，确认为**含 SAP 的混合材料**；比例在会中出现 **50/50** 与 **70/30**（"Seven thirty"）两个口径 → **须书面确认**。
5. **两种 pinhole cutting 方式（已确认）**：**carving part** 与 **tapered（锥形）** —— **锥形针对小孔/小尺寸更容易**。
6. **DLC 涂层的三个作用（已确认）**：① **减轻热量**；② **更光滑**；③ **防止材料粘/撞在一起**。涂层涂在**针的外部**。
7. **形状难度的排序（已确认）**：**圆孔最容易**（精度要求低）；**圆孔之后做其他形状难度上升**，对精度要求更高，且材料容易粘/撞在一起。
8. **Pilot 的边界（已明确）**：**不是真正的 pilot line**，而是**小型 pilot 模块**；最高 **500 m/min**；可讨论**安装到本方机台**；某通道（疑为 unwinding/rewinding）**可更换**。
9. **新模块的成熟度（已明确）**：新 pinhole 模块**仍只是概念**，**两种型号**均在开发中，预计 **2–3 年**；开发方的工作是"厘清工艺（figure out the process）"并提供使工艺可行的细节；**已有另一款 pinhole 模块在机台上高速在线运行**。
10. **推广对象（已明确）**：开发方拟将新模块推广至 **Yuhan-Kimberly**；本方建议同时也向本方推荐。
11. **合作资源（已明确）**：本方拥有来自 **IPC 与 Casey China** 的团队，若项目推进可 **co-develop**；本方将**提供测试材料**，若 promising 则推进共同开发。

## Open issues 待决问题

1. **日期矛盾**：文件名时间戳指向 2026-09-20，纪要标注整理日期 2026-09-04 —— **需核对**。
2. **配比未定**：50/50 与 70/30 两个口径并存 → **须书面确认**。
3. **克重口径未对齐**：10–18 gsm 与 18/18、30/30 的对应关系不明 → 需结合产品方实际产品确认"高/低克重哪种更容易"。
4. **涂层安全未闭环（本方核心关注）**：涂层/针与材料**直接接触** → 担心**粘附或迁移到材料上**；要求**对健康无害、对环境无害**；开发方称有多种涂层方案（various coating）会进一步确认，会中认为某一 type 更优 —— **未给出结论**。
5. **六项推荐中其余项未展开**：录音只清晰展开了部分（PE/克重、绒毛浆分区、超薄芯体、弹性恢复、Kirigami/共开发、打孔数据/涂层/pilot）→ **建议向开发方索取完整推荐清单与议程**。
6. **术语待确认**：carving part / uncarpeted part、thosson carbide / kirigami、BK/BW、PLO / "jo for p area"、IPC/Casey、Jareds、Sam 等 —— 纪要自身建议"以双方确认后的术语表为准"。
7. **切割/清洁问题**：录音提及"清理切过来，修不掉……肯定洗不掉，很难洗" → 涉及模块安装或材料切割后的处理，**需后续澄清**。
8. **模块成本未给出**：完整 pinhole module 的成本待开发方回复，本方采购将联系。
9. **高速热变形风险**：高速下产热导致**材料变形**，本方判断为**关键**；认为可通过**针的密度**缓解 —— **未量化**。
10. **弹性恢复的材料体系待确认**："未使用 cyber / 使用 spanx"的具体所指，以及成人产品的材料体系 —— **待核对**。
