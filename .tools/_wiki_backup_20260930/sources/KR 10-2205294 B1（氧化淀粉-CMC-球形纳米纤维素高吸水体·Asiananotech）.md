# KR 10-2205294 B1（氧化淀粉-CMC-球形纳米纤维素高吸水体·Asiananotech）

## One-line positioning 一句话定位

**韩国授权发明专利**（등록특허 10-2205294，B1；专利权人 **주식회사 아시아나노텍 / Asiananotech**）。它给出了一条**不含任何外加化学交联剂**的生物基高吸水体路线：**氧化淀粉的醛基**（aldehyde group）与 **CMC 的羟基**（hydroxyl group）以及**球形纳米纤维素的羟基**发生**缩醛交联**（acetal crosslinking），形成聚合物 A 与聚合物 B。说明书自报的 0.9 % 盐水吸收量最高 **45.8 g/g**、保水量 **37.5 g/g**，**均超过同批对照的合成 SAP**（41.5 / 34.1 g/g）。这是本库少见的、用**淀粉＋CMC＋纳米纤维素三组分**把"生物基"与"性能不输 SAP"同时写进权利要求的专利。

## Abstract 摘要

发明名称（韩文原题）：**나노 셀룰로오스와 카르복시메틸 셀룰로오스에 전분을 가교시켜 제조한 고흡수성 흡수체 및 이의 제조 방법**（以淀粉交联纳米纤维素与羧甲基纤维素制得的高吸水性吸收体及其制造方法）。摘要（(57)）逐字要点：**氧化淀粉的醛基（aldehyde group）与羧甲基纤维素的羟基（hydroxyl group）缩醛交联（acetal crosslinking）结合**的高吸水性吸收体及其制造方法。

独立权利要求 6 逐字：包含**淀粉、羧甲基纤维素及球形纳米纤维素**，其中所述淀粉的醛基与所述羧甲基纤维素的羟基**缩醛交联**结合而成聚合物 **(A)**；以及所述淀粉的醛基与所述球形纳米纤维素**缩醛交联**结合而成聚合物 **(B)** 的高吸水性吸收体。

## Key claims 关键论断

- **"无外加交联剂"是本案的核心工程主张**：网络完全由**氧化淀粉醛基 × CMC/纳米纤维素羟基的缩醛反应**自交联形成（[0030]、[0041]），从而绕开了传统纤维素醚化工艺中 **MSDS 列为有害毒性气体的环氧乙烷／环氧丙烷**（[0006]）。→ [[Starch-CMC Acetal Crosslinked Superabsorbent（淀粉-CMC 缩醛交联高吸水体）]]
- **三组分而非两组分**：权 6 同时要求聚合物 **A**（淀粉–CMC）与聚合物 **B**（淀粉–纳米纤维素）；实施例显示 **O-CNF 从 0 → 1 → 2 wt%** 时，凝胶形成评价由 **○ → ◎ → ◎**，窗口由 6:4–8:2 拓宽至 **4:6–9:1**，吸水量由 35.3 → 43.6 → 45.8 g/g。O-CNF 是性能跃迁的关键变量。
- **生物基路线首次在本库中做到"超过合成 SAP"**：SAC 2 (1 g) 与 SAC 2 (2 g) 在**吸水量与保水量两项上同时超过**对照合成 SAP（约 +5 % 与 +10 %）。但对照 SAP 仅一款且未标注牌号/规格 → 该"超过"的**可比性有限**。→ [[Sodium Polyacrylate SAP vs Cellulose-Based SAH（成本·性能·供应链）]]
- **原料取自非木质生物质**：油棕树干（oil palm trunk, OPT）的**薄壁细胞**（parenchyma cell）经 ClO₂/乙酸 + NaOH-乙醇/氯乙酸 + 研磨，得到 **10–50 nm 球形**纳米纤维素（TEM 实测 18.39 nm、33.93 nm）；说明书指出需先分离薄壁细胞，否则纤维间结合受阻。→ [[Citric Acid Crosslinked Cellulose SAH（柠檬酸交联纤维素超吸水凝胶）]]
