# STM-00040 厚度.docx

## 一句话定位

南京厂成品 SOP **STM-00040（第 2 版，2021-08-24）**：在 **0.2 PSI** 压力下用厚度仪测**婴儿纸尿裤厚度（mm）**——是本库成品厚度的**通用低压口径**，与澳洲出口专用的 [[澳洲厚度测试.docx]]（成品 TTM-001）**载荷相同但取数与等待时间不同**。

## 摘要

目的：测样品在 **0.2 PSI** 压力下婴儿纸尿裤的厚度（mm）。准备：打开厚度仪开关，确保降落过程中**指示器（圆柱形）运动平稳**；检查**压块位于测试区域中心**。样品：从包装袋取合格产品；**去除产品的折页和大腿松紧带**，使产品能平整放置——**注意不要剪切到吸收层、不要破坏其厚度**。步骤：踩脚踏板抬起铜块，清理测试台面与铜块底面；厚度仪清零；踩脚踏板抬起铜块，将样品**居中（使用面朝上）**放于铜块下，使 **MD 方向与基座保持水平**；松开脚踏板，**铜块停止下落后等待 3 秒（数完 1001、1002、1003）** 记录读数（**精确到 0.01 mm**）；踩脚踏板抬起铜块、移走样品、仪器复位。注意事项：严禁随意按动测试仪按钮；**所有制备的样品必须在 1 小时之内**完成测试。安全：插拔电源小心触电；铜块落下会压手。

## 提炼的数字与结论

| 项目 Item | 数值 / 结论 Value | 备注 Note |
|---|---|---|
| 方法编号 Method ID | **STM-00040**（第 2 版） | 通用成品厚度 |
| 载荷 Load | **0.2 PSI** | 低压口径 |
| 稳定等待 Dwell | **3 s**（数 1001-1002-1003） | 与澳洲法 10 s 不同 |
| 读数精度 Precision | **0.01 mm** | — |

| 放置 Orientation | 使用面朝上、居中、**MD 与基座水平** | 与澳洲法一致 |
| 时效 Time limit | 制备后 **1 h 内** | 与澳洲法一致 |
| 合格阈值 Threshold | 原文未给 `[待验证]` | 需与产品规格配对 |

> ⚠️ **口径差异（2026-09-29，重要）**：本页与 [[澳洲厚度测试.docx]]（成品 TTM-001）**载荷同为 0.2 PSI**，但——
> - **稳定等待**：本页 **3 s**，澳洲法 **10 s**；
> - **预处理**：本页**去除折页与大腿松紧带**，澳洲法**不触摸吸收层、不去皮筋**；
> - **取数**：本页**单点**，澳洲法取**前后端均值 T=(T1+T2)/2**。
> **同载荷不同操作 → 数值不可直接比较**，详见 [[成品厚度两条口径对比（澳洲 TTM-001 vs STM-00040）]]。
