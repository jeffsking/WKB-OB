# CN 120285261 A（一种超吸收纸尿裤及其制备方法和应用·广东宜柔）

## One-line positioning 一句话定位

A 2025 Chinese manufacturer application claiming an **adult-diaper hybrid core**（成人纸尿裤复合芯层）that blends acrylic SAP with **PAM microspheres + quaternized chitosan + a three-component modifier** to attack the salt-tolerance（耐盐）and gel-blocking problems at the core-recipe level rather than the SAP-particle level. 对本库的意义：提供了「芯层配方级耐盐改性」的量化对比表（去离子 272 vs 生理盐水 56 g/g 的同样品双口径），是**DI 口径与盐水口径差距的直接量化证据**。

## Technical breakdown 技术拆解

1. **配方（重量份）**：SAP 50–60 / PAM 微球 20–30 / 季铵化壳聚糖 20–30 / 改性剂 10–15 / 催化剂 1–5（次亚磷酸钠:过硫酸钾 = 1:0.5–1.5）。
2. **改性剂三元比**：酒石酸 : 2-丙烯酰胺-2-甲基丙磺酸（AMPS）: N,N'-双(丙烯酰)胱胺 = 1:(2–3):(1–1.5)；三组分分别承担氢键增强、耐盐、补充交联。
3. **芯层工艺**：乙醇分散（70–80 vol%，2–3 倍量）→ N2 → pH 3–4 → 50–60 °C 1–2 h → 模塑 80–90 °C → 干燥 100–120 °C 10–20 min。
4. **整机工艺**：热熔胶 2–4 g/m² 双面涂布 → 热压 130–150 °C / 0.3–0.5 MPa → 裁切折叠压边 → 两侧弹性侧封（20–30 wt% 氨纶无纺布）。
