# P&G–KC Industry Review and Xinweisheng Supplier Capability Visit（与宝洁交流及行业情况）

> ASR 转写讹字说明：本稿为供应商交流会录音自动转写，**时间戳乱序**（非按发言顺序）。已识别的讹字/音转：
> - **「无 t / 有 t / 五 t / 有气无气」** = **无锑 / 有锑（Sb，antimony）** —— 由 PET 缩聚的**锑系催化剂**引入；改用**钛系催化剂**即可无锑。此判读已由本批另一份材料（福地交流会："含锑量""PET 在做成 PET 的过程有个催化剂""钛型催化""完全可以用钛型催化"）交叉确认。「有贴无贴」= 有锑/无锑
> - **「维生 / 新维生 / 维盛 / 常州围胜 / 佛山卫生」** = 新维盛系（常州为**兄弟企业**，不在新维盛集团范围内）
> - **「大运 / 云南大学 / 云南大园」** = 大元（Dayuan）[待验证]
> - **「水司 / 水次 / 无生殖 / 无人市纹身制」** = 水刺（spunlace）
> - **「特旅 / 特里 / 特米」** = 特吕茨勒（Trützschler）[待验证]
> - **「敏锐 / 明锐 / 美味」** = 闽瑞；「雷尔」= 福建雷尔
> - **「星体 / 吸收晶体」** = 芯体；「徒步 / 涂布 / 同步线」= 涂布/复合线；「蓝皮蛋」= 莱赛尔（Lyocell）[待验证]
> - **「PC / YPC / YK / YPT」** = P&G 相关市场/主体 [待验证]；「男工 / 老公 / 路易斯 / 丹尼斯 / 刘总 / 杨总」为人名音转 [待验证]

## Key decisions 决策要点

1. **供应商战略定位（已明确）**：
   - 定位为「**卫生用品材质上的制造商**」，目标成为世界第一；**明确不做纺粘**（"我去跟 PGI 比，没意义"），也不会过多涉及纺棉。
   - 两大支柱：**创新 + 质量** —— 「有了质量才有今天，有了创新才有明天」。
   - 不做纯比价路线：坚持「指定就是指定，绝不往里加乱七八糟的东西」，因此价格不会是最低的；主张**可持续供应**（不能让供应商赔本供货）。
2. **客户隔离与 IP 机制（已建立）**：
   - **P&G 与 K-C 的研发团队、销售团队、产线完全分开**；未来可进一步**分工厂**（利用三期工厂），使人与人之间不产生交集。
   - 两种开发模式：① 供应商主动开发 → 客户可采用并签 **1–2 年排他**；② 客户委托开发 → **知识产权归客户**。
   - 明确拒绝抄袭客户产品："不准抄"。
3. **设备与产能路线（已决）**：
   - 与**特吕茨勒（Trützschler）**战略合作，其全球最新设备与技术**首装于本集团**；并**反向引导**设备商创新（全球第一条 3.8 m 线由本集团推动，三年后推进到 4.2 m）。
   - 判定 **4.6 m 线在机加工能力未显著提升前风险过大**（长时间运行后变形），故**先稳定 4.2 m 幅宽、在速度上做差异**；同时倒逼设备商提升德国侧机加工能力。
   - 海外布局（规划中，已决定方向）：未来两年海外投资 —— **美国 1 条、中东 2 条、埃及**；动因是地缘政治、热风布**运费占比越来越高**、以及国际化必然性。
4. **印刷工艺路线（已决）**：**不做传统水性/油性印刷** —— 需烘干（影响柔软度）、有排废问题、且当地对水污染要求高；改走**特种印刷**（无需烘干、自干），可做前调后变、分区（含左右分区）压花图案。
5. **打孔工艺路线（已决）**：**不走离线两步法**（成本高），改做**一步法单层打孔**；量大时走另一产线口径 [待验证 具体规格]。
6. **纤维供应策略（已明确）**：闽瑞为**主力供应商（约 50%）**，其余为江南高纤系 + 日本特种纤维 + 少量其他；**不单一供应商**（"不可能只有一个供应商"）。选商两条标准：**有创新能力** + **持续供应稳定性**。
7. **本方对行业格局的判断（会中表述，非猜测）**：
   - P&G 在**物质安全**上是行业标杆；K-C 在体系与眼界上存在**差距**（以"无锑"要求为例：P&G 数年前已有要求并商业化，K-C 内部此前并不优先）。
   - K-C 近年在产品形式上花样多，但**基础功不够扎实**；本次冲击「看起来偶然，实则有必然」。

## Open issues 待决问题

1. **K-C 份额下滑幅度**：会中口径为「一个月掉 7–8 个点，从约 19–20 掉到约 11–12」，P&G 反超至第一，且判断该走势**至少会维持到年底甚至明年初** [待验证 数据来源与口径]。
2. **无锑（TiO₂-free）在 PET 上的可行性**：难度高，导致韩国市场**只能用 PP**（PP 粗糙、软度差）；能否实现 PET 无锑**未定**。K-C 目前仅韩国市场有此要求，**美国近期开始要求**，中国大陆与其他市场未要求。
3. **旦数路线**：现供 0.8 旦 → 已可稳定供 **0.6 旦**（被称"最经典的产品"）→ 未来 **0.4 旦**；最低克重可做到 **12 gsm**。
4. **全棉/棉复合路线**：热风 + 水刺复合做「全棉」——只用 **15 g 棉** + 其余热风，规避纯棉高克重带来的潮感；复合方式**不加任何胶**（追求无胶），上下梳理后热合复合（与 K-C 现有做法不同）。
5. **NB/S 码红屁股投诉**：化纤刺激皮肤，全棉可缓解但克重高；上述 15 g 棉方案为候选解，未定。
6. **纤维创新的量产门槛**：纤维生产**一次投料数十吨**，中途停线需停管道、切换成本"不得了"；要求**起积量 ≥20–30 吨**，否则做不下去（有过 20 吨纤维用一年半、最终报废的案例；纤维最佳使用期为一年内）。
7. **功能性开发的小单困境**：小单品若走纤维路线不现实 → 改为**在涂布/后整理段加功能**，共用现有牌号纤维（如沿用 R100），从而摊薄纤维成本。
8. **4.6 m 线是否推进**：取决于设备商机加工能力是否提升，未定。
9. **常州工厂的定位**：做国内灵活切换的小单（三五百公斤级）；福建为主基地；上海维盛做水刺。
10. **认证体系**：已做瑞士（欧盟基础）认证、自行做 OEKO-TEX 与敏感肌认证、德国认证；**部分中国认证未做**（认为已"搞烂掉"）。EDANA 审核：2025 年该厂 **91 分**、2026 年佛山厂 **93 分**，明年目标 **95 分**。
11. **可降解 / 凉感 / 趣味性 / 复合材料**方向均在开发中，未定商用时点。
12. **本方（K-C）能给到的量偏少**：供应商明确"P&G 的量是 K-C 的三倍"；如何通过研发端配合建立互信机制、突破"投鼠忌器"的 barrier，**未决**。

## Background 背景

本次为 K-C BCC 侧走访福建热风非织造布供应商（新维盛系）的交流会，议题横跨三部分：① 行业格局与 P&G/K-C 竞争态势；② 供应商沿革、产能、设备与创新体系；③ 产品路线（无锑、细旦、全棉复合、特种印刷、一步法打孔）。会议在 K-C 近期因行业事件份额承压的背景下进行。
