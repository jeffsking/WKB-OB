# STM-00686弧形皮筋张力.doc

## 一句话定位

南京厂成品 SOP **STM-00686（第 0 版）**：测婴儿成长裤**弧形腿部皮筋**在 **90% 伸长率**下的拉伸力，结果由 kg 读数 **×1000** 换算为 **gf**，是"抱合不勒"弹性力窗口的部位级判据。

## 摘要

仪器准备：开机预热，**单位调为"千克"、状态为"C"**，按 ZERO 回零；检查上下夹子边缘是否平行、夹内橡胶垫块是否缺失（缺失须更换夹子）；用**校准杆**置于上下夹具中心调整夹具距离——**前端（左右）99 mm、后端（左右）144 mm**；通过粗/微调旋钮把上夹具调到所需高度（微调不得施力过大以免损坏载荷传感器）；另备一块秒表。制样：取线上样品**静置 0.5–1 h**后测试；去除芯体与外层但不破坏腰围；沿 **CD 方向**在前后弧形腿部皮筋之间把腰围一分为二；在**倒数第五与第六根腰围皮筋之间**标剪切线；修剪多余材料后沿 **MD 方向**分别把前后弧形腿部皮筋一分为二，共 **4 个样品**；在最底部腰围皮筋与弧形腿皮筋交叉处标识；把样品挂在灯箱上用 **150 g 配重夹**拉伸，量取**前端弧形皮筋 110 mm、后端 160 mm**，取下后立即测试。测试：交叉处一端夹上夹具、样品居中（标记线一半在夹具内）、自由悬挂并按 ZERO 归零；下夹具夹另一端（同样夹在划线上，确认皮筋竖直拉直），放下下夹具**立即计时**；到 **60 ± 3 s** 时记录读数，读数 **×1000** 即为最终结果，单位 **gf**。要求标记后的样品**必须在 1 h 内**测完，标记线须一笔画完。

## 提炼的数字与结论

| 项目 Item | 数值 / 结论 Value | 备注 Note |
|---|---|---|
| 对象 Object | 成长裤**弧形腿部皮筋**（前/后 × 左/右 = 4 样） | 部位级口径 |
| 伸长率 Extension | **90%** | 由校准杆长度实现 |
| 校准杆长度 Gauge rod | 前端 **99 mm**／后端 **144 mm** | 决定夹具间距 |
| 取样长度 Specimen length | 前端 **110 mm**／后端 **160 mm**（150 g 配重夹下量取） | 灯箱悬挂 |
| 保载时间 Hold | **60 ± 3 s** | 放下夹具即计时 |
| 读数换算 Readout | kg 读数 **×1000** → **gf** | 仪器单位设"千克" |
| 预拉伸载荷 Preload | **150 g 配重夹** | 与 MDP Plus 一致 |
| 状态静置 Rest | 下线后 **0.5–1 h**；标记后 **1 h 内**测完 | 时效约束 |
| 仪器状态 Status | 状态"C"，ZERO 归零 | 夹子须平行、垫块齐全 |
| 合格阈值 Threshold | 原文未给 `[待验证]` | 需与内控标准配对引用 |

> ⚠️ **口径差异（2026-09-29）**：本页与 [[MDP plus弧形皮筋张力测试.pdf]]（WI-59910）**同为弧形皮筋 90% 张力，但取样量不同**——本页前端 110 mm／后端 160 mm、校准杆 99/144 mm、取 4 个样品（前后各二）；WI-59910 取**后弧形**皮筋、基准长度 **100 mm**、左右各 1 个样品。**同部位不同方法的 gf 值不可互推**。
