## 摘要 Summary

资料主体由四个可分离的板块构成。**板块 A｜基础结构**：纸尿裤由表层、导流层、吸收芯层、底膜四大层加闭合系统、立体防漏护围、尿显条等辅助部件构成，一片成品约涉及近 20 种原材料；芯体口径分流为**混合芯体（绒毛浆 + SAP）**与**复合芯体（无尘纸 + 蓬松无纺布 + SAP）**。**板块 B｜ADL 与 REL 辨析**：REL 为事后第一道防线，靠低密度大孔径"容得下、不塌陷"承接瞬间涌流；ADL 为事后枢纽，靠中等密度定向孔径"导得快、分得匀"实现纵向扩散；两者在高端产品中常被密度梯度设计合并为一层。提升 ADL 效率的三条杠杆分别为高低旦尼尔分层、**增设熔喷转向层**、以及**冲压漏斗形贯通孔**形成单向阀效应。**板块 C｜芯体新材料与工艺**：SAF（超吸水纤维）与 RCF（再生纤维素纤维）梳理-针刺混纺芯体（SR-2，SAF 60%）、bioSAP 碳足迹降低 15–25%、PLA/PHA 包裹层、EAM "按需分布"多通道干法纸、以及**差异化超声波粘接蜂巢芯**（大王）与在线一体成型。**板块 D｜壳聚糖纤维报告**（2026-05-09）：此外该文件还夹带了完整的壳聚糖/壳聚糖纤维技术与产业报告，并包含一段把 REL 误读为**冶金屈服强度**与 **AIM Solder REL61 焊料**的内容——属术语歧义，检索时须排除。

## ADL vs REL 速查 REL-ADL quick reference

| Aspect 维度 | REL 收集/传递层 | ADL 导流层 |
|---|---|---|
| 功能 Function | 垂直方向的「收」：承接涌流、暂存、下传 | 水平方向的「导」：纵向扩散、均匀分配 |
| 结构 Structure | 低密度、大孔径 | 中等密度、定向孔径/贯通孔 |
| 典型材料 Material | 粗梳合成纤维网；含中空/卷曲纤维的空气铺网（SBR 胶乳 → VAE 可交联分散体） | 高蓬松热风非织造布；三维膜/打孔非织造布 |
| 失效 Failure mode | 受压塌缩或吸水软化 → 失去瞬间接收能力 | 导流不足或凝胶堵塞 → 局部过载、回渗侧漏 |
