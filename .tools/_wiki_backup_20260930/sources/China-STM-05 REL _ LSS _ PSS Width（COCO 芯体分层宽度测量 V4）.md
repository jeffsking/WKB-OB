# China-STM-05 REL / LSS / PSS Width（COCO 芯体分层宽度测量 V4）

## 一句话定位

**China-STM-05** 是专为 COCO（复合/无木浆芯体）开发的**芯体分层宽度测量方法**：把「REL 有多宽、SAM 在 REL 的哪一侧铺了多宽」这两个决定吸收分布的关键尺寸，变成可量化的进厂与过程判读指标。

## 摘要

实验目的原文：测量 COCO V1 吸收体中 **REL 在产品中的宽度**以及 **SAM 在 REL 中的宽度**；COCO V2 吸收芯体中 **LSS（Liner Side，面层侧）**与 **PSS（Poly Side，底膜侧）**宽度，适用于 Diaper 与 Pants 两种形态。

**COCO V1（三指标，撕开法）**：
- **REL Width**：找到 REL 与 LSN 的界面，按住 REL 一端、向外撕开 LSN 一侧，分离后用直尺量取 REL 左右侧边缘之间的 **CD 距离**，单位 mm。
- **LSS Width**：在 REL 一侧轻轻拨开覆盖的绒毛，分辨 SAM 在 REL 中的两侧边缘，标记 PAD MD 方向 SAM CD 的**最宽处与最窄处**，量取后取 **(最宽 + 最窄)/2**。
- **SAM in REL Width**：将芯体 **Film 侧朝上、Liner 侧朝下**放置，从 REL 与 PSN 的界面撕开 PSN，在 REL 材料中分辨 SAM 左右边缘，同样取最宽/最窄的均值。

**COCO V2（LSS / PSS × Diaper / Pants，表格化五步法）**：每个组合均为五步——备样（芯体完整、无破损变形、无明显鼓起）→ 将 LSN/PSN 折叠部分**完全展开**平铺（LSS 测 Liner 侧朝上，PSS 测 Liner 侧朝下），从芯体一角把 LSN/Liner（或 PSN）从 REL/PSN（或 REL/LSN）上拨开，两端两角分别拨开 → 一手按住 REL/PSN，另一手沿 **MD 方向**将 LSN/Liner 轻轻拨至完全剥离 → **明确 SAM 边缘并划线标记** → 用量尺测量划线间距，单位 mm。

**SAM 边缘的统一判据**：若芯体 **MD 方向上超过 1/2 pad 长度的范围内均有 SAM 颗粒**，即可认定为 SAM 边缘；辨认困难时可将芯体**斜铺在灯箱上**借助透光识别，过程中须确保 SAM 无掉落。

**试样制备的硬约束**：芯体材料（不包括面层）须完整、无破损、无明显变形；须确认芯体无明显鼓起；**PSS 宽度测试必须单独备样，不能与 LSS 共用**；剥离时可用特殊方式降低胶的粘度，但若造成 REL 破损或明显变形，须重新备样并重新剥离。

变更记录：版本 4（2020-02-26）变更内容为「COCO V2 SAM（LSS/PSS）测试步骤」，变更原因为「COCO V2 芯体，Diaper/Pants LSS/PSS 宽度需要更新测试方法」。

## 提炼的数字与结论

### 指标矩阵（Indicator Matrix）

| 芯体代次 Generation | 形态 Form | 测量指标 Metrics | 方法要点 Key points |
|---|---|---|---|
| COCO V1 | — | REL Width、LSS Width、SAM in REL Width | 撕开法；REL/LSN 界面或 REL/PSN 界面分离；直尺量 CD 距离 |
| COCO V2 | Pants | LSS Width、PSS Width | 五步表格法；LSN/Liner 与 PSN 分别剥离；灯箱识别 SAM 边缘 |
| COCO V2 | Diaper | LSS Width、PSS Width | 同上；额外需先用剪刀沿 Pad 边缘剪开、移除前后端封、剥离底膜 |

### 关键口径（Key Conditions）

| 项目 Item | 口径 Condition |
|---|---|
| 取样要求 | 吸收体完整无缺陷；不含面层的芯体材料完整、无破损、无明显变形、无明显鼓起 |
| 仪器 | 标准量尺一把 + **灯箱** |
| 单位 | mm |
| 宽度取值 | **LSS / SAM in REL Width =（最宽处 + 最窄处）/ 2** |
| SAM 边缘判据 | **MD 方向上超过 1/2 pad 长度范围内均有 SAM 颗粒** → 判定为该侧 SAM 边缘 |
| 识别辅助 | 可斜铺于灯箱上借助透光识别；过程中确保 SAM 无掉落 |
| 备样约束 | **PSS 与 LSS 各自单独备样，不可共用**；REL 破损或明显变形须重新备样 |
| 剥离辅助 | 允许「用特殊方式降低胶的粘度」（原文未给出具体方式） |
| 剥离方向 | 沿芯体 **MD 方向**轻轻拨开至完全剥离 |
| 主观性来源 | 原文明言 SAM 边缘确认「**目前依赖检验员培训进行边缘的确认**」 |
