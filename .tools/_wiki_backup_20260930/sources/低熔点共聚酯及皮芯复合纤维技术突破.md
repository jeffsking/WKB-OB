# 低熔点共聚酯及皮芯复合纤维制备技术实现关键突破（科技成果鉴定）

## 一句话定位

中国纺织工业联合会科技成果鉴定的官方通稿，披露「低熔点共聚酯及皮芯复合纤维设计开发与应用」项目的技术路线、创新点与产业链单位名单——**本库「皮芯复合纤维国产化供应格局」的核心来源，与 LMP-PP 低熔点聚丙烯项目群构成「聚酯路线 vs 聚丙烯路线」的对照证据**。

## 摘要

项目由东华大学牵头，联合江苏新视界先进功能纤维创新中心、优彩环保资源科技、福建闽瑞新合纤、江苏三联新材料、江苏佰家丽新材料、新疆蓝山屯河共七家单位完成，已通过科技成果鉴定，整体技术达到国际先进水平。研究背景指出：低熔点共聚酯牌号多、应用广，但多元共聚组分设计缺乏依据，熔点、结晶、模量、粘接等性能调控依赖试错；以高含量 IPA 共聚改性的路线存在结晶低、粘接差、干燥易板结、纺丝易降解、熔体流动匹配难等问题。项目构建了从结构设计与聚合、共聚改性及性能强化，到纤维成形及皮芯复合纤维开发的全产业链技术体系。创新点包括：1,5-戊二醇修饰的钛锌双金属催化剂、多元醇与酸组分分步酯化-共缩聚技术、SiO₂ 无机粉体/聚醚嵌段共聚/三乙醇胺微支化共聚改性、梯度升温固态干燥与压差式双螺杆负压抽提（解决板结与热降解）、低温与微正压熔体输送、高黏度比皮芯复合双组分组件、不对称纺丝与分段强冷。已建成年产 5 万吨生产线。

| 单位 | 角色 |
|---|---|
| 东华大学 | 牵头单位，总体技术路线设计、关键科学问题凝练、基础研究与技术研发 |
| 江苏新视界先进功能纤维创新中心 | 全国第 13 家、江苏省首家国家制造业创新中心；低熔点共聚酯聚合中试验证与工艺包形成 |
| 优彩环保资源科技 | 国家级绿色工厂、全国循环经济技术中心；低熔点共聚酯及粗旦低熔点皮芯复合纤维万吨级生产及销售 |
| 福建闽瑞新合纤 | 全球 ES 纤维行业领军企业（市占率约 20%），国内唯一实现超细旦纤维稳定量产；皮芯复合纤维成形及工程化应用支撑 |

| 江苏佰家丽新材料 | 国家级专精特新「小巨人」；热压板材与工程化应用支撑 |
| 新疆蓝山屯河科技 | 低熔点共聚酯聚合工程放大支撑 |
