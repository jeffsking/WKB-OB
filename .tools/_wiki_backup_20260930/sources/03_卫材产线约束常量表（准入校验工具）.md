# 03_卫材产线约束常量表（准入校验工具）

> 一句话定位：一张 **新材料上产线前的准入校验表**——把产线约束（线速、幅宽、克重-强力、厚度、干态、价位、温度/张力）**结构化为一格一格的门槛**，让**约束倒推材料方案**，而不是**由材料性能正推应用**。（中文：它解决的不是"材料好不好"，而是"这个材料能不能上这条线"。）

### 3. 干态装配铁律（§5 核心）Dry-state Assembly Iron Rule

- **尿裤为干态装配**：**SAP 遇水/胶水失稳** → **真空成型必须在 SAP 干燥态完成**；**先喷胶 → 再落 SAP**。
- **湿态/水凝胶类材料无法直接上干法线**，必须做成**干粉 / 干膜 / PEG 置换干颗粒**等干态中间体 —— 这是 **PEG 置换路线存在的理由**。
- BNC 中间体要求：**疏水干粉（纯度 ~100%、含水需报告）**；**PEG 置换低含水 BC/PEG 干颗粒（干态防菌）**。

> ⚠️ **工序顺序冲突标记（87 号脚本 §7.2 并入，跨资料分歧，未做技术裁决）**

| | 干态铁律（A 级一手会议） | COCO-v6 源文件（B 级工程方案） |
|---|---|---|
| 顺序 | **先喷胶 → 再落 SAP** | **NW 包裹 → SAP 成型 → land 清洁 → 上胶保形 → 压合**（落到鼓上时 **SAP 先于胶**） |
| 出处 | 拜科瑞纪要、FEI 纪要 | Patterned SAP 成型方案 P7 工位序 / P10 扇区序 / P15 叠层序 |

**三条后果对比（源文列出）**：
1. **锚固方式**：SAP 被胶锚固、抗移位强 vs SAP 落在裸包覆上、靠真空 + land 约束定位；
2. **屏孔风险**：胶先覆盖屏孔（Ø0.6–0.8 mm）→ 有堵孔/降真空风险 vs 屏孔始终洁净、真空效率稳定；
3. **产线代价**：需在成型段前增加喷胶工位、扇区角度须重排 vs 与源文件 6 区角度自洽。

> **处理要求（源文原文）**：**两条顺序并列记录，禁止静默取其一**。待澄清：①「先喷胶」是否仅适用于传统绒毛浆线/特定工位？② 是否已被 pattern 方案显式取代？**归口：向 FEI 项目组 + 拜科瑞确认该铁律适用范围。**

### 4. 关键可推导关系（A 级）Derivable Relations

| 关系 Relation | 表达式 / 结论 |
|---|---|
| **鼓面线速通用式** | **v [m/min] = 节距 [mm] × 节拍 [ppm] ÷ 1000** —— 即线速数值 = 节距 × ppm；本表「单片用料 380 mm → 342 m/min」即此式的一例（A 级，可推导） |
| **转阀脉冲频率** | **f = 节拍 ÷ 60 = 16.7 Hz @1,000 ppm**，**与 ups 无关**（脉冲数/转 = n，转速 = ppm/n，相乘消去 n）。⚠️ 因此**随 ups 变化的只有落料速度，脉冲频率不变** |

### 5. 落料速度匹配与容差（§7）SAP Dosing Speed Matching

| 项 | 值 / 表述 | 等级 |
|---|---|---|
| 到达速度 | **6.60 / 7.70 m/s**（随 ups 切换），允差 **±0.3 m/s** | B |
| 失配后果 | 落点 **in-spec 99.996% → 92.7%**（仿真） | B |
| 滑移模型 | **s = Δv²/(2a)**、**a = μ·Δp·A/m**（μ 0.5、d 450 µm、ρ 1.5 g/cm³） | B |
| ⚠️ 缺口 | **Δp 口径未定义** → **s 无法独立复算** | — |

### 7. 准入校验流程建议（§2）Suggested Admission Flow

1. **先对 §1 线速**：目标线速下材料经受的速度 = **准入第一关**（源文举例：希瑞 20 g 在 900 片/分已败下阵）；
2. **再对 §3 强力与 §4 厚度**：**克重—强力—厚度构成三角约束**，改任一需重测另两个；
3. **§5 干态铁律**：湿态/水凝胶类材料**必须转干态中间体**才能谈准入；
4. **§6 价位**：目标价与现有材料价差决定"值不值得引入"；
5. **§7 温度窗口**：材料耐温**必须覆盖工艺温区**（未测则立项前必测）。
