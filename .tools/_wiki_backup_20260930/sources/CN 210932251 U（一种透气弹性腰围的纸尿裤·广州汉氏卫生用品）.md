# CN 210932251 U（一种透气弹性腰围的纸尿裤·广州汉氏卫生用品）

## One-line positioning 一句话定位

A structural utility model（结构型实用新型）with two claimable ideas：**打孔氨纶弹性腰围**（透气+减压双目标）与**网格胶粘接的双层渗透层缓冲腔**（过载蓄水）。对本库的价值是「腰围透气孔」这一少见的结构选项——本库腰围讨论多集中在弹性力窗口与拉断，透气维度此前无结构参照。

## Technical breakdown 技术拆解

1. **透气腰围**：后腰氨纶弹性布开第一透气孔（圆形）；前腰氨纶弹性带开第二透气孔（圆形）；与腹部接触面积小、不勒紧、可通风。
2. **闭环贴扣**：后腰两侧第一/第二腰贴（各带贴部）分别贴前腰第三腰贴，重叠处以胶黏剂加固。
3. **缓冲腔渗透层**：上渗透层+下渗透层网格状热熔胶粘接，中间留缓冲腔；尿液过载时暂存，正常时向下渗入包裹层与芯体。
4. **叠层**：渗透层 / 包裹层 / 吸收芯体 / 不透液底膜 / 柔软不透液层，层间热熔胶复合；两侧防侧漏层（无纺布包折氨纶丝）。

## Key claims 关键论断

- **「腰围透气孔」是本件唯一新颖度较高的结构特征**——现有腰围文献几乎只谈弹性力，不谈开孔通风 → [[透气弹性腰围（打孔氨纶）]]
- **缓冲腔 = 芯体外部的临时蓄水空间**，与「芯体内错峰」思路互补（空间换时间）→ [[Waist Guard（腰围护挡）]]
