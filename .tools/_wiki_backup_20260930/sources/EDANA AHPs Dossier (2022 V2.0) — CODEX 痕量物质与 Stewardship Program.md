# EDANA AHPs Dossier (2022 V2.0) — CODEX™ Trace Chemicals & Stewardship Program

## 一句话定位

One-sentence positioning 一句话定位：欧洲非织造布协会（EDANA）关于吸收性卫生用品（AHPs）中痕量化学物质（CODEX™ 清单）分析与风险评估的技术白皮书，是卫品原料与成品安全管控的权威行业基准。

## 摘要

- 文件为 **EDANA Dossier / AHPs 技术档案**，版本 **V2.0（2022-04-01）**，由 EDANA（1971 年成立，>300 家会员）发布。
- 聚焦 AHPs（纸尿裤、卫生巾、湿巾等）中 **CODEX™ 清单痕量化学物质**的分析方法（均匀化制样、生物体液模拟萃取、化学分析）与暴露/效应风险评估（EBRA 参数）。
- **CODEX™** 是 EDANA 选定的痕量化学物质清单；加入 Stewardship Program 的企业承诺：用统一的、消费者相关的测试方法，使 AHP 中这些物质浓度不超过各自指导值。
- 涉及物质类：PAHs（多环芳烃）、二噁英和呋喃（dioxins & furans）、dl-PCBs、邻苯二甲酸酯（phthalates）、某些酚类（phenols）、农药（pesticides）、有机锡（organotins）、金属（metals）、甲醛（formaldehyde）（见原文档表2）。
- Stewardship Program 为**自愿性**，旨在超越现行 EU 及国家法规。

## 关键论断（key_claims）

- 卫品（AHP）合规不仅是强制国标，还受 EDANA Stewardship / CODEX™ 行业基准约束，原料与成品需做痕量物质管控。
- 与中国《一次性使用卫生用品卫生要求》（GB 15979）形成「强制 + 自愿行业基准」双层管控（后续批次建对比）。
