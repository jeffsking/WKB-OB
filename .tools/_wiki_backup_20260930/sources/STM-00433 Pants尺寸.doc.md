# STM-00433 Pants尺寸.doc

## 一句话定位 One-line Positioning

成品**几何尺寸测量**的主方法（第 5 版）：把"裤型尺寸"拆成 22 个可复现的测量项，并明确三套状态口径（松弛态 / 体侧层朝外挂测 / 底膜层朝外挂测）。是判断折页、导流层、绒毛与尿显线位置是否达标的基准。

## 摘要 Summary

本试验用于测定纸尿裤各部分的物理尺寸，工具仅需 300 mm 与 600 mm 直尺各一把。样品从包装取出后标记前后左右（均为穿着方向）。测量分三态：一、折叠宽度——置于平面上，不弄平、不拉直，量折叠部分最大宽度；二、松弛态——量腰部松紧带位置、粘扣 MD 长度、粘扣末端到底膜边缘的 CD 距离；三、挂灯箱（体侧层朝外）：产品后端向上垂直悬挂，确保腰部松紧带完全拉伸并用 1000 g 双配重夹夹在腰部中心（不夹到绒毛上），量折页间距、折页高度、导流层长度与位置、绒毛到导流层的 CD 距离、折页与底膜中心偏移、绒毛长度与宽度；四、挂灯箱（底膜层朝外）：同载荷下量粘扣 MD 位置、环抱腰贴 MD 位置、商标位置、尿显线 MD 位置与长度、后端耳部 MD 长度、尿裤长度、环抱腰贴长度。

## 测试方法要点 Method Specification

**三态口径 Three measurement states**

| 状态 | 装样方式 | 载荷 | 适用测项 |
|---|---|---|---|
| 松弛态（折叠宽度） | 平面，不弄平不拉直 | 无 | 折叠部分最大宽度 |
| 松弛态 | 平面 | 无 | 腰部松紧带位置、粘扣 MD 长度、粘扣末端到底膜边缘 CD 距离 |
| 挂灯箱 · 体侧层朝外 | 后端向上垂直悬挂，腰部松紧带完全拉伸 | 1000 g 双配重夹（腰部中心，不夹绒毛） | 折页间距 / 折页高度 / 导流层长度 / 导流层位置 / 绒毛-导流层 CD 距离 / 折页与底膜中心偏移 / 绒毛长度 / 绒毛宽度 |
| 挂灯箱 · 底膜层朝外 | 同上 | 1000 g 双配重夹 | 粘扣 MD 位置 / 环抱腰贴 MD 位置 / 好奇商标位置 / 尿显线 MD 位置 / 尿显线长度 / 后端耳部 MD 长度 / 尿裤长度 / 环抱腰贴长度 |

**轴向与定位定义 Axes & datum**

| 测项 | 取值口径 |
|---|---|
| 腰部松紧带位置 | 在 CD 中心处量底膜外边缘到腰部松紧带上边缘 |
| 粘扣 MD 长度 | 在粘扣 CD 中心处量取 |
| 折页间距 | 折页中间处，量折页结合线之间的距离 |
| 折页高度 | 折页中间处，量折页结合线到折页顶部 |
| 导流层长度 | 产品 CD 中心处量取 |
| 绒毛长度 | CD 中心处量 MD 方向长度 |
| 绒毛宽度 | MD 中心处量宽度 |
| 尿裤长度 | CD 中心处量 MD 长度 |
