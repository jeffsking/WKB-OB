# Biodegradable Thermoplastic Synthesis PLA Triblock Elastomers 生物可降解热塑性弹性体的合成（PLA 三嵌段体系）

> Source: Nakayama Y., Shiono T., "Synthesis of Biodegradable Thermoplastic Elastomers" / 生分解性を有する熱可塑性エラストマーの合成, *日本ゴム協会誌* (Journal of Japan Rubber Association), Vol.85, No.7, pp.229–233, 2012; 広島大学大学院工学研究院物質化学工学部門. Compiled from the 深度拆解报告 `Biodegradable Thermoplastic_report.md.md`. The paper is a review (no original experiments except the authors' own cited work, refs. 17–18) and cites 21 references.

## Thesis and method 论题与方法

- Core topic 核心论题：以聚 L-乳酸（PLLA）为硬段 hard segment、以低 Tg 聚合物为软段 soft segment 的三嵌段共聚物 PLA-b-(soft)-b-PLA，通过开环聚合（ring-opening polymerization, ROP）合成生物可降解热塑性弹性体。
- Structure 组织结构：Section 2 全生物可降解共聚体（软段本身可降解：PEG, PDXO, PTMC, PIP, PM, PMCL, P(CL-r-DLLA)）；Section 3 部分生物可降解共聚体（软段不可降解：PIB, PDMS）。

## Thermal properties of the relevant polymers 热性能汇总（Table 1, 绪言）

| Polymer 聚合物 | Tg (°C) | Tm (°C) | Role 角色 |
| --- | --- | --- | --- |
| PLLA | 55 | 170 | Hard segment 硬段 |
| PDLLA | 55 | — | Amorphous 非晶 |
| sc-PLA | 55 | 230 | Stereocomplex 立构复合 |
| PIP | −70 | 30 | Soft segment 软段 |
| PEG | −50 | 60 | Soft segment（高亲水） |
| PTMC | −20 | — | Soft segment |
| PDXO | −35 | — | Soft segment |
| PM | −25 | — | Soft segment（可再生） |
| PMCL | −45 | — | Soft segment |
| P(CL-r-DLLA), DLLA 30 mol% | −40 | — | Soft segment（作者最优） |
| PIB | −75 | 2 | Soft segment（不可降解） |
| PDMS | −120 | −50 | Soft segment（不可降解） |

PLA background 背景要点：PLA 源自植物、具生分解性；由丙交酯（lactide）开环聚合合成；PLLA（L-丙交酯来源）结晶性，PDLLA（外消旋）非晶性；PLLA 与 PDLA 共混形成立构复合晶体（sc-PLA），熔点由 170°C 升至 230°C；PLLA 缺点为硬而脆、耐热性较低。

## Fully biodegradable systems 完全生分解性体系（Section 2）

| System 体系 | Synthesis 合成要点 | Key result 关键结果 |
| --- | --- | --- |
| PLLA-b-PEG-b-PLLA | PEG 为大分子引发剂开环聚合 LLA，PEG 含量 27–57% | 三嵌段热分解温度高于 PEG 均聚物（PLLA 段稳定化）；吸水率随 PEG 含量上升，57% PEG 时吸水率 **82%**（亲水性极高） |
| PLLA-b-PDXO-b-PLLA | DXO 开环聚合得非晶 PDXO，再聚合 LLA；LLA 含量 7–27% | Tg ≈ −33°C（几乎不随组成变化）；≥11% LLA 时半结晶；Tm 与 ΔHm 随 LLA 含量上升；WAXS 证实晶区结构同均聚 PLLA |
| PLLA-b-PTMC-b-PLLA (Feijen) | — | PTMC 低 Tg、柔软，适用于再生医疗支架，但**耐蠕变差**；PLA 段足够长结晶时表现 TPE 行为；与 PDLA 版本共混形成 sc-PLA，拉伸性能与蠕变抗性俱优 |
| PLLA-b-PIP-b-PLLA (Hillmyer) | 烷氧基锂引发异戊二烯聚合 → 环氧乙烷封端/脱保护得 HO-PIP-OH → Et₃Al 或 Al(OiPr)₃ 催化聚合 DLLA | SAXS 显示三种形貌（spherical / cylindrical / lamella）；cylindrical 形貌断裂伸长率 **650%**；spherical 形貌弹性恢复最优 |
| PLLA-b-PM-b-PLLA (Hillmyer/Tolman) | (−)-Menthone 经 Baeyer–Villiger 氧化制 (−)-menthide → 开环聚合得 PM（Tg = −25°C）；DEG 引发、ZnEt₂ 催化得 HO-PM-OH → AlEt₃ 催化聚合 DLLA | SAXS 与 DSC 确认微相分离；断裂伸长率 **960%**，弹性恢复良好；添加粘着剂可赋予压敏胶功能 |
| PLLA-b-PMCL-b-PLLA (Hillmyer) | 2-甲基环己酮 Baeyer–Villiger 氧化得 6-methyl-ε-caprolactone；二甘醇存在下 Sn(Oct)₂ 催化得 HO-PMCL-OH → Sn(Oct)₂ 催化聚合 DLLA | 两个 Tg（如 −43 与 50°C）表明相分离；断裂伸长率约 **1900%**，恢复特性优异 |
| **PLLA-b-P(CL-r-DLLA)-b-PLLA（作者团队, ref. 17–18）** | ε-CL 均聚物半结晶（Tg −60°C, Tm 60°C）不宜直接作软段；CL 与 DLLA 共聚（Sn(Oct)₂ 催化、DEG 引发），**CL:DLA = 70:30** 得无定形低 Tg 软段；再以 HO-P(CL-r-DLLA)-OH 为大分子引发剂开环聚合 LLA | **Sample 8 (75-600-75)：断裂伸长率 2800 ± 200%**，为当时已知 PLLA 基 TPE 中最高值；循环试验（10–65% 应变，20 次）残留应变仅 **11.1%** |

Trend from Table 4 组成趋势：随 LLA 组成比增加，弹性模量上升、断裂伸长率下降（硬段比例↑ → 刚性↑、延展↓）。

## Partially biodegradable systems 部分生分解性体系（Section 3）

- **PLLA-b-PIB-b-PLLA**（Sipos）：以金属钾对 HO-PIB-OH (Mn = 7400) 阴离子化，生成钾醇盐作大分子引发剂，阴离子聚合 LLA；产物 Mn = 20000，两个 Tg（−69°C 与 45°C），TEM 确认微相分离。
- **PLLA-b-PDMS-b-PLLA**（Zhang & Gonsalves）：端羟基 PDMS 为大分子引发剂，Sn(Oct)₂ 催化 LLA 开环聚合；分子量、Tg、Tm、熔融热随 PDMS/LLA 比降低而下降；PDMS 引入可提高热分解温度。

## Concept deep-dive 核心概念

| Concept 概念 | Definition 定义 |
| --- | --- |
| Biodegradable TPE 生物可降解热塑性弹性体 | 常温呈橡胶弹性、加热可熔融加工、且具生物降解性；结构基础为 A-B-A 三嵌段，A 结晶性硬段提供物理交联，B 低 Tg 软段提供弹性 |
| Hard segment 硬段 | 半结晶聚合物（如 PLLA, Tg ≈ 55°C, Tm ≈ 170°C），常温形成微晶区作物理交联点阻止塑性流动 |
| Soft segment 软段 | 低 Tg 非晶聚合物，本综述涵盖 Tg 从 −120°C（PDMS）到 −20°C（PTMC） |
| Triblock copolymer 三嵌段共聚物 | A-B-A；硬段与软段热力学不相容自发微相分离，SAXS 可观测 spherical / cylindrical / lamellar |
| Ring-opening polymerization 开环聚合 | 丙交酯在金属催化剂（Sn(Oct)₂, ZnEt₂, AlEt₃, Al(OiPr)₃ 等）作用下开环，链端为羟基或醇盐；催化剂选择决定分子量控制与嵌段纯度 |
| Stereocomplex crystal 立构复合晶体 | PLLA 与 PDLA 分子间作用力更强，Tm 由 170°C 升至 230°C |
| Macromolecular initiator 大分子引发剂 | 软段两端保留 −OH，直接引发硬段开环聚合；分子量由单体/引发剂比决定，结构清晰、嵌段组成可调 |

## Hygiene implication 卫材关联

Partially relevant — this is a **materials-design playbook**, not a hygiene product paper; no hygiene application is claimed in the source. 可借鉴点：
1. **软段设计原则**（半结晶软段不可直接用，需无规共聚打掉结晶）可直接迁移到可降解弹性纤维/弹性膜的配方设计——卫材弹性件要求低 Tg + 高回弹，本文给出从 −120°C 到 −20°C 的软段选择谱。
2. **回弹指标口径**：残留应变 11.1%（10–65% 应变，20 次循环）是可直接借用的弹性恢复评价方法，优于单点断裂伸长率。
3. **耐热性仍是短板**：作者明确列出"耐热性提升与成本降低"为待优化方向，意味着 PLA 基 TPE 目前不宜用于需经受热风/热轧高温窗口（>150°C）的卫材在线工序，[待验证] 需实测 Tm/软化点后判断。
4. **压敏胶延伸**：PLLA-b-PM-b-PLLA 添加粘着剂可赋予压敏胶功能，与可降解热熔胶方向相关。
