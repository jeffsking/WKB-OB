# Absorbent Product Testing（吸液材料测试技术）

> 全书第 11 章。pp.406–463（书内 389–445），58 页。是全书中唯一系统论述**吸液性能评价体系**的章节，为 Ch10 工艺选择提供验收依据、为 Ch12 产品整合提供验证方法。对卫材 R&D 最直接的测试体系参考。

## One-line Position 一句话定位

卫材 R&D 的**测试金字塔总纲**：三级层次（材料→二维结构→产品）+ 三类方法（标准/研究工具/企业专有）+ 界面能第一性原理，建立"供应商评估→内部研发→客户满意度"的完整质量闭环。

## Summary 摘要

- **分层测试哲学**：测试必须遵循"构成材料 → 二维结构（网布/片材）→ 装配产品"三级递进，每层有独立指标体系与测试方法，"The single most important property of interest is the customer satisfaction"，需逐层筛选 + 最终 in vivo 现场验证。
- **三类方法定位**：标准方法（ASTM/AATCC/INDA/TAPPI/EDANA/Scan-C，用于 process control、QC、ranking、R&D）；研究工具（fluid intrusion/extrusion，提供机理洞察）；in vitro / in vivo（企业专有，模拟用况，是竞争壁垒来源）。
- **界面能第一性原理**：Wilhelmy 湿附力法 → F_w = γ_lv · P · cos θ，可获前进/后退接触角、附着功 W_A = γ_sv(1+cos θ)、润湿指数 WI、Hysteresis = W_AR/W_AA、表面能（dispersion/polar/total）。
- **标准方法映射**：INDA IST 10.1/10.2（吸液时间/容量，5g 试样、8×5cm 网篮、25mm 落高、浸泡+沥干各 10s）；AATCC 127（渗透时间）；Klemm 法（毛细前沿 lg h vs t → Washburn k₀）；Cobb 法（单位面积吸水量 g/m²）；液体挤出法（非汞，柔性材料孔径分布优选）。
- **湿力学系统退化**：亲水纤维吸水后 modulus 下降→弯曲刚性减小、压缩模量降低、单位质量厚度显著减小→直接影响蓬松度与容量。"Usually, the greater the absorption, the greater the loss in modulus"。
- **SAP 复合材料表征**：Fig.28 厚度方向 SAP/盐水分布（三层划分）；液体挤出法有效孔径 15–1000 μm；Fig.25 吸液等温线（两种半径材料接触时平衡饱和度）。
- **产品级测试**：尿布四层（coverstock → acquisition → core → backsheet）每层独立测试 + 组合 in vitro；coverstock 干燥性（滤纸+塑料板加压）；manikin 动态防漏测试；Syngyna 装置（61 cm H₂O 生理压）；Oathout 动态擦净 sled test。

## Key Claims 关键论断

1. **分层测试哲学**：吸液产品开发必须遵循材料→二维结构→装配产品的三级测试层次，每一层级有独立指标体系，不可越级或混用。
2. **标准化 ≠ 完整表征**：标准方法只能覆盖过程控制/QC/排名/研发比较等基本需求；对微观机理（孔结构、吸脱附动力学、界面能）的理解必须依赖非标准研究工具。
3. **速率比容量更重要**：吸液容量在静态条件下可能很高，但若不考察吸液速率、毛细上升及在负载/压力下的保持能力，产品在实际使用中仍会失败。
4. **企业专有 in vitro 是竞争壁垒**：Syngyna、MKT、Oathout sled 等 proprietary 方法代表行业标准之外真正的产品性能预测能力，也是企业间竞争壁垒的来源。

## Business Connection Points 业务连接点（供卫材采购/R&D）

### 供应商测试要点（对王总的建议）

| 场景 | 标准/方法 | 必须配套指标 |
|------|-----------|-------------|
| 木浆/粘胶纤维验收 | INDA IST 10.1/2、ASTM D4446、TAPPI | 静态容量 + INDA 10.1 速率 + AUL + WRV + 湿态压缩模量（四指标不可仅报容量） |
| 粘胶/棉纤润湿性评价 | Wilhelmy 法（Miller 改进） | 优选 θ_R 小、hysteresis 低的三角粘胶 |
| SAP 复合材料验收 | 液体挤出法、Fig.28 厚度分布 | 要求 0.3–0.7 psi、0.9% 盐水中 AUL 数据；注意 SAP 沉降致厚度不均 |
| 导流层/获取层 | AATCC 127 + Fig.32 装置 | 渗透吸液速率 + 导流均匀性（不能仅看 Cobb） |
| 面料表面干燥性 | Coverstock wetness（Fig.33） | 滤纸增重量（直接影响婴儿皮肤接触干燥性） |
| 防漏性能 | Manikin 动态测试（MKT） | 多尺寸 + 多冲击模式组合验证 |
| 湿巾/擦拭布 | Oathout 动态擦净 | 静态容量不能替代 |
| 卫生棉条 | Syngyna（61 cm H₂O） | 各厂商设备差异大，需统一协议 |

### 关键提醒

- **三角粘胶 vs 圆粘胶**：同为粘胶，三角截面 WI 高、hysteresis 低、达平衡快——采购合同应区分。
- **SAP 复合芯**：要求供应商提供厚度方向 SAP/水分布数据（Fig.28），避免底部 SAP 沉降致"上干下湿"失败。
- **跨厂数据可比性**：Syngyna、MKT 等 proprietary 设备间差异大，需统一测试协议或要求供应商提供设备参数细节。
