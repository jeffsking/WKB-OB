# Absorbent System Overview（K-C 吸收系统概览培训·2021-02）

## One-line positioning 一句话定位

K-C 内部培训讲义（Ryan Bowers, Feb 2021），把纸尿裤吸收系统**从上到下逐层讲一遍**：每层"干什么、用什么材料、谁供货、放多久"。是本库少见的**层职能定义口径**来源（层职能与本库概念页的术语对齐依据）。

## Summary 摘要

The deck opens with "What's in a diaper?" — component map: tapered stretch ear, front ear, containment flaps, waistband, narrow liner, SAM/fluff composite, clothlike outer cover, loop patch landing zone (PUB), ADL, core wrap, straight leg elastics. It then defines the **absorbent system** as materials that absorb urine/menses/BM (body side liner, surge, wrapsheet, absorbent core: pulp + SAM, coform, airlaid) plus materials that contain (containment flaps/leg elastics, inner cover/baffle). Layer functions: **liner** = soft/dry skin layer, SAM barrier, must not impede fluid access, little/no retention (SMS common — good SAM barrier at low cost; BCW or textured liners for softness/BM handling; treated for wettability); **surge (ADL)** = resilient, fast intake and quick desorption to core, little/no retention, normally TABCW or BCW, staple fibers 1–3″, mainly synthetic (PET/PP/bicomponent), **50–130 gsm** for BCC forms, internal (Berkeley, KC Mexico) and external (Shalag, TEXTOR, Freudenberg, PGI, Tenotex); **wrapsheet/spacer** = SAM containment + process aid, prevents gel on skin and SAM poke-through, aids drum release in form-on-substrate, minimal basis weight, SMS (BCC) or tissue (AFC), treated for wettability; **absorbent pad** = SAM + fluff, formed in-line, stabilized by debulking. Pulp: mechanically fiberized wood fiber, naturally wettable, distributes fluid, **~8 g/g**, wet/dry integrity, cushy feel, pancake rolls, needs some humidity for processing. SAM: partially neutralized polyacrylic acid, cross-linking controls deformation resistance, surface treatments improve permeability/flowability/intake, **30–40 g/g saline**, single largest $ material buy in Personal Care, 800–1000 kg bags, moisture-sensitive.

## Key claims 关键论断

- **各层"零/低保留"分工是设计原则**：liner、surge、wrapsheet 都要求 little/no retention——液体必须交棒给芯体 —— 支撑页：[[Intake System（摄入系统）]]、[[ADL（导流层）]]
- **Core wrap 的职能 = SAM 容纳 + 防凝胶沾肤 + 防戳穿 + 释料工艺辅助** —— 支撑页：[[Core Wrap（芯体包裹层）]]
- **SAM 是 Personal Care 单项金额最大采购且湿度敏感** —— 支撑页：[[SAP（高吸水树脂）]]
- **绒毛浆 ~8 g/g vs SAM 30–40 g/g 的量级差**是芯体配比设计的出发点 —— 支撑页：[[绒毛浆（Fluff Pulp）]]
