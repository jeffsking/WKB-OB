### A. 三维度定位与总体策略

| 维度 | 定位 | 难度 | 重要性 |

### B. Absorbency：指标体系与四个 Feature

**SAP 四大指标（EDANA 标准）：**

| 指标 | 含义 | 区间 | 标准 |
| --- | --- | --- | --- |
| **CRC（离心保留容量）** | 无加压下 SAP 吸水倍率 | **35–40 g/g** | EDANA WSP 241.0 |
| **AUL（载荷下吸收量）** | 0.9 psi 加压下保留量 | **25–30 g/g** | EDANA WSP 242.2 |
| **GBP（凝胶床渗透性）** | 加压下液体穿透能力 | **25–40 Darcy** | EDANA WSP 241.0–242.2 |
| **Vortex Time** | 涡流时间（吸液速度） | **20–40 s** | Vortex Method |

- **关键矛盾：CRC↑ → AUL↓（Trade-off）** —— 高端产品需在两者间找平衡点。

| Feature | 要点 | 收益 | 代价 / 风险 |
| --- | --- | --- | --- |
| **A1 多 SAP 层系统** | 总 SAP **~15 g**；三层 **N511（快速）+ SAP1（主体）+ SAP2（保留）**；芯体 **385 × 110 mm** | 首次吸入速度 **+30–40%**；回渗 **<2.0 g**（竞品基准 3.0 g） | SAP 用量 **+8–12%**；分层工艺复杂度↑ → 设备改造 |
| **A2 ActivTech 类技术** | **100% SAP 在线制造**芯体；适用无木浆与混合两种；**KC 专有、需规避专利**；自研替代 = **Blizzard** | 芯体厚度 **<2.0 mm**；成本 **-10–15%** | **专利风险**（优先级 ⭐⭐） |
| **A3 REL 4 增强层** | **五纤维配方**（见下） | **已验证**：干态 **30→38 N/m（+27%）**、湿态 **58→75+ N/m（+29%）**、空隙体积 **62→80–117 cm³/g（+29–89%）** | 成本 **+3–5%** |
| **A4 空隙体积设计** | **Kozeny-Carman：k ∝ φ³/(1-φ)²**；目标 **80–117 cm³/g**；测试 **GB/T 24218.2-2009** | "高空隙芯体、尿液秒速扩散不积聚" | 成本 0%（设计项），偏**内部指标** |

**REL 4 五纤维配方：**

| 纤维 | 占比 | 作用 |
| --- | --- | --- |
| **2D ES 纤维** | **32%** | 主体结构支撑 |
| **12D ES 纤维** | **34%** | 增强层强度 |
| **PTT-PET 双组分** | **18%** | **螺旋卷曲弹性（无需氨纶）** |
| **中空 PP 纤维** | **18%** | **空隙体积维持** |
| **PVA 纤维** | **8%** | **水溶性粘结** |

### C. Skin Health：路径与四个 Feature

- **核心机理（ULDP 框架）**：降低尿液泄漏 = **减少皮肤暴露在湿润环境中的时间** = **降低尿布皮炎发生率**。
- **关键路径**：**快速吸入 → 有效隔离 → 低回渗 → 皮肤干爽**。

| Feature | 要点 | 参数 / 目标 | 代价 |
| --- | --- | --- | --- |
| **S1 智能感知 + 提醒（IoT）** | 湿度/温度/尿量三重监测；柔性传感器 + 蓝牙 | 湿度 **±5% RH**；温度 **25–40 °C**；尿量误差 **<10%**；续航 **>7 天**；市场 CAGR **>25%（2024–2030）**；玩家 **Ontex + Henkel（Orizon）** | 单片 **+¥3–5**；需验证柔性电极生物相容性与电子废弃物回收 |
| **S2 消臭一体化芯体** | 九类臭味物质（氨/胺类/短链脂肪酸/硫化物）；五路线：化学中和 / 物理吸附 / 生物酶解 / 香味掩盖 / **消臭型 SAP 复合一体化（前沿）** | 氨吸附 **>200 μg/g** | SAP 成本 **+5–8%** |
| **S3 低刺激面层** | 方案A **壳聚糖抗菌**（抑菌率 **>99%**，金葡/大肠杆菌）；方案B **CNF 纳米纤维素**（高比表面积 → 高吸湿 → 干爽时间延长，低致敏）；方案C **永久亲水整理**（共聚/接枝/等离子，替代会迁移的表面活性剂） | 析出量目标 **<0.1 μg/cm²**（需验证） | A **+10–15%**；C **+3–5%** |
| **S4 可降解 + 低致敏胶** | **胶占纸尿裤总重约 3%** → 减胶 = 直接降本 + 降低刺激；前沿为**温度/pH 响应型智能胶**（皮肤上自动降低粘性） | "减少皮肤接触刺激物 **30% 以上**" | 减胶 **-5–10%** |

### D. Comfort：四个维度与五个 Feature

- **舒适性 = 触觉（Softness）+ 听觉（Noise）+ 体感（Breathability / Cloth-like）+ 贴合（Fit）**

| Feature | 要点 | 参数 |
| --- | --- | --- |
| **C1 Cloth-like 底膜** | SMS/SMMS 无纺布 + 透气膜层压，替代塑料感强的 PE 膜 | 透气率 **>8000 g/m²/24h**；底膜 **15–30 gsm**；SMS = **15+10+15**；SSMMS = **10+8+10+8+10**（更柔软）；噪音降低 **>15 dB**；透气提升 **3–5×** |
| **C2 超细纤维面层** | 对标 Babycare 金·山茶 **0.003 mm**、花王妙而舒 **0.1 cm** 超薄芯 | 纤维细度 **0.8–1.2 D**；面层 **15–20 gsm**；供应商 **福建闽瑞**（ES 皮芯，年产 **10.5 万吨**，超细旦 **0.8 D**） |
| **C3 低噪音腰围/腿围** | **PTT/PET 并列型双组分**：热收缩差异 → **永久螺旋卷曲** → 弹性（**无需氨纶**）；柔软无纺布包裹 vs 氨纶裸露 | **2–4 D**；弹性恢复率 **>90%（拉伸 50%）**；克重 **20–40 gsm** |
| **C4 超薄芯体 <2 mm** | 100% SAP 芯体 + REL 增强层 + ActivTech 类技术 | **矛盾**：薄型化 → SAP 载荷密度↑ → **凝胶阻塞风险↑**；解法 = **多 SAP 层 + GBP 优化牌号选型** |
| **C5 透气性优化** | 皮肤潮湿度与透气率强相关 | 高端基准 **>5000 g/m²/24h**；微孔 **0.1–1.0 μm**；SMS/SMMS **8000–12000** |

### E. 产品分层与路线图

| 层级 | Absorbency | Skin Health | Comfort | 溢价 |
| --- | --- | --- | --- | --- |
| **旗舰（Ultra Premium）** | 多 SAP 层 + ActivTech 类 | 消臭 SAP + 壳聚糖面层 | 超薄 <2 mm + Cloth-like + 超细纤维 | **+80–120%** |
| **高端（Premium）** | REL 4 + Void Volume 优化 | 永久亲水面层 + 低致敏胶 | Cloth-like 底膜 + 低噪音腰围 | **+40–60%** |
| **主流（Mainstream）** | 单 SAP 层优化 | 基础消臭 | 超薄 <3 mm | 基准 |
| **经济（Value）** | Baseline | Baseline | Baseline | **-10–15%** |

**18 个月路线图：** Phase 1（0–6 月）基础性能升级（多 SAP 层工艺、REL 4 优化验证、Cloth-like 供应商认证）；Phase 2（6–12 月）差异化导入（消臭型 SAP 供应商对接、壳聚糖面层小试、超薄芯体原型）；Phase 3（12–18 月）高端商业化（智能感知概念验证、可降解胶导入、全系列验证 + 消费者测试）。

## Workshop 拟讨论的议题（Open issues）

1. **技术可行性**：ActivTech 类技术的**专利规避方案**；多 SAP 层系统的**设备改造需求评估**；**消臭型 SAP 的供应链可行性**（哪些供应商有成熟产品？）
2. **成本—性能平衡**：Feature 优先级投票；各 Feature 的**成本增量 vs 溢价能力**量化；决策哪些 Feature 进入下一阶段
3. **竞品防御与差异化**：三个空白机会点是否**足够差异化**；如何构建**技术壁垒**（专利 / 专有工艺 / 独家供应商合作）
4. **研发资源分配**：18 个月路线图的资源需求；**内外研发分工**（自研 vs 供应商合作 vs 外部研发机构）；里程碑与 **GO/NO-GO 决策点**
