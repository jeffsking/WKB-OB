## 一句话定位

一次以「**复合芯体的上下层 SAP 怎么配**」为核心的供应商交流：一边对齐 GBP / CRC / AUL / vortex 的取舍与聚合工艺的关系，一边把越南、印尼、印度的复合芯体市场现状摸清楚。

## Key decisions 决策要点

> 只记会上明确「定了 / 达成共识」的事项。

1. **上下层分工原则确认**：芯体上层用「**吸收慢 + 保水高**」的牌号，下层用「**吸收快**」的牌号；KC 现行搭配为**上层 511 / 下层 610S**。
2. **替代方案的打样方向定下来**：上层 **511（70K）**、下层 **951 配 N8**（N8 的 CRC 更高，用于抬升下层保水能力），先做**方向性验证**（结构还在设计中，先用现有材料验证思路）。
3. **GBP 的价值需与结构设计一起评估**：若已有槽（channel）等结构设计，**上层不必追求过高 GBP**——**再高的 GBP 也不如槽结构对利用率的提升**。
4. **通液性（GBP）确实是性能杠杆，但成本代价高**（「把通业做高了，成本增加很多」）→ 需权衡。

## Open issues 待决问题

- **高 GBP 到底值不值**：有观点认为 GBP 高是为了「快速渗透 → 提高整体 SAP 利用率 + 改善多次 intake」；但**目前没有数据**量化「高 GBP 对现有结构设计的帮助是多少」 → 需打样验证。
- **指标目标区间未定**：讨论中的口径为 GBP 由约 25 提到 **30–40**、AUL 接近 **20**、CRC 由 31–32 降到 **28–29**（若必须降，AUL 可能降到 16–17）、vortex 会增加但**太高会导致吸收过慢** —— 均为设想值，未定案。
- **外部高指标牌号的可信度存疑**：某外部牌号标称 GBP **53**、吸收速度 **36**、保水 **31.5**、加压 **18**，会上评价「太完美、可能不现实」，但**值得拿样验证**（且不同实验室数据不可直接横比）。
- **三种聚合工艺的取舍未落到牌号**：后中和（溶出物低、稳定）、前中和（保水高但速度慢、长期溶出物高，芯体中不单独用）、注油型（首次快、后段弱）→ 如何组合到上下层未定。
- **越南市场的降本压力**：中国出口到越南的芯体价格极低，客户持续要求优化成本；**越南当地已能自产并出口**。
- **早期越南失败的根因已识别为结构问题**：三层结构（无绒毛浆、只用一层高分子）→ 仅首次吸收快，后续表现差；**该教训需在新市场复制时复用**。
- **蝉翼的木浆结构细节待核**：长纤 + 短纤 + 特殊浆（最贵）三搭配，仅木浆与高分子，无胶、无其他纤维（区别于无尘纸）→ 特殊浆的具体类型未明确 `[待验证]`。

## Background 背景

复合芯体（尤其在线芯体）对 SAP 的要求不再是「单一牌号全能」，而是上下层分工搭配；同时东南亚市场的复合芯体渗透率快速上升，供应商与 KC 需要同时对齐技术方案与市场判断。
