# STM-00440 腰围皮筋张力.doc

## 一句话定位

南京厂成品 SOP **STM-00440（第 3 版，2021-08-24）**：把产品**套在两根测试杆上**测量**腰围皮筋张力**——通过软件模板把腰围拉伸到规定尺寸档（M/L 170 mm、XL/XXL 190 mm），读取**平均值并取整数**，是"整圈腰围"级别的弹性力口径。

## 摘要

本方法用于测量产品的腰围皮筋张力。步骤：① **不得使用腰围区域有缺陷**的产品（会影响结果）；② 为张力测试仪配置合适的器具与传感器，**设置测量长度 100 mm（上下测试杆间的中心距离）**；③ 在软件"我的模板"中选择对应产品尺寸的命令——**M、L 选 170 mm；XL、XXL 选 190 mm**；④ 在产品水平放置状态下，用直尺在**腰围上边缘处**测量**松弛状态热封边内侧间距离**（保持平整但**不得有拉伸**；**所有准备过程中腰围都不能有任何拉伸**）；⑤ 把产品套在**上端测试杆**上，**归零 load 与 crosshead**（此步用于从结果中扣除产品重量）；⑥ 轻轻抻开腰围套上**下端测试杆**——**热封边须位于测试杆的最外侧**、测试杆须伸到**腿部开口处**、保证腰围位于测试杆中心，**测试过程中产品位置保持一致非常重要**；⑦ 点击开始；⑧ **crosshead 归零时**拿走产品并记录**平均值**；⑨ **保留整数**。安全：插拔电源小心触电。

| 项目 Item | 数值 / 结论 Value | 备注 Note |
|---|---|---|
| 方法编号 Method ID | **STM-00440**（第 3 版） | 整圈腰围口径 |
| 对象 Object | **腰围皮筋（整圈）** | 与单根/部位级方法不同 |

> ⚠️ **口径差异（2026-09-29）**：本页是**整圈腰围**口径（产品套在两根杆上、按 Size 拉到 170/190 mm），与 [[STM-00070 Elastic Tension - BCC Products（皮筋张力测试 第4版）]]（单根皮筋、90% 伸长校准杆）和 [[STM-00686弧形皮筋张力.doc]]（弧形腿部皮筋、90%、110/160 mm）**对象与尺度都不同**，**数值不可互推**。
