# SAP GBP Improvement & Surface Crosslinking Process Review（GDP提升工艺探讨）

> ASR 转写讹字说明：本稿为 SAP 供应商工厂交流的自动转写，**时间戳乱序**，中英夹杂，含大量**牌号代号**。已识别的还原与存疑：
> - **「GDP / GPP」** = **GBP（gel bed permeability，凝胶床渗透率 / 通液性）** —— 依据：与会中反复出现的"通透性 / 通液""与保水的取舍""与住友对比"一致；「通业 / 农业 / 通透」= **通透性（permeability）**
> - **「保水」** = **CRC（离心保水量）**；**「加压」** = **AUL（加压吸收量）**；**「速度」** = 吸收速度（Vortex 类）
> - **「五幺幺」** = **511**（SAP 牌号）；**「六零 S / 六幺零 S」** = **610S**；**「九五零 / 九五九」** = **950 / 959**；「家具五幺六」[待验证]
> - **「三大雅 / 三亚家住 / 森塔尔家住友 / 桑奈雅加注油」** = **San-Dia（三大雅）** 与 **住友精化（Sumitomo Seika）** 等竞品口径 [待验证]
> - **「SCB / 星体 / 新体」** = **SAP / 芯体**；**「KV 交联」** = 金属离子与羧基形成的**离子/配位交联** [待验证]
> - **「生物」** = **诺尔生物**；**「蓝湾」** = **蓝湾新材料**（供应商系两个厂区，新线在蓝湾、更大）
> - **「MMO Q」** = 大线单批批量音转 [待验证]；**「AS」** = 某替代配方/技术 [待验证]
> - **「槽」** = **芯体开槽（channel / groove）**；「导路桥」= 导流相关 [待验证]
> - **「卓笔 / 豪悦 / 豪越 / 天骄 / 利奥 / 家邦 / 桥东 / baby care」** = 品牌与代工厂音转 [待验证]

## Key decisions 决策要点

1. **目标已定（本方）**：提高 **GBP（通液性）**，最终目的是**提高 SAP 利用率** —— 本方口径："SAP 一旦利用率提高了，你很多事情都解决了"；漏尿、反渗等问题多源于 SAP"没用上"。
2. **三项工艺能力（李工确认"有"）**：
   - ① **表面离子交联**（前段，工艺包在前端控制）；
   - ② **后段涂层（coating）** —— 可施加**多价金属盐**，金属离子与羧基形成交联，**属表面交联的一种**，供应商可实现；
   - ③ **无机粉末撒粉** —— 在**大线设备**上，位置**不开放参观**。
3. **多价金属盐涂层未商业化（已确认事实，原因未披露）**：供应商"做过尝试"，但**未商业化**；具体原因需向领导确认，会中未给出。
4. **效果上限（已给出）**：多价金属盐与无机粉末对 GBP **都有提升作用，且表现基本一致**，但**"提升到一定程度之后，单纯靠它去增加 GBP 就比较困难"**；会中提到的量级为 **40 左右**（在相应保水水平下）。
5. **可交换的杠杆（已达成）**：本方对保水要求"不是那么高" → **可以牺牲一部分 CRC（保水）来换 GBP**。
6. **分层思路反转（本方提出，供应商评价"很新颖"）**：
   - **常规思路**：上层**高保水** + 下层**快吸**（行业通行，大家不考虑通透性）；
   - **本方新思路**：上层**通液（GBP）好** + 下层**快吸**（保水可差一点）→ **与常规相反**；
   - 供应商判断："通透和吸收速度本身有一定的背离"，若成功"还是很有创新的价值"。
7. **无机粉末段的多用途（已确认可行）**：既然能撒无机粉末，**也可撒吸味 / 净味材料**；与现有**抑菌**施加位置相同 → 为后续功能化留了工艺口子。
8. **信息与参观边界（已明确）**：
   - **工艺流程图只能现场看、不能外发**（中控室含大量数据）；供应商自己的 **PPT 可以提供**；
   - 次日安排：先在会议室由销售讲一遍工艺 → 参观**蓝湾**新厂（新线更大、看得更清晰）+ 展厅。
9. **历史事实（供应商口径）**：当年能迅速替代三大雅，**最主要的原因是应用实验室**；并靠**给客户送开槽架子**推动"槽"在芯体中的普及 —— 初期客户不接受，**两年后基本都有槽了**。

## Open issues 待决问题

1. **新牌号指标未披露**：本方多次追问"你那个新的东西到底指标啥"，供应商称"还需要点时间"，指标只给主任看过 → **本方目前没有概念**。
2. **多价金属盐涂层未商业化的原因未明**：需向领导确认；本方也问过是否为商业上不需要、或效果不好 —— **未获答复**。
3. **竞品对标数据不完整**：
   - 三大雅某款：指标与 **511** 差不多，但**保水差一点、防水差一点**；
   - 住友参照：**保水 34–35、加压 13–14、速度 30–40、0.9** [待验证]；但"现在我不确定他们能做到多少"。
4. **配方放大路径的规模跨度大**：实验室**一锅两三百克**（手搓）；若要上线至少 **4–5 kg**；**大线一次几十吨** → 配方研究需要时间，且本方自述"我们自己跑大线，大线太大了"。
5. **"AS"替代的影响**：会中提到 AS 出来后"替代了很大一部分配方，一是成本原因，二是通液也没有以前那么好" → 该技术的具体所指与影响范围未展开 [待验证]。
6. **开槽的测试差异**：开槽后**二次、三次的吸收差与吸收速度差异很大**；本方自述"用槽的经验不是很多，才刚开始"；**内部测试方法 vs 国标**（国标有加压）口径不一致。
7. **三大雅 / 住友配方的模拟价值**：本方问"现在这个配方市面上还流行吗"，答"也有，但是不多了" → 是否值得复现未定。
8. **行业研发能力的判断（会中讨论，非结论）**：涉及对宝洁、豪悦、卓笔、天骄、利奥、家邦、桥东等品牌/代工厂的评价 —— 属**内部竞争判断**，见下方 manual_review，**本页不下结论**。
9. **无机粉末段能否在中控流程图中看到**：约定次日看流程图确认 [待验证]。

## Background 背景

本方赴 SAP 供应商（诺尔系）工厂，核心诉求是**找到提升 GBP（通液性）的工艺手段**，并以此提高 SAP 利用率。会上逐一确认了供应商在表面交联、后段涂层、无机粉末撒粉三方面的工艺能力，讨论了"牺牲保水换通液"的取舍与"上层通液好 + 下层快吸"的反向分层思路；同时安排次日参观蓝湾新厂与中控流程图。
