# CD Pants Overview 1-Piece vs 3-Piece Design（裤型 1P 与 3P 设计总览 · 2017-11-30）

## 一句话定位 One-line Positioning

本批**裤型纸尿裤（CD Pants）两种结构平台的工艺与档位总览（Beth Johnson，2017-11-30）**：把三片式（3-Piece）与一片式（1-Piece）的构件拆解、档位配置与消费者测试结果压成一张对照图。是本库回答「裤型产品为什么分 1P/3P、各档差在哪」的结构来源。

## 摘要 Summary

议程两部分：CD pants 总览（产品构造 PDP vs 3 Piece）与按档位划分的产品设计与材料。美国计划按平台分流——**Milky Way** 采用**三片式设计**，更偏创新管线（CUBIC/PIPA）；**GoodNites Best Underwear** 在评估**一片式设计**。

**三片式（3 Piece）构造**：顶视图八构件——Insert、Panels、Poly、Liner、Corewrap、Pad、Surge、Leg elastics。吸收体构造为 Pad + Poly 侧包裹层 + Liner 侧包裹层 + Surge + Liner，折叠成型。Insert 构造为外覆盖布与 flap + Poly + 折叠吸收体 + 带橡筋的折叠外覆盖布与 flap。**Panel 构造**为外侧非织造布 + panel 橡筋 + 内侧非织造布，**折叠后剖分成 2 片 panel**（slit）。

**一片式（1 Piece）构造**：顶视图六构件——Insert、1-piece Panels、Poly、Topical Liner、Pad Channel、Flaps elastics。横截面显示 **Panels / Flaps / Poly / Lifting elastics（提升橡筋）/ Flap elastics / Absorbent**，以及 Topical Liner / **Liner support layer（面层支撑层）** / Corewrap / Pad——吸收体为**悬浮 pad（floating pad）**。侧视图含 panel 内外非织造布、panel 橡筋与**曲线腿围橡筋（curved leg elastics）**。Insert 构造含 flaps + Poly + 带橡筋的折叠外覆盖布与 flap；**Panel 构造为 panel 非织造布 + panel 橡筋 + 曲线腿围橡筋，经模切（die cut）成型**。图中另标出关键施胶位点：FLAP9 ELASTIC、FLAP8 TACK DOWN ADHESIVE、LIFTING ELASTIC、PAD INNER COVER 125 mm、PANEL TO INSERT ADHESIVE（间歇式 / slot coat）、INNER PANEL 380 mm、INNER TO OUTER PANEL ADHESIVE（SUMMIT）380/300 mm、OUTER PANEL 600 mm。

**档位对照表**（GOOD 3P / BETTER 3P / BEST 1P）：吸收性——容量与摄入 GOOD / BETTER / BEST；**SAM% 40–50 / 50–60 / 60**；pad 长度与形状——短异形 / 长贴合异形 / **悬浮 pad（长矩形）**；性别特异 pad——通用 / 性别特异 / 通用。贴合——chassis 3 片短 / 3 片长 / **1 片长**；腿围——直腿围橡筋 / 直腿围橡筋 / **曲线腿围橡筋**；裆部——标准 / 窄 insert / **窄 insert + pad 通道**；腰围——较长后 panel / 较长后 panel / **模切一体 panel**。柔软与外观——面层 SB / 柔软 SB-TABCW / **打孔 TABCW + 柔软 SMS**；腰带柔软与透气 SSMMS 白 / 柔软 SMS 白或着色 / **打孔柔软 SB 白**；图形 registered / registered + 增色 + Disney + GS / registered + 增色。

消费者偏好：2015 中国 COMPASS CUT——**3p Compass : 1p Merries = 42:58（无显著差异）**；2017 EMEA COMPASS+ CUT——**1p Compass : 3p Aurelius = 54:46（无显著差异）**、**1p Compass : 1p Merries = 33:67（落败）**。即平台（1P/3P）本身不构成消费者偏好差异，差距来自平台内的产品力。

项目管线：**Premium & Super Premium（Best）**——2016 COMPASS+ 中国上市、2017 CD BEST 俄罗斯（自中国进口）、2018 Triumph CD Best 中国；**Mainline（Better）**——2015 AMPS 中国、2015 Daisy 南非、2016 JAVA 泰国 + APAC、2017 SPINEL 以色列/意大利/土耳其/印度并升级 ASEAN；**Value（Good）**——2012–14 VIP/AQUAMARINE（ASEAN、巴西、印度等）、2015 T1 印度、2016 PEARL（印度、ASEAN）；**POME & Others**——2016 CD POME 上市 PIPA 印度、2018 技术 CUBIC（更易穿脱，AB EMEA）、2018 技术 Forman-Channels（AB EMEA）。市场背景：HUGGIES CD Pants 快速增长，2012 年首发以来形成 T2–T5+ 与 VIP/AQM/SUN/SPINEL/PEARL 等代际梯队；2018 年 CD Pant 产能版图以 Tianjin 等基地支撑。常见宣称包括 360° 弹力腰围、随动贴合、柔软 Hug-band、瞬时自动贴合、像普通内裤一样易穿。

## 关键论断（key_claims）

- **1P/3P 是结构平台之分，不是高低之分——消费者数据证明平台本身不产生偏好差异** —— 支撑页：[[1-Piece vs 3-Piece CD Pants Design（一片式 vs 三片式裤型设计对比）]]
- **档位升级的实质是 SAM% 提升 + 悬浮 pad + 曲线腿围 + 模切一体 panel 的组合** —— 支撑页：[[CD Pants Converting Process（CD裤式产品加工工艺）]]、[[Pant-Type Disposable Absorbent Article（裤型一次性吸收物品）]]
