# CD pants machine process.pptx

## Basic Information 基本信息
- **Title**: General introduce CD pants product construction and machine process
- **性质**: 产品结构与机器工艺培训件（MD 过程与 KC MD 机基本相同，重点为 CD 工序）
- **同族说明**: 与 [[CD Pants Process Overview - GIC Korea（CD裤式产品工艺概览·韩国上岗培训）]]（2016 上岗培训）不同文件不同侧重——本件以产品构造与工序机理为主；工艺机理已页面化于 [[CD Pants Converting Process（CD裤式产品加工工艺）]]，本页记录构造命名与工序细节。

## Product Structure 产品结构（产品结构 · Top View 8 组件）

1. Insert 2. Panels 3. Poly 4. Liner 5. Corewrap 6. Pad 7. Surge 8. Leg elastics

几何标注：**腿围弹性间距 5 mm**；**前区 tackdown bond 45 mm**。

## Constructions 分构造（分构造）

| 构造 | 组成 |
| --- | --- |
| 吸收构造 | Pad + poly 侧包裹片 + liner 侧包裹片 + Surge + Liner → Folded |
| Insert 构造 | 外覆布与翼片 + Poly + 折叠吸收体 → 折叠外覆布与翼片（带弹性） |
| Panel 构造 | 外层无纺布 + panel 弹性 + 内层无纺布 → 折叠后 slit 分成两片 |

## Machine Process 机器流程（机器流程）
FIBERIZER → Liner 侧包裹片 → Surge Applicator → Leg elastic → Liner → Pulp → Poly 侧包裹片 → Debulker → Pad cut off → 外覆布 → 翼片折叠板 → 腿围弹性 → 主贴合 → Insert cut off → Liner Applicator → 主贴合切断 → Poly/Paper → Bagger → Stacker（DMD 方向）。

分四段：SURGE/LINER PROCESS、INSERT PROCESS、FORMING SECTION、PRODUCT CUT OFF PROCESS、INSIDE/OUTSIDE PANEL PROCESS、FLAP/OUTER COVER PROCESS。

## CD Process CD 工序要点（CD 工序要点）
- **IAP（Insert Applicator, 2012）**: 将产品方向**由 MD 转 CD**（与概念页"转向是枢纽"一致）。
- **Panel Slitter**: 将 panel 分为**驱动侧（drive side）与操作侧（operation side）**。
- **Panel Chopper**: **部分切断 panel elastic——弹性回缩时获得清晰外覆图案**（clear out cover pattern）。
- **Panel Sealing / Product folding**: 封合与产品-panel 对折。
