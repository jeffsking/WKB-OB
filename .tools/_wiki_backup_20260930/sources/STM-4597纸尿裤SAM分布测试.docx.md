# STM-4597纸尿裤SAM分布测试.docx

## 一句话定位

内部 SOP **STM-4597**（第 1 版，2021-08-24）：用**溴甲酚绿指示液喷洒 + 标准照片比对**，定性评价婴儿纸尿裤/片产品中 **SAM（Superabsorbent Material，超级吸水材料）颗粒的分布均匀性**。

## 摘要

先配制 5% 乙酸（5 mL 纯乙酸 + 95 mL 蒸馏水）与**溴甲酚绿钠盐指示液**（450 mL 水 + 50 mL 5% 乙酸 + 0.25 g 溴甲酚绿钠盐，搅拌 ≥5 min）。样品沿绒毛边缘剪掉底膜与无纺布，取出使用面无纺布与衬纸（尽量不破坏绒毛区）。将样品使用面朝上平放，指示液在距表面 **152–254 mm** 处沿纵向来回均匀喷洒覆盖；喷洒后 **15–30 s 内**与一套标准照片（standard photo chart）比对，评价 SAP 分布。操作安全：指示液刺激性气味需戴口罩、接触皮肤难洗需戴手套。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| 乙酸浓度 | 5%（5 mL 乙酸 + 95 mL 水） | 配制指示液底液 |
| 溴甲酚绿钠盐 | 0.25 g / 500 mL 混合液 | 搅拌 ≥ 5 min 至全溶 |
| 喷洒距离 | 152–254 mm（≈6–10 inch） | 纵向来回 |
| 评级时限 | 喷洒后 15–30 s | 超时变色不可比 |
| 判定方式 | 与标准照片比对 | 定性 |
