# Pressure Sensory 测试方法.docx

## 一句话定位

内部 SOP **WI-65030**（第 1 版，2024-09-03）：用气囊式传感器 + 主机记录仪测量成品与橡筋材料的**皮肤接触压力（Pressure Sensory / Skin-Contact Pressure）**，是穿着舒适度量化的重要方法。

## 摘要

本方法使用一台带多通道的主机记录仪（屏显 ANRITSU AM-8051K COMPACT THERMO LOGGER）与**气囊式传感器（air-bag sensor）**：先通电、连接传感器、用蓝/红孔放气/充气使气囊呈半真空半充气态，插入主机通道开机自检。样品分两类——（1）**人体模型（mannequin）**：产品按尺寸穿在 model 上，气囊置于标记点位，数值稳定后读数 ×10，单位 V；（2）**手臂/腰围橡筋**：用软尺量手臂周长，按拉伸倍率算松弛长度 = 周长 ÷ 拉伸倍率，将样品绕臂一圈、订书机固定重合处，气囊置入测试区，计时结束读数 ×10（V）。注意事项强调橡筋测试前不可被拉伸、同一样品处理条件一致、测试期间保持同一位置。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| 仪器 | 主机记录仪 + 气囊式传感器（3 通道可选） | 屏显 ANRITSU AM-8051K |
| 读数单位 | V（伏特），稳定后读数 **×10** | 即压力读数 = 通道值 ×10 |
| 松弛长度公式 | 手臂周长 ÷ 拉伸倍率 = 松弛长度（腰围为松弛宽度） | 腰围/手臂通用 |
| 数据上限 | 单通道最多暂存 6000 个数据，满需 CLEAR | 操作约束 |
| 试样一致性要求 | 橡筋未拉伸、同位置、同处理条件 | 否则不可比 |
