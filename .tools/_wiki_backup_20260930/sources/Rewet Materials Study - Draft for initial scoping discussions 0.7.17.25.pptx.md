# Rewet Materials Study - Draft for initial scoping discussions 0.7.17.25.pptx

## Basic Information 基本信息
- **Author**: Clemmer
- **Date**: 2025-07-17（scoping 讨论草案）
- **Domain**: Performance / Rewet / Rewet Fundamentals —— 摄入材料设计变量 × 回渗

## Background 背景
- 各项目改动摄入材料特性时可能偶遇影响回渗的变量。
- 主张**主动**围绕摄入材料设计建回渗数据，而非被动收集项目数据。

## Draft Approach 草案步骤
1. 聚焦研究不足区域以缩小范围：**bodyside liner** 与 **topical surge**（传统 under-liner surge 已充分研究）。
2. 列出可能重要的变量。
3. 逐一判断是否研究过。
4. （会上）确定优先级，为供应商讨论做准备。
5. （会后）与供应商确认材料可得性，定最终 codes。

## Testing 测试方案（测试方案）
- 手工改造产品（hand-modify）。
- **双回渗口径**：closed cradle + low/high rewet（参见 [[LPR vs HPR Rewet（低压回渗 vs 高压回渗机制）]]）。
- 载体：BUFF BABY 产品与 GRIFFIN Depend 产品并用。
- 附带学习：**collagen vs blotter** 皮肤模拟介质对比；是否需要 **open cradle intake** 以理解摄入时间权衡。
