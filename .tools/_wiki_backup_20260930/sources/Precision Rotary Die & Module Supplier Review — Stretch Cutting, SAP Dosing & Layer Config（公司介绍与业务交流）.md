## Key decisions 决策要点

1. **K-C 区域范围（已明确）**：KC IPC 区域覆盖 **韩国、大中华区、澳大利亚/新西兰、印尼**；未来几年团队架构仍会重组，但这**四个国家/地区是重点**。
2. **供应商能力盘点（已给出）**：
   - 1992 年成立，**30 余年**；两个厂区合计约 **18,600 m²**；**44 台以上**精密加工设备（CNC / 放电 / 磨削）；出口 **12 国以上**。
   - 核心能力为**精密旋转模切与共用模块工程**；产品线四类：① 旋转模切模块（高速钢或超细晶硬质合金，用于纸尿裤/卫生巾/标签/口罩等）；② 压花与通道辊；③ 母卷与成型组件；④ 现场改造（提升产能、优化）；⑤ 产线开发支持（为新品规划量产线）。
   - **差异化**：全球仅约 **3 家**能自行研磨硬质合金模具，其为之一（本方对此表示惊讶并认可难度）。
3. **切割 + 拉伸工艺（已在用/已验证）**：流程为**先切孔 → 再拉伸 → 再复合**。
   - 拉伸比例可**精确控制到约 10%**（配张力控制模块 / T-channel 模块）；
   - 该模块的作用是：材料本身存在 GSM 波动与张力波动，**在高速下保持张力一致非常关键**；拉伸使材料**结构增强约 10%**；
   - 采用**两次拉伸**，可在第二次拉伸时**微调**以保证总张力合适，并可检查成品。
4. **SAP 计量改进方案（已提出，即将验证）**：
   - 现行布置：SAP 先经某单元计量，再输送 → 该组合造成两个关键问题：**输送过程中颗粒破碎** + **计量偏差**；
   - 改进：把混合位置前移，使**输送距离缩短至约 2–3 米** → 减少颗粒破碎、提高计量精度与一致性。
   - 状态：**本月（9 月）开始全面安装与测试**；**尚无实测数据**，仅理论上成立。
5. **多层芯体构型（已验证项）**：两层 / 三层配置；三层时**中间层位于两层之间**，可按客户规格更换中间层材料 → 提供"如何施加 SAP"的更大柔性。

4. **打孔（pin punch）的最小孔径未确认**：关键参数为 **pulling hole / pitch / pin diameter**，直接决定孔质量与一致性；本方追问"能做到的最小孔径是多少"（现有参照 6×9）[待验证]，**未获得答案**。
5. **打孔是否需要加热**：对方答**不加热**，为常温 pin punch [待验证]。
6. **模切 + 针孔的组合方式未定**：本方提出能否"一半用 die cutter 打大孔、一半用 pin 打小孔"，或交付两套（一套模切、一套针孔），并指出**需要平衡张力 + 对位**；对方未给出可否的明确答复。
7. **对位（registration）难度被指出很高**：本方明确"做对位很难，国内面层做不出来"；该项目是否推进未定。
8. **花型选择的原因未说明**：本方追问现有花型是"工艺上容易"还是"吸收上更好"，以及是否只有一种商用花型 —— **未得到明确回答**。
9. **与 Yuhan-Kimberly 的合作模式**：对方称有时由 YK 给出详细工艺，有时让其自行设计；本方希望了解如何借助其为其他国家做新品导入 —— 待探索。
10. **K-C 全球与 K-C 中国的业务占比很小**：K-C 全球"very little"，K-C 中国目前多为备件与报价 —— 如何扩大合作未定。
11. **弹性材料的放卷经验**：对方称有经验（墨西哥，多为自然区），本方未确认是否满足需求。
12. **是否有其他花型可提供**：本方询问是否可提供除现有之外的花型（提到 SP feeding system） —— 未定。
