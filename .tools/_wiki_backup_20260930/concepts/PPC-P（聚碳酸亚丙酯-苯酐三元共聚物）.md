# PPC-P（聚碳酸亚丙酯-苯酐三元共聚物）

> 一句话定义：以 **CO₂ + 环氧丙烷（PO）+ 苯酐（PA）** 三元共聚得到的**脂肪族聚碳酸酯改性树脂**；在纯 PPC 基础上引入苯酐把玻璃化温度从约 30 ℃ 抬到 **55 ℃ 以上**，从而获得可储存、可加工的稳定性，是本批「可家庭堆肥无纺布」路线的主要候选基体。

## 机理 / 结构拆解

1. **三元共聚而非改性共混**：单体为 **CO₂ 35~40% + PO 40~55% + 苯酐 10~20%**（三组分在同一聚合过程内投入），苯酐被明确定位为「PPC-P 中的 P 单体、用于稳定 PPC」。因此 PPC-P 不是「PPC 加添加剂」，而是**共聚物本身**。
2. **苯酐解决的是 Tg 与储存稳定性**：纯 PPC 的 Tg 仅约 30 ℃，室温下即处于高弹态、储存中易变形/降解；引入苯酐后 Tg **升至 55 ℃ 以上**，并带来「PPC-P 比 PPC 储存更稳定」的结论——这是 PPC-P 能作为商品树脂的前提。
3. **四项材料特征**：① UV 抗性优于当时可找到的任何可降解聚合物；② **只在接触微生物时才降解**（即非单纯水解型，环境暴露下更可控）；③ 高透明，接近 PC；④ 水蒸气与 O₂ 透过性良好（透气/阻隔取向取决于配方与制膜方式）。
4. **脆 + 低熔点 → 改性是应用前提**：原文判断「纯 PPC-P 脆、熔点相对较低」，因此**工程改性是必须项**，路线包括共混与共聚两类。
5. **主研路线是 PPC-P + PBAT 共混**：可家庭堆肥；PBAT 中可混入**最多 35% PPC-P** 得**纤维级 PPCT 树脂**；**80~90% PBAT + 10~20% PPC-P** 用于农用吹膜/流延膜；加 CaCO₃ 粉做**透气膜**树脂的研发在进行。
6. **PPC-P 与 PLA 的搭配受限**：两者硬度都高，**单纯共混只能得到注塑级**；要做纤维级须走**共聚**（在研代号 PPCL）。PPC-P/PHA 的共混或共聚亦在实验室阶段。
7. **成本是规模函数而非原料函数**：供应商自述原料成本口径约 **RMB 8/kg**（含 CO₂、PO、PA 与催化剂），售价则随产能释放分为三档——「贵」在这一阶段主要来自产能不足与摊销，而非原料本身。详见 [[联欣环保科技（泰兴）]]。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[LXBIO 拜访报告（2025-09-25 泰兴 PPC-P 基地）]]、[[PPC&PGA 基无纺布开发方案（第二版）]]、[[PPC 纺粘试产记录（2026-05-01）]]）：两份同源文档（拜访报告与开发方案）在单体配比、Tg、特征与认证状态上**完全一致**，可视为同一技术口径的重复确认；纺粘试产记录则提供了本批唯一的实测物性，结论与「PPC-P 需改性才能应用」一致——实测树脂维卡软化点仅 60.2 ℃，印证了低熔点约束。

- **教训一（口径）**：询价或评估 PPC-P 时，必须区分 **PPC-P 本体树脂 / PPCT（PPC-P+PBAT）共混料 / 成品无纺布** 三个层级的价格，本批资料中三者都出现过，混用会得出错误的成本结论。
- **教训二（选型）**：PPC-P 的低熔点是双刃剑——作 TABCW 皮层（130 ℃ 级复合料）是优势，作常规纺粘成品则是**耐热上限约束**（维卡 60.2 ℃），须先定耐热要求再定配方。
- **教训三（供应链）**：PPC-P 在本库时间线上是**全新产能**（泰兴 2.5 万吨 2025-10 首产、淄博 4 万吨 2027 中），规格与价格均未稳定，采购策略应假设「单源 + 爬坡风险」。
- **待补 `[待验证]`**：PPC-P 熔点；CO₂ 固定率与碳足迹口径；海洋可降解与 FDA 认证的实际取得时间；PPCL / PHA 共聚路线的结果。
