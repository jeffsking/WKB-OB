# Nanocellulose Hygiene Application Roadmap（纳米纤维素卫材应用路线图）

> 一句话定义 One-line definition：把三类纳米纤维素（CNF/CNC/BC，纳米纤维素）映射到卫材的**八个应用方向**，用「技术可行性 × 商业价值 × KC 业务关联度」排出梯队，并以三阶段（快速验证 / 中试 / 产业化）推进的**方向筛选与排期框架**。

## 机理 / 结构拆解 Mechanism and Structure

1. **方向一 SAP 增强（第一优先级）**：CNF/CNC 的高比表面积与表面羟基（–OH）充当 SAP（高吸水树脂）的**物理交联点**或共聚组分，提升凝胶强度 gel strength、降低回渗 rewet、改善颗粒间结合力。三条技术路径——CNF 与丙烯酸/丙烯酰胺共聚接枝（化学键合）、CNF 作物理互穿网络 IPN、表面修饰 CNF 的复合粒子方案。
2. **方向二 Foaming Core / ADL / 半芯体（第一优先级）**：利用 CNF 的成膜性 + 保水性 + 阻隔性，三个子方向——泡沫芯体（CNF 稳定泡孔防塌陷 → 超薄透气）、ADL（导流层，CNF 纤维网快导流 + 锁液减回渗）、半芯体（部分替代绒毛浆/SAP 混合体系，成本与环保双收益）。
3. **方向五 亲水涂层 / Core Wrap / SMS 涂层（第一优先级）**：CNF 形成致密亲水膜，替代 PE/PP 膜做芯包（core wrap）实现全可降解方案，或赋予 SMS 抗菌、缓释 lotion 功能，或作防漏隔边涂层。**投入小、见效快，是短期突破口**。
4. **方向四 增强粒子 → 超薄无纺布（第二梯队）**：CNC/CNF 作增强填料加入纺粘/熔喷，提高单纤拉伸强度，实现更薄、更软、更低克重。推荐路径：先热轧（门槛低）→ 再 SMS，重点攻关分散均匀性。
5. **方向七 水凝胶防侧漏大坝（第二梯队）**：CNF 基水凝胶用于腿围，随体温/湿度微膨胀形成自适应密封；难点在机械强度与柔软性的平衡及耐久验证。
6. **方向三/六 Lotion 分散剂与护肤载体（第三梯队）**：CNF 作活性物纳米载体/分散稳定剂，缓释释放；现有分散剂已够用，增量价值有限。
7. **方向八 三联结构改性 / 智能功能性尿裤（远期储备）**：pH 响应变色、温感指示、药物缓释、导电复合（健康监测传感器基底）；暂不投研发资源，等方向 1–5 跑通后向上延伸。
8. **排期逻辑**：第一梯队 Q2–Q3 立即启动；第二梯队 6–18 个月规划；第三梯队长期储备/观望。

## 经验教训 Lessons

> ✅ 验证（2026-09-29，来源 [[Nanocellulose Technology Roadmap for Hygiene Materials（纳米纤维素卫材应用技术路线图 V1）]]）：本路线图与 [[纳米纤维素（CNC、CNF、BNC）]] 既有结论一致——纳米纤维素**不作大宗替代**，价值在增强、阻隔与高端差异化；本页新增的是「先做哪个方向」的排序与参数门槛。

- **教训一（方向收敛）**：八个方向同时铺开会稀释资源；路线图给出的收敛准则是「可行性 × 价值」双高才进第一梯队，涂层方向因可行性 5/5 而成为最低风险的起手式。
- **教训二（参数先行）**：每个方向都附了可验收的材料参数（直径、羧基含量、结晶度、模量、固含量、稳定期），RFQ 与打样前先锁参数，避免「样品到了才发现不是同一支材料」。
- **待补 `[待验证]`**：CNF 在 SAP 体系中的实际回渗改善幅度；CNF 掺杂无纺布减薄 10% 后的强度保持率；水凝胶防侧漏的耐久循环数据。
