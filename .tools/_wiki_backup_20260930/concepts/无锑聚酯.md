# 无锑聚酯（Sb-Free PET）

> 一句话定义：以**钛系等非锑催化剂**替代常规聚酯缩聚所用锑（Sb）系催化剂的聚酯体系；在卫材链中被品牌方作为可持续与合规要求提出——**目前国内真实产能位点在切片层，不在纤维层**。

## 机理 / 结构拆解

1. **锑来自催化剂而非单体**：常规 PET/CoPET 缩聚普遍使用锑系催化剂，锑残留随切片带入纤维。无锑化的技术路径是**换催化剂体系**（钛系为主），不改变主链化学。
2. **能力位点：切片级**。本批核实（2026-07-09）结论是——**纤维厂均未见公开无锑牌号**；国内无锑聚酯的真实能力集中在切片供应端：天津石化 TFT500 全钛环保聚酯切片（10 万吨线、已出口欧盟）、恒逸逸钛康/逸泰康（钛系催化剂）。
3. **传导路径**：纤维成品商（A 层）通常不自产无锑切片，因此无锑 CoPET 纤维须由**指定上游切片来源 + 受托纺丝**实现，而不是「买现成牌号」。
4. **交付形态是「协议条款」而非「目录产品」**：可操作路径是把 Sb 检测限与细旦 CV 值、熔点窗口一并写入技术采购协议。
5. **需求侧压力**：终端卫材品牌（国际一线与国内头部）对细旦、无锑有话语权——无锑化正从「加分项」走向准入门槛。
6. **与 IPA 维度正交**：IPA 决定熔点与成本，无锑决定催化剂与合规；两者互不替代，需分别指定。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[CoPET 双组份热粘合纤维市场与供应商（供应链分层·文档版）]]、[[CoPET 采购蓝图：成本拆解与供应分层]]）：两份来源独立给出同一结论——**无锑能力在切片级、纤维端尚无公开牌号**，且都主张通过「指定上游切片 + 协议约束」实现。本页表述与来源一致。

- **教训**：无锑不是「选一个牌号」的问题，而是**供应链指定 + 协议核验**的问题。只向纤维厂询「有没有无锑牌号」通常得到「没有」，但这不代表做不到。
- **口径提醒**：优彩环保持有的是**绿色认证**，原文明确标注「非无锑」——两者不可混为一谈。
- **待补 `[待验证]`**：Sb 检出限具体数值；无锑切片的成本增量；钛系催化剂切片在皮芯复合纺丝上的工艺适配性。

> ✅ **验证（2026-09-29，来源 [[国内 CoPET 纤维厂商与无锑细旦核实表（2026-07-09）]]）**：独立核实结论与页内主线一致——**无锑（钛系）能力已就绪于切片级（天津石化 TFT500 10 万吨/年、恒逸逸钛康），纤维纺丝级 7 家国内 CoPET/双组份厂商均无公开无锑牌号**，「卡在切片与纤维之间」的判断成立；表并给出三条行动建议（函询 7 家 / 锁定无锑切片 + 指定纺丝厂代工 / 把 Sb 限值写入技术协议与检测项），与本页"供应链指定 + 协议核验"教训互为印证。
