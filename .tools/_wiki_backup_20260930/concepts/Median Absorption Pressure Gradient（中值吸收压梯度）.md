# Median Absorption Pressure Gradient（中值吸收压梯度）

> 一句话定义：P&G 用来设计"面层干爽"的量化工具——用 **Capillary Sorption Test**（毛细吸收试验，0–100% 液饱和度的吸收/解吸曲线）测出每层材料的**中值吸收压（Median Absorption Pressure, MAP）**，再让这个压力**沿厚度方向递增**：**面层最低 → 摄入层居中 → 芯体最高**，液体就会被"一级一级往下抽"，面层因此变干。它的价值在于把"梯度设计"从定性口号变成了**带数值门槛、可测可验**的设计规则。

## 机理 / 结构拆解

1. **MAP 是什么**：在吸收/解吸曲线上取**中值**（介于 0% 与 100% 液饱和度之间）对应的吸收压，单位用**液柱高度 cm**表示。它衡量的是"**这一层在多大的吸力下才肯把液体交出去**"——MAP 越高，吸力越强、越不肯放液。
2. **梯度方向必须是"向下递增"**：面层 MAP 最低（吸力最弱）→ 摄入层居中 → 芯体/摄入层下方材料最高。**下一层永远比上一层更能吸**，液体才不会在任何界面上停住。若方向反了（贴肤侧吸力最高），液体就会留在贴肤层——本库 [[毛细梯度设计]] 把这称为 **inverted Z-gradient（倒置 Z 梯度）**，并已把它判为现状缺陷。
3. **P&G 给出的门槛值是可直接抄的设计规则**：面层 **1–4 cm（优选 2–3）**；摄入层 **3–8 cm（优选 4–7）**；摄入层下方材料（芯体或交联纤维素纤维层）**8–11 cm**。三层区间**首尾相接而不重叠**，本身就是"梯度必须连续"的表达。
4. **为什么它专门用来治"3D 面层偏湿"**：3D 高克重面层厚、持水多，天然偏湿。梯度设计不是减少面层的持水量，而是**保证它持的水会被下一层抽走**——这是"用结构梯度替代单一材料指标"的典型应用。
5. **它与本库 MCCT 是同类测量的两条路线**：K-C 侧用 [[MCCT Multi-Component Capillary Tension（多组分毛细张力测试）]] 输出 **Bn（特征毛细压）与 n（分布宽度）**，P&G 侧用 Capillary Sorption Test 输出 **MAP**。二者测的都是"毛细压—饱和度"关系，**因此两套数值不能直接互换，但设计逻辑完全同构**。
6. **同一原理在 P&G 专利中是跨层复用的**：面层用**润湿性梯度**（两面接触角差 15°–45°）、ADS 用**超细纤维芯吸梯度**（3–35 wt%）、芯体用**双层功能梯度**、SAP 用**凝胶间隙持液**——四件专利共用"制造向下梯度"这一条原理，只是载体不同。
7. **梯度要"够但别过头"**：面层接触角差最大的样品（56.2°）回渗反而升到 117 mg，最优出现在中等梯度（44.3° → 40.7 mg）。**梯度过陡会在界面上造成失配**——这是一个容易被忽略的非线性。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[P&G Rewet Patent Deep Dive（宝洁回渗专利深挖）]]）：本页为新概念页。首条来源**把本库既有的定性判断升级为量化规则**——[[毛细梯度设计]] 此前只能说"上细下粗、吸力递增"，本页给出可直接写入设计规范的**三层 MAP 数值区间**与测定方法；两条来源在"梯度方向必须指向芯体、倒置梯度是缺陷"上**完全一致**。

- **教训**：**"有梯度"不等于"梯度正确"**。本页给出两个非线性证据——面层接触角差过大反而恶化回渗；P&G 三层区间刻意首尾相接。设计梯度时必须同时给**下限（够不够）与上限（过不过）**。
- **教训**：**梯度要靠"下一层接得住"才成立**。若摄入层或芯体的吸力没有真正高于上一层，梯度就是纸面上的；这也是为什么 P&G 要在芯体层单独要求 8–11 cm。
- **待补 `[待验证]`**：本库自有材料按 Capillary Sorption Test 测得的 MAP 值；MAP 与 MCCT 的 Bn 是否存在可用换算；MAP 梯度在 K-C 产品上的实测回渗收益。
