# TCF Bleaching（Totally Chlorine Free 全无氯漂白）

> 一句话定义（Definition）：**TCF（Totally Chlorine Free，全无氯漂白）** 是纸浆漂白工艺等级之一——整个漂白序列不使用任何含氯化学品（区别于 ECF 无元素氯漂白）。在本库中，它的意义**不在工艺本身，而在合规与供应链**：浆厂切换到 TCF 等级会触发**规格书、安全认证与客户认证流程的连锁重跑**。

## 机理 / 结构拆解（Mechanism）

1. **等级切换 = 化学品体系变更**：TCF 意味着漂白段化学品体系整体改变；一旦体系变更，**下游客户（卫材/纸巾）需要重新做产品安全认证**。
2. **过程稳定性是切换的第一风险**：多项目叠加（如同一时间做多个浆厂、多个改动）会造成过程不稳，行业做法是**回退到已知条件、沿用同一化学品体系重新上路**。
3. **文档链必须先于实物到位**：grade 变更需同步更新 **spec（规格书）/ TDS（技术数据表）/ PS number / RMS（raw material spec，原材料规格）**；由供应商侧 productivity 团队（全球团队，运营层面在印度）统一执行。
4. **样品 grade 名必须等于商用 grade 名**：若发给客户做认证的样品，与最终商用时的 grade 名称/规格不一致，**认证流程需重跑**——这是最容易被忽略、代价最高的一条。
5. **PSC（Product Safety Clearance 产品安全认证）的触发时点**：**在 TCF 等级商业化之后**才申请；仍处于 trial（试产）阶段时不应启动，因为 spec 尚未冻结。
6. **JV / 客户结构会改变认证路径**：并入 JV 的客户可采用**更集中、决策更快**的流程（一个浆厂通过即可延展到其他浆厂）；**未并入 JV 的客户仍走常规流程**，两条线的接口人与文档口径需分别管理。
