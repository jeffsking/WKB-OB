# High-Density Fluff Core（高密度绒毛浆芯体）

> One-line definition 一句话定义：**把绒毛浆压缩到明显高于常规芯体的单位厚度承载量（1 mm 厚度可承载至 170 gsm，而常规上限约 100 gsm）**，用以在**同厚度**下替代预制 airlaid 芯体的一种绒毛浆芯体技术。（中文：同样厚，装更多浆——用"在线压缩绒毛浆 + SAP"取代"买预制 airlaid 芯"。）

## Definition 定义与规格对比

| | 标准绒毛浆芯体技术 | **高密度绒毛浆芯体技术（HDC）** |
|---|---|---|
| 1 mm 厚度承载 gsm | **min 70 / max 100** | **min 70 / max 170** |
| 总 gsm 范围 | **150 – 500**（3D 芯体或中央凸起 650–700） | **200 – 350** |
| 中文 | 常规全浆芯 | 高密度芯（用于 HDC 产品） |

**参考产品实测点**：2.2 mm / 322 gsm；2.2 mm / 250 gsm；2.5 mm / 276 gsm。

## Mechanism 机理与驱动力

1. **替代路径**：源文明确指出**"在线 airlaid 芯（fluff + SAP）正在取代预制 airlaid 芯"**，且这是**跨品类的通用趋势**（femcare 起步，可外推至其它品类）。
2. **等价性判据**：高密度绒毛浆 + SAP 方案与**预制 airlaid + SAP** 商业方案在**相同厚度**下对标——即竞争的不是"更薄"，而是"同样厚度、更低成本/更短供应链"。
3. **⚠️ 缺失环节**：压缩工艺如何实现（压力、湿度、回弹控制）、压缩后的**吸收速率与回渗**代价、SAP 在压缩态下的 [[Gel Blocking（凝胶阻塞）]] 风险 —— **源文全部未给** → `[待验证]`。
4. **与本库主线的关系**：这是**"保浆路线"**（继续用绒毛浆），与 [[Fluff-Free 4th-Gen Absorbent Core（无木浆第四代芯体）]] 的**"去浆路线"**构成直接对立的两条路线；前者降本依赖**工艺（压缩）**，后者降本依赖**材料替代**。

## 经验教训

- **Lesson（保浆 vs 去浆不是同一层面的取舍）**：高密度路线降本靠**工艺压缩**（不换材料），无浆路线降本靠**材料替代**（换供应链）。两者**成本结构与风险不同源**，选型时应分开评估而非直接比单位成本。
- **待补 `[待验证]`**：压缩工艺参数与回弹；压缩态下的 CRC / 吸收速率 / 回渗；与预制 airlaid 的成本对比数据；是否适用于婴儿线（源文仅给 femcare / 轻失禁）。
