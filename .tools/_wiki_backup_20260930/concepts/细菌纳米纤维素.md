# 细菌纳米纤维素（BNC，Bacterial Nanocellulose）

> 一句话定义：由细菌合成的纳米级纤维素三维网络，具高比表面积与多孔结构；在本库中作为**可嫁接的功能载体材料**（干颗粒形态）与**纳米纤维素热熔胶（HTM adhesive）** 的原料，被列为 2027 年旗舰探索方向。

## 机理 / 结构拆解

1. **材料本征优势**：纳米级纤维（40–60 nm）带来高比表面积与多孔三维网络（孔隙率 >90%），持水率 200–1000×，机械性能突出（杨氏模量 78 GPa、拉伸强度 826 MPa）。这些特性使其天然适合作为**负载型载体**（抗菌剂/除臭剂/导电填料）与**吸水/保水介质**。
2. **干颗粒形态是关键工程化突破**：BC/PEG 置换干颗粒中间体可在**干态保持无菌、遇水复水成胶**，成为一个通用嫁接平台——抗菌剂、石墨烯、TiO₂、导电材料均可对接。
3. **两条主应用路径**：
   - **功能层嫁接**（近期）——抗菌、除臭、压力传感、导电加热等，其中**抗菌除臭是最优切入点**（工艺同构 + 温度兼容）。
   - **纳米纤维素热熔胶（HTM adhesive）**（2027 旗舰）——以纳米纤维素为核 + PEG/PCL 母粒，目标**替代/减少 SAP**。
4. **六条应用路线 + 三道决策门**：OI-01 已排序六条路线并设三道决策门，IP 布局策略已定为「尽早布局」（BMC 改性路径）。
5. **工艺温度兼容性**：BNC 预估耐温 200–280°C，高于可比工艺（CN117024899A 的 100–120°C 干燥）——这是嫁接可行性的关键前提。

## 追加：Thermal Comfort 项目批（2026-09-29 追加）

> 本节为 **Thermal Comfort 项目批（批次 S1_Projects_Thermal Comfort_01，3 份资料）** 编译时的追加记录，**不改动上方既有结论**。上方「价值在功能化载体平台、不在替代 SAP/绒毛浆」「卡点在干燥与受压无回弹」两条在本批仍成立；本节新增的是**热管理（调温）这一新应用维度**。

### 1. 新增应用维度：结构调温层

- **机理是几何而非化学**：≈85–95% 孔隙率封存静止空气（k_空气≈0.026）+ 纳米孔（≈20–200 nm）≈ 空气分子平均自由程（≈68 nm）产生 **Knudsen 抑制** + 点接触骨架（τ≈1.5–3）最小化固相传导并带来声子边界散射 + 富羟基表面结合水提供显热热质量 + 纳米纤维垫散射红外。见 [[PCM-Free Thermoregulation]]。
- **两个耗散回路**：结合水显热缓冲（不靠潜热即降低 dT/dt）与蒸发散热（湿态经水汽传递散热）。
- **定位结论**：多小时微气候舒适是**稳态问题**，四项调温功能中 3 项为结构性 → BNC 结构路线是**默认路径**，PCM 微胶囊仅在瞬态尖峰有边际价值。见 [[BNC-Only vs BNC+PCM (Thermoregulation Ledger)]]。

## 追加：Meeting Minutes 批（2026-09-29 追加）

> 本节为 **S5_Areas_Meeting Minutes_01 批次（产品研发与实验计划研讨）** 编译时的追加记录，**不改动上方既有结论**。上方「BNC 不可对位替代 SAP / 卡点在干燥与受压回弹」两条在本批被**正面支持**（转写原文：网状结构受压即坍塌、不可复原，故无法做 SAP 的对位替代）。本节新增的是**材料增强与外行业商业化参照**两条。

### 1. 本批新增：作为增强填料的外行业证据

- **PP 增强（汽车保险杠/抗冲改性口径）**：纯纳米纤维素干粉按 **3–4%** 加入 PP 的 masterbatch，可提升 PP 的**抗冲击能力与屈服强度约 35%**。（行业类比口径，非卫材实测）
- **特种纸**：造纸/特种纸行业添加 **2–5%** 纳米纤维素即可显著提升强度，用于重载包装，属已商业化场景；若用于卫材芯体增强，MD strength 有大幅提升空间（**估算，标 `[待验证]`**）。
- **医药/敷料**：创可贴敷料、面膜、靶向药载体等已有商业化应用；牙科种植与关节用氟化物为 FDA 批准路径——**该 FDA 口径不可等同平移到卫材**（原文明确）。

### 2. 本批新增：产业化三要素的因果口径

- 成本高的三个来源依次是 **① 糖源获取 → ② 发酵与后处理工艺效率 → ③ 粉体干燥能耗**；本批供应商的降本来自「糖源取自屠宰废水，成本近零」，**而非**干燥环节（干燥成本无法通过糖源优化摊薄）。此口径与页内既有「卡点在干燥」**互补、不冲突**。
- 三种干燥路线（冷冻干燥 / 超临界 CO₂ 干燥 / 常压干燥）中，**常压干燥在成本与效率上相对最平衡**，但存在角质化塌孔风险——与既有「干燥塌孔（horrification）」一致。
- 纯度路径：碱洗（NaOH）后可达到 99.9%+（三个九）纯度。

> ✅ Verification（2026-09-29，source 来源 [[纳米纤维素供应商拜访计划 V3.1（2026Q2）]]）：本批补齐了 BNC 的**发酵工艺窗口与成本结构**——Hestrin–Schramm 培养基、葡萄糖 20–50 g/L、pH 4.5–6.0、28–30 °C，静置 7–14 天 / 搅拌 3–7 天（低剪切 50–200 rpm）；产物纯度 >99%、结晶度 84–89%、纤维直径 20–100 nm、吸水率 200–1000 倍。成本结构为 原料 30–40% / 能耗 15–20% / 人工 15–25% / 后处理（碱洗·干燥）15–20%，即**原料与人工是两大降本空间**。
>
> 微凝胶方向给出可复现配方：BC:壳聚糖 = 10:90 (v/v)、四硼酸钠 2%、ε-聚赖氨酸 0.4 mg/mL、均质 10,000 rpm，对应包封率 48.23%、粒径 1,423 nm、PDI 0.25、Zeta 电位 33.26 mV；微凝胶粒径 1–10 μm 可调。该方向与 [[BNC Application Red Line（BNC 应用红线）]] 的「化妆品/医药优先、卫材需单独论证」口径一致，未改变既有结论。
