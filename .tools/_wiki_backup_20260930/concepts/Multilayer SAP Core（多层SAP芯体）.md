# Multilayer SAP Core（多层SAP芯体）

> One-line definition 一句话定义：**把 SAP 夹在两层高蓬松（high-loft）热风无纺布之间，靠包覆与 land 区压合把 SAP「困住」而不靠胶固定**的一种无绒毛浆 / 少绒毛浆芯体架构。（中文：SAP 不 dispersed 在绒毛浆里，而是被两片蓬松无纺布"夹住"形成独立吸收层。）

## Definition 定义与构型族

同一架构可切换三种构型（按产品需求）：

| 构型 | 结构 | 中文 |
|---|---|---|
| 无绒毛浆双 SAP 层 | 两层 SAP + 三层无纺布 | 全 SAP / 无浆 |
| 单 SAP 层 | 一层 SAP | 单层薄芯 |
| 单 SAP 层 + 绒毛浆混合 | SAP + fluff 混合层 | 混合芯体 |

> 要点：**构型切换不换架构**——变的是"夹几层、夹什么"，不变的是"SAP 被高蓬松无纺布夹持"这一固定方式。

## Mechanism 机理拆解

1. **固定机制**：SAP 沉积在下层高蓬松热风无纺布上 → 覆上层无纺布 → 在 land 区（无 SAP 带）land-to-land 压合/粘合，把 SAP 限制在 pocket 内。与 [[Patterned SAP Core Forming Drum（印花SAP芯体成型鼓）]] 的"land 也是封堵凸台"原理同源。
2. **功能分层**：靠**两层不同性能的 SAP** 分工——上层用**高渗透型**（high permeable，快速下渗），下层用**高保水型**（high retention，锁水）。这是本架构相对"单一 SAP 牌号均匀混合"的核心增益。
3. **层间用胶极少量**：示例构型中每层界面仅 **3 gsm** 热熔胶，主固定力来自 land 压合而非胶（对照 [[Glueless Bonding（无胶粘合工艺族）]]）。
4. **与 [[Fluff-Free 4th-Gen Absorbent Core（无木浆第四代芯体）]] 的关系**：本架构是"无浆化"的一条实现路径；差异在于**用高蓬松无纺布替代绒毛浆的分散与缓冲功能**，而非用 SAP 吸水纸（SAPP）或 SAF 替代。见 [[SAP 吸水纸（SAPP）]]、[[Super Absorbent Fibre（超吸水纤维 SAF）]]。
5. **⚠️ 代价**：[[Gel Blocking（凝胶阻塞）]] 风险由"两层 SAP 的渗透/保水分工"承担；若上层高渗透层失效，架构优势即消失。该机制为厂商披露，**无第三方验证** `[待验证]`。

## 经验教训

- **Lesson（分工优于均混）**：本架构把"渗透"与"保水"两个互相冲突的 SAP 指标**拆到两层**，绕开了单一牌号必须妥协的问题 —— 这是**分层架构相对均匀混合芯体的结构性优势**，可外推到其它分层设计（如 [[分区密度设计]]）。
- **Lesson（无浆化的第三条路）**：无浆化不止 SAPP / SAF 两条材料路，**"高蓬松无纺布夹持"是一设备/结构路**——选型时应把设备可行性纳入，而非只对比材料。
- **待补 `[待验证]`**：SAP 牌号与渗透/保水的量化判据；两层 gsm 配比与 CRC/AUL/GBP 的响应关系；量产速度与良率；专利覆盖范围。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 「上层通液好 + 下层快吸」的反向分层思路）

> 来源：[[SAP GBP Improvement & Surface Crosslinking Process Review（GDP提升工艺探讨）]]（SAP 供应商工厂交流 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**两条分层思路的对照（本批新增）：**

| | 常规思路（行业通行） | 本方新思路 |
| --- | --- | --- |
| 上层 | **高保水（CRC 高）** | **通液好（GBP 高）** |
| 下层 | **快吸** | **快吸**（保水可差一点） |
| 是否考虑通透性 | **不考虑** | **以通透性为上层首要指标** |
| 供应商评价 | — | "**很新颖**"，若成功"还是很有创新的价值" |

**机理层面的张力（本批新增）：**

- "**通透和吸收速度本身是有一定的背离的**" —— 追求通透就要让吸收速度"让一让"。
- 只有当**液体不需要靠 SAP 自身扩散**（例如结构与无纺布搭配已解决扩散）时，上层才可以专注通液；否则液体集中在中间最潮湿的位置，**太容易饱和**。

**分层的深层价值：给了"单项冠军"的可能（本批新增）：**

> "其实分层之后，是给了你们做**单项冠军**的可能性了。你原来是因为（只有）一个（SAP），只能做全能选手，全能选手必须要均衡。现在有多层的条件了，确实可以用技术力量去**追求单一赛道的冠军**，然后再去做比这个单项都极端的情况。"

- 这与本页既有的"多层 = 分工"逻辑一致，但补充了一条**选型原则**：分层之后每层可以**极端化**，不必每层都均衡。
- 现成的例证：**610S 无法单独使用，必须放在下层与上层搭配** —— 产品序列本身已经在为分层而设计。

**待验证（本批新增）：**

- 即便做出了高 GBP 材料，若**结构与无纺布搭配不对**，做出来的数据仍不是本方想要的（"因为它集中在这里"）→ **材料必须与结构协同验证**。
- 会上提出：若一个月内材料出来，可交给对方自行打样，但需先确认**对方是否有对应结构**。

✅ **验证记录（2026-09-29）**：以上为会中技术讨论 + 供应商口径，**无实测数据**；"通透与吸收速度背离"为机理判断 [待验证]。参见 [[GBP-Limited vs CRC-Limited Regime（渗透受限 vs 容量受限机制）]]、[[诺尔（Nuoer）]]、[[SAP性能指标（CRC AUL GBP Vortex）]]。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 多 SAP 层系统的定量方案与它解决了什么）

> 来源：[[Diaper NPD Workshop Prep — Absorbency, Skin Health & Comfort Feature Map（2026-06-05）]]（Workshop 准备材料 v1.0，2026-06-05）。本批只**追加**，不修改既有结论。

**A1 多 SAP 层系统的定量方案（本批新增）：**

| Item 项目 | Value 数值 | Note 备注 |
| --- | --- | --- |
| 总 SAP 载荷 | **~15 g** | — |
| 三层分布 | **N511（快速层）+ SAP1（主体层）+ SAP2（保留层）** | 按功能分层，非同一牌号 |
| 芯体尺寸 | **385 × 110 mm** | 按 6 个月婴儿优化 |
| 目标收益 | 首次吸入速度 **+30–40%**；回渗 **<2.0 g**（竞品基准 **3.0 g**） | — |
| 代价 | SAP 用量 **+8–12%**；**分层工艺复杂度↑ → 设备改造投入** | 主要风险是设备侧 |

**它真正解决的问题（本批新增）：**

1. **绕开 CRC / AUL 的 trade-off** —— 单一牌号无法同时高 CRC 与高 AUL（**CRC↑ → AUL↓**）；分层后**快速层取"低 CRC 高 AUL"（负责吸入），主体层取"高 CRC"（负责保留）**，各司其职。
2. **回渗从基准 3.0 g 降到 <2.0 g** —— 这是可被消费者感知的量化目标，而不是"更干爽"这类模糊宣称。
3. **与超薄化的矛盾关系**：超薄（<2 mm）会推高 SAP 载荷密度 → **凝胶阻塞风险↑**；材料给出的解法正是 **多 SAP 层 + GBP 优化牌号选型** —— 即**用分层与渗透性管理来对冲薄型化的副作用**。

**由此得到的认知（本批新增）：**

- **多层化的第一动因往往不是"更好吸收"，而是"破解单一材料的指标互斥"** —— 这是判断一个多层方案是否值得做的关键：若分层不能绕开某个 trade-off，则分层只是增加复杂度。
- **代价主要落在设备而非材料**（设备改造投入 + SAP 用量 +8–12%）→ 评估多层方案时应先问**产线能否做分层投放**。

✅ **验证记录（2026-09-29）**：方案与收益来自 **Workshop 准备材料 v1.0**，其引用 `references/53` **原始文件未随本批次提供**；+30–40% 与 <2.0 g 为**目标值**而非实测 [待验证]。参见 [[SAP性能指标（CRC AUL GBP Vortex）]]、[[GBP-Limited vs CRC-Limited Regime（渗透受限 vs 容量受限机制）]]、[[REL增强层]]。

## 追加：Resources/Open Innovation 批（2026-09-29 追加 · 复合芯体的分层自由度与其四项结构性代价）

> 来源：[[Complex Core Landscape in China（2017-08-07 COCO F2F · 复合芯体格局与专利谱系）]]（**2017-08-07 时点快照**）；结构化对照见 [[传统芯体 vs 复合芯体（性能·成本·供应链）]]。

1. **分层设计自由度是复合芯体的核心 PROS** —— 源文列为「**Flexible to multi-type SAM, and layered SAM design**」与「**SAM with SAM% design**」。**⇒ 分层不只是"放两层"，而是可以**按牌号、按 SAM 比例**分别设计每一层。**
2. **典型叠构（源文 Y&Q 系列图注）** —— **Airlaid / SAM / TABCW / SAM / 硬挺非织造 / NW 芯体包覆**。**⇒ "两层 SAM 夹一层 TABCW"是 2017 年本土复合芯体的主流形态。**
3. **本土厂商的主要改法是"加层加量"** —— 为提升吸收量，**尝试多层结构以增加 SAM 添加量与吸收容量**。**⇒ 层数成为容量的直接旋钮。**
4. **四项结构性代价（必须显式接受，而非待优化）** —— ① **摄入/分布**：**空隙体积与毛细更少**；② **保留容量**：**长效吸收 RC 更低**；③ **胶**：**高施胶量影响吸收性能**；④ **成本/运输**：**芯体成本高、运输成本高**。**⇒ 多层化会同时放大 ③（每层都要胶）与 ④。**
5. **一个正在发生的收敛现象** —— 为修摄入速度，本土厂商**在新的复合芯体结构中加入高蓬松 surge 与绒毛浆**。**⇒ 复合芯体正在把传统芯体的毛细结构"往回加"，两条路线并非单向替代。**
6. **"可编程空隙"是独立于层数的第三维度** —— Honeycomb（**溶胀打开不稳定键 ⇒ 形成通道与空隙**）与 Drylock（**超声键合永久主粘合 + 临时次粘合，溶胀打开次粘合产生新空隙**）都**让 SAP 自己开路**。**⇒ 设计空间 = 层数 × SAM 牌号/比例 × 空隙可编程性。**
