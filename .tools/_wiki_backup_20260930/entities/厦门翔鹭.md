# 厦门翔鹭（厦门翔鹭化纤）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | CoPET/PET 皮芯型低熔点复合短纤维（**4080 低熔点纤维**）；自主低熔点聚酯切粒 |
| 产地 / 基地 | 福建厦门海沧（马青路 1268 号）；总投资约 4.75 亿美元 |
| 产能 | 年设计产能约 **36 万吨**；**低熔点短纤约 3 万吨/年**（满负荷日产约 72 吨） |
| 规格 | 标准线密度 1.6–16.6 dtex、皮芯、圆截面、本色；市场牌号 4080 常用 4D×51 mm |
| 行业地位 | **FZ/T 52051-2018《低熔点聚酯(LMPET)/聚酯(PET)复合短纤维》第一起草单位**；国家企业技术中心、高新技术企业；「低熔点聚酯复合短纤维研发和产业化」获 2019 中纺联科技成果优秀奖 |
| 在本库中的角色 | CoPET 供应基盘中的**国内基准锚点（domestic benchmark）**——行业标准制定者与市场价基准来源 |

## 合作与供货历史

- **2026-07-09（背调核实日）**：在两份 CoPET 供应基盘背调中被列为大陆低熔点复合聚酯纤维标杆之一。详见 [[CoPET 供应基盘背调汇总（26 家企业·联系方式版）]]、[[CoPET 供应基盘背调汇总（布局核实精简版）]]。
- **2026-07**：在 [[CoPET 采购蓝图：成本拆解与供应分层]] 的 Layer A 诊断中被标为 **「Baseline Anchor（基准锚点）」**——标准制定者、约 3 万吨产能、市场基准价；与汇维仕（高价预警）、盐城市中联/嘉兴新丰（战略目标）并列构成 A 层四家。
- **2026-07**：在 [[CoPET ADL 转型蓝图（皮层聚合物替代评估）]] 的供应层级图中列入 **Tier A（真正供应 CoPET ADL 短切纤维的 5 家之一）**。
- 应用领域（来源口径）：热粘合法非织布（绿色黏胶剂/替代液体胶）、卫生材料、过滤、填充及产业用纺织品。

## 价格与商务要点

> ⚠️ 商务敏感信息只记要点与区间，不落完整价格表。每条标注记录日期。

- **记录日期 2026-07-09**：翔鹭 4080（4D×51 mm）出货价格在 CoPET 低熔点短纤中处于**国产下沿**；同规格国产全区间约 8,900–10,550 元/吨，进口/高端档位更高。→ 详见 [[CoPET 与 PET 成本差异对比（2026 年 7 月）]]。
- **记录日期 2026-07**：相对 PET 棉型标品的纤维级价差约 **+1,250 元/吨（+16%）**，即该口径的 CoPET 溢价基准。
- **记录日期 2026-07**：价格弹性观察——本厂 4080 在约 3 个月内上涨约 7%，同期 PET 短纤涨幅约 3–5%，说明 CoPET 价格弹性更大。
