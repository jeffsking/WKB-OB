# 中国石化（Sinopec）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | 聚丙烯树脂（含纤维料）、茂金属催化剂、化纤原料 |
| 产地 / 基地 | 镇海炼化、长岭炼化、茂名、扬子、上海石化、济南炼化、广州石化、中原石化、仪征化纤等 |
| 产能 | 镇海炼化 PP 产能 >100 万吨/年；仪征化纤短纤 40 万吨/年 |
| 角色 | LMP-PP 方案 B/C 的**树脂端首选合作对象**与纤维端验证伙伴 |

## 合作与供货历史

- **2026-09-26（检索记录）**：纤维料矩阵 Y2600T（MFR 26）、Y3700C（37）、S2040（38）、YS835（33）、S700（14）等，全部为纺丝/纺粘**均聚**料（熔点 164–165°C），无低熔点纤维级树脂牌号。
- **2026 H1**：北化院 SMC-PL02 完成工业化应用，产出 mPP 牌号 MC1005/MC1009（低析出、高洁净、高透明、覆盖合成纤维）；上代 SMC-PL01 已在广州石化、中原石化、扬子石化三套装置应用。
- **2026-08**：北化院新一代茂金属催化剂在中科炼化道达尔 ADL 环管聚乙烯装置成功应用，活性 7500 kg/kgcat 与进口持平。

## 价格与商务要点

> ⚠️ 商务敏感信息只记要点与区间，不落完整价格表。

- **记录日期 2026-09-26**：低熔点纤维端产品由仪征化纤持有（110/180/230°C 系列），原料由中石化内部直供——即「低熔点」能力在**纤维端**而非树脂端。
