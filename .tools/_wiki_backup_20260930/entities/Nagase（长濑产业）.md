# Nagase（长濑产业）

> 一句话定位：**全球首个公开宣称达到海洋可降解认证标准的高生物质含量 SAP 供应方**，由 **Nagase ChemteX（制造）** 与 **Nagase Viita（原林原商事，2024 年更名）** 承载；目标 **FY2026 上市**，**首先瞄准卫生巾与轻失禁，而非纸尿裤**。

## 基本盘

| 项目 | 内容 |
|---|---|
| 主体 | 日本长濑产业株式会社（Nagase & Co., Ltd.）旗下 **Nagase ChemteX**（制造）+ **Nagase Viita**（原林原商事，2024 年更名） |
| 技术路线 | **淀粉基（starch-based）高生物质含量 SAP**，经改性获得海洋可降解性 |
| 关键性能 | **180 天海洋降解率 ≥90%**（第三方 ASTM D6691 测试通过）；**生物质比例未公开** |
| 认证状态 | **ASTM D6691 通过**（2024-04 宣布） |
| 目标上市 | **FY2026**（2026 财年内） |
| 目标应用 | **卫生巾、轻失禁产品**；初期**不针对纸尿裤**（因后者对 SAP 性能要求更高） |
| TRL（源文自评） | **TRL 6–7**（量产技术建立中） |
| 角色 | 候选（行业对标与取样对象，非库内在用供应方） |

## 关键事实（均注日期）

- **2023-02**：首次宣布开发成功高生物质含量 SAP。
- **2024-04**：**新等级通过第三方 ASTM D6691 测试**，确认达到海洋可降解认证要求的降解率（源文引用 Nagase 官方发布，2024-04-18）。
- **FY2026（目标）**：产品上市；**首个目标市场为卫生巾**。
- **2026-05-21（调研引用）**：被列为海水可降解 SAP 领域 **Tier 1（已获海洋降解认证 / 即将上市）** 中**唯一实现 ASTM D6691 通过**的供应商；源文评价其"标志着行业从实验室走向商业化的关键一步"。

> ⚠️ **口径声明（2026-09-29）**：以上为**企业公开宣称 + AI 汇编调研引用**，**非本库实测、非本库验证过的供货能力**。生物质比例未公开；"FY2026 上市"为**目标**而非既成事实。

## 为什么重要（对本库的判断价值）

1. **它定义了"海洋可降解 SAP"的认证门槛参照**：180 天 ≥90% CO₂ 转化（ASTM D6691 / ISO 16204）。
2. **它给出了切入顺序的答案**：**单片 SAP 用量最小的品类先落地**（卫生巾），因为可降解 SAP 的成本是传统 SAP 的 **1.5–4 倍**，成本放大与用量成正比。
3. **它划出了纸尿裤的门槛**：源文明确"初期不针对纸尿裤，因后者对 SAP 性能要求更高"——与库内 [[Seawater-Degradable 3D Hydrogel System（海水可降解三维水凝胶体系）]] 记录的"性能差距 20–50%"互为呼应。
