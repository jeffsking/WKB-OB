# IPC BCC（K-C Baby & Child Care 材料开发团队）

## 基本盘 Basic profile

| 项目 | 内容 |
|---|---|
| 全称 | IPC BCC（Infant/Pregnancy Care · Baby & Child Care，金佰利体系内的婴儿护理业务单元代号；本批来源未展开拼写口径） |
| 团队 | OI Materials Development Team（材料开发团队），负责开放创新（OI）材料与技术寻源 |
| 上级 | [[Kimberly-Clark（金佰利）]] |
| 角色 | 本库全部 OI 材料的**组织主体**：项目清单、年度汇报大纲、供应商台账、法务文件均以该团队名义运作 |
| 相关单元 | AFC（联合方向，见电气石项目）；IPC 市场部（2026-09-03 确定三大新创新领域）；FBI 团队（Future Baby Innovation，聚焦 2029+） |

## 职能与产出 Deliverables

- **项目组合管理**：五大技术平台 × 二十余个 OI 项目，交付物含技术路线、KPI/验收判据、供应商基盘、法务文件（NDA/NNN/JDA/MOU）与 IP 归属。
- **年度汇报**：2026 年度汇报大纲 v7（2026-09-17，32 页 + 2 附录），参照 FEI update (IA2.0)-20260622 版式与配色。
- **知识资产管理**：以 IMA 知识库（"WKB"）为一等依据来源，2026 年汇报首次引入**外部 TRL 标尺**与**六条路线级方向**。
- **合规与法务**：材料安全管控 Class 1 / Class 2 双轨、COC 化学品清单、RA 审核前置。

- **2026-06-09**：与外部专家 Mr. Fike 就非织造芯体（REL）材料选型做白板头脑风暴（[[非织造芯体材料技术讨论会（Bryan 优先清单 2026-06-09）]]）。
- **2026-07-24**：COCO V6 芯体花型（channel）设计评审会，收敛出四条设计规则（[[芯体花型设计评审会（录音纪要 20260724）]]）。
- **2026-09-03**：IPC 市场部确定三个新创新领域——温度调节、微生态、气味控制。
- **2026-09-17**：发布官方 OI 英文清单、供应商明细台账与年度汇报大纲 v7。
- **2026-09-18**：OI 组合重构，25 项去重为 19 项并重新编号；同年 09-18 中文汇报稿按五方向组织。
