# 联欣环保科技（泰兴）

> 全称：联欣环保科技(泰兴)有限公司 / Lianxin Environmental Protection Technology (Taixing) Co., Ltd.（本批资料中简称 Lianxin Bio）。淄博基地方在资料中出现为「山东…绿色科技」，与泰兴方是否同一法人主体未在本批资料中说明，标 `[待验证]`。

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | **PPC-P**（CO₂ + PO + 苯酐三元共聚可降解树脂）及其中间体苯酐（PA） |
| 产地 / 基地 | 江苏泰兴（泰兴基地）；山东淄博（第二个基地） |
| 产能（刚性投资） | **65,000 吨/年** = 泰兴 25,000 吨（2025-10 投产）+ 淄博 40,000 吨（2027 年中投产） |
| 产能（规划） | 淄博另 200,000 吨，视 2030 年市场情况做可研；淄博厂房已按 **250,000 吨** 产能设计建成 |
| 设备 | 泰兴：30 吨/日聚合釜 ×5（预留 PPC-P 生产）+ 5 吨/日聚合釜 ×1（工程改性料）；淄博：500 kg 试验釜 |
| 人员 | 约 165 人（含技术人员 60 人），2025-09 底口径 |
| 技术壁垒 | 工艺与设备**专利自有**；共聚用**非金属催化剂为自有专利并自产** |
| 一体化程度 | 自产苯酐（泰兴收购 15 年历史苯酐装置）；PO 外购但供应商在厂区对街、**管道直供**；CO₂ 外购（槽车） |
| 在本库中的定位 | **可家庭堆肥无纺布路线的 PPC-P 候选供应商**（见 [[可家庭堆肥无纺布（Home Compostable Nonwoven）]]） |

## 合作与供货历史

- **2025-09-25**：泰兴与淄博基地现场拜访（见 [[LXBIO 拜访报告（2025-09-25 泰兴 PPC-P 基地）]]）。记录泰兴 2.5 万吨线计划 2025-10-20 投产、淄博 4 万吨线计划 2027 年中投产；确认单体配比 CO₂ 35~40% / PO 40~55% / 苯酐 10~20%，及引入苯酐使 Tg 由约 30 ℃ 升至 55 ℃ 以上。
- **2025-09-25**：拜访中明确改性是应用前提，主研方向为 PPC-P 与 **PBAT** 共混（≤35% PPC-P 得纤维级 PPCT 树脂；80~90% PBAT + 10~20% PPC-P 做农膜）；PLA + PPC-P 共聚做纤维级 PPCL 在研；PPC-P/PHA 共混或共聚在实验室阶段。
- **2025-09-25**：认证状态记录为 **TÜV 可降解认证**、**DIN CERTCO 注册（工业堆肥）**，**FDA 认证在办**；家庭堆肥与海洋可降解在后续方案页中列为「过程中」。
- **（第二版开发方案，日期未标注）**：联欣表达**开发 PPC-P/PBAT 共聚纺粘树脂**的意愿，并希望在合作初期**由客户方先给出聚合物必备项清单（must list）**；同期记录 30% PPC-P + 70% PBAT 长丝喷丝可纺性良好。见 [[PPC&PGA 基无纺布开发方案（第二版）]]。
- **薄膜端联动**：透气膜（加 CaCO₃）树脂研发在进行，薄膜方为**佛山允迪薄膜材料有限公司**（本批资料记为 Windeed film 的合作方）。

## 追加：线纺专用料 TDS 批（2026-09-29 追加 · Supply Base 批次）

> 来源：[[联欣 LXBIO T55P25T20 线纺专用料 TDS（PPC-P-PBAT 可降解）]]。本节为**追加记录，不改动上方既有结论**。

- **新牌号 T55P25T20（线纺专用，v1.0 TDS）**：改性 **PPC-P + PBAT** 基生物降解材料，通过 **EN 13432 与 ASTM D6400** 认证；典型值：密度 1.32 g/cm³、MFI 20.1（170 ℃）/40.5 g/10 min（190 ℃）、拉伸 10.6 MPa / 断裂伸长 162%、弯曲模量 176 MPa、**维卡软化点 60.2 ℃（10N）**；挤出窗口 **160–190 ℃**（温度敏感）、出厂已除湿开袋即用（暴露后 60 ℃×8 h 回干）、保质期 1 年。
- **意义**：将本方 PPC-P 平台从无纺布方向延伸到**线纺（纺纱成线）**方向，且拿到堆肥认证背书——与 [[PPC-P 基与 PGA 基可堆肥纤维路线对比]] 中的 PPC-P 路线进展互为印证。
- **工艺提示**：60 ℃ 级维卡点意味着下游热粘合/烘箱温度须按可降解基材重标定（对照常规 PP ~150 ℃）。
