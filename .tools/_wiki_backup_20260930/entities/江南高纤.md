# 江南高纤（江苏江南高纤股份有限公司）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | **皮芯型复合短纤维（ES 纤维）** + 低熔点复合聚酯纤维（**"4080 纤维"，涤/涤皮芯：皮层低熔点 PET/CoPET、芯层高熔点 PET**）；涤纶毛条 |
| 产地 / 基地 | 江苏苏州相城黄埭镇（苏阳路 7 号） |
| 产能 | 复合短纤维约 **23 万吨/年**、涤纶毛条约 **4.2 万吨/年**；2017 年募投新建 **4 万吨**高性能复合短纤维（ES） |
| 技术资产 | 多孔结构低熔点复合聚酯纤维专利 **CN114775106B**（0.1–1.0 μm 微孔）；并列型低熔点短纤专利 |
| 资质与地位 | A 股 600527；**国内最大涤纶毛条和复合短纤维生产企业**；国家火炬重点高新技术企业、国家级企业技术中心 |
| 在本库中的角色 | 同时占据两个位置——**D 层 ES（PE/PET）龙头（CoPET 的替代对象）** 与 **真 CoPET（4080）供应方** |

> ⚠️ **口径要点（原文明确）**：传统 ES 多为 PE/PP 或 PE/PET **聚烯烃皮**；只有 **4080 才是真正 CoPET（低熔点 PET 皮）双组分**。本厂两者都做，对标时必须写明皮层树脂体系。
