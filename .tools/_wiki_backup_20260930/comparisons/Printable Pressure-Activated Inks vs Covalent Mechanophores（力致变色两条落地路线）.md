# Printable Pressure-Activated Inks vs Covalent Mechanophores（力致变色两条落地路线）

> 对比对象：Pathway A「可印刷压力激活油墨」vs Pathway B「共价力色团」——力致变色材料进入卫材产品的两条产业化路径。回答「先做哪条、各自的成本与供应链代价是什么」。
> 数字全部溯源至源摘要页；源文未给数字之处标 `[待验证]`，不以外推填充。

## 对比维度表

> 必含「成本」与「供应链风险」两列。

| 维度 | Pathway A · 可印刷压力激活油墨 | Pathway B · 共价力色团 | 依据 |
|---|---|---|---|
| **技术定义** | 压力激活油墨印刷于基材上（示意：impression roller / flexo plate / wet ink flow / substrate / backup roller） | 分子（如 naphthopyrans）经**化学键合**直接接在聚合物主链上（covalent bond scission 触发变色） | [[Active Hygiene Roadmap（力致变色材料商业化路线图）]] |
| **性能（变色机制）** | 压力激活油墨体系（reversible / irreversible 取决于配方） | **covalent bond scission** → modular colour change | 同上 |
| **性能（是否「自评估材料」）** | 否——油墨是附加层 | **是**：原文称其为 superior "**self-assessing**" material | 同上 |
| **性能（成熟度与整合难度）** | **高**：highly scalable via standard offset/flexo production lines；整合难度低 | **低-中**：complex integration，须改变化学骨架与纺丝/成网条件 | 同上 |
| **性能（可逆性适配）** | 视配方；作为「事件记录/瞬态信号」更自然（naphthopyrans 属 modular / transient） | 与 naphthopyrans 等模块化信号绑定；HPC 类结构色才提供可逆的幂律关系 | 同上、[[Mechanochromic变色纤维]] |
| **性能（力值缺口适配）** | 不改变力色团本身的激活力值——同样受 40,000 PSI → 20–150 kPa 缺口约束，须靠 "stabilization bridge"（胶凝剂）下移 | 同左（缺口是材料共性问题，不是路径差异） | 同上、[[Active Diagnostic Zones（主动诊断分区）]] |
| **成本** | **相对低/快**：沿用既有 offset/flexo 产线，无需新建材料产能；原文明确「fastest route to market」 | **相对高/慢**：需自建化学生产与键合工艺；但形成**永久 IP 护城河**（一次性投入换长期独占） | 同上 |
| **成本（原文口径）** | 原文只给方向性判断：「pathway selection dictates final **COGS and velocity**」——**两条路径均无数字** `[待验证]` | 同左 `[待验证]` | 同上（成本指数与 TRL 数字见 [[Mechanochromic Routes Comparison（力致变色技术路线对比）]]） |
| **供应链风险（监管）** | **低**：使用 **food-contact grade inks** 作为 **immediate regulatory shield** | **中-高**：新型化学键合材料无既有食品接触/药典路径可借，须自证 | 同上 |
| **供应链风险（外部依赖）** | 依赖**外部油墨供应方**（食品接触级油墨的产能与配方）；库内已立页的对应供应方为 [[CTI (Chromatic Technologies)]] | **低**：键合分子自持，材料即 IP——但换来的是研发与放大风险 | 同上 |
| **供应链风险（放大/产线）** | **低**：现有印刷工序即可上量；改产线压力小 | **高**：须与无纺布/纺丝工艺耦合（分子接在聚合物主链上），牵动材料端整套工艺 | 同上 |
| **供应链风险（知识产权/FTO）** | **低-中**：印刷变色属成熟领域，须查既有专利（库内记录 K-C US7704589B2 拉伸变色**已失效**，该方向存在空间） | **低（自持）**：原文称形成 "permanent IP moat"——即风险从 FTO 转为**被绕过/被挑战**的风险 | 同上、[[Mechanochromic变色纤维]] |
| **供应链风险（放行优先级）** | 两者**都从属于监管放行**：原文 strategic directive —— pathway selection「remains entirely subordinate to regulatory gatekeeper clearance」 | 同左 | 同上 |
| **适用场景** | **先上市 / 快速去风险**：用最小监管成本验证消费者与场景（Zone 1 腰围防勒伤、Zone 3 压力分布），抢时间窗 | **建护城河 / 长期独占**：把「材料即传感器」做成竞品无法绕过的结构，适合作为第二代平台 | 同上、[[Active Diagnostic Zones（主动诊断分区）]] |

## 各自适用场景

- **Pathway A · 可印刷压力激活油墨**：**为了速度与低监管成本**。沿用 offset/flexo 产线、借食品接触级油墨作监管护盾，是「最快上市」的路径；适合用作第一个可卖的诊断功能（Zone 1 腰围防勒伤、Zone 3 压力分布）。
- **Pathway B · 共价力色团**：**为了护城河**。把力色团键合到聚合物主链上，得到「自评估材料」与长期 IP 独占；代价是整合复杂、需要自证合规、且必须与无纺布/纺丝工艺耦合。

## 结论

一句话：**先走油墨（借食品接触级油墨的监管护盾换取上市速度），再用共价力色团筑墙（把材料变成无法绕过的 IP）——两条路径不是替代关系，而是同一路线的第一代与第二代；而两者都排在监管放行之后，且原文明确指出路径选择直接决定最终 COGS 与速度。**
