## 各自适用场景

- **[[SAP性能指标（CRC AUL GBP Vortex）]] 中的 KC 511**：作为**基准料**存在，用于给其余牌号定标；其 GBP 跨源口径不稳，引用时须注明来源。
- **NR-610S**：Vortex 最快（19 s）、GBP 最低（6）——**顶层速度优先**场景，但渗透性差，需与高 GBP 料搭配。
- **NR-950**：CRC 与 AUL@0.7psi 双双最高、Vortex 最慢——**储库**角色，负责把容量留在底层慢慢吸。
- **Code X（High GBP）**：GBP 期望值最高（准备会 55.3）——**顶层高渗透**角色；但目前**样品量、数据完整度、口径一致性三项均有短板**，属"性能亮眼、可采购性未成立"的典型。

## 结论

四支 SAP **没有一支全指标领先**：**NR-950 是容量储库、NR-610S 是速度顶层（但低 GBP）、Code X 是高 GBP 顶层候选（但供应与口径风险最高）、KC 511 是定标用的基准**。真正的选型问题不是"哪支最好"，而是**"Code X 能否从 20 kg 试产样走到可量产，并把 GBP 口径统一后再拿来和 KC 511 比"**——在此问题解答前，任何"Code X 优于基准"的结论都不成立。
