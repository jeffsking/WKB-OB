# 国产 mPP 与进口 mPP 对比（纤维级低熔点空档）

> 对比对象：国产与进口茂金属聚丙烯在**纤维级低熔点**需求上的可得性与成熟度。回答「LMP-PP 项目能否用国产催化剂与树脂落地」。
> 数字全部溯源至源摘要页；无来源项标 `[待验证]`。

## 主对比表

| 维度 | 国产 mPP | 进口 mPP |
|---|---|---|
| **代表体系/牌号** | 中石化北化院 SMC-PL 系列（MC1005、MC1009）；中石油（中试） | TotalEnergies Lumicene MR 2002（Tm 151°C / MFR 15 / 抗气体褪色） |
| **催化剂成熟度** | 已进入**多装置复制推广**（SMC-PL01 用于广州石化/中原石化/扬子石化）；中石油中试装置 60 吨/年、收率 94.88% | 成熟商业化 |
| **牌号定位** | 通用高端料（包装/薄膜/纤维），**低析出、高洁净、高透明** | **纺粘卫材无纺布专用** |
| **低熔点纤维级覆盖** | ❌ **无公开的「熔点 135–150°C + 纤维级 MFR」牌号** | ✅ MR 2002 直接可用（Tm 151°C，接近但非 135–150°C） |
| **MFR 达成方式** | 中石油氢调敏感性 +70%，可走「聚合直接达标」路线 | 商业化配方（含降解补课路径） |
| **成本** | 未入库；国产化通常具备成本优势 `[待验证]` | 未入库；进口含关税/物流/汇率成本 |
| **供应链风险** | **低**（本土装置、政策支持、国产替代导向）；但需自研低熔点牌号，存在开发周期风险 | **中-高**（进口依赖、交期与汇率波动、地缘与贸易政策风险） |
| **行动建议** | 申请 MC1005/MC1009 样品做纺丝评价；把广州石化列为方案 B 首选树脂厂 | 以 MR 2002 为参数标尺（MFR 15 / Tm 151°C），不必依赖其供货 |

## 关键差异解读

1. **「催化剂不可得」已不是障碍**——国产两条体系（中石化工业化 + 中石油中试放量）使方案 B 从「理论可行」变为「有国内供应商可谈」。
2. **空档在牌号，不在催化剂**——国产 mPP 已能产出低析出高洁净料，但**没有瞄准低熔点纤维级**；这既是缺口也是本项目的价值所在。
3. **进口 mPP 的价值是「参数标尺」而非「供应来源」**——Lumicene MR 2002 给出了卫材纺粘级低熔点 PP 的现成目标（Tm 151°C / MFR 15），国产自研可直接对标。
4. **氢调敏感性是国产路线的差异化优势**——若走「聚合直接达标 MFR」，可减少过氧化物降解带来的强度损失。

## 结论

- **短期**：以进口 MR 2002 为参数标尺制定自研靶值（MFR 20–40 + 熔点 135–150°C + 乙烯 3–8%）。
- **中期**：用国产 mPP 催化剂 + 中石化/中石油装置载体试产，验证「聚合直达目标 MFR」路线。
- **长期**：把低熔点纤维级牌号做成国产差异化产品，填上现有空档。
