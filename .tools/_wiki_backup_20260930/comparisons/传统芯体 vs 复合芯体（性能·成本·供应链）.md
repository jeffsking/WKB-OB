# 传统芯体 vs 复合芯体（性能·成本·供应链）

## 对比维度表

> 必含「成本」与「供应链风险」两列。

| 维度 | **传统芯体（Traditional core）** | **复合芯体（Complex core）** | 依据 |
|---|---|---|---|
| **PROS 1** | ✓ **毛细结构** —— 液体快速吸收与摄入 | ✓ **完整性** —— 卓越的垫体完整性 | [[Complex Core Landscape in China（2017-08-07 COCO F2F · 复合芯体格局与专利谱系）]] |
| **PROS 2** | ✓ **SAM / 绒毛浆均匀混合** —— 机速快 | ✓ **加工** —— 用便宜设备即可轻松加工 | 同上 |
| **PROS 3** | ✓ **柔软** —— SAM 颗粒混在绒毛浆中 | ✓ **薄且贴合** —— 明显更薄的垫体 | 同上 |
| **PROS 4** | ✓ **SAM 选型灵活** —— 对不同渗透性适应性强 | ✓ **无浆** —— 供应链中无浆板 / 绒毛浆约束 | 同上 |
| **PROS 5** | — | ✓ **SAM 灵活性** —— 可多牌号 SAM 与分层 SAM 设计（含 SAM% 设计） | 同上 |
| **CONS 1** | □ **完整性** —— 高速成形下垫体完整性差 | □ **摄入 / 分布** —— 空隙体积与毛细更少 | 同上 |
| **CONS 2** | □ **厚度** —— 更厚 | □ **保留容量** —— 长效吸收的 RC 更低 | 同上 |
| **CONS 3** | □ **贴合** —— 厚度可能带来贴合问题 | □ **胶** —— 高施胶量影响吸收性能 | 同上 |
| **CONS 4** | □ **加工** —— 浆板纤维化能耗高 | □ **成本 / 运输** —— 芯体成本高、运输成本高 | 同上 |
| **成本** | **Total 100%（基准）**；但为解摄入与分布，需在 **3D 面层、蓬松 surge、高渗透性 SAM** 上叠加成本（Liner $ / Surge $ / Core $ / Out cover $） | **Total 120%+（更贵）**；成本**从面层与导流层迁移到芯体本身与芯体包覆**（Liner $$$ / Surge $$$ / **Absorbent core $$ / Core wrap $**） | 同上（**定性相对关系**，源文无绝对值与币种） |
| **供应链风险** | **① 绒毛浆 / 浆板约束** —— 依赖浆板供应与纤维化产能；**② 能耗风险** —— 纤维化能耗高；**③ 但工序在厂内 ⇒ know-how 与过程控制留在品牌商** | **① 工序外移** —— 芯体成形由 **OEM 芯体供应商**承担（带胶 SAM 添加、Airlaid/TABCW 复卷），品牌商只剩层压 ⇒ **know-how 与控制力外移**；**② 运输风险** —— 芯体体积/运输成本成为新成本项；**③ 胶依赖** —— 高施胶量使**胶的供应与性能**成为吸收性能的直接风险源；**④ 但解除绒毛浆约束** | 同上（风险列为**本页依据源文事实的推断 `[I]`**） |
| **适用场景** | **摄入速度 / 分布 / 柔软优先**；**长效吸收（高 RC）**场景；**希望保留芯体成形 know-how** 的自产体系 | **薄 / 贴合 / 完整性 / 易加工优先**；**无浆供应链**诉求；**多牌号分层 SAM** 的高设计自由度场景 | 同上 |

## 结构对照：四条已知技术路线（供选型参照）

| 芯体 | 归属 | 固定 / 空隙机理 | 配套 | 专利 |
|---|---|---|---|---|
| **DryMax** | **P&G** | 印刷辊沉积 + **热塑性胶纤维网在干湿两态固定 SAP** | 化学粘合 ADL + 卷曲纤维素纤维 | US 8206533 B2 / EP 2273959 B1 等 |
| **Honeycomb（Hexacore）** | **Fameccanica** | 两片层压；**溶胀打开不稳定键（labile bonds）⇒ 形成通道与空隙** | 高定量热风粘合 ADL | EP 1974705 B1 |
| **Drylock** | **Drylock Technologies** | 超声键合**永久主粘合 + 临时次粘合**；**溶胀打开次粘合 ⇒ 新空隙** | 140–150 gsm 热风粘合 ADL | WO 2012052172A1 / 2173A1 |
| **Bostik** | **Bostik / BASF** | 口袋阵列 + 珠状胶；**胶非水溶性** | — | 源文标为申请，**无编号** |

> **共同机理**：后两者（Honeycomb / Drylock）都是**"让 SAP 溶胀自己开路"**——**用溶胀产生可编程的空隙与通道**，而非静态多孔结构。**这是一个独立的设计维度，与"芯体是否含浆"正交。**

---

## 各自适用场景

- **传统芯体**：**摄入速度、分布、柔软与长效吸收容量**优先的场景，以及**希望把芯体成形 know-how 保留在厂内**的自产体系。**代价**：厚度、高速成形下的完整性、纤维化能耗。
- **复合芯体**：**薄 / 贴合 / 完整性 / 易加工（便宜设备）**优先的场景，以及**想摆脱绒毛浆供应链约束**、需要**多牌号 + 分层 SAM 设计自由度**的产品线。**代价**：摄入与分布的毛细不足、长效 RC 偏低、施胶量高、芯体与运输成本更高、know-how 外移到 OEM。

---

## 结论

**一句话结论**：**复合芯体不是"更好的芯体"，而是"把优势与代价整体搬家"——它把成本从面层/导流层搬到芯体本身（Total 100% → 120%+）、把 know-how 从品牌厂搬到 OEM、把风险从绒毛浆搬到胶与运输；换来的是更薄、更完整、更易加工与无浆约束。** 因此选型判据不是"哪个更先进"，而是**"这四项代价中，哪些是本产品线付得起的"**。
