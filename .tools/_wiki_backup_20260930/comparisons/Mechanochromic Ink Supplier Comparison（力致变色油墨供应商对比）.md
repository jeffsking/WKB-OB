## 各自适用场景 Where Each Fits

- **可印刷压敏油墨入口段（CTI 为主、Sun Chemical / LCR Hallcrest 为替代）**：**近期落地的最短路径**——在既有腰围层上做低张力阈值兼容性原型，以食品接触级油墨作法规盾牌。局限：需定制下调阈值（两个数量级）。
- **国产第二来源（Jiayida / Xingcheng）**：**成本杠杆与进口替代**，用于避开单一供应商锁定；门径是 TDS/SDS + 阈值核验。Xingcheng 的粉体形态与热熔胶体系不直接对应，适合作原料级备选而非成品供给。
- **国际平台伙伴（Merck / Avient）**：适合**联合开发与平台授权**，不适合当作量产卫品供货。
- **计量工具（Fujifilm Prescale / Sensor Products）**：**只作实验室量测**，不可作消费指示材料——这正是本批点名的「用工业计量材料当消费指示材料」三重错配陷阱。
- **研究伙伴（Chungnam / Hanyang）**：**知识产权与中期能力建设**，纳入 Track A，12–24 个月窗口，不阻塞量产轨。

（中文：可印刷压敏油墨入口段是最短落地路径，但须定制下调阈值两个数量级；国产两家作成本杠杆与进口替代，Xingcheng 粉体形态与热熔体系不直接对应；国际平台伙伴适合联合开发而非量产供货；计量工具只作实验室量测，不可作消费指示材料；大学为知识产权与中期能力建设，纳入 Track A。）

## 结论 Conclusion

**在卫生用品场景下，供应策略的关键不是「哪家便宜」，而是「哪家能把阈值降到 20–150 kPa 且能通过婴儿皮肤接触合规」。** 本批给出的答案是：可印刷压敏油墨（CTI 主供）是**近期唯一可落地**的供货类别，食品接触级油墨充当法规盾牌；国内两家（Jiayida / Xingcheng）承担**成本与供应安全**，但必须先完成 TDS/SDS 与阈值核验；四家国际龙头与两家大学分别属于**平台与 IP** 层面，不是量产供给。原文明言：市场顺风 ≠ 技术可得——**头部 IP 在美欧，而无人把守的入口只有可印刷压敏油墨这一段**。同时须警惕本批点名的陷阱：**把不可逆、超高阈值的工业计量材料当消费指示材料用**。

（中文：供应策略的关键不是哪家便宜，而是哪家能把阈值降到卫品窗口且能过婴儿皮肤接触合规。可印刷压敏油墨是近期唯一可落地类别；国产两家承担成本与供应安全但须先核验 TDS/SDS 与阈值；国际龙头与大学属平台与 IP 层面；须警惕「工业计量材料当消费指示材料」的三重错配陷阱。）
