# SAM Supplier Landscape Comparison（SAM 供应商格局对比）

> 一句话对比：九家 SAM 供应商的差异**不在"谁的 CRC 更高"，而在**——**谁在成本侧有空间、谁在供应侧有硬风险**。（中文：性能表可以横向抄，供应风险只能逐家记。）

## 各自适用场景（一句话）

- **[[LG Chem（LG 化学）]]**：全球覆盖最广的均衡型主力，代价是**反倾销税**这一结构性成本项。
- **[[Evonik（赢创）]]**：品质与创新领先（CIRRUS Consortium），但**成本是短板**且**所有权正在变动**。
- **[[巴斯夫欧洲公司（BASF SE）]]**：供应稳定 + 丙烯酸垂直一体化，风险点在生产侧的 **SAM 资产结垢**。
- **[[诺尔（Nuoer）]]**：成本与产能扩张的最强组合，但**换入现有 SAM/浆芯体有渗漏/回渗风险**，美国尚待认证。
- **[[Satellite Chemical（卫星化学）]]**：成本导向，需同时防渗漏并改善 **OTIF**。
- **[[Formosa Plastics（台塑）]]**：成本与可持续选项兼具，但**需重新配方**且 **OTIF 明确不可靠**。
- **[[宜兴丹森科技有限公司]]**：成本导向，代价是**提高添加量**或**渗漏/回渗风险**。
- **[[Sumitomo Seika（住友精化）]]**：品质导向的高容量路线，**成本是短板**且需提高添加量。
- **[[Nippon Shokubai（日本触媒）]]**：技术能力强，但**作为宝洁主供**使其成为 K-C 来源时"具挑战性"。

## 结论

> **性能可以横向抄表，供应风险只能逐家记。** 本表九家中，**只有 LG / Evonik / BASF 三家被标为 "Current Grade"（在用品种，可直接沿用）**；其余六家在替换时都带有**渗漏/回渗风险、需提高添加量或需重新配方**的注记——说明 **SAM 牌号替换不是 drop-in**，成本优势必须以**验证成本**折价。
