# 离型纸 vs 离型原纸（GB-T 27731-2011 vs GB-T 28207-2011）

## 对比维度表 Comparison table

| 维度 Dimension | [[GB-T 27731-2011 Release Paper for Sanitary Products（卫生用品用离型纸）]] | [[GB-T 28207-2011 Release Base Paper（离型原纸）]] | 依据 Source |
|---|---|---|---|
| 定位 Position | **涂布后的成品离型纸**（硅油面可直接用于卫品/包装） | **待淋膜的原纸**（27731 的上游基材） | 两标准第 1 章范围 |
| 定量 Basis weight | 29.0–44.0 g/m²（偏差 ±2.0） | 40–110 g/m² 系列（偏差 ±2.0→±5.0，更宽幅面） | 两标准表 1 |
| 核心指标 Core KPI | **剥离力 0.05–0.20 N/25 mm + 残余粘着率 ≥80.0%**（附录 A/B） | **抗张指数 ≥34.0 N·m²/g + 横幅均匀性（定量差 ≤3.0–4.0 g/m²、厚度差 ≤6%）** | 两标准表 1 |
| 表面要求 Surface | 硅油面涂布均匀连续、无孔隙划痕、无异味 | 平滑度 ≥20 s（两面差 ≤35%）、亮度 ≥90.0%、Cobb 30±10 g/m² | 两标准表 1 |
| 微生物 Microbial | 按 GB 15979，**单独否决权** | 无微生物条款（原纸非最终卫品接触层） | 27731 §4.8；28207 无 |
| 成本 Cost | 涂布工序叠加 → 单价高于原纸；剥离/残余粘着两项检测（标准胶带、拉力机、70 ℃×20 h 老化）为验收成本 | 纸厂直接供货、单价低；检测为常规纸物理指标（常规造纸实验室即可覆盖） | 两标准试验方法章节 |
| 供应链风险 Supply-chain risk | 涂布环节供应商少、切换成本高；硅油迁移/老化失效是到货后才发现的风险（需附录 B 老化试验兜底） | 原纸供应商多（太阳纸业等大型纸厂参与起草）、替代性强；**CD 均匀性差会向上传导成涂布不合格**，验收需锁定横幅定量差/两面差指标 | 两标准表 1 + 起草单位口径 |
| 适用场景 Applicability | 卫生巾/纸尿裤离型衬纸、防粘包装的到货验收 | 向纸厂采购原纸、评估涂布厂来料根因 | — |

> 尾注：本表所有限值均来自 [[GB-T 27731-2011 Release Paper for Sanitary Products（卫生用品用离型纸）]] 与 [[GB-T 28207-2011 Release Base Paper（离型原纸）]] 两份源摘要页；27731 表 1 部分不等号方向 OCR 退化处已标 `[待验证]`，本表未引用该项数值。

## 各自适用场景

- **[[GB-T 27731-2011 Release Paper for Sanitary Products（卫生用品用离型纸）]]**：成品级验收（剥离手感、高温贮存后防粘、微生物）。
- **[[GB-T 28207-2011 Release Base Paper（离型原纸）]]**：基材级采购与涂布不良根因分析（横幅均匀性、平滑度两面差、Cobb）。

## 结论 Conclusion

同一供应链的上下两环：**27731 验收「涂了之后好不好用」，28207 约束「没涂之前纸够不够格」**——剥离力不合格先回溯原纸横幅均匀性与平滑度两面差，再查涂布工艺。
