# 福建闽瑞 vs 厦门延江 产品定位对比

### 生产工艺


1. 热风无纺布


原料：ES纤维（向闽瑞等采购）


工艺：开松→梳理→热风穿透定型


特点：蓬松柔软、保暖性好


2. 3D打孔无纺布（核心产品）


原料：ES纤维


工艺：热风无纺布生产→机械打孔→3D成型


特点：3D锥形孔型、快速渗透、柔软亲肤


应用：高端纸尿裤/卫生巾面层


3. PE打孔膜


工艺：挤出流延→真空打孔


特点：防水透气、成本较低


### 产能规模（2025年）


热风无纺布：6-6.5万吨/年（国内4.5万吨，海外1.5-2万吨）


PE打孔膜：1.5-2万吨/年


### 主要客户


宝洁（P&G）


金佰利（Kimberly-Clark）


恒安集团


国内外主流卫生巾/纸尿裤品牌


## 三、两家公司的关系


### 供应关系


闽瑞是延江的ES纤维供应商之一


延江采购闽瑞的ES纤维，生产热风无纺布


闽瑞的下游客户包括延江、福建维盛、南六企业等热风无纺布制造商

# 福建闽瑞 vs 厦门延江 产品定位对比


## 一、福建闽瑞新合纤股份有限公司（新三板：834720）


### 公司定位


国家级专精特新"小巨人"企业


专业从事ES纤维（低熔点双组分复合纤维）的研发、生产和销售


上游原料供应商


### 核心产品


|产品类型|规格|主要应用|
|---|---|---|

|ES纤维（皮芯结构）|2.0D、1.2D、0.8D、1.0D以下超细旦|热风无纺布生产原料|

|功能型ES纤维|拒水型、亲水型、抑菌型|高端卫材|


## 总结


|公司|定位|核心产品|产业链角色|
|---|---|---|---|

|福建闽瑞|提供ES纤维原料|双组分复合纤维|热风无纺布的"面粉"|

|厦门延江|用ES纤维生产无纺布|热风/打孔无纺布、PE膜|面包"|


两家公司在产业链上下游形成紧密合作关系，共同服务于宝洁、金佰利、恒安等国际国内卫生用品巨头。
