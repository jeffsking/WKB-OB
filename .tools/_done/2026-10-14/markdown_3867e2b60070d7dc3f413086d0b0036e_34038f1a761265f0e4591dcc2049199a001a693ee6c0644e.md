# Biocare 技术平台 · 全链路候选供应商清单与甄选信息需求 v2（sourcing 版）

## Summary 摘要

v2 is the **sourcing version** of the Biocare supplier landscape, built for actual询源. Baseline input: the 2026-10-13 meeting minutes《益生菌/益生元项目——复配体系与丝网印刷工艺讨论》. Knowledge sources: ① the IMA minutes; ② Obsidian WKB (WIKI 2,246 pages + RAW_FULL mirror); ③ **15 groups of live web searches (2026-10-13)**. Evidence grading `[F]`/`[I]`/`[A]`/`[E]`; supplier levels E1 (official spec page / authoritative third party listing as a producer) / E2 (industry directory, corporate site, B2B certified store) / E3 (minutes or single relay only) / E4 (keyword co-occurrence only — not admitted).（中文对照：v2 为面向实际询源的 sourcing 版本，核心贡献是外部实盘候选池、物料真身澄清与 RFI 字段模板。）

v2's four deltas vs v1: (1) added 15 web searches to build real external candidate pools per stage; (2) added the **material-identity clarification** for Echinacea and citrus (previously missed); (3) added a **RFI field template** (what to actually ask suppliers); (4) explicit E1–E4 grading with E3 segregated and flagged.

## 一、物料真身澄清（本版核心）Material identity clarification

**紫松果菊（Echinacea purpurea）——采购规格陷阱**:

| 项 | 结论 | 证据 |
|---|---|---|
| 植物学身份 | *Echinacea purpurea* (L.) Moench（菊科松果菊属；别名紫锥菊、紫锥花、松果菊） | `[F]` |
| inulin 确是主要多糖 | 根中总果聚糖 ≈ **16%**，其中 inulin **>88%**；文献报根中 inulin **12.3%** | `[F]` MDPI 2023 |
| ⚠️ 但 inulin 未必是最强功效成分 | 最强免疫增强活性的多糖是**水溶性、酸性支链杂多糖（heteroglycans）**，而非 inulin 的聚果糖部分 | `[F]` |
| ⚠️ 干燥工艺可毁活性 | 鲜料未及时处理时**菊苣酸 + 烷酰胺损失可达 80%**；商品间及批间差异极大 | `[F]` |
| ⚠️ 提取溶剂决定成分谱 | 水提主溶 inulin（59%）与蛋白；40% 乙醇为折中；**70% 乙醇反沉淀 inulin**（提取液 inulin 仅 0.51% vs 40% 乙醇 0.70%） | `[F]` MDPI 2023 |

🔴 **三条硬要求（须写进 RFI）**: ① 规格书须**同时卡 inulin、总多酚/菊苣酸、烷酰胺三项**（否则可能只买到"淀粉样填充物"）；② 须书面说明**采收至干燥间隔、干燥方式（喷雾/真空/冷冻）与温度**；③ 须指定**提取溶剂体系**——水提拿 inulin、醇提拿酚类。

**柑橘果提取物——需先确认真身**：读法 A = **枳实/苦橙 Citrus aurantium 干燥幼果**（总黄酮 65–95% + 辛弗林 4–30%，与纪要"总黄酮 + 总生物碱"高度吻合 `[I]`）；读法 B = 甜橙/柑橘果皮（橙皮苷、PMFs）。两读法的供应商池**完全不重叠**，须先与研发统一口径。

**机理层 / 方案层分离**：机理层（可叠加）= 菌群调节 + pH 缓冲 + 屏障舒缓；方案层（互斥）= B1 油相热熔胶直接涂布 · B2 纳米纤维素三维锁持 · B3 水性丝网/圆网印刷 · B4 狭缝涂布。⚠️ 检索时**不得**把"益生菌/益生元/后生元"当三条互斥路线去找供应商，否则同一批供应商被重复筛三遍。

## 三、RFI 字段模板（回答"要问供应商什么"）RFI field template

**通用必填字段（所有环节，缺一不入评估）**: ① 工商全称 + 统一社会信用代码（**最高优先**，排除音译歧义）；② 角色（生产商/品牌商/贸易商/院所/设备商/试剂商）；③ 产线位置 + 是否自有；④ 年产能 + 当前利用率 + 可分配给我方的量（利用率 >90% = 弹性不足）；⑤ TDS + 近 3 批 CoA（须实测值）；⑥ MOQ + 交期 + 报价（注明有效期；**成本数据半衰期 6 个月**）；⑦ 同行业客户案例（可不透露客户名）；⑧ 技术对接人 + 能否安排产线参观。

**环节 A 特有项**: A-1 植物学来源（拉丁名）与使用部位（菊苣酸主要在花、烷酰胺主要在根）；A-2 标定物与含量（**不能只卡 inulin**）；A-3 检测方法（HPTLC/HPLC/UV/TLC）+ 第三方报告；A-4 提取溶剂体系；A-5 ⚠️ 采收至干燥间隔 + 干燥方式与温度（**80% 活性损失来源**）；A-6 批间一致性（近 6–12 批 CoA，CpK <1.33 视为一致性不足）；A-7 天然原料波动应对；A-8 粒度能否 <20 µm；A-9 化妆品原料备案 / 目录收录情况。

（环节 B/C/D/E 各有专段，见原文 §4.3–4.5。）

## 四、甄选逻辑 Selection logic（v2 版，已被 v3 修订）

**硬性门槛 H1–H7**: H1 合规（GB 15979 系列；化妆品路径需目录收录/备案；Class 1+2 双轨或 COC 澄清；完整成分披露，不接受黑箱）；H2 可持续来源可追溯；H3 功效可验证（含量标定 + 近 3 批 CoA + 配合四环验证链：分子识别→定量→渗透→转移）；H4 量产能力四问（哪条产线/年产能/自有或代工/TDS+CoA）；H5 上布携带量（**v2 写"必须自有丝网或圆网产能"——已被 v3 纠正**）；H6 低温工艺兼容（全程 ≤65 °C，接受现配现用）；H7 成本 <5 美分/片（超门槛不直接否决、降档处理）。

**加权评分（40/30/30 框架按环节再分配）**: A 段 = 功效与验证能力 30% / 合规与安全 25% / 供应与产能 20% / 技术响应与合作 15% / 成本 10%；B、C、D、E 段各有细分权重。

## 五、数量策略、风险与下一步 Strategy, risks, next steps

- **数量策略**: 上游原料多源（主供 + 备选 ≥2）；复配双源；上布双源（离线 + 在线）；设备按路线各评 1–2 家；检测 ≥2 家按能力拆分（HPTLC 与 3D 皮肤模型很少同强）。
- **风险登记**: 含**单点依赖显式提示**；音译名称污染列为最高优先风险；天然原料批间波动；转移率仅约 2%。
- **待核实**: 名称核实（最高优先级，Q1 沿江→**延江 YanJan** 已确认 / Q2 嘉凯 / Q3 和大 / Q4 卡博 / Q5 赛服 / Q6 NBC / Q7 联中·西安打开·奇峰·威大·大众·克复·奥利）；技术待验证；商务与合规待补。
- **下一步行动**: 按优先级逐环节询源与验证。
