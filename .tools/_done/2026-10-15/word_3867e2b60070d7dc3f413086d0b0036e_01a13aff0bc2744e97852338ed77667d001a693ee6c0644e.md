# 5CB 贴身合规评估结论备忘录（5CB Skin-Contact Compliance Assessment Memo, 2026-10-14）

## 一句话定位 Positioning

Internal compliance **decision memo** (doc no. COMPLIANCE-2026-1014-5CB) that **falsifies and closes** the 5CB route (4-cyano-4'-pentylbiphenyl, a nematic liquid crystal) for baby-diaper **skin-contact** applications, via a desk hazard–exposure assessment (step 0, no migration testing performed). （中文：内部合规决策备忘录，以桌面危害-暴露评估（第0步，未做迁移测试）形式，正式"已证伪-关闭" 5CB 用于婴儿纸尿裤贴身场景的技术路线。）

## 摘要 Summary

The memo assesses whether **5CB** — the liquid-crystal component used in the library's PDLC-based mechanochromic ("pull-to-change-colour") route — can be used in **skin-contact** baby-diaper products. Relying on public SDS/regulatory databases (Ossila, ChemicalBook) and the knowledge base's compliance framework (OI-23, compliance-audit checklist, OEKO-TEX, DMAC/formamide precedents), it concludes **no**: 5CB stacks acute dermal toxicity (H312), skin sensitisation (H317) and skin irritation (H315), its supplier SDS restricts it to **laboratory R&D only (PC21)** with REACH status "Not applicable", and it fails every internal skin-contact baseline. The route is therefore closed; PDLC is downgraded to non-skin-contact uses, and the skin-contact "gold standard" is redirected to HPC + CTI food-contact-grade pressure-activated ink.

（中文对照：5CB 为贴身 PDLC 力致变色路线的液晶组分。基于公开 SDS/法规库与库内合规框架，因经皮毒性 H312、致敏 H317、刺激 H315 三项叠加且供应商限研发用途（REACH 未注册），全部内部合规基线不通过 → 路线关闭；PDLC 降级为非皮肤接触应用；贴身金标准转向 HPC + CTI 食品接触级压力激活油墨。）

## 评估判据链 Evidence chain

### 1. 危害分类（GHS/CLP）

| 危害终点 Hazard endpoint | 分类 Classification | 备注 Note |
|---|---|---|
| 急性毒性-口服 Acute oral | 4类 H302 | — |
| 急性毒性-经皮 Acute dermal | 4类 H312 | **经皮吸收路径**（关键否决项） |
| 急性毒性-吸入 Acute inhalation | 4类 H332 | — |
| 皮肤刺激 Skin irritation | 2类 H315 | — |
| 眼刺激 Eye irritation | 2类 H319 | — |
| 皮肤致敏 Skin sensitisation | **1类 H317** | **贴身产品一票否决项** |
| 呼吸刺激 Respiratory | STOT SE 3 H335 | — |

### 2. 理化与暴露参数

| 参数 Parameter | 值 Value |
|---|---|
| LogP | **5.4**（高亲脂，经皮渗透潜力高） |
| 溶解性 / 熔点 | 水中不溶；熔点 **34℃**（室温呈液晶态） |
| 运输分类 | UN 3276，危险类别 **6.1**（毒性物质） |

### 3. 法规注册状态

- 美国 **TSCA**：已列管（listed: Yes）
- 欧盟 **REACH**：EC 255-093-2 存在，但注册 "Not applicable" —— 供应商 SDS 明确**仅供实验室研发（PC21）**，不得用于医药、家庭或其他用途
- **德国水危害等级**：WGK 3（强水危害）

### 4. 对照内部合规基线（全部不通过）

| 门槛 Baseline | 5CB 状态 |
|---|---|
| EU 10-2011 迁移测试 | 无数据，且经皮毒性已列 |
| FDA 21 CFR（长时皮肤接触 + 潜在口服） | 无许可 |
| 非致敏认证 | 被 H317 直接否决 |
| 口服毒性许可 | 急性口服 H302 已列 |
| OEKO-TEX STANDARD 100 Product Class I（婴幼儿最高级） | 预期不通过 |

### 5. 监管先例警示

- **DMAC**（氨纶行业溶剂）：生殖毒性 + 经皮吸收 + 长期低剂量慢性风险 → **REACH 附件 XVII 第 80 项限制（≥0.3% 禁用）**。
- **甲酰胺**：高水溶性易迁移 + 小分子易穿透 + 封闭环境积累 + 婴幼儿皮肤薄面积大 → 全球监管围堵。
- **判定**：5CB 的亲脂性 + 经皮毒性 + 致敏分类，处于**同一条被监管围堵的路径**。

## 决策与后续行动 Decision & next steps

- **风险状态更新**：《拉力松紧可视化技术评估报告》（路线 B PDLC）中的"5CB 贴身合规评估"专项风险项 → **已证伪-关闭**。
- **PDLC 方案降级**：仅保留非皮肤接触应用（外包装防篡改指示、包装膜受压指示），重新立项。
- **贴身路线合规金标准**：**HPC（羟丙基纤维素，可食、无毒、可降解）+ CTI 食品接触级压力激活油墨**；国内成本备份：**河南佳易达**。
- **供应链记录**：5CB 货源（论文来源 Kingston Chemicals 等）不再纳入贴身材料供应商池。

## 信息边界 Boundary

基于 2026-10-14 检索的公开 SDS/法规数据库信息（Ossila、ChemicalBook 等）及库内合规框架整理。若未来 5CB 供应商提供新的毒理学包（致敏阴性数据、经皮毒性豁免）或法规状态变化，可申请重新评估；否则按"关闭"处理。
