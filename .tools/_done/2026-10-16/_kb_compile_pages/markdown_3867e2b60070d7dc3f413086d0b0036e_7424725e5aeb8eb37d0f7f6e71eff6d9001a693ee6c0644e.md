## Key Claims 核心论断

1. **Biocare 主线是一条「口径纠偏 → 供应商池重构」的链**：W41 最重要的知识演进不是新增量（12 条），而是 v2→v3 把工艺口径从「丝网印刷」纠正为「功能性乳液/溶液 → 热风无纺布面层施加」，并新增「②整理液/乳液制造」前置环节；工艺族谱扩展到 10 类液体施加方法（吻涂 ANDRITZ / 喷涂 WEKO / 狭缝 Nordson / 圆网三次失败）。
2. **供应商证据分级（E1–E4）已成为本库的编目纪律**：v2/v3 与「三家技术档案复核」一致要求「以证据对齐参数」而非拿来主义。
3. **周新增统计存在时间基准缺陷**：`X-IMA-Create-URL-Time` 会被批量刷新，不得作为上传时间判据；微信文章无时间字段 → 须以「标题日期 + `list_note` 创建时间」双重交叉验证，未确认项（本次 9 条）不计入索引。
4. **配额阻塞是常态性风险**：`get_doc_content` 的 200005 日配额持续导致 Note 正文无法解析（W40 有 12 条、W41 有若干条受影响），须依赖无配额通道（MCP `fetch_media_content`）或次日补解析。
