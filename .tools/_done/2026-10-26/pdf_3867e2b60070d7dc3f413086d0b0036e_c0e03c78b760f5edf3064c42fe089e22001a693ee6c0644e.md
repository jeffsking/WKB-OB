# CN119278082A 用于将纳米颗粒保留在纤维材料内的系统和方法（Mativ × LMS Technologies）

## 一句话定位 Positioning

如果 10-23 / 10-20 两次聚合芯能对接暴露的核心死结是"**无机非溶物上布后烘干必然掉粉**"，那么这份专利就是该死结在**过滤行业**的成熟解法：不是设法让颗粒"粘在表面"，而是**先用粘合剂把纤维网络"上浆"，再把颗粒从一面吹/吸穿过去，靠负压与胶把颗粒锁在基材内部结构里**。它对本库的价值有三层：① 一套可直接照搬的固着工艺（胶 + 穿透 + 负压 + 可选二次补胶）；② 一张"颗粒添加量 → 过滤等级"的阶梯表，可用于估算除臭层的最低有效上胶/上粉量；③ 一个反直觉结论——基材纤维越粗，能容纳的颗粒越多。

A filtration-industry patent that solves, by engineering, what the hygiene supply chain still treats as an open bottleneck: retaining insoluble inorganic nanoparticles in a fibrous web without dusting-off. The route is binder-penetration + particle-through-flow + vacuum, plus an optional secondary binder pass — and it ships with a quantitative add-on vs. efficiency ladder, including a thermal-bonded carded (air-through) substrate example directly relevant to REL facings.

## 摘要 Summary

专利保护一套"把纳米颗粒保留在纤维材料内部"的系统与方法。流程是：纤维基材（第一表面 / 第二表面）由进料器从上游推进到下游；**第一分散装置把粘合剂分散到基材上**，使胶穿透第一表面进入内部结构（优选从第一表面到第二表面呈梯度分布）；**第二分散装置把纳米颗粒分散穿过第一表面**，使颗粒停留在两表面之间；**第二表面施加负压**帮助颗粒进入并被抽住。粘合剂促进纤维与颗粒之间的粘合，从而把颗粒锁在基材内部结构中，同时让颗粒分布更均匀。

粘合剂的选择范围是淀粉、糊精、瓜尔胶、PVOH（聚乙烯醇）与聚合物胶粘剂，形态可为溶液、乳液、悬浮液、热熔体或可固化体系；施加方式含喷涂（液滴约 20–30 µm）、浸涂、喷嘴多点喷涂；可与表面活性剂混配；颗粒分散后还可再用第二胶粘剂补涂纤维。纳米颗粒定义为"至少一个维度 <1 µm"。

性能侧给出了一组可直接用于设计的定量关系：纳米颗粒面密度 0.1–20 g/m²（优选 ≥2 g/m²）；**基材 gsm 与颗粒 gsm 的比值（密度比）越小，MERV 越高、压降也越高**——密度比 67 对应压降约 0.14 inH₂O、初始 MERV 10；33.4 对应 MERV 10、压降 0.17；22.3 对应 MERV 12、压降 0.24。添加量阶梯：≥2 g/m² → MERV ≈10、4 g/m² → 12、6 g/m² → 13、≥10 g/m² → ≥15。

实施例覆盖多种基材：90 gsm 纺粘（基础样 MERV 9、压降 0.07 → 加颗粒后 MERV 12–16、压降 0.17–0.41）、24 gsm 熔喷（对比"有胶无颗粒"与"有胶有颗粒"）、**5 旦热风粘合梳理纤维**（MERV 6 → 13，压降 0.03 → 0.31–0.33）、纺粘 + 熔喷复合（70 gsm + 24 gsm）。作者同时指出：纤维越粗（旦数越大），孔径与孔容越大，可容纳的颗粒密度越高，因而 MERV 越高但压降越大。

## 关键论断（key_claims）

- **固着问题的正解是"往内部锁"而不是"往表面贴"**：胶 + 穿透分散 + 负压三件套，把颗粒变成"内嵌"而非"外附"，从机理上消灭返粉 —— 支撑页：[[Odor Control Technology Landscape（异味控制技术图谱）]]
- **热风无纺布上可行，但透气代价约 10 倍**：5 旦热风布 MERV 6→13 的同时压降 0.03→0.31–0.33 inH₂O —— 卫材若照搬，必须重新评估"透气/回渗/下渗"三指标是否被压降吃掉 —— 支撑页：[[热风无纺布]]
- **颗粒量与性能可算账**：≥2 g/m² 才够 MERV 10，≥10 g/m² 才到 15；把这条阶梯换算到除臭场景，可作为"除臭层最低上粉量"的量级参考（`[待验证]` 过滤效率≠除臭容量） —— 支撑页：[[Chemical Adsorption Deodorant（化学吸附型消臭剂）]]
- **粘合剂选型是成本与合规的双重约束**：PVOH/淀粉/糊精路线便宜且低毒，但成膜后是否牺牲颗粒表面可及性，正是 10-23 纪要判定"五步闭环无解"的那一环 —— 本专利未给出可及性数据（只测过滤效率） —— 支撑页：[[粘合剂 Binder]]
- **两条路线互斥可选**：本专利（胶 + 穿透 + 2–10 g/m²）与 [[US2005-0084412A1 胶体纳米颗粒降味（金佰利 2003 申请）]]（无胶涂层 + 0.1–4%）在"薄/软"与"牢/量"之间各执一端 —— 支撑页：[[US2005-0084412A1 胶体纳米颗粒降味（金佰利 2003 申请）]]

## 与本库除臭/附着议题的关系

| 本库既有问题（2026-10 两次聚合芯能对接） | 本专利给出的对应答案 | 差距 |
|---|---|---|
| 无机粉体上布后烘干必然掉粉（无交联/附着） | 先上胶再穿透分散 + 负压抽吸 | 专利未验证"薄型卫材 + 高车速"工况 |
| 加胶成膜会覆盖颗粒表面 → 可及性下降 | 胶在**纤维-颗粒界面**而非颗粒表面全覆盖（穿透而非表面涂） | 缺少可及性/即时起效的测试数据 |
| 除臭粉 30–60 µm vs SAP 400–500 µm 共混偏析 | 颗粒不走共混，走**后处理内嵌** | 需评估对柔软度与厚度的副作用 |
| 要求即时起效、不需外界触发 | 内嵌颗粒直接暴露于气流/液体通道 | 与"包埋"路线互斥，与本专利不冲突 |

> 判定：本专利是**机理级可行证据**，但**不是可直接采购的卫材方案** —— 过滤介质的验收指标（MERV / 压降）与卫材的验收指标（除臭率 / 回渗 / 下渗 / 柔软度）不同构，需自建 MVT 转译。
