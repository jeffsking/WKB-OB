# NIFO参观速查卡_一页纸.pdf

NIFO参观速查卡（一页纸）

NIFO捻幅科技
＝上海捻幅智能 + 上海焕了个新智能｜东华大学孵化｜总经理朱文斌｜leafclock.com / nifotex.com｜400-996-5270

一句话定位：可视化先进纤维材料服务商，两大技术底座 Lifetracer 生物示踪 + Mintblue 生态感应；覆盖面料/标签/卫材；客户：东方甄选、爱慕、Babycare、网易严选、UCHINO、京东京造、东航。

四款产品（2025.12发布）

|产品|一句话|
|---|---|
|焕新标 Leafclock|累积使用指示，渐进不可逆变色（蓝→粉），无电子，可定制周期（约30次洗护模型）|
|温感标 ThermoTag|环境温感变色（非尿液触发）|
|光护盾 Raysafe|UV辐照强度可视化|
|安心标 Kameleon|首次洗护出红色条＝防伪+首次使用提示|

消费线：NIFO 感应毛巾（洗后变粉＝皂液残留）——唯一"湿触发"在售品，谈尿显切入点。

四大迁移方向

1. 焕新标 → 布尿裤/经期裤/可洗失禁垫（最顺，US5197958/5389093已届期满可自由实施）
2. 温感标 → 一次性尿显（需定制30~37°C窗口、≤120s响应；绕开P&G US8273939~2027、露乐 CN116327488B）
3. 安心标 → 单片包装/湿巾盖防伪开封（最快落地）
4. 光护盾 → UV暴露/包装指示

工艺三问

- 能否出油墨形态在线印刷（丝印/柔印/凹印）？还是只能标签缝制/烫印？
- 微胶囊自产/外购？壁材含甲醛？（Matsui有微量甲醛警示）
- 热风无纺布触发不明显，PE底膜是首选承印面——有基材适配数据吗？

成本基线（对标）

- 尿显胶 Bostik H9570：115元/kg，单片用量0.01~0.04kg → 单片1.4~4.4分
- 热熔尿显胶占市场84%，与现有产线完美适配
- PCM调温功能行业成本约+0.3元/片（功能层定位参考）
- 隐形成本：卫材合规（BPA-free/皮肤刺激/色料外渗）、溶剂油墨危化品物流、国产 vs 日美精度差

必问TOP5（Slepto）

① 睡眠巾技术路线/触发/量产？（卫材试金石）
② 油墨形态+微胶囊耐加工性数据？
③ 温变窗口能否定制32/34/36°C？精度±几度？循环寿命？
④ 卫材级合规报告（皮肤刺激/BPA/甲醛/EN71）？
⑤ 单片成本/MOQ/制版费/打样周期——直接对标1.4~4.4分。
