|C1|C1 【总览】本组共 6 组样品：4 组常规基线 + Code A（新开发 REL 28.8 gsm）+ Code B（REL Minrui 33.48 gsm）。两 Code 在 15 项核心指标中有 14 项可与基线和彼此直接比对（仅 Hold 住 SAM% 因 Code B 未测而不可比）。核心格局：**Code A 在「结构保持」维度断层领先（Hold 住 SAM% 62%，6 组唯一有数据者）、在「液体传递」维度双劣；Code B 在绝对力学（CD 强度 6 组第二）与 Wet-back（5 组有效数据中最优）占优，但穿透为 6 组最慢、减重幅度小于 Code A。** 两 Code 相对基线组的**共同优势项**为：CD 强度、CD 归一化强度、CD/MD 强度比、克重（更轻）；**共同劣势项**为：穿透时间（6 组最慢两位）、VV 无压估算（Code B）；**表现分化项**为：Wet-back（A 最差 / B 最优）、MD 强度与 MD 归一化强度（A 劣 / B 持平）。**|||
|C2|C2 【Code A · 结构保持】明确优势项，且为断层领先。Hold 住 SAM% = 62%，为 6 组最高；4 组基线为 4/15/42/33%，基线均值 23.5%，相对提升 +163.8%；相对最优基线（ZB 42%）仍高 +47.6%。该指标直接对应 REL 的第一性功能（SAM/SAP 迁移动阻挡），是本组最强增量。**Code B 该项未测，A↔B 不可比。**|||
|C3|C3 【两 Code · CD 向力学】共同优势项，且为 6 组前二。CD 归一化强度：Code A 18.65 gf/gsm（6 组第一）、Code B 17.05（6 组第二），基线均值 10.67，相对幅度 +74.7% 与 +59.8%。CD/MD 强度比：Code A 0.283（6 组第一）、Code B 0.243（6 组第二），基线均值 0.165 —— 即两 Code 是 6 组里面内各向异性最小、CD 向最不易先破的一对。绝对 CD 强度：Code B 570.9 为 6 组第二（仅次 YJ 586，而 Code B 克重仅为 YJ 的 84%），Code A 537 列第三。→ 两 Code 的 CD 向抗变形能力是「以克重换效率」得来的，而非靠堆料。|||
|C4|C4 【两 Code 减重】共同优势项，但幅度不同。Code A 28.8 gsm、Code B 33.48 gsm，对基线均值 39.6 gsm 分别 -27.4% 与 -15.6%；4 基线中 3 组为 40.0 gsm、1 组 38.8 gsm。即两 Code 均实现了相对常规 40 gsm 方案的减重，其中 Code A 减重幅度约为 Code B 的 1.76 倍（27.4% vs 15.6%）。⚠ 但 Code B 的设计克重为 28 gsm（CI-06 Material List：上层 11.2 + 下层 16.8），实测 33.48 gsm 超设计值 19.6% —— **若按设计值计，两 Code 的克重几乎相同（28.8 vs 28.0）**，因此本项对比对 Code B 不利，其真实定位可能同样是 28 gsm 级轻量方案（见 C12 边界与 Sheet8 C4）。|||
|C5|C5 【两 Code · 液体传递】共同劣势项（相对）。穿透时间 Code B 1.232 s、Code A 1.02 s，基线均值 0.51 s，二者分别为 +141.6% 与 +100.0%；**Code B 为 6 组最慢、Code A 为 6 组次慢**（最快为 ZB 0.23 s，Code B 是其 5.4 倍），且两 Code 是 6 组中唯二穿透超过 1 s 的样品。但两者仍在「1st Void STT 合格 &lt;3.5 s」之内，属相对劣势而非绝对不达标，且该判据为组装级口径（见 Sheet6）。→ 从整裤性能看，慢穿透直接压缩回渗测试前的可用时间余量，是两 Code 优先级最高的待改善项。|||
|C6|C6 【两 Code · Wet-back】表现分化，必须分开评价。Code A 0.09 g，在 5 组有效数据中**最高/最差**（+28.6%，相对最优基线 DY 0.07 g 高 28.6%；ZB 该项为 NA，未纳入均值）；**Code B 0.0474 g 则是 5 组中最低/最优**（低于基线均值 -32.3%，为最优基线的 68%）。→ 同为「慢穿透」路线，两 Code 在回渗侧结论完全相反：**Code B 的慢穿透换来了更低的回渗，Code A 的慢穿透没有换来回渗改善。**这一分化本身是重要信号 —— 说明「慢穿透」与「高回渗」之间不是必然的因果关系，中间存在其他控制变量（推断：孔隙结构形态与纤维表面润湿性）。|||
|C7|C7 【A↔B 直接配对】15 项核心指标中 **Code B 在 4 项占优、Code A 在 4 项占优、6 项为中性、1 项（Hold 住 SAM%）无数据**。▸ Code B 占优：MD 强度（2348.4 vs 1898，+23.7%）、CD 强度（570.91 vs 537，+6.3%）、Wet-back（0.0474 vs 0.09 g，低 47.3%）、MD 归一化强度（70.14 vs 65.90 gf/gsm，+6.4%）。▸ Code A 占优：穿透时间（1.02 vs 1.232 s，A 快 17.2%）、VV 无压估算（34.34 vs 25.11 cm³/g，A 高 36.8%）、CD 归一化强度（18.65 vs 17.05，A 高 9.3%）、CD/MD 强度比（0.283 vs 0.243，A 高 16.4%）。▸ 中性：克重、厚度、MD 延伸率、CD 延伸率、堆密度、孔隙率。→ **不存在单一占优的 Code**：Code B 赢「绝对力学 + 回渗」，Code A 赢「结构开度 + 面内均衡」，而最能区分两者定位的 Hold 住 SAM% 恰恰只有 Code A 有数据 —— 这是当前两 Code 无法择一的关键证据缺口。|||
|C8|C8 【A↔B 的机理提示】两 Code 设计配方逐组分同构（详见口径项 C4），因此上述差异**只能来自克重/厚度/成型工艺**。Code B 克重高 4.68 gsm（+16.2%）、厚度低 0.145 mm（-14.4%）、堆密度 0.0387 vs 0.0285 g/cm³（+35.7%）—— B 明显更致密。**致密化的代价与收益在实测中方向自洽：强度全面上升（MD +23.7% / CD +6.3%）、回渗下降 47.3%、但穿透变慢 +20.8%、VV 无压估算下降 26.9%。**这条『致密 → 强而慢、回渗更低、空隙减少』的链路方向自洽，可作为工艺调节的定性杠杆。而 Code A 在更低克重（28.8 gsm）下拿到 Hold 住 SAM% 62% —— 说明**结构保持能力主要不来自克重/致密化，而来自纤维体系的功能化组合**。⚠ 该对比受厚度测压口径不一致限制（B 为 @0.2 kPa，A 未注明），堆密度/孔隙率差异应作方向性参考。|||
|C9|C9 【基线规律与两 Code 的偏离】（本组最重要的机理发现）4 个基线按孔隙率升序为 YJ 95.85% → DY 97.47% → ZB 98.01% → 芥东 98.37%，对应 Hold 住 SAM% 为 4% → 15% → 42% → 33%，穿透时间为 0.77 → 0.55 → 0.23 → 0.49 s；前三个基线呈清晰单调关系（孔隙率↑ → Hold SAM↑、穿透↓），芥东因含 35% 疏水 PP（低表面能、削弱毛细驱动）偏离。**两 Code 同时偏离该规律**：Code A 孔隙率 97.92%（与 ZB 几乎相同）却把 Hold 住 SAM% 做到 ZB 的 1.48 倍、穿透慢 4.4 倍；Code B 孔隙率 97.18%（为 6 组最低）却拿下 CD 绝对强度 6 组第二、Wet-back 5 组最优，同时穿透 6 组最慢、VV 无压估算 6 组倒数第二。→ 说明两 Code 的性能均**不由孔隙率/蓬松度单独决定**。YJ 是最有力的对照：它孔隙率最低（95.85%）、穿透并不慢（0.77 s），Hold 住 SAM% 却只有 4% —— 证明**致密本身不带来 SAM 保持能力，功能化组合才是增益来源**。|||
|C10|C10 【三条技术路线的分野】基线组走「开放化」路线（ZB/芥东：大孔隙、快穿透、40 gsm 高克重，穿透 0.23–0.49 s）；Code A 走「轻量功能化」路线（28.8 gsm、中等孔隙率 97.92%、慢穿透 1.02 s、Hold 住 SAM% 62% 断层第一）；Code B 走「致密强化」路线（33.48 gsm、6 组最低孔隙率 97.18%、绝对力学最强、Wet-back 最优、穿透 6 组最慢）。**三者按「基线组均值 → Code A → Code B」穿透单调变慢（0.51 → 1.02 → 1.232 s），但「回渗」并不跟随该趋势（B 最优 0.0474 g、A 最差 0.09 g、基线 0.06–0.08 g）** —— 说明本组的穿透速度与回渗之间不存在简单因果，中间存在其他控制变量（推断：孔隙结构形态与纤维表面润湿性）。|||
|C11|C11 【未验证的关键假设 · 两 Code 的共同疑点】两 Code 的中空纤维占比均为 30%（KC 基准配方仅 14%），而《NEW REL 4》明确警告 ATB 烤箱 &gt;155°C 会使 hollow lumen 坍塌。**实测正好呈同向异常：中空占比同为 30% 的两 Code，穿透时间恰好占据 6 组最慢两位（1.232 s / 1.02 s），远慢于不含中空组分的 4 组基线（0.23–0.77 s）。** 该证据链与「lumen 坍塌或过度粘合导致中空结构失效」的假设高度自洽，且因两 Code 独立复现而**比仅看 Code A 时更具说服力**。**建议优先做截面 SEM / lumen 保留率检测 + 烤箱温度扫描（145→155°C）**；若 lumen 有效保留，则穿透应有改善空间。（此项为推断，属未验证假设，不作为结论引用）|||
|C12|C12 【证据效力边界】① 4 基线 + Code A 未标注样本量与测试日期，属**单批次单点观察**，不得作趋势性/统计性结论；Code B 为 n=5，两侧统计强度不对等 —— 不得以 Code B 的批内稳定性代表基线。② Code B 的 MD/CD 强度单位未标注（见 Sheet8 口径项 C2），若实为 N/2inch 则全部强度类与归一化强度判定作废。③ 厚度测压口径不统一（Code B 为 @0.2 kPa，其余 5 组未注明压力），堆密度/孔隙率/VV 三项为口径受限的估算值，不作强判定。④ 两 Code 设计配方逐组分同构（Sheet8 C4），克重差异来源（设计标称 vs 卷材实测 vs 手抄样）待复核；若二者实为同一材料的不同批次/形态，则 C7、C8 的配对结论需重新解释。⑤ Void Volume、压缩回弹、湿态结合强度、MD 渗透率 k、克重 CV 五项决定性资质指标 6 组全部未测，REL 资质无法闭环。⑥ Code B 与 4 基线是否同法测试未确认，其相对幅度应作方向性参考而非精确值；⑦ Hold 住 SAM% 仅 Code A 有数据，两 Code 无法在该最关键维度上择一。|||
