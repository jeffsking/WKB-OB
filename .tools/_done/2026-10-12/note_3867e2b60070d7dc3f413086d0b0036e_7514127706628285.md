### 3. 刮枪（喷枪）适配


中国区现用诺信（Nordson）Allegro 刮枪，由日本供应商千川特制，刮层设计 125mm，间距即 125×2=2.5mm；工程部倾向复用中国区刮枪（"偷懒"做法）。


方案：让千川或诺信单独定制 3 或 3.2 配置的刮层，capex 不高；3.2mm 机械加工难度低于 1.25mm（1.25 能做、0.75 不一定能做），可行性无问题。


### 4. 额外理由：拼厚（punch）工艺


EverWindow 的 pedal 需打拼厚孔，3.2mm 间距比 2.5mm 更适合打孔；已验证拼厚打在橡筋上会滑开、不会压到橡筋（小陶器桃子开孔除外，需至少保持 5mm）。


彩山、mark 等区域对开孔需求非常积极，可作为说服老板/彤彤主推 3.2mm 的正当理由（背后真实动机：股数越少 capex 越低、工艺越简单）。


结论倾向：主讲人强烈推荐 Trilight 未来向 3.2mm 靠拢，最终需看各国 marketing 及 CUT 消费端反馈，最终决策不在个人。


## 四、巴西 CUT 与在线验证计划


CUT 测试：4 个 code 交付巴西做 CUT（COT），安排在 十月最后一周；最终 focus 2.5 还是 3.2，取决于 CUT 消费端结果。


在线验证：巴西本月同时做 online 验证——其产线现配置 46 股橡筋，无法直接验证 full skill（约 80 根）方案；full skill 用米润产品验证，46 股在线验证交给工程部（杰克州下属工程）。


若 46 股在线工艺稳定，升到 80–82 根只需增加放卷即可；验证时间点在月底或下月初，同时跑米润样品与自有 46 股产品线。


## 五、施胶方式差异（在线 vs 离线）——项目风险点


米润（离线）：直接在 panel 上喷 1.8 gsm（add on）胶，喷胶后附橡筋；


自有在线工艺：橡筋上用喷唇刮胶，约 12 mg/m add on，施胶方式与 add on 均不同。


关键风险：两种方式 creeping（蠕变） 表现不同，离线蠕变可能优于在线；换成 240 tex 后，在线速度与断线问题可忽略不计，唯一需关注的是胶水配合程度、Open time 与 add on 之间的蠕变平衡。


### Phase Three：SEBS 捏塑替代橡筋


思路：采用奥利斯班（安迪在用）的捏塑路线，但不要无纺布复合，做成类似橡筋的盘卷（回到供应商原始方法）；10 月底出 quotation 与 100 卷样品（丁总提供数据）。


材料对比：SEBS 公斤价低于橡筋约 30%，但需升 OD 至 320 tex 才可覆盖 240 tex 弹性；SEBS 弹性模量与 240 tex 橡筋相当；SEBS 密度约 0.92，PTMEG/MDI（橡筋）密度约 1.23，可再获密度维度 savings，最终价格需核算。


关键卡点：SEBS 耐温仅约 85°C，橡筋可达 180–200°C——此前在诺信喷枪上直接化掉，胶水工艺不兼容；若明年超声波非接触式工艺研发成功，SEBS 即可启用。另：荷叶（global）催此项目并非因价格，而是 DMC（甲醛胺类物质）/DAC 合规需求，SEBS 的最大 benefit 是 DAC-free，而非价格。

### Phase Two：超声波无胶焊接（2026 年更早节点可见，2028 年底前交付金瑶）

# 会议纪要：TRY lite 橡筋规格选择讨论


会议主题：Trilight 项目橡筋规格（tex/间距）与无纺布方案、后续技术路线讨论


录音时长：约 24 分钟


主要发言人：项目负责人（"我"）为主，涉及金瑶、彤彤、杰瑞、Chris、小果、丁总、荷叶、安迪等（以录音转写识别为准）


## 一、背景与现状


中国区 Trilight 现有配置：120 tex（约×189），间距 1.25mm；巴西新产品计划上线，未来可能推广至其他区域（彩山、印尼）。澳洲 Carin 已在天津工厂打样，基本确定采用 240 tex、间距 2.5mm，规格比中国区高一倍。


巴西现状：目前使用 470 tex、5mm 间距，整体成本更贵；粗算 470×5 与 240×3 用量接近，若采用 3mm 间距，橡筋用量可产生 savings。


## 二、核心议题：橡筋规格选 2.5mm 还是 3.2mm


### 1. 用量与成本逻辑


120→240 tex：粗细增加一倍、间距减少一倍，橡筋使用量不变；若能从 2.5mm 升至 3.2mm，用量还能进一步节省。


3.2mm 与 2.5mm 肉眼差异不大，仔细对比可看出差异；米润（供应商）样品即为 3.2mm。


华丰细旦单价高于粗旦，但 appearance 有提升；470×5 改 240×3.2 后用量可做到 parity，细旦贵出的部分可被其他项综合掉。


## 三、无纺布方案讨论


供应商格局：目前仅中国区无纺布用乐风，后续 Trilight 项目基本转向 spunbond；巴西无选择权，当地供应商仅两三家。


Inner panel（内层）：建议 7 克重 spunbond（市面已逐步稳定）即可；亦可考虑 7–8 克 SMS——反正在内层消费者看不到。


Outer cover（OC / face）：中国区用 TBCW，彩山/巴西用 15 克；15 克若要提升手感，可用 lofted（白口、side-by-side 卷曲） 结构，成本略高但手感提升，可与内层降克重互相综合成本。


巴西先做熟工艺，彩山（自己人）后续再做进一步优化；需与 Chris 对齐巴西无纺布克重（12g 或 15g 待确认）。


### 2. 3.2mm 的核心收益——减少放卷


中国区 1.25mm 需 180 根以上单股放卷，其他国家产线空间不一定够；改 3.2mm 后橡筋股数至少减半，释放产线空间。


放卷减少双重收益：capex saving（约 1,200 美金/股）＋断线风险下降（股数越多断线概率越大）。中国区实际断线率未知，怀疑因项目受追捧而被运营数据隐瞒。


换用华丰（HF）600 号 240 tex 橡筋后，抗拉性优于旧 900 号，断线率降低一半以上（丝桥已验证）。


对比 2.5mm，3.2mm 可少 十几个到二十个放卷，节省空间明显。
