1.2 Channel形状优化方向


加长Channel：可冲淡SAP密度、增加透气性，且对位更简单，建议在后续考虑。


加宽Channel：多数与会者反对，理由是：


对CD方向导流不利；


局部无SAP区域变大，侧漏风险增加；


对Cradle二次/三次吸收的导液有负面影响。


Channel面积可进一步扩大（如到25%或更极端5%）需要重新定义“有效面积”，并分区域精确设计，不一定全Pad均匀减量。


1.3 分叉细槽（Code 1 vs Code 2）


Code1与Code2总长度、宽度一致，Code2在中间槽基础上增加分叉细槽。


结果：高压下MD导流显著提升，但第三轮Intake时间显著增加（异常值已排除检验员误差）。


讨论：


中间主干槽保留（8mm宽），分叉细槽更细可能更好；


分叉设计可通过上下层宽度差（上层8mm、下层4mm）降低对位难度；


分叉形状在U型状态下存在SAP完整性风险（断叉），需要绑定或局部小包固定，胶量需精确控制。

### 五、材料开发与前瞻验证


5.1 材料实验总体安排


本轮材料实验覆盖5个方向、9个材料代码，包括：


Liner、REL、SAP不同配比；


Co等（熔喷/纺粘复合材料）两种候选（希瑞copo技术、蓝鲸莱塞尔纤维混入热风材料）。


目的：借助V6实验线平台，探索上下游原材料（纤维端）创新，为后续选材提供数据。


5.2 Liner（面层导流层）


设计：上层添加10%三叶草异形截面纤维，下层添加50%异形纤维，验证MD导流作用。


当前使用Michael品牌PPT三叶草纤维，后续希望切换为单组分PET三叶草，但需解决卫生级原料和供应能力问题。


工艺风险：热风温度超过142℃时异形截面会流平，目前打样采用139℃。


注意：面层加10%异形纤维对白度可能有轻微影响，但通常不明显。


建议：面层不必过度纠结于异形纤维添加，重点放在下层导流层。

2.1 哑铃型SAP分布波动


测试方法：Pad切成1英寸宽条状称重，结合CAD计算各区域SAP克重。


结果：X型长条设计整体分布稳定；哑铃型在腰部最窄处（5号模块）SAP实际克重显著低于理论值，且趋势对称。


原因分析：


最窄处面积小，负压作用不足，SAP易飞散到边缘或被气流带走；


大颗粒SAP倾向走向远端，小颗粒易在近端被负压吸附，导致PSD均匀性变差。


改善方向：


在窄区增强局部负压或扩大负压面积；


减少理论SAP量，使实际可捕捉密度达到上限值（实测最高约540~580 g/m²）；


考虑在窄区取消Channel，以增加可吸附面积。


5.3 REL（蓬松无纺布）


现有开发采用PPT与PVA混用，PVA为直纺，在开松和梳理环节存在工艺挑战。


供应商网威预计年底上线卷曲设备，未来可提供卷曲PVA，改善纤维混合均匀性。


28g RL材料性能与现有材料相当，但分切后厚度下降，需关注时间恢复效应。

### 七、会议决议


Channel优化方向：加长不加宽；待第二轮/第三轮材料测试数据后再细化尺寸。


哑铃型窄区问题：通过增强负压/调整成型面积解决，必要时在该区域取消Channel。


大扇尾设计：暂保留，但需进一步验证其消费者沟通价值；若无明确benefit，倾向取消以节省4.8%成本。


材料实验：优先推进Liner、REL、SAP三个方向的工程验证，样品已在准备中。


SAP供应商：实验阶段可扩展范围（诺尔、巴斯夫、触媒等），验证概念后再锁定量产供应商。


专利：当前风险可控，后续如有设计变更需及时通知专利团队。

### 一、Channel结构设计与性能验证


1.1 Channel面积与SAP添加量


当前V6中所有Channel设计面积占Pad总面积的10%~15%。


假设：在SAP密度与现有5.6产品一致的前提下，增加Channel面积可减少SAP总添加量。


测试结论：将SAP总添加量从7.75g降至6.8g（约减少1g）时，回渗、高低压吸收无显著变化，但第三轮Intake时间显著延长（320.2s，远超对照的7.75g水平）。


结论：SAP添加量下限建议维持在7g左右；若进一步降低，U型回渗会出现明显劣势。


### 三、大扇尾设计评估


对比Code6、7、8与常规Control（X型等）：


Code6前后均为大扇尾；Code7缩短中部导流条至200mm；Code8在Code7基础上增加前部圆弧凹槽。


测试结果：均未对防前后漏产生显著帮助；两两对比也无显著差异。


讨论：人偶测试姿势单一（直躺、后仰、侧躺僵硬），实际使用中前后漏概率可能很低；大扇尾可能更多是贴合/舒适性作用。


成本影响：大扇尾设计使成本增加约4.8%（主要来自ILI、PSN等材料加宽）。若无法证实性能benefit，可考虑取消，或将此设计作为“storytelling”卖点。


5.4 SAP（SAP复合材料）


现用KC511是性能均衡的SAP，过去因工艺限制无法做分层/混合，现实验线可支撑。


计划验证两种概念：


上层高GBP/高AUL平衡，下层高CRC；


不同PSD尺寸搭配，如上层较大颗粒、下层较细颗粒。


SAP选型：主要采用诺尔（高GBP、后处理技术多样）；同时可考虑巴斯夫、触媒等外部样品进行概念验证，不必过早绑定单一供应商。


上下层比例：50/50可能不是最优，需通过实验找平衡（防凝胶阻塞、通液性与锁水性兼顾）。本轮实验先固定50/50以减少变量。


5.5 成本与供应


REL/新材料整体成本估计上升约15%（主要来自PVA和PPT纤维）。


熔喷/Co材料（希瑞）成本有优势，但强度偏低（MD约400g/in？实测数据需复核），高速线上可行性存疑，需后续测拉力、成本及实际走机。


建议直接拿一卷材料上机跑，以暴露问题。
