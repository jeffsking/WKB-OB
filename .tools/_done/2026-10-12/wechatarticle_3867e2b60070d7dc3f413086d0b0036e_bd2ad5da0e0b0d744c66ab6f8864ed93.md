## 聚酯为什么要控制水分：水解机理、动力学方程与纺丝后果

## 水分问题的本质：不是"蒸发"，而是"断链"

PET、PBT、PLA 等聚酯的共同结构特征，是主链中含有大量酯键 –CO–O–。聚酯通常由二元酸或其酯类衍生物与二元醇缩聚形成。将两段聚合物链分别记为 P 和 P′，缩聚反应可概括为：P–COOH + HO–P′ ⇌ P–COO–P′ + H₂O。水解是上述缩聚反应的逆反应：P–COO–P′ + H₂O → P–COOH + HO–P′。

因此，水不是与聚酯熔体无关的杂质，而是直接参与主链断裂的化学反应物。水解早期往往只有分子量下降，并不一定立即发生明显失重或外观变化；一条长链被切成两条短链后，聚合物总质量近似不变，但分子链数量增加。

PET 的一次局部水解可写为：P–COO–CH₂CH₂–O–P′ + H₂O → P–COOH + HO–CH₂CH₂–O–P′。这里的产物仍然可能是较长的 PET 链段，而不是立即完全转化成对苯二甲酸和乙二醇。只有酯键持续、反复水解，才会逐渐形成低聚物及更小分子产物。

## 酯键为什么会被水攻击？

酯基 R–C(=O)–OR′ 中的羰基具有明显极性。氧原子使羰基碳带有部分正电，水分子中的氧可作为亲核体攻击羰基碳。其过程可概括为四步：水分子接近酯基羰基碳；亲核加成形成四面体中间体；中间体内部发生质子转移；酰氧键断裂，形成羧基端与羟基端。总反应：R–COOR′ + H₂O → R–COOH + R′–OH。

高温熔融状态下，分子链运动和水的扩散速度显著提高，水更容易接近主链酯键；同时，水解速率常数随温度升高而快速增加。PET 的熔融加工温度通常远高于玻璃化转变温度，此时水解可在挤出和纺丝停留时间内造成可测量的分子量下降。

## 一次水解，分子层面发生了什么？

设初始聚合物链的物质的量为 n₀，发生的断链物质的量为 nₛ。每发生一次随机断链，体系中的分子链数量增加一条：n = n₀ + nₛ。若聚合物总质量 m 在水解早期近似不变，则数均分子量为 Mₙ = m / (n₀ + nₛ)。由初始数均分子量的定义可得：1/Mₙ = 1/Mₙ,₀ + nₛ/m。随机断链数与 1/Mₙ 近似呈线性关系。即使没有明显失重，只要断链数量增加，数均分子量就会下降。

一次酯键水解还会同时增加两类端基：[COOH]ₜ = [COOH]₀ + s，[OH]ₜ = [OH]₀ + s，其中 s 表示按单位质量或单位体积计的水解断链量。羧基端和羟基端增加，是聚酯发生水解的直接化学证据。

## 为什么水解可能表现出"越反应越快"？

聚酯水解可出现羧基端基参与的自催化。水解生成的 –COOH 端基提高局部酸性，促进羰基氧质子化，使羰基碳更容易受到水分子攻击。水解速率可写为：rₕ = (k₀ + kₐ·CCOOH)·CE·Cw。其中：rₕ 为水解速率；k₀ 为非催化水解速率常数；kₐ 为羧基端基催化项的速率常数；CCOOH 为羧基端基浓度；CE 为酯键浓度；Cw 为聚合物中的水浓度。

当水解程度较低、酯键浓度变化很小时，CE 可近似视为常数，基础反应可简化为：rₕ ≈ kₕ·Cw。不同研究对水反应级数的处理并不完全相同：有的采用对水一级的模型，有的采用零级或分数级模型。这与水在聚合物中的溶解、扩散、相态和测试温区有关。

## 温度如何放大水分的影响？

水解速率常数通常用 Arrhenius 方程描述：kₕ = A·exp(−Eₐ/RT)，取自然对数得 ln kₕ = ln A − (Eₐ/R)(1/T)。其中 A 为指前因子；Eₐ 为水解反应活化能；R 为气体常数；T 为绝对温度。温度升高时，指数项增大，水解速率常数上升。这就是同样的含水量在室温切片中可能暂时不表现出明显损伤，而在高温熔体中却会快速引起分子量下降的原因。

## 水分为什么会降低特性黏度？

聚酯行业常用特性黏度 [η] 间接表征分子量。Mark–Houwink 方程为：[η] = K·Mᵥᵃ，其中 Mᵥ 为黏均分子量，K 和 a 与聚合物—溶剂体系及测试温度有关。水解引起分子量下降，因此 Mᵥ ↓ ⇒ [η] ↓。这也是湿 PET 经高温加工后常出现特性黏度下降的根本原因。水并不是在特性黏度测试时简单地"稀释"样品，而是在熔融加工阶段改变了分子链长度。

## 为什么少量断链会造成明显的熔体黏度变化？

对于高于缠结分子量的线性聚合物，零剪切黏度与重均分子量常近似满足：η₀ ∝ Mw³·⁴。若重均分子量下降 10%（Mw,1 = 0.9 Mw,0），则 η₀,1/η₀,0 = 0.9³·⁴ ≈ 0.70。在这一理想化关系下，分子量下降约 10% 可对应零剪切黏度下降约 30%。实际纺丝条件下的表观黏度还受到剪切变稀、温度和分子量分布影响，但"分子量小幅下降、熔体黏度明显下降"的趋势仍然成立。

## 水分如何传递成纺丝问题？

水分 ↑ → 水解断链 ↑ → 分子量 ↓ → 特性黏度 ↓ → 熔体黏度与熔体强度 ↓ → 挤出、喷丝与拉伸稳定性发生变化。

## 为什么高特性黏度聚酯对水解更敏感？

高特性黏度意味着平均链长更大、分子链数量更少。相同质量聚合物若发生相同数量的随机断链，高分子体系的相对分子量损失往往更显著。由 1/Mₙ = 1/Mₙ,₀ + nₛ/m 可知，当初始 Mₙ,₀ 很大时，少量 nₛ 就会使 1/Mₙ 出现明显增加。因此，高特性黏度 PET 对水解降解具有更高敏感性。

## 水分指标怎样表达？

聚酯切片含水量常用质量分数或 ppm 表示：wH₂O (ppm) = (mH₂O / mpolymer) × 10⁶，例如 0.004 wt% = 40 ppm。熔融纺丝资料中常见将干燥后 PET 切片水分控制在约 0.004 wt% 以下的工艺描述；不同产品、设备、停留时间和目标特性黏度对应的内部规格并不完全相同。这个数值的意义不只在于防止水的物理气化，更在于限制单位质量熔体中的可反应水分子数量，从而限制高温停留期间的酯键断裂数量。

## 水分影响的完整逻辑

化学层面：水参与酯键逆缩聚，造成随机断链，并增加羧基与羟基端基。动力学层面：温度越高，水解速率常数越大；羧基端基还可能形成自催化。分子层面：链数量增加，Mₙ、Mw 与特性黏度下降。流变与工艺层面：熔体黏度、弹性和拉伸承载能力下降，压力、喷丝流量、纤度均匀性与断头状态随之变化。
