# 你手里的 PHA 粒料，和细菌体内的 PHA 不是同一种材料

> 绿塑分子社 · 细菌塑料工程笔记 · PHA 第一课（S1E01）

## 引子

做 PHA 的人，早晚会撞上同一堵墙：文献上 PHA 的断裂伸长率能到 20% 以上，你测出来只有 3%；文献说 PHA 在海水里几周就崩解，你的样件泡了半年还硬得能敲桌子；文献说 PHA 分子量能上百万，你拿到的粒料只有三四十万。这些"不一致"里，很少是造假。大部分是因为讨论的双方，说的其实不是同一种物质状态。而这个分歧的起点，就在细菌体内那个直径两三百纳米的颗粒上。

## 一、1926 年：一个被搁置了半个世纪的发现

1926 年，法国巴斯德研究所的 Maurice Lemoigne 在研究 Bacillus megaterium 的自溶产物时，发现培养液会持续酸化，析出的酸被鉴定为 β-羟基丁酸。他进一步确认，细菌胞内存在的并非游离的酸，而是它的聚合物——聚 3-羟基丁酸酯（P3HB）。这是人类第一次发现天然聚酯。

然后，这个发现基本被搁置了三十多年。直到 1958 年前后，Macrae 与 Wilkinson 系统研究了 PHB 的积累与消耗条件，才确立了它作为胞内贮藏物质的生理身份。真正的产业化冲动要等到 1970 年代石油危机——ICI 由此启动了 Biopol 项目。

值得注意的细节：PHA 是先被当作"代谢产物"，后被当作"贮藏物"，最后才被当作"材料"的。这个认知顺序留下的遗产是：PHA 的分子设计从一开始就不是为力学性能服务的。

## 二、细菌为什么要造它：三个层次的答案

### 第一层 · 碳与能量的贮备

教科书答案：当碳源过剩、而其他营养元素受限（最典型是氮限制，也可以是磷、硫、镁或溶氧限制）时，细菌把多余的碳流封装成聚酯存起来，饥饿时再动员。

以经典底盘 Cupriavidus necator 为例的代谢调控：

氮限制 → 蛋白质/核酸合成停滞 → NADH 累积 → TCA 循环受抑（柠檬酸合成酶被 NADH 抑制）→ 乙酰-CoA 累积、游离 CoASH 浓度下降 → β-酮硫解酶（PhaA）解除 CoASH 竞争性抑制 → 碳流转入 PHB 合成

关键在最后一步：PhaA 平时被游离 CoASH 抑制着。营养限制导致游离 CoA 被"锁"进乙酰-CoA，抑制自动解除。整条通路不需要额外的转录开关，靠代谢物浓度就完成了切换——一个纯粹的代谢物水平反馈。

工程含义：既然是浓度反馈，那 PHA 积累与细胞生长在天然菌株中天然是分离的两个阶段。这就是为什么经典 PHA 发酵是两阶段工艺。而部分菌株（如 Azohydromonas lata、以及强启动子驱动的重组 E. coli）可以做到生长偶联型积累，工艺上省一个阶段。

### 第二层 · 渗透压的解法（本文最重要的机理点）

这一层是理解 PHA 为什么必须是"聚合物"的关键。假设细菌不聚合，直接以游离 3-羟基丁酸的形式存碳。当 PHA 含量达到工业目标的 70–80% 细胞干重时，胞内的游离单体浓度会达到摩尔级。后果有两个，都是致命的：

- 渗透压爆表——渗透压正比于溶质粒子数，胞内几摩尔的小分子会直接把细胞撑破；
- 胞内酸化——3-羟基丁酸是有机酸，pKa 约 4.7，摩尔级浓度下 pH 无法维持。

聚合彻底解决了这两个问题。PHB 的重复单元分子量为 86，工业级 Mw 在 3×10⁵–1×10⁶ 量级，对应聚合度（DP）约 10³–10⁴。聚合把溶质粒子数降低了三到四个数量级，同时把羧基封进了酯键。最终这些聚合物还以固相颗粒形式存在，几乎不贡献渗透活性。

**PHA 是自然界解决"高密度储碳"与"渗透压"矛盾的方案。它的"高分子"身份不是巧合，是必要条件。**

### 第三层 · 不只是储碳（近二十年的新认识）

| 功能 | 证据强度 | 说明 |
|---|---|---|
| 碳/能量贮备 | 确证 | 教科书级 |
| 氧化还原缓冲（NADPH 汇） | 较强 | PhaB 消耗 NADPH，调节胞内还原力平衡 |
| 逆境存活优势（干燥、UV、氧化、冷、渗透冲击） | 较强 | 多个属的敲除/回补实验支持 |
| 参与共生固氮（根瘤菌类菌体内的 PHB） | 中等 | 与固氮效率相关，机制仍有分歧 |
| (R)-3HB 及其寡聚体作为信号分子/膜通道组分 | 存在争议 | 相关工作（如 cPHB 假说）尚未形成共识 |

编者注：把争议明确标出来，是本系列的固定做法。宁可少讲一条，不可含混一条。

## 三、类比的边界：为什么不该说"细菌的脂肪"

网上常见的说法是"PHA 是细菌的脂肪"或"细菌的脂肪肝"。这个类比只在功能层面成立，化学层面完全不成立，而且会误导工程判断。

| 对比项 | 甘油三酯（脂滴） | PHA（碳素体） |
|---|---|---|
| 化学结构 | 甘油 + 三条脂肪酸酯化，小分子 | 羟基酸缩聚，高分子聚酯 |
| 渗透活性 | 有一定 | 几乎为零 |
| 物理状态 | 液态/半液态油滴 | 固态、可结晶的聚合物 |
| 能否成材 | 不能 | 能——因为它是聚合物 |

功能类比可以用，但请在同一句话里说清它是聚酯。否则读者会顺理成章地推论"PHA 像油脂一样容易被分解"——而这个推论会被推翻。

## 四、那个颗粒的解剖：碳素体（Carbonosome）

### 4.1 基本尺度

| 参数 | 典型值 | 备注 |
|---|---|---|
| 颗粒直径 | 约 100-500 nm | C. necator 常见 0.2-0.5 μm |
| 每细胞颗粒数 | 约 5-15 个 | 受 PhaM/PhaP 表达量强烈调控 |
| PHA 占细胞干重 | 优化体系可达 80-90% | 此时细胞几乎被颗粒填满 |
| 表面层厚度 | 约 2-4 nm | 以蛋白为主 |

Jendrossek 等人提出用 carbonosome（碳素体）这个词取代笼统的"颗粒"，理由是：它不是一坨被动堆积的聚合物，而是一个有组织的亚细胞结构——有专属蛋白、有空间定位、有装配与拆解程序。这个概念转变很重要，它把 PHA 颗粒提升到与羧酶体、磁小体同一层级的功能单元。

### 4.2 表面的四类蛋白（GAPs）

| 蛋白 | 功能 | 工程杠杆 |
|---|---|---|
| PhaC | PHA 合成酶（聚合，引发剂+催化剂） | 表达量↓ → 分子量↑（Mn ∝ 1/[PhaC]） |
| PhaZ | 胞内解聚酶（拆） | 敲除以稳定产率与分子量；控制收获时机 |
| PhaP（相素） | 表面包覆（包），小分子量约 11–24 kDa 两亲性蛋白，颗粒上最丰富的蛋白 | 表达量↑ → 颗粒小而多 → 影响破胞与提取 |
| PhaR | 调控蛋白（管），用"物理表面积"作为传感器构成负反馈环路 | 改造以解耦颗粒尺寸与 PhaP 化学计量 |

- **PhaC 工程含义**：分子量可以通过启动子强度"设计"出来，不需要改配方、不需要改温度。超高分子量 PHB（Mw > 3×10⁶）就是靠低表达 PhaC 的重组体系做出来的，其超拉伸薄膜的强度远超常规 PHB。
- **PhaZ 工程含义**：菌体收获延迟、或积累期后误入饥饿状态，PhaZ 会同时造成产率损失与分子量下降。所以重组菌构建中，敲除 phaZ 是常规操作。如果中试批次分子量忽高忽低，收获时机是第一个要查的变量。
- **PhaP 工程含义（被严重低估）**：颗粒尺寸分布会影响破胞难度、固液分离效率、以及提取后的蛋白残留水平。一个转录调控层面的参数，直接传导到下游单元操作的成本上。
- **PhaR 负反馈环路**：用"物理表面积"作为传感器的负反馈环路——细菌不需要测量 PHA 的量，只需要"摸一摸表面还有没有空位"。（在 C. necator 中还有 PhaM：既激活 PhaC，又把颗粒锚定到核区，决定颗粒数量与胞内定位。敲除后往往只形成单个大颗粒。）

## 五、全文的核心：那个不可逆的相变

### 5.1 天然态：无定形

细菌体内的 PHA 不是结晶的。它处于无定形、链段可运动的橡胶态。证据来自三个独立方向：

- 原位 NMR：完整天然颗粒中的 PHB 链呈现高链段迁移率，与本体结晶态 PHB 的谱学特征完全不同；
- X 射线衍射：新鲜天然颗粒给出无定形弥散环，无结晶衍射峰；
- DSC：完整天然颗粒几乎测不到熔融吸热峰。

为什么能维持无定形？两个原因叠加：颗粒尺寸在纳米级、且表面被蛋白层限制，成核受阻；颗粒内含水，水起到增塑作用，把有效 Tg 压到环境温度以下。

### 5.2 提取：一次不可逆的相变

一旦破胞、去除蛋白层、脱水干燥——增塑剂走了，空间限制没了，成核位点出现了。PHB 开始结晶，结晶度可以爬到 55–80%。而且这个过程还没结束：因为干态 PHB 的 Tg 约 4°C，室温储存等于持续处在 Tg 之上退火，二次结晶会在数天到数周里继续进行。这就是 PHB 著名的"老化脆化"。

相变对比：

| 指标 | 胞内天然态 | 提取后粒料 |
|---|---|---|
| 凝聚态 | 无定形 | 半结晶（Xc 约 55–80%） |
| 链运动性 | 高（橡胶态） | 低（玻璃态 + 晶区） |
| 增塑 | 含水增塑 | 干态 |
| 可被酶攻击 | i-PhaZ 可直接水解 | 仅 e-PhaZ，仅表面无定形区 |
| 力学 | 柔软 | 脆 |

同一种化学结构，两种材料。化学式相同，聚集态不同——高分子物理的第一课，在 PHA 身上表现得比在任何其他聚合物身上都极端。

### 5.3 由此解开三个"矛盾"

- **矛盾一**："PHA 可生物降解"和"PHA 制品能用好几年"，哪个是真的？都是真的。结晶度是那个开关。胞外解聚酶只能进攻表面的无定形区，所以 PHA 的降解是表面侵蚀（surface erosion），而非本体侵蚀。结晶度越高、比表面积越小，降解越慢。
- **矛盾二**：为什么 PHA 的降解数据这么难复现？因为降解速率是 材料（组成/结晶度/分子量）× 制品形态（厚度/比表面积/表面处理）× 环境（温度/微生物丰度/水活度）的乘积。
- **矛盾三**：为什么我拿到的分子量比文献低？因为提取本身就是降解过程。次氯酸钠氧化提取尤为剧烈；溶剂法相对温和但受温度与时间影响；提取残留的碱金属/碱土金属离子还会在后续熔融加工中继续催化断链。文献报的常是"胞内分子量"或温和实验室提取值，与工业粒料不在同一口径。

## 常见误解纠偏

1. "PHA 是一种塑料。"——PHA 是一类天然聚酯。"塑料"是加工形态，不是化学身份。它的加工窗口只有二三十摄氏度。
2. "PHA 是细菌的代谢废物，所以生产成本天然低。"——恰恰相反。PHA 合成消耗大量碳源和 NADPH，是细菌的主动投资，需要付出还原力代价。
3. "细菌里的 PHA 和粒料里的 PHA 是同一种材料。"——本文主题。凝聚态不同，力学与降解行为都不同。
4. "PHA 就是 PHB。"——PHB（P3HB）只是 PHA 家族中最简单的一员，也恰好是力学性能最差的一员。
5. "PHA 像脂肪一样容易被分解。"——功能类比不能外推到降解行为。结晶态 PHA 的稳定性远高于甘油三酯。
6. "文献说 PHA 分子量上百万，商品怎么只有三四十万？"——不是造假，是口径。胞内分子量 ≠ 提取后分子量 ≠ 加工后分子量。三个数据要分别标注。

## 工程师速查

### 一、看到一份 PHA 数据，先问四个问题

| # | 问题 | 不问的后果 |
|---|---|---|
| 1 | 分子量是哪个环节测的？（胞内/提取后/造粒后/制品） | 数据差 2–3 倍，无法比对 |
| 2 | 力学测试前存放多久、多少度？ | 二次结晶让断裂伸长率掉一个量级 |
| 3 | 提取工艺是什么？残留灰分/金属离子多少？ | 直接决定加工窗口宽窄 |
| 4 | 降解数据的标准 + 环境 + 样件厚度？ | 无三者的"降解天数"是无效信息 |

### 二、四类颗粒蛋白 → 四个可操作的工程杠杆

降解速率 ≈ f(可及的无定形表面积)。降结晶度、减厚度、增比表面 → 加速；反之减速。

## 本期数据边界

- 本文所有颗粒尺寸、颗粒数、PHA 含量数据为典型值区间，随菌株、碳源、培养阶段变化显著，不可作为设计输入。
- "天然态无定形"这一结论建立在完整、含水、新鲜颗粒的前提下。任何脱水、冻干、溶剂接触均会启动结晶。
