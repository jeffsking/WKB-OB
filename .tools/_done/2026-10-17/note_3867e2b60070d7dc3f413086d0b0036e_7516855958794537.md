# PPS Sensor — Principle and Application Introduction

## Positioning 定位

本条是 2026-10-16 与 PPS（触感压力传感）中国代理团队的技术交流纪要（约 24 分钟录音转写 + 英文整理），含两段内容：**① 传感器原理/结构/标定与漂移特性**，**② 应用案例、定价与「贴弹性体做拉伸传感」的可行性判定**。用途：为 REL/芯体与面层相关压力测试（腰腿弹性压力、除臭粉施加均匀性、吸收后回渗压力分布）提供**测量端选型与数据口径**依据。

This is the meeting minutes of a technical exchange with the PPS (tactile pressure sensing) China agent on 2026-10-16, covering sensor principle/structure/calibration, application cases, pricing, and a feasibility verdict on turning the sensor into a stretch sensor by bonding it to an elastomer.

## Summary 摘要

PPS 是 1996 年成立的英国小体量公司（海外研发 20–30 人，多为高校/研究所教授），从机器人手部触觉研究起家，最早产品是记录外科手术过程的单点传感器。中国实体**不是全资子公司而是本地代理**，负责对接客户、收集需求并回传英国团队——响应效率低（邮件可能一个月不回甚至不回）。传感器为**三层薄膜电容结构**（上下导电电极层 + 中间类海绵介电层），受压使微观间隙改变、电容随之变化；因此**任何使其变形的力（垂直压、弯折）都会输出信号**，与人手"只对压力响应"的行为不同。

标定层面：理想电容随压力线性上升，实际曲线弯曲，**所有同类产品都必须做算法补偿**；不同软硬材料对应不同曲线，**每支传感器有专属标定文件**。漂移与蠕变客观存在但在规格带内（部分产品 FSR 精度 < ±3% FS），恒力保持时读数缓慢爬升，1/2/5 分钟窗口内读数可信。**判精度的关键指标是重复性**：同点同力 100 次中有 99 次落在误差带内即判准确；若每次都不一样则算法难以补偿。与电子秤的绝对值差异源于方法论不同（秤是单点集中受力、极稳；PPS 是多点平均+算法标定），**比较必须在同一参照系内（PPS vs PPS）**。

应用侧最有价值的两条：P&G 用其测**纸尿裤腰/腿弹性的平均与最大压力**（判断弹性配置对儿童是否舒适，测试对象为穿尿裤的塑料假人），以及**电子牙刷峰值振动力**；沈飞测飞机舱门开启力阈值，小米/联想测键盘按压力，歌尔（Google 智能手表代工）购自用。关键技术结论：**试图把现有三层传感器贴到 PDMS 上做「拉伸→压力正相关」传感器不可行**——弹性基材不拉伸电极/走线时只有中间层动，且传感器无法区分"拉伸"与"受压"，数据语义崩塌。

## Key Claims 关键论断

- 电容式三层膜结构决定其"对任何形变响应"，因此**不能把弯折信号当作压力信号**解读 —— 支撑页：[[薄膜压力分布传感（Pressure-Sensing Film）]]
- 精度评判应看**重复性**而非单次绝对值；跨设备（PPS vs 电子秤）绝对值对比无意义 —— 支撑页：[[Pressure Sensory Test（压力触感测试）]]
- 纸尿裤腰/腿弹性压力是已验证的商用场景（P&G 用塑料假人测量），可直接对标本库 REL 项目压力测试需求 —— 支撑页：[[PPS（触感压力传感）]]
- 「贴弹性体做拉伸传感」路线在现有材料体系下被供应商明确否定，需重新设计电极/走线可拉伸体系 —— 支撑页：[[PPS 薄膜压力传感应用场景（触感压力分布技术）]]
- 商务结构：中国仅有经销商无独家代理；定制开发须经英国团队，交期与响应是项目风险项
