# 中科一然-公司介绍.pdf

## Positioning 一句话定位

The most **evidence-complete** deodorisation dossier in the library: a Dalian Institute of Chemical Physics (CAS) spin-out that replaces adsorption with **adsorb-then-catalytically-decompose**, and — unusually — backs every claim with a named third-party lab, a standard number, and a CMA/CNAS accreditation.

本页是库内**证据链最完整**的除味资料：中科院大连化物所背景的团队，把「吸附」升级为「**吸附 + 常温催化分解**」，并且罕见地为每条宣称配齐了**机构名 + 标准编号 + CMA/CNAS 资质**。

## Core Material 常温催化材料（沸石）

| 参数 | 值 |
|---|---|
| 外观 | 白色粉末 / 可加工为颗粒 |
| 粒径 | 微米级 |
| 密度 | 0.6–0.7 g/ml |
| 水溶性 | 不溶 |
| 耐温 | **>550 ℃** |
| 安全性 | 无毒无害 |

**机理**：高温高压条件合成的沸石，具高化学/热稳定性、大比表面积、丰富孔径与大量活性位点。先**吸附**快速捕获分子颗粒，再通过**催化**将其彻底分解 —— 与纯吸附材料（活性炭、硅藻土、环糊精）的本质区别在于：**不会饱和后二次释放**。

**与吸附型的对照**：

| 维度 | 常温催化型（本材料） | 物理吸附型（活性炭/硅藻土/环糊精） |
|---|---|---|
| 终点 | 分解为无害小分子 | 转移到孔隙中储存 |
| 饱和风险 | 低（位点可循环） | 高（饱和即失效/脱附） |
| 选择性 | 依赖催化活性位点 | 依赖孔径与极性匹配 |
| 失效判据 | 活性位点中毒（硫/卤素） | 吸附容量耗尽 |

## Critical Reading 批判性读点

1. **「催化」的直接证据缺失**：全篇给的是「去除率」，未给「分解产物」或「循环使用 N 次后去除率保持」的数据。要证明是催化分解而非吸附，最少需要：① 饱和穿透实验；② 脱附/升温后是否释放原分子；③ 多次循环后活性保持率。
2. **材料本体参数缺失**：只给密度与耐温，未给**比表面积、孔径分布、活性位点密度、Si/Al 比**——这些才是催化材料可比性的基础。
3. **耐温 >550 ℃ 的好消息与坏消息**：好消息是热稳定性远超加工温度（纺粘 230–260 ℃）；坏消息是**这条参数对「常温催化」不构成证据**——耐高温不等于常温有活性。
4. **抗菌数据跨越多个方法**（GB/T 20944.3、GB 21551.2、ISO 18184），抑菌率区间宽（95%–99.99%），引用时必须标明方法与对应值，禁止笼统写「抑菌率 99%」。
