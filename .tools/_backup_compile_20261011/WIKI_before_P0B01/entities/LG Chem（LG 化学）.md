- **产能与份额（2023 口径）**：**25+ 万吨/年，全球份额 ~8%**，标签为「规模扩张 / 快速扩张」；对华供应为「进口 + 本地」。
- **生物基路线（关键）**：**LG 化学 + ADM 联合开发生物基丙烯酸 SAP**，状态为「开发中」——即**生物基 SAP 五路线中的第 ⑤ 条（生物基单体路线）的唯一产业方**。
- **该路线的特性（与可降解路线区分）**：生物基丙烯酸 SAP **性能与传统 SAP 相当、并不降解**；成本溢价仅 **+10–20%**，是五条生物基路线中**溢价最低**者。
- **供应风险 [I]**：生物基丙烯酸目前**仅此一个联合开发项目**，属单点来源；若生物基路线要上量，须评估 ADM 原料端与 LG 聚合端的双重依赖。
