# Qiansebian（千色变新材料）

## 基本盘 Basics

| 项目 Item | 内容 Content |
|---|---|
| 主营 | 变色油墨及**变色颜料（微胶囊）源头厂家**；温变、光变、湿变微胶囊颜料及油墨 |
| 主体 | 东莞市千色变新材料有限公司 / 深圳市千色变新材料科技有限公司 |
| 产地 / 基地 | 工厂位于**东莞**（另有深圳主体） |
| 成立 / 规模 | **2009 年创立，注册资金 1500 万** |
| 产能 | **自主工厂，月产能可达几十至上百吨**（公开规模估算）；支持**水性、油性、UV 等多种体系** |
| 角色 | 变色油墨供应基盘中的**国内主力**梯队——国内最大综合性生产厂商，产品线全、性价比高，主攻中端市场 |

## 合作与供货历史 Cooperation History

- **2026-06-12（[[Hygiene Chromic Ink Supplier Landscape（卫生护理变色油墨供应商调研 · 2026-06-12）]]）**：被列为全球卫生护理变色油墨 7 家核心供应商之一，属**国内主力**梯队；主要客户为国内头部纸尿裤代工厂（福建、广东、浙江区域）与品牌商，**部分出口东南亚**。
