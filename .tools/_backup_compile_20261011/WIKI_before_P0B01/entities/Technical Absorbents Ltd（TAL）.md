# Technical Absorbents Ltd（TAL）

> 一句话定位：**SAF™（Super Absorbent Fibre，超吸水性纤维）的开发者与专利持有者**，也是**全球唯一全系列 SAF 商业供应方**——这既是它的技术地位，也是本库对 SAF 路线最大的**单一来源风险**。（中文：技术上独家，供应上也独家。）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | **SAF™ 纤维**（7 种牌号）、**标准 Airlaid 芯材**（11 种现货规格）、**可水洗面料**（6 种） |
| 产地 / 基地 | 英国 **Grimsby（North East Lincolnshire）**——**单一生产基地** |
| 工艺 | 丙烯酸衍生 → **专有聚合物共混** → 水基工艺挤出 → 热风干燥 → 固化交联 → 控制吸收度；源文称已 **20+ 年工业化验证** |
| 产品线完整度 | 纤维 6 mm / 52 mm / 80 mm 三系列；Airlaid 芯材 SAF 含量最高 **60%**、克重 **70–1000 gsm**、幅宽 0.6 m；可水洗面料 SAF 含量最高 **30%**、**190–450 gsm**、幅宽最大 1.95 m |
| 认证 | **ISO 认证、UK AEO**；**FDA 批准食品接触、EFSA 批准**（源文） |
| 角色 | 候选（概念验证与取样对象；非库内在用供应方） |

## 关键事实（均注日期）

- **2026-07-08（评估引用）**：技术成熟度与产品线完整度被评★★★★★；**产能规模 ★★★**（特种纤维，产能远小于 SAP 主流供应商）、**供应稳定性 ★★★**（单一产区，物流风险）、**价格竞争力 ★★**（特种产品价格劣势）。
