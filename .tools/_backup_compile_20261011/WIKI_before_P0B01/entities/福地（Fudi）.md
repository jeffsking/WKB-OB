- **2026-09-11（试产准备会）**：面层配方中所有**三叶形（Trilobal）3D Bico PE/PET** 均标注来自福地——上层 10%、下层 50%（其余 2D/4D Bico 由延江提供）。详见 [[Coco V6 试产原料清单（Raw material list v3.0）]]。
- **2026-09-18（中文汇报稿）**：
  - **OI-25 Liner Nonwoven** 的供应分工记为"Yanjan（基材/2D/4D ES）、**Fudi（三叶）**"；
  - **OI-02 异形纤维**（Excel 新编号）的供应方记为"江南高纤、**Fudi**、Emon、Lenzing"，产品方向为 Y 形/哑铃形/**三叶形**（bico PE/PET 及 mono PET）；
  - 出行计划中记有"泉州出差（Minrui kick off 巴西项目，**顺访福地、起风**）"，即福地位于**泉州**一带。详见 [[OI项目清单与优先级]]。

**异形/新结构纤维路线（本批新增）：**

| 结构 | 状态 | 关键数据 |
| --- | --- | --- |
| **偏心** | 已稳定量产 | 2.0 / 2.5 / 2.8 D；同克重下**厚度更大、反渗更小、手感更好** |
| **扁平** | 现 3.0 D（原目标 1.0 D） | 初衷模拟动物毛发（扁、丝滑）→ 实际**触感偏棉感、顺滑度未达预期** → 转向用**更大比表面积**做导流层扩散 |
| **中空** | 开发中（与扁平结合是下一步） | 中空度 **7–8%**（国内普遍水平），目标 **15%**（日系可达 15%） |
| **三叶（trilobal）** | 实验线已出约 **200 kg**（3.0 D 强亲水），**Q4 推出** | 布上表现**未测** |
| 纤度扩展 | 主力 0.6–3.0 D，最近开 **5.0 D**，实验线规划 **12 D** | **从细旦往粗旦扩**（品牌方希望一厂多品类） |
| 亲水/拒水比例 | 约 **4:6 或 6:4** [待验证] | 超细旦（0.6/0.8）聚焦**拒水**端（亲水端反渗太大） |
| 超干爽系列反渗 | 扩散型多亲约 **3.6** → 弱亲约 **0.26** → 超干爽约 **0** | **偏科**：前三次（尤其第三次）高于常规 |
| 超柔 PE | 软化点/熔点更低 → 下游烘箱可**下调约 2 ℃** | 触感更柔 |

**无锑（Sb-free）能力（本批新增）**：切片端恒逸、恒力均可供无锑切片并已上机生产过；切换方式有停线清仓（无风险）与在线排料（有残留风险）两种；现有客户已按 **30 余吨/车**发货，报告送 GALAB（检出限约 0.1，对比 SGS 约 20 mg）。详见 [[Antimony-Free PET Fibre（无锑 PET 纤维）]]。

**研发与打样能力（本批新增）：**

- 实验线：独立入料系统、独立螺杆挤压、独立纺丝、独立卷绕 + 后纺配套 + 小梳理机（幅宽约 **30 cm**，仅内部比对用）。
- 打样最小量：不动前纺（只动后纺上油/卷曲）**200–300 kg**；动前纺设备 **600 kg–1 吨**。实验线后纺 **5 吨/天**，大线 **60 吨/天**。
- 规划中：从塑料米**直接做到成品纸尿裤/卫生巾**的实验大线（本方表示"有这个意向和能力肯定最好"）。

**本方提出的合作前提（本批新增，重要）：**

- **只给纤维不够** —— 本方明确希望纤维厂具备**小型成布能力**，直接给**布卷**以便换料做**单变量验证**。
- 成品数据参考价值有限：各品牌**结构不同**（面层/导流层/芯体），本方仍需自己测材料。
- 单一异形纤维**无法承载全部功能需求**，最终必须走到**混纺**（含上下层比例）的方案比对。
