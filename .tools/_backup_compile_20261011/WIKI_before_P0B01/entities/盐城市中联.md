# 盐城市中联（盐城市中联复合纤维有限公司）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | 双组份复合纤维：PE/PP、PE/PET、**COPET/PET**、PA/PET |
| 产地 / 基地 | 江苏盐城盐都区龙冈镇鞍湖社区节能装备产业园（占地约 23,000 ㎡、厂房 8,000 ㎡） |
| 产能 | **两条复合生产线**（关键设备从美/日进口），年生产能力 **6,000 吨** |
| 规格 | 纤度 1D–25D，切断长度 3 mm–102 mm；本白/增白/有色短纤及束状；可赋高分散、强亲水、抗菌、无味等特殊性能 |
| 资质 | 2005 年 ISO 9001:2000；建有完备检验中心（原辅料/半成品/成品全检） |
| 在本库中的角色 | **CoPET/PET 双组份短纤的 Tier A 战略目标**——被两份独立采购文档明确点名为"真正该找的成品商" |

## 合作与供货历史

- **2001-05成立**；2012 年搬迁至现址（总投资 3,000 余万元）。
- **2026-07（采购蓝图）**：在 [[CoPET 采购蓝图：成本拆解与供应分层]] 的 Layer A 诊断中被列为 **「Strategic Target（战略目标）」**——具备深厚技术专长、有明确的 CoPET/PET 产线，被两家世界 500 强指定为合格供应商。
- **2026-07（ADL 转型蓝图）**：在 [[CoPET ADL 转型蓝图（皮层聚合物替代评估）]] 供应层级图中列入 **Tier A（真正供应 CoPET ADL 短切纤维的 5 家之一）**。
- **2026-07-09（市场与供应商）**：在供应链分层中归入 **A 层（CoPET/PET 双组份短纤成品商，真正采购目标）**；应用覆盖卫生材料、清洁用品、皮革基布、电池隔板、绝缘材料。详见 [[CoPET 双组份热粘合纤维市场与供应商（供应链分层·明细表）]]。
- **2026-07-09（细分能力核实）**：细旦（旦数）能力标「待确认」、无锑牌号「未查到」，**须商务函询书面确认**。详见 [[CoPET 双组份热粘合纤维市场与供应商（供应链分层·文档版）]]。
