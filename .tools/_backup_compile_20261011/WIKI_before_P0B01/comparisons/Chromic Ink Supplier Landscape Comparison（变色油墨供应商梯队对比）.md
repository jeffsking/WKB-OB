## 各自适用场景 Where Each Tier Fits

- **国际标杆（CTI / 松井 / Intellego）**：需要**完整行业测试报告与技术确定性**的顶级卫品品牌项目；CTI 是唯一覆盖湿敏且明确用于纸尿裤湿显的全品类标杆，且已在 P&G、K-C 供应链中。
- **国内主力（千色变）**：**中端量产与成本敏感项目**，产品线全、月产能数十至上百吨、多体系可选，适合国内头部代工厂规模化切换。
- **区域备选（乐迪 / 科维尔）**：**特定卫品湿显场景的国产替代**；科维尔的独特价值在于可与热熔胶配套供应，减少供应商接口。
- **区域补充（格林春天）**：福建、广东区域的水性油墨定制需求（如背膜湿敏/温敏特性），适合小批量与区域配套。

## 结论 Conclusion

变色油墨的供应基盘呈**"技术确定性—成本—响应速度"的三向取舍**：国际标杆提供技术与测试报告但成本最高且产能跨区域，国内主力以性价比与可见产能承接中端量产，区域厂商补齐特定工艺（水性、胶墨配套）与区域响应；选型的第一筛选条件是**是否覆盖湿敏（hydro-chromic）**这一纸尿裤湿显专用品类，第二才是梯队与成本。
