# 可降解皮芯架构对比（PPC-PBAT 皮 × 四芯层）

> 对比对象：**PPC/PBAT 皮层**（参考 LX-T55P25T20）固定不变，芯层在 **PET / PLA / PGA / PLGA** 四者中选择；工艺为皮芯型双组分短纤 → 梳理成网 → 热风加固（120–145 °C，最佳 120–140 °C）。English: a fixed PPC/PBAT sheath evaluated against four core polymers for biodegradable through-air nonwovens.

## 皮层通用风险（四芯共担）Shared sheath risks

| # | Risk 风险 | Threshold / 验证方法 门槛与验证 |
|---|---|---|
| 1 | 粘合点内聚强度不足（PPC-P 相增脆，10.6 MPa / 162% vs 纯 PBAT >600%） | CD 拉伸对标 **9.0 N/50 mm**；小试比对剥离强度与粘结点 SEM |
| 2 | 维卡 60.2 °C → 夏季集装箱 50–60 °C 皮层先软、布卷层间粘连 | **60 °C × 72 h** 卷材模拟验证 |
| 3 | 亲水整理失效（表面化学由聚烯烃换为聚酯族） | 聚酯表面润湿持久性：多次穿透后接触角 |
| 4 | PPC 无定形、无清晰熔点，摊宽熔融窗口 | PPC 皮内占比 **≤20%** |
| 5 | 热风设定温度与实际温度偏差 | 逐线实测 ΔT，找「强度够用的最低加工温度」 |

## 各自适用场景

- **PET 芯**：工艺最稳、成本最低、供应最成熟；但芯层不降解使环保叙事打折，定位为**对照/备份**。
- **PLA 芯**：唯一可通过旋光比**定制 ΔTm** 的芯层，货架期 12–24 月安全、纤维级牌号现成 → **主线量产方案**；短板是降解需工业堆肥条件。
- **PGA 芯**：以「海水 28 天 75.3%」提供最强差异化叙事 → **高端/出口线**；前置条件是货架期加速老化验证与纤维级牌号开发。
- **PLGA 梯度**：降解速率连续可调 → **预研杠杆**，用于在 PLA 芯上微调降解速度，工艺开发量最大。

## 结论

可降解热风无纺布的架构决策，本质是**用 ΔTm 换工艺可行性、用货架期换降解叙事**：PLA 芯是唯一同时满足「工艺可调 + 货架期安全 + 供应现成」的方案，故为量产主线；PGA 芯提供最强叙事但须先过货架期关；PET 芯只作备份。真正决定成败的往往不是芯层，而是**皮层的粘合点强度（9.0 N/50 mm 门槛）与维卡 60.2 °C 的仓储边界**。
