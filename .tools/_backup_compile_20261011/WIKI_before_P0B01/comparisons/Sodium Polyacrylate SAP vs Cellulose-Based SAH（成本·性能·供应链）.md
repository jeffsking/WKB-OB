# Sodium Polyacrylate SAP vs Cellulose-Based SAH（成本·性能·供应链）

## 对比维度表 Comparison matrix

> 必含「成本 Cost」与「供应链风险 Supply chain risk」两列 (Required columns per AGENTS.md §2.4)。

| Dimension 维度 | Sodium Polyacrylate SAP 聚丙烯酸钠系 | Cellulose-Based SAH 纤维素基超吸水凝胶 | Source 依据 |
|---|---|---|---|
| **去离子水中的吸收 In DI water** | 明显占优：**593 g/g**（38 ℃）；另一实验中**市售材料约 243–245 g/g**（干燥后复溶） | **164 g/g**（CMC–1.5 % CA，38 ℃）；另一体系 ESR **516–756 g/g**（合成态，非干燥复溶） | [[Citric Acid Crosslinked Cellulose Superabsorbent Hydrogels (CEJ 2025)]]；[[Quaternized Tunicate Cellulose Nanocrystal Superabsorbent Hydrogels (Cellulose 2021)]] |
| **盐水 / 合成尿中的吸收 In saline / synthetic urine** | **93 g/g**（0.9 % 盐水，38 ℃）；**85 g/g**（室温）；**合成尿约 53 g/g**（市售材料） | **110 g/g**（0.9 % 盐水，38 ℃）；**92 g/g**（室温）；**合成尿 79–123 g/g** | 同上两源 |
| **排序是否反转** | 去离子水中**胜出**；盐水/合成尿中**被反超**（本对比的核心发现） | 去离子水中**落后**；盐水/合成尿中**反超** | 同上两源 |
| **加压吸收 AUL / 载荷敏感** | 加压后吸收 **108.9 g/g（DI）/ 27.9 g/g（盐水）**；**载荷引起的损失 81.6 %** | 加压后 **99.9 g/g（DI）/ 47.0 g/g（盐水）**；**载荷引起损失仅 32–39 %**（CMC:HEC 共混更差：63.6 % / 82.4 %） | [[Citric Acid Crosslinked Cellulose Superabsorbent Hydrogels (CEJ 2025)]] |
| **盐浓度与离子价敏感性** | 属聚丙烯酸体系的既有特征，本库两源未给同口径对照曲线 → `[待验证]` | 随 NaCl 浓度上升单调下降，**浓度超过约 0.024 g/g 后走平**（静电屏蔽饱和）；**Ca²⁺ 抑制更强，Fe³⁺ 最剧烈**（约 750 → 约 20 g/g，在 0→0.01 g/g 区间） | [[Quaternized Tunicate Cellulose Nanocrystal Superabsorbent Hydrogels (Cellulose 2021)]] |
| **力学强度（凝胶态）** | 本库两源未给同口径数值 → `[待验证]` | 压缩强度 **1.9 → 5.4 kPa**（随 Q-TCNC 含量 0 → 0.3 wt% 上升）；有效交联密度 **0.122 → 0.443 mol/L** | 同上 |
| **环境归宿 End-of-life** | 石油基；原文援引 US EPA：单片一次性尿裤在填埋场可需长达 **450 年**分解 | **堆肥条件下 7 周降解 72 %**（ASTM D5988 改良法，58 ℃ 高温条件）；**细胞毒性试验 >80 % 细胞存活率**（NIH3T3，间接接触法） | [[Citric Acid Crosslinked Cellulose Superabsorbent Hydrogels (CEJ 2025)]] |
| **成本 Cost** | 成熟工业品，是本库的**成本基准**；两源**均未给出单价** | 两源**均未给出单价或量产成本 → `[待验证]`**；已知的可变项为交联剂（柠檬酸 1.5 wt%，或 EPI 0.1 mL/g）与纳米填料（Q-TCNC 0.12–0.3 wt%） | 同上 |
| **供应链风险 Supply chain risk** | ①供应基数成熟、牌号多、可多源；②石油基，**ESG/可降解法规是长期负面因素**；③本库已有专门牌号与供应商格局记录 | ①原料可再生（纤维素/CMC/海鞘纳米晶体），**但均为实验室自制体系**，无可量产货源；②**交联剂合规性是硬约束**：柠檬酸路线相对友好，而 **EPI（环氧氯丙烷）属需管控交联剂**，残留与卫生用品法规符合性本库无来源 → `[待验证]`；③纳米填料（Q-TCNCs）目前无规模化供应 → `[待验证]` | 同上两源 + 本页 manual_review |

## Evidence Update 证据更新（2026-09-29）

新增第三个来源 —— **KR 10-2205294 B1**（[[KR 10-2205294 B1（氧化淀粉-CMC-球形纳米纤维素高吸水体·Asiananotech）]]，[[아시아나노텍 주식회사（Asiananotech）]]）。它是本对比中**第一个"生物基体系在盐水工况下自报超过合成 SAP"的专利来源**，也是第一个**不使用外加化学交联剂**的生物基体系：

> ⚠️ **口径警告（2026-09-29，重要）**：KR 10-2205294 的数值由 **EPA 改良茶袋法**测得，与 [[Citric Acid Crosslinked Cellulose Superabsorbent Hydrogels (CEJ 2025)]]、[[Quaternized Tunicate Cellulose Nanocrystal Superabsorbent Hydrogels (Cellulose 2021)]] 的实验条件**不同，三个来源的数字不可放在同一行比较**。本页上表**刻意不与主表合并**，仅作独立记录。另：该专利的对照 SAP **仅一款且未标注牌号/规格**，故"超过 SAP"的**可比性有限**。

**对主表结论的影响**：不构成修正 —— 主表"盐水/合成尿里纤维素基反超"的方向性结论**不变**，KR 10-2205294 只是从**专利侧**给出第二个独立证据，并补充了"无外加交联剂即可成网"这一工艺路径。新增概念页 [[Starch-CMC Acetal Crosslinked Superabsorbent（淀粉-CMC 缩醛交联高吸水体）]]。

## 各自适用场景 Where each wins

- **[[SAP（高吸水树脂）]]（Sodium polyacrylate 聚丙烯酸钠系）**：在**去离子水/低离子强度**条件下吸收量最高，且供应基数成熟、多源可得；仍是**当前量产产品的基准**。在需要极限吸收量的场景（而非盐水工况）下胜出。
- **[[Biodegradable SAP（可降解高吸水树脂）]]（Cellulose-based SAH 纤维素基）**：在**盐水 / 合成尿（即真实使用工况）**与**加压条件**下的相对表现更好，且有**可堆肥降解与细胞相容性**的实测支撑；适用于**对可持续性有硬指标**的产品线。代价是：去离子水中的绝对吸收量明显落后、货源与量产成熟度未验证。

## 结论 Conclusion

一句话结论 One-sentence conclusion：**"谁更强"完全取决于介质——去离子水里聚丙烯酸钠约 3.6 倍领先，盐水/合成尿里纤维素基反超（110 vs 93 g/g；79–123 vs 53 g/g），且加压下损失更小（32–39 % vs 81.6 %）；但在补齐量产成本、可量产货源与交联剂合规三条之前，本库只支持"盐水工况优先"这一方向性结论，不支持任何替代判断。**

> 🔴 **manual_review（2026-09-29）**：
> - **成本列缺失实际数据**：两体系相对单价本库无来源，已标 `[待验证]`，**不得由 AI 估算**。
> - **合规缺口**：纤维素路线的两条具体配方使用了**两种不同交联剂**——柠檬酸（CA，1.5 wt%）与 **EPI（环氧氯丙烷，0.1 mL/g）**；后者在卫生用品中的残留限值与法规符合性本库无来源 → `[待验证]`，落地前须由法规/材料方确认。
> - **AI 不得据此下"可直接替代现有 SAP"的结论**：两源均为实验室尺度论文，非商业成熟度或供货能力证明（转化到量产须独立评估成本、克重、卫生合规与单体残留）。
