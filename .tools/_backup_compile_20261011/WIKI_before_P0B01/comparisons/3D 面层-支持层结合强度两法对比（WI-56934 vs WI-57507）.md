# 3D 面层-支持层结合强度两法对比（WI-56934 vs WI-57507）

> 两条南京厂 WI **测的是同一个界面**（3D / topical liner ↔ supporting layer），却给出**两套夹具、速度、试样与环境口径**——**同一界面的 gf 值不可跨 WI 比较**。（Same interface, two WI methods with different gauge, speed, specimen and conditioning — values not comparable.）

## 各自适用场景

- **[[面层粘合强度测试方法.pdf]]（WI-56934）**：针对 **CIDER 产品的在线复合**——试样只取 3D 压花区、排除侧封边干扰，适合评价**复合工序本身**。
- **[[Topical liner Supporting layer Embossing pressure.pdf]]（WI-57507）**：针对**压纹压合**，在恒温恒湿下用小试样测，适合**图案/工艺切换**的强度验收。

## 结论

**同一个界面出现两条厂内方法，说明厂内是按"工序"而非按"界面"建方法的**：在线复合归 WI-56934，压花压合归 WI-57507。**引用时必须写清 WI 号与试样尺寸**，否则两个 gf 值会被误当成同一指标的趋势数据。
