# CoPET-PET 与 PE-PET 皮芯纤维对比（ADL 性能·成本·供应链）

> 对比对象：两类卫材热风无纺布用皮芯双组分纤维——**CoPET/PET（TT 型，聚酯同源皮）** 与 **PE/PET（ET 型，聚烯烃皮，即传统 ES 体系）**。回答「换皮层到底换来什么、代价是什么、该换到什么程度」。
> 构型定义与 PE 系皮芯的机理见 [[皮芯复合纤维]]；CoPET 本身见 [[CoPET（低熔点共聚酯）]]。数据基准 2026 年 7 月；无来源项标 `[待验证]`。

## 各自适用场景

- **[[CoPET（低熔点共聚酯）]] / CoPET/PET（TT 型）**：干爽与重复冲击性能优先的下层 ADL；薄芯体 / 高 SAP 设计（需要更好的横向铺展以缓解局部凝胶阻塞）；需要"全聚酯单一材质"叙事的场景。**代价是工艺必须重调 + 价格带上沿。**
- **[[皮芯复合纤维]] / PE/PET（ET 型）**：触感柔软为营销主诉的贴面层；降本导向的产品；希望零烘箱改造、高速线即插即用；以及成熟卫材认证体系优先的场景。**代价是重复冲击下更依赖亲水整理剂的存留。**

## 结论

**两者制造成本几乎相同（差 2.5%），差别在"钱花在哪一环"和"要不要改工艺"**——CoPET/PET 赢在同材质界面带来的加工节省与重复干爽，输在手感、即插即用性与价格带上沿；因此最优解不是整层替换，而是**分层选材（下层 CoPET + 贴面保留 PE/PET）+ 阶梯共混（先 30% CoPET）**，并把**厚度回复**设为推进全量的不可让步门槛。
