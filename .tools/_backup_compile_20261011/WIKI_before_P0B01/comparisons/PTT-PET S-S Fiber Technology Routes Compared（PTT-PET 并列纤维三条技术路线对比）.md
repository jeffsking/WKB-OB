# PTT-PET S-S Fiber Technology Routes Compared（PTT-PET 并列纤维三条技术路线对比）

> 一句话对比：同样是"PTT/PET 并列复合弹性纤维"，**上游 PTT 从哪里来**决定了三件完全不同的事——**IP 归属、长期成本曲线、以及供应中断时的可替代性**。（中文：牌号可以一样，路线不能一样——比价前先比路线。）

## 主对比表 Comparison Matrix

| Dimension 维度 | **Route A 全生物基一体化** | **Route B Sorona® 授权合作** | **Route C 外购树脂 + S-S 纺丝** |
|---|---|---|---|
| **Representative 代表供应商** | **Shenghong（盛虹）** | **Fangyuan（方圆）** | **Sanlian（三联）/ Tianmei（天美）/ Longjie（龙杰）** |
| **Upstream 上游结构** | 自产生物基 PDO（废甘油发酵）→ 自聚合 PTT → S-S 纺丝 | DuPont Sorona® 授权 PDO/PTT 树脂 → 纺丝 | 市场采购 PTT 树脂（Shell / Sorona / 国产多源）→ 纺丝 |
| **IP 归属** | **完整自有**（国际标准制定者） | 授权使用，存在 **IP 约束** | 无上游 IP |
| **成本 成本** | **长期 COGS 最低**；但**前期 CAPEX 最高**、运营复杂、**规模经济依赖** | **需付授权费**（royalty/license fees）；研发负担低、树脂质量稳定 | 门槛低、采购灵活；但**成本随 PTT 商品价格波动**、**存在利润压缩风险** |
| **供应链风险 供应链风险** | 供应安全度高；但**若单一来源则选择受限（sole-source 风险）**；生物基原料价格波动 | **对单一外方来源依赖**（DuPont）；灵活性低 | 树脂**多源可得**但**质量波动**；**无上游控制**；随行就市 |
| **ESG / 生物基** | ✅ 唯一全链可追溯（甘油→纤维）；碳优势 | 部分生物基（Sorona 生物基路线） | 取决于所购树脂牌号，**不可控** |
| **典型性能（报告值）** | 回弹 ≥95%；卷曲收缩 ≥35%；强度 3.0–4.0 cN/tex | Somalor® PTT 纤维；国内最早（约 2000 起） | S400：回弹 ≥95%、卷曲 >30%；TM800：回弹 >95%、规格 50D–300D |
| **适用场景** | 大批量卫材/弹性无纺布；高端研发伙伴；**ESG/生物基含量要求（唯一推荐）** | 看重树脂质量稳定性与品牌背书的场合 | 成本优先大批量；规格齐全、交期快的订单 |

## 成本与供应链风险：一句话读法

| Route | 成本一句话 | 供应链风险一句话 |
|---|---|---|
| A | **贵在前期、赢在长期**——CAPEX 与运营复杂度换来最低长期 COGS | **自己掌握上游**，但客户侧会形成**单一来源依赖** |
| B | **为确定性与品牌付费**——授权费换树脂质量与技术支持 | **命门在外方**——单一境外来源 + IP 约束 |
| C | **轻资产、随行就市**——门槛低但毛利薄 | **多源却无控制**——质量波动 + 无上游议价力 |

> ⚠️ **口径警示（2026-09-29）**：本表**成本列全部为方向性表述**（"最低 COGS""授权费""随商品价波动"），源文**未提供任何绝对价格或区间**。因此三路线**不可据此做成本排序**，只能做**成本结构定性判断**。

## 选型含义 What it means for sourcing

1. **不要只比牌号**：T400 等价物（TM800 / S400 / 各家 T400）背后的上游结构分属三条路线，**同牌号比价会掩盖供应风险差异**。
2. **ESG 诉求会强制收敛到 Route A**：若产品宣称需要生物基含量与可追溯，源文给出的国内选项**只有盛虹**（备选方圆走 Sorona 授权生物基路线）。
3. **成本优先会落到 Route C 或 Tier-2**：天美与古纤道等靠价格与交期竞争，代价是**上游不可控**与**规模化一致性风险**（源文列为天美的 Threats）。
4. **性能边界独立于路线**：SSY（PET/PET 改性并列，非真正 PTT/PET）回弹仅 70–85%、卷曲 15–25%，**显著低于 T400 系**，不属同一选型池——见 [[并列复合自卷曲纤维]]。
