# SAF vs SAP（超吸水纤维 vs 高吸水树脂）

> 一句话对比：**SAF 不靠"吸得更多"赢，而靠"吸得更快、不堵、不跑、不扬尘"赢**——但它在这四项上赢的代价是**成本约 3–5 倍、供应实际只剩一家**。（中文：结构性优势 vs 结构性代价。）

## 各自适用场景

- **[[Super Absorbent Fibre（超吸水纤维 SAF）]]**：
  - **最佳场景**：**可重复使用尿裤 / 医用敷料**（源文适配度最高）——因为 **SAP 无法提供可水洗方案**；其次是**女性卫生巾**（薄型芯体 + 快吸 + 柔软，单片 SAP 用量小使成本放大有限）。
  - **卫材芯体的正确用法**：**与 SAP 协同而非替代**——上层/导流层用 SAF 快吸导液，下层/储液层用 SAP 保容量；源文中期推荐起始配比为 **SAF 20–30% 替代 SAP**，并采用**三层梯度芯体**。
  - **不适合**：经济型纸尿裤的全量替代（成本账算不过）。

- **[[SAP（高吸水树脂）]]**：
  - **最佳场景**：一切以**容量与成本**为第一约束的主流芯体（纸尿裤、成人失禁的主力层）。
  - **结构位置**：在 SAF+SAP 混合设计中担当**储液底层**，用其高 CRC/AUL 抵消 SAF 的容量与加压数据缺口。
  - **代价**：必须接受凝胶阻塞、迁移与粉尘三项结构性问题——这三点是 SAF 的存在理由。

## 结论

> **SAF 的竞争力不在容量，而在四件 SAP 做不到的事：不堵、不跑、不扬尘、可水洗。** 因此正确的短期策略是 **SAP + SAF 协同**（SAF 做导流与快吸，SAP 做储液），而不是用 SAF 全量替代 SAP——**因为替代后成本增幅约 87–105%，而容量与加压保液的数据缺口至今没有填**。

> ⚠️ **口径警示（2026-09-29）**：**"SAF 盐水自由溶胀 47–57 g/g"与"SAP CRC 32–38 g/g"不可直接比较**——源文明确指出 **CRC 方法是为 SAP 设计的，SAF 可能无法完全等效**。因此本表**不因自由溶胀数值更高而判定 SAF 容量更优**，该判断为 `[待验证]`。

> 🔴 **manual_review（2026-09-29）**：成本列（3–5× 吨价、87–105% 增幅、2.05× / 1.87× 方案对比）均为**行业对标估算**，源文自陈"SAF 无公开报价，实际价格需向 TAL 直接询价"；本页**只记倍数与增幅量级，不落价格表**。供应链风险列中"全球仅 TAL 一家"为源文判断，**Main S.p.A. 的 SAF 来源属推断未确认**。
