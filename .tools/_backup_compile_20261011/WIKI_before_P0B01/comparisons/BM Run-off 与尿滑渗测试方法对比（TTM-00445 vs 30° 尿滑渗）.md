# BM Run-off 与尿滑渗测试方法对比（TTM-00445 vs 30° 尿滑渗）

> **倾角同为 30°，但液体从"牛顿流体盐水"换成"非牛顿流体便液模拟液"，注液量从 60–180 mL 降到 11 mL，读数从"只量滑落量"变成"铺展尺寸 + 滑落质量"**——两者**不是同一个实验**。（Same 30° tilt, but different fluid class, insult volume and outputs — not the same experiment.）

## 各自适用场景

- **[[TTM-00445 BM Run-off.docx]]**：回答"**稀便会不会顺着产品表面跑掉、铺开多大**"——因为便液黏度高、容量小，**铺展尺寸（CD/MD）比滑落质量更能反映污染范围**。
- **[[GB-T28004-2011 滑渗.doc]] / [[TTM-00279产品30°滑渗测试.docx]]**：回答"**尿液冲击下有没有被及时吸收**"——容量大、黏度低，主要矛盾是吸收速度。

## 结论

**30° 这个数字是两条路线唯一的共同点，也是最容易被误用的地方**。BM 与尿在液体类别、注液量、注液方式与输出指标上全面不同，**"滑渗量"三个字在 BM 与尿语境下指的不是同一个量**；跨液体类型比较时必须声明模拟液配比、注液量与读数定义。
