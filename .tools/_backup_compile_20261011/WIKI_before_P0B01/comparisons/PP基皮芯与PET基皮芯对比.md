# PP 基皮芯与 PET 基皮芯对比（低熔点组分路线之争）

> 对比对象：三种主流皮芯体系的低熔点皮层方案。回答「LMP-PP 项目为何选 PP 同源皮层，而非沿用成熟的 PE 皮或共聚酯皮」。
> 数字全部溯源至源摘要页；无来源项标 `[待验证]`。

## 主对比表

| 维度 | PE/PP 皮芯（ES 纤维） | PP/PP 皮芯（EPC，方案 C） | 低熔点共聚酯皮芯（PET 系） |
|---|---|---|---|
| **皮层熔点** | PE ≈130°C（低粘合点型 EA/EAC 110°C、EKC 105°C） | ≈140°C（区间 140–155°C） | 110–160°C |
| **芯层熔点** | PP ≈165°C | 常规 PP ≈165°C | 常规 PET |
| **皮芯温差窗口** | 约 35–60°C | 约 10–25°C（**窗口最窄**） | 视牌号而定 |
| **粘合兼容性** | 与 PP 骨架**异源**，界面相容性一般 | 与 PP 骨架**化学同源**，界面相容性最好 | 与 PET 骨架同源 |
| **回收性** | 含 PE 皮，全 PP 回收受限 | **整根纤维 100% 聚丙烯**，利于全 PP 无纺布路线 | PET 体系回收 |
| **工艺成熟度** | **最成熟**（热风棉标准构造） | 中（有 EPC 商业化产品，但国内供应薄弱） | 成熟（已建成 5 万吨级国产产线） |
| **成本** | 低（但 Bico 本身是降本对象） | 低-中；结构设计可放宽树脂熔点要求（皮层比例降至 30:70 甚至 10:90） | 中（国产化后下降） |
| **供应链风险** | PE 皮与 PP 芯双料供应，且 Bico 的 PE 皮工艺麻烦（表面难处理、上色/Kirigami 受限） | **国内纤维级低熔点 PP 粒子无公开牌号**，树脂端需自研；纺丝端验证伙伴已有（仪征化纤、德福伦） | 国产产线已通，供应风险低；但属 PET 体系，与 PP 骨架异源 |
| **关键工艺风险** | — | 二甲苯可溶分失控（热风线 100–180°C 运行，皮层发黏则整线停）；热定型窗口仅十几度 | 高含量 IPA 共聚路线带来结晶低、粘接差、干燥易板结等连锁问题 |

## 关键差异解读

1. **方案 C 的核心卖点是「同源 + 可回收」**——PP/PP 皮芯的界面相容性最好，且整根纤维 100% 聚丙烯，符合全 PP 无纺布与回收趋势；代价是熔点窗口最窄、可溶分控制最难。
2. **PE 皮的优势只是「便宜且成熟」**——而 Bico 恰是 TBCW 降本要替代的对象（见 [[低温PP纺粘与TBCW低成本方案]]），这构成了本项目的外部驱动力。
3. **PET 基皮芯是「别人已经走通的路」**——东华大学等已完成低熔点共聚酯皮芯项目并建 5 万吨产线，说明**低熔点组分 + 皮芯结构**这条技术范式是成立的；方案 C 是把它移植到 PP 体系。
4. **结构设计给树脂减负**——降低皮层比例（30:70 甚至 10:90）可把皮层熔点要求从「死磕 130°C」放宽到 145–150°C，只要芯层 165°C 留足窗口。

## 结论

- **若目标是「降本 + 摆脱 Bico」** → PP/PP 皮芯（方案 C）方向正确，但须攻克可溶分与定型窗口两大工艺风险。
- **若目标是「最快验证皮芯路线可行性」** → 可先借道已有的 PE 皮或共聚酯皮体系做验证，再把结论迁移到 PP 体系。
- ⚠️ **库内缺口**：PP/PP 皮芯的实际纺丝成功率与成本数据、各体系在热风线的手感对比，均标 `[待验证]`。
