## 各自适用场景 Where Each Sits

- **Depend 现行方案**：供应与工艺稳定、可改动空间明确——四条可执行杠杆依次是降低面层润湿性、提高孔径单分散性、在保持摄入速度前提下降 surge 克重、减小面层/导流层界面间隙。
- **Always Discreet 对标方案**：以「窄孔径分布 + 低克重 surge + 强界面结合」三件套实现更低解吸能，是 GRIFFIN ≤0.15 g 目标的拆解模板；但其能力依赖 P&G 非织造布供应体系，移植需先验证我方供应基盘能否复现。

## 结论 Conclusion

竞品回渗优势**不在孔径大小，而在「更窄的孔径分布 + 显著更低的导流层克重 + 更紧密的层间界面」三者的组合**；其中降克重是唯一同时改善成本与性能的杠杆，但必须与摄入速度同轮验证，否则会重演 SIROCCO 的互斥失败。
