# Mechanochromic Routes Comparison（力致变色技术路线对比）

> 对比对象：把拉伸/压力转成颜色的三条路线——**几何光学掩膜**（几何遮光）、**分子力致变色**（共价键断裂/重排）、**结构色**（光子晶体/液晶/多层膜/HPC）。

## 各自适用场景 Where Each Fits

- **[[Geometric Optical Mask（几何光学掩膜）]]**：需要**尽快量产**的一次性卫生用品功能层——腰围/侧片合身与防漏指示。它的胜负手不在性能而在「不引入任何新东西」：无新化学类别、无新工位、无新毒理包、控制点在来料而非设备。
- **[[Mechanophore Mechanochromism（机械力致变色分子）]]**：**不要用于热熔产线**。其价值在中期研究轨——连续监测（不止过紧报警）、可植入/可穿戴诊断等允许化学固化网络的场景；作为 IP 护城河单独布局，且不得阻塞量产路线。
- **[[Structural Colour Mechanochromism（结构色力致变色）]]**：**等工艺，不等性能**。色彩表现最好、可逆性最好，但两条共同失效（湿/UV 与角度依赖）与工艺原生性（振荡剪切、平面取向+UV 固化）都不在近期解决范围。保留观察窗口至 2028 平台门径。
- **一个被低估的第四选项**：[[Geometric Optical Mask（几何光学掩膜）]] 的 Phase 2 变体（空洞化增白，"craze / cavitation whitening"，成本指数 1.4×、TRL 5）——**它是「材料自身变色」与「热熔可加工」之间唯一可行的交汇点**，代价是只能给**单一**阈值。

（中文：几何掩膜——用于需要尽快量产的一次性卫品功能层，胜负手是「不引入任何新东西」；分子力化学——不要用于热熔产线，其价值在中期研究轨与 IP 布局；结构色——等工艺而非等性能，色彩与可逆性最好但湿/UV 与角度依赖两条共同失效未解，观察窗口至 2028；此外还有一个被低估的第四选项：几何掩膜的 Phase 2 变体「空洞化增白」，是「材料自身变色」与「热熔可加工」之间唯一可行的交汇点，代价是只能给单一阈值。）

## 结论 Conclusion

**在一次性卫生用品的量产语境下，三条路线不是「性能排序」而是「约束满足」问题：只有几何光学掩膜同时满足热熔可加工、无限循环、零新毒理包、可自由实施四项硬约束。** 分子力化学的否决来自物理（未交联热塑性体链滑移 → 力到不了那个键）与时间（18–30 个月毒理）；结构色的否决来自工艺原生性（需要热熔工位没有的两道单元操作）与角度依赖（合身仪表最糟的失效）。选型建议是：**几何掩膜立即量产、分子力化学降为大学合作轨、结构色列入 2028 复审**——这正是原文「Track B 立即推进 / Track A 维持 / 结构色 watch」的决策结构。

（中文：在一次性卫品量产语境下，三条路线的差别不是性能排序而是约束满足——只有几何光学掩膜同时满足热熔可加工、无限循环、零新毒理包、可自由实施四项硬约束；分子力化学的否决来自物理与时间，结构色的否决来自工艺原生性与角度依赖。结论即原文的「Track B 立即推进 / Track A 维持 / 结构色观察」。）

### 1. 两条路线的机理对照（本批补全的分子层）

| | **Naphthopyran（化学）** | **Hydroxypropyl Cellulose / HPC（结构）** |
|---|---|---|
| 机理 | **共价 6π 电环开环** | **胆甾相螺距压缩** |
| 呈色基础 | 生成扩展共轭的**部花青染料（merocyanine）** | 圆偏振反射的**光子带隙移动** |
| 可逆性 | 光化学 / 热回复 | **粘弹性物理松弛** |
| 生态属性 | 合成化学品整合 | **可生物降解、可食用、无毒** |
| 主要用例 | 分子力探针（追踪断链） | 低成本、动态反射显示 |

**分子开关三步**：① **The Break**（力选择性断裂 C-O 吡喃键）→ ② **The Shift**（快速旋转至 **trans-transoid / TT** 构型以最小化位阻）→ ③ **The Color**（部花青染料扩展共轭 π 体系，吸收移入可见区）。

**Naphthopyran 的三个优势（本批新增）**：① **抗疲劳**——开环态保留部分芳香性、电荷中性醌型基态高度稳定；② **刺激专一性**——严格需外力或 UV，**因高热活化势垒而热致变色可忽略**；③ **可调性**——光化学结构-性能关系可精确工程化吸收谱。

> ✅ **与上方结论的关系**：上方已判「分子力化学**否决**用于热熔产线（未交联热塑性体链滑移 + 18–30 个月毒理）」。本批的**刺激专一性**一条为分子力化学**补上一个正面属性**（不被温度误触发），但**不改变否决结论**——否决来自加工与毒理，不来自选择性。

### 3. 合成放大路径（Naphthopyran 商业可行性来源）

| 路线 | 输入 | 工艺 | 亮点 |
|---|---|---|---|
| **酸催化液相** | 萘酚 + 二芳基炔丙醇 | **PPTS + 原甲酸三甲酯 / 1,2-二氯乙烷** | 高收率、**1–3 h**、抑制 Meyer-Schuster 副反应 |
| **无溶剂固相机械化学** | 同上 | **球磨 + 催化 InCl₃** | **免溶剂**、完整保留酸敏感官能团 |

> 商业可行性来自**模块化合成路线**（萘酚与二芳基炔丙醇偶联）——这是"分子力化学虽被否决于量产、但仍可作为 IP 护城河布局"的**成本侧依据**。

## 追加：Resources/Open Innovation 批（2026-09-29 追加 · 阈值鸿沟、假阴性区间与「build 而非 buy」）

> 追加来源：[[力致变色材料研究报告（2026-08-02·纸尿裤应用研判）]]（`RAW/ima_sync/个人知识库/WKB/Resources/Open Innovation/Material/力致变色材料研究报告_2026-08-02.docx.md`）。
> **本追加不修正上方任何结论**；上方为**技术路线对比**（几何掩膜 / 分子力化学 / 结构色），此处补入**把任一路线落到纸尿裤时必须跨过的两个量化门槛**，以及**市场侧的可行性判断**。
> 🔴 **manual_review（2026-09-29）**：含 IP 收购标的与研究合作对象的战略定位，**不得对外披露**；本页不含报价与合同条款。

### 追加-1 · ★ 阈值鸿沟：从「结构失效检测」到「皮肤侧低张力」

| 端 | 阈值 | 设计目的 |
|---|---|---|
| **工业级力化学基团（现状）** | **≥ 40,000 PSI** | 检测高性能聚合物的**结构失效** |
| **纸尿裤需求（目标）** | **20–150 kPa**（微致动研究识别的低张力区间） | 腰贴/腰围**过紧**指示、婴儿安全 |

> 📌 **对上方三条路线的共同约束**：**无论选哪条路线，都必须把触发阈值下移约三个数量级**。这不是配方微调，而是**重新设计力化学基团的键能或结构色的晶格灵敏度**——是本对比中**唯一对所有路线等效的硬门槛**。

### 追加-2 · ★ 25–27% 应变假阴性区间（Barty-King et al., 2025）

| 应变区间 | 材料状态 | 信号表现 |
|---|---|---|
| **< 25%** | 稳定**粘弹性螺距压缩态** | 颜色信号稳定、可逆 |
| **25–27%（转变区）** | 进入**流动 / 剪切态** | **剪切变稀 + 非弹性横向流动**破坏信号 |
| **> 27%** | 同上加剧 | 可能在**应力仍施加时**出现「**松弛 / 消散**」⇒ **假阴性** |

> ⚠️ **对结构色路线（HPC）的直接含义**：上方记 HPC 具有「可预期幂律关系 + 可逆」的优势；本追加给出**该优势的失效边界**——**一旦应变越过 25–27%，幂律关系不再成立**。原文提出的对策是**用凝胶剂（gellant）做该区间的稳定性测试**。

### 追加-3 · 「build 而非 buy」：Day-1 假设被显式证伪

| 项 | 内容 |
|---|---|
| **原假设** | 纸尿裤力指示可直接采用**市售压力激活材料**，短期商业化 |
| **翻转测试结论** | **被证伪** |
| **证伪依据** | 市售压力激活材料（**CTI HPP 墨、Fujifilm Prescale 膜**）**均属不可逆计量型**；阈值固定在**超高压力或工业接触压力**；**无现成的柔软、低阈值、可逆、可皮肤接触规格** |
| **结论** | 纸尿裤力指示是**创新空白（innovation white space）** ⇒ 走 **build（自建阈值 + 印刷工艺）**路径 |

> 📌 **与上方的关系**：上方判断「**几何掩膜路线立即量产 / 分子力化学降为大学合作轨**」——本追加**支持**该判断：因为**现成材料的阈值与可逆性都不匹配**，能立即做的只有**印刷工艺侧的构建**（几何掩膜属此类），分子侧只能走合作轨。

> 📌 **补入「供应链风险」与「成本」两列的增量**：
>
> | 维度 | 可印刷压力激活油墨（CTI 路线） | 共价力化学基团（自建路线） |
> |---|---|---|
> | **成本** | 上市最快，但**溢价来自法规合规（食品接触级）**；成本备份为国内河南佳易达 / 深圳星成珠光 | 工艺更复杂、前期投入高；但**自评估材料 + 永久 IP 护城河** ⇒ 长期单位成本潜力更优 |
> | **供应链风险** | **单点依赖**：主选仅 CTI 一家具食品接触级；须以国内 Tier 2 作备份 | **IP 获取风险**：依赖 [[Duke Capital Partners（Dr. Cary Ritter 力致变色 IP 目标）]] 等标的的可获得性；一旦锁定则形成排他壁垒 |

> ⚠️ **国内甄别警告（对供应链风险列的关键提示）**：**多数国内「变色材料」厂商实际主营热致/光致/角度变色（变色龙），并非力致变色** ⇒ 须严格区分「**声称压力/力致**」与「**相邻未确认**」。本源 7 家国内厂商中，**仅河南佳易达与深圳星成珠光为 [F] 级确认**，其余 4 家为 [I] 未确认、1 家因含湿致变色被排除。

### 追加-5 · 法规门槛（**对所有路线的准入条件**）

- 全部候选须通过 **FDA 21 CFR / EU 10-2011 / REACH** 筛查，**优先食品接触级**。
- **HPC 为金标准**：**可食、无毒、可生物降解**，已用于医药 ⇒ 在**婴儿口服与皮肤安全为最高优先级**的前提下，**HPC 是唯一自带合规背书的候选**。
- 原文自陈**不构成法律意见**；儿童皮肤接触产品的法规符合性**须以专业顾问的测试/合规文件为准**。
