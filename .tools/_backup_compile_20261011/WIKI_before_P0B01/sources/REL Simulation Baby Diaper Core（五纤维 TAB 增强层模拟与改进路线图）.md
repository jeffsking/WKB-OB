## 摘要

**对象**：穿透热风粘合（Through Air Bonded, TAB）工艺的 **REL 非织造**，用于**双 SAP 层婴儿纸尿裤芯体**。

**芯体截面（自上而下）**：面层（Topsheet）→ **ADL / 获取层**（快速分布）→ **上层 SAP**（**高 AUL + 高 GBP** → 快摄入与防回渗）→ **REL 增强层** → **下层 SAP**（**高 CRC + 宽粒径分布** → 储存与分布）→ 芯体包裹/底膜。

**REL 的三重作用**：结构隔离（阻止 SAP 迁移）｜**液体传递桥（Z 向毛细流）**｜**负载下维持蓬松**。

## 提炼的数字与结论

### 当前配方与纤维分工（15 gsm）

| 纤维 | 占比 | 功能（原文） |
|---|---|---|
| **2D ES（粘合）** | **40%** | 细旦双组分 PE/PET 粘合纤维，在整个纤网形成**热粘合点**，提供结构完整性与柔软手感 |
| **12D ES（蓬松）** | **10%** | 粗旦双组分，提供**蓬松、Z 向空隙**，用于快速导液与芯吸 |
| **3D PTT/PET 并列** | **28%** | **3D 并列自卷曲**双组分；**高回弹**，**在压缩下维持芯体蓬松以避免凝胶阻塞** |
| **9D 中空 ES** | **14%** | **偏心中空皮芯**；提供**毛细通道与低密度**，提升渗透性与穿透 |
| **4D PVA** | **8%** | **非水溶性 PVA 短纤**；提供结构增强、湿度调节与**湿态强力** |

### 模拟性能 vs 目标（六项）

| 指标 | 模拟值 | 目标 | 判定 |
|---|---|---|---|
| **穿透时间 STT（第 1 次）** | **~0.9 s** | <0.8 s | 接近，未达标 |
| **回渗（5 min，0.5 kPa）** | **0.04 g** | <0.03 g | 接近，未达标 |
| **湿态 MD 抗张** | **58 N/m** | **>75 N/m** | ⚠️ **关键缺口（critical gap）** |
| **液体分布面积（第 3 次）** | **42 cm²** | >50 cm² | 未达标 |
| **干态芯体蓬松（15 gsm）** | **8.2 mm** | 9–10 mm | 未达标 |
| **SAP 捕获率** | **97%**（迁移 <3%） | — | **excellent** |

### 双层 SAP 的规格与相互作用

| 层 | 关键指标 | 功能 |
|---|---|---|
| **上层 SAP** | AUL（0.7 psi）**≥28 g/g**；**GBP ≥40 Darcy**；粒径 **200–400 µm（细）**；CRC 28–32 g/g | 快速吸收、凝胶渗透性，使液体快速通过至 REL |
| **下层 SAP** | AUL（0.3 psi）**≥24 g/g**；**CRC 38–48 g/g（高储存）**；粒径 **400–800 µm（粗）**；GBP 20–30 Darcy | 最大容量储存，全片水平分布 |

| 流向 | Upper SAP → REL | REL → Lower SAP |
|---|---|---|
| 流动方式 | 通过凝胶基质的**向下渗透** | **毛细驱动的向下芯吸** |
| 关键纤维 | **9D 中空 ES 形成 Z 向通道** | **3D PTT/PET 回弹防止塌陷** |
| 风险 | **REL 蓬松塌陷 → 凝胶阻塞** | **PVA 占比过低 → 分布不完全** |
| 目标流量 | **>45 ml/min（每次加液）** | **>35 ml/min（第 3 次后）** |

### ★ 四条改进项（当前 → 建议）

| 纤维 | 当前 → 建议 | 理由与预期 |
|---|---|---|
| **2D ES** | **40% → 32%** | **当前 40% 过粘合**，使蓬松与透气下降约 **18%**；降至 32% 并换用**更低 Tm 的皮层 ES** 以在更低添加量下获得同等粘合 ⇒ **透气 +20%、STT −15%** |
| **3D PTT/PET** | **28% → 34%** | 自卷曲纤维是**负载下回弹的关键组分**；提高占比直接**对抗凝胶阻塞**并在 3 次加液内维持 Z 向通道开放 ⇒ **回渗 −35%、蓬松恢复 +22%** |
| **9D 中空 ES** | **14% → 18%** | 中空偏心纤维提供**关键 Z 向毛细通道**；提高占比改善渗透与吸收速率，**尤其在第 2/3 次加液（SAP 膨胀阻碍流动时）** ⇒ **液体渗透 +28%、第 3 次 STT −20%**（原文评为**改善 STT 的最高 ROI**） |
| **12D ES** | **10% → 8%** | 粗旦粘合纤维略减；其蓬松收益**已被提高的 PTT/PET 3D 卷曲取代**；8% 仍提供足够的蓬松锚点 ⇒ **净克重中性、手感更软** |

### 四条进阶纤维选项

| 选项 | 内容 | 预期收益 |
|---|---|---|
| **2D → 1.5D ES（粘合）** | 更细的 1.5D ES 粘合纤维，**每克形成更多粘合点**、降低添加量%；兼容现有 TAB 工艺（**200–220 ℃ 热风**） | 粘合均匀性 **+15%**、手感指数 **+20%**、**成本变化极小** |
| **3D → 4D PTT/PET 并列** | **卷曲频率 ≥8 个/cm**、**四叶截面**（除 3D 卷曲效应外还提供**毛细沟槽**芯吸） | 0.7 kPa 下蓬松恢复 **+35%**、横向铺展 **+22%**、**抗凝胶阻塞显著改善** |
| **9D → 6D 偏心中空** | 保留中空芯以维持 Z 向毛细，但**降低纤维直径**，改善堆积密度平衡、**提高单位面积毛细通道数** | 毛细密度 **+40%**、STT **−18%**、**克重中性** |
| **新增 2% 的 1.5D PET/PA6 微沟槽芯吸纤维** | 经亲水处理的 PET/PA6 双组分**微沟槽**纤维；**微沟槽提供定向芯吸、无需化学整理**，改善多次加液后的亲水耐久性（**从 ES 粘合纤维中替换 2%**） | 第 3 次芯吸速度 **+30%**、**亲水耐久性 +50%** |
