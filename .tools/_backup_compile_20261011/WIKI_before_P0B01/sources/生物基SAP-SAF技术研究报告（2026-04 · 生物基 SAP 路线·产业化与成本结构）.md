# 生物基SAP-SAF技术研究报告（2026-04 · 生物基 SAP 路线·产业化与成本结构）

> 报告日期 **2026 年 4 月**。技术方向标注为「生物基高吸水性树脂（SAP）｜可持续航空燃料（SAF）」。本页为该综述报告（`.md.md`）的编译页。
> **可信度定级说明**：该报告为**二手综述**（数据来源自述为「行业研究报告、企业公告、专利文献」），**无一手实验数据、无逐条出处**。因此：

## Definition 定义

**生物基 SAP（Bio-based SAP）生物基高吸水树脂** — 以可再生原料（淀粉、纤维素、蛋白质、生物基单体）替代或部分替代石油基丙烯酸路线的高吸水树脂。与之**正交**的概念是 **可降解（degradable）**：**生物基 ≠ 可降解**（生物基丙烯酸 SAP 的性能与寿命与传统 SAP 相当，并不降解）。二者常被混用，是本报告最需要澄清的一点。

## Absorption Mechanism & KPI 吸水机理与关键指标

**吸水机理四要素（source-stated）：**
1. **渗透压驱动**：树脂内部高浓度离子与外部低浓度溶液形成渗透压差；
2. **毛细管作用**：三维网络结构形成毛细吸附效应；
3. **氢键作用**：亲水基团与水分子氢键结合；
4. **网络弹性**：交联结构限制无限溶胀、保持凝胶形态。

|指标 KPI|典型值 Typical value|测试方法 Test method|
|---|---|---|
|吸水倍率（纯水）|500–1000 g/g|茶袋法|
|吸水倍率（0.9% NaCl）|50–80 g/g|茶袋法|
|保水性|>90%|离心法|
|吸水速率|30–120 s|涡旋法|
|凝胶强度|20–50 kPa|流变仪|

> 对照：本知识库内 CRC/GBP/Vortex 体系口径见 [[SAP性能指标（CRC AUL GBP Vortex）]]；上表为**通用行业典型值**，不是牌号选型数据。

## Bio-based SAP Routes 生物基 SAP 五条路线

|路线 Route|工艺路径 Process|关键参数 Key parameters|状态 Status|
|---|---|---|---|
|① 淀粉接枝共聚（淀粉-g-PAA/PAM）|糊化 → 接枝聚合 → 交联 → 干燥 → 粉碎|接枝率 60–80%；吸水 200–500 g/g|部分企业已工业化|
|② 纤维素接枝（CMC / 羟乙基纤维素）|纤维素活化 → 羧甲基化 → 交联改性 → 后处理|来源：农业废弃物、木浆；降解周期 3–6 个月|实验室/中试|
|③ 蛋白质基（大豆蛋白、胶原蛋白）|蛋白改性|—|研发|
|④ PASP 聚天冬氨酸|天冬氨酸缩聚 → 交联 → 造粒|完全生物降解；吸水 100–300 g/g|BASF 等小规模|
|⑤ 生物基单体（生物基丙烯酸）|生物基丙烯酸 → 常规聚合|性能与传统 SAP 相当|LG Chem + ADM 开发中|

**生物基优势（source-stated）**：原料可再生、部分可降解、**对盐溶液敏感性低**、减少微塑料污染。
**生物基代价（source-stated）**：成本高于石油基 **20–50%**、**吸水性能略低**、认证与标准待完善、**规模效应尚未形成**。

> 路线 ③ 的专门讨论见 [[生物基高吸水材料（大豆蛋白 SAP）]]；路线 ②④ 与 [[Citric Acid Crosslinked Cellulose SAH（柠檬酸交联纤维素超吸水凝胶）]]、[[Starch-CMC Acetal Crosslinked Superabsorbent（淀粉-CMC 缩醛交联高吸水体）]] 同源。

## Process Routes 制备工艺

**三条聚合工艺（全球供应商对应关系）**

|工艺 Process|特点 Characteristics|代表企业 Represented by|
|---|---|---|
|反相悬浮聚合|产物颗粒均匀、吸水率高|日本触媒、住友精化、三大雅|
|水溶液聚合|工艺简单、成本低|巴斯夫、赢创|
|反相乳液聚合|产率高、反应快|部分企业|

**反相悬浮聚合工艺参数（B 级参考）**：油相油水比 3–5:1（环己烷/分散剂）；水相中和度 70–80%；聚合 70–80 °C、2–4 h、引发剂 0.1–0.5%；共沸脱水 80–110 °C；**筛分粒度 150–850 µm**（粒度分布控制）。

**表面交联（Surface Crosslinking）**：作用是**提升凝胶强度、减少凝胶结块**；交联剂为多元醇、碳酸酯、噁唑啉等；工艺为**喷雾涂覆 + 热处理 120–180 °C**。与 [[SAP 表面包覆（SAP Particle Surface Coating）]]、[[SAP GBP Improvement & Surface Crosslinking Process Review（GDP提升工艺探讨）]] 为同一技术域（GBP 提升的主手段）。

## Cost Structure 成本结构（C 级 · 市场口径）

**原料成本结构（石油基 SAP）**：丙烯酸 **50–60%**、液碱 15–20%、交联剂 5–8%、引发剂 2–3%、溶剂/分散剂 5–10%、其他 5–10%。
→ **结论性含义**：**SAP 成本由丙烯酸单一主导（>50%）**，因此任何降本/可持续路径都要么动丙烯酸（生物基单体），要么动用量（芯体设计）。

**生物基溢价与降解周期（本报告核心可比表）**

|路线 Route|成本溢价 Cost premium|降解周期/寿命 Degradation|
|---|---|---|
|淀粉基|+20–30%|6–12 个月|
|纤维素基|+30–50%|3–6 个月|
|聚天冬氨酸 PASP|+50–100%|2–4 个月|
|生物基丙烯酸|+10–20%|与传统 SAP 相当（不降解）|

**投资成本（C 级）**：1 万吨/年产能线投资约 1–1.5 亿元；单吨投资 1–1.5 万元/吨；**高端 SAP（反相悬浮）投资增加 30–50%**。

## Application Split 应用结构

- **卫生用品约 75%**：婴儿纸尿裤（单用量 8–15 g）、成人失禁（15–30 g）、女性卫生巾（3–8 g）、护理床垫（20–50 g）。
- **农业约 15%**（种子包衣 0.5–1、土壤保水 2–5、育苗基质 1–3、无土栽培 5–10）：生物基优势为**可降解、无土壤残留**。
- **工业约 10%**：电缆阻水带、混凝土养护、医用敷料/冰袋、废水处理（吸附重金属）、食品保鲜包装。
- **技术趋势**：纸尿裤超薄化（SAP 用量↑、绒毛浆↓）、复合芯体（SAP+粘合纤维一体化）、功能性 SAP（抗菌/除臭/护肤）。

> 卫生用品单件 SAP 用量（婴儿 8–15 g）可与 [[Baby Diaper Absorbent Core Design（五层无浆 SAP 芯体设计方案与仿真 KPI）]]（14.0 g / 385×110 mm、≈329 g/m²）互为量级校验：两者一致，且后者为**具体设计值（A/B 级）**。

> **判定**：SAF 与 IPC BCC 卫材业务**无技术或供应链交集**，本页仅登记该并置关系，**不派生 SAF 页面**。

## Trends 技术趋势（source-stated）

1. **生物基化**：目标 **2030 年生物基 SAP 占比达到 20%**；路径为「生物基单体 → 生物基聚合物 → 可降解 SAP」；挑战为成本控制、性能平衡、标准建立。
2. **功能化**：抗菌（银离子、季铵盐）、除臭（活性炭复合、酶固定化）、温敏、pH 响应。
3. **复合化**：SAP-纤维复合（芯体结构优化）、纳米 SAP（提速）、有机-无机复合（提凝胶强度）。
4. **绿色化**：可降解 SAP（PASP、改性淀粉）、循环再生（废旧 SAP 化学回收）、低碳生产（绿电、碳足迹）。

## 存疑与冲突 Open Issues

1. **成本口径冲突（重要）**：本报告称生物基 **+20–50%**、PASP **+50–100%**；而 [[IPC BCC OI 材料开发团队 2026 年度汇报大纲 v7（2026-09-17）]] 口径为**可降解 SAP ≈ PAAS 的 2–5 倍**（OI-06 达 30–40 USD/kg）。**两者并非同一对象**：本报告为**生物基（bio-based）**溢价，OI 口径为**全降解（degradable）**溢价。**结论：不要把「生物基 +20–50%」用于可降解路线的成本论证。**
2. **赢创业务出售**：本报告称赢创 SAP 业务「已出售给 ICIG」，与 [[Evonik（赢创）]] 页面若存在不同表述，**须以外部公告核实**，本页仅登记 source-stated。
3. **三大雅（Samyang）国别标注不一致**：3.1 表标为韩国企业（Samyang），6.2 表写作「日本三大雅」。**未做修正**，已登记。
4. **产能口径年份混用**：全球表为 2023、中国表为 2024；且 6.1/6.2 与 3.1/3.2 存在个别不一致（万华 6–8 vs 8 万吨、宜兴丹森 20+ 两处一致）。跨表比较前须确认年份。
5. **共沸脱水「含水率%」缺值**：原表目标值一栏为「含水率%」，**数值缺失**，不得补写。
6. **SAF 章节**：与卫材无关，且无实质技术内容，仅作并置登记。
