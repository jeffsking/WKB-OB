# CN 118369075 A（具有前后弹性腰带的胶粘吸收制品·宝洁）

## One-line positioning 一句话定位

**宝洁的 PCT 进入中国国家阶段发明专利申请公开**（CN 118369075 A，2024-07-19 公开）。题目叫"具有前后弹性腰带的**胶粘**吸收制品"，但真正的发明点是一个**反直觉的力值窗口**：**前腰带弹性力必须"低"——0.03–0.32 N**，后腰带力反而要"高"（1.1–2.9 N），**后/前比值 4–40（优选 5–30）**。理由不是拉伸性能，而是**失效模式**：前腰带力过大会产生大量褶皱，护理人员要反复拉伸才能把后耳片贴到着陆区；穿上后前腰边缘**弯成 U 形**，尿裤显松垂，且后粘带的一部分可能**接触皮肤**。

## Abstract 摘要（逐字摘录）

(54) 发明名称：**具有前弹性腰带和后弹性腰带的胶粘吸收制品**。
(57) 摘要逐字：一种胶粘吸收制品(20)具有邻近其前腰边缘(10)的**前弹性腰带(100)** 和邻近后腰边缘(12)的**后弹性腰带(200)**。前弹性腰带具有在**约 0.03 N 至约 0.32 N** 范围内的**前腰带弹性力**，后弹性腰带具有**高于前腰带弹性力的后腰带弹性力**，如通过本文所公开的**腰带弹性力测量方法**所测量。

### Consumer fit study 消费者贴合度研究（表 2，逐字摘录）

在**消费者贴合度研究**中测试具有不同前/后腰带弹性力的**四种**胶粘尿布（**N = 28 或 12 名婴儿**），并测试**仅具有后腰带而不具有前腰带的另一对照尿布**。要求陪同的父母将尿布**前腰部**的贴合度分为**紧 / 正好 / 松**。

| 所测试的尿布 | #1 | #2 | #3 | #4 | #5（对照） |
|---|---|---|---|---|---|
| 基准大小 N | **28** | **12** | **12** | **12** | **12** |
| 前腰带贴合度「紧」 | 21.4 % | 8.3 % | 8.3 % | 0.0 % | 0.0 % |
| 前腰带贴合度「**正好**」 | **64.3 %** | **83.3 %** | **91.7 %** | **100 %** | 91.7 % |
| 前腰带贴合度「松」 | 14.3 % | 8.3 % | 0.0 % | 0.0 % | 8.3 % |
| **前腰带弹性力** | **0.53 N** | **0.40 N** | **0.20 N** | **0.10 N** | **不适用** |
| 后腰带弹性力 | 1.35 N | 1.36 N | 1.37 N | 1.44 N | 1.98 N |
| 前/后弹性力比值 | 2.55 | 3.40 | 6.84 | 14.4 | 不适用 |

> **结论（[0100] 逐字）**：在所测试的所有尿布中，发现具有**前弹性腰带力 0.10 N** 的尿布具有**最高的消费者贴合度等级（100 % 正好）**。
>
> ⚠️ **两点必须同时读**：①#1（0.53 N）的**前腰带力已超出权利要求上限 0.32 N**，属**对照性质**的高力值样本；②对照尿布 #5（**无前腰带**，亦无前腰带力）的"正好"率为 **91.7 %**，**高于 #1（64.3 %）、#2（83.3 %），并与 #3 持平**——即本数据**只能说明"在 0.10–0.53 N 区间内，力越低贴合越好"**，**不能说明"有前腰带一定优于无前腰带"**。样本量亦很小（N = 12 的四组中，1 人即等于 8.3 个百分点）。

### 腰带弹性力测量方法（Belt force test method，逐字摘录要点）

| Item 项目 | Content 内容 |
|---|---|
| 测量对象 | 以**最大拉伸长度 L最大** 拉伸**两次**后，前/后弹性腰带在 **85 % 有效胶粘弹性长度 L读取** 下的**腰带弹性力** |
| 环境条件 | **23 ℃ ± 2 ℃** 标准条件的**气候调节室** |
| **EGEL（有效胶粘弹性长度）** | 对含股线的腰带：单根股线末端在**其开始起皱的位置**之间的**最小距离**；对弹性膜类腰带：腰带每一侧**第 1 个褶皱**的位置。实践中可由腰带材料**全长（松弛态）减去两侧非粘结区 D1、D2 长度**得到 |
| L最大 | **0.95 × EGEL** |
| L读取 | **0.85 × EGEL** |
| 测力计 | **支架/型号 E-DFE-002**，制造商 **Trimborn+Guld Maschinenbau GmbH**；数字测力计 **0–10 N** 刻度，**最小分辨度 0.01 N**（或等效物） |
| 直尺 | 可追溯至 **NIST、DIN、JIS、CMC** 或其他相当国家标准的毫米刻度金属直尺 |
| 样品制备要点 | 从包装取出后**不拉伸**腰带；沿平行于横向轴线的引导线**剪下腰带**；**不得剪断或撕扯弹性部件**；若有 **SAP 暴露**须用遮蔽粘带密封（粘带不得约束材料） |

### 制造方法（权 15 / [0009]–[0018]，连续且同时制前后腰带）

1. 纵向提供腰带材料（70）连续供应，第一半部（71）与第二半部（72）由折叠线（73）分开；
2. 提供弹性股线（110, 210）连续供应；
3. 在弹性股线上**间歇涂粘合剂**（故部分股线未涂胶）；
4. 将股线沿 MD 重叠在第一半部上；
5. 沿折叠线把第二半部折到第一半部上，得到**连续腰带层压件（74）**，其具有由**非粘结区域（76）**分开的**粘性粘结区域（75）**；
6. 沿非粘结区中的**虚线切割线（77）**横向切割——**切断弹性股线，但仅部分切断腰带材料**；
7. 与底座横向对齐（可经 90° 旋转辊）；
8. **拉伸层压件使其沿虚线切割线断裂**，形成**组合垫（78）**；
9. 沿切割线（79）切割组合垫，得到离散的**前腰带层压件（100）与后腰带层压件（200）**；
10. 附接到底座。

**关键机理（[0075]）**：股线在**未涂胶的间歇区 76 弹回**，而腰带材料因虚线切割**保持部分连接**——这正是"**同一条起始材料同时产出两条不同弹性力的腰带**"的工艺基础。腰带材料优选**低基重非织造物（8–20 gsm，如 SMS）**，幅宽约为前后腰带宽度之和的**两倍**。

## Key claims 关键论断

- **"前腰带力要低"是对常识的反转**：直观上腰带越紧越防漏，但本案指出的失效模式是**穿戴流程层面**的——**褶皱导致贴不上粘带、U 形变形导致松垂、后粘带触皮肤引发不适**。→ [[Front Belt Force Window（前腰带弹性力窗口）]]
- **"后 >前"的比值被写进权利要求**：4–40（优选 5–30）。这意味着前后腰带的**功能定位不同**：后腰带提供主弹力与防漏，前腰带只提供**轻度贴合与防前漏**。
- **力值可由"股线数量 + 分特值"双旋钮调节，且两种腰带可同源共线生产**（权 6、权 15）。实施例给出 11 根 × 620 dtex（后）vs 3 根 × 470 dtex（前）→ 1.98 N vs 0.1 N。→ [[Elastic Tension & Creep（橡筋张力与回缩率）]]
- **测量方法本身是本案的重要交付**：EGEL / L最大 = 0.95×EGEL / L读取 = 0.85×EGEL、23±2 ℃、0.01 N 分辨度。**没有这套方法，0.03–0.32 N 这个窗口无法复现**——引用该窗口时必须连方法一起引用。→ [[Product Waist Break Test（产品腰围拉断测试）]]
- **"360 度可拉伸保护"是配套的产品叙事**（[0003]）：可拉伸前腰带结合可拉伸后腰带，并特别提到**前腰带在婴儿趴着时提供额外防漏**。→ [[Waist Guard（腰围护挡）]]
