# Pre-work BFS APAC Workshop 2017 (Product Metrix)_BL_VerC.xlsx

## One-line positioning 一句话定位

Pre-work product-matrix workbook prepared for a 2017 BFS APAC workshop, tabulating bath-tissue SKUs (jumbo / standard / folded rolls) across six APAC markets with five-year (2016–2021) volume plans and per-case economics.（为 2017 年 BFS 亚太研讨会准备的预研产品矩阵，汇集六大亚太市场的卫生纸单品及 2016–2021 五年销量规划与单箱经济性。）

## Summary 摘要

- Scope is **bath tissue**, not diapers: Jumbo Roll, Standard Roll and Folded Bath across Australia, New Zealand, China, Taiwan, India and Hong Kong, brands SCOTT / KLEENEX / corporate & private-label.（范围为卫生纸而非纸尿裤：澳/新/中/台/印/港的 Jumbo/Standard/Folded，品牌含 SCOTT、KLEENEX 及自有/贴牌。）
- Each row carries furnish (EUCA/bagasse/softwood/RF/broke), basis weight, plies, sheet dimensions, yearly plan (cases & MT) for 2016–2021, and per-case NSV / COGS / Dist / GP / GM%.（每行含浆料配比、克重、层数、尺寸、2016–2021 年规划（箱/吨）、单箱 NSV/COGS/分销/GP/毛利率。）
- Margin notes are explicit: many lines carry "GM is less than 20%" or "Reduce softwood to 15% or add more RF"; a few China SCOTT 1-ply JRT rows show deeply negative GM% (e.g. −56.6%, and one anomalous +449.9% flagged "GM is something wrong?").（利润批注明确：多行标注「GM<20%」「针叶木浆降至 15% 或加 RF」；部分中国 SCOTT 单层 JRT 毛利率深负，并有异常值被标「数据疑似有误」。）
- Source mills referenced: KC-China (SH Mill), KC-Taiwan (Tayuan/ChungLi/HsinYing), KC-Thailand, KC-Australia, KC-US; some OEM/contract converters (Shangtou Wan'an, Sh AIHUA ZHONGXING).（涉及的工厂：KC-China（上海）、KC-Taiwan、KC-Thailand、KC-Australia、KC-US，及部分代工。）

## Key claims 关键论断

- APAC bath-tissue profitability was mixed in 2017 planning: premium KLEENEX JRT in China reached ~41% GM, while several SCOTT value JRT SKUs were margin-negative.（2017 规划中亚太卫生纸盈利分化：中国 KLEENEX JRT 毛利率约 41%，多个 SCOTT 入门 JRT 单品亏损。）
- Fibre-substitution (less softwood / more RF) was the named primary cost lever across markets.（减少针叶木浆、增加再生纤维是被点名的主要降本杠杆。）
