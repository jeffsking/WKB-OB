# R150540 / TL-14137 Poise Use-Test Load & Leakage Summary（失禁产品 HUT 数据汇总）

## 一句话定位 One-line positioning

本库**失禁产品线定量化的源头数据件**：把消费者使用实态转化为三条可直接用于设计的曲线——**单次排尿量分布（single insult）**、**累积载荷分布（loading）**、**渗漏发生率（LD50 / 渗漏率）**。下游所有 Poise/Depend 类 bench 加液参数（含 STM-00497）都由它派生。

## 摘要 Summary

报告明确三点用途分层：**single insult 决定 bench 冲击量，loading 决定所需容量，leakage 校核容量上限**。数据来自 2000–2008 年间的多项 HUT 与单次排尿量专项研究，覆盖 Poise® pantiliner 到 Ultimate Long 的全产品线；其中 Single Insult 部分给出各产品 10–100 百分位的分布（并注明 Ultimate Long 当时尚未测试、Regular 虽已退出美国市场但因其他地区仍在售而保留），N(insults) 从 311 到 1124、N(subjects) 从 38 到 161。Product Loading 部分给出各产品 50/70/80/90/95 百分位载荷，并记录了自 TL-11541 以来的两项变化：**Moderate 载荷上升、Maximum Long 载荷下降**；同时指出 Moderate Long / Maximum / Maximum Long / Ultimate 四者的载荷分布**显著重叠**，而 Pantiliner、Ultra Thin、Moderate、Ultimate Long 的分布相对可辨。Leakage 部分给出各产品的 **LD50**（半数渗漏载荷）与产品级/受试者级渗漏率。Comparison 部分把同一产品的 Load–All / Load–Leak / Load–No Leak 三组分位并列，实证**渗漏样本的载荷显著更高**。最后给出三条后续建议：把 Poise Hourglass® 延伸产品线纳入后续汇总（如 Chanel HUT 33063）、与 Urinary Leakage Spectrum 研究 31140 对比、以及更新 single insult 数据。

## 关键论断（key_claims）

- **bench 加液量不是实验室约定，而是消费者使用数据的统计分位**：缺失这一步的产品，其摄入/渗漏评价与真实工况脱节 —— 支撑页：[[Use-Test Loading & Leakage Percentile（使用测试载荷与渗漏分位）]]
- **排除渗漏样本会把容量需求算小**：本版把渗漏样本纳入后才得到真实分布，这是该系列报告最重要的方法论修正 —— 支撑页：[[Use-Test Loading & Leakage Percentile（使用测试载荷与渗漏分位）]]
- **三条曲线的分工清晰：single insult → bench 冲击量；loading → 容量目标；LD50 → 渗漏风险上限** —— 支撑页：[[Bladder Box Intake Test（膀胱箱压载摄入测试）]]、[[STM-00497 Intake via Bladder Box（成人·女性护理压载摄入法草案）]]
