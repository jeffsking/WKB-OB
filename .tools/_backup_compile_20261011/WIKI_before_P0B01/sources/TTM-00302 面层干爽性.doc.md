# TTM-00302 面层干爽性.doc

## 一句话定位

南京厂成品 SOP **TTM-00302（第 1 版，2021-08-24）**：在 **FIFE 板**上对同一片产品做**三次定量注液**，每次记录**吸收时间**，并用 **177 g 压板 + 预称重滤纸**压 **2 min** 读取**回渗量**，同时称下层滤纸得**溢出量**——一次实验同时产出"摄入—溢出—回渗"三条曲线，是面层干爽性的综合判据。

## 摘要

测试液为 **0.9% 生理盐水 + 蓝色食品级色素**：用蒸馏水将 **0.1 g 蓝色粉体**定容至 **100 mL**，取其中 **4 mL** 加入 **1 L 0.9% 盐水**，水浴加热至 **37 ℃**。制样：称产品重量（精确 **0.01 g**）；**去掉腿部与折页皮筋**使产品能在 FIFE 板上放平（但不可剪得太深，否则测试时会从侧面渗漏）；称滤纸重量并记录；滤纸放在 FIFE 板上再固定产品，按 Size 在 **target zone** 做标记——靶区距吸收体前端边缘 **NB 102 / S 114 / M 127 / L 140 / XL 146 / XXL 146 mm（±5 mm）**，注液量 **50 / 60 / 70 / 85 / 100 / 100 mL（±0.5 mL）**。步骤：以 **15 mL/s** 注入 37 ℃ 盐水并记录**第一次吸收时间**；吸收完成后**等待 30 s**；放上已称重的长方形滤纸与**表面干爽性压板（177 g）**，**等待 2 min**；取下滤纸称重算回渗量，同时称下层滤纸记录溢出重量；重复三次。输出表包含三次各自的吸收时间、溢出重量、回渗量，以及 **Total rewet（总回渗）**与标准差。

## 提炼的数字与结论

| 项目 Item | 数值 / 结论 Value | 备注 Note |
|---|---|---|
| 测试液 Liquid | **0.9% 盐水**，37 ℃；0.1 g 蓝粉/100 mL 取 4 mL 加入 1 L | 染色便于读吸收时间 |
| 注液速度 Rate | **15 mL/s** | — |
| 靶区 Target zone（距吸收体前端） | NB **102** / S **114** / M **127** / L **140** / XL **146** / XXL **146 mm**（±5 mm） | 与 FIFE 中国区档位一致 |
| 注液量 Insult | NB **50** / S **60** / M **70** / L **85** / XL **100** / XXL **100 mL**（±0.5 mL） | 单次 |
| 注液次数 Insults | **3 次**（重复步骤 1–4） | 产出总回渗 |
| 吸收后等待 Wait | **30 s** | 再上压板 |
| 压板载荷 Plate load | **177 g**（表面干爽性压板） | 远轻于国标 1.20 kg |
| 压合时间 Hold | **2 min** | — |
| 读数 Outputs | 吸收时间（s）、溢出重量（g）、回渗（g）×3 + Total rewet + s.d. | 滤纸增重法 |
| 制样 Pretreatment | 去除腿部/折页皮筋，**不可剪太深** | 否则侧漏作废 |
| 称重精度 Weighing | 产品 0.01 g；滤纸需预称重 | — |

> ⚠️ **口径差异（2026-09-29）**：本页的"回渗"与 [[GB-T28004-2011 回渗渗漏.doc]]（1.20 kg / 直径 100 mm 压块 / 1 min）**不是同一个量**——本页载荷仅 **177 g**、压 **2 min**、且回渗取自**三次注液各自的滤纸**；两者数值不可互换。本页亦不同于 [[STM-00034 FIFE - Fluid Intake Flowback Evaluation Rev.5（FIFE 摄入-回渗评价全球方法）]]：后者在 SAT CAP 上以 **14 ± 1 inH₂O 真空**压 2 min，而本页是**常压 + 177 g 压板**。
