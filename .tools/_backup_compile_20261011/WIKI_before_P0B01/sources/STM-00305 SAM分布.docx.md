# STM-00305 SAM分布.docx

## 一句话定位 One-line Positioning

**SAM（高吸水树脂）分布膨胀测试**（第 5 版）：把成品中切水化，目视判读吸收体内 SAM 与绒毛是否为均匀混合，按 4 档评分并拍照。是把"芯体结构设计"（[[分区密度设计]]、[[SAP错峰膨胀]]）落地为可验收读数的目视方法。

## 摘要 Summary

该测试用来判断尿裤中吸收体的分布情况。测试前准备 500 mL 以上的蓝色水溶液，并选择适合产品型号的水槽（C124-A4-05467/68/70-C-02）。样品准备：小心取出样品，尽可能避免 SAM 和绒毛移动；面层向下，用 1 英寸切刀切下产品 MD 方向中间位置（转向切时应小心，避免产品倾斜）；拿住两头端封位置时尽可能保持水平，面层向下置于水槽中，样品应平放于水槽底部。测试步骤：按产品型号使用不同体积的蓝色水溶液（初生 NB-Step1 为 20±5 mL；S-Step2 250±5；M-Step3 300±5；L-Step4 350±5；XL-Step5 350±5；XXL-Step6 350±5）；用 1000 mL 烧杯取出规定量液体均匀倒入水槽；评估样品，观察绒毛的缺失情况及 SAM 与绒毛的分布情况；打分并拍照保存。评分档位为：SAM/Fluff 混合均匀、无分层无明显堆积；SAM 局部堆积（堆积总面积 <4 cm²）但无分层；有分层现象但分层不连续或不明显，或 SAM 结团总面积 >4 cm²；绒毛/SAM 在产品中部有明显分层、形成长条形连续性分层现象（靠近上下端有少量绒毛堆积不算作分层）。

## 测试方法要点 Method Specification

| 项目 | 口径 |
|---|---|
| 溶液 | 蓝色水溶液（≥500 mL 备量），非 0.9% 盐水（原文只写"蓝色水溶液"）`[待验证]` |
| 水槽 | 型号 C124-A4-05467/68/70-C-02（按产品型号选） |
| 切样 | 面层向下，1 英寸切刀切 MD 方向中间位置 |
| 摆放 | 面层向下平放于水槽底部，持端封保持水平 |
| 判读 | 绒毛缺失情况 + SAM/绒毛分布与分层堆积 |
| 输出 | 评分 + 拍照 |

**液量分档 Liquid volume by size**

| 产品型号 | 溶液用量 |
|---|---|
| 初生（NB-Step1） | 20 ± 5 mL |
| 小号（S-Step2） | 250 ± 5 mL |
| 中号（M-Step3） | 300 ± 5 mL |
| 大号（L-Step4） | 350 ± 5 mL |
| 加大号（XL-Step5） | 350 ± 5 mL |
| 加加大号（XXL-Step6） | 350 ± 5 mL |

**评分档位 Scoring rubric**

| 档位 | 判据 |
|---|---|
| 均匀档 | SAM / Fluff 混合均匀，无分层、无明显堆积 |
| 局部堆积档（原文标 5 分） | SAM 局部堆积，堆积总面积 <4 cm²，但无分层 |
| 3 分 | 有分层现象，但分层不连续或不明显；或 SAM 结团总面积 >4 cm² |
| 1 分 | 绒毛/SAM 在产品中部有明显分层，形成长条形连续性分层现象（靠近上下端少量绒毛堆积不算分层） |

> ⚠️ 评分表存疑：原文图中「混合均匀」与「局部堆积」两档**均标 5 分**，疑后者应为 4 分。本页照录并标 `[待验证]`。
