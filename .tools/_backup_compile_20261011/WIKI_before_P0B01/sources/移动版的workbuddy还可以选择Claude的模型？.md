## Key Claims 关键论断

1. **Mobile model availability 移动端模型可选性** — Mobile clients expose DeepSeek/GLM/Kimi by default and additionally allow GPT/Claude/Gemini; Claude is materially more expensive in credits. （中文：移动端默认 DeepSeek/GLM/Kimi，亦可选 GPT/Claude/Gemini，Claude 积分消耗更高。）
2. **EDANA / INDA are sister organisations EDANA 与 INDA 为姐妹协会** — EDANA covers Europe (1971, Brussels, 250+ members) while INDA covers the US (200+ members); they jointly develop the WSP methods referenced throughout hygiene materials testing, see [[EDANA（欧洲非织造布协会）]].
3. **WSP is the shared test vocabulary WSP 为共同测试语言** — Acceptance criteria in this knowledge base are routinely expressed in WSP terms; see [[芯体测试方法与验收基准（STM）]].
4. **Regional counterpart 区域对应组织** — CNITA plays the analogous role in Asia; no standalone page is created here because the mention is single-source.
