| 表面覆盖层 | 亲肤透气无纺布 / 打孔膜 | 下渗、阻回渗、保持干爽 |

### ADL 与 REL 功能分工（本页核心增量）

| Dimension 维度 | REL（收集/传递层）第一道防线 | ADL（导流层）交通枢纽 |
| --- | --- | --- |
| 功能侧重 | 垂直方向的「收」：瞬间捕获冲击性液体，暂存并向下传递 | 水平方向的「导」：沿平面纵向扩散，均匀分配至 SAP |
| 密度与孔径 | 低密度、大孔径，需极大空隙容纳瞬时涌流 | 中等密度、定向孔径，控制流向与扩散速度 |
| 材料结构倾向 | 粗梳合成纤维网，含中空/卷曲纤维的空气铺网织物，强调蓬松与回弹 | 高蓬松热风非织造布，带开孔的三维膜/非织造布，强调导流路径 |
| 粘合剂 | 侧重湿态结构锚固（SBR 胶乳 / VAE），防受力塌缩 | 侧重低粘着，保证表面多孔，提升三维回渗性能 |
| 失效风险 | 受压塌缩或吸水软化 → 失去瞬间接收能力 → 溢漏 | 导流不足或「凝胶堵塞」 → 局部过载 → 回渗/侧漏 |

### ADL 效率提升五策略 Five ADL levers

| Lever 策略 | Design window 设计窗口 | Mechanism 机理 |
| --- | --- | --- |
| 纤维组分分层 | 上层 >5 d 高旦尼尔（大孔隙 + 骨架支撑，快速涌入）；下层 <5 d 低旦尼尔（致密通道 + 毛细吸力） | 上蓄下抽 |
| 熔喷转向层 | 分层梳理网下增设 **15–50 gsm** 熔喷组分 | 超细纤维网把上层液体「拔出」转移至芯体，减少表层回渗 |
| 多层密度梯度 | 顶层低密度高膨体（水库暂存）+ 底层高密度（毛细抽离） | 形成单向驱动力 |
| 漏斗形贯通孔 | **3–20 个/cm²**，突起朝向芯体 | 单向阀效应，液体易进难出，提升干爽度并减少恶臭 |
| 开孔率与纤维直径 | 70% 纤维直径 **12–22 μm**；开口面积 **35–65%**；0.5 kPa 下厚度 **0.8–1.2 mm** | 兼顾支撑力与排水性 |

## Key Claims 关键论断

1. **REL ≠ ADL：一个是「收」、一个是「导」** — REL 负责垂直向的瞬时捕获与暂存（低密度大孔径、湿态锚固），ADL 负责水平向的纵向扩散与均匀分配（中等密度定向孔、低粘着）；混用这两个词会导致失效归因错误，见 [[ADL（导流层）]] 与 [[REL增强层]]。
2. **Denier layering is the cheapest ADL lever 旦尼尔分层是最廉价的 ADL 杠杆** — 上层 >5 d 提供涌流空隙与骨架、下层 <5 d 提供毛细抽力，直接对应「上蓄下抽」。
3. **Meltblown turning layer bridges scales 熔喷转向层跨尺度桥接** — 15–50 gsm 超细纤维网把粗孔中的液体「拔」向芯体，是降低表层回渗的具体手段，与 [[Meltblown Nonwoven（熔喷非织造布）]] 的细旦能力对应。
4. **Funnel holes are one-way valves 漏斗孔即单向阀** — 3–20 个/cm²、突起朝芯体，实现「易进难出」，与 Janus/毛细压差思路同源。
5. **Aperture window is narrow 开孔窗口很窄** — 开口面积 35–65%、纤维直径 12–22 μm、0.5 kPa 下 0.8–1.2 mm，超出即失去支撑或排水。
6. **Overlap note 重复说明** — 本文与 [[纸尿裤的核心结构及市场主流方向]] 在结构/品牌/芯体部分高度重叠；本页保留其增量（ADL/REL 与设计窗口），其余仅作交叉引用。
