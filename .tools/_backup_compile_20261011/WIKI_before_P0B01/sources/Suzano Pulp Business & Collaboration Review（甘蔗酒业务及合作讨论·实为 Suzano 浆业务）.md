## 一句话定位

与核心桉木浆供应商围绕 **TCF 等级认证进度、PSC 合规流程、区域供应分配、以及 fiber-to-fiber（短纤替代长纤）联合推广** 的一次业务 + 技术对齐会。

## Key decisions 决策要点

> 只记会上明确「定了 / 就这么做」的事项。

1. **TCF 等级继续推进，8 月恢复试产**：供应商 7 家浆厂中多数已完成 TCF 转换，剩余一家仍在进行中；此前因「同一时间叠加多个项目」造成过程不稳，已**回退到已知条件、用同一化学品体系重新上路**，计划 **8 月恢复**，中国/亚洲交付时间约**年底**（土耳其为 8 月）。
2. **样品 grade 名称必须与未来商业化一致**：发给客户（尤其韩国）的样品，**只要能保证同一 grade、同一性能即可立即发**；若届时 grade 名不同，认证流程要重跑。需以邮件明确告知对方。
3. **文档更新是硬性前置**：grade 变更（含 TCF）必须同步更新 **spec / TDS / PS number / RMS（raw material spec）**；由 productivity 团队（全球团队，运营层面在印度）执行。
4. **PSC 的触发时点**：**TCF 等级商业化之后**才申请产品安全认证；仍在 trial 阶段时不应启动（spec 尚未冻结）。
5. **ECM 项目统一切换**：中国湿巾代工厂（wipes）正在把不可批准的浆等级全部换掉；为避免「先换一版、几年后再换 TCF」的二次切换，**等 TCF / 新等级可供亚洲后一次性切换**。
6. **fiber-to-fiber 的优先市场定为台湾与澳大利亚**（会上明确建议先按此方向推进），用已有 hero case 给当地团队做思路示范，再由对方自行决定是否要我方支持。
7. **JV 之后的技术接口分工**：KC 侧对韩国仍走常规客户流程；对 IP 侧由驻欧洲的接口人负责。

## Open issues 待决问题

- **韩国的认证流程与 JV 后 IP 的流程不一致**：JV 后 IP 采用**更集中、决策更快**的流程（一个浆厂通过可延展到其他浆厂）；韩国**不在 JV 内**，仍按常规客户流程走，两条线并行，接口人与文档口径尚未统一 → **待厘清**。
- **PSC 是否现在就触发**：仍在 trial → 建议等商业化；但需与合规侧最终确认。
- **供应缺口**：原计划发往高雄（Kaohsiung）的 **1,000 吨**发货**已取消**，原因是 TCF 产品量不足 → 需与 planning 团队重新排期（以 6 月船期为基准复核）。
- **区域分配未定稿**：亚洲（含中国、韩国）计划用新等级；欧洲**仍在评估**（可能同等级，同时保留巴西现有供应）；拉丁美洲**在分析是否跟进** → 未承诺。
- **港口 consignment 库存空间不足**：过去 10 年无问题，近 2–3 年用量上升后现有堆场设计已到瓶颈；扩容需 YK 与 Suzano 协同，**费用分担待谈**（Suzano 承担卸货与操作费，港口其他费用由对方承担）。
- **白度（brightness）变更的影响**：台湾/泰国/澳洲若把白度从 **81 提到 88**，在 furnish（配比）不变的前提下预计无问题，但需纳入认证早期一并考虑。
- **pitch（树脂/粘性物）敏感度**：pitch 对下游工序影响大（我方造纸机已开始出现问题），是后续质量关注重点；**下游工艺条件（温度、pH、剪切力）也会放大或缓解该问题**。
- **历史质量事故**：2–3 年前的两起——**黑砂（black sand）** 与 **黑色污染（pitch / oil）**，分别源自芬兰与韩国 → 均触发停机清理与换网等大处理。
- **硬木供应格局**：中国区 hardwood 产量约 **15,000 吨/年**（其中约 10,000 吨来自一处基地），仍有约 **5–6 千吨**的切换机会；**景兴（Jingxing）** 相对东莞的重要性在上升 `[待验证]`。
- **磨片是否必须更换**：不换磨片、仅切换 grade 也能省 refining energy；但要做到 **BSKP 由 10–15% 降到 0%** 的全短纤方案，**建议重新选型磨片**。国内装备（含黑龙江等厂商）已可满足，进口（Andritz / Voith 等）更贵 `[待验证]`。

## Background 背景

核心桉木浆供应商正在把浆产品切换到 TCF 漂白等级，同时与 KC 推进 fiber-to-fiber（以短纤桉木浆替代部分长纤 BSKP）的联合降本项目；两条线都卡在认证流程与文档更新上，故召开本次业务 + 技术对齐。
