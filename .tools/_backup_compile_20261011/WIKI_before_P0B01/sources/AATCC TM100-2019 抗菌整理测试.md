# AATCC TM100-2019 抗菌整理测试

## 一句话定位

AATCC **TM100-2019** 抗菌整理定量测试方法的标准/出版物资料，是本库抗菌性能评估方法的信息源。

## 摘要

The document is an AATCC standards/publications reference that includes **AATCC TM100-2019 — Antibacterial Finishes on Textile Materials, Quantitative**. AATCC (American Association of Textile Chemists and Colorists, nonprofit since 1921) provides trusted textile test methods, quality-control materials and education used globally. TM100-2019 quantifies the antibacterial effect of finished textiles (bacterial reduction / survival after inoculation). The read portion is a standards catalog; the detailed inoculation/counting procedure should be taken from the method text itself.
