# 低熔点 PP 粒子开发任务书

## Positioning 一句话定位

This Chinese project brief defines the baseline three-tier development program for domestic low-melting-point PP resin used in air-through, thermal-calendered, and spunbond hygiene materials.  
（中文：该中文任务书定义了国产低熔点 PP 树脂用于热风、热轧与纺粘卫材的基础三档开发方案。）

## Summary 摘要

The brief links melting-point suppression to disruption of isotactic sequences by ethylene or C4–C10 α-olefin comonomers. Plan A is a lower-risk 150–158°C random-copolymer grade; Plan B is the core 135–150°C binder grade; Plan C is an experimental ≤135°C sheath resin for PP/PP bicomponent fibers. As melting point and crystallinity fall, xylene solubles, slow crystallization, surface tack, and thermal-setting collapse become critical process risks. The document therefore requires enhanced quenching, redesigned drawing and heat-setting windows, and fiber-level acceptance tests. It also distinguishes true fiber-grade resin development from low-MFR heat-seal-film grades and from market labels that use “low melt” for impact copolymers whose melting point remains above 160°C.
