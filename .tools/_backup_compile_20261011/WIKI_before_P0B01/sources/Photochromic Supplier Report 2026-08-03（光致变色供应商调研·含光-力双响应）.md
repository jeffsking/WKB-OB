# Photochromic Supplier Report 2026-08-03（光致变色供应商调研·含光-力双响应）

> 一句话定位：一份 **光致变色（photochromic）供应商格局调研**——它先**把"光致变色"与"力致变色"严格切开**，再回答一个具体命题：**"能因拉力而变色的光致变色材料"到底能不能买到**。（中文：结论是——**买不到成品，只能买到分子**；供应链上真正的关键枢纽是**卖螺吡喃/螺噁嗪原料的那一家**。）

> ⚠️ **来源性质（2026-09-29）**：本件为**自编调研报告**（署名"原材料供应商甄选专家"，2026-08-03），**含 `[F]`/`[I]`/`[A]`/`[E]` 四级证据标注**，但**市场数据来源为行业研究博客与 B2B 平台目录**（源文自注：公司存在可核验，**排名/份额为单一二手来源，按 `[I]` 处理**）。credibility 定为**中**：**格局判断与分级方法可用，份额与排名须尽调**。

## 原文要点 Original Key Points

### 1. 术语边界（本报告的开篇，也是最有价值的部分）

> **严格意义上，光致变色 photochromic = 由光（UV/可见光）触发可逆变色；力致变色 mechanochromic = 由机械力/拉力/压力触发变色。两者机理不同、供应链不同。**

- 命题中的"**可实现拉力变色的光致变色材料**"，对应的是一类 **光–力双响应材料（photomechanochromic / dual-stimuli-responsive）** —— 典型如 **螺吡喃（spiropyran, SP）**、**二芳基乙烯（diarylethene）**、**偶氮苯（azobenzene）**、**萘酰亚胺–螺吡喃杂化体**等光致变色分子被**工程化为力致基团（mechanophore）**，在受力（**研磨、拉伸、超声、压缩**）时发生**异构/断裂**并伴随可见光谱变化。

**三条处理原则（源文）**

1. 主框架按"**光致变色商业供应商**"铺开（原料/颜料/油墨 → 成品与应用）；
2. 单列「**力学刺激响应供应能力**」专项，**严格区分"仅光响应"与"可改造为力响应"**；
3. **不把纯力致材料与纯光致材料混为一谈**，证据按 `[F]` 事实 / `[I]` 推断 / `[A]` 假设 / `[E]` 估算分级。

### 10. 三条结论与四条建议

**结论**

1. **商用光致变色产值 82% 集中于镜片染料**，其配方封闭、仅光响应 `[F]`；
2. **颜料/油墨/成品段**（盛色、崇誉、CTI、QCR、Transitions 等）**均仅光响应，无拉力变色 SKU** `[F]`；
3. **力学刺激响应仅在螺吡喃等原料分子 + 高校配方层面成立**，无现成成品 `[F/I]`。

**战略判断**

1. 光致变色供应链**成熟且集中**，但**几乎全部仅光响应**；镜片段由 Transitions/Essilor、Tokuyama、Mitsui、Vivimed 主导，**颜料/油墨/成品段中国厂商性价比与交期优势显著** `[F]`。
2. **力学刺激响应是"原料级机会"而非"成品级供给"** —— 可采购的力响应光致变色供给 = **螺吡喃/螺噁嗪分子**（**天津塞特瑞为最务实来源**），成品化须自研或联合定制商（OliKrom）与高校 `[F/I]`。
3. **天津塞特瑞是连接"光致变色"与"力致变色"的关键枢纽供应商** —— 其分子骨架与文献双响应体系同源，是任何力响应应用落地的**第一采购锚点** `[I]`。

**建议（均为 `[A]` 假设级）**

1. **若目标为力学指示应用**（如贴身穿戴拉力/贴合度可视化）：以**天津塞特瑞螺吡喃/螺噁嗪原料**为起点，联合 **OliKrom（定制配方）** 或高校（华盛顿大学式 3D 打印/棉布涂层路线）做配方开发。
2. **若目标为常规光致变色成品采购**：镜片/太阳镜走 **Transitions 体系**或中国 OEM/ODM（KARUSON、温州/广州集群）；颜料/油墨走**盛色、崇誉、CTI、QCR**，按应用场景比选成本与合规。
3. **合规前置**：贴身/婴幼儿场景须过 **FDA 21 CFR、EU 10-2011、REACH**；盛色已标"食品接触级"可作优先筛查对象。
4. **建立双响应技术雷达**：跟踪螺吡喃力致变色（**TDBA-SP、NSP、Rh–SP**）与可印刷力响应油墨的专利与中试进展，锁定早期 IP 与供应商。
