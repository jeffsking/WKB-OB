## 提炼的数字与结论 Numbers & Conclusions

⚠️ 本页**不含实测数据**。凡带数字处均为**待向供应商追问的维度或目标口径**，**不是结论**。

### 1. 前沿热点类议题（4 项）

| # | 议题 | 关键追问维度 |
|---|---|---|
| **1** | **生物基 / 可降解结构胶** | **生物基单体占比**；已验证可用于 **SBC / SIS / SARA** 配方的生物基原料；**ASTM D6691（海洋降解）/ ISO 14855（堆肥）**认证进展；与**可降解 SAP（如 Nagase Viita）、PLA 无纺布、纤维素面层**的界面相容性；**生物基含量 vs 剥离力/蠕变抗性/耐老化性** 的 trade-off 数据；海洋可降解结构胶**上市 roadmap** |
| **2** | **超低添加量胶线技术** | **当前结构胶最低稳定涂布量（g/m² 或 gpm）及其极限边界**；螺旋喷涂 vs 其他喷涂 vs 新型喷涂的效率对比；**1000+ ppm 高速产线下稳定性**与**开停机过渡期胶线一致性**；超低量下对**流变性（MFI / 粘度 / 熔融指数）**的特殊要求；**胶量减少 30–50% 后的单位成本净节省** |
| **3** | **皮肤微生态友好型热熔胶** | 胶体是否具备 **pH 缓冲能力**（维持皮肤表面 **pH 4.5–5.5**）；对婴儿皮肤菌群（**葡萄球菌属、棒状杆菌**）的体外/临床数据；**ISO 10993 / OECD 致敏性**测试结果；**低分子量组分迁移至皮肤**的抑制措施；抗氧化剂/稳定剂的安全性选择 |
| **4** | **智能响应型胶粘剂** | **温度 / 湿度 / pH / 离子浓度**响应型的开发进展（概念阶段 or 已有原型）；**尿湿后粘接力自适应变化**（增强防漏 vs 方便剥离）的可行性；技术路径三选一：**形状记忆聚合物 SMP / 水凝胶复合胶 / 相变材料嵌入**；距量产的瓶颈（成本 / 工艺稳定性 / 专利壁垒） |

### 2. 产品开发痛点类议题（4 项）

| # | 议题 | 关键追问维度 |
|---|---|---|
| **5** | **超薄芯体（<2 mm）的胶挑战** | 超薄芯体中**胶层渗透风险**控制；各层间**剥离力优化窗口**与胶线位置/宽度对层间完整性的影响；薄型化后**抗蠕变下降**与长期存储形变；有限空间内胶线排布策略（**连续 vs 间断 vs 点阵式**） |
| **6** | **弹性材料专用胶** | **氨纶 Spandex / SPE（苯乙烯弹性体）/ TPU / TPE** 各自最优胶接方案；**反复拉伸 >500 次循环**后的粘接保持率与疲劳失效模式；弹性膜与无纺布**层合温度压力窗口**及高温对弹性的损伤；**胶接区硬度增加（hard spot）**与软触感配方思路 |
| **7** | **亲水 / 疏水性差异化胶** | **ADL 区域用疏水胶**的需求与可行性；**面层与芯体粘接用亲水胶是否会加剧反渗**；同一片产品内**不同功能区差异化胶种**的工艺实现；胶线自身拒水处理（**氟碳涂层 / 硅油**）**对后续回收的影响** |
| **8** | **工艺窗口宽窄** | 推荐操作温度区间与 **>180 °C / <130 °C** 极端表现；**产线速度 ±20% 波动**下胶线宽度与重量稳定性；车间温湿度对流变与粘接质量的影响；**换胶周期**（不同批次/牌号切换时间与废料损失） |

### 3. 可持续发展类议题（3 项）

| # | 议题 | 关键追问维度 |
|---|---|---|
| **9** | **碳足迹与 LCA** | 单片纸尿裤全部胶水的**碳排放基数（kg CO₂e/unit）**；生物基替代 **30% / 50% / 100%** 后的减排幅度；**Scope 3 协同**（单体供应商 + 品牌商联动）；与传统石油基胶的**全生命周期 EPD 对标**；第三方碳足迹认证计划（Carbon Trust / TPF） |
| **10** | **回收 / 循环经济适配** | 化学/机械回收场景下胶的**可分离或共处理设计**；**水热解 / 水解**回收流程中胶的行为（是否干扰纤维回收或 SAP 提取）；**热解 / 溶剂溶解**回收时胶组分的**产物与毒性**；**面向回收的设计（DfR）**在胶水开发中的落地 |
| **11** | **无溶剂 / UV 固化路线** | 适用于高速产线的**无溶剂胶**方案；**UV 固化胶**在多层复合材料中的应用潜力与挑战；**传统热熔胶 VOC 排放基准值**与新路线减排幅度；**设备改造投资与成本估算** |

### 4. 蓝海 / 探索类议题（4 项）

| # | 议题 | 关键追问维度 |
|---|---|---|
| **12** | **胶线功能集成化** | 能否把**抗菌 / 香氛 / 示温 / 酸碱指示**集成进胶线；功能因子**缓释速率与长效性**；添加剂**法规准入（REACH / EPA / 中国 GB）**；医药贴剂或功能性纺织品的**类比案例** |
| **13** ★ | **纳米纤维素增强胶（重点协同点）** | **CNC / CNF 作为热熔胶增强相**的可行性与增韧/增强效果；纳米纤维素在**高粘度熔体中的均匀分散**工艺挑战；**表面改性（酯化 / 硅烷化 / 接枝）**提高与聚合物基体相容性；**JDA / 联合实验室**可能性；**专利布局现状与合作开发的 IP 归属框架** |
| **14** | **静电纺丝纳米纤维膜的无胶粘接** | 纳米纤维膜**热压 / 超声波自粘**可行性；纳米级纤维**低压热压下的熔融互锁机制**；无胶粘接 vs 传统热熔胶的**剥离强度 / 耐水性 / 耐老化性**对比；**量产路径**（设备 / 速度 / 成本）；优先应用场景（**腰围 / 腿围**） |
| **15** | **数字化 / AI 辅助胶型设计** | **机器学习驱动的配方性能预测**模型准确度与适用范围；基于高分子材料数据库的**快速定制开发平台**；**从目标性能反推最优配方**的逆向工程能力；AI 能否把传统胶型开发周期**从 12–18 个月**缩短；**客户是否可接入平台**自主筛选与虚拟验证 |

### 5. 优先级矩阵与交流技巧

| 优先级 | 议题 | 理由 |
|---|---|---|
| **⭐⭐⭐ 必谈** | 1 生物基胶、**2 超低添加量**、6 弹性材料专用胶 | 直接影响下一代产品竞争力，汉高核心优势区 |

2. **带具体参数去谈**（例如"我们追求 XX g/m² 以下"），避免泛泛而谈；
3. **议题 13 是最佳的 JDA 切入点**——可直接抛出联合研究意向；

5. **备好己方当前使用的胶种型号与痛点列表**，便于针对性讨论替代/升级方案。

## 关键论断 Key Claims

1. **这份清单的真正资产是"提问结构"** —— 每个议题都按**材料体系 / 标准认证 / 兼容性 / 性能平衡 / 时间表**或等价的 4–5 个维度展开；**同一套维度树可平移到任何一家胶供应商**。
2. **"可降解胶"的第一个问题不是降解率，而是界面相容性** —— 源文把**与可降解 SAP（Nagase Viita）、PLA 无纺布、纤维素面层的相容性**与降解标准并列；**胶是连接者，它必须同时兼容两侧的可降解基材**。
3. **超低添加量的三个极限是并列的** —— **涂布量极限（g/m²）**、**机速极限（1000+ ppm）**、**流变极限（MFI/粘度）**；**只谈"能涂多薄"而不谈机速与流变，等于没谈**。
4. **超薄芯体（<2 mm）把胶变成了渗透风险源** —— 在薄芯体里，**胶层本身的渗透**与**层间剥离力窗口**是新的失效模式；胶线排布（连续/间断/点阵）成为设计变量。
5. **"亲水胶会不会加剧反渗"是一个被明写出来的疑虑** —— 面层与芯体粘接用亲水胶的**反渗代价**被列为待问项；**这直接把胶纳入回渗归因链**。
6. **可回收性给胶提出了"退出路径"问题** —— 水热解/水解/热解场景下胶**是否干扰纤维回收或 SAP 提取**、产物是否有毒，**这是 DfR 在胶上的具体落地**。
7. **纳米纤维素增强胶被定位为"我方主动出题"的协同点** —— 与生物基胶、超低量（汉高既有优势区）不同，议题 13 的落点是 **JDA / 联合实验室 + IP 归属框架**，**属于共同开发而非采购**。
8. **AI 辅助配方设计的判据是"周期压缩"** —— 源文给出的基线是**传统胶型开发 12–18 个月**；**能否把客户接入平台自主筛选**，是判断该能力是否外溢的关键问题。
