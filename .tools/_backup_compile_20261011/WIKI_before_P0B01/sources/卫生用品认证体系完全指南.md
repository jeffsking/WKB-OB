# 卫生用品认证体系完全指南（法规地图·第八篇）

## 一句话定位

《全球卫生用品法规地图》系列第八篇，系统讲清 OEKO-TEX / bluesign / EU Ecolabel / ZDHC MRSL / ISO 14001 五大认证体系的边界、关系与优先级——**本库「出口合规与客户准入」的总纲来源**。

## 摘要

文章从行业交流群中最常被混淆的问题切入（「做 REACH 合规够了吗」「bluesign 和 OEKO-TEX 先做哪个」），先确立认证与法规的根本区别：法规（REACH / GB / CPSIA）强制、违反有罚则；认证自愿、不做无法律风险，但正成为采购的事实门槛。随后逐一拆解五大体系：OEKO-TEX 是以产品视角检测有害物质的认证家族（STANDARD 100 覆盖 100+ 项指标，纸尿裤属 Product Class I），bluesign 从工厂生产系统出发评估资源效率、消费者安全、工人健康、空气排放、废水五大支柱，EU Ecolabel 由欧盟委员会 DG ENV 主管、采用产品生命周期视角，ZDHC MRSL 管控投入使用的化学品本身（通过 ZDHC Gateway 注册），ISO 14001 是环境管理体系基础认证。文章给出五大体系横向对比表、卫生用品认证适用矩阵、五个常见误区与按企业类型的认证路线图。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| OEKO-TEX 组成 | 18 个国际检测和认证机构，总部苏黎世 | 协会性质 |

### 五个常见误区（原文）

| 误区 | 正确认知 |
|---|---|
| 有 OEKO-TEX 就等于满足 REACH | 错。认证不替代 REACH 法律义务；SVHC 通知义务与供应链申报无法由认证报告替代 |
| bluesign 是产品认证、可贴在产品上 | 错。认证对象是工厂生产系统；工厂认证后其产品可标注 bluesign APPROVED |
| EU Ecolabel 和 OEKO-TEX 选一个就够 | 不完全正确。关注点不同：前者含生命周期环境与纤维来源，后者聚焦产品有害物质 |
| 认证取得一次即长期有效 | 错。有效期 1 年（OEKO-TEX）至 3 年（bluesign/EU Ecolabel），限值逐年收紧 |
| ZDHC 只是大品牌的事 | 不准确。要求沿供应链传导至整理剂/助剂供应商 |

## 关键论断（key_claims）

- **认证与法规不可互相替代**，但认证覆盖范围通常超前于法规 —— 支撑页：[[认证与法规的区别]]
- **OEKO-TEX STANDARD 100 是婴儿卫生用品出口欧洲的第一优先认证**，测试数据可兼作 REACH 合规技术支持文件 —— 支撑页：[[OEKO-TEX]]
- **bluesign 认证工厂、ZDHC 认证化学品、EU Ecolabel 认证生命周期环境表现**，三者对象不同不可互替 —— 支撑页：[[bluesign]]、[[卫生用品五大认证体系对比]]
