# CoPET-PET 与 PE-PET 成本差异对比 v3（卫材级对等口径修正）

## 一句话定位

`CoPET_PET与PE_PET成本差异对比_v3.xlsx` 是一份**三级价格（原料 → 切片 → 纤维）的成本对比表**，其价值**不在给新数字，而在纠正一个口径错误**：此前「CoPET/PET 比 PE/PET 便宜 12~30%」的结论来自**工业级 vs 卫材级的不对等比对**。在卫材级对等口径下，两者**基本同价**，成本因此**不再是选型的决定变量**——决定变量是**认证壁垒与性能**。

> 补充：本页**不含合同条款、未公开合作方或个人联系方式**——上述项在该源文件中未出现。

## 摘要

源文件给出 8 张表：原料价格基准（2026-07）、纤维级市场价格、三种皮芯结构对比、CoPET/PET 完全成本拆解、CoPET/PET 与 PE/PET 原料成本逐项对比、全品类价差汇总、采购情景与价格趋势风险、综合结论。

**核心结论（原文综合结论表，五条）**：
1. **工艺同质性**：CoPET/PET（TT 型 4080）与 PE/PET（ET 型）**均为皮芯双组分 ES 工艺**，仅皮层材料不同，芯层均为 PET ⇒ **对比必须同级**。
2. **价格对等（核心修正）**：卫材级两者均锚定 ~10,000~11,600 元/吨，**基本同价，价差 <5%**。
3. **真实差异来源**：皮层材料微差（原料级仅 +7%）、认证壁垒（2~3 年周期）、性能（手感 / 熔点 / 相容性）。
4. **采购建议（修正）**：按规格/认证/性能选型，而非按「谁便宜」。
5. **数据置信度**：见 key_claims 末条。

## 关键论断（key_claims）

- **v3 = 口径纠偏**：「CoPET 便宜 12~30%」是工业级对卫材级的不对等比对假象；卫材级对等同价。 —— 支撑页：[[CoPET-PET 与 PE-PET 皮芯纤维对比]]
- **原料级真实差异 +7%、完全成本 +8% ⇒ 成本不是决定变量。** —— 支撑页：[[CoPET-PET 与 PE-PET 皮芯纤维对比]]
- **反直觉：LDPE 皮层（9,250）比 CoPET 皮层（7,900）贵 1,350 ⇒ 「PE 皮更便宜」的直觉错误。** —— 支撑页：[[CoPET（低熔点共聚酯）]]
- **差异真正在认证（2~3 年周期，溢价 10~15%）与性能（手感/熔点/相容性）。** —— 支撑页：[[皮芯复合纤维]]

- ⚠️ **与既有页两处冲突（未裁决）**：毛利率 10~15% vs 3~6%；纺丝加工费 800/950 vs 1,850/2,050。 —— 支撑页：[[CoPET 与 PET 成本对比]]、[[CoPET-PET 与 PE-PET 皮芯纤维对比]]
