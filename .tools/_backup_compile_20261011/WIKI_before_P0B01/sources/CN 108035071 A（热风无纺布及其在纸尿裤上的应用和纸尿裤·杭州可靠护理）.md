# CN 108035071 A（热风无纺布及其在纸尿裤上的应用和纸尿裤·杭州可靠护理）

## One-line positioning 一句话定位

A manufacturer application claiming a **zonal-hydrophilic, conically-perforated hot-air nonwoven topsheet**（局部亲水印花+锥形打孔热风面层）：把「亲水才下渗、拒水才干爽」做成一张布上的分区方案，并用**表面张力数据（70 / 31–50 / <30 dyne/cm）**论证了「拒水布打孔无效、亲水区打孔才有效」。对本库是**面层亲水-拒水梯度设计最完整的工艺参数锚点**（含车间温湿度、印花辊规格、烘箱与打孔温度全窗口）。

## Technical breakdown 技术拆解

1. **原理链**：合成纤维纺丝油剂不含亲水剂 → 全亲水面层「过于潮湿、易红臀」→ 全拒水面层打孔无效（水 70 dyne/cm vs 纤维 31–50 dyne/cm，水进不了孔）→ 局部亲水（<30 dyne/cm 成膜）+ 孔开在亲水区内 = 干爽与下渗兼得。
2. **结构**：拒水基底 + 印花亲水区 + 亲水区内锥形通孔（顶 0.4–0.5 mm、底 0.12–0.25 mm，上大下小防反渗）；单/双/三层均可。
3. **工艺链（5 步）**：选纤维 → 开松梳理成网+热风加固+烫光+冷却定型 → 印花辊局部印耐久亲水剂 → 双层热风烘箱烘干 → 针辊打孔并同步固化亲水剂。
4. **整机应用**：面层 + 下层无纺布 + 导流层 + 复合芯体 + 防侧漏隔边 + 防渗底膜复合成裤。
