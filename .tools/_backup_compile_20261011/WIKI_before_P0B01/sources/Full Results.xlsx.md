# Full Results.xlsx

## Basic Information 基本信息
- **位置**: Surge-Liner Interface / Test Results（Rewet Fundamentals 子目录）
- **性质**: 试验矩阵原始结果汇总（22 codes）
- **Domain**: Performance / Rewet / 面层-导流层界面

## Test Matrix 试验矩阵（试验矩阵）

| 变量 Factor | 水平 Levels |
| --- | --- |
| 主基材 Primary substrate | 74mm CT5 surge vs 12gsm SB liner |
| 施胶 Adhesive | Henkel 5402 vs Rextac RT-8723 |
| 上胶量 Add-on | 1.7–3.9 gsm |
| 喷嘴 Nozzle | Signature / Summit / Minibead / CF Swirl |
| 压合 Bonding | None vs Pressure / PICASSO |

## Key Results 关键结果（关键结果）

- **残留液量 Residual fluid mass**: 0.096–0.157 g
- **附着强度 Attachment strength**: 15.4–537 gf（跨度大，说明施胶/压合组合对界面结合影响显著）
- **Control**: code 17
- **Code 17B "Loki"**: 换用 China Liner，残留液 **0.096 g 为全矩阵最低**

## Interpretation 解读
- 残留液整体已进入 GRIFFIN 目标带（≤0.15 g 量级），组合间差异更多体现在附着强度维度。
- 最低残留液（17B, China Liner）提示 liner 供源本身对 desorption 通路影响显著，与 [[Rewet Mechanisms Desorption and Flowback（回渗双机理：解吸与回流）]] 的摄入系统归因一致。
