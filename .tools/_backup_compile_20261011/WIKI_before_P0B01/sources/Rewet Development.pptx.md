# Rewet Development.pptx

## Basic Information 基本信息
- **Date**: 2025-08（K-C 内部培训材料）
- **Domain**: Performance / Rewet —— 定义、消费者关联、方法沿革

## Definition 定义（定义）
- Rewet 是**产品表面干爽**的度量。
- 常被用来**暗示甚至宣称**皮肤干爽——但这不准确（见下）。

## 与其他吸收特性的边界
- 影响 rewet 的设计杠杆同时影响其他吸收系统特性；但 **rewet 与 leakage 不相关**——理解 leakage 应用 intake、runoff 等测试。
- 反之，intake / retention capacity 也不必然给出 rewet 洞察。**各测各的，不可互相替代。**

## Consumer Relevancy 消费者关联（消费者关联）
- 皮肤干爽是皮肤健康与刺激的关键因素。
- Rewet 只是皮肤水分的众多影响因素之一 → **与 skin moisture 相关性差**；**inner cover breathability 是主驱动**（Skin Moisture vs Mocon 数据）。
- **EWL 仍是 substantiate 皮肤干爽的推荐方法**。

## History 宣称与方法史（宣称与方法史）

| 时点 | 事件 |
| --- | --- |
| 2014 前 | KC 以 **TEWL** 作为产品湿度度量 |
| 2014 | **P&G 发起激进 rewet 宣称**；KC 质疑并主张 TEWL 更优；**NAD 裁定 rewet 宣称可成立** |
| 此后 | BCC 与 AFC 分别开发**消费者相关参数**的 rewet 方法 |
| 后续 | Depend 基于 Poise 方法**加 curvature** 以更好反映其产品使用条件 |
