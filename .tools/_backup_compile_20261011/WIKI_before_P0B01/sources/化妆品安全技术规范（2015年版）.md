# 化妆品安全技术规范（2015年版） / Safety and Technical Standards for Cosmetics (2015 Edition)

## 一句话定位

One-sentence positioning 一句话定位：中国化妆品安全的顶层强制性技术规范（2015年版，2016-12-01 施行），规定禁限用组分、准用组分及检验方法，是卫品湿巾/护肤配方合规的基线依据。

## 摘要

- 由原卫生部《化妆品卫生规范》(2007) 修订而来，国家食品药品监督管理总局（CFDA，现 NMPA）组织编制，2015 年 11 月经化妆品标准专家委员会审议通过、批准颁布，**自 2016-12-01 起施行**。
- 全文八章：概述（范围/术语/安全通用要求）、禁限用组分（禁用 1388 + 限用 47）、准用组分（防腐剂 51 / 防晒剂 27 / 着色剂 157 / 染发剂 75）、理化检验方法 77 个、微生物检验 5 个、毒理学试验 16 个、人体安全性检验 2 个、人体功效评价 3 个。
- 本版主要修订：铅限量 40→10 mg/kg、砷 10→2 mg/kg、新增镉 5 mg/kg、二噁烷 ≤30 mg/kg、石棉不得检出。
- 与 EU / US / JP / KR / CA / 中国台湾等法规比对后调整禁限用要求与部分准用组分限量。

## 关键论断（key_claims）

- 中国化妆品合规基线 = 本规范 + 后续修订公告；卫品湿巾/护肤配方中防腐剂、限用组分须落在表3/表4 限量内。
- 重金属与风险物质（铅/砷/镉/二噁烷/石棉）限值是原料入厂与成品放行的安全红线。
