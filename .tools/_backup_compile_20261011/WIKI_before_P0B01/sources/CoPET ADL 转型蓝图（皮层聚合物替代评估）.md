# CoPET ADL 转型蓝图（皮层聚合物替代评估）

## 一句话定位

「是否把 ADL 的 ES 纤维皮层从 PE 换成 CoPET」的**决策级提案**：把工程收益、商业溢价、供应链分层与试验路径压缩到一页可决策的框架。与本批 [[CoPET-PET 与 PE-PET ES 纤维 ADL 影响模拟（英文详版）]] 同族，但更偏「给管理层下判断」。

## 摘要

蓝图开篇给定结论框架：CoPET 在第 3 次冲击的干爽性能上有明确优势（**回渗质量 -24%**），但需要热工艺重调来抵消**约 16% 的市场溢价**。工程证据上，相对 PE/PET，CoPET/PET 的第 3 次冲击摄入从 32 s 降至 27 s、MD 铺展从 175 mm 增至 205 mm（核心利用率 +17%），第 3 次回渗 0.34 g → 0.26 g；模拟固定变量为 ATB 35 gsm 的 ADL、相同 SAP/绒毛浆/面层、3×60 mL 合成尿液间隔 15 min，唯一变量是 ES 皮层。商业证据上，基础聚合物制造端 CoPET/PET 反而**便宜约 2.5%**（约 9,528 vs 9,772 元/吨），溢价来自 IPA 添加剂价格波动（30 天内大幅摆动）与利基市场加价——原文直陈「16–40% 的市场溢价是供需缺口造成的，不是物理定律」。供应链现实是：26 家潜在厂商中仅 **5 家为 Tier A**（真正供应 CoPET ADL 短切纤维），其余 21 家是上游切片商或传统 PE/PET 厂；Tier B 为切片商（如桐昆、三房巷），供 Tier A 使用，**不应直接向 Tier B 索取成品报价**。最大工程风险被命名为「厚度陷阱（Caliper Trap）」：CoPET 粘合点更强更硬，沿用 PE 烘箱温度会造成过粘合、熔掉空隙体积；若 ADL 厚度损失 ≥8%，-24% 的回渗收益将归零，因此文档要求「厚度回复必须完全匹配 PE 基线，空隙体积不可让步」。落地路径为阶梯式：100% PE 对照 → 30% CoPET 平衡共混 → 60% 进取共混 → 100% 溢价方案，并建议**立刻从第 2 级（30%）起做中试线试验**。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| 第 3 次冲击回渗 | 0.26 g（CoPET）vs 0.34 g（PE），-24% | 模拟值 |
| 第 1 次冲击摄入 | 14 s（CoPET）vs 16 s（PE） | 模拟值 |
| 第 3 次冲击摄入 | 27 s（CoPET）vs 32 s（PE） | 模拟值 |
| MD 铺展（第 1 / 第 3 次） | 110 / 205 mm（CoPET）；95 / 175 mm（PE） | 核心利用率 +17% |
| 制造成本 | 约 9,528 元/吨（CoPET/PET）vs 约 9,772 元/吨（PE/PET） | CoPET 低约 2.5%，工程估算 |
| 市场价差 | 基础聚合物 7,650 + 添加剂与市场加价 1,250 = 8,900 元/吨 | ⚠️ 报价类，见 manual_review |
| 市场溢价 | 约 16%（区间口径 16–40%） | 相对常规 PET |
| 供应商盘点 | 潜在 26 家 → Tier A 仅 5 家 | 其余 21 家为上游/传统厂 |
| 皮层熔点 | CoPET 110–180 ℃（可定制）vs PE ~130 ℃ | — |
| 过粘合阈值 | 厚度损失 ≥8% → 收益归零 | 「Caliper Trap」 |
| 试验阶梯 | 100% PE → 30% → 60% → 100% CoPET | 30% 级可捕获 50–70% 收益 |
| 放行门槛 | 第 3 次摄入 ≥10% 更快；铺展 ≥15% 更长；回渗 ≥15% 更低；厚度回复 ≥ 基线；手感僵硬度惩罚 ≤10% | 中试第 2 级判据 |
