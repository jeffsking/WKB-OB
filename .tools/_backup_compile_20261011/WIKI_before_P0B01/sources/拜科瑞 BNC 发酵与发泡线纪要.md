# 拜科瑞 BNC 发酵与发泡线纪要

## 一句话定位

拜科瑞**发酵线与发泡线的技术纪要**（2026-09-04），是六条应用路线中 A（发泡复合）、B（SAP 交联）、C（粉体增强）、D（PEG 母粒）细节最完整的一手记录，也是「绒毛浆起点 ≥60%」这一配方的出处。

## 摘要

纪要按「发酵线 → 发泡线 → BNC 粉体 → SAP 表面交联 → PEG 母粒」五段记录。**发酵线**：拜科瑞正在建中试线以验证全工业放大工艺参数，总 CAPEX 约 RMB 3 M，BMC 发酵线产出约 50 kg/天 100% BNC；10K 吨/年 100% BNC 发酵车间处于可行性研究阶段，预计投资 RMB 50 M；工艺为托盘发酵 7 天、H₂O₂ 脱色，得 2 wt% BNC 水凝胶（98% 是水），释放 98% 水分能耗巨大，且干燥易发生 horrification（塌孔）。干燥路线判断：冻干最抗塌孔但效率存疑；超临界 CO₂ 干燥 CAPEX 高；**闪蒸蒸馏是 100% 纯度 BNC 的工业化平衡方案**。**发泡线**：当前发泡 BNC 主用于包装（刚性），公司具备调节发泡材料软硬度的技术；恒安（Hygiene 行业）正与其用 BNC 发泡开发卫生巾垫片；我方已看到涂覆发泡 BNC 到无纺布的样品、手感软，但两问题：① horrification（表面孔隙差、水透过发泡 BNC 耗时长，但一旦透入内部亲水性很好）；② 强度低（蓬松发泡体一旦受压完全不回弹）。**对 KC 的跟进建议**：送 1 卷 18 gsm TABCW 无纺布（正确 CD 宽度与芯体尺寸）+ 纤维化绒毛浆，索取绒毛浆基发泡样品；绒毛浆/BNC 比例需实物验证，建议 60% 绒毛浆起步（高比例、<2 mm 短纤维更优）；绒毛浆提供内部强度并作支撑骨架，同时构建表面毛细通道以缓解 horrification（待样品验证）；远期看能否开发纸尿裤（及卫生巾）超柔软材料。**粉体**：拜科瑞将用三种干燥工艺（冻干 / CO₂ 超临界 / 闪蒸）做实验室规模纳米纤维素粉分析，并向我方交付约 5 kg 细级疏水处理 BNC 粉 + 粒径分布 + 水纯度报告；99.9% BNC 粗估约 50K RMB/t（需按干燥工艺验证）。**SAP 交联**：拜科瑞正与中国 SAP 供应商合作 BNC 基表面交联化学品，SAP 供应商名称保密，但同意核实排他协议以确认能否在 2 周内与我方建议的 SAP 供应商直接合作；机理为 50 nm × 2 μm BNC 纤维在 SAP 表面成网络（提升 AUL）、BNC 导液而非单纯间隔、共反应进交联壳（纤维素羟基与多元醇/碳酸亚烃酯/环氧化物同化学）。**PEG 母粒**：因 BNC 干燥易塌孔丢失孔隙率，提出可低成本工业放大的 BNC:PEG 母粒路线，并延伸出吸收芯粘合剂（BNC:PEG 作 SAP 间隔层 + PCL 调开松时间 + PEG 调粘度）、接枝功能（Na⁺ 吸收、除臭抗菌、压力/温度传感）与精油/乳液缓释涂层平台。
