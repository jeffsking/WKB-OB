# PPC&PGA 基无纺布开发方案（第二版）

## 一句话定位

本批次的**技术方案页（PPT 版式）**：把 PPC-P 从「供应商的一种树脂」推进到「两种卫材无纺布形态」——**PPC-P/PBAT 纺粘布**与 **PPCP+PBAT+PLA 皮 / PGA 芯的 TABCW 纤维**，并给出两条路线的初版成本估算与下一步试产安排。

## 摘要

方案前段与 [[LXBIO 拜访报告（2025-09-25 泰兴 PPC-P 基地）]] 同源，重述 PPC-P 的三元共聚配比（CO2 35~40%、PO 40~55%、苯酐 10~20%）、纯 PPC 的 Tg 约 30 ℃ 而引入苯酐后升至 55 ℃ 以上、以及 PPC-P 比 PPC 储存更稳定的结论；四项特征（UV 抗性最优、仅接触微生物降解、高透明近似 PC、水蒸气与 O2 透过性良好）与认证状态（TÜV 可降解、DIN CERTCO、海洋可降解与 FDA 在办）亦一致。

方案的主体是**开发路径**。其一是 **PPC-P 基纺粘（spun-bond）**：**30% PPC-P + 70% PBAT** 经长丝喷丝试验表现出良好可纺性；采购侧正在与 **Yanjan** 推进 NDA 与 NNN，文件齐备后即以**中性包装树脂**送 Yanjan 做纺粘试产，排期 **2026 Q1**，试产须记录树脂熔融温度、喷丝板温度、粘合辊温度与喷丝压力。该路线的树脂估成本被写成算式：`30%×15 + 70%×10 + 3（加工费）= RMB 14.5/kg ≈ USD 2.07/kg`。其二是 **PPCP 基 TABCW 纤维**：PPCP + PBAT + PLA 复合料熔点 **130 ℃**，适合作 TABCW 的**皮层**（目标可家庭堆肥，成本低于 RMB 15/kg）；**PGA** 被描述为「刚性、易纺纱、海洋可降解、已获 FDA 认证、熔点约 220 ℃」的材料（成本低于 RMB 20/kg），充当**芯层**——组合即「PPCP+PBAT+PLA(130 ℃) 皮 + PGA 芯」，被标注为一种**尚待深度技术评估**的可家庭堆肥 TABCW 纤维新材料组合，估成本 `0.5×15 + 0.5×20 + 5 = RMB 22.5/kg ≈ USD 3.2/kg`（口径截至 2026 年 1 月）。方案末尾给出优先级：**PPCP + PBAT 熔喷 pending，先聚焦纺粘纤维 kick off**。

## 关键论断（key_claims）

- **两条路线的成本量级差 8 元/kg**：纺粘 14.5 vs TABCW 皮芯纤维 22.5（RMB/kg）——皮芯路线的成本增量几乎全部来自 PGA 芯层（20 元/kg）。支撑页：[[PPC-P 基与 PGA 基可堆肥纤维路线对比]]
- **配方已经过喷丝验证的只有纺粘一条**：30/70 的 PPC-P/PBAT 是唯一有实测可纺性结论的组合；TABCW 皮芯组合仍标「待深度技术评估」。支撑页：[[可家庭堆肥无纺布（Home Compostable Nonwoven）]]
- **加工费被显式计入**：纺粘 +3、TABCW +5（RMB/kg）——是本库少见的把加工段与原料段分开列示的口径。支撑页：[[PPC-P 基与 PGA 基可堆肥纤维路线对比]]
- **TABCW 是该新材料的应用载体**：PPCP+PBAT+PLA 皮层 130 ℃ 的定位，正好对应 TBCW/TABCW 结构对低熔点粘合层的需求。支撑页：[[TBCW结构]]
