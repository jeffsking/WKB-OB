# QUOTATION For Dual forming drum system 20260721（双成型鼓系统报价单）

## Positioning 定位

Supplier quotation（HCH，安徽安庆，报价号 HCH2026072161，2026-07-21）to Kimberly Clark for a **Dual Forming Drum System** producing **ultrathin core（超薄芯体）**. This page records the technical configuration and process-relevant facts only; **commercial terms are deliberately not page-ized**（报价金额、付款节点、交期、质保不落页面）per AGENTS.md §5.（双成型鼓系统技术配置记录页；金额与条款见原文。）

## Summary 摘要

Section 1（machine & product specification）: HCH Dual Forming Drum System, product = ultrathin core; layout shows SAP3 and SAP1+SAP2 dosing points over a ~7,500 mm footprint with two forming drums（成型轮毂 ×2）, 导流槽总成, 4 negative-pressure boxes, fixed fluff roll stand（A1）, SAP hanging silo, cyclone dust collection, 75 kW forming fan + 22 kW waste-fiber fan + 38 kW mill, 3× SAP flat-dosing units（Acrision, C1–C3）+ Ktron（C4）, FIFE 500 web guides, 500 m/min box winder, 3× 7.5 kW vacuum pumps, 5× Nordson guns, 28 servo axes + PLC. Note on the quote: hardware cost only — test-site and personnel costs billed separately（测试费按日另计）. Section 2（price, delivery, payment）与质保条款属商务敏感内容，**不页面化**，原文留存于 RAW_FULL 路径下。Section 1's equipment list doubles as a procurement checklist for the ultrathin-core pilot/production line.（技术清单为主，商务条款留原文。）
