# 异型截面涤纶纤维卫生用品生产商清单（11 家·产能与应用确认）

## 一句话定位

一份 **国内异型截面 / 差别化涤纶纤维生产商的调研清单**，目标是识别**产品已用于一次性卫生用品（卫生巾、纸尿裤、成人失禁用品、湿巾/医用敷料）**的厂商，并以「**卫生用品应用确认状态**」三档区分可信度。本库价值：为 [[Pentagram PET (Star Cross-Section Fibre)]]、[[三叶形截面纤维（Trilobal Fibre）]] 等异型截面技术提供**国产供应基盘**与**产能口径**。

## 摘要

筛选逻辑（原文）：以「**卫生用品应用确认状态**」列区分——
- **确认**：官方/半官方资料明确用于卫生用品；
- **倾向确认（中强）**：官网将卫生材料列为应用领域但无专用型号；
- **未确认（潜在）**：具备异型截面技术基础但公开资料未指向卫生用品，作为储备。

**产品类型说明（原文，重要）**：卫生用品主流用的是 **ES/皮芯复合、低熔点、单亲/多亲/拒水、水刺专用**等差别化涤纶（及聚酯复合）纤维，经**热风/水刺**无纺布工艺用于**面层、导流层、芯体包覆层**；**异型截面（三叶/十字/多叶/中空）多用于柔软、蓬松、导流及填充，常与上述复合纤维配合**。

## 关键论断（key_claims）

- **三档确认：确认 8 家 / 倾向确认 1 家 / 未确认（潜在）2 家。** —— 支撑页：（无，登记于本页）
- **产能第一梯队：江南高纤 19~23 万吨、闽瑞 ~18 万吨（超细旦 ES）、天富龙 ~61.24 万吨（含非卫材）。** —— 支撑页：[[江南高纤]]、[[福建闽瑞新合纤]]
- **细旦化=竞争焦点：闽瑞 0.8D(2020) → 0.6D(2022) → 0.4D(2024)，规格 0.6D~6D。** —— 支撑页：[[福建闽瑞新合纤]]、[[Shaped PET Add-On Window]]
- **异型截面是「配合」而非「替代」：主流仍是 ES/皮芯复合 + 低熔点 + 亲/拒水，异型截面负责柔软/蓬松/导流/填充。** —— 支撑页：[[三叶形截面纤维（Trilobal Fibre）]]、[[Pentagram PET (Star Cross-Section Fibre)]]
- **两家「潜在」厂商（德福伦、益盟）客户均在服装/家纺/工业用，卫材可用性需尽调。** —— 支撑页：[[上海德福伦]]、[[Emon Jiangsu（江苏益盟）]]
- **竞争维度已从产能转向「差异化功能 + 合规背书」（彩色/弹性/超亲水/缓释护肤；FDA/OEKO-TEX/SGS）。** —— 支撑页：[[皮芯复合纤维]]
