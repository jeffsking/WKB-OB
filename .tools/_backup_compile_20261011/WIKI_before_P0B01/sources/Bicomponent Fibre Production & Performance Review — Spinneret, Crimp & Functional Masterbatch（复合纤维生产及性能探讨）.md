## Key decisions 决策要点

1. **两步法为主（已明确的工艺）**：螺杆 → 在**喷丝板**处汇合 → 三分 → 冷却 → 上油 → 落桶（盛丝桶）→ 集束 → **牵伸** → **卷曲** → **烘干** → 切断打包。
   - **一步法（short spin）** 成本更低，但**一处出问题整条线停掉**，工艺挑战更大 → 供应商选择两步法（long spin）。
2. **起订量与切换成本（已明确）**：**至少 30 吨**；切换过去再切换回来，**前后的料都废掉**，废料可能比常规供料还多 → **小批量验证必须走试验位**。
3. **截面能力边界（供应商已明确）**：
   - **可商业化**：**同心、偏心、中空** 三种；
   - **目前做不了**：**瓣形（桔瓣 / segmented pie）**、**海岛型**（海岛后续需用溶剂/水把"海"溶掉，后道设备要改造）；
   - **实验性研究过**：**十字形**、三叶形等，约**十几幅**喷丝板（非商业化）。
4. **异形纤维用于 ADL 的失效机理（已识别）**：双组分异形纤维在**熔融/热风粘合时外层 PE 融平**，中间的沟槽形态消失 → 起不到扩散效果。
5. **由此确定的路线（已达成一致）**：**优先用单组分异形纤维** —— 四个理由：① 不依赖熔融粘合，**形态不会被融平**；② **成本更低**；③ **可塑性更好**；④ **导液性也不错**。结论："完全没必要用双组分"。
6. **添加量窗口（已给出）**：ADL 上不会 100% 使用异形纤维，约 **10–20%**；先以 **5%、10%** 小批量试；单组分添加**不能太多**（比例受限）。
7. **提高添加上限的备选路线（已提出）**：若需要更高添加量，用双组分的**"全融掉"或"半融掉"** —— 全融掉等于回到单组分；**半融掉可部分保留沟槽形态**，从而**提高异形纤维的添加量上限**。
8. **卷曲与热定型（已明确）**：
   - **Z 字形** = 常规机械卷曲；**U 字形** = 偏心纤维 + 机械卷曲；**螺旋形** = 自卷曲 + 机械卷曲；
   - 前两种（机械卷曲）**稳定性好**；烘箱**热定型**使形态"像烫发一样"稳定 → **成布时形态保持率好**；
   - 若不给予卷曲，后道**梳理会出问题**（纤维需要一定的**抱合力**）；
   - **卷曲的均匀性影响后道加工的稳定性**。
9. **功能化的效果分层（双方一致）**：
   - **抗菌**：确实有抑菌效果；**弱酸（pH）**：确实有；
   - **凉感（薄荷醇）**：**不是真正的凉感，只是刺激神经**带来凉的感觉；
   - **护肤类（维 E / 神经酰胺 / 泛醇）**：添加量极少 → **效果有限，主要起市场宣称作用**；要真实起效**仍需在布上做 coating**（例：供 KC 卫生巾面层的维他命 B5 泛醇仅 **100–200 ppm**）。
10. **消臭的两条路线（供应商已在做）**：① **母粒型消臭剂加在皮层** —— **先吸附、后化学反应**，二者结合；② **活性炭**（纯物理吸附），同样加在 **PE 皮层**。
11. **本方的方向性表态（已明确）**：未来会**加大在纤维端的发力**；希望在**纤维层面**实现 **变色 / 温感 / 湿感 / 相变 / 拉力** 等功能（比布面印刷更底层、更直接）；希望**早期介入**供应商的前沿合作（东华大学、中科院），以便在终端产品上做技术植入。
12. **反向提案机制（已建立）**：供应商可主动向本方提案（例："你看这个方向 KC 要不要一起"），本方在职责范围内"比较 open"。

## Open issues 待决问题

1. **异形纤维的有效添加量未知**：本方明确"我们现在也不知道异形的添加多少是有效果的" → 需小试确定。
2. **单组分异形纤维的卫材级供给是障碍**：市面上单组分异形纤维**大部分在纺织业**，且以**高旦数**为主（2 旦 / 1 旦少见）；纺织厂的**洁净度、文虫管控、终端质量要求**与卫材**不是一个级别**，很少**单线专做卫材** → 需评估可得性。
3. **跨行业截面的适用性差异**：纺织业多用**十字形**（透气透湿），但十字形**手感很差、非常粗糙** → 对卫材不适用。说明跨行业迁移存在细微但关键的差别。
4. **功能助剂经全流程后是否失效（未验证）**：辅料添加在母粒里 → 经过纺丝 → 再到布，**到底能不能起作用、会不会失效** —— 本方明确"这部分是我们比较感兴趣的"，尚无结论。
5. **可降解与改性聚合物的下游要求未明**：PBAT / PLA / PBS / PGA、二氧化碳基聚合物、PTT 等方向"关键要看下游对这种材料有什么要求，还涉及成本与性能" → 未收敛。
6. **前沿合作的披露边界未定**：供应商与**东华大学**（基础原料/改性粒子，偏基础理论）、**中科院**（保密项目）有合作；本方希望早期听到方向，但供应商需**先确认保密协议 scope** → 待回复。
7. **海岛纤维与瓣形截面是否投入改造未定**：理论上产线可做海岛（同为熔融纺丝、同为双组分），但后道需溶剂/水溶"海"的设备改造 → 供应商目前**没有这方面的规划**。
8. **海岛的用途边界（会中澄清）**：海岛用于**单一组分的超细纤维**（如仿麂皮），属**另一个应用领域**，不是卫材方向。
9. **十字形是否"白口"**：会中确认为白口，且内外都是十字形 [待验证]。
10. **粗旦方向**：供应商"接下来会做一些粗旦的"，针对手感等 → 尚未开展。
