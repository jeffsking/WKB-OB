# ATB Topsheet with Bico Spunbond for 600 mpm Ultrasonic Lamination

## One-line positioning 一句话定位

A literature-based **fibre-mix strategy for a laminated topsheet**: a 25 gsm carded ATB web on a 12 gsm PE/PP bico spunbond carrier, ultra-sonically bonded and 3D-pattern-formed in-line at 600 m/min. It is the batch's "**bonding and pattern reliability constraint**" page.
本页是**层压面层的纤维配比策略**：25 gsm 梳理 ATB 网 + 12 gsm PE/PP 双组分纺粘载体，在 600 m/min 车速下在线超声粘合与 3D 花型成型，回答「**粘合与花型可靠性如何约束配比**」。

## Summary 摘要

The design brief carries five constraints: inline diaper lamination at 600 m/min; ultrasonic bonding / 3D pattern forming; a soft body side with high intake and better MD/CD wetting spread; stable deformation and pattern retention after ultrasonic bonding; and a blend that stays highly processable in carding and through-air bonding.
设计简报含五条约束：600 m/min 在线尿裤层压；超声粘合 / 3D 花型成型；贴肤侧柔软且摄入高、MD/CD 润湿铺展更好；超声后变形稳定、花型保持；混料在梳理与热风粘合中保持高可加工性。

The working hypothesis is a three-fibre blend in the 25 gsm ATB web — **55–65 wt% 2D ES** (softness, fine touch, more bondable surface), **20–30 wt% 4D eccentric ES** (bulk, void volume, pattern-depth support, resilience under compression) and **12–18 wt% 2D rounded trilobal mono-PET** (capillary guidance, faster strike-through, better urine spreading) — with the 12 gsm PE/PP bico spunbond kept as the ultrasonic carrier/support layer.
工作假设是 25 gsm ATB 网的三纤维配比：**55–65 wt% 2D ES**（柔软、细腻触感、更多可粘表面）+ **20–30 wt% 4D 偏心 ES**（蓬松、空隙体积、花型深度支撑、受压回弹）+ **12–18 wt% 2D 圆角三叶形单组分 PET**（毛细导向、穿透更快、尿液铺展更好）；12 gsm PE/PP 双组分纺粘保持为超声载体/支撑层。

The recommended recipe resolves to **60 / 25 / 15** (2D ES / 4D eccentric ES / 2D rounded trilobal mono-PET) = 15.00 / 6.25 / 3.75 gsm, described as the best overall balance: enough 2D ES for softness, enough 4D eccentric ES for loft and pattern depth, and 15% rounded trilobal PET for a wicking upgrade without over-penalising ultrasonic bonding. The most important engineering rule is stated as: keep the **total ES fraction above 80 wt%** so the ES-rich network still dominates bonding and pattern formation.
推荐配方落在 **60 / 25 / 15**（2D ES / 4D 偏心 ES / 2D 圆角三叶形单组分 PET）= 15.00 / 6.25 / 3.75 gsm，被评价为综合最佳：2D ES 保证柔软、4D 偏心 ES 提供蓬松与花型深度、15% 圆角三叶形在不明显损害超声粘合的前提下提升芯吸。最关键的工程规则表述为：**ES 总量保持在 80 wt% 以上**，使富 ES 网络继续主导粘合与花型成型。
