## Key Themes 核心主题

1. **多孔介质流动理论**：Péclet 数判据、达西定律、Washburn/Lucas-Washburn 方程、毛细压力与 Kelvin 方程——吸液动力学的物理基础，直接对接 `hygiene-absorption-model` 仿真接口。
2. **表面化学第一性原理**：接触角/润湿指数/附着功/Wilhelmy 湿附力法——决定纤维与结构能否有效吸液的材料选择先决条件。
3. **核心 C/Q 模型**：芯体容量（Capacity）与释放速率（Release rate）的定量关联——超薄芯体设计的核心权衡。
4. **SAP 谱系两极**：纤维素基（Ch7，Kimberly-Clark 磷烷基工艺）与丙烯酸基/水凝胶基（Ch8–9）——配方侧完整参考，含 2016/2022 综述更新。
5. **非织造四要素与工艺矩阵**：纤维→排列→粘合→整理因果链；airlaid / spunbond / meltblown / spunlace / SMS 工艺与四部件（Top Sheet / Core / ADL / Back Sheet）匹配。
6. **三层功能模型**：Acquisition–Distribution–Retention——吸收核心从"被动复合材料"到"活性交互体系"的范式转变。
7. **绒毛浆减量因果链**：SAP 引入 → 芯体密度↑ → 获取速率↓ → gel blocking → 必须配置获取层；51g → 29g → 16g 的量化演进依赖 coverstock/leg cuff 综合创新。
8. **测试金字塔与企业壁垒**：三级层次（材料→二维结构→产品）+ 三类方法（标准/研究工具/企业专有）；Syngyna、MKT、Oathout sled 等 proprietary 测试是真实竞争壁垒。
