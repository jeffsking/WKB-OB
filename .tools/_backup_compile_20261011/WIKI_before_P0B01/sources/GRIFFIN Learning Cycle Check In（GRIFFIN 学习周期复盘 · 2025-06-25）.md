# GRIFFIN Learning Cycle Check In（GRIFFIN 学习周期复盘 · 2025-06-25）

## 一句话定位 One-line Positioning

本批**GRIFFIN 回渗项目的学习周期复盘（2025-06-24/25）**：按 Liner / Core / Adhesives 三条工作流盘点进展，并把 SIROCCO 时代三处施胶试验的结论固化为可复用知识。是本库回答「吸收系统里施胶到底怎么影响回渗」的关键证据页。

## 摘要 Summary

**工作流回顾 —— Liner（面层）**：GRIFFIN HUT 已投放**未处理（untreated）面层**（渗漏结果预计 7 月底）。**未能完成**"通过用 SF19 改变盐水表面张力来研究摄入/回渗权衡"的实验，后续可考察其他表面活性剂。Always Discreet 面层分析：① 看起来**可能有更多胶**（SIROCCO 总结 slide 5）；② **Summit 喷头可能带来增量回渗改善**；③ 自 4/22 分享后是否有新学习（开放问题）；④ **随着更多批次被测，AD 持续显得比 Depend 更不亲水（less philic）**；⑤ **AD 产品在同一时间段、不同机台上存在 2 种不同的胶型**；⑥ **Depend/AD 摄入系统互换**——**假设是 AD 的差异来自面层/导流层，而不是卷曲纤维（curly fiber）**。

**工作流回顾 —— Core（芯体）**：**无 SAM 的 ActivTech Hybrid（ATH）芯体**——诊断 ATH 芯体相对 SAM/fluff 芯体回渗更高的原因；已在 GML 成功生产；测试计划待定：**MicroCT**、**毛细压力测试**（已有摄入系统即面层/导流层，是否要做芯体（包裹层/绒毛浆）？另有独立芯体与包裹层样品）、**积压排期**（可相对于其他 ADT 项目优先，高于 RED1，延迟 1 周）；策略是**先测整体系统，再按需拆分（芯体）**；可选尝试**2-丙醇溶液**下的回渗/摄入。**绒毛浆层中加入 SAM**——假设是**这将使绒毛浆脱水并降低回渗，因为在 ATH 芯体中绒毛浆起到了摄入层的作用**；回渗测试结果待提交（Kerry）。**1 gsm dSB vs 20 gsm BCW 包裹层**——假设其可能影响回渗（因为在纸尿裤中确有影响）；若会增加摄入时间，则考虑搭配**更低克重的导流层**（历史上此举有助于回渗）。**卷曲纤维复合材料**——感兴趣材料为 **50/50 绒毛浆与卷曲纤维（Helix）混纺**、**90 gsm 卷曲纤维/PET 复合纤网（按导流层与包裹层用途分幅宽）**；正为 **7 月 GML 试验（7/14–8/1）** sourcing。

**Depend 施胶（本节最可复用）**：吸收系统三处施胶为 **Surge Adhesive（SLA，导流层胶）**、**LTD Adhesive（面层固定胶）**、**PAA Adhesive（吸收体附着胶）**，另有 SAM/Fluff 与 Wrapsheet。**SIROCCO 曾考察三者的各种改动，唯一统计显著的回渗改善是"降低 LTD 施胶量"**；同时在三处都试过**亲水胶——方向性乃至统计显著地增加回渗**。三份文档的学习点为：
- **ERR-61012（LTD 面层固定胶施胶量）**：**降低施胶量降低了回渗**——假设是 **LTD 胶阻碍了液体向下层流动**；**亲水胶增加回渗**；**分区/TRIO 施加理论上最优，但测试中并不总是带来回渗改善，因此资本开支无法被证明合理**（据 Monica）。
- **ERR-61046（PAA 吸收体附着胶花型）**：**去掉 pad 中央 50 mm 条带的 PAA，方向性降低回渗**；**亲水胶方向性增加回渗**。
- **ERR-61047（SLA 导流层胶型号）**：**Signature 喷头相对对照 Summit 方向性降低回渗**——**Signature（随机纤维）比 Summit（漩涡）具有更高的表面覆盖面积**；**亲水胶增加回渗**。

## 提炼的数字与结论 Key Numbers and Conclusions

| 项目 Item | 数值 / 结论 Value / Conclusion | 备注 Note |
|---|---|---|
| **LTD 施胶量** | **降低 add-on → 回渗降低（唯一统计显著改善）** | 假设：LTD 胶**阻碍液体向下层流动** |
| **亲水胶（三处一致）** | **方向性至统计显著地增加回渗** | LTD、PAA、SLA **三处结论一致**（反直觉） |
| PAA 花型 | **去掉中央 50 mm 条带 → 方向性降低回渗** | ERR-61046 |
| SLA 喷头 | **Signature（随机纤维、覆盖面积更大）vs 对照 Summit（漩涡）→ 方向性降低回渗** | ERR-61047 |
| 分区/TRIO 施加 | 理论上最优，但**测试中并不总是改善回渗 → 资本开支未被证明合理** | 据 Monica |
| ATH（无 SAM）芯体 | 回渗**高于** SAM/fluff 芯体；已在 GML 成功生产 | 诊断中 |
| 绒毛浆层加 SAM 假设 | **使绒毛浆脱水 → 降低回渗**（因 ATH 中绒毛浆充当摄入层） | 待测 |
| 包裹层变量 | **1 gsm dSB vs 20 gsm BCW**；若增加摄入时间则搭配**更低克重导流层** | 纸尿裤中曾有影响 |
| 卷曲纤维材料 | **50/50 绒毛浆 + 卷曲纤维（Helix）**；**90 gsm 卷曲纤维/PET 复合纤网** | 目标 7 月 GML 试验（7/14–8/1） |
| 测试手段 | MicroCT；毛细压力（摄入系统已有，芯体待定）；可选 2-丙醇溶液 | 先整体后拆分 |
| AD 面层观察 | **更多批次下 AD 持续更不亲水**；AD 同一时段不同机台有 **2 种胶型** | 与摄入系统互换假设呼应 |
| 摄入系统互换假设 | **AD 优势来自面层/导流层，而非卷曲纤维** | 与 2025-08-28 的结果一致 |
| 未完成实验 | **SF19 改变盐水表面张力 → 摄入/回渗权衡实验未能完成** | 后续可换其他表面活性剂 |

## 关键论断（key_claims）

- **"更少的胶"和"非亲水的胶"是两个独立且方向一致的有利变量** —— 支撑页：[[Absorbent System Adhesive Effects on Rewet（吸收系统施胶对回渗的影响）]]
- **亲水胶增加回渗是反直觉但三处一致的结论，应作为配方红线而非可选项** —— 支撑页：[[Hydrophilic SAP Wrapping Adhesive（亲水SAP包裹胶）]]、[[Surge-Liner Adhesive Bonding（导流层-面层施胶粘合）]]
- **ATH 芯体回渗偏高的根因假设是"绒毛浆充当了摄入层"——故解法是给绒毛浆层加 SAM** —— 支撑页：[[ActiveTech Platform（ActiveTech 在线薄芯体平台）]]、[[Rewet Mechanisms Desorption and Flowback（回渗双机理：解吸与回流）]]
- **喷头覆盖面积（Signature > Summit）是继花型之后的第二层变量** —— 支撑页：[[Liner-Surge Interstitial Space（面层-导流层界面间隙）]]
- **理论最优不等于测试有效：分区/TRIO 施加因未稳定改善而未获资本授权** —— 支撑页：[[Hot-Melt Slot Coating（热熔狭缝涂布）]]、[[Ultra-Low Add-On Adhesive Application（超低添加量施胶）]]
