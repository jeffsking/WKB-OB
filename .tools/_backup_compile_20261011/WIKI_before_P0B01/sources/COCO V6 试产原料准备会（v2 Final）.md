# COCO V6 试产原料准备会（v2 Final）

## 一句话定位

COCO V6 试产原料准备会的**定稿版**：在物料矩阵（见 [[COCO V6 试产原料准备会（英文版，2026-09-11）]]）之上补齐**结构设计与测试基准**四页，是理解 V6 芯体「为什么这样选料」的技术主文档。

## 摘要

v2 Final 保留「4 位置 · 9 项 · 3 选择维度」的物料矩阵，并新增三页设计与一页测试矩阵。**Liner 设计**：ATB 双梳理面层 50 gsm，4 铺层 / 2 梳理系统——上层 25 gsm（22.5 gsm 90% ES 2D + 2.5 gsm 10% 三叶形 PE/PET 3D）、下层 25 gsm（12.5 gsm 50% ES 4D + 12.5 gsm 50% 三叶形 PE/PET 3D）；三叶形 PET 共 15 gsm（30%），皮肤侧仅 5% 以保住手感；Z 梯度自柔软贴肤面过渡到芯体侧 MD 沟槽网络，三叶形沟槽沿 MD 引液；CD 拉伸 9.3 N/50mm（下限 8.0 N @600 m/min）。**REL 设计**：5 纤维 28 gsm 穿透热风粘合，Z 栈为「上细旦 → 中粗/中空 → 下 PVA」，上 40% 为 2D ES + 3D PE/PET（细毛细摄入）、下约 60% 为 6D PVA + 3.5D 中空 ES + 7D PTT/PET（Z 输运 + 湿强骨架）；1st STT 0.65 s（相对常规 ADL **-41%**）、湿态 MD 抗张 78 N/m（24 gsm）、SAP 捕获/分离 98%。**Layer Architecture**：SAP1 为皮肤侧独立层（REL 之下直接贴身，求快与低回渗），SAP2（快膨胀）与 SAP3（延迟膨胀）**同层混合**（非上下叠放），以膨胀速率差维持凝胶床在 4 次冲击下持续通透。**Test Matrix** 汇总 Liner/REL/Core Wrap 的 STM 方法号与通过/优秀基准。

## 提炼的数字与结论

**Liner 材料设计（ATB 双梳理 · 50 gsm）**

| 铺层 | 克重 | 组成 |
|---|---|---|
| A1 上层 | 22.5 gsm | 90% ES 2D 圆形 |
| A2 上层 | 2.5 gsm | 10% 三叶形 PE/PET 3D |
| B1 下层 | 12.5 gsm | 50% ES 4D |
| B2 下层 | 12.5 gsm | 50% 三叶形 PE/PET 3D |
| 合计 | 50 gsm | 三叶形 PET 15 gsm（30%）；皮肤侧仅 5% |

- 结构：Z 梯度「柔软贴肤面 → MD 沟槽网络」；三叶形沟槽沿 MD 方向引液。
- 指标：MD 分布 **+30%**（3rd-insult，模型增益）；CD 拉伸 **9.3 N/50mm**（下限 8.0 N @600 m/min）。

**REL 材料设计（5 纤维 · 28 gsm 穿透热风粘合）**

| 纤维 | 功能 |
|---|---|
| 2D ES PE/PET | 亲水 · 细毛细摄入 |
| 3.5D 中空 ES | 偏心 · Z 通道 + 蓬松 |
| 7D PTT/PET SxS | 自卷曲 · 回弹（**必选纤维**） |
| 3D PE/PET | 亲水 · 第二级毛细 |
| 6D PVA | 非水溶 · 湿强（**必选纤维**，8.4 gsm） |

- Z 栈（2 梳理）：上 40% = 2D ES + 3D PE/PET（细毛细摄入）；下 ~60% = 6D PVA + 3.5D 中空 ES + 7D PTT/PET（Z 输运 + 湿强骨架）。
- 指标：1st STT **0.65 s**（相对常规 ADL **-41%**）；湿态 MD 抗张 **78 N/m**（24 gsm）；SAP 捕获/分离 **98%**。

**分层架构（Skin → Poly）**

| 层 | 功能要点 |
|---|---|
| 面层（Liner 侧非织造） | 加 10% 圆形三叶形单组分 PET 以改善 MD 分布 |
| SAP1（皮肤侧独立层） | 直接贴身于 REL 之下；Fast-acq · CRC 31 · GBP 53 · 低回渗；**求速度与低回渗，不求最大 CRC** |
| REL 纤维层（5 纤维 TAB，28 gsm） | 毛细梯度 · 抗凝胶阻塞 · Z 向单向流 |
| SAP2 + SAP3 混合层（Poly 侧） | SAP2 快膨胀（冲击 1–2 快速接液，CRC 有意封顶以免过度膨胀堵孔）；SAP3 延迟膨胀（最高 CRC 储库，冲击 3–4 才完全介入） |
| Poly 侧非织造 | 含更多天然亲水纤维的水刺非织造 |

> **机理句（原文）**：SAP2 与 SAP3 **同处一个物理层（混合、非叠放）**，二者不同的膨胀速率让凝胶床在全部 4 次冲击中保持通透，而不是第一次后就封死——这是全部容量利用率的机制来源。

**Test Matrix（原文摘要）**

| 部件 | 核心参数 | 方法 / 标准 | 基准（通过/优秀） |
|---|---|---|---|
| Liner | Rewet（产品主 KPI） | STM-00059-2 Flowback（14±1 in WC = 3.4 kPa · 3 min + 2 min） | < 5.9 g / 34 min（产品级门） |
| Liner | Strike-through (STT) | STM-2470（Lister，4×4 in，5 mL 盐水） | STT ≤ 0.8 s（产品级） |
| Liner | MD 分布 / 铺展 | STM 1001，30 s | ≥ +30% vs 对照（目标 34.9%） |
| Liner | 湿态 MD 抗张 | STM-00146（50.8×152.4 mm，76 mm 夹距，305 mm/min，60 psi） | ≥ 75 N/m |
| REL | Void Volume | TTM 000429 @0.05 psi VV-Sat 曲线 | cm³/g @0.05 psi |
| REL | 压缩回复 | TTM 00038 / TTM 00437，3 循环厚度-应力曲线 | TBC |
| REL | 1st/2nd/3rd void STT 与 3rd void rewet | STM 00034 | ≤ 对照批 |
| REL | 克重 | STM-00109（As-is 与绝干） | 名义 28 gsm（上 11.2 + 下 16.8） |
| Core Wrap | 规格与亲水等级 | 克重 / 厚度法 | 15–18 gsm SMS 或 tissue（L1 处理 / L5 标准） |
| Core Wrap | SAP 隔离 / 抗迁移 | SAP migration / isolation check（Stage 2） | ≥90% 捕获、97% 迁移 <3% = best-in-class |
| Core Wrap | 芯体级回渗 / 摄入 | ISO 11950 或 EDANA | 回渗 ≤3.0 g（3rd void）、摄入 ≤35 s · 3 次冲击 |
| Core Wrap | MD 分布 | STM 1001，30 s | ≥ 130 mm |
| Core Wrap | 端封 / 复合强度 | STM-00078（Rev.7, 2024-12, 2-in gauge） | 峰值载荷 gf，记录最大 + 平均 |

> **原文注**：REL 按「KC NEW REL 4 per-lot qualification（pass / excellent）」判定；core-wrap 回渗与摄入为**芯体级**目标；**试产 MPM 为 20 gsm，而规格为 15–18 gsm——须确认适用性**；Liner 回渗按低负载协议判定，**高负载短间隔法会掩盖真实穿着表现**。
