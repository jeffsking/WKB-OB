# GB 31701-2015 Safety Technical Code for Infants and Children Textile Products（婴幼儿及儿童纺织产品安全技术规范）

## 一句话定位

China's **mandatory** safety code for infant/children **textiles**（A/B/C 三类分级）—— for this library its main value is a **scope boundary marker**: disposable hygiene products are explicitly excluded, so diaper elastic cuffs / nonwoven topsheets are NOT judged by GB 31701.

## Summary 摘要

GB 31701-2015 (SAC/TC 209/TC 219) is fully mandatory and applies to textile products sold in China for infants (≤36 months, ≈ height ≤100 cm) and children (3–14 y). It inherits GB 18401 classes A/B/C one-to-one and adds infant-grade extras: wet rubbing colorfastness, coating/print-only total lead & cadmium, coating/print-only phthalate sums (two groups, each ≤0.1%), and 45° burning performance with fibre/grammage exemptions. Mechanical safety is a distinctive block: attachment pull-off forces (70/50 N by size, wash-variation route for ≤3 mm), no sharp points/edges, and an extensive cord/drawstring rule table (head/neck cords banned outright for infant and ≤7 y garments). Packaging and products must be free of metal needles. For hygiene-product work the operative clause is the scope note excluding 一次性使用卫生用品 — the chemical-safety floor for diapers/wipes instead lives in GB 43631-2023 and GB 15979.

## 关键论断（key_claims）支撑页

- **范围排除是一次性卫品合规里的关键「负知识」**：纸尿裤/湿巾不在 GB 31701 范围内，勿误把 A 类纺织要求套到卫品面层 —— 支撑页：[[GB 43631-2023（婴幼儿及儿童纸品化学安全总门槛）]]
