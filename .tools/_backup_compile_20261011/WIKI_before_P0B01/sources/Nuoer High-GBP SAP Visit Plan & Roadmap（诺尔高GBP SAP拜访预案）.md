# Nuoer High-GBP SAP Visit Plan & Roadmap（诺尔高GBP SAP拜访预案）

## 一句话定位 One-line positioning

本库**"高 GBP SAP 为什么难、怎么突破"的唯一一份完整作战方案**：它把 GBP 从"一个测试指标"还原成**一条由芯体结构倒推的需求链**（SAM% 越高 → GBP 门槛越高 → 否则凝胶阻塞 → 未饱和就漏），并在供应商侧给出**三条可执行路径 + 目标牌号 + 里程碑 + 21 条问询**。其中最有普适价值的一条是：**AUL 是 GBP 的必要不充分条件——先过 AUL，再谈 GBP。**

## 摘要 Summary

**背景段**先回答"为什么是 GBP、为什么是 Nuoer"：芯体向薄型化、高 SAP 含量演进使 GBP 从"锦上添花"变为"核心刚需"，并给出**按 SAM% 分档的 GBP 最低要求表**；随后说明凝胶阻塞的失效链条与 HUT 相关性。选择 Nuoer 的理由是**釜式工艺的底层优势 + 中国成本结构 + 承接 SDP 退出后的份额**，并如实指出差距：**GBP 天花板 35 vs 标杆 50–96 Darcy**。

**第一部分（可行性）**把釜式工艺拆解为三项有利于 GBP 的特性，给出三条提 GBP 路径与适配性、分段目标（6–12 / 12–24 / 24–36 个月）、技术难点可解性、资源投入与风险表。

**第二部分（开发方案）**定义目标牌号 `NR-GBP-H`、给出两阶段性能窗口、工艺流程图（基础聚合 → 凝胶处理 → 三条并行表面处理路径 → 目标性能）与 M1–M8 里程碑。

**第三部分**是 21 条供应商问询（Q1–Q21），**第四部分**是 T1–T6 技术难点与成本效益框架，**第五部分**是 Phase 0–4 路线图、交付物清单与三道 Gate。**附录**给出标杆牌号对照（含反应器类型）、Nuoer 产品组合、四指标取舍原理与测试方法标准对照。

## 提炼的数字与结论 Key figures & conclusions

### A. GBP 门槛随芯体 SAM 含量递进

| 芯体类型 Core type | SAM% | GBP 最低要求 Minimum GBP | 典型产品 Typical product |
|---|---|---|---|
| SAM/Fluff 中低含量 | <40% | **无硬性要求** | Poise |
| SAM/Fluff 中等含量 | 40–55% | **>7 Darcy** | 拉美 / 印度纸尿裤 |
| SAM/Fluff 高含量 | 55–70% | **>15 Darcy** | Pull-Ups、Depend |
| 薄芯（BONNIE / ActivTech-Hybrid） | 70–85% | **>20 Darcy** | BONNIE-P、AT-hybrid |
| 无绒毛浆薄芯（Fluffless / CIRRUS） | 85–100% | **>20 Darcy** | Fluffless AT、Complex Core |

> **失效链条 Failure chain**：GBP 不足 → 膨胀颗粒变形粘连 → **第二/三次加液无法穿透凝胶层** → 局部过饱和、其余区域闲置 → **在未达饱和容量前即泄漏**。**HUT：In-product GBP 与泄漏率负相关，R² ≈ 0.59–0.63。**

### C. 三条提 GBP 路径

| 路径 Path | 机理 Mechanism | Nuoer 适配性 | 预期增益 Expected gain |
|---|---|---|---|
| ① **表面交联调控** | 优化交联剂种类/用量与热处理 → 更均匀坚韧的"壳层"，颗粒吸水后保持独立形状 | **高** | **35 → 45–55 Darcy** |
| ② **离子相互作用涂覆** ⭐ | 聚胺 + 多价金属盐（Al³⁺/Ca²⁺）复合涂层；多价阳离子与 −COO⁻ 形成局部离子交联点限制表面过度膨胀；电荷梯度引导液体定向传导；协同形成抗附聚屏障。技术来源 **CN101111271A** | **高**（需新增涂覆工段） | 在 ① 基础上**再 +15–30 Darcy** |
| ③ **无机粉末隔离** | 后处理添加纳米 SiO₂ 等不溶性粉末作物理"隔离珠"防止凝胶贴连 | **中高** | **+5–15 Darcy**（辅助） |

**分段目标**：近期（6–12 月）**45–55**；中期（12–24 月）**60–80**；远期（24–36 月）**>80 Darcy**。

### D. 四指标取舍原理（速查）

| 取舍关系 Trade-off | 机理 Mechanism | 优化路径 Optimization |
|---|---|---|
| CRC ↑ ↔ GBP ↓ | 高 CRC 需低交联密度 → 颗粒过软易变形堵通道 | **核-壳梯度交联**（内核低交联保 CRC，外壳高交联保 GBP） |
| GBP ↑ ↔ Vortex ↑ | 高交联外壳阻碍水分进入 | 表面造孔 + 发泡 + 粒径优化（300–600 μm） |
| AUL ↑ ↔ CRC ↓ | 高 AUL 需高交联密度 | 非均匀交联（表面高、芯部低） |
| **GBP ↑ 需 AUL ↑** | **凝胶强度是渗透性的前置条件** | **AUL ≥18 是 GBP ≥50 的基础** |
