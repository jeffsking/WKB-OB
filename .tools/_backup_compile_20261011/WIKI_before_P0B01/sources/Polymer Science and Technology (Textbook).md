## Scope and Structure 范围与结构

本书是**面向入门课程的聚合物科学与技术教科书**（非研究专著、非配方手册）。按源文 PREFACE，全书分三大部分：**(1) 聚合物基础**（历史、定义与分类、单体成聚条件、一级/二级/三级结构、结构-性能关系、聚合物改性）；**(2) 从单体到制品**（聚合方法、机理与动力学、分子量控制、反应工程、助剂与增强、加工单元操作）；**(3) 性能与应用**（溶液性能 → 力学性能 → 黏弹性与断裂 → 固态应用）。

## Relevance to Hygiene R&D 与卫材研发的关联

相关性评级：**P1（参考级 / reference-level）**。本书不针对卫材应用，也不含任何供应商或牌号数据；它的价值是把本库零散的「为什么」串成一条教学级因果链，作为查证术语与标准定义的**通用底座**。

| 本书落点 Where it lands | 卫材场景 Hygiene use |
|---|---|
| Ch1/Ch3 结构-性能关系、一级/二级/三级结构 | 理解 PE/PP 皮芯纤维（双组分 ES 纤维）的结晶与取向基础；对应 [[Manufactured Fibre Technology Ch19 Spunbonding and Melt-Blowing Processes]] 的纺丝侧 |
| Ch2/Ch6/Ch7/Ch8 聚合机理与共聚 | PP/PE/共聚物（含 SAP 用丙烯酸体系）的链结构来源与分子量分布成因 |
| Ch4 热转变、Ch14 黏弹性 | ES 纤维的粘结窗口（PE 皮层软化）、热熔胶开放时间与抗蠕变的物理语言 |
| Ch9 助剂与增强 | 亲水整理剂、抗静电/抗氧剂在非织造布与薄膜中的功能定位 |
| Ch10/Ch11 反应工程与加工单元操作 | 从聚合到纺丝/挤膜/复合的工艺-性能传导链 |
| Ch12 溶液性能、Ch13 力学性能 | 面层/底膜的力学与润湿表征逻辑 |

诚实评价：**这是教学级综述，不是研究前沿也不是工艺手册**。深挖同一主题请优先使用 [[Seymour Carraher Polymer Chemistry]]（反应与机理）与 [[Introduction to Physical Polymer Science]]（物理与转变）；需要反应器设计细节时回到 [[Polymer Reaction Engineering]]。
