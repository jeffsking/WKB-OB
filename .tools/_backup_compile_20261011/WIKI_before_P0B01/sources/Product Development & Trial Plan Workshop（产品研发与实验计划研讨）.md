## 一句话定位

一场把 **T4 pants 结构/工艺统一、超声波设备国产化选型、BNC（细菌纳米纤维素）技术扫盲** 三条线串起来的研发 workshop；输出的是实验排程、供应商二选一的评估口径与若干行动项，而非最终结论。

## Key decisions 决策要点

> 只记原文明确「定了/要这么做」的事项。

1. **T4 pants 改走在线 LSE 路径**（online ultrasonic embossing / bonding 在线超声波压花帮顶），与 T4 demo 统一 pattern 与结构 —— 现有 demo 与 pants 的 pattern 完全不一致（demo 为在线六边形/菱形，pants 为离线大圆点），统一后外观一致、后续升级更灵活。（统一后需实验验证，见 Open issues）
2. **超声波模块优先国产方案（prefer 国产 solution）**，在 **传越** 与 **恒昌** 两家间继续评估；进口方案（KTW / 杜肯 Dukane 体系）作为对照。
3. **FGD（焦点小组）不等外部排期，研发自行推进**：先拿市场现有竞品做，若竞品答不了问题再上手工样；手工样准备下周启动。
4. **下一轮实验在上层做文章**：对比 20 / 30 / 40 g 克重对 3D 效果的影响，并验证变形纤维与**三叶草（Trilobal）纤维**放在第二层对分散/导流效果的影响。
5. **除臭项目立刻 kick off**：中科依兰先做，新维盛（IQ fresh）同步取样对比，做 A 样 / B 样对照；验证通过即可交付。
6. **项目按「平台化 + 模块化」组织**：以「主干 + 枝条」的树状结构呈现（skin care、V Max 两类平台），各国 DNC 按需取舍枝条；China 作为 leading country 负责落地。

## Open issues 待决问题

- **传越 vs 恒昌 如何选**：四点比较项中第一/三/四项差异不大，真正差异在第二项（工艺经验与优劣势）。稳定性是首要判据，取决于超声波模头钛/稀有金属合金程度、传动摆动臂形式、发生器能量选型与模头间距的经验值。恒昌在 N35/N36 已有商业化应用，报有焊头磨损导致超声波过载报警、每班需清理 build-up 的问题；传越报价与交期更优但缺乏同等级量产经验。**成功标准（车速、稳定性、外观焦状等量化指标）尚未定义** —— 原文要求「早点把成功标准定出来」。
- **CPN 下层材料改 SMS 是否成立**：QQV5 下方 CPN 位由水刺改 12 g SMS 后，原由该层承担的导流作用是否会消失 —— 必须实验验证。
- **T3 是否沿用 T4 路径 / 材料组合**：仅讨论，未定。
- **花型（pattern）效果**：小样品照片呈现「一片麻点」，压合效果不如渲染图；供应商提两个改法（点径差异收窄、大圆改中空圆环，内圈 Ø0.9 / 外圈 Ø1.6，面积差 3.72 倍），需等中秋后（约 10/13–10/14）样品到位后与「马」确认。
- **BNC 应用路线**：六条路线仅处于设想/待验证阶段（与绒毛浆混合改善网络刚性、SAP 表面交联增强、发泡吸收体、亲水热熔胶 master batch、功能性载体、提高 MD 强度），均未决策。
- **Smart / 智能方向**：marketing 的真实需求（大数据 vs 落地功能）尚未澄清，暂无可落地物。
- **BM indicator 复配**：已用 AI 模拟出配方，配混执行方未落实。
- **组织/人事闲聊（篇幅较大）**：涉及全球团队与区域人事变动，**与本库技术主题无关，不页面化**。

## Background 背景

T4 现有 demo 与 pants 在外观 pattern、面层与芯体用材上长期不统一，且进口超声波模块 Capex 与交期成为产能扩张瓶颈；同期团队在扫盲 BNC（细菌纳米纤维素）这一新材料平台，寻找其在吸收芯体、热熔胶与除臭载体上的落点。本次 workshop 即围绕这三条线的实验排程与选型口径展开。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| 进口超声波模块 | 单线约 RMB 2.5 M，交期 8 个月 | 现有 T4（PWKDW 设备，超声波用杜肯，花纹用日本金川） |
| 国产方案（传越） | 初步约 RMB 0.5 M，交期约 2–2.5 个月（含设计与运输） | 超声波与花纹均为自查 `[待验证]` |
| 国产方案（恒昌） | Capex 与交期与传越相近 | 超声波为比隆系 `[待验证]`，花纹自产；已有 N35/N36 商业化应用 |
| 国产 vs 进口 Capex | 单线至少节省约 RMB 2 M | T4 pants 产线数量较多 |
| BNC 产能 | 约 1,000 t/y（实验室/中试级），规划 10,000 t/y | 发酵周期 7 天得 2% 固含量水凝胶 |
| BNC 成本 | 100% 粉体约 RMB 50,000/t，较市场 50 万–150 万/t 降约 90% | 糖源取自屠宰废水，成本近零 |
| BNC 吸水 | 纯水 200–2,000 g/g；生理盐水约 100 g/g | 网状结构孔隙率 >90% |
| BNC 形貌 | 直径 20–100 nm，结晶度高，微观模量约 78 GPa | 宏观回弹差（发泡体受压不回弹） |
| BNC 发泡体厚度 | 现 3–5 mm，应用目标 <1 mm | 表面光滑导致初期吸水慢 |
| 三叶草纤维添加 | 上层 10% 或 0，下层 10%；Home PET 因手感偏糙需降量 | 白口 PET 耐热约 130 ℃ vs 复合 PET 约 220 ℃ |
| 非热熔纤维添加上限 | 约 15% 以内可调，超过需上机试 | 蚕丝类建议 8–10%，1% 混不匀 |
| T4 上市 | 初步排 2028-03 | 以国产方案成熟为前提 |

## 关键论断（key_claims）

- **T4 pants 与 demo 统一到在线 LSE 是「外观 + 结构 + 用料」三合一的技术路径** —— 支撑页：[[Ultrasonic Bonding of PET-Containing Topsheet]]
