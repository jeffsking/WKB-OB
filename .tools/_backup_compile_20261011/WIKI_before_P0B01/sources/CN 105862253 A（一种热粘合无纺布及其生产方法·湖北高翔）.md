# CN 105862253 A（一种热粘合无纺布及其生产方法·湖北高翔）

## One-line positioning 一句话定位

A 2016 supplier-side application claiming **elastomer-doped ES sheath-core fibres**（掺弹性体的皮芯 ES 纤维）for **through-air bonded nonwovens** — the standard industry answer to "热风布要更软、低模量、无摩擦感"：把弹性体（Vistamaxx 类）加进皮层或芯层母粒，再用常规开松-梳理-热风线生产。对本库是**热风布弹性体改性的配方+工艺窗口锚点**（皮芯比、弹性体 5–50%、梳理线速、热风温度/车速均有量化）。

## Technical breakdown 技术拆解

1. **纤维结构三态**：弹性皮层（PE/PET+弹性体 ‖ PP/PET 芯）；弹性芯层（PE/PET 皮 ‖ PP/PET+弹性体 芯）；皮芯双弹性层。皮芯母粒质量比 70:30 ~ 30:70。
2. **弹性体选型**：塑料弹性体，优选 Vistamaxx（PE/PP 半结晶共聚物，说明书标注"化学名称是聚丙烯"）；均聚 PP 中加 15–20%、共聚 PP 中加 5–10% 即可达理想性能；低温 <−20 °C 不适用；与 POE 增韧比透明性更好。
3. **工艺链**：热熔高压挤出纺丝 → 粗/精两步开松 → 气压储棉箱 → 梳理成网（锡林 500–1500 m/min，最佳 1350–1450）→ 热风（或热轧）粘合（110–180 °C、10–300 m/min，最佳 120–140 °C）→ 卷取。
4. **实施例四个**：皮芯比/弹性体含量/梳理速度/热风温度·车速组合分别为 50:50+20%@1000 m/min+127 °C·30 m/min；30:70+30%@1400 m/min+130 °C·60 m/min；70:30+5%@1200 m/min+125 °C·100 m/min；40:60+50%@1350 m/min+120 °C·80 m/min。
