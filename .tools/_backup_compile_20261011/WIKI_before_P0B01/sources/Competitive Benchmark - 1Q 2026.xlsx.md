# Competitive Benchmark - 1Q 2026.xlsx

## One-line positioning 一句话定位

A 1Q-2026 competitive rewet benchmark workbook (STM TTM-00643) measuring fluid-intake-pressure / rewet in grams for incontinence liners and pads across competitive brands — the external yardstick for dryness claims.（2026 Q1 竞品回渗基准工作簿（STM TTM-00643），以克计量失禁护垫/拉巾的回渗，用作干爽宣称的外部标尺。）

## Summary 摘要

- Method is **TTM-00643 Fluid Intake Pressure, Rewet**; metric unit is grams (g) of rewet; each SampleID carries multiple replicate Reps.（方法为 TTM-00643 流体摄入压力·回渗；单位为克；每个样品含多次重复。）
- Scope covers competitive adult-care items — e.g. *Always Discreet Liners 2 Drop Long Length* (purchased Nov 2024) and *Poise Pads and Liners* research samples.（范围含竞品成人护理品，如 Always Discreet 2 Drop 长款拉巾、Poise 护垫研究样品。）
- The workbook is structured as RequestID → STM → Variant → Metric → Sample Description → SampleID → Meta Data (e.g. "2 Drops", Long) → Code_Lot → Rep → Value → Brand → Size.（结构为请求→方法→变体→指标→样品描述→样品ID→元数据→批号→重复→数值→品牌→尺码。）
- It is the external benchmark counterpart to internal rewet studies (e.g. Depend Rewet Over Time) in the same Open Innovation Rewet folder.（与本开放创新 Rewet 文件夹内的内部回渗研究（如 Depend Rewet Over Time）互为内外标尺。）
