# GB-T 28207-2011 Release Base Paper（离型原纸）

## 一句话定位

Product standard for **release base paper**（离型原纸）— the uncoated substrate that is subsequently coated (淋膜/硅油) to become release paper; the upstream half of the GB/T 27731-2011 release-paper family, specced on paper physics rather than release performance.

## Summary 摘要

GB/T 28207-2011 (SAC/TC 141; drafters 太阳纸业、中冶银河、中国制浆造纸研究院) covers jumbo-roll base paper intended for coating into release paper. Because release behaviour comes from the coating, the standard's limits are all substrate properties: a 40–110 g/m² basis-weight ladder with tight tolerances, cross-profile (CD) uniformity (≤3.0–4.0 g/m² basis-weight spread, ≤6% thickness spread) — critical for coat-weight uniformity — plus brightness ≥90.0%, Bekk smoothness with two-side-difference caps, MD tensile index ≥34.0/32.0 N·m²/g and TD tear index by grade, air permeability ≥2.0 µm/(Pa·s), Cobb 30±10 g/m² and 6±2% moisture. Grade split is 优等品/合格品 with slightly looser smoothness/tensile/tear at 合格品. Splice policy (≤1 per roll top grade, ≤50 mm tape) protects converting uptime. Lots ≤100 t, AQL 4.0 for the two strength indices.
