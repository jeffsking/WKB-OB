# Baby Diaper Absorbent Core Design（五层无浆 SAP 芯体设计方案与仿真 KPI）

> 一句话定位：**一份"从婴儿排尿生理反推芯体结构"的全无浆五层芯体设计方案**——用**三种 SAP 按功能分层 + 四种区域按尿量分配**来同时满足摄入、回渗、分布与容量。（中文：它把"回渗屏障"从面层/导流层搬到了**芯体最上层的 SAP 选型**上。）

---

## 摘要 Executive Summary

| 类别 | 内容 |
|---|---|
| **芯体** | **385 mm (MD) × 110 mm (CD)**，**5 层全无浆（fluffless）**，干态总厚 **~3.2 mm** |
| **SAP 体系** | **3 种**：NR-511（poly 侧主体）+ SAP1（快吸共混）+ SAP2（高 GBP，liner 侧） |
| **总装载** | **14.0 g**（SAP2 5.0 / N511 6.3 / SAP1 2.7），**SAP 定量 ≈329 g/m²** |
| **共混比** | **N511 : SAP1 = 70 : 30**（poly 侧所有区域恒定） |
| **MD 分区** | **A 前 0–77 / B 裆前 77–200 / C 裆峰 200–270 / D 后 270–385 mm** |
| **仿真结论** | 6 项 KPI **全部 PASS**（摄入 / 回渗 / MD 分布 / 累计吸收 / 利用率 / 凝胶阻塞） |

## 提炼的数字与结论 Numbers & Conclusions

⚠️ **证据等级：B（设计仿真输出，非实测）**——本页所有性能数字为**模型/设计推演结果**，**未经试产验证**，**不得写入规格**。

### 1. 设计基准：6 月龄婴儿排尿生理

| 项目 | 数值 |
|---|---|
| 排尿频率 | **15–20 次/日**（约 **1 次 / 72–96 min**） |
| 单次尿量 | **20–45 mL**（均值 **~30 mL**） |
| 峰值流速 | **2–5 mL/s**（短促爆发式） |
| 更换周期内多次排尿 | **3–4 次** |
| 总容量需求 | **90–140 mL / 更换周期** |
| 尿液热点 | **裆部（crotch）承接 45–55% 前裆区域** |

**关键设计含义（源文明写）**：**尿液目标区（裆部，距前缘约 130–260 mm）承接 ≥73% 的总吸收需求**；**前区靠 SAP2（liner 侧）快速摄入**，**poly 侧靠 N511 + SAP1 做分布与主体储存**。

### 2. 三种 SAP 的规格与分工

| 指标 | **NR-511（诺尔）** | **SAP1（快吸）** | **SAP2（高 GBP / liner 侧）** |
|---|---|---|---|
| **角色** | Poly 侧**主体储存** | Poly 侧**共混 · 快速摄入** | Liner 侧顶层 · **回渗控制** |
| CRC (0.9% saline) | **31.5 g/g**（30–34.5） | 28–30 g/g（≥28） | **26–29 g/g** |
| AUL (0.9 psi) | 18.2 g/g（≥16） | **20–23 g/g**（≥20） | **22–25 g/g** |
| 粒径 D50 | 300–600 µm（76.2% 落在区间） | 300–500 µm（与 N511 相近） | **500–800 µm（更大）** |
| 表观密度 | 0.61 g/mL（0.57–0.65） | 0.60–0.65 g/mL | 0.62–0.68 g/mL |
| pH | 6.2（6.0–6.5） | 6.0–6.5 | 6.0–6.5 |
| **GBP** | **26 mD**（≥20） | 20–30 mD（≥18） | **45–60 mD（最高）** |
| **Vortex** | 28 s（≤45） | **15–22 s（最快）** | **30–45 s（最慢 · 受控溶胀）** |
| 含水率 | 4.9%（0.5–6.5） | — | — |
| 残留单体 | 170 ppm（≤400） | — | — |
| 交联类型 | — | **轻度表面交联** | **高双交联（芯部 + 表面）+ 增强涂层** |
| 膨胀倍率 | ~35×（vol） | **≥40×（vol）** | — |

- **N511**：经**气流分级 + 防结块处理**，吸收与渗透**平衡**，用于**分布**。
- **SAP1**：**与 N511 相近的粒径分布**（保证共混均匀）+ **更快 Vortex 与更高 AUL**，用于**应对多次排尿**。
- **SAP2**：**更大颗粒 + 更强交联 → 更高 GBP**，**在婴儿体重载荷下维持渗透性**；定位是**回渗屏障 + 抗压**。

### 3. 五层结构（横截面，liner 侧 → poly 侧）

| 层 | 构成 | 定量 / 规格 | 功能 |
|---|---|---|---|
| **L1** | Liner 侧芯体包覆 NW（tissue 或 SMS） | **15–18 gsm**，**穿孔 / 亲水** | 容纳 SAP2，实现液体摄入 |
| **L2** | **SAP2 区（liner 侧超吸）** | 高 GBP SAP2，**500–800 µm** 大颗粒 | **回渗屏障 + 抗压** |
| **L3** | **TABCW 增强层（热风粘合梳理网）** | **20–25 gsm** | **结构分隔 + 横向分布辅助** |
| **L4** | **Poly 侧 SAP 共混（N511 + SAP1 = 70:30）** | — | **主体吸收 + 分布容量** |
| **L5** | Poly 侧芯体包覆 NW（tissue 或 SMS） | 15–18 gsm | 底部包容，**与背层粘合** |

- **总厚（干态）≈ 3.2 mm**；**功能矩阵**：L1 包容+摄入 / L2 快速摄入+回渗阻断 / L3 分布+结构 / L4 主体储存+芯吸 / L5 包容+粘合。

### 4. MD 四区定量分配（单位 g）

| 区域 | 范围 (mm) | SAP2 | N511 | SAP1 | 区域合计 |
|---|---|---|---|---|---|
| **Zone A（前）** | 0–77 | 1.0 | 1.05 | 0.45 | **2.50** |
| **Zone B（裆前）** | 77–200 | 2.0 | 2.45 | 1.05 | **5.50** |
| **Zone C（裆峰）** | 200–270 | 1.5 | 1.75 | 0.75 | **4.00** |
| **Zone D（后）** | 270–385 | 0.5 | 1.05 | 0.45 | **2.00** |
| **合计** | — | **5.0** | **6.30** | **2.70** | **14.0** |

- **SAP 重量分布**：N511 **45%** / SAP1 **19%** / SAP2 **36%**。
- **SAP 定量（仅 SAP）≈ 329 g/m²**（14 g / 385×110 mm）。
- **分配逻辑**：**SAP2 前置于 A+B（合计 3.0 g，占其总量 60%）**，因为**回渗风险最高的区域在前部**；**后区减少投放以避免浪费**。
- **Zone B 优先**：**35%+ 的尿液需求落在 Zone B**，此处加密投放**使每克材料的 ROI 最大**。

## 关键论断 Key Claims

1. **回渗屏障可以"用 SAP 选型来做"，而不必只靠面层** —— SAP2 放在**最靠 liner 的一层**，用**高 GBP（45–60 mD）+ 大颗粒（500–800 µm）+ 双交联**在载荷下保持渗透性。**这是"芯体即功能层"的设计思路。**
2. **三 SAP 是按"指标分工"而非按"成本分工"选型的** —— N511 平衡（GBP 26 / Vortex 28 s）、SAP1 快（Vortex 15–22 s）、SAP2 透（GBP 45–60 mD）；**每个牌号只负责一项性能，靠分层组合取全**。
3. **分区投放的本质是"把材料放到尿液落点上"** —— **≥73% 的吸收需求在裆部**，**Zone B 单独占 35%+**；**把 SAP 均布等于把 1/3 的材料放在不需要的地方**。
4. **SAP2 前置、后区少投** —— 回渗风险在前部，因此 **SAP2 的 60% 放在 A+B**，后区仅 0.5 g。**"贵的材料只投在风险区"是成本与性能同源的优化。**
5. **共混均匀性靠粒径匹配保证** —— SAP1 与 N511 **粒径分布相近**是 70:30 共混能均匀的前提；**共混比不只是配比问题，也是粒径匹配问题**。
6. **利用率被当作"上限约束"而非"越高越好"** —— KPI 表把 **SAP 利用率 ≤90%** 作为限值（85% 通过），**留出余量以避免饱和后失效**；这与"利用率越高越经济"的直觉相反。
7. **设计起点是生理数据，不是竞品对标** —— 15–20 次/日、2–5 mL/s 峰值流速直接推出**"短促爆发 + 多次冲击"的载荷谱**，这才决定了需要"快吸 SAP1 + 抗压 SAP2"的组合。
8. **全无浆把厚度压到 3.2 mm 干态** —— 5 层全部由 SAP + 非织造构成，**同时带来包装材料的节省**（源文列为无浆化的次级收益）。
