# OI 项目清单与优先级（2026-09-18 汇报准备稿）

## 一句话定位

依 2026-09-18 最新 OI 项目清单、会议纪要与年度汇报大纲，按**五个方向**（BNC / Odor Control / REL / Liner / SAP）整理的项目全貌与讨论要点——**本库卫生用品创新项目（OI 系列）的总纲来源**。

## 摘要

材料按五方向组织。**BNC（OI-01 NanoCellules）**：海南拜瑞科供应，BNC 40–60 nm、杨氏模量 78 GPa、拉伸强度 826 MPa、持水率 200–1000×、孔隙率 >90%，成本约 RMB 50,000/t；六条应用路线已排序并设三道决策门；延伸方向为**纳米纤维素热熔胶（HTM adhesive）**（纳米纤维素为核 + PEG/PCL 母粒），目标替代/减少 SAP，列为 2027 旗舰项目。**Odor Control（OI-09 + OI-18）**：中科依兰供应，9/18 会议明确重点从「尿味」转向「胶水/塑料袋气味」。**REL（OI-02/04/14/20）**：四个项目覆盖 PVA 纤维、PVA/PTT、3 梳理 + SAP、三层梳理 + SAP。**Liner（OI-25 + 异形纤维）**：新增 High 项目，含三叶形 PET 与 Z 梯度设计。**SAP（OI-13 + OI-06）**：双 SAP 架构 + 可降解 SAP（暂停）。末尾附五项跨项目战略议题。

## 关键论断（key_claims）

- **REL 是当前项目群重心** —— 四个 OI 项目沿技术演进路径组织，且 OI-20 已将 Route A 升级为优先。支撑页：[[REL增强层]]、[[COCO芯体平台]]
- **分区化取代均匀化** —— 这是影响 REL/Liner 架构的路线级调整（丝网分区密度、Z 梯度）。支撑页：[[REL增强层]]
- **BNC 的落点在 HTM 热熔胶** —— 目标替代/减少 SAP，2027 旗舰项目，尚未立项。支撑页：[[细菌纳米纤维素]]、[[海南拜瑞科]]
- **Odor Control 对象已换** —— 从尿味转向胶水/塑料袋气味，意味着评价体系（9 种代表性臭味物质）与验证方案需同步调整。支撑页：[[中科依兰]]
- **合规升为选材前置条件** —— 对 Odor Control / BNC 改性等涉化项目构成硬约束。
