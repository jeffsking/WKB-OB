# GB-T28004-2011 PH.doc

## 一句话定位 One-line Positioning

**纸尿裤 pH 值** 的国标（GB/T 28004-2011）作业方法：1 g 试样 / 200 mL 蒸馏水浸提 10 min，三点校准电极读取，双样平均精确至 0.1 pH 单位。

## 摘要 Summary

本作业文件按 GB/T 28004-2011 测纸尿裤 pH 值。测试前需拔掉电极上的运输保护盖、用蒸馏水冲洗电极并清除沉积盐、像甩动医用体温计一样甩动电极以排除气泡，并把电极浸泡于 3 M KCl 溶液 2 h 以活化。样品准备：同规格产品任取两片，剪去边部松紧带、去掉底膜，剪产品中间部位；各从每片样品任取 1 g（称准至 0.001 g）试样放入 400 mL 烧杯，加入 200 mL 蒸馏水并用玻璃棒用力搅拌；若未见游离水应适当多加水直至出现游离水为止，此时开始计时并适当搅拌试样；10 min 时放入电极测试其 pH。取 2 个试样测试值的算术平均值作为测定结果，精确至 0.1 pH 单位。仪器操作：开机后切换测量模式到 pH 模式，将电极分别插入 25 ℃ 的 pH 4.01、6.86、9.18 缓冲液中，按 CAL 键校验（"A"闪烁表示测试中，根号 A 表示稳定），三点校准完成后按"结束"并"保存"；按 Read 键 3 秒切换进入测试状态，将电极插入样品内按 Read 键测量，数值稳定后读数；测试后用蒸馏水清洗感应端并用标准滤纸擦干；全部结束后电极擦干放入专用保护液、盖保护盖，按 ON/OFF 键 2 秒关机。

## 测试方法要点 Method Specification

| 项目 | 口径 |
|---|---|
| 标准 | GB/T 28004-2011 |
| 取样 | 同规格任取 2 片；剪去边部松紧带、去掉底膜，剪中间部位 |
| 试样量 | 每片任取 1 g（称准至 0.001 g） |
| 浸提 | 400 mL 烧杯 + 200 mL 蒸馏水，玻璃棒用力搅拌 |
| 计时起点 | 出现游离水时开始计时（不足则补加水） |
| 浸提时间 | 10 min |
| 电极活化 | 3 M KCl 浸泡 2 h |
| 校准 | 三点缓冲液 pH 4.01 / 6.86 / 9.18（25 ℃） |
| 结果 | 2 个试样算术平均，精确至 0.1 pH 单位 |
| 读数判据 | 屏幕"根号 A"出现表示数值稳定 |
