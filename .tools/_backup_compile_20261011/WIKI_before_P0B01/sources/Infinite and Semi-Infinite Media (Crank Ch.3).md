# Infinite and Semi-Infinite Media (Crank Ch.3)

*J. Crank — The Mathematics of Diffusion, 2nd ed., Clarendon Press 1975 · Ch.3 · 8 KB*

## One-line Position 一句话定位

**无限/半无限介质中的扩散源函数族**——四类源（点/面/球/柱）与连续源的完整解析解，是 SAP 单球溶胀与湿巾湿斑扩散的数学基础；半无限域解是芯体厚度远大于扩散长度时的有效近似。

## Summary 摘要

- **四类源函数族**：
  - 瞬时点源——n 维推广 C = A t^(-n/2) exp(-r²/4Dt)
  - 瞬时面源——一维基本解
  - 瞬时球源——三维有限初始分布
  - 瞬时柱源——二维有限初始分布
- **球源轴心解**：C = C₀{1-exp(-a²/4Dt)}——单个 SAP 微球球心浓度指数演化。
- **圆盘源**：Q(t) = 2πa²C₀ ∫₀^∞ [J₁(ωa)]² exp(-Dτω²)dω——湿巾湿斑扩散模型。
- **半无限域**：芯体厚度远大于扩散长度时的有效近似。
- **Bessel 函数**：I₀, J₀, J₁ 是柱/球坐标下的标准工具。

## Key Claims 关键论断

- **SAP 单球溶胀有解析解**——球源轴心解直接给出浓度演化，估算 SAP 吸水饱和速率初段。
- **湿巾湿斑扩散=圆盘源问题**——Rideal & Tadayon 方法给出解析级数形式。
- **半无限域是芯体建模的有效近似**——芯体厚度 1-2mm 远大于初期扩散长度时适用。
