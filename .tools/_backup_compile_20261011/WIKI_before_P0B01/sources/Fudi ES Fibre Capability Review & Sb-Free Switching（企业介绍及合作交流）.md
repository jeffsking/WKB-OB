# Fudi ES Fibre Capability Review & Sb-Free Switching（企业介绍及合作交流）

> ASR 转写讹字说明：本稿为供应商交流会录音自动转写，**时间戳乱序**（非按发言顺序）。已识别的讹字/音转：
> - **「无 t / 五 t / 有 t / 有气无气 / 五 T」** = **无锑 / 有锑（Sb，antimony）** —— 由 PET 缩聚的**锑系催化剂**引入；改用**钛系催化剂**即可无锑（原文："T 是 PET 在做成 PET 的过程有个催化剂……锑型催化完全可以用钛型催化，不要用 T 这个东西"）
> - **「清水 / 聚水 / 多氢 / 洛氢 / 强氢」** = **亲水 / 拒水（疏水）**；「单清 / 弱清 / 强清 / 超干爽」= 单点穿透亲水 / 弱亲水 / 强亲水 / 超干爽
> - **「三页 / 三角 / 椰子 / 意子 / 异形」** = **三叶（trilobal）**；「椰子纤维 / ES 纤维」= ES 复合短纤维
> - **「前返 / 后返 / 反思 / 分丝板 / 泵房」** = 前纺 / 后纺 / 纺丝 / 喷丝板 / **混纺**
> - **「格莱伯 / galab / 格莱 B / 盖的」** = **GALAB**（德国检测机构）；「瑞曲 / SBHC」= OEKO-TEX / SVHC [待验证]
> - **「恒毅」** = 恒逸 [待验证]；「实施 / 石狮」同指石狮基地；「甲酰胺」为行业事件指称 [待验证]

## Key decisions 决策要点

1. **供应商定位与产能规划（已明确）**：
   - **ES 复合短纤维**专业制造商，2017-04 成立、2018-03 出产品，起步即为 2.0 D / 1.5 D 高端定位；愿景为「全球最值得信赖的高品质纤维制造商」；**2034 年目标年产 30 万吨以上**。
   - 现有：泉州**晋江**（1 条线，2 万吨/年）+ **石狮**一期（4 条线）→ 合计 **5 条线、10 万吨/年**，月产约 **8,500 吨**。
   - 在建：**苏州常熟**（规划 3 条线，明年 9–10 月先投 2 条线，约 4 万吨）；石狮**二期**（80 亩，规划 6 条线）。总规划 **14 条线、28 万吨**。
   - **常熟定位为未来研发总部**（周边 100 km 辐射四五所高校，人才资源优于泉州）；现研发在石狮。
   - **日本公司（东京）已成立**，1 位日本同事：① 搜罗日本 ES 纤维厂工程师；② 对接日本当地国际品牌做产品推荐与测试。
2. **无锑（Sb-free）路线（已决方向）**：
   - 机理：锑来自 PET 缩聚的**锑系催化剂**；**改用钛系催化剂即可做到无锑**。切片端**恒逸、恒力**均可供无锑切片，且**已在大线上机生产过**。
   - 供应商表态：将**快速把无锑全部覆盖掉**（而非循序渐进），并在 20 天内按竞品最高标准把产线（含可能与塑化剂相关的辊、链条、输送带）**全部换一遍**。
   - 现有客户已有**按 30 余吨/车**发货的常规无锑供应，测试报告送 GALAB 检测均无问题。
3. **本方（K-C）明确提出的合作前提（已表达）**：
   - **希望纤维厂具备小型成布能力** —— 只给纤维不够，需要能把纤维在布上做出 demo、甚至做成布卷/成品，以便本方直接换料做**单变量验证**。
   - 本方明确：拿到"成品数据"参考价值有限，因为**结构不同**（面层、导流层、芯体结构均不同），本方仍须自己把材料拿去测；因此**最有效的是给布卷**。
   - 异形纤维（扁平/三叶/中空）的**单一性能无法承载全部功能需求**，最终必须走到**混纺**（含上下层比例）的方案比对。
4. **产品与结构路线（已明确）**：
   - 纤度：现主力 **0.6–3.0 D**，最近开 **5.0 D**，实验线规划 **12 D**；路线是**从细旦往粗旦扩**（品牌方希望一个工厂提供更多品类）。
   - 亲水/拒水比例约 **4:6 或 6:4** [待验证]；超细旦（0.6 / 0.8）聚焦**拒水**端（因亲水端反渗量太大）。
   - 新结构：**偏心**（2.0 / 2.5 / 2.8 D，已稳定量产）、**扁平**（现做到 3.0 D）、**中空**（开发中，中空度 7–8%，目标 15%）、**三叶**（实验线已出产品，Q4 推出）。

## Open issues 待决问题

1. **检测标准与检出限未对齐**：SGS 口径 T 含量要求假设为 5 ppm、检出限约 **20 mg**；而 **GALAB** 检出限约 **0.1**，且"设备能检出来的都给你检出来"。本方要求供应商**明确其执行的标准、可达成的指标、以及测试方法（消解法 vs 萃取法）** —— **萃取法测不出**，消解法才有绝对含量。
2. **无锑切换的工艺能力（process capability）未量化**：本方要求供应商给出「排料—过渡—隔离」的时间与量，并做**工艺能力测试**（多久后风险降到最低）；供应商现有做法为**按物料排空为指征**（有 T 料需退出数十吨、停机、清料仓），并已有定型工艺（排料 + 过渡料量），但**未做过系统性的时长—残留研究**。
3. **在线切换 vs 专线**：在线切换每次都有一 residual 风险；**专线（dedicated line）**是最优解但需足够量。存量受行业事件（原文称"甲酰胺事件"[待验证]）影响暂时下降，等"国家队"通知后可能回升。
4. **无锑的成本增量**：供应商口径约 **700–800**（单位 [待验证]，双组分口径，单/双组分是否需除以二未定）；本方与热风厂可各吸收一部分以压缩品牌端加价 —— 具体分摊**未定**。
5. **扁平纤维的手感未达预期**：初衷是模拟动物毛发（扁、丝滑），做出**粗旦化但手感细旦化**；实测摩擦系数与柔滑度数据较好，但**触感偏棉感、顺滑度未达预期** → 方向转为**利用其更大比表面积**做导流层的扩散。
6. **三叶纤维尚未测试到布上表现**：实验线已出 200 kg 左右（3.0 D 强亲水），但**未做布上测试**；本方希望寄样约 **10–20 kg**（供应商现有 200 kg）。
7. **中空度目标差距**：国内（含自产）中空度普遍卡在 **7–8%**，日系可达约 **15%**；目标 15%，尚未达成。
8. **可降解路线（PLA/PBAT/PBS）仍在对接供应商阶段**，面临手感与成本问题，未排定节拍。
9. **样卷规格**：本方实验机需一两卷；常规大卷卷径 1 m 以内，样卷约 800 mm–1 m。本方提出**往复收卷（左右移动收卷）**可减少换卷 —— 供应商需回去确认是否具备"防卷/反锤（纺锤式放卷）"能力。
10. **打样最小量**：不动前纺（只动后纺上油/卷曲）可 **200–300 kg**；需动前纺设备约 **600 kg–1 吨**。实验线后纺 **5 吨/天**，大线 **60 吨/天**。
11. **幅宽匹配**：样卷幅宽依排产而定（通用规格），本方新品类需提前 1–2 周才能确定；克重基本可先定。
12. **成品端指标固定化不现实**：本方明确，打样时无法固定 SAP 添加量等其他材料指标 —— 因各品牌结构不同，成品数据参考意义有限。
13. **是否上"从塑料米直接做到成品纸尿裤/卫生巾"的实验大线**：供应商在规划中，本方表示"如果有意向有能力，那肯定是最好的"。
