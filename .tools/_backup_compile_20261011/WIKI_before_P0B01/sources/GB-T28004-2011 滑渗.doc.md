# GB-T28004-2011 滑渗.doc

## 一句话定位

南京厂引用的 **GB/T 28004-2011《纸尿裤》滑渗量（run-off）测定法**：在 **30° 斜面**上一次性倒入 **60 mL 生理盐水**，称量从产品表面流走的液体量，用于评价"液体没被吸住、顺着表面跑了"的程度（中文：滑渗量）。

## 摘要

测试装置为一台可调角度的斜面测试仪：**上下面板夹角调至 30 ± 2°**，下面板须处于水平面；放液漏斗下口中心点的投影距斜面板下边缘 **200 ± 2 mm**，下口开口朝向操作者；漏斗先用生理盐水润洗两遍。样品需**剪去两边松紧带（含立体护围）**后平铺在斜面上、使用面朝上、后端朝上，自内置吸收层中心点两侧各量 **100 mm** 作为受液面，长出部分分别向斜面上部与底部折回，用 **4 个夹子**固定（夹子不得妨碍液体流动）。调节漏斗高度使其下口最下端距样品表面 **5–10 mm**，下方放烧杯收集流下液体。用量筒量取 **60 mL** 测试液，迅速把漏斗活塞打到最大使液体自由流到样品表面，流完后关闭活塞；再用量筒量取烧杯中收集的液体，**量准至 1 mL** 即为单次结果。若液体从样品侧面流走，该次作废并另取一片重测。每个样品测 **7 条**，去掉最大值与最小值，取其余 **5 条的算术平均值**作为最终结果，精确至 **1 mL**。

## 提炼的数字与结论

| 项目 Item | 数值 / 结论 Value | 备注 Note |
|---|---|---|
| 斜面角度 Angle | **30 ± 2°**（上下面板夹角） | 下面板须水平 |
| 漏斗定位 Funnel position | 下口中心投影距斜面板下边缘 **200 ± 2 mm** | 下口朝向操作者 |
| 漏斗高度 Funnel height | 下口最下端距样品表面 **5–10 mm** | — |
| 注液量 Insult | **60 mL** 生理盐水（一次放完） | 活塞打到最大 |
| 受液面定义 Test area | 自吸收层中心点两侧各 **100 mm** | 长出部分折回、4 夹固定 |
| 样品预处理 Pretreatment | 剪去两侧松紧带（含立体护围） | 使产品可平铺 |
| 单次读数 Readout | 烧杯收集液体积，**量准至 1 mL** | — |
| 重复与取值 Replication | **7 条**去最大最小 → **取余 5 条均值** | 精确至 1 mL |
| 作废判据 Void rule | 液体从样品**侧面**流走 → 该条作废 | 另取一片重测 |
| 测试液 Liquid | 生理盐水（文中未给浓度与温度）`[待验证]` | 与 GB/T 28004-2011 回渗同源 |

> ⚠️ **口径差异（2026-09-29）**：本页 30° 滑渗与 [[TTM-00279产品30°滑渗测试.docx]] **同为 30° 滑渗但来源与口径不同**——本页注液量固定 **60 mL**、取 **7 条去极值取 5 条均值**、无分方位要求；TTM-00279 按 **Cradle 出液量 180 mL ±1%**、以 **C 线 325 mm** 定位、并要求**前部/后部/侧面三方位**各测一次。**两者数值不可直接比较**，引用必须带方法号（见 [[Run-off 30° 两法对比（GB-T28004-2011 vs TTM-00279）]]）。
