# BIG LEAGUE - Cradle Intake Improvements Across BCC One Pager (April 2026).pptx

## Basic Information 基本信息
- **Title**: ActivTech Hybrid Cradle Intake Improvements Across BCC
- **Date**: 2026-04（one pager）
- **Domain**: Performance / Intake —— ATH 芯体 cradle intake 改进跨三产品格式汇总

## Results Matrix 三格式结果矩阵（三格式结果矩阵）

| 格式 | 手段 | Cradle intake 前后 | 当前 SAM/Fluff 参照 |
| --- | --- | --- | --- |
| Open Diapers | fluff +0.5 g；MACH 3→**MACH 4** SAM；ActivTech 胶 4.0%→3.2% | **15s-15s-60s+ → 10s-10s-40s** | 10s-10s-40s |
| Training Pants | SAM 由 ActivTech 层**移入 fluff 层**；宽度 80→100 mm；胶 4.0%→3.2% | **25s-25s-220s → 15s-15s-30s** | 10s-15s-13s |
| Youth Pants | SAM 移入 fluff 层；MACH 4→**MACH 5**；fluff 克重↑；宽度↑ | **25s-15s-40s → 15s-10s-20s** | 10s-10s-50s |

（Youth Pants 为 XS 码测试）

## Design Principles 设计原则（设计原则）
1. **增加 void volume**（增孔隙体积）。
2. **更快锁液** → 加速液体渗透。
3. **Functional capacity**: 让 SAM 更可及、更快溶胀。
4. **更充分覆盖 target zone**（润湿图谱目标区）。

## 关联
- 与 [[ActiveTech Platform（ActiveTech 在线薄芯体平台）]] 的 ATH 回渗问题记录互补：本页是**摄入侧**的改进成果（2026-04），ATH 仍在 GRIFFIN 范围外但持续优先跟进；SAM 迁移到 fluff 层与该页"SAM relocation 未达预期"的怀疑形成对照——Training/Youth Pants 中迁移本身即有效。
