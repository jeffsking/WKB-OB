# Liner-Surge Interface HSBL Trial.xlsx

## Basic Information 基本信息
- **位置**: GRIFFIN Rewet 目录
- **性质**: HSBL trial 设计变量表（与 [[Full Results.xlsx]] 实测结果配套）
- **Domain**: Performance / Rewet / 面层-导流层界面（联系人：Mike Markley）

## Variables 设计变量（设计变量）

| 变量 | 水平 |
| --- | --- |
| Adhesive Pattern | Depend (Summit) / Signature 62mm / Always Discreet (CF Swirl) / Always Discreet (Slot) |
| Adhesive Add-On | 1.7 gsm（spec LL）/ **2.8 gsm（spec target）** / 3.9 gsm（spec UL）；部分组合 Disallowed |
| Adhesive Type | **Rextac RT-8723（phobic, APAO）** vs **Henkel 5402（rubber-based）** |
| Bond Pattern | PICASSO / Honeycomb / None |
| Bonding Type | Pressure / Ultrasonic / Thermal（部分 Disallowed） |

橙色单元格 = control。

## 关联
- 设计矩阵与 [[Full Results.xlsx]] 的 22-code 实测一一对应（施胶双胶种、PICASSO 压合、1.7-3.9 gsm add-on 均已在结果页量化）；试验计划与施胶计算见 [[HSBL Rewet Trial Plan & Adhesive Calcs（面层-导流层施胶回渗试产计划）]]。
