# TTM-00279产品30°滑渗测试.docx

## 一句话定位 One-line Positioning

**30° 滑渗（run-off）** 方法（第 3 版）：产品置于 30° 斜面，定量注液后收集未被吸收而流走的液体并称重。与 [[GB-T28004-2011 回渗渗漏.doc]] 的"渗漏量"、[[TTM-00296产品外层滚轮测试（Pin Hole）.docx]] 的"外层渗漏"共同构成 [[Run-off & Leakage Test（滑渗与渗漏测试）]] 三口径。

## 摘要 Summary

本方法通过测定不被成品吸收的液体量来评估产品的吸收或潮湿性能。测试前把生理盐水水浴加热到 37 ℃，并在斜板上标记 C 线（位于测试面顶部往下 325 mm 处）。仪器准备：主菜单选"定量输注模式"，流量单位确认为 mL/min、管路尺寸确认为 25，流量设定按 Cradle 设置；进入"管路校准"确认出液量为 180 mL 并把称量值输入，再退出调整至设定流量，复校出液量应满足 180 mL±1%；再按 Cradle 设置"容积"，并确认定量输注模式下溶液在设定值 ±1%。样品准备：按穿着方向标记前后左右，用手指沿折页和腿部使其拉直并保证折页立起，按 Cradle 标准确定注液点，剪断腿部皮筋与折页使产品能放在斜面上。测试步骤：分别做前部（吸收芯前部边缘与 C 线重合）、后部（后端边缘对齐 C 线）、侧面（侧边缘对齐 C 线）三次滑渗；调整产品使注液点位于斜面正中、其下方即斜面收集液体的洞；称量干烧杯（0.1 g）并置于收集洞下方；在不受压前提下把注液管口对准并垂直于注液点；开泵注液，注液完毕后等全部液体进入烧杯并称重（0.01 g）；再把烧杯中的溶液沿注液点缓慢倒回产品确认完全吸收；设 5 min 计时器，擦干烧杯后重复步骤 3–6 做第二次；最后记录滑渗值。

## 测试方法要点 Method Specification

| 项目 | 口径 |
|---|---|
| 斜面角度 | 30° |
| C 线位置 | 测试面顶部往下 325 mm |
| 测试液 | 生理盐水，37 ℃ |
| 管路尺寸 | 25（标准出液管） |
| 管路校准出液量 | 180 mL ±1% |
| 流量 / 容积设定 | 按 Cradle 设置 |
| 注液方式 | 定量输注模式，注液管口垂直对准注液点且不受压 |
| 测试方位 | 前部 / 后部 / 侧面（吸收芯对应边缘对齐 C 线） |
| 两轮间隔 | 5 min |
| 称量精度 | 干烧杯 0.1 g；收集后 0.01 g |
| 计算式 | 滑渗量 = 收集液烧杯重量 − 空烧杯重量 |
