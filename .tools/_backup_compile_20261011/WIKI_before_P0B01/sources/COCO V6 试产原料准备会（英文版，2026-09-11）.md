# COCO V6 试产原料准备会（英文版，2026-09-11）

## 一句话定位

COCO V6 芯体试产的**英文版原料准备会材料**：一页讲清「4 个位置 / 9 项物料 / 3 个选择维度」，是试产**物料矩阵与选型逻辑**的最简版底稿（不含结构与测试附录）。

## 摘要

准备会以「4 位置 · 9 项 · 3 选择维度」定调，供应商为 Yanjan（Liner）、Minrui（REL）、Nuoer（SAP）、Unikorn（Core wrap）。三个选择维度分别是：**① Liner 选型**——Code 1（50 gsm，双组分 PE/PET 双层）／Code 2-A（30 gsm，与 Code 1 同配方半克重，优先）／Code 2-B（30 gsm，上层去三叶形，视样本量）；**② SAP 上下层组合**——Code X 或 610S 作顶层、950 作储库；**③ Core wrap 选型**——LSN MPM 与 PSN MPM（均 20 gsm）；输出物为 **Core Code List**。REL 被明确为**单一方案（Minrui，28 gsm，6 卷）直通，不进入选型矩阵**。SAP 附页给出四牌号横评与「Code X vs 7 月开发目标」对照，并标注三条口径警告（0.9psi vs 0.7psi 不可比、KC511 GBP 跨源四值、Code X 缺 DI/1min/残单）。Prep notes 记录：Core wrap 2 项已到货、其余 7 项 ETA 9/18；Code 2-B 是否上机取决于异型纤维样本量；**Code X 样品仅 20 kg，试产规模必须匹配**。

## 提炼的数字与结论

**试产物料矩阵（4 位置 · 9 项）**

| 位置 | Code / 材料 | 规格构造 | 数量 | 供应商 | ETA / 站点 |
|---|---|---|---|---|---|
| Liner（双层 PE/PET Bico） | Code 1，50 gsm | 上 25 gsm = 10% 三叶形 + 90% 2D；下 25 gsm = 50% 三叶形 + 50% 4D（三叶形 = Fudy；2D/4D = Yanjan）；102 mm × >100 m | >100 m | Yanjan | 9/18 - 天津 |
| Liner | Code 2-A（优先），30 gsm | 上 15 gsm = 10% 三叶形 + 90% 2D；下 15 gsm = 50% 三叶形 + 50% 4D（同 Code 1 半克重）；82 mm × 6 km | 6 km | Yanjan | 9/18 - 川越 |
| Liner | Code 2-B（备选），30 gsm | 上 15 gsm = 100% 2D；下 15 gsm = 50% 三叶形 + 50% 4D（上无三叶形） | 6 km | Yanjan | 9/18 - 川越 |
| REL | 单一方案，28 gsm | 上 11.2 gsm = 80% 2D PE/PET 38mm + 20% 3D；下 16.8 gsm = 50% 3.5D 中空 + 40% PTT/PET + 10% PVA；145 mm × 300 m | 6 卷 | Minrui | 9/18 - 天津 |
| SAP | Nuoer 610S | 极快吸 / 低 GBP：Vortex 19 s（四支最快） | 300 kg | Nuoer | 9/18 - 天津 |
| SAP | Nuoer 950 | 高 CRC / 高 AUL 储库；保水 36.7 g/g（四支最高） | 300 kg | Nuoer | 9/18 - 天津 |
| SAP | Nuoer Code X | 高 GBP 试产样：GBP 55.3 Darcy，远超其余三支 | 20 kg | Nuoer | 9/18 - 天津 |
| Core Wrap | LSN MPM，20 gsm | 200 mm × 4 km｜卷径 ≤800 mm，6.75″ core | 2 km | Unikorn | 已到 - 天津 |
| Core Wrap | PSN MPM，20 gsm | 150 mm × 4 km｜卷径 ≤800 mm，6.75″ core | 2 km | Unikorn | 已到 - 天津 |

| 指标 | KC 511 | NR-610S | NR-950 | Code X（20kg） |
|---|---|---|---|---|
| CRC 保水 (g/g) | 30.9 | 30.8 | 36.7 | 28.8 |
| AUL (g/g) | 18.4（0.7psi） | 12.1（0.7psi） | 19.4（0.7psi） | 22.2（**0.9psi**） |
| GBP (Darcy) | 24 | 6 | 8 | 55.3 |
| Vortex 吸收 (s) | 29 | 19 | 51 | 33 |
| 1 min 吸水 (g/g) | 145 | 227 | 117 | —（未给） |

| 角色 | 快吸顶层 · 高 GBP | 极快吸 · 低 GBP | 高 CRC/AUL 储库 | 高 GBP 新品 |

> **口径警告（原文）**：① Code X 的 AUL 为 0.9psi、其余三支为 0.7psi，**不可直接横比**；② KC 511 的 GBP 跨源有 24/25/26/35 四值，本表取 S1 实测 24；③ Code X 未提供 DI 自由溶胀 / 1 min 吸水 / 残单（其余三支 DI 自由溶胀 59.4–62.5 g/g、残单 154–156 ppm 相近，故略）。
