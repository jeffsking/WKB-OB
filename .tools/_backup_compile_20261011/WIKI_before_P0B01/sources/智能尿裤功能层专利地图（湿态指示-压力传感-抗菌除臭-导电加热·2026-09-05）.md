# 智能尿裤功能层专利地图（湿态指示/压力传感/抗菌除臭/导电加热·2026-09-05）

## One-line positioning 一句话定位

An **internal landscape map**（内部专利地图，补库动作 4）把「BNC 干颗粒可嫁接载体」与「智能尿裤四大功能层」连成一张决策图：每层列技术路线、代表专利、载体形态要求、成熟度与 BNC 契合度，并给出 FTO 速查。本库把它当作**智能功能层导航页**——它不是原始专利文本，其中所有法律状态与「可自由实施」判断都必须按原话记录、逐件复核后才能使用。

## Summary 摘要

地图分四层展开。①湿态指示：热致变色（US5197958 已过期、US5389093 已放弃、US20070270773A1 公开未授权且非 P&G、US8273939B2 有效约 2027+PTA、CN116327488B 有效）、电子/导电回路（US20220125319A1、K-C US11013641B2、Ontex Orizon 量产）、pH/化学比色（CN114209501A、Pixie Scientific 原型）。②压力传感：电容/压阻织物阵列（UC Regents、深圳先进院）实验室→原型，尿裤内置无量产；BC 织物/BC-CuNW/纳米纤维素压感文献扎实。③抗菌除臭：纳米 Ag/ZnO/TiO₂ 复合 SAP/面层多条路线，CN117024899A 与 BNC 嫁接几乎同构，为最优切入点；除臭四路线（物理吸附/化学中和/微胶囊/消臭 SAP 一体化）。④导电加热：印刷导电油墨（JABIL PTC 自限温）量产级但尿裤集成早期；纤维素基加热文献级。总体判断：抗菌除臭是 Face 1 首选落点，压力传感是蓝海但成熟度最低，导电加热作 Face 2 储备。
