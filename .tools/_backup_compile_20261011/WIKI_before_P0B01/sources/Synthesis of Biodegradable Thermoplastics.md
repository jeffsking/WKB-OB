## Scope and Structure 范围与结构

本综述聚焦一类材料：**以聚乳酸（PLA）为硬段、以低 Tg 聚合物为软段的 A-B-A 三嵌段共聚物热塑性弹性体**（PLA-b-(soft segment)-b-PLA）。它不是配方手册，而是把「软段选择 → 合成路线 → 热性能 → 力学性能」串成一条设计逻辑：软段两端的水羟基充当大分子引发剂，直接引发丙交酯开环聚合，因此嵌段组成与分子量均可由投料比事先设计。

## Relevance to Hygiene R&D 与卫材研发的关联

相关性评级：**中（可持续材料设计参照，非直接产品依据）**。原文未提及任何卫材应用；其价值在于给「可降解弹性件」提供一套**软段选择谱与回弹评价口径**。

| 可迁移要点 Transferable point | 卫材落点 Where it lands |
|---|---|
| 软段设计原则：半结晶软段（ε-CL 均聚 Tg −60 / Tm 60 ℃）不可直接使用，需无规共聚打掉结晶（CL:DLLA = 70:30 得非晶软段） | 可降解弹性膜/弹性无纺布（腰围、防漏隔边）的配方设计逻辑：先保证软段非晶与低 Tg，再谈强度 |
| 弹性恢复评价口径：10–65% 应变、20 次循环、残留应变 11.1% | 可直接借用的弹性件评价方法，比单点断裂伸长率更贴近实际贴身反复拉伸工况 |
| 耐热性短板（PLLA Tm ≈ 170 ℃，作者自认耐热性待提升） | PLA 基 TPE 短期不宜进入热风/热轧高温在线工序；上机前须实测软化点与热收缩 |
| 可降解路线对照：PLLA-b-PM-b-PLLA 加粘着剂可赋予压敏胶功能 | 与可降解热熔胶方向相关，可与 [[Synthesis of Thermoplastic Polyester Elastomers]] 的聚酯弹性体路线互校 |

诚实评价：**这是材料设计层的参考文献，不是工程工艺文件**。它能回答「为什么选这个软段」「回弹该怎么测」，但不能直接给出卫材产线可用的加工窗口与成本模型；卫材端可降解工程化现状应回到 [[PPC&PGA 基无纺布开发方案（第二版）]] 与 [[Seawater-Degradable SAP 3D Hydrogel System Technical Report（海水可降解SAP三维水凝胶体系技术调研）]]。
