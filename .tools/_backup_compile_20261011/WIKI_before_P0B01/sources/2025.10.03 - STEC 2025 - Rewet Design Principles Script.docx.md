# 2025.10.03 - STEC 2025 - Rewet Design Principles Script

## Basic Information 基本信息
- **Speaker**: Kerry Clemmer（NA 回渗负责人）；global 接口为 Ingrid Hoeger
- **Venue**: STEC 2025 技术会议演讲底稿（script）
- **Domain**: Performance / Rewet / 设计原则

## Core Framework 回渗双机理框架（回渗双机理）

演讲将回渗（rewet）拆解为两个独立机理，与既有概念页 [[Rewet Mechanisms Desorption and Flowback（回渗双机理：解吸与回流）]] 的结论一致：

1. **Desorption（解吸）** — "Desorption comes from the intake system where small pockets of fluid are trapped." 液体小袋截留在摄入系统（intake system）中，在压载下被重新挤出。
2. **Flowback（回流）** — "Flowback comes from the core where fluid isn't fully locked up." 芯体（core）对液体锁定不完全，液体回流至面层。

## Six Design Principles 六条设计原则

- **原则 1–4（芯体侧）**: 围绕芯体设计——容量（capacity）与 SAM（superabsorbent management），确保液体"locked up"。
- **原则 5–6（摄入系统侧）**: 将摄入系统定位为 **buffer（缓冲）**——在芯体吸收之前承接并分配液体，减少瞬时过量进入芯体局部。

## Desorption Side Factors 解吸侧六因素

| 因素组 | 内容 |
| --- | --- |
| 毛细作用（×3） | 与截留液袋的毛细结构相关的前三项因素 |
| 组分间液体交接（×2） | 面层/导流层/芯体之间的液体 handoff |
| 生产波动（×1） | 制造 variability 对解吸表现的影响 |

## Design Implication 设计含义
- 回渗优化必须**同时**处理 desorption 与 flowback：只优化芯体（SAM）或只优化摄入系统均不完整。
- 摄入系统应按"buffer + 定向传输"设计，而非单纯追求摄入速度。
