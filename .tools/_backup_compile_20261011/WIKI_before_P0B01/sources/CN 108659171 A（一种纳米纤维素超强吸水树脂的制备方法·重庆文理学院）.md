# CN 108659171 A（一种纳米纤维素超强吸水树脂的制备方法·重庆文理学院）

## One-line positioning 一句话定位

A university application（高校申请）claiming a **waste-tea-residue nanocellulose SAP**（废茶渣纳米纤维素接枝 SAP）with two process simplifications that matter industrially（免通氮除氧、丙烯酸免预处理）and headline uptakes of 2500 g/g DI / 133 g/g 9% NaCl. 对本库是「纤维素基 SAP」证据链里**工艺减法做得最激进**的一件，但 2500 g/g 为极端口径（无压力、无回渗、无卫生场景数据），只能作上限参考。

## Technical breakdown 技术拆解

1. **纤维素制备**：废茶渣 → 60% 酸液 60–70 °C 水解 1–2 h → 粉碎 10–50 µm → 1 mol/L 盐酸 70–80 °C 浸泡 2 h → 醋酸酸化亚氯酸钠（100–150 mL 水+2 mL 冰醋酸+2–2.5 g NaClO₂）50–60 °C 漂白 1–5 次。
2. **超声纳米化**：茶渣纤维素:水 = 1:50–400，超声 15–20 min；宣称中空度 ≥80%。
3. **接枝共聚**：纳米纤维素液:丙烯酰胺液:丙烯酸钠液 = 1:(1–1.5):(0.5–1)（质量）；70–80 °C 水浴 4–10 h；K₂S₂O₈ 或过硫酸铵 0.003–0.005%、MBA 0.0003–0.0005%（对混合液总质量；引发:交联 = 10–12:1）。
4. **后处理**：粘度骤增停搅 → 保温 2–3 h → 烘干 → 粉碎 40–80 目。

## Key claims 关键论断

- **「免通氮除氧」是本申请最大工艺卖点**——归因于丙烯酸用量少+水蒸气携氧；若成立可显著简化纤维素 SAP 产线 → [[纳米纤维素基高吸水树脂（茶渣-CNC 接枝）]]
- **2500 g/g / 133 g/g 是文献级极值口径**（无载荷、无反渗、9% NaCl 非生理盐水 0.9%），与库内 SAP 指标（CRC/AUL）不可直接比数 → [[SAP（高吸水树脂）]]
- **废茶渣原料 = 成本+降解双叙事**，与库内蔗髓纳米纤维素保水剂（CN104004521B）同属「废弃物纤维素→SAP」家族 → [[Biodegradable SAP（可降解高吸水树脂）]]
