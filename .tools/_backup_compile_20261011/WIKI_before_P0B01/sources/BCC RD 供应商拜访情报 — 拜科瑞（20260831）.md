# BCC RD 供应商拜访情报 — 拜科瑞（20260831）

## 一句话定位

本批**唯一的一手现场情报页**（2026-08-31 海南现场拜访，英文纪要）：给出拜科瑞的公司画像、产品矩阵与产能、发泡材料实测参数、以及拜访后双方已确认的 6 项 follow-up。是评估该供应商「能给什么、什么时候给」的基准。

## 摘要

纪要分四块。**公司画像**：CEO 张晓龙（北大法律硕士 + 清华 EMBA，30 余年产业运营经验），总部海口；核心 IP 为「tailwater → BC」，水回用率 99.6%、无化学试剂、无固废，成本比糖基路线低 80%+；15 项已授权/申请专利（含 2 项海南大学专利转入拜科瑞），覆盖菌种、发酵、发泡、涂层。**产品与产能**：BC 原料（凝胶/分散液/干粉/晶体多形态），海南 1,000 t/y 智能线已投产，10 kt/y 计划 FY26-27；发泡材料走溶胶-凝胶 + 物理三元交联、无化学交联剂；高阻隔 CNF 涂层处中试，实验室 PVA/CNF 膜 OTR 0.072、WVTR 0.45 g/m²·24h，涂层 OTR<0.22。**工艺流程 S1–S4**：S1 原料（屠宰/消毒尾水，蒸汽消毒，菌种 -30 ℃ 保存）→ S2 发酵（两步法：先生长后纺丝；7 天托盘培养 → 2% BNC 水凝胶）→ S3 后处理（参数锁定的脱色工艺 + 自动化收获线）→ S4 成型（凝胶/分散液/干粉，或溶胶-凝胶 + 物理三元交联发泡）。干燥路线经冻干（抗塌孔最好、效率低）/ 超临界 CO₂（高 CAPEX）/ 闪蒸蒸馏（100% BNC 的工业化平衡方案）三条验证。**在研与竞合**：恒安（likely）正与其合作开发卫生巾垫片用 BNC 发泡，样品已送我方；另有与中国 SAP 供应商的 BNC 基表面交联合作（50 nm × 2 μm 纤维；多元醇/碳酸亚烃酯/环氧化物路线）。最后列出 6 项 follow-up。
