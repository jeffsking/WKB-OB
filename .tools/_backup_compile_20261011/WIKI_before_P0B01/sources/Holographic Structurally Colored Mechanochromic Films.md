# Structurally Colored Films with Mechanochromic Shifts via Holographic Recording

## One-line Position 一句话定位
A parameterised, statistically controlled recipe space for holographically written structural-colour films that shift colour monotonically with strain — the strongest source in this vault for humidity-stable visual indicators and anti-counterfeit film.

> Source caveat: compiled from the paper's **Supporting Information only** (Fig. S1-S17, Table S1-S5); the main text is absent, so thesis-level claims are inferred from the SI. One OCR ambiguity is flagged in the numbers table.

## Business Connection Points 业务连接点

- **应变/力指示标签** — 0-20 % 应变区间蓝移约 58 nm、反射率降约 68 %，50 次循环后结构完整，可作包装封口过拉指示、弹性腰围穿戴伸长量目视指示（推演：需层压于弹性无纺布并标定颜色-伸长曲线）。
- **湿热稳定 → 贴身卫材适用性** — RH 100 % 与 80 °C 下 120 h 反射谱仍可测，是标签在穿戴环境（体温、尿液高湿）与夏季仓储下不退化的必要条件。**注意：SI 只证"不退化"，未测"湿度响应"，不能直接当湿敏传感器。**
- **全息防伪/品牌标签** — 结构色由全息记录产生，记录角 0/15/30/45° 可调 + 膜厚/曝光剂量大工艺窗口 + 面内均匀，天然具备难以复制、角度依赖的光学防伪特征，适用于高端纸尿裤/湿巾包装防伪与溯源（推演）。
- **湿敏指示的差距与改造路径** — 若要"吸湿变色"，须在 PEGDA 基体中引入溶胀性组分（如 SAP 类吸水网络），使应变随吸湿产生，即把"力致变色"转为"湿致变色"——**属配方改动，非直接沿用（推演）。**
- **与 SAP 网络设计的同源性** — PEGDA 基 Michael 加成网络，分子量可由摩尔比 9896→6742 g/mol 精确调节；PEGDA 亦是高吸水/水凝胶体系常用交联单体。Table S1-S5 的"参数→反射率 SD"标定方法可直接迁移到 SAP 网络 DOE（交联密度、分子量、吸水/力学权衡）（推演）。
- **薄膜-无纺布柔性复合** — 膜厚 30-190 µm，20 % 应变 50 次循环不断裂，满足层压/折叠加工柔性要求，可作表层可视化功能层或包装"开封/挤压"指示（推演）。
