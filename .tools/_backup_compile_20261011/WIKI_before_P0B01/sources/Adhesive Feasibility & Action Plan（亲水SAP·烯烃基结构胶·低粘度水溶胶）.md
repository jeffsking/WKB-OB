# Adhesive Feasibility & Action Plan（亲水SAP·烯烃基结构胶·低粘度水溶胶）

## 一句话定位 One-line positioning

本资料是 **K-C 与 Henkel（汉高）2026-05-26 技术交流议程**的下游产物：一份把「前沿议题 → 痛点议题 → 综合行动计划」串起来的**胶黏剂可行性评估 + 24 个月路线图**。本库回答「下一代纸尿裤用什么胶、用多少、怎么涂」时应先落到本页。

## 摘要 Summary

文档由两部分组成。**Part 1** 是对交流议程本身的结构分析：议程按「交流背景与目标 → 前沿热点 → 开发痛点 → 可持续发展 → 探索性蓝海 → 交流策略」递进，并以「讨论维度—具体问题」表格化每个议题；隐含时间分配为三星必谈议题 40–50%、二星重点 30–40%、一星探针 15–20%。**Part 2** 是三项技术的可行性深度评估：① **亲水 SAP 包裹胶水**——技术路径已从物理混合演进到分子设计（巨型表面活性剂自组装、反向结构表面活性肽、接枝改性，乃至废弃 SAP 开环回收升级为压敏胶 PSA）；核心矛盾是 SAP 吸液后粘接强度下降，应对包括仿生协同保水体系、界面设计优化、交联涂层低温化（≤150 ℃ 对比传统 >200 ℃）；② **Olefin 基结构胶**——茂金属催化 + 官能化改性（MAH / 硅烷 / NCO）使其在粘接强度、耐温、热稳定性、可持续性上全面超越传统 EVA；并给出设备兼容性评估（191 ℃ 工艺温度、约 5000 cP、喷嘴堵塞与 UFD 适配）与维护体系（周期性清洁、碳化预防的「梯步加温法」与「降温封闭法」、智能过滤）；③ **低粘度水溶性胶（Knight 4 载体）**——低于 1000 cP 的水基体系实现「精密渗透 + 无损固定 + 水溶移除」，难点在干燥效率与溶解一致性。**Part 3** 汇总 12 议题优先级矩阵与三阶段（0–6 / 7–18 / 19–24 月）行动计划，其中**纳米纤维素（CNC/CNF）增强胶被明确升级为 JDA 联合重点**。

## 关键论断（key_claims）

- **官能化是把聚烯烃从「物理吸附」提升到「化学键合」的唯一使能器** —— 支撑页：[[Olefin-Based vs EVA Construction Hot Melt（烯烃基 vs EVA 结构胶）]]、[[Polyolefin Hot Melt Adhesive（聚烯烃热熔胶）]]
- **超低添加量不是单纯降耗，而是「胶料-设备-工艺-维护」四件套的一次性重构** —— 支撑页：[[Ultra-Low Add-On Adhesive Application（超低添加量施胶）]]
- **亲水 SAP 包裹胶的本质是「吸液-粘接」此消彼长的长期界面问题，短期靠界面设计与封装，长期靠标准缺失的补齐** —— 支撑页：[[Hydrophilic SAP Wrapping Adhesive（亲水SAP包裹胶）]]
- **纳米纤维素（CNC/CNF）增强胶是最合适的 JDA 切口：既有明确的增强机理支撑，又便于从联合验证切入而非一开始就谈价格** —— 支撑页：[[汉高]]、[[IPC BCC OI Portfolio（开放创新项目组合）]]
