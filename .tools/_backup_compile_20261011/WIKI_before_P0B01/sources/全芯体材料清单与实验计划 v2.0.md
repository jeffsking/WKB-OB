# 全芯体材料清单与实验计划 v2.0

## Positioning 一句话定位

This controlled project workbook integrates version changes, the material register, interaction risks, experimental phases, test methods, decision gates, and milestones for a full absorbent-core and topsheet program.  
（中文：该受控项目工作簿整合全芯体与面层方案的版本变更、材料清单、相互作用风险、实验阶段、测试方法、决策门与里程碑。）

## Summary 摘要

Version 2.0 replaces the earlier material plan after a layered trilobal-PET topsheet option and a Multi-SAP architecture were selected for further validation. The workbook removes stand-alone ADL and surfactant purchasing lines, treats a spunlace REL（增强层）as a Z-direction capillary bridge, and aligns every retained material with an explicit experiment. It separates top-layer rapid acquisition from lower-layer storage through staggered SAP swelling（SAP 错峰膨胀）and makes a four-dose Enterprise Standard the primary rewet protocol. A high-load short-interval method is retained only as a gel-blocking stress test because the workbook records that it can create a misleading performance peak. The plan also identifies bonding-density loss, SAP segregation, ultrasound-seal weakness, static and abrasion, and over-constrained SAP swelling as cross-material risks. Full recipes, named commercial candidates, quotations, and sourcing actions are not reproduced here.
