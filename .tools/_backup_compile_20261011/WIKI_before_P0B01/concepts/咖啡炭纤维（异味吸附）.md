# 咖啡炭纤维（异味吸附）
> 📌 **Page completed 2026-09-30** from 5 citing sources. All figures traced to their source pages. Anything not evidenced is marked `[待补]`.

## Definition 定义
将回收咖啡渣经摄氏 1000 度以上煅烧处理（使晶向与孔隙呈最佳状态）制得的消臭功能纤维，属**吸附型除臭路线**（adsorption-type odour route）中的纤维化物理吸附分支（源：[[功能性纤维产品简介（PTT_超仿棉_咖啡炭_纳米凉感）]]、[[活性炭除臭（DARCO）]]）。

## Key Parameters and Data 关键参数与数据
| Parameter 参数 | Value 数值 | Source 来源 |
|---|---|---|
| 消臭率 | 80–90%（40 PPM 氨气消臭测试） | （源：[[功能性纤维产品简介（PTT_超仿棉_咖啡炭_纳米凉感）]]） |
| 吸附机理 | 蜂窝状炭孔结构的天然物理性吸附，对人体无伤害 | （源：[[功能性纤维产品简介（PTT_超仿棉_咖啡炭_纳米凉感）]]） |
| 附加功能 | 三种保暖功能：蓄热保暖、吸湿发热保暖、远红外线发热保暖 | （源：[[功能性纤维产品简介（PTT_超仿棉_咖啡炭_纳米凉感）]]） |

## Method / Mechanism 方法 / 机理
- 多孔炭相以物理吸附捕获挥发性致臭分子，与 PAC（粉末活性炭，磷酸法造孔、吸附大分子有机物）和沸石载体同族对照（源：[[Powdered Activated Carbon（粉末活性炭）]]）。
- 添加形态决定可行性：纤维化（本品）vs 拌入颗粒层 / 母粒化（源：[[Powdered Activated Carbon（粉末活性炭）]] 的卫材映射框架）。

## Hygiene Relevance 卫材关联
- 应用场景：卫品气味控制、面层/内裤无纺布消臭（源：[[活性炭除臭（DARCO）]]）。
- 气味管理路线族全景见 [[Odour Management Routes（气味管理技术路线）]]；同族对照：[[Zeolite Odour Control（沸石除臭载体）]]、[[SymDeo™ XPP 抑臭聚合物]]、[[活性炭除臭（DARCO）]]；测试干扰风险见 [[Odour-Control Granular Interference（除臭颗粒干扰）]]。
