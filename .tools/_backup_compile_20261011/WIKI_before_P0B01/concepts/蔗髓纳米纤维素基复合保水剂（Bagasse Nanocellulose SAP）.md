# 蔗髓纳米纤维素基复合保水剂（Bagasse-pith Nanocellulose Composite Superabsorbent）

> One-line definition 一句话定义：以甘蔗制糖副产物「蔗髓」经提取/超声解离得到纳米纤维素，再经阳离子醚化 + 接枝共聚/交联并复合纳米纤维素，制得的一类**复合保水剂（非卫材 SAP，属农艺保水剂）**；其「纳米纤维素–SAP」路线与 KB 的细菌纳米纤维素（BNC）主题相邻。

## 机理 / 结构拆解 / Mechanism

1. **原料**：榨糖后蔗渣风干筛分得到蔗髓（bagasse pith）。
2. **纳米纤维素提取**：冰醋酸/过氧化氢法提取蔗髓纤维素 → 高强超声波解离得纳米纤维素。
3. **阳离子醚化**：碱性条件下将纳米纤维素醚化为阳离子纤维素醚。
4. **接枝共聚/交联**：水溶液聚合法对阳离子纤维素醚接枝共聚并交联。
5. **复合**：反应结束后再加入纳米纤维素复合，得蔗髓纳米纤维素基复合保水剂。
6. **性能区间**：在 pH 5–6.5 弱酸性水样中对去离子水、0.1 mol/L KCl、0.1 mol/L NH4Cl、0.1 mol/L KH2PO4 有较优吸液值与耐盐能力。
