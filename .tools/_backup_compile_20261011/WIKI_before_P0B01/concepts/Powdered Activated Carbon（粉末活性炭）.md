# Powdered Activated Carbon（粉末活性炭）

> One-line definition 一句话定义：以高比表面积多孔碳吸附气/液相中有机分子（含致臭物与色体）的粉末状吸附材料；在本库中是**气味管理材料族的吸附型路线之一**，与沸石颗粒、抑臭聚合物、咖啡炭纤维并列。

## Mechanism 机理 / 结构拆解

1. **活化造孔**：木基原料经磷酸法化学活化（phosphoric acid activation）形成发达中孔-微孔网络；对照水蒸气物理活化，磷酸法孔径偏中孔、利于吸附大分子。
2. **吸附目标**：大分子量有机物优先——大色体（color bodies）、蛋白质等致臭/致色前体；低添加量即有可观脱色除味效果（厂商口径）。
3. **形态与加工**：粉末形态（D50 ≈ 20 μm），需过滤步骤分离；过滤性与吸附容量需平衡（本品过滤时间 25 min 量级）。
4. **卫材映射**：在卫生用品场景，PAC 的气味吸附逻辑与 [[Zeolite Odour Control（沸石除臭载体）]]、[[咖啡炭纤维（异味吸附）]] 同族——以多孔固相捕获挥发性致臭分子；添加形式（拌入颗粒层 / 纤维化 / 母粒化）决定其是否可行，本页 TDS 未涉及卫材直接应用 `[待验证]`。
