# Fluff-Free 4th-Gen Absorbent Core（无木浆第四代芯体）

> 一句话定义（Definition）：The **4th-generation absorbent core（第四代吸收芯体）** is an intelligent-acquisition + functional-composite structure built without fluff pulp — using **curled/hollow-fiber hot-air tufted nonwoven + multi-property SAP**, consolidated by **thermal-piercing melt fixation**, with **U-shaped / hetero-cut acquisition channels** for fast, anti-clotting, thin-and-strong performance.（不含绒毛浆、以卷曲中空纤维热风蓬松无纺布+多特性SAP、热风穿刺熔融固结、U型/异型切导流通道实现的智能导流+功能复合薄且强芯体）.

## 代际演进 Evolution

1. **1st gen 传统木浆芯体**：fluff pulp + SAP — thick, clumps, breaks after absorption.
2. **2nd gen 复合芯体**：airlaid + nonwoven + SAP — less clumping, but slow uptake & uneven SAP use.
3. **3rd gen 无木浆多维复合芯体**：hot-air tufted nonwoven + SAP — thin, no break, but strength challenge at extreme thinness.
4. **4th gen 智能导流+功能复合芯体**：U-shaped/hetero-cut channels + antibacterial/skincare integration — current frontier: **thin + strong + multi-function**.

## 核心模块 Core Modules（HaoYue 豪悦）

- **基材 Substrate**：curled hollow-fiber hot-air tufted nonwoven → higher SAP lock-in.
- **SAP 配方 SAP blend**：multiple superabsorbent polymers composite → layered absorption, 3D lock.
- **固结 Consolidation**：thermal-piercing melt fixation → anti-clotting.
- **导流 Acquisition**：multi-channel + density-graded SAP layers → faster uptake, higher utilization.
- **工艺 Process**：online 3D embossing + offline wrap → thin + soft.

> Reliable（可靠）five-layer structure: infiltration → SAP layer 1 (SAP+antibacterial) → acquisition → SAP layer 2 → diffusion.

## 战略意义 Strategic Note

Fluff-free 4th-gen core is cited as **China's leading edge and patent moat** (HaoYue, Reliable, Baiya 百亚 hold patents). It also reduces fluff-pulp import dependence — a supply-chain security lever (see [[China vs Korea Diaper Market（中韩纸尿裤市场对比）]]).

## Evidence Update 证据追加（2026-09-29）

> ✅ Verification（2026-09-29，source 来源 [[纸尿裤的核心结构及市场主流方向]]）：既有「无木浆/复合芯体是主流方向」的判断被支持，且本批把**「复合芯体」拆成可执行的三条工艺路线**：① 立体承载空腔（模具定型下凹空腔，SAP 独立封闭、空腔间留贯通流体通道，防跑动 + 避免凝胶堵塞）；② 按需分布干法纸（定制孔隙 + 分区铺 SAP + 多通道，使**芯体材料与导流层材料合二为一**）；③ 在线一体成型（模具定型 + 胶粘/热压/超声波封边，缩短工序并保证出厂 SAP 分布）。
>
> 无胶化方向：蜂巢芯体以**差异化超声波粘接**取代热熔胶——六边形点线处轻度粘接为 SAP 膨胀预留空间、大三角边缘高强度粘接固定位置，同时形成通风通道。与 [[Hot-Melt Slot Coating（热熔狭缝涂布）]] 的用胶思路形成对照。
>
> ⚠️ 口径：本批中所有品牌级效果数字（防漏 98%、隔菌 >99%、泛红下降 89%）均为**厂商宣称**，未附测试协议，不可直接作为验收门。
>
> 追加 `[待验证]`：立体空腔结构在高粘稠负荷（稀便）下的通道保持率；在线一体成型对 SAP 分布 CV 的实际改善量级。

> ✅ Verification（2026-09-29，source 来源 [[可降解生物基材料与薄且强芯体技术深度解析]]）：本批给出第四代无木浆芯体的**四模块拆解**，与本页既有方向一致且更可执行——① 基材：**卷曲及中空纤维热风蓬松无纺布**（多维蓬松，提高 SAP 锁定率）；② SAP 配方：多种不同特性 SAP 复合以实现分层吸收与立体锁水；③ 固结：**热风穿刺熔融固结**（防高分子移动、防断层）；④ 导流：多道导槽 + 不同疏密高分子层（提升吸速与芯体利用率）。另有超薄五层叠加结构（木浆水刺布 + SAP 层 + 蓬松无纺布分层）与「快速吸收 → 立体锁水」的分级锁水设计。
>
> **薄型化的代价**：超薄后 **SAP 易移位**，必须靠固结与分层导流配套解决——即减薄不能单独作为目标。
>
> 融合方向：PLA 纤维替代传统无纺布作为芯体基材（无木浆 + 可降解）；薄芯体 + 生物基 SAP（淀粉基/纤维素基 SAP 研发中）；抗菌植入 SAP + 天然植物抗菌剂替代化学品。
>
> 追加 `[待验证]`：SAP 锁定率的定义与测试方法（本批未给量化口径）；多道导槽与五层叠加结构的兼容性；无浆板/中凸结构（蓬松无纺布替代浆板）对吸收速度的实际贡献。
