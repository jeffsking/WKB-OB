# SAP 吸水纸（SAPP）

> **Definition 定义**：**SAPP（SAP paper / SAP 吸水纸）** 是把高吸水树脂（SAP）与纸浆纤维通过**湿法造纸**工艺固着成纸状的吸收材料；其定位是**薄型化的吸收主体**——在卫生巾中替代"普通吸水纸"或"绒毛浆 + SAP"两种传统结构，以**更薄的材料厚度**换取更薄的成品。

## Mechanism and structure 机理与结构

1. **湿法造纸 + 计量施加**：原文口径为 **wet paper making process + 专利 SAP dosage system**，核心目的是"**保证 SAP 与纸浆纤维稳定固着**"——即解决 SAP 在纸基中的分布均匀性与固着牢度。
2. **结构层次**：
   - **SAPP（1 层）**——单层吸水纸。
   - **SAPP core（2–3 层压花）**——多层压花复合，作为芯体主体。
3. **与"预制吸收芯"的关系**：同一供方的尿裤产品线把 `airlaid / nonwoven + SAP + fluffy nonwoven` 包裹体称为 **prefabricated absorbent core（预制吸收芯）**，用于超薄吸收制品——SAPP 是同一思路在卫生巾上的形态。
4. **厚度是它的第一性指标**：与库内芯体路线的"分区密度 / 通道 / 蓬松"逻辑不同，SAPP 的卖点是**在给定吸收量下把厚度压下来**。
