# 变色油墨（Chromogenic Ink：光敏/温敏/湿敏/力敏）

> 一句话定义：随外界刺激（温度/湿度/光/机械力）改变颜色的功能油墨体系；在卫生用品中主要承担**湿态指示与视觉反馈**功能，是智能尿裤功能层①的核心材料。

## 机理 / 结构拆解

1. **热致变色（温敏）**：主流为 **leuco 染料微胶囊体系**——供电子体（leuco 染料）: 受电子体 : 脂肪酸 ≈ 1:5:50 的配比，通过熔融/结晶的可逆转变实现显色/褪色。典型用于尿湿指示（体温或尿温触发）。
2. **力致变色（力敏）**：机械力改变分子排列或光子晶体结构导致颜色变化。代表应用为**拉伸变色**（K-C US7704589B2，已失效）与液晶弹性体变色纤维（可机洗应变可视化）。
3. **湿敏/化学比色**：pH 或离子强度变化引发比色反应（如 CN114209501A 的 pH 纳米微胶囊纳米纤维膜）。
4. **载体形态要求**：印刷油墨/涂层（丝网印刷于底膜外侧、弹性侧片等），或作为薄膜/纤维基材的负载相。**功能层多在非皮肤面**，对材料安全性要求相对低。
5. **与本库其他方向的接口**：变色油墨可作为「视觉反馈」层与压力传感（力敏）、湿态指示（温敏/湿敏）耦合；BNC 膜/纤维可作比色指示基材。

## 经验教训

> ✅ 验证（2026-09-27）：变色油墨的技术成熟度呈现「尿显线已量产、温变量产早期、力敏原型」的梯度——选型时应按目标功能的成熟度匹配，而非把实验室方案当日用方案。

> ✅ 验证（2026-09-29，来源 [[Active Hygiene Roadmap（力致变色材料商业化路线图）]]，批次 S1_Projects_Active Hygiene_01）：本页「力致变色可作视觉反馈层」的判断被一份商业化路线图推进到**产业化路径层面**，新增两条结论——① **Pathway A「可印刷压力激活油墨」**被明确为最快上市路径：沿用 standard offset/flexo 产线放大，并以 **food-contact grade inks 作即时监管护盾**（本库已立页的对应供方为 [[CTI (Chromatic Technologies)]]）；② **Pathway B「共价力色团」**（分子如 naphthopyrans **化学键合到聚合物主链**）整合更复杂，但得到「自评估材料」与**永久 IP 护城河**，适合作为第二代平台。原文的战略指令是：**路径选择直接决定最终 COGS 与速度，但两者都从属于监管放行**。本页既有结论未被修正，属补充（详见 [[Printable Pressure-Activated Inks vs Covalent Mechanophores（力致变色两条落地路线）]]）。
> ⚠️ 该来源**未给出任何成本数字**，成本格标 `[待验证]`；来源可信度为**低**（无数据溯源、自标 NotebookLM 辅助）。

- **要点**：leuco 微胶囊体系的三组分配比是性能（变色温度、灵敏度、可逆性）的核心杠杆；纺织/卫材场景还须考虑耐水洗与迁移安全性。
- **2026-09-29 追加要点（力敏侧材料细目与阈值缺口）**：路线图列出四种力致变色候选——**HPC**（黏弹性格点间距变化 → 压缩蓝移；可食/无毒/可降解）、**Naphthopyrans**（共价键断裂 → 模块化变色；稳定性与合成可达性最优）、**Spiropyrans**（6π 电环化开环 → 强显色；**热致瞬态**）、**Cu-based HCP**（发光位移；抗环境污染）。共同瓶颈是**力值缺口**：工业力色团需 **40,000 PSI**，卫材目标仅 **20–150 kPa**，需用「stabilization bridge」（胶凝剂，如 gelatin）调流变下移阈值。出处同上；详见 [[Active Diagnostic Zones（主动诊断分区）]]。
- **待补 `[待验证]`**：变色油墨的迁移/安全合规口径（涉化学品，须过法规前置条件）。

> ✅ 验证（2026-09-29，来源 [[Stretch-Triggered Colour Indicator for Diaper Pant Side Panels]]、[[BM Indicator Design — Viscosity & Cost（便指示·流变与成本）]]）：**本页既有结论未被改写**，仅追加编译追记。本页第 2 条「力致变色（力敏）」与第 3 条「湿敏/化学比色」在本批获得工程级落地细节：(i) 力敏方向的卫品落地形态不是变色化学，而是**几何光学掩膜**（TB-A 遮光热熔胶，配方已完整给出：APAO 26 % / 氢化 C5 16 % / 聚 α-甲基苯乙烯 10 % / FT 蜡 8 % / 金红石 TiO₂ 22 % / 包覆 CaCO₃ 17 % / 抗氧剂 1 %）→ 见 [[TB-A Opaque Mask Hot Melt（TB-A 遮光热熔胶）]]；(ii) 化学比色方向的卫品落地形态是**热熔胶比色通道**（尿湿阶梯 + 便通道），其关键工艺约束是「每一切固体须满足垫片 ≥ 10 × d90」与「禁用可溶性季铵盐作染料锚定剂」→ 见 [[Protein Error of pH Dye（pH 染料的蛋白误差）]]、[[Wetness Indicator Ladder（尿湿指示阶梯）]]。

### 3. MVP and gates 三条 MVP 与验收门

- **MVP A（温敏，P1）**：外层印刷/标签；非结构功能；门＝30–37 ℃ 内颜色稳定变化 + **>70%** 消费者正确解读"过冷/舒适/过热"。
- **MVP B（湿敏，P1）**：与现有尿显**相邻**的湿致变色窗口/贴片；门＝冲击后 ≤60 s 稳定显色 + 与传统尿显**可区分**；4 周包装后无异常变色。
- **MVP C（复合，P2）**：双区显示；**学习型原型**；若解读失败或错误率高，立即回退单功能方案。
- **排序规则**：**不替代**现有尿显；复合方案只在单功能验证后启动；台架必须**干态与湿态双测并量化误触发率**（最重要的 MVP 出口门）。
- 市场锚：全球尿显市场 $506M（2025）→ $774M（2032E），CAGR 6.28%；婴儿尿裤占下游 62.9%；热熔形态 84.1%；亚太占 42.0%。见 [[Thermochromic & Hydrochromic Materials for Diapers (Feasibility Review v3)]]。

### 4. Safety hard gate 安全硬门（本批新增）

- **100% 无 BPA、零甲醛、零重金属**；框架为 **ISO 10993**（细胞毒性/刺激性/致敏）+ **REACH** + **FDA** + **GB/T 35613-2017 / GB/T 36420-2018**。
- **绝对禁止**回渗、可见渗色与直接皮肤接触；指示层须位于**非皮肤接触面**（外层/底膜窗口）；粉末形态在验证前禁用皮肤层。
- **Matsui（松井）**部分产品含**微量甲醛**，官方指引排除婴儿直接接触 → 相关门控条件与实体记录见 [[Matsui Shikiso (松井)]]。
- 微胶囊化（封装成熟度）是**供应商真实差异轴**，而非色化学本身，见 [[Microencapsulation]]。
