# 化妆品限用/准用组分体系（中国 2015 技术规范） / China 2015 STSC Restricted & Permitted Substance System

> 一句话定义：中国《化妆品安全技术规范》(2015) 建立的禁限用与准用组分清单体系，是境内化妆品（含湿巾 lotion、护肤）配方合规的强制性基线。

## 机理 / 结构拆解

1. **三层结构**：禁用组分（表1/2，共 1388 项）→ 限用组分（表3，47 项，带使用范围与最大允许浓度）→ 准用组分（表4–7：防腐剂 51 / 防晒剂 27 / 着色剂 157 / 染发剂 75）。
2. **配方约束（3.2.3 条）**：配方中所用防腐剂、防晒剂、着色剂、染发剂必须是对应的本规范第三章表4至表7中所列物质，使用要求须符合表中规定。
3. **安全通用要求**：重金属与风险物质红线——铅 10、砷 2、镉 5 mg/kg；二噁烷 ≤30 mg/kg；石棉不得检出。
