# Short-Fibre Substitution & Refiner Plate Design（短纤替代与磨片设计）

> 一句话定义（Definition）：**Fiber-to-fiber（短纤替代长纤）** 指以短纤桉木浆（BEKP/BHKP）替代长纤针叶浆（BSKP）的降本配方路线；其成败不在纤维本身，而在**打浆段的磨片（refiner plate / 盘磨磨片）是否重新选型**——短纤比例上升后，原磨片会造成过度切断，必须换成「齿更细、齿数更多」的轻柔型磨片。

## 机理 / 结构拆解（Mechanism）

1. **经济驱动**：BSKP 与 BEKP 之间存在**价差**，替代即降本；供应商侧也借此推动客户多用短纤。
2. **磨片必须随配方变**：配方的短纤比例变化后，原磨片的**切断作用过强**；而短纤本身已短，需要**避免切断**。
3. **磨片选型方向**：**齿宽、齿槽、齿深都更细**，因此**齿数更多**。在相同周长下齿数变多 → 单位时间内纤维被磨到的**次数增加**，但**每次的冲击/压力更小**。
4. **效果类比（原文口径）**：像「打肉丸」——以前打 20 次、切断多；现在打 50 次、每次更轻 → 纤维被**敲得更柔软**而不是被切断。
5. **不换磨片也有收益**：仅切换浆的 grade（更高松厚度/更低能耗的等级）也能省 refining energy；但要做到**全短纤（BSKP → 0%）**，换磨片是必要条件。
6. **推广方式是 hero case 而非纯说理**：给客户看「之前 vs 之后」的对比——磨片设计变化、浆号、成纸质量、起皱率、粘缸剂使用、柔软度、强度、抗张等，**用可复制的案例说服**。
7. **客户侧的隐性门槛**：工厂对工艺细节通常敏感（保密顾虑）；并入 JV / 更紧密的合作框架后，联合推进会容易得多。
