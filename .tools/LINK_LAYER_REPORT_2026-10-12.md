## 一、起因

断链已清零，但「WIKI 内部互链」口径下仍有 **485 个源摘要页完全孤立**（正文零出链 + 无人回链），其中 476 页是 10-11 抽取式编译的产物（`pages_linked: []`）。断链修复不负责给孤立页造边，故需单独建链。

## 二、匹配方法（保守，可复算）

对每个源摘要页，扫描其正文，命中的目标须满足：

| 规则 | 说明 |
|---|---|
| 候选来源 | 页名本身 + 去括号裸名 + front matter `aliases` + 标题内的**全大写缩写**（SAP/PET/ADL…） |
| 匹配方式 | CJK 候选→子串匹配；含拉丁字母→**词边界匹配**（防 `cti` 命中 `practice`） |
| 最小长度 | CJK ≥2 字；拉丁 ≥3 字符 |
| 噪声过滤 | 剔除 `Ltd./Inc./REACH/ROHS/ISO` 等通用缩写；剔除 `待补/待核` 等占位词 |
| 歧义候选 | 同一候选串指向多个页面时，按 `status(stable>growing>seed)` + 名称长度择一（22 例） |
| 上限 | 源页 ≤12 条；Related Sources 小节 ≤25 条 |

**被否掉的更激进方案（记录在案）**：抽取「标题中的短 CJK 词块」→ 泛词（`纤维`/`问题`/`亲水`/`溶胀`）全库误命中，链接数 1229→3495、噪声不可控，**已弃用**。
