# Material Safety Control（材料安全双轨管控）

> Definition 定义：公司侧的材料安全管控体系——**Class 1（政府法规强制）+ Class 2（公司自愿、超越法规）双轨制**，配合 **COC chemical watch list（化学物质观察清单）**，并将合规从「事后检测」提升为「选材前置条件」。

## Mechanism 机理 / 拆解

1. **Two-track control 双轨管控**
   - **Class 1**：政府法规强制项（不可选）。
   - **Class 2**：公司自加的更严标准（超出法规要求）。
2. **COC chemical watch list**：供应商可就关注物质提交「说明声明（clarification statement）」替代强制检测；新物料须经 **PA（法规团队）评审**。
3. **Precondition logic 前置逻辑**：合规不再是上市前检测，而是**选材时的第一道筛**——所有 25 个 OI 项目页面均加「Compliance & IP risk」块。
4. **High-risk categories 高风险类别**：化学品与油墨类项目 —— **OI-09 / OI-15 / OI-16 / OI-21 / OI-22**（除臭剂、变色胶/膜、湿致/温致指示）。

## Case Evidence 案例证据（警示案例）

- **Formamide incident 甲酰胺事件**（China market, 2026-06）：caused a marked sales decline; "in the worst case we may lose a generation of consumers"（中国市场，造成明显销量下滑，最坏情况「可能失去一代消费者」）。
- **Korea wet-wipes precedent 韩国湿巾先例**：after the incident, "market share has not recovered in nearly twenty years"（近二十年未恢复市场份额）→ material selection must lean toward natural, safe materials（选材须倾向天然、安全材料）。
- **SAP residue 树脂残留**：SAP monomer residue ≤1000 mg/kg；heavy metals ≤20 mg/kg 须并行评估（见 OI-06）。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 无锑 Sb-free 与 K-C/P&G 体系差距）

> 来源：[[P&G–KC Industry Review and Xinweisheng Supplier Capability Visit（与宝洁交流及行业情况）]]（供应商交流会 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**无锑（Sb-free）作为法规驱动的物质安全议题（本批新增）：**

| Item 项目 | 内容 | Note 备注 |
| --- | --- | --- |
| 议题 | **无锑 / Sb-free**（ASR 转写作「无 t」「五 t」「有气无气」） | 属物质安全，非性能指标 |
| 来源 | PET 缩聚所用**锑系催化剂** | 改用**钛系催化剂**即可做到无锑（福地交流会口径） |
| P&G | **一直有要求**；数年前已商业化 | 会中判断为行业标杆 |
| K-C | **目前仅韩国市场要求**；美国近期开始要求 | 中国大陆与其他市场未要求 |
| 驱动来源 | **当地法律法规**（韩国、美国） | 非客户内部标准 |
| 技术后果 | PET 的无锑难度大 → 韩国市场**只能用 PP**（PP 不使用锑系催化剂）；PP 粗糙 → **软度差**，卫生巾上尤为明显 | 性能让位于合规 |

**会中对 K-C 安全体系的差距判断（本批新增，属会中表述，非本方正式审计结论）：**

- P&G 在**物质安全上是行业标杆**；本方在体系与眼界上存在差距 —— 以无锑为例，P&G 数年前已有要求并商业化，而本方内部此前**并不优先**（"无视了，或者说没有优先"）。
- 本方近年在**产品形式上花样多**，但**基础功不够扎实**；本次行业冲击「看起来偶然，实则有必然」。
- **上游把控弱化**：本方过去可直接与埃克森美孚等上游谈 PP 规格（因纺粘量大），如今对**二级、三级供应商"控制不住"**；新进研发同事对上游纤维厂的历史做法不了解。
- 会中亦提及历史案例：塑化剂检测能力曾"被扒了几层皮"，德国实验室/培训体系的使用频率下降。

**COC 双档制的运行细则（本批新增，补充本页既有 seed 内容）：**

| Item 项目 | Class 1 | Class 2 |
| --- | --- | --- |
| 来源 | **政府法规强制** | **YK 内部自愿管控**，超越法规 |
| 执行 | 导入新物料时由供应商**按法规检测并提交报告**，确认满足政府目标值 | 两种路径：① 按 YK 内部方法**实测**；② 供应商提交**澄清声明（clarification declaration）**声明不含该物质，YK 予以采信 |
| 维护 | 随法规变化 | 内部法规团队**每年更新**清单，并纳入物料规格（specification） |

**测试方法的开放策略（本批新增）：**

- YK 自建了部分 Class 2 的**测试方法**（其中一批针对 **odor 气味**，起因是某大学教授公开检测并发布后引发事件）。
- 这些方法**会开放给原材料供应商**，使其校准到相近方法 → 目的是让**供应商端具备自检能力**，而非全部回流到 YK 检测。
- ⚠️ 未解决：本方追问"中国供应商在中国本地检测用什么方法"，对方答"这就是问题所在"；YK 建议可接韩国的几家指定检测机构之一 → **跨境检测的方法一致性未决**。

**跨品类外溢机制（本批新增，是本页既有"警示案例"的机理补充）：**

- COC 清单**不限于本品类**。已写入的实例：**加湿器杀菌剂**（完全不同品类）、**CMIT 牙膏**、**婴儿洗护**。
- 传导机理：**"同一个妈妈"** —— 买牙膏的妈妈会对纸尿裤产生同样的安全疑虑 → 担忧**跨品类迁移**。
- 由此推论：监控系统必须**跨品类扫描**；只看卫材品类的法规会漏掉绝大多数前置信号。

**待核对的存疑（本批新增）：**

- 本页 `Case Evidence` 已记"**中国市场 2026-06 甲酰胺（formamide）事件**"；本次转写把**韩国湿巾历史事件**（约 2005 / 2008 年起）的物质也读作「form I / F○○M」 → **两起事件是否同一物质需人工核对**。本批**不做裁决**，只在两处各自标注。
- 会中另指出"取决于哪种测试方法、多少 PPM —— 十分之一个 PPM 没有意义" → **限值口径未统一**。

## 追加：Meeting Minutes 批 3（2026-09-29 追加 · 与材料直接接触的工艺部件涂层：安全关注点的第三类）

> 来源：[[Structured Minutes — New Material Development & Elastic Recovery Process（录音纪要 2026-09-20）]]（同一场会议的结构化纪要，日期 [待验证]）。本批只**追加**，不修改既有结论。

**新的关注对象：工艺部件涂层（本批新增）**

本页既有内容关注的是**材料本身的化学物质**（Class 1 / Class 2 / COC）。本批补充第三类关注对象 —— **与材料直接接触的工艺部件涂层**（本例为打孔针外的 **DLC 类金刚石涂层**）：

| Item 项目 | 内容 |
| --- | --- |
| 涂层位置 | **针（pin）的外部**，**与材料直接接触** |
| 三个作用 | ① **减轻热量**；② **使切割更光滑**；③ **防止材料粘/撞在一起** |
| 本方核心担忧 | 涂层会**粘附或迁移到材料上（adhere to the material）** |
| 要求 | **对健康无害、对环境无害** |
| 状态 | 开发方称有多种涂层方案（various coating），会进一步确认；会中认为某一 type 更优 → **未给出结论** |

**由此得到的认知（本批新增）：**

1. **合规对象要从"材料"扩展到"接触面"** —— 只要部件与材料直接接触，其涂层就构成**潜在迁移源**；这是材料安全体系里容易被漏掉的一类。
2. **两个维度必须同时满足**：**健康**（对使用者无害）+ **环境**（对环境无害）—— 本方在会中是**两个都提**的，不是只问其中一个。
3. **涂层往往是为了解决工艺问题而引入的**（本例：高速产热、粘料），因此**工艺改进会反向制造新的合规项** → 工艺变更应触发安全复核。
4. 与本页既有逻辑的关系：这类问题**通常不在政府法规清单里**（属 Class 2 型的**自加管控**项），正好对应本页"Class 2 = 公司自愿、超越法规"的定位。
