# 弹性热熔胶腰围（减压腰围）

> One-line definition 一句话定义：用**条状弹性热熔胶膜替代氨纶丝**作腰围弹性体，双面夹无纺布并以**致密超声波点焊**贴合、以**速差压合**赋予弹性——把氨纶丝的「线-面接触」升级为「面-面接触」以分散腰部压强（中文：减压腰围）。

## Mechanism 机理拆解

1. **压强分散**：氨纶丝与皮肤是线面接触，收缩时产生交替勒痕红肿；弹性胶膜面面贴合增大接触面积。
2. **速差储能**：熔胶喷涂至冷却辊（间隙 0.1 mm）→ 冷却定型 → 第二压片轴以 1.3–3× 速差拉伸，拉伸倍率 (1, 3]。
3. **超声点焊省胶**：20 kHz / 5.0×10⁵ Pa / 焊接 1.4 s / 保压 1.1 s，无纺布可少喷胶（≤常规 40%）或不喷胶。
