# 纳米纤维素（CNC、CNF、BNC）

> 一句话定义：以纤维素为原料、至少一维处于纳米尺度（约 3–100 nm）的材料统称；按制备路线分三支——**CNC**（纤维素纳米晶体，酸解）、**CNF/NFC**（纤维素纳米纤丝，机械/化学机械解纤）、**BNC/BC**（细菌纳米纤维素，微生物合成）。三者**不是替代关系**，而是三种不同的结构尺度与形态。

## 机理 / 结构拆解

1. **CNC = 「刚性填料」**：酸水解无定形区，留下高结晶短棒（直径 3–20 nm、长 100–500 nm），结晶度 >70%、模量 100–150 GPa；缺点是分散难、脆性大。
2. **CNF = 「造纸纤维的纳米化」**：机械/化学机械解纤得到高长径比柔性纤丝（直径 10–100 nm、长数微米），成网性强；缺点是制备能耗高、干燥团聚。
3. **BNC = 「微生物织出来的整张网」**：细菌直接挤出并氢键组装成三维连续网络（pellicle），直径 20–100 nm、长数微米；纯度 >99%、无木质素/半纤维素/果胶，超强持水、生物相容、可完全降解；缺点是产能低、成本极高。
4. **BNC 的独特之处在「连续性 + 纯度」**：CNF 要后天成网，BNC 生下来就是网；植物源纤维素要提纯才能用，BNC 生下来就是纯的——这是它在持水与结构连续性上「独一档」的原因。
5. **下游功能共识**：三者的高比表面积与表面羟基都使它们能作**增强剂**（复合纤维/薄膜/发泡）、**阻隔涂层**（氧气/水蒸气/油脂）、**流变助剂**（涂料/水泥/钻井液）与**乳化稳定剂**（Pickering 乳液，可稳定 24 个月）。
6. **同一材料的两种叙事**：BNC 既被用于「高端差异化」（面膜基材、创面敷料、可降解发泡），也被主张用于「大宗替代」（替换绒毛浆/SAP）——后者已被判不成立（见下）。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[BNC 技术分享（英文完整版，20260911）]]、[[BNC 卫生用品技术可行性评估（访前尽调详细版）]]）：两份独立文档在同一判断上互证——**三类纳米纤维素互不替代**，且纳米纤维素**不可作为大宗材料替代绒毛浆或 SAP**（发酵经济性、吸水机制、规模经济三重不成立）。其价值在**高端差异化**：纯度、亲肤性、可生物降解、阻隔与增强。

- **教训一（定位）**：谈纳米纤维素时先问「哪一支、什么交付形态」。CNC/CNF 是能源与化工路线，BNC 是发酵路线，成本结构完全不同，混用会把价格与技术要求一并带偏。
- **教训二（口径）**：「纳米纤维素」在公司材料中同时承担「原料」「发泡材料」「高阻隔涂层」三种商品角色，谈判或对标时须先锁定交付形态（凝胶/分散液/干粉/晶体/发泡体），否则 RFQ 无法比价。
- **待补 `[待验证]`**：CNC/CNF 国内量产产能与价格带；BNC 与 CNF 在同等克重下的毛细性能对比实测；各支材料的食品接触/皮肤接触法规状态。

## Evidence Update 证据追加（2026-09-29）

> ✅ Verification（2026-09-29，source 来源 [[纳米纤维素供应商拜访计划 V3.1（2026Q2）]]）：本页既有判断「三类纳米纤维素互不替代、价值在高端差异化」未被修正；本批补充的是**制备能耗与增强幅度**两组可操作参数——CNF 添加 1–10 wt% 时拉伸强度 +20–100%、弹性模量 +30–200%，湿法成网 1–5 wt% 时纸张强度 +20–50%；制备能耗 高压均质 30–50 kWh/kg vs **TEMPO 氧化 + 均质 1–5 kWh/kg**（较机械法降低 60–300 倍）。CNC 酸水解条件：硫酸 60%、50–60 °C、1–2 h，洗涤离心 → 透析纯化 → 浓缩干燥。表面改性（乙酰化 / 硅烷化）与 10–20 wt% 母粒路线用于改善与聚烯烃的相容性。

> 商业化标杆产能：CelluForce CNC 1 t/天（全球首家 CNC 商业化工厂）、Borregaard CNF 1,000 t/年、Nippon Paper CNF 500 t/年+（TEMPO 路线）。
