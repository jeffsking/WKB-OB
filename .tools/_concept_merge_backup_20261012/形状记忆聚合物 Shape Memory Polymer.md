# 形状记忆聚合物 Shape Memory Polymer
> 📌 **Page completed 2026-09-30** from 3 citing sources. All figures traced to their source pages. Anything not evidenced is marked `[待补]`.

## Definition 定义

- 形式化定义：**定义待补（引用来源未给出明确定义）**。
- 功能口径（有来源支撑，属**刺激响应聚合物**的一支）：SMP 是**在转变温度（Tg / Tm）附近改变弹性与隔热行为的聚合物** —— "shape-memory polymers (e.g. Diaplex) changing elasticity/insulation near Tg"（源：[[Smart Textiles and Sportswear]]）。
- 在智能纺织品功能版图中，shape-memory 与 chromic（变色）、thermoregulation、waterproof-breathable、wearable electronics、PCM 并列为六条功能主线之一（源：[[Smart Textiles Review]]）。
- 在卫材胶黏语境下被归为**温度响应路径**："聚氨酯 / 聚己内酯形状记忆聚合物，**Tg/Tm 附近模量突变 → 粘接力切换**"（源：[[Henkel 议题补充：超低添加量与智能响应胶（2026-05-26 交流背景）]]）。
- 历史锚点：shape-memory **silk thread，1980s 晚期，日本**（源：[[Smart Fabric Textiles Recent Advances and Challenges]]）。

## Method / Mechanism 方法 / 机理

- **转变点附近的模量突变。** SMP 的开关来自 Tg / Tm 附近的力学—（乃至光学/阻隔）性质突变：Diaplex 靠**粒子在约 25 °C 转变点上下的重分布**工作，并据此宣称**无孔隙的防水透气防冷凝**（源：[[Intelligent Textiles and Sports Clothing]]）。在胶黏语境中，这一突变被表述为"Tg/Tm 附近模量突变 → 粘接力切换"（源：[[Henkel 议题补充：超低添加量与智能响应胶（2026-05-26 交流背景）]]）。
- **被动 → 主动 → 超智能的三级框架。** 智能纺织品按"被动（感知）/ 主动（感知 + 响应）/ 超智能（感知 + 响应 + 适应）"分类，SMP 属**能改变形状/性能的响应材料**；核心组件为传感器、致动器、控制单元（源：[[Smart Textiles Review]]、[[Smart Textiles and Sportswear]]）。
- **SMP 作为动态粘接路径。** 传统热熔胶"施胶 → 冷却 → **固定**粘接力（被动、不可逆）"；智能响应胶"施胶 → 固化 → **感知刺激** → **动态调整**粘接行为（主动、可逆/可控）"，刺激类型含温度/湿度/pH/光/力/电场；SMP 是三条候选技术路径之一（另两条为水凝胶复合胶、相变材料嵌入）（源：[[Henkel 纸尿裤胶粘剂技术交流议题清单（2026-05-26 · 汉高全球研发中心参观提纲）]]、[[Ultra-Low Add-On Adhesive Application（超低添加量施胶）]]）。
- **可逆性的分子级反证。** 把螺吡喃并入聚氨酯形状记忆聚合物（PUR-SP）可同时获得力学致变色与形状记忆 → 说明 SMP 与力致变色分子可在同一网络中共存，但该体系仍为研究级（源：[[Mechanophore Mechanochromism（机械力致变色分子）]]）。

## Hygiene Relevance 卫材关联

- **舒适层热管理**：PCM 微胶囊与 SMP 属智能纺织的温控技术，库内判断其可迁移至卫材舒适层（PCM 微胶囊"可直接用于卫材舒适层而不改变产线形态"）（源：[[Smart Textiles Review]]、[[Smart Textiles and Sportswear]]）。
- **智能响应胶的中期路线（3–5 年）**：卫材最相关的形态是**温/湿响应结构胶**的四阶段设想 —— [生产] 强粘接 ｜ [存储] 稳定 ｜ [穿着-干态] 维持 ｜ [穿着-尿湿] 粘接力自适应增强（防结构松散导致侧漏）；其中**湿度响应（PVA/PVP/PEG 接枝）近期可行性最高（⭐⭐⭐⭐），温度响应（SMP）为中期 3–5 年**（源：[[Ultra-Low Add-On Adhesive Application（超低添加量施胶）]]、[[Henkel 议题补充：超低添加量与智能响应胶（2026-05-26 交流背景）]]）。
- **形状记忆 SAP（研究前沿）**：Acrylic-Based SAP 的 2024 新方向明确把"**形状记忆 SAP**"列入结构优化方向（另含 3D 打印分级孔道 SAP、纳米复合 SAP）（源：[[Acrylic-Based Superabsorbent Polymers]]）。
- **市场语境**：卫生产品约占全球医疗纺织品市场 **~50 %**，舒适性是首要接受参数 —— 这是 SMP / 响应材料在卫材落地的场景依据（源：[[Smart Textiles Review]]）。
