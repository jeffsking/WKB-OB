# Kirigami Apertured Nonwoven（切割拉伸开孔工艺）

> 名称说明：ASR 转写中作「kigami / kiligami」，还原为 **Kirigami**（剪纸式切割 + 拉伸成孔）。本页为单一来源（2026-09-29 编译的内部现场交流会），参数均为**供应商/内部口径**，未见第三方验证。

## 机理 / 结构拆解

| 环节 | 内容 |
|---|---|
| 工艺本质 | 对材料**先切割、再拉伸**，使切缝张开成为**开孔（open area）** —— 与直接打孔（perforating）不同，孔是靠拉伸"张开"出来的 |
| 三支柱 | **material（材料）/ stretch（拉伸）/ pattern（花型）** —— 三者构成"三角形"工艺，缺一不可 |
| 开孔率的驱动 | **拉伸比越大 → 开孔面积越大** |
| 失效模式 | 拉伸比过大**会破（break）**；切割边缘拉伸后**不平整、会变形** |
| 纤维层面后果 | 切割 + 拉伸会使材料中的**纤维发生形变** |

**关键机理推论（本方在会上提出的开放问题）**：
1. 用作 **surge（导流层）** 时，形变有利于创造 **void volume（空隙体积）** → 有利。
2. 用作 **topsheet / topical liner（面层）** 时，变形的切边会带来**与皮肤的摩擦**问题 → **未解**，理论上取决于 draw（拉伸倍率）。

## 关键参数表

| Item 项目 | Value 数值 | Note 备注 |
| --- | --- | --- |
| 拉伸方式 | 拉伸比需**在线根据材料调整**，无法固化为一步/两步/三步固定拉伸 | 材料波动 → 在线调整 |
| 首步开孔率 | 约 **3–4%**（若设定一步拉伸，实际首步只能开到该水平） | 开孔率受破膜风险限制 |
| Pattern pitch | 最终 **10 mm**（曾比较 **12 / 8 mm**）；另一决策点为 **14 mm vs 10 mm** | 由 R&E 团队决策，**与整体 CD 相关** |
| 工艺版本 | **V1 / V2 / V3**，**V3 为当前量产运行版本** | R&E 团队持续改进 |
| 应用边界 | **只用于 surge**，**从未用于 topsheet / topical liner** | 摩擦与变形是障碍 |
| 开孔率 vs 一等品率 | 开孔要"大到消费者能看见"，但**对 first grade（一等品率）不易** | 二者存在冲突 |
| bonding 方式 | **LSE 超声波**（试过 adhesive 与 ultrasonic 两条路线，2 次 trial 均保留 ultrasonic） | adhesive 在细线上不易施加 |
| 范围控制 | 为最小化项目范围，**只在 2 号、3 号机**上应用 | 其余工序沿用既有 |
| 落地地域 | 该设计全球推多年，**只在韩国落地** | 其他地区未采用 |

## 经验教训

1. **"切割 + 拉伸"的形变量是把双刃剑**：同一个形变，在 surge 上是 void volume（正收益），在面层上是摩擦（负收益）。评估 Kirigami 类工艺时**必须先界定应用位置**，不能只谈开孔率。
2. **开孔率不是越高越好**：消费者可辨识度要求开孔够大，但一等品率与破膜风险反向约束；需要一个**可制造的开孔窗口**，而非单一目标值。
3. **拉伸比不能固化**：因材料（如 TBCW 的 GSM 波动、CD 方向差异）存在波动，拉伸比必须**在线根据材料调整**，无法写成固定工艺卡。
4. **花型 pitch 与 CD 耦合**：pitch 的选择（10 vs 12 vs 8 mm）不只是外观问题，它与整体 CD 相关，改动 pitch 会牵动结构。
5. **花型细节的保密边界**：角度、间距、pitch 图纸通常在 R&E 与工艺人员小范围内，工程侧常只拿到"要什么"而不知原因 —— 这会削弱工程侧自主改进的能力。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 张力控制模块与两次拉伸的工艺细节）

> 来源：[[Precision Rotary Die & Module Supplier Review — Stretch Cutting, SAP Dosing & Layer Config（公司介绍与业务交流）]]（供应商交流会 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论；本批内容来自**设备/模块供应商**视角，与前述内部视角互为补充。

**完整工艺链（本批新增）：**

**切孔 → 拉伸 → 复合**（cut → stretch → laminate）。供应商可交付完整方案（含张力控制模块 / T-channel 模块），而非只交付模具。

**张力控制模块的作用（本批新增）：**

| Item 项目 | 内容 | Note 备注 |
| --- | --- | --- |
| 拉伸比例 | 可**精确控制到约 10%** | 配专用模块 |
| 为什么需要 | 材料本身存在 **GSM 波动**与**张力波动**；在**高速下保持张力一致非常关键** | 不是可选配置，而是高速前提 |
| 拉伸的收益 | 材料**结构增强约 10%** | 拉伸不只是开孔，也强化材料 |
| 拉伸次数 | **两次拉伸**；可在第二次拉伸时**微调**，以保证总张力合适并检验成品 | 类似 spandex 的分段拉伸思路 |

**由此得到的关键认知（本批新增）：**

1. Kirigami 类工艺的**拉伸段必须有闭环张力控制** —— 否则 GSM 与张力波动会在高速下放大为花型不一致。
2. **拉伸是"开孔 + 增强"双重作用**：既张开孔，又使材料结构增强约 10%，这与"切割削弱材料"的直觉相反。
3. **分段拉伸比一步拉伸更可控**：第二次拉伸提供微调机会，是工艺柔性的来源。

**模具能力补充（本批新增）：**

- 打孔（pin punch）关键参数：**pulling hole / pitch / pin diameter** —— 三者直接决定孔的质量与一致性；**常温作业**（不加热）[待验证]。
- 最小可做到的孔径：**未获得答复**（本方以 6×9 为参照追问）[待验证]。
- 模切（die cutter）与针孔（pin hole）可考虑**组合**（一半大孔 + 一半小孔）或交付两套；但**需要平衡张力 + 对位**，本方明确指出"**做对位很难**"，可行性未定。

✅ **验证记录（2026-09-29）**：以上为**供应商自述能力**，未见第三方或本方实测数据；10% 拉伸与"结构增强 10%"为供应商口径 [待验证]。参见 [[TBCW结构]]、[[ADL（导流层）]]、[[Patterned SAP Core Forming Drum（印花SAP芯体成型鼓）]]。

## 追加：Meeting Minutes 批 3（2026-09-29 追加 · 项目定位、TRL 与四大风险）

> 来源：[[TJ Mill Visit Pre-Brief — GRID × Kirigami, Coform & Gasket Deep-Dive（2026-09-07 v3.1）]]（本方内部会前准备文件，Prepared 2026-09-02，附来源引用表）。本批只**追加**，不修改既有结论；本批来自**内部项目文件**视角，可补足前两批的供应商视角。

**项目定位（本批新增）：**

| Item 项目 | 内容 |
| --- | --- |
| 启动动因 | 消费者对尿液/稀便管理与皮肤干爽的需求 + 透气性提升 + **POME Topical Surge 成本上升** |
| 一句话定位 | **Kirigami 是作为 POME topical surge 的降本替代而启动的** |
| 机理 | **切割 + 拉伸**形成**半圆开孔 + 微观形貌**（实物样 **SemiCircle 10 mm**）→ 构建 **3D 通道** |
| 对标平面材料 | 表面光滑、液体通道少、分布慢、**回渗风险高、透气性差** |
| 价值主张 | **不增加克重**改善液体管理/透气/干爽；消费者接受度好；**有望降低对 POME Topical Surge 的依赖** |
| 成熟度 | **KIRIGAMI Surge (GRE) TRL 3–4**；同侪 U-Bonder / 3D Sensation / 3D Bico (GNW)；**CLEANSHIELD 已 TRL 5+** |
| 切割路线 | **Kirigami 与激光切割**被并列为腰带透气性的两个方案（claim space TBD）；在线/离线、激光/机械分切**未定** |

**四大风险（本批新增，是本页最重要的补充）：**

1. **开孔/通道是储液 reservoir**：高抽吸开孔网络（**40–50 kPa**）若**输给下层采集层**，会把液体**存留在面层里**，并在受压下回渗；且**芯体接近饱和时余量变窄**。
2. **凉爽/潮湿悖论**：面层或 surge 上的**凉爽方案可能增加"潮湿感"**（2022 Intake Strategy 已知顾虑）→ 与 PCM / 温感路线直接冲突。
3. **降克重风险**：面层计划降至 **18 gsm**；**纸尿裤面层低于 12 gsm 有 GOS 风险** → **切割+拉伸比例与克重的交互必须问清**。
4. **切换经济性未闭环**：**Kirigami 的原料 + 加工成本 vs. POME 总成本**比较**尚未闭合**。

**BM 控制机理（本批新增）：**

- topical liner 设计核心 = **开孔 + 下方空隙**。无开孔/空隙 → **BM 积在表面**；有开孔 + 空隙 → **BM 进入下层、皮肤更干净**。
- 已用 **CleanShield 假人 + 30 ml 液态 BM** 验证。
- → **开孔必须配"下方空隙"才有意义**，单独开孔不解决问题。

**与防漏垫片的交叉风险（本批新增）：**

- 若开孔区**延伸到腿围 / 腰围垫片区域**，会创造**新的最小阻力泄漏路径** → 面层议题与垫片议题**必须交叉评审**，不能各自优化。见 [[Gasketing Effectiveness（防漏阻隔有效性）]]。

✅ **验证记录（2026-09-29）**：以上来自**内部准备文件**，非实测数据；文件自身标注 —— **Kirigami 的放大/在线切割速度/成本对比数据不可得**，**SemiCircle 10 mm 是否为终版待现场确认** [待验证]。参见 [[ADL（导流层）]]、[[Gasketing Effectiveness（防漏阻隔有效性）]]、[[Coform Composite Nonwoven（熔喷-木浆复合非织造）]]。

## 追加：Meeting Minutes 批 4（2026-09-29 追加 · 相邻的 pinhole 打孔路线：高速下的涂层、间隙与针型）

> 来源：[[Pin-Hole Module, Targeted Fluff Distribution & Elastic Recovery Process Review（新材料开发与弹性恢复工艺探讨）]]（供应商技术推荐会 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。
> 说明：本批讲的是**另一条开孔路线 —— pinhole（针孔）打孔**，与 Kirigami 的"切割 + 拉伸"并列；供应商同时具备 **die cutter + 张力控制/拉伸**能力，两条路线在其处交汇。

**高速打孔的两个关键工程点（本批新增，可直接迁移到 Kirigami 的切割段）：**

| 工程点 | 内容 |
| --- | --- |
| ① **DLC 涂层（类金刚石涂层）** | 作用是**缓解发热（alleviate the heat）**并让运行**更顺滑** |
| ② **孔—针间隙（hole-pin gap）** | 决定 **pin 外径与孔内径**时**必须做计算**，并留出**安全余量（safety buffer）** |

**高速下的失效机理（本批新增）：**

- 高速下会产生**热量 → 导致材料变形**，供应商与 KI 方均判断为 **critical**。
- 缓解手段之一是**针的密度（density of pins）** —— 密度是需要与速度联动设计的变量，不是固定值。

**针型与孔型（本批新增）：**

| Item 项目 | 内容 |
| --- | --- |
| 针型 | **carving（带雕刻）** 与 **tapered（锥形）** 两种；**锥形更适合做小孔** |
| 孔型现状 | **目前只有圆孔** |
| 待确认 | 能否做**异形孔（abnormal patterns）** —— 本方已提出，**未获答复** |
| Pilot 速度 | **可达 500 m/min**（本方评价 "good enough"） |
| 克重范围 | **10–18 gsm**（另有 18 / 30 / 30 口径）[待验证] |

**由此得到的认知（本批新增）：**

1. **"热 → 材料变形"是所有高速开孔工艺的共性问题** —— Kirigami 的切割 + 拉伸段同样会遇到；**涂层（降热 + 降摩擦）是通用解法**，不是 pinhole 独有。
2. **间隙必须留安全余量**：孔—针的配合不能按名义尺寸设计，须做计算并留 buffer —— 这与 Kirigami 中"拉伸比不能固化、须在线调整"是同一类**波动容忍设计**。
3. **针/刀的几何（锥形 vs 直刃）决定可做到的最小特征尺寸** —— 想做更小的孔/缝，先改刀具几何。
4. **两条开孔路线可以共存并互为备份**：Kirigami（切+拉，开孔率大）与 pinhole（直接打孔，孔径可控），供应商能力可同时覆盖。

✅ **验证记录（2026-09-29）**：全部为**供应商技术推荐口径**，**无实测数据**；会中存在**口径冲突** —— 同一会议既说 pinhole 模块"已在机高速运行"，又说新模块"只是概念、可能两三年" [需澄清]；涂层为**直接接触材料**，健康与环境影响**未闭环** [待验证]。参见 [[Pin-Hole Module, Targeted Fluff Distribution & Elastic Recovery Process Review（新材料开发与弹性恢复工艺探讨）]]、[[分区密度设计]]。

## 追加：Meeting Minutes 批 5（2026-09-29 追加 · 访问收尾会：花型取用、工装材质路线与共同开发框架）

> 来源：[[Co-Development Tooling Design Review — Kirigami Pattern, Pin-Hole Module & Carbide Guidance（合作开发新模具设计）]]（供应商现场访问**收尾会** ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**三项 follow-up（会中收口，本批新增）：**

| # | 议题 | 内容 |
| --- | --- | --- |
| ① | **花型（pattern）设计** | 现场已有 **3 种现成花型**，请供应商**发花型图纸**；本方**不想照抄延江 / K-C 的 smile 花型** [待验证]，要另找花型 |
| ② | **hole cutter [待验证]** | 需给出**提案**，走邮件给 Li XG（抄送 Jerry 与主讲人），并引入本方采购 |
| ③ | **pinhole 模块共同开发** | 本方发花型设计 → 供应商给设计提案；本方**只承担一定比例的工装费用、非 100%**，对价是**模块不得售予他人**（供应商当场接受）[待验证] |

**对本页最关键的补充 —— 工装材质路线（本批新增）：**

- **高速钢（HSS）：任意花型都容易做** → 先做**原型**；**原型确认后再转硬质合金（Thompson carbide）** 做量产刀具。
- **硬质合金：不易做花型**，须**规避刚性角度与刚性边（rigid angles / rigid edges）**。
- → 本方据此两次追问"**哪些花型在硬质合金上做不出来**"，**未获答复**。

**Kirigami 拉伸模块（本批新增）：**

- 供应商已提供**一级 / 二级拉伸（stretch one / stretch two）与拉伸模块**；本方要求其**补齐完整设计**。
- 目标材料为 **liner（面层）与 panel**，形态考虑 **inline（在线）**，panel 亦在范围内。
- 本方将**提供材料**供试，并**回国后确定最终花型** → 结论**尚未形成**（不得写成已决）。

**由此得到的认知（本批新增）：**

1. **Kirigami 的可行性不只由工艺决定，还由工装材质决定** —— 花型必须在**高速钢打样阶段**就按硬质合金的约束收敛，否则"原型做得出、量产做不出"。
2. **"能力边界"是设计输入而非设计输出**：孔径上下限、**孔—孔间距**、异形孔可行性这三项拿不到，设计就无法真正启动 —— 本方明确说"我需要这三项指引才能开始"。
3. **共同开发的商务结构是"费用分担 ↔ 独家性"的对价**：分担比例（非 100%）换的是模块**不售予他人**；这是把供应商工艺能力转为排他资产的机制。
4. **现成花型是低成本起点**：先索取供应商已有的 3 种花型图纸，若不满意再开新花型 —— 比一开始就定制更省工装投入。
