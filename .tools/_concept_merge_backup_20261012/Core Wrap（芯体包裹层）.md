# Core Wrap（芯体包裹层）

> 一句话定义：包裹在 SAM/绒毛浆芯体外围的低克重薄层（BCC 常用亲水处理 SMS，AFC 用 tissue），承担**把 SAP 困在芯体内**的最后一道屏障，同时是成型工艺的辅助载体。术语：Core Wrap = Wrapsheet = Spacer Layer（K-C 培训口径，三者同义）。

## 机理 / 结构拆解

1. **SAM containment（SAP 容纳）**：使用中把 SAM 与绒毛浆保持在芯体内，**防止凝胶沾肤**——这是包裹层的第一职能。
2. **保护底膜（outer cover protection）**：防止 SAM **戳穿（poke-through）**并隔绝芯体湿气向透气底膜转移（dampness of breathable outer covers）。
3. **工艺辅助（process aid）**：在 form-on-substrate（衬底成形）工艺中**辅助芯体从成型鼓转移（drum release）**。
4. **材料口径**：minimal basis weight（尽量低克重）；BCC 用 **SMS**、须亲水处理；AFC 用 **tissue**；pancake roll 供货，内外采购均有；建议储存期限约 1 年。
5. **与相邻层的分工**：面层与导流层都要求 little/no retention——包裹层同样不是吸收/保留层，它的价值是"隔离 + 转移"而非吸液。
