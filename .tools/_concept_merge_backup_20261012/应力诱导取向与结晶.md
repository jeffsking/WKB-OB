# 应力诱导取向与结晶（shish-kebab 结构）

> 一句话定义：拉伸过程中分子链由无规蜷曲转为沿纤维轴排列，并形成**拉长的 shish-kebab 晶体**（而非模塑件的球晶）——这是纤维强度的来源，与「低熔点 = 少结晶」构成一对根本矛盾。

## 机理 / 结构拆解

1. **纤维晶态与模塑件根本不同**：纺丝与牵伸使分子链高度取向，形成拉长的 shish-kebab 结构；注塑件则从成核点径向生长球晶。这直接造成机械性能差异。
2. **强度-取向-分子量的三元条件**：纤维达到结晶取向 ≥90% + 非晶取向 ≥85%，且 Mw ≥7.0×10⁵ 时，强度可稳定超过 7 cN/dtex。三者缺一不可。
3. **两段拉伸的分工**：
   - **一段**（110–160°C，4×–14×）：在 α-松弛温度以上进行，使晶区与非晶区同时塑性变形，链段沿轴排列。
   - **二段**（80–135°C，1.2×–3×，张力 1.50–5.00 cN/dtex）：精修取向，张力过高促进非晶取向但易断丝。
   - **总牵伸 5×–15×**：过大导致断丝毛丝，过小则强度潜力未实现。
4. **结晶度与晶粒取向**：牵伸纤维结晶度 60–75%（高于模塑件 50–60%）；小角 X 射线散射（SAXS）的子午/赤道强度比 0.5–0.95 表征层晶取向程度。
5. **与熔点的矛盾**：低熔点 PP 的本质是少结晶、片晶不完善，而强度要靠结晶与取向——**这是单组分路线的死结，也是皮芯结构的理由**。

## 经验教训

> ✅ 验证（2026-09-27）：本页「拉伸是强度的唯一实现路径」与 [[成纤聚合物的判据]] 的结论一致——固化后必须为后续拉伸保留足够变形空间，否则取向发展不足、强度难以提高。

- **要点**：评审低熔点 PP 方案的强度指标时，应把「树脂端分子量」与「纺丝线牵伸能力」分开看——前者定上限，后者实现发挥。
