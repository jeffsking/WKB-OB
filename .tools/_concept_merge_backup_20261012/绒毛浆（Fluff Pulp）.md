# 绒毛浆（Fluff Pulp）

> 一句话定义：经解纤（纤维化）处理的化学浆，是纸尿裤/卫生巾吸收芯的传统主体材料，承担**快速芯吸（wicking）**与**蓬松骨架**两个功能。在本库中它同时是 BNC 复合路线的**骨架解药**与 BNC 替代路线的**否决对象**。

## 机理 / 结构拆解

1. **功能分工（行业基准架构）**：吸收芯 = 绒毛浆 + SAP；**浆负责快速芯吸，SAP 负责受压下的液体保持**；典型配比纤维素/SAP = 80/20 – 90/10（EDANA AHPs 白皮书 2022）。
2. **与 BNC 的尺寸反差**：绒毛浆纤维直径 30 µm 级，BNC 为 40–60 nm——**细约 200 倍**；同等克重下 BNC 的毛细比表面积指数级上升。孔隙率对比：绒毛浆约 80% → BNC >90%。
3. **作为 BNC 的骨架解药（路线 A 的机理核心）**：绒毛浆提供**内部支撑骨架**（解 BNC 发泡体受压无回弹），同时构建**表面毛细通道**（解表面孔隙差、渗透慢，并缓解塌孔）。
4. **起点配方**：绒毛浆占比 **≥60%** 起步，优选 **≤2 mm 短纤维**；实际比例需样品验证后迭代。
5. **为什么不能被发酵 BNC 替代**：绒毛浆的价值 = **全球规模（约 24 Mt/年供应）+ 成本 + 长纤维回弹性/蓬松度**；发酵 BNC 在任何反应器配置下都无法匹配纸浆经济性，且 BNC 网络缺乏长纤维蓬松度（芯体蓬松依赖纤维刚性与卷曲）。
6. **例外场景**：仅在局部功能分区（如男婴前漏垫）作为复合增强使用——即「不得以终端材料身份替代绒毛浆」的红线形态（该红线已于 2026-09-05 修订为仅约束**终端材料替代**，中间体/载体/增效角色不受限）。
7. **评价指标语境**：绒毛浆基发泡样品的验证指标=手感软、渗透时间、回渗（rewet）、厚度 0.5–0.8 mm；当前样品偏厚、有闷热问题。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[BNC 卫生用品技术可行性评估（访前尽调详细版）]]、[[BNC 技术分享（英文完整版，20260911）]]）：两份文档从相反方向互证同一结论——**绒毛浆不可被 BNC 替代（规模与机理双重不成立）**，但**绒毛浆是 BNC 复合路线不可缺的骨架**。一个材料同时是「替代对象（否决）」与「关键配料（首选）」，取决于交付形态与角色定义。

> ✅ 验证（2026-09-29，来源 [[Blizzard and ActiveTech Technologies（在线薄型无绒毛浆芯体技术）]]，批次 S1_Projects_Active Hygiene_01）：本页「浆负责快速芯吸」的表述得到**去浆方向的实测旁证**——在在线无浆芯体（Blizzard/ROTC）的成人护理对照中，去浆带来厚度 5.5 → 4.4 mm、高压回渗 2.67 → 0.40 g、保液容量维持约 700 g，**代价正是「第三次摄入变慢」**；婴儿形态下另出现 **cradle intake 变慢与漏尿趋势上升**，故最终**保留带导流槽的混合构型**。这直接印证：**绒毛浆被移除后，最先受损的是摄入/导流动力学，而不是容量**——与本页「浆负责快速芯吸 + 蓬松骨架」的定位一致。详见 [[Blizzard Core（Blizzard 芯体结构）]]、[[ROTC（Real Online ThinTech Core）]]。⚠️ 该实测为**内部测试口径**（未标样本量与测试方法），标 `[待验证]`。

- **教训一（角色 vs 对象）**：判一条新材料路线时，先定义它的**角色**（骨架/载体/增强剂/增效剂/终端材料），再判可行性；按「替代谁」一刀切会误伤中间体与增效类路线（这正是 2026-09-05 红线修订的原因）。
- **教训二（指标前置）**：绒毛浆复合样品的首要收敛指标是**厚度**（目标 0.5–0.8 mm），因为当前样品的痛点是偏厚与闷热——若不先锁定厚度，回渗数据没有可比性。
- **待补 `[待验证]`**：绒毛浆的价格与指数口径；国内绒毛浆供应格局；BNC 复合后对芯体蓬松度衰减的定量影响。

## 追加：Open Innovation 批（2026-09-29 追加）

> 本节为 **Resources / Open Innovation 批（批次 S4_Resources_Open Innovation_05）** 编译时的追加记录，**不改动上方既有结论**。上方「浆负责快速芯吸 + 蓬松骨架」的定位在本批仍成立；本节补充的是**浆在回渗中的负面角色**，以及它在两种回渗里**方向相反**的证据。

### 1. 本批新增：绒毛浆是「摄入系统的一部分」，因此是低压回渗的来源

- **假说**：在 ATH（ActivTech Hybrid）结构中，绒毛浆实际承担摄入系统职能——**液体留在浆里，之后以解吸（desorption）形式回到面层**。见 [[ADT Brain Trust - Fluff and Rewet（绒毛浆与回渗 DOE 复盘）]]。
- **毛细测试旁证（2025-07，GRIFFIN 样品，为排除干扰做成无 SAM 样品）**：**有浆时解吸能更高（更难晾干）、且截留残液更多**；12 gsm dSB 与 20 gsm BCW 两种包裹层下趋势一致。这是"浆 → 残液 → 低压回渗"链条的仪器化证据。
- **注意这是「同一材料的功能漂移」**：浆在去浆路线里是"被移除的对象"，在 ATH 路线里却变成"摄入系统的一部分"——**同一份浆在不同芯体架构中承担不同角色，评价前须先定义架构**。

### 2. 本批新增参数

| 参数 | 数值 / 方向 | 出处 |
|---|---|---|
| 浆量 ↑ 对低压回渗（LPR） | **降低 LPR**（六套 DOE 一致） | [[ADT Brain Trust - Fluff and Rewet（绒毛浆与回渗 DOE 复盘）]] |
| 浆量 ↑ 对高压回渗（HPR） | **可能升高 HPR**（低 MACH SAM 下效应更大） | 同上 |
| 浆在 LPR 因子排序中的位次 | **第 2 位**（Logworth 6.725，仅次于 SAM 类型 7.057） | 同上（MAMBA 汇总） |
| 浆在 HPR 因子排序中的位次 | 第 5 位（Logworth 8.220），**远低于 SAM 类型 25.749 与垫容量 20.815** | 同上 |
| 浆形（Shaped vs Rectangular） | 影响弱、方向不一致（异形浆对 LPR 略好、对 HPR 略差） | 同上 |
| 浆在 BB DOE 中的 LPR 位次 | **第 1 位**（Logworth 17.042，高于导流层 11.448 与 SAM 总量 10.156） | 同上 |
| 把 SAM 掺进浆（SiF） | 一般降低 HPR/LPR；**但在 Depend CCR 上反向升高**（0.34 → 0.40 g），未解 | 同上 |

> ⚠️ **矛盾记录（2026-09-29，待人工确认）**：掺 SAM 进绒毛浆（SiF）在 **closed cradle 回渗上升高回渗**（Depend GRIFFIN，0.34 → 0.38（30%）→ 0.40 g（47%）），却在多套 DOE 的 **HPR/LPR 上降低回渗**（Logworth 9.179 / 7.570）。源文件本身将其标为 "Why?" 未解项。**本节照录两种口径，不裁决、不换算、不推断成因。**

### 3. 验证记录

> ✅ 验证（2026-09-29，来源 [[ADT Brain Trust - Fluff and Rewet（绒毛浆与回渗 DOE 复盘）]]）：本页既有判断「绒毛浆负责快速芯吸与蓬松骨架」在本批得到**反向补强**——浆的好处（芯吸）与坏处（残留液体 → 低压回渗）**同源**：正因为浆会把液体留在自己身上，它才能在低压下把液体从面层拉走，也正因为如此它成为解吸型回渗的储液库。原页结论**未被修正**，但需补一句**角色依赖架构**的限定。

- **追加要点**：评价"加减浆"必须同时报 LPR 与 HPR 两个数；**只报一个等于只报一半**。
- **追加 `[待验证]`**：浆的解吸能 ↔ 低压回渗的定量关系；不同浆形（shaped / rectangular）在不同芯体架构下的效应方向为何不一致。

## 追加：Meeting Minutes 批 2（2026-09-29 追加 · 处理浆等级在熔喷-木浆复合材料中的取舍）

> 来源：[[Low-GSM Pulp-Meltblown Core Wrap Review — Strength, Dual Colour & Cost（尿裤包覆层材料探讨）]]（供应商现场交流 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**三种处理等级在同一材料中的取舍（本批新增）：**

| 浆等级 | 表现 | 结论 |
| --- | --- | --- |
| **全处理浆（fully treated）** | 处理后**吸水后塌缩比较厉害** | **被排除** |
| **半处理浆（semi-treated）** | 开松更好、**蓬松度更高**，塌缩可接受 | **现用方案** |
| **未处理浆（untreated）** | **扩散/吸收性能更好**（本方偏好） | 待验证，见下 |

**未处理浆的两个障碍（本批新增）：**

1. 用未处理浆会**增大熔喷压力**（工艺侧需一并调整）；
2. 现有**针式锯齿粉碎机可能打不碎**未处理浆 —— 供应商判断"不太好处理"。

**供应侧切换（本批新增）：** 因关税导致北美 **IP / GP** 浆"涨价且无货"，该供应商已切换为**国产绒毛浆**，并为此**调整了整套工艺体系**。供应商口径：国内真正能达到进口级别质量的绒毛浆厂**不多**，已筛选多轮才定 [待验证]。本方（应用侧）对浆的品牌**无要求**，"国产进口都行，只要便宜且无污点"。

✅ **验证记录（2026-09-29）**：以上为单一供应商口径，未见第三方数据；"未处理浆 + 针式锯齿粉碎机"的适配性**尚未验证**。参见 [[Coform Composite Nonwoven（熔喷-木浆复合非织造）]]、[[Meltblown Nonwoven（熔喷非织造布）]]。

## 追加：Regulation&PSC 批（2026-09-29 追加 · 国标验收口径）

> 来源：[[GB-T 21331-2021 Fluff Pulp（绒毛浆）]]（GB/T 21331-2021，2021-03-09 发布、2022-04-01 实施；2026-09-29 记录：生效中）。本节只**追加**国标验收口径，不修改既有结论。

- **产品分类（国标口径）**：处理浆（treated，化学处理、耐破度显著降低）vs 未处理浆（untreated）——与本页「处理等级取舍」追加节（全处理/半处理/未处理）相互印证，国标只设两档。
- **国标关键限值（入厂验收锚点）**：干蓬松度 ≥17.0（处理浆）/ 15.0（未处理浆）cm³/g；吸水时间 ≤8.0 / 5.0 s（23 ℃ 生理盐水，附录 B 成型法）；吸水量 ≥8 g/g；耐破度 800 / 1,500 kPa；D65 亮度 ≥90.0%；可迁移性荧光物质不得检出（定性，GB/T 27741-2018）；AOX ≤5.0 mg/kg；Pb/As/Cd/Hg ≤10/2/5/1 mg/kg；交货水分 6.0–10.0%。
- **注意口径差异**：国标附录 B 的蓬松/吸水方法（500 g 压块、50 mm 成型管、盐水）与本库内部 STM/EDANA 口径**不完全等同**，跨口径比较需注明方法。

> ✅ 验证（2026-09-29，来源 [[GB-T 21331-2021 Fluff Pulp（绒毛浆）]]）：本页「绒毛浆承担快速芯吸与蓬松骨架」定位在国标指标结构中得到印证——国标以**干蓬松度、吸水时间、吸水量**为核心分级指标，与「芯吸+蓬松」双功能一致。原结论未修正。
