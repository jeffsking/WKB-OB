# Waist Guard（腰围护挡）

> One-line definition 一句话定义：设于裤型吸收制品**后弹性腰带**上、部分粘合形成**口袋（pocket）**的护挡结构，用于阻止**低黏度排泄物（稀便/爆漏）**沿腰口向外渗漏。

## Definition / Mechanism 定义与机理拆解

1. **要解决的是"爆漏"而非"吸收不足"**：目标是阻止**低黏度体液排出物**从后腰口溢出，同时不牺牲裤型制品原有的其他功能。
2. **结构定义（权利要求 1 口径）**：
   - 制品有纵向与横向，含前弹性腰带、后弹性腰带、裆区、腰口与一对腿口；裆区在前/后腰带之间纵向延伸；
   - 吸收主体贯穿裆区全长并向前后腰带各伸入一部分（含透液面层、阻液底膜与夹于其间的吸收材料区）；
   - 前腰带横向边缘**全长**与后腰带横向边缘缝合一段长度，形成侧封，**缝合长度 LS**；
   - 后腰带按距**远端边缘（0 %）→ 近端边缘（100 %）**的 LS 百分比划分为多个区；
   - **腰围护挡自闭合基线（closed base line）向开口边（open edge）朝裆区延伸**，并**部分粘合**于后弹性腰带以形成口袋；
   - **整个口袋须位于 LS 的约 5 %–60 %** 区间内，且**口袋区域须与底膜重叠**（superpose the backsheet）；
   - 腰围护挡在口袋区含**护挡弹性部**；后腰带上与该弹性部重叠的区域定义为**相关部（correlated portion）**；**护挡弹性部的拉伸应力必须与相关部的不同**。
3. **"弹性解耦"是机理核心**：护挡弹性部与腰带相关部张力必须不同（不是简单叠加），否则无法形成并维持可以兜住稀便的口袋几何。
4. **量化门槛（同为权利要求要素）**：爆漏率 <4 %（摘要口径 <1 %）+ **腰围力 >5.6 N**（即：防漏不能以牺牲腰围贴合/上拉手感为代价）；从属项再加 **效率因子 <15 %**。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[US2022-0339044A1 Pant-Type Absorbent Article with Waist Guard (P&G)]]）：对比例数据支持了一个反直觉结论——**对比例的纸尿裤更重（最高 38.4 g）却漏得更多（最高 10.84 %）**。说明爆漏是**结构/几何问题**，不是**吸收容量问题**。本页"要解决的是爆漏而非吸收不足"的表述与来源一致。

- **教训一（评价口径）**：评估防漏设计时不要只看芯体容量与 CRC/AUL，须同时看**腰口几何与弹性解耦**。
- **教训二（约束并存）**：防漏门槛与**腰围力 >5.6 N** 是并列的，意味着"把腰围收紧"不能作为防漏手段。
- **待补 `[待验证]`**：护挡材质/克重/粘合图样；口袋深度对兜容量的定量影响；该结构在裤型以外形态（如贴式）的适用性。
