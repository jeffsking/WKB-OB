# 季铵化壳聚糖复合芯层（PAM 微球+AMPS 体系）

> One-line definition 一句话定义：在丙烯酸类 SAP 基体中共混**聚丙烯酰胺微球（储水单元）+ 季铵化壳聚糖（阳离子抗菌/电解质吸附）+ 三元改性剂（酒石酸-AMPS-胱胺双丙烯酰胺）**的芯层配方体系，主打尿液耐盐与防凝胶堵塞（中文：季铵盐壳聚糖复合芯层）。

## Mechanism 机理拆解

1. **微球分区**：PAM 微球多孔储液、表面氨基/酰胺基结合离子，兼顾吸附与防团聚；树脂网络负责整体强度。
2. **聚电解质复合**：季铵化壳聚糖阳离子与丙烯酸树脂阴离子静电成复合物增强网络；季铵基同时抑菌。
3. **三元改性剂协同**：AMPS 磺酸耐盐 + 胱胺双丙烯酰胺补交联 + 酒石酸氢键增强并分散微球；三者缺一盐水吸收即从 56 g/g 跌至 31–36 g/g。
