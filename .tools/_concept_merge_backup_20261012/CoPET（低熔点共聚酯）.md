# CoPET（低熔点共聚酯 / Low-Melt Copolyester）

> 一句话定义：在 PET 聚合阶段引入 **IPA（间苯二甲酸）** 等共聚单体，破坏链段规整性、把熔点从常规 PET 的约 256–260 ℃ 下探到 **约 110–180 ℃** 的共聚酯；在皮芯复合纤维中充当低熔点皮层，受热熔融后充当热粘合粘结剂。

## 机理 / 结构拆解

1. **降熔原理是「破坏结晶」而非「改变化学骨架」**：常规 PET 是 PTA + MEG 的均聚物，链段规整、结晶度高；掺入 IPA 后共聚链段无序，结晶度与熔点同步下降——所以 CoPET 与 PET **同属聚酯体系**（这也是它与 PE 皮芯的本质差别）。
2. **典型皮芯构型即「4080 型」**：皮层 = 改性低熔点 PET/CoPET，芯层 = 常规高熔点 PET。行业标准 **FZ/T 52051-2018《低熔点聚酯(LMPET)/聚酯(PET)复合短纤维》** 即针对该产品，厦门翔鹭为第一起草单位。
3. **判据（采购用的总闸门）**：「低熔点涤纶短纤」**不等于** CoPET 皮芯双组分纤维——传统 ES 纤维皮层为 PE/PP 或 PE/PET 等**聚烯烃**，只有皮层为低熔点 PET 的 4080 型才是真 CoPET。
4. **成本结构的两面性**：独有成本项是 IPA（约 8.1% 纤维总成本）；但皮芯同属聚酯体系带来**界面相容性优势**，复合纺丝良率 85–92%、加工费比 PE/PET 低约 200 元/吨。
5. **在 ADL 中的性能机理**：CoPET 皮层极性更强、亲水整理锚定更牢，重复润湿下的毛细连续性更稳——因此优势集中在第 2/3 次冲击（摄入更快、MD 铺展更宽、回渗更低）。
6. **工艺陷阱（Caliper Trap）**：CoPET 粘合点更强更硬，沿用 PE 的烘箱温度会**过粘合**、熔掉空隙体积；厚度损失 ≥8% 时，-24% 回渗收益可归零。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[CoPET-PET 与 PE-PET 成本结构深度拆解报告]]、[[CoPET 采购蓝图：成本拆解与供应分层]]）：本批三份独立文档（中文成本拆解报告、英文采购蓝图、价格差异对比）在**同一结论**上互证——CoPET/PET 与 PE/PET 的**制造成本高度接近**（差约 2.5%），市场溢价来自 IPA 波动与利基供需结构，而非聚合物物理差异。本页「成本结构两面性」表述与来源一致。

- **教训一（口径）**：市场上「低熔点纤维」是**大类名**，含聚烯烃皮 ES 与聚酯皮 4080 两种截然不同的产品。询价或写技术协议时必须写明**皮层树脂体系**，否则容易拿 PE/PET 的价格对标 CoPET 的性能。
- **教训二（工艺）**：CoPET 不是 PE/PET 的即插即用替代品。换皮层必须重调烘箱温度、抽风与卷绕张力，**先对齐厚度再测液体指标**——原文明确「空隙体积不可让步」。
- **待补 `[待验证]`**：CoPET 熔点—IPA 含量定量关系；国内 A 层成品商的细旦（<2D）能力与无锑牌号（本批均标「待确认」，须商务函询）。
