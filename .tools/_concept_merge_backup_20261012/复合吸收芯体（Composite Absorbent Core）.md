# 复合吸收芯体（Composite Absorbent Core）

> 一句话定义：以**绒毛浆 + 高吸水树脂（SAP）**为主体、由无尘纸/非织造布包裹定型、作为**中间品**供应给成品厂的预制吸收芯；中国由 **QB/T 5650—2021** 直接规范，是「芯体」层级唯一的产品标准。

## 机理 / 结构拆解 Mechanism

1. **层级位置**：上游原料（绒毛浆 GB/T 21331、SAP GB/T 22875、无尘纸 GB/T 24292）→ **本层（QB/T 5650 复合芯体）** → 下游成品（GB/T 28004.1 婴儿 / 28004.2 成人）。三层各有独立指标，**不可互相替代**。
2. **两类产品**：按应用对象分**卫生巾（女性卫生裤）用**与**婴儿纸尿裤用**；后者额外考核**吸收速度与回渗量**。
3. **指标层级并不等于成品层级**：婴儿芯体**吸收速度 ≤40 s** 比婴儿成品（第一次 ≤50 s）**更严**；回渗量 ≤15.0 g 与成品一致。中间品标准可以比成品更严 —— 这是因为芯体层要留出加工余量。
4. **检验属性是采购关键点**：安全五项（重金属、可迁移性荧光物质、丙烯酰胺、甲醛、邻苯二甲酸酯）**全部为型式检验**；**交货水分仅出厂检验** —— 来料 COA 默认不覆盖安全项。

## 经验教训 Lessons

1. **采购须单独约定型式检验频次**：安全五项不在出厂检验范围内，只看出厂 COA 会漏掉重金属与甲醛。
2. **按最终用途下规格**：同一家芯体厂供卫生巾与供婴儿纸尿裤，甲醛限值差 12.5 倍（75 vs 6 mg/kg），错配即不合规。
3. **禁用废弃回收原料是准入红线**，与 GB/T 30133 面层标准、GB/T 27728 湿巾标准（人体用只可用原生纤维）构成一致的原料侧原则。
