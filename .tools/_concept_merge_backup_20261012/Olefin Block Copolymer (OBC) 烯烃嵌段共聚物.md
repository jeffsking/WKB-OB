# Olefin Block Copolymer (OBC) 烯烃嵌段共聚物

> One-line definition 一句话定义：通过**链穿梭催化（chain shuttling catalysis）**合成的、由**可结晶硬段（乙烯—辛烯，共单体极少）**与**非晶软段（共单体高、玻璃化温度低）**交替排布的线性嵌段聚烯烃；在热熔胶中充当主体聚合物，提供抗蠕变（creep resistance）与弹性回复。

## Definition / Mechanism 定义与机理拆解

1. **与 APAO / 茂金属无规共聚物的本质差别是"嵌段 vs 无规"**：OBC 是**特意造出结晶区**的嵌段结构；APAO 的低结晶度是 Ziegler-Natta 无规聚合的副产物。因此两者**不可互换**。
2. **结构带来的性能**：相对同密度的茂金属无规共聚物，OBC 的高温耐受性与弹性更好（更好的弹性回复、压缩永久变形与高温阻抗）。
3. **分子量分布更窄**：来源记述 OBC 的 poly-dispersity 显著窄于 APAO，从而影响其 DSC 熔融曲线——窄分布 + 嵌段结构共同给出 improved hot tack、adhesion、低温柔韧性，同时不牺牲高温耐受。
4. **用量与功能分工**：在 EP2456819B1 的配方中 OBC 是**主聚合物**（10–30 wt%，最优 12–20 wt%），另配低结晶度次级聚合物调节加工。
5. **判据（不能只看熔融焓）**：来源明确指出有些 Infuse® 牌号的熔融焓约 **20 J/g**，**仍不能算 APAO**，因为"聚合物架构完全不同（嵌段 vs 无规）且被专门制造出结晶区"。→ **DSC 焓值不是唯一判据，架构才是**。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[EP2456819B1 Olefin Block Copolymer Hot Melt Adhesive (Bostik)]]）：来源**自己给出了判据校正**——Bostik 先铺设"DSC 熔融焓 <25 J/g 即为 APAO"的经验线，随后又说明 Infuse® 部分牌号焓值约 20 J/g 却**不应被视为 APAO**，因为**架构（嵌段 vs 无规）与制造意图**才是本质区别。这修正了"只按焓值分类聚烯烃"的简化做法。

- **教训一（物料识别）**：在技术协议或询价中把 OBC 与 APAO 混为一谈，会导致性能预期错配——两者在弹性回复、压缩永久变形与高温阻抗上是不同的。
- **待补 `[待验证]`**：OBC 的价格与在国内卫生用品供应链的可得性；除 Dow Infuse® 外的商业 OBC 来源（来源为时点记述，未做全市场尽调）。
