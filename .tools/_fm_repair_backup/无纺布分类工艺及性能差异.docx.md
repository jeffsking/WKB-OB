# 无纺布（非织造布）主要分类、工艺及性能差异

根据中国产业用纺织品行业协会2023年数据，我国非织造布产量814.30万吨。以下为主要工艺分类及各工艺详细介绍。

## 一、无纺布主要工艺分类（按产量排序）

|工艺名称|英文名称|产量占比|
|---|---|---|
|纺粘法|Spunbond|约40%|
|针刺法|Needle-punched|约25%|
|水刺法|Spunlace|约15%|
|熔喷法|Meltblown|约8%|
|热风法|Hot Air|约7%|
|化学粘合法|Chemical Bonded|约5%|


## 二、各工艺详细介绍及性能对比

## 1. 纺粘法（Spunbond）

工艺流程：高聚物切片 → 熔融挤压 → 纺丝 → 冷却牵伸 → 分丝铺网 → 纤网加固（热轧/针刺）

## 性能特点：

✅ 强度高、拉伸能力强、不起毛

✅ 耐高温性能好、耐老化

✅ 延伸率高、稳定性好

✅ 单机生产效率高、生产流程短

⚠️ 手感相对较硬

主要应用：卫材（纸尿裤/卫生巾面层、底层）、医疗防护服、包装材料、土工布

## 2. 水刺法（Spunlace/水刺）

工艺流程：纤维开松 → 梳理成网 → 高压微细水流喷射 → 纤维缠结加固 → 烘干

## 性能特点：

✅ 透气性好、柔韧

✅ 手感柔软细腻、不掉毛

✅ 结构紧密、表面平整光滑

✅ 性价比高

⚠️ 能耗较高（高压水泵）

主要应用：湿巾、面膜、医疗敷料、高端擦拭材料、超纤革基布

## 3. 针刺法（Needle-punched）

工艺流程：短纤维 → 梳理铺网 → 刺针高频机械穿刺 → 纤维缠结加固

## 性能特点：

✅ 通透性好、机械性能优良

✅ 厚度范围大（可达数十毫米）

✅ 结构蓬松、保暖性好

⚠️ 表面有针孔痕迹、不如水刺细腻

主要应用：汽车内饰、地毯基布、过滤材料、土工布、合成革基布

## 4. 熔喷法（Meltblown）

工艺流程：高聚物熔融 → 高速热空气拉伸 → 超细纤维凝集 → 自身粘合

## 性能特点：

✅ 纤维极细（1-5μm）、结构蓬松

✅ 孔隙多、过滤性能优异

✅ 比表面积大、吸附性好

⚠️ 强度较低、易起毛

主要应用：口罩熔喷层（过滤）、空气/液体过滤材料、吸油材料、保暖材料

## 5. 热风法（Hot Air）

工艺流程：纤维梳理成网 → 加入热熔粘合材料 → 热风穿透加热 → 冷却固化

## 性能特点：

✅ 蓬松柔软、弹性好

✅ 保暖性强

✅ 手感舒适

⚠️ 强度相对较低

主要应用：卫生巾/纸尿裤芯体包裹层、保暖材料、一次性卫生用品

## 6. 化学粘合法（Chemical Bonded）

工艺流程：纤网 → 喷洒/浸渍粘合剂 → 烘干固化

## 性能特点：

✅ 工艺简单、生产成本低

✅ 可生产多种克重产品

⚠️ 手感较硬（有胶感）

⚠️ 环保性相对较差（含化学粘合剂）

主要应用：鞋材、包装材料、过滤材料、工业用布
