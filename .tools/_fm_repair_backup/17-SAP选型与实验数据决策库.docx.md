单一自由膨润值会骗人：两个截然不同配方的单点 free-swell 可能一模一样；只有顺序 4 次冲击（gush）测试才能暴露错峰是否真生效 → bench 序列测试是硬门槛。

推论：原报告"全511 最优"系 高压短间隔测试假象；多 SAP 分层策略在真实穿着条件下获实证支持。

顶/底比率是第一主导轴：3/7 相对 5/5 → 扩散 +0.354、后期吸收 +0.101，但留存 −0.351（回渗约 2.6×）。速度 ↔ 留存是明确的 trade-off 曲线。

错峰物理基础存在：951(27 s) / 959(34 s) / 610S(19 s) 溶胀速率有级差；但 N8(611) 与 610S 速率接近且 GBP 均低 → 需引入高 AUL 料(959) 或控快吸料占比。

|假设|结论|
|---|---|
|H1 纯 511 可行|部分支持（综合排名前二，但留存差）|
|H2 复配优于纯|混合/弱（仅 959 有益）|
|H3 N8 有益|失败/倒置（归因不安全）|
|H4 比率影响|强支持（最稳健）|
|统计显著性|无组内重复 → 无法做正式检验；Spearman 0.81–0.90 复合排名稳定|

路线 A（完整多SAP + REL）→ 升级为「获支持 / 优先推进」：企标数据已证混底反超全511。强化：底层固定 951:959 ≈ 1:1；顶层用 KC511 或 930；评估高 AUL 料（BASF 7059 AUL 17.7 / NR-950 AUL 19.4）平衡容量-渗透。
