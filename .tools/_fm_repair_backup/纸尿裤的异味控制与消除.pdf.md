#   纸尿裤的异味控制与消除

纸尿裤的异味控制与消除是提升产品核心竞争力的关键赛道，尤其在成人失禁用品领域，消臭性能已成为产品升级的重要方向。基于搜索结果，纸尿裤odor control（异味控制）和 deodorization（消臭）的相关技术应用与发展趋势可系统地归纳为以下五个维度：

#   一、异味来源的精准解析与评价体系标准化

纸尿裤异味的有效控制前提是对异味来源的科学解析与评价体系的标准化。目前，行业正从感官评价向精准量化转变。

1. 异味来源的双重机制:纸尿裤在使用中的臭味主要来源于两方面:一是排泄物排出时直接挥发的臭味物质(如酮类、有机酸等);二是体外微生物发酵作用下排泄物进一步产生的臭味物质,如氨气等。

2. 代表性臭味物质的锁定:为了精准评价消臭性能,行业已筛选出9种代表性臭味物质,涵盖酮类(丁酮)、含氮类(氨气、三甲胺、吲哚)、羧酸类(异戊酸)、醛类(2-乙烯醛)及含硫类(硫化氢、甲硫醇、二甲基二硫醚)。其中,氨气是尿液分解产生的主要异味气体。

3.检测体系的科学构建:针对不同特性的臭味物质,检测方法日益精细化。例如,氨气测试采用模拟发酵法;硫化氢、甲硫醇采用气体静态吸附法;三甲胺采用超高效液相色谱三重四极杆质谱法;丁酮等五种物质则采用热脱附-气相色谱-质谱法进行检测。消臭效果通过臭味物质浓度减少率公式计算。

#   二、物理吸附技术的迭代与载体优化

物理吸附是传统的消臭手段，目前正经历从简单吸附到载体优化的迭代。

1. 传统吸附材料的局限:活性炭是常见的物理吸附材料,能吸附臭味性物质。然而,活性炭天然为黑色,容易对制品造成污染,且具备最大容量特性,无法源源不断地吸附产生的异味分子,导致产品时效性较短。

2.无机多孔载体的崛起:为克服活性炭的缺陷,新型多孔吸附载体被广泛应用。以无机硅酸盐混合物(如膨润土、蒙脱土、硅藻土和高岭土等)作为多孔吸附载体,通过扩孔插层方法增大其内部层间距,可显著提高对氨气等异味分子的吸附效率,且避免了深色颗粒污染产品的问题。

3.结构化吸附芯体设计:在芯体结构设计上,出现了一种去味型芯体,通过在吸收芯的通孔内设置功能性母粒层和高吸水性树脂层,将纳米银粉、茶多酚、改性杯芳烃等功能性原料与SAP分层布局,提升整体去味效果。

#   三、化学中和与生物抑制技术的深度协同

从根源上消除异味，需要化学中和与生物抑制的深度协同，实现“抑制-吸附-分解”三位一体。

1. 化学中和快速反应：通过添加酸性调节剂（如乳糖酸、柠檬酸、醋酸锌等），能够强力捕捉并中和尿液分解产生的氨气、正丙胺等碱性异味气体，进行快速的酸碱中和与还原反应，达到快速减少异味的效果。

2. 微生物抑制从源头控制:通过抑菌剂抑制细菌繁殖，减少尿液发酵产生的氨气等。例如，采用具有除臭功效的高吸水性树脂吸收尿素分解产生的氨气;或者在除味剂中添加壳聚糖、柚子花提取物、丝兰提取物等气味抑制剂，有效抑制尿液分解发酵产生异味分子。

3. 中草药天然抑菌除臭：添加仙人掌汁液、柠檬、艾草、常春藤、金银花、生大黄粉末等天然抗菌除臭中草药成分，穿戴后无任何毒副作用，具有良好的抗菌及除臭效果。

#   四、缓释微胶囊与胶囊芯体技术的创新应用

为解决消臭成分时效性短的问题，缓释微胶囊与胶囊芯体技术成为重要的创新方向。

1. 控释微胶囊技术：通过制备控释微胶囊，其内核层为多孔壳聚糖材料并包覆天然植物提取物（如茶树精油或薰衣草精油），外壳层由季铵盐壳聚糖、明胶和聚乙烯醇混合构成。该技术实现除臭成分的缓释，结合季铵盐壳聚糖的抑菌作用，显著提升除臭效率和持久性。

2. 除味胶囊芯体技术:一种除味胶囊芯体工艺采用水溶性薄膜包裹除味剂形成第一除味颗粒, 存储于芯体的尿液槽和便液槽内。当尿液接触时,水溶性薄膜溶解,除味剂释放出来进行除 味。该工艺将除味颗粒大面积分布并存储于芯体内部,解决了传统薄层除臭层难以对大面积液 体进行除味、除味效果差的问题。

#   五、消臭功能与高吸水性树脂(SAP)的复合一体化

未来的发展趋势是将消臭功能与高吸水性树脂(SAP)深度复合，实现吸液与消臭的同步一体化。

1. 消臭型SAP的应用：直接在吸收芯体中采用具有除臭功效的高吸水性树脂与吸液纤维的混合吸收层，使其在快速吸收和贮藏尿液的同时，能够吸收尿素分解产生的氨气，兼具高吸水性和消臭作用。

2. 多层复合结构的集成:纸尿裤结构正向多功能层复合发展。例如,一种微胶囊控释高效除臭纸尿裤,包括依次复合的除臭面层(涂布含控释微胶囊的除臭抑菌液)、导流层、复合芯体(由含控释微胶囊的快速吸收层和含活性炭无纺布的除臭锁水层组成)和底层,实现从面层到芯体的全方位消臭。

3. 除味剂与布料的结合：通过将抑制吸收尿骚味的除味剂对无纺布等布料进行上浆处理，使得除味剂涂覆在布料表面，制备出高效抑制去除尿骚味的布料，且掉屑数少，满足行业卫生性要求，便于推广应用。


综上所述，纸尿裤的异味控制与消臭技术正朝着异味评价标准化、消臭机理协同化（物理吸附+化学中和+生物抑制）、功能释放缓释化（微胶囊/胶囊芯体）、以及材料功能一体化（消臭型SAP/除味布料）的方向深度演进，旨在为消费者提供更干爽、更清新、更长效的穿戴体验。
