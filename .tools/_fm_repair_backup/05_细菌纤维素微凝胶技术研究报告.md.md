# 细菌纤维素微凝胶技术研究报告

报告日期: 2026年4月

## 一、主要技术原理

### 1.1 微凝胶定义与特性

微凝胶(Microgel)是由生物聚合物分子通过交联作用构成的具有三维网络结构的胶体粒子，粒径通常在100nm-100μm。

BC微凝胶核心特性:
| 特性 | 参数 | 优势 |
|-----|------|------|
| 粒径 | 1-10μm(可调) | 易于分散，稳定性好 |
| 比表面积 | 高 | 负载能力强 |
| 含水率 | 70-95% | 保湿性能好 |
| 生物相容性 | 优异 | 适合医药应用 |
| 可降解性 | 完全降解 | 环境友好 |
|  stimuli响应 | pH/温度敏感 | 可控释放 |

### 1.2 微凝胶形成机理

交联方式:
- 共价交联: 化学交联剂形成稳定共价键
- 离子交联: 离子键合形成可逆网络
- 氢键交联: 分子间氢键作用
- 疏水相互作用: 疏水基团聚集

BC微凝胶特点:
- 以细菌纤维素为骨架材料
- 结合壳聚糖、海藻酸钠等功能材料
- 负载活性成分(药物、香精、营养物)

## 二、制备工艺

### 2.1 化学交联法

工艺流程:

BC分散 → 功能材料混合 → 交联剂加入 → 搅拌反应 → 均质处理 → 微凝胶

典型配方:
| 组分 | 比例 | 作用 |
|-----|------|------|
| BC分散液(1%) | 10-30% | 骨架材料 |
| 壳聚糖溶液(1%) | 70-90% | 功能材料 |
| 四硼酸钠(ST) | 1-3% | 交联剂 |
| 活性成分 | 0.1-5% | 负载物 |

工艺参数:
| 参数 | 条件 |
|-----|------|
| 搅拌速度 | 500-1000rpm |
| 反应时间 | 2-12h |
| 均质转速 | 8000-10000rpm |
| 均质时间 | 2-5min |

### 2.2 阳离子改性法

专利工艺示例:

BC分散(4800r/min, 15s) → NaOH溶液(25%)混合 → 室温搅拌1h
→ 加入2,3-环氧丙基三甲基氯化铵 → 室温搅拌30min
→ 62°C搅拌7h → 水洗至中性 → 阳离子微凝胶

BC与改性剂比例: 1:3.5(质量比)

负载ε-聚赖氨酸(PL)的BC/壳聚糖微凝胶:
