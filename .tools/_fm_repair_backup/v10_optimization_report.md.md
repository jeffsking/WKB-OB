## 2. Phase 0.1：注入区宽度校准

### 2.1 目的

确定合理的注入区宽度（inj_frac），使模拟条件接近真实尿液接触面积（婴儿排尿时液体集中在芯体中部，而非全宽分布）。

### 2.2 方法

- 扫描 inj_frac = 0.20 / 0.30 / 0.40（对应宽度 180 / 270 / 360 mm）
- 对比指标：SAP 利用率 (ΣM_abs / ΣM_eq)、MD 方向扩散比、质量误差
- SAP 模式：Flory-Rehner (Q_eq ≈ 26.6 g/g)
### 2.3 结果

|||||||
|---|---|---|---|---|---|
|0.20|180|13|3.6|1.4|0.00|
|0.30|270|19|5.3|0.9|0.00|
|0.40|360|25|6.9|0.4|0.00|


### 2.4 结论与建议

- ✅ inj_frac=0.20：最真实（尿液接触面积约 180 mm），但 SAP 利用率偏低 (3.6%)
- ✅ inj_frac=0.30：平衡选择，SAP 利用率 5.3%，MD 扩散 %
- ⚠️ inj_frac=0.40：全宽注入，过高估计 SAP 初始利用率，不推荐
- → 推荐值：inj_frac = 0.30（已设为 v10 默认）
## 3. Phase 2：Flory-Rehner SAP 热力学模型

### 3.1 目的

用热力学平衡模型替代经验吸收公式，提升 SAP 吸收预测精度，支持盐浓度（离子强度）依赖性。

### 3.2 Flory-Rehner 理论

渗透压平衡条件：π_osm = P_cap

π_mix = -RT · (1/v_polymer) · (φ_p + χ·φ_p²)    [混合熵]
π_ion = -RT · (2·C_salt) · φ_p^(1/3)             [离子梯度，Donnan 平衡]
π_elastic = -RT · ν_e · (φ_p^(1/3) - φ_p/2)      [网络弹性，注意负号]
Q_eq = 1/φ_p - 1                                   [溶胀比，g 液体/g 干 SAP]

### 3.3 参数设置 (0.15M NaCl)

||||
|---|---|---|
|交联密度 (1/m³)|ν_e|300|
|Huggins 参数|χ|0.55|
|聚合物比容 (m³/mol)|v_polymer|1×10⁻⁴|
|离子强度 (mol/m³)|C_salt|150|
|平衡溶胀比 (g/g)|Q_eq|26.6|


### 3.4 三种 SAP 模式对比

|||||||
|---|---|---|---|---|---|
|Legacy (Q=1)|1.0|480|15119.5|100.0|❌ 严重超吸收，误差极大|
|Empirical (Q≈21)|21.2|205|0.00|2.0|✅ 经验公式，质量守恒|
|Flory-Rehner (Q≈27)|26.6|205|0.00|1.6|✅ 热力学平衡，推荐|


### 3.5 关键发现

- Legacy 模式（Q=1）严重低估 SAP 吸收能力，导致液体在表面堆积（V_liq → 15324 mL），物理不合理，建议废弃。
- Empirical 与 Flory-Rehner 模式均满足质量守恒（误差 <0.01 mL）。
- Flory-Rehner 的 Q_eq 比 Empirical 高 ~25%，更符合高吸水性树脂的实际性能。
- ⚠️ 当前 SAP 面密度下，利用率仅 1.6%，说明 SAP 严重过量——这是参数选择问题，非模型 bug。
- 若降低 SAP 面密度至 0.02–0.04 g/cm²，利用率可升至 10–20%，更贴近真实芯体。
## 4. Phase 5：自适应时间步长

### 4.1 目的

在保证数值稳定性的前提下，自动放大时间步长，提升计算效率。

### 4.2 方法

- CFL 条件：dt = CFL · min(dx/|u_x|, dz/|u_z|)，CFL=0.4
- 注入期 (t < t_inj)：液体集中，速度大 → dt 自动缩小（典型值 0.005 s）
- 注入后 (t > t_inj)：液体趋于平衡，速度小 → dt 自动放大（典型值 0.5 s）
- 实现位置：solver_2d.py 的 _compute_dt() 方法
### 4.3 性能对比

|||||
|---|---|---|---|
|注入期步数|~2660|~2660|—|
|注入后步数|~45340|~430|105×|
|总步数|~48000|~1100|44×|
|运行时间 (s)|~20|~0.5|40×|


### 4.4 结论

- ✅ 自适应 dt 工作正常，注入期保持小步长保证精度，注入后自动放大 100×
- ✅ 总步数从 ~48000 降至 ~1100，速度提升约 40×
- ✅ 质量守恒误差与固定步长版本一致（<0.01 mL）
- → 已设为 v10 默认行为
