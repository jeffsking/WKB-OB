#   511 水刺布打样·三视角实验分析

$\bullet$ 数据源: 8种SAP搭配×3套测试协议(盐水/新国标/企标)

$\bullet$ 视角：趋势/结构/异常三 Agent 并行实算

* 核心结论：纯 511 可行但留不住；比率是主导杠杆；N8 单元失效

#   一、整体洞察

$\bullet$ 回渗随时间呈 1-2 个数量级攀升，25/34min 仍无平台——最强趋势

$\bullet$ 纯511综合排名前二，但3/7留存三协议全最差（≈最优2.6×）

$\bullet$ 比率 (5/5 vs 3/7) 为第一主导轴，单指标摆动最大

$\bullet$ 511/951+N8 双封顶(90/60s) $\rightarrow$ 配方整体失效

$\bullet$ 959 有益、610S 中性偏负、N8 无法孤立

#   二、关键趋势

$\bullet$ 吸收速度：全511(3/7)三协议均最快；511/951+N8均最慢且封顶

$\bullet$ 扩散长度：窗口内无平台，33min 仍在涨；排名较协议敏感

$\bullet$ 回渗：单调急升、无饱和，是最强‘随时间恶化’信号

$\bullet$ 跨协议一致性：前二与末段稳健；中段（511/951、930/住友）排名剧烈翻转

#   三、结构与排名

$\bullet$ 综合排名(归一23项): 1.全511(3/7) 2.全511(5/5) 3.511/951+959 4.930/住友...

$\bullet$ 比率效应: 3/7 提吸收/扩散, 但恶化留存 (分裂大效应)

$\bullet$ 添加剂: 959 净正(+0.08); 610S 中性偏负; N8 全混淆不可孤立

$\bullet$ 设计判定：非单因素实验，仅3个干净两两对比（比率/959/610S）

#   四、异常与风险

$\bullet$ CRITICAL×2: 511/951+N8 新国标90s、企标60s 双封顶=吸收未完成

$\bullet$ WARN: 全511(3/7) 新国标回渗5.312g(z+3.11)——可解释的比例效应

* WARN: 全511(5/5) 测试日期错位(6/19 vs 7/16-7/18)$\rightarrow$批次混淆

$\bullet$ INFO: 930/住友 结构性对照离群; 扩散异常全部回溯至 N8 与日期混淆

#   五、假设验证与统计显著性

$\bullet$ H1 纯511可行：部分支持（前二但留存差）

$\bullet$ H2 复配优于纯：混合/弱（仅959有益）

$\bullet$ H3 N8有益：失败/倒置（归因不安全）

$\bullet$ H4 比率影响：强支持（最稳健）

$\bullet$ 统计显著性：无组内重复 $\rightarrow$ 无法做正式检验；以跨协议一致性+留一法 z 为代理

复合排名 Spearman 0.81-0.90 稳定，但单指标排名跨协议翻转 $\rightarrow$ ‘最优配方’ 依赖所选测试法

#   六、局限性与未解释变量

$\bullet$ 无组内重复（无法估计方差/显著性）

$\bullet$ 全511(5/5) 早测1个月$\rightarrow$批次混淆

$\bullet$ 上下层比例未受控；930/住友 不同SAP基

* N8 全混淆+封顶；协议构造不同致绝对值不可跨比

$\bullet$ 未记录：SAP批号/粒径/交联度、布克重、湿度、操作员、凝胶强度
