# 温变湿变材料在纸尿裤设计中应用

的可行性分析报告

技术路线  ·  MVP 方案  ·  供应商策略  ·  推进计划

编制：卫材研发中心（材料与结构创新）

日期：2026-08-04

密级：内部参考（基于公开信息与内部 Brief 整理）

核心结论：GO（条件通过）。建议以"双低后悔 MVP"切入——A 温变指示器（P1）+ B 湿变指示器（P1），不替代现有尿显（WI），先做差异化学习；C 组合版（P2）视单功能验证结果启动。硬性边界：指示器须位于非皮肤接触面，且不得损害吸收性 / 贴合 / 成本 / 皮肤健康 / 可制造性。

温变（Thermochromic）与湿变（Hydrochromic）材料可将纸尿裤内部的"微气候（microclimate）"与"受潮状态"转化为消费者可见的视觉信号，是差异化 RTB（Reason to Believe）的低成本切入点。内部 BCC Thermal Regulation 立项 Brief 已确认：纸尿裤微气候是明确的消费者痛点，"simple visual indicator" 被视为可能的必要组件，且成功边界已被严格定义——必须在 dry 与 wet 两种状态下看到可测的热/湿收益，且不能带来吸收性、贴合、成本、皮肤健康、可制造性的不可接受 trade-off。

市场侧，湿敏指示胶作为最成熟的"湿变"路线，2025 年全球规模约 5.06 亿美元，预计 2032 年达 7.74 亿美元（CAGR 6.28%）；其中婴儿纸尿裤占下游 62.92%，热熔型尿显胶占产品形态 84%。温变材料处于"工业化成熟但卫品应用早期"阶段，主流供应商（CTI、Matsui）已具备 30–37°C 定制温区能力，但 dry-state 热提示的 claim 路径仍需用 bench 数据澄清。

综上，本报告建议：先以两个 low-regret MVP 验证"看得懂、信得过、不会误解"的视觉语言，而非一上来做高精度传感器；供应商以 Tier 1（Matsui / CTI / DaeHyun）主接触，湿变优先走成熟热熔胶路线（Bostik / Henkel / H.B. Fuller）以最小化风险。

机理：微胶囊包裹隐色染料（leuco dye）+ 显色剂 + 溶剂/温控介质。当温度达到阈值时，体系发生电子转移或相变，染料呈色或消色，实现"有色 ↔ 无色"或"颜色互变"。

机理：油墨 / 胶层遇水（尿液）后，树脂溶解或发生结晶 / 络合反应，由无色或黄色变为青 / 蓝色（或不透明 → 透明）。以液体接触 / 液体迁移触发为主，比真正的相对湿度（RH）传感器更现实。尿显胶主流为不可逆变色，以确保一次性使用的准确性。

路线一 · 可逆温变油墨 / 颜料（Thermochromic Ink-Pigment）

路线二 · 热熔湿敏胶（Hot-melt Wetness Glue）—— 84% 主流成熟路线

路线三 · 水性 / 溶剂型尿显油墨（Water / Solvent-based Hydrochromic Ink）

微胶囊封装（Microencapsulation）是上述三条路线的共同 enabling 技术——它决定了色变的稳定性、耐迁移性与印刷适性，也是供应商核心能力的分水岭。

验收：设定温区内稳定可重复变色；70%+ 受访者正确理解"太热 / 太冷 / 舒适"；不引起 curl / blocking / set-off / smudge；40°C / 75%RH 1 周仍可读；与现有 graphics 不冲突。

验收：指定 insult 后稳定显色；消费者能分清与传统 WI 的含义差别；不污染导辊 / 版辊 / 热封；包装内存放 4 周无异常变色；能支持"humidity / wetness exposure cue"叙事而非过度承诺。

两类指示器的量化验收项复用表 1-1 / 表 1-2，并特别强调：dry 与 wet 两种状态均须测试，且须量化 false trigger（误触发）率——这是 MVP 退出的最关键门槛之一。
