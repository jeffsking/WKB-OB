## 一、背景：为什么是 GBP？为什么是 Nuoer？

## 1.1 高 GBP 的战略意义

随着纸尿裤/拉拉裤芯体向薄型化、高 SAP 含量方向演进，凝胶床渗透性（GBP, Gel Bed Permeability） 已从"锦上添花"变为"核心刚需"：

|芯体类型|SAM%|GBP 最低要求|典型产品|
|---|---|---|---|
|SAM/Fluff 中低含量|<40%|无硬性要求|Poise|
|SAM/Fluff 中等含量|40-55%|>7 Darcy|拉美/印度纸尿裤|
|SAM/Fluff 高含量|55-70%|>15 Darcy|Pull-Ups, Depend|
|薄芯（BONNIE/ActivTech-Hybrid）|70-85%|>20 Darcy|BONNIE-P, AT-hybrid|
|无绒毛浆薄芯（Fluffless/CIRRUS）|85-100%|>20 Darcy|Fluffless AT, Complex Core|


关键趋势：在 SAM% >55% 的芯体中，如果 GBP 不足，膨胀后的 SAP 颗粒会变形、相互粘连形成"凝胶阻塞（Gel Blocking）"，导致：

• 第二次/第三次 insults 的液体无法穿透凝胶层到达下层 SAP

• 芯体局部过饱和，其余区域未充分利用

• 最终结果：渗漏——在 SAP 尚未达到饱和容量之前就发生泄漏。

HUT（Home Use Test）数据显示，In-product GBP 与泄漏率呈显著负相关（R² ≈ 0.59-0.63）。

## 1.2 为什么选择 Nuoer？

Nuoer 的定位与独特价值：

技术路线优势：Nuoer 采用釜式反应器（Batch Reactor）+ 先聚合后中和工艺，与 SDP、Satellite CR7 系列同源

• 釜式工艺的核心优势：高分子量骨架、低可萃取物、交联密度精准可控

• 低可萃取物 → 凝胶致密性更好 → 有利于 GBP 的基础

• SAM Training 2025 明确指出："Some vendors (e.g. Nuoer) claim that lower SAM extractables improves skin dryness and microclimate."

成本优势：Nuoer 凭借中国供应链成本结构（低 NaOH 和人工成本），以极具竞争力的价格提供产品；部分垂直整合（现场 AA 生产），供应稳定性有保障

发展势头：SAM Training 2025 评价 Nuoer 为"rapidly gaining in capability and capacity"，已承接 SDP 退出市场后的大部分份额

现有基础不差但存在差距：

## 二、第一部分：可行性分析

## 2.1 技术可行性评估

## 2.1.1 Nuoer 釜式工艺对高 GBP 的天然优势

基于 SAP 技术总结报告的机理分析，釜式工艺具备三项有利于 GBP 的基础：

|工艺特性|对 GBP 的贡献|量化支撑|
|---|---|---|
|不规则多边形颗粒形态|堆积时形成丰富毛细管缝隙 → 液体导流通道|釜式产物经粉碎后天然形成，带式产物偏向片状|
|高分子量骨架|温和低温引发 + 长反应时间 → 长链高分子 → 高弹性回缩力 → 颗粒不易变形塌陷|反应时间 5-10 小时 vs 带式数分钟|
|低可萃取物|充分聚合 → 极高单体转化率 → 未交联低聚物极少 → 凝胶致密性好 → 颗粒独立性强|Nuoer 强调的低 extractables 特性|


结论：Nuoer 的釜式工艺路线在 GBP 上存在底层优势，不需要改变核心聚合工艺，重点在表面处理环节突破。

## 2.1.2 提升 GBP 的三大技术路径及 Nuoer 适配性

路径一：表面交联调控（Surface Crosslinking Optimization）

• 原理：通过优化表面交联剂的种类、用量和热处理工艺，形成更均匀、更坚韧的"壳层"，使颗粒吸水后保持独立形状

• 挑战：过度交联会牺牲 CRC 和 Vortex

• Nuoer 适配性：高 — 釜式产物良好的孔隙结构为表面交联处理提供理想基础

• 预期 GBP 增益：35 → 45-55 Darcy

路径二：离子相互作用涂覆（Ionic Interaction Coating）⭐ 核心推荐路径

• 原理：在表面交联后的颗粒上施加聚胺 + 多价金属盐（Al³⁺/Ca²⁺）复合涂层

• 多价阳离子与 -COO⁻ 基团形成局部离子交联点 → 限制表面过度膨胀

• 电荷梯度引导液体在颗粒间定向传导

• 聚胺与多价盐协同形成抗附聚屏障

• 技术来源：CN101111271A 专利技术路线；SAM Training 2025 明确列为 GBP 增强表面处理手段

• Nuoer 适配性：高 — 需新增涂覆工段，但釜式工艺灵活性高，适合引入新工段

• 预期 GBP 增益：在表面交联基础上再提升 15-30 Darcy

路径三：无机粉末隔离（Inorganic Powder Spacer）

• 原理：后处理添加纳米级 SiO₂ 等不溶性无机粉末，作为物理"隔离珠"防止凝胶贴连

• Nuoer 适配性：中高 — 工艺相对简单，但需评估对粉尘（Dustview）和消费者感知的影响

• 预期 GBP 增益：5-15 Darcy（辅助手段）

推荐技术路线：路径一 + 路径二 复合策略，路径三作为可选辅助。

目标 GBP 分段：

|阶段|GBP 目标 (Darcy)|主要技术手段|
|---|---|---|
|近期（6-12月）|45-55|表面交联优化 + 初步离子涂覆|
|中期（12-24月）|60-80|离子涂覆深度优化 + 交联剂体系升级|
|远期（24-36月）|>80|复合策略成熟 + 新型交联剂/涂覆体系|


## 2.1.3 技术难点的可解性分析

|技术难点|严重程度|可解性|解决思路|
|---|---|---|---|
|GBP↑ 与 CRC↓ 的 Trade-off|高|中高|核-壳梯度设计：内核低交联保 CRC，外壳高交联 + 离子涂覆保 GBP|
|GBP↑ 与 Vortex↑ 的 Trade-off|高|中|湿法研磨 + 发泡创造表面孔隙；粒径向 300-600μm 优化|
|离子涂覆均匀性控制|中|高|精确雾化喷涂 + 分区温控 + 在线监测|
|AUL 是 GBP 的前提条件|中高|中|需同时提升 AUL 至 ≥18 g/g（目前 NR511 仅 14.7-15）|
|多批次一致性|中|中高|釜式工艺批间控制优于连续式，但需强化 QA/QC|


关键认知：SAM Database 的 Trade-off 分析表明——AUL 是 GBP 的必要不充分条件。没有足够的 AUL（凝胶强度），GBP 无从谈起。Nuoer 当前 AUL 在 14-16 g/g 区间，而高 GBP 标杆（BASF 5400/9807、LG LK804ND、SDP SG-N210）的 AUL 均在 18-20 g/g。因此，提升 AUL 是提升 GBP 的前置任务。

|风险类别|具体风险|概率|影响|缓解措施|

|市场接受风险|高 GBP 牌号因 CRC 略低被采购团队拒绝|低中|中|提前用芯体级 HUT 数据证明综合性能优势|

## 五、第四部分：高 GBP SAP 关注要点

## 5.1 技术难点清单

|编号|技术难点|详细描述|应对策略|
|---|---|---|---|
|T1|GBP-CRC Trade-off|提升 GBP 通常需要增加交联密度（尤其是表面交联），这直接损害 CRC。对 NR511，CRC 31 → 28 即触及薄芯底线。|采用核-壳梯度交联结构：内核保持低交联密度保 CRC，外壳渐进提升交联密度保 GBP。严格控制表面交联深度。|
|T2|AUL 瓶颈|NR511 AUL 仅 14.7-15 g/g，而高 GBP 标杆普遍 AUL ≥18 g/g。AUL 不足时，颗粒在压力下变形塌陷，再高的 GBP 也无意义。|① 内交联引入刚性基团交联剂；② 评估无机纳米复合（MMT 蒙脱土）原位掺杂；③ 优化表面交联壳层韧性和厚度。|
|T3|GBP-Vortex Trade-off|更高交联密度的外壳会阻碍水分快速进入颗粒内部，导致 Vortex 时间显著上升（典型：GBP 65 时 Vortex 可达 70s+）。|① 湿法研磨创造表面微裂纹和孔隙；② 发泡引入内部联通孔道；③ 粒径分布向 300-600μm 集中；④ 亲水性表面处理。|
|T4|离子涂覆均匀性|工业规模下，确保每颗 SAP 颗粒表面的离子涂覆层均匀一致是极大的工艺挑战。不均匀 → 性能波动大。|① 双流体精密雾化喷嘴；② 流化床或旋转鼓式涂覆设备；③ 在线近红外（NIR）监测涂覆均匀性。|
|T5|涂覆层耐久性|离子交联（非共价）可能在长期储存、运输振动或高湿度环境中退化，导致 GBP 随时间衰减。|① 老化加速测试（高温高湿）验证长期稳定性；② 评估离子交联 + 共价交联杂化涂覆体系。|
|T6|多批次一致性|釜式工艺批次间可能存在差异，放大到连续化涂覆工段后，需保证批次一致性。|① 建立完善的 SPC 控制图；② CPK ≥1.33 为量产准入门槛。|

## 5.2.2 效益分析

定量效益：

• 进入 70-85% SAM 薄芯市场 → 可替代当前从 BASF（T5400/T5520）或 Evonik（4400/5660）采购的高 GBP 牌号

• 若 Nuoer 能提供 GBP ≥50 的产品且成本优势保持 10-15%，将具有极强竞争力

定性效益：

• 从"快速跟随者"向"创新引领者"转变，提升 Nuoer 在 KC 供应商矩阵中从 "Core" 向 "Strategic" 层级跃迁

• 补齐产品组合中高端牌号的空白，形成 N8（高容量）→ NR511（均衡）→ NR-GBP-H（高渗透）的完整梯队

• 增强在 KC 全球供应链中的不可替代性

## 7.3 四指标 Trade-off 原理速查

|Trade-off 关系|机理|优化路径|
|---|---|---|
|CRC ↑ ↔ GBP ↓|高 CRC 需低交联密度 → 颗粒过软，易变形堵塞通道|核-壳梯度交联|
|GBP ↑ ↔ Vortex ↑|高交联外壳阻碍水分进入|表面造孔 + 发泡 + 粒径优化|
|AUL ↑ ↔ CRC ↓|高 AUL 需高交联密度|非均匀交联（表面高、芯部低）|
|GBP ↑ 需 AUL ↑|凝胶强度是渗透性的前置条件|AUL ≥18 是 GBP ≥50 的基础|
