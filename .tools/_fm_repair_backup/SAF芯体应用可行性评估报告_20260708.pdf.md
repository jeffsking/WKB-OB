#   一、SAF技术概述

#   1.1 什么是SAF?

SAF™ (Super Absorbent Fibre, 超吸水性纤维) 由英国Technical Absorbents Ltd (TAL) 开发并拥有专利，是一种高技术含量、质地柔软的短纤维。与传统的高分子吸水树脂 (SAP) 不同，SAF以纤维形态存在，而非粉末或颗粒状。

核心原理：SAF的分子结构与SAP类似（聚丙烯酸钠型交联网络），但通过专有的聚合物共混和纺丝工艺制成纤维。其圆柱形纤维形态带来了更高的表面积/芯体比（high core to surface ratio），从而实现更快速的液体吸收。

#   1.3 SAF四大生产工艺路线回顾

根据知识库中《高吸水纤维的生产工艺》笔记，SAF及其类似产品可通过以下四种工艺路线制备：

|工艺路线|关键技术特点|后处理方式|吸水性能|代表产品|
|---|---|---|---|---|
|干-湿法纺丝|PVA/聚丙烯酸体系 + 丙酮凝固浴|热拉伸 + 热交联|较高|实验室级|
|干法纺丝|溶液一步聚合 + 直接纺丝|热交联|较高|接近TAL的SAFT™|
|超支化结构|天然纤维酯化 + 支化接枝|离子交换 + 热处理|≥360 g/g|研究阶段 (实验室)|
|碱化醚化法|纤维素短纤维直接化学改性|强制循环传质|60~100 g/g|可降解纤维级|


Technical Absorbents of SAF™采用的是类似于干法纺丝的专有工艺——丙烯酸衍生 → 专有聚合物共混 → 水基工艺挤出 → 热风干燥 → 固化交联 → 控制吸收度。该工艺已经过20+年的工业化验证。

#   3.3 SAF芯体性能优势分析

#   □优势一:无凝胶阻塞(No Gel Blocking)

SAF以纤维形态存在于芯体中，吸水膨胀后依然保持纤维间的毛细通道，液体可以持续通过。而SAP颗粒吸水后形成凝胶块，堵塞液体通道——这是传统SAP芯体最突出的问题之一。

#   □ 优势二：吸收速度快

SAF的圆柱形纤维形态提供了更大的表面积（high core to surface ratio），液体可通过毛细作用快速进入纤维内部。实测SAF纤维在15分钟内即可达到最大溶胀能力（47-57 g/g盐水），而等量SAP在相同条件下往往需要更长时间。

#   优势三：柔软性和透气性

SAF是纤维形态，比SAP粉末更柔软，且与木浆混合后形成均质结构，不产生SAP颗粒的"颗粒感"或"凝胶块"的不适感。这是高端卫生巾/失禁产品的重要卖点。

#   □ 优势四：无粉尘问题

SAF以纤维形态存在，加工时不会产生SAP粉末飞扬的问题——这在高速生产线上意味着更低的设备维护成本和更好的工作环境。

#   □优势五：纤维缠结结构

SAF纤维之间可以形成物理缠结，在芯体中不易迁移，解决了SAP在芯体中"迁移"（SAP Migration）的问题——特别是在湿态下SAP颗粒向芯体边缘移动导致吸收不均的问题。

#   3.4 SAF芯体性能劣势分析

#   □劣势一：盐水溶胀容量低于SAP

以纸尿裤用高端SAP为例：

· 主流SAP (如BASF 2320)：CRC 32-38 g/g (0.9%盐水)

· SAF最高 (112/52/10) : 57 g/g (0.9%盐水)

关键差异：SAF的盐水自由溶胀在数值上与SAP相当甚至略高（47-57 vs 32-38）。但CRC（离心保留容量）测试方法为SAP设计，SAF可能无法完全等效。此外，SAF在加压下的保液能力（AUL指标）尚未获得与SAP直接对比的数据。

#   □劣势二：加压吸收（AUL）数据不完整

SAF官网仅提供"15分钟自由溶胀"数据，缺乏与SAP测试标准对准的AUL (0.3/0.9 psi载荷下吸收量) 和 GBP/SFC (凝胶床渗透性) 数据。这对于纸尿裤芯体设计来说是重要的性能基准——尤其是在婴儿穿戴和受压状态下的表现。

#   □劣势三：供应链单一

全球可商业供应的SAF基本上只有Technical Absorbents Ltd一家 (Main S.p.A.使用的SAF很可能也来自TAL)。单一供应源意味着：

· 价格谈判空间有限

· 供应中断风险集中

· 交货周期受限于英国产能

#   □ 劣势四：成本预期高于SAP

SAF作为特种工程纤维，其制造成本显著高于大规模工业化的SAP。目前SAP国内市场均价约1.38万元/吨（SAP行业数据，2024年）。SAF虽无公开报价，但保守估计在3-8万元/吨之间（基于特种纤维行业对标估算）。

|保液能力|高——CRC 32-38 g/g, AUL 22-28 g/g|中高——盐水溶胀47-57g/g但AUL数据不完整|□□ 待验证|
|加压吸收|优异——有成熟的表面交联技术增强AUL|有潜力但数据不完整|□□ 待验证|

|可降解性|传统SAP不可降解|可水洗/可重复使用|□ SAF环保优势|
|食品级认证|部分有|已有FDA和EFSA批准|□□ 基本持平|


#   5.3综合评价

SAF的核心竞争力不在于替代SAP的高容量保液能力，而在于：

1. 吸收速度——比SAP快数倍

2.抗凝胶阻塞——解决传统SAP芯体的核心痛点

3.抗迁移——纤维形态确保芯体均一性

4. 无粉尘——改善生产环境和产品质量

SAF最有效的应用场景是与SAP协同使用，而非完全替代SAP。
