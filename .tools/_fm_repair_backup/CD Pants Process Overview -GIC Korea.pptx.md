#   CD PANTS MAIN PROCESS SUMMARY

#   1. Fluff forming process

1) Pulp fiberization

2) SAM system (SAM ratio)

3) SAM/Fluff mixing @forming chamber

4) Pad formation(w/wo empty channel)

#   2. Insert combining process (with absorbent core)

1) Surge/Liner lamination w/wo embossing with pad

2) Flap/Out cover lamination with pad

3) Flap folding while flap/leg elastic lamination with flap

4) Insert cut off and insert applicator

#   3. Wait panel combining process (with insert)

1) Inside/Outside panel material and panel elastic lamination

2) Panel elastic chopping

3) Panel slitting

4) Insert to Panel lamination

5) Panel folding

6) Panel sealing

7) Final cut off

#   4. Packaging process

1) Using Optima packaging machine
