# Wilhelmy 湿附力法

> 📌 **Page completed 2026-09-30** from 2 citing sources. All figures traced to their source pages. Anything not evidenced is marked `[待补]`.

## Definition 定义

A wetting-force measurement method forming the first-principles tier of absorbent product interface-energy testing. 定义待补（引用来源未给出明确定义）。中文：通过测量薄片浸入液体时的湿附力求接触角与表面能的界面表征方法。

## Key Parameters and Data 关键参数与数据

| Parameter 参数 | Value 数值 | Source 来源 |
|---|---|---|
| Wetting force equation | F_w = γ_lv · P · cos θ | （源：[[Absorbent Product Testing]]） |
| Work of adhesion | W_A = γ_sv(1 + cos θ) | （源：[[Absorbent Product Testing]]） |
| Outputs | advancing/receding contact angles, wetting index WI, Hysteresis = W_AR/W_AA, surface energy (dispersion/polar/total) | （源：[[Absorbent Product Testing]]） |

## Method / Mechanism 方法 / 机理

Positioned in the three-tier testing philosophy (constituent material → 2D structure/web/sheet → assembled product) as the interface-energy first-principles tool for the material tier（源：[[Absorbent Product Testing]]）.

## Hygiene Relevance 卫材关联

Wilhelmy-derived contact angle / wetting index data decide whether a fibre or web can be wetted effectively at all — the material-selection precondition for absorbent structures（源：[[Absorbent Product Testing]]）.
