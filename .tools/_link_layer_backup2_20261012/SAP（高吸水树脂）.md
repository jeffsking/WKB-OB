## Definition 定义

SAP = Superabsorbent Polymer（高吸水树脂）：一类能吸收并**在压力下保留**自身质量数十倍以上水溶液的交联高分子材料，
在纸尿裤/卫生用品中承担**最终锁液与保水**职能，与 [[绒毛浆（Fluff Pulp）]]（导流与结构）和 [[ADL（导流层）]]（临时储液与铺展）分工不同。

## 追加：行业产能格局与工艺/成本结构（2026-09-29 追加 · 来源：生物基SAP-SAF技术研究报告 2026-04 · C 级二手口径）

> ⚠️ 以下产能/份额/价格均为**二手市场口径（C 级）**，仅用于建立量级与结构认知，**不得用于采购谈判或成本模型**。

- **成本结构由单一原料主导**：石油基 SAP 原料成本中 **丙烯酸占 50–60%**，液碱 15–20%、交联剂 5–8%、引发剂 2–3%、溶剂/分散剂 5–10%。→ **降本只有两条路：动丙烯酸（生物基单体）或动用量（芯体设计）**。
- **工艺三分**：**反相悬浮聚合**（颗粒均匀、吸水率高；日本触媒/住友精化/三大雅）｜**水溶液聚合**（简单、成本低；巴斯夫/赢创）｜**反相乳液聚合**（产率高、反应快）。
- **反相悬浮关键工艺窗口（B 级）**：油水比 3–5:1；中和度 70–80%；聚合 70–80 °C / 2–4 h / 引发剂 0.1–0.5%；共沸脱水 80–110 °C；**筛分粒度 150–850 µm**。
- **表面交联（通用手段）**：多元醇/碳酸酯/噁唑啉 + **喷雾涂覆 + 热处理 120–180 °C**；作用是**提凝胶强度、减少凝胶结块**（即 GBP 提升的主工艺路径）。
- **行业 KPI 典型值（通用口径，非牌号选型）**：纯水 **500–1000 g/g**、0.9% NaCl **50–80 g/g**、保水 **>90%**（离心法）、涡旋 **30–120 s**、凝胶强度 **20–50 kPa**（流变仪）。
- **全球格局**：CR10 产能占比 **>85%**；日本触媒 60+ 万吨（~20%）｜巴斯夫 50+（~15%）｜赢创 40+（~12%，**业务已出售给 ICIG**）｜住友精化 30+（~10%）｜LG 化学 25+（~8%）｜三大雅 23（~8%）。
- **中国格局（2024）**：总产能 **>150 万吨/年**，但**高端 SAP 仍依赖进口约 30%**；水溶液聚合为国内主流（上海华谊 20、卫星化学 15、邦丽达 14、诺尔 10、广西华谊 10、万华 6–8），反相悬浮仅三大雅南通 23 与日触张家港 5。
- **单件用量基准（卫生用品）**：婴儿纸尿裤 **8–15 g**｜成人失禁 **15–30 g**｜卫生巾 **3–8 g**｜护理床垫 **20–50 g**。与 [[Baby Diaper Absorbent Core Design（五层无浆 SAP 芯体设计方案与仿真 KPI）]] 的 14.0 g 设计值量级一致。
- 来源页 [[生物基SAP-SAF技术研究报告（2026-04 · 生物基 SAP 路线·产业化与成本结构）]]；牌号口径见 [[SAP性能指标（CRC AUL GBP Vortex）]]。

## 追加：水溶液聚合的工业化流程（2026-09-29 追加 · 来源：蓝湾工厂工艺讲解）

> 来源：[[SAP Production Process Walkthrough — Polymerisation, Grinding & Surface Treatment（I sap生产流程介绍）]]（供应商工厂会议室工艺讲解 + 现场参观 ASR 转写，日期 [待验证]）。本批只**追加**，不修改既有结论。
> 价值：上文记录的是**反相悬浮聚合**的工艺窗口（二手 C 级口径）；本批补的是**水溶液聚合**（国内主流路线）在**真实产线**上的工序与设备，二者互补。

**六段主流程（本批新增）：**

**原材料准备 → 混合（静态混合器 + 混合罐：搅拌 + 降温）→ 聚合反应（水状 → 凝胶）→ 干燥（滚筒热风）→ 研磨筛分 → 后处理（表面交联）→ 包装**

| 工序 | 关键做法 | 数值 / 备注 |
| --- | --- | --- |
| 聚合 | **吹氮排空**后聚合；**低温聚合 + 后中和**（先聚合、后加碱） | 先中和会大量放热、影响内部结构、反应过快、易有**溶出物** |
| 连续化 | **小罐慢跑**，靠 **10 个聚合罐**轮转 | 聚合本身是间歇的，靠罐数换连续 |
| 造粒干燥 | 造粒机造粒 → 滚筒**燃烧热风**烘干（翻滚如糖炒栗子） | **进风温度最高 500 ℃** |
| 除铁 | 滚筒尾部**强磁磁选** | 设备运行产生铁屑 |
| 研磨 | **全干态**闭环：摇摆筛 + 磨机，粗料回粉碎机再磨至目标粒径 | 固含约 **97%**；湿态在摇摆筛里筛不出 |
| 筛分三分类 | **颗粒（回磨）/ 合格（进半成品罐）/ 细粉（回胶体二次混合）** | 色选机剔除黑点与脏料 |
| 后处理 | **上层加表面交联剂**；**下层加抗静电、抗黄变、抑菌类原料**（离子交换涂布） | **约 130 ℃** 烘干使表面交联更彻底 |
| 混料 | **高速混合机 → 膨料机 → 双轴搅拌**，**每台设备各加一种原料**（分步加料更均匀） | 高速混合机内近百个小桨叶片 |
| 计量连锁 | **绞龙只做计量**，与引发剂添加量 **DCS 连锁**（按吨数比例自动给料） | — |
| 固含 | 进入后处理前约 **96%** → 加液体引发剂后表面带水、固含下降 → **二次烘干** | 保证成品固含 |
| 粒径 | 成品 **300–600 μm**；筛网目数固定，**30 目以下合格、30–50 目也可以** | 半成品粒径**刻意偏大**（后处理三次搅拌会破碎） |
| 包装 | **色选机 → 磁选器 → 过筛防结块 → 精检仪（金属，报警即剔除隔离）** | 四道 |

**两条可迁移的认知（本批新增）：**

1. **水溶液聚合的"连续性"是靠罐数换来的** —— 聚合反应本身是间歇（小罐慢跑），用 **10 个聚合罐**轮转上料才实现整线连续；这与"低温聚合 + 后中和"绑定：低温是为控制放热与内部结构，代价是反应慢、必须多罐并行。
2. **粒径是"倒推设计"的** —— 后处理段要经历三次搅拌与摩擦破碎，因此**半成品粒径必须刻意做大**，成品才会落在目标 PSD。只规定成品粒径而不倒推半成品粒径，是 PSD 失控的常见原因。

**过程控制的真实水平（本批新增，对来料一致性评估直接相关）：**

- **开环控制**：**无在线粒径监测**，靠**每小时抽样检测**（成品 / 半成品 / 包装）+ 经验控制 PSD。
- 供应商的辩护理由是**筛网目数固定** → 粒度基本不波动；本方当场追问"如何确保进成品罐时 PSD 最优"，**未获实质答复**。
- → 评估供应商来料时，**PSD 一致性的保证方式是抽样而非在线闭环**，这是一个需要显式管理的风险点。

**添加剂的一个实例（本批新增）：**

- **二氧化硅（SiO₂）已在使用**，加入点在高速混料机加液处；目的是**改善颗粒流动性（flow rate）** —— 不加则颗粒粘连、流动性差、**影响吸水性**。
- → 无机粉末在 SAP 后处理段不是"噱头"，而是**流动性与吸水性的功能性添加剂**；这与 [[SAP 表面包覆（SAP Particle Surface Coating）]] 的"无机粉末撒粉提 GBP"是同一机理的不同表述。

✅ **验证记录（2026-09-29）**：以上为**供应商现场讲解口径**，无第三方验证；温度、固含（96% vs 97%）、目数（30 / 30–50 目）与粒径（300–600 μm）的**对应关系与单位均未获澄清** [待验证]；"先聚合后中和"为本页据上下文还原，供应商未使用该术语 [待验证]。参见 [[诺尔（Nuoer）]]、[[SAP 表面包覆（SAP Particle Surface Coating）]]、[[SAP性能指标（CRC AUL GBP Vortex）]]。

> ✅ 验证（2026-09-29，来源 [[Absorbent System Overview（K-C 吸收系统概览培训·2021-02）]]）：K-C 2021 内部培训口径与本页既有结论**方向一致**——容量 30–40 g/g（0.9% saline，培训口径；本页既有口径为 50–80 g/g 茶袋法，测试法不同、并列不矛盾）；部分中和聚丙烯酸颗粒、交联度控形变、表面处理改善渗透/流动/吸入速度均吻合。培训补充口径：SAM 为 Personal Care **单项金额最大**原材料（800–1000 kg 袋装、湿度敏感）；讲义供应商名单 Evonik、BASF、**San-Dia**、LG、**Danson**——后两家与本库 [[Sanyo Chemical · SDP Global（三洋化成工业）]]、[[宜兴丹森科技有限公司]] 的对应关系 [待验证]。
