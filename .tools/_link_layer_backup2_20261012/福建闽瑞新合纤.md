## 追加：Meeting Minutes 批（2026-09-29 追加 · 主力供应商份额与纤维开发的量产门槛）

> 来源：[[P&G–KC Industry Review and Xinweisheng Supplier Capability Visit（与宝洁交流及行业情况）]]（供应商交流会 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**在下游客户处的份额与定位（本批新增）：**

- 热风非织造布集团新维盛明确：**闽瑞为其主力纤维供应商，占其采购约 50%**；其余为江南高纤系 + 日本特种纤维 + 少量其他。
- 选择标准两条：**有创新能力** + **持续供应的稳定性**（"刚开始样品还行，一到持续供应就惨不忍睹"的供应商被剔除）。
- 合作领域：与闽瑞在**纺丝（纤维）层面的创新**上有直接合作；并与浙大（高分子）、东华（纺织）分别对接上下游研究。

**纤维开发的量产门槛（本批新增，重要）：**

| Item 项目 | Value 数值 | Note 备注 |
| --- | --- | --- |
| 纤维一次投料量 | **数十吨** | 中途停线需停管道，切换成本"不得了" |
| 起积量门槛 | **20–30 吨** | 低于此"做不下去" |
| 纤维最佳使用期 | **一年内** | 一年半后需报废；有 20 吨纤维用一年半后报废的实际案例 |
| 小单替代路径 | **不动纤维，改在涂布/后整理段加功能**，共用现有牌号纤维 | 可摊薄纤维成本、避免起积量问题 |

- 实践含义：**功能性小单品不应走"开发新纤维"路线**，而应在后整理段实现，并尽量复用已量产的牌号纤维。

✅ **验证记录（2026-09-29）**：50% 份额为**下游客户自述口径**，非闽瑞官方披露；起积量与报废案例为客户经验值，标 `[待验证]`。参见 [[新维盛集团（Xinweisheng Group）]]、[[江南高纤]]、[[热风粘合无纺布]]。

## 追加：Meeting Minutes 批 2（2026-09-29 追加 · 双组分产线工艺、截面能力边界与试验位能力）

> 来源：[[Bicomponent Fibre Production & Performance Review — Spinneret, Crimp & Functional Masterbatch（复合纤维生产及性能探讨）]]（ES 双组分纤维供应商工厂交流 ASR 转写，会议日期 [待验证]）。
> ⚠️ **身份提示**：本次转写中供应商名读作「敏锐 / 美锐」，并自述"**细旦纤维是敏锐的一个优势**"，主业为 ES 双组分纤维、起订量 ≥30 吨 —— 与本页面主体的画像一致，故归入本页；但**名称未经确证**，标 [待验证]。本批只**追加**，不修改既有结论。

**产线与工艺能力（本批新增）：**

| Item 项目 | 内容 | Note 备注 |
| --- | --- | --- |
| 工艺路线 | **两步法（long spin）**：螺杆 → 喷丝板汇合 → 三分 → 冷却 → 上油 → 落桶 → 牵伸 → 卷曲 → 烘干 → 切断打包 | 一步法成本更低但停线风险大，未采用 |
| 纤度能力 | **1–6 dtex**；供应商表述"最细约 0.4" [待验证] | 自述**细旦是优势** |
| 截面能力 | 可商业化：**同心 / 偏心 / 中空**；做不了：**瓣形（桔瓣）、海岛型** | 海岛需溶剂/水溶"海"的后道改造 |
| 实验性截面 | 十字形、三叶形等约 **十几幅**喷丝板 | 非商业化 |
| 起订量 | **≥30 吨** | 切换料前后废料可能比常规供料还多 |
| 试验能力 | **五楼小型纤维试验线** + 生产线上的**单纺位试验位**（可换喷丝板、直接用生产线原料） | 关键：试验位与量产同原料 → 放大风险低 |

**研发方向（本批新增）：**

- 相对成熟/商业化：**中空纤网**、**偏心纤维**（持续优化使其更蓬松）、**抑菌**。
- 进行中：**消臭**（母粒型：先吸附后反应；活性炭：纯物理吸附，均加在 **PE 皮层**）、粗旦（手感方向）。
- 基础研究合作：**东华大学**（基础原料/改性粒子、偏基础理论）、另有**中科院**保密项目。
- 基础原料清单：HDPE、PP、Co-PP、Co-PA、PET、LLDPE、PBS、PLA、PGA、PBAT、二氧化碳基聚合物。

**与本方（K-C）的协作机制（本批新增）：**

- 本方希望**早期介入**其前沿合作方向，以便在终端产品上做技术植入 → 供应商需先确认**保密协议 scope**，尚未回复。
- 建立了**反向提案机制**：供应商可就其专业方向（如变色 / 温感 / 湿感 / 相变）主动向本方提案，本方"在职责范围内比较 open"。

✅ **验证记录（2026-09-29）**：全部为供应商自述 + ASR 音转，供应商名称与"0.4 旦"等数值**未经确证**；引述前须回溯原文。参见 [[皮芯复合纤维]]、[[并列复合自卷曲纤维]]、[[ADL（导流层）]]、[[Mineral-Powder Functional Masterbatch（矿物粉功能母粒平台）]]。
