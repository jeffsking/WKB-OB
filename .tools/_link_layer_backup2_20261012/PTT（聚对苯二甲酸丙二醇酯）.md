# PTT（聚对苯二甲酸丙二醇酯）

> **Definition 定义**：**PTT（polytrimethylene terephthalate，聚对苯二甲酸丙二醇酯）** 是由 **PDO（1,3-丙二醇）** 与 PTA/DMT 缩聚得到的聚酯。在卫材领域，它的价值集中在两点：**与 PET 并列复合后获得自卷曲弹性**（见 [[并列复合自卷曲纤维]]），以及**在同等性能下降低克重**。

## Mechanism and value path 机理与价值路径

1. **单体路径决定成本**：PDO 可由**石油基**或**生物基（非粮粗甘油转化）**路线获得；生物基/非粮路线是 PTT 成本竞争力的主要来源（见 [[恒碳（Hengtan）]]）。
2. **并列复合获弹**：PTT 与 PET 收缩率不同，沿轴向并排纺出后受热自发形成三维螺旋卷曲——PTT 在卫材纤维配方中的主流形态是**并列（side-by-side）短纤维**，而非单组分。
3. **降克重 + 增厚度的组合**：PTT 替代 PET 可降低克重，同时在**同等克重下提高厚度**——这两点共同指向"同性能更轻"或"同重量更蓬松"。
4. **弹簧填充功能**：在尿裤**中间层**用作**弹簧填充**（hold 住 SAP），与 [[毛细梯度设计]]、[[SAP错峰膨胀]] 的孔隙保持逻辑同向。

## Lessons learned 经验教训

> ✅ 验证（2026-09-29，来源 [[优化 REL 五纤维配方与穿透热风粘合工艺模拟]]、[[EM Supplier Meetings 2026-06-02（紫华、恒碳、格菲林、Huayi 四场技术交流）]]）：两份来源一致把 PTT/PET 并列纤维定位为**回弹/蓬松组件**而非粘合组件，且都把**厚度**（而非伸长率）列为首要受体指标。本页结论与既有 [[并列复合自卷曲纤维]] 页一致。

- **要点**：PTT 的采购评估不能只看"每吨价格"——**降克重 5–6%** 会把成本比较的单位从元/吨变成元/片 `[待验证]`。
- **待补 `[待验证]`**：PTT 的国内产能真实性（供应商自述产线与实际月出货量差距较大）、生物基含量核验与认证口径。
