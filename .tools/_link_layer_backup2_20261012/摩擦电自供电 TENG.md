# 摩擦电自供电 TENG

> 📌 **Page completed 2026-09-30** from 2 citing sources. All figures traced to their source pages. Anything not evidenced is marked `[待补]`.

## Definition 定义

摩擦电自供电（TENG，triboelectric nanogenerator）在本库中作为**无源（自供电）传感器的重要方向**出现——Zhong Lin Wang 综述的自供电传感器对智能纺织品 / 卫生用品传感有直接意义（源：[[Wearable Electronics (National Science Review 2023)]]）。库内在一个器件里把它与**机械变色**耦合，实现单一器件、无需外部电源的双机制读出（源：[[Self-Powered Photonic Sensor CLCE Sandwich]]）。

## Method / Mechanism 方法 / 机理

- **摩擦电响应**：器件在拉伸/接触事件下输出 VOC / ISC / QSC 三通道电信号，无需外部电源（源：[[Self-Powered Photonic Sensor CLCE Sandwich]]）。
- **两大主流形态**：可穿戴电子的两个互补发展方向是**薄膜化（减小一个维度）与纤维化（减小两个维度）**；纤维形态电子器件可水洗数百次（源：[[Wearable Electronics (National Science Review 2023)]]）。

## Hygiene Relevance 卫材关联

- **自供电降低智能穿戴供电成本**：摩擦电输出无需电池，可避开电池与皮肤接触的安全与回收问题（源：[[Self-Powered Photonic Sensor CLCE Sandwich]]）。
- **库内记录的推演（非论文实验结论）**：将 CLCE 层与 SAP 溶胀/芯体膨胀耦合，可使吸水膨胀产生的应变触发变色，作为免染料、免电源的尿湿可视化指示路径；论文未做 SAP/湿敏实验（源：[[Self-Powered Photonic Sensor CLCE Sandwich]]）。
- 与机械变色、结构色、银纳米线柔性电极同列为光子传感器相关概念（源：[[Self-Powered Photonic Sensor CLCE Sandwich]]）。
