# Intake System（摄入系统）

## Definition 定义与系统边界

> 一句话定义：**摄入系统 = 尿裤/护理垫中"负责把液体从皮肤表面带走并往下送、且尽量不让它回来"的那几层**——它不是某一层材料，而是**面层、导流层、转移层、摄入层、包覆层、贴肤面**共同构成的一个**层序系统**。（中文：摄入是**系统属性**，不是材料属性；换一层材料常常改的是系统，而不是指标。）

**权威边界定义**（[[Intake Systems Development Pathway 2023（摄入系统开发通路）]] 原文）：

> **Intake Systems: Liners, Surges, Transfer Layers, Intake Layers, Wrapsheets, Facings**（面层 / 导流层 / 转移层 / 摄入层 / 包覆层 / 贴肤面）

## Mechanism 机理 / 结构拆解

1. **摄入与保持是两件事**：摄入系统负责**快速接纳与向下输运**，保持由芯体（SAP / 绒毛浆）负责。**摄入层本身不"装"液体**——它装得越多，回渗与皮肤湿润风险越高（见 `[[Residual Fluid & Pore Stranding（残液与孔隙滞留）]]`）。
2. **摄入系统的失效有三种形态**：① **来不及**（摄入速度不足 → 漏）；② **送不下去**（层间界面输运受阻 → 滞留）；③ **回得来**（解吸/毛细回送 → 回渗与皮肤过度水合）。三者**对应不同的结构解法**，不可混为一谈。
3. **层序本身是设计变量**：同一材料在不同层序下表现不同。ActivTech Hybrid 体系中**绒毛浆被并入摄入系统**，导致回渗升高——这是"层序改变材料角色"的直接证据（[[Depend Rewet Update 2025-04-04（LUGH 与 GRIFFIN 回渗进展）]]）。
4. **摄入与芯体存在匹配关系**：同一导流层在不同芯体上的档位不同（CT5 在 SAM/Fluff 上最佳，在 AT hybrid 上与 MOJAVE 持平）——见 `[[Resilient Surge（PET 回弹导流层）]]`。**离开芯体谈摄入指标是无效比较。**

## 需求侧驱动：为什么做摄入（Demand Drivers）

| 驱动 | 内容 | 出处 |
|---|---|---|
| **#1 全球未满足需求** | **Rash-Free Skin Health（无疹皮肤健康）**；尿布疹是最大的消费者痛点与**品牌转换触发因素** | [[Global Overview - Intake Workshop（摄入系统研讨会·全球品牌与区域概览）]] |
| 三大需求空间（排序） | **1 预防红疹与刺激 → 2 强化与滋养 → 3 治疗与修复** | 同上 |
| 尿布疹八项成因 | 尿液+粪便混合、**pH 升高**、粪便酶、尿液中刺激物、**皮肤过度水合**、机械应力、潜在皮肤病、来自产品的刺激物 | 同上 |
| 摄入侧两条机理路线 | **"把致疹刺激物挡在皮肤之外"（多兜住污物）** 与 **透气性 = 更多气流 / 更好温感 / 更低湿度** | 同上 |

> ⚠️ **口径提示**：**"皮肤过度水合（skin overhydration）"** 是摄入系统**唯一能直接干预的成因项**——这与 `[[Dryness Measure System（干爽度量三分）]]` 中"干爽焦点从回渗推进到皮肤干爽"的方向一致，但**两者的度量方法不同**，不互推。

- **五大开发领域**：**Affordability / Leakage Protection / Comfortable Wear / Skin Health & Wellness / Sustainability**；
- **14 个议题**，每个统一用「**机会 / 壁垒 / 项目 / TRL 0–5+ 表**」四段式；
- **TRL 5+ 已落地项**：Resilient Surges（GNW、Shalag 等）、MOJAVE、ATACAMA PLUS、CLEANSHIELD/NAXOS/ZUIKO/AC4、Zn0/D-panthenol/lotion 活性物；
- **TRL 0 新立项**：Fluid Distribution (CRO)、BM Fundamentals/Capabilities、Actives Playbook (GADT)。

## Lessons Learned 经验教训

- **教训一（摄入是系统，不是材料）**：换一层材料常常改的是**层序与界面**，而非单一指标。ATH 把绒毛浆并入摄入系统后回渗升高，就是反例。
- **教训二（摄入层不该"装"液体）**：摄入层的价值在于**快速向下送**，装得越多回渗与皮肤湿润风险越高；评估摄入材料时**必须同时看它的"留住量"**。
- **教训三（离开芯体谈摄入无效）**：同一导流层在 SAM/Fluff 与 AT hybrid 上档位不同，**引用摄入指标必须带芯体口径**。
- **教训四（需求侧驱动 ≠ 技术判据）**：**"无疹皮肤健康是全球第一未满足需求"** 是需求判断，**不是可验收的技术指标**；把它转成判据需要**临床可测的终点**（区域表已把 "clinically measured skin health benefit" 列为机会，但**未给方法**）。
- **教训五（区域约束不同，材料路线不能一刀切）**：同样的机会清单，EMEA 受**本地法规**、LAO 受**供应链**、APAC 受**上市速度**约束——**同一材料在不同区域的可行性不同**。

## 追加：摄入系统的战略边界定义与技术组合组织法（2026-09-29 追加 · 来源：2022 Intake Systems Innovation Strategy Workshop Charter）

- **权威边界（2022 战略章程口径）**：**In Scope = Enterprise（Global & KCNA）Adult Care + Baby/Child Care，液体为尿液与稀便（Runny BM）**；**Out of Scope = 女性护理、以及吸收芯体技术（SAM / Fluff / Adhesives / CIRRUS）**。
  - 关键补充：芯体虽被划出界，但章程要求**「consider how these impact the intake systems strategy」** → **摄入系统与芯体是「分域但必须做影响传递」**的关系，不是互不相关。
  - 同样被排除的还有：**战术性材料迁移计划与 glidepath**、**特定项目/区域的技术对比 POV** —— 即摄入系统战略管的是**技术域与机理**，不管具体牌号迁移与区域选型。
- **顶级需求即组织维度**：四大企业级需求为 **Skin Health & Wellness（含 Fresh Protection）、Leakage Protection、Comfortable Wear、Natural & Sustainable**；技术组合**按 benefit area 组织**（共 5 个利益空间），**不按技术门类组织** → 评估一项摄入技术时，应回答「它服务于哪个 benefit」，而非「它属于哪类材料」。
- **双轮驱动**：① 需求侧按 **benefit / sub-benefit** 逐层细化；② 供给侧识别 **portfolio gap**，且明确 gap 可能要靠 **new technology development 或 fundamentals projects（基础机理项目）**来补——**不是所有缺口都能靠换材料解决**。
- **组合来源三支**：现有组合由 **M2M** + **其他 GNW & GRE 技术** + **其他 Global 技术**构成；并要求识别 **GNW / GRE / GADT / 全球**之间的**联合协作重点**。
- **术语尚未统一（重要）**：研讨会开场即把 **「What is the Intake System? 摄入系统到底是什么」**与**「其它吸收策略对它的影响是什么」**列为待澄清问题 → **「摄入系统」在跨职能/跨区域间没有统一定义**，本页的定义应视为**当前工作定义**，引用时须注明口径。

## 追加：研讨会成果落地（2026-09-29 追加 · 来源：Stakeholder Report-Out.pptx）

> ✅ Verification（2026-09-29，source 来源 [[Stakeholder Report-Out.pptx]]）：2022-08 研讨会（即上方章程所在活动，"rebuilt from the ground up"）的**成果侧数据**：按 TRL 定义技术组合、逐 sub-benefit 识别缺口、**缺口优先级 17 → 4**。Top 4 缺口：① Active Ingredients——往摄入材料施加活性成分的最优方式（Go Do）；② Less Irritants on Skin——**Runny BM foundations**（BM 沾肤机理与测试方法开发，Go Do）；③ Fluid Distribution（Prioritize）；④ Skin Dryness——**zoned treated materials** 分区处理材料（Connect）。行动项含请求 surfactant SME、No Feel 关键驱动优先级化、优化 liner & surge 与 zoned 方案连接其他 IMF 项目。技术组合按 benefit/sub-benefit 组织的上方判断由此获得成果侧实证。
