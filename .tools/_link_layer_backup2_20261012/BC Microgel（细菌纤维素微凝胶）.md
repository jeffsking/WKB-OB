# BC Microgel（细菌纤维素微凝胶）

> 一句话定义 One-line definition：以细菌纤维素（BC）为骨架、经四种交联方式（共价/离子/氢键/疏水）构筑的 1-10 μm 三维网络胶体粒子，含水率 70-95%、pH/温度双刺激响应，用于活性成分负载与缓释——化妆品已商业化，医药中试/临床。

## Definition 定义
微凝胶（microgel）：生物聚合物分子经交联构成的三维网络结构胶体粒子，粒径通常 100 nm–100 μm。BC 微凝胶以细菌纤维素为骨架材料，常复合壳聚糖、海藻酸钠等功能材料，负载药物、香精、营养物等活性成分。

## Key Parameters 关键参数表（关键参数表）

| 特性 | 参数 |
|---|---|
| 粒径 | 1-10 μm（可调） |
| 含水率 | 70-95% |
| 刺激响应 | pH / 温度敏感（可控释放） |
| 生物相容性 / 可降解性 | 优异 / 完全降解 |

**载药微凝胶最优条件**（BC:壳聚糖 10:90 v/v、四硼酸钠 2%、ε-聚赖氨酸 0.4 mg/mL、均质 10000 rpm）：包封率 **48.23%**、粒径 1423 nm、PDI 0.25、Zeta 电位 +33.26 mV。

## Process 制备工艺（制备工艺）

| 路线 | 要点 | 产出特点 |
|---|---|---|
| 化学交联法 | BC 分散 + 壳聚糖 + 四硼酸钠（1-3%）交联后均质 | 通用负载 |
| 阳离子改性法 | 25% NaOH + GTMAC（2,3-环氧丙基三甲基氯化铵），62°C 7 h，BC:改性剂 1:3.5 | 阳离子微凝胶 |
| 物理法 | 超声破碎 / 高压均质 / 喷雾干燥 | 粒径均匀 / 连续生产 / 干粉 |

## Cost Structure 成本结构（成本结构）

| 构成 | 占比 |
|---|---|
| BC 原料 | 30-40% |
| 功能材料 | 20-30% |
| 加工 | 20-25% |
| 包装储运（冷链） | 10-15% |

价格锚点：化妆品级原料 **200-500 元/kg**；医药级载药 **1000-5000 元/kg**。

## Industrialization 产业化状态
- **商业化**: 化妆品（精华液、面膜——包埋视黄醇/VC/神经酰胺，高含水量承载精华）。
- **中试/临床**: 医药递送（口服缓释、透皮、注射微球）；抗菌材料（负载 ε-聚赖氨酸/银离子，对大肠杆菌、金黄色葡萄球菌有效）。
- **研发**: 食品（益生菌包埋）、农业（缓释肥料、种子包衣）。
- **四大挑战**: 批量化生产、粒径分布控制、长期储存稳定性、成本。

## Supply Chain 供应与科研（供应与科研）
- 原料供应商：桂林奇宏科技（BC 分散液）、南京天禄纳米（BC 原料）。
- 科研：南京工业大学（ε-聚赖氨酸抗菌 BC 微凝胶）、浙江轻工业品质量检验研究院（检测/标准）、中科院（药物载体专利）。

## 与卫材的潜在关联
- **抗菌/除臭载体**：负载抗菌剂或气味抑制剂的微凝胶可与 SAP/无纺布复合，衔接 [[Odor Control Technology Landscape（异味控制技术图谱）]] 的微胶囊路线。
- **吸水口径提示**：BC 吸水 200-1000× 与 [[SAP（高吸水树脂）]] 的 500-1000 g/g（纯水）区间重叠但机制不同，不可直接比价（见 [[细菌纳米纤维素]]）。

## 经验教训 Lessons
- **产业化成熟度梯度明确**：化妆品载体已商业化的核心是"温和工艺 + 高含水/贴合"与高端溢价承受力；医药与卫材应用须先解决批量化与粒径控制。
- **待补 `[待验证]`**：卫材场景的 directly relevant 实测数据（如微凝胶负载除味剂在芯体中的缓释寿命）；供应商实际产能与品质稳定性。
