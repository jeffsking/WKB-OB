# 脱水/干燥工艺族谱（一页纸）——BNC/纤维素水凝胶产业化干燥路线全图



补库动作 1 | 对应短板 A（脱水/干燥工艺族谱残缺）
目的：把"置换后保留功能组分 → 干态 → 复水"这一族补进知识库。此前库内只有"完全干燥"（冷冻干燥/热风/喷雾/微波）与"置换后脱除"（乙醇+超临界、乙醇+TMCS 常压）两条族，导致 PEG 置换方案在库内无分类位置。

## 一、一页纸族谱

三条族：① 完全干燥（直接除水）｜② 置换后脱除（溶剂/CO₂ 置换 → 完全脱除，产物=干态气凝胶/粉）｜③ 置换后保留（功能组分留在干态产物 → 遇水复水） ← 补库核心

## 二、空白缺口（补库即补这里）

- 置换后保留族在库 = 0 条：R10（PEG）在库只有"方向+流程图"（拜科瑞小试中）；R11（甘油）、R12（海藻酸钠封端）全部证据仅来自 web——这是知识库真正的空白格。
- 常压保结构干燥新变体（R8 EMFD、R9 丁醇）在库 = 0 条。
- 可复水干粉定量文献（角质化机理、复水动力学）在库 = 0 条（库内仅"干粉可复融解决 50%+ 没问题"一句口头表述）。
- BNC 各干燥路线每公斤/吨能耗-成本定量对比缺失（web 也仅通用干燥手册值，勿当 BNC 实测值用）。

## 三、拜科瑞场景初判

主判：R10（PEG 置换保留）最适配——拜科瑞已在推小试、宣称节能/低成本/工艺简单可连续化；PEG 低毒（区别于 TMCS 禁用）；干态天然防菌；遇尿即复水；满足"湿态水凝胶无法上 400 m/min 干法线，必须离线做成干态中间体"的现实约束。

必要分流：若目标是 8gsm→5gsm PP/PE 熔融无纺布增强，交付物必须是疏水干粉（R1/R2/R6 干粉 + 非硅烷疏水改性，加量 3–5%、成本 +~2.5 元/kg PP），R10 的复水特性不适用——两条交付形态（PP 熔融干粉 vs 吸收芯干颗粒）应分列立项。
