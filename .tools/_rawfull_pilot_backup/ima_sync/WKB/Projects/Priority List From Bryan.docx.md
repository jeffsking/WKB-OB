# 会议纪要：非织造芯体材料技术讨论

|会议日期|2026/06/09|
|---|---|
|会议主题|非织造芯体（REL/卫生用品）材料选型与结构方案讨论|
|参会人员|Mr. Fike（外籍专家）、Chris Wang 及研发团队|
|会议形式|白板头脑风暴|


## 一、纤维材料配比与规格方案

## 1.1 主纤维体系

|方案|材料组合|配比|规格/特性|备注|
|---|---|---|---|---|
|A|PE/PTT|30/70 (s/s)|155°C 工艺温度|当前基准方案，28% 占比标注|
|B|ES|—|PE/PET 或 PE/PP|双组分热粘合纤维，8000 系列|
|C|CoPET/PET|—|160/240 dtex，115°C 粘合|毛发状纤维（Hairs），用于 Airlaid 体系|
|D|PE/PTT|—|江南供应商方向|6D 规格双向讨论|


## 1.2 纤维截面与丹尼规格演变

|阶段|截面形态|规格|目标/应用|
|---|---|---|---|
|初始|Hollow（中空）→ 4D|—|14% 占比|
|优化|4D → 1D|V 型截面|提升比表面积与毛细效应|
|扩展|3D s/s|—|右下角方案|
|扩展|7D V|—|高蓬松方向|
|ES 路径|6D → 12D|—|渐变丹尼，提升空隙体积|


关键参数：40% 比例下采用 3D ES 纤维；8% 比例下引入 PVA 亲水性组分。

## 二、关键供应商与材料来源

|材料|供应商/来源|角色定位|
|---|---|---|
|PVA（聚乙烯醇）|皖维高新|亲水改性组分，8% 添加比例|
|PE/PTT 纤维|江南（某供应商）|6D 规格候选|
|CoPET/PET|—|毛发状纤维，Airlaid 工艺适配|
|NCC（纳米纤维素晶体）|—|SAP 层间增强材料|


## 三、芯体层结构示意图

白板底部绘制的 SAP 双层结构示意：

|层级|组成|功能/工艺|
|---|---|---|
|上层|SAP¹ + NCC|高吸水性树脂 + 纳米纤维素晶体增强|
|下层|SAP² + 水刺|高吸水性树脂 + 水刺非织造加固|
|复合工艺|水刺|整体层间加固|


## 四、技术决策要点

## 4.1 已确认方向

## ●PE/PTT 30/70 s/s 作为基准双组分纤维，155°C 热粘合窗口

## ●4D 截面为当前最优平衡点，1D 为下一代目标

## ●PVA 亲水改性由皖维高新供应，8% 比例纳入配方

## 4.2 待验证/开放问题

## 1.ES 纤维路径：PE/PET vs PE/PP 的选择（6D→12D 丹尼梯度）

## 2.CoPET/PET "Hairs" 方案在 Airlaid 体系中的可加工性

## 3.NCC（纳米纤维素晶体）与 SAP 的相容性及溶胀协同效应

## 4.水刺工艺对 SAP 颗粒固定与芯体完整性的影响

## 4.3 下一步行动
