# 温度响应材料

## Definition 定义

定义待补（引用来源未给出明确定义）。据 [[Hydrogel-based Superabsorbent Polymers]]：**部分水凝胶具有温度响应性，在特定温度下发生相变，释放或保持水分**。（中文：本库当前对"温度响应材料"的全部可溯源描述来自该 SAP 综述章节对水凝胶温度响应行为的陈述。）
