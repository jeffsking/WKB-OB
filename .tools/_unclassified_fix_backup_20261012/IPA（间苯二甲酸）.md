# IPA（间苯二甲酸 / Isophthalic Acid）

> 一句话定义：CoPET 的**核心共聚改性单体**——掺入 PET 聚合体系后破坏链段规整性、把熔点从约 256–260 ℃ 下探到 110–180 ℃；同时它是 CoPET 独有的、也是价格波动最剧烈的成本项。

## 机理 / 结构拆解

1. **化学作用**：IPA 是对苯二甲酸（PTA）的**间位异构体**。间位羧基使链段无法紧密堆砌，结晶度与熔点同步下降——这就是「加 IPA 降熔点」的物理本质。
2. **在成本结构中的位置**：CoPET 改性切片投料比为 PTA 0.66 t + **IPA 0.20 t** + MEG 0.34 t（每吨切片）；IPA 单价高，因此在 CoPET 切片原料成本中占 **26.8%**，在成品 CoPET/PET 纤维总成本中占 **8.1%**。
3. **与 PE/PET 路线的「对映项」**：CoPET/PET 的独有单体成本是 IPA（约 8.1%），PE/PET 的独有单体成本是乙烯（约 29.9%）——两者不可互相抵扣，构成本批成本对比的核心断层。
4. **波动是主风险**：IPA 在 30 天内出现 4,800 → 9,800 元/吨量级的摆动，远大于 PTA/MEG，是「CoPET 成本稳定性低于 PET」与「CoPET 价格弹性更大」的直接成因。
5. **供应格局**：华东市场以**日/韩进口**为主，国内供给集中度与替代能力库内暂无来源 `[待验证]`。
6. **采购含义**：IPA 是 CoPET 溢价叙事里被反复引用的「挡箭牌」；但按成本取证，中间体层 CoPET 切片仍比 PE 树脂便宜约 10.7%——IPA 的贵主要被同质体系的加工节省部分抵消。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[CoPET 与 PET 成本差异对比（2026 年 7 月）]]、[[CoPET 采购蓝图：成本拆解与供应分层]]）：两份来源均把 IPA 列为 CoPET 的「关键溢价因子 / 波动源」，且都指出 30 天内 4,800 → 9,700–9,800 元/吨量级的摆动。本页表述与来源一致。

- **教训（谈判口径）**：把 CoPET 溢价全部归因于「IPA 贵」是**不完整的**。成本取证显示：单体层两者几乎打平（-0.4%），CoPET 切片层反而便宜，真正差异在加工段与市场加价。谈判时应把 IPA 波动与**乙烯惩罚 + 200 元/吨加工节省**一起摆上桌。
- **待补 `[待验证]`**：IPA 的国内买方长协/现货采购结构；IPA 波动与 CoPET 短纤报价之间的传导时滞与传导率。
