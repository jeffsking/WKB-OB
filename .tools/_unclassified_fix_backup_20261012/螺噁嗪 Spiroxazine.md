## Definition 定义

据引用来源，螺噁嗪（spiroxazine / spironaphthoxazine）属于**光致变色（photochromic）染料分子家族**之一，与螺吡喃、萘并吡喃、俘精酸酐、二芳基乙烯并列，是接近理想光致变色要求的五大分子家族之一（源：[[光致变色 Photochromic]]）。其商业范式为**眼科镜片**中的光致变色应用（源：[[Photochromism Dihydroindolizines]]；[[Molecular and Supramolecular Systems]]）。

## Method / Mechanism 方法 / 机理
- **分子家族定位**：spiropyrans、spironaphthoxazines、naphthopyrans、fulgides、diarylethenes 为接近理想光致变色要求的五大分子家族（源：[[光致变色 Photochromic]]）。
- **螺环开环机理（同螺吡喃类）**：螺吡喃 C_spiro–O 键受力开环 → 有色部花青（merocyanine）异构体；螺吡喃/螺噁嗪骨架与文献已证双响应（光 + 力）体系同源（源：[[Tianjin Security-Chemical（天津塞特瑞科技）]]；[[光致变色 Photochromic]]）。
- **供应链三层结构**：① 染料/分子（spiropyran、diarylethene、螺噁嗪等）→ ② 配方化颜料/油墨（微胶囊粉、色膏、印刷墨）→ ③ 终端成品（镜片、太阳镜、智能纺织品、玩具、防伪标签）（源：[[Photochromic Supplier Report 2026-08-03（光致变色供应商调研·含光-力双响应）]]）。
- **力响应现状**：无商用“开箱即用”的力–光双响应光致变色材料；可采购的力响应供给 = 螺吡喃/螺噁嗪原料分子（天津塞特瑞为最务实来源）（源：[[Photochromic Supplier Report 2026-08-03（光致变色供应商调研·含光-力双响应）]]）。
- **放置约束**：DHI/螺噁嗪为有机光致变色体，需 UV 激发且有有限疲劳寿命；适合包装、标签与非接触外层指示（源：[[Photochromism Dihydroindolizines]]）。

## Hygiene Relevance 卫材关联
- **UV 显影防伪包装**：螺噁嗪已在透明塑料基体中商业化，是纸尿裤 / 卫生巾纸箱与柔性包装上做 UV 显影图形、隐藏信息、品牌防伪的直接、已验证模板（源：[[Photochromism Dihydroindolizines]]；[[智能包装 Smart Packaging]]）。
- **湿敏 / UV 指示面层**：光致变色 novelty printing 可对接成人失禁用品的湿度 / UV 指示智能面层（UV 暴露后变色 → 提醒更换）（源：[[光致变色 Photochromic]]）。
- **供应面**：天津塞特瑞科技供应螺吡喃/螺噁嗪骨架原料，被列为力响应应用落地的第一采购锚点（该锚点地位为推断，未经样品验证）（源：[[Tianjin Security-Chemical（天津塞特瑞科技）]]）。
- 与光致变色油墨路线互补（源：[[光致变色油墨 Photochromic Ink]]）。
