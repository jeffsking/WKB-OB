# 原纤化（Fibrillation）

> 一句话定义：莱赛尔（Lyocell）等纤维素纤维在湿态摩擦下，表面因缺少皮层而被逐层剥开、长出细小原纤的现象；表现为起毛、发白、起球，**干态看不出来，必须洗过才显现**。

## 机理 / 结构拆解

1. **成因在莱赛尔自身结构**：这种纤维表面没有皮层，结晶度和取向度又高，遇水加摩擦后表皮一层层剥开，长出细小原纤。
2. **湿态最明显**：干着看、上手摸都看不出来，一定要洗过才知道——这决定了验证方法必须是水洗后的布面比对。
3. **两条解决路径，性质完全不同**：
   - **纤维本体解决（根治）**：在纤维内部先做交联把结构锁住（兰精 A100 即交联型）。
   - **工艺端解决（管理）**：纺纱织造时控制张力与摩擦减少磨开机会；染整端用酶处理、控制开纤与砂洗程度，把已起的毛压回去或控制在可接受范围。
4. **管理型方案的代价**：成本低、手脚灵活，但**批次之间容易波动**——换个染厂、换口缸，结果可能就是两样东西。

## 经验教训

> ✅ 验证（2026-09-27，来源 [[天丝为什么突然这么难买]]）：本页「湿态才显现」与「根治 vs 管理」两条机理表述，与来源完全一致。来源额外给出可操作推论——**用国产做替代，验证必须在染整厂完成**，本页采纳并保留为要点。

- **采购动作**：对依赖交联型（A100 档）的产品线，应单独建清单，区分「防起毛 / 防发白 / 客户指定」三类动因，才能预判断供时的处置路径（改设计 / 谈客户 / 不可动）。
- **风险提示**：来源所述的 A100 停产消息**属传闻非公告**，不得作为长约、囤货或交期承诺的决策依据。详见 [[兰精集团]] 的 manual_review 标注。
