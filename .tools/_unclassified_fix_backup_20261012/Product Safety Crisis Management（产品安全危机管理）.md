# Product Safety Crisis Management（产品安全危机管理）

**一句话定义**：当某个化学品在**任意品类**被曝出安全问题时，消费者担忧会**跨品类外溢**到纸尿裤/湿巾等婴幼儿接触品类，引发销量骤降；企业为此需要的整套能力 —— **危机响应组织 + 政府关系 + 信息披露策略 + 选材前置纠偏**。

> 名称说明：本页由一次内部交流（本方 K-C 与韩国 YK 体系）的 ASR 转写提炼，转写质量较差、多处音转 [待验证]；同时与 [[Material Safety Control（材料安全双轨管控）]] 记录的案例同源，两页**互补**：本页讲"事件如何发生与如何响应"，该页讲"物质如何被管控"。

## 机理 / 结构拆解

### 1. 跨品类外溢（Cross-category spillover）

| 环节 | 内容 |
|---|---|
| 触发 | 某化学品在**完全无关的品类**被大学/第三方检测并公开（如加湿器杀菌剂、CMIT 牙膏、彩妆中的锑） |
| 传导 | 担忧由"**同一个妈妈**"跨品类迁移 —— 买牙膏的妈妈会对纸尿裤产生同样的安全疑虑 |
| 放大 | 社交媒体放大；政府介入调查/成立研究团队；企业被动 |
| 落地 | 企业把该物质写入 **COC 清单**（见 [[Material Safety Control（材料安全双轨管控）]]），并反向约束**供应商** |
| 后果 | 销量下滑；**最坏情形是"失去一代消费者"** |

### 2. 长尾损失（Long-tail damage）

- 韩国湿巾事件（约 **2005 / 2008 年**）后，YK 从该品类**第一**跌落，**近 20 年未恢复份额**。
- 启示：安全事件的损失**不是季度级的，而是以十年计的**；这也是"选材必须前置"的根本理由。

### 3. 危机响应组织（YK 已运行的做法）

| Item 项目 | 内容 |
|---|---|
| 组织形式 | **跨职能危机管理团队**（市场、制造等） |
| 工作方式 | **每天在同一地点**开会 |
| 持续时间 | 约 **3 个月** |
| 制度化 | 事后固化为制度（"the system has been set up"） |

### 4. 三个未解的张力（Tensions）

1. **披露 vs 不披露**：危机期间，安全团队**拒绝向公众提供检测信息**，与会者对此明确失望 → 披露策略在内部存在分歧。
2. **口径未统一**：会中指出"取决于用哪种测试方法、说多少 PPM —— 十分之一个 PPM 没有意义" → **方法与限值口径不统一会让所有沟通失效**。
3. **耐心 vs 行动**：会中并存两种判断 —— ① "我们有市场上最好的产品，消费者迟早会知道，需要更多耐心"；② 主动做**透明化**（如官网放工厂摄像头让消费者看到制造过程）。**尚未收敛**。

### 5. 政府关系（Government relations）作为能力项

- 会中判断：本方在政府关系处理上**不如竞品**；竞品有 **4 条产品线**（含 sensing 类产品），本方在消费品市场的品类组合**很小**。
- 结论（会中表述）：**未来必须建立更强的政府关系能力**。
- 机理推论：**品类组合越大，与政府的接触面与话语权越大** —— 单品类企业在监管议题上的议价能力天然偏弱。

## 经验教训

1. **跨品类外溢是常态，不是例外**：只要"同一个消费者"重合，别的品类的安全事件就是**本品类的风险事件**。监控系统必须**跨品类扫描**，不能只看卫材。
2. **损失的量级是"代际"而非"季度"**：韩国湿巾近 20 年未恢复 —— 这决定了在选材上为安全多付的成本是**保险费，不是额外成本**。
3. **危机响应要制度化，而不是临时抱佛脚**：YK 的做法（跨职能团队 + 每日同地 + 约 3 个月 + 事后固化）说明危机响应是可以被"排练"的组织能力。
4. **口径比态度更重要**：当测试方法、PPM 限值、检测机构都不统一时，"我们有检测数据"这句话本身没有说服力 —— 先统一口径，再谈沟通。
5. **信息披露的分歧要在危机前解决**：安全团队"拒绝向公众提供信息"在内部已造成失望；若不在平时定好披露原则，危机时必然内耗。
6. **政府关系是品类组合的函数**：单品类企业在监管议题上话语权天然偏弱 —— 补齐政府关系能力是结构性问题，不是公关技巧问题。
