# Front Belt Force Window（前腰带弹性力窗口）

## Definition 定义

**胶粘（taped）尿布前后双弹性腰带的力值配比设计规则**：**前弹性腰带**的弹性力须落在**一个相对低的窗口**内（**约 0.03–0.32 N**），而**后弹性腰带**的弹性力须**更高**（**约 1.1–2.9 N**），**后/前比值 4–40（优选 5–30）**。力值均须以**同一套"腰带弹性力测量方法"**测得。本库中该窗口的唯一来源是 **CN 118369075 A**（宝洁）。

> 术语首现：**有效胶粘弹性长度**（Effective Glued Elastic Length, **EGEL**）＝ 对含股线的腰带，指**单根弹性股线末端在其开始起皱的位置之间的最小距离**；对弹性膜类腰带，指腰带每一侧**第 1 个褶皱**的位置。实践中可由**腰带材料全长（松弛态）减两侧非粘结区长度**得到。它是本案全部力值口径的**归一化基准**。

## Why it matters 为什么重要

直觉上"腰带越紧越防漏"。本案给出的反例是：**前腰带力过高会破坏穿戴流程与穿着形态**，其失效链为：

```
前腰带力过高
  ├─ 前腰区产生大量褶皱
  │    └─ 护理人员须反复拉伸前腰，才能把后耳片粘带贴到着陆区（穿戴不便）
  ├─ 穿上后前腰边缘弯成 U 形变形
  │    └─ 尿裤显松垂、不利贴合
  └─ 后粘带的一部分可能接触皮肤 → 穿着者不适
```

同时说明书给出的**另一侧边界**是：**前腰带力太低，则在防液体渗漏方面相对"无前腰带"产品没有益处**（[0101]）。即本案是一个**双侧有界窗口**，而非"越低越好"。

## Test method 测量方法（引用该窗口时必须连带引用）

| Item 项目 | Content 内容 |
|---|---|
| 定义 | 以 **L最大** 拉伸**两次**后，腰带在 **85 % EGEL（L读取）** 下的力 |
| 环境 | **23 ℃ ± 2 ℃** 气候调节室 |
| L最大 | **0.95 × EGEL** |
| L读取 | **0.85 × EGEL** |
| 设备 | 测力计支架 **E-DFE-002**（Trimborn+Guld Maschinenbau GmbH），**0–10 N** 刻度、**最小分辨度 0.01 N** |
| 样品制备 | 取出后**不拉伸**腰带；沿平行于横向轴线的引导线剪下；**不得剪断/撕扯弹性部件**；SAP 暴露处以遮蔽粘带密封 |
| 直尺溯源 | 可追溯至 **NIST / DIN / JIS / CMC** 或其他相当国家标准 |

> ⚠️ **口径警告（2026-09-29）**：**0.03–0.32 N 只在上述方法下成立**。换成其他拉伸比、其他读取长度或常温常湿，**数值不可比**。本库 [[Product Waist Break Test（产品腰围拉断测试）]] 测的是**拉断强度**，与本窗口的**弹性力**不是同一指标，**不得混用**。

**如何正确读这张表（2026-09-29 判读要点）**：
1. **在 0.10–0.53 N 区间内，前腰带力越低，"正好"率越高**（64.3 % → 100 %），且"紧"的抱怨从 21.4 % 降到 0 %。
2. **#1（0.53 N）超出权利要求上限 0.32 N**，属窗口**外**的高力值对照样本。
3. **对照组 #5（无前腰带）"正好"率 91.7 %**，**高于 #1 与 #2、等于 #3**。因此本数据**支持"力要低"**，但**不足以支持"有前腰带优于无前腰带"**。
4. **样本量很小**：N = 12 时**一人即 8.3 个百分点**，100 % 与 91.7 % 的差异仅 1 人。

## Manufacturing note 制造要点

权 15 与 [0009]–[0018] 给出**同一条起始材料同时产出前后两条不同力值腰带**的连续工艺：**间歇涂胶 → 折叠包覆 → 沿非粘结区的虚线切割线切断股线（仅部分切腰带材料）→ 拉伸使其沿虚线断裂**形成组合垫 → 分切成离散的前后腰带。其物理基础是：**股线从未涂胶的间歇区弹回，而腰带材料因虚线切割保持部分连接**。
