# Technology Roadmap 2026-2029（技术路线图）

> Definition 定义：卫材行业 **2026–2029 产业化技术路线图**——由「双轨演进主线 + 四阶段产业化时间轴 + 外部 TRL 标尺 + 六大新方向」构成，用于校准 [[IPC BCC OI Portfolio（开放创新项目组合）]] 的「方向正确性」。

## Dual-Track Evolution 双轨演进

| Track 轨道 | 2024 | 2025 | 2026+ |
|---|---|---|---|
| Track 1 Green & sustainable（绿色可持续） | bio-based materials（PLA/PPC）应用 | bio-based SAP 规模化 | fully degradable / compostable products（全降解/可堆肥） |
| Track 2 Functional premiumisation（功能高端化） | ultra-fine / ultra-soft topsheet（0.003 mm 纤维） | pulp-free core 成为高端标准 | agile supply chain + patent barriers（敏捷供应链 + 专利壁垒） |

## Four-Phase Commercialisation Roadmap 四阶段产业化路线图

| Phase 阶段 | Years 年份 | Theme 主题 | Key target 关键目标 / 对应项目 |
|---|---|---|---|
| I | 2026–2027 | Technology integration & cost drive（技术整合与降本） | 主流价位段引入超声波粘合，材料成本降 8–12% ← OI-05 / OI-04 |
| II | 2027–2028 | Premium performance upgrade（性能段全面升级） | 4th-gen core SAP ≥70%；Ω 腿口 100% 产线 ← OI-14 / OI-20 / OI-02 / OI-25 |
| III | 2028–2029 | Eco & ultra-premium breakthrough（环保/超高端突破） | PLA 纤维产能 30 万吨/年；全降解体系成本溢价降至 15% 以内 ← OI-24 / OI-06 / OI-12 / OI-13 |
| IV | 2029+ | Circular economy（循环经济） | Unicharm 干洗回收法量产，用水降至 1/50 ← watch item |

- **Cost crossover points 成本交叉点**：PLA fibre 预计 2028–2029 与 PP 平价；bio-based SAP 预计 2030 年后平价。

## Six New Technology-Roadmap Directions 六大新方向

Reverse-engineered from the knowledge base; the basis of the 2027 initiation proposals（反推所得，是 2027 立项建议来源）:

1. **Zoning replaces homogenisation（分区化取代均匀化）** → OI-02 / OI-20 / OI-14 / OI-25；单层均质架构项目须重述目标。详见 [[分区密度设计]]。
2. **Ultrasonics upgraded to the cost-reduction mainline（超声波升为降本主线）** → OI-05 / OI-04；替代 90% 热熔胶、设备国产化 >80%、约 18 个月回本。
3. **Degradables counting down to the cost inflection point（可降解进入成本拐点倒计时）** → OI-24 / OI-06 / OI-12 / OI-13；PLA 2028–2029 平价、bio-based SAP 2030 后平价。
4. **Smart indication downgraded to a "visual language"（智能指示降为视觉语言）** → OI-15/16/21/22/23；验收口径统一为「消费者可解码率 ≥70%」而非精度指标。
5. **Compliance upgraded to a precondition for material selection（合规升为选材前置条件）** → 全部 25 项，高风险：OI-09/15/16/21/22。详见 [[Material Safety Control（材料安全双轨管控）]]。
6. **Patents & exclusivity become the first deliverable（专利与排他成为第一交付物）** → OI-07 / OI-10 / OI-12 / OI-23 / OI-25。

## 经验教训 Lessons

- **要点**：六大方向中「分区化」「超声波」「可降解拐点」三条有明确数字锚点（+40% CD 扩散、降本 8–12%、2028–2029 平价），可作为项目立项的时间/指标判据；「智能指示降为视觉语言」与「合规前置」是口径级改动，不改变技术路线。
- **待补 `[待验证]`**：PLA/bio-based SAP 平价时点的第三方验证；超声波 18 个月回本的产线实测。
