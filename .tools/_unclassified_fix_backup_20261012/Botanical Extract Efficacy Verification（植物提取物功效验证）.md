# Botanical Extract Efficacy Verification（植物提取物功效验证）

> 本页为 2026-09-29 编译的内部研发评审会内容整理，参数均为**内部口径**，未见第三方复核。

## 机理 / 拆解：验证链条的四个环节

植物提取物从"原料有活性"到"产品有效"，需要穿过四个环节，每一环都会损失：

| 环节 | 要回答的问题 | 本批信息 |
|---|---|---|
| ① 活性分子识别 | 真正起效的化学分子是什么？ | 紫松果菊 → **菊粉（inulin）**，分解为果糖；柑橘果 → **总黄酮 + 总生物碱** |
| ② 定量方法 | 用什么方法测含量？ | 紫松果菊 → **HPTLC**；柑橘果 → **紫外分光光度法** |
| ③ 渗透验证 | 能否穿过角质层？ | 原用猪皮渗透 → **改为 3D 皮肤模型** |
| ④ 转移验证 | 从无纺布到皮肤能转移多少？ | 转移率是最大瓶颈，同类约 **2%** |

**核心教训**：细胞层面的功效 **≠** 无纺布上的功效 **≠** 产品上的功效。必须逐级验证，不能跳步。

## 为什么放弃猪皮渗透（三条理由）

1. **法规限制**：猪皮为**活体活性皮**，可能不适用于某些区域的法规限制（中国、新加坡可做）。
2. **分层不可控**：无法分离**角质层与真皮层**；对方希望**只保留角质层**以提高渗透检测的灵敏度。
3. **仪器缺失**：原合作方只有**紫外分光光度法**，**没有 HPTLC 仪器**，无法完成猪皮测试。

→ 结论：**模型选择受"仪器能力 + 法规 + 分层可控性"三重约束**，不是单纯的"哪个更真实"。

## 两大瓶颈

**瓶颈一：转移率（transfer rate）**
- 把活性成分"carry"到皮肤上，转移率一直很低（同类约 2%）；油脂类转移相对容易，活性成分则难。
- 必须建立反推链：**无纺布添加量 → 皮肤转移量 → 最低起效量**，才能确定该加 1% 还是 0.5%。
- 无纺布里的添加量与最终到达皮肤的量**不是同一个量**。

**瓶颈二：涂布工艺的 add-on 上限**
- 丝网印刷：速度慢、对材料粘性要求高；
- 柔性印刷（flex printing）：ink 近乎水性，**add-on 有上限**；
- 理想：复用现有 capex 的刮枪做**狭缝涂布**实现高速在线，但要求物料为**高粘度油剂或固态**，与水性体系相悖。

## 经验教训

1. **对照实验必须按"活性物含量"对齐，而不是按"添加百分比"对齐** —— 修饰前后活性含量不同，直接按相同百分比对比会引入系统误差（本例：10% vs 11%，使总芦丁持平）。
2. **清洗步骤是定量前提** —— 不洗净表皮残留，就无法区分"皮中"与"皮下"，渗透结论会系统性偏高。
3. **逐级验证，不跳步** —— 细胞有效 ≠ 无纺布有效 ≠ 产品有效；本批明确要求：有了无纺布样品先做 efficacy（含不同温度老化），确认有效后才做产品级手臂测试。
4. **渗透越深，监管风险越大** —— 一旦功效依赖"渗入角质层以下"，是否仍按一次性卫生用品监管就成了问题；**过敏与刺激是不同机理**，需要防御性说法。
5. **天然提取物的质量管控极难** —— 以总黄酮/总生物碱含量控制，但天然原料变化后的稳定性与纯度需持续核查。
