# 弹性恢复工艺


## Definition 定义

由「拉伸—回复」循环定义的工艺：材料从 **100% 拉伸至最高 250%，然后回复到 100%**。


## Key Points 要点

- 该「拉伸—回复」循环定义该工艺（源：Daehyoon 供应商技术来访（技术专场））
- **材料弹性差异大**：PE 有的伸长率 >500%、有的 <200%，不能简单按比例放大（同上）
- 待补：完整模块成本、500 m/min 下的针孔尺寸范围、异形图案可行性、两种切割类型说明、DLC 涂层安全说明（同上）
