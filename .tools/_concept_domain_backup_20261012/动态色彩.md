# 动态色彩


## Definition 定义

BLOCLO（广州盛色科技）的定位概念——材料本身随**光或温度**发生可逆颜色变化的「动态色彩」材料。


## Key Points 要点

- BLOCLO = **B**looming **C**olor（盛开的色彩），定位功能性「动态色彩」材料制造商（源：BLOCLO 盛色科技产品册）
- 产品形态：光变类（光变染料/粉/色膏/纤维，4 种）、温变类（温变粉/色膏/色母粒，3 种）；设「动态色彩协同开发中心」四大开发方向（同上）
