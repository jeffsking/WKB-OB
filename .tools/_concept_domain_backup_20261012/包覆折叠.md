# 包覆折叠


## Definition 定义

芯体的**包覆折叠**工艺——芯体经包覆折叠后实际用料幅宽显著大于芯体幅宽。


## Key Points 要点

- 芯体实际幅宽 110 mm，**包覆折叠后实际用料幅宽约 170~210 mm**（源：会议纪要：山东希瑞新材）
- 需方产线 900 片/分钟、单片用料长度约 380 mm（同上）
