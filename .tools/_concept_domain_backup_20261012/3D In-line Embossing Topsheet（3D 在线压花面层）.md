# 3D In-line Embossing Topsheet（3D 在线压花面层）

> One-line definition 一句话定义：两层热风无纺布（或 SMS）复合后**在线经凹凸压花辊立体压印成型**的面层技术——压花辊凹凸形成规律鼓包结构，改变面层与皮肤接触的几何形态；在线工艺避免人工触碰，降低微生物污染风险。

## Mechanism 机理 / 结构拆解

1. **成型**：两层热风布（或 SMS）复合后即时通过凹凸配对压花辊；鼓包结构在面层表面形成规律立体图案。
2. **功能增益（公开行业口径）**：鼓包抬升接触面 → 增大瞬时孔隙与透气通道；配合打孔可进一步提速导流。
3. **降本降重逻辑（核心卖点）**：常规热风面层 ~45 g/m²，压花后可降至 38–35 g/m²（降幅 15–22%），同时保持或提升导流与透气——克重下降直接降低面层成本与整体厚度，契合 REL 超薄芯体方向。
4. **边界**：3D 压花解决「面层」问题（降克重 + 透气），**不解决「扩散卡层」问题**——与 [[Triple Cutting Topsheet（三层切割面层）]] 可能并行组合而非互相替代。
5. **在卫品的应用现状**：据行业资料，Pampers/Huggies 高端线采用率约 85% `[待验证]`。
