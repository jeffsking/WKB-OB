# 水性聚氨酯 Waterborne PU
> 📌 **Page completed 2026-09-30** from 3 vault source pages. All figures traced to their source pages. Anything not evidenced is marked `[待补]`.

## Definition 定义

引用来源未给出"水性聚氨酯"的严格化学定义。可追溯的表述为：水性聚氨酯（Waterborne PU）胶黏剂**不含 VOC 排放**且**不易燃（nonflammable）**，因此被描述为"更环保（more environmentally friendly）"（源：[[Adhesive Handbook Part 3 Adhesive Classes]]）。

## Method / Mechanism 方法 / 机理

- **水基化转型被视为不可逆**：资料以"水基化转型不可逆"描述该技术路线转变（源：[[卫材胶黏系统 Hygiene Adhesive Systems]]）。
- 从溶剂型转向水性（waterborne）路线的直接动因是**溶剂价格上涨**（源：[[Adhesive Handbook Part 3 Adhesive Classes]]）。

## Hygiene Relevance 卫材关联

- 作为聚氨酯（PU）家族的一支，水性 PU 关联卫材聚氨酯体系的"原材料/工艺基础"。PU 在卫材中的三种形态被列为**高相关性**：弹性纤维/膜（氨纶、PU elastic film，用于弹性腰围与防漏隔边）、热熔/复合胶（PU 类胶）、功能涂层/膜（透气膜、PU 膜复合）（源：[[聚氨酯 Polyurethane]]）。
