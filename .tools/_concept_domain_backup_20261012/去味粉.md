# 去味粉


## Definition 定义

用于芯体除味的粉体功能材料；因 EHS 粉尘管控改由诺尔预混。


## Key Points 要点

- 去味粉因**实验室无大规模混料能力且涉 EHS 粉尘管控**，改为**委托诺尔预混**（源：CO V6 新体机芯体验证实验方案评审）
- （另一路线）中科依兰纳米除臭粉可通过**油剂施加于热风无纺布**，需验证喷嘴堵塞与线上跌落问题（源：OI（Open Innovation）团队会议纪要）
