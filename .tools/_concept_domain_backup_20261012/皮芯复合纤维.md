# 皮芯复合纤维（Bicomponent Sheath-Core Fiber）

> 一句话定义：由两种熔点不同的聚合物按「皮层—芯层」同心结构复合纺出的纤维；受热时**皮层选择性熔融**充当粘结剂，芯层保持强度骨架。

## 机理 / 结构拆解

1. **皮芯熔点差是关键**：以最常见的 PE/PP 皮芯（即 ES 纤维）为例，皮层 PE 约 130 °C 熔融粘合，芯层 PP 熔点更高，粘合过程几乎不受影响 → 这是热风棉能同时保持蓬松回弹性与基础强度的根本原因。
2. **ES 纤维可 100% 单独使用**，无需额外混入其他粘结纤维——这是它在热风棉中成为最主流选择的直接原因。
3. **其他常见构型**：PE/PET 皮芯（皮层约 120 °C，添加 20–40%，兼顾粘合与骨架支撑）；低熔点 PET（共聚酯粘结纤维，110–160 °C，添加 15–50%，与常规 PET 混用）。
4. **低熔点共聚酯的技术难点在加工窗口**：高含量 IPA 共聚改性路线虽能降熔点，但会带来结晶低、粘接差、干燥易板结、纺丝易降解、熔体流动匹配难等连锁问题——这是国产化项目要解决的核心工程问题。

### 1. 本批新增：偏心（eccentric）皮芯作为蓬松与花型支撑

- **4D 偏心 PE/PET ES 的功能定位**：提供蓬松（bulk）、空隙体积、受压回弹，并承担**超声 3D 花型的深度支撑**；建议不超过约 30 wt%，否则柔软度下降、表面变粗。见 [[ATB Topsheet with Bico Spunbond for 600 mpm Ultrasonic Lamination]]。
- **与"同心皮芯"的分工差异**：同心皮芯＝粘合功能；偏心皮芯＝蓬松/回弹与花型支撑（本批口径下的新增用途），两者可同时出现在同一配方中。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 双组分纤维产线工艺、截面能力边界与「融平」失效）

> 来源：[[Bicomponent Fibre Production & Performance Review — Spinneret, Crimp & Functional Masterbatch（复合纤维生产及性能探讨）]]（ES 双组分纤维供应商工厂交流 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**两步法（long spin）产线流程（本批新增）：**

**螺杆 → 在喷丝板处汇合 → 三分 → 冷却 → 上油 → 落桶（盛丝桶）→ 集束 → 牵伸 → 卷曲 → 烘干 → 切断打包。**

| Item 项目 | 两步法（long spin） | 一步法（short spin） |
| --- | --- | --- |
| 流程 | 纺丝后落桶、再集束牵伸 | 从纺丝直接到切断打包 |
| 成本 | 较高 | **更低** |
| 风险 | 工序间有缓冲 | **一处出问题整条线停掉**，工艺挑战更大 |

**截面设计的载体与能力边界（本批新增）：**

- 皮芯与 side-by-side **靠喷丝板（spinneret / 组件）设计**实现；异形、中空同样靠喷丝板 —— **喷丝板是截面能力的唯一载体**。
- **可商业化**：**同心、偏心、中空** 三种。
- **目前做不了**：**瓣形（桔瓣 / segmented pie）**、**海岛型** —— 海岛虽同为熔融纺丝、同为双组分，但**后道需用溶剂/水把"海"溶掉**，设备要改造，供应商无此规划。
- **实验性研究过**：十字形、三叶形等约**十几幅**喷丝板（非商业化）。
- 海岛的用途边界：用于**单一组分的超细纤维**（如仿麂皮），属**另一应用领域**，与卫材无关。

**「融平」失效机理 —— 双组分做异形纤维的根本矛盾（本批新增）：**

> 双组分异形纤维在**熔融 / 热风粘合时，外层 PE 融平**，中间的沟槽形态**消失** → 扩散效果失效。
> - **全融掉** = 等同于单组分（形态仍保留，但已不靠双组分粘合）；
> - **半融掉** = 部分保留沟槽形态，可作为**提高异形纤维添加上限**的手段。

**由此确定的选型原则（本批新增）：**

1. **做异形纤维优先用单组分**：不依赖熔融粘合 → 形态不被融平；成本更低；可塑性更好；**导液性也不错**。结论是"完全没必要用双组分"。
2. **只有需要把添加量做大时**，才回到双组分的全融/半融路线 —— 这是**用工艺换添加量上限**的取舍。

✅ **验证记录（2026-09-29）**：以上为供应商口径 + 会中技术讨论；"融平失效"为机理推断，另有本方补充"全融掉不如直接用单组分"；**尚无实测数据**。供应商身份由 ASR「敏锐/美锐」音转推断为闽瑞 [待验证]。参见 [[并列复合自卷曲纤维]]、[[ADL（导流层）]]、[[福建闽瑞新合纤]]。

## Evidence Update 证据追加（2026-09-29）

> ✅ Verification（2026-09-29，source 来源 [[皮芯架构决策矩阵（可降解热风无纺布）]]）：既有「选择性熔融」机理未被修正；本批把该机理应用到**可降解体系**——皮层改为 PPC/PBAT 共混（参考 LX-T55P25T20：MFI 20.1 g/10min @170 °C、拉伸 10.6 MPa、伸长 162%、维卡 60.2 °C、加工 160–190 °C、EN13432 / ASTM D6400 认证），芯层在 PET / PLA / PGA / PLGA 中选择，工艺为皮芯型双组分短纤 → 梳理成网 → **热风加固 120–145 °C（最佳 120–140 °C）**。（中文：可降解热风无纺布的皮芯架构评审，皮层固定、芯层可调。）
>
> 关键补充是 **ΔTm 成为支配变量**：PET 芯 Tm 255–260 °C（ΔTm ~130 °C，窗口最宽但纺丝 ~280 °C 有皮层降解风险）；**PLA 芯 Tm 155–170 °C 且可由旋光比调节**（PDLLA 无定形 → PLLA 170 °C → sc-PLA 230 °C），是唯一可按需定制 ΔTm 的芯层；PGA 芯无熔点调节杠杆；PLGA 随组成变化、工艺开发量最大。
>
