# 亲水—疏水梯度设计（Hydrophilic-Hydrophobic Gradient）

> 一句话定义：在蓬松型无纺布（尤其热风棉）上做「上层疏水、下层亲水」的分层助剂设计，上层防止液体在表面停留造成闷湿感，下层加速液体导入芯体深处的高吸收树脂（SAP）。

## 机理 / 结构拆解

1. **梯度方向**：上疏下亲。
2. **各自功能**：疏水层负责**回渗控制**（防止吸收芯体表层液体倒流）；亲水层负责**导流**（加速液体向 SAP 层传递）。
3. **实施难度高于平面型无纺布**：蓬松的三维结构使助剂容易形成「表层浓、内部稀」的不均匀分布，对施加精度要求更高。
4. **防干扰**：需与亲水层配合形成梯度，避免助剂之间互相干扰。
