# REL 增强层（Relative Enhancement Layer / 超薄芯体增强层）

> 一句话定义：纸尿裤芯体中的**增强层**，承担液体快速输运与结构支撑；本库项目目标是**空体积（void volume）80–117 cm³/g @0.5 kPa** 的超薄芯体性能。

## 机理 / 结构拆解

1. **核心设计思路——「快输运 + 强支撑」解耦**：REL 双层设计把液体输运与结构支撑两件事分层承担，与「分区化取代均匀化」的路线级方向一致（V7 已要求分区密度）。
2. **多项目并行演进**（均属 COCO V6 平台）：

   | 项目 | 技术路线 | 关键指标 |
   |---|---|---|
   | OI-02 | PVA Fibre for TABCW (REL) | 非水溶性 PVA ~7D×51mm 耐 >140°C；配方 12D ES PE/PET 92% + 6.5D PVA 8%；空体积 108–117 cm³/g；成本 +RMB 1,400/吨 |
   | OI-04 | PVA/PTT REL（原 OI-11 合并） | 1st STT 1.02s、厚度 1.01mm、SAP 捕获 62%；MD 分布 ≥+30%（目标 34.9%）；克重 28gsm |
   | OI-14 | 3-Carded REL with SAP | 多梳理 REL 整合 SAP；丝网分区密度 + 3D 凹凸网面 + 气垫滚筒 |
   | OI-20 | Three-layer Carded REL + SAP | 全芯体 v2.0：Route A（Multi-SAP + REL）升为优先；移除 ADL 与亲水剂；面层三叶形 PET 定稿 |

3. **PART 进展**：OI-02 第 2 次实验室试验（7 月）结果良好，等待天津实验室第 3 次 Intake-Speed 验证；OI-04 的 6 卷 REL（145mm×300m）预计 9/18 到天津。
4. **供应与放大**：Minrui（网）、Yanjan（放大）、皖维（PVA）、C1 Life（PTT）、Fudi（三叶）、大原（梳理）。
5. **专利启动条件**：OI-02 数据确认后立即启动专利撰写（Teng 负责），需明确专利范围（PVA 改性 / 工艺 / 应用）。

### 2. 结构定位与失效模式（追加）

- **100% SAP 芯体为 5 层**：芯包 / 上层 SAP / **REL** / 下层 SAP / 芯包——REL **夹在两层 SAP 之间**，在 SAP 吸液之前先提供可穿行的空隙，以规避表面凝胶阻塞（对比传统 3 层绒毛浆混合芯体）。
- **缺 REL 的五种失效**：SAP 凝胶阻塞 → 无空体积导致积液 → Z 向坍塌 → MD 分布差 → 回渗。

### 追加-4 · 改进项 ROI 排序与进阶纤维（可直接转成 DOE）

**四条改进项**：**9D 中空 14→18%**（渗透 +28%、第 3 次 STT −20%，原文评为**改善 STT 的最高 ROI**）> **3D PTT/PET 28→34%**（回渗 −35%、蓬松恢复 +22%）> **2D ES 40→32%**（当前 40% **过粘合**使蓬松与透气降约 18%；调整后透气 +20%、STT −15%）> **12D ES 10→8%**（克重中性、手感更软）。

**四条进阶纤维**：**1.5D ES 粘合纤维**（粘合均匀性 +15%、手感 +20%、成本变化极小）｜**4D PTT/PET 并列（卷曲 ≥8 个/cm + 四叶截面毛细沟槽）**（0.7 kPa 下蓬松恢复 +35%、横向铺展 +22%）｜**6D 偏心中空**（毛细密度 +40%、STT −18%、克重中性）｜**新增 2% 的 1.5D PET/PA6 微沟槽芯吸纤维**（第 3 次芯吸 +30%、**亲水耐久性 +50%**）。

> 📌 **「过粘合」是本批新增的一个 REL 失效模式**：**粘合纤维占比过高（40%）本身会压低蓬松与透气约 18%** ⇒ REL 的粘合设计存在**最优窗口，而非越多越好**。此前本页未登记该失效模式。

### 追加-5 · 双层 SAP 的接口规格（**REL 两侧的边界条件**）

| 层 | AUL | GBP | 粒径 | CRC |
|---|---|---|---|---|
| **上层 SAP**（快速摄入） | **≥28 g/g（0.7 psi）** | **≥40 Darcy** | **200–400 µm（细）** | 28–32 g/g |
| **下层 SAP**（储存） | **≥24 g/g（0.3 psi）** | 20–30 Darcy | **400–800 µm（粗）** | **38–48 g/g** |

**接口风险**：Upper SAP→REL 侧为「**REL 蓬松塌陷 → 凝胶阻塞**」；REL→Lower SAP 侧为「**PVA 占比过低 → 分布不完全**」。目标流量分别为 **>45 ml/min（每次）**与 **>35 ml/min（第 3 次后）**。

> ⚠️ **注意**：这两条风险**分别对应 REL 的「结构」与「化学组成」两个维度**，说明 **REL 不是单一目标层**——**蓬松（物理）与 PVA 占比（配方）须同时达标**。

## 追加：Resources/Open Innovation 批（2026-09-29 追加 · ⚠️ 20 gsm TABCW 被测出疏水）

> 来源：[[ATH SAM Relocation（2025-07-29 · 解吸能量·残液·microCT 与 SAM 再分配台架）]]（K-C 内部研究）。

1. **独立发现** —— 源文单列一页标题：**「20gsm TABCW found to be hydrophobic」**，对照样品为 **53901-04（Wrapped Core, 12 gsm dSB）** 与 **53901-06（Wrapped Core, 20 gsm TABCW）**。
2. **⇒ 同为芯体包覆/增强层材料，定量相近 ≠ 润湿性相同** —— **12 gsm dSB 与 20 gsm TABCW 在本测试中表现出不同的润湿行为**。**"换一个定量的同类材料"不是等价替换。**
3. **对本页的直接含义** —— REL / TABCW 作为**结构分隔 + 横向分布**层，其**润湿性会直接决定它是"通道"还是"屏障"**；**疏水的 TABCW 可能阻断层间液体传递，而不是帮助分布。**
4. **与回渗归因的关系** —— 源文的总假设是"**摄入系统中滞留的液体都可能被表达为回渗**"；**若增强层本身疏水，它会成为一个新的持液/阻断点**，**⇒ 增强层材料应被纳入回渗归因链，而不只是结构件。**
5. **可迁移判据** —— **在替换任何增强/包覆层材料时，必须同时核验"定量"与"润湿性"两项**，**只对齐定量是不够的。**
