# 感光变色微胶囊


## Definition 定义

**感光（光致）变色微胶囊**——Insilico 的 Chameleon UVC Series，以微胶囊包覆感光色素。


## Key Points 要点

- Insilico 的感光变色微胶囊为 **Chameleon UVC Series**（源：Insilico 功能性微胶囊产品手册（英文版））
- 与盛色科技（粉体/膏体/母粒路线）构成不同技术路线：Insilico 微胶囊包覆感温色素，**稳定性和耐久性更好，但成本通常更高**；BLOCLO 盛色成本低、适合大面材与纤维，耐久性需实测（同上）
- ⚠️ 光变由紫外光触发，**不能当作湿显指示材料**（源：BLOCLO 产品册）
