# 张力控制


## Definition 定义

拉伸/开孔工艺中的**在线张力控制**——TJ 工艺要求两步拉伸并配在线张力监测。


## Key Points 要点

- TJ 供应商核心技术判断：**一步拉伸不可行，须两步（或多步）拉伸并配在线张力监测**（源：TJ 供应商工厂访问与会谈纪要（英文））
- 无纺布在放卷、牵引、复合、分切过程中被持续施加张力；张力过大 → 拉长/幅宽收缩/克重与孔隙变形，张力过小 → 打褶跑偏（源：Nonwoven Deformation Force Test）
