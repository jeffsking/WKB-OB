# Light-Scattering Masking Wetness Indicator（光散射遮蔽型尿湿指示）

## Definition 定义

**一种不依赖染料、指示剂或微胶囊的尿湿指示原理**：在亲水基片上依次设置**含无机光散射粒子的显色层**（first coating layer）与**含同类粒子的遮蔽层**（second coating layer），两层在**干态**因**二氧化硅（SiO₂）／氧化铝（Al₂O₃）粒子的光散射**而呈**白色或乳白色**，遮蔽层把显色层的图案"盖住"；**被尿液润湿后散射被抑制**、遮蔽层**转为透明**，显色层**显出其本色**，透过**透光背层**（light-transmissive backsheet）被外部观察到。

> 术语首现：**光散射遮蔽**（light-scattering masking）＝ 借"干态不透明、湿态透明"的**物理光学**切换实现信息显隐，而非靠化学变色。可与 [[Chromism Taxonomy（变色现象分类）]] 中的各类变色现象并列，但**机理上属"散射/折射率匹配"，不属变色**。

## Why it matters 为什么重要

本库现有的两条湿显路线——[[Wetness Indicator Glue]]（热熔胶，pH/树脂溶解型，**不可逆**）与 [[Water-Activated Ink（水变／湿变油墨）]]——**都依赖化学变色体系**。光散射路线提供第三条路径：

| Dimension 维度 | 热熔胶尿显 | 水变油墨 | **光散射遮蔽（本路线）** |
|---|---|---|---|
| 物理化学基础 | 树脂被尿溶解/重置，pH 指示 | 水活化油墨 | **无机粒子光散射 → 湿态透明化** |
| 是否需染料/微胶囊 | 需指示剂 | 需油墨体系 | **不依赖染料或微胶囊**（颜料仅用于给显色层上色） |
| 干态外观 | 黄/橙 | 设计色 | **白色/乳白（遮蔽态）** |
| 湿态外观 | 蓝 | 变色 | **显出本色（显形态）** |
| 图案化能力 | **不可**（只能刮条，25–30 g/m²） | **可**（3–4 g/m²） | **可**（可为花卉图案、间断排列或整面涂层） |
| pH 依赖 | 是 | 否 | **否** |

→ 该路线与本库 [[Geometric Optical Mask（几何光学掩膜）]] 属同一"用光学手段控制信号可见性"的思路，但前者是**液体触发的可逆/半可逆光学切换**，后者是静态几何遮蔽。

## Mechanism 机理

| State 状态 | 显色层（第一涂层） | 遮蔽层（第二涂层） | 外部可见性 |
|---|---|---|---|
| **干态 Dry** | 无机粒子散射光 → 呈**白色**，本色被自身散射掩盖 | 无机粒子散射光 → 呈**白色/乳白**，**遮蔽**显色层图案 | 图案**不可见** |
| **湿态 Wet** | 水填充粒子间空隙、折射率差减小 → **散射被抑制** → 显出**本色** | 同上 → **透明度上升** | 图案**透过遮蔽层与透光背层可见** |

切换的**物理本质**是：干态时 **SiO₂/Al₂O₃ 粒子（n ≈ 1.45–1.76）与空气（n ≈ 1.0）** 折射率差大 → 强散射；湿态时孔隙被**水（n ≈ 1.33）**替代 → 折射率差缩小 → 散射减弱 → 透明化。这是"**湿致透明**"（wet-induced transparency），与"湿致变色"是两类现象。

## Key parameters 关键参数（源：EP 0 776 645 A1）

| Parameter 参数 | Range / Value 范围 / 数值 | Note 备注 |
|---|---|---|
| **第一涂层（显色层）** | 颜料 **5–20 wt%**；**SiO₂ 或 Al₂O₃ 5–35 wt%**；亲水丙烯酸粘合剂 **5–25 wt%**；水 **30–75 wt%** | EP 0 776 645 A1 说明书 |
| **第二涂层（遮蔽层）** | **SiO₂ 或 Al₂O₃ 10–40 wt%**；亲水丙烯酸粘合剂 **5–25 wt%**；水 **40–85 wt%** | 同上 |
| 基片 | 亲水纸，**定量 15–40 g/m²**；纸浆纤维或人造丝纤维 | 同上 |
| 背层透光率 | **20–80 %**，优选 **30–70 %**（含 TiO₂/BaSO₄/CaCO₃ 的拉伸透气膜） | 权 2；透光率是**外显的前提** |
| 粘接方式与面积 | **间断热熔胶点**；**不超过每个图案面积的 70 %**；胶须**不含油分** | 说明书；见下方"工程注意点" |
| 未粘合边 | **≥10 mm**（保证基片可变形、与芯体贴合） | 权 7、权 8 |

## Engineering caveats 工程注意点

- **热熔胶是潜在失效源**：用于把指示器粘到背层的热熔胶**会渗入遮蔽涂层并使其"像被尿湿一样"变透明**，造成**干态误报**。故要求**间断施胶 + 无油分配方 + 覆盖面积 ≤ 图案面积 70 %**。这一条对任何"印刷层 + 胶粘接"结构都有普适意义。
- **"让尿到达指示层"是主要工程问题**：EP 0 776 645 用三招解决——①基片留 **≥10 mm 未粘合边**以便变形贴芯；②**波纹状（undulated）**基片，波峰触芯、波谷粘背层；③芯体开**局部压缩高密度沟槽**，自前/后区延伸到裆区并横穿指示器，把尿快速导到远处的指示器。
- **背层必须透光**：本路线**与不透光背层不兼容**；换成高遮盖白色背层后方案直接失效。与 [[SMMMS Film-Free vs Microporous Film Backsheet（无膜背层 vs 微孔膜背层）]] 的选型需联动评估。
- **未验证项 `[待验证]`**：来源未给出显色时间、最小可检出尿量、干态高湿储存误触发、循环可逆次数、色牢度与迁移数据——**这些正是 [[Wetness Indicator Glue]] 页已记录的关键参数，横向对比前须补齐**。
