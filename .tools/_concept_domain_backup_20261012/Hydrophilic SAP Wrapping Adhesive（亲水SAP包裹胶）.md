# Hydrophilic SAP Wrapping Adhesive（亲水SAP包裹胶）

> One-line definition 一句话定义：用于**在亲水环境中固定 SAP（Superabsorbent Polymer，高吸水树脂）颗粒**的功能胶层——它必须同时解决「SAP 吸液后胶层失效」与「胶层不能堵住 SAP 吸水通道」这对矛盾。
> (An adhesive layer that immobilises SAP particles in a wet environment, balancing bond retention against the risk of blocking SAP absorption.)

## Mechanism 机理拆解

1. **核心矛盾 Root conflict**：SAP 吸液溶胀会①**稀释胶层有效成分**（削内聚与粘附）、②在界面产生**巨大膨胀内应力**（微裂纹与剥离）、③而高湿环境又会干扰胶自身固化进程。结果是**湿态剪切强度随时间快速衰减**。
2. **路线一：分子设计 Molecular design**——通过亲水/疏水单体共聚制备相分离结构的**水下胶粘剂**；进而用阴离子聚合与点击化学合成结构明确的**巨型表面活性剂**（如亲水 POSS 头部 + 疏水 PS 尾部），在选择性溶剂中调控自组装形态（囊泡 / 蠕虫状圆柱体），为封装与胶基质构建提供结构单元。
3. **路线二：接枝改性 Grafting**——淀粉/纤维素骨架接枝丙烯酸再水解引入羧酸钠（生物降解 SAP 经典路线）；前沿案例是把**废弃聚丙烯酸热固性 SAP 通过开环回收转化为压敏胶 PSA**（酸碱水解断交联 → 酯化转聚丙烯酸酯），LCA 显示其全球变暖潜势优于石油基 PSA 路线。
4. **路线三：仿生协同保水 Bio-inspired water lock**——如 ESM/GOx/CSO 复合体系，用氧化催化与无机低聚物协同把水锁在固定网络中，**减少自由水对粘接网络的破坏**，从而在潮湿环境保持较高湿剪切强度。
5. **路线四：物理隔离 Physical isolation**——**微胶囊封装**（聚氨酯/聚酯双层囊壁，100–300 µm）：平时 SAP 与基材隔离，产生裂缝时胶囊破裂、SAP 遇水膨胀封堵；代价是工艺难度大、成本高。
6. **路线五：矿物复合增强 Mineral reinforcement**——SAP 与膨润土/蒙脱土复合提高力学强度，例：掺蒙脱土的聚丙烯酸系 SAP **凝胶强度 29.00 mJ/g，较未复合提高 52.6%**。

## Failure modes 失效模式 & counters 对策（结构侧）

| Failure 失效模式 | Root cause 根因（胶侧） | Countermeasure 对策 |
|---|---|---|
| 湿态粘接崩溃 Wet-state collapse | 溶胀稀释胶层 + 界面内应力 | 保水型复合体系 + 界面分散设计 |
| SAP 吸水下降 Capacity loss | 胶层堵孔 | 水性分散体特定 pH/温度涂覆，低温≤150 ℃ 交联 |
| 颗粒抖出 Particle shedding | 固定力不足 | 氨基类粘结剂替代聚氯化铝 |
| 界面剥离 Interfacial peel | 极性差异、相容性差 | 硅烷偶联剂 / 微胶囊隔离 / 矿物复合 |

## Open gaps 现存缺口（research 侧）

- **耐久数据缺口**：反复吸湿-干燥循环、动态压力、不同温度下的界面长期耐久数据不足。
- **标准缺口**：SAP-胶复合体系的界面相容性、防霉性能**尚无统一高效的标准化测试方法**。
- **性能极限**：追求超低添加量（<0.1 g/m²）时，"粘接强度 / 耐水性 / 不影响 SAP 吸液速率"存在材料学上的固有矛盾（见 [[Ultra-Low Add-On Adhesive Application（超低添加量施胶）]]）。

**已决的排程（本批新增）：**

- **8 月**：聚焦「最佳 pattern 筛选」（不加亲水胶）。
- **9 月**：在筛选出的 pattern 上**加亲水胶**（清水胶）验证。
- **不为亲水胶单独新增「无 channel」对照 code** —— 无 channel 的验证改由 **DNC 在产线穿插做 ISR**；DNC 侧评估亲水胶的 benefit，若无帮助则后续材料实验不再考虑。

**分工与路径（本批新增）：**

| Path 路径 | Owner 承担方 | Purpose 目的 |
| --- | --- | --- |
| 芯体机 + channel | 本方（COCO V6 试验） | 结合 channel 设计，为 V6 材料开发做储备 |
| 无 channel / 产线 ISR | DNC | 穿插验证亲水胶 benefit，作为是否纳入后续材料的依据 |

**重要提醒（本批新增，待决）：**

- 会议明确指出：「这个过程中，**对性能的影响可能大于亲水胶本身**」—— 即工艺/过程变量可能盖过胶本身的效应，实验解读时须先剥离。
- 胶的实验本身**耗时较长**（从排胶到胶量离线确认均需时间），排期时需与工艺侧共同确认所需时长。

✅ **验证记录（2026-09-29）**：8/9 月排程与 DNC 分工为会议已决事项；「亲水胶是否带来 benefit」**尚无结论**，须待 9 月实验与 DNC 产线验证。参见 [[COCO V6 Trial Code Design & Process Alignment（录音纪要 2026-08-17）]]、[[COCO芯体平台]]、[[Polyolefin Hot Melt Adhesive（聚烯烃热熔胶）]]。
