# 无溶剂TPU


## Definition 定义

**无溶剂 TPU**（热塑性聚氨酯）路线——行业主流，但物性波动（熟化漂移）。


## Key Points 要点

- 无溶剂 TPU 是行业主流但**物性波动（熟化漂移）**（源：与华峰集团研发及合作会议纪要）
- 简易产线调整方案（下移喷丝/热风点促挥发）约 **1 个月**出结果；复杂重卷绕退 DMF 方案**增本 20–30%**（同上）
- 与氨纶关联：无溶剂氨纶为同类「移除溶剂即移除残留路径」思路（源：无溶剂氨纶）
