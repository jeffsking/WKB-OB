# Composite Core Patent Clearance（复合芯体专利规避审查）

> 一句话定义（Definition）：对**复合芯体（composite core：蓬松无纺布 REL + 上下 SAP 层 + 上下包裹层的五层结构）**逐件比对同行已授权专利权利要求、确认我方产品是否落入其保护范围的工作方法；核心不是「改设计」，而是**找到权利要求中我方不具备的那个特征**。

## 机理 / 结构拆解（Mechanism）

1. **比对的最小单元是「特征」而非「产品」**：先把专利拆成独立特征（材料层构成、层序、槽的形成方式、压合位置、数值范围），再逐条对照我方产品「有 / 没有」。
2. **封闭式写法是最强规避支点**：专利若用「由 A、B、C 构成」（封闭式），则我方同层内**多出一种纤维/组分**即可跳出；若用「包括」（开放式），则不能靠添加组分规避。
3. **术语区分即区分**：同一专利若同时用「压槽」与「凹槽」两个术语并分别描述，则二者被解释为不同概念——我方若只落入其一（如只做「凹槽」不做「压槽」）即可绕开。
4. **背景技术中的明确排除 = 极强规避证据**：当专利在背景技术里把「蓬松无纺布」列为缺陷并改用其他方案时，任何使用蓬松无纺布的方案都被其自己排除在外，不必再比结构。
5. **数值范围是弱规避点**：孔隙率、配比、透光率这类数值限定的**等同空间极小**，差 10% 上下仍可能落入；规避要靠**实测证明不落区间**，而非靠设计描述。
6. **实用新型 vs 发明的稳定性差异**：实用新型不经过实审、范围写得越大越容易被无效；发明专利（尤其有数值限定的）相对稳定。策略上——实用新型走**无效**，发明走**规避**。
7. **结论有保质期**：FTO 结论只对**当前冻结的设计**成立；上下层 SAP 宽度差异、外层加木浆纤维、成型鼓数量变化等任一项落地都必须重做。

## 已确认的规避支点（Confirmed distinctions，仅对当前设计成立）

| 我方做法 | 对应被规避的专利写法 |
|---|---|
| **胶与 SAP 混合后一并铺于蓬松层，无独立胶层** | 「上覆盖层 / 上喷胶层 / 上高分子层」严格分层 |
| **不使用无尘纸（air-laid paper）** | 上层限定为无尘纸、下层为无纺布（两者不同） |
| **复合芯体外不加额外木浆纤维层** | 芯体外再加木浆纤维层以提升柔软与吸水 |
| **REL 不开宏观槽填塞 SAP**（开槽是为捏合上下层形成通道） | 开槽起毛装置形成宏观槽并**塞入 SAP 颗粒** |
| **无 REL 预复合步骤**（REL 直接进线） | REL 先与一层无纺布粘合形成复合层再承接 SAP |
| **导流槽靠切割 / 挡板不铺粉形成** | 折叠机构对折形成厚度差作为导流槽 |
| **芯体无纺布本身不分层**（同一层，无纤维比值差异） | 无纺布分上层纤维 / 下层纤维且比值不同 |

**由此得到的认知（本批新增）：**

1. **FTO 是双向的**：本页既有内容站在"本方规避他人专利"一侧；本次情境显示**本方的过期专利同样会被他人用来做改进专利布局** —— 专利过期后，控制点从"专利权"转为"技术秘密 + 工程 know-how"。
2. **技术外溢的主通道是人，不是文献**：K-C 无纺布部门技术人员离职创业 → 设备扩散 → 国内多家买设备。设备买主中**三家（巨富 / 俊富 / 必德福）全部没开起来**，唯一跑通的一家追加约 4,000–5,000 万元技改 —— 说明**专利可以买、工程 know-how 买不到**。
3. **区域布局决定销售自由度**：对方按"销售地"而非"生产地"布局专利（中 / 韩 / 日），与其客户区域一致。

## 追加：Resources/Open Innovation 批（2026-09-29 追加 · 2017 年谱系盘点：四个族的可检索编号与"两条腿"框架）

> 来源：[[Complex Core Landscape in China（2017-08-07 COCO F2F · 复合芯体格局与专利谱系）]]（**2017-08-07 时点快照，约 9 年前**）。

**谱系总判断（源文原话）**：「China complex core: **a brand new innovation? No!**」——**以资产（设备）创新为导向的芯体成形已被研究多年**。

| 芯体 / 归属 | 结构 · 固定机理 | **专利 / 申请号（源文列出）** |
|---|---|---|
| **DryMax（P&G）** | 印刷辊储料槽沉积 + **热塑性胶纤维网在干湿两态固定 SAP**；配化学粘合 ADL + 卷曲纤维素纤维 | **US 8206533 B2**、**US 2008/312625 A1**、**EP 2273959 B1**、**WO 2007/014235 A1** |
| **Honeycomb / Hexacore（Fameccanica）** | 两片层压元件热熔胶连接；**溶胀打开不稳定键（labile bonds）⇒ 形成通道与空隙**；配高定量热风粘合 ADL | **EP 1974705 B1** |
| **Drylock（Drylock Technologies）** | 载体层 + 辅助层 + 中间吸收材料；**超声键合 = 永久主粘合 + 临时次粘合**，溶胀打开次粘合产生新空隙；配 140–150 gsm 热风粘合 ADL | **WO 2012052172 A1**、**WO 2012052173 A1** |
| **Bostik / BASF** | 第一片材的**口袋阵列**承载 SAP + 第二片材覆盖；**口袋间珠状胶**保证完整性；**胶非水溶性** | 源文标为 "patent application"，**未给出编号** |

**"两条腿"框架（对规避审查的直接含义）**：
1. **材料创新**与**资产（设备）创新**是两条独立路径 —— **P&G / Drylock 是竞争对手（产品端）、Fameccanica 是资产供应商、Bostik 是材料供应商**。**⇒ 规避审查必须同时检索"产品专利"与"设备/工艺专利"两条线，只查一条会漏。**
2. **可被主张的构造特征被具体化** —— **"永久主粘合 + 临时次粘合"（Drylock）**、**"不稳定键"（Honeycomb）**、**"非水溶性胶"（Bostik）**都是**可写进权利要求的具体特征**。**⇒ 规避设计应在这些特征上做差异化，而不是只改层数或尺寸。**
3. **KC 自有路线的四个特征（Big Mac，2014）** —— **在线分层构筑、SAM 沉积/印花提效、不压实（no debulking）、以效率与减蓬松降本**；结构为**非织造基材 / SAM（抽吸）/ 热熔胶 / 非织造基材**。**⇒ 自有路线的可专利点集中在"印花 + 不压实 + 在线分层"。**
4. **一个易被忽略的规避维度：供应链** —— 复合芯体把**芯体成形移交给 OEM**（带胶 SAM 添加、Airlaid/TABCW 复卷），品牌商只剩层压。**⇒ 专利风险的主体也随之变化：若侵权发生在芯体成形段，责任可能在 OEM 侧。**
