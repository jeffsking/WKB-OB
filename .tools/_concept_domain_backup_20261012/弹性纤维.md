# 弹性纤维


## Definition 定义

具弹性的纤维统称；本库相关专利族指向尿裤弹性部件（腿围橡筋、弹性片材、弹性腰区等）。


## Key Points 要点

- CN 111134966 A（防漏尿裤型纸尿裤，ω 型腿围橡筋）同批可读专利：EP2413866B1、EP1581159B1、EP0820747A1，均为弹性部件主题（源：CN 111134966 A）
- PTT 弹性纤维本身具弹性（织物弹性约 20%，接近氨纶包覆丝），价格更低、尺寸稳定性好（源：功能性差别化纤维）
