# 结构色 Structural Color
> 📌 **Page completed 2026-09-30** from 6 citing sources. All figures traced to their source pages. Anything not evidenced is marked `[待补]`.

## Definition 定义

- 结构色（structural colour）= **颜色来自周期层厚 / 物理结构，而非染料分子**（"Colour from periodic layer thickness rather than from dye molecules"）—— 这正是本库变色项目背后的同一物理。（源：[[Intelligent Textiles and Sports Clothing]]）
- 在力致变色语境下：**结构色不由染料驱动而由物理结构驱动** —— 机械应变压缩胆甾螺距 → 结构间隙缩小 → 产生**可预测、可逆的蓝移**。（源：[[The Chromatic Shift（力致变色：Naphthopyran 与 HPC 双路线）]]）
- 在技术路线分类中记为 **M2 photonic-crystal structural colour**（与 M1 力色团激活、M3 CLCE 介晶取向、M4 表面起皱并列）。（源：[[Mechanochromic Materials Technical Review（EN v3, 2026-08）]]）

## Method / Mechanism 方法 / 机理

- **物理结构驱动呈色**：HPC 自然自组装为**胆甾型液晶相**，是本征力致变色材料，并**选择性反射右旋圆偏振光（RCP）** —— 肉眼或数码相机直视**无需偏振片**；应变压缩胆甾螺距 → 产生可预测、可逆的蓝移。（源：[[The Chromatic Shift（力致变色：Naphthopyran 与 HPC 双路线）]]）
- **光子晶体 / 聚合物蛋白石**：核壳 PS/PEA 颗粒经剪切组装成弹性蛋白石，可卷对卷（>100 m）；**但有序化需要加热辊间约 300% 应变幅的振荡剪切 —— 是专用产线，不是狭缝模头**。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）
- **胆甾相液晶弹性体（CLCE）**：螺距受压**蓝移**；2025 年工作引入光开关手性掺杂剂做压印图案；单轴红 → 蓝通常需 **>100% 应变**且**强度随位移下降**；成膜需**平面取向与氮气下 UV 固化**（热熔工位没有的两道单元操作）。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）
- **可拉伸 DBR（分布式布拉格反射）**：多层布拉格堆栈，NIR → 可见，但仅**在 0–50% 应变**且为共挤膜。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）
- **HPC 结构色**：羟丙基纤维素改变黏弹晶格间距，压缩蓝移（红 → 蓝），具**可预测的幂律应变—色关系（power-law relationship）**，纸面上最有吸引力；同时**可生物降解、可食用、可卷对卷连续生产**。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]、[[The Chromatic Shift（力致变色：Naphthopyran 与 HPC 双路线）]]）
- **两条共同失效模式**：（1）**湿与紫外**（水凝胶吸水同时改变力学与光学行为；UV 光降解显色单元；纸尿裤面层同时暴露于尿汽、汗液与日光）；（2）**角度依赖（虹彩）**（布拉格色随视角变化，家长一倾斜就会看到并非应变引起的变色）。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）

### 选型层面的三条教训
- **教训一（失效模式优先）**：对合身仪表而言，**角度依赖是致命失效**，选结构色路线前必须先解决**非虹彩化**。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）
- **教训二（假阴性比缺失更糟）**：超阈值后颜色会「松弛掉」，护理者会看到「安全」色而纸尿裤仍过紧 —— 这是结构色路线的**生死门**。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）
- **教训三（工艺原生性）**：蛋白石需加热辊间振荡剪切、胆甾相需平面取向 + 氮气 UV 固化 —— 这两道单元操作在热熔工位**不存在**，属**架构级不兼容**，而非配方问题。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）
- **保留观察窗口**：「非晶光子」非虹彩变体 + 硅-橡胶成本下降，值得在 **2028 平台门径**复审。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）

## Hygiene Relevance 卫材关联

- **合身 / 过紧指示的路线选择**：连续合身监测需**可逆路线（M2 结构色 / M3 CLCE）**，而一次性过紧报警可用**半可逆路线（M1 力色团）**；可逆性是本场景**硬要求**（源文原话 "reversibility is a non-negotiable requirement"）。（源：[[Mechanochromic Materials Technical Review（EN v3, 2026-08）]]、[[Structural Colour Mechanochromism（结构色力致变色）]]）
- **HPC 的幂律关系支持连续合身监测**：照护者可在调整腰围后**看到颜色回到安全基线**，把「结构色可逆性最好」落到连续监测场景。（源：[[Structural Colour Mechanochromism（结构色力致变色）]]）
- **可食性（edibility）是一等指标**：终极风险被定义为**婴儿误食耳贴 / 腰围**，这改变了材料筛选项，也是 **HPC 被称为黄金标准的唯一理由**。（源：[[Active Diagnostic Zones（主动诊断分区）]]）
- **监测 vs 记录是两种产品**：贴合监测要「可逆」（HPC 结构色的幂律关系），事件记录可用「不可逆」（naphthopyrans 的模块化信号）。（源：[[Active Diagnostic Zones（主动诊断分区）]]）
- **路线定位**：在一次性卫品量产语境下，结构色的否决来自**工艺原生性**与**角度依赖**；结论是**「等工艺，不等性能」**，列入 **2028 复审**（原文决策结构：Track B 立即推进 / Track A 维持 / 结构色 watch）。（源：[[Mechanochromic Routes Comparison（力致变色技术路线对比）]]）
- **性能天花板与供应约束**：路线 A（力致变色结构色）的 < 15.9% 线性段与 30,000 次循环是性能天花板，但受制于特种化学品供应。（源：[[Elastic Tension Visualization Technology Assessment（拉力松紧可视化技术评估）]]）
