# BNC 基 SAP 表面交联（BNC-based SAP Surface Crosslinking）

> 一句话定义：用 **50 nm × 2 μm 的 BNC 纤维**在 SAP 颗粒表面构建**共反应交联网络壳层**，替代（或叠加于）传统表面交联工艺；化学反应沿用行业成熟的**多元醇 / 碳酸亚烃酯 / 环氧化物**路线。目标是在受压场景下同时提升加压吸收（AUL）与凝胶强度。

## 机理 / 结构拆解

1. **三重收益**：
   - **提升 AUL（加压吸收/耐压）**：50 nm × 2 μm 纤维网络在 SAP 表面成网络，借 BNC 自身强度抗压——直接拉动芯体受压场景性能。
   - **液体传导，而非单纯间隔**：亲水 BNC 原纤网络**主动导液**，比惰性间隔层高一个维度。
   - **共反应交联壳**：壳层参与反应而非物理包裹——纤维素羟基与多元醇/碳酸亚烃酯/环氧化物同化学，因此带来**凝胶强度的系统性提升**。
2. **化学同源性**：该化学与行业已用于卫品的 SAP 表面处理同源（聚合物型第一剂 + 二醇类第二剂、表面交联密度由表及里递减），因此工艺路径不属于全新发明，**创新点在 BNC 纤维的引入**。
3. **与「SAP 掺 CNF」的区别**：SAP + CNF 复合（US9162007/CN102245218B/WO2010071584A1 等）是共混增强；本路线是**表面壳层共反应**，作用位置与机理不同。
4. **前置条件是商务条款而非技术**：须先确认现有合作中的排他/保密约定，才能决定是否引入我方指定 SAP 供应商——排他性核查是这条路线的「Gate 0」，谈不清楚则不进开发资源。
5. **在路线图上的位置**：六赛道中排第 2（价值高、可行性中），关键门槛=排他性核查（2 周）+ 新 SAP 测试。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[拜科瑞 BNC 发酵与发泡线纪要]]、[[BNC 技术分享（英文完整版，20260911）]]、[[PEG-多元醇 × 纤维素吸水体系交叉索引]]）：三份文档在「三重收益」与「化学走多元醇/碳酸亚烃酯/环氧化物路线」上互证，且交叉索引独立确认该化学与卫品行业成熟表面处理同源——说明**技术可行性不依赖新化学，风险主要落在商务与工艺适配**。

- **教训一（Gate 0 是商务不是技术）**：本路线的第一道门是排他/保密条款核查，**不是**性能验证。技术再可行，条款谈不清就不该分配开发资源——这是本批最明确的一条流程教训。
- **教训二（竞合边界）**：同一供应商同时与竞品在相邻方向合作（发泡垫片），因此**数据边界与信息隔离必须在 JDA 前谈定**，否则壳层技术会经由供应商流向竞品。
- **教训三（别把行业参数当自身参数）**：表面交联的 CRC/AUP 数值来自 SAP 行业既有专利，**不能直接外推为 BNC 壳层的性能承诺**。
- **待补 `[待验证]`**：BNC 交联壳层的 AUL/凝胶强度实测；BNC 用量—性能曲线；与我方现有 SAP 体系的兼容性；可量产性与工艺温度窗口。
