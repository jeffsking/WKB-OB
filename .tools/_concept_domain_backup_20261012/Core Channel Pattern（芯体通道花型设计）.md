# Core Channel Pattern（芯体通道花型设计）

> One-line definition 一句话定义：在吸收芯体的 SAP 分布层上，用**模压/绑定形成的通道（pattern / channel）**引导液体沿指定方向铺展的设计手法——目标是提升高压（坐/躺受压）状态下的扩散长度与吸收时间，而不是常温平板条件下的速度。
> (A set of moulded/bonded channels pressed into the SAP-bearing core layer to steer fluid along a chosen direction, targeting **high-pressure** diffusion and intake time rather than flat-bed speed.)

## Mechanism 机理 / 结构拆解

1. **中轴通道（central axial channel）是必需要素** —— 须有一条贯穿的中轴，且**镂空槽必须正对注液点**（行业标准注液点 = 中心靠前 35 mm；低压/cradle 注液点 = 中心靠前 85 mm）。机理：注液点下方有通道，液体第一时间被导走，而不是在尿点处堆积。
2. **侧枝（side branches）是可选项，不是必选项** —— 侧枝有助于缩短吸收时间、提升 ICP 用量利用率，但对位（上下层贴合公差）更难、工艺更复杂；可依外观与工艺难度自由调整。
3. **花型收敛为叶脉（leaf-vein）优先** —— 叶脉 = 一条中轴 + 斜向侧枝；其优势体现在**高压扩散长度**（≈330 mm 量级），而非 cradle 第三次吸收速度。
4. **绑定（bonding）宽度是工艺寿命问题** —— 3 mm 优于 6 mm（第三次吸收更快），8 mm 对模具寿命最安全；超声波下 3 mm 可用。数据上 3 mm 与 6 mm 的差异未达显著，故该点被有意弱化。
5. **分区密度由丝网孔径实现** —— 在成形网（wire mesh）中央加大孔径，配合真空吸附，使中心区域 SAP 堆积更多；**粉量与线速不变**（线速 100），因此是"重分布"而非"加量"。
6. **过度中心加密有反效果** —— 中心密度最高的方案（Code 10 类）性能并未同比例提升，疑似**凝胶阻塞（gel blocking）**。

## Experience notes 经验教训

> ✅ 验证（2026-09-29，来源 [[芯体花型设计评审会（录音纪要 20260724）]]）：本轮观察**支持**"结构分区优于材料堆砌"的组合层方向，并**修正**了一个直觉——中心 SAP 密度越高越好并不成立（Code 10 为反例，疑似凝胶阻塞）。
> ✅ 验证（2026-09-29，来源 [[IPC BCC OI 材料开发团队 2026 年度汇报大纲 v7（2026-09-17）]]）：Coco V6 Step 1 的窄通道结果与评审会结论方向一致（尿点周围窄通道改善 MD 分布、缩短高压吸收时间）。

- **教训 1（对位公差）**：模式越复杂，上下层对位误差越大——特斯拉的花型对位容错率最低，叶脉居中。设计复杂度必须与对位能力匹配。（来源：[[芯体花型设计评审会（录音纪要 20260724）]]）
- **教训 2（评价口径）**：平板（flat）条件与 U 型（cradle）条件的最优解可能相反——叶脉在平板上快速扩散，但绑定部位在 U 型下反而是积液区。筛选须分两阶段（先用平板筛 channel，再用材料匹配提升反重力输送）。（同上）
- **教训 3（规避设计的代价）**：为规避竞品专利而做的形态改造（如 Code 4）可能同时改变液体路径与工艺对位难度，需在性能与自由度之间显式权衡。具体的规避口径见 manual_review 记录，不在本页展开。（同上）

## 追加：Meeting Minutes 批（2026-09-29 追加 · 在线新品竞争与策略 workshop）

> 本节为 **S5_Areas_Meeting Minutes_01 批次** 编译时的追加记录，**不改动上方既有结论**。本批给出的是**一轮实验后总结出的 channel 设计规则**（八条口径）。

### 1. Design rules added in this batch 本批新增设计规则

1. **中间贯穿性中心导流槽**：用于覆盖不同尿点，贡献高压下 intake 加快与扩散。
2. **导流槽必须加 bonding**：否则湿态下被 SAP 膨胀抹平、丧失导流功能；加 bonding 同时提升湿态/高压吸收。
3. **bonding 必须做窄**：过宽会伤害 U 型下扩散（推测原因是超声 bonding 破坏内层纺粘纤维、影响毛细传导）；由约 **6 mm 收到 3 mm** 后影响降低，后续继续试更窄。**bonding 是双刃剑**。
4. **横向导流槽**：帮助 cradle 下水、加速 cradle intake（与第 8 条共同贡献 U 型下约 **50%** 的指标降低）。
5. **开槽宽度**：按 **8 mm / 10 mm** 设置，需匹配最终工艺难度。
6. **横向导流槽不超出 pad 边缘**，预留数毫米。
7. **导流槽不能贯通**：贯通会让液体过度扩散到前后端 → 前后漏。
8. **哑铃形（中间窄、两头宽）**：两头宽扩大 coverage（前趴/后躺防漏），中间窄提升中心区 **SAP density**（总量不变、面积收窄 → 更多 SAP 堆到中心区）。**代价是材料用量上升**，需做成本与性能平衡。

### 2. Physical limit identified 本批明确的物理边界

- **channel 是「物理槽」，不能反重力输运液体**：U 型下的扩散更多依赖**材料的毛细作用**（这也解释了行业克重走高的趋势）→ channel 解决不了的部分必须靠材料选型补。
- **形状可成型性边界**：鼓上 3D 打印样件试验表明，**圆弧形可做**；**尖角/非常尖锐的形状做不到**（尖角处 SAP 分布不均）。圆润角要做到约 **2 mm** 级才漂亮，而圆润角又影响毛细反重力爬坡。

> ✅ Validation（2026-09-29，source 来源 [[Online Core Competition & COCO V6 Strategy Workshop（在线新品竞争与策略）]]）：本页既有「channel 花型设计」的定位被本批**支持并细化**为可执行规则；同时**新增一条反直觉结论**——**bonding 过宽会伤害 U 型毛细传导**，属对既有认知的收紧而非推翻。

## 追加：COCO V6 第二轮实验批（2026-09-29 追加）

> 本节为 **S5_Areas_Meeting Minutes_01 批次（[[COCO V6 Trial Round-2 Review（录音纪要 2026-09-16）]]）** 编译时的追加记录，**不改动上方既有结论**。

### 1. Sizing rules confirmed 尺寸规则（本批收敛）

- **只加长、不加宽**：加宽被一致反对，理由有三——① 对扩散方向不利；② 宽度越大，局部无 SAP 区域越大 → **CD 方向毛细更差**（侧漏风险）；③ **channel 对 cradle 本身是负面影响**，中间越宽负面越大。
- **加长可考虑**，但必须匹配 SAP 的能力；且实际减量是「**均匀减**」，中心区域的 SAP 也会一起降低，不能假设「只减掉那两块」。
- **当前尺寸**：中间宽 **8 mm**，上下 **35**，枪面长度 **300**（385−300）。

### 2. Failed hypothesis 被数据否定的假设

- **假设**：V6 中 channel 面积约占 pad 的 **10–15%**；若维持「有 SAP 处的 density 与 5.6 一致」，则开槽面积增加后**可减少一定量 SAP 添加量而性能维持**。
- **实测**：回渗与高低压性能**无明显影响**，但**第二轮 cradle intake 与第三轮 input 明显变差**（远超 CTRL 与对照 code）。
- **收敛结论**：**下层 SAP 添加量维持约 7 g**；再降低虽对回渗影响不大，但 **U 型回渗会出现明显劣势**。

### 3. Dumbbell shape 哑铃形的新增风险

- **重量波动**：最窄模块实测值明显低于理论值，其余模块趋势一致偏低；候选成因为 **负压 / 面积 / geometry** 三者之一，**尚未区分**。
- **成本 vs 收益**：两头加宽（含 REL、PSN、IL 与包裹部加宽）带来约 **+4.8% 成本**，但第二轮侧漏测试**未看出对前后漏有帮助** → 收益未证实。

> ✅ Validation（2026-09-29，source 来源 [[COCO V6 Trial Round-2 Review（录音纪要 2026-09-16）]]）：本页既有「channel 花型设计规则」被本批**支持并收紧**——上批的「哑铃形」从「推荐设计」下调为「**收益未证实、且带来约 4.8% 成本**」，属**对既有认知的修正性收紧**（非推翻：规则仍成立，只是价值待证）。

- 导流槽方向：后端向后、前端向前（两个 code 做平行对比），目的为验证导流槽的引流作用是否提升液体横向扩散，从而改善吸收时间与回渗。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 开槽的推广史与测试口径分歧）

> 来源：[[SAP GBP Improvement & Surface Crosslinking Process Review（GDP提升工艺探讨）]]（SAP 供应商工厂交流 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**开槽是如何被普及的（本批新增，供应商口径的历史事实）：**

- 当年国内出口几乎没业务、吸收速度快的材料在木浆结构里很难推 → 供应商转而推**芯体 + 开槽**，让市场认识吸收速度快的材料。
- 具体做法：**给客户送开槽的架子**（"几乎市面上所有的槽都是我们送的"）—— 最初市面上没有槽、也没有人有槽，**刚开始推时有些客户还不接受，两年之后基本上都有槽了**。
- 演进：从"只让他们放下层槽"→ 现在**通槽的、多少槽的都有了**；现在由客户自己做。

**开槽效果的测试口径分歧（本批新增，是评估开槽时的关键陷阱）：**

| 口径 | 表现 |
| --- | --- |
| **内部测试方法** | 开槽之后，**二次、三次的吸收差**与**吸收速度**，差异**还是蛮大的** |
| **国标** | "就还好"，因为**国标有压力压上去**（仪器自带加压） |

- 本方自述："像这些 cradle 的这种测试，我们用槽的**经验不是很多，才刚开始**"。
- 会中还提到一个意外观察：某测试条件下出现"**克服重力**"的现象（平面加压 vs 无加压的差异）[待验证]。

**由此得到的认知（本批新增）：**

1. **开槽是被"送设备"推开的，不是被性能数据说服的** —— 新结构导入的阻力往往来自**缺少评估手段**，先给客户能测的工具，比先讲性能更有效。
2. **开槽的收益依赖于测试口径**：内部方法显示二/三次吸收与速度差异大，国标（带加压）则不明显 → **对比开槽效果时必须先声明测试条件**。
3. **开槽已成通用做法**，差异化空间从"有没有槽"转向"槽型 / 数量 / 位置"。

✅ **验证记录（2026-09-29）**：以上为供应商自述的历史推广过程 + 会中讨论，**无引用实测数据**；"克服重力"的观察未获进一步解释 [待验证]。参见 [[诺尔（Nuoer）]]、[[Multilayer SAP Core（多层SAP芯体）]]、[[Core Channel Pattern（芯体通道花型设计）]]。
