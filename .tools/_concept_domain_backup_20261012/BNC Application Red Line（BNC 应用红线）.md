# BNC Application Red Line（BNC 应用红线）

> One-line definition 一句话定义：本库对 BNC（细菌纳米纤维素）项目立项的**准入红线**——自 2026-09-05 起，禁止的是「以**终端材料身份**替代绒毛浆／SAP 的项目」，而**中间体／载体／增效**角色不受此限。（中文：红线管的是**角色**，不是材料。）

## Mechanism / Structure 机理 / 结构拆解

1. **The rule before 2026-09-05**：a single sentence — "do not start projects replacing fluff pulp / SAP". Its judgement basis was the substitution object, so any BNC scheme had to be expressible as "replacing X".（中文：旧红线一句话按「替代对象」判，所有方案必须能写成「替代 X」。）
2. **The measured failure**：the Baikerui PEG displacement intermediate（方向四）replaced neither fluff pulp nor SAP — its substitution object was *empty* — so the old rule blocked a route that the new rule explicitly permits.（中文：替代对象为空 → 无类别可归 → 被一刀切拦下。）
3. **The rule after 2026-09-05**：the restriction is now scoped by **role**，not by material. Prohibited role = bulk **end material** substituting fluff pulp or SAP. Permitted roles = intermediate（可复水干颗粒／母粒）、carrier（嫁接抗菌／传感／加热／变色）、reinforcer（PP 熔融／发泡）、SAP synergist or spacer（SAP 增效剂／间隔剂）。
4. **What the revision does *not* change**：the end-material finding is untouched — fermentation economics, absorption mechanism and scale economy still rule out bulk substitution, and this remains anchored to the feasibility assessment（[[BNC 卫生用品技术可行性评估（访前尽调详细版）]]）。红线修订**不软化终端材料层面的结论**。
5. **Document-history handling**：earlier documents retain their original "strictly forbidden" wording as a decision trail; where a judgement concerns intermediate / carrier / synergist roles, the 2026-09-05 notice takes precedence.（中文：历史文档原文保留为决策历史，角色类判断以修订说明为准。）
6. **The rule is deliberately self-limiting**：a reversal condition is pre-declared — if a case appears that uses an "intermediate" identity to perform substantive substitution, the rule is re-evaluated and tightened.（中文：预声明反向触发条件，防止以角色名义绕线。）
7. **Why this is a *concept* here, not merely a log entry**：it is the upstream gate on candidate-set admission for the whole BNC track, and it is the reason several downstream pages exist（[[BNC-PEG 母粒（干态可复水中介体）]]、[[Pain-Point Backward Derivation（痛点倒推法）]]）。

## Lessons Learned 经验教训

> ✅ Verification（2026-09-29，source [[BNC Application Red Line Revision 20260905（BNC 应用红线修订说明）]]、[[Pain-Point Backward Derivation Template v2（材料合作分析模板 v2）]]）：两份同族文档互证——红线误伤与模板漏项是**同一根因**（分类维度缺「交付形态／角色」），同一批次的两次修正互为闭环。（中文：本页「红线管角色不管材料」的表述与来源一致。）

- **Lesson 1（红线的措辞即工程约束）**：一句话红线可以误杀一整条技术路线。写红线时须同时写出**禁的是哪一层**（终端材料？中间体？载体？），否则下游立项会按字面执行。
- **Lesson 2（中间体是红线的边界地带）**：中间体既不替代绒毛浆也不替代 SAP，因此它天然落在旧红线的盲区。后续如出现「以中间体身份实质替代」的案例，按预声明条款收紧。
- **Lesson 3（历史与现行并存要写清优先序）**：历史文档保留原文会导致同一知识库出现两种红线表述——本页必须显式写明「角色类判断以 2026-09-05 修订说明为准」，否则查询时会产生矛盾结论。
- **待补 `[待验证]`**：红线修订在后续立项评审中的实际引用记录；是否存在其他材料（非 BNC）同样需要角色化表述的类比红线。
