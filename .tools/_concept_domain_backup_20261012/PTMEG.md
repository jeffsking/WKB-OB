# PTMEG


## Definition 定义

聚四亚甲基醚二醇（Polytetramethylene Ether Glycol），氨纶（聚氨酯弹性纤维）的关键软段原料。


## Key Points 要点

- **生物基路线成本口径**：bio-PTMEG 原料成本为常规的 **3.3 倍**；掺 30% 后总成本 **1.5–2 倍**（玉米芯路线）（源：与华峰集团研发及合作会议纪要）
- 生物基 PTMEG 存在**回弹损失、耐温差**问题；正与汉高开发低温胶，若无法平替则需规格加粗 10–20%（同上）
