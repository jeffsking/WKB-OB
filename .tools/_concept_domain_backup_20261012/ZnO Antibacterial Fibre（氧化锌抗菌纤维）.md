# ZnO Antibacterial Fibre（氧化锌抗菌纤维）

> One-line definition 一句话定义：将纳米氧化锌（ZnO）抗菌剂**加入纺丝熔体**制得的功能涤纶——抗菌/抑菌、除臭、抗紫外三效合一，属**非溶出型（in-melt）**路线，区别于后整理表面抗菌。

## Mechanism 机理 / 结构拆解

1. **接触反应（主要抗菌机理）**：Zn²⁺ 借库仑引力吸附带负电的菌体细胞膜 → 穿透细胞壁与巯基（-SH）反应 → 蛋白凝固、合成酶失活、丧失繁殖能力；菌体失活后金属离子重新游离、**重复杀菌** → 抗菌效果持久（厂商口径）。
2. **光催化反应**：ZnO 为 N 型半导体，经纳米化 + 表面处理后光催化效应大幅提升——日光/紫外甚至无光下激活水与氧产生 ·OH 自由基与 ·O2⁻，短时破坏细菌繁殖能力。
3. **除臭延伸**：光催化将小分子臭味物（**氨气、醋酸、异戊酸、甲醛**）分解为水与 CO₂——与吸附型除臭（沸石/活性炭，见 [[Zeolite Odour Control（沸石除臭载体）]]、[[Powdered Activated Carbon（粉末活性炭）]]）机理不同，属**分解型**。
4. **非溶出判据**：广微测检测中**抑菌圈宽度 ≤5 mm** 为溶出安全性合格线——区分「溶出型抑菌」与「接触型抗菌」的关键指标。
5. **工程含义（卫品）**：in-melt 路线抗菌组分在纤维体内，耐水洗/耐摩擦优于表面涂层；但需评估 ZnO 纳米颗粒的皮肤接触与法规口径（OEKO-TEX 附录、GB 相关标准）。
