# 益生菌


## Definition 定义

益生菌（护肤/益生元）项目——通过面层向皮肤递送益生元。


## Key Points 要点

- 技术路线两条：**路线 A 为热熔胶直接涂布**（现有胶枪系统，不开热熔、气压齿轮泵），不锁死活性，靠迁移保证转移到皮肤的量（源：会议纪要：FEI & OI 益生菌项目）
- 施加量约 **3 克/片**，转移到皮肤起效量约 **6 毫克**（同上）
- 局限：水溶性成分兼容性、粘度适配（刮枪粘度不能太高）（同上）
