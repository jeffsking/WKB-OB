# 低温PP


## Definition 定义

低熔点聚丙烯（熔点约 **140℃**），作为 TBCW 底层降本替代材料。


## Key Points 要点

- TBCW 底层（Bottom Layer / Spun Bond）由 20 gsm 降至 12 gsm 即足够，并**建议改用低温 PP（熔点约 140℃）替代昂贵的皮芯 PE/PP 材料**（源：KC 团队内部技术讨论会（TBCW 在线超声波复合工艺））
