# Styrenic Block Copolymer Hot Melt（SIS-SBS 苯乙烯嵌段共聚物热熔胶）

> One-line definition 一句话定义：以 **A-B-A 型苯乙烯嵌段共聚物**（如 SIS 聚苯乙烯-聚异戊二烯-聚苯乙烯、SBS 聚苯乙烯-聚丁二烯-聚苯乙烯）为弹性体骨架，复配**增粘树脂 + 增塑油 + 抗氧剂**构成的热熔胶体系；其性能不是由"用什么牌号"决定，而是由**四个分子量参数是否同时落在窗口内**决定。

## Definition / Mechanism 定义与机理拆解

1. **两相结构是全部性能的来源**：硬相 = 两端**聚苯乙烯嵌段（A）**，提供强度与耐热（物理交联点）；软相 = 中间**聚异戊二烯（SIS）或聚丁二烯（SBS）嵌段（B）**，提供初粘与柔顺。
2. **本案的核心命题是高 PS 嵌段分子量 + 低整体分子量**：PS 嵌段做到 **12,000–20,000**、整体仍只有 **60,000–110,000**——即少量很长的硬嵌段配短的总体链长，从而**同时拿到高耐热与低粘度**（见 [[US5266394A Disposable Articles Containing SIS Block Copolymers (Dow)]]）。
3. **四个参数必须同时命中**：苯乙烯含量、整体分子量、中嵌段分子量、PS 嵌段分子量——来源明确写着"It is required that **all four** of these parameters fall within the ranges"。任一出界，性能塌陷（对照例的 35 ℃ 保持可从 >3,900 min 掉到 80 min）。
4. **典型配方窗（按权利要求口径）**：嵌段共聚物 **15–35 wt%**（优选 20–30）；主增粘树脂 **45–70 wt%**；增塑油或次级增粘树脂 **0–30 wt%**；稳定剂 **0.1–2 wt%**；且苯乙烯相应占共聚物 **≥27 至约 50 份 / 100 份**。
5. **为什么要在"低到不损伤聚烯烃基材"的温度施胶**：应用场景是把 PE/PP 膜粘到薄纸、无纺布或绒毛浆上（multi-line 结构），PE/PP 受热易变形，因此**低粘度低温施胶**不是节能选项，而是成品良率前提。
6. **SIS 与 SBS 之争有明确反例**：来源认为在当时以 SBS 为优的既有论断（US 4,526,577）之外，本案 SIS 反而以**更低粘度、更高 SAFT、更长剪切保持、更好的 PE 剥离**胜出。
