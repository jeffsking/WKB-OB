# Coform Composite Nonwoven（熔喷-木浆复合非织造）

**一句话定义**：把**熔喷 PP 纤维（meltblown polypropylene）**与**木浆纤维（fluff pulp / cellulose）**在同一成形过程中直接复合而成的非织造材料 —— 木浆提供吸收与蓬松，熔喷纤维提供连续相与强度；典型用于湿巾基材，本库关注其在**纸尿裤芯体包裹层（core wrap）**上的迁移可行性。

> 名称说明：ASR 转写中只描述为"熔喷 + 木浆"、设备型号读作「MPM / NPN」，未出现 "coform" 字样；本页按技术同源性（源头为 K-C 的 coform 技术谱系，会中明确"这个技术最早是我们公司"）定名为 **Coform Composite Nonwoven**，**命名本身属推断，标 [待验证]**。

## 机理 / 结构拆解

| 环节 | 内容 |
|---|---|
| 复合方式 | 熔喷头（左右对称、共 **4 组**）喷出 PP 纤维的同时，木浆经**针式锯齿粉碎机**开松后落入同一成形区 → 纤维**在线复合**，非后道贴合 |
| 木浆的作用 | 提供**吸收性、蓬松度、手感**；处理浆开松更好、蓬松度更高 |
| 熔喷的作用 | 提供**连续相与强力**；PP 比例越高 → 强力越高、成本越高 |
| 克重可设计性 | 供应商口径 **20–200 gsm** 均可做；**低克重的产能低于高克重**（速度更慢） |
| 双色实现 | 在不同熔喷头组分别加入 **3–4% 色母粒（masterbatch）** → 可做**正反面异色**；已验证色母对强力**基本无影响** |
| 对位（registration）边界 | **做不了**"中间白 + 两边带色"的需对位构型；只能做正反面/单边带色 → 设计上必须规避对位切 |

## 关键参数表

| Item 项目 | Value 数值 | Note 备注 |
| --- | --- | --- |
| 目标克重（芯体包裹层） | **20 gsm**（上限可接受 25 gsm） | 越薄越好，但受强度约束 |
| 现有强力 | **6–6.5 N** | 20 gsm 样品，干态 |
| 高速机门槛强力 | **8–9 N**（需 +2 至 +2.5 N） | 对应 **900 片/分钟** 的纸尿裤线 |
| 木浆 / PP 配比 | 现约 **40 / 60**；可上调 PP 至 **70 / 30** | 上调 PP 推高成本 |
| 熔喷头孔密度 | 本方建议 **≥60 孔/英寸（25.4 mm）** | 现设计值未知；国内熔喷装备能力存疑 |
| 熔喷头组数 | **4 组**（左右对称 2×2） | 主机核心部件已无改造空间 |
| 色母粒添加量 | **3–4%** | 对强力基本无影响（供应商已测） |
| 压花辊（离线） | 便宜 **15–16 万元** / 贵 **30 多万元**（人民币） | 速度慢、会增加材料成本 |
| 压花辊（在线） | **30 多万欧元** | 本方判断无必要；高速（500+ m/min）下热压辊受热旋转产生离心/弧形变形，中间压得上、两边压不住 |
| 花纹影响 | 花纹由**大改小**、或改做**更致密压点** → 可能提升强度（不改配方） | 供应商**不保证** |
| 绒毛浆等级 | 现用**半处理浆（semi-treated）**；**全处理浆被排除**（吸水后塌缩严重） | 未处理浆扩散更好但熔喷压力更大 |
| 产能 / 开机率 | **40 吨/天**；开机率约 **50%** | 供应商口径 [待验证] |
| 包装形态限制 | 目前**做不了纺锤形卷** | 未获授权 [待验证] |

## 强度提升的三条路线（Levers to raise strength）

1. **配方 lever**：提高 PP 比例（40/60 → 70/30）。最有效但**直接推高成本**，与"降本"目标冲突。
2. **压花 lever**：花纹改小 / 加密压点。在**不改配方**前提下可能有效，但供应商不保证；受现有压花辊资产约束（离线便宜但慢、在线很贵）。
3. **熔喷密度 lever**：提高喷头孔密度（本方建议 ≥60 孔/英寸）。同时改善**强度与手感**，但受国内熔喷装备能力限制，且供应商不清楚现设计值。

> ⚠️ **配套的隐性约束**：只堆强力不够 —— 还需同步调整**断裂伸长（elongation at break）**。若强力提升而伸长不调，材料会从"变形"直接变为"**脆断**"；同时需控制 **CD 方向的收缩/变形**，核心增量在 **MD 方向强度**。

## 经验教训

1. **低克重 ≠ 可用**：20 gsm 在干态可被拉断测试接受，但**湿态明显发脆、湿强不足** —— 评估包裹层材料必须**湿态测**，不能只看干态强力。
2. **"900 片/分钟"是分水岭**：国内同行（芯体供应商、国产低速机客户）对强度要求不高，恰恰因为他们**速度慢**；一旦上 K-C 高速线，同一材料立刻不达标。**供应商的既有客户名单不能证明高速适用性**。
3. **技术谱系回溯有价值**：该设备技术在国内的三家买主（巨富 / 俊富 / 必德福）**全部没开起来**，唯一跑通的一家追加约 4,000–5,000 万元技改 —— 说明**同类设备的工程化难度极高**，不能只看"有设备"。
4. **对位（registration）是硬性能力边界**：能否做对位切决定了花型/双色设计的自由度；本方为规避对位而改设计（正反面异色），是**用设计换工艺可行性**的典型做法。
5. **成本与强度是两个独立门槛，且顺序固定**：本方口径为"**强度上不去，价格没意义**" —— 先解决可制造性，再让采购进场谈价。

**TripleClean™ 结构（本批新增）：**

| Item 项目 | 内容 |
| --- | --- |
| 成形原理 | **含木浆与聚合物的气流混合成网** |
| 结构 | **熔喷 / 木浆 / 熔喷 三明治（sandwich）**，**成形后压花** |
| 功能分工（一句话） | **聚合物纤维提供湿强，木浆纤维提供吸收** |
| 单片用量 | 木浆 **1.34 g**（约 **200 万根**纤维）+ PP **0.5 g**（约 **35 英里**长纤维） |
| 单片干重 | **1.84 g** |
| 木浆占比 | **实测 72.8%**（高于标称 **2/3**） |

**全球规模（本批新增）：**

- **10 条 coform 线 / 20 个 bank / 约 400 亿片/年** → 推算 **木浆约 53.6 kt/年、PP 约 20 kt/年**。
- KC 婴儿湿巾**转换资产 8 个厂区**（Maumelle 美、Tlaxcala 墨、Cali PDC 哥、Suzano 巴、Pilar 阿、Flint 英、Taejon 韩、Tuas 新）；**coform 资产 7 个厂区**（Cali 有转换但无 coform）。
- **Taejon 是亚太两个厂区之一**（另一个 Tuas），**同时具备 coform 与转换能力**。

**由此得到的认知（本批新增）：**

1. **"湿强来自聚合物、吸收来自木浆"是本材料的分工定义** —— 这解释了为什么低克重化会先撞上强度墙：克重降下去，提供湿强的那一相也一起降。
2. **木浆占比实测 72.8% 高于标称 2/3** —— 说明实际配方偏向木浆（吸收），**湿强侧是稀缺侧**；提升强度应优先考虑**聚合物相的连续性**（PP 比例、熔喷密度、压花），而不是加木浆。
3. **规模数据给出了"单片用量"这一可迁移口径**：1.84 g/片（1.34 g 浆 + 0.5 g PP）—— 可用于任何以片为单位的成本/碳排估算。
4. **参观湿巾厂时的否决项是"工厂系统性卫生"**（"防腐剂不能防护系统性的工厂卫生问题"）→ 查**水系统、储罐/管道 CIP 周期、沉降菌与浮游菌记录**。这与湿巾的产品属性（含水、直接接触皮肤）直接相关。
