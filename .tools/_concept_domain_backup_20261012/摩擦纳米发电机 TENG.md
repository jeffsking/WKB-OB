## Method / Mechanism 方法 / 机理
- **自供电传感定位**：TENG 被视为无源传感器（self-powered sensor）的重要方向——Zhong Lin Wang 综述的自供电传感器对智能纺织品 / 卫生用品传感有直接意义（源：[[Wearable Electronics (National Science Review 2023)]]）。
- **可穿戴电子坐标中的位置**：可穿戴电子分两大主流方向——① 薄膜电子器件（减小一个维度 → 最薄化 → 最佳柔性）；② 纤维形态电子器件（减小两个维度 → 可编织为高柔性透气纺织品 → 可水洗数百次）。TENG 与可穿戴显示、人工肌肉、界面键合、热拉伸纤维、辐射冷却、表观电子学同列十大前沿方向（源：[[Wearable Electronics (National Science Review 2023)]]）。
- **领域定位**：可穿戴电子是化学 / 物理 / 材料科学与工程 / 电气工程 / 生物医学工程的交叉多学科领域（源：[[Wearable Electronics (National Science Review 2023)]]）。

## Hygiene Relevance 卫材关联
- 作为**无源传感器**方向，对智能纺织品 / 卫生用品传感有直接意义（源：[[Wearable Electronics (National Science Review 2023)]]）。
- 与可穿戴传感器、电子纺织品、柔性电子、健康监测、辐射冷却材料构成智能可穿戴技术簇（源：[[Wearable Electronics (National Science Review 2023)]]）。
- 与智能包装等卫材指示类应用同属“功能化外层”技术方向（源：[[智能包装 Smart Packaging]]）。
