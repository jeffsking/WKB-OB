# Acquisition (Liquid Guidance) Test（导流性能测试 / STM-00060）

> 一句话定义：在**斜面板（inclined plane）**上以定量蒸馏水冲击样品，测**到达收集端的液体量**，用以评价纸尿裤的**导流性能（Acquisition / Liquid Guidance）**——即液体被快速导入并沿产品输运、而非在注液点就地积滞的能力。

## Definition 定义 / Principle 原理

导流性能关注的是"液体去向"：若产品导流好，液体被迅速吸入并横向/纵向输运，到达斜面收集端的量就少；若导流差，液体在注液点附近积滞并顺斜面下淌，收集端量就多。它与**扩散（spreading）**互补——扩散看铺展多远，导流看是否"被带走"。两者共同指向 ADL/面层的结构设计。

## 经验教训

- **导流与扩散要成对看**：导流差常表现为收集端量大，但未必扩散短；评价 ADL 应两者并重。
- **待补 `[待验证]`**：合格导流基准；与回渗/滑渗的关联判据。
