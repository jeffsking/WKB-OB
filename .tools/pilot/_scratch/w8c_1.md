## SAP 四大核心指标拆解与说明

## 1. CRC — Centrifuge Retention Capacity（离心保留容量）

定义：SAP在无压力自由吸液后，经离心脱去未结合水，每克干树脂保留的液体克数。

测试方法（茶袋法/EDANA ERT 441.2）： 1. 称取W1克SAP装入茶袋 2. 浸入0.9% NaCl溶液30分钟，自由吸液 3. 离心（250g，4分钟）脱去未结合水 4. 称重W3 5. CRC = (W3 - W2 - W1) / W1（W2为空茶袋离心后重量）

典型值：

|SAP类型|CRC (0.9% NaCl)|备注|
|---|---|---|
|纸尿裤用普通级|30-40 g/g|釜式/带式工艺|
|纸尿裤用高端级|40-50 g/g|釜式工艺+表面交联优化|
|生物基SAP|20-40 g/g|比石油基低20-50%|
|纯水测试|300-1000 g/g|不代表实际使用性能|


关键提醒：CRC衡量的是"自由吸液最大容量"，相当于SAP的"理论天花板"。但纸尿裤实际使用中SAP是受压的，CRC高不代表使用时真能吸这么多。CRC是基础，AUL才是实战。

CRC偏低的常见原因： - 内交联密度过高 → 网络空间小，容水量少 - 表面交联过度 → 吸液速率慢，30分钟未达平衡 - 粒径偏大 → 比表面积小，吸液不充分

## 2. AUL — Absorbency Under Load（载荷下吸收量）

定义：SAP在特定压力下吸液后，每克干树脂保留的液体克数。模拟宝宝坐/躺压在纸尿裤上的真实工况。

测试方法（EDANA ERT 442.1）： 1. 称取W1克SAP置于带孔平底圆柱容器中 2. 施加规定压力（0.3 psi / 0.7 psi / 0.9 psi） 3. 底部接触0.9% NaCl溶液，吸液60分钟 4. 称重W3 5. AUL = (W3 - W1) / W1

不同压力下的典型值：

|压力条件|普通SAP|高端SAP|对应场景|
|---|---|---|---|
|0.3 psi (~2.1 kPa)|25-30 g/g|30-35 g/g|轻压，坐姿瞬间|
|0.7 psi (~4.8 kPa)|18-25 g/g|25-30 g/g|纸尿裤核心指标，宝宝体重压迫|
|0.9 psi (~6.2 kPa)|15-20 g/g|20-25 g/g|重压，学步期集中受力|


行业标准：纸尿裤用SAP，0.7 psi下AUL ≥ 25 g/g为合格，≥ 28 g/g为优质。

AUL与CRC的关系：

|指标|测试条件|衡量什么|纸尿裤相关性|
|---|---|---|---|
|CRC|无压，自由吸液|理论最大容量|基础参考|
|AUL|加压，受限吸液|实际使用保水力|直接决定反渗|


AUL是CRC的"打折版"——AUL/CRC比值越接近1，说明SAP加压后保水能力越强。高端SAP的AUL/CRC比值可达0.6-0.7，普通产品只有0.4-0.5。

AUL偏低 = 反渗——宝宝坐着的时候，尿液被压回面层，红屁屁的元凶。

提升AUL的核心手段： - 表面交联处理：形成致密"壳层"，受压时凝胶不塌陷 - 高凝胶强度内核：内交联剂引入刚性基团，构建"支撑骨架" - 无机纳米材料掺杂：蒙脱土/MMT充当物理交联点，凝胶强度可提升50%+

## 3. GBP — Gel Bed Permeability（凝胶床渗透性）/ 也称SFC — Saline Flow Conductivity

定义：SAP吸液溶胀后形成凝胶层，液体透过该凝胶层的速率。衡量的是"第一次吸完后，后续尿液还能不能穿过去"。

测试方法（EDANA ERT 470.2）： 1. 将定量SAP置于特制圆柱容器中 2. 施加0.3 psi压力，吸0.9% NaCl溶液至饱和 3. 维持压力，从顶部持续注入盐水 4. 测量单位时间透过凝胶层的液体量 5. SFC = K × (Q / ΔP)，单位 ×10⁻⁷ cm³·s/g

典型值：

|SAP类型|SFC (×10⁻⁷ cm³·s/g)|表现|
|---|---|---|
|普通SAP|5-15|凝胶堵死，后续尿液难以通过|
|高端SAP|20-40|凝胶层保持通透，多次吸收性能好|
|超高端（多孔/复合交联）|40-70|凝胶层几乎不阻塞|


GBP/SFC为什么是"隐藏boss指标"：

CRC和AUL都只测单次吸收。但纸尿裤的真正考验是多次吸收——宝宝一天排尿5-8次，第3次、第5次尿液到达芯体时，SAP已经吸水膨胀成凝胶。如果凝胶互相粘连堵死通道，后续尿液就无法穿透，只能从侧边漏出。

GBP/SFC低的表现： - 第1次尿：秒吸 ✅ - 第3次尿：吸不进去，从侧边漏 ❌ - 这就是"前几次不漏，后面必漏"的根本原因

提升GBP的核心手段： - 二次/多重表面交联：保持颗粒吸水后独立性，防止粘连 - 不规则颗粒形态：堆积时形成毛细管缝隙（釜式工艺天然优势） - 添加纳米SiO₂等"隔离珠"：物理阻隔凝胶贴连 - 控制粒径分布：适当粗细搭配，粗颗粒形成骨架通道
