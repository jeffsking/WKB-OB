#   Blade Folder

* How does it work?

$\bullet$ Fold product in half before heading to stacker

* Consists of a set of (2) timed blades that are independently servo driven and one belt for quick phasing response

* Examples:

* BCC and DEPEND use one set to make bi-fold

$\bullet$ Pads machines use two sets to make tri-fold
