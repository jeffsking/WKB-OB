#   Unwinds

![](1/parseimages/figured6d8015a71ad469c8c4c068a0deba525_0_1.png)
Purpose – Feed material into our converting machines at a constant speed and tension without the need to shut down to splice in new rolls.

#   Main Components:

1. Spindles – Hold rolls of material in place and are driven.

2. Splice Unit – Fastens the web from the staged roll onto the running roll, then cuts the expiring roll.

3. Festoon (Accumulator/Buffer) – A stack of rollers on a moving carriage that creates web storage for zero speed splices

4. Dancer – Controls the web tension into machine by controlling the speed of the feed roll

#   Process Draws

Control Point: Any point in the process that drives the web continuously and at a fixed speed.

Control Point Examples: driven wrapped rolls
driven nip rolls
vacuum conveyors
function rolls

Draw: The percent difference in speed between two control points.

This effect puts tension on materials being fed into the machine

Why Important:

$\bullet$ Too much draw creates high web tensions which necks down the web as it is stretched or even worse the material breaks

$\bullet$ Too little draw creates low web tensions which makes webs loose, and floppy, and wrinkles or weaves because it is not being controlled

$\bullet$ Different draws are needed depending on material type, basis weight, (single vs. multi-materials) etc.

#   Web Guides

#   Purpose of web guides:

$\bullet$ Accurately control CD web position going into critical operations in a process. Ex: before die cutters, adhesive applicators, laminators, etc.

$\bullet$ Make it possible to process a "non-ideal" web.

#   Web Guides

#   Web Guide Components

1. Actuator: Receives signal from Controller and mechanically moves the web.

2. Sensors: Measures edge of web and sends a position signal to the controller.

3. Controller: Analyses the sensor signals and decides what action must be taken and sends signal to the actuator.

These operate in a closed loop manner to correct any web disturbances
