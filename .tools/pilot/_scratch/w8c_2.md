## 4. Vortex — 涡流时间（Vortex Time / Absorption Rate）

定义：SAP接触液体后，吸收至液面漩涡消失所需的时间。直接反映吸液速度。

测试方法（行业通用，非EDANA标准）： 1. 量取50 mL 0.9% NaCl溶液放入烧杯 2. 加入1克SAP，立即启动磁力搅拌（500-600 rpm） 3. 液面形成漩涡 4. SAP吸液，液体变稠，漩涡逐渐消失 5. 漩涡完全消失的时间 = Vortex Time

典型值：

|Vortex时间|评级|适用场景|
|---|---|---|
|≤ 30秒|极快|高端纸尿裤（首次瞬吸关键）|
|30-45秒|快|纸尿裤标准要求|
|45-60秒|中等|卫生巾、成人失禁|
|> 60秒|慢|农业保水剂（不需要快吸）|


Vortex慢的后果： - 尿液到达芯体后不能即时锁定，沿导流层扩散到边缘 - 面层湿感时间延长，消费者直接感知"不够干爽" - 与ADL导流层不匹配：导流层把尿液送到了，SAP却来不及接

影响Vortex的关键因素：

|因素|影响方向|机制|
|---|---|---|
|粒径小|Vortex时间更短（更快）|比表面积大，接触液体更快|
|表面交联过度|Vortex时间更长（更慢）|表面"硬壳"阻碍液体渗入|
|多孔结构|Vortex时间更短（更快）|毛细管效应加速液体进入|
|内交联密度高|Vortex时间更长（更慢）|网络膨胀慢|


Vortex与AUL的trade-off：这是SAP设计最核心的矛盾—— - 要Vortex快 → 粒径小、表面交联浅 → 但AUL低（受压保不住水） - 要AUL高 → 表面交联深 → 但Vortex慢（吸液速率慢）

解法：内层低交联（快吸）+ 外层高交联（保水）= 表面交联梯度设计，这也是釜式工艺的核心优势所在。

## 四指标联动关系

CRC ──→ 理论天花板（能吸多少）
 │
 ▼
AUL ──→ 实战保水力（压着能留多少）←── 决定反渗
 │
 ▼
GBP ──→ 多次吸收通透性（吸完还能不能继续吸）←── 决定漏尿
 │
 ▼
Vortex ──→ 首次响应速度（多快接住第一波）←── 决定瞬吸干爽感

纸尿裤芯体设计的本质：在四指标的矛盾中找平衡——

|矛盾对|取舍逻辑|
|---|---|
|CRC vs AUL|交联度↑ → CRC↓ AUL↑ → 高端产品牺牲5-10% CRC换AUL|
|Vortex vs AUL|表面交联↑ → Vortex慢 AUL高 → 梯度交联解耦|
|GBP vs CRC|两者同向，GBP高的产品CRC通常也不低|
|Vortex vs GBP|粒径小→Vortex快，但细粉多→GBP可能下降|


选型一句话： - 高端纸尿裤：AUL ≥ 28 g/g（0.7 psi）+ Vortex ≤ 35s + SFC ≥ 30 - 主流纸尿裤：AUL ≥ 24 g/g + Vortex ≤ 45s + SFC ≥ 15 - 生物基SAP：当前AUL比石油基低20-30%，需重点攻关
