#   Cut and Place (a.k.a. Slip-cut)

![](1/parseimages/figurebe1535d615584a65b631b4bdcf6d4856_0_1.png)
#   Single speed within a module

#   How does this work?

$\bullet$ Incoming material travels slower than the base web

$\bullet$ Applicator travels at the base web speed

$\bullet$ Material "slips" on the applicator as it's being pulled until it gets cut

$\bullet$ Cut material speeds up and gets applied to the base web

#   Common issues & solutions

$\bullet$ Vacuum pattern is critical

* Gap is critical – too big, it won't stick, too small, it can cause web handling issue

* JOA applicator for surge

#   Matched Speed

(a.k.a. Re-pitch)

2 or more speed within a module

* When do we use this?

$\bullet$ Nature of the component and web makes it difficult for Cut and Place

* Example: Insert Applicator for DEPEND

* How does this work?

* Re-pitch modules are based on rotation

* Linear velocity (fpm) = Angular velocity (rpm) X radius (ft)

* Works by changing the effective radius throughout the cycle

$\bullet$ Not all re-pitch modules rotate components or products

* Examples:

* OSCAR module (WEA, Insert Application)

GDM Zero Waste Ear module
