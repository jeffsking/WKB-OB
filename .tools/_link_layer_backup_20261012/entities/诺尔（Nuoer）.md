## 追加：Open Innovation 批（2026-09-29 追加 · 高 GBP 拜访预案）

> 本节为 **Resources / Open Innovation 批（批次 S4_Resources_Open Innovation_05）** 编译时的追加记录，**不改动上方既有结论**。上方"COCO V6 试产 SAP 指定供应商"的定位在本批仍成立；本节补充的是**高 GBP 方向的完整开发预案**，并把本页此前的 Code X 记录放到一条更长的目标链上看。

### 1. 本批新增：工艺路线与 GBP 天花板

- **工艺路线**：**釜式反应器（Batch Reactor）+ 先聚合后中和**，与 **SDP、Satellite CR7 系列同源**；反应时间 **5–10 小时**（带式为数分钟）。见 [[Nuoer High-GBP SAP Visit Plan & Roadmap（诺尔高GBP SAP拜访预案）]]。
- **釜式工艺的三项 GBP 底层优势**：① **不规则多边形颗粒形态** → 堆积时形成毛细缝隙；② **高分子量骨架** → 弹性回缩力强、颗粒不易变形塌陷；③ **低可萃取物** → 凝胶致密、颗粒独立性强。因此判断为**不需改核心聚合工艺，重点在表面处理环节突破**。
- **当前 GBP 天花板约 35 Darcy（NR511）**，而行业标杆为 **50–96 Darcy**（BASF 5400 = 65、LG LK804ND = 53、SDP SG-N210 = 80 / SG-N212 = 96、Satellite 710 = 75）。→ 现有产品适配 **SAM% 55–70%** 的芯体，**不足以支撑 70–85% 及以上的薄芯/无绒芯**。
- **一条重要旁证**：**同为釜式的 SDP SG-N210/N212 曾做到 80 / 96 Darcy**——说明**釜式本身不是 GBP 的天花板**，瓶颈在表面处理。

### 2. 本批新增：目标牌号 NR-GBP-H 与三条路径

| 项 | 内容 |
|---|---|
| 目标牌号 | **`NR-GBP-H`**（High GBP Grade） |
| 两阶段窗口 | 一阶段 CRC ≥29 / AUL ≥17 / **GBP ≥50** / Vortex ≤40；二阶段 CRC ≥28 / **AUL ≥18** / **GBP ≥65** / Vortex ≤35 |
| 硬约束 | **CRC ≥28 不可逾越**（薄芯最低要求） |
| 路径① 表面交联调控 | 预期 **35 → 45–55 Darcy** |
| 路径② 离子相互作用涂覆 ⭐ | 聚胺 + 多价金属盐（Al³⁺/Ca²⁺）复合涂层，来源 **CN101111271A**；在①基础上**再 +15–30 Darcy** |
| 路径③ 无机粉末隔离 | 纳米 SiO₂ 后处理，**+5–15 Darcy**（辅助，需评估粉尘与消费者感知） |
| 前置任务 | **AUL 是 GBP 的必要不充分条件**——NR511 的 AUL 仅 14.7–15，须先提到 **≥18** |
| 周期 | 乐观 **12–15 个月**、保守 **18–24 个月**；三道 Gate 分别在第 18 / 32 / 40 周 |

## 追加：Meeting Minutes 批（2026-09-29 追加）

- **2026-09-16（实验评审）**：讨论「为什么 SAP 限定在诺尔」——
  - **优势一**：相对其他供应商，在开发**高 GBP 且更均衡**的 SAP 方向上有优势（各有优势，非全面领先）。
  - **优势二（本批新增，为核心）**：**后道/后段表面交联的技术手段更多**——其**三条工艺路线**都可在外壳强化上做功能改善，因此能开发出高 GBP 的 code。
  - **策略讨论（本批新增）**：会上建议**实验阶段先把 window 打开**——用其他公司现成牌号**先证明 concept 可行**，再让诺尔跟进开发，而不是等诺尔开发完再验证。
  - **其他候选**：satellite（与诺尔的 cross-link 工艺相对接近）、住友（日系，**纯水数据很好，但生理盐水测试无强优势**）。日系与德系整体未见明显优势。
- **风险（本批新增）**：**混合 SAP 在运输过程中会上下分层** → 生产端到产品存在差异；国内以提高性能为目的的混合 SAP 厂商不多。

## 追加：Meeting Minutes 批 · 蓝湾厂区工艺流程讲解（2026-09-29 追加）

> 来源：[[SAP Production Process Walkthrough — Polymerisation, Grinding & Surface Treatment（I sap生产流程介绍）]]（蓝湾厂区会议室工艺讲解 + 现场参观 ASR 转写，日期 [待验证]）。本批只**追加**，不修改既有结论。
> 承接上批：上批记录了"**次日先在会议室由销售讲一遍工艺 → 参观蓝湾新厂 + 展厅**"的安排，本批即该次讲解的落地内容。

**产线构成（本批新增）：**

| 工序 | 现场事实 |
| --- | --- |
| 原料 | **丙烯酸 + 中水**（自来水 / 去离子水），经静态混合器进混合罐（搅拌 + 降温） |
| 聚合 | **吹氮排空** → 低温聚合；**后中和**（先聚合后加碱）；**10 个聚合罐**轮转（小罐慢跑，靠罐数换连续） |
| 干燥 | 造粒 → 滚筒**燃烧热风**烘干，**进风温度最高 500 ℃**；尾部**强磁磁选**除铁屑 |
| 研磨 | **全干态**闭环：摇摆筛 + 磨机，粗料回粉碎；**色选机**剔黑点/脏料；三分类（回磨 / 合格 / 细粉回胶体） |
| 后处理 | **上层表面交联剂 + 下层抗静电/抗黄变/抑菌**（离子交换涂布）；**约 130 ℃** 二次烘干 |
| 混料 | 高速混合机 → 膨料机 → **双轴搅拌**（分步加料）；**绞龙只做计量，与添加剂 DCS 连锁** |
| 粒径 | 成品 **300–600 μm**；筛网固定，**30 目以下合格、30–50 目也可**；半成品粒径**刻意偏大** |
| 包装 | **色选机 → 磁选器 → 过筛防结块 → 精检仪（金属，报警即剔除隔离）** |

**质量控制的真实水平（本批新增，对来料一致性评估直接相关）：**

- **开环控制**：**无在线固体粒径监测**，靠**每小时抽样**（成品 / 半成品 / 包装）与经验控制 PSD；本方当场追问"如何确保进成品罐时 PSD 最优"，**未获实质答复**。
- 供应商的理由是**筛网目数固定 → 粒度基本不波动**。
- 包装端**四道剔除**（黑点 / 铁屑 / 结块 / 金属）是其 visibly 最强的质量控制环节。

**与本方后续合作直接相关的两条能力（本批新增）：**

1. **无机粉末已在线使用**：**二氧化硅**在高速混料机加液处加入，用于改善**流动性（flow rate）**，不加则粘连、影响吸水性 → 印证上批"**无机粉末撒粉**"能力确在大线上存在。
2. **可再加纳米级粉末**：现场设备**全密封**，供应商口头（李振 [待验证]）认为可行；**加入点与需本方提供的粉末条件待定**。

**现场可达性（本批新增）：**

- 厂区为**防爆设计、每段有隔离墙**；工艺流程图**只能在中控 DCS 画面看、不外发**（与上批一致）。
- 中和加碱点**未画在流程图上**（保密），双方约好到中控确认。
