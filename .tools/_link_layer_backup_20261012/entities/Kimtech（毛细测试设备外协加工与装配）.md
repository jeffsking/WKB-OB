# Kimtech（毛细测试设备外协加工与装配）

| 项目 Item | 内容 Content |
|---|---|
| 主营 Scope | **金属零件加工与整机装配**（metal parts and assembly）；可承接整机图纸绘制（drawing） |
| 定位 Role | 毛细测试（[[MCCT Multi-Component Capillary Tension（多组分毛细张力测试）]]）新机与升级套件的**外协制造方** |
| 边界 Boundary | 只做结构与装配，**不做软件与测量算法**；激光、天平、阀件等标准件由 K-C 侧自行采购 |

## 合作与供货历史

- **2026-02-19**：项目启动前已与 Steve Rocke 建立联系，按设计图承接加工；**人工费口径约 7 千美元量级**（内部报价，见商务要点）。
- **2026-03-19**：完成图纸走查（含视频绕机 walk-around），被要求在两周内（**5/15 前**）提交整机估价；同时要求单独报一份**整机图纸绘制**的价钱。
- **2026-03/04**：提供零件清单（parts list）用于报价；K-C 侧提示「请考虑 IP」，说明图纸外发存在知识产权边界。
- **2026-04/23**：已获取更低成本的零件方案，并解决了**零位（zero level）与砂芯板水平（frit level）**的装调问题；3D 打印件转由 K-C 内部自制。
- **2026-05-01**：整机估价落到**单台 6 千美元量级并已下单**；装配报价口径 = 装配人工 + 此前讨论过的零件。
- **2026-05-07**：要求 Kimtech 出具**整机装配图（assembly drawing）**，用于未来复制与重建（re-builds）。

## 价格与商务要点

> ⚠️ 商务敏感信息只记要点与区间，不落完整价格表。每条标注记录日期。

- **记录日期 2026-09-29**：装配人工约为**单台设备同量级**（数千美元量级）；整机**单台估价亦为数千美元量级**，二者接近——即本项目里「加工装配 ≈ 整机」的成本结构，零件反而是可优化的次要项（K-C 侧通过自采低价件与 3D 打印件已压下这块）。
- **记录日期 2026-09-29**：报价周期约 2 周；图纸绘制为**单独计价项**，采购时必须与整机报价分开谈。
- **记录日期 2026-09-29**：**图纸外发须先约定 IP 归属**（内部已提出 "please consider IP"），装配图是后续复制与重建的前提资产。
