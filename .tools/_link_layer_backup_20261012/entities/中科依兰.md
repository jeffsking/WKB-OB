## 追加：Meeting Minutes 批 · 项目梳理与资源规划（2026-09-29 追加）

> 本节为 **S5_Areas_Meeting Minutes_01 批次（项目梳理与资源规划）** 编译时的追加记录，**不改动上方既有结论**（含同批次「产品研发与实验计划研讨」的追加内容）。本批补充的是**悬浮液技术路线与验证计划口径**。

- **2026-09（内部研讨，日期 `[待验证]`）**：
  - **技术路线定案**：纳米除臭粉**不可能溶于油剂，但可做成悬浮液**放入油剂 —— 关键变量是**粉的纳米级别**与**悬浮液浓度**，需设定 n 个 code 做梯度验证。
  - **施加位置定案**：喷在 **outcover 侧、贴 film 的那一面**（热风无纺布本身已有亲水油剂工序），由膜遮挡避免粉体跌落。
  - **两个风险点（交付门槛）**：① 新维盛（辛维胜）的喷嘴喷含粉油剂时**是否堵塞**、能否均匀喷出；② 单层带粉材料上 KC 机器后，经多辊**粉体是否跌落（build-up）**。两点解决后即可交付。
  - **推进节奏**：新维盛把油剂寄中科依兰 → 中科依兰配不同浓度悬浮液 → 路易斯（Louis）试喷 → 选出可喷浓度后立即做大货卷样 → 拉到 KC 工厂上机验证 build-up。
  - **供方背景**：为**中科院体系下的实验室**（大连），需考察其**外包加工场地的稳定性**与科研能力；计划**年后组织现场考察**。
  - **痛点优先级**：胶水/塑料袋气味是当前消费者痛点；**尿便（BM/urine）方向不再是重点**，让负责人继续做学习与储备即可。
