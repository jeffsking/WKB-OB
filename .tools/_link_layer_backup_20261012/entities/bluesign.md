# bluesign technologies ag

## 基本盘

| 项目 | 内容 |
|---|---|
| 性质 | 总部位于瑞士的独立认证机构 |
| 创立 | 2000 年 |
| 认证对象 | **工厂的生产系统**（流程认证），而非最终产品——这是与 OEKO-TEX 最根本的区别 |
| 在本库中的角色 | 工厂层面综合可持续性背书的来源机构 |
| 官网 | bluesign.com |

### 五大支柱

| 支柱 | 核心要求 | 与无纺布行业的关联 |
|---|---|---|
| 资源效率（Resource Productivity） | 对能源、水、化学品的消耗设定基准并追踪改善 | 水刺工艺耗水量大、能耗高，受影响最直接 |
| 消费者安全（Consumer Safety） | 最终产品须通过有害物质测试（与 STANDARD 100 高度对齐） | 认证工厂产品可同时申请 OEKO-TEX 标签，减少重复测试 |
| 工人健康（Worker Health） | 工作场所化学品暴露限值、PPE 要求、职业健康监控 | 纺丝与整理工序；与 ISO 45001 有协同 |
| 空气排放（Air Emission） | VOC 及特定气体排放限值 | 热粘合、熔喷工艺的加热过程；整理助剂挥发性管控 |
| 废水（Wastewater） | 特定化学指标排放浓度限值 | 水刺布生产废水是重要管控点 |

## 合作与供货历史

- **2026-09-27（记录日期）**：据 [[卫生用品认证体系完全指南]]，bluesign 在运动/户外纺织品行业认可度极高（Nike、Adidas、Patagonia 等均要求供应商认证），在卫生用品领域起步较晚，但随着欧洲品牌对工厂可持续性要求的提升，重要性正在快速上升——**特别是在莱赛尔、有机棉等高端原料领域**。

## 关键规格要点

| 维度 | 说明 |
|---|---|
| 有效期 | 3 年（中间年度审核） |
| 检测方式 | 工厂现场审计（系统性） |
| 化学品认证 | bluesign APPROVED chemicals——化工供应商须提交配方经审查合格；**整理剂/助剂供应商若未取得，其产品将无法用于 bluesign 认证工厂** |
| 与 ZDHC 关系 | 与 ZDHC MRSL 高度协调，同时获两者认可可减少重复验证 |
| 卫生用品市场认可度 | ★★★（工厂认证加分；医疗级参考价值有限） |
