# Main S.p.A.（SOFTCARE HAF）

> 一句话定位：**把 SAF 做成预制 Airlaid 芯材卷材**的意大利专业 Airlaid 制造商——在 SAF 路线上它是 TAL 的**下游加工方 / 第二供应渠道**，而非 SAF 纤维的独立来源。（中文：买它的芯材可以绕开自建芯体，但绕不开 TAL 的纤维。）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | **SOFTCARE HAF（Highly Absorbent Fibre）** 系列——含 SAF 的 Airlaid 芯材卷材 |
| 产地 | 意大利 |
| 克重范围 | **70–500 gsm** |
| 层结构 | **三层 或 五层** |
| 标准产品 | **Softcare HAF 07**、**Softcare HAF 10** |
| 适用领域 | 女性卫生巾、婴儿纸尿裤、成人失禁用品 |
| 核心卖点 | **快速吸收导流（Fast acquisition & distribution）+ 低回渗（Low wet back）** |
| 定制能力 | 可按客户要求的克重与性能参数开发 |
| 角色 | 候选（第二供应渠道 / 概念验证用预制芯材） |

## 层结构（源文）

| 层位 | 组成 | 功能 |
|---|---|---|
| 第一层（顶层） | 纤维 + 浆粕 + EVA 粘合剂 | **导流分散层** |
| 第二层（吸收层） | **SAF + 双组分纤维 + 浆粕** | **核心吸收层** |
| 第三层（底层） | 纤维 + 浆粕 | 支撑层 |
| 第四层（可选） | 纤维 + 浆粕 + EVA 粘合剂 | 五层结构附加层 |
| 第五层（可选） | 纤维 + 浆粕 + EVA 粘合剂 | 五层结构底层 |

> 中文：**第二层是 SAF 的落点**——即 SAF 被放在"中间吸收层"而非表层，与库内 [[Super Absorbent Fibre（超吸水纤维 SAF）]] 页"SAF 的价值是结构性（通道导流、抗起坨断层）"的判断一致。

## 关键事实（均注日期）

- **2026-07-08**：被列为 SAF 三层应用路径中的**路径 B（预制 SAF Airlaid 芯材直接采购）**的两个来源之一（另一为 TAL 自身）；关键优势为**"省去芯体开发环节，快速验证 SAF 概念"**，适用于**概念验证、小批量试产、快速进入市场**。
- **2026-07-08**：在供应保障建议中被明确列为**多源策略的一环**——"TAL 直接供应 + Main S.p.A. 芯材供应双渠道"。
- **2026-07-08**：源文判断 **Main S.p.A. 使用的 SAF 很可能也来自 TAL**（原文措辞为"很可能"，属**推断**）。

> ⚠️ **不确认（2026-09-29）**：**Main S.p.A. 的 SAF 纤维来源是推断而非确认**。因此把 Main S.p.A. 作为"第二供应渠道"**只能缓解芯材加工端的集中风险，不能缓解 SAF 纤维本身的单一来源风险**——这一区别在采购判断上至关重要。
