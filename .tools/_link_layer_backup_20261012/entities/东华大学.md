# 东华大学（Donghua University）

## 基本盘

| 项目 | 内容 |
|---|---|
| 性质 | 教育部直属高校，国家「211 工程」、国家「双一流」建设高校 |
| 主营 | 纺织、纤维材料等方向的教学科研 |
| 在本库中的角色 | 「低熔点共聚酯及皮芯复合纤维」项目的**牵头单位**；卫材纤维材料方向的产学研来源 |

## 合作与供货历史

- **2026-08-15（原文发布日）**：作为牵头单位完成「低熔点共聚酯及皮芯复合纤维设计开发与应用」项目，**主要负责项目总体技术路线设计、关键科学问题凝练、基础研究与技术研发，为产业放大提供理论依据和技术支撑**；项目通过中国纺织工业联合会科技成果鉴定，整体技术达国际先进水平。详见 [[低熔点共聚酯及皮芯复合纤维技术突破]]。
