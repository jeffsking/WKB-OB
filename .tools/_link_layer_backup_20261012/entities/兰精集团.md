# 兰精集团（Lenzing Group）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | 纤维素纤维，莱赛尔（Lyocell）商品名 TENCEL™（中文「天丝」） |
| 产地 / 基地 | 奥地利（总部）；全球布局 |
| 产能 | `[待验证]`——本库当前来源未给出兰精莱赛尔总产能口径 |
| 角色 | 莱赛尔高端档位的**技术与规格标杆**；国产替代的对标对象 |
| 官网 | lenzing.com |

### 天丝三大系列

| 系列 | 定位 | 适用方向 |
|---|---|---|
| G100 | 基本型，**有**原纤化 | 桃皮绒、牛仔做旧、水洗风格（原纤化是卖点） |
| LF | 低原纤化，性能介于两者之间 | 家纺、常规针织（既要手感又要耐洗的平衡点） |
| A100 | **交联型**，非原纤化（在纤维内部先把结构锁住） | 深色面料、贴身内搭（对起球和发白零容忍） |

### 规格铺陈（来源给出的示例）

| 系列 | 已知规格 |
|---|---|
| A100 | 1.25*38、1.4*38 |
| LF | 0.9*34（细旦） |

> 来源评价：兰精的规格**铺得很细**，这是与国产莱赛尔最关键的一处差距之一。

## 合作与供货历史

- **2026-09-18（原文发布日）**：据 [[天丝为什么突然这么难买]]，行业反馈 A100 交期紧张、部分工厂拿不到货；兰精官网**无相关公告**，2026 年 3 月上海春夏面辅料展上兰精在功能运动区主推的仍是 A100。
- **2023 年**：推出 LF 的升级版 LF 2.0。
- **2026-03**：在上海首发新型号天丝莱赛尔-HV100，采用 **Variocut 变切技术**控制纤维长度差异，在布面做出类似棉的不规则纹理，主打棉感，首选应用为牛仔；据中华纺织网报道，该产品目前仍处**品牌打样阶段**。

### 1. 供货/评估历史（追加）

- **2026-08（记录于 v3 表格）**：在 [[KC Diffusion-Enhanced Topsheet v3 DOE Plan (C1-C4 Liner DOE)]] 中，**兰精莱赛尔三叶形（Lenzing Lyocell, trilobal）** 被选为 **C1「最优解」方案**的上层异形纤维（**2D 10% Lyocell + 90% ES**），定位为"表面积与手感最佳"；试产用量口径为 **100 kg/month**（同类异形纤维候选的最低量级）。
- **同批对照路线**：C2 用福地三叶形 ES、C3 用苏州益盟单组分 PET 纺锭型、C4 用十字截面 PET——**兰精是四条路线中唯一的纤维素纤维（莱赛尔）路线**，其余三条均为聚酯/聚烯烃体系。见 [[Diffusion-Enhanced Topsheet C1-C4 (Cost-Performance-Supply Chain)]]。
- **项目定位（本批口径）**：兰精路线被赋予"**性能上限**"角色（best surface area + feel），同时被同时标注"**highest cost**"。
