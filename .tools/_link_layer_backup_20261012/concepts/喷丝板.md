# 喷丝板


## Definition 定义

纺丝用喷丝板；闽瑞的单纺位试验线**可更换喷丝板**，与生产线共用原料。


## Key Points 要点

- 经济性判据：小批量添加（5%~10%）优先用单组分最经济；添加量大时由闽瑞用单纺位试验线（**可换喷丝板**、与生产线共用原料）做初步验证（源：复合纤维生产工艺及性能探讨）
- 三叶草纤维方向需推动**三叶草喷丝板开发**并深度绑定中纺（源：OI（Open Innovation）团队会议纪要）
