# 聚酯水解与水分控制（Polyester Hydrolysis）

> 一句话定义：在聚酯（PET/PBT/PLA）熔融加工中，水不是惰性杂质，而是**参与主链断裂的化学反应物**；控制切片水分（约 <0.004 wt%）的本质是限制高温停留期间的酯键断裂数量。

## 机理 / 结构拆解

1. **化学本质**：水解是缩聚的逆反应（P–COO–P′ + H₂O → P–COOH + HO–P′）。早期表现为分子量下降而非失重（长链切成两条短链，总质量近似不变、链数增加）。
2. **反应机理**：酯基羰基具极性 → 水分子氧作为亲核体攻击羰基碳 → 四面体中间体 → 质子转移 → 酰氧键断裂，形成羧基端与羟基端。
3. **动力学与自催化**：rₕ = (k₀ + kₐ·CCOOH)·CE·Cw——生成的 –COOH 提高局部酸性，使羰基碳更易受攻击，形成**自催化（「越反应越快」）**；速率常数服从 Arrhenius。
4. **分子量关系**：1/Mₙ = 1/Mₙ,₀ + nₛ/m，随机断链数与 1/Mₙ 近似线性；羧基与羟基端基等量增加是水解的直接化学证据。
5. **流变放大效应**：η₀ ∝ Mw³·⁴，故 **Mw 降 10% → η₀ 降约 30%**（0.9³·⁴ ≈ 0.70）。即便表观黏度还受剪切变稀、温度、分子量分布影响，「分子量小幅下降、熔体黏度明显下降」的趋势仍成立。
6. **高特性粘度更敏感**：分子量基数越大、链数越少，相同断链数造成的**相对**损失越显著。

## 经验教训

> ✅ 验证（2026-09-27）：本页与 [[熔融指数与化学降解]] 构成对照——PP 是「主动提 MFR 消耗分子量」，PET 是「被动水解掉分子量」，二者共用「分子量决定加工稳定性」这一底层规律。

- **要点**：聚酯切片的干燥是**化学工艺步骤**而非物理除湿，其目标值须与产品特性粘度、设备停留时间、目标分子量一起确定，不能照抄通用值。
- **待补 `[待验证]`**：不同牌号 PET/PLA 的水解活化能 Eₐ 具体数值（原文只说「Arrhenius 型」）。

> ✅ 验证（2026-09-29，来源 [[MXD G-100 技术数据表（PGA 树脂）]]、[[MXD G-101 技术数据表（PGA 树脂）]]）：脂肪族聚酯 **PGA** 的供应商 TDS 给出与本页同源的约束——切片水分 **≤300 ppm**（Karl-Fischer），加工前必须 **120 ℃ × 4 小时**干燥（除湿或真空设备），且铝箔袋密封、储存 **< 25 ℃**。这说明「水分是反应物、干燥是化学工艺步骤」在酯键密度更高的 PGA 上同样成立（约束比 PET 更显性）。**本页既有结论不变，此条为跨材料追加验证。**
