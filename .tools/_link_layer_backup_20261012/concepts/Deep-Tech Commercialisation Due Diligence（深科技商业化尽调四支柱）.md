# Deep-Tech Commercialisation Due Diligence（深科技商业化尽调四支柱）

**一句话定义**：针对**底层化学/物理材料类**创新的风险投资尽职调查框架 —— 用四个支柱判断一个深科技项目能否跨越"**死亡之谷**"（从实验室到量产）：**方法论的严谨性 / 时间线容忍度 / 生态系统杠杆 / 使命契合度**。

> 来源说明：本页由一份外部技术资料的音频解读（[[Mechanochromic Screen from Molecule to Market — HPC Structural Colour & Deep-Tech Funding（压力变色环保屏）]]）转述的尽调框架提炼，讲者引用一位由化学博士转为风险投资人的从业者（Dr. Ritter，杜克资本合作伙伴）[待验证]。框架本身**可迁移到任何深科技项目的评估**，不局限于力致变色。

## 机理 / 结构拆解

### 为什么深科技不能用"互联网/软件"的尽调逻辑

| | 软件 / SaaS | 深科技（化学 / 物理材料） |
| --- | --- | --- |
| 比喻 | **短跑** —— 看营销、看几个月内占领市场 | **极其昂贵且充满不确定性的马拉松** —— "在跟冷冰冰的物理定律较劲" |
| 出错成本 | 代码写错 → 熬个通宵第二天修复上线 | 分子合成路径遇物理瓶颈 → **推翻重来，再耗 3–5 年** |
| 试错成本 | 低 | **极高** |

→ 因此尽调**必须换成"物理定律是否成立 + 资本是否有耐心"**这两条主线。

### 四支柱

| 支柱 | 投资人在问什么 | 不通过的后果 |
| --- | --- | --- |
| ① **方法论的严谨性** | 有无**无可辩驳的数据**证明核心机理成立（例：分子确实**共价键绑定**而非物理混合）？经历**数千次**循环后，稳定结构**是否真的没有降解**？ | "科学容不得半点侥幸，物理定律是骗不了人的" → 底层逻辑不稳则一切归零 |
| ② **时间线容忍度** | 研发周期是否远超基金周期？若基金仅 5 年、期望 2 年量产 10 倍回报 → **这种钱绝对不能要** | 急功近利的 KPI **会把初创团队撕裂**；深科技需要**耐心资本**与对硬件成熟周期的统一共识 |
| ③ **生态系统杠杆** | 是否**聪明地利用了周边生态**：通过**大学技术转化办公室**解决专利授权？与**大型化工巨头**战略合作、借用现成产线放大？ | "**单打独斗在深科技领域是死路一条**" —— 初创公司不可能凭空建起一座化工厂 |
| ④ **使命契合度** | 技术的最大优势（例：极端环保、完全生物降解）是否与资本方战略部署一致 → 应精准对标 **ESG 基金** | 拿了"不合适"的钱，双方走不远 |

## 关键参数表

| Item 项目 | Value / Rule 值 / 规则 | Note 备注 |
| --- | --- | --- |
| 支柱数 | **4**（严谨性 / 时间线 / 生态杠杆 / 使命契合） | 顺序即优先级 |
| 反面样本：基金周期 | 生命周期 **5 年**、期望 **2 年**量产、10 倍回报 → **不可接受** | 与硬件成熟周期冲突 |
| 关键质问（严谨性） | "是**共价键**还是物理混合？" | 机理成立与否的分水岭 |
| 关键质问（循环寿命） | "**数千次**压力测试后是否降解？" | 稳定性的硬指标 |
| 生态杠杆的两条路径 | **大学 TTO 专利授权** + **化工巨头现成产线** | 不可自建工厂 |
| 资本匹配 | 环保/可降解类技术 → **ESG 基金** | 使命契合度 |

## 经验教训

1. **先问机理，再问市场**：第一支柱是"有没有无可辩驳的数据证明机理成立"，不是"PPT 漂不漂亮"。对卫材的启示 —— 评估一个新材料提案时，**第一问应是"共价键还是物理混合"这一级的机理证据**，而不是成本与产能。
2. **钱的属性决定项目的死法**：拿了周期不匹配的钱，团队会被 KPI 撕裂。**"不能为了拿钱什么都答应"** —— 创业者需要极大的克制。
3. **深科技必须借生态**：大学 TTO 解决 IP、化工巨头解决放大 —— 初创公司不该自建工厂。对本库的意义：与供应商合作时，**"对方有没有现成产线"是放大可行性的第一判据**（呼应 [[福建闽瑞新合纤]] 的"单纺位试验位"这类资产的价值）。
4. **使命契合是融资策略**：环保/可降解技术的对标资本是 ESG 基金 —— 技术叙事与资本叙事必须对齐。
5. **"死亡之谷"是默认结局**：大量技术耗光科研经费后止步于实验室 —— 尽调的目的就是**提前识别哪些能跨过去**。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 尽调的具体提问方式与杜克生态漏斗）

> 来源：[[Force-to-Colour Direct Conversion — Mechanophore Chemistry & HPC Photonic Bandgap（把压力变成颜色）]]（对 `the chromatic shift.pptx` 的音频解读 ASR 转写，日期 [待验证]）。本批只**追加**，不修改既有结论；本批补足了"严谨性支柱"**具体怎么问**，以及资本方的**项目漏斗**。

**尽调不是查造假，而是剥离实验室条件再拷问（本批新增）：**

> 一位杜克化学系出身的风险投资人（Dr. Karri Rieder [待验证]）的做法：把科研方法论直接转化为**深科技尽职调查**。**不止于验证实验数据真假**，还会追问：
> 1. **应变阈值是不是太窄了？**（性能窗口的可制造性）
> 2. **工业化球磨合成时，良品率能保证吗？**（放大后的收率）
> 3. **那些对酸敏感的官能团，在现实环境里会不会几天就降解？**（使用端稳定性）
>
> 本质：**剥离实验室的完美条件后，技术还能不能经受现实的毒打。**

**由此得到的尽调提问范式（本批新增，可直接套用）：**

| 维度 | 提问模板 |
| --- | --- |
| **性能窗口** | 关键阈值/窗口是不是太窄？在量产波动下还能不能命中？ |
| **放大收率** | 从实验室合成路线放大到工业化时，**良品率**是多少？ |
| **使用端稳定性** | 那些在合成中被"保护起来"的敏感基团，在**真实使用环境**里能撑多久？ |
| **角色画像** | 需要"**能看懂复杂化学公式，又能把它翻译成商业语言的人**" |

**资本方的项目漏斗（本批新增）：**

- 杜克生态**每年利用校友网络筛选超过 1000 家初创企业** → 构成**金字塔模型**：
  - **底层 = 分子工程**（基础）；
  - **中层 = 设备集成**（让其扩展落地）；
  - **顶层 = 商业转化**（需要**催化剂**）。
- 对照案例：该技术从 **Stephen Craig 博士**的基础研究 → **Matthew Becker 博士**博士后期间的发明与商业化探索，**历时约 10 年** —— 一般风险资本不喜欢这种周期。

**由此得到的认知（本批新增）：**

1. **"合成端解决了"不等于"使用端解决了"** —— 球磨法保护了酸敏官能团，但尽调仍追问其在使用环境中的降解。**这是深科技尽调里最容易漏的一跃**。
2. **金字塔模型说明：分子工程只是底层** —— 没有中层的设备集成与顶层的商业转化催化剂，底层成果不会自动变成产品。评估一个材料项目时，应同时看**三层是否都有人接**。
3. **尽调问题应"可证伪"**：好的尽调问题不是"你们技术好不好"，而是"**阈值多窄、良品率多少、能撑几天**"—— 这些是可以被数据回答的。
