# 纳米纤维素基高吸水树脂（茶渣-CNC 接枝）Tea-Residue Nanocellulose-Grafted SAP

## Definition 定义

以**废茶渣**为纤维素来源，经酸水解 → 漂白 → 超声纳米化得到纳米纤维素（宣称中空度 ≥80%），再与丙烯酰胺 + 中和丙烯酸接枝共聚制得的 SAP。核心工艺主张是两条**减法**：免通氮除氧（归因丙烯酸用量少 + 水蒸气携氧）、丙烯酸免预处理（不蒸馏除阻聚剂）。

## Process window 工艺窗口（CN 108659171 A 权利要求 1，逐字）

- 茶渣 60% 酸液 60–70 °C 水解 1–2 h → 10–50 µm → 1 mol/L 盐酸 70–80 °C 浸 2 h → 醋酸酸化 NaClO₂ 50–60 °C 漂白 1–5 次；
- 纤维素:水 = 1:50–400 超声 15–20 min；
- 纳米纤维素液:丙烯酰胺液:丙烯酸钠液 = 1:(1–1.5):(0.5–1)（质量），中和度 60–80%；
- K₂S₂O₈ 0.003–0.005%、MBA 0.0003–0.0005%（引发:交联 = 10–12:1）；70–80 °C 水浴 4–10 h，粘度骤增停搅、保温 2–3 h，40–80 目。
- ⚠️ 原文内部不一致：权利要求交联剂 0.0003–0.0005%，说明书文本重复写 0.003–0.005%——照抄并存疑 `[待验证]`。

## Position 在库内纤维素-SAP 家族中的位置

- **「废弃物纤维素→SAP」家族**：废茶渣（本件）≈ 蔗髓（[[蔗髓纳米纤维素基复合保水剂（Bagasse Nanocellulose SAP）]]）——同以废弃物纳米纤维素为骨架，本件工艺减法最激进。
- **审查链证据**：本件在 CN 112442152 B（[[可降解纳米纤维素-天然高分子复合 SAP（制浆造纸研究院）]]）审查中被引为对比文件，说明「纤维素接枝 AA/AM」是 2019 年前后审查员惯引的现有技术基线。
