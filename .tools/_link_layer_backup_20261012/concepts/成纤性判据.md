# 成纤性判据（Spinnability Criteria）

> 一句话定义：一种聚合物能否稳定成纤，取决于它能否**连续通过五道门槛**——线形可流动的分子结构 → 具粘弹性记忆的可纺流体 → 熔点与分解温度间有可用窗口 → 能快速均匀固化 → 固化后仍保留可拉伸性。

## 机理 / 结构拆解

1. **分子结构（最硬的门槛）**：必须线形（非交联、非高度支化）；分子量落在「足够高但不至于过高」的窗口（过低则缠绕不足、一拉即断；过高则粘度过大、塑化不均）；链刚柔性平衡（过刚如芳香族聚酰胺需液晶/特殊溶剂体系；过柔如硅橡胶 Tg 过低、室温即高弹态）；结构规整且有适当分子间作用力（氢键/偶极）。
2. **体系形态**：判据不是「液态」，而是**可挤出、可连续拉伸的流体**（熔体/溶液/冻胶/半固态）。粘度对温度（窄温区 Arrhenius、宽温区 WLF）与浓度极敏感（10%→20% 可使牛顿粘度升高 10–100 倍）。
3. **可纺性（必要非充分）**：严格定义为流体在单轴拉伸下承受很大不可逆变形的能力，量化判据为最大细流长度。**主导机理是内聚破裂**——粘弹性射流储存变形能，达极限即断裂。因此**纯牛顿流体不具可纺性，唯有具指数记忆效应的粘弹性流体方可纺**。细流长度与「粘度 × 速度」呈**峰形曲线**，并非粘度越高越好。
4. **固化能力**：熔纺靠传热、干纺靠传质、湿纺靠传质与相分离。聚丙烯腈因熔点前分解，只能走湿法（溶液）路线。
5. **固化后可拉伸性**：须在「已成形」与「仍可变形」之间处于精确工艺窗口——固化过快则拉伸只能断裂或形成细颈，固化过慢则丝条无法承受自重。

## 关键参数表

| 层次 | 判据 | 不满足的后果 |
|---|---|---|
| 分子结构 | 线形长链、分子量适中、刚柔平衡、结构规整 | 无缠结，流体缺乏弹性记忆 |
| 流变性能 | 粘弹性（非纯牛顿流体），可纺性窗口适宜 | 无法形成细流，或拉伸即内聚破裂 |
| 热性能 | 熔点/软化点与分解温度间有可用窗口 | 熔前分解（如 PAN），只能溶液路线 |
| 固化能力 | 能经传热或传质快速均匀固化 | 丝条粘连、成形不均 |
| 可拉伸性 | 固化后仍保留可观塑性变形能力 | 取向发展不足，强度难提高 |
| 结构演化能力 | 拉伸时能取向与应变诱导结晶 | 取向难保持，尺寸不稳、易回缩 |

## 经验教训

> ✅ 验证（2026-09-27）：本页判据可解释 LMP-PP 的核心权衡——降熔点（破坏结晶）与可纺性（需要粘弹性缠结）之间存在张力，故必须用皮芯结构把两件事拆到两种组分上完成。

- **要点**：讨论「某种聚合物能不能做纤维」时，先定位它卡在哪一道门槛（结构/流变/热/固化/拉伸），再谈工艺可行性——这是评审新材料路线的通用清单。
