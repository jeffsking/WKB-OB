# Cohesive Fastener（自粘扣合系统）

> 一句话定义：用**只与自身粘合、不粘衣物与皮肤**的自粘（cohesive）A/B 材料，替代纸尿裤腰贴的魔术贴（hook & loop）的下一代扣合方案——FEI 项目卡：高剪切低剥离、轻量、低噪、不刮肤，宣称对钩扣系统**约 50% 成本节省**。

## 机理 / 结构拆解

1. **替代对象与痛点**：现行 hook & loop 材质硬、有噪音、可能刮伤婴儿皮肤；cohesive 材料只自身互粘（A 对 B），剥离安静、轻量、不刮肤。
2. **力学窗口**：目标特性 = **高剪切力（保持扣合牢固）+ 低剥离力（易开启）**；初步结果记录"24h 扣合后剥离力增幅低/无""老化后性能稳定""无反光外观"；**剪切/剥离强度仍需提升**（当前主要技术缺口）。
3. **项目状态（FEI 口径，2026-06）**：Project Lead Jingyao Li；GRD 对接 Knorr, Kraig；Product/Material/Process Readiness = **TRL 1 / TRL 1 / TRL 2**；TRL4 目标 **2027**。里程碑：Y25 Jul–Aug 材料采购 → Y25 Q3 打样/台架 + 材料优化 → Y26 Q2 小规模使用测试 → **Y27 H1 技术就绪交接**。
4. **经济性口径**：CORM（成本口径）**较 hook/loop 系统节省 ~50%**（deck 宣称口径）。
5. **宣称空间**：柔软/轻量、提升舒适度。
