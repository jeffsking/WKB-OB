# Material Open Innovation Function（材料开放创新职能）

> One-line definition 一句话定义：把**外部材料创新**（供应商、高校、研究院所）与**内部产品需求**（FEI 概念、产品线创新与降本）连接起来的职能——其技术执行臂是 **Material Development Engineer**（材料开发工程师）。（中文：不是"自己做研究"，而是"把外部概念变成可规模化的材料方案"。）

## Definition 定义与组织定位

| 项 | 内容 | 出处 |
|---|---|---|
| 部门 | **IPC BCC** | [[JD - IPC BCC Material Development Engineer（材料开发工程师岗位说明书）]] |
| 汇报对象 | **Material Open Innovation Leader（材料开放创新负责人）** | 同上 |
| 角色层级 | Individual Contributor（个人贡献者） | 同上 |

| 出差 | **20–30%**（供应商拜访、技术交流、行业会议） | 同上 |
| 内部客户 | **FEI Team、Product Development、Procurement、Supply Chain、Quality Control** | 同上 |

## Mechanism 运作链路（四步）

1. **需求输入**：来自 **FEI 概念需求** → 材料层需给出**快速可行性评估**（rapid material feasibility assessments）。
2. **开发与验证**：配方开发 → 打样 → 性能测试 → 技术报告（物理/功能/安全三类测试计划）。
3. **外部联合开发**：与外部供应商、高校、研究院所技术沟通；传递 KC 技术要求并**反馈样品测试结果**。
4. **降本与简化**：参与 **"Fuel to Grow"（F2G）** 降本项目——材料替代方案的技术评估、替代材料验证、工艺兼容性测试，并推动**材料规格统一**。

> 中文：这条链路的关键在**第 3 步的闭环**——**"反馈样品测试结果"被写进职责**，说明开放创新不是单向索取样品，而是**测试—反馈—再迭代**的循环。

## 能力要求（本职能需要什么样的能力组合）

| 类别 | 要求 |
|---|---|
| 材料知识 | **非织造布、热熔胶、SAP、弹性膜**及其性能与测试方法 |
| 工艺知识 | **纺粘、水刺、熔喷、热风**等加工工艺 |
| 方法能力 | **基础数据分析与 DOE（实验设计）能力** |
| 设备能力 | 万能试验机、透气仪、**SEM** |
| 语言 | 英语读写（技术文献 + 海外供应商邮件） |
| 经验 | **3–8 年**材料开发/应用；卫材/非织造/医用材料背景优先；湿巾或纸尿裤材料经验为加分 |

> 中文：**"DOE 能力"被明确写入技能要求**——与本库中大量 DOE 复盘材料（如 [[ADT Brain Trust - Fluff and Rewet（绒毛浆与回渗 DOE 复盘）]]）互为呼应：**实验设计是该职能的基本功，而不是加分项**。

## Lessons Learned 经验教训

> ✅ Verification（2026-09-29，source [[JD - IPC BCC Material Development Engineer（材料开发工程师岗位说明书）]]）：本页职责链路与该源 §Key Accountabilities 逐条对应，未作外推。

- **Lesson 1（开放创新是双向循环）**：职责把"反馈样品测试结果"与"响应周期 ≤3/≤5 个工作日"写成指标——说明**反馈速度本身就是合作条件**，不只是内部效率。
- **Lesson 2（材料职能没有采购权，但有技术窗口责任）**：无直接采购权、只协助成本评估，却是采购/供应链/质量的**材料技术窗口**——**技术判断与商务决策分离**是这条职能的设计原则。
- **Lesson 3（降本与创新的接口在"替代 + 规格统一"）**：F2G 支持的三件事——替代评估、替代验证、工艺兼容性——最后的落点是**材料规格统一**，即**降本来自简化而非单纯压价**。
- **待补 `[待验证]`**：该职能在 IPC BCC 的实际在岗状态与人员配置；年度降本目标的实际达成；材料数据库的现有覆盖范围。
