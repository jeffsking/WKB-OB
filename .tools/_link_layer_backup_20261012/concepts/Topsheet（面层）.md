# Topsheet（面层）

> 一句话定义：一次性卫生用品中与皮肤直接接触的最外层材料；中国由 **GB/T 30133—2022** 直接规范，分**天然纤维 / 化学纤维 / 混合纤维 / 打孔膜**四类，并设**禁用回收原料**与**禁用含 PFOS/PFOA 表面活性剂**两条专属红线。

## 机理 / 结构拆解 Mechanism

1. **功能定位**：液体通过的**第一道界面**，决定穿透速度（吸收时间）与表面残留（液体残留量）→ 直接决定干爽感；同时承担手感与外观。
2. **四类材质**：天然纤维（棉/粘胶类）、化学纤维（PP/PET 纺粘、热风）、混合纤维、**打孔膜**（PE 打孔膜，常用于卫生巾干爽面层）。打孔膜在**抗张力**与**液体残留量**上标准与其他三类不同（更宽松的强力、更严的残留）。
3. **两条面层专属红线**（本库其他卫材标准未见）：
   - **不应使用回收原材料**（GB/T 30133 §5.1）
   - **不应使用含 PFOS（全氟辛烷磺酰基化合物）和 PFOA（全氟辛酸）的表面活性剂**（同条款；另禁石棉纤维）
4. **按用途分档**：pH 与甲醛按**是否婴儿用**分档 —— 婴儿纸尿裤用面层 pH 4.0~7.5、甲醛 ≤6 mg/kg；其余用途 pH 4.0~8.0、甲醛 ≤75 mg/kg。

## 经验教训 Lessons

1. **面层采购必须按最终用途下规格**：婴儿用与非婴儿用的甲醛差 12.5 倍（≤6 vs ≤75 mg/kg），同一供应商的同一牌号也可能因用途不同而不合规。
2. **吸收时间与液体残留量只在卫生巾/卫生裤面层考核**，纸尿裤面层不受此两项约束 —— 做纸尿裤项目时不要误加这两条。
3. **PFOS/PFOA 是面层供应商问卷里必须单列的一条**（表面活性剂/整理剂来源），常规「禁用物质清单」常常漏掉它。
4. **打孔膜的盲孔数与孔径是外观判定的量化项**（2 m 内 ≤6 个、不应有 ≥1 mm²），容易在来料检验中被忽略。
