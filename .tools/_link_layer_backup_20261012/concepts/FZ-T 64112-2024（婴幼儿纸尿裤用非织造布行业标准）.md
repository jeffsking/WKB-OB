# FZ-T 64112-2024（婴幼儿纸尿裤用非织造布行业标准）

> 一句话定义：中国纺织行业第一个**按「在纸尿裤中的位置」**组织非织造布验收的产品标准（面层/底层/防漏隔边/导流层/包裹层/腰贴六位），2025-01-01 起实施——是 CN 纸尿裤非织造布供应商验收语系的统一锚点。

## 机理 / 结构拆解

1. **位置分类取代工艺分类**：同一标准下，面层、底层、防漏隔边、导流层、包裹层、腰间及左右贴各有功能定位；复合/层压产品不在范围内（那些走合同或复合标准）。
2. **方法锚点全部外引 GB/T 24218 非织造布系列**：定量（24218.1）、条样法强力（24218.3）、**模拟尿液液体穿透时间（24218.8）**、多次穿透（24218.13）、**返湿量（24218.14）**——即原料层的「穿透-返湿」口径与成品层（GB/T 28004.1）的「吸收速度-回渗」口径分属两套方法，不可直接互比。
3. **化学安全走纺织品体系**：甲醛（HPLC 法）、pH（GB/T 7573 水萃取液）、耐摩擦色牢度、荧光增白剂（FZ/T 01137-2016）、禁用芳胺（GB/T 17592）、总铅镉（GB/T 30157）、邻苯（GB/T 20388），并引用 GB 18401-2010 与 GB 15979-2002（注日期旧版——现行验收按最新版本执行）。
4. **供应商即起草人**：延江、南海南新、大源、优全、恒安卫生材料、俊富、恒鹏、京兰等主要 CN 非织造布厂全部参与起草——标准落地阻力小，且天然成为 CN 供应链的公共验收词汇表。

## 经验教训

- **原料层方法 ≠ 成品层方法**：向供应商索要「返湿量」数据时先确认是 GB/T 24218.14（包覆材料返湿）还是成品回渗（GB/T 28004.1 附录 A）口径，两者试样与负载都不同。
