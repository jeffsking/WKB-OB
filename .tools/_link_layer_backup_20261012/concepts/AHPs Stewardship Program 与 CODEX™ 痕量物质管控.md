# AHPs Stewardship Program 与 CODEX™ 痕量物质管控 / EDANA AHPs Stewardship & CODEX™ Trace Chemicals

> 一句话定义：欧洲非织造布协会（EDANA）主导的、针对吸收性卫生用品（AHPs：纸尿裤/卫生巾/湿巾等）的**自愿性**痕量化学物质管控计划；CODEX™ 是其选定的「不得超过指导值」的痕量物质清单。

## 机理 / 结构拆解

1. **CODEX™ 清单**：EDANA 选定的痕量化学物质列表，会员企业承诺 AHP 中这些物质浓度不高于各自指导值（用统一的、消费者相关的测试方法测定）。
2. **物质范围**：PAHs（多环芳烃）、二噁英和呋喃（dioxins & furans）、dl-PCBs、邻苯二甲酸酯（phthalates）、某些酚类（phenols）、农药（pesticides）、有机锡（organotins）、金属（metals）、甲醛（formaldehyde）等（见原文档表2）。
3. **计划性质**：自愿性 Stewardship Program，目标超越现行 EU 及国家法规，提升消费者信心与透明度。
4. **与强制国标关系**：是 GB 15979 等强制卫生要求的「行业基准补强层」，而非替代。
