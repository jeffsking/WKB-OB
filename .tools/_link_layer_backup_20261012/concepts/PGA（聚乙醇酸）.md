# PGA（聚乙醇酸 / Polyglycolic Acid）

> 一句话定义：由乙醇酸（glycolic acid）缩聚得到的**脂肪族聚酯**，酯键密度高、亲水性强，因而降解速率在可降解聚合物中属最快一档；同时具备**高熔点（220~225 ℃）与高刚性**，历史上主要作为**可吸收手术缝合线**基材，本批中被评估为可堆肥无纺布的**高熔点芯层**材料。

## 机理 / 结构拆解

1. **降解快的结构原因**：PGA 主链为–O–CH₂–CO–重复单元，**无侧基、链段规整、结晶度高**，但酯键密度远高于 PET，且亲水；因此水解/酶解速率快，可吸收性与可堆肥性同源。
2. **降解环境广**：MXD™ G-100/G-101 的 TDS 明确列出可在**工业堆肥、家庭堆肥、土壤掩埋与海洋环境**中降解，并已取得工业 + 家庭**双堆肥认证**（DIN Geprüft + BPI）——在本库现有可降解材料中属认证面最宽的一类。
3. **高熔点 + 高刚性 + 脆**：熔点 **220~225 ℃**，拉伸模量 **≥6,000~6,500 MPa** 而断裂伸长仅 **≥3~5%**。高模量与低伸长的组合说明 PGA 是典型的**刚性脆性树脂**，用于柔性卫材必须**增韧**（共混/共聚）或改作承受压强的结构层。
4. **水敏感是第一加工约束**：切片水分须 **≤300 ppm**，加工前必须 **120 ℃ × 4 小时**干燥（除湿或真空设备）；铝箔袋密封、储存 **< 25 ℃**。这条约束的机理与 [[聚酯水解与水分控制]] 完全同源——水分在高温熔融中是反应物而非杂质。
5. **两个流动性档位**：G-100（MFR 5~15，注塑 + 挤出）与 G-101（MFR 20~40，TDS 仅列注塑），其余规格（熔点、密度、水分、弯曲强度、缺口冲击）完全相同——**选型本质是在流动性与强度之间做交换**。
6. **在可堆肥无纺布中的角色是「芯」**：本批方案把 PGA（约 220 ℃）与 PPCP+PBAT+PLA 皮层（130 ℃）组合为皮芯纤维，利用**约 90 ℃ 的熔点差**实现皮层熔融粘合而芯层保形——见 [[可家庭堆肥无纺布（Home Compostable Nonwoven）]]。
7. **行业叙事须打折看待**：本批另有一份 PGA 行业报告声称市场 2025–2030 年 CAGR 约 12%、医疗占比 35~45%、生物基路线降本 30~40%，但该报告**同文内数字互斥且无出处**（判低可信），本页不采用其任何量化结论，详见 [[2025至2030中国聚乙醇酸（PGA）行业投资策略与可持续发展建议报告]]。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[MXD G-100 技术数据表（PGA 树脂）]]、[[MXD G-101 技术数据表（PGA 树脂）]]）：两个牌号的 TDS 互证了「水敏感 + 高熔点 + 刚而脆」三项核心属性，本页表述与来源一致。

- **教训一（不要拿行业报告当参数源）**：本批 PGA 行业报告的量化结论**不可用**（同文价格差一个数量级、产能口径 15~150 万吨并存）。做技术或采购判断时，一律回到 TDS 与方案页取数。
- **教训二（干燥是工艺步骤，不是环节）**：PGA 必须 120 ℃×4 h 干燥且水分 ≤300 ppm——这一条要写进试产前的设备与排产条件，不能靠现场临时加烘干。
- **教训三（熔点差是资产也是风险）**：220 ℃ 芯层 + 130 ℃ 皮层给了热粘合自由度，但同时意味着**加工窗口被夹在高熔点与皮层熔点之间**，任何温度漂移都同时威胁「芯不熔」与「皮够粘」。
- **待补 `[待验证]`**：PGA 在纺粘/熔喷工艺下的可纺性与纤维力学；增韧方案（与 PPCP/PBAT/PLA 共混比例）的实测数据；海洋可降解与 FDA 认证的取得状态。

## Evidence Update 证据追加（2026-09-29）

> ✅ Verification（2026-09-29，source 来源 [[皮芯架构决策矩阵（可降解热风无纺布）]]）：与本页既有「PGA 降解快、但纤维级数据与卫材供应是缺口」的判断一致，本批给出了**可写入产品页的量化降解数据**与**明确的验证门**——PGA 芯在**海水 28 天降解 75.3%**（家族最快；对照 PLA 需 58 °C 工业堆肥 180 天、土壤 1–3 年、海水极慢），缝合线体内 2–4 周失强。
>
> 关键约束：PGA **无熔点调节杠杆**（Tm 偏高且缺纤维级 TDS），在皮芯架构中只能「硬配」工艺窗口；货架期方面，干态仓储无水不水解，但高湿海运/南方梅雨场景必须做 **40 °C/90% RH × 4/8/12 周 CD 拉伸保持率**加速老化验证。供应端：熔纺可行性由医用缝合线（Dexon，1970 至今）证明，但**卫材级粗旦短纤无现成牌号**，需联合开发。
>
> 定位：在可降解皮芯架构中，PGA 芯被定为**高端线/出口欧洲**方案——用最强降解叙事换取最严的货架期与供应前置条件；详细评级见 [[可降解皮芯架构对比（PPC-PBAT 皮 × 四芯层）]]。
>
> 追加 `[待验证]`：PGA 纤维级 TDS（Tm/结晶行为）的获取；煤基 PGA 万吨级产能对价格的改善幅度；PGA/PLGA 在海水降解基线上的可比数据。
