# 两性离子高吸水树脂（纤维素接枝耐电解质）Zwitterionic SAP (Cellulose-Grafted, Salt-Tolerant)

## Definition 定义

在同一聚合物网络中同时引入**阴离子基团（—COO⁻）、阳离子基团（季铵）与非离子基团（酰胺）**，并常以水溶性纤维素（CMC/HEC）为接枝骨架的高吸水树脂。其差异化价值不在吸液倍率的绝对值，而在**盐溶液中的性能保持率**（耐电解质性）。中文对照：两性离子高吸水树脂。

## Mechanism 机理（缔合-屏蔽-舒展）

来自 CN 1330679 C 说明书（本库最完整的两性 vs 阴离子盐敏性解释段）：

- **阴离子型 SAP**：链内只有静电斥力；遇盐则渗透压减小 + 离子基团离解被抑制（盐效应/同离子效应），分子链蜷曲 → 吸液能力骤降。
- **两性离子 SAP**：链内阴/阳离子基团相互**静电引力缔合**；盐溶液中小分子离子**屏蔽**了缔合作用，分子构象反而**舒展** → 维持吸液能力，因此耐电解质。

一句话：阴离子 SAP 怕盐是因为斥力被屏蔽；两性 SAP 靠「缔合被屏蔽后舒展」把盐从敌人变成构象开关。（关键结论：两性化 = 用机理换耐盐，不是用配方换吸量。）

## Notes for our library 对本库的意义

- **0.9% NaCl 115 g/g（2005 年）**是库内纤维素系 SAP 中最高生理盐水口径之一，可作为「两性化收益」的量化锚点 → [[SAP性能指标（CRC AUL GBP Vortex）]]
- 库内阳离子相关路线：季铵化壳聚糖复合芯层（[[季铵化壳聚糖复合芯层（PAM 微球+AMPS 体系）]]）走的是**复合**路线；本概念走**共聚**路线——两者机理同源（阳离子基团）但实现层级不同。
- 卫生用品应用提示：耐电解质直接对应**含盐体液（尿）中的有效吸量**，与 AUL/生理盐水口径正相关；来源未记载皮肤刺激性/细胞毒性数据 → 安全性 `[待验证]`。
