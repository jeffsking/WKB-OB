# 薄膜压力分布传感（Pressure-Sensing Film / Distributed Tactile Sensing）

> 一句话定义：以**柔软可伸展的薄膜式传感阵列**对接触面做**分布式压力成像**（而非单点测力）的量测技术；在卫材场景的潜在用途是**纸尿裤/裤型的贴合压力与舒适度可视化**。（Chinese: a flexible sensor sheet that maps pressure distribution over a contact area, not a single-point load cell.）

## 机理 / 结构拆解 Mechanism

1. **分布式而非单点**：传感单元按阵列排布，输出**二维压力分布图**与随时间的压力曲线，用于看「哪里压、压多久、怎么变」——这是贴合/舒适度问题的关键维度，单点力值无法给出。
2. **电容式测量（本来源口径）**：源文称采用**专利的电容测量方式**，可做实时、快速的动态数据反馈；薄膜方案可与**电容触控**叠加，实现「力 + 触控」三维输入（厚度仅 **1–2 mm**，保持多点响应）。
3. **柔软可伸展**：传感器材质柔软、可贴合曲面与不规则面，**低压段分辨能力**是其差异化点（可分辨低至 **<10 Pa** 量级的压力；高灵敏型可达 **<0.3% FSR** 的检测下限）。
4. **动态 + 温度补偿**：可用于运动件（雨刮、刹车片、滚轮热压机）的动态测量，并提供**动态温度补偿**；传感器可重复使用场景可替代一次性压敏纸，降低成本。
5. **对卫材的接口**：纸尿裤/裤型的**腰围、腿围、裆部**贴合压力分布、以及假人/穿戴试验中的压力可视化，是本库引入该技术的主要动机；但源文**未列出任何卫品案例** → 适用性 `[待验证]`。

## 经验教训 Lessons learned

- **教训一（手段 vs 功能）**：本页技术在本库有两种用法——**研发量测手段**（贴合压力成像，见效快、风险低）与**产品功能**（把传感做到尿裤里，涉及成本、安全与合规）。**先当工具，再谈集成**。
- **教训二（量程错配风险）**：源文的成熟场景是**医疗康复、可穿戴脉搏、机器人抓取、刹车片/雨刮**等**中高压**场景；卫材贴合压力属**低压段**（kPa 量级），须确认低压分辨与漂移是否满足，不可直接照搬参数。
- **待补 `[待验证]`**：卫材场景所需的压力量程与空间分辨率；薄膜传感器在尿裤曲面/湿润环境下的稳定性；与假人测试的联用方式；国产替代与供货周期。
