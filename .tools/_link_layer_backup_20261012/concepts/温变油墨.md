# 温变油墨


## Definition 定义

**温变（热致变色）油墨**——随温度可逆变色的油墨体系；与尿显/温显指示方向相关。


## Key Points 要点

- 主流为 leuco 染料微胶囊体系：供电子体（leuco 染料）: 受电子体 : 脂肪酸 ≈ 1:5:50，通过熔融/结晶切换显隐色（源：变色油墨）
- 松井为**粉末/油墨级 Chromicolor** 体系（11 色 × 9 温度类型）；Insilico 为**微胶囊包覆**体系（源：松井色素产品册、Insilico 产品册）
- Demo 用温变指示设定约 **34℃** 变色（源：会议纪要：FEI & OI 益生菌项目）
