# PET（聚酯 / Polyethylene Terephthalate）

> 一句话定义：由 **PTA（对苯二甲酸）+ MEG（乙二醇）** 缩聚得到的饱和聚酯；卫材与纺织链最通用的合成聚合物。其**常规熔点约 256–260 ℃ 偏高**，因此不能直接充当热风粘合的粘结组分——要么共聚降熔（→ [[CoPET（低熔点共聚酯）]]），要么改用聚烯烃皮（→ [[皮芯复合纤维]] 的 ES 体系）。

## 机理 / 结构拆解

1. **投料比与成本骨架**：PET 切片 ≈ **0.86 t PTA + 0.34 t MEG**（每吨切片），切片原料成本约 6,445.5 元/吨；PTA 在切片内占比约 77%，是价格主导项。
2. **在皮芯纤维中的角色是「芯层」**：常规 PET 熔点高、强度好，在 CoPET/PET 与 PE/PET 两类皮芯中**共用同一芯层**——这也是两类皮芯在单体层成本几乎打平（差 0.4%）的原因。
3. **"低熔点涤纶短纤"与"真 CoPET 皮芯"必须区分**：PET 均聚短纤（含低熔点 PET 均质短纤）不具备双组分皮芯结构；判据见 [[CoPET（低熔点共聚酯）]]。
4. **再生 PET 是降本杠杆**：再生 PET 仿大化白片约 4,700 元/吨，与原生切片（6,800+）价差约 **2,000 元/吨**；芯层若可用 rPET 可显著降本（"CoPET 皮 + rPET 芯"是本批提出的组合方向）。
5. **加工敏感点是水解**：聚酯在含水/高温下会发生水解断链，干燥与水分控制是纺丝前置条件。→ 详见 [[聚酯水解与水分控制]]。
6. **催化剂维度可升级**：常规 PET 使用锑系催化剂；改用钛系即"无锑聚酯"，是品牌端可持续议题。→ 详见 [[无锑聚酯]]。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[CoPET 与 PET 成本差异对比（2026 年 7 月）]]、[[CoPET-PET 与 PE-PET 成本结构深度拆解报告]]）：两份来源口径互证——PET 切片约 0.86 PTA + 0.34 MEG、芯层熔点约 256–260 ℃、PET 切片端属薄利（毛利率约 0%）。本页表述与来源一致。

- **要点**：在 CoPET 议题里，PET 有**三重身份**——成本基准（分母）、共用的芯层材料、以及"低熔点涤纶短纤"这一易混淆品类的母体。讨论溢价时必须先写明拿 PET 的哪一档做基准。
- **待补 `[待验证]`**：PET 与 CoPET 在皮芯界面的具体相容性机理数据（本批仅给"良率 85–92%"的工程结论）。
