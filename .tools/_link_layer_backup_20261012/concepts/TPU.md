# TPU


## Definition 定义

热塑性聚氨酯（Thermoplastic Polyurethane），可用作无溶剂路线材料与基膜。


## Key Points 要点

- **无溶剂 TPU** 是行业主流，但物性波动（熟化漂移）（源：与华峰集团研发及合作会议纪要）
- 产线调整方案：简易方案（下移喷丝/热风点促挥发）约 1 个月出结果；复杂重卷绕退 DMF 方案**增本 20–30%**（同上）
- 会议给出 TPU 基膜完整参数（同上）
