# 分叉导流


## Definition 定义

导流层/芯体的**分叉（树状）导流**结构设计，用于改善液体铺展与对位容差。


## Key Points 要点

- 建议**中间树干部分做细槽**（如上方叉 8、下方叉 4），兼顾对位容差（**MD 方向 2 mm 偏差可接受**）与上下绑定强度（源：纸尿裤产品设计与材料开发评审会）
