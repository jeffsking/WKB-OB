# Biodegradable SAP（可降解高吸水树脂）

> One-line definition 一句话定义：在保留高吸水倍率与保液能力的前提下，可在土壤、堆肥或海洋环境中被微生物/水解作用降解的超吸水材料家族 —— 用以替代不可降解的 **PAAS（聚丙烯酸钠）**。
> (Superabsorbent materials that keep high absorption/retention while degrading under soil, compost or marine conditions, replacing non-degradable PAAS.)

## Mechanism / route taxonomy 机理与路线分类

本批来源给出**四类技术路径**（同一份海水降解研究报告）：

1. **可水解塑料粒子（PGA / PLGA）+ 天然多糖水凝胶** —— 靠酯键水解起效，降解速率可控。
2. **PVA 基水溶粒子 + 合成高分子水凝胶（IPN / semi-IPN）** —— 互穿网络兼顾强度与降解。
3. **PASP 基全降解 SAP（聚天冬氨酸）** —— 全生物降解。
4. **PDA 型全自然域可控降解** —— 国科海纳（中科院理化所）路线，**海水崩解 3–90 天可控、2 年矿化率 >90%**。

另有一条**淀粉接枝共聚物**路线（部分可降解），是本组合 OI-06 的技术对象。

### 2. 海水场景的额外约束（本页此前未记录）

| 维度 | 海水 |
|---|---|
| 温度 | 10–25 °C |
| pH | 8.0–8.3（弱碱，**有利**于碱催化水解） |
| 盐度 | **~3.5% NaCl —— 屏蔽电荷、抑制渗透压驱动吸水** |
| 微生物 | 以海洋细菌为主，**多样性低** |
| 认证标准 | **ASTM D6691-24 / ISO 16204**；门槛 **180 天 ≥90% CO₂ 转化** |

> 中文：**高盐是双重打击**——既降低吸液能力，又改变降解环境。因此**耐盐性设计（两性离子基团 / 盐敏性离子交联）是可降解 SAP 的必答题**，而不是可选项。

### 4. 落地顺序的判断（与既有"OI-06 为 Paused/Low"的关系）

源文四场景判断：**卫生巾是最佳切入点**（单片 SAP 仅 0.5–1.5 g、消费者付费意愿强、Nagase 亦列为第一目标，2026–2028）；**成人失禁裤为长期目标**（单片 10–30 g、成本极敏感，2030 年后）。

### 1. 按海水降解性的 SAP 分类（本批新增的分类维度）

| 类型 | 代表材料 | 吸水倍率 (g/g) | **海水降解性** | 现状 |
|---|---|---|---|---|
| 合成 SAP（石油基） | **聚丙烯酸钠 PAAS** | 300–500 | **不可降解** | **主流商用** |
| 合成 SAP（可降解） | **聚天冬氨酸 PASP** | 100–600 | 可生物降解 | 研究 / 小规模生产 |
| 天然基 SAP | 淀粉接枝共聚物 | 200–1000 | **部分可降解** | 研究 / 小规模生产 |
| 天然基 SAP | 海藻酸钠 / 壳聚糖水凝胶 | 50–300 | 可生物降解 | 研究 / 医用 |
| 蛋白质基 SAP | 明胶、胶原蛋白水凝胶 | 20–100 | **可酶解** | 医用为主 |
| **全自然域可控降解 SAP** | **PDA 基高吸水材料** | 可定制 | **3–90 天可控崩解** | **产业化初期** |

> ⚠️ **口径并列（第三次）**：本页此前已记录**两种分类口径**（四条 vs 六条），本批**再增一种按"海水降解性"的分类**。三者**切分维度不同**（机理路线 vs 降解性等级），**并列记录、不合并**。
> ⚠️ **"部分可降解"**：源文把**淀粉接枝共聚物**标为"**部分**可降解"——这与海水降解 SAP 定义中"**无微塑料残留**"的要求**存在张力**，源文未调和。

### 2. 六项瓶颈（本批新增，与上文"核心矛盾"互补）

| 挑战 | 现状 | 解决方向 |
|---|---|---|
| **成本** | **可降解 SAP ≈ 传统 PAAS 的 2–5 倍** | 规模化生产、原料替代（**煤基 PGA 路线**） |
| **吸水倍率 vs 降解性矛盾** | 高吸水倍率需低交联密度 → 力学性能下降 | **IPN 结构、纳米增强** |
| **海水环境复杂性** | 温度 **1–30 ℃**、盐度 **32–41 PSU**、微生物群落差异大 | 多因素响应型材料 |
| **降解产物安全性** | 需确保**中间产物**无毒 | 选天然单体（氨基酸、乙醇酸） |
| **微塑料残留** | 崩解中可能产生碎片 | 设计为**完全溶解/矿化，而非碎片化** |
| **标准化测试** | 缺乏统一的海洋降解测试标准 | 推动 ASTM/ISO 海洋降解标准完善 |

> ✅ **与上文关系**：上文的核心矛盾是**"使用期稳定 vs 废弃后快降解"**；本批的**"吸水倍率 vs 降解性"**是**同一矛盾在配方层面的具体表现**（交联密度这一个旋钮同时控制两者）。**不冲突，是同一判断的另一种表述。**

## 追加：生物基（bio-based）与可降解（degradable）是两个正交轴（2026-09-29 追加 · 来源：生物基SAP-SAF技术研究报告 2026-04）

- **概念澄清（本批最重要的一条）**：**生物基 ≠ 可降解**。**生物基丙烯酸 SAP** 的性能与寿命**与传统 SAP 相当、并不降解**；而 **PASP、淀粉基、纤维素基**才是同时具备可再生来源与降解性的路线。两者常被混用，导致成本口径被张冠李戴。
- **生物基五路线与参数（C 级二手）**：

|路线 Route|工艺 Process|吸水倍率 Absorption|降解周期 Degradation|成本溢价 Premium|状态 Status|
|---|---|---|---|---|---|
|淀粉接枝 PAA/PAM|糊化→接枝→交联→干燥→粉碎|200–500 g/g（接枝率 60–80%）|6–12 个月|+20–30%|部分企业工业化|
|纤维素接枝（CMC/HEC）|活化→羧甲基化→交联|—|3–6 个月|+30–50%|实验室/中试|
|蛋白质基（大豆蛋白/胶原）|蛋白改性|—|—|—|研发|
|PASP 聚天冬氨酸|天冬氨酸缩聚→交联→造粒|100–300 g/g|2–4 个月|+50–100%|小规模|
|生物基丙烯酸|生物基单体→常规聚合|与传统相当|不降解|+10–20%|开发中|

- **生物基的三条优势（source-stated）**：原料可再生、**对盐溶液敏感性低**、减少微塑料污染。
- **生物基的四条代价（source-stated）**：成本高 20–50%、**吸水性能略低于合成 SAP**、认证与标准待完善、**规模效应尚未形成**。
- **产业化目标**：**2030 年生物基 SAP 占比达 20%**；路径为「生物基单体 → 生物基聚合物 → 可降解 SAP」。
- **成本口径冲突（必须分开使用）**：本报告的**生物基溢价 +20–50%（PASP +50–100%）** 与本页上方**可降解 SAP ≈ PAAS 的 2–5 倍**是**两个不同对象的口径**——**不得混用**。向上取整的 2–5 倍只适用于**全降解**路线。
