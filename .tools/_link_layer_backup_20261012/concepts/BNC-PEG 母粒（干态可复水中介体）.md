# BNC-PEG 母粒（干态可复水中介体）

> 一句话定义：把 BNC 水凝胶中的水用**水溶性 PEG 置换**，再经机械挤压与干燥得到**干态、可运输、遇水/尿可复水**的 BNC-PEG 中间体（母粒/颗粒）。其技术关键在 PEG 充当「**牺牲占位剂**」——干燥时占住孔隙位置防止塌孔，遇水时溶出、水回替、原位恢复水凝胶。

## 机理 / 结构拆解

1. **四步工艺链**：2–4% BNC:H₂O 水凝胶 → 水溶性 PEG 置换水分 → 机械挤压 → 干燥 → **BNC-PEG 母粒**（干粉、易运输）。
2. **可逆机制**：遇水或尿液时 PEG 被冲走、H₂O 回替，重新形成 BNC:H₂O 水凝胶——即「可逆」必须被**量化证明**，不能停留在机理图。
3. **为什么是「占位」而不是「包覆」**：SAP 工业界 PEG 的既有角色是包覆剂、表面交联剂、吸水增强剂、间隔剂；把它当**可溶出占位剂做干态中间体**，据交叉索引核查是**拜科瑞首创用法**，无独立文献/专利佐证，是本库最大空白也是本项目机会点。
4. **战略价值（为什么排第 4 却最重要）**：把「壳层技术」握在自己配方里，**降低对 SAP 交联供应商的依赖**，实现供应链自主。
5. **延伸一（吸收芯粘合剂/芯体胶）**：BNC:PEG 作 **SAP 间隔层** + **PCL 调开松时间（open time）** + **PEG 调粘度**。
6. **延伸二（功能平台）**：同一干颗粒形态可作嫁接平台——Na⁺ 吸收、除臭/抗菌、压力/温度传感器（智能纸尿裤）；另可作 2–4% BNC 水凝胶的**乳液替代**（个护方向，可分摊产能）。
7. **工程约束来源**：湿态水凝胶无法上 400 m/min 干法产线，必须离线做成干态中间体——这是该路线存在的根本理由（见 [[水凝胶脱水干燥工艺族谱]]）。
8. **风险读法**：工艺链长（置换 + 挤压 + 干燥），**任何一环不通则整条路线归零**，故排序第 4；但一旦成立，供应链价值最大。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[PEG-多元醇 × 纤维素吸水体系交叉索引]]、[[脱水干燥工艺族谱（一页纸）]]、[[拜科瑞 BNC 发酵与发泡线纪要]]）：本页的机理与战略定位得到三份文档互证，并额外得到两条**旁证**——① SAP 工业界从未把 PEG 当可溶出占位剂（用法为实创新）；② 海藻酸钠封端与 CNF 化学交联两条「无 PEG」路线已证明干态可复水在物理上可行，为设计提供对照。

> ✅ 验证（2026-09-29，来源 [[BNC Application Red Line Revision 20260905（BNC 应用红线修订说明）]]、[[Pain-Point Backward Derivation Template v2（材料合作分析模板 v2）]]）：本页路线被**两份治理文档反向确认**——红线自 2026-09-05 起改为「不启动以**终端材料身份**替代绒毛浆/SAP 的项目；中间体/载体/增效角色不受此限」，**PEG 置换中间体（方向四）正是该修订的触发案例**；模板 v2 的角色库亦把「中间体/占位剂 × 可复水干颗粒」列为标准一格。本页「属置换后保留族、交付物是可复水中间体」的定位因此获得制度性准入，结论不变。

- **教训一（先做分流）**：本路线属「置换后保留」族，产物是**可复水中间体**；若目标是 PP/PE 熔融纺粘增强，需要的是**疏水干粉**（不可复水）。同一供应商的同一原料会导出两种交付物，立项时必须先写明交付形态。
- **教训二（可逆必须量化）**：「遇尿 PEG 冲走、水回替」目前只是机理图，项目 Go/No-Go 应挂在**台架级可逆性数据**（置换效率、复水速率、循环次数）而非概念描述上。
- **教训三（安全链条不等于合规结论）**：PEG 有药典级与化妆品目录背书，但**卫材迁移量级实测缺失**——面向婴儿产品的暴露评估仍须单独完成。
- **待补 `[待验证]`**：PEG 等级筛选结论；模拟尿液环境下的置换速度；残留 PEG 的迁移与暴露评估；干态母粒的规模化成本曲线。

## 追加：Meeting Minutes 批（2026-09-29 追加）

> 本节为 **S5_Areas_Meeting Minutes_01 批次（项目梳理与资源规划）** 编译时的追加记录，**不改动上方既有结论**。本批把「BC-PEG 母粒」进一步落到了**热熔胶（芯体胶）**这一具体形态上。

### 1. 本批新增：热熔胶形态的三要素

- **主体 = PEG**：PEG 在约 **60 ℃ 以上为液态**、冷却后固化 —— 本身就满足热熔胶的「加热流动 / 冷却固化」定义。**甘油方案被明确否决**：甘油任何温度都是液态、**无法固化**，且带颜色（发黑），PEG 还可被水完全冲掉。
- **固化剂 = PCL**：PEG 在 60 ℃ 以下还原成固态的时间偏长，需固化剂；**PCL 的相变温度更低，用来调 open time（开放时间）**。
- **施胶窗口**：约 **60–80 ℃**，远低于常规热熔胶的 **150–175 ℃**。
- **工作机理**：尿液进入后把固化的 PEG 融化，BC 母粒重新还原为水凝胶 —— 即「干态母粒 → 遇尿复水」的芯体胶。
- **当前关键难点**：**如何让复水（还原成水凝胶）的速度加快**，这是本批明确的第一攻关点，其次才是功能嫁接（除臭剂、生物活性物缓释等）。

### 2. 本批新增：IP 与供应链策略

- **不做 SAP 表面交联的外包路线**：把纳米纤维素交给 SAP 供应商做表面交联虽可行（壳更硬 → GBP 更高、且有毛细导流），但会**绑定 SAP 供应商、技术握不住**，且对方可能外售。→ **改为我方自制纳米纤维素热熔胶**，在芯体内实现同样的「隔离 + 导流」效果，**IP 落在 BCC 研发侧**（原文：「热熔胶的 IP 应该放在我们这里」）。
- **需新寻源**：找一家能实现该热熔胶的供应商，**偏好非卫材行业、日系或韩系、小众但技术好**；列为明年投入项。

### 3. 验证记录

> ✅ 验证（2026-09-29，来源 [[Project Portfolio Review & Resource Planning（项目梳理与资源规划）]]）：本页既有结论（BC-PEG 母粒作为**干态可复水中介体**、用于规避「BNC 替代谁」的一刀切红线）被本批**支持并具体化**——其首个商业化形态被定为**纳米纤维素热熔胶（芯体胶）**，与既有「中间体/载体/增效」的定位完全一致。**原结论未被修正**。
