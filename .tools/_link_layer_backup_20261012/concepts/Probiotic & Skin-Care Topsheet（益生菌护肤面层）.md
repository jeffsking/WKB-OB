# Probiotic & Skin-Care Topsheet（益生菌护肤面层）

> 一句话定义（Definition）：A topsheet engineered for **skin micro-ecology and rash prevention** — microencapsulated **probiotics（益生菌, e.g. L. reuteri 罗伊氏乳杆菌）**, soothing oils (jojoba 霍霍巴籽油, squalane 角鲨烷, panthenol 泛醇), and **weak-acid functionalization（弱酸化, pH 5.5, malic acid 苹果酸）** — rather than mere liquid transport.（为肌肤微生态与防红屁屁设计的面层：微胶囊益生菌、舒缓油脂、弱酸功能化，而非仅导液）.

## 机理 / 结构拆解 Mechanism

1. **Probiotic microcapsule（益生菌微胶囊）**：slow-release active probiotics regulate skin flora and help prevent diaper rash (红屁屁).
2. **Soothing actives（舒缓活性物）**：jojoba oil, squalane, panthenol, ceramide (神经酰胺) for barrier support.
3. **Weak-acid topsheet（弱酸面层）**：pH ~5.5 approximating skin, with malic/citric acid to inhibit fecal enzyme irritation.
4. **Ultrafine-fiber substrate（超细纤维基材）**：0.003mm / 0.6-0.8D fibers for silk-like softness, the physical carrier of the above.

**氧化锌（zinc oxide）在纤维上的施加方式（本批新增）：**

| Item 项目 | 内容 | Note 备注 |
| --- | --- | --- |
| 施加位置 | **在纤维上**（不是布上），通过 **finishing oil** 带入 | 纤维先制成，再做 finishing 处理 |
| 化学处理 | 在 finishing oil 中**加酸**，使纤维具备该处理 | [待验证 具体酸种] |
| 供应商侧工艺 | **kiss roll** 或 **喷涂** | 之后**自然干燥**（不烘干） |
| add-on | 控制得**很小** | 已在线应用多年 |
| 历史风险 | 中国区此前曾因 **build-up** 放弃过类似应用（约 2010 年前后） | 风险是否复发待观察 |

**"来源于自然"作为宣称支点（本批新增）：**

- 竹纤维线（tier 7）施加**柠檬酸**，理由明确是**"因为它来源于自然"** —— 即成分选择服务于**宣称逻辑**，而非性能最优。
- 配套做法：叠加易获取的品类认证，与竹纤维品牌叙事一致。
- 竹纤维添加量：实际 **5–5.5%**（研究建议 20%）；竹纤维在消费者认知中"不知为何"被视为比一般 natural 更 premium，故阶位由 6.5 上调至 **7**。

**生物质材料的性能支点（本批新增）：**

- Nature Made 的关键转折点：用**生物质 TBCW 替代 PE/PP 腿围纺粘**，**大幅改善干爽**。
- 后续方向：加**更多生物质材料**，且**不止于纤维**。

**tier 8 的宣称策略（本批新增）**：**不宣称成分**（如氧化锌），只宣称**功效/保护** —— 概念测试中对成分宣称的反馈不佳。会中归纳的三个支点为：① 基于临床/电视研究；② 柔软（因所用材料）；③ 抗菌/抗刺激。

✅ **验证记录（2026-09-29）**：氧化锌的施加方式与 add-on 为会中口径，**未见工艺参数与实测数据**；"加酸"的具体酸种转写不清，标 `[待验证]`。参见 [[Skin Health Treatment on Nonwoven（无纺布护肤处理）]]、[[TBCW结构]]、[[Marketing Claim Translation Paradigms（市场宣称六大转化范式）]]。

### 追加-1 · ★ 两条路线分属 BCC 与 AFC

| 板块 | 技术路线 | 机理 | 代表项目 |
|---|---|---|---|
| **BCC（婴儿）** | **氧化锌（ZnO）+ 酸** | **刺激物中和（irritant neutralization）** | ZEN / MAGIC 2.0 / ZinCAre / FIRENZE / KNIGHT III |
| **AFC（成人）** | **酸 + 益生 / 后生元** | **健康微生物组（healthy microbiome）** | ACTIMEL (BioCare) / ProBalance 1.0 / ProBalance 2.0 |

> 📌 **对本页的直接意义**：本页标题为「益生菌护肤面层」，其**机理归属在 AFC 侧（微生物组）**；而**婴儿侧的主流并非益生菌路线，而是 ZnO + 酸的刺激物中和路线**。⇒ **"护肤/护肤面层"不是一个单一技术族，引用时必须区分 BCC 与 AFC 两条路线**。

### 追加-2 · BCC 技术明细（ZnO + 酸）

| 技术 | 低 pH | ZnO | 备注 | 区域 |
|---|---|---|---|---|
| **ZEN** | ✓ | ✓ | **Textor 独家**，对刺激物有效 | KCA、KCNA |
| MAGIC 2.0 | ✓ | ✓ | **未商业化**，因生产问题停止 | EM（欧洲） |
| **ZinCAre** | ✓ | ✓ | 开发中，**目前唯一的非 BCW 方案** | IPC（巴西） |
| FIRENZE | ✓ | ✓ | 乳液 + **d-Panthenol**，**效果温和** | IPC（韩国） |
| KNIGHT III | ✓ | ✓ | 乳液 + **SymRepair**，**无有效性数据** | IPC（中国） |

**未来可能加入**：**d-Panthenol、SymRepair、Cluster Dextrin** 等更高级成分。

> ⚠️ **两条「有效性证据」提示**：五者中**仅 ZEN 被描述为「有效」**；FIRENZE 为**温和有效**；**KNIGHT III 明确无有效性数据**。⇒ 引用这些技术时**须区分「已验证」与「仅已配方」**。

### 追加-4 · 载体与相邻约束（本批新增）

- **ZinCAre 被明确标注为「目前唯一的非 BCW 方案」** ⇒ **现有皮肤健康技术主要搭载在 BCW（热风粘合非织造）上**，载体替代仍是缺口；
- 皮肤健康技术与**柔软度升级、3D/打孔材料**并列于同一管线 ⇒ **三者在同一面层上可能互相竞争添加空间与成本预算**；
- AFC 与 BCC 之间存在**迁移可能**：管线中提及未来成人护理学习可反向迁移（该句出现在干爽域，此处仅登记相邻性）。
