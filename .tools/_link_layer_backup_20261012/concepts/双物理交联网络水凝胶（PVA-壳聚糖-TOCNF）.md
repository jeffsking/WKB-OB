# 双物理交联网络水凝胶（PVA-壳聚糖-TOCNF）

> One-line definition 一句话定义：不用任何化学交联剂，靠**静电（壳聚糖 –NH₃⁺ / TEMPO-CNF –COO⁻）+ 氢键 + 冷冻-解冻 PVA 结晶微区**三种物理作用搭出的双层复合水凝胶（中文：双物理交联网络水凝胶）。

## Mechanism 机理拆解

1. **第一重网络**：乙酸体系中壳聚糖/PVA/TOCNF 共溶，静电+氢键成胶；−30~−10 °C 冷冻 1–2 h 定型。
2. **第二重网络**：在胶面倾倒 2–10 wt% PVA 溶液，再冷冻 12–24 h、室温解冻，PVA 结晶微区成第二网络并形成双层。
3. **不对称功能**：壳聚糖侧抑菌（大肠杆菌/金葡 0 CFU/mL vs 纯 PVA 层 8 CFU/mL），PVA 侧力学增强；层间结合耐 ~188.9% 拉伸不分层。
