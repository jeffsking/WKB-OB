# 异形纤维


## Definition 定义

**异形截面纤维**（非圆形截面，如三叶形/扁平形）的统称；用于提升纤网导流与蓬松等性能。


## Key Points 要点

- 经济性判据：小批量添加（**5%~10%**）优先用单组分最经济；单组分添加上限一般为 5%~10%，**双组分全熔/半熔可提高异形添加量上限**（源：复合纤维生产工艺及性能探讨）
- 行动项：**异形纤维成布后性能提升研究**（添加量与性能的关系）（同上）
- Liner 打样采用「**上层少量异形、下层大量异形**」配比策略（上层 10% 三叶草 / 下层 50%）（源：Liner Trial Request）
