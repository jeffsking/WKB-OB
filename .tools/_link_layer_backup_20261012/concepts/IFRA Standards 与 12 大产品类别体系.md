# IFRA Standards 与 12 大产品类别体系 / IFRA Standards & 12 Product Categories

> 一句话定义：国际香料协会（IFRA）制定的香精香料使用标准框架——将消费产品归入 12 大类别（Category 1–12），按暴露程度分档设定香精限用物质的允许浓度，评估基于 QRA2 与 Crème RIFM 聚合暴露模型。

## 机理 / 结构拆解

1. **分类逻辑**：将产品按皮肤暴露（致敏）端点分组，并兼顾光毒性与系统毒性；Category 1（唇部产品，暴露最高）→ Category 12（不直接接触皮肤/最小转移，暴露最低）。
2. **限量机制**：每个香精限用物质在每类下有不同允许浓度（驻留型/淋洗型/儿童产品差异显著）。
3. **合规周期**：以 Amendment（如 51st Amendment）推送更新，每版有合规时间表。
4. **特殊管控**：玩具等儿童产品若有口腔接触可能，禁止/限制香精并归入 Category 1；医疗装置不在 IFRA 分类内。
