# Super Absorbent Fibre（超吸水纤维 SAF）

> 一句话定义：SAF 是**以纤维形态（而非颗粒/粉末形态）呈现的高吸水材料**——其价值不在更高吸水倍率，而在**形态带来的结构功能**：固定 SAP 颗粒、形成贯通孔隙通道、减少热熔胶、无粒状物泄出。（Chinese: SAF differs from granular SAP by form: it immobilises particles, creates flow channels and removes powder leakage, rather than simply absorbing more.）

## 机理 / 结构拆解 Mechanism

1. **形态即机理**：纤维相互交错形成多个连通的纤维空间，SAP 颗粒均匀分布其中，相邻颗粒间的纤维空间自然成为导流通道，避免 SAP 吸水膨胀凝聚形成阻滞层（凝胶阻塞）。（[[纸尿裤的核心结构及市场主流方向]]）
2. **定位作用**：纤维对 SAP 颗粒起位置固定作用，可减少热熔胶用量并提升柔软度；根本上改善吸液后起坨、断层、局部隆起。（同上）
3. **快吸慢释**：亲水吸水纤维负责锁水（氢键），疏水纤维间的毛细作用负责快速虹吸导流——交叉铺网可解耦「导流」与「保水」两个功能。（[[SAF 高吸水纤维的生产工艺与技术进展]]）
4. **定向输运**：多层 Janus 不对称结构利用层间**毛细压差**实现「只进不出」的定向迁移与防回渗，与芯体通道化是同一物理语言。（同上）
5. **与颗粒 SAP 的关系**：SAF **不是替代 SAP 的吸收剂**，而是**改变 SAP 存在方式的结构材料**；吸收主力仍是 SAP，SAF 提供形状稳定性与流体管理。

## 经验教训 Lessons learned

> ✅ 验证（2026-09-29，来源 [[纸尿裤的核心结构及市场主流方向]]、[[SAF 高吸水纤维的生产工艺与技术进展]]）：两份独立来源在同一结论上互证——**SAF 的价值是结构性的（固定颗粒、通道导流、抗起坨断层），而非吸收倍率更高**。二者均把 SAF 归入芯体结构工程，而非「SAP 替代品」。与库内 [[Fluff-Free 4th-Gen Absorbent Core（无木浆第四代芯体）]] 的既有判断一致，属补充而非修正。

- **教训一（口径）**：谈 SAF 前先问「测的是什么」——纤维本体吸水倍率（纯水，可达 200×甚至更高）、非织造芯体吸液倍率（生理盐水，约 28 g/g）与成品芯体性能不是同一量纲，混用会导致项目目标失真。
- **教训二（绿色代价）**：可降解的碱化醚化路线当前只有 60–100 g/g，明显低于合成路线的实验室水平；**绿色化要以吸收倍率与工艺复杂度为代价**，立项时须先定「可降解」还是「高倍率」。
- **教训三（形态复用）**：SAF 在非卫品领域（电缆阻水、防结露、油水分离、农林保水）已成熟，这些场景的**孔隙率与交叉铺网经验**可反向输入芯体设计，见 [[CN 101464548 A（光缆-电缆阻水材料及其制备方法·含超吸水纤维 SAF）]]。
- **待补 `[待验证]`**：SAF 在国内的量产供应与价格带；SAF 与现有热风/水刺产线的兼容性；SAF 芯体在四次加液企标口径下的回渗表现；可重复使用 SAF 的洗涤-吸收衰减曲线。

### 4. 上文教训二（绿色代价）的新证据

源文列出两条绿色 SAF 路线：**超支化结构**（吸水 >360 g/g，**研究阶段未商业化**）与**碱化醚化法**（**60–100 g/g**，纤度 1.29–10.0 dtex，**可降解、可再生**）。

> ✅ 与本页既有"绿色化要以吸收倍率与工艺复杂度为代价"**同向**：本批数据显示**可降解的碱化醚化路线（60–100 g/g）显著低于合成路线（>360 g/g 实验室水平）**——本页既有判断**未被修正，而是被量化**。

### 5. 新的差异化信息：可水洗

**可水洗 SAF 面料**：SAF 含量最高 30%、190–450 gsm、梳理针刺法、**>250 次洗涤/干燥循环、40 次洗涤后保持 >80% 吸收性能**。

> 中文：**SAP 无法提供可水洗方案**——这是 SAF 在本库中**唯一不可替代的能力**，也是源文把"可重复使用尿裤"与"医用敷料"列为适配度最高的原因。本页既有教训三（形态复用）**未涵盖此点**，属本批新增。

## 追加：SAF 应用实例与前沿补充（2026-09-29 追加 · 不改上方结论）

来源 [[高吸水纤维技术应用.pdf]]（2026-05-03）补充四条 SAF/高吸水纤维纸尿裤应用实例与工艺参数：

- **应用实例**：抗菌 SAF（东莞苏氏 2025，PVA+改性伊利石+气凝胶静电纺丝）；壳聚糖凝胶热喷 PET 亲肤层（2023，快吸锁水防反渗+抗菌+可降解）；超薄低回渗复合体（2016，SAP 在 ES 布上原位聚合+等离子刻蚀，**厚度 ≤3 mm、回渗 ≤1.0 g**）；五层水刺复合（2022，导流/柔滑/抑菌/吸水/稳定）。
- **工艺路线定量**：超支化改性天然纤维**吸水 ≥360 g/g**（金属离子交换度 60–80%）；碱化醚化可降解生物质短纤 **60–100 g/g**（取代度 0.6–0.95）；冻融 PVA 纤维吸水自重 200 倍（免化学处理）。
- **前沿**：Janus"导液-储液-阻隔"三层不对称结构（毛细压差"只进不出"）；β-环糊精包合牛至精油（吸水+长效气相抗菌）；Y/十字/W 异形截面与亲疏水交叉铺网。
- 医用敷料→纸尿裤迁移清单（鞣酸含药面层、黄疸遮光衬垫、湿度传感+蓝牙报警、臭氧再生 SAP/绒毛浆闭环）见 [[Shandong Nameixin Biotechnology（山东纳美欣生物科技）]]。
