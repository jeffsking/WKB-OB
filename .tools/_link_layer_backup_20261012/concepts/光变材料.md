# 光变材料


## Definition 定义

**光变（光致变色）材料**——BLOCLO 盛色的两条产品线之一（4 种形态）。


## Key Points 要点

- BLOCLO = Blooming Color；产品形态：光变类（**光变染料、光变粉、光变色膏、光变纤维**，4 种）、温变类（温变粉/色膏/色母粒，3 种）（源：BLOCLO 盛色科技产品册）
- **关键警示：光变 ≠ 湿变**——光变由紫外光触发，湿变需靠水分触发；**不能把光变产品当作湿显指示材料**（源：BLOCLO 产品册「与卫材变色的关联」）
