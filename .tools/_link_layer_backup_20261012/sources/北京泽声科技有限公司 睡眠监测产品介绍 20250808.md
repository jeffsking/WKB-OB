- 单AFE、AFE+PD SiP多种封装形式，适合各种应用形态
- 领先的人工智能算法

适用形态：智能戒指、智能手表、睡眠臂带

# 非穿戴无感睡眠监测系统

## 基于ZSBM1003及PVDF压电薄膜的无感睡眠监测系统

性能特色：

- 基于泽声科技ZSBM1003芯片
- 高输入阻抗特性，完美适配超高灵敏度压电传感器，可实现枕下呼吸及心率测量
- 大容量FIFO，降低MCU工作时长，降低工作能耗，可电池驱动
- 套片+算法方案形式提供，用户产品形态灵活
- 领先的人工智能算法
- 实时心率、呼吸率、起夜输出（终端）
- 基于整晚数据的睡眠分期与评价(手机/云端)

适用形态：睡眠监测带、智能枕头、智能床垫

# 心率/呼吸率监测

- 同步处理压电和压阻数据
- 及时反馈模块，快速响应用户当前的心率/呼吸变化，减少计算和显示延迟
- 平滑稳定模块，消除因外部环境导致的异常跳动，提供稳定、可信、视觉舒适的心率读数
- 自动化结合策略，在实时性和可信度/用户体验之间找到最佳平衡点，保证输出的及时性和稳定性

算法流程：压电数据/压阻数据 → 在/离床检测 → 滑动窗口 → 及时反馈模块/平滑稳定模块 → 自动筛选+组合算法 → 心率/呼吸率/在离床状态

# 睡眠监测

- 同步处理压电和压阻数据
- 提取体动、心率、呼吸率等变化特征，并映射生成高维特征
- 统计特征规律，实时监测睡眠状态，返回详细的睡眠结果
- 深度学习模型，输出高精度睡眠分期、睡眠质量分数和AHI呼吸指数

算法流程：压电数据/压阻数据 → 在/离床检测 → 特征提取 → 统计特征曲线/映射高维特征 → 监测入睡/出睡 → 深度学习模型 → 睡眠分期、睡眠质量分数、AHI呼吸指数、入睡时长、睡眠时长、睡眠效率、翻身次数、离床次数
