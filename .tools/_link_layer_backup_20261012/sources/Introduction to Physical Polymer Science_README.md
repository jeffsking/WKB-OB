## 三、全书知识骨架（一句话每章）

- Ch1: 分子量分布 (MWD) + Mn/Mw/PDI + 缠结临界 ~25,000 g/mol 是卫材纤维性能的基础
- Ch2: Tacticity (等规/间规/无规) 决定结晶性——i-PP 熔喷与 at-PP 副产分离的核心
- Ch3: 溶解度参数 δ、GPC/SEC、Mark–Houwink 是原料质控与胶黏剂选型的工具箱
- Ch4: P=DS、相分离、胶乳成膜支撑卫生巾包装阻隔与湿巾涂覆
- Ch5: C_∞、Reptation、η∝M^{3.4} 决定熔喷工艺 Mw 窗口与纤维牵伸机制
- Ch6: Avrami + tie molecules + 8/9 T_f 规则 = 无纺布结晶度/热定型核心
- Ch7: 液晶聚合物（Kevlar）——纤维取向工艺借鉴
- Ch8: WLF + Fox 方程 + 自由体积 f_0=0.025 = Tg 选材与仓储预测基石
- Ch9: σ=nRT(α−1/α²) + Mc + SAP/Spandex 原文 = 弹带与 SAP 设计核心
- Ch10: Maxwell/Kelvin + Deborah 数 + Master curve = 熔喷工艺与产品寿命
- Ch11: 屈服/ESCR/Wool 门槛 = PE 包装与湿巾瓶力学选型
- Ch12: γ + Young + Fowkes + σ_th + Corona = 亲水改性与胶粘选型
- Ch13: Fox T_g + ODT χN=10.5 + 纳米复合 = TPU 共混、包装阻隔
- Ch14: 茂金属 + Biopolymer + Dendrimer = 高端熔喷与可降解未来
