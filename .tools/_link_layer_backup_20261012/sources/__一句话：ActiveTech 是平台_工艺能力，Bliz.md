### 5. 性能 trade-off


在成人护理的 ROTC HBC benchmark 中，相比现有芯体，厚度从 5.5 mm 降至 4.4 mm，高压 rewet 从 2.67 g 降至 0.40 g，而 retention capacity 保持约 700 g；但第三次 intake 变慢。


在婴儿尿裤的纯 fluffless ROTC Slim 验证中，薄度和 rewet 有改善，但 cradle intake 变慢、尿液泄漏呈上升趋势；团队因此转向保留 hybrid structure 并增加 pad channel 的 ROTC 2.0。


工程结论： Blizzard/ActiveTech 的真正价值不是“无 fluff”，而是以在线化的 SAP/adhesive core 实现更薄、更柔、更完整的芯体；真正的难点是如何在薄度优势不被牺牲的前提下，补回初始吸收速度、液体分配与防漏余量。

### 3. ActiveTech 在制造端做什么？


ActiveTech 是让 Blizzard 这类芯能够在线、连续、稳定地形成的技术平台。ROTC 的 YK 方案采用 ACF module，并增加 SAP feeding system；工艺上要控制 SAP 在输送及 D-wrap 折叠过程中的飞散。


关键工艺控制点：


SAP 定量与分布：ROTC 使用 volumetric feeder 应用，并有两套 feeder。


真空成形与转移：低 fluff add-on 时，pad formation 对真空条件很敏感；YK 的经验显示，调整真空箱与输送带孔径后，3.5 g fluff 可实现较好成形，但低于 3.0 g 仍有挑战。


包覆/D-wrap 与封边：需要避免 SAP 在折叠区飞散，并确保吸收芯包覆完整。


胶量与胶型窗口：胶不足会影响完整性，胶过多则可能压缩孔隙、影响 intake；这也是为什么 Blizzard 对 adhesive selection 很敏感。


### 4. ROTC 与 Blizzard/ActiveTech 的关系


ROTC（Real Online ThinTech Core）是 YK 基于 ActiveTech/Blizzard 的在线薄芯应用。它有两类典型方案：


ROTC Slim / Fluffless：以无 fluff 的 ROTC core 为主，追求极薄和高柔韧。


ROTC HBC（Hybrid Core）：底层为 100% fast-SAP 的 ROTC，顶层保留 SAM/fluff 混合层及 pad channel；用少量 fluff/SAP top layer 补足高吸收量和液体管理。


简单理解：


Blizzard/ROTC Slim：极致薄、柔软、灵活，但 intake 和 leakage 的设计余量更紧。


ROTC HBC：用 hybrid top layer 换取更稳妥的容量与性能平衡。


### 1. 为什么要从传统 SAP/fluff core 转向 Blizzard？


传统芯体中，fluff pulp 的主要作用是提供毛细导流（wicking）和暂存空隙（void volume），在 SAP 吸胀、锁液之前先接住并传递液体。


Blizzard 去掉 fluff 后，芯体可以显著变薄、柔软和灵活，并减少湿后芯体开裂/断裂等 pad integrity 问题。


但代价也很直白：没有 fluff 提供的导流与孔隙缓冲后，SAP、胶黏剂和包覆材料（facing/core wrap）的组合必须承担液体处理与初期 intake 的责任。

**一句话：ActiveTech 是平台/工艺能力，Blizzard 是该平台形成的 100% SAP + adhesive 薄芯结构。**ROTC 是把 Blizzard/ActiveTech 在线化应用到尿裤芯体的具体项目/方案。


|项目|ActiveTech|Blizzard|
|---|---|---|

|本质|用于制造薄型、无绒毛浆吸收芯的设备与工艺平台。|由该平台制成的具体芯体设计，典型为 100% SAP 加胶黏剂。|

|结构|通过 ACF module、SAP 计量/输送、真空成形、包覆与封边等，实现在线芯体形成。|通常是 fully wrapped 的 SAP/adhesive core；SAP gsm 随产品尺码调整，胶量示例为 SAP 重量的约 5%。|

|目标|建立在线（online）生产 fluffless core 的能力，替代离线薄芯或传统 fluff/SAP 芯。|在减少或去除 fluff 的同时，得到更薄、更柔韧、完整性更好的 absorbent pad。|


### 2. Blizzard 的结构逻辑


典型 Blizzard core 是：


Top facing / wrap → SAP + adhesive layer → Bottom facing / wrap


SAP：吸收并锁住液体，是主体。


Adhesive：固定 SAP、维持 pad integrity；示例工艺中用量约为 SAP 重量的 5%。


全包覆（full wrap）：把 SAP 层封装，防止颗粒迁移/流失并维持薄芯形态。


因此，Blizzard 不是“把 fluff 去掉”这么简单；它是用 SAP distribution + adhesive bonding + wrap construction 重建芯体的形态稳定性和液体管理能力。
