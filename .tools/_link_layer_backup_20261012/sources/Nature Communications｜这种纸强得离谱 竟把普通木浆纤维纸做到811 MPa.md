# Nature Communications｜这种纸强得离谱 竟把普通木浆纤维纸做到811 MPa

Nature Communications｜这种纸强得离谱 竟把普通木浆纤维纸做到811 MPa
作者: 先进微纳纤维复合材料研究荟
发布时间: 2026年3月17日 07:01
发布地点: 广东

1.研究背景

在塑料污染与微塑料风险持续加剧的背景下，纸基材料被视为替代石化塑料的重要方向，但传统纸张一直存在一个核心短板：单根木浆纤维本身其实很强，强度甚至可达上千兆帕，可一旦组装成纸，整体强度却往往只有几十兆帕，根本原因在于纤维与纤维之间的界面黏结太弱，内部还存在大量微米级孔隙，导致载荷无法高效传递。已有研究通常通过加入纳米纤维、增强氢键或构建化学交联来提高纸张强度，但仍难以同时解决“微米级空隙填不满”和“纳米级界面黏结不够强”这两个问题。本文正是瞄准这一瓶颈，提出将毫米级木浆纤维、微米级细菌纤维素微凝胶和纳米级细菌纤维素纳米纤维三者协同组装，利用脱水过程中毛细力驱动多尺度纤维逐步靠近、压实并形成致密界面，从而显著提升纸结构的强度、韧性与界面黏附能力，同时兼顾能耗与可持续性，为高性能绿色包装和结构材料提供了一条新路径。

2.本文要点

1.多尺度纤维协同填隙，让“纸”真正接近纤维本征强度。 作者以木浆纤维构建主体骨架，用平均粒径约72.9 μm的细菌纤维素微凝胶填补微米级孔隙，再用B-CNF填补更小尺度空隙，1:1:1配比下得到的杂化纤维素纸拉伸强度高达811 MPa、模量36.1 GPa、韧性56.5 MJ/m³，刷新了随机取向纤维素纸/膜的性能水平。

2.高强并不只靠“压得更紧”，还依赖结合水参与的氢键网络。 研究发现，完全干燥会破坏材料中的紧密结合水状态，使拉伸强度从811 MPa骤降到167 MPa；而自然干燥并在50% RH下保留紧密结合水时，材料表现出最优强韧平衡，说明“纤维素—结合水—纤维素”氢键网络是高性能形成的关键。

3.除了强度高，还兼具实用加工性与界面黏附能力。 该材料对玻璃和纸等亲水基底表现出强黏附，搭接剪切强度分别达到6.6 ± 0.5 MPa和27.0 ± 1.1 MPa；同时其过滤成形时间仅1.417 h，远低于B-CNF单独制膜的7.79 h，说明这一路线不只是“性能高”，也更接近低能耗、可放大的实际制造。

图2. 对比不同组分纸张的截面结构与取向特征，说明只有三元杂化体系才能充分填充层间与纤维间空隙，形成致密连续的多层堆叠结构，并获得更高取向因子

图3. 通过近红外、低场核磁和力学测试揭示结合水的决定性作用，表明紧密结合水主导高强高韧，而过度干燥或高湿都会削弱力学性能

图4. 从黏附角度验证多尺度纤维间强界面作用，显示三元体系对玻璃和纸基底都具有显著优于单组分的黏接性能，同时兼具较好的氧气阻隔能力

3.研究结论

本文构建了一种由木浆纤维、细菌纤维素微凝胶和B-CNF组成的多尺度致密化纤维素纸结构，实现了目前随机取向纤维素纸中极为突出的强度与韧性表现。研究表明，微米级微凝胶与纳米级B-CNF共同作为木浆纤维之间的界面黏结相，在过滤与干燥过程中促进形成致密多层堆叠结构，从而显著增强纤维间黏附与载荷传递。进一步的黏附测试说明，该三元体系对纸和玻璃基底均表现出比各单一组分更强的界面结合能力。机制上，作者明确指出，结合水与纤维素之间形成的氢键是该材料获得高机械性能的关键因素之一；与此同时，该体系在过滤成形阶段的能耗明显低于单独使用B-CNF制备纳米纤维纸。总体而言，这项工作为传统木浆纤维向高性能、低能耗纤维素结构材料升级提供了新思路，也为可持续包装与结构材料开发奠定了方法基础。
