### 直接说我的建议


如果你要做消费者可见，我建议只做 1 个 MVP：侧腰 panel 的 2 段式拉伸显色。


建议设计成：


未拉伸：浅色/隐色


合适拉伸区：出现清晰色带


过度拉伸：颜色进一步加深或出现第二提示区


这样它就不是“变色好玩”，而是把 fit/comfort 视觉化。


### 一句话结论


消费者可见场景里，最值得做的是“pants elastic panel 的拉伸舒适度指示”，不是整片花哨变色。 这个方向你们内部已经有人在盯，行业场景也开始出现“力致变色在卫生用品中的应用”讨论，但真正能不能成，关键不在材料会不会变色，而在颜色是否能稳定映射消费者可感知的贴合状态 + 宣称是否站得住。


光子晶体膜（photonic crystal film）是个更靠谱的“消费者可见拉伸变色”技术路线，但更适合做小面积指示区，不适合先上整片尿裤。


### 它本质上是什么


光子晶体膜本质是结构色膜（structural color film），不是靠传统色粉本身变色，而是靠周期性微结构改变光的反射波长。


所以一旦被拉伸（strain）、压缩、吸湿或层间距变化，就可能出现颜色变化。


### 为什么它比“拉伸变色粉”更值得看


说明：这里故意不写死绝对应变百分比或力值，因为不同 side panel / laminate / size platform 的力学窗口差异很大。第一版应先用现有 side panel 的应力–应变曲线做反推，定义“消费者可接受 fit zone”再匹配显色阈值。


### 3.4 感官与安全要求


|项目|最低要求|
|---|---|

|手感|不明显发硬，不产生边缘刮擦感|

|气味|无新增可感知异味|

## 一页结论


最适合的第一版 MVP 不是整片光子晶体膜（photonic crystal film），而是做在裤型或开放型尿裤外侧腰围/侧腰区域的小面积拉伸指示贴片（fit indicator patch）。


这个方向有内部依据：K-C 内部材料筛选报告已明确把 diaper mechanochromic 视为“创新空白”，短期应走 build-not-buy 路线，优先用 printable pressure-activated ink 做 pilot，CTI 为 primary，LCR Hallcrest / Sun Chemical 为替代，Jiayida / Xingcheng 为国内成本备份。mechanochromic-supplier-report-2026-08-01-en


这个方向也有消费者价值基础：内部 fit 研究显示，stretch ear 在 perceived fit / comfort 上持续优于 non-stretch ear；外部竞品与历史 claim 也长期在用 “stretchy sides / fit / comfort / wetness indicator” 这套消费者语言。Fit fundamental study result sharing Recommendation Brief stretch ears vs non-stretch ears Claims_Request_450


中长期如要拉开体验差距，再切向 structural color / CLCE / photonic crystal route；但第一版别直接上那条线。

### 放到 diaper 上，我的判断


最佳应用点还是腰围或侧腰的小面积“fit indicator”贴片，不是大面积 panel。


更具体地说：


放在 pants elastic panel 外侧


做成 1–2 条色带或小 icon


拉到目标应变区才显色/变色


避免整片随动作闪烁，太花哨反而像 gimmick


### 和你现有内部路线怎么接


你自己的技术路线图里，“智能功能性尿裤”被放在第三梯队，建议先观望，等基础材料方向跑通后再延伸；而更近阶段优先的是涂层 / Core Wrap / SMS coating。 


另外，你的资料里也明确把 CNF 的优势写成了成膜性好（film-forming），并把涂层方向列为第一优先级。 


这意味着如果你真要碰光子晶体膜，更聪明的切法不是单独开一条“炫技材料线”，而是挂靠你现在已有的 film/coating 能力路线。
