## 四、这套分级在实战中怎么用（说点直接的）


拍板只看 Tier 1 的 5 项：Code 7 的争议（国标 1st +6% 首吸改善）为什么不能当卖点？因为 Tier 1 里 Cradle 3rd −16% 明显劣——首吸 +6% 是 Tier 2 量级，3rd 摄入 −16% 才是 Tier 1 量级，胜负自明 。反过来，Code 10 的回渗 +56% 是 Tier 1 显著优，但 Tier 1 里 3rd 摄入 −51% 显著劣——两个决策核心打架，才需要矩阵试验裁决，而不是拿 Tier 2 的残留 −95% 来背书 。


Tier 2 的价值是机理定位，不是锦上添花：L/H 拆分是唯一能暴露"工况敏感型"的手段（Code 5 的 H 摄入 −21%），国标 2nd + Cradle 1st/2nd 是识破"首吸伪装"的工具（Code 7）。下一轮试验设计时，Tier 2 该砍的是无区分度项（Cradle 扩散、L-H 扩散全 ±8% 内）和小基数项（L/H 残留），该留的是 L/H 拆分系列 。


缺失项提醒：Enterprise 标准（4×60ml）主 KPI 和国标渗漏的独立排查不在这个分级里——Tier 1 管选型，量产决策门（企标回渗 <5.9g）管能不能上市，两套体系别混 。


## 二、Tier 1·决策核心参数（5 项）逐个详解


|参数|测什么 / 工况|表达的性能|为什么是决策核心|
|---|---|---|---|

|国标 1st 吸收时间|国标法第一次注液的吸收时间，基准 25.664s，↓越低越优|首泡尿的瞬吸速度——液体多久离开面层进入芯体|直接决定"第一滴尿"的干爽体验和侧漏起点；Vortex 主控机理被证伪后，这一项只能靠整裤实测拍板|

|国标回渗|国标法（2×80 ml、4 kPa）加压后的回渗量，基准 0.492g，↓越低越优|皮肤侧接触液体量——红屁屁的直接元凶|消费者最敏感的干爽指标；Code 10 的 +56%（全批最强）和 Code 9 的 −210%（红线）都靠它定性|

|国标渗漏|国标法注液后的泄漏量，基准 0.466g，↓越低越优|失效防线——液体有没有逃出产品|本轮 10 个 Code 无一进入优势档（全部 −15.9%~+2.1%），证明它是批次/结构级共性问题，与任何单一材料变更无关，必须独立排查 |

|Cradle 3rd 摄入时间|Cradle 法第三次注液的吸收时间，基准 39.68s，↓越低越优|多次摄入能力——第 3 泡尿还能不能接住|纸尿裤真正的考验是 5–8 次排尿，第 3 次是分水岭；Code 5（+25%）是唯一明显优的 SAP 方案，Code 9/10/11 全部显著劣（−45/−51/−230），这是 SAP 混配选型的第一主战场|

|Cradle 扩散长度|Cradle 法纵向扩散长度，基准 205mm，↑越高越优|液体利用芯体面积的程度——扩散越远，单位面积负载越低|与回渗门槛并列的判据之一 ；但本轮所有 Code 落在 ±8% 内无区分度，实际作用降级为"确认没做坏" |

这个问题问得好——参数分级的逻辑本身就是本轮报告最值钱的设计。先给框架，再逐个拆。


## 一、分级逻辑：为什么分 Tier 1 / Tier 2


报告的总览图（10 个 Code vs Control-2）把所有指标按"对整裤最终表现的决定力"分成两类 ：


Tier 1·决策核心参数（5 项）：直接决定整裤性能取舍，是选型主战场——每个 Code 的生死由这 5 项判定 


Tier 2·支撑参数（10 项）：用于印证机理与定位，单项不单独作选型依据——它们回答"为什么 Tier 1 会这样"，不回答"选谁" 


判定标尺统一：|Δ%| <5 持平 / 5–15 轻微 / 15–30 明显 / >30 显著，色阶严格对齐 。


## 三、Tier 2·支撑参数（10 项）逐个详解


|参数|测什么|表达的性能|支撑作用|
|---|---|---|---|

|国标 2nd 吸收时间|国标法第二次注液吸收时间|第 2 泡尿的吸收速度|与 1st/3rd 连成"多次摄入曲线"，定位 Code 是"前快后慢"还是"全程稳" |

|Cradle 1st 摄入时间|Cradle 法第一次注液|Cradle 工况下的首次吸收|与国标 1st 交叉验证首吸；判断测试方法间的稳健性|

|Cradle 2nd 摄入时间|Cradle 法第二次注液|多次摄入的中间段|区分"1st 好但 2nd 崩"的伪装优势（如 Code 7 1st +6% 但 3rd −16%，中间段已露败象）|

|L 摄入时间|L-H 测试低压（模拟平躺静态）注液吸收时间|低压工况下的吸收速度|识别"工况敏感型"方案：Code 5 低压摄入 −2%~+6% 正常，但 H 摄入 −21%——单看低压会误判|

|H 摄入时间|L-H 测试高压（模拟坐压/动态）注液吸收时间|高压工况下的吸收速度|高压是宝宝坐姿的真实工况，Code 5 的 −21%（明显劣）只有这里暴露，是排除风险的关键证据|

|L 回渗|L-H 低压回渗量|低压锁水能力|与国标回渗互证；Code 5 的 +28%、Code 10 的 +31% 在这里提前预示国标回渗表现|

|H 回渗|L-H 高压回渗量|高压（坐压）下抗回渗能力|高压回渗直接关联"坐着时红屁屁"；Code 5 H 回渗 −21% 与 L 回渗 +28% 形成极端分化，证明其 trade-off 本质|

|L 残留|L-H 低压注液后未被产品吸收固定的游离液体量（注液板/表面残留，TTM-00623 残留滤纸法）|低压锁水效率第一道关口|注意：绝对值仅 0.005–0.1g，百分比被小基数放大，n=4 无显著性检验——只作方向参考，不作判据 |

|H 残留|L-H 高压工况下的残留量|高压锁水效率|同上，Code 8 +68%、Code 10 +91% 看着吓人，实际差 0.0x 克，参考即可|

|L-H 扩散|L-H 测试中的纵向扩散长度|低压/高压下的扩散表现|与 Cradle 扩散一样无区分度（全落在 ±8% 内），本轮实际只作"未恶化"确认 |
