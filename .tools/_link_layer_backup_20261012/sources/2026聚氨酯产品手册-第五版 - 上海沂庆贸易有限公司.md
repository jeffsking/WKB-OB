# 新戊二醇 NPG
## 产品简述
主要用于生产饱和/不饱和聚酯类树脂、无油醇酸树脂、聚酯多元醇以及合成润滑剂所用酯类、聚氨酯泡沫塑料和弹性体增塑剂、高级润滑油的添加剂及其他精细化学品。NPG结合到聚酯类树脂分子链中，使树脂具有优良的化学稳定性，抗水解性、耐候性、耐腐蚀性、耐老化性和热稳定性，这些性能在高档涂料中更显得尤为明显。新戊二醇被广泛应用于汽车、家电、装饰材料等行业，尤其是在粉末涂料领域的应用和发展更为突出。另外，在医药行业也有所应用。同时，新戊二醇是优良的溶剂，可用于芳烃和环烷基碳氢化合物的选择分离。

# 三羟甲基丙烷
