# 关键区别是：__liner（面层）优先解决皮肤界面；surg

可把它理解为以下两种典型 stack：


Conventional: Skin → Liner → Surge / ADL → Core  Topical-liner design: Skin → Local topical liner + base liner → Surge / ADL → Core  Topical-surge design: Skin → Local topical surge → Liner → Surge / ADL or Core


Topical surge 是“把导流层功能前移到皮肤侧”；topical liner 是“把面层体验/皮肤界面功能局部强化”。前者更偏 fluid handling，后者更偏 skin interface；但 3D、开孔、双层及活性成分的发展，正在让两者合并为一个兼顾 intake、dryness、skin health 和消费者感知的 intake structure。


Would you like material recommendations, example constructions, or test methods for these topical vs. conventional layers?

关键区别是：**liner（面层）优先解决皮肤界面；surge（导流层）优先解决液体瞬时冲击与向芯体传输；topical 表示该局部材料被放到 liner 的身体侧（body side）。**因此，topical liner 和 topical surge 都靠近皮肤，但设计主功能不同，且边界正在变得模糊。


|层/结构|相对位置|主要功能|常见结构特征|


|Topical liner（局部表层）|叠加于主 liner 的局部 body side 区域，即接触皮肤的一面。|把“softness / 3D visual cue / breathability perception / skin health”集中到关键区域；可通过 3D 或开孔减少皮肤与湿表面的接触，并提供感知价值。|一般是轻量、柔软、3D embossed 或 apertured 的 nonwoven/film；重点是 skin-facing texture 与开孔，而非大量液体暂存。|


|Topical surge（局部表层导流层）|明确位于 liner 上方的局部 intake/distribution layer。|同时承担快速 intake 与 fluid distribution，并可将 BM 与皮肤隔离、减少 BM spread，或提供可见的产品 cue。|可为双层结构：上层偏柔软、棉感与皮肤触感；下层偏导流/支撑，并以胶黏剂贴合在 liner 上。|


|Liner / topsheet（面层）|覆盖吸收区的 body-facing 连续面层；其下通常是 surge 与 core。|皮肤接触舒适性、干爽感、柔软性、外观及皮肤健康；同时允许液体穿过。|常见 SMS、spunbond（SB）、BCW；升级方向包括低 bond、柔软纤维、3D、开孔（aperture）、印刷或 skin-health actives。|


|Surge / ADL（导流层）|常规设计中位于 liner 下、core 上，通常为局部 cut-and-place；历史上也曾是 full-length topical 结构。|接住排尿瞬间的高流量（surge）、暂存并分配液体，直到 core 吸收；影响 intake、leakage 与 rewet。|通常较厚、更蓬松、孔隙体积更高，常见 BCW 或 resilient nonwoven；例如 78–80 gsm BCW surge 对比 11 gsm SMS liner。|
