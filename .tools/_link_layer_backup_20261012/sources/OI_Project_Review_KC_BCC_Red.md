# CONSUMER INSIGHT & BENEFIT

The consumer need is a softer, more adaptive fit — not simply more stretch

1 Consumer Tension：Current elastic systems can feel harsh, warm, or restrictive against the skin.
2 Product Benefit：Soft, breathable, secure fit with lower localized pressure across the panel.
3 Technical Response：Wider elastic panel with distributed recovery force and softer facings.

Claim Space / RTB
- CLAIM: "Softer, cooler, more comfortable fit"
- REASON TO BELIEVE: Wider elastic panel + breathable nonwoven
- PROOF POINT: Lower marking; higher air permeability
- CONSUMER LANGUAGE: "Gentle, not tight"

# TECHNICAL SOLUTION

A layered elastic structure integrates stretch, comfort, and breathability

Cross-Section：Facing Nonwoven / SEBS Elastic Layer / Facing Nonwoven

Key Parameters：STRETCH RATIO 180-220%｜BASIS WEIGHT 45-60 gsm｜ELASTIC FORCE 1.2-1.8 N｜BREATHABILITY High / WVTR

Process Flow：Extrusion / Spinning → Lamination → Pre-stretch → Cooling → Roll
