# 聚乳酸无纺布的介绍以及在卫生用品上的应用

聚乳酸（PLA，Polylactic Acid）无纺布是一种以植物资源（如玉米、甘蔗等）发酵生成的乳酸为原料，经聚合、纺丝等工艺制成的生物基可降解环保材料。

PLA：是最常见的可降解塑料之一，是以乳酸为主要原料聚合得到的聚合物。

原料：通常提取自玉米、木薯、甘蔗等可再生植物资源中的淀粉。

过程：淀粉 →葡萄糖 → 发酵生成乳酸 →聚合生成聚乳酸 →纺丝成网 →无纺布。

PLA生产过程无污染，而且产品可以生物降解，使用后的PLA可以通过堆肥，在温度高于55°C或富氧和微生物作用下降解为二氧化碳和水，实现在自然界中的物质循环，不会对环境产生影响。

## 一、聚乳酸无纺布的特性

100% 全降解：在堆肥条件下（工业堆肥为主），可在数月内完全分解为二氧化碳和水，不产生微塑料，符合欧美最严格的环保法规（如英国的湿巾禁塑令）。

天然抑菌防霉：PLA呈弱酸性（pH值6.0-6.5），与人体皮肤弱酸性环境契合，具有天然的抑菌和抗螨效果（对金黄色葡萄球菌等有抑制作用）。

导湿透气：PLA纤维吸湿性低（不吸水），但导湿性好，能迅速将液体透过面层传导至吸收层，保持表面干爽。

安全性：生物相容性好，无毒、无刺激，不易引起过敏。

## 二：常见工艺

PLA水刺无纺布 (Spunlace)：手感柔软，吸水性可通过混纺调节，主要用于湿巾。

PLA纺粘无纺布 (Spunbond)：强度高，用于纸尿裤面层、底层或防漏隔边。

PLA熔喷无纺布 (Meltblown)：过滤性能，用于口罩（技术难度较高，目前不如PP熔喷普及）。

## 二、在卫生用品上的应用

随着全球“减碳”和“禁塑”政策的推行，PLA在一次性卫生用品（AHPs）中的应用正在快速增长。

1. 湿巾（Wet Wipes）—— 目前最热门的应用

这是PLA应用增长最快的领域，直接应对英国和欧盟的“含塑湿巾禁令”。

- 替代对象：替代传统的“聚酯（PET）+粘胶”混纺布。

- 应用形态：PLA水刺无纺布。

- 优势：

- 符合“无塑（Plastic Free）”认证要求。

- 由于PLA不吸水，做成湿巾时，它能更好地将药液释放到擦拭表面，而不是锁在布里，药液释放率比棉高。

- 强度比纯棉和纯粘胶更好，擦拭不易破。

2. 婴儿纸尿裤与拉拉裤 (Baby Diapers & Pants)

- 面层（Top Sheet）：

- 利用PLA的疏水性和导湿性，尿液能迅速穿透，且表面不反渗，保持婴儿屁股干爽。

- 由于其天然弱酸性，有助于预防尿布疹（红屁股）。

- 防侧漏隔边（Leg Cuffs）：

- 利用PLA纺粘布的疏水性，阻挡尿液侧漏。

- 底膜复合布（Back Sheet）：

- 虽然底膜通常是薄膜，但外层的手感布可以使用PLA，实现整片尿裤的高生物降解率。

3. 女性卫生巾 (Sanitary Napkins)

- 面层：PLA热风或纺粘无纺布用于面层，触感干爽（类似“干爽网面”的效果，但触感更接近棉质）。

- 优势：女性经期私处敏感，PLA的抑菌特性和不致敏特性是高端卫生巾的主要卖点。

4. 医用卫生材料

- 口罩：PLA无纺布用于口罩内外层，亲肤不过敏（解决佩戴PP口罩导致的脸部过敏问题）。

- 手术衣/铺单：利用其可降解特性，减少医疗废物的处理压力。

## 三、 优势与面临的挑战

优势

- 法规通行证：完美解决英国湿巾禁令、欧盟SUP指令等法规限制。

- 市场溢价：品牌可以打出“100%植物源”、“环保”、“零塑料”的高端营销概念。

- 健康属性：相比PP（聚丙烯）和PET（聚酯），PLA对敏感肌更友好。

挑战

- 成本较高：目前PLA原料价格仍高于PP和PET，会导致成品成本上升（通常贵30%-50%甚至更多）。

- 加工难度：

- PLA熔点较低（约170℃），耐热性差，在高速生产线上容易收缩或粘辊。

- 手感相对较硬，如果不经过特殊柔软处理，触感不如棉或超细旦PP纤维细腻。

- 货架期问题：PLA在高温高湿环境下会自然降解。作为成品库存时，对仓储条件要求比传统塑料高，否则可能导致布料变脆。

## 四、未来发展趋势

- 技术创新：开发PLA与PBAT、PHA等材料的共混无纺布，平衡性能与成本。

- 闭环系统建设：推动卫生用品回收-堆肥体系建设，实现真正意义上的循环。

- 政策支持：各国对生物基材料的补贴及标准制定，将加速PLA无纺布的普及。

## 总结

聚乳酸无纺布凭借其可降解性、安全舒适等特性，正逐步渗透卫生用品市场，尤其在高端、环保细分领域潜力显著。尽管面临成本与技术的挑战，但随着绿色消费升级和产业链的成熟，PLA无纺布有望成为卫生材料领域的重要可持续发展解决方案。
