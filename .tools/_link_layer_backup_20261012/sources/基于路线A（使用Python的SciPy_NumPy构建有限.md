热力学一致的相变边界反馈：根据Sauerwein与Steeb提出的多孔介质内动态水凝胶膨胀模型，水凝胶（SAP）在孔隙空间内的溶胀改变了多孔介质的形态，并显著影响了水力渗透率和机械刚度。在模型边界处，如果SAP发生强烈的朝向外部的膨胀，边界条件必须能够响应这种变形。此时，纯粹的固定压力或固定位移边界将不再适用，必须引入力学-渗流耦合的混合边界条件（类似Robin边界），即边界上的流体压力与骨架位移通过本构方程动态关联。
