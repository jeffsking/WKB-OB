# Ebewole Polymer Science & Technology — 深度阅读项目说明

源书：*Polymer Science and Technology: An Integrated Approach*（F. W. Ebewole 等，约 1997 年出版）
全书：15 章 / 约 451 页
项目路径：/sandbox/workspace/deepread/
语言规则：报告框架与执行摘要用中文；原文摘选、公式、概念定义保留英文原文不翻译；概念术语首次出现：英文 + 中文释义。

## 一、项目概述

本项目对 Ebewole 高分子教材进行了学术级深度拆解，产出三层次工作物：

- 逐章深度报告（15 份）：每章独立拆解（宏观解读 → 章节级拆解 → 核心概念深挖 → 学术对话 → 知识体系关联 → RIA 实践转化 → 合成报告），共 15 份 .md 文件；
- 概念汇总（2 批次）：Batch 1 覆盖 Ch.1–8（基础与聚合机理）；Batch 2 覆盖 Ch.9–15（助剂、反应工程、加工、溶液、力学、粘弹性、聚合物族）。每组给出"英文概念 + 中文释义 + 英文操作化定义 + 出处"；
- 原文摘选索引（2 批次 + 1 合并版）：共 202 条原文精摘，含"章节、英文原句、页码、引用目的"四栏。
顶层输出：
- Ebewole Polymer Science Technology_synthesis.md — 全局合成报告（全书地图 + 概念全景索引 + 证据链 + 阅读路线图 + 学术贡献评估 + 与 Seymour 对比）
- Ebewole Polymer Science Technology_master_index.csv — 合并版原文摘选索引（202 条）
- Ebewole Polymer Science Technology_README.md — 本文件

业务定位：本项目服务于卫材（卫生材料）非织造布研发（PP/PE/PET/PAN/PU 为主），为材料选型、聚合路径决策、加工参数优化、性能评估建立理论底座。

## 三、阅读建议

### 3.1 通用路径

- 入门：先读 synthesis.md §1–2（执行摘要 + 全书地图），建立全局认知；
- 术语预热：读 chapters/..._ch01.md 或 batch1_concepts.md A 组；
- 按业务主题跳转：参见 synthesis.md §5.2（卫材非织造布相关章节）；
- 原文溯源：用 master_index.csv 精准定位原句（含页码与引用目的）；
- 深度阅读：按需回到对应章的逐章 .md 报告。
### 3.2 卫材研发重点路径

|||
|---|---|
|快速建立聚合物基础|synthesis.md §3（概念全景索引）|

|非织造布工艺原理|Ch.11（挤出、拉伸取向）+ Ch.10（反应工程）|
