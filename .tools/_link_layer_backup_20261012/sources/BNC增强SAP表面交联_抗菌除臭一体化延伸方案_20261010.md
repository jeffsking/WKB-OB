## 一、定位与价值主张

一句话：把 BNC 的两种能力叠到同一颗 SAP 上——壳层做力学增强与导液（路线 B），壳层/载体做抗菌除臭功能负载（本方案），形成卫材 SAP 的"增强+功能"一体化产品。

为什么成立（知识库判据）：
1. BNC 嫁接抗菌除臭是"最优切入点"：智能尿裤功能层专利地图明确，CN117024899A（氨基化 CNC 改性 SAP+抗菌除臭负载）与 BNC 干颗粒嫁接工艺几乎同构，100–120℃ 干燥远低于 BNC 预估耐温 200–280℃，热工艺完全兼容。
2. BNC 干颗粒=天然多孔三维网络：可负载酸性调节剂/精油微胶囊/纳米银，作"SAP 内分散除臭颗粒"或"上浆涂料"。
3. 专利空白：BNC 干颗粒直接用于功能层的授权专利未找到——"文献可行+供应链就绪+专利空白"正是差异点。
4. 行业趋势：消臭功能与 SAP 深度复合、吸液与消臭同步一体化已被列为纸尿裤除臭技术发展方向。

## 二、理论基础（本方案的四根柱子）

### 2.1 核壳结构理论（为什么壳能干两件事）

CN117024899A 原文机理：氨基化纤维素纳米晶改性 SAP 后表面形成"核-壳"结构——低交联度的"核"保持高吸水倍率，高交联度的"壳"提高加压吸收量、凝胶强度、降低凝胶堵塞，使卫生用品持续干爽。本方案壳层在路线 B 中已由"BNC 共反应交联网络"实现力学增强，功能负载直接挂在这层壳上，核壳结构一壳两用。

### 2.2 三重协同除臭机理（功能设计依据）

CN117024899A 原文：空腔物理吸附"锁住"异味分子（氨基化纳米纤维素晶空腔）→ 蓖麻油锌酸酯化学中和"分解"异味分子 → 抗菌成分抑制细菌繁殖避免异味产生——物理吸附+化学中和+生物抑制三层递进。仅靠抗菌剂无法消除排泄物自带气味，必须双功能组合。

### 2.3 氢键+静电吸附锚定机理（为什么不溶出）

抗菌/除臭成分通过与高活性氨基化纤维素晶的氢键作用及静电吸附作用负载在树脂颗粒中，不从树脂中溶出，避免进入生殖系统或皮肤表层破坏菌群环境。

### 2.4 载体特性基础（为什么用 BNC）

BNC 表面-OH 是"天然分子挂钩"（功能接枝路线 E/F 的依据）；BNC 孔隙率约 90%+多孔三维网络=天然吸附/锚定空间；干态中间体（PEG 置换干颗粒）本身就是"通用嫁接平台"（拜科瑞在推进）。

## 三、技术路线设计（两步法，推荐）

设计原则：温度窗口分离——交联壳固化（130℃）与功能负载（100–120℃）分两步，避免功能剂在 130℃ 段热损失，且对齐 CN117024899A 的 100–120℃ 干燥窗口。

### 路线总览

【阶段 A·交联壳固化】（路线 B 原样，诺尔后处理线）
SAP 半成品(固含≈96-97%) + BNC 分散液(2%) + 交联剂液(柠檬酸酯化路线)
→ 高速混合机 → 130℃ 二次干燥(交联固化,固含≈96%) → 冷却筛分
→ 增强型核壳 SAP(BNC 交联网络壳层)

【阶段 B·功能负载】（新增工段，诺尔线低温段/独立喷涂单元）
增强型核壳 SAP + 氨基化 BNC 分散液(锚定载体,可选)
→ 抗菌剂+除臭剂混合液喷涂(高速混合机二次混料)
→ 100–120℃ 低温干燥(功能锚定) → 冷却筛分
→ 抗菌除臭增强型 SAP

### 为什么两步（对照 CN117024899A 的顺序逻辑）

其工艺本身就是"缩合改性→物理负载→100–120℃ 干燥"的顺序；我方阶段 A 的 130℃ 固化在前、阶段 B 的 100–120℃ 负载在后，功能剂全程不经历 130℃ 高温——这是与"一步法混合喷涂"（功能剂在 130℃ 下存在降解/挥发风险）的本质区别，也是本方案工艺上的护城河点。

## 五、验证清单

### 5.1 材料级（阶段 A+B 成品）

- 四指标矩阵：CRC / AUL(0.7–0.9 psi) / GBP / Vortex（与未负载对照比对，确认功能负载不牺牲力学指标）
- 吸收速度（600 rpm 磁力搅拌漩涡消失时间，参照 GB/T 22875-2018）

### 5.2 抗菌性能（GB 15979-2024 口径）

- 载体浸泡定量抑菌试验（E.6.2）/ 非溶出性材料用振荡烧瓶法（E.6.6）：大肠杆菌、金黄色葡萄球菌、白色念珠菌
- 判定：抑菌率≥50% 有抑菌作用、≥90% 较强抑菌作用
- 溶出性鉴定：无菌蒸馏水浸泡 24 h，浸泡液无抑菌效果→非溶出性材料，走振荡烧瓶法

### 5.3 除臭性能（CN117024899A 同口径）

- 2.00 g 样品+50 g 异味源（氨水/醋酸）置于气体采样袋，37℃/50%RH 恒温恒湿 7 h，测 NH₃/CH₃COOH 残留浓度，去除率=(C₀-C₁)/C₀
- 目标：氨去除≥90%（专利最高 98%）、醋酸去除≥85%（专利最高 95%）

### 5.4 安全与迁移

- 抗菌剂（聚六亚甲基胍）、EDTA、蓖麻油锌酸酯在诺尔 130℃/100–120℃ 双温段的热稳定性评估（先于台架）
- 不溶出验证（24 h 浸泡）+ 重金属/微生物指标（卫材原料要求）

## 八、风险与成本要点

1. 热稳定性是第一风险：聚六亚甲基胍、蓖麻油锌酸酯/吐温体系在 130℃ 的降解/挥发未验证——两步法已把功能剂隔离在 100–120℃ 段，但仍需台架确认；
2. 功能负载对力学指标的冲击：除臭剂含多元醇/吐温类表面活性组分，过量可能软化石壳——DOE 限幅（除臭剂 0.5–5 wt% 优先）；
3. 成本：抗菌剂+除臭剂用量为 SAP 的 0.5–5 wt% 量级，加 BNC 成本，最终增量成本须在 F3 前核算清楚（增强+功能双卖点的可接受溢价边界）；
4. 安全合规：聚六亚甲基胍、EDTA 在卫材中的允许用量与法规适用性须专项确认；优先用壳聚糖类（食品/药用级）作低风险抗菌剂替代；
5. 与诺尔现有线的工程衔接：阶段 B 需 100–120℃ 低温段——诺尔后处理设备温度窗口 120–180℃ 可下调，或利用冷却后二次喷涂+余温干燥，改造量小。

## 九、总结

本方案=路线 B（增强壳）×CN117024899A（功能负载）的工程化合并：两步法把 130℃ 交联固化与 100–120℃ 功能负载分离，规避功能剂热损失；BNC 壳层同时充当力学增强网络+功能锚定载体；专利空白点（BNC 干颗粒嫁接功能层）支撑联合申请。三个前置门：CN117024899A 授权状态、功能剂热稳定性、抑菌/除臭双 90 达标——过了再上诺尔线。

本方案为延伸设计，配方参数引自知识库收录专利公开文本；法律状态标注"待查"处须以官方数据库复核为准。
