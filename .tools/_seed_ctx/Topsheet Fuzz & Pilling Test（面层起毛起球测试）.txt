--- [[Rewet Test（回渗测试）]]  (6 句)
   • 1. **回渗的物理来源**：液体被 SAP 吸收后仍有一部分以**毛细水 / 颗粒间隙水**形式停留在面层与芯体表层；受皮肤压力时，这部分水被挤出到滤纸上。因此回渗量对**载荷**与**等待时间**极度敏感。
2. **等待时间决定"自由回渗"的量**：注液后立即测（短等）读到的是面层残液；等待 10–15 min 后测读到的是"压力下长期未吸收液"。前者对应溢奶/快速活动的体感，后者对应久坐/夜间的体感。
3. **载荷决定测量档位**：本库出现三档——国标 1.20 kg（直径 100 mm 压块）、U Rewet 的国标回渗压块（1 min）、高低压反渗的 2×4 kg（合计 8 kg）。**三档不可互相替代**。
4. **读数计算在三种方法中高度一致**：（BM 便液版本同构）。
5. **回渗与滑渗是互补指标而非重复**：回渗量液体"返出"，滑渗量液体"漏走"（见 Run-off & Leakage Test（滑渗与渗漏测试））。
   • 上游指标：Cradle Intake Test（Cradle 摄入测试）（吸收时间）、SAP性能指标（CRC AUL GBP Vortex）（AUL / GBP 是回渗的物质基础）
- 互补指标：Run-off & Leakage Test（滑渗与渗漏测试）（滑渗 / 渗漏）
- 同族口径：Liquid Diffusion Test（液体扩散测试）（扩散长度）
- 便液版本：Mannequin BM Test（BM 假人测试）
- 上位索引：芯体测试方法与验收基准（STM）
- 对比：Rewet Protocols Compared（回渗测试口径对比）
   • 上文已确立的硬约束是 **"回渗值不可裸引"**（同一公司 30 年间用过 0.005 / 0.05 / 0.24 / 0.5 / 0.7 / 1.0 psi 六档压力）。本追加段把这条约束**从"纵向的历时变化"扩展到"横向的跨组织方法"**：**客户（Walmart 训练裤招标）指定的是另一套标准**，其加液量、压力、介质与时长全部不同。

--- [[三叶形截面纤维（Trilobal Fibre）]]  (6 句)
   • 1. **截面决定功能**：圆形截面纤维之间只有"点接触"，液体靠纤维间孔隙毛细力输运；三叶形截面的三个凹槽在纤维表面形成**轴向沟道**，纤网中相邻纤维的沟道叠加即成为**准连续的低阻导流路径**。
2. **方向性 = MD 沟槽**：梳理成网时纤维沿机向（MD）取向，沟道也随之沿 MD 排列 → 液体被**沿机向拉长铺展**，而非在冲击点堆积。这是"MD distribution / MD 铺展"指标的物理来源。
3. **两种载体**：
   - **PE/PET 皮芯型三叶形**（面层用）：三叶形截面 + 皮芯结构并存，兼顾导流与热粘合；COCO V6 面层上层仅放 10%、下层放 50%。
   - **三叶形莱赛尔（Lyocell）粘胶纤维**（芯包/水刺用）：用于 LSN 水刺非织造，主打湿态强度与亲水通道——对应 OI-08「Trilobal Lyocell for LSN」。
4. **配比的两难**：三叶形越多导流越好，但贴肤侧三叶形**手感偏硬**。COCO V6 的解法是 **Z 梯度分层**——整体 30%（15 gsm），但皮肤侧只放 5%。详见 ATB双
   • 结构载体：皮芯复合纤维、ATB双梳理面层（Dual-Card Topsheet）
- 工艺载体：热风粘合无纺布、SMS复合结构
- 导流家族：ADL（导流层）、毛细梯度设计、分区密度设计
- 纤维成纤性：成纤性判据、原纤化
- 对比：COCO V6 Liner 方案对比（Code 1 vs Code 2-A vs Code 2-B）
   • ✅ **验证记录（2026-09-29）**：分层 10%/0% 与 0%/10% 的双 code 设计为已决方案；打样米数、温度点、旦数口径均来自 ASR 转写，标 ，引用前须与实验记录核对。参见 COCO V6 Trial Code Design & Process Alignment（录音纪要 2026-08-17）、COCO芯体平台、Ultrasonic Bonding of PET-Containing Topsheet。
   • ✅ **验证记录（2026-09-29）**：+20–30% 为**目标值而非实测值**；50/50 为报价前的建议配比；「粘胶亲水、PET 疏水」为机理判断，未见对比测试数据 [待验证]。参见 ADL（导流层）、ATB双梳理面层（Dual-Card Topsheet）、COCO芯体平台。

   • **Complex Core（复合芯体）**九项（基重、厚度、COV、尺寸、回渗、吸收性、滑渗、水分、白度、pH）**全部指向 Inner Quality Testing Standard（内控质量标准），无任何 KC STM 编号**——这是本表最值得注意的结构性事实：复合芯体作为新兴材料，其进厂判读尚未进入 KC 全球方法体系。
   • **SAM 五指标（PSD/GBP/CRC/AUL/Vortex）已有完整 KC STM 编号，是本库 SAP 来料判读的正式口径** —— 支撑页：SAM Testing Methods（超级吸水材料测试方法）、SAP性能指标（CRC AUL GBP Vortex）
- **复合芯体九项判读全部依赖内控标准，尚未纳入全球 STM 体系** —— 支撑页：COCO芯体平台、芯体测试方法与验收基准（STM）
- **GB/T 22875-2018 是 SAM 的国标总括方法，覆盖 7 项化学与物理指标** —— 支撑页：SAM Testing Methods（超级吸水材料测试方法）
- **无纺布判读以 GB/T 24218 系列为主干，KC STM 仅作补充** —— 支撑页：热风粘合无纺布
- **WVTR 归入内控-12，另有 Mocon 法 WI-62362，属两条并行的透气/透湿路线** —— 支撑页：WVTR 测试口径（失重法 vs 增重法）
- **「差异点汇总」表为空，截至 2026-09 无已登记的操作-标准偏差** —— 支撑页：Kimberly-Clark（金佰利）
   • 概念：SAM Testing Methods（超级吸水材料测试方法）、SAP性能指标（CRC AUL GBP Vortex）、热风粘合无纺布、WVTR 测试口径（失重法 vs 增重法）、Rewet Test（回渗测试）、Run-off & Leakage Test（滑渗与渗漏测试）、COCO芯体平台、芯体测试方法与验收基准（STM）
