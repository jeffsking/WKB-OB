--- [[Residual Fluid & Pore Stranding（残液与孔隙滞留）]]  (2 句)
   • 1. **残液的两个出口条件由 Young-LaPlace 方程给出**：**ΔP = −2γcosθ / R**。毛细压由**润湿性（θ）**与**孔径（R）**共同决定。**毛细压越高 → 孔越想把液体留住；解吸能越高 → 纤维越难"晾干"**。因此降低残液只有两条路：**降低润湿性（提高 θ）**或**加大孔径 R**（以及让孔径分布收敛）。
2. **孔径分布（PSD）比平均孔径更重要**：假说是**液体滞留在极小孔里，因为旁边没有足够大的孔把它拉出来**。双峰/宽分布会造成"抽不出来"的死角；对策是**让纤维尺寸趋同以收窄分布**，并**减少孔的总数以减少可拘留液体的位置**。
3. **润湿性这条路有硬冲突**：去掉面层润湿处理确实降回渗（0.26 → 0.20 g），但**漏液率从 3.2% 升到 4.6%**——因为面层不亲水就拦不住涌流。**同一处改动同时影响"干"与"漏"，必须成对验收**；且该冲突在不同品类上结论不同（未处理面层在 BCC 可行，在成人护理上不可行）。
4. **加大孔径这条路相对安全**：粗纤维 → 大孔径的面层（LOKI 类）在预测与实测上**
   • **教训**：**降回渗与防漏必须在同一次试验里验收**。去润湿处理把回渗降了 0.06 g，却把漏液率抬了 1.4 个百分点——**只看回渗会做出错误决策**。
- **教训**：**"更好"的单项指标可能整体更差**。导流层毛细性更好 ≠ 排水更好（克重更高）；剥离强度更高 ≠ 回渗更低（Henkel 强度高但 RT-8723 残液更少）。**每个界面变量都有最优区间，不是单调的**。
- **教训**：**把两个耦合功能解耦到不同手段上**。竞品用**卷曲纤维单独承担摄入**（且不影响回渗），从而让导流层可以降克重——这是"不要用一个手段解决两个问题"的范例。
- **教训**：**预测模型可用于排序，不可用于绝对值**。三组预测全部高估（0.63→0.36；0.32→0.16），但组间排序正确。
- **待补 **：残液量 ↔ 回渗的定量系数；孔径分布的最优宽度与"孔数量"的度量方法；SMS 包裹层抬高回渗的成因。

--- [[HSBL Attachment Strength Results（HSBL 附着强度结果 · 2025-11-18）]]  (2 句)
   • **结果摘要**：**施胶花型（adhesive pattern）对剥离强度影响最大**；**Minibead 花型的剥离强度远高于其他**，**Summit 最低**，**Signature 与 CF Swirl 相近**。附加效应：更高剥离强度对应 **施胶基材为导流层（surge）**、**胶型 Henkel 5402**、**有压合（PICASSO bonding）**；更低剥离强度对应 **基材为面层（liner）**、**胶型 Rextac RT-8723**、**无压合**。
   • **各因子细节**：
- **施胶花型**：Minibead 最强；**Minibead 的剥离强度同时变异最大**——原文提出 CF Swirl 与 Minibead 之间的剥离强度落差**可能正是 Depend 回渗值更不稳定的原因**；另注 **Summit 喷嘴历史上粘合强度 ≥ Signature**，本次偏低疑为试验期间花型质量不达标（Tukey-Kramer 0.05 分组中 CF Swirl 52.879 / Signature 44.119 / Summit 24.097 等均值）。
- **施胶基材（Primary Substrate）**：**胶应施加在导流层上以获得高剥离强度**——Surge 均值 **408.19**（Std Error 29.750，A 组）vs Liner **230.09**（Std Error 26.434，B 组），**未共享字母即统计显著**。注：面层作基材仅在 Minibead 喷嘴组合中出现，故右图只含 minibead 代码。
- **压合（Bonding）**：**压合的剥离强度高于不压合**（p = 0.0002）。**
