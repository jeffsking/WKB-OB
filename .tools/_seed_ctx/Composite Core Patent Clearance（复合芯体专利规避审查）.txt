--- [[COCO V6 Trial Round-2 Review（录音纪要 2026-09-16）]]  (6 句)
   • COCO V6 第二轮实验数据的逐条复盘会：确认「减 SAP + 增大开槽面积」这条路走不通，把设计约束收敛为「**下层 SAP 维持 7 g、channel 只加长不加宽**」，并暴露出哑铃形的重量波动与熔喷 core wrap 的强度风险。
   • 1. **下层 SAP 添加量维持约 7 g**：再往下调虽对回渗影响不大，但**U 型回渗会出现明显劣势** → 定为下限口径。
2. **channel 不加宽（会上一致反对）**：① 对扩散方向不利；② 宽度越大、局部无 SAP 区域越大，**CD 方向毛细更差**（侧漏风险）；③ **channel 对 cradle 本身是负面影响**，中间越宽负面越大。
3. **channel 加长可以继续考虑**，但必须匹配 SAP 的能力（且实际减量是「均匀减」，中心区域的 SAP 也会一起降低）。
4. **三叶草纤维打样温度压到 139 ℃ 以下**：实测**142 ℃ 以上异形截面会流平**（丧失截面形状）。
5. **熔喷 core wrap 的强度问题要立项**：若方向成立，需尽快组织 project team 解决材料在高速下的强度问题。
6. **SAP 的实验策略调整**：实验阶段**不要只等现有供应商开发**，可先把其他家的 SAP 拿来证明 concept 可行，再让现有供应商跟进。
   • **减 SAP 的假设被数据否定**：假设「有 SAP 处 density 与 5.6 一致 + 开槽面积增加 → 可减量且性能维持」，实测**回渗/高低压无大影响，但第二轮 cradle intake 与第三轮 input 明显变差**（某 code 时间远超 CTRL 与 code 2）。→ 该路径**未走通**。
