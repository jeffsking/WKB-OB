# SMS 复合结构（Spunbond-Meltblown-Spunbond）

> 一句话定义：按「纺粘—熔喷—纺粘」顺序叠加的三明治型复合无纺布，用纺粘的强度弥补熔喷的强度短板，同时保留熔喷的过滤性能。

## 机理 / 结构拆解

1. **分工逻辑**：纺粘层（纤维 7–30 μm）提供强度骨架；熔喷层（纤维 1–5 μm 超细）提供过滤/阻隔功能。三明治式分工。
2. **为什么必须复合**：熔喷的过滤精度虽遥遥领先，但**强度几乎为零、蓬松度垫底**——单独使用无法满足医用防护服的实际需求。
3. **典型场景**：医用防护服、手术衣、口罩内外层。
4. **同类复合思路的其他形态**（同源资料列举）：热风棉+SAP+底膜（纸尿裤/卫生巾吸收芯体整体结构）、水刺+纺粘（高端擦拭布/部分医用敷料基材）、针刺+树脂加固毡（工业过滤毡/汽车内饰基材）。

## 经验教训

> ✅ 验证（2026-09-27，来源 [[无纺布-五大工艺论剑]]）：来源明确给出「复合结构的核心价值 = 用长处互补」的工程逻辑，并指出这正是无纺布工艺设计的核心思维方式。本页作为 seed 级页面仅记录该逻辑。

> ✅ 验证（2026-09-29，来源 [[Laser-Assisted Meltblown Film-Free Backsheet（激光辅助熔喷无膜背层）]]）：新增一份**以熔喷为阻隔主体的复合结构**系统数据，与既有「用长处互补」的定位一致，同时补上三条量化结论——① 阻隔完全由熔喷克重与**束数**承担，内层纺粘零贡献（SMMSMMS 同束数同克重 → 同阻隔，代价 **+8 gsm / +27 % 成本**）；② 同聚合物同克重下把熔喷**拆成 4 束**（15 % CV）可把最弱斑保住克重从 44 % 提到 72 %，即 **+64 % 阻隔**；③ SMMMS 30 gsm 静水压 141 mbar（清水）/121 mbar（合成尿），但遇稀便降至 55 mbar、护臀膏降至 14 mbar。详见 [[SMMMS vs SMMSMMS（成本·性能·供应链）]]、[[Formation-Limited Barrier（阻隔的成形受限机理）]]、[[Film-Free Backsheet（无膜背层）]]。

- **⚠️ 本库重点风险提示（来源原文强调）**：**PFAS 风险不只在「防水」宣称里**。熔喷布的**驻极助剂**常含含氟电荷俘获剂，是最容易被忽视的隐藏 PFAS 来源；常规质检思路经常遗漏这一点。应对方向：驻极助剂需专项核查，转向 C0 无氟体系。
- **2026-09-29 追加（无氟路线已出现可执行的化学选项）**：无膜背层方案要求疏水化走 **PFAS-free alkyl-modified polyolefin masterbatch（无氟烷基改性聚烯烃母粒）**，advancing contact angle 105° → 118–122°，约 +35 % hydrohead，成本 3.5 EUR-c/kg——可作为「转向 C0 无氟体系」的具体落点。出处：[[Laser-Assisted Meltblown Film-Free Backsheet（激光辅助熔喷无膜背层）]]。
- **待补**：SMS 各层的克重配比与阻隔性能定量关系，本库暂无来源 `[待验证]`；2026-09-29 追加：SMMMS 的**实测**（非模拟）静水压与单束成形 CV 仍缺。
