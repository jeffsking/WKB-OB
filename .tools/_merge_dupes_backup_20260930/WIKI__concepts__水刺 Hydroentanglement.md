# 水刺 Hydroentanglement
> 📌 **Page completed 2026-09-30** from 6 citing sources. All figures traced to their source pages. Anything not evidenced is marked `[待补]`.

## Definition 定义

- Hydroentanglement (also called **spunlacing 水刺**) is **high-velocity water-jet mechanical bonding** — **binder-free, lint-free, soft**.（源：[[Mechanical bonding]]）
- 水刺属于**机械加固 mechanical bonding** 三技术之一，另两者为**缝编 stitch-bonding**（Maliwatt / Malimo / Malipol）与**针刺 needlepunching**。三者共同点是：不依赖粘合剂、热粘合或化学粘合剂，而是让纤维**互锁**成布。（源：[[Mechanical bonding]]）
- 定位差异：缝编与针刺主要面向**耐用 / 工业制品**；水刺是**面向一次性用品（disposables）的增长引擎**。（源：[[Mechanical bonding]]）

## Method / Mechanism 方法 / 机理

- **成布原理**：高速水射流对纤维网施加冲击，迫使纤维相互缠结，从而在**无粘合剂**条件下获得强度（binder-free）。（源：[[Mechanical bonding]]）
- **水刺章节给出的设计工具**：比能量 K、SE_c，射流冲击力 F ∝ p·d²，以及纤维选择规则与**原位微纤化（in-situ microfibre）路线** —— 可分裂双组分（splittable bicomponents）、Lyocell 原纤化 `[原文残缺]`。（源：[[Mechanical bonding]]）
- **纤维选择规则**：粘胶 / 莱赛尔（低湿模量，low wet modulus）**易缠结、成本低**；PP / PET 则**需做亲水处理（hydrophilic finishes）**。（源：[[Mechanical bonding]]）
- **高冲击力解锁高端路线**：提高射流冲击力可解锁微纤化路线 —— 双组分分裂（BICO split）与 Lyocell 原纤化。（源：[[Mechanical bonding]]）
- **湿法成网（wet-laid）相关机理**：湿法成网先以标准定义（EN 29092 / ISO / EDANA）区分湿法无纺布与湿法纸，再推导堰口速度的伯努利方程；两种沉积机制 —— 过滤式（filtration，逐根纤维 → 均匀）与增稠式（thickening，预絮凝 → 不均）。（源：[[Wet-laid web formation]]）

### 水刺在 SAP 固定载体中的分工（专利证据）
- **刻意不对称的分工**：顶层多孔、柔软、蓬松（porous, soft and bulky），让颗粒**钻进**纤维之间；底层孔径小得多、机械强度高得多，负责拦住颗粒不掉落。（源：[[Hydroentangled Nonwoven Carrier for SAP Immobilization（水刺复合 SAP 固定载体）]]）
- **两个约束方向**：（1）**x–y 平面**移动靠顶层纤维的**缠结捕捉**阻止；（2）**z 向掉落**靠底层**孔径 < 颗粒粒径**阻止。（源：同上）
- **为何必须是水刺**：来源把机械缠结（hydroentanglement）与热粘合、热熔 / 超声、针刺、化学粘合、胶粘合并列后**定为优选**，因为它使短纤对底层形成**基本永久的固定（essentially permanent fixation）**，从而得到足以兜住颗粒的稳固结构。（源：同上）
- **权利要求层面**：载体由**可被颗粒穿透的顶层**与底层组成，顶层经**水刺机械粘合**到底层，底层多孔且**孔径小于颗粒**。（源：[[EP3085346A1 Nonwoven Carrier for Absorbent Article (Ontex)]]）

## Hygiene Relevance 卫材关联

- 水刺被明确列为**面向一次性用品的增长引擎**，是三者中最贴近卫材应用的机械加固方式。（源：[[Mechanical bonding]]）
- **SAP 固定载体**：水刺用于把 SAP 颗粒固定在薄载体中 —— 底层选 spunmelt / SMS，因其在**很低的克重（最优选仅 4–12 gsm）**下仍能提供足够强度与足够小的孔径，这是把载体做薄的前提；顶层按**双峰纤维设计**（≤50% 短而轻 + ≥50% 长而重，至少两类 PET / PE / PP）。（源：[[Hydroentangled Nonwoven Carrier for SAP Immobilization（水刺复合 SAP 固定载体）]]）
- **柔软 / 不掉屑（soft, lint-free）** 与**无粘合剂**特性，适合与面层等贴身层相关的应用。（源：[[Mechanical bonding]]）
- **成本杠杆**：K 与 SE_c 可工程化调控 —— 在强度不变的前提下**降低 SE_c 即降低水耗 / 电耗（water/power cost）**。（源：[[Mechanical bonding]]）
- 库内相关条目并与水刺并列登记：[[SMS 纺粘熔喷复合]]、[[纺粘 Spunbond]]、[[熔喷 Meltblown]]、[[Nonwoven 非织造布]]、[[Topsheet（面层）]]、[[吸收芯体]]、[[ADL（导流层）]]、[[SAP（高吸水树脂）]]。（源：[[Absorbent Technology]]、[[Nonwovens in Absorbent Materials]]、[[Handbook of Nonwovens]]、[[Fluid Absorption in High Bulk Nonwovens]]）
