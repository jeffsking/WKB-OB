# 热风粘合无纺布（Air-through Bonding / Thermal Bonding）

> 一句话定义：让热风穿透疏松纤维网，使网中的热塑性**粘结纤维选择性熔融**、冷却后在纤维交叉点形成粘合点，从而固定蓬松结构的一种干法固结工艺；主体纤维并不熔化。

## 机理 / 结构拆解

1. **选择性熔融是本质**：只熔化配方中的粘结纤维（或双组分纤维的皮层），主体纤维被「焊」在原位。若所有纤维都熔融，蓬松结构会直接塌陷——这正是热风棉能同时兼顾蓬松度与强度的原因。
2. **粘结纤维是配方核心**：纯天然纤维（棉、粘胶）不具热塑性，无法单独热风固结，因此热风棉配方几乎都围绕粘结纤维设计。
3. **典型流程**：纤维开松混合 → 梳理成网 → 热风烘箱穿透加热 → 冷却定型 → 分切卷绕。
4. **蓬松的三维结构带来预处理复杂度**：助剂容易出现「表层浓、内部稀」的不均匀分布，梯度设计难度高于平面型无纺布。

> ✅ 验证（2026-09-27，来源 [[热风与针刺无纺布]]、[[无纺布-五大工艺论剑]]）：两份同源资料对热风法的定位一致——「蓬松柔软但强度弱」，且均将**纸尿裤吸收芯体包覆层**列为热风法的首选场景。本页结论与来源一致，未发现矛盾。

### 1. 本批新增工艺参数（含 PET 面层）

| 参数 | 现状 / 基准 | 含 PET 构造设定 | 理由 / 出处 |
|---|---|---|---|
| 烘箱风温 | 132–136 ℃ | **138–142 ℃** | 更少的 ES 交叉点须各自承担更大载荷 → 驱动更充分的皮层流动（[[Trilobal PET for MD Distribution in 45 gsm Dual-Card ATB Liner]]） |
| 停留时间 | 基准 | **+10–15%** | 回收约 3–5% 的模拟 CD 拉伸损失，且不过粘合（同上） |
| 穿透风速 | 1.2–1.5 m/s | **1.4–1.8 m/s** | 网中惰性 PET 占比升高，须把更多焓送到 ES 上（同上） |
| 压网 / 托网张力 | 基准张力 | **降 10–15%** | 保厚度——过粘合是丢掉柔软度的最快路径（同上） |
| 目标厚度 | — | **控制在 ±5% 内** | 蓬松度承载bulk 手感与空隙体积，不可用其换拉伸（同上） |
| 冷却 | 自然冷却 | **卷绕前强制冷却** | PET 在冷却中恢复卷曲与蓬松；热态卷绕会把塌陷锁死（同上） |
| 分切 | 钢刀 | **碳化物/陶瓷刀，换刀频次 +30–40%** | PET 磨蚀性强，钝刀起毛并在转化段暴露（同上） |
| 幅宽监控 | — | 过烘箱收缩 **>1–2% ⇒ 热定型不足，停线改规格** | 未定型 PET 在烘箱中收缩 → 幅宽损失、边卷、CD 皱（同上） |
| 温度窗口（面层 DOE 口径） | — | **126 / 128 / 130 ℃** × 低/高载荷，且**不提高烘箱温度** | PE 皮层约 130 ℃ 流动，找"强度 vs 扁平化"平衡点（[[KC Diffusion-Enhanced Topsheet v3 DOE Plan (C1-C4 Liner DOE)]]） |
| 烘箱温度稳定性 | — | **±1 ℃ 稳定 / 位置间 ±2 ℃**，每次试验前校准 3 个位置 | 位置差会直接移动试验结果（同上） |
| 粘合强度门 | — | **≥10 N/cm（剥离）**；厚度损失 ≥8% 则收益归零 | "强度 vs 扁平化"是本批关键平衡指标（同上） |
| 粘合点量化（粘合模型） | — | `B(w)=w²+2w(1−w)·k`，`k≈0.55`；CD 拉伸与 8.0 N/50 mm 下限的交点约 **41% PET** | 粘合点下降速度快于 ES 占比下降（[[PE-PET Bond Efficiency Model]]） |
| **关键禁令** | — | **不得为提高粘合而升高烘箱温度去粘 PET**；保护 PE 皮层与蓬松度 | 单组分 PET 不是 ES 粘结剂（[[Pentagram PET Fiber Add-On for 25 gsm ATB Diaper Liner (Deep Dive)]]） |

### 2. 验证记录

> ✅ 验证（2026-09-29，来源 [[Trilobal PET for MD Distribution in 45 gsm Dual-Card ATB Liner]]、[[Pentagram PET Fiber Add-On for 25 gsm ATB Diaper Liner (Deep Dive)]]、[[KC Diffusion-Enhanced Topsheet v3 DOE Plan (C1-C4 Liner DOE)]]）：本页既有判断「选择性熔融是本质」「最优解是满足湿强下限的最小粘合」在本批被**以含 PET 配方再次确认**——三份来源都把"**不得靠升温去粘 PET**"写成红线级约束，并把厚度/蓬松度列为不可让步项。原页结论**未被修正**。

- **追加要点**：含不可粘纤维的配方里，烘箱调参的目标不是"提高粘合"，而是**让更少的 ES 交叉点承载更大的载荷**，同时用冷却与张力保护厚度。
- **追加 `[待验证]`**：138–142 ℃ / +10–15% 停留的**产线实测**拉伸与厚度数据（本批为模拟与设计建议）。

- **手感是第一需求**：本方明确指出「产品性能好，但消费者拿到手的第一直观感受差，就不会被选择」→ 性能不能替代手感。

**打孔（perforating）质量问题（本批新增）：**

- 缺陷：部分孔**连在一起**、孔大小不均。
- 机理：卷内侧（靠内部）张力更大 → **大孔比小孔更易变形**；小孔变形较小。
- 对策（本方建议）：打孔材料应开发**张力更小的收卷/加工方式**，以提高孔型保持率。
- 打孔幅宽口径：2.4 / 2.2 m；图案已到 3.0 版，其中前 5 种为在线生产；越南明年 Q1 建离线打孔能力。

**扎点 / 棉结（本批新增）：**

- 现象：布面有「疙瘩 / 扎点」。
- 机理：**开棉（开松）与梳理不均**所致，取决于开松机/梳理机的状态与结果。
- 影响：扎点与结球都会影响手感，且不符合本方质量要求。
- 对策方向：若因纤度变化（如 0.6 旦材料）引起，需**更换针布（carbon wires）**以适配。
