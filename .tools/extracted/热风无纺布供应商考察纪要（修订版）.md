# 热风无纺布供应商考察纪要（修订版：已剔除证伪内容）

整理日期：2026-08-21 说明：本纪要基于本轮对话全部内容整理，已剔除被证伪或经核实无证据支持的部分（见文末“已剔除内容”），其余内容均保留原始细节并标注信息来源与可信度状态。

# 一、供应商主体关系：新维盛集团与雷尔（已核实，互联网公开信息）

# 1. 股权关系

•新维盛集团于 2021年12月收购福建雷尔，正式成立新维盛集团（集团官网口径）；雷尔招聘页面表述为“2021年11月加入新维盛集团”。

•新维盛集团构成：

–常州维盛（母体，约30年历史，国内最早同时拥有热轧/热风/水刺产能的厂家之一）

–佛山维盛（2016年设立）

–福建雷尔（2021年12月收购，位于南平松溪县）

–福建维盛南平建阳新厂（2022年7月投产）

•福建维盛新材料成立于2021年4月21日，整合江苏维盛、佛山维盛、松溪雷尔等企业，目前管理 5家热风无纺布工厂，形成集团化运营。

# 2. 雷尔自身情况

•成立于2017年，位于南平松溪县经济开发区（不在建阳），占地46亩

•规划6条热风线、目标产能1.5万吨/年；一期投资3000万元、年产3000吨，2018年9月量产

•产品定位高端热风无纺布，用于纸尿裤/卫生巾的面层、导流层、拒水底层

# 3. 与闽瑞的绑定关系

•闽瑞2023H1公告：第一大客户为“佛山维盛/福建维盛合并列示”（占30.17%），福建雷尔单列（10.69%）——即集团整体占闽瑞出货约41%

•闽瑞对维盛系和雷尔给予 150–180天账期（普通客户仅30天），理由为“产业园下游协同”

•集团位于建阳医卫材料产业园，与上游闽瑞ES纤维（超细旦0.4–0.8D）形成“闽瑞—新维盛”材料链条，产业集群协同能力强，样品调试和问题追溯快

采购含义：拜访对象实为同一集团在福建的两个厂（建阳厂+松溪厂），商务谈判和产能调剂可在集团层面统一考虑；备选产能池包括建阳、松溪、佛山、江苏四地5厂。

# 二、新维盛热风无纺布技术能力（已核实，公开披露口径）

# 1. 产能与装备

•14条特吕茨施勒热风线（全球运营特吕线最多的厂家），年产能4.5万吨

•未来三年扩产计划：国内再增1.5万吨 + 海外3.2万吨

•配有世界一流的中仓混棉系统

# 2. 产品工艺能力

•超细旦：0.8D、0.6D已量产，0.4D在研，具备超细纤维高速稳定生产能力

•超低克重：14 g/m²稳定量产，向12 g/m²推进

•后加工：3D热压打孔压花、超声波压花、高能冲孔赋型共12条深加工线；美妆级喷涂车间（2025年投产）

•复合材料：热风复合无尘纸、复合SAP/SAF“一体芯”（导流层+超薄芯体方向）

•功能性产品：微胶囊香氛、温感变色（如橘红色温变面料，体温触发变色）、长效抑菌、植物精华、可降解纤维

•研发迭代：2025年新增专利12项；与设备厂商合作研发全国最宽热风无纺布产线（即将投产）

# 3. 3D压花降克重（一手会议记录，可信度：高）

•常规45 g/m²克重可降至 38 g/m²、35 g/m²（降幅约15–22%），同时保持导流和透气性能

•在线压花工艺，避免人工触碰，降低污染风险

•来源：EM Supplier Meeting Follow-ups（2026-06-21会议纪要）

# 4. 专利层面

•常州维盛无纺（集团母体）公开专利包括：多层无胶复合无纺布（纤维层+基材层一体成型）、凹凸花纹热轧复合（沟槽导流、凸起干爽）

•工艺思想为分层功能梯度，走“复合/压花”路线

# 三、“三层切割（Triple Cutting）”：状态为未验证概念（重点澄清）

# 1. 信息源头追溯（已核实）

•唯一一手来源：《EM Supplier Meeting Follow-ups》会议纪要（2026-06-21），原文记录格菲尼亚/新维盛提到两个感兴趣方向——“Triple cutting（三层切割）材料开发：研究配方搭配，未来可能不需导流层、中间层，直接用其材料加芯体即可”及3D压花技术

•该记录为口头术语记录，无技术细节、参数或书面材料支撑

# 2. 真实性核查结论（互联网检索，2026-08-21）

•新维盛官方对外披露的全部技术清单（集团官网、中产协、行业媒体报道、宣传片）中均未出现“三层切割”，亦无“切割成三条窄幅再复合”的表述

•功能最接近的官方说法是热风复合无尘纸/SAP一体芯做导流层——属“复合”路线而非“切割”路线

•专利层面无对应记录；无产品页、无商业化客户证据

# 3. 当前判断

•不排除为实验室/客户定制能力（技术上可行，集团有12条深加工线）

•更可能是术语转述偏差：供应商销售将“热风复合/一体芯”方案口头包装为“三层切割”

•结论：按“未验证概念”处理，不计入REL项目备选技术路线权重

# 4. 现场待关闭问题（拜访Q1升级版）

•“三层切割在你们官网和对外资料里都没有出现，是独立产品还是热风复合方案的定制版本？”

•是否有已商业化客户、实测样品和参数（各层克重分配、切割方式在线/离线、热切/机械切、复合方式热复合vs胶粘）

•湿拉伸强度、首渗时间、回渗量、MD/CMD扩散速度等实测数据

•注意区分：7月24日实验室录音中讨论的“REL层在芯体中间是否切断”（卓笔切断IEL方案）是另一件事，勿混淆

# 四、竞争位势评估（保留，来源：知识库拜访计划）

•与景其昌、格菲林同属可比供应商梯队

•产品设计与性能可对标延江/大源，技术差异不大

•对KC定位：EM地区低成本补充供应商（第三选择）；背景为延江/大源产能紧张，寻找第三家补充产能

# 五、已剔除的证伪/无证据内容（原对话中出现过，不可采信）

1.“雷尔与维盛是独立并列的两家公司” —— 已被股权信息证伪：雷尔是2021年12月被新维盛集团收购的松溪老厂，属同一集团（原始知识库清单为信息滞后）

2.“三层切割的分层功能架构（上层亲肤/中层导流/下层渗透）、切割-复合工艺路线、Janus三层不对称毛细驱动原理” —— 这些是早期拜访计划中的推测补写，无任何供应商书面材料、专利或公开文献佐证，且互联网核查无此产品线，全部剔除；仅保留“供应商口头提及Triple cutting、意图省去导流层/中间层”这一原始事实

3.“三层切割与3D压花为并行而非替代关系” —— 基于上述推测的分析，随推测一并剔除

4.“华谊双功能导水面层、DID立体面层为业界对标” —— 该对标基于三层切割被假定为真实产品线，前提不成立，剔除（如后续供应商证实三层切割存在，可再行对标）
