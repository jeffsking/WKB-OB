## 2. 每批标准作业流程（SOP）

1. 从 `.tools/_compile_plan_data.json` 取本批清单
2. 逐份读 **优先 `RAW_FULL/`，缺失回退 `RAW/`**（两侧路径已 1:1 对齐）
3. **判重**：在 `WIKI/sources/` 中按 `source_path` 查 —— 已存在则**只追加**验证记录并注日期（AGENTS.md §3）
4. 建/更新 **source 页**（必填 9 字段：`type / title / source_type / source_path / date_published / date_processed / credibility / knowledge_update_status / key_claims / pages_linked`）
5. 从 source 页**派生概念页 / 实体页**（**先查再建**，已有只追加）
6. 全页 `[[wikilinks]]` 互链；**禁止无来源参数**，无法溯源标 `[待验证]`
7. 收尾：更新 `index.md` 四区 + `log.md` 追加记录
8. 跑 `.tools/verify_wiki.py`（断链 / front matter / 索引对齐三查）
