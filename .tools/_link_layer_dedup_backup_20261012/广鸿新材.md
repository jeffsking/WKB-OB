# 广鸿新材（Guanghong New Materials）

## 基本盘 Basic Profile

| 项目 | 内容 |
|---|---|
| 主营 | 纺熔复合无纺布（SMS / SMMS / SSMMS / SSS）、水刺无纺布、PET 无纺布（长纤/再生） |
| 产地 / 基地 | 浙江（义乌广鸿无纺布为关联卷材主体，待核） |
| 产能 | 约 6 万吨/年；20 余条产线（纺粘、纺熔、水刺） |
| 成立 / 资质 | 2006 年；国家级高新技术企业 |
| 角色 | 国内 SSMMS 产能领跑者；卫材/医卫两用无纺布候选供方 |

## 合作与供货历史 Cooperation History

- **2026-04（行业报告口径，2026-09-29 记录）**：[[06_SSMMS无纺布技术研究报告.md]] 将其列为国内 SSMMS 产能分布首位；产品覆盖医用非织造布（手术衣/防护服）、卫材非织造布（纸尿裤/卫生巾面层与底层）、水刺（湿巾）与 PET 无纺布（过滤/包装）。

## 价格与商务要点 Commercial Notes

> ⚠️ 以下为市场口径区间，非报价。

- **记录日期 2026-04**：SSMMS（卫材级 15–30 gsm）市场价 12,000–16,000 元/吨，亲水整理 +10–20%；相对 SMS 成本溢价约 1,200 元/吨。SSMMS 产线（3.2 m，8,000 t/y）投资 3,000–5,000 万元。
