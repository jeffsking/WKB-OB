## 0. 本版改了什么

v1.0 把 Phase 2 的三项差异化当成「ND33 成立与否的唯一条件」——**这是错的**。三项差异化是 Phase 2 的**目标**，属于「能覆盖多少」的问题，不是「能不能上」的问题。把它当门槛，等于用后期目标否掉入场资格，识别上会误导。

**v2.0 的正确结构**（v2.1 仅更正年份口径，结构与判定未变）：

| 层级 | 回答什么 | 内容 |
|---|---|---|
| **Gate 0** | Phase 1 能不能满足 | Phase 1 是**入场券**。F-01~F-08 有一项做不到，ND33 方案就不成立 |
| **Gate 1** | 物理上装不装得下、跑不跑得动 | 11 项硬指标，全部服务于验证 Phase 1 |
| **Gate 2** | Phase 2–5 各自能做到什么程度 | 逐期列：需要什么能力 / ND33 能不能做 / 不能做何时能做 / 需要什么信息输入 / 跟进事项 |

**决策逻辑随之更正：**
> **ND33 成立与否，只看 Phase 1 能否满足一件事。**
> Phase 2–5 决定的是：改造分几期、每期投多少、哪些必须放北京——不是能否成立。

## 4. 汇总：ND33 能做 / 不能做 / 何时能做

| Phase | 目标 | ND33 判定 | 实现时点 | 关键条件 | 缺失资源 |
|---|---|---|---|---|---|
| **Phase 1** | 入场券（8 条基本功） | **必须满足** | 改造一期 | F-01 ~ F-08 | — |
| Phase 2-a | add-on 差异化 | **【有条件】** | 一期 | 两套独立 dosing | 空间 |
| Phase 2-b | 密度差异化 | **【有条件】** | 一期或二期 | 分区筛网 + 分区真空 | HCH 方案 + 追加 capex |
| Phase 2-c | 覆盖率差异化 | **【有条件】** | 一期或二期 | 同 2-b | 同上 |
| Phase 3 | PSS 加 fluff | **【不能】预判** | ND33 二期或北京 | fiberizer + 防爆 + 空间 | 空间 / 公辅 / capex 阈值 |
| Phase 4 | REL pattern cut | **【有条件】** | 一期预留、定型后实现 | 切刀位 + 张力控制 | 工艺定型 |
| Phase 5 | fluff + 双面 pattern | **【不能】** | 北京 / 下一代 | 全套 | 独立产线 |

### 4.1 一句话读法

> **ND33 能覆盖 Phase 1 全量 + Phase 2 全量（分期）+ Phase 4 接口；Phase 3 与 Phase 5 大概率要到北京。**
> 所以 ND33 与北京不是二选一的对立，而是**分工**：ND33 做 Phase 1–2 的量产级验证，北京承担 Phase 3–5。
> 真正要决策的是：**这个分工值不值一条 Blizzard 产能线？**

```
        └─ 不能 → 结论 C（北京），结束

Step 1  Gate 1：11 项硬指标有无「否」？
        ├─ 有 → 结论 C，结束
        └─ 无 → 进入 Step 2

Step 2  Gate 2：Phase 2 三项差异化在 ND33 上的实现代价
        ├─ 一期即可（HCH 有成熟分区方案）→ 高质量 A 案
        ├─ 需二期追加 → A 案成立，分两期投资；二期立项前需重评
        └─ 需 HCH 从头开发 → A 案仍成立，但 2-b/2-c 降为「预留接口」

Step 3  产能：停掉的 Blizzard 产量能否承接？
        ├─ 能 → Step 4
        └─ 不能 → 受限改造（保留部分 Blizzard 产能）或否决

Step 4  分工定位：接受「ND33 做 Phase 1–2，北京做 Phase 3–5」吗？
        ├─ 接受 → A 案 + 北京列为中长期项
        └─ 不接受（要求一条线全覆盖）→ C 案（北京）
```

**关键变化**：v1.0 用 Phase 2 当否决条件；v2.0 把 Phase 2 当**投资分期问题**，把「分工定位」当真正要决策的事。
