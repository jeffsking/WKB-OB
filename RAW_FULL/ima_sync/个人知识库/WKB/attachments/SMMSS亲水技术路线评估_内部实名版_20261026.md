## 0. 一页结论

| 项目                             | 结论                                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------- |
| **最可能路线（推断）**                  | ① 在线后整理（辊涂/泡沫/喷涂 + 烘干）概率最高；② 迁移型亲水母粒次之；③ 聚合型长效助剂母粒第三                                              |
| **纯 PP-g-MAH 接枝 PEG/PVA 作主路线** | **不成立**。亲水上限不足（MAH 8 wt% 仅把接触角从 96° 降到 81°），PVA 与 PP 完全不相容，且热稳定性随 PEG 含量升高而下降                     |
| **PP-g-MAH 的真实价值**             | 不是"亲水主力"，而是"**锚**"——2 wt% 量级即可显著提升亲水效果的持久性                                                        |
| **优选组合**                       | 近期「低给液后整理」打底 + 中期「聚合型亲水助剂母粒」做耐久档 + 高端「单面亲水梯度」做差异化                                                 |
| **最大隐藏风险**                     | 亲水化与抗静水压**物理互斥**。同一卷 SMMSS 不可能同时"强亲水"与"≥100 cmH₂O"；若以阻隔产品线宣传亲水，需警惕 SKU 混淆                         |
| **最大工艺约束**                     | 600 m/min × 3.2 m = **1,920 m²/min**。浸轧（pickup 60%）需蒸发约 830 kg/h 水（≈550 kW 烘干功率），高速线**只容得下低给液施加** |

> **口径声明**：路线判定基于设备条件、产品谱与行业通行做法的推断，并辅以公开演示视频的帧级分析（见第 8 节）。视频可证实"润湿行为"（瞬时穿透、重复冲击不衰减），**仍不能区分后整理与母粒**，且耐久性/萃取行为须实物验证。

**三条关键判读：**

1. **"可生产亲水"是产品谱宣称，不是技术等级宣称。** 国内 SMS/SMMS 线把亲水列进产品谱是标准动作，通常对应"能做过"而非"做到了永久亲水"。所谓"强亲水"必须落到指标上才有意义（见第 2 节）。
2. **产能口径自洽**：12 gsm × 3.2 m × 600 m/min = 1.38 t/h，按 8,000 h/y ≈ 11,000 t/y，与 15,000 t/y 的宣称相容。说明 600 m/min 是真实工作线速，不是峰值。
3. **商业动机**：亲水档在市场上是**加价档**。卫材级 15–30 gsm SMMSS 市场价约 12,000–16,000 元/t，**亲水溢价约 +10–20%**，即 +1,200–3,200 元/t（市场区间口径，估算）。这条溢价空间决定了：**成本最低的可量产路线会赢**，而不是性能最好的路线。

**SMMSS 结构对亲水的特殊含义**：5 层 = 3 层纺粘（PP，14–22 µm）+ 2 层熔喷（PP，1–5 µm）。毛细压力 `P = 2γcosθ/r`，M 层纤维直径只有 S 层的 1/5–1/10，**毛细驱动力放大 5–10 倍**——这是"表面看起来特别亲水"的物理放大器，也意味着 **M 层是决定整卷布亲水表现的那一层**。

## 2. 先把"强亲水"变成判据（否则无法评估路线）

### 2.1 三个必须分开的"亲水"

| 概念      | 指标                       | 对 SMMSS 的意义                       |
| ------- | ------------------------ | --------------------------------- |
| **润湿性** | 接触角 θ、铺展时间               | 决定"水滴下去多快消失"——观感来源                |
| **芯吸性** | 液态水爬升高度/速率、WSP 70.3 穿透时间 | 决定液体在 M 层细孔里的传输                   |
| **保水性** | 保水率、回渗（WSP 80.10）        | **对芯包/面层是负指标**：亲水过头 = 液体滞留 = 回渗升高 |

> 关键认知：**"强亲水"≠"好性能"**。整理剂本质是"残液的持有者"，用量越高回渗越高——行业经验显示，降低亲水剂用量往往使回渗**单调下降**，而穿透时间无明显趋势。所以评价路线时必须同时看"多快进去"和"多少回来"。

### 2.2 三步取证法（10 分钟可反推对方用了什么）

| 步骤       | 操作                        | 判读                                     |
| -------- | ------------------------- | -------------------------------------- |
| **① 铺展** | 滴水于两面，分别计时                | <1 s 全铺展 = 强亲水；两面差异 >2 s = 单面处理        |
| **② 萃取** | 40–50 ℃ 温水浸 5 min + 晾干，复测 | 衰减 >50% → **后整理**；基本不变 → **母粒/接枝（本体）** |
| **③ 阻隔** | 测静水压（若手上有方法）              | 仍 >30 cmH₂O 却"强亲水"→ 只能是一面亲水/图案化，不是全幅亲水 |

仪器级确认（送第三方）：**ATR-FTIR** 看 1100 cm⁻¹（C–O–C 聚醚）与 1730 cm⁻¹（C=O 酯/酸）；**XPS** 看表面 O/C 比；**萃取液表面张力**（<40 mN/m 说明有游离表面活性剂）；**TGA** 找 50–60 ℃ PEG 熔融/分解特征。

## 3. 六条路线逐条评估

### R1｜迁移型亲水母粒（内添加，纺前共混）

**原理**：母粒含表面活性剂/亲水助剂，与 PP 共混熔融纺丝。活性基团在纤维成型后**定向迁移**到表面，亲水端朝外形成吸附层。

**工艺实现**：三种形态——① 普通母粒法（母粒 + PP 干混，2–4%）；② 全造粒法（先做成亲水 PP 切片）；③ 纺前注射（计量泵直注主螺杆）。对 SMMSS 而言，**纺粘 3 个 S 梁用普通母粒、熔喷 2 个 M 梁必须用高熔指载体母粒**（熔喷 MFI 800–1,500，载体不匹配会堵模头）。

**亲水效果与持久性**：★★★★（强）。商业标杆为聚合型长效助剂（如 Irgasurf HL 560 类，1.5–3.0% 添加）：初始穿透 **<3 s**、**50 次注水仍保持亲水**、吸水达自重 **8 倍**、兼抗静电、无细胞毒性 [供应商公开产品资料]。迁移型普通母粒耐久性中等，取决于化学体系。

**对结构与力学**：添加 2–3% 时 MD/CD 强力衰减 0–5%，断裂伸长 −5~15%，柔软度反而略升；但**助剂是增塑剂**，热轧粘合窗口会变窄，粘辊/析出风险上升。

**成本与量产**：母粒市场价约 15,000–30,000 元/t，按 2–4% 添加，**增本约 300–900 元/t 布**（量级估算）。优点：**不需要任何后处理设备**，与 600 m/min 完全兼容。

**风险**（这是 R1 最容易被低估的地方）：

- **起效慢**：迁移需要时效，刚下线可能不亲水，需熟化 24–72 h。客户取样即测会误判。
- **可纺性差**：同行公开案例有"用两家母粒厂产品、浪费 5 吨布仍未做出成品"；母粒法成本是后整理的 **2–3 倍**。
- **熔喷梁最脆弱**：超细纤维 + 高比表面积 → 表活富集 → 模头结焦、断丝、布面斑点。
- **多品种不经济**：8–80 gsm 全线共线，换品种就要换料清机。

---

### R2｜聚合型长效亲水助剂母粒（R1 的高配版）

**原理**：不是小分子表面活性剂，而是**聚合型/带锚定段**的亲水添加剂（如聚醚改性聚硅氧烷、聚醚接枝聚烯烃）。疏水锚定段"钉"在 PP 基体里，聚醚段朝外提供亲水——本质是"**把表面活性剂做成不迁移的高分子**"。

**工艺实现**：与 R1 完全同路径（母粒/全造粒），区别在助剂牌号与添加量（1.5–3.0%）。

**亲水效果与持久性**：★★★★★。这是目前唯一有"50 次注水"公开背书的路线。

**对结构与力学**：同 R1，略优（高分子量、低析出）。

**成本与量产**：**最贵**。助剂约 80–160 元/kg（未询价，量级估算），1.5–3% → **增本 1,200–4,500 元/t 布**，正好对应市场 +10–20% 的亲水溢价。国内产业化应用"尚未见报道"（公开文献口径）[《中国聚合物添加剂应用技术新热点》]，说明**牌号集中在少数外资供应商**，供应风险高于成本风险。

**风险**：单一来源依赖；换牌号 = 换化学体系，需重新做全套验证；对熔喷梁的加工窗口更敏感。

---

### R3｜PP-g-MAH 接枝 PEG / PVA（本体化学改性）

**原理**：PP 熔融接枝马来酸酐得 PP-g-MAH（MAH 环与 PP 主链化学键合），再用 MAH 与 **HO-PEG 酯化**（或与聚醚胺酰胺化）接出聚醚侧链，得到 PP-g-PEG 两亲共聚物；共混后亲水链段向表面富集。

**这一条必须拆开看，因为"PP-g-MAH"和"PP-g-PEG"是两件事：**

| 子方案                 | 实测/文献上限                                                                            | 判读                       |
| ------------------- | ---------------------------------------------------------------------------------- | ------------------------ |
| **PP-g-MAH 单体**     | 8 wt% PP-g-MAH/PP 共混膜，水接触角 **96°→81.3°**（接枝率 2.4%）；另一路线接枝率 4.56–5.25% 时 96°→74–78° | **只能做到"不那么疏水"，达不到"强亲水"** |
| **PP-g-MAH + PEG**  | 4 wt% PEG200/PP → **64.8°**（钢基材）；换 PTFE 基材 → 77.7°                                 | 加工界面影响巨大；仍 >60°          |
| **PP-g-PEG（接枝共聚物）** | 接枝率随 PP 与 PEG 分子量升高而**下降**；PEG 含量/分子量越高，**热稳定性越差**                                 | 想靠提高 PEG 含量冲亲水，会撞上热稳定墙   |
| **PVA 变体**          | PVA 与 PP **完全不相容**，共混呈**海岛分布**，需 60–95 ℃ 热水浴**溶出**才形成亲水孔道                          | 引入"溶出"工序，600 m/min 在线不可行 |

来源：[湖北工业大学硕士论文《混凝土用聚丙烯纤维料亲水改性研究》]（PP-g-MAH/PEG 接触角数据）、[CN106317334B]（接枝率与接触角）、[J. Appl. Polym. Sci. PP-g-PEG 合成与表征]（接枝率与热稳定性反向关系）、[CN101487150A]（PVA/PEG 与 PP 海岛结构）。

**工艺实现**：两步法——① 反应挤出制备 PP-g-MAH；② 酯化接枝（180–200 ℃ + 催化剂 + 真空脱副产物）。**纺丝现场做不了，只能买预制接枝料或母粒**。

**亲水效果与持久性**：★★（强度）／★★★★★（持久）。持久性确实是最好的——亲水基团是化学键合的，洗不掉。但**强度天花板明显**：公开数据里没有一条把 PP-g-MAH 体系做到 θ<30°。

**对结构与力学**：PEG 侧链**破坏 PP 结晶完善度**（阻碍 β 晶），拉伸 −5~15%；热稳定性下降 → 230–260 ℃ 纺粘温度下**烟雾、模头结焦、黄变**风险高。这恰恰是纺熔工艺最忌讳的。

**成本与量产**：PP-g-MAH 20,000–35,000 元/t；PP-g-PEG 属定制接枝物，估计 50,000–120,000 元/t 且小批量定制（**均为量级估算，需询价**）。按 3–10% 添加，增本 1,500–12,000 元/t，**性价比最差**。

**结论**：

- **作主亲水相 → 不成立**。亲水强度不够，工艺风险高，成本失控。
- **作"锚定助剂"→ 成立且有效**。文献明确：在聚醚改性聚硅氧烷/PP 体系中加入 **2 wt% PP-g-MAH 可显著提高改性效果的持久性**。这才是它的正确位置。
- **PVA 路线 → 只能以"纤维/涂层"形态存在，不能作为 SMMSS 的熔融亲水相。** PVA 纤维只能进入梳理/热风（ATB）路线，属纤维级方案，与纺熔不兼容。

### R4｜在线后整理（辊涂 / 喷涂 / 泡沫 + 烘干）

**原理**：纤维成型后，把亲水整理剂（非离子/阴-阳离子复配表面活性剂）以水溶液形式施加到布面，烘干成膜。亲油端吸附纤维、亲水端朝外。

**工艺实现**（600 m/min 是硬约束，必须算账）：

| 施加方式           | 带液率 pickup | 需蒸发水量（12 gsm @600 m/min） | 烘干功率估算        | 适配性            |
| -------------- | ---------- | ------------------------ | ------------- | -------------- |
| 浸轧（dip-nip）    | 50–80%     | 690–1,100 kg/h           | 450–720 kW    | ❌ 高速线基本不可行     |
| 喷涂（spray）      | 20–30%     | 280–410 kg/h             | 180–270 kW    | △ 需多喷头 + 均匀性控制 |
| 辊涂（kiss-roll）  | 10–20%     | 140–280 kg/h             | 90–180 kW     | ✅ 主流           |
| **泡沫整理（foam）** | **5–15%**  | **70–210 kg/h**          | **45–140 kW** | ✅✅ 最优，且穿透性好    |

> 计算假设：产量 = 12 gsm × 3.2 m × 600 m/min = 1.38 t/h；蒸发 1 kg 水约 0.65 kWh（含升温+汽化）。实际烘箱效率按 60–70% 折算后功率更高。

**这条账说明一件事**：600 m/min 的线，**只有低给液施加方式才不需要为烘干付巨额代价**。这也解释了为什么高速 SMMS 线的亲水装置几乎都是辊涂或泡沫，而不是浸轧。

**亲水效果与持久性**：★★★★★（强度）／★★（持久）。SS 纺粘无纺布实测：亲水整理后穿透时间从 4 s 降到 **0.3 s**，而**强力基本不变**（MD 25.6–93.3 N → 24.6–99.2 N；CD 11.6–58.7 N → 22.5–94.6 N）[中国纺织报《以瞬时概念评判亲水性 SS 非织造布》]。但耐久性是硬伤：**洗涤 3 次水渗透时间增加约 15 倍**；行业经验是常规整理**常在 1–2 次冲击后即被洗脱**。

**对结构与力学**：力学几乎无损（唯一一条有实测背书的路线）；手感略变；**烘干温度有最优窗口**——90 ℃ 最佳，120 ℃ 时表面活性剂分解，布面**发脆发硬** [中国纺织报]。这个细节很重要：很多厂"亲水做不好"不是配方问题，是烘箱温度超了。

**成本与量产**：最便宜。助剂 15–35 元/kg × 0.3–0.8% 给液 → 助剂成本 45–280 元/t，加能耗/折旧约 150–350 元/t，**合计 200–600 元/t**（量级估算），是母粒法的 **1/2–1/3**。设备投资：若产线已配在线亲水装置则边际成本极低；若无，3.2 m × 600 m/min 的施加+烘干单元估计 **800–2,000 万元**。

**风险**：

- **耐久性差**是本质缺陷，不适合"多次排尿/长时穿戴"的高端场景；
- **整理过量 → 面层滞留液 → 回渗升高**（行业已有多起反面案例）；
- 表面活性剂**迁移到热熔胶/膜层**，可能降低剥离力、影响印刷与复合；
- 皮肤刺激/可萃取物需评估（医疗级还要 ISO 10993）；
- **单面/双面控制**：喷涂易两面污染，辊涂可做单面。

### R5｜表面活化接枝（电晕 / 等离子 / UV / 电子束 + 亲水单体）

**原理**：高能手段在 PP 表面生成自由基，引发丙烯酸、AMPS、PEGMA 等亲水单体接枝聚合，形成共价键合的亲水层（10–100 nm）。

**工艺实现**：常压等离子或电晕在线可做（3.2 m 幅宽需多电极阵列）；UV/电子束接枝多为离线，且 EB 设备投资 2,000 万元级。

**亲水效果与持久性**：★★★／★★。初始接触角可降到 20–30°，但**疏水回复（hydrophobic recovery）**&#x662F;固有问题——低分子量碎片向表面翻转，数天到数周衰减；纯等离子活化（不加单体）尤其快。

**对结构与力学**：本体力学**无损**（只改表面 10–100 nm），这是最大优点。

**成本与量产**：设备 100–500 万元（等离子/电晕），运行成本低；EB/UV 路线成本不可接受。

**风险**：3.2 m × 600 m/min 的**均匀性**是最大工程难点；老化衰减不可控；对 M 层（深藏在层间）几乎无效——**表面处理改不到内部**，而 SMMSS 的亲水恰恰需要穿透 5 层。→ **在 SMMSS 上属于"用错工具"**。

---

### R6｜结构 / 复合路线（绕开"全幅均匀亲水"的思路）

| 子路线                | 做法                | 价值                | 限制                  |
| ------------------ | ----------------- | ----------------- | ------------------- |
| **单面亲水梯度**         | 贴肤面亲水、外面拒水（或反之）   | 兼顾导流与阻隔，做**单向导流** | 需精确单面施加；两层界面易串液     |
| **图案化局部亲水**        | 亲水印花条纹/网点，其余拒水    | 降低残液、提升干爽感        | 需印花单元；图案对贴合精度敏感     |
| **PVA 水溶纤维复合**     | 混入 PVA 纤维，遇水溶出成孔道 | 超亲水 + 多孔          | **纺熔线做不了**，属梳理/热风路线 |
| **CNF / 纳米纤维素涂层**  | 表面涂纳米纤维素          | 超亲水（θ≈20°）、毛细强    | 耐水性差、成本高、堵孔风险       |
| **换材料（PET 纺粘/水刺）** | 用极性聚合物或天然亲水纤维     | 天然亲水，无需整理         | 需新产线，成本结构完全不同       |

**评价**：R6 不是"另一种亲水剂"，而是**另一种产品定义**。它的价值不在"更亲水"，而在"**亲水 + 阻隔/干爽可以同时要**"——这正是 SMMSS 相对 ATB（热风）的唯一结构性优势所在。

## 4. 横向对比矩阵

**权重**：亲水强度 25%｜持久性 20%｜600 m/min 工艺兼容 20%｜结构/力学影响 10%｜成本 15%｜量产成熟度 10%（1–5 分，5 最优）

| 路线                    |  亲水强度 |  持久性  |  工艺兼容 | 力学/结构 |   成本  |  成熟度  |  **加权分** |
| --------------------- | :---: | :---: | :---: | :---: | :---: | :---: | :------: |
| R1 迁移型亲水母粒            |   4   |   3   |   3   |   4   |   4   |   4   | **3.60** |
| R2 聚合型长效母粒            |   4   | **5** |   3   |   4   |   2   |   4   | **3.70** |

## 5. 优选建议

### 5.1 按应用场景选路线

| 目标产品              | 克重        | 首选路线             | 理由                                                                        |
| ----------------- | --------- | ---------------- | ------------------------------------------------------------------------- |
| **SAP 载体 / 芯体包裹** | 10–12 gsm | **R4 后整理（低给液）**  | 只需"快穿透"，一次性使用，耐久性不敏感；业界已有用亲水化 SMS 10–12 gsm 作 SAP 载体的公开专利方案 [EP2529717A1] |
| **医护垫 / 成人尿裤面层**  | 13–18 gsm | R4 打底 + R1/R2 提档 | 需多次排尿，耐久性要求上升                                                             |
| **高端耐久档（溢价产品）**   | 13–20 gsm | **R2 聚合型母粒**     | 50 次注水背书，支撑 +10–20% 溢价                                                    |
| **单向导流 / 干爽差异化**  | 15–25 gsm | **R6 单面梯度**      | 亲水 + 阻隔同时要，SMMSS 的结构优势                                                    |
| **医疗阻隔（手术衣/防护）**  | 35–60 gsm | **不做亲水**         | 亲水化与 ≥50 cmH₂O 静水压物理互斥                                                    |

### 5.2 三阶段落地路线

**Phase 1（0–3 月）｜先证明"是哪条"，再谈优化**

1. 用第 2 节三步取证法拆解对手样品（萃取前后 + 双面 + ATR-FTIR）；
2. 同线做 R4 的 **DOE**（见 5.3），锁定给液量与烘干窗口；
3. 建立"亲水"的内控指标卡（见 5.4），停止用"手感/观感"验收。

**Phase 2（3–9 月）｜耐久档立项**

- R2 助剂送样 + 熔喷梁可纺性专项（模头结焦、断丝率、连续开车时长）；
- 同步验证 R1 母粒在 3 个 S 梁 + 2 个 M 梁的差异化配方；
- 判据：5 次穿透 ≤3 s、回渗 ≤0.13 g、加速老化后第 3 次穿透 Δ≤10%。

**Phase 3（9–18 月）｜差异化**

- R6 单面梯度：一面亲水一面拒水，做"吸收 + 阻隔"一体化 SKU；
- 若 R2 成本压不下来，转"R4 耐久整理剂 + 2% PP-g-MAH 锚定"的降本替代（R3 的正确用法）。

### 5.3 DOE 设计（R4 为主）

| 因子           | 水平                         |
| ------------ | -------------------------- |
| 助剂体系         | A（非离子）/ B（阴-阳复配）/ C（聚醚硅氧烷） |
| 给液量          | 0.2 / 0.4 / 0.6 % owf      |
| 施加方式         | 辊涂 / 喷涂 / 泡沫               |
| 烘干温度         | 90 / 110 / 130 ℃           |
| **线速**（噪声因子） | 300 / 450 / 600 m/min      |

**响应**：初始穿透、5 次穿透、回渗、保水率、静水压、MD/CD 强力、手感、萃取液表面张力。

> 必做：**线速作为因子而非固定值**。600 m/min 下的烘干停留时间比 300 m/min 少一半，温度窗口会整体右移，实验室数据直接外推到量产是常见翻车点。

### 5.4 技术协议必须写死的 8 条（不要只写"亲水"两个字）

1. **初始穿透**：WSP 70.3，≤1.5 s（高端 ≤1.0 s）
2. **第 5 次穿透**：≤3 s（对标 ES 无纺布高端门槛，公开实测可达 <3 s、回渗 <0.11 g [ES 无纺布亲水整理硕士论文]）
3. **回渗**：WSP 80.10，≤0.13 g
4. **老化**：40 ℃/75%RH × 2–4 周（行业通用加速老化条件），第 3 次穿透变化 Δ≤10%，回渗不增
5. **可萃取物 / 表面张力**：萃取液表面张力、extractables 含量、气味/VOC 声明
6. **双面差**：面/底接触角差（用于锁定单面或双面工艺）
7. **相容性**：与热熔胶剥离力、与 SAP 粉尘、与乳液(lotion)、与储存老化
8. **变更控制**：整理剂/母粒**牌号变更视同材料变更**，须重新验证


## 7. 一句话回答"他们大概怎么做的"

> 若样品**萃取后失效** → 大概率是**在线后整理**（辊涂/泡沫 + 90–110 ℃ 烘干），成本 200–600 元/t，是最符合"600 m/min + 8–80 gsm 多品种"经济性的解。  
> 若样品**萃取后仍强亲水** → 才轮到**亲水母粒**（迁移型或聚合型），且更可能是 3 个 S 梁 + 2 个 M 梁的差异化配方。  
> **PP-g-MAH 接枝 PEG/PVA 既解释不了"强亲水"，也过不了 600 m/min 的可纺性关**——它在这套体系里的位置是"锚"，不是"主力"。

## 8. 视频证据分析（公开演示视频帧级判读，2026-10-26）

**证据**：**联成官方抖音号**发布的实测视频，15.6 s，竖屏 640×1424，文案「联成无纺布有限 SMMSS 的 **10 gsm 亲水** 亲水效果测试，无剪辑，无美颜」，标签 #亲水 #10g #smmss #测试。用橡胶洗耳球向布面滴加**深色染色水**，累计 15+ 滴。

### 8.1 帧级观察（24.3 fps，逐帧 83 ms 步进）

| 观察项      | 结果                                   | 判读                                      |
| -------- | ------------------------------------ | --------------------------------------- |
| 水滴接触布面形态 | **无任何球珠停留帧**——接触后 1 帧内（≤83 ms）即成平坦湿斑 | 穿透/润湿为毫秒级，远快于 WSP 70.3 的 1 s 量级口径       |
| 湿斑形态     | **树枝状/分形边缘**，非圆形透镜                   | 液体沿纤维网络**毛细芯吸横向扩散**，是真实 wicking 而非仅表面润湿 |
| 表面光泽     | 全部湿斑**哑光，无高光**                       | 无自由水残留表面，完全渗入                           |
| 重复性      | 15+ 滴、跨 15 s，行为完全一致                  | **多次冲击无衰减**的粗信号（同场次内）                   |
| 保水性      | 湿斑全程保持深色不消退、不缩小                      | **保水率高**——液体滞留在布内                       |
| 处理均匀性    | 全幅面积行为一致                             | 全幅处理，非图案化/单面                            |
| 渗漏       | 深色台面上未见明显渗液                          | 液体被 10 gsm 布层持留                         |
| 规格       | 文案明示 **10 gsm**                      | 与本报告第 5.1 节「SAP 载体/芯体包裹」档位完全吻合          |

### 8.2 视频改变了什么

1. **SKU 确认**：10 gsm 亲水 SMMSS——正是第 5.1 节预判的**首选应用场景（SAP 载体/芯包）**，该档位对耐久性不敏感、对瞬时穿透敏感，与演示行为自洽。
2. **润湿性为真**：即使测试液是染色水（墨水含表活、表面张力低于纯水 72 mN/m），疏水 PP 布（θ≥90°）无外压不会渗透——视频能瞬间穿透，**证明布面确实亲水**，不是液体表演出来的。
3. **「无剪辑」= 真实性营销，不等于标准化测试**：洗耳球滴液体积不标准、无计时基准、无次数定义、无洗涤/老化数据——这是销售演示，不是验收测试。
4. **保水率偏高的信号**：湿斑持久不消 → 若此布用于**面层**，回渗风险高；用于 SAP 载体则无害甚至有益（持液防侧流）。
5. **路线判定推进有限**：瞬时穿透 + 高保水 + 全幅均匀，与「表面活性剂类处理（后整理或迁移型母粒）」一致；聚合接枝型表面更倾向"导走液体"而非"持住液体"——弱信号略偏向**后整理/迁移型**，但不能定论。

### 8.3 由此产生的取证动作（比原三步法更具体）

1. **要实物样**：10 gsm 与 15–20 gsm 各一块，按 5.4 节 8 条测；
2. **纯水 vs 合成尿复测穿透**：剥离染色水的表活加成，看真实润湿等级；
3. **萃取试验**（温水 5 min）判整理 vs 母粒；
4. **双面接触角差**判单/双面；
5. **问对方三个问题**：① 是否耐受多次洗涤（几次后穿透多少）；② 整理剂/母粒牌号与化学体系类别；③ 同一卷布能否同时提供拒水版（判断其亲水/拒水切换是配方级还是设备级）。

### 8.4 竞争情报读法

- 用抖音发「无剪辑无美颜」测试，说明**亲水 SMMSS 已是联成的主打卖点 SKU**（销售端在推），产线已批量稳定生产，不是研发阶段样品；
- 10 gsm 档位直指 SAP 载体/芯包/医护垫市场，与芯体包裹材料的供应池存在直接替代关系；
- 强调"无剪辑"暗示同业演示视频普遍掺假——侧面反映当地（孝感卫品产业集群）亲水无纺布价格战激烈，**技术差异化已下探到营销层**。
