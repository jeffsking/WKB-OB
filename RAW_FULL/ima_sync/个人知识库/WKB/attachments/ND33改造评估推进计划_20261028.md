### 3.1 Gate 1 六个数（实测，不许估）

可用空间净尺寸（含维护通道）｜层高净空｜地坪承重｜真空余量（风量 + 静压）｜电容量余量｜除尘风量余量

### 3.2 Gate 1 两个快检

主机机械最高速（须 ≥ 1000 PPM × 1.2）｜约 150 RPM 下振动与 runout

### 3.3 门槛怎么定（不给现成数字）

> **门槛 = 双鼓布置净需求 + 20% 维护通道余量；速度门槛 = 目标速度 × 1.2。**
> 由 Rocky 与 Schaefers 在 11/2 数据会上当场写入确认书，**不得由单方设定**。
> （本计划刻意不给数值门槛——手上没有 ND33 实测数据，编一个门槛是这行最危险的事。）

**任一不过 → ND33 方案直接否，转北京，不再讨论。** 13 天没有「再研究一下」的预算。

## 6. 三案对比 6 维度（不只比 capex）

> 「与 HCH 的解耦度」经确认为无评估意义，已从对比维度中删除。

| 维度 | 为什么重要 |
|---|---|
| **产能损失（首要维度）** | **ND33 仍承担实际 Blizzard 产量**——停产即真实商业损失，量级须先算清，其余维度都在此之下 |
| 单轮试验周期（天） | 决定工艺迭代速度，比 capex 更影响 2029 基线 |
| 单轮试验成本 | pilot 的核心 KPI 是「试一次多贵」 |
| 可试验配置数（鼓规格数量） | 11 个尺寸能不能覆盖 |
| 与量产机相关性 | ND33 是量产机，相关性高；北京是专用 pilot，可控性高 |
| 不可逆性 | 拆了 Blizzard 回不去，这是风险不是成本 |

## 7. 决策规则（会前认可，评审只填数）

| 情形 | 结论 |
|---|---|
| Gate 1 不过 | **选北京**，ND33 退出，不再研究 |
| Gate 1 过 + Gate 2 过 + capex ≤ 北京 60% + 交期早 ≥ 6 个月 | **选 ND33**，但必须做可逆化改造 |
| Gate 1 过 + Gate 2 不过 | **优先北京**（可按最终工艺定制，不必迁就 ND33 约束） |
| Blizzard 产能无替代方案（**已确认 ND33 承担实际产量，故此项为必答，不可跳过**） | **ND33 降为受限改造**，或直接否决 |

## 8. 可逆化改造五条（评估基线 → 实施方案的桥）

1. **Blizzard 设备不处置**：封存 + 标识 + 记录，评估「恢复到可用」的工时与备件
2. **保留原机接口**：安装基座、真空与管路接口、电气柜预留位不动
3. **设可断开点**：机械 / 真空 / 控制三路均可快速断开
4. **恢复路径入图**：恢复工时、外委项、验证项写进方案正文，而非附录
5. **可逆化成本单列**，不摊进总价（摊进去，决策层就看不到「拆掉」的代价）

---

## 9. 完整 capex 口径（9 项，缺一项就是低估）

装备本体｜拆旧（Blizzard 拆除与处置）｜场地与结构（地坪 / 层高 / 钢结构）｜公用工程增量（真空泵 / 除尘 / 冷却 / 电气容量）｜控制与信息系统｜安装调试与试产废料｜停产损失与产能替代｜备件与培训｜可逆化预留

> 经验上设备本体只占总装机成本约一半，其余四散在拆改、公辅、安装与停产损失。
> 只报设备价，决策层看到的数是偏低的。

## 13. 风险与「现在明确不做」

### 13.1 最可能出问题的四点

1. **产能缺口无承接** → ND33 承担实际 Blizzard 产量，一旦停产改造，缺口是真实商业损失；这一项不给答案，方案本身不成立（对策：11/5 前锁定承接机台与量）
2. **RFQ 按不可逆口径发出** → 报价与工期全部返工（对策：双栏报价）
3. **Gate 1 与 Gate 2 混淆** → 把「供应商说能做到」当成「本厂装得下」，两个风险叠成一个决策，错因无法归因
4. **输入不到位仍硬凑结论** → 决策层依据推断拍板，后面全部重做

### 13.2 现在明确不做

- ✕ 不下设备订单、不签 HCH 合同（Gate 2 未过）
- ✕ 不真拆 Blizzard（评估用纸面 + 临时移机）
- ✕ 不按「全部拆除」发 RFQ（最容易漏的一条）
- ✕ 不在 ND33 上做实物打样（鼓规格没收敛，打出来没有代表性）
