# CoPET/PET 与 PE/PET 成本结构深度拆解报告

上游原材料 × 加工工艺 双维度成本建模

数据基准：2026年7月  |  口径：元/吨成品纤维，皮芯比40/60，纯制造成本（不含利润/市场波动）

# 一、执行摘要

本报告抛开市场供需波动，从上游原材料与加工工艺两个维度，对卫材热风无纺布用两类皮芯双组分纤维（CoPET/PET 的 TT 型、PE/PET 的 ET 型）做成本结构拆解。核心发现：

# ① 两者总制造成本高度接近——CoPET/PET ≈ 9,528 元/吨，PE/PET ≈ 9,772 元/吨，CoPET/PET 仅低约 2.5%；

② 在商品中间体（切片/树脂）层，CoPET/PET 皮层比 PE/PET 皮层便宜约 22%，成品原料成本低约 10.7%；但在单体原料层（PTA+IPA+MEG vs 乙烯）两者几乎打平（差 0.4%）。

③ 真实差异在加工段：CoPET/PET 因皮芯同材质（PET 基）界面相容性优、复合纺丝良率高，加工转化成本低约 7.2%；PE/PET 因 PE/PET 异质界面需处理，纺丝加工费高约 200 元/吨。

# ④ CoPET/PET 独有 IPA 成本项（约 8% 纤维总成本），PE/PET 独有乙烯成本项（约 30%）。两者成本优势各在不同环节，并非单向谁更便宜。

# 二、上游原材料成本拆解

# 2.1 CoPET 核心原料（皮层，占成品 40%）

CoPET 为低熔点共聚 PET，由 PTA、IPA（间苯二甲酸）、MEG 三元共聚，投料比 0.66 / 0.20 / 0.34（t/t 切片）。切片原料成本 7,230.5 元/吨，内部构成：

|核心原料|单价(元/t)|单耗(t)|金额(元)|在CoPET切片内占比|
|---|---|---|---|---|
|PTA|5,775|0.66|3,811.5|52.7%|
|IPA（间苯二甲酸）|9,700|0.20|1,940.0|26.8%|
|MEG|4,350|0.34|1,479.0|20.5%|
|合计|—|1.20|7,230.5|100%|

→ 在成品 CoPET/PET 纤维总成本中：PTA 占 47.3%、IPA 占 8.1%、MEG 占 15.5%。IPA 是 CoPET 独有且昂贵的改性单体。

# 2.2 PE 核心原料（皮层，占成品 40%）

PE（取 LDPE）由乙烯聚合而成，核心上游原料为乙烯（石油/乙烷裂解）。LDPE 树脂价 9,250 元/吨（含聚合），内部构成（一体化估算）：

|核心原料|单价(元/t)|金额(元)|在PE树脂内占比|
|---|---|---|---|
|乙烯|≈7,300|7,300|78.9%|
|聚合及能耗等其他|—|1,950|21.1%|
|合计|—|9,250|100%|

→ 在成品 PE/PET 纤维总成本中：乙烯独占约 29.9%，是 PE/PET 最大的单一成本项。

# 2.3 PET 核心原料（芯层，两者共用，占成品 60%）

PET 由 PTA、MEG 缩聚，投料比 0.86 / 0.34（t/t 切片）。切片原料成本 6,445.5 元/吨，内部构成：

|核心原料|单价(元/t)|单耗(t)|金额(元)|在PET切片内占比|
|---|---|---|---|---|
|PTA|5,775|0.86|4,966.5|77.0%|
|MEG|4,350|0.34|1,479.0|23.0%|
|合计|—|1.20|6,445.5|100%|

# 2.4 成品纤维原料占比对比

以皮芯比 40/60 组合后，两材料在原料层面的对比呈现“中间体层差异大、单体层接近”的特征：

|对比层|CoPET/PET|PE/PET|差异|
|---|---|---|---|
|商品中间体（切片/树脂）原料|6,759.5 元/t|7,567.3 元/t|CoPET/PET 低 10.7%|
|单体原料（PTA/IPA/MEG vs 乙烯）|6,759.5 元/t|6,787.9 元/t|几乎打平（-0.4%）|
|皮层材料单价|CoPET 7,230.5|LDPE 9,250|CoPET 便宜 22%|

# 三、加工工艺成本拆解

# 3.1 制备流程对比

两者流程同构：聚合/共聚制切片 → 皮芯复合纺丝制纤维，差异在皮层聚合化学与皮芯界面性质：

CoPET/PET：CoPET/PET：PTA+IPA+MEG 共聚（IPA 降熔点）→ CoPET 切片；与 PET 切片分别挤出，皮芯复合纺丝。皮芯同属 PET 体系。

# PE/PET：PE/PET：乙烯聚合制 LDPE（多外购树脂）；PET 切片独立制备；两者皮芯异质（聚烯烃/聚酯），复合纺丝需界面处理。

# 3.2 聚合 / 共聚段（工程估算，元/t 切片）

|环节|加工费|能耗|设备折旧|人工|折合纤维(×占比)|
|---|---|---|---|---|---|
|CoPET 共聚（皮层）|600|300|150|60|444（×40%）|
|PET 聚合（芯层，共用）|400|250|100|40|474（×60%）|
|PE 聚合（皮层）|400|500|200|50|460（×40%）|

聚合段合计：CoPET/PET ≈ 918 元/t 纤维，PE/PET ≈ 934 元/t 纤维。CoPET 共聚窗口窄、控制难；PE 聚合成熟但 LDPE 高压法能耗高。

# 3.3 挤出复合（皮芯复合纺丝，元/t 纤维）

|材料|纺丝加工费|能耗|设备折旧|人工|品质损失|小计|
|---|---|---|---|---|---|---|
|CoPET/PET（TT型）|800|400|300|150|200|1,850|
|PE/PET（ET型）|950|450|300|150|200|2,050|

CoPET/PET 皮芯同材质（PET 基）界面相容性优、合格率 85~92% 且纺丝温度可调控（CoPET 熔点 110~180℃），加工费低 150 元、能耗低 50 元；PE/PET 异质界面相容差、需特殊处理，纺丝加工费高约 200 元/t。

# 五、主要差异点

# ① 皮层聚合物体系：CoPET/PET 为改性 PET（PTA+IPA+MEG 共聚），PE/PET 为聚烯烃（乙烯→PE），两者上游路线完全不同。

# ② 独有成本项：CoPET/PET 含 IPA 共聚（约 8% 纤维总成本），PE/PET 含乙烯（约 30% 纤维总成本）——这是两者成本结构最显着的断层。

# ③ 聚合工艺：CoPET 需 IPA 共聚，工艺窗口窄、粘度/升华控制难、合格率略低；PE 聚合成熟但 LDPE 高压法能耗高。

# ④ 复合纺丝界面：CoPET/PET 皮芯同材质，相容性优、良率高；PE/PET 异质界面相容差，需相容剂/界面处理，加工费高约 200 元/t。

# ⑤ 能耗：CoPET/PET 皮层熔点可定制且与芯层同体系，纺丝可低温节能；PE/PET 因 PE/PET 异质、温度梯度大，纺丝能耗略高。

# 六、各自成本优势

# CoPET/PET 的成本优势

# 制造成本略低（约 -2.5%），主要来自加工段（皮芯相容、良率高、纺丝加工费低）。

# 皮芯同材质（PET 基），界面相容性优、复合纺丝良率高，品质损失小。

# 皮层熔点可定制（110~180℃），工艺柔性好，可针对热风布优化节能。

# 在商品切片层，CoPET 皮层比 LDPE 便宜约 22%，采购弹性与降本空间更大。

# PE/PET 的成本优势

# 聚合段无需共聚改性，工艺相对简单（PE 直接采用聚合树脂，省去 IPA 共聚工序）。

# 皮层 PE 熔点低（~130℃）、手感更柔软，卫材热风布性能优，终端溢价可覆盖成本差。

# 产业成熟、卫材级供应稳定（江南高纤等大规模稳定供货），认证体系完善。

# 虽制造成本略高，但下游卫材认可度高，单位性能/溢价比具备竞争力。

# 七、结论

# 1. 两者总制造成本高度接近（CoPET/PET 9,528 vs PE/PET 9,771 元/吨，差约 2.5%），不存在“谁绝对更便宜”的单向结论。

2. 原料层“中间体差异大、单体接近”：CoPET/PET 皮层切片比 PE/PET 便宜 22%，但单体层（PTA+IPA+MEG vs 乙烯）几乎打平——乙烯路线并不比聚酯路线便宜。

3. 成本差异主要在加工段：CoPET/PET 赢在皮芯同材质带来的高良率/低加工费；PE/PET 赢在聚合简单与终端卫材性能溢价。

4. 选型建议：追求制造成本与工艺柔性选 CoPET/PET；追求超柔手感与成熟卫材认证选 PE/PET。二者均为合理卫材热风布方案，应按终端性能与认证要求决策，而非单纯比吨成本。
