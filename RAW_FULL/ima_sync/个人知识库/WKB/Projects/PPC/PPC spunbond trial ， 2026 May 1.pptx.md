## Lesson learnt

PPC/PBAT resin has good spinnability .

Ideal process temperature window set up: 180 to 185C

Strength of yarn need to be improved.

Die tip hole diameter need to double check to best fit for T55P25T20 resin

Testing spunbond line parameter

Die tip width: 1365mm (600 x 216)

600 holes per 216mm / module

Set up based on PP resin: 0.155g/ min, actual PPC add on will be more due to density difference.
