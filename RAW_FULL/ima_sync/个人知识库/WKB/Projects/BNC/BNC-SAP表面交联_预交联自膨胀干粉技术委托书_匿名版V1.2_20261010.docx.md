## 一、项目背景与委托目的

甲方拟启动"细菌纳米纤维素（BNC）增强 SAP 表面交联"试验项目（路线 B，目标提升 AUL、凝胶强度与加压吸收性能）。经内部技术评估，确定采用预交联自膨胀 BNC 干粉作为 BNC 干态运输与复水中间体：干粉在复水罐内 30 s 内快速复水为 BNC 分散液（固含 2%），与表面交联剂液混合后进入丙方后处理线喷雾涂覆，在约 130℃ 浆液干燥机二次干燥过程中完成壳层固化。干粉本身不直接进入后处理线，避免遇水膨胀成团风险。

该形态的技术依据为公开专利所述"化学交联+干燥收缩→遇水快速自膨胀"路线：纳米纤维素与交联剂共混后，经化学交联与干燥（顺序可互换），得到遇水 2–30 s 膨胀、质量倍率 3000–90000% 的干态材料，可粉碎为粉末形态。该路线可解决 BNC 干粉角质化（复水差、吸水能力大幅衰减）的产业化障碍。

V1.1 新增委托目的：基于同一尾水制 BNC 原料，同步制备氨基化 BNC（γ-氨丙基三乙氧基硅烷改性）作为功能负载锚定载体，支撑甲方"增强+抗菌除臭一体化"延伸方案（阶段 B 功能负载：抗菌剂/除臭剂经氢键+静电吸附锚定于氨基化 BNC，不溶出）。氨基化 BNC 同时参与阶段 A 交联壳共反应（氨基+羟基与交联剂共反应），一载体两用途。

V1.2 形态决策：功能验证阶段（材料级+芯体级）主样 D 以 2% 固含分散液为第一交付形态——公开专利原生工艺即以氨基化纳米纤维素水溶液/悬浮液形态进线；乙方产线支持分散液直接出货；丙方后处理线交联剂本身为液体注入通道（计量绞龙注表面交联剂→高速混合机）。液态形态跳过复水环节、批次一致性好，功能验证阶段量小（kg 级），湿态运输劣势可忽略。干粉形态保留为量产切换的后备方案（干态运输经济性）。

委托目的：由乙方基于其尾水制 BNC 原料与工艺能力，制备符合甲方规格要求的预交联自膨胀 BNC 干粉样品与氨基化 BNC 样品（湿态优先），并交付制备工艺参数包，支撑甲方在丙方产线上的工程验证。

## 二、委托范围（任务内容）

1. BNC 原料准备：采用乙方尾水制细菌纳米纤维素（纤维直径 40–60 nm、纯度>99%）。
2. 预交联自膨胀干粉制备（主样 A）：羧甲基化改性→柠檬酸交联→干燥过程中交联→粉碎成粉。
3. 对照样品制备（对照 B）：冷冻干燥保孔路线（-80℃ 冷冻→冻干→85℃ 热交联）。
4. 对照样品制备（对照 C）：未交联羧甲基化 BNC 干粉（角质化基线对照）。
5. 氨基化 BNC 制备（主样 D）：γ-氨丙基三乙氧基硅烷（γ-APTES）改性，四档接枝密度标定；交付形态：2% 固含分散液（功能验证第一优先）+干粉（量产后备），双形态并行交付。
6. 检测报告交付：粒径分布、含水率、复水时间、复水后分散液固含与稳定性、取代度、130℃ 热稳定性、残留物检测；氨基化 BNC 另附氨基接枝密度与残余硅烷检测；分散液另附静置沉降、Zeta 电位、pH、微生物检测（V1.2 新增）。
7. 制备工艺参数包：共混、干燥、交联、粉碎各工序小试级参数与批次记录；氨基化 BNC 另附硅烷化工艺参数（偶联剂用量、反应时间/温度、洗涤与干燥条件）及分散液储存条件（温度、期限、密封/氮封要求）（V1.2 新增）。

## 三、技术要求与送样规格

### 3.1 制备工艺要求

#### 3.1.1 预交联自膨胀干粉（原 V1.0 条款）

| 工序 | 主样 A（推荐路线） | 对照 B（保孔对照） |
|---|---|---|
| 原料 | 细菌纳米纤维素（醋酸菌属代谢产） | 同左 |
| 化学改性 | 羧甲基化，取代度 0.20–0.35 | 同左（可另备 TEMPO 氧化样） |
| 交联剂 | 柠檬酸（食品级/无水） | 柠檬酸（食品级/无水） |
| 配比（纳米纤维素干重:交联剂纯品） | 1:0.02 | 1:0.08 |
| 共混 | 机械搅拌（可捏合/密炼） | 机械搅拌 |
| 交联+干燥 | 100℃ 干燥过夜（干燥中交联），一锅法 | -80℃ 冷冻→冷冻干燥→85℃×12 h |
| 再加工 | 粉碎机粉碎成粉末 | 粉碎/压缩成颗粒 |
| 参考性能 | 复水约 2.6 s、持水约 4100% | 复水约 8.2 s、持水约 8600% |

#### 3.1.2 氨基化 BNC（主样 D，V1.2 形态更新）

| 工序 | 要求 |
|---|---|
| 原料 | 同主样 A（细菌纳米纤维素，纯度>99%） |
| 硅烷偶联剂 | γ-氨丙基三乙氧基硅烷（γ-APTES），配制成 3% 水溶液使用 |
| 偶联剂用量窗口 | 硅烷偶联剂纯品为 BNC 干重的 10/20/30/40 wt% 四档（参考公开专利对纤维素纳米晶的 10–40 wt% 窗口，对 BNC 重新标定） |
| 反应条件 | 室温搅拌反应，反应时间/温度由乙方小试标定（以氨基接枝密度达标为准） |
| 后处理 | 洗涤去除游离硅烷→分散液直接定容至固含 2%（第一优先形态）；如需干粉则干燥（不高于 100℃，保持氨基活性） |
| 交付形态（V1.2 调整） | ①2% 固含分散液（功能验证阶段第一优先，免复水、直接进丙方液体注入通道）；②干粉（量产切换后备，复水≤30 s 至 2% 固含） |
| 分散液储存 | 4℃ 短储（保质期≥7 天）、无菌灌装、密封氮封；pH 控制在中性偏酸区间（保持氨基质子化正电荷，提升分散稳定性） |
| 参考定位 | 氨基位点承担：a) 与 SAP 羧基的酰胺化缩合（可选，EDC/NHS 活化路线）；b) 抗菌/除臭功能剂氢键+静电锚定；c) 与交联剂共反应参与壳层构建 |

## 四、甲方验证清单（乙方配合提供必要信息）

甲方收到样品后按以下顺序验证，结果反馈乙方：

1. 复测：干粉复水时间与分散液固含复核（≤30 s、2%±0.3%）；分散液形态直接复核固含、Zeta 电位、pH、静置沉降（V1.2 更新）。
2. 热模拟：130℃×30 min 热处理前后复水性能与白度对比（干粉），分散液热处理后固含/沉降复测（模拟丙方后处理干燥条件）。
3. 混涂台架模拟：SAP 半成品+表面交联剂液+BNC 分散液→高速混合→130℃ 二次干燥→筛分，验证分散液形态在丙方后处理工段的挂靠可行性。
4. 材料级性能：CRC、AUL、GBP、Vortex、rewet、液体传导（与未添加 BNC 基线对照）。
5. 芯体级验证：13.5 g/片基准打样、多次 Insult。
6. 用量 DOE：BNC 相对 SAP 干重 0.05/0.1/0.3/0.5/1.0% 五档扫描，确定最优添加量与性能响应面。
7. 氨基化 BNC 专项验证：氨基接枝密度复核（N 元素分析，与乙方报告对账）；氨基在 130℃ 交联固化段的消耗率测定（验证氨基是否在壳层共反应中被消耗，评估对阶段 B 锚定能力的影响）；功能负载锚定小试：聚六亚甲基胍 0.05–0.5 wt%+除臭剂 0.5–10 wt%（蓖麻油锌酸酯体系）喷涂→100–120℃ 干燥→24 h 浸泡不溶出验证（抑菌率≥90%、氨去除≥90%、醋酸去除≥85% 目标）。
8. 絮凝台架实验（V1.2 新增）：氨基化 BNC 分散液与丙方交联剂液混合稳定性专项——混合顺序（先稀释交联剂再混合/反向）、交联剂浓度梯度、pH 窗口三因素扫描；以 Zeta 电位跟踪+目视/显微观察判定絮凝边界；输出"无絮凝安全操作窗口"，作为 Phase 3 混涂配制的输入参数。

6. 违约责任：违反上述保密与排他约定的一方，按双方 NDA/JDA 约定承担违约责任。
