1.4.1 为什么要有噪声底
★ 状态：方法论成立，但本批无法实施。 下表说明的是若存在有效复现样时该如何设定两道闸门； 由于 Code 13 / Code 15 均非复现样（见 1.4.2），② 归因闸门在本报告中不启用，全篇只用①幅度闸门。
上一轮（9.30 版）的所有比较都建立在一个隐含假设上：指标差异来自材料变更。要检验这个假设，最直接的办法是引入与基准完全同配方、仅成型批次不同的样本 —— 它与基准的差异就只能来自过程波动，这个量级就是噪声底（noise floor）。

2.18 第一组 —— 总体结论（★2026-10-11 随噪声底撤回重写）
★★ 本节判读前提（必读）：上一版曾以 Code 13 / Code 15 为噪声底做「可归因 / 噪声内」二分判定，该前提已被推翻（见 1.4.2 与 Q18）。本批无任何全同配方复现样，故：
以下全部结论只给「观测幅度」，不给归因。凡写「显著劣」仅指幅度 &gt;30%，不含「由该变量导致」的含义。
不同收样日期的 Code 之间不可直接比大小（见 1.4.4 与 Q21）：Code 10/11/12/14/15/16/17 收样于 9/28–9/30，Control-2 收样于 9/22，批次差异未受控。
唯一可用于倾向性判断的，是同一变量在多个指标上方向一致的情形（下列结论 5、6 属此类，相对更可信）。
★结论 0（新增，居首）：本批最大的限制不是数据缺失，而是「无法剥离批次效应」。 上一版曾据两个「复现样」推断存在批次级定向漂移（Cradle 3rd 摄入 +61.1% / +67.9%），该推断随噪声底前提一同撤回 —— 那两个样本实为 Code 13（PSN 换 Unikorn 155mm）与 Code 15（多变量），其偏离是真实变量效应，不是噪声。 → 代价是：本批 15 个 Code 的所有幅度，其材料贡献与批次贡献无法分离。 这不改变任何数值，但彻底改变了结论的可用性：本节不再产出可用于选型的确定性结论，只产出「待验证的候选假设」。 → 补齐方式（最高优先级 P0）：在同一收样日、同一成型批次内，制备 Control 全配方复现样 n≥3（LSS/PSS SAP、LSN、PSN、REL、胶种、胶宽、pad 宽幅、pattern、成型鼓全部与 Control-2 一致），与待测 Code 同批测试。这是把本批数据变成可用数据的唯一钥匙。

4.4 差异分析与可能原因
Code A 优势项原因：① PVA 的 Z 向刚性骨架（~25 GPa，为 PE 的 125 倍）受压不塌，SAP 无横向逃逸路径；② 中空 PET 4D 占比 30%（基准配方仅 14%）形成连续的机械俘获网络；③ CD 归一化强度 6 组第一 + CD/MD 比最均衡（0.283），边缘不易散边；④ 高 MD 延伸率（72.8%，6 组第一）带来「以柔裹住」效应。→ 材料减量 27.4% 的同时厚度未同比例下降，说明单位克重的结构效率更高。
Code B 优势项原因：① 双层分克重结构的方向性液体管理 —— 上层 11.2 gsm 细旦致密层（80% 2D + 20% 3D）形成小孔径高毛细压界面把液体主动向下压入，下层 16.8 gsm 蓬松层（中空 + PTT + PVA）提供低阻力接纳空间，「上密下疏」梯度本身具备单向导流效应（与 ADL 孔径梯度设计原理一致）；② 细旦上层直接阻断 SAP 凝胶向上迁移路径，减少表层游离水回渗；③ 致密化（堆密度 0.0387 vs Code A 0.0285 g/cm³，+35.7%）提高纤维—液体接触面积，同时带来 MD 强度 +23

6.5 ★★★ 本轮最重要的变化：噪声底体系撤回，本批无复现样（2026-10-11 修订）
上一版（10.10 版）曾把「建立逐指标过程噪声底」列为本轮方法论升级：由 Code 13 / Code 15 两个「Control 全同配方复现样」逐指标取 |Δ%| 较大者作噪声底，得到 Cradle 3rd ±67.9%、Cradle 2nd ±50.9%、国标渗漏 ±40.8%、L/H 残留 ±100%、国标回渗 ±4.1% 等 19 个数值，并据此判定「169 项效应量中 37 项（21.9%）可归因」。
★ 该体系已于 2026-10-11 全量撤回。
撤回的证据链
Code	被当作「复现样」的依据	源文件实际记录	判定
Code 13	Product Test U10–U16 七行（SAP / LSN / PSN / REL / 胶种 / Liner）与 Control-2 逐格一致	U13 = UNIKORN -155mm —— PSN 由 Control-26g 换成 Unikorn 20gsm PP+fluff 155mm 宽；Material List 第 11 项规格即为「Width: 155mm」；Tar.Weight 22.462 ≠ 22.817	单变量试验，非复现样
Code 15	同上，W10–W16 亦逐格一致	W4 = #VALUE!（Code Design 公式失效）；W21 Remark 明列四项：-16,17 在一个成型鼓 / -PSN,REL需要换成适合110mm Pad / -胶宽需要减窄 / -需要两卷；ADH width 125 ≠ 137.5；Tar.Weight 22.120 ≠ 22.817	多变量试验，非复现样
为什么这一误判特别危险
噪声底是「能否归因」的闸门。一旦把有变量试验当作噪声基底，会产生两重反向错误：
压低真效应：把真实变量效应（Cradle 3rd +61.1%、国标渗漏 −40.8%）误读为「过程噪声」→ 大量真实劣化被判为「不可归因」而被放过（如 Code 8 曾被判「0 项可归因」）；
虚增结论强度：由此得出的「本批 78% 的差异都是噪声」「存在批次级定向漂移」等推论，其实是把两个不同的变量效应当成了漂移的度量。
