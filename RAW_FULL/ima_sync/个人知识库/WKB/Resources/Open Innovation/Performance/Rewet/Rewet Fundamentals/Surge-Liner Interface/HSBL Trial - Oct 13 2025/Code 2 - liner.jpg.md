**图形结构描述**
- 背景为深蓝近黑的暗场，呈 UV/蓝光荧光显色。
- 画面中部为一条横向样品带，呈明显的**上下分层结构**：上层为**较亮、颗粒/串珠状（beaded）纹理的窄带**，纹理由密集的亮点/颗粒构成；下层为**较暗、相对平滑的宽带**，颗粒感弱。
- 样品带在右侧中段可见一条**竖向分界线**，将左右两段分开；样品带左右两端边缘不齐。
- 样品带整体亮度低于 Code 2 / Code 2 (2)，颗粒显得更粗、更松散。

**推断**
- [推断] 上层的颗粒/串珠状纹为 liner 面上的胶粒或熔喷纤维层在 UV 下的荧光；下层的平滑区为基材本体。
- [推断] 右侧竖向分界线为材料拼接或折叠处；文件名 "liner" 指该样品为导流层/衬层（liner）件。
