# Ideas Thus Far

$\bullet$ Increased rewet might be due to lower capacity, but this is a non-negotiable for GRIFFIN to launch

* SAM/fluff capacity has not shown to impact rewet

$\bullet$ Wrapsheet and fluff layer should be considered as part of intake system for ATH codes

* More layers and more interfaces for fluid to get caught in – need to identify where fluid is getting stuck (requires SAM-less cores for testing)

$\bullet$ If fluid is hanging up in `fluff`, can including some SAM in the fluff help desorb?

$\bullet$ Is dSB wrapsheet making a difference?

* SIROCCO testing says they found no difference vs tissue, but can't find data

* TABCW wrapsheet helped BUFF BABY & KCM (diapers). Will it help here?

* Would adding curly fiber to wrapsheet help?
