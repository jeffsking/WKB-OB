修订说明（v3, 2026-07-21）：在 v2 基础上纳入最新打样 xlsx（8方案、3测试方法）与 SAP 牌号参数 PDF，全面重做数据解读。核心反转：实验数据显示测试协议（载荷 / 次数 / 间隔）是决定胜负的变量，而非"单材 vs 多SAP"本身——高载短间隔（3.5 kg, 80 ml×3）下全511因最高 GBP 胜出；但在低载多次（企标 1.2–2 kg, 60 ml×4）下，分层多SAP混底方案（尤其 930/住友、511/951+959）反超全511于回渗。原"全511最优"系高压短间隔测试假象，多SAP分层策略在真实穿着条件下获实证支持。

---

实验已从 2 方案扩展为 8 方案 × 3 测试方法（高载芯体法 / 新国标尿片法 / 企标尿片法），覆盖多种 SAP 搭配与上下层比例（5/5、3/7、3/(2.5+4.5)、5/(2.5+2.5)）。

方法1（高载短间隔，3.5 kg, 80 ml×3）：全511吸收最快（GBP 24 最高→凝胶床不阻塞）；混底因低 GBP（951=4.3 / 610S=6 / 住友=2）阻塞→偏慢；但终态回渗以 511/951(5/5) 最优（27.7 g）。

方法3（企标，低载多次，1.2–2 kg, 60 ml×4）：混底全面反超——930/住友回渗 0.18 / 1.66 / 4.33 g、511/951+959 0.36 / 1.82 / 5.58 g，均远优于全511（8.36 g @ 34 min）。

方法2（新国标，4 kPa, 80 ml×2）：930/住友（1.12 g）、511/959（1.62 g）、511/951+610S（1.65 g）领先，全511（2.12 g）居中。

机理：高载下渗透（GBP）受限→高GBP的511占优；低载多次下容量（CRC）受限→高CRC（35+）的混底释放容量、抗饱和→回渗更低。原报告"全511最优"是高压短间隔测试假象。

方向修订：路线A（完整多SAP+REL）由"待证明"升级为"获支持 / 优先推进"；路线C（修正协议重测）已获企标数据实证，转为常规监控；路线B（分层+单平衡）降级为保守备选。

---

核心架构：分层 + 错峰（timing > 位置）

三档选型标准（详见 v2 §1.1 表）：SAP1 重 GBP/快吸；SAP2 刻意封顶 CRC + 快膨胀；SAP3 最高 CRC + 充分膨胀后高 AUL，GBP 激活后达标即可。

选定牌号（v2 §1.2）：LG LK804ND（SAP1, GBP 53）/ Nuoer KC-511（SAP2, CRC 30.9, GBP 24）/ Nuoer NR-950（SAP3, CRC 36.7, GBP 8）。仿真结果：−59% 回渗、+29% 容量、−40% 成本（建模非实测）。

v3 补充：本次打样用 KC 511 实测作顶层（与仿真 SAP2 牌号一致），底层改用 951 / 959 / 610S / 住友 等高CRC低GBP料混配（对应策略 SAP3 候选），并以水刺布（上35 gsm / 下26 gsm）充当 REL 毛细 z-flow 层，与策略架构一致——详见 §三。

① 高载短间隔（方法1）：全511吸收占优，但混底未必更差

但终态回渗以 511/951(5/5) 最优（27.71 g），优于全511（31.77 g）——说明即便在高载下，合适的底层混配（951 单一高CRC）也能改善终态保液。全511(3/7) 反而最差（37.55 g），因顶层占比过低、第一响应不足。

② 低载多次（方法3，最贴近真实穿着）：混底全面反超全511

930/住友 回渗 0.18 / 1.66 / 4.33 g 全面最优；511/951+959 0.36 / 1.82 / 5.58 g 次之；全511(5/5) 达 8.36 g（最差梯队），全511(3/7) 更达 11.27 g。

机理：低载下高GBP优势消失，转为容量竞争——底层高CRC（951/959/住友均 60+ vs KC511 59.4）在 4 次加液后释放更大储库，混配底层抗饱和、回渗更低。这是策略"分层多SAP提升重复排泄利用率"主张的直接实证。

③ 新国标法（方法2）：混底领先，全511居中

930/住友(1.12) > 511/959(1.62) ≈ 511/951+610S(1.65) > 511/951+959(1.82) > 511/951(1.48) > 全511(2.12) > 511/951+N8(4.32) > 全511(3/7)(5.31)。

错峰可行性：951（速度27s）/ 959（34s）/ 610S（19s）膨胀速率存在差异，具备"错峰"物理基础；但 N8(611) 与 610S 速率接近、且 GBP 均低，纯951+N8 方案回渗偏高，提示需引入高AUL料(959)或控制快吸料占比。

---

多SAP分层策略在真实穿着条件（低载多次）下获实证支持；原"全511最优"系高压短间隔测试假象。分层架构（顶层511/930 + 水刺布REL + 底层高CRC混配）成立，优选底层为 951+959 或 951+610S（控量），避免纯951或纯住友（渗透过低）。

路线A（完整多SAP+REL）— 升级为「获支持 / 优先推进」：企标数据已证混底反超全511。强化：底层固定 951:959 ≈ 1:1（兼顾CRC与AUL）；顶层用 KC511 或 930；评估SAP3 alt 中 高AUL料（巴斯夫7059 AUL 17.7 / NR-950 AUL 19.4） 作容量-渗透平衡。

路线C（修正协议重测）— 已实证、转为常规监控：企标法（60 ml×4, 1.2–2 kg）数据已直接验证错峰收益，无需再作为"生死gate"，改为日常配方筛选标准。

锁定优选方案推进 Stage 2：以企标数据领先者 930/住友、511/951+959 为基准，放大打样（建议增设 511/951+959 的 5/5 与 3/7 对照，验证顶层占比）。

底层混配优化：固定 951:959 = 1:1 与 951:610S = 1:1(控量)，bench 测 swell kinetics 确认错峰；评估 巴斯夫7059 / NR-950 作高AUL替代以提渗透。
