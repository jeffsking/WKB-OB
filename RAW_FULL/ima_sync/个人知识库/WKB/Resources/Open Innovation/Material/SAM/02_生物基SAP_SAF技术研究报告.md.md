# 生物基SAP/SAF技术研究报告

## 超吸水性树脂与生物基材料发展趋势

报告日期: 2026年4月
技术方向: 生物基高吸水性树脂(SAP) | 可持续航空燃料(SAF)

## 一、主要技术原理

### 1.1 SAP（超吸水性树脂）技术原理

高吸水性树脂(Super Absorbent Polymer, SAP)是一种具有三维网状结构的功能性高分子材料，能够吸收并保持自身重量数百至上千倍的水分。

吸水机理:
- 渗透压驱动: 树脂内部高浓度离子与外部低浓度溶液形成渗透压差
- 毛细管作用: 三维网络结构形成毛细管吸附效应
- 氢键作用: 亲水基团与水分子形成氢键结合
- 网络弹性: 交联结构限制无限溶胀，保持凝胶形态

关键性能指标:
| 指标 | 典型值 | 测试方法 |
|-----|-------|---------|
| 吸水倍率(纯水) | 500-1000 g/g | 茶袋法 |
| 吸水倍率(0.9%NaCl) | 50-80 g/g | 茶袋法 |
| 保水性 | >90% | 离心法 |
| 吸水速率 | 30-120 s | 涡旋法 |
| 凝胶强度 | 20-50 kPa | 流变仪 |

### 1.2 生物基SAP技术路线

传统石油基SAP: 聚丙烯酸钠/聚丙烯酸钾为主

生物基SAP发展方向:
1. 淀粉接枝共聚: 淀粉-g-聚丙烯酸/丙烯酰胺
2. 纤维素接枝共聚: CMC/羟乙基纤维素接枝改性
3. 蛋白质基SAP: 大豆蛋白、胶原蛋白改性
4. 聚天冬氨酸(PASP): 氨基酸聚合物，完全生物降解
5. 生物基单体合成: 生物基丙烯酸路线

生物基SAP优势:
- 原料可再生，降低石油依赖
- 部分产品可生物降解
- 对盐溶液敏感性低
- 环境友好，减少微塑料污染

### 1.3 SAF（可持续航空燃料）关联

虽然SAF与SAP应用领域不同，但两者在生物基原料开发上具有协同效应：
- 原料共享: 植物油、废弃油脂等可作为共同原料
- 技术协同: 生物炼制技术平台可共享
- 市场驱动: 碳中和目标推动两者发展

## 二、制备工艺

### 2.1 传统SAP生产工艺

||||
|---|---|---|
|反相悬浮聚合|产物颗粒均匀、吸水率高|日本触媒、住友、三大雅|
|水溶液聚合|工艺简单、成本低|巴斯夫、赢创|
|反相乳液聚合|产率高、反应快|部分企业|

反相悬浮聚合工艺参数:
| 工序 | 参数 | 控制要点 |
|-----|------|---------|
| 油相配制 | 环己烷/分散剂 | 油水比 3-5:1 |
| 水相配制 | 丙烯酸/碱/交联剂 | 中和度 70-80% |
| 聚合反应 | 温度70-80°C, 时间2-4h | 引发剂用量 0.1-0.5% |
| 共沸脱水 | 温度80-110°C | 含水率% |
| 表面处理 | 表面交联剂 | 提升凝胶强度 |
| 筛分包装 | 粒度150-850μm | 粒度分布控制 |

### 2.2 生物基SAP制备工艺

淀粉基SAP:

淀粉糊化 → 接枝聚合(丙烯酸/丙烯酰胺) → 交联 → 干燥 → 粉碎

- 接枝率: 60-80%
- 吸水倍率: 200-500 g/g
纤维素基SAP:

纤维素活化 → 羧甲基化 → 交联改性 → 后处理

- 纤维素来源: 农业废弃物、木浆
- 降解周期: 3-6个月
聚天冬氨酸(PASP):

天冬氨酸缩聚 → 交联 → 造粒

- 完全生物降解
- 吸水倍率: 100-300 g/g
### 2.3 表面交联技术

表面交联是提升SAP性能的关键：
- 作用: 提升凝胶强度、减少凝胶结块
- 交联剂: 多元醇、碳酸酯、噁唑啉等
- 工艺: 喷雾涂覆+热处理(120-180°C)

## 七、技术发展趋势

### 7.1 生物基化

- 目标: 2030年生物基SAP占比达到20%
- 路径: 生物基单体→生物基聚合物→可降解SAP
- 挑战: 成本控制、性能平衡、标准建立
### 7.2 功能化

- 抗菌SAP: 银离子、季铵盐改性
- 除臭SAP: 活性炭复合、酶固定化
- 温敏SAP: 温度响应型凝胶
- pH响应SAP: 肠道靶向释放
### 7.3 复合化

- SAP纤维复合材料: 芯体结构优化
- 纳米SAP: 提升吸液速率
- 有机-无机复合: 提升凝胶强度
### 7.4 绿色化

- 可降解SAP: 聚天冬氨酸、改性淀粉
- 循环再生: 废旧SAP化学回收
- 低碳生产: 绿电应用、碳足迹管理
