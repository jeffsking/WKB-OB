#   供应商概况

诺尔集团：2003年成立诺尔化工（聚丙烯酰胺）；2011年成立诺尔生物（东营港区）进军SAP。

产能: 6条SAP线(诺尔生物3+蓝湾3), 总产能56万吨; 利用率约80%, 2021年起国内份额第一。

原料：丙烯酸20万吨+精酸24万吨；明年计划新增8万吨。

规划: 2028年新增5万吨新工艺SAP; 2029-30新增10万吨吸水纸(两期)。

其他: 7条卫生巾线+2条经期裤线, 以OEM代工为主(软风/禅翼品牌)。

#   产品组合与产能

SAP牌号: 511 (KC专供) /760 (经济型511) /N8/951/950/959。

511 (KC): AUL 18-19 (0.7psi)、保水31.5、吸速27s, 通液性最均衡。

N8: CRC 39-40 (极高保水)、AUL 12、吸速45s, 仅作下层兜底。

951: 快吸+高保水, 优于老牌610S; 950上层/959上下层通用。

复合芯体: 2015年起推搭配方案(511+610S), 配芯体机+尿片机一条龙打样。

#   质量与工艺优势

后中和工艺：先聚合后中和，溶出物低、适配高GBP（通液性）。

* 粒径(PSD): 人工每小时抽样，目标300~600µm占比约80%。

GDP提升路径一多价金属盐涂层：提升表面交联，GBP个（上限约40），或降保水。

GDP提升路径二·无机粉末添加：大线具备能力，需综合平衡。

粉末添加：二氧化硅/纳米级/吸味材料均可（设备密封）。

#   创新与研发

六阶段工艺: 配料混合$\rightarrow$聚合(氮气/小罐慢跑)$\rightarrow$干燥(≤500℃)$\rightarrow$研磨筛分$\rightarrow$后处理(表面交联+抗黄变)$\rightarrow$包装(光学/磁/金属检)。

新颖分层思路: 上层高通液+好保水+下层快吸, 打破“全能须均衡”限制。

60GBP新品对标LG 804 (标称GBP 53): 诺尔可调内外交联与表面处理达GBP≈40/AUL≥20/保水28-29/吸速≈60s。

LG 804绝对值存疑（非同实验室），但高GBP方向获认可。

复合芯体know-how: 511+951+N8预混(五五/四六开)实现极致上层GBP/下层CRC。

#   后续行动

1. 即时打样：基准全511 vs 上层511+下层951+N8预混（13.5g/片），当晚测吸速/反渗/通液。

2. 高GBP上层专用SAP研发: 目标GBP40/AUL≥20/保水28-29/吸速≈60s, 8月内出小试。

3. 蓝湾工厂参观(次日): 吸水纸+SAP产线, DCS仅看不可发。

4. 资料调阅：三大雅+住友常规配方、SAP配比实验数据库。

5. GDP验证：多价金属盐/无机粉末/吸味材料拓展实验。
