# 力致变色材料研究报告

面向纸尿裤领域的应用现状、技术路线与供应商策略

——基于战略路线图与供应商选型两份材料的综合研判

编制说明：本报告严格限定于“机械应力 / 拉伸触发”的力致变色（Mechanochromic）材料，全文排除湿致变色（Hydrochromic / 尿湿指示）相关内容。证据分级：[F] 可核实事实｜[I] 公开信息推断｜[A] 行业基准假设｜[E] 估算。报告日期：2026-08-02。

摘要

力致变色材料能够在无源、无电条件下，仅凭拉伸、压力或剪切等机械刺激发生颜色或发光变化，为卫材从“被动吸收”迈向“主动诊断反馈”提供了战略支点。综合两份材料研判：该领域目前处于“创新空白”阶段——尚无任何供应商提供“纸尿裤专用力指示”成熟 SKU，纸尿裤力指示不能直接复用市售压力激活材料，必须走“自建阈值 + 印刷工艺”的 build 路径，而非购买 off-the-shelf 产品。

全球力致变色材料市场 2024 年规模约 12 亿美元，预计 2033 年达 41 亿美元（CAGR 14.6%）；北美约占 38% 份额，亚太增速最快（CAGR 17.2%）。竞争中度集中，Merck KGaA、GIVIDI、Avient、Sun Chemical 为四大龙头，CTI 与 LCR Hallcrest 在可印刷智能油墨细分领域形成差异化。对于纸尿裤，短期最可行的切入点是“腰贴 / 腰围过紧指示”，以 CTI 食品接触级可印刷压力激活油墨为主选构建模块，配合国内河南佳易达、深圳星成珠光作成本备份，并以 Chungnam / Hanyang 大学 CLCE 研究合作布局中长线“舒适度形变反馈”。婴儿口服与皮肤安全为最高优先级，全部候选须通过 FDA 21 CFR / EU 10-2011 / REACH 筛查，优先选用食品接触级材料。

力致变色指“对机械刺激（拉伸、压力、形变、剪切）响应而变色 / 发光”的材料。它与卫材常见的湿致变色（尿湿指示，Hydrochromic）机制完全不同，本报告全程排除后者。四类覆盖机制为：① 力化学基团（Mechanophore）激活；② 光子晶体 / 结构色；③ 液晶弹性体（CLCE）取向；④ 表面起皱。（注：富士 Prescale 等压力指示膜属不可逆计量型，其余多为可逆，适合重复监测。）[F]

四大龙头：Merck KGaA（德国）、GIVIDI、Avient（原 PolyOne，美国）、Sun Chemical（美国 / 全球）主导高价值应用与材料平台 [F]。

护城河本质：不是产能，而是“IP + 法规合规能力”（医疗 / 儿童 / 食品接触级），国内厂商在热致 / 光致等相邻市场凭成本与定制领先，力致变色仍处萌芽 [I/A]。

战略路线图将当前格局定义为“innovation white space（创新空白）”：先行者优势取决于把实验室力化学成功下移至高速无纺布工业生产。卫材核心价值主张包括——防勒颈 / 过紧警示（腰贴集成高可见信号）、精准贴合与舒适度反馈、无源压力分布测绘。这意味着从“商品”转向“智能安全器件”，可构建深层技术护城河。[F]

|机制|触发方式|变色来源|典型形态|

|材料|机制|视觉输出|对纸尿裤的战略优势|
|---|---|---|---|
|羟丙基纤维素（HPC）|粘弹性晶格间距变化|压缩蓝移（红→蓝）|可食、无毒、可生物降解；依托成熟医药供应链 [F]|

来源：战略路线图技术评估表。

阈值严重错位：工业级力化学基团为检测高性能聚合物结构失效而设计，触发阈值极高（≥ 40,000 PSI）；进入纸尿裤需“下移至”微致动研究识别的低张力区间（20–150 kPa）。[F]

25–27% 应变区间转变（Barty-King et al., 2025）：低于该区间，HPC 等处于稳定粘弹性螺距压缩态；一旦超过，材料进入流动 / 剪切态，剪切变稀与非弹性横向流动会 destabilize 颜色信号，可能在应力仍施加时出现“松弛 / 消散”假阴性。[F]

对于连续贴合监测，可逆性是不可妥协的硬指标。结构色材料（如 HPC）在应变与颜色间呈可预期的幂律关系，照顾者可调节腰围并观察到颜色回到基线“安全”态；萘并吡喃的模块化优于螺吡喃的热瞬态，是定制特定激活阈值的更稳健平台。[F]

Day-1 主假设“纸尿裤力指示可直接采用市售压力激活材料、短期商业化”经翻转测试被证伪：市售压力激活材料（CTI HPP 墨、Prescale 膜）均属不可逆计量型，阈值固定在超高压力或工业接触压力，无现成柔软、低阈值、可逆、可皮肤接触的规格。结论：纸尿裤力指示是创新空白，应走 build（自建阈值 + 印刷工艺）路径。[F/I]

方法对比：可印刷压力激活油墨（胶印 / 柔印，最快上市，CTI 食品级作法规盾）vs. 共价力化学基团（键合至聚合物骨架，自评估材料 + 永久 IP 护城河，工艺更复杂）。[F]

策略 4 — 法规优先：全部候选须过 FDA 21 CFR / EU 10-2011 / REACH 筛查，优先食品接触级；HPC 为金标准（可食、无毒、可降解，已用于医药）。[F]

|阶段|周期|关键动作|
|---|---|---|
|阶段 1 · 阈值与安全|0–3 月|向 CTI 索取食品级压力激活油墨样品；依儿科安全数据定义过紧力阈值（20–150 kPa）；开展口服毒性与皮肤迁移初步审计|
|阶段 2 · 技术去风险|3–6 月|下移至低张力测试，确保染料在卫材区间触发；用凝胶剂做 25–27% 应变区间稳定性测试，防信号松弛|
|阶段 3 · 规模化与可见性|6–12 月|在现有无纺布产线柔印原型；开展“人因”测试，确保低光育婴环境可见|

路线图：试点（印刷压力油墨，场景 A/C，6–12 月）→ 预研（CLCE / 应变纺织，场景 B，12–24 月）。[A]
