# SSMMS无纺布技术研究报告

## 广鸿新材与纺熔复合无纺布产业化

报告日期: 2026年4月
技术方向: SSMMS纺熔无纺布 | 医疗卫材 | 无纺布设备

## 一、主要技术原理

### 1.1 SSMMS结构定义

SSMMS是纺粘(Spunbond)-纺粘(Spunbond)-熔喷(Meltblown)-熔喷(Meltblown)-纺粘(Spunbond)五层复合结构无纺布。

结构特点:

表层: 纺粘层(S) - 提供强度、耐磨性
中间层: 熔喷层(M+M) - 提供过滤、阻隔性
底层: 纺粘层(S) - 提供强度、柔软性

### 1.2 各层功能

||||
|---|---|---|
|S(纺粘)|PP|15-30μm|机械强度、耐磨|
|M(熔喷)|PP|1-5μm|过滤、阻隔、抗菌|
|S(纺粘)|PP|15-30μm|机械强度、柔软|

### 1.3 性能优势

与传统SMS对比:
| 性能 | SSMMS | SMS | 提升幅度 |
|-----|-------|-----|---------|
| 静水压 | >50cmH₂O | 30-40cmH₂O | +25-67% |
| 透气性 | 良好 | 良好 | 相当 |
| 过滤效率 | >95% | 85-90% | +5-10% |
| 强度 | 更高 | 一般 | +20-30% |
| 手感 | 更柔软 | 一般 | 改善 |

## 二、制备工艺

### 2.1 一步法复合工艺

生产线配置:

原料 → 挤出机(3台纺粘+2台熔喷) → 熔体过滤 → 计量泵 → 模头
→ 纺丝 → 冷却 → 牵伸 → 成网 → 热轧 → 卷取

五层成网顺序:
1. 第一层纺粘(S): 纺粘模头1
2. 第二层纺粘(S): 纺粘模头2
3. 第一层熔喷(M): 熔喷模头1
4. 第二层熔喷(M): 熔喷模头2
5. 第三层纺粘(S): 纺粘模头3

### 2.2 工艺参数

||||
|---|---|---|
|挤出温度|190-250°C|熔体流动性|
|熔体压力|10-30MPa|稳定性|
|纺丝速度|3000-5000m/min|纤维细度|
|熔喷温度|230-280°C|纤维直径|
|热轧温度|130-160°C|粘合强度|
|热轧压力|50-150N/mm|产品厚度|

### 2.3 静电驻极处理

||||
|---|---|---|
|电压|30-100kV|驻极充电|
|驻极时间|0.5-2s|电荷稳定|
|过滤效率提升|10-20%|静电吸附|

### 2.4 后处理工艺

||||
|---|---|---|
|亲水整理|改善亲水性|纸尿裤、卫生巾|
|拒水整理|提高防水性|手术衣、防护服|
|抗菌整理|添加抗菌剂|医疗用品|
|抗静电整理|添加抗静电剂|电子行业|
