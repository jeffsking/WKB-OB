#   3. Fix 1: 质量守恒常数伪影修正

#   问题诊断(红队反馈)

v8 报告摘要宣称质量误差约为 0 mL（完美守恒），但观察质量误差曲线，纵轴始终存在一个接近 5 mL的常数偏移量。蓝队将其解释为"初始液体带来的常数偏移"，但红队指出这在严谨的数值计算中是危险的——这意味着在t=0 时刻，系统凭空多出了约 2.5% 的注液量（200 mL注液中的 5 mL）。

#   根因分析

模型初始化时将所有网格的饱和度设为  $S w=0.02$  (对应约 5.04 mL液体),使得  $V_{initial}=N x* N z* S w* p h 0* c e l_v o\approx 5.04~mL$  。但 v8 的质量误差公式仅包含注入量: M_error = M_total M_injected,未扣除这 5 mL初始液体,导致恒定的  $\sim 5~mL$  偏移。

#   修复方案

修正全局质量平衡积分公式: M_error = M_total - M_injected - M_initial。在模拟开始时记录 V_initial = sum(V_liq[:,:] t=0),每次计算质量误差时显式扣除该初始量,确保 t=0时误差严格为零。

#   4. Fix 2: 非线性毛细扩散系数 D_cap(Sw)

#   问题诊断(红队反馈)

v8 将毛细扩散系数 D_cap 设定为恒定的 1E-9
m^2/s。但在真实的非饱和多孔介质中,扩散速度受含水率的强烈控制。常数 D_cap
导致前沿扩散变得像热传导一样平滑,无法模拟出真实尿液渗透时陡峭的湿润前沿(Wetting Front)。

#   修复方案

将 D_cap 升级为饱和度 Sw 的非线性函数,基于 Mualem-van Genuchten/Brooks-Corey 模型:

$$D\_cap(Sw) = k(phi) * kr(Sw) / mu * |dPc\_dSw|$$

其中:

- $kr(Sw) = Sw^3$ (相对渗透率, Mualem 模型)

- Pc (Sw) = Pe * Sw(-lambda), lambda=2.0 (Brooks-Corey 毛细压力)

- dPc/dSw = -lambda * Pe * Sw(-lambda-1): 低 Sw 时梯度极大, 产生快速扩散

该公式从物理第一性原理推导，在极低饱和度时 D_cap 可达 1E-7 m^2/s，比 v8 常数大 100 倍，产生尖锐的湿润前沿；随饱和度增加而衰减。

#   5. Fix 3: Carman-Kozeny 动态渗透率 (凝胶阻塞)

#   问题诊断(红队反馈)

v8 中渗透率 k0=1E-12 $\hat{m}^2$ 在整个模拟过程中保持不变，即使 SAP 溶胀导致孔隙率从 0.42 显著下降。红队指出:如果不动态衰减渗透率，模型会严重高估芯体在多次吸收后的导流能力，无法捕捉到真实纸尿裤中常见的"芯体断层"或"阻水"现象。

#   修复方案

引入 Carman-Kozeny 动态渗透率模型：

$$k(phi) = k0 * (phi/phi0) \hat{3} * ((1-phi0)/(1-phi)) \hat{2}$$

该模型从颗粒填充床的微观流道理论推导，自动捕捉凝胶膨胀导致的孔隙堵塞效应。随着溶胀压缩孔隙，渗透率非线性骤降。

9. 物理洞察与工程启示

9.1 数值扩散对产品设计的警示

网格收敛性测试揭示了一个重要工程教训：在  15x6  粗网格下，约  30  个百分点的SAP利用率来自数值扩散而非真实物理扩散。这意味着如果直接使用粗网格结果指导产品设计（如

SAP

用量优化），可能会过高估计材料利用率，导致实际产品吸收性能不达标。建议以 30x12（或更高分辨率）作为仿真基准。

9.2 凝胶阻塞的物理意义

Carman-Kozeny

渗透率模型揭示了一个自限性机制：SAP溶胀降低孔隙率，进而降低渗透率，限制后续液体到达更深层。这在细网格中更为显著——最低孔隙率降至  0.284（vs粗网格

0.347），因为细网格能更精确地解析SAP颗粒附近的局部孔隙结构。这一效应在产品设计中至关重要：它解释了为什么高

SAP

含量的纸尿裤有时反而容易出现侧漏。

9.3 非线性湿润前沿的影响

非线性  D_cap(Sw)  产生的陡峭湿润前沿更接近真实吸收过程。细网格中自由液体在模拟结束时已完全吸收（0.0 mL），而粗网格仍有 2.6 mL 残留——这暗示粗网格可能低估了毛细排液效率。

10. 局限性 & 后续工作建议

注入区宽度：目前 40% 的注入区宽度可能偏大，建议缩小至 20-30% 以减少初始 SAP 利用率偏高的问题

D_cap  参数校准：非线性  D_cap(Sw)  中的  Brooks-Corey  参数  (Pe=3000  Pa,  lambda=2)需要与实验湿润前沿数据校准

反渗 (Rewet) 机制：v9 仍不包含二次加载后的反渗模拟，这是后续 v3.0 的关键功能

多组分传输：尿素、NaCl、表面活性剂对 SAP 溶胀的抑制效应未建模

3D 扩展：当前 x-z 平面 2D 模型可自然延伸至 x-y-z 全 3D，但需注意计算成本

实验验证：强烈建议将细网格模拟结果与真实纸尿裤吸收实验数据进行直接对比校准

更高分辨率网格：建议尝试 60x24 网格以进一步确认 SAP 利用率是否已收敛
