## 0. 为什么需要这一层知识

references/08-芯体成型工艺与设备.md 是本地唯一覆盖成型设备的文档，内容为 2021 年 KC 培训的绒毛浆 + SAP 传统成型（纤维化 / 成形室 / 成形鼓与筛网 / Scarfing / 芯体转移 / 折叠 / Debuking / QC）。它完全没有：pattern-SAP 分部成型、一鼓多 ups、sleeve 架构、双层套准、伺服相位架构、扇区停留时间、风机 duty point、repitch 解耦。

这构成一个结构性缺口：COCO-v6 的芯体架构已经改为「全 SAP + REL」（绒毛浆移除，见 references/74-COCO-v6项目技术档案.md），但支撑该架构量产化的机器工程方法在本地知识层为零。专家在不检索 WKB 时，对「高速 pattern 芯体成型」整块只能依赖通用知识——这正是 2026-09-22 的 COCO-v6 gap 比对中 7 个高优先级 gap 全部落在同一区块（转换机械工程） 的根源。

本文件的边界：只覆盖 pattern-SAP 分部成型线（鼓 / sleeve / SAP 落料 / 套准 / repitch / 换型 / 风机 / 伺服）。吸收性能、材料化学、成品测试不在本层，见 references 01–29、72–79。

## 1. 传统成型 ↔ pattern 成型：分野说明（对 08 的补充指路）

||||
|---|---|---|
|SAP 布局|与绒毛浆均匀混合成整幅|分区沉积（skin / poly 两层各自图案）|
|尺寸定义载体|成形鼓筛网段 + 段位排列|可换 sleeve（尺寸载体），鼓体固定|
|多规格手段|换鼓 / 换网 / 调速|换 ups（n） + 换 sleeve；P = πD/n|
|相位基准|相对宽松（整幅无图案对齐）|严格：双层 pattern 互套，`|
|关键质量门|芯体完整性、SAP 分布均匀度|套准 Cpk + 通道湿态粘接 + 边缘锐度|
|后道耦合|直接由砧辊切断|必须经 repitch 单元把鼓距解耦成产品节距|
|成型真空|通幅恒定|6 区固定角度，逐区设定，且随 ups 改停留时间|
|仿真对象|纤维气流铺网|颗粒轨迹 + 相位误差统计 + 气流场|

使用建议：凡问题涉及「pattern 分区、多规格共鼓、套准、repitch」→ 走本层；涉及「纤维化、混合、Debulking」→ 仍走 08。

## 4. 本次独立复核结论（仅算术闭合性，不含物理正确性验证）

对源文件的核心数值做了独立算术复核（不采信其内部一致性，全部重算）：

✅ 闭合的项

|||
|---|---|
|鼓距 = πD/n|2,770.8/6 = 461.80 ✓；2,770.8/7 = 395.83 ✓|
|鼓面线速 = 鼓距 × ppm|461.8 × 1000 = 461.8 m/min ✓；395.8 → 395.8 m/min ✓|
|时间/度 = 60/(rpm×360)|166.7 rpm → 1.000 ms ✓；142.9 rpm → 1.166 ms ✓|
|离心场 = ω²r|166.7 rpm → 134.3 m/s² = 13.70 g ✓；142.9 rpm → 98.7 m/s² = 10.07 g ✓|
|全部 11 个端区|逐规格重算，与 P5 表完全一致 ✓（如 Open XL 461.8−420 = 41.8 → 42 ✓；Pant XL 395.8−365 = 30.8 → 31 ✓）|
|全部 11 个 repitch ratio|逐规格重算，与 P5 表完全一致 ✓（如 Open NB 390/395.8 = 0.985 → 0.99 ✓；Pant XL 495/395.8 = 1.251 → 1.25 ✓）|
|SAP g/片 与 kg/h|如 Open M（358×110、160 gsm）= 0.03938 m² × 160 = 6.30 g ✓；×1000×60 = 378 kg/h ✓|
|风机轴功|22 m³/min = 0.3667 m³/s；×15 kPa = 5.5 kW 水力；/0.65 效率 = 8.46 kW ≈ 8.5 kW ✓（隐含效率 ~65%）|
|鼓惯量|270 kg 全质量在 r = 0.441 m → J = mr² = 52.5 kg·m² ✓（即薄环上限假设，保守）|
|扇区角度合计|60+65+25+54+18+138 = 360° ✓|

⚠️ 两处软点（建议在 RFQ / 中试中核实）

- 保形压力 ~39 Pa 的推导未闭合。 源文件称「230 gsm 床 @13.7 g 需 ~39 Pa」。裸算惯性压力 = 0.230 kg/m² × 134.3 m/s² ≈ 31 Pa。反推 39 Pa 需等效 17.3 g 或 290 gsm，或按「扣除 land 后的净图案面积」口径（÷~0.77）→ 40 Pa，与 39 Pa 吻合。源文件未给出推导细节。
*结论稳健性*：保形段给 ~4,000 Pa，无论 31 还是 39 Pa，余量都是两个数量级，故「保形从不是瓶颈」这一结论不受影响。
- 3 s 停车扭矩与稳态运行扭矩口径不一致（约 −15%）。 由 6-up ≈455 Nm、7-up ≈410 Nm 反解，隐含 J·α 项为 302.5 / 259.3 Nm，两者差 43.3 Nm ≈ 52 × (5.818−4.986) ✓ 两 ups 之间自洽；但隐含的摩擦/运行扭矩为 ≈152 Nm，与 P12 表列的稳态 180 Nm 差约 15%。
*处置*：选型时按 455 Nm 峰值 × 安全系数取，不要用 180 Nm 反推峰值；要求设备商提供停机曲线。

声明：本节只验证算术闭合性与表间一致性，不验证任何物理模型（气流、颗粒轨迹、误差统计）的正确性。上述「闭合」不等于「实测成立」。
