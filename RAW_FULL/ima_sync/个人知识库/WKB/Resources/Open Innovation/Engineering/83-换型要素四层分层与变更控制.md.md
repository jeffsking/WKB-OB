# 83 · 换型要素四层分层与变更控制

补库来源：One_Drum_Two_Ups_11_Sizes_1000ppm.pptx P4/P7/P8/P12/P18
对应 Gap：G2（换型要素「四层分层」架构缺失）｜严重程度 高｜属 P0 批次
主表改善建议：补充①Body / Sleeve / Recipe / Change-part 四层清单与归属判据 ②每层变更成本与工时 ③CD 变更走 chute 插片而非 ups 的理由 ④各层与工艺参数（真空/风量/胶量/相机）的耦合关系
创建日期：2026-09-22

## 1. 分层的第一原则

源文件 P8 副标题（原文）：*"Everything that defines phase is on the drum body; everything that defines size is on the sleeve."*

即架构按「定相位」vs「定尺寸」正交切分：

|||
|---|---|---|
|鼓体 Body|一切决定相位基准与机械几何的量（节圆、扇区角度、编码器零点、压合间隙、轴向对中）|永不动|
|Sleeve|一切决定尺寸（MD 方向 pattern 布局）的量|必换（每次 2 片）|

另有一条来自 P4 的强约束：*"Both drums (skin and poly) always carry the same ups — the nip requires identical pitch and phase on each side."*
→ skin 鼓与 poly 鼓的 ups 必须始终相同。这不是可选项：双鼓对压要求两侧鼓距与相位完全一致（见 85 套准）。因此 ups 是整线级参数，不是单鼓参数。

## 2. 四层清单

### 2.1 Layer 1 · Body（鼓体层）——永不动

|||
|---|---|---|
|节圆直径|Ø882.0 mm @ NW 中面（周长 2,771 mm）|定义鼓距网格；NW 中面是包覆材料的中性面，只有在此面上量周长才能与芯长口径一致|
|鼓壳|估算 270 kg（J ≈ 52 kg·m²）|惯量决定轴选型；不可因规格改变|
|轴承|—|精度链基准|
|真空扇区|固定角度，与 ups 无关|换型不改扇区（源文件 P8：「No sector change at grade change」）|
|力矩电机 + 编码器|≥250 Nm 连续 / ≥600 Nm 峰值；≥23 bit 绝对值编码器|一套电机覆盖两个 ups（源文件 P12）|
|压合间隙|land-to-land 0.15–0.18 mm，限位 + 预压|与尺寸无关，靠 land 与限位结构保证|
|轴向对中（CD centring）|pattern 在所有宽度上居中对齐鼓面；100/110/120 共用同一轴向设定|CD 居中由 Body 保证，不由换件保证|
|镜像手|skin / poly 为同一本体、镜像手|保证同鼓距、同惯量、同跳动等级|
|风机 / 管路 / 胶模块|—|换型不改硬件（仅设定值变，见 Recipe）|

### 2.2 Layer 2 · Sleeve（尺寸载体层）——必换

|||
|---|---|---|
|数量|22 片 = 11 尺寸 × 2 侧（skin / poly）|源文件 P9|
|结构|pocket-and-land 浮雕；land 高 0.45 mm|详见 84|
|端区|也是 land（保证核间无 SAP）|源文件 P9|
|屏|Ø0.6–0.8 mm、30–40% 开孔、各 sleeve 一致|与 ups 无关（84 §4）|
|pattern 公差|±0.02 mm over 2,771 mm，全部 n 个节距|等节距 = 同一相位适配全部（源文件 P8）|
|承载体|pin + 锥面锁紧；≤15 min/鼓换装|源文件 P9|
|防错|sleeve ID tag，由 PLC 读取以阻止错误 ups 的 recipe|源文件 P9/P12/P18（详见 84 §7）|
|成对规则|skin/poly 必须成对设计（同一 CAD、同时制造）；凡需粘合的通道必须两侧同位置存在|源文件 P9|

每次换型更换：2 片（skin 1 + poly 1）。

### 2.3 Layer 3 · Recipe（配方层）——必改，无实体换件

|||
|---|---|---|
|ups n|6 或 7|尺寸（按 81 §6 分配表）|
|cams|凸轮 / 电子凸轮曲线（含 repitch 转塔每规格凸轮）|尺寸|
|fan|成型风机 VFD 速度设定（+ 保形风机、气刀）|尺寸（SAP 床阻随 gsm 变）|
|glue|胶分段阀开关（按 100/110/120 宽度族）+ 泵速跟随鼓面线速|尺寸（宽度 + 线速）|
|chute|SAP 落料速度（eductor 设定）396 或 462 m/s 级|ups（见 86，这是头号失效模式）|
|成型真空|逐段真空设定值（−8…−12 kPa 属 recipe 项）|尺寸（床高/床阻）|
|气刀压力|—|尺寸|

源文件 P12 的 Recipe 摘要（原文）：*"Recipe (sleeve ID-checked): ups n, cams, fan, glue, chute"*。
关键性质：Recipe 是纯软件/设定层——它的正确性由 sleeve ID 校验把关（防错联锁见 84 §7）。

### 2.4 Layer 4 · Change-part（换件层）——仅特定规格需要

||||
|---|---|---|---|
|SAP chute 宽度插片|100 / 110 / 120 mm|每次换宽度族时需要|源文件 P7/P18；B|
|刀片插片（knife insert）|仅 NB、S（需 chip 切）|仅换到/离开 NB/S 时需要|源文件 P6/P18；B|

源文件 P8 的「At grade change」双栏（原文归纳）：
Changes：2 sleeves (skin + poly) · SAP chute width insert · Recipe: ups, cams, fan, glue · Knife insert (NB, S only)
Stays：Drum bodies, bearings, sectors · Torque motors and encoders · Nip gap and axial alignment · Fans, ducts, glue modules

## 3. 归属判据（决策规则）

对任何一个「换型时会变化的量」，按以下顺序判定其层级——这解决了「哪些量该固化在哪个层级」的工程问题：

Q1. 换 ups 时它会变吗？
    ├─ 不变 → Layer 1 Body（永不动）
    └─ 变   → Q2

Q2. 它由「尺寸（MD 长度）」决定吗？
    ├─ 是 → Layer 2 Sleeve（实体换件）
    └─ 否 → Q3

Q3. 它只由「宽度族（CD 100/110/120）」或「边缘形状」决定吗？
    ├─ 是 → Layer 4 Change-part（宽度插片 / 刀片插片）
    └─ 否 → Q4

Q4. 它能否仅靠设定值（伺服/变频/阀）表达，无需更换实体件？
    ├─ 能 → Layer 3 Recipe
    └─ 不能 → 设计缺陷：应重新设计为 Recipe 或 Change-part

判据的工程含义：

- Q1 把「几何与相位」完全隔离在 Body —— 这是换型不需要重新对相（re-registration）的前提（源文件 P8：「Grade change without re-registration」依赖 sleeve 由 pin 定位到编码器零点 ±0.02 mm）。
- Q4 的「不能」分支是架构缺陷检测：任何「随尺寸变、又必须换实体件、且换起来很贵」的量，都是设计没做干净——应改造为设定值或廉价插片。
- 典型反面案例：若把 CD 宽度做进鼓体（而非 chute 插片），则 100/110/120 三档宽度需要三套鼓体 → 成本与换型时间失控。这正是 §4 要回答的问题。
## 4. 为什么 CD 变更走 chute 插片，而不是 ups / 鼓体

||||
|---|---|---|---|
|用 ups 解决 CD|—|不可能：P = πD/n 只作用于 MD 方向，与 CD 无关（源文件 P2：「3 widths — handled in CD, not by ups」）|✗|
|把 CD 做进鼓体|每宽度族一套鼓体|3 套鼓体 + 3 套扇区 + 3 套对中 → 与「单一鼓体」前提矛盾|✗|
|把 CD 做进 sleeve|22 片 → 33 片（11 尺寸 × 3 宽度 × …）|sleeve 数量爆炸；且 CD 与 MD 正交，混在一层会让换件规则复杂化|✗|
|chute 宽度插片|100/110/120 三档成型出口插片|最廉价、换装最快、且 CAD 上只改出口轮廓|✓（源文件采纳）|

支撑事实：

- 源文件 P2：芯宽 100 / 110 / 120 mm，"handled in CD, not by ups"。
- 源文件 P7：Servo rotary SAP valve + shaped chute — width insert 100/110/120。
- 源文件 P8：CD 居中由鼓体保证（Pattern centred on drum face for all widths — Same axial setting for 100/110/120）。
- 逻辑闭环：CD 由「鼓体对中 + chute 出口宽度插片」共同决定 → 鼓体只负责居中（不变），插片负责宽度（可换）→ 宽度族扩展的边际成本降到只剩一片插片。这是本架构最重要的成本设计。

## 6. 换型 SOP 四步（工时骨架）

⚠️ 范围说明：本节是骨架。完整的换型损失核算模板、完整 FMEA（含严重度/探测度）、KC 现场 WI 依据属 G3（中优先级，本次未执行）。此处只沉淀源文件 P18 已给出的内容。

||||||
|---|---|---|---|---|
|1|Stop & swap|skin 与 poly 两片 sleeve 并行更换，≤15 min；换 chute 插片；NB/S 换刀片插片|≤15 min|源文件 P18；B|
|2|Recipe load|先校验 sleeve ID → 载入 ups n、cams、fan、胶分段、chute 速度|源文件未给出|源文件 P18；B|
|3|Auto-phase|引脚给出 ±0.05 mm；相机闭环在 ~17 片内把 MD 修正到位|源文件未给出（含首件试跑）|源文件 P18；B|
|4|Verify|首件通道叠合 + 湿态粘接验证 → 放行|源文件未给出|源文件 P18；B|

总目标：< 30 min（源文件 P18 标题）。

⚠️ 时间账不闭合提示（本次发现）：Step 1 已占用 ≤15 min，Step 3 的收敛需 ~17 片（1,000 ppm 下约 1 s 生产时间，但含启停与验证则不止）。源文件未给出 Step 2–4 的工时分解，因此「<30 min」目前无法从分项加总验证。这是 G3 必须补齐的第一件事。

### Sleeve 换装工时（Layer 2 的实测基准）

|||
|---|---|---|
|单片 sleeve 换装|pin + 锥面，≤15 min/鼓|源文件 P9；B|
|两鼓并行|目标 ≤15 min（并行，不串行）|源文件 P18；B|
|对比：Nichidai 卡簧式换网|供应商目标 30 s 换网（经验待确认）|WKB [日本Nichdai 丝网工艺技术交流]；C|

⚠️ 需呈现的分歧：源文件的 sleeve 换装规格是 ≤15 min/鼓；WKB [日本Nichdai 丝网工艺技术交流] 记录供应商目标是 30 s 换网。两者差 30 倍，不可静默取其一。差异可能源于：换装对象不同（整片 sleeve 含承载体 vs 仅丝网）、换装内容不同（是否含对相与验证）、或供应商口径为「换网动作本身」不含外围。须向 Nichidai 澄清口径后再引用。

## 7. 变更控制红线（禁止固化到 Body 的量）

以下量绝不可做进 Body / 固定结构，否则规格扩展成本失控：

|||
|---|---|
|CD 宽度（100/110/120）|必须走 chute 插片（§4）；做进 Body 则每宽度一套鼓体|
|pattern 长度 / 端区分布|尺寸载体必须可换（sleeve）；做进 Body 则每尺寸一套鼓体|
|ups 相关的相位关系（n 脉冲）|必须由 Recipe 表达（SAP 转阀 e-cam = n 脉冲/转）；做进机械凸轮则每 ups 一套凸轮组|
|端区长度（随尺寸变）|属 sleeve；不可由固定挡块定义|
|换宽度族的涂布宽度|必须走分段阀 + 插片；不可用固定喷嘴|

反之，以下量必须固化在 Body（不可下放到 Sleeve/Recipe）：

|||
|---|---|
|真空扇区角度|源文件 P8：固定、与 ups 无关；下放会导致换型需改扇区|
|压合间隙与轴向对中|与尺寸无关；下放会引入每规格的间隙误差，破坏 land-to-land|
|编码器零点 / 引脚基准|换型不重新对相的前提（P8）|
|双鼓镜像手与同 ups 约束|对压要求两侧鼓距与相位一致（P4）|
