# 85-双层pattern芯体套准工程规格

补库来源：One_Drum_Two_Ups_11_Sizes_1000ppm.pptx P3/P4/P7/P9/P12/P14/P15/P17/P18
对应 Gap：G4（双层 pattern 套准公差链与 Cpk 体系缺失，主表标为最高优先级）｜严重程度 高｜属 P1 批次
副交付：G17（视觉闭环「相位微调」的控制规格）
主表改善建议：补充①MD/CD 套准公差及其与通道粘接面积的换算（≥90% 的依据）②公差链拆解 ③Cpk 目标与样本量 ④MD 可自纠/CD 需机械钉死的机理解释 ⑤视觉闭环相位控制规格
创建日期：2026-09-22

## 1. 为什么套准是本架构的质量门

本架构的芯体不是「一层 SAP + 一层包覆」，而是：

skin 侧鼓 → 沉积 skin SAP pattern ─┐
                                    ├─ 双鼓对压（land-to-land）→ 通道粘接
poly 侧鼓 → 沉积 poly SAP pattern ─┘

芯体的「通道」不是切出来的，而是两侧 land 对压粘出来的（源文件 P7：「raised lands bond channels in register」）。因此：

套准精度直接等于通道成型质量。 两层 pattern 一旦错位，land 与 land 不再正对 → 通道粘接面积下降 → 通道在润湿后（84 所强调的湿态）开胶 → 通道丧失导流功能。而通道一旦失效，本架构相对传统芯体的核心优势（湿态开孔、防凝胶阻塞）随之消失。

推论：套准是本架构中唯一一个「失效即架构失效」的质量门。这也是主表把它标为最高优先级 gap 的原因。

## 2. 规格定义

### 2.1 公差规格

||||

|---|---|---|---|

|MD（机器方向，沿鼓面周向）|`|MD| ≤ 1.0 mm`|保证 ≥90% 通道粘接面积|源文件 P14；B|

|CD（横向，沿鼓轴）|`|CD| ≤ 0.5 mm`|同上|源文件 P14；B|

### 2.2 ⚠️ 「≥90% 通道粘接面积」的换算——源文件未给出，本次重构

源文件只给出端点结论（公差 → ≥90%），未给出换算公式。以下为本次重构，供反验使用：

模型（线性重叠模型）：设 land 特征尺寸（CD 方向 = 通道宽 w；MD 方向 = 横向连接段长 l），偏移为 δ，则

重叠率 ≈ (特征尺寸 − |δ|) / 特征尺寸               …(1)

令重叠率 = 0.90（即容许 10% 面积损失），反解特征尺寸：

|||||

|---|---|---|---|

|CD|0.5 mm|w = 0.5 / 0.10 =5.0 mm|通道宽量级 ≈ 5 mm|

|MD|1.0 mm|l = 1.0 / 0.10 =10.0 mm|MD 方向 land 特征长量级 ≈ 10 mm|

⚠️ 等级与用法：本重构为推断，依据是式(1) 与「10% 面积损失」这一隐含判据。必须用 sleeve 图纸的实际几何（通道宽、横向连接段长、fishbone 骨架尺寸）反验：
- 若实际 land 特征尺寸与 5 mm / 10 mm 同量级 → 公差与 90% 判据自洽，可继续使用；
- 若显著不同 → 0.5 / 1.0 mm 公差必须重新推导，不得直接引用。

源文件 P1 提到 sleeve 为 fishbone（鱼骨形） 图案，其「骨宽 / 横肋长」正是式(1) 所需的特征尺寸。这是向 sleeve 供应商索取图纸时的新增必填项。

### 2.3 ⚠️ 两项易混指标的区分（防误引）

源文件 P14 同时给出两个数字，它们是不同的指标，不可互换：

|||||

|---|---|---|---|

|套准 in-spec 率|≥99.99%（两 ups；chute 未随 ups 重设时 92.7%）|套准偏差落入 `|MD|≤1.0 / |CD|≤0.5` 的片数占比|套准偏差（机械 + 控制）|

|Cpk|MD 2.43–2.49 / CD 1.39|套准分布的过程能力指数|同上|

|落点合格率（92.7%）|92.7%（仅当 chute 未随 ups 重设）|SAP 落点落入 pattern 的合格占比|chute 线速失配（见 86），不是机械套准问题|

关键区分：92.7% 的成因是 SAP 落料速度失配（86），与套准机械精度无关。不得把 92.7% 归因于套准精度不足。

## 3. 公差链拆解

### 3.1 误差源清单

|||||

|---|---|---|---|

|σ_pin|Sleeve 承载体定位（pin + 锥面）|±0.02 mm（源文件 P8，规格值）或 ±0.05 mm（源文件 P18，换型实操值）|⚠️ 口径冲突，见 84 §5.1|

|σ_pattern|Sleeve pattern 加工（n 个节距等距性）|±0.02 mm over 2,771 mm（源文件 P8）|已知（B）|

|σ_cam|视觉测量 / 闭环死区|±0.1 mm（源文件 P12/P18）|已知（B）|

|σ_mat|包覆材料 pitch 波动 / 张力波动|未量化|❌ 缺（主表 G12）|

|σ_thermal|热漂移（鼓温升、胶温、材料热收缩）|未量化（但包覆 140℃ 热收缩 ≤1%，见 86）|❌ 缺|

|σ_cd|CD 侧：鼓体对中 + sleeve 横向加工 + 装配|未量化|❌ 缺|

### 3.2 ⚠️ 由 Cpk 反解隐含误差 sigma（本次独立推导）

源文件未给误差 sigma（其 notes 明确说 "error sigmas are estimates to calibrate on a pilot rig"）。但可以从 Cpk 反解：

Cpk = USL / (3σ)        （若分布近似居中）
⇒ σ_implied = USL / (3 × Cpk)                     …(2)

||||||

|---|---|---|---|---|

|MD|6-up|1.0 mm|2.43|0.137 mm|

|MD|7-up|1.0 mm|2.49|0.134 mm|

|CD|6-up / 7-up|0.5 mm|1.39|0.120 mm|

推导出的三条结论：

- MD 与 CD 的 sigma 同量级（0.134 vs 0.120 mm），但 CD 的 Cpk 差得多（1.39 vs 2.43） —— 纯粹因为 CD 的 USL 只有 MD 的一半（0.5 vs 1.0 mm）。CD 是整线的约束项。
- Cpk CD 1.39 独立解释了源文件的「in-spec ≥99.99%」：

失效率 = 2 × [1 − Φ(USL/σ)] = 2 × [1 − Φ(0.5/0.120)] = 2 × [1 − Φ(4.167)] ≈ 3.1 × 10⁻⁵ = 31 ppm
→ in-spec ≈ 99.9969% ≥ 99.99% ✓

MD 侧 Cpk 2.43 → 失效率 ~10⁻¹³，可忽略。故 in-spec 率 100% 由 CD 决定。✅ 该反解与源文件结论自洽，构成对源文件数值的独立交叉验证。
- MD 侧的误差主要不来自相机死区：

σ_cam（±0.1 mm 均匀分布）= 0.1/√3 = 0.058 mm
σ_other = √(0.137² − 0.058²) = 0.124 mm  ← 远大于相机项

→ MD 残差的 82% 来自未量化的材料/张力/机械项，相机死区不是瓶颈。这直接说明：把相机升级为更高分辨率对套准几乎没有帮助；要改善 MD 必须去量化 σ_mat / σ_thermal。

等级：§3.2 全部为本次推导（基于式(2) 与源文件 Cpk 值），未实测。其价值在于给出「哪些误差源值得量化」的排序，而不是替代实测。

### 3.3 提高 Cpk CD 的量化目标（可直接写进设备协议）

||||

|---|---|---|

|1.39（当前）|0.120 mm|—|

|1.67|0.100 mm|−17%|

|2.00|0.083 mm|−31%|

通用验收口径常取 Cpk ≥ 1.67；若项目要求 Cpk ≥ 2.0，则 CD 机械链的合成误差须从 0.120 降到 0.083 mm（−31%）。这是本架构最硬的一条机械精度要求，应作为鼓体/承载体/sleeve 的公差分配起点。

|工况数|2（6-up、7-up）|源文件 P14|

⚠️ 实测样本量的空白：源文件的 20 万片是仿真样本量。实线验收所需的实测样本量未定义。 这是必须补的一项——Cpk 的置信区间依赖样本量：
- 常规做法：n ≥ 100 用于短期 Cpk（Cp/Cpk 的 90% 置信下限在 n=100 时约为点估计的 0.75 倍）；
- 若要在 Cpk 1.39 附近做判定，建议 n ≥ 125（使点估计与置信下限差 <0.25）；
- 换型后首件验证（83 §6 Step 4）只能用极小样本（首件 + 收敛后数片），不能据此计算 Cpk——只能做「通道叠合目视 + 湿态粘接」的属性判定。

要求：在验收 KPI 集（80 §6）中把 K2 的样本量补为「n ≥ 125，连续取样，覆盖两 ups 与至少 3 个尺寸」。等级：本次建议（推断），依据是 Cpk 置信区间的一般统计性质。

## 5. MD 可自纠 / CD 必须钉死——机理

### 5.1 现象（源文件 P14）

|||

|---|---|

|MD|「MD self-corrects in ~17 products (1 s)」 —— 可在约 17 片内自动收敛|

|CD|「CD must be pinned」 —— 必须在机械上钉死，无自纠|

### 5.2 机理解释（源文件未展开，以下为本次推导）

为什么 MD 可自纠：

- MD 偏差是「一个相位标量」。 鼓面圆周方向上，pattern 相对对侧 pattern 的 MD 偏差，对所有 n 个 pattern 是同一个相位偏置（前提：节距等距，见 84 §5.2）。因此只需修正一个标量即可对齐全部 n 个 pattern。
- 该标量可由伺服直接修正。 相位偏置可叠加在鼓轴传动上（源文件 P12：「Poly drum torque motor — 1/n rev per product + trim」）→ 纯软件修正，无需动硬件。
- 存在可观测的基准。 UV 相机可读 skin 侧（其胶含 UV 示踪剂，源文件 P17）→ 以 skin 侧为基准测 MD 偏差 → 闭环修正 poly 侧。
为什么 CD 不能自纠：

- CD 偏差是「一个轴向几何量」。 修正它需要改变 sleeve 相对鼓面的轴向坐标，或改变 pattern 的横向坐标——两者都是硬件属性，不是设定值。
- 不存在可伺服修正的自由度。 鼓沿轴线的位置由承载体锥面/端面机械定位，没有轴向伺服轴（源文件 P12 的轴清单中无轴向修正轴）。
- 视觉也不覆盖。 相机只测 MD 相位（源文件 P12：「phase trim → poly drum only」）。CD 是开环量。
- 因此 CD 只能靠三段机械链一次做对：鼓体对中（源文件 P8：100/110/120 共用同一轴向设定）→ 承载体定位 → sleeve 横向加工精度。

工程结论：CD 公差链是「一次做对、事后不可补救」的链路，因此必须：
(a) 作为sleeve 与鼓体的到货验收项（84 §9.1 A1/A2）；
(b) 在设计阶段预留收紧（§3.3 的 −17%~−31% 目标）；
(c) 视觉系统只做 MD 闭环，不要把 CD 的期望寄托在视觉升级上。

### 5.3 附带的重要推论：为何必须「只在 poly 侧 trim」

若两侧都做相位修正，则一个观测量（相机测得的相对 MD 偏差）对应两个自由度（两侧相位） → 解不唯一（可整体平移，无法收敛）。

固定 skin 侧为基准、只动 poly 侧，是把 2 个自由度降为 1 个的必要手段。这也是源文件 P12 只保留一条 phase trim → poly drum only 通路的原因。
等级：推断（基于控制可辨识性），但结论与源文件设计一致。

              └───────┬──────────────────────────────┬──────────────────┘

                      ▼                              ▼

                      │                             │
                      │ skin 侧胶含 UV 示踪剂        │ 相位偏置修正
                      ▼                             │
              ┌──────────────┐   MD 偏差 e         │

控制律（据规格反推）：

if |e| > deadband(0.1 mm):
    修正 poly 鼓相位偏置，使 e → 0
else:
    保持（死区内不动作，避免追噪声）

⚠️ 未给出的控制参数（须向供应商索取或自行整定）：
- 死区内的稳态残差：死区 ±0.1 mm 意味着理论残差可达 ±0.1 mm，但 §3.2 反解的 σ_MD = 0.137 mm > 0.058 mm（死区等效 σ），说明实际稳态由过程噪声支配，而非死区。→ 死区可适度放大（如 ±0.15 mm）而不显著恶化 Cpk，反而可减少执行机构动作频次（降低磨损）。等级：推断。
- 修正增益 / 积分时间 / 是否逐片修正还是每 k 片修正：未给出。
- 相机视野覆盖几个 pattern：未给出（影响 n 个 pattern 的平均 vs 单片测量）。
- 是否只在特定相位窗口采样（高速下曝光时间约束）：未给出。
- UV 示踪剂在 140–150℃ 施胶温度下的稳定性：未给出（源文件 P17 规定施胶 ≤150℃）。
