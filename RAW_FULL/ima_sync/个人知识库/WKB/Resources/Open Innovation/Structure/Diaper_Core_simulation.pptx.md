#   Cost Strategy

* N511 as Base

Largest volume (6.3g / 45%) uses cost-effective N511. Nuoer qualified supply = stable cost baseline.

$\bullet$ SAP1 Minimal Add

Only 2.7g SAP1 blended 30% with N511. Fast intake achieved without over-specifying expensive SAP1.

$\bullet$ SAP2 Front-Loaded

5.0g SAP2 concentrated in Zones A+B (3.0g) where rewet risk is highest. Reduces waste in rear zones.

$\bullet$ Zero Fluff Pulp

Fluffless core eliminates $0.02-0.04/diaper fluff cost. Thinner core = less packaging material.

* Zone B Priority

35%+ urine demand in Zone B — dense SAP placement here maximises ROI per gram of material.
