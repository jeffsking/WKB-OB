# 产品重量-STM00069

## MANU+ALIUKING

最新版本号：第2版

实验目的：这个测试方法用于测试样品的总重量。

测试前的准备：

1. 打开天平的电源，预热15分钟。

2. 检查天平的水平气泡是否在中心位置上。

3. 将天平清理干净。

样品的准备:

1. 从包装袋中取出合格的样品。

测试步骤：

1. 将天平清零。

2. 将尿裤放在天平上，确保尿裤的所有测试部位在天平的测试区域。

3. 待数字稳定后，读数。

4. 记录测试结果，保留到 0.01g。

操作注意事项：

1. 试样从包装中取出后，应尽快测试。

2. 不要随意移动天平。

操作安全：

1. 插拔电源时，小心触电。

# 产品厚度-STM00040

## JANVOTACTUINTU

最新版本号：第3版

实验目的：该方法用来测试样品在0.2PSI压力下，婴儿纸尿裤的厚度（mm）。

测试前的准备：

1. 打开厚度仪开关，确保降落过程中指示器（圆柱形）运动平稳。

2. 检查压块的位置，使其在测试区域的中心位置。

样品的准备：

1. 从包装袋中取合格的产品。

2. 去除产品的折页和大腿松紧带，使产品能够平整放置。注意不要剪切到吸收层，不要破坏其厚度。

测试步骤：

1. 踩住脚踏板使铜块抬起，清理测试台面及铜块底面。

2. 将厚度仪清零。

3. 踩住脚踏板使铜块抬起，将样品中心向前没有褶皱区域（使用面朝上）放于铜块下。使样品 MD 方向与基座保持水平。

4. 松开脚踏板，在铜块停止下落后等待3秒（数完1001, 1002, 1003）后记录读数（精确到0.01mm）；

5. 踩住脚踏板使铜块抬起，移走样品，将仪器复位。

操作注意事项：

1. 严禁随意按动测试仪上的按钮。

2. 所有制备的样品必须在1小时之内进行测试(从样品制备开始到测试结束);

操作安全：

插拔电源时，小心触电；

# 端封强度-STM00078

最新版本号：第6版

实验目的：该测试是使用拉力仪来测量尿裤外层与体侧层之间的端封和侧封的强度，用于判定胶量和粘合强度。峰值载荷值用 gf 单位表示。

测试前的准备：

1. 打开拉力仪，检查压力表。夹具的气压不能超过0.6Mpa。

2. 选择测试方法为STM-00078，调整夹具的距离为50.8mm

样品的准备：

1. 从包装袋中取出合格的产品。

2. 对样品进行标记。

3. 从侧封边打开产品。对于CD-Pants，将腰围用剪刀从芯体上剪下。

4. 如果使用切刀，伸展腰围放在切刀下。保证产品放在中心位置且平直。切下样品并拿走。

![- 2010:05:14\n](2/Oy0YFe4o874ND9Udefofxe/ppt_3867e2b60070d7dc3f413086d0b0036e_c4c4ead04d3838e3e7aab60902461089001a693ee6c0644e/tmp_zip_img/e7f82680-4236-4e6f-a971-351887872bc3.png)
如果使用手工剪切,则将产品放在灯箱上保证腰围伸展。用3英寸模具标记样品宽度,然后从灯箱上拿下产品,沿宽度线剪切100mm长度的样品。

5. 切取的样本宽度应该接近100mm长。

6. 小心去除REL填充物，不要刮到端封胶。

7. 设定拉力机的夹具和传感器：计量长度为2英寸，选择STM-00078 测试方法。

测试步骤:

1. 把样品的底膜层夹到上夹具上，样品的内侧面朝向操作者，体侧面夹到下夹具上，并且样品内部朝向检验员。

2. 外层与体侧层的分离边缘应该在上下夹具的中心位置。

3. 清零并开始测试。测试过程中如果发生滑动，重新取样测试

4. 记录下最大值，用 gf 表示。

操作注意事项：

1. 样品夹在夹具上的时候，与夹面平行，不能倾斜或者有皱褶。

操作安全:

1. 操作过程中佩戴防护手套及安全剪刀，防止划伤。

2. 操作时应佩戴护目镜、口罩及防护手套避免吸入绒毛和划伤。

紧急处理:

1. 拉力仪夹住手指时，请尽快使用另外一只手按急停按钮。

2. 如发生断电，设备无法运行，请联系实验室管理员处理，切勿自行检查电源。

3. 去掉芯体吸收物时，如不慎误入口鼻，请尽快使用清水处理。

4. 如被剪刀划伤，应立即使用医药箱包扎处理。

# 腰围皮筋张力-STM00400

最新版本号：第3版

实验目的：此测试用于测量产品的腰围皮筋张力。

测试前准备：

从包装袋中取出要测试的产品。打开拉力仪电源开关。

测试步骤：

取线上样品，静置0.5h后进行测试

1. 不要使用在腰围区域有缺陷可能会影响测试结果的产品。

2. 为张力测试仪配置好合适的器具和传感器。设置测量长度为100mm(上下测试杆间的中心距离)。

3. 在软件“我的模板”中选择所测产品尺寸所对应的命令。(M选择170mm; L及以上选择190mm)。腰围张力初始值(下图)输入产品松弛宽度即产品放松状态下顶部宽度。

9. 保留整数。

操作安全:

1. 插拨电源时，小心触电。

2. 如遇紧急情况，拍下急停按钮。

3. 仪器测试过程中，请勿靠近。

紧急处理:

1. 如遇异常情况，先拍下急停按钮，再做其他处理。

5. 将产品套在上端测试杆上，归零 load 和 crosshead。此步可以从测试结果中扣除产品重量。

7. 点击开始。

8. 当 crosshead 归零时，拿走产品并记录平均值。

# 折页皮筋张力-STM00070

最新版本号：第4版

实验目的：测试婴儿纸尿裤腿部，折页和腰部松紧带在 90%伸长度下进行的拉伸强度测试。测试结果单位用 gf 表示。

测试前的准备：

1. 打开仪器开关，调整单位为“千克”，状态为“C”，按下“ZERO按钮将仪器回零；

2. 检查上下夹子边缘是否平行，不平行时需要进行调整。

3. 将校准杆置于上下夹具中心位置，调整夹具距离。

|松紧位置|校准杆长度 mm|
|---|---|
|折页|90|


4. 将上夹具移至所需的近似高度，将标杆放到两个夹具之间，再轻轻调整旋钮将上夹具 调至最终所需的位置：（微调时不要施加过大的力，以免破坏拉力仪的载荷）

5. 准备一块秒表。

样品的准备:

取线上样品，静置0.5-1h后进行测试。

从包装袋中取合格的产品，标记产品前后左右（所有涉及前后左右均为穿戴方向）。

1. 将体侧层朝外，后端向上，垂直挂在灯箱上，确保腰部松紧带完全拉伸。

2. 手指轻轻过松紧带。将1000g的双配重夹夹在腰部中心位置，不要夹到绒毛上。

3. 手指再一次轻轻过松紧带，确定腰部松紧带是完全拉伸的。

4. 将 p. o.12329887 模具放于测试侧折页松紧带的 MD 中心位置(目测),并用笔在模具 100mm 四槽处做记号。

5. 移走模块，用直尺在上下标记线以外各量取13mm并做上记号作为剪切处。

6. 将配重夹从产品上取下，用剪刀沿着折页和粘合线之间剪下测试区，取下样品，立刻测试样品，

测试步骤：

1. 将准备好的样品一端夹在上夹具上，样品居中，夹具夹在样品的划线上（标记线刚好能看见，一半在夹具内，一半在夹具外），使样品呈自由悬挂状态，按下“ZERO”按钮，将试样的重量归零；

2. 将仪器的下夹具轻轻向上抬起，将样品的另一端夹在下夹具上，同样夹具夹在样品的划线上，确认松紧带在竖直方向被拉直且不会被拉出角度；

3. 将下夹具轻轻放下时，立即开始计时。

4. 到测试所要求的时间后立即记录读数，将所记录的读数乘以 1000 计为最终结果，单位：“gf”；

5. 将下夹具轻轻抬起，将样品从夹具上取下，将仪器复位。

### 操作注意事项：

1. 校准时，旋动粗调旋钮时要轻而慢，避免仪器受力过大而损坏传感器；

2. 放下下夹具时要轻，以免损坏仪器；

3. 仪器上的按键严禁随意按动；

上述方法中，所说的前、后、左、右均指尿裤穿着时的方位；

5. 做好标记的样品必须在1小时之内进行测试。

6. 使用模块画标记线时，要一笔画完，严禁来回画线。

## 操作安全:

1. 插拔电源时，小心触电：

2. 将样品夹在夹具上时应小心，避免夹手；

3. 当往悬挂在灯紧急箱上的尿裤上夹 1000 克配重夹时，脚不要放在重物之下，以免重物落下砸伤脚；

4. 使用剪刀裁割样品时，注意手指的安全。

## 紧急处理:

如被剪刀划伤，应立即使用医药箱包扎处理。

# 弧形皮筋张力-STM00686

最新版本号：第0版

实验目的：测试婴儿成长裤弧形皮筋在90%伸长度下进行的拉伸强度测试，结果用 gf表示。

测试前的准备：

1. 打开仪器开关, 预热, 调整单位为“千克”, 状态为“C”, 按下‘ZERO’按钮将仪器回零;

2. 检查上下夹子边缘是否平行，不平行时需要进行调整；检查上下夹子内的橡胶垫块是否缺失，若缺失请及时更换夹子；

3. 将校准杆置于上下夹具中心位置，调整夹具距离：

|松紧位置|校准杆长度 mm|
|---|---|
|前端(左右)|99|
|后端(左右)|144|


4. 通过调节仪器粗旋钮将上夹具移至所需的近似高度，将校准杆放到两个夹具之间，再轻轻调整微旋钮将上夹具调至最终所需的位置：（微调时不要施加过大的力，以免破坏拉力仪的载荷）：

5. 准备一块秒表。

样品的准备：

取线上样品，静置0.5-1h后进行测试。

从包装袋中取合格的产品，标记产品前后左右（所有涉及前后左右均为穿戴方向）：

1. 去除芯体和外层，不要破坏腰围。

2. 沿CD方向在前、后弧形腿部皮筋之间将腰围一分为二。

3. 在倒数第五根与第六根腰围皮筋之间标出剪切线。

4. 修剪多余的腰围材料,沿MD方向分别将前、后弧形腿部皮筋一分为二,共4个样品。

5. 在最底部腰围皮筋与弧形腿部皮筋交叉处对样本标识。

6. 将标识好的样品悬挂在灯箱上，用150g配重夹拉伸，分别量取：前端弧形皮筋110mm，后端弧形皮筋160mm，取下测试样品立刻测试。

|松紧位置|弧形腿部皮筋量取长度|
|---|---|
|前端(左右)|110 mm|
|后端(左右)|160mm|


测试步驟:

1. 将样品最底部腰围皮筋与弧形腿部皮筋交叉处的一端夹在上夹具上，样品居中，夹具夹在样品的划线上（标记线刚好能看见，一半在夹具内，一半在夹具外），使样品呈自由悬挂状态，按下“ZERO”按钮，将试样的重量归零；

2. 将仪器的下夹具轻轻向上抬起,将样品的另一端夹在下夹具上,同样夹具夹在样品的划线上,确认皮筋在竖直方向被拉直且不会被拉出角度;

3. 将下夹具轻轻放下时，立即开始计时。

|松紧部位|时间|

1. 滤纸在23℃, 50%湿度恒温恒湿处理16后重量保持稳定, 可将重量稳定后的滤纸置于自封袋中密封保存备用。回渗吸收滤纸: 10张/片; 滲漏吸收滤纸: 3张/片。

2. 设备处于水平状态，主机与面板连接。确认接入气源，气源压力0.4MPa-0.6MPa。

3. 清洁天平，保持干净无杂物（天平最大量程300g）。

4. 0.9%生理盐水，润洗储液仓。

5. 闭合蠕动泵，润洗直至出液口出现连续线状液体（确保管道内充满液体）。

6. 根据产品型号选择对应型号的U型底座、支架、标准测试加液模块和标准测试加压模块。

1. 流量校准：加液量偏差满足±2mL

① 选择“系统管理”，进入“设备调试”，选择当前测试产品型号，并填入对应的加液量，点击“蠕动泵启动”读取出液体积，加液偏差满足±2mL：

② 加液量偏差超出±2mL, 进入“设备校准”, 选择“流量校准”, 调整每转出液量, 此时不点击蠕动泵启动(原则: 加液量低, 出液量往低调; 加液量高, 出液量往高调), 返回“设备调试”点击“蠕动泵启动”读取出液体积, 直至加液偏差满足±2mL。

1. 设备异常时,多次拍下急停按钮,确保急停已拍下,旋起急停按钮,点击复位,如果压头处于被夹持状态,请用网篮按住压头,再在“设备调试”界面松开夹爪。

2. 如遇紧急情况压手,先多次拍下急停按钮,确保急停按下,选择参数设置,长按参数设置上万5秒,进入参数设置界面,选择Z轴复位,如无法进入参数设置界面,关机重启后再进入,选择Z轴复位,再旋起急停按钮,在界面点击复位即可。(和设备复位操作不一样,直接旋起急停,防止造成二次伤害。)

3. 如溶液误入眼中, 请到实验室水池旁, 使用洗眼器清洗眼部, 并尽快就医。

4. 如溶液误入口中, 请用清水漱口, 必要时及时就医。

# 待判定处理

属性 NG:

如果缺陷出现在多个时间段，则整个检验周期内的产品需全部扣留。如果缺陷出现在某一个时间段，则由操作团队根据产生缺陷产品的时间，以产生缺陷的时间为中心，分别向两端延伸检查产品，直至将不合格产品全部找出并扣留。扣留产品由在线检验员每 10min 产品抽检 50 片进行检查，若抽检结果满足安全 0%；功能≤1%；外观≤7%的比例，则判为放行，否则返工或拒收。

变量 NG:

按时间顺序分子批再检，先每30min为大子批，每个子批至少抽5个样本，检测发现合格的大子批可放行，至少有1个变量不合格的大子批继续扣留，待全部锁定具体问题时间段后，每10min为小子批，每个子批至少抽检5个样本，则每个子批中只要抽检到1个样本不合格则继续扣留，评估是否需要进一步分子批，精准追溯问题产品区间。

包装 NG:

对检验过程中发现的缺陷包装进行返工处理。

# 仪器校验

天平

校验操作：

1. 打开天平预热15分钟

2. 确定天平是干净和水平的

3. 清洁标准砝码

4. 按"ZERO"键，使读数为零

5. 戴手套或使用镊子拿取标准砝码至天平中央，待其读数稳定后记录数据

6. 重复4-5步至所需校验的不同重量的砝码均称重完成

7. 如果读数超出范围，请及时通知负责人

注意事项：

1. 不要直接用手取砝码，请戴手套

2. 校验前清洁天平托盘，保证天平水平

厚度仪

校验操作：

1. 打开设备，擦净厚度仪基座

2. 调整测量单位为mm，按“ZERO”键清零

3. 升起脚踏板，将1.00mm的厚度块放到铜块正下方中心

4. 松开脚踏板，使铜块慢慢落下，记录仪表的读数

5. 重复步骤3-4，完成5.00mm和10.00mm的厚度块的校准

注意事项：

1. 不要直接用手取厚度块，请戴手套

2. 校验前清洁基座
