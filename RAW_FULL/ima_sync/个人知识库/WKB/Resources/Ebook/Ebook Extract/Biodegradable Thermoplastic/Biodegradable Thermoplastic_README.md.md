## 核心发现摘要

- 研究主题：以聚L-乳酸（PLLA）为硬段的三嵌段共聚物型生物可降解热塑性弹性体（TPE）
- 合成策略：两端带羟基的软段聚合物 → 大分子引发剂 → 丙交酯开环聚合
- 全生物可降解软段：PEG, PDXO, PTMC, PIP, PM, PMCL, P(CL-r-DLLA)
- 部分生物可降解软段：PIB, PDMS
- 最优性能：作者团队的 PLLA-b-P(DLLA-r-CL)-b-PLLA (Sample 8, 75-600-75) 断裂伸长率达 2800%
- 关键发现：形貌（spherical/cylindrical/lamellar）与力学性能的对应关系
