# Biodegradable Thermoplastic Elastomer — 学术深度拆解报告

论文原文: Nakayama Y., Shiono T. "Synthesis of Biodegradable Thermoplastic Elastomers"
生分解性を有する熱可塑性エラストマーの合成
*日本ゴム協会誌*（Journal of Japan Rubber Association）, Vol.85, No.7, pp.229–233, 2012
広島大学大学院工学研究院物質化学工学部門

## 执行摘要（Executive Summary）

本文是一篇综述型学术论文，由广岛大学中山祐正（Yuushou Nakayama）与盐野毅（Takeshi Shiono）撰写，系统回顾了以聚乳酸（poly(lactide), PLA）为硬段（hard segment）的三嵌段共聚物（triblock copolymer）型生物可降解热塑性弹性体（biodegradable thermoplastic elastomer）的合成策略与性能。文章涵盖全生物可降解与部分生物可降解两类体系，梳理了多种软段（soft segment）材料（PEG, PDXO, PTMC, PIP, PM, PMCL, P(CL-r-DLLA), PIB, PDMS）的引入及其对弹性体性能的影响。本文最突出的实验成果来自作者团队自身工作：以 P(CL-r-DLLA) 为软段合成的 PLLA-b-P(DLLA-r-CL)-b-PLLA 三嵌段共聚物中，Sample 8（75-600-75）在断裂伸长率上达到 2800%，为当时已知基于 PLLA 的 TPE 中最高值。

## 一、宏观解读

### 1.1 核心论题

本综述聚焦于 以聚L-乳酸（PLLA）为硬段、以低玻璃化转变温度（low Tg）聚合物为软段 的三嵌段共聚物（PLA-b-(soft segment)-b-PLA），通过开环聚合（ring-opening polymerization）方法合成生物可降解热塑性弹性体。

### 1.2 研究方法

综述型论文，不涉及原创实验。作者按以下逻辑结构组织文献：
- 全生物可降解共聚体（Section 2）：软段本身也可降解（PEG, PDXO, PTMC, PIP, PM, PMCL, P(CL-r-DLLA)）
- 部分生物可降解共聚体（Section 3）：软段不可降解（PIB, PDMS）
- 实验数据主要来自引用文献及作者自身研究（ref. 17, 18）

### 1.3 主要结论

- 利用两端带羟基的软段聚合物作为大分子引发剂（macromolecular initiator），进行乳酸丙交酯（lactide）的开环聚合，是合成此类三嵌段共聚物的高效通用策略。
- 弹性体的物理性能取决于软段类型、组成、分子量等因素。
- 通过合理设计软段组成（如 CL:DLA = 70:30 的无规共聚物），可以获得无定形、低 Tg 的理想软段。
- 该领域仍有待优化的方向：耐热性提升与成本降低。
## 二、段落级拆解

### 2.1 绪言（Section 1）

核心内容：介绍聚乳酸（PLA）的背景、性质与局限，引出热塑性弹性体（TPE）的概念。

- PLA 源自植物，具生分解性，是环境友好高分子材料。
- PLA 通过丙交酯（lactide）的开环聚合合成；PLLA（L-丙交酯来源）为结晶性，PDLLA（外消旋）为非晶性。
- PLLA 与 PDLA 混合可形成立构复合晶体（stereocomplex crystal, sc-PLA），熔点从 170°C 升至 230°C。
- PLLA 的缺点：硬而脆、耐热性较低。
- TPE 由柔性软段（soft segment）与防止塑性变形的硬段（hard segment）构成，常温下呈橡胶弹性，加热后可熔融加工。

### 2.2 完全生分解性共重合体（Section 2）

#### 2.2.1 PLLA-b-PEG-b-PLLA 体系

- Mohammadi-Rovshandeh 等以 PEG 为引发剂开环聚合 LLA，合成 PEG 含量 27–57% 的三嵌段。
- 三嵌段共聚物热分解温度高于 PEG 均聚物，PLLA 段对 PEG 起稳定化作用。
- 吸水率随 PEG 含量增加而上升，57% PEG 时吸水率达 82%，亲水性极高。
#### 2.2.2 PLLA-b-PDXO-b-PLLA 体系

- 以 1,5-dioxepan-2-one (DXO) 开环聚合得非晶性 PDXO 段，再继续开环聚合 LLA。
- LLA 含量 7–27% 范围内合成，≥11% LLA 时呈半结晶性。
- Tg ≈ −33°C（几乎不随组成变化）；Tm 和 ΔHm 随 LLA 含量增加而上升。
- WAXS 证实晶区结构与均聚 PLLA 相同。
#### 2.2.3 PLLA-b-PTMC-b-PLLA 体系（Feijen 等）

- PTMC 低 Tg、柔软，适用于再生医疗支架，但耐蠕变差。
- PLLA-b-PTMC-b-PLLA 及 PDLA-b-PTMC-b-PDLA 在 PLA 段足够长结晶时表现出 TPE 行为。
- 两者共混可形成 sc-PLA，拉伸性能与蠕变抗性俱优。
#### 2.2.4 PLLA-b-PIP-b-PLLA 体系（Hillmyer 等）

- 以烷氧基锂引发的异戊二烯聚合，经环氧乙烷封端/脱保护制得 HO-PIP-OH。
- 以此为大分子引发剂，以 Et₃Al 或 Al(OiPr)₃ 为催化剂聚合 DLLA。
- SAXS 显示三种形貌（spherical, cylindrical, lamella）。
- cylindrical 形貌样品断裂伸长率达 650%；spherical 形貌弹性恢复最优。
#### 2.2.5 PLLA-b-PM-b-PLLA 体系（Hillmyer 等）

- (−)-Menthone 经 Baeyer-Villiger 氧化制 (−)-menthide，再开环聚合成 PM（Tg = −25°C）。
- 以 DEG 引发、ZnEt₂ 催化合成 HO-PM-OH，再以 AlEt₃ 催化聚合 DLLA。
- SAXS 与 DSC 确认微相分离。
- 断裂伸长率达 960%，弹性恢复良好。
- 通过添加粘着剂可赋予压敏胶功能。
#### 2.2.6 PLLA-b-PMCL-b-PLLA 体系（Hillmyer 等）

- 2-甲基环己酮经 Baeyer-Villiger 氧化得 6-methyl-ε-caprolactone。
- 二甘醇存在下 Sn(Oct)₂ 催化开环聚合，得 HO-PMCL-OH。
- 以 Sn(Oct)₂ 催化聚合 DLLA 得三嵌段共聚物。
- 两个 Tg（如 −43 和 50°C）表明相分离。
- 断裂伸长率高达 ~1900%，恢复特性优异。
#### 2.2.7 PLLA-b-P(CL-r-DLLA)-b-PLLA 体系（作者团队，ref. 17, 18）

- 软段设计：ε-CL 均聚物为半结晶（Tg = −60°C, Tm = 60°C），不适合直接做软段。
- 将 CL 与 DLLA 共聚合（Sn(Oct)₂ 催化，DEG 引发），当 CL:DLA = 70:30 时得到无定形、低 Tg 共聚物。
- 以 HO-P(CL-r-DLLA)-OH 为大分子引发剂，开环聚合 LLA 得三嵌段。
- Table 3：系统展示了 H-S-H（硬段-软段-硬段）组成对 Tg、Tm、ΔHm 的影响。
- Table 4：力学性能随 LLA 组成比增加，弹性模量上升、断裂伸长率下降。
- 最佳样品 Sample 8 (75-600-75)：断裂伸长率 2800 ± 200%，为已知 PLLA 基 TPE 中最高。
- 循环试验（10–65% 应变，20 次）残留应变仅 11.1%。
### 2.3 部分生分解性共重合体（Section 3）

#### 2.3.1 PLLA-b-PIB-b-PLLA

- 以金属钾对 HO-PIB-OH (Mn = 7400) 进行阴离子化，生成的钾醇盐作为大分子引发剂，阴离子聚合 LLA。
- 产物 Mn = 20000，呈现两个 Tg（−69°C 和 45°C），TEM 确认微相分离。
#### 2.3.2 PLLA-b-PDMS-b-PLLA

- 以端羟基 PDMS 为大分子引发剂，Sn(Oct)₂ 催化 LLA 开环聚合。
- 分子量、Tg、Tm、熔融热随 PDMS/LLA 比降低而下降。
- PDMS 引入可提高热分解温度。
### 2.4 まとめ（Section 4 — 总结）

- 以 PLA 为硬段的多种三嵌段 TPE 已被报告。
- 通用合成策略：低 Tg、非晶性、两端带羟基的聚合物 → 大分子引发剂 → LLA 开环聚合。
- 性能取决于软段种类、组成、分子量。
- 未来方向：耐热性提升、成本降低。
## 三、核心概念深挖

### 3.1 Biodegradable Thermoplastic Elastomer（生物可降解热塑性弹性体）

- 定义：一类兼具橡胶弹性（常温）和热塑性加工性（加热后熔融流动）的聚合物材料，同时具有生物降解性。
- 结构基础：三嵌段共聚物 A-B-A 型，其中 A 段为硬段（crystallizable, 提供物理交联），B 段为软段（low Tg, 提供弹性）。
- 降解机制：PLA 在堆肥或自然环境中通过水解降解；软段若是 PEG、PTMC 等也可降解；PIB、PDMS 则不可降解，归为"部分生物可降解"。
### 3.2 Hard Segment（硬段）与 Soft Segment（软段）

- Hard Segment：通常是半结晶性聚合物（如 PLLA, Tg ≈ 55°C, Tm ≈ 170°C），在常温下形成微晶区，作为物理交联点阻止塑性流动。
- Soft Segment：低 Tg 的非晶性聚合物，提供橡胶弹性和高链段运动性。本综述涉及的软段涵盖 Tg 从 −120°C（PDMS）到 −20°C（PTMC）。
### 3.3 Triblock Copolymer（三嵌段共聚物）

- A-B-A 结构：两个相同硬段（A = PLA）夹一个软段（B）。
- 合成方法：以两端带羟基的软段聚合物作为大分子引发剂（macromolecular initiator），催化开环聚合丙交酯。
- 微相分离：硬段与软段热力学不相容，自发形成微区（micelles），SAXS 可观测到 spherical、cylindrical、lamellar 等形貌。
### 3.4 Ring-Opening Polymerization（开环聚合）

- 丙交酯（lactide, 乳酸的环状二聚体）在金属催化剂（Sn(Oct)₂, ZnEt₂, AlEt₃, Al(OiPr)₃, Baeyer-Villiger 氧化产物等）作用下开环，增长链端为羟基或醇盐。
- 催化剂选择对分子量控制和嵌段纯度至关重要。
### 3.5 Stereocomplex Crystal（立构复合晶体, sc-PLA）

- PLLA 与 PDLA 分子间形成更强的间作用力，形成熔点更高的晶体（Tm = 230°C vs. 170°C）。
- 在 PLLA-b-PTMC-b-PLLA 与 PDLA-b-PTMC-b-PDLA 的共混体系中可形成 sc-PLA，赋予优异拉伸性能和蠕变抗性。
### 3.6 大分子引发剂策略（Macromolecular Initiator Strategy）

- 软段聚合物的两端保留活性官能团（如 −OH），直接作为引发剂参与硬段的开环聚合。
- 优势：分子量可控（由单体/引发剂比决定），结构清晰，嵌段组成可调。
