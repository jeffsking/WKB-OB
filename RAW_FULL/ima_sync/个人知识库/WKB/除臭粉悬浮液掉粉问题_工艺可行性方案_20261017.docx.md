# 除臭粉悬浮液掉粉问题_工艺可行性方案_20261017.docx

亲水油剂悬浮液干燥后掉粉问题——工艺可行性方案
项目：OI-09 / OI-18（除臭粉悬浮液施加于 Outer Cover 底膜侧热风无纺布） 问题：除臭粉悬浮液经亲水油剂施加后，烘干前有一定粘附、完全烘干后粉体全部脱落，与无纺布无连接力，去味效果失效（10/17 小样实测）。 版本：V1 ｜ 2026-10-17

一、问题根因分析
根因
说明
证据依据
粉体对纤维无固有亲和力
颜料/粉体类颗粒对纤维几乎没有“纤维亲和性”，必须靠粘结剂树脂（binder）在干燥、热固化过程中固定在纤维表面
Handbook of Nonwovens：pigments have little fibre substantivity, applied along with a suitable binder resin
亲水油剂干态无锚定能力
油剂提供亲水/润湿功能，干燥后不形成粘结膜，粉体只是“物理堆在表面”，水分蒸发后失去支撑即脱落
10/17 小样：带水时粘在布上、烘干后全部掉下
热风布蓬松三维结构
蓬松度 3–5 cm³/g，助剂呈“表层浓、内部稀”梯度，粉体集中在表面而非嵌入纤维间，接触锚点少
Biocare v3 工艺文档：热风布特有约束
悬浮液体系本质
悬浮液靠液体载体上布，溶剂蒸发后颗粒间及颗粒-纤维间无连接相
中科反馈：完全水溶/油溶均不可行，只能走悬浮液
结论：不是“浓度不够”或“烘干过度”问题，而是体系里缺一个“干燥后把粉体锚定在纤维上”的粘结相。行业先例（纳米竹炭、沸石脱臭滤材、纳米氧化铝涂层等）均使用 binder 或化学偶联解决。

二、必须遵守的工艺约束（决定方案形态）
施加位置必须在成布之后：热风粘合烘箱 Zone 1 128–132℃、Zone 2 138–143℃，悬浮液/活性物不能在线与热风粘合同区；若在线须后段低温区或改离线整理
避免高压压辊：热风布蓬松怕压，排除浸渍/压榨式，优先非接触或低接触工艺（吻涂/无接触喷涂/泡沫施加）
面层克重薄：商用面层 12–25 gsm，载体容量有限，必须低 add-on、高效率
均匀性：热风布三维结构导致“表层浓、内部稀”，需雾化/泡沫类可渗透施加方式，必要时底部真空抽吸辅助渗透
除臭粉为无机矿物粉，耐温性无虞：干燥固化窗口可放宽到 80–120℃（若未来换活性物则回退 ≤65℃）
亲水性必须保持：多亲油剂体系多次吸收快、回渗量低，是纸尿裤面层的主流方向，任何粘结方案不得破坏多次亲水性能

三、工艺路线比选（五条路线）
路线 A：配方端引入粘结剂（binder）——主推
做法：悬浮液配方升级为“分散剂 + 水性 binder + 增稠剂 + 除臭粉”，一次施加，干燥时 binder 固化成膜把粉体锚定在纤维表面。
配方先例（纳米氧化铝涂覆无纺布专利）：分散剂 SN5040 + 增稠剂 CMC1220 + 分子量 7–20 万、固含量 45% 水性丙烯酸树脂，配浆后线棒涂布、五级悬浮烘箱 100–105℃ 烘干
binder 可选池：水性丙烯酸树脂、PVOH/PVA、EVA、SBR；或天然基（淀粉、糊精、瓜尔胶），低用量即可（喷雾施加先例：粘合剂液滴 20–30 μm，少量即可把纳米颗粒与纤维粘结）
用量控制要点：binder 太少锚不住，太多会包埋粉体（降低除臭效率）并堵塞孔隙（降低透气）——沸石脱臭滤材专利明确提示了这两个失效模式，建议 binder 固含从 1–3% 起做梯度
施加方式：泡沫施加 / 无接触转子喷涂 / 吻涂三选一（与热风布约束匹配），避免压辊
优点：改动最小（只改配方），一次施加不增加工序；有大量行业先例。 风险：binder 增加体系粘度 → 喷嘴堵塞风险上升；手感变硬（binder 胶感）需选软性树脂（Handbook 明确提示 binder 会劣化手感，软性 binder 树脂是发展方向）。
路线 B：泡沫涂布（foam coating）——针对透气与效率的升级版
做法：把“粉体 + binder”打成泡沫后施加，泡沫破裂后 binder 在纤维交叉点成膜、粉体被锚定且大部分表面裸露。
沸石脱臭滤材专利（KR20000000187A）：传统“沸石粉 + 低熔点树脂粉末浸渍”存在两个问题——binder 部分包埋脱臭剂使效率下降、binder/粉体覆盖表面堵塞孔隙使透气性下降；改用泡沫涂布在滤材表面形成树脂泡沫层直接粘附脱臭剂，同时保持脱臭剂比表面积与透气性
泡沫施加同时是 Biocare 工艺族谱中适配热风布的三选一工艺之一（可渗透蓬松三维结构）
优点：低带液量、可渗透热风布、干燥后开孔结构不堵气；直接对标本项目“既要锚定又要透气又要除臭”的三重要求。 风险：泡沫稳定性与发泡比需调试；设备门槛（发泡机 + 泡沫施加头）。
路线 C：双层施加（先粉后胶 / 先胶后粉）——防包埋
做法：把“粉体施加”与“binder 施加”分成两步，避免粉体被 binder 完全包埋。
行业先例（纳米颗粒保留于无纺布的美国专利 20230323055）：binder 在纳米颗粒沉积之前或之后喷洒均可，粘合剂液滴 20–30 μm 增加渗透深度，可底部负压辅助渗透；binder 可自交联（干燥时热激活）
具体两种排布：
先喷含粉悬浮液 → 轻度预干 → 再喷低用量 binder 雾 → 固化（粉体表面不被包埋）
先喷极薄 binder 底涂 → 再喷含粉悬浮液 → 固化（粉体锚在底涂膜上）
优点：锚定效率高、粉体裸露率高；与路线 A 可互为对照实验。 风险：多一道工序、两个干燥段；产线占地与节拍成本。
路线 D：硅烷偶联剂化学锚定——最耐久、可作为进阶
做法：引入硅烷偶联剂/硅烷 binder，化学键把粉体锚定在纤维表面，而非物理粘附。
催化滤网行业案例（湖北师大，2026）：硅烷官能团“分子桥梁”——一端与基材表面羟基化学键合、一端绑定催化颗粒，解决催化涂层长期掉粉/脱落问题；可直接嵌入现有喷涂工艺，无需大幅改造产线
PP 无纺布已有先例（KR20220147221A）：咪唑-磺酰基硅烷 binder 0.5 wt% + 复合金属纳米颗粒 + 氨基酸，PP 纺粘布浸渍（pickup 50–150%），80–120℃ 干燥固化 1–10 min 完成锚定
注意：PP/PE 纤维表面无羟基，硅烷“一端键合纤维”的前提不成立，需先做表面活化（电晕/等离子/UV 接枝）或选择可与聚烯烃作用的改性硅烷体系——这一步需要中科一然或专业助剂商验证。
优点：耐气流冲刷、耐湿、长效不脱粉；化学键结合，是根治方案。 风险：PP 表面活化是技术不确定点；助剂成本与合规（皮肤接触产品需做安全评估）。
路线 E：胶体化/粒径再降——物理自锚定，最轻量
做法：把“悬浮液”做成“胶体分散液”（粒径降到胶体尺度），干燥时颗粒间毛细力/范德华力自聚集，在纤维表面形成自支撑多孔薄层。
美国专利 US7879350（胶体纳米颗粒除臭）：胶体纳米颗粒可直接涂覆于吸收制品面层（bodyside liner），涂层厚度 &lt;1 μm（2–500 nm），即使约 100% 面积覆盖仍保持基材多孔透气；固含量 add-on 0.001%–20%
与本项目现状的衔接：中科已反馈“悬浮液粒径已做得很低”——若能进一步降到胶体尺度并配合分散剂/表面张力调节，可能不依赖 binder 也能自锚定
优点：不引入粘结剂，手感/透气几乎不受影响，无喷嘴堵塞增量风险。 风险：对粒径分布和分散稳定性要求极高（Biocare 风险登记明确：粉体在乳液中的稳定性是高风险项，需 d90 与储存稳定性数据）；干燥工艺窗口窄。
兜底路线 F：湿态复合夹粉（物理锁定）
做法：含粉悬浮液施加后不彻底烘干，趁湿与底膜（film）复合压合，粉体被“夹”在纤维层与膜之间，由复合工艺物理锁定。
依据：原方案本就把除臭粉设计在底膜侧、利用膜阻挡防掉粉；干式复合用低熔粘合 web（coPET/TPU）或挤出复合可做强固结
注意：复合后需验证透气（MVTR）与克重增加
优点：完全绕开粘结剂与掉粉问题。 风险：改变材料结构、影响透气与柔软度；与现有卷材供应链/复合工位耦合，排产约束大。

四、推荐方案（组合拳，按优先级）
第一阶段（立即做，1–2 周）：配方改造 + 小样筛选
由中科一然在悬浮液配方中引入 低用量水性 binder（丙烯酸/PVOH 类，固含 1–3% 起梯度），配套分散剂与增稠剂（参照纳米氧化铝涂覆配方先例）
同步制备“无 binder 胶体化小样”（路线 E）作为对照——验证“粒径降到胶体尺度后能否自锚定”
小样测试矩阵：粉体粒径 × binder 类型 × binder 用量 × 烘干温度（80/100/120℃），用摩擦/跌落/气流法测掉粉率
掉粉率达标线：干态摩擦与跌落测试无明显粉体脱落（可参照 Taber 磨损、气流暴露、称重法建立基线）
第二阶段（3–4 周）：上机工艺窗口验证
施加方式选择：泡沫施加或无接触喷涂（避免压辊），必要时底部真空辅助渗透
位置确认：成布后离线整理段施加（绕开热风粘合高温区），干燥固化 80–120℃ × 1–10 min 窗口内完成
保留新维胜在线施加路径作为低成本备选，但必须过“喷嘴堵塞”关——binder 增稠后此风险上升，建议先离线验证锚定效果再决定
检测项：add-on（g/m²）与全幅均匀性 CV、渗透深度（解决“表层浓内部稀”）、掉粉率、透气率保持、多次亲水吸收/回渗（多亲油剂指标不得劣化）、除臭有效性（9 种臭味物质体系）
第三阶段（第 5–6 周）：量产验证与合规
在目标基布（12–25 gsm 热风布）上跑卷样，KC 产线 Build-up 实测
皮肤接触合规：binder/偶联剂做 GB 15979-2024 安全评估；沸石粉体安全性论证
若物理锚定（A/B/C）均不达预期，启用路线 D（硅烷偶联，需先验证 PP 表面活化）或路线 F（湿态复合夹粉）

六、风险与底线
binder 手感/透气劣化：选软性水性树脂、控制用量梯度，手感与透气作为否决项
喷嘴堵塞上升：binder 增稠后在线喷涂风险加大——离线整理路线是主推，在线路线必须浓度 code 实测
binder 包埋粉体：除臭效率验证必须做“施加后 vs 施加前”对比，防止“锚住了但没效果”
合规：新增助剂均需通过 GB 15979-2024 安全评估，偶联剂路线需额外皮肤刺激/致敏数据
底线不变：验证不达标不推进；本次拜访（10/22–23 大连）携带上述路线方案与田总/新维胜对齐，重点敲定“配方加 binder + 离线整理”联合验证计划与样品往返安排
