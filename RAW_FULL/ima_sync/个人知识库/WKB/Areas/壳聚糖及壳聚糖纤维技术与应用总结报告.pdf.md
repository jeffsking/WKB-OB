#   壳聚糖及壳聚糖纤维技术与应用总结报告

#   报告摘要

壳聚糖作为一种天然的生物基材料，因其优异的生物相容性、抗菌性、可降解性和成纤维性，在医疗卫生、个人护理、食品包装、水处理及纺织服装等领域展现出巨大的应用潜力。本报告基于现有资料，系统梳理了壳聚糖及壳聚糖纤维的核心技术特性、改性方法、制备工艺以及在纸尿裤、医用敷料、环保材料等领域的应用现状和最新进展。

#   一、核心技术特性

1. 天然抑菌性:壳聚糖纤维具备天然的抑菌特性,可有效抑制大肠杆菌、金黄色葡萄球菌等多种常见细菌的生长,减少尿布疹、皮肤感染等风险。其抗菌效果具有持久性,部分产品声称经50次洗涤后仍能保持高抗菌率。

2. 生物相容性与安全性：壳聚糖与人体组织具有良好的亲和力，无毒、无免疫原性、对皮肤无刺激，是理想的亲肤材料。

3. 可降解性与环保性：作为一种天然高分子材料，壳聚糖及其衍生物可被微生物快速、完全降解，对环境友好。

4. 高吸湿性与成膜性:壳聚糖纤维具备良好的吸湿性,且能形成多孔网络结构,适合用于吸液和保湿。

5.可修饰性:壳聚糖分子链上含有活性基团(如氨基、羟基),易于进行化学改性,以赋予其更多功能。

#   二、在纸尿裤及卫生用品中的应用

#   1.亲肤层与面层材料

。壳聚糖纤维可直接用于制备纸尿裤、卫生巾的亲肤面层。其天然抑菌性能够减少细菌滋生，呵护敏感肌肤。例如，温州佳远生物科技有限公司已成功将废弃虾蟹壳转化为纯壳聚糖纤维，并广泛应用于婴儿纸尿裤等产品。

°一项2023年的专利技术，将亮聚糖凝胶通过热喷粘附工艺附着在PET纤维表面，制成强吸水纤维并纺织成无纺布，用作纸尿裤的亲肤层。该设计利用壳聚糖凝胶的多孔网络结构实现快速吸液锁水、防止反渗，同时具备抗菌和可降解特性。

#   2. 端护理与护肤功能集成

。壳聚糖纤维的天然抑菌特性使其成为高端纸尿裤实现“主动护理”功能的关键材料之一。它可与益生菌、弱酸性表层等概念结合，共同预防红屁屁。

#   三、在医用敷料中的应用

壳聚糖及其衍生物是制造现代医用敷料的重要材料，尤其在高端伤口护理领域。

1.抗菌敷料:壳聚糖纤维或壳聚糖水凝胶因其出色的生物相容性和抗菌性,被广泛用于制造伤口敷料。通过负载抗菌剂(如纳米银、$\varepsilon$-聚赖氨酸、壳聚糖季铵盐)或采用三层结构设计,可制备出具有高效抗菌活性和促进伤口愈合功能的复合敷料。

2.药物载体:壳聚糖微凝胶可作为药物的理想载体。例如，资料中提及的载药微凝胶配方(BC:壳聚糖比例为10:90)可实现药物的高效包封和缓释，应用于皮肤修复、慢性伤口治疗等场景。

#   四、在环保及水处理中的应用

壳聚糖分子上的氨基和羟基使其对重金属离子具有良好的整合能力。壳聚糖基高吸水材料可用于制备功能性的水处理材料，用于吸附水体中的重金属离子、染料等污染物。

#   五、在食品包装中的应用

1.保鲜材料：壳聚糖的抑菌性和良好的成膜性使其成为理想的绿色食品包装材料。将其作为涂层或复合膜，可有效抑制食品表面的微生物生长，延缓腐败，延长货架期。

2. 活性包装:壳聚糖可作为载体,负载植物精油(如牛至精油)等天然抗菌剂,通过缓慢释放实现长效气相抑菌,用于冷鲜肉、果蔬等的保鲜。

#   六、在纺织服装中的应用

菌草纤维的制备中,通过离子液体法或NMMO法进行工艺改性,可使衍生出的功能性菌草纤维具备抗病毒、吸湿速干等功能,其中抗甲型流感病毒活性率超99.99%。虽然菌草纤维并非壳聚糖,但这一案例展示了天然纤维通过改性实现高效抗菌、抗病毒功能的需求和可行性,壳聚糖纤维在高端功能性纺织品领域亦具类似潜力,可用于内衣、袜子、母婴服装等。

#   七、前沿改性策略与制备工艺

为进一步提升壳聚糖的性能并拓展其应用，当前的研究主要集中在以下方面：

1. 壳聚糖凝胶强吸水纤维:通过将壳聚糖进行化学改性，引入可聚合基团，再与丙烯酰胺等单体聚合，形成具有支化网络结构的壳聚糖凝胶。这种凝胶通过热喷粘附工艺附着在纤维(如PET)表面，制成集快吸、锁水、防反渗、抗菌及可降解于一体的复合纤维。

2.壳聚糖基抗菌高吸水材料:这是一种针对卫生用品的新兴设计,通常采用三层结构设计,上下表层由木棉纤维、竹纤维等制成高透气层,中间层则是壳聚糖与丙烯酸缩聚交联后复合海藻酸形成的抗菌高吸水微球。该设计解决了传统吸水材料吸水后透气性变差、缺乏抗菌功能的问题。

3.壳聚糖微凝胶化:通过对壳聚糖进行交联(如与细菌纤维素BC结合),制备成粒径可调的微凝胶或纳米凝胶。这种微凝胶可作为功能性载体,用于缓释抗菌剂、药物、香精或护肤活性成分(如神经酰胺、维生素E)。这在高端卫生巾、纸尿裤的“功能化涂层”或面层整理中具有重要应用前景。

#   八、总结与未来趋势

1. 产业化进程：壳聚糖纤维在卫生护理用品（如纸尿裤）和医用敷料领域的应用已实现商业化，证明了其市场可行性和消费者接受度。温州佳远等企业已成为国内领先的纯壳聚糖纤维生产商。

#   2.发展趋势势:

°功能复合化:壳聚糖正从单一的抗菌、吸湿功能，向兼具护肤、消炎、智能传感等复合功能的集成化方向发展。例如，将其用于食品保鲜的活性包装中，或作为药物载体用于组织工程。

。成本优化:利用工农业副产品(如虾蟹壳)作为原料，并优化提取和纺丝工艺，是降低壳聚糖纤维成本、推动其大规模应用的关键。

°绿色与可持续:结合可降解生物材料(如PLA、PHA、PPC),组完全生物基、可堆肥的壳聚糖复合材料体系，是满足未来环保法规和高端市场需求的必然选择。
