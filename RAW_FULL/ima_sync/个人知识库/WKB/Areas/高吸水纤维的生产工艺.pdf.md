高吸水纤维的生产工艺

根据搜索结果，高吸水纤维的生产工艺主要有以下几种技术路线，其关键步骤因制备方法不同而有所差异：

#   一、干-湿法纺丝工艺(以聚乙烯醇/聚丙烯酸体系为例)

这是较经典的高吸水纤维制备方法，关键步骤包括:

#   1.溶液准备与配制

$^{\circ}$ 分别制备溶液A(聚乙烯醇水溶液)、单体溶液B(丙烯酸/丙烯酰胺中和液)、引发剂溶液C(过硫酸钾)和交联剂溶液D(二醛类交联剂)

#   2.纺丝溶液制备

。将单体溶液B分散在溶液A中，升温后加入引发剂C，在氮气保护下于65~80℃反应3~8小时，得到共聚共混溶液

°最后加入交联剂溶液D混合均匀

#   3.干-湿法纺丝

°纺丝溶液经加压过滤、脱泡后，在70~90℃从喷丝头喷出

。纺丝细流经过10~50mm的空气层后进入丙酮凝固浴凝固成形，制得初生纤维。

#   4.后处理

°热拉伸:在100~150℃下拉伸1.5~2.5倍,时间2~10分钟

°热交联:在120~180℃下处理30秒至30分钟，进一步提高纤维的吸水性能和结构稳定性

#   二、干法纺丝工艺(溶液一步聚合法)

该工艺的特点是将聚合与纺丝直接衔接，关键步骤包括：

#   1.溶液一步聚合

○将聚合物单体(丙烯酸/丙烯酸钠/丙烯酰胺)、共混聚合物(聚乙烯醇)、潜交联剂和引发剂混合

°在氮气保护下，于55~85℃进行水相溶液聚合，聚合时间6~8小时

°采用分段控温工艺:链引发和链增长阶段控制在60~65℃，自动加速现象消失后升温到80~90℃

#   2.纺丝液制备

○将聚合产物溶液直接作为纺丝溶液，真空脱泡1~3小时

#   3.干法纺丝

。采用溶液干法纺丝工艺制得纤维

#   4.热交联处理

°在120~180℃下处理3~30分钟，使潜交联剂发挥作用，形成稳定的交联网络结构

#   三、超支化结构高吸水纤维工艺（以天然纤维为基材）

这是一种较新的技术路线，采用天然纤维(棉纤维、甘蔗渣纤维、木浆纤维等)为基材，通过化学改性实现超支化接枝:

#   1. 纤维支点引入

○丙烯酸与天然纤维在有机钛类酯化催化剂（如钛酸四正丁酯）作用下发生酯化反应，制得纤维丙烯酸酯

#   2.支化接枝共聚

○将纤维丙烯酸酯与接枝单体(丙烯酸、丙烯酰胺、烯丙基聚乙二醇等)和三功能支化单体(三羟甲基丙烷三丙烯酸酯等)进行共聚反应,得到支化改性纤维

。反应后过滤水洗

#   3.亲水处理(金属离子交换)

○将氢氧化钠或氢氧化钾加入支化改性纤维，进行钠离子或钾离子交换，交换度控制在60~80%

○ 这一步可提高支化亲水基团的裸露程度，进一步增强亲水性和吸水容量

#   4.溶液与喷丝

○制备丝状长纤维

#   5.固定化与表面热处理

°包括烘干与固定、表面处理以及热处理(温度约120~135℃)

#   6.气流干燥与梳理

°最终获得超支化结构高吸水纤维，其吸水速率可达360g/g以上

#   四、可降解生物质高吸水短纤维工艺(碱化醚化法)

这是一种以纤维素短纤维为原料的绿色制备工艺，关键步骤包括：

#   1.原料准备

○以植物纤维(麻、棉、绒毛、竹纤维等)或再生纤维素纤维(粘胶纤维、莱赛尔纤维)为原料

。 经历加湿、打饼处理，形成便于反应传质的纤维饼

#   2. 碱化处理

○将纤维饼吊入反应罐，在碱化浴中处理至碱化程度达60~90%，获得碱纤维素纤维

。采用强制循环传质、传热方式，确保均匀性并保持短纤维形态

#   3.醚化处理

°去除碱化浴溶液后添加醚化浴，继续处理至醚化度(取代度)0.6~0.95

○得到羧甲基纤维素纤维初级品

#   4.中和与洗涤

。经酸浴中和、溶剂洗涤、上油、高速离心甩干，得到半成品

#   5.后处理

○湿喂给、湿开纤、干燥、计量包装

°最终产品的吸水率为60~100g/g，纤度为1.29~10.0dtex

#   总结

|工艺路线|关键技术特点|后处理方式|吸水性能|
|---|---|---|---|
|干-湿法纺丝|共聚共混+丙酮凝固浴|热拉伸+热交联|较高|
|干法纺丝|溶液一步聚合+干法纺丝|热交联|较高|
|超支化结构|天然纤维酯化+支化接枝|离子交换+热处理|≥360g/g|
|碱化醚化法|纤维素短纤维直接改性|强制循环传质|60~100g/g|

这四种工艺路线各有适用场景：前两种适合工业化大规模生产合成高吸水纤维；超支化结构路线可大幅提升吸水性能；碱化醚化法则更注重可降解性和绿色环保。

● 将热带作物纤维素与桃胶形成交联结构的气凝胶，再进行烯丙基功能化接枝改性

● 通过交联剂与单体的协同共聚作用，构建兼具高吸水性和机械强度的网络结构

●突破传统高吸水材料吸水后结构易塌陷的缺陷，保水性能优异

● 可应用于农林保水材料和食品保鲜材料（如荔枝涂膜保鲜）

● 中间层：壳聚糖与丙烯酸缩聚交联后再复合海藻酸形成的抗菌高吸水微球

● 木棉纤维经改性后水接触角高达160°，具有显著疏水特性，确保高吸水环境下良好的透气性

● 解决了现有高吸水材料在吸水后透气性变差、缺乏抗菌功能的问题

#   高吸水纤维在不同领域的应用实例

高吸水纤维(Super Absorbent Fiber,简称SAF)是一种能够吸收自重几十倍至上千倍水分的功能性纤维材料，凭借其高吸水性、保水性强、吸水速度快、柔软舒适等特性，已在多个领域展现出广泛的应用价值。以下是不同领域的典型应用实例：

#   一、医疗卫生与保健领域

这是高吸水纤维目前最主要的应用市场，每年约消耗95%的吸水树脂产品。

1. 个人卫生护理用品：高吸水纤维被广泛应用于婴儿尿布、成人失禁垫、妇女卫生巾等产品。与传统粉末状吸水树脂相比，纤维形态的吸水材料制成的产品更薄、更柔软，无粒状物泄出，能有效减轻湿疹等皮肤病。采用高吸水纤维制造的卫生用品不仅吸收速率高、吸量大，而且更加舒适贴肤。

2.医用敷料与伤口护理:高吸水纤维可用于制造泡沫敷料、岛状敷料、烧伤敷料、绷带和毯子等医疗耗材。Technical Absorbents Ltd开发的超强吸水面料能够快速吸收血液和体液,提供高吸水性、柔软、贴合且无需边缘密封的解决方案。将高吸水纤维用于手术垫、手术手套、手术上衣、手术棉等,可以迅速吸收血液、体液,保持医疗环境的干爽洁净,用于病床垫褥还可避免褥疮。

3.止血材料:用人造纤维接枝制成的止血栓已大量用于临床医疗。

#   二、工业领域

1. 电缆电缆阻水材料：高吸水纤维可制成阻水纱和阻水带，起到比传统吸水树脂更方便、更安全的阻水作用。这种材料在欧美已得到广泛应用，在中国国内仍是一个较新的产品。

2. 防结露材料:含有高吸水纤维的非织造布具有平衡水分功能——在高湿度下能吸收水分,低湿度时又能释放水分。用于内墙装饰可有效防止结露,用于包装袋内、室内墙纸、天花板及集装箱内,可防止内部环境过湿而产生结露,使物品不发霉、不变质。

3. 油水分离材料: 高吸水纤维可用于除去润滑油等工业用油中的微量水分,也可与亲油材料复合制成既亲油又易脱油的分离材料,用于船舶、陆上油污水的分离回收。相比传统的离心分离、沉淀分离、蒸馏等手段,这种方法能耗低、成本低。

4. 离子交换与环保材料: 一些阴离子高吸水剂(如纤维素接枝丙烯腈水解物、纤维素接枝丙烯酸)具有很高的重金属离子吸附量, 用这类纤维制成的滤布是理想的环保材料, 可除去水中的$Cu^{2+}$、$Mg^{2+}$、$Cs^{2+}$等金属离子。

5. 防火阻燃材料:吸收了大量水而形成凝胶状的高吸水纤维可用于制造防火材料,与易燃纤维混纺能改善其阻燃性,是制造消防服的良好材料。

#   三、食品领域

1. 食品保鲜材料：用高吸水性非织造布与薄膜复合，制成蔬菜水果等包装袋，可起到保水作用，防止水果蔬菜干枯。在欧美市场，食品包装已成为高吸水纤维最大的应用领域之一。

2. 食品加工应用：用大豆蛋白与少量高吸水剂聚丙烯酸钠共混，采用湿纺制得改性蛋白质纤维，添加到人造肉中，可以增加蛋白质的粘附力，大大改善人造肉的风味和口感，且确保无毒。

#   四、农林园艺领域

1. 土壤保水材料: 高吸水纤维在农业及园艺方面具有潜在的应用前景, 可使土壤水分不易流失, 而且缓慢释放水分, 节约人工、减轻劳动强度。同时, 高吸水纤维吸水时产生膨润, 放湿时发生收缩, 使土壤透气性增加, 具有改良土壤的作用。

2.沙漠绿化应用:TAL公司开发的“美植袋”在荒漠造林中应用,使苗木成活率平均提高12.5%,缓解土壤水分损失达9-12天。高吸水纤维也被应用于沙漠绿化材料领域。

3.园艺应用:高吸水纤维可用于园艺领域的保水材料，特别是在干旱地区的植物栽培中发挥重要作用。

#   五、纺织服装领域

1. 运动服装与内衣：高吸水纤维可以纺成纱线并织成布，用于运动衣和内衣中起吸湿吸汗作用，帮助人体保持干爽舒适。蒸发冷却功能使体温调节达到适合人需要的程度，其工作原理就像排汗，当水分从表面蒸发时，热被吸收并将液体改变为气体，是最自然的机械冷却方法。

2.功能性服装:三层复合冷却纺织物利用高吸水性材料制成,具有散热和保温双重功能。这种多层复合冷却纺织材料在制冷和保温领域应用广泛,浸染水中还具有冷却功能,穿在身上让人感觉凉爽舒适而不感到潮湿,特别适合沙漠等极端环境穿着。

#   六、其他新兴应用领域

1. 建筑材料：高吸水纤维可用于建筑领域的防结露材料和保水材料。

2. 蒸发散热织物: 高吸水纤维在蒸发散热织物上的应用正在开发中,利用其吸水后蒸发冷却的原理,为高温环境下工作的人员提供降温解决方案。

3. 可重复使用产品: Technical Absorbents Ltd开发的可水洗SAFm织物实现了突破性的可重复使用功能,在经历40次洗涤后仍能保持80%以上的吸收性能。

4. 智能热湿管理: 高吸水纤维可对纱线进行热与湿度管理,通过人体活动连续变换效应达到排汗恒温、衣服内空气流通的效果,可用于制作贴身内衣裤,尤其适用于军人和个人的应急需要。

#   总结

高吸水纤维凭借其独特的纤维形态——吸水表面积大、吸水速度快、手感柔软、加工性能好——正在逐步替代传统的粉末状吸水树脂，在医疗卫生、工业、食品、农林、纺织服装等领域展现出广阔的应用前景。随着技术的进一步发展，特别是可重复使用、多功能复合等方向的突破，高吸水纤维有望在更多领域实现创新应用

更强调吸水后的结构稳定性、液体定向管理能力以及抗菌、环保等附加价值。结合最新文献与专利，高吸水纤维的最新研究进展主要体现在以下几个方面关键方向：

#   一、绿色生物质基材的深度开发与结构增强

传统高吸水材料(如聚丙烯酸类)面临原料成本上升及不可降解的环境污染问题，因此利用天然可再生资源开发可降解高吸水纤维成为核心前沿方向。

●热带作物纤维素的高值化利用:2025年的最新研究利用菠萝叶纤维、剑麻纤维等热带作物纤维素，通过共价交联技术将其与桃胶形成交联结构的气凝胶，再进行烯丙基功能化接枝改性。这种协同共聚网络不仅实现了高吸水倍率，还突破了传统高吸水材料吸水后网络结构极易塌陷的缺陷，赋予了材料优异的保水性能和机械强度，可应用于农林保水与食品(如荔枝)涂膜保鲜。

● 聚乙烯醇（PVA）纤维的物理交联创新：针对PVA分子内强氢键导致其几乎无吸水性的难题，2023年的研究提出了一种物理循环冻融工艺。通过在低温（-50~-2℃）与常温环境中循环冻融，诱导分子链间结晶形成低交联密度的凝胶网络交联点，避免了复杂的化学热处理。该方法制得的PVA高吸水纤维吸水倍率最高可达自重的200倍，且常温保湿时间长达48小时，工艺更简单且利于规模化生产。

#   二、仿生毛细工程与Janus结构的精准流体管理

从“被动吸水”向“主动界面调控”转变是近期高吸水材料的一大飞跃，研究者开始利用多层结构与润湿性差异来实现液体的定向迁移与防回渗。

●三层Janus不对称结构:南京农业大学团队在2026年构建了导液-储液-阻隔协同的三层Janus纳米纤维保鲜垫。顶层为疏水导液层，中层为高吸水储液层(吸水率达1079%)，底层为致密阻隔层。通过层间的毛细压差驱动，该结构能将含蛋白、脂质的复杂渗出液快速导入内部并有效抑制反向回渗(“只进不出”)，成功应用于冷鲜鸡肉保鲜，使货架期延长一倍。

● 超快蒸发仿生纳米纤维膜：东华大学科学家受自然启发，研发出一种具有疏水表层与亲水内层的双层仿生纳米纤维膜。利用差动毛细效应与结构设计，其水分蒸发速率达到市面上主流吸湿排汗面料Coolmax的2.1倍，为极端环境下的高效吸湿快干织物提供了新思路。

#   三、吸水-抗菌-保湿等多功能协同复合

单一吸水功能已无法满足高端卫生医疗与保鲜领域的需求，将抗菌、保湿等功能与高吸水特性集成是当前应用研究的重点。

●无机/有机杂化抗菌高吸水纤维:2025年东莞苏氏卫生用品获得专利，以聚乙烯醇为基料，辅以改性伊利石（无机抗菌材料）和气凝胶改性料，通过静电纺丝技术制备出兼具优异吸水性与抗菌功能的纸尿裤用高吸水纤维，解决了传统吸水材料极易滋生细菌的痛点。

● 精油缓释抗菌保鲜垫：上述南农大的三层Janus结构中，研究团队还在顶层引入了$\beta$-环糊精对牛至精油进行主客体包合，构建了“分子胶囊”。这使得挥发性抗菌分子由突释转变为持续7天的气相缓释，完美结合了高效吸液与长效抗菌功能。

#   四、织物形态与孔隙率工程的创新调控

高吸水纤维最终需以织物或非织造布形式应用，纤维集合体结构的微观调控对宏观吸液与保液性能至关重要。

●亲疏水纤维交叉铺网技术:最新工艺将高吸水PVA短纤维与疏水性纤维进行交叉铺网，制得孔隙率可控的无纺布。其中，疏水纤维间的毛细作用负责快速虹吸导流大量液体，而吸水纤维内部及表面的氢键则负责锁住水分起长效保湿作用，实现了“快吸慢释”，有效避免了表面积液，非常适用于高吸收医用创面敷料。

● 异形截面与微孔结构的极致优化：通过物理改性设计Y字形、十字形、W形等异形截面纤维，或使纤维形成直径小于3微米的多孔性中空结构，大幅增加比表面积与毛细管效应。例如多孔聚丙烯腈纤维表观密度较普通腈纶减少25%，吸湿后仍保持优异的透气性和保温性，广泛用于贴身内衣与高端运动服饰。

综上所述，高吸水纤维的最新研究已不再局限于单纯的化学改性提升吸水倍率，而是向着原料绿色化、结构仿生化、功能复合化以及流体管理智能化方向深度演进，极大拓展了其在医疗敷料、高端卫生用品、生鲜保鲜及智能穿戴等领域的应用边界。
