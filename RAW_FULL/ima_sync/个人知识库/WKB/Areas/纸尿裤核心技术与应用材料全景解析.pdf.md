#   纸尿裤核心技术与应用材料全景解析

#   一、纸尿裤基础结构与最新技术概览

#   1.核心结构组成

纸尿裤主要由以下功能层协同工作:

●表面覆盖层(表层):亲肤透气无纺布/打孔膜，促使尿液下渗并阻止回渗，保持干爽。

●导流层(ADL):无纺布材质,将尿液均匀、纵向扩散至吸收芯层,扩大吸收面积。

● 吸收芯层：由纯木浆（绒毛浆）和高吸水性树脂（SAP）构成（分为混合芯体与复合芯体），负责吸收、分散和储存尿液。

●底布/防渗底层:PE膜或透气无纺布，防止尿液外渗。

● 辅助结构:闭合系统(腰贴/弹性腰围)、立体防漏护围、尿显条等。

#   1.最新技术演进

● 结构与防漏创新:复合芯体、“按需分布”多通道干法纸、超吸收通道(防下垂)、360°防漏护围、扩容防漏兜(防稀便)。

● 肌肤护理进阶：类胎脂精华屏障（神经酰胺)、物理隔菌科技（表层物理阻隔）、生物基面层(PLA/粘胶/莱赛尔)。

●散热透气重构: Air-Max全裤散热系统、腰围立体散热通道、轻薄隐形化芯体。

● 智能化与环保：物联网RFID/湿度传感器智能预警、生物基SAP（碳足迹降15-25%)、可降解材料（PLA/PHA)。

#   三、吸收芯体最新研究进展与新型材料

#   1.结构创新

● 立体承载空腔与流体通道：SAP颗粒被独立封闭在模具定型的立体空腔内，空腔间形成贯通流体通道，解决“凝胶堵塞”和成坨鼓包问题。

● “按需分布”多通道干法纸：定制孔隙结构、分区铺设SAP，将吸收芯体与导流层合二为一。

#   1.材料革新

● 超吸水纤维（SAF）：与传统颗粒SAP相比，SAF与再生纤维素纤维（RCF）混纺制成的非织造芯体，吸液后呈一体凝胶状，仅在厚度方向有限膨胀，形状极度稳定，彻底解决起坨断层。

●生物基高吸收性聚合物：采用可再生资源替代部分化石原料的bioSAP，碳足迹降低15%-25%。

● 新型环保纤维: PLA(聚乳酸)和PHA纤维用于芯体包裹层,兼具强度与可降解性;无合成纤维干法纸满足极薄与生物基需求。

● 复合抑菌除味材料：大芯体上层设置抑菌茶叶/活性炭吸附复合层，抑制细菌并吸附异味。

#   1.工艺升级

● 差异化超声波粘接：大王蜂巢芯体技术，六边形点线轻度粘接预留膨胀空间，边缘高强度粘接固定位置，取代热熔胶，提升透气性。

●在线一体成型工艺:新型立体空腔芯体支持在线一体成型，缩减步骤，保证SAP理想分布。

#   四、ADL（导流层）与REL（收集/传递层）深度解析

#   1.功能与材料差异对比

|维度|REL(收集/传递层)-第一道防线|ADL(导流层)-交通枢纽|

| :--- | :--- | :--- |

|功能侧重|垂直方向的“收”:瞬间捕获冲击性液体，暂存并向下传递。|水平方向的“导”:将液体沿平面纵向扩散，均匀分配至SAP。|

|密度与孔径|低密度、大孔径，需极大空隙容纳瞬时涌流。|中等密度、定向孔径，控制流向和扩散速度。|

|材料结构倾向|粗梳合成纤维网，含中空/卷曲纤维的空气铺网织物，强调蓬松和回弹。|高蓬松热风非织造布，带开孔的三维膜/非织造布，强调导流路径。|

|粘合剂应用|侧重潮湿状态下结构锚固(SBR胶乳/VAE),防受力塌缩。|侧重低粘着特性,保证表面多孔,提升三维回渗性能。|

|失效风险点|受压塌缩或吸水软化，失去瞬间接收能力导致溢漏。|导流不足或“凝胶堵塞”，导致局部过载引发回渗侧漏。|

#   2. 提升ADL吸收效率的改进策略

● 优化纤维组分(高低旦尼尔分层):上层采用>5d高旦尼尔纤维提供大孔隙和骨架支撑(快速涌入);下层<5d低旦尼尔纤维提供致密传输通道和毛细吸力(加速转移)。

● 引入熔喷转向层：在分层梳理网下增设15-50gsm的熔喷组分转向层，超细纤维网快速将上层液体“拔出”转移至芯体，减少表层回渗。

● 构建多层密度梯度：顶层低密度高膨体（水库暂存），底层高密度（毛细抽离），形成单向驱动力。

●创新物理构型(漏斗形贯通孔):在ADL上冲压漏斗形贯通孔(3-20个/cm$^{2}$),突起朝向芯体,形成单向阀效应,液体易进难出,大幅提升干爽度并减少恶臭。

● 精确调控开孔率与纤维直径：70%纤维直径控制在12-22μm，开口面积35%-65%，保证0.5kPa压力下0.8-1.2mm厚度，兼顾支撑力与极好排水性。
