# 皮芯架构决策矩阵

# PPC/PBAT 皮层（含联欣 LX-T55P25T20 线纺专用料）× 四芯层方案对比

用途：可降解热风无纺布（芯体包裹层/导流层优先，面层次之）技术评审 日期：2026-09-17

# 一、评估对象

•皮层方案：PPC/PBAT 共混（参考联欣 LX-T55P25T20：PPC-P/PBAT 基体，MFI 20.1 g/10min @170 ℃，拉伸 10.6 MPa，断裂伸长 162%，维卡 60.2 ℃，加工温度 160–190 ℃，EN13432/ASTM D6400 认证）

•芯层方案：PET / PLA / PGA / PLGA（梯度掺混）

•工艺：皮芯型双组分短纤 → 梳理成网 → 热风加固（120–145 ℃，最佳 120–140 ℃）

# 二、五维决策矩阵（★=弱 ★★=中 ★★★=强）

|维度|PET 芯|PLA 芯|PGA 芯|PLGA 梯度|
|---|---|---|---|---|
|1. 工艺窗口（ΔTm 与热风适配）|★★★|★★★|★★|★★☆|
|2. 纺丝可行性（成熟度）|★★★|★★★|★★☆|★☆|
|3. 货架期/水解风险|★★★|★★☆|★|★☆|
|4. 可降解叙事|★|★★|★★★|★★☆|
|5. 成本与供应链|★★★|★★|★|★☆|
|综合建议|保守方案|主线方案|高端叙事方案|调节杠杆/预研|

# 三、逐维解析

# 1. 工艺窗口（ΔTm 与热风适配）

|芯层|Tm|与皮层 ΔTm|评价|
|---|---|---|---|
|PET|255–260 ℃|~130 ℃|窗口最宽，芯层最安全；但 PET 芯纺丝温度 ~280 ℃，皮层（PPC/PBAT）有高温降解风险，需小试验证皮芯汇合区停留时间与皮料分子量保持|
|PLA|155–170 ℃（D/L 比例可调）|30–60 ℃|独门武器：旋光比精调熔点（PDLLA 无定形 → PLLA 170 ℃ → sc-PLA 230 ℃），可按热风工艺定制 ΔTm；纺丝熔体温度低于 PET，对皮层热冲击更温和|
|PGA|高（库内无纤维级 TDS 数值）|待核|无熔点调节杠杆，窗口只能硬配；信息缺口：需向神华/中石化要纤维级 TDS|
|PLGA|单体比例可调|可调|降解速率可连续调控，但熔点/结晶行为随组成变化复杂，工艺开发量最大|

# 2. 纺丝可行性

•PET：双组分 ES（PE/PET）50 年成熟工艺，皮芯组件现成——迁移到 PPC/PBAT 皮只需换皮料

•PLA：Ingeo SLN2711D（远东纺织双组分）已商品化；“PLA 生物基化学纤维+热风穿刺熔融固结”国内已验收；卫材纤维级牌号现成

•PGA：Dexon 缝合线（1970 至今）证明熔纺可行，但均为细旦医用，卫材级粗旦短纤无现成牌号，需联合开发

•PLGA：医用可降解缝合线/支架领域成熟，纤维级卫材应用空白

# 3. 货架期/水解风险

|芯层|水解行为|风险评估|
|---|---|---|
|PET|不水解|无风险（但也不降解）|
|PLA|结晶区挡水，水解慢；PDLLA 无定形态 3–6 个月快水解|PLLA 高结晶 = 天然货架期保护；12–24 月货架期基本安全|
|PGA|家族最快：海水 28 天降解 75.3%；缝合线体内 2–4 周失强|干态仓储无水不水解，但高湿海运/南方梅雨场景必须做加速老化验证（40 ℃/90% RH × 4/8/12 周 CD 拉伸保持率）|
|PLGA|介于两者之间，随 GA 比例加快|需按具体配比验证|

# 4. 可降解叙事

•PET：不降解——芯层占 50–60%，环保卖点被砍半，只能讲“皮层部分可降解”

•PLA：堆肥 180 天（58 ℃ 工业堆肥条件）；土壤 1–3 年、海水极慢——“需要工业堆肥”会被自然降解认证挑战

•PGA：海水 28 天 75.3%，家族最快，可写进产品页的差异化数据；瞄准欧盟 2028 法规方向和“可自然降解”认证

•PLGA：可调——想给 PLA 芯“加一点降解速度”时掺 GA 单元做梯度

# 5. 成本与供应链

|芯层|价格锚点|供应格局|
|---|---|---|
|PET|大宗最低|完全成熟|
|PLA|15,000–25,000 元/吨|联泓 4 万吨（PLA）+ PPC 5 万吨一站配齐；丰原 10 万吨；纤维级牌号（Ingeo）现成|
|PGA|医用级贵；煤基是降本变量|神华煤基万吨级在建、中石化大连院中试推进；卫材纤维级牌号空白，需联合开发（闽瑞+东华大学为通道）|
|PLGA|最高（医用级）|医用供应商为主，卫材量价未建立|

# 四、皮层通用风险（四芯共担）

1.粘合点内聚强度：T55P25T20 拉伸 10.6 MPa / 伸长 162%（显著低于纯 PBAT >600%）——PPC-P 相增脆，粘结点强度与柔韧性大概率低于 PE 皮；小试必须做 CD 拉伸对标（门槛 9.0 N/50mm）

2.维卡 60.2 ℃ 仓储风险：夏季集装箱 50–60 ℃ 皮层先软，布卷层间粘连；需 60 ℃ × 72 h 卷材模拟验证

3.亲水整理重做：表面化学从聚烯烃换成聚酯族，现有亲水剂配方体系不适用

4.PPC 在皮内占比建议 ≤20%：无定形无清晰熔点，摊宽熔融窗口、降低粘合一致性

5.Delta T 管理：热风设定温度与实际温度差必须逐线实测，找“强度够用的最低加工温度”

# 五、推荐策略：分层下注

|层级|方案|定位|
|---|---|---|
|主线（量产）|PPC/PBAT 皮 + PLA 芯|熔点可调、货架期安全、供应链现成；韧性靠 PBAT 皮 + 芯层 PLA/PCL 共混兜底|
|高端线|PPC/PBAT 皮 + PGA 芯|“海水 28 天 75%”极致降解叙事，瞄准出口欧洲高端/限量；前置货架期验证|
|调节杠杆（预研）|PLGA 梯度|在 PLA 芯内掺 GA 单元连续调控降解速率；跟踪陈等 2025（Polymers）PLA/PGA/PLGA 海水降解基线|
|对照/备份|PPC/PBAT 皮 + PET 芯|工艺最稳但环保叙事打折；仅当 PLGA/PGA 验证失败时保留|

# 六、下一步验证清单

1.皮料粘合点对决（联欣/ES 厂）：LX-T55 皮 + 各芯 vs 标准 PE/PET ES，同工艺热风，比 CD 拉伸、剥离强度、粘结点 SEM——对标 9.0 N/50mm 门槛

2.皮料高温耐受：各芯层纺丝温度工况下皮层分子量保持（IV/GPC）——决定 PET 芯路线是否可行

3.PGA 芯货架期加速老化：40 ℃/90% RH × 4/8/12 周 CD 拉伸保持率 vs PET 芯对照

4.仓储模拟：60 ℃ × 72 h 卷材层间粘连 + 粘合点强度保持（针对维卡 60.2 ℃）

5.亲水剂适配：聚酯表面润湿持久性（多次穿透后接触角）

6.供应商动作：

–联欣：确认 PPC-P/PBAT 具体配比、纯 PBAT 对照牌号、合作纤维厂/纺丝验证记录（联欣纺丝能力库内无记录，需核实是树脂厂还是有纺丝线）

–神华/中石化大连院：PGA 纤维级牌号 TDS、MOQ、价格

–联泓：PLA 纤维级牌号 + PPC 共混配比方案

–闽瑞：PGA/PBAT/PLA 双组分打样可行性（实验线，400 kg 级）
