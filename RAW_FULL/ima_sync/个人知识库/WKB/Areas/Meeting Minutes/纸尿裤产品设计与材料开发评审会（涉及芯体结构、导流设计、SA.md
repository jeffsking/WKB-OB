# 纸尿裤产品设计与材料开发评审会（涉及芯体结构、导流设计、SA

## 二、哑铃型版型与撒粉均匀性


结论与发现：


采用切条称重法（1英寸宽切条）测量实际单位面积添加量：X型各条重量较稳定；哑铃型在最窄处（5号模块区域）出现明显重量波动，实际值显著低于理论值。


原因分析：最窄处面积小、负压不足，大颗粒SAP倾向走向远端，小颗粒易被负压吸附在近端，导致该区域PSD均匀性偏差；单点密度上限约在540–580 g/m²之间，超出部分会飞散到其他区域。


对照组（10号）在最窄处差异不明显。


改进方向：


可通过区域负压增强、或减少该区域镂空面积来改善最窄处的抓粉能力。


前端叉型区域可考虑简化（“能省则省”），以优化撒粉效率。


## 三、分叉导流设计测试


结论与发现：


Code 1（有分叉）vs Code 2（无分叉）对比：高低压吸收两者均表现良好；高压下纵向导流有显著贡献；cradle第三轮测试中Code 1显著优于Code 2（同一检验员测试，可排除人员误差）。


横向channel方案（Code 6/7/8系列，针对大扇尾防前漏设计）测试结果均无显著性差异，两两对比亦无显著差异，大扇尾设计对前后漏无实质性帮助，且带来约4.8%的成本上升（主要来自IL加宽、PSN增加及版型加宽）。


建议中间树干部分做细槽（如上方叉8、下方叉4），兼顾对位容差（MD方向2mm偏差可接受）与上下绑定强度。


遗留问题：


一条粗分叉 vs 两条分叉（X型）哪种效果更好，需进一步一对一比试。


分叉过窄的工艺可实现性及侧漏姿势下的表现需继续验证。


## 四、侧漏分析与体形对比


结论与发现：


侧躺测试中，测试人偶（胖子版型）侧漏量168–330，而6.5版型量级明显更大，差异可能源自折页结构（直通式 vs 仅侧翼）及腰部环形包裹贴合度。


漏点位置主要集中在腰胯/前腰区域，液体先被前端结构兜住后沿侧边渗出。


后端pocket对后漏有阻挡作用，前端可考虑增加类似阻挡结构。


## 五、材料开发计划（核心工程验证三大方向）


### 4. 熔喷材料（Core wrap替代方案，20克）


熔喷纤维细度约为常规纺粘的1/20，毛细效应显著，爬坡优于现有38克方案；成本有优势。


最大风险：高速产线下的强度不足（MD强度约400–800 g，参考值1600 g基本不可用）。改善路径：打孔微切（embossing增加MD拉力）、添加10%–15% POE/弹性体、增加喷孔密度或加喷中间bank。


行动：安排材料上试验线实跑验证强度、掉毛/飞絮等问题；配套组织专项项目推动希瑞（供应商）强度改进。


## 六、其他事项


专利风险：已完成40余篇风险专利检索，总体风险较低；若IEL不切割则风险极低，若切割可借鉴5.6版做法（IEL内增加纤维素）降低冲突风险。


胶水：关注汉高聚烯烃胶（印尼厂已在MSR线使用），可索取样品评估；注意清洗机换胶成本（每次约50公斤清洗量）。


测试方法：材料端STM测试方法需与成品端方法结合，部分指标需借用成品测试标准；需明确材料开发的benchmark（对标现有材料+竞品要求），后续与DNC/Fei共同设定明确目标。


成本：哑铃型方案成本上涨约4.8%，取消大扇尾可回到control水平。

### 1. SAP（吸水树脂）


现阶段以工程能力/设计验证为主：验证“上层高GBP+高AUL、下层高CRC”的分层逻辑，计划做7–8个code。


SAP混合后需验证上下层配比（如4:6优于5:5的可能性），核心逻辑是防止上层凝胶堵塞影响下渗，需寻找通液性与吸收量的平衡。


粒径分布（PSD）尽量与现用KC511保持一致，暂不引入粒径差异作为变量（避免早期成本抗争）。


供应商方面：现阶段以诺尔（Norske？）为主力；实验阶段可开放窗口，接触住友、巴斯夫、触媒等以验证concept，不限于后段供应策略。


### 2. 导流层/面层（Liner + 三叶草纤维）


双层设计：上层加约10%三叶草异形截面纤维（验证MD方向导流），下层加50%异形纤维；目标切换为单组分PPT三叶草纤维（现阶段暂用替代品打样）。


上层10%添加仅作探索性test，不必过度纠结；下层添加比例是关键。


风险点：150克以上克重时异形截面在高温（>142℃）下有流平风险；双梳理双头设备热风厂基本为标配，供应商门槛可控。


### 3. IEL/PEVA纤维（28克方案）


采用PPT+PVA（PVA暂为直签，网威年底将上卷曲设备，未来可提供卷曲PVA纤维，改善开松梳理问题）。


62%的液体抓取率（vs 现有约十几%、竞品约30%），按标准加压方法测得。


成本：整体上升约15%（PVA约2万–2.5万/吨，PPT约2万/吨）。


待办：分切后厚度衰减问题需分析；安全评估（safety）结果待确认，溶剂为水性，预计风险不大。

## 一、芯体添加量与Channel结构验证


结论与发现：


Channel开槽面积占pad面积约10%–15%。在保持撒粉点密度与5.6版一致的前提下，channel区域开槽面积减少约6%–7%，添加量下限约为7克（7.75克减1.5克以内可接受）；再往下虽回渗影响不大，但U型回渗会呈现明显劣势。


高低压、回渗性能对各channel方案均无显著影响；主要差异体现在第二轮cradle intake及第三轮测试，Code 3（添加量6.8克）表现明显落后。


U型分布基本无变化（约两百上下）。


讨论要点：


Channel加长可考虑（可增加撒粉量、更透气、对位更容易），但加宽不建议——加宽会扩大无吸粉区域、恶化CD方向表现、增加侧漏风险。


建议等第二轮、第三轮材料测试结果出来后，再决定channel尺寸是否进一步推广。
