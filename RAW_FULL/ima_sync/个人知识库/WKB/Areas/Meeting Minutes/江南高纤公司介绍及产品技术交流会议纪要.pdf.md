#   江南高纤公司介绍及产品技术交流会议纪要

#   一、会议概况

会议主题：江南高纤公司概况介绍及产品技术交流

主持人：张靓颖（陈艳明）

参会人员:周总、陶总、KC专家组及相关技术人员

会议议程：公司简介、工厂参观、产品展现

会议围绕江南高纤的公司实力、产能配置、质量管控体系及产品技术细节展开深入交流，并就5G产品认证、新配方开发、多次清水技术、喷丝板定制等议题进行了专业探讨。

#   二、公司基本情况

会议指出，江南高纤位于苏州市上城区王寨镇，紧邻上海，高铁25-30分钟可达，地理位置优越。公司占地约2000亩（1.35平方公里），员工800人，是中国民营企业制造500强企业，近年营收稳定在200亿元左右。

会议介绍了公司的主要特点：

● 资金与能源保障:公司现金流充足，可保障原料采购和供应链稳定;自备电厂可应对特殊时期的拉闸限电情况。

●组织架构:旗下有上市公司江南高纤(主营短纤维、涤纶毛条)和江南金板(主营涤纶短纤维、聚酯切片、再生定位白纤维)。

● 行业地位：国家高新技术企业，涤纶复合短纤维和涤纶毛条行业标准的主体制定者（复合短纤维五项标准全部为主体，涤纶毛条五项同步）；累计授权专利35项，发明49项。

● 市场覆盖：产品销往全球20多个国家（除非洲外均有销售）。

#   三、5G产品专项讨论

会议重点就5G产品进行了深入交流，会议认为该产品是公司的重要技术成果：

#   1. 产品背景

会议指出，公司是国内最早开发5G产品的企业，最初是与上海石化合作开发，使用新催化剂去除重金属。后来中石化内部合并导致合作中断，公司又寻求其他合作伙伴继续推进。

#   2. 技术指标

●有机锡:正常5G产品要求<250PPM,有机锡<10PPM

●检测方法:委托第三方测试,采用汗液萃取法,并送德国格拉克实验室进行认证

● 专利认证：国内外均已认证

#   3.生产现状

会议说明，5G产品目前已实现常规批量生产，用量较大，出口韩国需符合韩规要求。初期开发风险较高，系统切换可能影响整条生产线，但现在影响已较小。

#   四、主营产品系列

会议介绍了公司四大主营产品:

|产品|主要应用|备注|
|---|---|---|
|复合纤维special|卫材|—|
|涤纶短纤|卫生用品、水次、卫材|—|
|涤纶毛条|高档西服面料、军队服装|细分领域市场占有率高|
|再生涤纶短纤维|沙发填充等|国家控制严格，产量较少|

会议特别说明，公司曾在棉花紧张时期开发再生纤维用于被子填充，具有轻、薄、吸湿性好的特点，当时市场需求旺盛。

#   五、产能与设备配置

#   1. PET产能

● 聚合车间产能：35万吨

● 纺织线：6条，其中5号、6号线为德国进口

●关键部件:塑料泵(日本进口)、葵花轮、软曲机、取暖机(德国摩纳克进口)

● 短线规格:1.2-1.4公分，可根据客户要求做有T/无T

#   2. Bicomponent产能

● 总产能：20-23万吨

● 产线：12条线+1条小实验线（X线）

● 11号、12号线为德国NO马进口，是目前世界最先进的产线

● 国产线关键部件（如分子板）均为日本进口

● 小实验线产能：一天2吨，一年600吨，用于新品开发，成本可节省

#   3. 温度控制

会议讨论了双组分纤维的温度控制问题：

· PE温度：约130°C

● PET温度：约250-260°C

● 控制精度：±2°C

●温度变更需经研发部审批，生产部执行，并查看数据差异进行分析

#   六、质量管控体系

会议强调，公司承诺质量管控实行"3S"体系:

#   1. CS (第三方测试)

每年将产品送第三方实验室检测，包括重金属、磷苯二甲酸酯、毒理、离曲和REACH等项目。公司已进行欧盟REACH检测十几年，主要使用SGS或欧陆等机构。会议指出，包装材料也严格管控，避免邻苯等问题。

#   2. STA (生产运行管控)

● 推行质量文化“自愿型”，全员参与风险管理

· 运用FMEA（失效模式分析）工具，从原料进仓到成品出库全程管控

● 通过小程序奖励机制激发员工发现问题

● 推行“完美开车”评比，三个月检查一次，要求一次性开车成功

● 实行零停车、零慢车考核，优秀产线可达一个月无停车

#   3. 标准化

●岗位工序规范化，每道工序必须达标才能进入下一道

● 设备完好性检查，避免因故障导致停车

● 三级检查体系：生产车间、生产部、宾管部协同检查

● 装车发货要求车辆干净，避免运输污染

会议特别分享了宝洁罗德伟先生深入现场检查的故事，体现了公司对质量管控的严格要求。

#   七、产品技术细节讨论

#   1. 有T/无T标准

会议澄清了不同产品的有T/无T标准:

• PET无T: 10PPM

● ES (PE/PET) 无T: 低于5PPM (因PE包在外面,实际含量约为PET的一半)

●检测方法:采用汗液萃取法,具体方法可后续提供

#   2.多次清水技术

会议就单次清水与多次清水的区别进行了讨论:

●主要区别在于做成无纺布后的穿透性

● 多次清水可达到6-8次尿液渗透测试

●大聚合工艺无法添加改性物质，永久清水需通过物理方法(如激光微扫描调整毛细孔径)或接枝工艺实现

● 会议建议提供多次清水的测试数据供参考

#   3.新配方开发

会议讨论了在小实验线上开发新配方的可能性:

●可更换PE和PET材料，调整熔点(如PET从250-260℃降至230℃)

●温度可控范围内均可试验

●如需惰性气体保护，需具体评估

●开发要求:提供原材料工艺参数,评估安全和环保问题

●可签订保密协议锁定配方

●需注意螺杆清理问题，某些材料可能难以清洗干净

#   4.功能性添加

会议说明:

● 目前抗菌抗氧化的植物精华主要使用艾草，添加在皮层

· 如需功能性纳米粉粒（如石墨烯），需通过第三方改性处理好母粒后再使用

公司自身不具备粉体改性能力

#   5. 产品规格与颜色

· Bicomponent规格: 0.8-15D

● 形状：圆形、偏心、中空、并列等（下午重点讨论）

· 颜色：白色（主白、增白、高白）、彩色（客户提供潘通字号可开发）

● 增白添加有上限，过高会影响纺织强度

● 目前未使用CoPET，受聚合工艺限制

#   6. 喷丝板定制

● 喷丝板合作方：日系企业（未使用国产）

● 开发新结构喷丝板投资：约20-30万元

●开发周期:从提出需求到产品出来约3.5个月

#   八、下午参观安排

会议确定下午参观内容:

● 参观Bicomponent产线（从前到后）

● 参观后处理工序

● 聚合车间因管道多、温度高，不安排参观

● 偏心、异形等技术细节下午重点讨论

#   九、待办事项

1.检测方法提供:发送5G产品及ES有T/无T的检测方法报告(包括欧盟/美国标准)

2. 多次清水数据：提供多次清水测试数据供客户参考

3. 新配方开发评估:客户回去咨询法务后，可签订保密协议开展新配方合作

4. 喷丝板开发：如有新结构需求，可启动定制开发，周期约3.5个月

5. 下午技术讨论：重点讨论偏心、异形纤维技术

#   十、会议总结

会议认为，江南高纤作为细分领域的领跑者，在产能规模、设备配置、质量管控方面具备较强实力。会议就5G产品认证、多次清水技术、新配方开发等关键技术问题进行了深入交流，为后续合作奠定了基础。会议强调，双方应就检测方法、技术资料等细节进一步加强沟通，并在安全和环保前提下推进新品开发合作。

#   尿裤材料与工艺技术研讨会会议纪要

#   一、会议基本信息

· 会议主题：尿裤材料与纤维工艺技术交流

● 参会人员:钱总/张总(尿裤产品开发方)、陶总(纤维生产方)、田总、港姐(合规/保密)、Chris、王宇翔、小霞、婷婷等

● 会议形式：现场参观+技术座谈

#   二、会议主要内容

#   (一) PPD/PET纤维产品现状介绍

陶总介绍公司目前主打三大、四大、六大、九大品类纤维，主要供应国际大客户，应用于Baby（婴儿尿裤）导液层等部位，采用化学结合工艺。目前四大产品用量较大。

钱总询问"化学粘合"概念。陶总解释:化学粘合是指PP纤维在无网布中通过上胶(化学胶,如EVA胶或PV胶)进行粘合,区别于热风工艺的高酯结合。此工艺可用于传统纸尿裤生产。

#   (二)水刺布与热风工艺温度匹配问题

钱总提出核心问题：未来若在芯体包覆层使用混纺水刺布（添加植物纤维如木浆、粘胶），并希望用50%热熔纤维+50%植物纤维通过超声波粘合替代胶水粘合，会面临温差难题——

● 混纺水刺布含PET纤维，熔点约250°C

● 其他PP基无纺布、PE/PP热风布熔点约130°C-210°C

● 两层布温差大，超声波工艺难以均匀粘合

钱总诉求：PET温度改性方面有何建议？或能否用复合纤维替代？需低成本解决方案。

#   陶总回应：

1. 可考虑超短纤维 (3mm、6mm长度)，木浆+PE/PP复合，粘合后不怕水，强度好，成本低

2. 超短纤维工艺已有应用（如高铁飞机擦手巾）

3. PET温度改性可行，但需要一定起订量，干燥工艺有难度

4. 市场有110℃熔点改性PET，但量少

#   （三）异形纤维导流性能探讨

钱总提出：为提升尿裤面层liner在MD（机器方向）的导液性能，考虑加入5%左右异形纤维（十字形或Y形）。

#   问题分析：

● 双组分白口 (PE/PET) 做十字、Y形纤维，PE熔点低，经过两次加温（溶出+干燥+客户端梳理绑定）后，PE易流平，十字槽/Y形槽效果打折

● 不如直接用单组分PET纤维拉制十字或Y形，刚性更好

#   陶总回应：

1. 单组分PET拉异形纤维技术上可行，仅需更换喷丝板

2. 开发周期约2-3个月，起订量约二三十万吨（单组分）

3. 目前热风供应商未提出此类需求，常规以六单、九单为主

4. 现有产品6单4单弹性较好，可先试用6单9单看效果

双方共识：先做小样试验，加3%-5%异形纤维到常规ES纤维中，对比导流效果。

#   （四）纤维截面结构设计（A-I型号）

陶总展示多款纤维截面设计：

|型号|结构特点|功能定位|
|---|---|---|
|A|皮芯对称|常规产品|
|B|平行并列|量大,常规|
|C|并列中空偏心|弹性好,蓬松|
|D|已上机(北京大元)|反馈正常|
|F|偏心三叶|弹性|
|G(新开发)|三孔支撑结构|减少用料,保持弹性,Mercedes式缩放设计|

|I|哑铃型|月底上机打样|
|---|---|---|

#   钱总意见：

· G型三孔结构担心强力不够、空隙跑料

● 多叶草形式更适合做手感柔软度，而非导流

● 十字/Y形单组分PET更适合导流方向

· C型或F型偏心结构用于超声波永久变形效果更好

#   (五)永久亲水油剂问题

钱总指出：水刺纤维有两大毛病——

1. 水刺工艺会冲掉油剂

2. 水刺后处理温度170-180℃，会挥发油剂

热风工艺最高温度不超过120℃，油剂可保留。钱总要求：永久亲水油剂能承受4次左右0.9%氯水冲刷即可。若达到要求，直接用偏心纤维即可，不必用PET。

#   （六）纤维混料服务讨论

钱总询问：是否有将不同纤维按比例混合打包的服务？

#   陶总回应：

1. 正式产线无法混料，怕影响质量管控

2. 可在小试线上操作：小试线做好长丝包，放在烘房边，与大线丝束一起切断

3. 需确保比例均匀，可加8%、20%等比例。

#   (七)钛白粉/纳米粉改性

钱总提出超白纤维需求（如天鹅般白度），现有常规钛白粉无效，需找新钛白粉替代。

#   陶总介绍：

● 目前PET最高添加量12%，超过则切刀易损（已用陶瓷刀）

● 细度问题：磨粉时加油层防粘，仍有颗粒

钱总扩展：除钛白粉外，未来考虑添加石墨烯纳米粉、红外感光等功能性粉末，用于温度调控等功能。

双方讨论：陶总推荐寻找第三方改性公司。钱总推荐苏州Amateur（美资公司，KC使用30多年，实验室齐全，全套检验在印度孟买），建议签三方合作协议。

#   (八)可降解纤维现状

陶总介绍：可降解纤维研发已暂停。大厂家近年不再提需求。曾生产PLA可降解纤维，后因客户不要而停产。主要问题：

●成本高

●家庭堆肥难实现(PLA需工业堆肥)

● 回收分拣困难

● 降解周期不确定

钱总表示：不需要PLA，太贵且需工业堆肥，目标需家庭堆肥。石化基可降解材料也可以考虑，不一定要植物基。

#   (九)能耗优化探讨

钱总询问：螺杆加温（五区）、过滤器等环节是否有能耗改进项目？

陶总介绍：目前正在研究不同原材料（一价、零价）的最佳工艺方案，通过对比模拟数据，寻找最优成本方案。各区温度、过滤器均可独立控制，目标是找到成本最省、纺制最好的方案。

#   (十)小事件事件影响

会议提及"小霞"事件带来较大影响，双方将考虑产品更新和开发中的相关调整，需等国家队给出结论。目前所有检测暂无定论。
