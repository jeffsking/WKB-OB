# 2. 模块一：09:30 GRID 项目评审（GRID = Topical Liner × Kirigami Surge）

# 2.1 GRID 在产品架构中的位置

•KC Open Diaper 架构：T4 及以下用 Surge/Liner 二件套；T5 及以上升级为 Support Layer / Topical liner（三片式 3-Piece Liner）；产线含 Double Turn Bar for T5（Topical liner） 工位。

# •SOAR4（腰弹性 + Topical liner）为 T5+ 配置；同档 New 3D Emboss + Apertured Liner（全码段）。

•Intake Material Development Pathway 中 GRID*（星标=开发中）列于 Surge 的 3D/Apertured 分支，与 Textor AC4、Naxos、CleanShield、DEFENDER 同列。

# 2.2 Kirigami Surge：GRID 的关联技术

项目定位（KC R&amp;D 项目页）： - 驱动因素：消费者对尿液/稀便管理与皮肤干爽需求提升 + 更好透气性 + POME Topical Surge 成本上升，需更具性价比的替代——Kirigami 立项动机即降本替代 POME topical surge。 - 机理：切缝+拉伸（cut & stretch）形成半圆形孔洞与微地形（实物 SemiCircle 10mm），构建立体通道；解决传统平面材料“表面平整、液体通道少、扩散慢、回渗风险高、透气性低”的问题。 - 卖点：不增加材料用量前提下实现更优液体管理、透气、干爽；消费者接受度好；有望降低对 POME Topical Surge 的依赖。

成熟度与路线图坐标： - TRL 阶梯：KIRIGAMI Surge (GRE) 处于 TRL 3–4；同期 U-Bonder、3D Sensation、3D Bico（GNW）；TRL 5+ 为 CLEANSHIELD。 - 3D Liner/Surge 供应商样品库：KIRIGAMI 与 CleanShield、YanJan Naxos/Diamonds/Wave、Berry Apertured、Shalag Hexagon、Avgol Waveform 并列。 - 2026 IPC BCC FEI：Kirigami 技术与 laser cutting 并列作为腰部透气性（waistband breathability）两个解决方案，claim space 待定。 - 产品日历：COCO V7 KIRIGAMI；另有 “Kirigami Electric Nano Lin” 条目。 - 女性护理线：Responsive Dri Fit / Kirigami Stretch（2025+）。 - 内部脑暴：Kirigami 打孔材料列为“定点下渗”视觉方案候选（与下层有色材料结合形成视觉差异）。

# 2.3 Topical 3D 技术演进背景

Flat Liners（SMS/SB/BCW）→ 3D Visual Cues（纹理/开孔）→ 3D Skin Health（CleanShield 隔 BM、ZEN/BITS 活性物、dryness 待定）→ 3D Enhanced Cues（TBD：非贴身面印刷做深度感）。

创新需求（官方口径）： - 近期：Drier 3D liner & topical surge（尿液场景），目标 rewet 0–0.3 g；应用 Active Baby、POISE Ultra Thins。 - 长期：3D liner/topical surge 的印刷方案；壁垒：高速印刷质量、油墨堆积、单面可视性。 - 核心追问：“Do we need liner & topical surge innovation to also achieve superior protection beyond perception?”

# 2.4 BM 控制机理

Topical liner 设计核心 = 开孔 + 下方空隙：无孔无空隙 BM 积于面上；孔+空隙将 BM 收入下层，皮肤更干净（CleanShield 假人 30 ml 稀便验证）。

# 2.5 关键风险

# 1.开孔/沟槽是储液池：高吸力开孔网络（40–50 kPa）若竞争不过下层，液体积存 liner 层受压回渗；芯体近饱和时裕度收窄。

# 2.凉感湿感悖论：liners/surge 的 cooling 方案可能增加湿感（2022 Intake Strategy 已知顾虑）。

3.克重下探风险：UBK Maxi / POISE UT liner 计划降至 18 gsm；纸尿裤 liner 低于 12 gsm 增加 GOS 风险——Kirigami 切缝+拉伸工艺下克重与拉伸比的关系必问。

# 4.POME 降本背景下的切换经济账：Kirigami 原料成本、加工成本 vs POME 综合成本对比是否已闭环。

# 2.6 建议讨论点（GRID × Kirigami）

# 1.GRID I/II 已验证结论；III 相对 II 的核心变更（结构？切缝图案？活性物？）；DYSON 含义。

2.评审主线预判：用切割成型工艺（Kirigami/laser）做结构化 topical surge/liner，替代涨价且工艺复杂的 POME 方案——现场确认此框架。

# 3.切缝密度/图案（SemiCircle 10mm 是否最终版）与 rewet/扩散实测数据 vs 目标 rewet 0–0.3 g。

4.切割工序是在线还是离线；laser vs 机械切缝的机速、刀具损耗、成本曲线（waistband breathability 议题里二者并列待定 claim space）。

5.Kirigami 与 CleanShield 式“开孔+空隙”BM 控制机理是否兼容；开孔区若靠近腿口 gasket，是否成为新的最小阻力泄漏路径（与下午垫片场的交叉点）。

6.供应路线：KC 自产 vs 外购（Textor、Shalag、YanJan、Berry、Avgol 等样品池）；TRL 3–4 到 2028 Summer upgrade 的验证节点倒排。

# 7.与温度调节方向交叉：topical liner 叠加凉感/PCM 如何规避湿感悖论。

# 3. 模块二：10:30 工厂参观

口径风险：资料中无 “TJ” 缩写记录。以下按韩国大田（Taejon）KC 湿巾工厂备料。若 TJ 指天津，本模块不适用。

# 3.1 Taejon 站点定位

•KC 全球婴儿湿巾 converting 资产 8 处：Maumelle（美）、Tlaxcala（墨）、Cali PDC（哥）、Suzano（巴西）、Pilar（阿根廷）、Flint（英）、韩国大田（Taejon）、新加坡 Tuas。

# •coform 资产 7 处，与 converting 重合（Cali 无 coform）。

# •大田为亚太两站之一，同时具备 coform 与 converting 双功能。

# 3.2 Coform 技术现状

•成网机理：“Sheet formed by mixing air streams containing pulp and polymer”——浆流与聚合物流气流混合成形。

# •结构：TripleClean™ = 熔喷/木浆/熔喷三明治 + 压花。

# •功能分工核心句：聚合物纤维给湿强，浆纤维给吸收性。

# •单片物耗：木浆 1.34 g（约 200 万根纤维）+ PP 0.5 g（约 35 英里纤维），干重 1.84 g；浆实测占比 72.8%（高于标称 2/3）。

# •全球规模：10 条产线 / 20 banks / 年产约 400 亿片；年耗木浆约 5.36 万吨、PP 约 2 万吨。

# 3.3 参观重点

1.工厂系统卫生（一票否决项）：“Preservatives … Do NOT protect against systemic mill hygiene issues”。看水系统、储罐/管道清洗周期、沉降菌/浮游菌记录。

# 2.压花单元与克重控制：Tier 4 基线 53 gsm。

# 3.折叠/分配：interfolded 易粘连多片抽出，看其解法。

4.若含纸尿裤产线：重点看 T5 Double Turn Bar（topical liner）工位与 gasket 施胶/弹性件工位——衔接上午 GRID 与下午垫片议题。

# 4. 模块三：13:00 垫片（Gasket）工艺深度讨论

口径修正：垫片 = gasket（防漏屏障件），指腰围/腿围/翼片 gasket 及 gasketing 有效性。原 pad forming 备料见附录。

# 4.1 Gasketing 在尿液管理中的位置

KC 尿液泄漏管理五大支柱：Target Zone Capacity → Intake at Rate of Insult → Free Fluid Control → Bucket Volume → Gasketing（有效屏障系统）。

定义：Gasketing = 材料性能、位置及与其他部件的粘合，应阻止失控尿液沿最小阻力路径（tunnels、channels、holes、gutters、seams）逃逸。具体涉及 waist / leg / flap 三处 gasket。

# 4.2 测试方法体系

•Gap Test（液柱高度测试）：测量 gasketing 元件失效前能撑住的液柱高度；输出=液柱高度；用途=评估 gasketing 设计变更影响、表面张力影响。

# •Clear mannequin（透明假人）：识别失效模式。

# •Flap hydrohead（翼片静水压）：翼片抗渗性能。

# •Outercover pinhole test（外层针孔测试）：外层泄漏。

# •MOCON：透气性。

# •SAM poke-through（SAM 抗刺穿）：SAM 抗刺穿强度（在 gasketing effectiveness 测试包内）。

测试液关键点：0.9% NaCl 血库盐水 + 0.1% 牛磺胆酸钠（STCH），将静/动态表面张力降至尿液水平——含 gasket 的测试必须加 STCH（TL-16147）。

# 4.3 典型失效模式（KC 内部命名）

# •Flow Underneath：贴身面下侧渗流。

# •Tunnel Leakage：通道泄漏——“No adhesive to stop fluid flow”，粘合缺失是根因。

# 4.4 弹性件与专利侧

# •腿围 gasket-cuff 弹性区设计可引专利 JP07308341：曲线形弹性区（聚氨酯泡沫/Spandex 弹性片材粘合于 gasket-cuff）。

# •腰部弹性（SOAR4，T5+）与 gasket 的接合工艺为 T5 升级项。

# 4.5 建议讨论点

# 1.当前 TJ 产线 leg / waist / flap gasket 的弹性件选型（橡筋规格、氨纶/弹性片材）与施胶路径、粘合工艺参数。

# 2.失效模式分布：Flow Underneath / Tunnel Leakage 各占比例？Gap Test 液柱高度基线值？

# 3.粘合缺失（Tunnel Leakage 根因）：喷胶 vs 超声、胶量监控、在线检测手段。

# 4.测试侧是否使用含 STCH 的标准液做 gap/leakage 测试；clear mannequin 失效分析频次。

5.交叉议题（连上午 GRID）：Kirigami/GRID 开孔区若延伸至腿口或腰口 gasket 区，是否制造新的最小阻力路径？孔洞边缘的毛细通道对 gasketing 的影响评估。

# 6.SAM poke-through：gasket 区受压集中，SAM 与底层材料的抗刺穿表现。

# 附录：Pad Forming 备用资料（若“垫片”实指 shims / 芯体成型）

# A.1 验收目标

高垫层完整性 / SAM 损伤少 / 克重正确（含 zoned pads）/ 低 CoV / 无结块硬点。

# A.2 纤维化设备产能

# •PCMC / Williams 锤磨机：4,000 lbs/hr

# •JOA 纤维化机（推荐标准）：3,000 lbs/hr

# •Kamas 解纤机：2,200 lbs/hr

# •JOA 盘式磨：500 lbs/hr

1 g 绒毛浆约含 400 万根纤维。

# A.3 DBK 模块 trade-off

DBK Gap（center）越小 → Pad Integrity 越好，但 Softness 越差、SAM 压破风险增加；Gap 由 Shims 在 center/side 调整；新增毛毡辊改善 DBK 粘胶。Integrity/Softness/SAM 完整性三者取二。

# A.4 SAM 计量

气力输送（4,500 ft/min，占地省但伤 SAM）vs 重力下落（SAM 友好但占夹层空间）。

# A.5 FPC 切断（1,000 DPM 示例）

Cutter 线速 500 m/min；XXL 码 pad 420 mm / 420 m/min；Knife Roll 6.27 inch / Anvil Roll 12.48 inch；MAX pad 长度必须小于 Anvil 弧长。
