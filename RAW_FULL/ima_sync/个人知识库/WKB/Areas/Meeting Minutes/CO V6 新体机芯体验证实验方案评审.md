### （七）实验顺序与合并


实验顺序按操作便利性排列，可打乱、可合并调整（不像上次有依赖关系）。


合并方案（议定）：Code 1 与 2 合并；Code 6/7/8/9 合并（Code 2 形状与 678 不同但系边缘问题，可现场看）；Code 3/4/5 必须单独开（需调 SAP 密度，整辊都要变）。


Code 9 因 365mm 宽度长度，一辊四个，中间有不需要的区域——按密度计算长度，辊上跑长一些，剪切时剪短。


形状选择：艳恒下班前导出侧躺测试数据，据此决定 Code 9 用大扇尾还是长方形。


### （一）Code 1–5 设计要点


导流槽设计：听取老板建议，导流槽方向需有引流作用——后端向后、前端向前。后续将通过 Code 平行对比，验证在中间导流槽两边再增加导流槽，能否提升液体横向扩散性能，从而改善吸收时间及回渗（两个实验目的）。


Code 1/2：整体形状沿用上一轮“大扇尾”设计（前端 110、后端 135），两码可放到同一滚子上试验。


Code 3/4/5：无需花型变化，仅调整 SAP add-on：


Code 3 的 SAP add-on 参照目前 X pad 的 SAP 密度核算，上下层各 6.8 克；


Code 4/5 用于探究 SAP 密度上下限，数值暂为拍脑袋预设（如 Code 4 上下层各 6 克），待现场测试性能趋势出来后动态调整。


胶量：因 SAP add-on 变化，胶量需相应改变。目前暂放一个 TPD 值，届时现场快速查看完整性后再定胶量。


排产安排：前五个 Code 可放到一个成型辊上进行安排。


### （二）导流槽工艺与浆板说明


上次试验用浆板制作导流槽，浆板 8 毫米，实际导流槽 10 毫米。第一轮新体机安装时对比过浆板与贴纸，浆板效果更好，导流槽边界更清楚，因此本轮继续采用浆板 8 毫米设计，图纸均按 8 毫米绘制。


## 三、清水胶（芯片胶）实验计划（大爷介绍）


背景：汉高反馈该胶与 2820 使用情况一致，中国区在胶量、胶型上均无进一步研究，信息空白；有降胶量的潜在优势但未明确可降至多少。


原方案：8 个 Code = 2 款芯体形状（现有 commercial 直条无 channel ／ 带 channel 的高潜力 Code）× 2 款胶量（3.5 GSM 与 V2 结构一致的较高胶密度／降至与 copy 一致）× 2 种胶（新体胶与结构胶 2820）。


讨论后调整（议定）：


无 channel 的验证意义不大——芯体机工艺与 copy 不同，若只为 copy 验证可直接上产线做 ISR；


决定基于婷婷最佳 Code 换胶并调胶量：八月份实验 focus 在最佳 pattern 筛选，清水胶实验推迟至九月份，与九月原材料筛选实验合并进行（届时花型结论也更明确）；


实验规模缩减为四个 Code（含一个婷婷现有 Code 作为 control，另取 2 个胶量变化档）；若 control 直接沿用婷婷现有 Code 数据，可再缩减至三个 Code；


评估维度：以导流扩散、吸收时间为主，其他性能同步评估；


清水胶 benefit 评估也可交由 DNC 在未来材料实验中穿插验证，如无帮助则后续材料不再考虑。


曼姐补充信息：


晶体胶由两个胶缸单独供应，LSN 与 PSN 共用一个、喷在吸水粉上（相当于 IEL 两侧）；


胶实验本身较耗时（排胶到胶量离线确认需较长时间），预订机时需提前商定时长。


## 四、去味粉样品准备方案（思杰）


实验设计（三款）：


款 1：现有 control 基础上，上层芯体混 0.25 克去味粉；


款 2：上层芯体混 0.5 克去味粉；


款 3：上下层各混 0.25 克，合计 0.5 克。


混料方式讨论（核心难点）：


手工实验室无大规模混料能力（需求量大，且涉及 EHS 粉尘管控/实验室污染，自行混料不可行）；


首选方案：委托 SAP/西瑞供应商（诺尔）预混——告知供应商“提供颗粒，与吸水粉按比例均匀混合后做成小样袋交付”（如 1 公斤颗粒配 200 公斤吸水粉）；供应商有专业混合工艺，最低混合量约 200 公斤（吨袋边小型混合装置），实验室亦可混约 50 公斤；国内复合芯体供应商（如美灯）早已用类似方式混五六种 SAP；


Chris 负责联系诺尔确认一捆最低起订量，思杰核算所需公斤数后对接；


备选方案：自购小型桌面干粉搅拌设备自混——需先约 EHS 会议确认可行性（职业健康与工厂粉尘管控要求严格，除尘器已外包每日检查）；若 EHS 会议需要，设备方一起参加听取意见。


上料工艺问题：


混合粉必须抽吸上料（芯体机为间断性抽吸，料满自动停止）；储料桶能否人工倒料需永生到现场查看设备确认（上盖是否可开）；


运输过程震动可能导致粒径/密度不同的材料分层，预混比例与最终进入产品的实际比例可能不一致，无法精确验证；


与思杰确认实验目的：目前以定性验证去味有效性为主，非精确定量——若非精确定量则方案仍有价值；也可多设几个添加量看统计趋势，或采用手工样方式（拆开芯体手动撒粉，保证每片总量准确但均匀性差）再进一步评估。


传月工艺认证情况（腾哥）：


出料口可密封并用泵间断式抽到 hopper，无问题；


主要卡点：两种不同粉的自动进料需投开畅自动进料称重桶（约六七十万元以上，不划算，不值得为一次实验投入）；人工称重则存在灌入混合机时的粉尘防护问题，尚无成熟方案；


结论：该实验可能延至九月或十月，待找到合适的防粉尘方案后再做；下一步先看诺尔预混的反馈。


## 五、Be Max（三叶草纤维）与巴西项目相关讨论（会后补充段）


重要结论：Be Max 不会用于 COQ V6。Be max（别称 affordable manner，定位为“买不起 3D 加加”的替代方案）的 50 克上下层结构（上 25/下 25）与现有方案逻辑不同，仅适用于巴西等单独折扣项目；


巴西项目 30 克 GSM：上下各 15 克（有 15/15 与 13/13 等搭配），由岩江复合绑定后作为 top sheet，到传月再超声绑定 ADL，八十二宽度规格；


三叶草纤维开发目的：给客户做 V6；两个 Code 设计——①上层放 10% 三叶纤维（2 弹+4 弹）、下层不放；②上层不放、纯下层放；每个 Code 需 6000 米，供应商光调试就要 4000 米，三叶纤维已让供应商加量备 100 公斤，其他原材料按 6000–8000 米备料；若纤维量不够则先保一个 Code；该实验下下周（约 9 月初）执行，需跑不同温度以在强度与纤维形态保留之间找平衡点；


IEL 材料：因需上机，准备 300 米/卷 × 6 卷 = 1800 米，只能低速跑，尽量做长（明面生产）；另有 102 宽度的 Be max 相关物料只能做手工样，约需 100 米；


诺尔 SAP 新品：诺尔新推出一款高 GBP 的 SAP（接近 40，现有约 24–28，略牺牲 CRC），参数上 promising；九月中赴韩国回来后，快速过 ICP 混合量，九月底进行 ICP 实验（材料实验需一个材料一个材料试，避免耦合干扰，暂无精确成本信息、尚未 VO）。

## 二、COQ V6 新体机芯体验证实验方案（Code 1–9）


### （三）绑定（Bonding）方案讨论


本轮所有花型中间均有导流槽，实验中将统一加上中间的 binding（目前仅中间竖条，与 Python 不同）。手工样将用超声波方式包一下。


工程部不同意见的说明：8 月 14 日会议中，工程部基于 ND5 的 ETR 实验（SpaceS 相关测试）提出“压得越实、绑得越牢，越影响吸收（牺牲时间变慢）”的结论，与 Space S 设计思路相反。会议决定：不采纳该结论干扰本轮实验，按自身实验方案执行。


超声波绑定 vs 胶水热合的关键差异（重要发现）：


超声波绑定的优点是不用胶，缺点是对基材热熔纤维有要求；超声波的封顶不提供毛细作用；


用胶绑顶则自带一定毛细渗透，可能引起拍痕之间的相互渗透差异——这也许正是工程部实验结论背后的真实原因（可能仅是毛细差异）。


九月实验计划：将定制一套 embossing 辊（两个压辊），拟在 9 月实验中安排超声波 bonding 与胶水热合 bonding 各做两个 Code 平行对比，验证两者对毛细方面的影响。


设备与安装安排：


腾哥确认两个压辊九月份可以 ready（做两个压辊速度较快）；

### （五）局部区域 SAP 密度测试方法讨论（重要技术议题）


问题提出：新体机开口 screen 孔径全板一致，未针对裆部做大孔径设计；理论上改变 shape 后，更高的 SAP 密度只是平均分配到新形状，并未向 crotch 集中。


不同观点：


供应商说法：下料均匀，收窄区域会把 SAP 集中，理论上收窄区 SAP 密度更高，channel 形状也会把 SAP 推向周边，但稳定性存疑（如稳定在 380 可接受，若在 360–400 波动则只能看趋势）；


现场经验：每片 CUV 稳定性较好，撕开目测未见 SAP 明显堆积或不均；


疑虑：跌落稳定但风压未变（提高风压唯一途径是 screen 孔径差异化），SAP 可能实际已平均分配至两端，仅总密度高于未收窄版本。


验证方案（议定）：


下一轮取样时（以 Code 1 为例），将中间区域与前后大扇尾区域各裁固定长度，分别称重测 SAP 分布（重量法最简便）；


需注意材料波动可能覆盖差异，且 fluff 在现场分配不稳定，结果精度有限，先试做；


未来 COQ V6 工艺验证方向：在 crotch 处将 screen 孔径做大于两端，增大 airflow，形成两维调节 SAP 密度的工艺能力（目前只能一维）。


### （八）关于未来 Marketing 概念沟通


上线时间：最早离线版 2028 年、在线版 2029 年，提前两三年让 marketing 准备概念不现实；


路径共识：先基于性能找最佳设计，未来再围绕最佳设计挖掘概念/claim，而不是为概念改 pattern；


当前阶段是确认平台能力（与 channel 高度相关）而非确认最终 feature；今年 Q3/Q4 定 design 框架，但不会是最终 commercial 版——上市时可能 6/6.5 各用不同 pad，届时允许微调（如叉枝弯直等）；输出为基础 channel + guideline，供 DNC 落地；


建议：后续与 marketing/com team 沟通时提前讲清此逻辑、提前“吹风”，避免过早介入造成 comments 干扰。


### （四）Code 6–9 设计要点


共同变化：Code 6 起，前后宽度一致均为 135（此前大扇尾为前 110/后 135），目的是验证前后均为大扇尾对防前漏、后漏是否有进一步提升。


Code 6：在 Code 2 基础上把前端加宽。


Code 7：针对“中间导流槽太长、液体顺导流槽冲出”的担忧，缩短导流槽长度（前端距离由 42.5 改为 100），主要测试前趴姿势下的趋势。


Code 8：在 Code 7 基础上，前端增加一条横向导流层，验证液体冲到前面时能否起到格挡并向两边扩散的作用。


Code 6–8 的 SAP add-on 均维持 15.5，胶密度不变。


Code 9（重点讨论）：


背景：此前样品均在 Pans XXL（宽 120）上制作，而目前实验基于大扇尾宽度；第一轮实验优胜者为海王与大扇尾；T6 到 T5.6 的 XXL 芯体宽 145，PA 宽度最多容忍到 135；


结论：大扇尾与 channel 技术平台不冲突（仅包裹时略宽），建议 Code 9 沿用大扇尾宽度 135，使未来 dapper L 以上与 Pans XXL 宽度统一为 135，但 Pans 侧芯体宽度需加宽（可维持 145，两边留量少一些）；


前后宽度确认为前端 110、后端 135（与第一轮实验数据可对比），中间最窄处 80；


风险讨论（重要）：中间收窄至 80 有利于合身性，但存在漏尿风险——侧躺时液体窝在折叶处、离芯体边缘太远易漏；且中间比现有 110 更窄，会“变出一个小窝”。U 型状态下液体集中在裆部，裆部总吸收量偏低。建议：部分 Code 保持现有长方形、部分保持大扇尾，对比 risk 大小；侧躺人偶测试今天下班前出结论，若与 control 无明显差异则维持大扇尾设计，若有差异则考虑 Code 9 改回长方形（第一轮有长方形对比数据）；若 banking 有差异，前八个 Code 也可反算对比；
