#   紫华公司与KC团队技术交流会议纪要

会议时间:2026年6月2日

会议主题:紫华公司与KC团队技术交流会议

#   参会人员:

● 紫华团队：沈总（介绍人）、Jacky付（研发副经理）、查理（销售/英文沟通）

● KC团队：HW、CW(EM研发负责人)、Grace、Chris、艾米(采购)、李一凡(膜/弹性材料)、潘妮/Penny(AFC膜/印刷/胶)等

#   主要内容：

1.紫华公司及集团背景:紫华隶属紫江集团(80多家企业),1996年成立,是国内首家流延PE膜供应商。2025年11月集团在越南成立首家海外子公司“紫日”,未来紫华拟在越新建卫材工厂(选址将靠近KC客户)。

2. 合作历史与在推项目：双方自1999年合作至今27年。当前在推项目包括KC Soft Test BCCC (Sweety项目，6月上机)、KC VN (Purple项目)、KC China (ACE 1C 15g认证中）及拉美 AFC业务。

3.产能与设备:总产能25,000吨/年，流延/吹膜线速均为行业最快(250米/分钟，日产能15吨)。可供KC产能各200吨/月。柔印最多6色(无双面印刷)。是KC China首家VMI供应商。2026年计划落地自动包装项目(行业首创，以降低毛发/异物风险及罚款)。

#   4.市场与技术分析:

。亚太市场BCC底膜以吹膜和流延膜为主，流延膜成本更低，吹膜可做更低克重(12g)且适应高速线。紫华已储备12-13g吹膜产品，目前瓶颈在物理性能。

。WVTR测试:紫华用失重法,KC China用增重法,数据约2倍关系;KC正推动向ISO标准统一。

° 渗漏测试：KC China使用达因液加压测试(较人工经血严苛)，双方需协商确立适用于 BCCC低克重膜的测试标准。

5.技术创新:演示了智能包装(导电油墨尿液报警,尚在优化);可降解材料(PLA/PBAT、纸包膜)已有能力但成本高昂(3-4倍)。

6. 原材料：碳酸钙采用进口表面处理钙粉(合成、金发供应)，不自产；茂金属供应商为埃克森美孚等。

#   下一步计划:

● 信息共享: 紫华提供机器能力表、越南紫日具体位置及KC China达因液测试标准; KC确认Family Care与BCC产品规格。

● 标准对接: KC协调全球测试标准，双方商定BCCC低克重膜渗漏标准。

● 产品开发：紫华优化12-13g吹膜物理性能、推进自动包装落地并分享视频；评估双面印刷需求(KC提供趋势)。

●项目与越厂：双方跟进Sweety/Purple项目；KC提供越南2-3年底膜需求以便紫华评估设厂；KC采购协助对接EM部门。

#   恒碳公司与KC团队PTT材料合作交流会议纪要

会议时间:2026年6月2日

会议主题: PTT材料合作交流会议

#   参会人员:

● 恒碳团队:李总(PTT材料供应商)、杰米/杰敏(前期对接人)

● KC团队: Chris (材料开发负责人)、Chris (BCCC材料研发)、采购(待跟进)

#   主要内容：

1. 背景与诉求：KC急需PTT材料低成本替代方案（此前华丰报价过高）。恒碳采用非粮粗甘油转化PDO再合成PTT路线，成本较华丰低10%-20%，具原料优势。

2. 产能与销量：恒碳现有7000吨和5万吨两条产线，但当前月出货仅几十吨，亟需订单支撑以开满5万吨线。

#   3.应用需求讨论:

○ 项目一（优先启动）：Side-by-side PTT/PET并列双组分短纤维，用于尿裤中间层弹簧填充（hold住SAP）。PTT替代PET可降克重5-6%，KC要求同等克重下厚度增加20%-35%。中国区预期用量80-100吨/月。

○ 项目二（暂缓）：PTT熔喷布用于弹性外层替代三层复合布。因熔喷难度大且需预拉伸，KC表示取决于价格。

4. 样品与供应链：恒碳已提供PE/PTT ES纤维样品（厚度提升显著）。生产将由合作纺丝厂完成（6月出样）。KC提出独供要求，需签NDA及JDA，且供应链需确保无KC禁用物质。

#   下一步计划:

● 打样与测试：恒碳尽快安排3D/4D/7D、长度38mm和51mm(待KC确认)的并列双组份短纤打样(2-5kg)；KC提供卷曲度、收缩率等目标参数。

● 协议与合规：KC采购安排签署NDA/JDA；恒碳自查供应链禁用物质。

● 信息共享：恒碳提供公司Profile及PPT；确认纺丝厂配合度。

● 优先级与后续：立即启动项目一（目标2026年末/2027年初出结果）；项目二待价格驱动再议；探索化妆品面膜无纺布交叉合作。

#   格菲林与KC团队技术交流会议纪要

会议时间:2026年6月2日

会议主题:格菲林与KC团队技术交流会议

参会人员:

●格菲林团队: Johnny Wong(海外事业部)、乔总(淮安工厂)、李晓波(国内KC业务)

● KC团队: HW Park (EM MBCC研发经理)、一凡、潘妮、Chris (IPC BCCC开放创新)

#   主要内容：

1.公司概况:格菲林2011年成立,广东民企,广东排名第一、全国前五。2026年淮安新厂投产后总产能将从3万吨扩至6万吨。

2.设备与工艺能力:

○ 佛山南海:13条生产线，15条后加工线，1条研发小试线，1条离线喷涂线（0.5%-5%涂层比例）。

○ 异物控制:4个检测点覆盖,全产线装德式金属及异物检测器($>0.5mm^2$),获QAP 87 分。

3.淮安新厂规划:预计2026年8月建成，8条线（6条双梳理，2条三出/三梳理)，幅宽4.2米。采用蒸汽加热降碳，引入西门子控制及全自动包装。“三出”设备系与特吕茨勒合作，可在中间层加入ADL等功能层（最多5层控制）。

4.海外扩展:埃及工厂(2027年底完工，4条双梳理线)及美国佐治亚洲工厂(1条小试线，依赖本地及泰国纤维供应)。

5.产品创新与建议:

○喷涂/滚涂:淮安厂规划3条喷涂线(升级独立电机及蠕动泵控流);KC建议增加滚涂能力以覆盖更多工艺,格菲林表示将评估引入。

○ 3D压花与三梳理：格菲林将推进在线3D压花；KC要求尽快明确“三梳理”产品的具体应用方案与市场定位。

○ 样品反馈：格菲林去年底提供10余个软度样品，待KC反馈排名。

#   下一步计划:

● 数据共享: 格菲林提供产线产能、设备参数、可用产能及后加工能力汇总表。

● 样品与开发：KC反馈软度排名；格菲林准备在线3D压花样品，评估引入滚涂设备方案，明确“三梳理”产品初始方案。

● 标准与协调：对齐全球测试标准；KC采购协助对接EM部门。

●后续会议:格菲林发送完整资料，8月淮安新厂 ready后安排KC参观，并召开第二轮技术研讨会。

#   Huayi集团创新非织造布技术交流会会议纪要

会议时间:2026年6月2日

会议主题:创新非织造布产品技术交流

#   参会人员:

●金佰利(KC)团队:EM BCCC研发负责人、原材料开发与工程团队负责人、李一凡、潘妮、Damon(无纺布/高分子/协调)、IP代表

● Huayi集团团队:研发总监、总经理/业务负责人、业务代表

#   主要内容：

1. Huayi集团背景:37年非织造布经验，亚洲4个基地15条产线，总部及研发在泰国，视创新为首要目标。

2.核心技术讨论:

0.6旦热风底布:展示蓬松型与光滑型(Omega烫平)。金佰利指出25gsm成本过高(主流18-22gsm),且20gsm样品有“扎点”、梳理不均;建议走1.0D-1.2D配18-20gsm的商业化路线，并优化碳素网及梳理工艺。

○ 打孔材料：Huayi自有机速90m/min偏慢，孔洞均匀性不足、易变形。金佰利建议开发力度更小的打孔工艺以保持孔型。

° 3D压花(TR与ET): TR三辊技术为核心创新,解决了传统压花中空问题,3D效果及厚度保持率优异,2.5米辊宽可量产;ET为单热轧辊,立体感较弱。

° DID立体面层：利用热风成型保留蓬松感，已在金佰利越南商用。痛点是图案清晰度不足(后续喷胶分切导致立体感损失)。Huayi正开发第二代DID（填充5mm PET短纤维增支撑），预计8月泰国量产。

°双功能导水面层：上层疏水、下层6旦亲水的复合材料，保持皮肤干燥。当前处于研发阶段，存在条纹间距不一致和压痕问题。

#   下一步计划:

1.资料提交:Huayi会后补发含1-3年产能扩张、特殊产品能力及设备产能的详细PPT。

2. 工艺优化: Huayi重点解决20gsm样品纤维梳理不均导致的“扎点”问题;并针对图案清晰度、3D持久性等痛点纳入研发改进。

3.内部评估:金佰利内部评估1.0D/1.2D、18-20gsm方案的成本与性能平衡。

4. 产品跟进：双方跟进第二代DID8月份量产进展，并安排后续样品评测。

5. 后续准备：金佰利团队（潘妮/李一凡）整理当前使用胶种及痛点列表，为后续与汉高等胶粘剂供应商交流做准备。
