# Huayi集团创新非织造布技术交流会

打孔材料 (Perforated Material)：


技术与样品： Huayi展示了多种打孔花型，包括在线生产（in-line）和离线生产（off-line）的技术。


工艺困扰： Huayi自有技术制造的非织造布打孔机，速度为 90m/min，低于普通平网的130m/min，且形成（formation）均匀性不足，存在孔洞连接、大小不一、卷曲时孔洞变形等问题。


金佰利建议： 建议Huayi开发力度更小的打孔工艺，以利于孔型的保持率，尤其是对于内部卷曲张力大的位置。


3D压花系列 (3D Embossing Series) — Tri-Rollers 与 ET：


Tri-Rollers (TR) 技术： 这是Huayi的核心创新工艺，使用三辊（凸辊、凹辊及梳理纤维所用风嘴）在线生产。


优势： 解决了传统压花工艺中纤维层与层之间的“中空”问题，使压花图案的3D立体效果和厚度保持率远优于传统压花。TR工艺辊宽达2.5米，具备量产基础。


ET压花： 另一种花型，工艺为单热轧辊，结构相对简单，立体感不如TR。


DID 立体面层 (DID Top Sheet)：


技术原理： 区别于传统模具压制，DID利用热风将纤维吸入成型网中成型。其优势在于不压实纤维，保留蓬松感，有利于液体疏导和隔湿，液体的流动性好于被压实的传统压花。


应用现状： 该产品已被 Casey Vietnam (金佰利越南) 用于商业化生产。


客户反馈与挑战：


核心问题： 图案清晰度不足。在成品中，经过喷胶、分切等工序后，立体感会损失，且图案不够清晰。


回复装置尝试： Huayi曾在马来西亚金佰利工厂安装了“回复装置”（通过热风吹拂使被压扁的蓬松区域回弹），可恢复约20-30%厚度，但后续的复合压花又会使其失效，因此改进效果有限。

### 二、 核心技术讨论要点


热风底布 (Air Through Backsheet) — 0.6旦技术：


产品展示： 展示了 0.6旦 超细旦热风底布（25gsm及20gsm样品）。


两种类型： 一种为蓬松型（Bulky），采用多层纤维结构（如0.6旦+1.8旦），手感厚实、抗拉强度高；另一种为光滑型（Smooth），通过Omega烫平辊加工，手感丝滑。


技术反馈与要求（金佰利方）：


克重与手感： 金佰利主流外底层克重在 18~22gsm，主流旦数在 1.0~1.5D。认为25gsm对于尿裤外底层成本过高。


纤维细度导向： 行业趋势是向超细旦发展，使用0.8D细纤维配合适当蓬松度，可替代更高旦数的粗纤维手感。


关键问题： 20gsm样品手感有较多“扎点”（Snap/疙瘩），纤维梳理不均匀，影响品质。金佰利方建议Huayi调整碳素网（carbon wires）或梳理机工艺来解决。


商业化建议： 从商业角度看，1.0D~1.2D的纤维配合18~20gsm的克重，是更具性价比且能满足需求的路线。


纤维来源： Huayi目前使用国内福建供应商的纤维。

第二代DID (DID Gen 2)： Huayi正在开发改进版，通过填充 5mm长的ET (PET) 短纤维到凹凸结构中，增加支撑性和饱满度，改善图案的清晰度、耐用性以及抗变形能力。


量产时间： 8月份可在泰国量产。


双功能导水面层 (Double Function ID Layer)：


产品概念： 一种亲疏水复合材料，上层为疏水条纹，下层为 6旦的亲水纤维。


应用设想： 应用于纸尿裤面层，宝宝屁股压在上层疏水区域，始终保持永久干燥，液体可快速被导流到下层的亲水区域并被吸收。


当前状态： 仍处于实践和研发阶段。存在条纹间距不一致（因切割拉伸导致）、压痕等问题。


间距调整： 条纹间距最小可调整到 5mm。
