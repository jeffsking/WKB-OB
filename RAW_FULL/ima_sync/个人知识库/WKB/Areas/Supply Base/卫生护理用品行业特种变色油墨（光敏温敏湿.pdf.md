# 卫生护理用品行业特种变色油墨（光敏温敏湿.pdf.md

8
卫生护理用品行业特种变色油墨（光敏/温敏/湿敏）全球主要供应商调研报告

# 一、行业背景与技术要求

在卫生护理用品(如婴儿纸尿裤、成人失禁用品、妇女卫生巾、智能宠物垫等)行业，变色油墨主要用于尿湿指示、体温感应和防伪互动。由于该行业产品直接接触皮肤(甚至私密部位)，且使用者多为敏感人群(婴幼儿、老人、经期女性)，因此对油墨的安全性有极严苛的要求:

1. 环保与安全:必须不含双酚A(BPA-Free)、无甲醛、无重金属。

2. 皮肤无刺激：需通过细胞毒性、皮肤刺激性和致敏性测试（如 ISO 10993 标准）。

3.工艺适应性:需在无纺布(Non-woven)或PE透气底膜上有极佳的附着力，且耐摩擦、不浸润、不穿透。

# 二、核心生产商详细介绍

## 1. 日本松井化学 (Matsui International Company, Inc.)

●公司介绍:全球智能变色材料与特种油墨的奠基者与行业巨头。其微胶囊包裹技术在全球处于绝对领先地位，率先解决了特种油墨在母婴接触面料上的环保安全难题。

· 主要产品：

° Chromicolor® 系列 (温敏)：精准控制变色温度。

○ Photopia® 系列（光敏）：紫外线感应变色。

° Hydrochromic 系列 (湿敏)：高端水性遇水显色/消色油墨。

●产能规模:拥有日本及海外数个现代化高产能基地，年产特种变色微胶囊及油墨数千吨，供应链极其稳定。

●主要应用场景:高端婴儿纸尿裤的动态尿湿指示线(遇水由黄变蓝);母婴用品外包装及湿巾盖的紫外线强度提示。

●主要客户:宝洁(P&G帮宝适)、花王(Kao妙而舒)、大王(Goon)等国际一线日化巨头。

## 2. 美国 CTI 公司 (Chromatic Technologies Inc.)

●公司介绍:全球最大的功能性变色油墨供应商之一，技术重心在于微胶囊的耐高温稳定性与精准变色区间断裂。在医疗、食品包装及卫生护理等特种显示领域市场份额极高。

· 主要产品：

°High-Definition Thermochromic (高性能热敏):可定制在特定人体体温(如37℃或38℃)时发生色彩突变。

° Photochromic & Hydrochromic (光敏/湿敏)：环保型水性无毒系列。

●产能规模:全球化工厂布局，特种油墨日产能达数十吨，具备极强的跨国大批量订单交付能力。

●主要应用场景:智能成人失禁用品(体温/尿液成分感应)、医疗级无纺布手术衣/垫的无菌与湿度指示。

●主要客户:金佰利(Kimberly-Clark)、爱司开及多家欧美大型医疗卫生用品集团。

# 3. 深圳市千色变新材料有限公司 (Qiansebian)

●公司介绍：中国本土特种变色材料的领军企业，国家高新技术企业。具备从变色微胶囊颜料研发到成品功能油墨制造的完整产业链，在国内市场占有率名列前茅。

· 主要产品：

°感温变色油墨、感光变色油墨:针对塑料、无纺布、油墨基材有多种配方。

° 遇水变色(湿敏)水性油墨:环保无毒，专为卫品底膜设计。

●产能规模:华南及内地设有大型现代化生产基地，成品变色油墨年产能超500吨。

●主要应用场景:国内各大品牌婴儿纸尿裤、拉拉裤的尿湿指示线;宠物排泄垫的湿度互换显示。

●主要客户:广泛供应于国内头部卫品OEM/ODM大厂(如豪悦护理、百亚股份、可靠股份、延江股份等供应链体系)。

# 4. 长沙新诺新材料科技有限公司 (Xinnuoxin)

· 主要产品：

●产能规模:拥有专业微胶囊合成车间及自动化油墨复配线，年产能约200-300吨。

●主要应用场景:中高端母婴护理用品、功能性智能无纺布、包装防伪标识。

●主要客户:国内华中、华东地区的无纺布复合膜加工厂、新锐国货纸尿裤品牌供应商。

●主要应用场景:功能性妇女卫生巾(温度/健康感应测试点)、高档透气PE膜印刷、母婴湿巾包装互动。

# 三、变色油墨在卫生护理用品中的主流应用方案对比

|油墨类型|核心变色原理|在卫品中的典型应用位置|主要功能卖点|安全资质要求|
|---|---|---|---|---|
|湿敏油墨(水变)|遇到水分(尿液)后,无纺布或PE膜上的油墨树脂溶解或发生化学结晶反应,由无色/黄色变为青色/蓝色。|纸尿裤、成人失禁裤、宠物垫的底膜内侧。|提示父母或护理人员及时更换,防止红屁股或褥疮。|必须不含双酚A,通过皮肤无刺激测试,严禁向外渗漏色料。|
|温敏油墨(热变)|随着局部温度升高(如达到人体$37^{\circ}\text{C}$以上),微胶囊内部电子转移导致颜色由有色变无色,或由一种颜色变为另一种。|智能卫生巾中心感应区、成人护理床垫。|体温及热舒适度提示,或部分产品作为经期健康/炎症风险的辅助预警。|极高的热稳定性和皮肤接触安全性。|

|光敏油墨(光变)|微胶囊吸收阳光中的紫外线(UV)后,分子结构发生改变呈现颜色;回到室内失去紫外线后恢复无色。|母婴湿巾塑料盖、包装袋外侧、纸尿裤腰贴外侧。|防伪标签以及户外紫外线强度提醒,主打品牌营销与互动。|符合食品/化妆品包装级环保标准(FDA/EN71)。|
