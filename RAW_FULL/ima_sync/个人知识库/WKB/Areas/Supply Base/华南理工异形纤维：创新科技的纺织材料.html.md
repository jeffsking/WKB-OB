# 华南理工异形纤维：创新科技的纺织材料.html.md

2.三叶形截面纤维
三叶形截面纤维除具有优良的光学特性外,还具有较大的摩擦系数,因此织物手感粗糙、厚实、耐穿,比较适合做外衣织物。如三叶形长丝做针织衣料,不会出现勾丝和跳丝。
此外，在光学领域，三叶形光纤具有更高的传感灵敏度，可以应用在纺织品触摸传感器方面，还可以用作具有不同照明模式的照明元件及光学天线。
3.扁平形截面纤维
普通合成纤维易起毛起球，且由于纤维强力高，摩擦产生的球粒不易脱落，球粒会越积越多，严重影响纺织面料的外观和手感。纤维异形化后，由于纤维表面积增加，丝条内纤维间的抱合力增大，起毛起球现象大大减少。
扁平形聚酯纤维有良好的刚性和闪光性，不起球，可制作纬编起绒织物和仿丝绸织物。例如，德国J．FAdolffAG公司生产的“Adoff-polital”扁平形聚丙烯纤维可生产地毯和袋类产品。由美国CelaneseCorp公司生产的“Celafil”扁平形醋酯纤维长丝，具有闪光性和刚性，可做假发。

4.中空纤维
中空度(％)为纤维空腔面积与纤维截面积的比值，是描述中空纤维中空程度大小的指标。
保暖性和蓬松性：中空度越高，保温效果和蓬松性越好，并且吸湿性也较高，但强度相对降低。中空纤维由于具有空腔，可储存静止的空气，所以织物具有优良的保暖性和蓬松性且质地较轻，是制造保暖丝袜的原料。
抗静电性：中空形纤维抗静电性有所增加。例如，日本富士纺公司生产的中空聚氯乙烯纤维可用于纺制人造皮革。
此外，在生物医学领域，使用中空纳米纤维可以准确控制药物的量和靶点，对受影响的大脑区域进行局部给药。
5.十字截面纤维
十字截面纤维具有较大的比表面积，并且它表面具有众多的微孔或沟槽，能够达到快速吸水、扩散和挥发的效果，能迅速将皮肤表面的湿气和汗水释放到外层并迅速蒸发，因而常用于运动服中，保持身体干爽。
6.其它截面纤维
Y形截面纤维：光泽柔和，可用于仿真丝绸产品。
X、H形截面纤维：防污性好，可用于制作毛刷。
T形截面纤维具有闪光效果和山羊绒感，透气性好。
7.异形纤维增强复合材料
用异形纤维作为增强体来制备复合材料是其应用的一个热点。聚合物纤维增强复合材料的力学性能在很大程度上取决于纤维横截面形状，从结构力学的角度来看，异形纤维增强的复合材料在某些力学性能方面要优于传统的聚合物纤维增强复合材料。
 在汽车工业领域，汽车行业需要开发轻质、高性能及减噪的材料。中空纤维复合材料可以在减轻汽车整体质量的同时保持车身强度，从而达到提高汽车的燃油经济性和性能的目的。
在航空航天领域，用三角形、Y形、中空三角形等形状的碳纤维与玻璃纤维混杂编织制造的复合材料有着像消声器一样的微观结构，可以多次反射入射微波，达到吸收电磁波的作用，有助于提高电磁波的吸收率。

异形纤维的定义
在合成纤维仿天然纤维的过程中，人们采用非圆形喷丝板，制取各种不同截面形状的纤维或中空纤维，以改善纤维的手感、回弹性、起球性、蓬松性、光泽等性能，这种纤维称为异形截面纤维，简称异形纤维。异形纤维按其截面形态可以分为三角形、三叶型、十字形、多角形、多叶形、中空纤维等几种类型。市场上出售的聚酯纤维、聚酰胺纤维及聚丙烯腈纤维,大约有一半为异形纤维。
02
异形纤维的制备
异形纤维的制备方法主要包括以下几种：
直接法
采用所要求的纤维截面形状相似的喷丝孔直接进行纺丝，得到异形纤维，是普遍采用的方法。直接法制作的异形纤维是常规纺织面料采用多的一种原料，各种涤纶长丝纤维就属于这一种。
膨化粘着法
将喷丝孔制成相互靠近的圆形孔、弧形孔以及狭缝等，当纺丝时，由于纺丝细流的出口胀大效应而相互黏着形成异形纤维，中空纤维常采用该方法进行纺丝。
挤压法
利用热塑性圆形截面初生纤维在后处理时进行挤压而变形，从而得到异形截面纤维。
复合法
将两种或两种以上成纤高聚物制成复合纤维，再将复合纤维中的一个组分溶解除去或采用机械剥离的方法使各组分分离而得到异形或超细纤维，如将非黏合体熔体聚酯和聚酰胺制成复合纤维，再经剥离后可以制得多瓣型超细异形纤维。
造异形纤维的过程中，需要根据产品应用需求和性能指标选择合适的纺丝原料、喷丝头，同时调整优化纺丝温度、纺丝速度、冷却速度等纺丝工艺参数，从而保证纤维具有理想的形态及性能。
03
异形纤维的性能与应用
纤维截面异形化是改善合成纤维性能的重要方法之一，不同的纤维截面赋予纤维的性能也不同。
1.三角形纤维
三角形纤维的截面类似于蚕丝的截面，就像三角形的分光棱镜一样，入射光的单纤维分成各色光，后经单纤维表面进行反射使得此类纤维光泽夺目，有蚕丝般的柔和光泽。
三角形截面纤维大大弥补了日常纤维光泽差的特点。应用这种闪光效应具有真丝光泽的合纤织物,用三角形截面的有光异形涤纶纤维代替马海毛可用于制作女式大衣。
