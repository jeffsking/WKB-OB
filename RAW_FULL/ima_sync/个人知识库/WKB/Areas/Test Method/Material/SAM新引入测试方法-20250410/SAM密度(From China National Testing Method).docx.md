# SAM密度(From China National Testing Method).docx.md

8
WI-66080

SAM密度 (From China National Testing Method)

[图片: 密度仪]
仪器编号:

最新版本号：第1版           修订日期：2025年2月12日

实验目的：

仪器的准备：

# 1.打开天平，静放10min，用法码校准，以确保数值准确稳定。

# 2.将密度仪调制水平。

# 3.漏斗，容量大于120ml，且带有孔式节流阻尼或挡板，孔口内径40mm±0.01mm。

# 4.密度杯，杯筒容量100cm³±0.5cm³。

样品的准备：

# 1.SAM原材料样品，放置密封袋内（无需筛分）。

测试步骤：

# 1.将密度测试仪放置在平台上，调整三个脚上的螺丝，使其保持水平。将洗净烘干的漏斗垂直放置在密度杯中心上方40mm±1mm高度处，确保漏斗水平。

# 2.称取空密度杯的重量，精确至0.01g，并记录该重量为M1。

# 3.准确称取100g（精确至0.01g）试样，轻轻加入漏斗中，漏斗下方的孔式节流阻尼或挡板处于关闭状态。

# 4.快速打开漏斗下方孔式节流阻尼或挡板，让漏斗内的试样全部自然落下。

# 5.用玻璃棒轻轻刮掉密度杯顶部多余的试样，不应拍打或震动密度杯。

# 6.称取装有试样的密度杯的重量，精确至0.01g，并记录该重量为M2.

# 7.计算试样SAM的密度，方法如下：

试样密度（g/cm³）=（M2-M1）/密度杯体积

同时进行两次测定，取其算术平均值作为测定结果，结果保留至小数点后一位。

操作注意事项：

测试过程中，拿稳密度杯，注意砸伤。
