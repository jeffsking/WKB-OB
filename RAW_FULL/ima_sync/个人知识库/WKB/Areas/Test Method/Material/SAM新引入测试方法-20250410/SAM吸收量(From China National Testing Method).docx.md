# SAM吸收量(From China National Testing Method).docx.md

WI-66078

SAM吸收量(From China National Testing Method)

[图片: 3 59]
仪器编号：

最新版本号：第1版           修订日期：2025年2月12日

实验目的：

用于测量SAM颗粒在没有外力干涉的情况下，SAM颗粒能够吸收自身重量多少倍的水分，以便确认原材料的吸收倍数是否能满足生产需求。

仪器的准备：

# 1.打开天平，静放10min，用法码校准，以确保数值准确稳定。

# 2.封口机加热。

# 3.计时器分别倒计时 10min、30min。

# 4.茶袋，尺寸为70mm×70mm，透气性（230±50）L/min/100cm²（压差124Pa）。

样品的准备：

# 1.原材料：SAM100g,放置密封容器内。

测试步骤：

# 2.依据测试样品数量，取出相应数量的标准过滤袋，编号，称重，记录过滤袋重量M1。（用油性笔在过滤袋上编号，防止浸入水中融化）

# 3.称量0.200±0.001g SAM样品放入过滤袋内，用封口机密封。

# 4.在10×10×9.5cm的塑料盒子内加入0.9%生理盐水，高度以能够完全浸没过滤袋为准。

# 5.将装有试样的茶袋完全浸没在装有生理盐水的塑料盒子内，使SAM颗粒充分吸水，开始计时30min。

# 6.30min后，轻轻地将装有试样的茶袋取出取出，用夹子悬挂起来，静止状态下滴水10min。多个茶袋同时悬挂时，注意茶袋之间不应接触。

# 7.10min后，称量滴水后茶袋的重量M2，记录数据。

# 8.计算样品 SAM吸收量的方法如下：

吸收量= (M₂-M₁-过滤袋吸水克重-0.2)/ 0.2

过滤袋吸水克重：干的空的过滤袋吸水30min后，沥水10min后的重量，减去吸水前过滤袋的重量。可以通过试验得到一个常用稳定数值参与计算。

同时进行两次测试，算术平均值作为测试结果，结果保留小数点后一位。
