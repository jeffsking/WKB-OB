# SAM通液速度(From Nuoer).docx.md

SAM通液速度（From Nuoer）

[图片]
仪器编号：

最新版本号：第1版           修订日期：2025年2月12日

实验目的：

仪器的准备：

# 1.打开天平，静放10min，用法码校准，以确保数值准确稳定。

# 2.0.9%的氯化钠溶液。

# 3.计时器清零。

样品的准备：

# 1.SAM原材料样品，放置密封袋内。

测试步骤：

# 1.量取150ml 0.9%氯化钠溶液倒入200ml烧杯中。

# 2.称取0.32±0.005g试样加入装有0.9%氯化钠溶液的烧杯中。

# 3.放置30min，让试样充分膨胀。

# 4.往已关闭活栓的通液管内注满0.9%氯化钠溶液；然后，打开活栓放流液体，在液面接近通液管底部时关闭活栓，确认活栓和滤器之间已经没有空气。

5.再次往通液管内注入0.9%氯化钠溶液，液面满至60ml（中间刻度线）以上5cm处。放入加压轴和砝码，打开活栓放流液体，测定管内液体从60ml（中间刻度线）下降至40ml（下刻度线）时所需时间，记录为T0。T0的适当范围是7±5秒。如超过12秒，要好好清洗滤器表面。（清洗后仍超时，可以用火烧掉堵住网眼的样品，如若仍然达不到7±5秒，请更换滤器。）

# 6.关闭活栓，把已经膨胀好的SAM和0.9%氯化钠溶液一起倒入通液管中，并用管内溶液冲洗烧杯内的SAM，务必将所有SAM毫无残留的倒入通液管内。

7.打开活栓让管内液面降至60ml（中间刻度线）以上5cm出。然后放入加压轴和砝码（加压轴和砝码合计为0.3PSI压力），放置30秒（为了挤排出附着在加压轴网眼上的空气）。

# 8.打开活栓放流液体，用秒表测量液面从60ml（中间刻度线）下降至40ml（下刻度线）所需时间，记录此时间为T1。

# 9.SAM的测试进行2次。如果2次的测试结果相差很大时，要再测试。

# 10.计算样品SAM的通液速度，方法如下：

通液速度（ml/min）=20*60/（T1-T0）

同时进行两次测试，算术平均值作为测试结果，结果保留小数点后一位。
