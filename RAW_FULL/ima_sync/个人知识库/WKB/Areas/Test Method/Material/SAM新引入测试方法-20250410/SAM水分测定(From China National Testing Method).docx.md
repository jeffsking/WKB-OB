# SAM水分测定(From China National Testing Method).docx.md

SAM水分测定 (From China National Testing Method)

[图片]
仪器编号：

最新版本号：第1版           修订日期：2025年2月12日

实验目的：

仪器的准备：

# 1.提前预热烘箱至105℃±2℃。

# 2.打开天平，静放10min，用法码校准，以确保数值准确稳定。

# 3.干燥器，带有活性干燥剂。

# 4.试样容器，用于试样的转移和称重。该容器由能防水蒸汽，且在试验条件下不易发生变化的轻质材料制成。

样品的准备：

# 1.SAM原材料样品，放置密封袋内。

测试步骤：

# 1.称取4g试样，精确至0.001g，装入恒重的容器中，称量样品、容器和盖子的重量，记录为M1。

# 2.将称好重量的容器及样品，开盖放置在105℃的烘箱中，烘干3h。

# 3.当烘干结束时，在烘箱内盖上容器盖子，然后移入干燥器内冷却，30min后称取容器及试样的重量，记录为M2。

# 4.将该容器再次移入烘箱中重复2、3步骤，两次连续称量间的干燥时间不应少于1h,当两次连续称量间的差值不大于烘干前试样质量的0.4%时，即可确定试样达到恒重。

SAM水分X（%）按照以下公式计算：

X=（M1-M2）/M1x100%

M1---烘干前的重量，单位（g）

M2---烘干后的重量，单位（g）

注意事项：

# 1.烘箱高温，需佩戴防烫手套。

# 2.同时进行两次测定，取其算数平均值作为测定结果，并修约至整位数。两次测定结果的绝对误差应不超过0.4%。
