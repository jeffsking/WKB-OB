# SAM保水量（From China National Testing Method）.docx.md

WI-66077

SAM保水量（From China National Testing Method）

[图片: BIORIDGE 卢湘仪 7TD5GL]
仪器编号：

最新版本号：第1版           修订日期：2025年2月12日

实验目的：

用于测量SAM颗粒在吸水饱和状态下，通过外力脱水的方法，来检测SAM颗粒的锁水能力，以便确认原材料的锁心保水能力是否能满足生产需求。

仪器的准备：

# 1.测试环境温度为23+/-2℃，湿度为≤85％。

# 2.封口机加热。

# 3.计时器倒计时30min。

# 4.离心机电源开启，静放10min。直径200mm，转速1650r/min（可产生约250g离心力），检查离心机后方的排水管不要堵塞。

# 5.茶袋，尺寸70mm*70mm,透气性（230±50）L/min/100cm² (压差124Pa)。

# 6.打开天平，静放10min，用法码校准，以确保数值准确稳定。

样品的准备：

# 1.准备浓度0.9%生理盐水（氯化钠溶液）。

# 2.SAM原材料样品，放置密封袋内。

测试步骤：

# 1.依据测试样品数量，取出相应数量的标准过滤袋，编号，称重，记录过滤袋重量M1。（用油性笔在过滤袋上编号，防止浸入水中融化）。

# 2.称量0.200±0.001g SAM样品放入过滤袋内，用封口机密封。

# 3.在10×10×9.5cm的塑料盒子内加入0.9%生理盐水，高度以能够完全浸没过滤袋为准。

# 4.将装有试样的茶袋完全浸没在装有生理盐水的塑料盒子内，使SAM颗粒充分吸水，开始计时30min

# 5.30min后，将吸水饱和的样品过滤袋贴放在离心机内壁的网筛上，均匀对称放置，盖好盖子。

# 6.设置离心机转速为1650rmp，离心力F=250g，时间为3min，开始。（机器运转过程中不能打开盖子）。

# 7.3min后，待离心机完全停止转动后，打开盖子，取出过滤袋，放置到清零后的天平上分别称重，记录每个过滤袋重量M₂。

# 8.计算样品SAM的保水量，方法如下：

保水量=（M₂-M₁-甩干后过滤袋吸水克重-0.2)/ 0.2

甩干后过滤袋吸水克重：干的空的过滤袋吸水30min后，用离心机甩干3min后重量，减去吸水前过滤袋的重量。可以通过试验得到一个常用稳定数值参与计算。
