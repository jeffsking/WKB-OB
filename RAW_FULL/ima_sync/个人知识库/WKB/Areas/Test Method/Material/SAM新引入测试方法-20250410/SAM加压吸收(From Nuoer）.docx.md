# SAM加压吸收(From Nuoer）.docx.md

SAM加压吸收(From Nuoer)

[图片: UH 诺尔生物 诺尔生物]
仪器编号：

最新版本号：第1版           修订日期：2025年1月24日

实验目的：用于测量SAM颗粒在有一定外部压力干涉的情况下，SAM颗粒能够吸收自身重量多少倍的水分，以便于确认原材料的吸收性能是否能满足金佰利的生产需求。

仪器的准备：

# 1.测试环境温度为23+/-2℃，湿度为≤85％。

# 2.打开天平，静放10min，用法码校准，以确保数值准确稳定。

3.塑料圆筒，内径为60mm±0.2mm、高为 64.0mm±1.0mm，底部往上 13mm 处自下而上固 定有孔径 850μm 且厚度 1mm 的金属过滤网和孔径 36μm 金属网。

# 4.清理套筒内壁及底部滤网，使其干燥，无堵塞，无破损。

5.活塞（6207Pa），高度大于 60 毫米且直径比 PMMA 气缸内径小 0.5 到 1.0 毫米之间的聚四氟乙烯（PTFE 或同等）圆筒，能与塑料圆筒紧密连接，且能上下自如活动，不锈钢砝码重量设计为适合 PTFE 圆筒，该砝码重量与 PTFE 圆筒一起提供 63.38g.cm -2（0.9 psi）的压力。

# 6.计时器倒计时60min。

# 7.圆形培养皿，直径15cm、高度3.5cm。

样品的准备：

# 1.原材料：SAM100gsm,放置密封容器内。

# 2.准备浓度0.9%氯化钠溶液，温度25+/-0.5℃。

测试步骤：

# 1.套筒及白色活塞进行整套称重，并记录对应数值A。

# 2.称量0.900±0.001g SAM样品，放在称重后的套筒滤网上轻轻晃动，使其均匀分布，套上白色活塞。

# 3.将装好试样和活塞的塑料圆筒放入培养皿中，加入0.9%氯化钠溶液使其高度为18mm，并迅速加上0.9砝码（约1500g)，开始倒计时60min。

# 4.60min后，将套筒和砝码一起取出，套筒放置到清零后的天平上进行称重，记录对应数值B。

# 5.计算试样SAM的0.9psi加压吸收，计算方法如下：单位g/g

加压吸收=（B-A-0.9）/0.9
