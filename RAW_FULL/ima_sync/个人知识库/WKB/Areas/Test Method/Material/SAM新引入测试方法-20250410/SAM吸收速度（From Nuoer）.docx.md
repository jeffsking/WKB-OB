SAM吸收速度（From Nuoer）

[图片: 仟器 ON 电 速度显示 上海硕光电了口技有限公司 搅拌仪]
仪器编号：

最新版本号：第1版           修订日期：2025年2月12日

实验目的：

# 1.用于测量SAM的吸收速率，以便确认原材料的吸收速度是否能满足生产需求。

仪器的准备：

# 1.打开天平，静放10min，用法码校准，以确保数值准确稳定。

# 2.0.9%的氯化钠溶液。

# 3.计时器清零。

样品的准备：

# 1.原材料：SAM100gsm,放置密封容器内。

# 2.根据每个样品需要50ml的用量，准备浓度0.9%生理盐水（氯化钠溶液）

测试步骤：

# 1.将100ml烧杯加入50ml生理盐水，温度23±2℃，放入8*30mm转子（8楞）后放置在磁力搅拌器上，转速需稳定在600±5rpm，先使溶液搅拌均匀。

2.称量2.000±0.05g SAM样品，一次性全部倒入旋涡中。投入后，开始计时，随着SAM颗粒吸水膨胀，液体表面旋涡会慢慢消失，当漩涡消失液面达到水平时，以烧杯周围SAM凝胶停止转动为终点停止计时，记录时间（单位：秒）。

# 3.每个样品测试2次，误差范围<3s，报告平均值。

# 4.试验完成后，将废弃SAM样品倒入指定垃圾箱，切记拿出烧杯内的转子，清洗使用过的工具。

注意事项：

# 对装有试样的容器进行充分摇动，使颗粒大小均匀后再采集试样。

# 测定要进行2次以上，如确认误差在3秒内，报告平均值，如误差超过3秒，则需要重新复测。
