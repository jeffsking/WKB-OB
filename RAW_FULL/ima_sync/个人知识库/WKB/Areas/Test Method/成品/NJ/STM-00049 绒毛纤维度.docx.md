# STM-00049 绒毛纤维度.docx.md

8
STM-00049

绒毛纤维度测试

ST、、ST\\

最新版本号：第4版     修订日期：2021年8月24日

实验目的：

测量绒毛纤维度。

测试前的准备：

1. 将仪器接到电流转换器上。

2. 检查仪器真空膛清洁干净，真空吸尘袋没有被堵塞。

3. 打开仪器电源开关。

4. 检查仪器的设定是否为4分30秒，真空度的指针是否为8英寸水柱。

测试步骤：

# 1. 称取10g绒毛放入真空膛内，按下开始键。

# 2. 立即观察真空值（C），确定为1.99kpa（8英寸水柱）。如果不是，调节球形阀，直到读数到达1.99kpa

# （8英寸水柱）。

# 3. 在整个测试时间内观察绒毛的流通，如果绒毛纠结在一起（不流通），堵上空气孔，保持1秒钟，绒毛会重新分散。

# 4. 经过4分30秒后，维测试仪会自动停止。拿出真空膛（A）内的剩下的所有绒毛，放在天平上称取重量。

# 5. 立即读出重量，保留到0.1g。

# 6. 测试结果计算：（10g-剩余绒毛重量）/10*100%

操作注意事项：

# 1.真空吸尘袋每次试验后需清洁，在更换吸尘袋时，将袋子全部取出，在取袋子时慢慢操

作，以免粉尘泄漏，把袋子扎紧后放入垃圾袋中。

# 2.该仪器电源为110V电压，切勿直接接到电源，必须连接到转换器）。

操作安全：

1. 插拔电源时，小心触电。

2. 测试时带好相应的PPE。
