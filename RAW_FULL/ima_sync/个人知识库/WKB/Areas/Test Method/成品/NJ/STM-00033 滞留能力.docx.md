# STM-00033 滞留能力.docx.md

8
STM-00033

滞留能力

[图片: Lo]
最新版本号：第3版           修订日期：2021年12月04日

实验目的：

主要用于测试纸尿裤和纸尿片在14±1英寸水柱外压下滞留的能力。

测试前的准备：

1. 打开控制面板电源，将真空压力控制在14+/-1英寸的水柱压力

2. 在控制面板上设定浸泡时间20分钟±15秒，滴水时间1分钟±15秒，测试时间5分钟±15秒，真空度14±1英寸水柱。

样品的准备：

样品称重，精确到0.01克，将样品的腿部松紧带和折叶松紧带每隔0.5英寸剪开，但不要剪掉，不要剪至密合缝或绒毛区域，使样品平放。

测试步骤：

# 1. 将样品底膜面朝上置于2英寸（51mm）高的盐溶液中，启动控制面板上的浸泡开始开关，样品浸水后，无纺布面朝下漂于水中，不要给样品施加力，样品不能与不锈钢容器底部接触，必须在水中自由漂浮。

# 2. 待浸泡警报声响起后，按下停止开关，托住尿裤前后边缘立刻将样品从测试液体中取出，在将样品转移到测试仪上时，尽可能保持样品在水平位置，样品仍然底膜面朝上放置。

# 3. 平放于测试仪上，启动控制面板上的滴水开始开关，滴水过程中，用测试液将测试仪四周润湿。

# 4. 待浸泡警报声响起后，按下停止开关，将乳胶膜平铺于测试仪上，启动控制面板上的测试开始开关。

# 5. 待测试警报声响起后，按下停止开关，抬起乳胶膜，将样品从测试仪上取下称重，精确至0.01克。

# 6. 绝对滞留能力g = 湿样品重量—干样品重量 ，相对滞留能力g/g = 绝对滞留能力/干样品重量

操作注意事项：

1. 实验前，先检查乳胶膜看是否存在孔或撕裂的痕迹；

2. 准备样品时，剪产品上的松紧带时不要破坏产品的胶线；

3. 在真空泵工作过程中，不要将盖在实验仪上的橡胶布掀开；

4. 如果测试仪上的乳胶膜是湿的，在测试下一个样品前将其擦干；

5. 方法中所说的前、后、左、右均指尿裤穿着时的方位；

操作安全：

1. 插拔电源时，小心触电；

2. 随时观察乳胶膜是否堵住了通气孔，以免发生内爆的危险。
