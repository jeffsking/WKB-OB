# GB-T28004-2011 PH.doc.md

8
GB/T28004-2011

纸尿裤PH值测试

最新版本号：GB/T28004-2011   修订日期：2021年8月24日

测试前的准备：

1. 拔掉电极上的运输保护盖。

2. 用蒸馏水冲洗电极以及清楚沉积盐。

3. 像甩动医用体温计一样甩动电极以排除气泡。

4. 将电极浸泡于3MKCL溶液2小时以活化电极。

样品的准备：

1. 同规格产品任取两片样品，剪去边部松紧带，去掉底膜，剪产品中间部位。

2. 各从每片样品任取1g（称准至0.001g）试样放入400ml烧杯中，加入200ml蒸馏水用玻璃棒用力搅拌。

3. 若未见游离水，应适当多加水，直至出现游离水为止，此时开始计时并适当搅拌试样。

4. 10min时放入电极测试其PH。

5. 取2个试样测试值的算术平均值作为测定结果，精确至0.1PH单位。

测试步骤：

1. 打开ON/OFF键开机，开机后切换测量模式到PH模式，将电极反别插入袋25℃时PH4.01、PH6.86和PH9.18缓冲液中。

2. 按下CAL键进行校验，“A”闪烁表示正在测试，根号A表示数值稳定。

3. 重复之前步骤对PH4.01、PH6.86、PH9.18进行校准，校准完后，按下“结束”，结束校准，结束后按下“保存”，保存校准结果。

4. 按Read键3秒切换进入测试状态，将电极插入样品内，按Read键进行测量，根号A表示数值稳定，稳定后读取数值。

5. 测试后用蒸馏水对PH计感应端进行清洗，用标准滤纸擦拭干净后进行下一个测试。

6. 如测试全部结束，电极擦干放入专用保护液中，并盖上保护盖，按下ON/OFF键2秒后释放关机。

操作注意事项：

1. 试验前必须对PH计进行校准。

2. 后端接孔不得随意变动。

3. 每次测试完立即用蒸馏水清洗电极。

操作安全：

1. 插拔电源时，小心触电。

2. 玻璃器皿易碎，小心扎手。
