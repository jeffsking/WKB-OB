# TTM-00512 绒毛完整性.doc.md

8
TTM-00512

最新版本号：第2版           修订日期：2021年9月28日

实验目的：主要用于纸尿裤绒毛整体性的测试。

测试前的准备：

# 1.测试液准备：准备好室温下含有蓝色染剂的0.9%氯化钠溶液。

# 2.将适量的测试溶液（生理盐水）倒入漏斗中，将漏斗润湿，用测试溶液洗两遍漏斗待用。

样品的准备：

# 1.称量产品的重量，保留到0.01g，并记录下来。

# 2.在灯箱上剪去样品的松紧带，并标记绒毛中心向前25mm的位置为测试点。

# 3.将样品两边的松紧带（包括立体护边）剪去后作为测试样品。

测试步骤：

# 1.将样品平铺在水平桌面上，将漏斗下口中心点对准测试点，垂直距离约5~10mm。

# 2.用量筒准确量取测试溶液，倒入调节好的漏斗当中，迅速将漏斗节门打到最大，使溶液自由地流到样品的表面上，同时开始计时，等待5分钟。

|测试产品|测试液量|
|---|---|
|Step0- Step 1|40ml|
|Step 2- Step 3|60ml|
|Step 4- Step 6|80ml|

# 3.将样品前端向上，用固定夹固定到测试杆上，启动仪器，开始记录振动次数。

# 4.当样品的吸收芯断裂长度超过CD方向的一半，停止计数，记录总的振动次数；如果断裂长度不连续，则将各断裂区域CD方向长度相加，总长超过CD方向一半停止计数；见下图。

# 5.测试结束后，将样品取下，关闭仪器。

操作注意事项：

# 1.固定样品时，确保样品垂直向下；

# 2.样品的固定需确保牢固，以免振动过程中掉落；

# 3.仪器中用于减震的垫片，需两周更换一次，以保证测试结果的稳定性。

操作安全：

# 1.插拔电源时，小心触电；

# 2.剪刀裁剪时，注意手指安全；

# 3.玻璃器皿易碎，小心扎手；

# 4.仪器运行过程中，不要靠近，以免受伤。
