# STM-00440 腰围皮筋张力.doc.md

8
STM-00440

腰围皮筋张力测试

最新版本号：第3版         修订日期：2021年8月24日

实验目的：

此测试用于测量产品的腰围皮筋张力。

测试前准备：

1. 从包装袋中取出要测试的产品

2. 打开拉力仪电源开关。

测试步骤：

1. 不要使用在腰围区域有缺陷可能会影响测试结果的产品。

2. 为张力测试仪配置好合适的器具和传感器。设置测量长度为100mm（上下测试杆间的中心距离）。

3. 在软件“我的模板”中选择所测产品尺寸所对应的命令。（M、L选择170mm；XL、XXL选择190mm）

4. 将产品放在水平表面上测试产品松弛状态下热封边内侧间距离。将直尺放在腰围上边缘处测量，保持产品平整但不能有拉伸。在所有准备过程中腰围不能有任何拉伸。

5. 将产品套在上端测试杆上，归零load和crosshead。此步可以从测试结果中扣除产品重量。

6. 轻轻抻开腰围套上下端测试杆。热封边需位于测试杆的最外侧，测试杆需伸到腿部开口处，保证腰围位于测试杆中心。测试过程中产品位置保持一致非常重要。

7. 点击开始。

8. 当crosshead归零时，拿走产品并记录平均值。

9. 保留整数。

操作安全：

插拨电源时，小心触电。
