# STM-00686弧形皮筋张力.doc.md

8
STM-00686

成长裤弧形皮筋张力测试

[图片: 0.000]
最新版本号：第0版

实验目的：测试婴儿成长裤弧形皮筋在90％伸长度下进行的拉伸强度测试，结果用gf表示。

测试前的准备：1. 打开仪器开关，预热，调整单位为“千克”，状态为“C”，按下'ZERO’

按钮将仪器回零；

# 2.检查上下夹子边缘是否平行，不平行时需要进行调整；检查上下夹子内

的橡胶垫块是否缺失，若缺失请及时更换夹子；

# 3.将校准杆置于上下夹具中心位置，调整夹具距离：

|松紧位置|校准杆长度mm|
|---|---|
|前端（左右）|99|
|后端（左右）|144|

# 4.通过调节仪器粗旋钮将上夹具移至所需的近似高度，将校准杆放到两个

夹具之间，再轻轻调整微旋钮将上夹具调至最终所需的位置；（微调时

不要施加过大的力，以免破坏拉力仪的载荷）；

# 5.准备一块秒表。

样品的准备：  取线上样品，静置0.5-1h后进行测试。

从包装袋中取合格的产品，标记产品前后左右（所有涉及前后左右均为穿戴方向）：

# 1.去除芯体和外层，不要破坏腰围。

# 2.沿CD方向在前、后弧形腿部皮筋之间将腰围一分为二。

# 3.在倒数第五根与第六根腰围皮筋之间标出剪切线。

# 4.修剪多余的腰围材料，沿MD方向分别将前、后弧形腿部皮筋一分为二，共4个样品。

# 5.在最底部腰围皮筋与弧形腿部皮筋交叉处对样本标识。

# 6.将标识好的样品悬挂在灯箱上，用150g配重夹拉伸，分别量取：前端弧形皮筋110mm，后端弧形皮筋160mm，取下测试样品立刻测试。

|松紧位置|弧形腿部皮筋量取长度|
|---|---|
|前端（左右）|110 mm|
|后端（左右）|160mm|

测试步骤： 1.   将样品最底部腰围皮筋与弧形腿部皮筋交叉处的一端夹在上夹具上，样品居中，夹具夹在样品的划线上（标记线刚好能看见，一半在夹具内，一半在夹具外），使样品呈自由悬挂状态，按下“ZERO”按钮，将试样的重量归零；

# 2.将仪器的下夹具轻轻向上抬起，将样品的另一端夹在下夹具上，同样夹具夹在样品的划线上，确认皮筋在竖直方向被拉直且不会被拉出角度；

# 3.将下夹具轻轻放下时，立即开始计时。

|松紧部位|时间|
|---|---|
|腿部|60 ± 3 s|

# 4.到测试所要求的时间后立即记录读数，将记录的读数乘以1000计为最终结果，单位：“gf”；

# 5.将下夹具轻轻抬起，将样品从夹具上取下，将仪器复位。

操作注意事项：1. 校准时，旋动粗螺旋钮时要轻而慢，避免仪器受力过大而损坏传感器；

STM-00686

# 2.放下下夹具时要轻，以免损坏仪器；

# 3.仪器上的按键严禁随意按动；

# 4.上述方法中，所说的前、后、左、右均指尿裤穿着时的方位；

# 5.做好标记的样品必须在1小时之内进行测试。

# 6.标记线时，要一笔画完，严禁来回画线。

操作安全： 1. 插拔电源时，小心触电；

2. 将样品夹在夹具上时应小心，避免夹手；

3. 当往悬挂在灯箱上的尿裤上夹150克配重夹时，脚不要放在重物之下，以免重物落下砸伤脚；

4. 使用剪刀裁割样品时，注意手指的安全。
