仪器编号：

最新版本号：第1版           修订日期：2024年9月3日

实验目的：主要用于成品及橡筋材料的压力测试。

测试前的准备：

# 1.人体模型

# 2.记号笔，直尺，剪刀，订书机，计算器，软尺，计时器。

仪器准备：

# 1.从箱中取出主机，气针，气囊式传感器，电源线及变压器；

# 2.黑色电源线一端连接蓝色主机，另一端连接变压器，变压器插入插座面板内，接通电源；

# 3.将气囊式传感器连接到气针上，听到“咔”一声，连接完成。接着把气针上的顶部白色按钮推到底，再将蓝色针头插入蓝色孔内，向下推动抽气，使气囊内的气体全部放空，气囊呈真空状态。再将蓝色针头插入红色孔内，向上推动充气，使气囊内有少量气体，不能完全膨胀；

测试步骤：

人体模型

# 1.将产品穿在对应size的人体模型上，为保证实验准确性，每片产品尽量保持在同一位置，穿戴完成后整理尿裤，使其平整，方便测试；

[图片]
# 2.充好气的气囊依次放入需要测试的点位上（注意气囊不要弯折，不要用手扶气管，自然放置）；

# 3.读数，待数值稳定后读取对应通道的数值，并乘以10，单位：V。

手臂

1.  用软尺先量取测试者手臂的周长，并在手臂上标记，固定测试位置。再根据提供的拉伸倍率用计算器算出材料的松弛长度（如图五）；

# 4.计时结束后，立即读数，并乘以10，单位：V；

# 5.如需记录手臂压痕，请拍照保存；

# 6.弹性腰围原材料与成品腰围橡筋测试方法一致，请重复步骤1-5；

# 7.仪器使用完毕后，点主机上“OFF”键，再拨动主机上端“OFF”的黑色按钮，断开电源，拔出气囊传感器，关机完成，仪器及所有配件收入箱中。

操作注意事项：

# 1.样品在测试前保持橡筋未被拉伸；

# 2.同一测试样品需要处理条件保持一致；

# 3.测试期间保持同一位置；

# 4.仪器使用时，按步骤操作，避免损坏仪器。

操作安全：

# 1.插拔电源时，小心触电；

# 2.订书机使用时，注意手臂的安全；

# 3.使用剪刀时，小心伤手。
