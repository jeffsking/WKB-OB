# STM-00061 折页渗漏.docx.md

8
STM-00061

折页渗漏测试

最新版本号：第2版          修订日期：2021年8月24日

实验目的：

测量在一定条件下，尿裤折页的防渗漏性能。

测试前的准备：

1. 确保斜面板放置在水平的实验台上。

2. 清理斜面板上的水及SAM颗粒，确保其清洁。

3. 用大塑料烧杯装大于80ml测试液，放置于水浴锅内，插上温度计。

4. 确保水浴锅内的水达到水浴锅一半水位处，且温度保持在35±1.7摄氏度。

样品的准备：

# 1. 标记产品的前后左右端（穿着时的方向）。

# 2. 将体侧层朝外，后端向上，垂直挂在灯箱上，确保腰部松紧带完全拉伸。

# 3. 手指轻轻捋过松紧带。将1000g的双配重夹夹在腰部中心位置，不要夹到绒毛上。

# 4. 手指再一次轻轻捋过松紧带，确定腰部松紧带是完全拉伸的。

# 5. 将p.o12329886的模板放置在样品的MD方向中心位置上。

# 6. 根据样品选择模板上不同的横线对折页做标记，分别标记出测试区和中心位置

# 7. 将产品从灯箱上取下来。

# 测试步骤：

# 1. 在斜面板上边缘贴上双面胶，调整样品的位置使漏斗开口对准折页的中心标记处的折页粘合线，

# 固定住样品。

# 2. 将配重架放在尿裤折页上，内边缘对准标记线。折页在水平和垂直位置上都不应该有折痕。

# 3. 在斜面板的收集管口下方放置一个去皮的100ml空烧杯。

# 4. 调节漏斗尖口端距尿裤折页密封线处10mm。

# 5. 对应不同产品，量取不同量的测试液。

# 6. 关闭漏斗活塞，倒入量取好的测试液，将活塞迅速打开到标记线处。观察各个方向是否有液体流出。

|测试产品|测试液量|
|---|---|
|NB、S号|40ml|
|M|60ml|
|L|60ml|
|XL、XXL|80ml|

# 7. 称量流出的液体，精确到0.5克，且记录测试左右侧。

# 8. 如果液体是从在折页1/3中心处以外流出，或液体是越过折页流出，该测试无效，重新取样测试。

# 9. 实验结束后，将样品从斜面板上取下来。清洁斜面板，并擦干烧杯。

操作安全：

1. 插拔水浴锅电源时，小心触电。

2. 从水浴锅中取放液体时不要把水溅出，以免水浴锅漏电。

3. 在制备样品使用剪刀时，必须将手正确放置以防止手部被割伤。
