# STM-00070 皮筋张力.docx.md

8
STM-00070

纸尿裤松紧带拉伸测试

[图片: 0.000]
SE

最新版本号：第4版           修订日期：2021年8月24日

实验目的：

测试婴儿纸尿裤腿部，折页和腰部松紧带在90％伸长度下进行的拉伸强度测试。测试结果单位用gf表示。

测试前的准备：

1. 打开仪器开关，调整单位为“千克”，状态为“C”，按下“ZER按钮将仪器回零。

2. 检查上下夹子边缘是否平行，不平行时需要进行调整。

3. 将校准杆置于上下夹具中心位置，调整夹具距离。

|松紧位置|校准杆长度mm|
|---|---|
|大腿|90|
|折页|90|
|腰部（≤100mm）|72|
|腰部（＞100mm）|90|

4. 将上夹具移至所需的近似高度，将标杆放到两个夹具之间，再轻轻调整旋钮将上夹具调至最终所需的位

置，即标杆在两夹具之间自由独立站立（微调时不要施加过大的力，以免破坏拉力仪的载荷）。

5. 准备一块秒表。

样品的准备：

从包装袋中取合格的产品，标记产品前后左右（所有涉及前后左右均为穿戴方向）

腿部松紧带：

1. 将底膜朝外，后端向上，垂直挂在灯箱上，确保腰部松紧带完全拉伸。

2. 手指轻轻捋过松紧带。将1000g的双配重夹夹在腰部中心位置，不要夹到绒毛上。

3. 手指再一次轻轻捋过松紧带，确定腰部松紧带是完全拉伸的。

4. 将p.o.12329655模具放于测试侧腿部松紧带的MD中心位置（目测），并用笔在模具100mm凹槽处做记号。

5. 移走模块，用直尺在上下标记线以外各量取13mm并做上记号作为剪切处。

6. 将配重夹从产品上取下，用剪刀沿着绒毛与松紧带之间剪下测试区，取下样品，立刻测试样品。

折页松紧带：

1. 将体侧层朝外，后端向上，垂直挂在灯箱上，确保腰部松紧带完全拉伸。

2. 手指轻轻捋过松紧带。将1000g的双配重夹夹在腰部中心位置，不要夹到绒毛上。

3. 手指再一次轻轻捋过松紧带，确定腰部松紧带是完全拉伸的。

4. 将p.o.12329655模具放于测试侧折页松紧带的MD中心位置（目测），并用笔在模具100mm凹槽处做记号。

5. 移走模块，用直尺在上下标记线以外各量取13mm并做上记号作为剪切处。

6. 将配重夹从产品上取下，用剪刀沿着折页和粘合线之间剪下测试区，取下样品，立刻测试样品。

腰部松紧带：

STM-00070

1. 将尿裤水平挂在灯箱上，底膜层向外，夹子夹在腰部松紧的中心位置上，不要夹到绒毛

2. 双配重夹夹在腰部宽度方向的中间位置，不要夹到松紧带上。

3. 轻轻放下配重夹，整理尿裤。

4. 把p.o.12329887   80mm或100mm的标准模板摆在腰部粘着区域中心位置，在凹槽内画单线标记，对

样本标示。

|腰部松紧长度|模板沟槽尺寸|
|---|---|
|≤ 100 mm|80 mm|
|&gt; 100 mm|100 mm|

移走模块，用直尺在上下标记线以外各量取13mm并做上记号作为剪切线，同时在松紧带CD方向向产品内量

取3毫米，标记作为剪切线。

5. 将配重夹从产品取下来，将产品平放。按照剪切线剪下测试区域。并立刻测试。

测试步骤：

1. 将准备好的样品一端夹在上夹具上，样品居中，夹具夹在样品的划线上（标记线刚好能看见，

一半在夹具内，一半在夹具外），使样品呈自由悬挂状态，按下“ZERO”按钮，将试样的重量归零；

2. 将仪器的下夹具轻轻向上抬起，将样品的另一端夹在下夹具上，同样夹具夹在样品的划线上，确认松

紧带在竖直方向被拉直且不会被拉出角度；

3. 将下夹具轻轻放下时，立即开始计时

|松紧部位|时间|
|---|---|
|腰部|60 ± 3 s|
|折页，大腿|30 ± 1 s|

4. 到测试所要求的时间后立即记录读数，将所记录的读数乘以1000计为最终结果，单位：“gf”；

5. 将下夹具轻轻抬起，将样品从夹具上取下，将仪器复位。

操作注意事项：

1. 校准时，旋动粗调旋钮时要轻而慢，避免仪器受力过大而损坏传感器；

2. 放下下夹具时要轻，以免损坏仪器；

3. 仪器上的按键严禁随意按动；

4. 上述方法中，所说的前、后、左、右均指尿裤穿着时的方位；

5. 做好标记的样品必须在1小时之内进行测试。

6. 使用模块画标记线时，要一笔画完，严禁来回画线。

操作安全：

1. 插拔电源时，小心触电；

2. 将样品夹在夹具上时应小心，避免夹手；

3. 当往悬挂在灯箱上的尿裤上夹1000克配重夹时，脚不要放在重物之下，以免重物落下砸伤脚；

4. 使用剪刀裁割样品时，注意手指的安全。
