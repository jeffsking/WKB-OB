# STM-00060 导流性能.docx.md

8
STM-00060STM2417

纸尿裤导流性能的测试

最新版本号：第3版           修订日期：2021年8月24日

实验目的：

该测试用来测定婴儿纸尿裤的导流性能。

测试前的准备：

# 1. 确保斜面板放置在水平的实验台上。

# 2. 清理斜面板及收集废液的容器内的水及SAM颗粒，确保其清洁。

# 3. 确保水浴锅内的水达到水浴锅一半水位处，且温度保持在35±3摄氏度。

# 4. 用塑料烧杯大于100ml蒸馏水，插上温度计，放置于水浴锅内。

样品的准备：

# 1. 从包装袋中取出合格产品

# 2. 标记产品的前后端（穿着时的方向）

# 3. 沿着折页和大腿松紧粘着点剪切，剪下折页和大腿松紧。不要剪到绒毛。

测试步骤：

# 1. 将尿裤吸收层向上，使前端绒毛边缘与斜面板上第二根黑线对齐，且放置于漏斗下方中心位置。

# 2. 用夹子将样品固定在斜面板上

# 3. 调节漏斗尖嘴端与样品之间的距离为10mm

# 4. 在斜面板的收集管上插上10ml的量筒。

# 5. 关闭活塞，量取100ml蒸馏水倒入漏斗中。

# 6. 打开活塞迅速调到标记线处，让蒸馏水完全流出。

# 7. 计量从收集管流出的液体：如果没有液体流出，

|实际流量ml|记录值ml|
|---|---|
|没有流出|0|
|≤0.5|0.5|
|0.5-10|实际记录，保留到0.1ml|
|≥10|实际记录，保留到1ml|

# 8. 如果有液体从样品两侧流出，不作为结果记录。

# 9. 测试完成后，取走测试样品，清洁并擦拭量筒和斜面板。

操作注意事项：

1. 每次测试时注意观察液体流速是否正常，避免漏斗被SAM颗粒堵住，流速改变而影响

测试结果；

2. 每次测试前注意调节漏斗高度到要求位置；

3. 将测试溶液倒入漏斗前应确保漏斗的节门是在关闭状态；

4. 经常注意水浴锅中是否缺水，如缺水，应立即加入，以免水浴锅干锅而烧坏水浴锅。

操作安全：

1. 插拔水浴锅电源时，小心触电。

2. 从水浴锅中取放液体时不要把水溅出，以免水浴锅漏电。

3. 在制备样品使用剪刀时，必须将手正确放置以防止手部被割伤。
