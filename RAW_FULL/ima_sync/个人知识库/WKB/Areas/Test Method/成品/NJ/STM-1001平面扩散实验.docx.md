# STM-1001平面扩散实验.docx.md

8
STM-1001

平面扩散实验

[图片: Kimberly-(lak Bring our]
最新版本号：第1版        修订日期：2021年8月24日

实验目的：

该方法用于检测产品平面扩散性能。

测试前的准备：

1. 打开仪器的电源。

2. 配置0.9%的NaCl溶液倒入水箱中至溶液高度高于出水口，打开平面扩散实验水阀。

3．打开30s出水开关，排放溶液若干次，直至放出的溶液呈澄清透明。

样品及器材的准备：

# 1.电脑开机，打开实验软件。

# 2.样品称重，精确到0.01克，将样品的腿部松紧带和折叶松紧带每隔1英寸剪开，但不要剪掉，不要剪至密合缝或绒毛区域。

# 3.取产品绒毛中心点做好标记。

测试步骤：

# 1.打开软件，启动程序。

# 2.打开控制泵开关，取烧杯去皮，量取3次30s溶液量，算出平均值。

# 3.在电脑页面上点击系统配置→实验参数设定→在尿液扩散实验（平躺）的“30s内剂量”中输入步骤2中得到的平均值，保存后关闭界面。

# 4.在电脑页面上点击系统配置→批号（样品）设定，输入批号，厂商，尺寸；点击“新增”按钮后在中间界面出现输入的批号，再点击“样品设定”。

# 5.在样品设定中输入编号和产品重量。也可在将样品放在天平上后点击“自动生成”。

# 6.重复步骤5，根据测试量进行添加，依次编号和输入产品重量。设置完成后关闭窗口。

7.点击“实验”，选择“平面扩散暨渗透实验”，在出现的界面上更改每次注入量，周期和次数。注入量为NB号50mL，S号65mL，M号80mL，L和XL号100mL，周期设置为60s，次数为1次。

# 8.样品编号，选择之前编好的样品，点击“确认”。

9.将样品放置在平面板上，前端向左，中心测试针对准产品中心点，用压块将样品平整的压在平面板上，盖上上层平板，上层平板中心的测试针与下层测试板中心的测试针要尽量靠近，但不要与下层中心针触碰，也不要触碰到产品。

# 10.将圆柱形模具放在上层平板孔洞中，放入软管，点击“开始实验”。

# 11.电脑桌面上显示出数据后，保存。重复步骤8~10，完成该批号的平行实验。

# 12.生成报表，点击“报表”，选择平面扩散实验报告，选择该批号后，点击“生成报表”。

# 13.实验结束后，用清水轻轻擦拭针头，保证实验台干净整洁。

操作注意事项：

# 1.不要随意移动天平。

# 2.绒毛中心对准中间针。

# 3.操作过程中，可轻压模具，防止溶液侧漏。

# 4.做完实验后，关闭水阀，并将水箱中的水放干。

操作安全：

# 1.使用剪刀时，注意划伤。

# 2.将样品放置在实验台上时，注意扎手。可戴防扎手套。
