# 澳洲dip and drip 实验.docx.md

8
澳洲Dip & Drip测试

最新版本号：第0版         修订日期：2019年5月13日

实验目的：

本测试用于出口澳洲产品测试其吸收性能力。

测试前准备：

# 1．准备托盘，水槽，不锈钢网格，

# 2．蒸馏水。

测试步骤：

# 1.将空托盘放置在天平上，并将其校去皮清零；

# 2.从包袋中抽取1片产品，称量产品的重量W1；

# 3.准备一个大的水槽，向其内部倒入蒸馏水直到水槽的黑线标记处的水位；

# 4.展开产品，liner的一面朝上，放置在水槽内，并且用网格压住浸没在水中；

# 5.用手按住网格直到产品没有气泡冒出再松开，此时开始计时3分钟。

# 6.3分钟后，用手拎取产品两端将其悬挂在横杆上，liner的一面朝上。

# 7.开始计时1分钟，1分钟后将产品放置在托盘中，称量产品的重量W2.

# 8.记录下两次称量产品的重量。

备注：如果结果小的话，重新换蒸馏水复测。如果数值仍小，通知到机台工艺工程师与技师调整。进行厚度验证实验。
