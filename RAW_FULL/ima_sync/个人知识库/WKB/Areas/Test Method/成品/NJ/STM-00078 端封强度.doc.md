# STM-00078 端封强度.doc.md

8
STM-00078

端封强度测试

最新版本号：第6版           修订日期：2021年8月24日

实验目的：

该测试是使用拉力仪来测量尿裤外层与体侧层之间的端封和侧封的强度，

用于判定胶量和粘合强度。峰值载荷值用gf单位表示。

测试前的准备：

1. 打开拉力仪，检查压力表。夹具的气压不能超过0.6Mpa。

2. 选择测试方法为STM5599-1，调整夹具的距离为2英寸。

样品的准备：

1. 从包装袋中取出合格的产品

2. 标记产品的前后左右端（穿着时的方向）

3. 将体侧层朝外，后端向上，垂直挂在灯箱上，确保腰部松紧带完全拉伸。

4. 手指轻轻捋过松紧带。将1000g的双配重夹夹在腰部中心位置，不要夹到绒毛上。

5. 手指再一次轻轻捋过松紧带，确定腰部松紧带是完全拉伸的。

6. 选择P.O11946994模块，将黑线对准即将测试的端封边，在凹槽中标记

7. 量取3英寸*100mm区域。

8. 将配重夹移走，然后将样品从灯箱上。

9. 剪下样品，轻轻去除绒毛，不要破坏密封边。

测试步骤：

1. 拉力仪清零；样品的内侧面朝向操作者，把样品的底膜层夹到上夹具上。

2. 样品自由悬挂，拉力仪清零；体侧面夹到下夹具上。

3. 点击“开始”，开始拉伸测试。

4. 外层与体侧层的分离边缘应该在上下夹具的中心位置。

5. 测试过程中如果发生滑动，重新取样测试。

6. 记录下最大值，用gf表示。

操作注意事项：

样品夹在夹具上的时候，与夹面平行，不能倾斜或者有皱褶。

操作安全：

1. 在制备样品使用剪刀时，必须将手正确放置以防止手部被割伤。

2. 当往拉力仪上下夹具间夹测试样品，松开脚踏板时，注意手指不要被夹具夹伤。
