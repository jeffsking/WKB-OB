# STM-00048 SAM含量.docx.md

8
STM-00048

纸尿裤SAM含量的测试

最新版本号：第2版           修订日期：2021年8月24日

实验目的：

本测试根据样品中的钠含量测出SAM的含量。

测试前的准备：

氯化铵溶液（50L）：1. 测试蒸馏水的电导率<40µs。

2. 用干净的大烧杯称取氯化铵固体1750g+/-5g。

3. 充分溶解后定容至50L。

4. 等待溶液恢复室温后方可进行测试。

标准液：1.取纯净的SAP。

2.分别量取2g+/- 0.01g、5g+/- 0.01g、10g+/- 0.01g、15g+/- 0.01g的纯净SAP于测试袋中。

3.分别称取1500g+/-10g的氯化铵溶液，加入到塑料袋中。放进搅拌器中搅拌2分钟,静置至少15分钟。

4.分别用标准液润洗四个干净的容器3次，将标准液倒入容器中，盖紧并贴上标签。

5.将四个干净的100ml烧杯去皮，从容器中称取100g±0.5g标准液。剩余标准液盖紧，以备下次测试时使用。

润洗液：称取2g+/-0.02gISA，定容至1000ml，转入500ml的洗瓶中以备使用。

样品的准备：

# 1. 从包装袋中取出合格的产品，记录样品重量。

# 2. 装在塑料袋中，撕开产品使绒毛暴露（撕开的过程中尽量少接触产品，如果撕开的过程中SAP蹦出测试带，取样无效）。

# 3. 称取1500g+/-10g的氯化铵溶液，加入到塑料袋中。放进搅拌器中搅拌2分钟,静置至少15分钟。

# 4. 用样品溶液将一个大烧杯润洗3次，再将溶液倒在这个大烧杯中。

# 5. 对100ml的烧杯去皮，从大烧杯中量取100g+/-0.5g测试液，盖上薄膜，并标记。

操作步骤:

# 1. 将电极从电极储存液中移出，打开气孔；按压电极盖帽，挤出一点电极填充液后，加入一点新鲜的电极填充液；润洗电极和搅拌棒，并用吸水纸轻轻吸走电极和搅拌棒上的水滴。

# 2. 称取2g+/-0.02gISA加入到已标记的标准液中，将电极和搅拌棒放入低浓度标准液中浸泡30min（浸泡过程中不用启动仪器）。

操作注意事项：

1. 每个月应该至少对电极斜率进行一次检查。

2. 每次测试前检查电极填充液至少保持在螺旋管底部。

3. 每次测试前检查电极上密封扣是否打开。

4. 操作时不得使电极碰触任何物品或用纸擦电极，应使用柔软的纸巾轻轻吸去电极上的水份，以免损坏。

5. 应保持电极清洁。

6. 所有的玻璃制品和塑料制品必须干净，且无任何钠离子残留物。

7. 在校验标准液的时候，从低浓度到高浓度。

操作安全：

1. 插拔电源时，小心触电。

2. 由于氯化铵刺激眼睛，因此在使用氯化铵颗粒剂时，应戴上护目镜。

3. 使用氯化铵粉剂时，应戴上乳胶手套。

4. 振荡器在工作中不允许将门打开。
