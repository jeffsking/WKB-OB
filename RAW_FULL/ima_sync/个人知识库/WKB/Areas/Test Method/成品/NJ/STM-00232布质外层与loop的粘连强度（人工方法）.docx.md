# STM-00232布质外层与loop的粘连强度（人工方法）.docx.md

8
STM-00232

布质外层与loop的粘连强度（人工方法）

最新版本号：第1版           修订日期：20年9月30日

实验目的：这是一个主观感受loop和外层材料之间的粘连强度。本方法通过对比照片评定1-5级的方式给出最终结果。

样品的准备：1. 从包装袋中取出合格的样品。

测试步骤：

# 1.标记产品的的穿着方向（左右）

# 2.打开尿裤，外层面朝操作者，如图一用大拇指和食指拿住尿裤前面部分（loop端）保证耳朵被捏住。

# 3.用另一只手的拇指和食指捏住loop无胶区域，该手要小心，不要破坏loop和外层的连接。

# 4.从尿裤右侧快速撕开loop，撕的方向是180度剥离力，撕到loop中间位置即可。

# 5.从左侧开始，步骤同上。

评价等级：

# 1.很容易将loop从外层撕开，loop没有任何破损，外层材料也没有无纺布掉落，见1#

# 2.Loop完全被撕掉，但是在CD方向上有小于25.4mm的撕破或者无纺布分层起毛（测试终止位置是撕到loop中间就停止）

# 3.Loop完全被撕掉，同上，但是撕破的面积大于25.4m，见3#.

# 4.Loop完全被撕掉，同上，撕掉面积大于50%以上（测试终止位置为时候loop的中间）

# 5.Loop完全被撕掉，同上，全部材料都有撕破。见图5#
