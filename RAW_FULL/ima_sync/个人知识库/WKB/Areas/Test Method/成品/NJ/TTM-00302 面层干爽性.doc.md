# TTM-00302 面层干爽性.doc.md

8
TTM-00302

表面干爽性测试

最新版本号：第1版         修订日期：2021年8月24日

实验目的：

本测试用于测试纸尿裤吸收液体后表面的干爽程度。

测试前准备：

1. 测试液准备：用蒸馏水将0.1g蓝色食品级粉末定容到100mL容量瓶中，混合均匀后取出4mL溶液，加入到1L0.9%的盐溶液中。

2. 水浴加热盐水至37℃。

样品的准备：

# 1.称取产品重量，精确到0.01g。

# 2.去掉腿部和折页皮筋，使产品能够平整放置到FIFE的板上。注意不要剪的太深导致产品测试过程中从侧面渗漏。

# 3.称量滤纸重量，并记录。

# 4.放置称过重量的滤纸在FIFE的板上，然后固定产品，按照下表在target zone做标记。

测试步骤：

# 1.开始注液（37℃的0.9%的生理盐水），速度为15ml/s. 记录第一次吸收时间

# 2.吸收完成之后等待30秒

# 3.等待30秒之后，放上称过重量的长方形滤纸和表面干爽性的压板（177g），等待2min。

# 4.取下滤纸称重，计算回渗量。同时称量下层滤纸记录溢出重量，并记录。

# 5.重复步骤1-4，进行第二次和第三次测试，并记录。
