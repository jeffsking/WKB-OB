# China-WI-62416 无纺布变形测试 20240201.docx.md

实验目的：

本实验意在测试无纺布材料MD方向2%的形变力，评估材料拉伸形变情况。

测试前的准备：

# 1、确定拉力仪的合适负重单元，安装适当的夹具，确保夹具和夹面没有杂质堆积且夹具面没有压痕或其他损伤。选择测试方法为2%形变拉力，调整夹具间距为50.8cm（20英寸），确认连杆器速度为25.4cm/min（10英寸/分钟）

# 2、剪刀一把

# 3、订书器一个

# 4、60cm的直尺一把

# 5、直径1cm，长度≥60cm的不锈钢棍一根（如图1）

# 4、将准备好的测试样一端夹在拉力仪上端，样品自由悬挂，拉力仪清零，另一端夹在拉力仪下端，选择“2%形变拉力”方法，夹具初始高度50.8cm，点击“开始”，拉力仪开始拉伸测试。

结果：

记录2%的形变力，单位“N”表示。用得出的形变力除以材料的幅宽值（单位cm），得出的是N/cm。

具体计算过程：
2%形变力=\frac{2.5\mathrm{\%}\mathrm{应}\mathrm{变}\mathrm{力}-1.5\mathrm{\%}\mathrm{应}\mathrm{变}\mathrm{力}}{1\mathrm{\%}\mathrm{应}\mathrm{变}}/材料幅宽（cm）

操作注意事项：

为了不使夹面过度磨损，拉力仪不使用时释放压力。

操作安全：

使用剪刀和拉力仪时注意安全，不要弄伤手。
