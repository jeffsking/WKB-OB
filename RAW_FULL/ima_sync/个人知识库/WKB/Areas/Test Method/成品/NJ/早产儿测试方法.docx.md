# Preemie Diaper Absorption Test Methods & Parameters
早产儿尿不湿吸收性能测试方法与参数总结

# 1. Summary / 摘要

This document consolidates the retrieved preemie (low-birth-weight) diaper absorption test requirements across GB/T 28004.1, Cradle (TTM-00148), Surface Moisture (TTM-00302), Rewet (TTM-00623) and Retention Capacity (STM-00033), including the North America preemie parameters and available retention values.

本文档整合了目前检索到的早产儿（低出生体重）尿不湿吸收性能测试要求，涵盖国标 GB/T 28004.1、Cradle（TTM-00148）、Surface Moisture（TTM-00302）、回渗（TTM-00623）与滞留能力（STM-00033），并包含北美早产儿详细参数及可查到的滞留能力数值。

# 4. Rewet Methods (besides Cradle) / 回渗测试方法（Cradle 之外）

Insult parameters by method (preemie) / 各方法注液参数（早产儿）

|Method / 方法|Insult volume / 注液量|Flow rate / 注液速度|Insults / 注液次数|Location &amp; pressure / 位置与压力|
|---|---|---|---|---|
|Surface Moisture (TTM-00302)|TTM-00148 preemie (NP 3 / MP 5.5 / SP 6 / P 8 mL) / 引用 TTM-00148 早产儿量|7.5 mL/s|1 (optional repeat) / 1 次（可重复）|By size/market (Table 1, preemie = &#34;0/Newborn Preemie&#34;); rewet pressure ~0.02–0.05 psi / 按尺码定位，回渗压力约 0.02–0.05 psi|
|Low/High Pressure Rewet (TTM-00623)|TTM-00148 preemie (same) / 同上|1 mL/s per TTM-00148 / 按 TTM-00148 早产儿流速 1 mL/s|2 (low + high) / 2 次（低压+高压）|TTM-00148 insult point (NP/MP 3cm, SP 3.5cm, P 4cm); insult pressure 0.02/0.4 psi, rewet 0.005/0.24 psi, 15 min interval / 注液压力 0.02/0.4 psi，回渗压力 0.005/0.24 psi，间隔 15 min|
|Retention Capacity (STM-00033)|N/A — whole-product saturation / 无注液，整片饱和|N/A / 不适用|N/A / 不适用|Saturation then 0.5 psi (3.45 kPa) for 5 min / 饱和后加压 0.5 psi 保持 5 min|

Recommended: TTM-00623 Low/High Pressure Rewet, optionally supported by TTM-00302 Surface Moisture. Cradle (TTM-00148) is an intake method, not rewet.

推荐：TTM-00623 低/高压回渗，可辅以 TTM-00302 表面潮湿度。Cradle（TTM-00148）属于吸收(intake)方法，非回渗。

North America measured values / 北美实测值

Low/High Pressure Rewet (TTM-00623), Huggies preemie under new parameters.

高低压回渗（TTM-00623），Huggies 早产儿新参数实测。

|Size / 尺码|Low Rewet / 低压回渗|High Rewet / 高压回渗|
|---|---|---|
|Nano Preemie|0.03 g|0.05 g|
|Micro Preemie|0.03 g|0.06 g|
|Preemie|0.04 g|0.99 g|

Surface Moisture / 表面潮湿: No NA preemie-specific measured value found this time / 本次未检到北美早产儿专项 Surface Moisture 实测值。

# 5. Retention Capacity / 滞留能力

Recommended method: STM-00033 Absolute & Specific Retention Capacity (gold standard, whole product).

推荐方法：STM-00033 绝对/相对滞留能力（金标准，适用整片产品）。

|Region / 区域|Retention capacity / 滞留能力|Note / 说明|
