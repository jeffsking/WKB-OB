# STM-4597纸尿裤SAM分布测试.docx.md

8
STM4597

纸尿裤SAM分布测试

最新版本号：第1版           修订日期：2021年8月24日

实验目的：

本测试方法确定婴儿纸尿裤或婴儿纸尿片产品的SAM分布。

测试前的准备：

1.  5%乙酸配制

# (1)在大烧杯中加入纯乙酸5ml。

# (2)再加入95ml蒸馏水，搅拌。

2.  溴甲酚绿SAP指示溶液的配制：

# (3)在900毫升烧杯内加入450毫升蒸馏水；

# (4)在量筒内量取50毫升5％的乙酸；

# (5)在搅拌蒸馏水的同时，加入50毫升5％乙酸，持续搅拌使两种溶液完全混合；

# (6)用已去皮重的称量纸称取0.25克溴甲酚绿钠盐；

# (7)搅拌的同时慢慢地将0.25克溴甲酚绿钠盐加入上述混合溶液中，持续搅拌至少5分钟;

# (8)直到所有溴甲酚绿钠盐溶解;

# (9)将溶液小心倒入喷壶中，待用。

样品的准备：

1. 沿绒毛的边缘剪掉底膜和无纺布部分，围绕整个产品边缘。

测试步骤：

1. 将样品平放在容器内，使用面朝上；

2. 从尿裤上取出使用面上的无纺布和包裹衬纸尽量不要破坏绒毛区；可以用镊子拣去绒毛上的尿裤组件碎片

3. 用指示液均匀喷洒样品，保持指示液喷头离样品表面152-254毫米）

4. 按下喷洒阀，沿纵向来回喷洒，用指示喷洒液均匀地覆盖样品表面；

5. 通过将样品与一套合适地标准照片进行比较，评价SAP颗粒的分布。

操作注意事项：

1. 样品必须在喷洒后15到30秒的时间内定出级别

2. 实验完毕后将样品和保护覆盖物放在一个塑料袋中废弃。

操作安全：

1. 因指示液有强烈的刺激气味，故实验过程中请佩戴口罩；

2. 指示液与皮肤接触后，不容易用水洗去，故在操作中请佩戴一次性手套。
