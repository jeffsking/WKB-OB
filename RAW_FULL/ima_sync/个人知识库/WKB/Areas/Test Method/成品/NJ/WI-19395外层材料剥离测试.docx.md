# WI-19395外层材料剥离测试.docx.md

8
WI-19395

外层材料剥离测试

最新版本号：第0版           修订日期：2014年5月28日

实验目的：这个测试是使用恒定速度的拉力设备测定尿裤底膜与外层之间的粘连强度。

测试前的准备：确保拉力仪夹具清洁，没有绒毛和Sam颗粒。

测试步骤：

# 1.完全拉直后腰围，完全展开后腰围，使得尿裤居中放在3英寸切刀上切刀边与尿裤侧边平行。

# 2.将切刀向下压过腰部松紧带末端上以致完全切断腰部皮筋，最终的样品应该长于160mm

# 3.将样品取出，在MD方向上从后腰围边缘开始往loop端160±1mm，在该处CD方向剪断，确保样品长宽分别是160±1mm和76mm±1mm。

# 4.去掉pad部分，不要破坏外层和面层的粘连

# 5.从端封边缘开始，轻轻拉开外层使得外层和底膜分离，分离的MD距离为38mm。分离的部分用于夹具固定。

# 6.拉力仪参数设定：

夹具之间的距离(gage length)是51±1mm(2英寸)，夹具速度（crosshead spead 305±10mm/min）开始计算距离Start Calculation 20mm，结束计算距离（end calculation）150mm，测试结束test end 160mm 全程负载(full scale load)单位gf 测试结果选择均值，测试前清零负载（load）和crosshead

# 7.将样品放在夹具中间，外层加在上夹具上，底膜在下夹具

# 8.底膜图案面朝测试者，外层和底膜的分离线需要放在两夹具中间

# 9.保证样品有一定的松度，有张力的话会影响测试结果

WI-19395

# 10.开始测试，记录均值精确到0.1gf

# 11.如果测试过程中有样品松动，需要丢弃这个测试值，重新测试。
