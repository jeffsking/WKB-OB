# STM-00305 SAM分布.docx.md

8
STM-00305

纸尿裤SAM分布—膨胀测试

最新版本号：第5版           修订日期：2021年8月24日

实验目的：

该测试用来判断尿裤中吸收体的分布情况。

测试前的准备：

1. 准备500ml以上的蓝色水溶液；

2. 选择适合产品型号的水槽（C124-A4-05467/68/70-C-02）。样品的准备：

3. 小心的取出样品，尽可能避免SAM和绒毛的移动；

4. 面层向下，使用1inch切刀，切下产品MD方向中间位置，转向切时应小心，避免产品的倾斜；

5. 拿住两头端封位置时，尽可能保持水平，面层向下置于水槽中，样品应平放于水槽底部。

测试步骤：

# 1.使用不同体积的蓝色水溶液进行测试，具体使用量如下表所示：

|产品型号|溶液用量|
|---|---|
|初生（NB-Step1）|20ml±5ml|
|小号（S-Step2）|250ml±5ml|
|中号（M-Step3）|300ml±5ml|
|大号（L-Step4）|350ml±5ml|
|加大号（XL-Step5）|350ml±5ml|
|加加大号（XXL-Step6）|350ml±5ml|

2. 使用1000ml烧杯取出规定量的液体，均匀倒入水槽中；

3. 评估样品，观察绒毛的缺失情况及SAM和绒毛的分布情况；

4. 打分并拍照保存。

操作注意事项：

1. 测试前不要取出产品，裁切过程中尽量避免SAM和绒毛的移动；

2. 产品不可悬挂于灯箱上。

操作安全：

裁切过程中，穿戴好PPE，并避免切刀造成的手部损伤。
