# STM-00059 反渗.docx.md

8
STM-00059

纸尿裤反渗测试

最新版本号：第3版           修订日期：2021年8月24日

实验目的：

测量一定压力下，尿裤吸收一定量液体后的反渗量，用g表示。

测试前的准备：

1. 打开真空泵，选择设定按钮，将真空压力设置为14±1英寸的水柱压力。

2. 在测试时间设定处设定期望测试时间，这个时间包括到达到测试压力的时间。

样品及器材的准备：

1．样品称重，精确到0.01克，将样品的腿部松紧带和折叶松紧带每隔1英寸剪开，

但不要剪掉，不要剪至密合缝或绒毛区域，使样品平放。

2.准备尺寸为3.5英寸×12英寸的滤纸。

# 测试步骤：

# 1. 按照不同样品测试时所需要的测试盐溶液量取溶液：ST2-150±0.5ml，ST3/Med-180±0.5ml，ST4/L-210±0.5ml,ST5/XL-240±0.5ml。

# 2. 将尿裤底膜层向下放在测试仪的中心位置上,确保样品平放，按照测量表格指出的目标值从绒毛前端量

# 出测试区域，并进行标记。

|Size|ST2|ST3|ST4|ST5&amp;6|
|---|---|---|---|---|
|Unisex test length (mm）|114|127|140|146|

# 3. 小心的将测试液倒入测试区域上,不要将液体倒到样品的外面。

# 4. 将测试仪的四周边缘湿润，将干燥的乳胶膜盖在样品上，在控制面板上设定测试时间3分钟±15秒，设定等待时间1分钟。

# 5. 点击开始按钮，确保压力控制在14+/-1英寸水柱的压力（3447pa）下保持3分钟±15秒，不要超过30秒。

# 6. 待警示声响起后，掀起乳胶膜并擦干。

# 7. 对准备好的滤纸称重，保留到0.01g，并记录下这个值，作为Dry wt.

# 8. 放置时间到达1min时，从距离绒毛前端6mm的位置覆盖滤纸。

# 9. 将测试仪的四周边缘湿润，将干燥的乳胶膜盖在样品上，在控制面板上设定测试时间2分钟。

# 10. 点击开始按钮，确保压力控制在14+/-1英寸水柱高度的压力（3447pa）下保持2分钟±15秒。

# 11. 待警示声响起后，掀起乳胶膜并擦干。将湿滤纸的称重，保留倒0.01g，记录作为Wet wt.

# 12. 计算反渗值：反渗量= 湿滤纸重量 - 干滤纸重量

操作注意事项：

1. 实验前，先检查乳胶膜看是否存在孔或撕裂的痕迹；

2. 准备样品时，剪产品上的松紧带时不要破坏产品的胶线；

3. 在真空泵工作过程中，不要将盖在实验仪上的橡胶布掀开；

4. 如果测试仪上的乳胶膜是湿的，在测试下一个样品前将其擦干；

5. 在每次分配液体实验后，如果滤纸上无溢出是干的，可在下次样品测试时使用；

操作安全 ：

随时观察乳胶膜是否堵住了通气孔，以免发生内爆的危险。
