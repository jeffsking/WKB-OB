# KC U Rewet测试.docx.md

8
U Rewet测试

最新版本号：第2版                  修订日期：2021年3月1日

实验目的：

本测试用于模拟纸尿裤在穿在身上时，吸收一定量液体所需要的时间和回渗。

测试前准备：

1.  测试液准备：用蒸馏水将0.1g蓝色食品级粉末定容到100mL容量瓶中，混合均匀后取出4mL溶液，加入到1L 0.9%的盐溶液中。

2.  水浴加热盐水至37℃。

3.  准备合格的产品若干片

测试泵的校验：

每次测试前及不同Size检测时进行校验

# 1、按开始键启动泵，通过Mode键调至Flow rate灯亮，按上下键调至待测Size Flow rate值。

# 2、按Mode键调至DISP灯亮，调整至读数60。

# 3、按Mode键调至Volume灯亮，通过上下键调至待测Size Volume值。

# 4、在Volume灯亮状态下，按Run键，用去皮的烧杯称量流出液体的重量，记下读数，按Cal键将读数通过上下键输入仪表盘内，再按Cal键确认。

# 5、重复Volume灯亮，Run键启动泵并称量流出液体的重量，目标值±3g内可以接受。

|---|---|---|---|---|---|---|
|Flow rate（mL）|600|720|900|900|900|900|
|DISP（s）|60|60|60|60|60|60|

# 1、取1片合格的样品， 称量并记录其重量---Weight （Dry Product）

# 3、利用直尺测量合格的产品并标记产品的中心位置，以中心位置为基准向产品前标记出测试位置，各Size距产品中心位置如下：

表2

将标记好的样品轻轻拉伸固定在Cradle托架上，产品前端面朝测试者，确保产品中心位置对准托架凹槽的最底部。

# 4、用手指沿折页和腿部捋过固定产品位置，并确保折页打开站立且不要挡住吸收芯。

测试步骤：

# 1、通过Mode键调至Flow rate灯亮调整至相应Size设定值，调Volume灯亮调整至目标值，详见表1。

# 2、调至DISP灯亮显示60，调至Pause灯亮显示15’。

# 3、调Flow rate和Volume灯同时亮，进入测试状态。

# 4、将出液口对准产品前端的标记处，距离产品水平距离10mm。

# 5、准备好秒表，按Run键同时按下秒表开始计时，观察产品上面的液体流动，当所有液体已经渗透到表面以下，停止秒表并记录第一次吸收时间。

# 6、5 分钟后设备启动重复注入液体，记录第二次吸收时间。

7、第二次注液后等待5分钟,  取下尿裤，粘贴于国标回渗测试板上，用直尺测量扩散区域MD 长度， 记录为扩散长度。 同时确认产品扩散区域的中心位置（测量时请保持直尺不接触产品表面）。

8、将滤纸放置于产品液体扩散区域（尽量保证滤纸中心和扩散区域中心重合），后将国标回渗压块放置于滤纸之上， 压1min后取下压块和滤纸， 称量滤纸的湿重， 并记录为Weight (Wet Paper)。

试验后记录数据：

1.  产品干重 --- Weight (Dry Product)

2.  第一次吸收时间， 第二次吸收时间

3.  扩散长度

4.  回渗 =  Weight (Wet Paper) – Weight (Dry Paper)

操作注意事项：

1、校验：泵首次启动时确保进液管和出液管内液体是充满的；校验时保持出液口与接液烧杯呈水平位置，在液体最后流完时不要甩动出液口；

# 2、注意测试时出液管与产品间的距离，防止距离过近，瞬间压力变大而使测试液飞溅。

3、测试用的液体需提前放至水浴锅，并保证加热至37℃。

4、注意水浴锅中是否缺水，如缺水，应立即加入，以免干锅而烧坏水浴锅。

操作安全：

# 1、插拨电源时，小心触电。

# 2、从水浴锅取放液体时不要把水溅出，以免水浴锅漏电。
