# TTM-00148 Cradle测试.doc.md

8
Cradle测试

最新版本号：第1版         修订日期：2021年8月24日

实验目的：

本测试用于模拟纸尿裤在穿在身上时，吸收一定量液体所需要的时间。

测试前准备：

1.  测试液准备：用蒸馏水将0.1g蓝色食品级粉末定容到100mL容量瓶中，混合均匀后取出4mL溶液，加入到1L0.9%的盐溶液中。

2.  水浴加热盐水至37℃。

测试泵的校验：

每次测试前及不同Size检测时进行校验

1. 按开始键启动泵，通过Mode键调至Flow rate灯亮，按上下键调至待测Size Flow rate值。

2. 按Mode键调至DISP灯亮，调整至读数60，按Run键，用去皮的烧杯称量流出液体的重量，记下读数

若不在范围内，通过Mode键调至Flow rate灯亮，按Cal键将读数通过上下键输入仪表盘内，再按Cal键确认。

3. 重复第2步，直至满足流出液体的重量，目标值±3g内可以接受。

4. 按Mode键调至Volume灯亮，通过上下键调至待测Size Volume值。

5. 在Volume灯亮状态下，按Run键，用去皮的烧杯称量流出液体的重量，记下读数，满足流出液体的重量，目标值±3g内可以接受。

表2

将标记好的样品轻轻拉伸固定在Cradle托架上，产品前端面朝测试者，确保产品中心位置对准托架凹槽的最底部。

# 2.用手指沿折页和腿部捋过固定产品位置，并确保折页打开站立且不要挡住吸收芯。

测试步骤：

1. 调Volume灯亮，进入测试状态。

2. 将出液口对准产品前端的标记处，距离产品水平距离10mm。

3. 准备好秒表，按Run键同时按下秒表开始计时，观察产品上面的液体流动，当所有液体已经渗透到表面以下，停止秒表并记录吸收时间。

4. 15分钟后设备自动启动重复滴加液体，记录第二次吸收时间，再过15分钟后重复记录第三次吸收时间。

读数：发生以下几种情况，数据记录无效。

# a.如果有液体滴到了产品非吸收部分，数据被认为是无效的，应当载明产品失败的结果。

# b.如果液体流出折页到了Cradle模具上，数据被认为是无效的，应当载明产品失败的结果。

# c.如果液体超过5分钟后流转，数据被认为是无效的，应当载明产品失败的结果。

操作注意事项：

1. 校验：泵首次启动时确保进液管和出液管内液体是充满的；校验时保持出液口与接液烧杯呈水平位置，在液体最后流完时不要甩动出液口；

2. 注意测试时出液管与产品间的距离，防止距离过近，瞬间压力变大而使测试液飞溅。

3. 测试用的液体需提前放至水浴锅，并保证加热至37℃。

4. 注意水浴锅中是否缺水，如缺水，应立即加入，以免干锅而烧坏水浴锅。

操作安全：

1. 插拨电源时，小心触电。

2. 从水浴锅取放液体时不要把水溅出，以免水浴锅漏电。
