# 橡筋拉伸比测试.doc.md

8
橡筋拉伸比测试

最新版本号：第0版         修订日期：2021年3月4日

实验目的：此测试用于测量尿裤产品中橡筋的拉伸率。

测试前准备：

[图片: 70mm 70mm]
# 1.无水酒精；

# 2.50cm 钢尺1 把；

# 3.胶头滴管1 支；

# 4.镊子1 把。

测试步骤：

# 一、腰围皮筋拉伸率检测：

# 1. 按照STM-00433 方法，将腰围展开，在前后腰围，

橡筋连续的部位分别剪取70mm 样品；

# 2．用胶头滴管吸取无水酒精，充分浸润剪下的样品10min，

剪取下来的片样，用镊子取出每根橡筋 ； （在取下橡筋的过程中，

尽量避免拉伸橡筋，若遇到无法剥离的橡筋，可适当增加浸润时间，

或换一片产品，取相应位置的橡筋作为替代）

# 3．以腰围顶端为第一根，按照腰围橡筋分布顺序，依次排列取下的橡筋；

# 4．用胶头滴管在操作平台上滴上少量液体，利用镊子拖拽橡筋的一头，直至橡筋拉直且不拉伸的状态；

# 5．利用钢尺依次测量每根橡筋的长度，并记录每根橡筋长度数据；

前腰围F1, F2,F3...…(mm)

后腰围B1,B2,B3...…(mm)

# 6．分别计算每根橡筋的拉伸 倍率 Installed elongation =70/Fn or Bn

# 二、 折页/腿部皮筋拉伸比检测：

# 1．按照 STM00433的方法， 将产品展开， 分别剪取左右折页 /腿部中间

160mm长的皮筋；

# 2．用胶头滴管吸取无水酒精，充分浸润 剪下的样品10min 剪取下来的片样 ，用镊子取出每根橡筋；

（在取下橡筋的过程中，尽量 避免 拉伸 橡筋 ，若遇到无法剥离的橡筋，可适当增加浸润时间，或换一片产品，取相应位置的橡筋作为替代）

# 3．用胶头滴管在操作平台上滴上少量液体，利用镊子拖拽橡筋的一头，直至橡筋拉直且不拉伸的状态；

# 4．利用钢尺 依次测量 每根橡筋的长度，并记录每根橡筋长度数据 L ；

# 5．分别计算每根橡筋的拉伸率为：Installed elongation =160/L 。

操作注意事项：

# 1.测试样品必须是未拉伸过的，刚从包装袋取出的样品；

# 2.注意撕开腰封的时候，尽量避免拉伸腰围橡筋；

# 3.从无纺布取下橡筋的过程中，尽量避免拉伸橡筋，若取下橡筋有困难，可加长无水酒精浸泡的时间

# 4.钢尺必须经过检定才可以使用；

# 5.注意剪刀的使用安全。
