# 实验目的：

主要用于测试纸尿裤和纸尿片在14±1英寸水柱外压下滞留的能力.

测试前的准备：1. 打开控制面板电源，将真空压力控制在 14+/-1 英寸的水柱压力

2. 在控制面板上设定浸泡时间 20 分钟±15 秒，滴水时间 1 分钟±15 秒，

测试时间5分钟±15秒，真空度14±1英寸水柱。

3. 配置 0.9% 的 NaCl 溶液倒入水槽中溶液高度不能低于 2 英寸（51mm）

样品的准备:样品称重，精确到 0.01克，将样品的腰围松紧带，腿部松紧带和折页松紧带每隔 1英寸剪开，但不要剪掉，不要剪至密合缝或绒毛区域，使样品平放。

测试步骤：1. 将样品底膜面朝上置于2英寸（51mm）高的盐溶液中，启动控制面板上的浸泡开始开关，样品浸水后，无纺布面朝下漂于水中，不要给样品施加力，样品不能与容器底部接触，必须在水中自由漂浮。

2. 待浸泡警报声响起后，按下停止开关，托住尿裤前后边缘立刻将样品从测试液体中取出，在将样品转移到测试仪上时，尽可能保持样品在水平位置，样品仍然底膜面朝上放置。

3. 平放于测试仪上，启动控制面板上的滴水开始开关，滴水过程中，用测试液将测试仪四周润湿。

4.待滴水警报声响起后，按下停止开关，将乳胶膜平铺于测试仪上，启动控制面板上的测试开始开关。

5.待测试警报声响起后，按下停止开关，抬起乳胶膜，将样品从测试仪上取下称重，精确至0.01克。

6. 绝对滞留能力$g$ = 湿样品重量——干样品重量，相对滞留能力$g/g$ = 绝对滞留能力/干样品重量

操作注意事项：1.实验前，先检查乳胶膜看是否存在孔洞或撕裂的痕迹；

2. 准备样品时，剪产品上的松紧带时不要破坏产品的胶线；

3. 在真空泵工作过程中，不要将盖在实验仪上的橡胶布掀开；

4.如果测试仪上的乳胶膜是湿的，在测试下一个样品前将其擦干;

5.方法中所说的前、后、左、右均指尿裤穿着时的方向;

6. 仪器使用结束后，关闭电源，如遇断电断气，请勿使用仪器。

7. 手部接触盐溶液后，请彻底清洗手部。

8.测试溶液需在测试数量 30片样品后更换一次，如当日测试数量未达到30片，则每班更换一次。

操作安全:1.插拔电源时，小心触电;

2. 随时观察乳胶膜是否堵住了通气孔，以免发生内爆的危险。

3. 在制备样品使用剪刀时，必须将手正确放置以防止手部被割伤。

4. 真空泵运行过程中，请勿靠近，以免受伤。

5.使用氯化钠时，根据MSDS要求需佩戴化学品手套、化学品护目镜。

紧急处理:1.如溶液误入眼中，请到实验室水池旁，使用洗眼器清洗眼部，并尽快就医。

2.如溶液误入口中，请用清水漱口，必要时及时就医。

3. 任何异常情况，点击控制面板上停止按钮。

4. 如制样时，被剪刀伤手，请立即用碘伏消毒，包扎，如必要请立即就医。

# 纸尿库厚度测试

[图片]
最新版本号：第 3 版

修订日期：2022年4月5日

实验目的:该方法用来测试样品在 0.2PSI 压力下，婴儿纸尿裤的厚度(mm)。

测试前的准备:1. 确保测厚仪上脚踏板的管路压力至少为60 psi (413±21 kPa)

(4.2 kg/cm$^{2}$)，并且不超过每平方英寸65磅(4.55 kg/cm$^{2}$)。

2. 打开厚度仪开关，确保降落过程中指示器（圆柱形）运动平稳。

3.检查压块的位置，使其在测试区域的中心位置。

样品的准备：1.从包装袋中取合格的产品。

2. 去除产品的折页和大腿松紧带，使产品能够平整放置。注意不要剪切到吸收层，不要破坏其厚度。

测试步骤：1. 踩住脚踏板使铜块抬起，清理测试台面及铜块底面。

2. 将厚度仪清零。

3. 踩住脚踏板使铜块抬起，将样品居中（使用面朝上）放于铜块下。使样品 MD 方向与基座保持水平。

4.松开脚踏板，在铜块停止下落后等待3秒(数完1001,1002,1003)后记录读数(精确到0.01mm);

5. 踩住脚踏板使铜块抬起，移走样品，将仪器复位。

操作注意事项：1. 严禁随意按动测试仪上的按钮。

2.所有制备的样品必须在1小时之内进行测试(从样品制备开始到测试结束);

操作安全:1.插拔电源时，小心触电;

2. 当将样品送到铜块下方进行测试时，铜块落下会压手。

3. 在制备样品使用剪刀时，必须将手正确放置以防止手部被割伤。

4. 断电断气后，请勿使用仪器。

紧急处理：1.如遇铜块压手，请勿直接抽离，先踩下脚踏将铜块抬起后，再移开手。

2. 如制样时，被剪刀伤手，请立即用碘伏消毒，包扎，如必要请立即就医。

# 纸尿裤SAM分布测试

STM-00236

最新版本号：第2版

修订日期：2018年4月23日

## 实验目的：

本测试方法确定婴儿纸尿裤或婴儿纸尿片产品的 SAM 分布。

## 测试前的准备:

### 1.5%乙酸配制

(1)在大烧杯中加入纯乙酸5ml。

(2)再加入95ml蒸馏水，搅拌。

2.溴甲酚绿SAP指示溶液的配制:

(3)在 900毫升烧杯内加入 450毫升蒸馏水;

(4) 在量筒内量取 50毫升 5%的乙酸;

(5)在搅拌蒸馏水的同时,加入50毫升5%乙酸,持续搅拌使两种溶液完全混合;

(6) 用己去皮重的称量纸称取 0.25 克溴甲酚绿钠盐；

(7)搅拌的同时慢慢地将 0.25克溴甲酚绿钠盐加入上述混合溶液中，持续搅拌至少 5分钟;

(8)直到所有溴甲酚绿钠盐溶解;

(9) 将溶液小心倒入喷壶中，待用。

## 样品的准备：

1. 沿绒毛的边缘剪掉底膜和无纺布部分，围绕整个产品边缘。

## 测试步骤:

1. 将样品平放在容器内，使用面朝上；

2.从尿裤上取出使用面上的无纺布和包裹衬纸尽量不要破坏绒毛区;可以用镊子拣去绒毛上的尿裤组件碎片

3.用指示液均匀喷洒样品，保持指示液喷头离样品表面152-254毫米)

4.按下喷洒阀，沿纵向来回喷洒，用指示喷洒液均匀地覆盖样品表面;

5. 通过将样品与一套合适地标准照片进行比较，评价 SAP 颗粒的分布。

## 操作注意事项:

1. 样品必须在喷洒后15到30秒的时间内定出级别

2.实验完毕后将样品和保护覆盖物放在一个塑料袋中废弃。

## 操作安全：

1. 因指示液有强烈的刺激气味，故实验过程中请佩戴口罩。

2. 指示液与皮肤接触后，不容易用水洗去，故在操作中请佩戴一次性手套。

实验目的:该方法用来测试样品在0.2PSI压力下,婴儿纸尿裤的厚度(mm)。

测试前的准备:1.打开厚度仪开关，确保降落过程中指示器(圆柱形)运动平稳。

## 厚度测试

测试步骤：1. 踩住脚踏板使铜块抬起，清理测试台面及铜块底面。

3. 踩住脚踏板使铜块抬起，将样品居中（使用面朝上）放于铜块下。使样品 MD 方向与基座保持水平。

4.松开脚踏板，在铜块停止下落后等待3秒(数完1001,1002,1003)后记录读数(精确到0.01mm);

## 密度测试

测试步骤：1. 在厚度测试完成时，记录厚度 D1，并使用记号笔在圆形压块周围描出轮廓。

2. 使用圆形切刀在轮廓区域内压下圆形。

3. 称量此圆片的重量，记为 W1。

4.小心去除整个芯体部分(包含绒毛、SAM、LSN、REL、PSN)，再次重复测量厚度，记为D2,称量重量记为W2。

5.密度 = (W1-W2) / [17.94*(D1-D2)*0.1]

实验目的:该测试用来测定尿裤的交货水分。

测试前的准备：1. 天平：精确到 0.001g

2.试样容器:用于试样的转移和称量。该容器应由能防水蒸气，且在试验条件下不易发生变化的轻质材料制成。

3. 提前打开烘箱预热至 105±2℃

4. 干燥器

样品的准备:1.取2包样品，从每包样品中各取1片试样，剪开试样边部松紧带，从2片试样的中间位置各取2g试料。

2. 将试料剪成块状，混合均匀后分成 2 组试样进行平行实验。放入试样容器中，分别记录容器的重量，2g 试料的重量。

测试步骤：1. 将装有试样的容器盖子打开，放入105℃的烘箱中烘干。

2. 当试样完全烘干时，应迅速将容器盖子盖好，然后将容器放入干燥器中冷却，冷却时间根据不同的容器估计。

3. 将容器的盖子打开并马上盖上，以使容器内外的空气压力相等，然后称量装有试样的容器，并计算出干燥试样的质量。

4. 重复步骤 1-3，其烘干时间应至少为第一次烘干时间的一半，当连续两次在规定的时间间隔下，称量的差值不大于烘干前试样质量的 0.1% 时，即可认为样品已达到恒重。（对于纸张试样，第一次烘干时间应不少于 2h，对于纸浆试样，应不少于 3h）

5.2次测定值的绝对误差不超过1%，取其算术平均值表示测定结果，修约至小数点后一位。

6. 计算公式如下：

水分X(%)应按以下公式计算:

$$X = \frac{m1-m2}{m1} \times 100$$

M1——烘干前的重量，单位（g）

M2——烘干后的重量，单位（g）
