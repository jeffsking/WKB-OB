# WI-64766温湿度纽扣测试方法.docx.md

8
WI-64766

温湿度纽扣测试方法研究

仪器编号：

最新版本号：第0版         修订日期：2024年6月21日

实验目的：

# 电子温度数据记录器 DS1923，是一种小体积的温湿度一体化数据记录器，直径约有 16.5mm，适合放置于很多需要测温湿度的场所。

# 本试验用于测试产品在吸尿后温湿度变化，评估产品穿着舒适度，进一步指导产品设计。

测试前准备：

# 1.将生理盐水加热至37±1℃。

# 2.产品称重记录。

# 3.准备好量筒、漏斗和计时器。

# 4.相对应size测试产品的新国标回渗仪器的模架。

# 5.准备胶带和双面胶。

# 6.将mannequin假体上的二氧化硅粉去除干净，否则会影响数据。

# 7.根据不同型号在下表中选择相应的注液量和注液间隔时间：

|Size|S|M|L|XL|
|---|---|---|---|---|
|LoadingUnit: ml|30+30|50+50|60+60|70+70|
|注液间隔时间|间隔1h 注液|间隔1.5h注液|间隔2h注液|间隔2h注液|

测试步骤：

# 1.将mannequin假体双腿分开并固定。

# 2.用胶带从假体裆部穿过粘贴在假体前后侧“皮肤”上，此步骤用于固定双面胶的粘贴位置（图1）。

# 3.取15mmX15mm左右的双面胶粘贴在假体裆部中间用于粘贴固定温湿度纽扣（图2）。

# 4.将产品穿戴在新国标回渗的架子上（图3）。

# 5.用量筒称量出所需的注液量，并用漏斗在产品MD中心位置上注液，称量生理盐水时，加热的生理盐水与架子上需要注液的产品距离不宜过远，否则会影响温度数据。

# 6.注液后马上计时3min，在3min等待时间中打开温湿度纽扣软件进行参数设置。

# 注：注液时请避开空调出风口或换气口，气流会导致注液后的产品温度不一致，从而影响数据的判断。

# 8.点击左上角菜单栏“任务设定”进入设定页面，勾选“标定记录仪时钟”延时启动选择“5分钟”最后点击“任务设定”按钮（图5）。

# 9.设定完成后点击“任务状态”栏查看“记录仪当前状态”是否为“运行”（图6）。

# 10.设置完成后将纽扣取下粘贴在步骤3准备好的双面胶上。

# 11.将产品穿戴在Mannequin上戴完成后用一根手指划过腿部皮筋和折页皮筋位置，确保产品服帖Mannequin。用记号笔标记出腰围前后的位置和裆部位置，保证产品穿着高度的一致，保证微环境空间尽量一致；保证穿着严密，没有和外界的空气流通（图7）。

[图片]
# 12.第一次测试时间结束后，将产品取下，重复测试步骤4-5注液并计时3min。

# 13.将纽扣与软件链接，点击主界面右侧的“下载数据”（图8）。

# 14.数据下载完成后点击“导出数据”将数据保存为excel格式（图8）。

# 注：数据下载时软件可能会出现数据异常的bug，为消除误差，在第一次下载保存完数据后请在次点击“下载数据”按钮，重新下载数据，并与第一次下载的数据对比，数据一致即可避免此bug。

# 15.重复步骤8-10重新设定纽扣并粘贴在mannequin假体上进行第二次测试。

# 16.重复步骤1重新将产品再次穿戴在mannequin假体上。

# 17.第二次测试时间结束后重复步骤13-14进行数据下载并保存。

# 18.全部测试完成后在“任务设定”栏点击“停止任务”关闭纽扣的测试状态，以避免纽扣电池不必要的消耗（图5）。

# 19.测试完成后将测试数据整理后发给对应工程师。
