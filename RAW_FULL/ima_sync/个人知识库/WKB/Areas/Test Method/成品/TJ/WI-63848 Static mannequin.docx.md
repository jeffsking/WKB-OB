实验目的：

本试验用于模拟尿裤产品使用状态下，产品的吸收和漏尿性能。

配制溶液：

校准：

液体校准：

# 1.在Mannequin下方放置液体收集容器，收集流出的液体。

# 2.天平上放置液体收集容器清零备用。

# 3.点击左上角“Fluid Delivery” （图2）进入参数调整页面（图3）。

# 4.Station Delay设置为10s（可根据熟练情况增加或减少）；Flow Rate设置为15ml/S；Volume设置为产品型号相对应的注液量；点击白色激活窗口按钮勾选工作站1和2；点击按钮开始校准。

# 5.将工作站1流出的液体倒入天平称重记录；工作站2重复以上步骤。

# 6.重复以上步骤校准剩余4个工作站；液体校准波动控制在±3%以内。

# 7.如液体波动范围在±3%以外，调整界面底部的液体传输参数Calibration（图3椭圆处）。

样品的准备：

# 1.产品称重记录在“Dry Wt”中（图19）。

# 2.在每个Mannequin工作站位置的漏尿探测垫位置放置一张吸水纸。

# 3.将4inch×4inch的硅胶垫放置于mannequin注液位置下方的吸水纸下面。确保硅胶垫能覆盖注液位置。

# 4.将产品穿戴在Mannequin上。

# 5.穿戴完成后用一根手指划过腿部皮筋和折页皮筋位置，确保产品服帖Mannequin。

# 6.根据提示摆放Mannequin的姿势。
