REL Width, SAM Width in REL
(V1), LSS Width, PSS Width

最新版本号：第4版

修订日期：2019年6月20日

实验目的：主要用于测量产品 COCOV1 吸收体中 REL 在产品中的宽度以及 SAM 在 REL 中的宽度；COCO V2 吸收芯体中 LSS（Liner Side）和 PSS（Poly size）宽度（Diaper & Pants）。

# 测试前的准备:

1. 吸收体完整无缺陷的产品

2. 标准量尺一把

3. 灯箱

# 样品的准备：

1. 取出已确认的吸收体完整无缺陷的产品，放置于操作平台。

2.按照以下步骤剥离吸收体，剥离过程请轻轻操作，不要破坏吸收体结构

▶打开产品，面层朝上放置。剥离出吸收体(即将腰围材料，折页，底膜，外层等组件尽量剥除)。Pants:将吸收体的Liner材料一侧朝下放置，打开面层和包裹材料的翻折，后翻转产品将吸收体的linear一侧朝上放置，以备测试使用。

# 测试步骤：

## REL Width: (COCO V1)

1. 将吸收体平铺在水平桌面上，找到 REL 和 LSN 的界面，然后一手一端按住 REL 材料一端，另一只手向外撕开 LSN 一侧材料，小心将两者分离。

2.剥离后，找到REL材料所在一侧的吸收体，分辨出REL材料的左右侧边缘，用直尺量取左右侧边缘之间的CD距离，并记录，单位:毫米。

## LSS Width: (COCO V1)

1. 重复样品准备步骤，准备好待测试样品。

2. 观察 REL 一侧吸收体，选取吸收体 CD 一侧边缘，用直尺一端轻轻拨开 REL 材料上面覆盖的绒毛，分辨 SAM 在 REL 中的边缘，重复以上操作，分辨出 SAM 在 REL 中的另一侧边缘。标记 PAD MD 方向 SAM CD 最宽处和最窄处。然后用直尺量取左右侧边缘之间最宽处和最窄处的宽度 CD 距离，并记录，单位：毫米（目前依赖检验员培训进行边缘的确认）。

3. LSS (Liner Side SAM) Width = (最宽处距离+最窄处距离)/2

## SAM in REL Width: (COCO V1)

1. 重复样品准备步骤，准备好待测试样品。

2. 将吸收芯体 Flim 侧朝上，Liner 侧朝下放置。到 REL 和 PSN 的界面，然后一手一端按住 REL 材料一端，另一只手向外撕开 PSN 一侧材料，小心将两者分离。

3. 剥离后，找到REL材料所在一侧的吸收体，分辨出REL材料中SAM的左右侧边缘，记PADMD方向SAM CD最宽处和最窄处。然后用直尺量取左右侧边缘之间最宽处和最窄处的宽度CD距离，并记录，单位：毫米（目前依赖检验员培训进行边缘的确认）。

4. SAM in REL Width = (最宽处距离+最窄处距离)/2
