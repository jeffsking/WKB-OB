# 纸尿裤拉力松紧可视化技术路线评估报告

评估对象：纸尿裤/拉拉裤腰围、侧区弹性体的拉力（松紧）可视化指示方案 编制日期：2026-08-24 适用范围：卫材研发立项评估 / 战略采购选型

# 一、结论速览

四条候选路线中：

# •路线 C（印刷图形变形）：唯一具备专利级量产验证、零新增供应链，建议作为首发方案；

# •路线 B（PDLC 机械变色膜）：配方与工艺最简单、成本最低，建议作为中端差异化试点；

# •路线 A（力致变色结构色）：分辨率与数据表现最强，但依赖小批量特种化学品，建议锁专利卡位、长线布局；

# •路线 D（柔性电子传感）：单件成本与供电/安全/回收问题对一次性卫材基本不可行，仅适用于可复用高端产品验证。

真正的技术门槛不是变色材料本身，而是“颜色↔拉力”关系在蠕变工况下的长期标定有效性——8 小时穿着后颜色必须仍对应真实松紧状态。

# 二、技术路线总览对比

# 三、各路线详析

# 路线 A：力致变色结构色（光子弹性体）

硬数据：

•CLCE（胆甾相液晶弹性体）：拉伸时螺距从 P0 = 438 nm（红态）收缩至 P1 = 285 nm（蓝态），“红→蓝”可逆机械变色；颜色可由手性剂含量精确定制（5.8% / 6.4% / 7% 分别对应红/绿/蓝膜）。同器件以 PDMS–CLCE–PDMS 摩擦电结构输出电压/电流/电荷信号，免电池双模态；CLCEs-S 膜 80 °C 下可自修复，自修复 PDMS 可拉伸。

•MET 织物：纬编涤纶 + 等离子活化 + ALD 沉积 AZO 导电（150 °C），实现“结构色 + 电阻”双信号同步；0%→51.6% 应变内 λmax 单调蓝移，两段线性区（<15.9% 快速变化段可用作定量区间）；韧度 35.6 kJ m⁻³，光/电响应 ≈0.30 s、恢复 <0.22 s，30,000 次拉伸/释放循环后结构色与电响应保持恒定；CPT 半嵌入层合结构抗分层，对腰贴、弹性耳贴反复拉伸部位的功能层附着工艺有直接借鉴价值。

•全息结构色薄膜：0→20% 应变下反射峰从 578.79 nm 蓝移至 520.65 nm（约 −58 nm），反射率从 41.4% 降至 13.25%（降幅约 68%），带宽同步增大；50 次循环（20% 最大应变、2% s⁻¹）后截面 SEM 结构完整；反射谱在 20/50/80 °C 及 RH 11%/43%/100% 下 120 h 仍可测——湿热不退化，这是贴身卫材环境的必要条件。

短板与风险：

# •CLCE 依赖 RM82/手性剂/光引发剂等小批量特种化学品，供应商集中、交期长，立项前必须锁定货源；

# •全息膜体系只验证了“湿热不退化”，未验证“湿敏响应”——尿液环境下颜色—应变对应关系需重新标定；

# •结构色与 SAP 溶胀耦合（“尿量+松紧”双指示一体层）为可行推演方向，但膨胀方向与变色区间的匹配性需实验验证，不宜作为短期项目。

# 路线 B：PDLC 机械变色膜（5CB–PDMS）

硬数据：

•配方工艺极简：Sylgard 184 PDMS 预聚体与固化剂 30:1 重量比混合，加入 5 wt% 5CB 液晶（Kingston Chemicals），搅拌 1 分钟、脱气、玻璃基底浇铸、120 °C 固化 20 分钟即成膜，样品厚度约 1 mm；

# •应变响应显著：压缩态与松弛态透光率差异达 50%；PPT 数据显示应变 0→0.7 区间透光率 20%→75% 连续可调；

# •机制清晰：低应变压缩聚合物空隙，高应变改变液晶指向矢涨落/微滴形貌，微观形貌—透光率关系已有模型化描述，具备精密调控潜力。

短板与风险：

# •水/尿液环境下 5CB–PDMS 体系的稳定性未验证——这是该路线最大的开放风险项，必须在立项前补实验；

# •现有论文以压缩/单轴应变表征为主，腰围穿戴的反复拉伸工况需重新做循环寿命测试；

# •5CB 为环境敏感化学品，需评估贴身产品的合规与迁移风险。

# 路线 C：印刷图形变形（P&G 已验证路线）

硬数据：

•P&G US 10,905,605 及其家族（US 7,887,522 → 8,657,802 → 9,844,478 → 10,905,605）已验证完整工程方案：零应变层合体（无纺布层+弹性元件松弛态贴合后激活）与预拉伸层合体（弹性元件拉伸后贴合无纺布再回缩）两种结构；图案可“松弛态可读”（松弛态印刷原图）或“拉伸态可读”（拉伸态印刷变形图、回缩后复原）两种工艺路线；

•产线级细节齐备：油墨须“充分干燥且耐水（water steadfast）”，耐干摩擦转移且耐水/尿液/饮料接触不洇不脱；跨侧缝图案采用弧形边界容忍对位偏差；侧片穿戴伸长通常不超过 40%，常见 0–20%、常在 0–10%——这直接给出了松紧指示的目标应变窗口；

# •弹性元件可选 elastic film、scrim、foam、strands、printed elastomer patterns 等多种形态。

专利窗口：

•该专利族最早非临时申请 2005-03-18 起算 20 年，加 PTA 延长 382 天，名义届满约 2026 年 4 月；权利要求绑定“双侧区手形认知图形 + 松弛态可读 + 开孔露出弹性体的三层纹理特征”，六要素缺一不可——规避空间大：仅单侧区图案、非手形图形（箭头/脚印/动物）、纯印刷无纹理、压花替代开孔、仅拉伸态可读、图形不落横向区，均可绕开权利边界。需注意同族在审成员及中国/欧洲同族的 FTO 复核。

短板：

# •只有定性/粗分辨（“松/紧”两三档），做不了连续拉力刻度；

# •指示精度受层合体回缩均匀性影响，需与弹性体供应商协同标定。

# 路线 D：柔性电子传感

硬数据：

•IMEC/Ghent 大学两项可产业化技术：UTCP 超薄芯片封装（裸片减薄至 20–30 µm、聚酰亚胺嵌入、扇出金属化、总厚 <100 µm）+ 蛇形金属走线互连 + PDMS/PU 弹性埋置；蛇形几何以结构柔性吸收宏观应变，保护金属互连不超过屈服应变（Cu 约 0.2–0.5%）；15-LED 演示电路在极端形变下正常工作。

短板：

# •芯片+封装+供电+读取的整套成本远超一次性卫材单件成本模型；

# •电池与皮肤接触的安全与回收问题；

# •仅适合拉拉裤高端线或可复用产品做卖点验证，不适合作为一次性产品主路线。

# 四、商业化参照系：热致变色湿感指示

任何松紧可视化方案上产线前，都应对标湿感指示的成熟度：

•工艺：gravure / flexo / inkjet / slot / screen 五种印刷工艺均有落地案例；施加方式涵盖印刷、喷涂、粘贴、染色、熔融（US 2007/0270773 A1），底膜外侧印刷无需改动芯体结构；

•材料：leuco 染料三组分体系（供电子显色化合物 + 受电子化合物 + 脂肪酸决定变色温度），变色温度可在 −30 °C 至 +80 °C 自由设定，灵敏度 1–2 °C，可逆变色可达数万次；微胶囊化采用脲醛树脂原位聚合、约 45% wt 胶囊颗粒水基浆料；

# •供应链：Dynacolor、ThermaSOFT、Liquid Crystal Resources 等现成油墨供应商渠道可查；

# •设计教训：P&G 案例明确提示隔热因子/RH 因子会影响实际激活温度——任何颜色指示方案在卫材环境下的标定都必须实测产品热阻与湿度环境，避免误触发。

# 五、关键风险：蠕变工况下的标定有效性

腰围弹性体在穿戴中承受恒定拉伸应力数小时，属典型蠕变工况：

# •四单元模型中若 η₃ 稳态流动分量过小，卸载后永久拉伸过大，导致腰围松动、漏液——变色层若只标定“瞬时应变—颜色”，8 小时穿着后颜色将不再对应真实松紧；

# •贴合层胶体在体温（32 °C）下处于应力松弛工况，应力随时间指数衰减（σ=σ₀e^(−t/τ₁)），τ₁ 必须大于使用时长；

# •腰围氨纶等弹性体在穿着中经历数千次循环拉伸，工作应力必须低于疲劳极限，否则指示层与弹性体本体都会提前失效。

采购行动项：选型时必须向供应商同时索取 ①拉伸—回复曲线、②永久变形率、③TTS 主曲线（覆盖 1 s–10⁵ s、40–70 °C 温区）。

# 六、验证实验清单（立项前必做）

# 6.1 全路线通用项

实验 1：湿热稳定性 验收要点：RH 100% / 80 °C / ≥120 h 条件下信号不衰减（全息膜论文条件为底线，需加尿液介质）。

实验 2：尿液浸泡/接触 验收要点：指示层与人工尿液接触 8 h，无洇染、无脱落、颜色基准无漂移。

实验 3：循环拉伸标定 验收要点：0–20% 应变（对应侧片穿戴常见区间）、≥1,000 次循环，颜色—应变对应关系漂移量。

实验 4：蠕变工况标定 验收要点：恒定拉伸 8 h 后，“颜色指示的松紧”与“实际残余拉力”的偏差。

实验 5：误触发测试 验收要点：体热（35–40 °C）、环境温度波动、摩擦、折痕下的假阳性率。

# 6.2 分路线专项

路线 A（结构色）专项：

# •CLCE 特种化学品（RM82/手性剂/光引发剂）双源锁定与交期评估；

# •MET 半嵌入工艺在无纺布基材上的附着强度；

# •应变—λmax 定量区间（<15.9% 线性段）的重复性。

路线 B（PDLC 膜）专项：

# •5CB–PDMS 体系在尿液/水环境下的溶胀与迁移（核心风险项）；

# •反复拉伸（非压缩）工况的透光率循环寿命；

# •5CB 贴身合规评估。

路线 C（印刷图形）专项：

# •P&G 专利族 FTO 复核（含中国/欧洲同族与在审成员）；

# •油墨耐水耐转移实测（对标“water steadfast”要求）；

# •跨缝弧形边界印刷套准公差验证。

路线 D（柔性电子）专项：

# •单件 BOM 成本核算 vs 目标售价；

# •免电池方案（摩擦电）功率预算评估。

# 七、落地建议

# 1.首发（0–12 个月）：路线 C 印刷图形——零新供应链、专利即将届满、P&G 已验证工艺窗口，直接进产品发布；

# 2.中端差异化（12–24 个月）：路线 B PDLC 膜——完成尿液环境验证后做中端线试点，主打“透光即松紧”的可视化卖点；

# 3.专利卡位（24 个月+）：路线 A 结构色——边锁供应链边布局“结构色+弹性体层合”专利，同时对“CLCE+SAP 溶胀耦合”的尿量+松紧双指示一体层做预研；

# 4.所有路线：把“颜色—拉力”标定和蠕变有效性验证写进供应商技术协议，与 TTS 主曲线、永久变形率一并作为来料验收指标。
