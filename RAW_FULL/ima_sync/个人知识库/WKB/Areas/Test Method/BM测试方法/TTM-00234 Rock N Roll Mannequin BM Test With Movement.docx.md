# TTM-00234 Rock N Roll Mannequin BM Test With Movement.docx.md

8
TTM-00234

Rock N Roll Mannequin BM Test With Movement

最新版本号：第0版                          修订日期：2021年02月28日

实验目的：

本测试用于测试模拟躺的姿势下，纸尿裤吸便后的真实状态，获取的照片可用于照片分析、消费者测试、感官测试

测试前准备：

# 1.按照配方调配模拟便便（BM simulant A），实验前放置至室温。

[图片]
# 2.确保宝宝BM注液管状态正常，如下图。

[图片]
3. 将宝宝BM注液管与BM gun相连接。

表1 BM gun注液量

||BM量|按键|速度mm/s|加速度rpm/s||
|---|---|---|---|---|---|
|Large|30cc|Blowout|147|9,998|140mL/s|
|Small|1cc|Insult|21|998|20mL/s|

测试步骤：

1. 称量并记录纸尿裤干重(g)。

2. 将两张擦手纸对折，称量并记录擦手纸干重。

3. 将纸尿裤穿着到对应尺寸的mannequin上。纸尿裤穿着位置参照下表。用马克笔在宝宝的正面和背面标记纸尿裤位置，以保证每片产品都穿到相同的高度。

表2 纸尿裤穿着位置

|尺寸|纸尿裤后端边缘距离mannequin后边缘的距离(mm)|
|---|---|
|NB|13.9|
|1|20|
|2|24.3|

4. 将宝宝放倒成躺姿，按下BM gun上的‘insult’或‘blowout’键进行注液。注液后倒计时5分钟。

[图片]
5. 躺姿下，摇动宝宝从左脚贴着工作台，到右脚贴着工作台，来回5次。如下图。

6. 抓住宝宝顶部的环，使其坐起来，双脚伸直。倒计时15秒。

7. 15秒后，让宝宝重新躺下，重复步骤5，后让宝宝保持躺的姿势，直到注液后的5分钟倒计时结束。

8. 小心从宝宝身上取下纸尿裤。用擦手纸擦拭干净所有可见的BM，将宝宝小心放置在工作台上。称量并记录擦手纸和纸尿裤湿重。

[图片: T]
9. 将纸尿裤平铺并贴到平板上，在平板边上放置标度尺作为参考，将纸尿裤和擦手纸拍照。如下图。
