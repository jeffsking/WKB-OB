# TTM-00445 BM Run-off.docx.md

8
TTM-00645

BM Run-off

BM

最新版本号：第0版                          修订日期：2021年02月28日

实验目的：

本测试用于测试BM滑渗。

测试前准备：

# 1.按照配方调配BM（BM simulant A），实验前放置至室温。BM:生理盐水以3:1混合代表稀便，以350转速匀速搅拌30s混合均匀。

表1 推荐BM配方及用量

|类型|描述|比例|Simulant A|生理盐水|
|---|---|---|---|---|
|Runny|代表“稀便”|3:1|300mL|100mL|

2. 建议产品MD长度至少200mm，CD长度至少50mm。

3. 将BM simulant放置至室温，BM注入量如下表。

表2 BM注液量

|用量|描述|
|---|---|
|11 mL-insult|Step 1宝宝平均注液量|
|30 mL-blowout|高注液量|

4. 产品台调至30度角倾斜，下端放置一个圆碗用于承接滑落的BM。如下图。

[图片]
[图片]
5. 固定摄像头，使其对准样品区中心。

实验步骤：

1. 将产品放在产品架子台面上，用磁铁固定，产品下边缘必须与台面下边缘平齐。注液点应在产品上边缘之下。注液点的高度应统一。

2. 将BM gun喷嘴对准纸尿裤上标记的注液点，喷嘴距离纸尿裤约240mm。

3. 开始录像。1-3秒后，按下insult注入BM simulant（11mL）。等待30秒，让产品充分吸收BM。

4. 测量并记录：1）纸尿裤上BM区域最大CD长度，2）纸尿裤上BM区域最大MD长度，3）BM滑渗量。
