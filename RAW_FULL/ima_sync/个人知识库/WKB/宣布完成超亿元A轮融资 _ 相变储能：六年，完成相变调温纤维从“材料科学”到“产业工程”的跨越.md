# 宣布完成超亿元A轮融资 |  相变储能：六年，完成相变调温纤维从“材料科学”到“产业工程”的跨越

![[宣布完成超亿元A轮融资-_-相变储能：六年，完成相变调温纤维从“材料科学”到“产业工程”的跨越-32143c16.png|图片]]

在功能性纺织品的世界里，有一种技术长期卡在实验室与生产线之间：微胶囊相变材料。

原理并不复杂。把相变材料封装成微米级的胶囊，再通过后整理工艺附着在织物表面。温度升高时，胶囊里的材料融化吸热；温度降低时，材料凝固放热。衣服从此不再只是“被动保温”，而是能“主动控温”。

![[宣布完成超亿元A轮融资-_-相变储能：六年，完成相变调温纤维从“材料科学”到“产业工程”的跨越-a74d859f.jpg|图片]]

但这个逻辑有一个致命的工程缺陷：微胶囊太脆弱了。洗涤、摩擦、拉伸，都会让胶囊破裂，相变材料泄漏，功能衰减。更关键的是，微胶囊只能“涂”在织物表面，无法进入纤维内部。这意味着洗涤几十次之后，“空调衣”就变成了普通衣服。

二十年来，全球无数实验室试图解决这个问题。有人尝试更坚固的胶囊壁材，有人尝试更温和的附着工艺，但都没有从根本上改变“材料与纤维分离”的底层逻辑。

直到2020年，一个清华材料博士决定换一条路走。

#  01

# 一个“连续创业者”的选择

宋鹏程的履历，在中国新材料创业者中极为罕见。

清华大学材料专业博士，美国宾州州立大学联合培养，北京大学材料化工专业工程博士。博士毕业后，他进入中国核动力研究设计院，从事科技成果转化工作。

核动力研究设计院是一个与“产业化”距离极远的地方。那里研究的材料，用于核反应堆的极端环境，精度以微米计，验证周期以年计。但正是这段经历，让宋鹏程理解了“工程化”这三个字的重量——一个材料从实验室走向生产线，需要跨越的不仅是技术门槛，还有工艺一致性、成本控制、供应链协同等一系列工程问题。

2020年，宋鹏程决定创业。

他选择的赛道，是相变储能材料。但切入的方式，与所有先行者都不同。当时行业的主流路径是“微胶囊后整理”——先做相变微胶囊，再通过涂层或浸轧工艺附着到织物上。宋鹏程选择的方向是 “直接高温熔纺”——把相变材料直接混入聚合物熔体，在纺丝过程中让相变材料“长”进纤维内部。

这个选择的底层逻辑是：如果相变材料本身就在纤维里，就不存在“附着不牢”的问题。

2020年，相变储能（杭州）新材料有限公司在杭州临平注册成立。创始团队由北大、清华、南开青年博士组成，核心团队汇聚教授级高级工程师1人、博士3人、硕士9人，覆盖高分子物理、化学、材料科学及纺织工程等领域。由北大教授领衔技术研发，中纺院资深专家主导工艺开发。

#  02

# 从“涂上去”到“纺进去”

理解相变储能的技术突破，需要先理解“熔纺”这个工艺的物理约束。

熔纺是化纤生产的主流工艺：把聚合物加热到熔点以上，变成熔体，从喷丝板挤出，冷却固化，卷绕成丝。聚酯的熔纺温度大约在260到280℃，聚酰胺（锦纶）的熔纺温度在230到250℃之间。

相变材料的问题在于，它们的相变温度通常在20到40℃之间。这个温度区间意味着，如果直接把相变材料丢进260℃的纺丝熔体里，它会瞬间气化。

传统解决方案是微胶囊封装。用一层耐高温的聚合物壁材把相变材料包起来，让胶囊在熔纺温度下保持稳定。但微胶囊的壁材在260℃的剪切力下会变形、破裂，而且胶囊的加入会显著恶化纤维的力学性能——纤维变脆、强度下降，根本织不成布。

宋鹏程的团队走了一条完全不同的路： “纳米限域封装”。

这个技术的核心，是在分子尺度上约束相变材料的运动。通过特殊的化学设计，让相变材料在聚合物基体中形成纳米级的分散相，而不是微米级的胶囊。分散相与聚合物基体之间通过化学键或强相互作用连接，使得相变材料在260℃的高温剪切下不会泄漏、不会气化、不会破坏纤维的力学性能。

这项技术的成果，就是AC-TEX®相变调温纤维。

从产品性能上看，AC-TEX®实现了几个关键突破。它的相变材料含量可以达到纤维重量的10%以上，储热密度远高于传统的微胶囊涂层织物。更重要的是，相变材料在纤维内部均匀分布，功能不会因洗涤而衰减，纤维的力学强度保持率超过90%。

这意味着，一件用AC-TEX®纤维做成的衣服，可以像普通衣服一样洗、一样穿、一样耐磨。而它的“空调”功能，不会因为洗了五十次就消失。

#  03

# 迪桑特与“从实验室到货架”的两年

技术突破是一回事，被市场接受是另一回事。

2026年6月，一则合作消息在户外运动圈传开：日本高端运动品牌迪桑特（DESCENTE）宣布与三沐新材料达成深度战略合作，迪桑特成为AC-TEX®相变调温纤维在全球运动户外领域的首个落地首发品牌。

三沐新材料是相变储能的母公司。这次合作的细节值得细看：迪桑特深耕滑雪专业赛道近90年，以严苛的面料测试标准筛选上游材料。双方“历经两年多试样打磨、成衣实测与工艺调校”，才完成AC-TEX®纤维的适配研发。

两年，对于一个品牌面料合作来说，是一个异常漫长的周期。但它也说明了一件事：AC-TEX®不是“实验室样品”，而是经过真实场景验证的工业产品。滑雪场景对温控的要求极为苛刻——山上零下十几度，缆车上被风吹透，滑下来又在高强度运动中出汗。一件滑雪服需要在“保暖”和“透气”之间找到平衡，而AC-TEX®的相变调温功能恰好解决了这个矛盾。

迪桑特的合作，是AC-TEX®从“技术验证”走向“商业验证”的关键一步。一个国际高端品牌愿意花两年时间测试一种新材料，本质上是在为这种材料的可靠性背书。

产品矩阵上，相变储能已形成三大材料体系——相变、辐射制冷、气凝胶，主打PCM锦纶、PCM涤纶、PCM生物基等智能温控纱线产品。应用场景覆盖高端家纺、户外装备、特种防护服、建筑节能等多个领域。

#  04

# 杭州国资的“产业投票”

2026年10月12日，相变储能宣布完成超亿元A轮融资。

投资方名单是清一色的“杭州国资”：杭州城投、临平国投、杭州金投，加上前轮投资人Ventech China的持续追加。

这份名单的信号意义，比融资金额本身更值得关注。

杭州城投是杭州市属最大的城市建设投融资平台，杭州金投是杭州市属国有金融投资平台，临平国投是临平区属国资平台。三级国资同时入局，指向的不是一个“财务回报预期”，而是一个 “产业卡位判断” 。

临平区正在打造“新材料产业高地”。2026年3月，相变储能在临平区重大项目集中签约仪式上完成签约，计划建设先进相变功能切片及高温融纺纺丝生产线。2026年8月，公司正式落地临平，完成工商变更登记。

杭州国资的投资逻辑，可以从两个维度理解。第一个维度是税收和就业——万吨产线落地，意味着数十亿产值和数百个就业岗位。第二个维度是产业链拉动——相变调温纤维的量产，可以带动上游聚合物原料、下游功能性纺织品、户外品牌供应链的协同发展。

本轮融资的资金用途也很明确：重点投向AC-TEX®相变调温纤维万吨产线建设，同步推进品牌建设、授权合作生态构建及相变控温技术迭代开发。

万吨产线意味着什么？以一件户外冲锋衣需要约1公斤面料计算，万吨纤维可以覆盖数百万件服装的用料。这是从“小批量供货”到“规模化量产”的关键一跃。

#  05

# 新材料的“死亡之谷”

相变储能选择的赛道，有清晰的机遇，也有真实的难题。

第一个难题是“成本”。相变材料的加入，会推高纤维的原料成本。当前阶段，AC-TEX®的定价大概率高于普通功能性纤维，目标客户集中在高端户外品牌和特种防护领域。但随着万吨产线的投产和规模效应的释放，成本曲线会持续下行。宋鹏程对此有一个判断：“新材料的商业化，本质上是一场与成本曲线的赛跑。”

第二个难题是“客户教育”。大多数服装品牌对面料的理解停留在“物理指标”——透气率、防水等级、保暖值。相变调温纤维的“主动控温”能力，是一个全新的价值维度。品牌需要理解、验证、信任，然后才能大规模采购。迪桑特用了两年完成验证，下一家品牌可能更快，也可能更慢。

第三个难题是“标准缺失”。相变调温纤维的性能评价，目前没有统一的国家标准或行业标准。储热密度怎么测？调温效果怎么量化？洗涤后的功能保持率怎么评估？标准缺失意味着客户在采购时缺乏判断依据，也意味着产品的“价值叙事”需要企业自己去建立。

#  06

# 一根纤维的“双碳”叙事

相变储能做的事情，在宏大的“双碳”叙事中有一个精确的坐标。

建筑能耗占中国总能耗的三分之一以上，其中采暖和制冷是最大的两块。如果相变调温纤维能够大规模应用于建筑外墙、窗帘、家纺产品，建筑对空调和暖气的依赖就会下降。这不是“锦上添花”的节能，而是“结构性减碳”。

从杭州临平的一间实验室，到迪桑特滑雪服的面料清单，再到万吨产线的建设——相变储能用了六年时间，完成了一次从“材料科学”到“产业工程”的跨越。2026年的超亿元A轮融资，为这场跨越加了一脚油门。

但真正的考验还在后面。万吨产线建成之后，相变储能需要回答一个更朴素的问题：当一件“会调温”的衣服摆在货架上，消费者愿意为它多付多少钱？这个问题的答案，不在实验室里，不在投资人的PPT里，在市场里。

宋鹏程说过一句话：“我们做的不是材料，是温度。”这句话里藏着相变储能的底层逻辑——它不卖纤维，它卖的是“刚刚好的温度”。从消防员的防护服到航天员的舱内服，从婴儿的睡袋到户外爱好者的冲锋衣，这个“刚刚好的温度”，正在从实验室走向货架。
