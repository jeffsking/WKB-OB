# 锦琪昶拜访讨论清单与背景资料_20261029.docx

锦琪昶拜访 · 讨论清单与背景资料
日期：2026年10月29日（周四） 对象：江苏锦琪昶新材料有限公司（KSC，南京） 主题：① 三投料热风布产线现场考察 ② 优势热风布产品对接 ③ CoCo V6 REL 生产能力评估 ④ 与KC在途项目对齐
含内部数据（成本、trial数据、供应安排），仅供内部准备使用。
一、本次拜访要拿到什么（4个成果）
产线事实：4.8米线+三头投料口的真实配置、可用产能、可释放给REL的窗口。
技术判断：五组分REL配方在该线上的可制造性；8项未测资质指标的补测路径。
打样承诺：首批REL样品的线体、批量、周期、规格（对齐11月项目节点）。
商务框架：角色（保底/第二源）、加工费口径、IP与保密安排、合约节点。
二、讨论清单
A. 现场参观：三投料热风布线
A1. 产线配置核对 — 4.8米线的梳理机/投料口配置？“三投料”对应哪三层结构，三层如何做梯度分配（旦数/克重/功能）？ 背景：内部会议已确认“锦旗昌（锦琪昶）梳理机投料口有四米八线、对应三头料口，有保底”，并列为优先推进项。
A2. 产能与预留 — 该线名义产能、当前利用率？若KC项目落地，可释放的月度产能与锁定方式（专线/窗口）？ 背景：整体14条ATB线、3.3万吨/年；2026年新增4条4.6米线、1.5万吨/年；南京8号线（0.4D+4.6M）2026年7月已投产。
A3. 多组分喂料能力 — 三投料口如何支撑五组分混料（ES 2D/3D、中空ES 4D、PVA 6D、PTT/PET S/S 7D）？混棉方案与均匀性控制（KC判据要求定量CV<5%，优秀<3%）？ 背景：KC REL基准为四纤维体系（ES+PTT/PET+中空ES+PVA），我方28gsm方案为五组分。
A4. 热风工艺窗口 — 烤箱温区精度与风速均匀性；能否支持145→155℃温度扫描？对中空纤维lumen（中空腔）保留、PVA（需非水溶、耐温>140℃）的工艺经验？ 背景：现有两套REL样品的穿透均为6组最慢，怀疑与中空纤维lumen坍塌或过度粘合有关，需截面SEM+温度扫描验证。
A5. 后处理准备 — 超声波复合、压花打孔能否为REL或面层提供增值加工（打孔图案、复合结构）？
A6. 小试资源 — 1m幅宽ATB试验线的打样周期、最小批量、交付规格（卷样/片样）？
B. 优势热风布产品（第二/第三合作点）
B1. Velvet超柔系列（0.4–1.2D）与“0.4D+4.6M”新品 — 0.4D新品的量产稳定性、柔软/强度平衡数据；能否为KC面层（Liner）方向打样？ 背景：0.6D纤维直径≈发丝1/10；0.8D超柔口罩已进入日本市场；“0.4D+4.6M”为全球首创、南京8号线专属量产。
B2. 无胶超声波方案 — 去掉阻隔层后的成本结构？与KC减胶/降本方向（含新型热熔胶路线）的适配性？ 背景：无胶超声波具备图案美观、手感柔软、剥离力持久、少气味、图案保持性好等卖点，10年经验。
B3. CD/MD分区设计（Chloe/Dynasty） — 尿便分区、防漏多重屏障区等设计能否按KC规格迭代？ 背景：单层CD Zonal 26–35gsm（面层/外覆），双层超声42gsm；分区是差异化卖点。
B4. 透气防漏布（Baffle/5S-CBC） — 透气较PE膜+300倍、防漏+200%的验证数据；在KC背层/外层方向的应用机会？
B5. 石狮布局 — 福建新基地（高端卫材全产业链）产能规划、供应半径与成本弹性？ 背景：2026年10月石狮签约引入锦琪昶作为高端热风无纺布环节（“零新增用地”、链主引荐）。
C. CoCo V6 REL 能力评估（核心议题）
REL = Reinforcement Enhancement Layer（增强层）：100% SAP芯体中、上下两层SAP之间的无纺布功能层，承担结构分离、液体传递桥、回弹蓬松保持、SAP迁移阻挡四项功能。
C1. 判据交底 — 向KSC交底 NEW REL 4 资质矩阵10项（逐批/每周频次）及内控目标（湿强≥75 N/m、STT≤0.8s、返渗<0.03g），逐项确认“能做/需第三方”。
C2. 五组分方案可制造性 — 以28gsm方案为例（ES CoPET/PET 2D 32% + 3D 8% + 中空ES 4D 30% + PVA 6D 6% + PTT/PET S/S 7D 24%）：原料通道（中空ES/PTT/PET/PVA）、克重控制（设计28gsm→实测回缩至33gsm，需控制）、加工费口径（基准5,000元/t，锦琪昶或高10%）。
C3. 三项决定性缺口 — Void Volume（>80 cm³/g@0.5kPa）、ATB湿态结合强度（>8 N/5cm MD）、压缩回弹（>80%）：现有两套样品全部未测，是资质闭环最大缺口，能否联合补测/DOE？
C4. 穿透慢症结 — 两套样品穿透均为6组最慢（1.02s / 1.232s）：怀疑中空纤维lumen坍塌，能否做截面SEM + 烤箱温度扫描（145→155℃）？
C5. 打样计划 — 从哪条线打（4.8米三投料线 vs 试验线）、最小批量、周期几周、首批规格；对齐11月项目节点。
C6. 测试路径与口径 — 材料级 vs 组装级（KC判据为EDANA WSP 70.3 diaper assembly / 80.10）；谁测（KSC实验室/KC复测/第三方）、每批频次、数据交付格式。
C7. 角色与产能 — 定位（主供/第二源/保底）？预留量与扩产保证（在建4.6米线矩阵）？
D. 与KC在途项目（进展对齐）
D1. 2026年6月3日“KC & KSC Meeting”之后的进展与反馈；KC侧关注点与下一步要求。 D2. 合约与保密：NDA/独家条款/合约节点（内部安排：拜访后推进合约落定）。 D3. 对接人与日程：技术/商务接口人确认；南京参观（可结合实验室行程）。 D4. 联合开发议程：从“供货”扩展到共创（面层/导流/REL/无胶方案组合）。
E. 商务、IP与合规
E1. 价格 — 加工费基准与规模效应、年度降本路径（纤维价每降1,000元/t，全成本降约0.00672元/m²；28gsm方案临界克重34.93gsm）。 E2. IP与保密 — 独家供应、IP安排（KC政策不与供应商共有专利；按“KC持有/供应商持有+独家许可”设计）。 E3. 合规 — Supplier Code of Conduct确认、EDANA QAP（已通过）、质量协议与现场审核安排。

6. REL 现状与缺口（COCO V6 第三轮trial，2026-09）
Code A（28.8gsm，五组分）：穿透1.02s、Wet-back 0.09g、Hold SAM 62%（横向对比占优）；但穿透、Wet-back 相对基线双劣。
Code B（33.48gsm，n=5）：Wet-back 0.0474g为6组最优、CD归一化强度+59.8%；穿透1.232s为6组最慢。
10项资质指标中8项全员未测；三项决定性指标（VV/湿态结合/压缩回弹）全部空白。材料级vs组装级口径不可直判，不得对外宣称“通过KC资质”。
7. REL 成本模型要点（28gsm vs 传统40gsm；内部）
输入：PTT/PET S/S纤维20,500元/t、ES 2D/3D 11,600元/t、中空ES 13,500元/t、PVA 6D 20,000元/t、加工费5,000元/t（热风粘合+分切；常规品类锦琪昶或高10%，未纳入模型）。
结果：设计克重28gsm全成本≈0.5547元/m²；实际回缩33gsm≈0.6537元/m²；传统40gsm基线≈0.692元/m²；临界克重34.93gsm。
注：模型内两页口径存在不一致（0.692 vs 0.5775基准），对外引用前先统一。
