# 低熔点PP粒子开发任务书 · 补充页：方案C技术要点

日期：2026-09-21 主题：全PP皮芯复合纤维（EPC型）皮层用超低熔点PP树脂（熔点≤135°C）

# 1. 方案C定位

方案C的本质：不开发低熔点PP单组分纤维，而是开发皮芯复合纤维皮层用的超低熔点PP树脂，即替代当前ES纤维体系中低熔点组分的国产粒子。

皮芯结构中，低熔点皮层是“胶水”，高熔点芯层是“骨架”：热粘合时仅皮层熔融，在纤维交叉点形成聚合物熔桥，芯层不熔、保持纤维形态与束强度。皮芯之间的熔点温差窗口是结构价值所在（如PE/PP组合：PE皮130°C熔融、PP芯约165°C保持完好）。

方案C瞄准PP/PP全聚丙烯皮芯：皮层熔点约140–155°C、芯层常规PP（约165°C）。相比PE皮方案（110–135°C），PP皮粘合温度更高，但与芯层化学同源、界面相容性更好，且纤维100%聚丙烯，利于全PP无纺布回收路线。

# 2. 树脂端三重降熔点手段（叠加使用）

|手段|参数|说明|
|---|---|---|
|共聚单体打满上限|~10 wt%（乙烯+丁烯，丁烯降熔点效率更高）|共聚单体破坏结晶完善性；0.8–10 wt%区间可从160–165°C降至153–158°C，取上限继续下探|
|掺入低等规组分|5–30 mass%（等规五元组30–60%）|低等规组分结晶能力弱，为第二压熔点杠杆，同时改善低温流动与柔软手感|
|反向配方：零成核剂|不加苯甲酸钠/硬脂酸钙/山梨醇类（10–2000 ppm区间常规用于减收缩）|成核剂加速结晶、细化晶粒、降低收缩，与低熔点目标相反；结晶度压至60%以下（拉伸纤维基准60–75%），片晶越不完善熔点越低|

# 3. 四个工艺雷区

1.二甲苯可溶分失控（最大风险）：可溶分随低结晶度伴生升高，导致发黏、纺丝操作性变差、纤网尺寸稳定性下降；热风线在100–180°C运行，皮层若在纺丝/铺网阶段发黏则无法开车。必须锁死可溶分<6 wt%（共聚物控制线）——低等规组分须靠催化剂嵌段化控制实现，不能无规稀释。

2.淬火不足：低结晶倾向物料结晶慢。商业做法为受控温度/速度空气淬火，终温控制Tg≈-10°C至Tg+15°C以最大化拉伸性；建议冷辊+骤冷风强化，淬不透会在拉伸段断丝。

# 3.热定型窗口极窄：定型温度须高于应力松弛需要、低于纤维熔点，否则结构塌陷；135°C熔点皮层料可用窗口远窄于常规PP，定型温度整体下移，不可照搬常规线参数。

4.拉伸倍率重标定：标准两段拉伸（一段110–160°C，4×–14×；二段80–135°C，1.2×–3×）按均聚设计；低熔点皮层在110°C已接近软化区，一段拉伸下限温度与倍率需重新做DOE。

# 4. 复配结构缓冲设计（给树脂端减负）

•降低皮层比例：商业皮芯配比常见50:50或30:70，极端10:90。皮层占比降至30:70以下，低熔点树脂用量减少，对树脂熔点要求可放宽（皮层不必死磕130°C，145–150°C亦可工作，只要与芯层165°C保持足够窗口）。

•添加剂分区：皮层承载功能添加剂（如0.1–0.6 mass%硫酸钡抗静电）、芯层保持高纯度承载力学；亲水剂加在皮层，避免干扰芯层结晶。树脂开发目标可放宽一档，“结构设计+树脂设计”两条腿走路。

# 5. 验收与对标

|项目|指标|
|---|---|
|粘合验证|热风线：烘箱温度与驻留时间为主变量（典型驻留3–8 s）；不足则低强度、过量则芯层压扁手感发硬|
|纤维强度|4–6 cN/dtex（标准级体系）|
|断裂伸长率|10–30%|
|热收缩|&lt;5%（117°C张应力下，热定型良好纤维标准）|
|应用规格|1.5D–3D细旦、38–51mm切断、亲水整理（卫生材料皮芯短纤通行规格）|

一句话定位：方案C不是“更激进的方案B”，而是换赛道——从“低熔点PP单组分纤维”换成“全PP皮芯复合纤维的皮层树脂”。树脂单看难度最高，但配合皮芯结构与皮层比例设计风险可控，且直接对标国内低熔点纤维厂（仪征化纤、上海德福伦）的原料需求，验证路径清晰。
