### 1.4 派生量的计算方式（透明化声明）

源数据给出 9–10 个数值指标，为形成可比性判断，本报告计算 6 个派生量。**计算方法与假设全部公开如下，供复核与质疑**：

| 派生量 | 公式 | 假设与说明 |
|---|---|---|
| 堆密度 ρ (g/cm³) | ρ = 克重 gsm ÷ (1000 × 厚度 mm) | 直接由两个实测值导出，无额外假设；**但厚度测压口径不一致（见 C3）** |
| 孔隙率 ε (%) | ε = 1 − ρ / ρ_fiber | 需**按组分加权估算纤维密度** ρ_fiber |
| Void Volume 无压估算 (cm³/g) | VV = ε × (1000 × 厚度 mm) ÷ 克重 gsm | **厚度未注明/测压偏低 → 该值为无压缩条件下的上限估值，不可与 KC 的 80–117 cm³/g @0.5 kPa 对标（见 C3）** |
| MD / CD 归一化强度 (gf/gsm) | 强度 ÷ 克重 | 消除克重差对强度绝对值的影响；**Code B 的强度单位未标注，该项有效性待复核（C2）** |
| CD/MD 强度比 | CD 强度 ÷ MD 强度 | 反映纤维取向各向异性；越接近 1 越均衡 |
| MD/CD 延伸率比 | MD 延伸率 ÷ CD 延伸率 | 反映形变的方向差异 |

**纤维密度加权取值**（文献典型值，非实测）：

| 纤维 | 取值 (g/cm³) |
|---|---|
| PET / 中空 PET | 1.38 |
| CoPET / PE-PET 皮芯 | 1.33 |
| PTT/PET（并列双组分，按 50/50 取均值） | 1.365 |
| PE/PP、PE/PET | 0.92 / 0.95 |
| Lyocell | 1.50 |
| PVA | 1.30 |

加权结果：YJ 1.350 · DY 1.355 · ZB 1.134 · 芥东 1.216 · **Code A 1.372 · Code B 1.372**（两 Code 配方同构，故取值相同）g/cm³。
> **敏感性提示**：纤维密度取值 ±10% 会使孔隙率变动约 ±0.4 pt、VV 估算变动约 ±0.3 cm³/g。本报告的**性能排序与结论不因该假设而改变**（排序差异远大于该敏感度）。

### 1.5 判定标尺

与主报告一致：|Δ|<5% 记「≈ 持平」；5–15% 记「轻微」；15–30% 记「明显」；>30% 记「显著」。
指标方向：强度、Hold SAM%、VV、孔隙率、CD/MD 比取「越高越好」；穿透时间、Wet-back 取「越低越好」；克重、厚度、延伸率、堆密度按**中性**处理（不参与优劣判定，仅作结构特征描述）。
另对「越高/越低越好」类指标给出 **6 组内位次排名**（1 = 最好）。

## 四、差异分析与可能原因

### 4.1 Code A 的优势项及可能原因

**① Hold 住 SAM% = 62%（第 2 名 ZB 42%，最差 YJ 4%）**

这是 REL 的第一性功能指标（SAP 迁移阻挡），也是 6 组中唯一有数据且达到 60% 量级的方案。四项可能机理，按贡献度推定排序：

1. **PVA 的 Z 向刚性骨架**（6%）：PVA 拉伸模量约 25 GPa，是 PE（0.2 GPa）的 125 倍、PET（2.8 GPa）的 9 倍 [《NEW REL 4.pptx》"Z-Direction Scaffold Theory"]。受压时 PVA 纤维不塌陷，SAP 无处横向逃逸。NEW REL 4 明确将 PVA 类比为「混凝土中的钢筋」。
2. **中空 PET 4D 占比 30%（基准配方仅 14%）**：中空 lumen 形成「陷阱」结构，SAP 颗粒在 lumen 与纤维交错处被机械俘获；30% 的高占比使中空纤维形成连续网络而非孤立点。
3. **CD 向强度高 + 各向异性最低（CD/MD = 0.283，6 组第一）**：CD 归一化强度 18.65 gf/gsm 为 6 组第一。CD 方向承载更好意味着 REL 边缘不易散边、不易沿 CD 方向被液体冲开，从而把 SAP 约束在平面内。
4. **高 MD 延伸率（72.8%）带来的「以柔裹住」效应**：结构在形变时倾向包裹而非破裂 —— 与 PTT/PET 弹性组分的组合效应。

> **注意 Code B 的印证**：Code B 配方中中空占 30%、PVA 占 6%，与 Code A 同构；但其克重高 16.3%、更致密，实测 Wet-back 反而最低。因此**「中空＋PVA 组合 → 高 Hold SAM」这一机理链在 Code B 上未获验证**（Code B 无该项数据），不能简单外推（见 C12）。

**② 克重 28.8 gsm（基线 38.8–40.0 gsm，低 27.4%）且厚度未同比例下降**

厚度 1.01 mm 高于 YJ（0.71 mm）、接近 DY（1.13 mm），而克重比二者都低 → **单位克重的结构效率更高**。机理上可归因于 PTT/PET 7D 的卷曲弹性撑开结构 + 中空 lumen 的固有体积贡献（不需要靠增加材料量来换取厚度）。直接工程收益：**同面积 REL 的材料用量减少约 28%**。

**③ CD 向力学（归一化 +74.7%，各向异性比 +71.7%）**

5 组分体系使纤维取向更随机、面内更均衡，避免了 2 组分体系（YJ/DY）常见的 MD 高度取向、CD 薄弱的各向异性结构。**Code B 在同一指标上列 6 组第二（+59.8% / +47.6%），属同向印证** —— 说明该优势来自纤维体系设计而非单一试样偶发。

### 4.2 Code A 的劣势项及可能原因

**① 穿透时间 1.02 s（基线均值 0.51 s，慢 100%；相对最快的 ZB 慢 4.4 倍；6 组位次 5/6）**

1. **强毛细保持**：渗透速度 ∝ 毛细压力 ΔP = 2γcosθ/r。Code A 含 40% 细旦（2D/3D）纤维 + 6% 强亲水 PVA（接触角 <20°），形成**小孔径 + 强润湿**的组合，ΔP 高 → 液体被「抓住」而非快速通过。
2. **孔隙率并非最高**：97.92%，低于 ZB（98.01%）与芥东（98.37%），通道曲折度相对更高。
3. **【待验证假设】中空 lumen 可能坍塌**：NEW REL 4 明确提出「Hollow lumen survives ATB if oven temp ≤155°C. Over-bonding collapses lumen」[《NEW REL 4.pptx》"Fiber-Specific ATB Behavior"]。若 30% 中空纤维的 lumen 在粘合过程中坍塌，则大孔快通道失效，只留下致密基体 —— 与「穿透最慢 + Hold SAM 最高」的实测组合自洽。
4. 注意：Code A 穿透慢**并非**因为克重低（克重低通常意味着路径更短、应更快），这个反直觉现象支持第 3 条假设。

**② Wet-back 0.09 g（3 个有效基线均值 0.07 g，高 28.6%；5 组位次 5/5 最差）**

与穿透慢同源：毛细保持力强的结构，液体不易被「夺回」表层，因此回渗（Wet-back）通常也偏高。这与主报告第一组中「亲水胶（胶量 3.5*4）国标回渗 −34.6% 但渗漏 +15.9%」形成对照，说明**同一材料的干爽性与阻漏性常常是此消彼长的**。

**③ MD 强度绝对值 1898 gf（基线均值 2667.5 gf，低 28.9%；位次 5/6）**

但该差异**主要是克重低带来的表观效应**：按克重归一化后为 65.9 gf/gsm，对基线均值 67.36 gf/gsm 仅差 −2.2%（持平）。→ **Code A 不存在本征的 MD 强度缺陷**，若需要提高绝对强度，提高克重是最直接的杠杆（NEW REL 4 亦将「克重 15→18–20 gsm」列为提升湿强的 P1 杠杆）。

### 4.3 Code B 的优势项及可能原因

**① Wet-back 0.0474 g（6 组最优；比基线均值低 32.3%，比 Code A 低 47.3%；5 组位次 1/5）**

这是 **Code B 最反直觉、也最有价值的结果**：作为 6 组中穿透最慢的样品，其回渗反而最低。可能机理：

1. **双层分克重结构的方向性液体管理**：上层 11.2 gsm 细旦致密层（80% 2D + 20% 3D）形成小孔径高毛细压界面，把液体**主动向下压入**储库层；下层 16.8 gsm 蓬松层（中空 + PTT + PVA）提供低毛细阻力的接纳空间。**这种「上密下疏」的梯度结构本身就具备单向导流（one-way valve）效应** —— 与 ADL 的孔径梯度设计原理一致 [《01-纸尿裤基础结构与技术全景》第三节]。
2. **上密层的物理阻挡**：细旦层直接阻断 SAP 凝胶向上迁移的路径，减少表层游离水回渗（压回）量。
3. **更高的堆密度（0.0387 vs Code A 0.0285 g/cm³，+35.7%）**：致密化提高了纤维—液体接触面积，降低结构内残余自由水。

> **替代解释（须排除）**：Code B 与 4 基线**是否同法测试未确认**（C6）。若两者 Wet-back 测试条件（压重、纸垫、时长、液量）不同，则该优势可能被口径放大。**须先核对 CI-06 的 Wet-back 是否与 benchmark 图同协议，再决定该结论的强度。**

**② 绝对力学（MD 强度 2348.36；CD 强度 570.91，6 组位次 2/6）**

Code B 在 MD 强度上相对基线仅 −11.96%（Code A 为 −28.85%），CD 强度 +35.21%，MD 归一化强度 +4.13%（6 组第二，仅次于 YJ 的 95.6）。这是**致密化的直接收益**：更低的孔隙率与更高的堆密度意味着更多的纤维—纤维粘合点。

**③ 致密—强而慢的自洽链路**

Code B 相对 Code A：堆密度 +35.7%、MD 强度 +23.7%、CD 强度 +6.3%、Wet-back −47.3%、穿透 +20.8%、VV 无压估算 −26.9%。**「致密 → 强、回渗低、但空隙少、穿透慢」四个方向完全自洽**，可作为工艺调节的定性杠杆。

### 4.4 Code B 的劣势项及可能原因

**① 穿透时间 1.232 s（6 组最慢；比基线均值慢 141.6%，比 Code A 慢 20.8%）**

在 Code A 的全部致慢机理（强毛细保持、孔曲折、可能的 lumen 坍塌）之上，Code B 还叠加了 **最低孔隙率（97.18%，6 组最低）与最高堆密度**。即：**Code B 是 6 组中最致密的样品，穿透最慢符合其结构特征，是「设计取向的自然结果」而非异常**。

**② VV 无压估算 25.11 cm³/g（6 组倒数第二；比基线均值低 27.5%，比 Code A 低 26.9%）**

致密必然带来单位克重空隙体积下降。**但需特别注意口径**：★ 该项为无压上限估算，而 KC 的真实 Void Volume 判据为 **@0.5 kPa 蓬松态（80–117 cm³/g）**。REL 的核心价值恰恰在于**受压后仍能回弹恢复空隙**，无压值低不等于蓬松态值低。**因此该「劣势」不构成对 Code B 的实际否决**，必须等 0.5 kPa 实测数据出来才能判定。

**③ 设计克重超差（实测 33.48 vs 设计 28 gsm，+19.6%）**

这不是性能缺陷，而是**试制一致性问题**：超设计值 19.6% 会直接恶化 BOM 成本与芯体总厚度的接口设计。若按设计值 28 gsm 计，Code B 的克重与 Code A（28.8）几乎相同，本报告中「Code B 更重」的对比将大幅弱化（C4）。

### 4.6 关键机理发现：基线组内规律与两 Code 的双重偏离

| DY ND055 | 97.47% | 15% | 0.55 | ✓ 中间态 |
| ZB 箱式REL | 98.01% | 42% | 0.23 | ✓ 孔隙率高 → SAM 高、穿透最快 |
| 芥东 箱式REL | 98.37% | 33% | 0.49 | 部分偏离（孔隙率最高但穿透非最快） |

**基线规律**：孔隙率↑ → Hold SAM%↑、穿透时间↓（前三个基线严格单调）。
芥东的偏离，推断与其含 **35% PP（非极性、低表面能 ~30 mN/m，疏水）** 削弱毛细驱动有关。

| **Code B** | **97.18%（6 组最低，低于 YJ）** | NA（未测） | **1.232（慢 5.4 倍）** | **0.0474（最优）** | **同时大幅偏离** |

> **核心推论（较 5 组版本增强）**：两 Code 的性能**均不由孔隙率/蓬松度单独决定**。
> **关键增强证据**：Code B 是全组孔隙率最低的样品，若按基线规律应预期「Hold SAM 最低、穿透较慢」，但实测 Wet-back 最优、强度最高；而 Code A 孔隙率与 ZB 几乎相同却把 Hold SAM% 做到 1.48 倍。**两个独立 Code 从相反方向偏离同一条规律，构成对「功能化组合才是增益来源」这一推论的交叉验证。**
> **YJ 的对照意义**：YJ 与两 Code 同为「致密 + 穿透慢」，但 Hold SAM% 仅 4% —— 证明**致密本身不带来 SAP 保持能力**。

### 4.7 三条技术路线的分野

| 路线 | 代表样品 | 结构特征 | Hold SAM% | 穿透 | Wet-back | 克重 |
|---|---|---|---|---|---|---|
| **开放化路线** | ZB 箱式、芥东 箱式 | 大孔隙（ε 98.0–98.4%）、厚（1.77–2.02 mm）、3D 成像信号弱/无法成像 | 33–42% | 快（0.23–0.49 s） | 0.07–0.08 g | 40 gsm |
| **轻量功能化路线** | **Code A** | 中等孔隙率（97.92%）、薄（1.01 mm）、克重最低（28.8 gsm） | **62%** | 慢（1.02 s） | 0.09 g | 28.8 gsm |
| **致密强化路线** | **Code B** | 最低孔隙率（97.18%）、最薄（0.865 mm）、堆密度最高 | NA | **最慢（1.232 s）** | **最优（0.0474 g）** | 33.48 gsm |
| **致密未功能化** | YJ DL24C | 最低厚度（0.71 mm）、最低延伸率 | 4% | 0.77 s | 0.06 g | 39.8 gsm |
| 中间态 | DY ND055 | 粗旦双组分 | 15% | 0.55 s | 0.07 g | 38.8 gsm |

**三条路线的关键分野**：按「基线组均值 → Code A → Code B」穿透时间单调变慢（0.51 → 1.02 → 1.232 s），**但回渗并不跟随该趋势**（0.07 → 0.09 → 0.0474 g）。
→ **说明本组的穿透速度与回渗之间不存在简单因果**，中间存在其他控制变量（推断：孔隙结构形态、层间梯度、纤维表面润湿性）。Code B 的「上密下疏」双层结构是这一推断最可能的物理解释，但需与「测试协议不同」这一竞争性解释一并验证（C6）。

## 五、结论

### 5.1 总体结论

> **结论 1（两 Code 的共识优势）**：**CD 向力学与面内均衡**。CD 归一化强度 Code A 18.65 / Code B 17.05 gf/gsm，分列 **6 组第一、第二**（基线均值 10.67，分别 +74.7% / +59.8%）；CD/MD 强度比 0.283 / 0.243 同样分列 **6 组第一、第二**（基线均值 0.165，+71.7% / +47.6%）；绝对 CD 强度 Code B 570.91 为 6 组第二（仅次 YJ 586，而克重仅为其 84%）。**两 Code 均以更低的克重获得了优于常规方案的面内承载与均衡性。**
>
> **结论 2（两 Code 的共识代价）**：**液体穿透**。Code B 1.232 s（6 组最慢）、Code A 1.02 s（6 组次慢），相对基线均值（0.51 s）分别 +141.6% / +100.0%，两 Code 是 6 组中**唯二超过 1 s** 的样品。
> **但必须同时声明**：这是**相对劣势，不是绝对不达标** —— 1.02 s 与 1.232 s 在 KC 判据的量级上均远低于门槛（合格 3.5 s）。**不得据此判定两 Code「性能差」。**
>
> **结论 3（Code A 的独占优势）**：**Hold 住 SAM% = 62%**，是 6 组中唯一有该项数据且达到 60% 量级的方案，对 4 个基线全部显著占优（相对最优基线 ZB 42% 高 47.6%，相对均值 23.5% 高 163.8%，相对最差 YJ 4% 高 1450%）。**Code B 该项未测 → 两 Code 无法在这一 REL 第一性功能指标上择一，是本组最大的证据缺口。**
>
> **结论 4（Code B 的独占优势）**：**Wet-back = 0.0474 g（6 组最优）**，比基线均值低 32.3%、比 Code A 低 47.3%，对 4 个有效基线配对全部占优（−21.0% ~ −40.8%）。**这与「Code B 穿透最慢」形成鲜明反差，是本组最反直觉、也最有价值的结果。**
> **但必须声明**：该结论**受「是否与基线同法测试」这一未决口径条件约束**（C6）—— 若测试协议不同，优势幅度可能被放大，须先核对协议再定结论强度。
>
> **结论 5（A↔B 无单一胜者）**：15 项指标中 **Code B 占优 4 项、Code A 占优 4 项、中性 6 项、无数据 1 项**。
> - **Code B 赢**：绝对力学（MD +23.7%、CD +6.3%）、回渗（−47.3%）、MD 归一化强度（+6.4%）
> - **Code A 赢**：穿透（快 17.2%）、结构开度（VV 高 36.8%）、CD 归一化强度（+9.4%）、CD/MD 比（+16.4%）
> - **中性**：克重、厚度、堆密度、孔隙率、MD 延伸率、CD 延伸率
> → **选择取决于整裤层面的优先级**：若「回渗/干爽」优先则 Code B；若「液体传递速度/结构开度」优先则 Code A；若「SAP 保持」优先则**当前无法判断，必须补测 Code B 的 Hold 住 SAM%。**
>
> **结论 6（机理）**：基线组内存在「孔隙率↑ → Hold SAM%↑、穿透↓」的单调规律，而**两 Code 从相反方向同时偏离该规律**：Code A 孔隙率与 ZB 几乎相同却把 Hold SAM% 做到其 1.48 倍、穿透慢 4.4 倍；Code B 是全组孔隙率最低却拿到最优 Wet-back、最强力学。**两个独立 Code 的交叉偏离，共同支持「性能由纤维功能化组合与层间结构决定，而非蓬松度」这一推论。** YJ 的对照（同样致密、Hold SAM 仅 4%）进一步证明：致密本身无收益。
>
> **结论 7（可能的失效风险，待验证）**：两 Code 的中空纤维占比均为 30%（基准配方 14% 的 2.1 倍），而 NEW REL 4 明确警告「烤箱温度 >155°C 会使 hollow lumen 坍塌」。**实测正好呈同向异常：中空占比同为 30% 的两 Code，穿透时间恰好占据 6 组最慢两位，远慢于不含中空组分的 4 组基线（0.23–0.77 s）。** 该证据链因两 Code 独立复现而比 5 组版本更具说服力 —— **建议优先验证**（截面 SEM / lumen 保留率 + 烤箱温度扫描）。
>
> **结论 8（证据边界）**：① 4 基线 + Code A 未标注样本量与测试日期，属**单批次单点观察**；Code B 为 n=5，两侧统计强度不对等。② Code B 的 MD/CD 强度单位未标注（C2），若实为 N/2inch 则全部强度类与归一化强度判定作废。③ 厚度测压口径不统一（C3），堆密度/孔隙率/VV 为口径受限的估算值。④ 两 Code 设计配方逐组分同构（C4），克重差异来源待复核。⑤ **10 项 KC 资质指标中有 8 项 6 组全员未测**，Void Volume、压缩回弹、湿态结合强度三项决定性指标全空白，**两 Code 均不能宣布资质通过**。⑥ Code B 与基线是否同法测试未确认（C6）。
