# 低温PP相关的纺粘布讨论主要集中在TBCW低成本方案

## 2. 团队倾向单组份的原因：Bico工艺麻烦


同段讨论明确提到"是Bico的公屏，不是单口的"，并指出Bico后续处理麻烦：超声波焊接虽然可行，但PE皮太嫩、表面很难处理，做上色、Kirigami类工艺不如纯PP好做——这是把低温PP做成单组份的工艺动机 。


6月3日内部会上也对比过：现有TBCW用皮芯（PE+PP）是因为"皮芯的便宜"，而降本第二步就是把底层纺粘从皮芯PE/PP换成熔点约140℃的低温PP 。


## 3. 验证安排


打样Code List里"低温PP下层方案"已列入Part B创新验证（9月21日打样）；9月19日巴西实验计划中下层会同时试普通PP和低温PP（约140℃），共约10种搭配，普通PP若粘不上再看超声波能量上限 。


一句话总结：现有纺粘底层是Bico（PE/PP皮芯）结构，低温PP的需求正是为了把底层做成单组份普通PP纺粘、直接与TBCW低熔点层热粘合，从而省掉Bico成本和PE表皮的工艺麻烦；目前还处于供应商摸排+打样验证阶段，尚无定论。

王总，低温PP相关的纺粘布讨论主要集中在TBCW低成本方案，几条线我给你归拢一下：


## 1. 核心背景：TBCW在线超声波复合工艺的底层替代


KC团队内部技术讨论会（6月3日）：TBCW结构底层（Span Bond）原为20gsm，讨论降为12gsm降本，核心是改用低温PP（熔点约140℃）替代昂贵的皮芯PE/PP（Bico）材料 。


下一步行动：材料开发组推动低温PP（熔点~140℃）的供应评估与小型试制，作为第二步成本优化方案 。


## 2. 供应与供应商线索


9月3日录音：纺粘布如用普通PP必须Bico（PE/PP外皮）；低温PP的优势是纺粘可直接与TBCW低熔点层/Bico热粘合。讨论了Sabic作为潜在供应商，其PP粒子可改性到比现有PP低约30℃的温度，计划安排会议对接 。


福建兴泰（6月2日SMS交流）：KC提出低熔点PP需求，但兴泰不推荐——认为低温PP纤维偏硬、影响柔软度，建议用超声波焊接解决PP粘合问题而非用Bico/低熔点PP 。


9月18日项目梳理录音：bio-based PPT项目中，低温改性PP作为重点——如果底层用Bico，现small层只能用Bico，希望改用低温PP直接一步成型；提到某家供应商（Copp PP / 低温PP方向），尚未系统扫过一轮供应商 。


## 3. 打样与验证落地


OI&FEI Catch-up（8月7日）：9月21日打样分Part A（商业化，冠宏/俊富）+ Part B（创新验证），Part B Code List 中明确含“低温PP下层方案”，与商业化同类目合并、创新部分独立验证 。8月6日录音也确认“低温PP做下层”列入打样Code List 。


9月19日产品研发录音：巴西实验中会有低温点PP（熔点约140度），下一轮测试约10种搭配，底层普通PP/低温PP都会试，普通PP若连不上再看能量上限 。


## 4. 工艺逻辑上的一个关键点


9月19日另一段录音提到：越来越多三层纤维结构中，中间层粘合强度是未知数；如果能改性PP到约130℃（接近现Bico中PE的熔点），理论上可行 。

## 1. 现状：纺粘底层目前只能用Bico


9月3日录音里说得直白：现在用的纺粘布（spunbond）"must be bico, so PE outside"，即外皮PE的皮芯结构；低温PP的意义就是让纺粘布可以直接与TBCW低熔点层/Bico热粘合，不再依赖Bico 。


9月18日项目梳理录音也印证：如果底层保持Bico方案，下面的small层只能用Bico；所以才希望用低温PP"直接一步成型"（单组份直接粘合），目前还没系统扫过供应商，只联系过一家做低温改性PP（约低30℃）的 。
