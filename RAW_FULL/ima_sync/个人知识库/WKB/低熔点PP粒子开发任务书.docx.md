# 低熔点PP（低温PP）粒子开发任务书

日期：2026-09-21 需求方：卫材创新研发 依据：聚丙烯纤维级结构—性能关系资料（Polypropylene Fiber Grade）

# 1. 开发背景与目标

卫材无纺布（热风/热轧/纺粘）用粘合组分长期依赖进口低熔点PP或低熔点PE皮芯复合方案。本项目目标为开发国产纤维级低熔点PP粒子，填补国内树脂端空白（国内现有纤维级PP均为均聚料，熔点164–165°C）。

技术原理：共聚单体（乙烯或C4–C10 α-烯烃，0.8–10 wt%）切断等规序列、压制片晶完善度，使熔点从均聚160–165°C降至目标区间。

# 2. 三档开发方案

# 方案A：常规低温级（熔点150–158°C）——风险最低，先行验证

|参数|目标值|
|---|---|
|共聚单体|乙烯 0.8–5 wt%（无规共聚）|
|MFR|20–40 g/10min（纺粘区间6–150内取值，可由基础树脂经过氧化物化学降解获得）|
|等规度|≥95%|
|二甲苯可溶分|<6 wt%（共聚物控制线）|
|适用工艺|现有纺粘/热轧线直接切换|

# 方案B：中温粘合级（熔点135–150°C）——核心开发目标

|参数|目标值|
|---|---|
|共聚单体|乙烯+丁烯合计 5–10 wt%（丁烯降熔点效率更高）|
|低等规组分|5–30%（催化剂体系主动引入，进一步压熔点并改善低温流动性与柔软度）|
|MFR|30–50 g/10min（热轧/热风粘合用）|
|PDI|2.8–4.5（氢调+茂金属双控）|
|二甲苯可溶分|<6 wt%|

# 方案C：超低温实验级（熔点≤135°C）——PP/PP皮芯皮层料替代

|参数|目标值|
|---|---|
|共聚单体|~10 wt%|
|结晶度|<60%（基准60–75%）|
|成核剂|不添加（与热定型减收缩配方反向操作）|
|用途|替代PP/PP皮芯ES纤维（EPC）皮层料|

# 3. 工艺与配方要点

# 1.抗氧化体系：200–320°C挤出窗口下添加0.1–0.5 wt%抗氧化剂；共聚单体含量越高取值越接近上限（0.5%）。

2.拉伸/热定型重调：低结晶度物料两段拉伸（一段110–160°C，4×–14×；二段80–135°C，1.2×–3×）下限温度整体下探；热定型温度随熔点同步下移，避免低熔点组分在定型段软化。

# 3.可溶分控制：可溶分随熔点降低而升高，与纤维强度直接相关，方案B/C必须锁定<6 wt%，保证强度不低于标准级下限。

# 4.淬火强化：低结晶倾向物料结晶更慢，需提高淬火速率（冷辊/骤冷风），防止表面发黏粘辊。

# 4. 验收标准

|项目|指标|
|---|---|
|纤维强度|4–6 cN/dtex（标准级，350–525 MPa）|
|断裂伸长率|10–30%|
|热收缩|<5%（117°C张应力下）|
|熔点|按方案A/B/C目标区间|

# 5. 对标与验证路径

# •对标牌号：TotalEnergies Lumicene MR 2002（mPP，MFR 15，熔点151°C，纺粘卫材专用）为现成标尺。

# •实施路径：

# 1.方案A：现有装置小改，1–2个月出样；

# 2.方案B：调整催化剂/氢调方案，作为主开发目标；

# 3.方案C：与皮芯复合纤维厂联合验证。

# •应用验证伙伴（纤维端）：仪征化纤（低熔点纤维系列110–230°C，中石化内部直供原料）、上海德福伦（低熔点差别化纤维，可小批量打样）。

# •中试资源：中石化系统（镇海炼化、茂名、长岭炼化）或民营装置（福建中景石化等）。

# 6. 风险提示

•热封膜级低熔点PP（JPP三元共聚125.5–137°C、TotalEnergies 8573/Z9450等）MFR普遍<10，不可直接移用参数，须按纤维级MFR 20–50重新设计。

# •网络牌号名中“低熔共聚”（如K8303）指抗冲共聚俗称，熔点仍160°C+，选型时勿混淆。
