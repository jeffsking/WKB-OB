# Informational Image on Pull-On Article（可穿脱制品信息图形）

> One-line definition 一句话定义：印在可穿脱（pull-on）吸收制品侧壁ゾーン（side laminate）上的**认知功能性图形（cognitively functional graphic）**，用于向**识字前儿童**传达"怎么用这件产品"——抓哪里拉、怎么开合、怎么丢弃——而非用于指示尿湿。

## Definition / Mechanism 定义与机理拆解

1. **传达对象是识字前的儿童**：沟通载体必须是**符号 / 图形 / 标记**，不能依赖文字（pre-literate child）。这是本概念与常规"包装说明"的根本差别。
2. **松弛态可读性（relaxed-state legibility）是硬约束**：图形必须在侧翼层合件处于**松弛态（relaxed state）**时仍然清晰可辨，而非拉伸后可读。这决定了图形如何被施加到弹性层合件上（zero-strain laminate / elastomeric film / pre-stretch laminate 三条路径），是 Brendeling 的实现难点。
3. **图形 + 纹理 = 复合图像（composite image）**：在图形近旁设**纹理特征（texture feature）**——外无纺布层上的**开孔（apertures）**露出内部的弹性件——使传达方式从纯视觉扩展为**视觉 + 触觉**。
4. **典型纹理工序**：压花（热/冷、光辊或花辊）、环辊（ringrolling）、SELF（structural elastic-like film）结构弹性膜、刻痕（scoring）、穿孔（puncturing）、局部热收缩。
5. **可传达的信息清单**（说明书列举）：抓持/拉拽位置、可重复开合的侧翼怎么办、用后制品丢弃时的折叠处理、性别适配、是否适合如厕训练、是否有干爽面层、尺码与成长变化。
