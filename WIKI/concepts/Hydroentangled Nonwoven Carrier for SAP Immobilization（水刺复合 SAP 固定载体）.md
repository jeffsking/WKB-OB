# Hydroentangled Nonwoven Carrier for SAP Immobilization（水刺复合 SAP 固定载体）

> One-line definition 一句话定义：一种**双层非对称无纺布载体**——上层为可被 SAP 颗粒穿透的**梳理短纤（carded staple fibre）层**，下层为孔径小于 SAP 颗粒的**纺熔（spunmelt，优选 SMS/SMMS）层**，两层以**水刺（hydroentanglement）**机械缠结复合；依靠「孔径差 + 机械锚固」两件事把 SAP 固定在 xy 面内且不从 z 向掉落，从而**替代绒毛浆的固定作用**。

## Definition / Mechanism 定义与机理拆解

1. **分工是刻意不对称的**：顶层多孔、柔软、蓬松（porous, soft and bulky），让颗粒**钻进**纤维之间而不是只躺在表面上；底层孔径小得多、机械强度高得多，负责拦住颗粒不掉落。
2. **两个约束方向**：
   - **x–y 平面（纵向/横向）移动**靠顶层纤维的缠结捕捉来阻止；
   - **z 向（截面方向）掉落**靠底层孔径 < 颗粒粒径来阻止。
3. **为什么必须是水刺**：这里是**机械缠结（hydroentanglement）**，来源把它与热粘合、热熔/超声、针刺、化学粘合、胶粘合并列后定为优选；水刺使短纤对底层形成**基本永久的固定（essentially permanent fixation）**，从而得到足以兜住颗粒的稳固结构。
4. **底层选 spunmelt / SMS 的原因**：纺熔布在**很低的克重**（来源最优选仅 4–12 gsm）下仍能提供足够的强度与足够小的孔径，这是把载体做薄的前提。
5. **双峰纤维设计**：顶层短纤按权利要求做「≤50% 短而轻 + ≥50% 长而重」的至少两类（PET / PE / PP）共混——长而重的纤维负责穿透缠结、短而轻的负责填充与手感。
6. **形态与后续处理**：成品可**卷取（rolled up）**为卷材（权利要求 13），并可对载体/顶层/底层做**表面活性剂亲水处理**（权利要求 8、11）。
