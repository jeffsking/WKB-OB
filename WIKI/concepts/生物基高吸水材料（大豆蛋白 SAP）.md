# 生物基高吸水材料（大豆蛋白 SAP / Bio-based SAP from Soy Protein）

> 一句话定义：以**大豆分离蛋白（SPI）**经**琥珀酸酐（SA）酰化**提升亲水性，再与**甘油**增塑，通过热机械工艺制成的**天然基高吸水塑料/树脂**，作为石油基丙烯酸 SAP 的**可降解替代路线**。

## 机理 / 结构拆解

1. **动机**：传统 SAP 多由丙烯酸及其衍生物聚合，存在**生物降解性差、成本高**的问题。
2. **原料**：大豆蛋白是豆油工业副产物，价格低、含天冬/谷氨酸故亲水性强，与甘油增塑后加工性好。
3. **改性**：用 SA 对 SPI 酰化（acylation）引入更多亲水/羧基位点，提高吸水能力。
4. **成型**：50 wt% 蛋白（酰化或未酰化 SPI）+ 50 wt% 甘油，两段式热机械共混。
5. **表征**：吸水率（24h）按 UNE-EN ISO 62:2008；WIC（water imbibing capacity）用 Baumann 装置。

## 追加：蛋白基在生物基五路线中的定位（2026-09-29 追加 · 来源：生物基SAP-SAF技术研究报告 2026-04）

- **路线位置**：蛋白基（大豆蛋白、胶原蛋白改性）被列为生物基 SAP 的**第 ③ 条路线**，与①淀粉接枝、②纤维素接枝、④PASP、⑤生物基丙烯酸并列。
- **成熟度判断**：在该报告的产业化现状表中，**蛋白基未被列入商业化产品**（列入的只有淀粉接枝「工业化」、PASP「小规模」、纤维素基「研发」、生物基丙烯酸「开发中」）→ 蛋白基在五条路线中**成熟度最低**。
- **共性约束（source-stated）**：生物基路线整体面临 **成本高 20–50%、吸水性能略低于合成 SAP、认证与标准待完善、规模效应尚未形成**四条代价——蛋白基同样适用，且因其成熟度更低而放大。
- **优势侧**：原料可再生、**对盐溶液敏感性低**、减少微塑料污染。
- 与 [[Biodegradable SAP（可降解高吸水树脂）]] 的关系：蛋白基属**生物基**轴，其**可降解性需单独验证**，不可默认。
