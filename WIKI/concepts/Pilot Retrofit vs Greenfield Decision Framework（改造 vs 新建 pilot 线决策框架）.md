# Pilot Retrofit vs Greenfield Decision Framework（改造 vs 新建 pilot 线决策框架）

> One-line definition 一句话定义：在「改造现有机台 vs 新建专用 pilot 线」之间做**可审计**决策的一套制度装置——核心不是算 capex，而是**把「资格」与「覆盖度」分开、把「评估基线」与「实施授权」分开、并预先规定数据缺失时如何降级**。（中文：它防的不是算错，而是**把供应商口述当成本厂事实**。）

## Definition 定义

A retrofit-vs-greenfield decision is structurally different from a normal equipment purchase: the incumbent machine is usually **still producing**, the technology being installed is often **not yet mature**, and the party supplying the equipment is also the party whose claims must be verified. Three failure modes follow, and the framework exists to block exactly those three:

改造 vs 新建在结构上不同于常规设备采购：现役机台**仍在产出**、要装的工艺**往往尚未成熟**、而设备方同时是「待验证主张」的提供方。由此产生三种典型失败模式，本框架就是针对这三条设的：

| # | 失败模式 | 后果 | 框架对策 |
|---|---|---|---|
| 1 | 把「供应商说能做到」当成「本厂装得下」 | 两个独立风险叠成一个决策，**错因无法归因** | Gate 1（本厂实测）与 Gate 2（对方能力）**两表分离、分别签字** |
| 2 | 把「评估基线」读成「实施授权」 | 提前触发不可逆动作（拆机），成本不可回收 | 基线确认书限定适用范围 + 三方签署 |
| 3 | 数据不到位仍硬凑结论 | 决策层依据推断拍板，后面全部重做 | 预设 **Go / Degrade / Stop** 三档降级 |

## Mechanism 机理

### 1. 资格 vs 覆盖度必须分离

最容易被搞反的一步：**用后期目标去否掉入场资格**。正确切法是三层——

| 层级 | 回答什么 | 判据性质 |
|---|---|---|
| **Gate 0 入场券** | 基线能力（速度/结构/尺寸覆盖/下游可制造性）能否满足 | 全满足才进下一闸；任一不满足 → 转新建 |
| **Gate 1 物理验证** | 空间、层高、承重、公辅、主机速度、振动 runout 是否装得下跑得动 | 纯实测，最快出结论、也最快否决 |
| **Gate 2 分期能力** | 后续各阶段各自能做到什么程度 | **只决定分几期、投多少、哪些必须外置**，不决定立项与否 |

> 反例（真实踩过）：把「Phase 2 的三项差异化」当成改造成立的条件，等于用 Phase 2 的目标否掉 Phase 1 的资格，识别上直接误导。

### 2. 闸门顺序按「可测量性」而非「重要性」排

**先测最便宜的否决项**。主机机械最高速是纯测量（规格书 + 一次实测），第一周即可出结论，却往往是最硬的否决点；而工艺能力（如 add-on 上限、配准精度、速度-密度曲线）要等供应商数据，可能拖到半年后。把 Gate 1 放在 Gate 2 之前，等于**用一周换掉数月的无效等待**。

### 3. capex 必须九项全列——设备本体只占约一半

| # | 成本项 | 常见遗漏 |
|---|---|---|
| 1 | 装备本体 | 唯一被记住的一项 |
| 2 | 拆旧与处置 | 老设备处置本身有成本 |
| 3 | 场地与结构（地坪/层高/钢结构） | 层高不足要改钢结构 |
| 4 | 公用工程增量（真空/除尘/冷却/电气容量） | 最常被低估 |
| 5 | 控制与信息系统 | |
| 6 | 安装调试与试产废料 | 试产废料是真实成本 |
| 7 | **停产损失与产能替代** | 现役机台仍产 → 真实商业损失，非理论风险 |
| 8 | 备件与培训 | |
| 9 | **可逆化预留** | 与第 2 项互为镜像，缺它就无法比较「保留退路」的代价 |

> 只报设备价，决策层看到的数就是偏低的；而偏低的方向永远偏向「改造更便宜」。

### 4. 可逆化：把「不可逆」从风险改写成价格

五条硬性要求：**① 旧设备不处置**（封存/标识/登记，评估恢复到可用的工时与备件）；**② 保留原机接口**（基座、真空与管路、电气柜预留位不动）；**③ 设可断开点**（机械/真空/控制三路可快速断开）；**④ 恢复路径入图**（恢复工时、外委项、验证项写进方案正文而非附录）；**⑤ 可逆化成本单列**，不摊进总价。

配套制度是 **RFQ 双栏报价**（可逆化主栏 / 不可逆对照栏，含「恢复为原状态」的工时与费用）。若只按不可逆口径询价，决策层看不到保留退路的真实代价；后续改为可逆化，报价与工期全部返工。

### 5. 对比维度里「产能损失」必须排第一

| 维度 | 为什么排这个位 |
|---|---|
| **产能损失（首要）** | 现役机台仍产 → 停产即真实商业损失，其余维度都在此之下 |
| 单轮试验周期（天） | 决定工艺迭代速度，比 capex 更影响商业化基线 |
| 单轮试验成本 | pilot 的核心 KPI 是「试一次多贵」 |
| 可试验配置数 | 多规格产品能否被覆盖 |
| 与量产机相关性 | 量产机相关度高 / 专用 pilot 可控性高，二者是取舍不是优劣 |
| 不可逆性 | 拆了回不去，这是**风险**不是成本 |

> 已剔除的伪维度示例：「与设备商的解耦度」—— 在设备已定型的比较中无评估意义，留在表里只会稀释权重。

### 6. 能力矩阵：四档 × 三态

**档位**：① 现在就能测 ｜ ② 有条件（需追加条件，代价可控）｜ ③ 以后能（工艺未定或需换方案）｜ ④ 不可能（结构上做不到）。
**现状**：实测 ｜ 推断 ｜ **未取得**。

硬规则：**现状列允许写「未取得」，不允许写「预计可行」**。四档里 ④ 的价值是「省掉两周无效讨论」，① 的价值是「让评估在等供应商的同时也出结论」。

### 7. 合法留空制度

对 2027 年才能拿到数据的指标，**留空是合规的，填一个猜测是不合规的**。制度要求：留空处必须写清「谁补、何时补、需多少资源、影响哪个结论」。这条决定了决策包敢不敢被批准——**敢写「还没验证」的评估，比样样答满的可信**。

### 8. 降级三档（会前约定，会上不辩论）

| 触发 | 动作 |
|---|---|
| 输入 ≥ 目标项 + 关键实测数齐 | **Go**：按三案对比走 |
| 输入不足或关键数缺 2 个以上 | **Degrade**：只交物理可行性结论 + 补证计划，砍掉 capex 三案对比 |
| 关键否决项（空间/速度）拿不到 | **Stop**：明确告知需延期及原因，不硬凑 |

### 9. 决策规则预认可

判据表在评审会**之前**由管理层认可，会上**只填数、只判过/不过**，不重新辩论判据本身。否则评审会会退化成新一轮方案论证，13 天工期在会议室里烧完。

典型规则形态：*Gate 1 不过 → 选新建；Gate 1 过 + Gate 2 过 + capex ≤ 新建 60% + 交期早 ≥6 个月 → 选改造（必须可逆化）；Gate 1 过 + Gate 2 不过 → 优先新建；产能无替代 → 改造降级为受限改造或否决。*

## 交付定性：三档而不是一档

| 交付 | 何时用 | 内容 |
|---|---|---|
| **完整评估** | 三闸数据齐 | 三案对比 + capex ±30% + 时间计划 + 风险册 |
| **条件决策**（最常用） | 物理可判、工艺待证 | 物理可行性结论 + 经济区间 + **补证计划**；明写「本次定不了什么」 |
| **数据缺口报告** | 触发 Stop | 能力矩阵（部分）+ 布局 + 补证计划 |

## Key Parameters 关键参数表

| 参数 | 取值 / 写法 | 备注 |
|---|---|---|
| 速度门槛 | 目标速度 × **1.2** | 20% 余量内化进设计值，不二次加余量 |
| 空间/公辅门槛 | 净需求 + **20%** 维护通道余量 | 门槛须供需双方**共同写入**，不得单方设定 |
| capex 精度声明 | **±30%** + 依据类型（询价/类比/口述） | 不构成报价承诺 |
| 可逆化预留 | 单列，不摊入总价 | 摊进去决策层就看不到「拆掉」的代价 |
| 决策包事件时长 | 评审会 **90 min** | 10 基线 / 25 Gate 1 逐项 / 20 三案 / 15 留空与补证 / 15 出倾向 / 5 定口径 |

## Boundaries 适用边界与反模式

- **适用**：现役机台仍在产出、待装工艺未成熟、设备方即主张方、决策窗口被压缩到 2–3 周。
- **不适用**：纯新增产能（无停产损失）、工艺已商业化（Gate 2 不存在）、决策周期以年计（无需降级制度）。
- **反模式清单**：把 Gate 1 与 Gate 2 混成一张表 ｜ 只报设备价 ｜ 按不可逆口径发 RFQ ｜ 在鼓/工装规格未收敛时做实物打样（打出来没有代表性）｜ 把「评估基线」当「拆除授权」写进会议纪要小字。
