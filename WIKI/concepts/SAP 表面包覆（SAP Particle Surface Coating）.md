# SAP 表面包覆（SAP Particle Surface Coating / Coating of superabsorbent polymer particles）

> One-line definition 一句话定义：在 SAP 颗粒后处理阶段，通过混合设备将液体或微粒固体包覆到吸水聚合物颗粒表面（典型为喷至产物床层表面以下），以调控粉尘、流动性与表面交联程度的一类工艺；本批两项 BASF 授权专利（CN 101641398 B、CN 101679760 B）分别给出「液体喷涂」与「气流分散微粒固体」两种实现。

## 机理 / 结构拆解 / Mechanism

1. **目的**：SAP 颗粒表面包覆用于改善粉尘、流动性、表面交联层（surface-crosslinking），从而影响 AUL / CRC 等性能与加工性。
2. **液体喷涂法（CN 101641398 B）**：在带可移动混合工具的混合器中，经至少一个喷嘴将液体喷至产物床表面以下。
3. **气流分散微粒固体法（CN 101679760 B）**：在混合器中用经气流分散的微粒固体包覆 SAP 颗粒，分散微粒的进料终止于产物床层表面之下。
4. **SFC（表面交联率/表面交联分数，Surface-Crosslinking Fraction [待验证]）**：本批 BASF 变体副本披露了 SFC 计算公式，用于表征包覆/表面交联程度——缩写完整展开 [待验证]。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 产线上的"双层后处理"：上层交联 / 下层功能涂布）

> 来源：[[SAP Production Process Walkthrough — Polymerisation, Grinding & Surface Treatment（I sap生产流程介绍）]]（供应商工厂工艺讲解 ASR 转写，日期 [待验证]）。本批只**追加**，不修改既有结论。
> 价值：上方为**专利口径**（怎么喷、怎么分散）；本批补的是**真实产线**上后处理段怎么组织——**上下层分工 + 分步加料 + 二次烘干**。

**产线后处理的真实组织方式（本批新增）：**

| 环节 | 做法 | 备注 |
| --- | --- | --- |
| 加料计量 | **计量秤**加固体引发剂；**质量流量计**按比例加液体引发剂 | — |
| 绞龙 | **只做计量**，与引发剂添加量 **DCS 连锁**（按吨数自动给料） | 不是混合设备 |
| 上层 | 加**表面交联剂** | 定型动作 |
| 下层 | 加**抗静电、抗黄变、抑菌类原料**（对应前一日所说的**离子交换涂布/涂覆**） | 功能性涂布 |
| 混料序列 | **高速混合机**（近百个小桨叶片）→ 膨料机 → **双轴搅拌** | **每台设备各加一种原料** |
| 为什么混三次 | 加的添加剂较多，**分步加料更均匀**；每级设备都有存在意义 | 不是冗余 |
| 烘干 | **约 130 ℃** 高温烘干 → 使表面交联**更彻底** | 二次烘干兼补固含 |
| 固含链 | 后处理前 **≈96%** → 加液体添加剂后表面带水、固含下降 → **二次烘干** | 加液体必然降固含 |
| 收尾筛分 | 后处理后再过**摇摆筛**，粗的"后处理大颗粒"**单独收集回研磨** | 三次搅拌会破碎 → 半成品粒径刻意做大 |

**无机粉末的实例（本批新增，与专利族互相印证）：**

- **二氧化硅（SiO₂）已在产线使用**，加入点在**高速混料机加液处**；作用是**改善颗粒流动性（flow rate）** —— 不加则颗粒**粘连**、流动性差、**影响吸水性**。
- → 与专利中"**气流分散微粒固体**"（CN 101679760 B）是同一思路的工业实现：**固体粉末在混料机内与液体同步加入**，而非单独工序。

**由此得到的认知（本批新增）：**

1. **"表面包覆"在产线上不是单一工序，而是一串分工明确的加料—混料—烘干序列**：上层负责交联（保强度/保 GBP），下层负责功能（抗静电、抗黄变、抑菌）；**分工设计使多个功能可以叠加而不互相干扰**。
2. **分步加料是均匀性的解法**：添加剂种类多时，一次性加入会不均，故拆到高速混合机 / 膨料机 / 双轴搅拌三级，每级各加一种 —— 是可迁移的混料设计原则。
3. **加液体必降固含，二次烘干不可省**：这是后处理段的固有耦合，也是表面交联能否"彻底"的温度—时间窗口所在（本线约 130 ℃）。
4. **破碎是后处理的副作用**：三次搅拌会打碎颗粒 → 必须在半成品段**把粒径刻意做大**倒推补偿。

✅ **验证记录（2026-09-29）**：以上为**供应商现场讲解口径**，无第三方验证；上下层的**具体成分与加量未披露**（商务/配方敏感，见源页 manual_review）；设备名（皂壳 / 胶原压动机 / 浆液干燥机）为 ASR 音转，**设备对应关系 [待验证]**。参见 [[SAP（高吸水树脂）]]、[[SAP GBP Improvement & Surface Crosslinking Process Review（GDP提升工艺探讨）]]、[[诺尔（Nuoer）]]。
