# Peel Test STM-00438（剥离强度测试）

> 一句话定义：用来量化**两层材料"粘得有多牢"**的方法——把复合好的试样以规定宽度夹住、按 **STM-00438** 拉伸剥离，读取**平均载荷（Average Load）与峰值载荷（Peak Load，gf）**。它的价值不只是给出强度数字，更在于**暴露失效模式**：当剥离力高到把某一层本身撕破时，测到的已经不是界面强度，而是**基材强度**——**此时数据越"好"越危险**。

## 机理 / 结构拆解

1. **测的是界面，读的是力**：剥离过程记录一条力—位移曲线，**Average Load** 反映整段剥离的平均抗力，**Peak Load** 反映最强的局部锚点。两者常常不同步（本批数据中码 1 的平均 43.2 gf 却出现 113.7 gf 的峰值），说明**结合是不均匀的**。
2. **标准差本身就是结论**：同一码重复 3 次的离散度从 **0.6 gf（码 1）到 133.8 gf（码 11B）**不等。**离散大不是"测试没做好"，而是工艺不稳定或失效模式在切换**——务必用重复次数把离散"跑出来"，而不是用 3 次均值把它盖掉。
3. **失效模式的三段**：① **界面分离**（胶没粘住，力最低）；② **混合失效**（部分胶内聚破坏、部分界面分离，力居中）；③ **基材撕裂（rips in the surge）**——结合强度超过导流层自身强度，剥离时把导流层撕破。**第三段的读数不再代表界面质量**，而是进入**过强区**。
4. **"过强"为什么也是问题**：结合过强通常伴随**高覆盖率/高添加量**，而这与"胶堵住排液通道"是同一件事的两面；同时压合过强会**压缩导流层空隙**。因此剥离测试的正确用法是**找窗口**——下限由"界面分离"给出，上限由"基材撕裂 + 排液堵塞"给出。
5. **界面是两个表面的事**：同工艺下只换面层（12 gsm SB → China Liner），剥离强度从 **85.6 gf 降到 24.9 gf**。**评价一个胶种时必须连同被粘的两个面一起评价**，单看胶没有意义。
6. **剥离 ≠ 回渗**：剥离只证明"连上了"。结合强度能否转化为更低的回渗，还要靠**毛细测试**看通路是否还通、**MicroCT** 看空隙还剩多少。**三项必须配套**，缺一项就会把"粘得牢"误判成"性能好"。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[HSBL Peel Test Results（面层-导流层剥离强度实测）]]）：本页为新概念页。首条来源给出一条**方法层面的硬规则**——**剥离测试必须同时记录失效模式**。若只看 gf 数值，码 7（537 gf，出现导流层撕破）会被判为"最好"，但它实际上已进入基材撕裂区；**数值最高的码与最优工艺并不重合**。

- **教训**：**离散度要用重复次数"买"回来**。源表对 6 / 6B / 11 / 11B 补测到 8–10 次，正是因为首轮 3 次的标准差高达 96–134 gf——**用 3 次均值盖住这么大的离散，结论就是假的**。
- **教训**：**反向剥离（把主/副基材互换）会让数据失效**。6B / 11B 相对正向码不仅均值下降，标准差还放大到正向码的 1.2–9.5 倍——**同一界面的强度不是对称的**，剥离方向必须写进方法。
- **教训**：**换面层等于换界面**。China Liner 把强度砍到 1/3.4，说明"胶好不好"这个问题本身是错的，正确问法是"**这对表面配不配**"。
- **待补 `[待验证]`**：STM-00438 的完整操作规程；剥离强度 ↔ 回渗的定量关系（是否存在"最优窗口"）；各胶种的失效模式分布。
