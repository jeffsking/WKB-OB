# Migratable Fluorescent Whitening Agents（可迁移性荧光增白剂）

> 一句话定义：指可从材料（纸、非织造布、绒毛浆等）中**迁移出来**的荧光增白剂（FWAs / optical brighteners）；中国卫材与卫生用品标准体系对其统一口径为**「不得检出 / 不应有 / 无」**，且是**原材料与成品双层约束**。

## 机理 / 结构拆解 Mechanism

1. **为什么只管「可迁移」**：荧光增白剂本身用于提高白度；风险在于**迁移到人体接触面或被摄入/接触黏膜**。因此标准管控的是「可迁移部分」而非「总含量」——这决定了检测方法（迁移/萃取法）与判定口径。
2. **来源路径**：纸类原料（绒毛浆、无尘纸、吸水衬纸、面层用纸）是最主要来源；非织造布与织物也可能带入。供应链上表现为「**原料侧禁添加 + 成品侧不得检出**」两道闸。
3. **判定表述在各标准中不完全一致**：`不得检出`（GB 15979—2024 表1）、`无`（GB/T 28004.1/2、GB/T 27728.3—2024、GB/T 30133—2022、GB/T 43585—2023）、`不应有`（QB/T 5650—2021）、`不应添加`（GB 15979—2024 §4.3 c 原料侧）。**语义等价但措辞不同，写技术协议时须照抄目标标准原文**。
4. **检验属性**：在多个标准中被列为**型式检验项目**（QB/T 5650—2021、GB/T 28004.2—2021），出厂检验不覆盖 → 采购须单独约定型式检验频次。

> **方法标准锚点（2026-09-29 追加）**：上述「无/不得检出」条款的检测方法落点是 **GB/T 27741-2018**（定性纱布-UV 法 + UV-Vis 348 nm 以 VBL 计 + HPLC-FLD 7 种目标物），详见 [[GB-T 27741-2018 Determination of Migratable Fluorescent Whitening Agents in Paper and Board（纸和纸板 可迁移性荧光增白剂的测定）]]。UV-Vis 检出限 20.0 mg/kg、HPLC 检出限 1.0 mg/kg、回收率 80–120%——「不得检出」在实操上=「低于所选方法的检出限」，写协议时应指定方法与检出限口径。

## 经验教训 Lessons

1. **「无 / 不得检出 / 不应有」是三条措辞，写进采购协议时必须照抄目标标准的原文措辞**，否则判定依据会在争议中被质疑。
2. **原料侧「不应添加」≠ 成品侧「不得检出」**：GB 15979—2024 同时设了这两条，原料合格不能推定成品合格（加工过程可能带入）。
3. **多数标准把它列为型式检验**，来料 COA 若只做出厂项目，不能证明合格 —— 这是本批多份标准反复出现的同一个坑。
