# Pad Zoning：Flat vs Pocketed（成型分区：平区 vs 袋区）

> 一句话定义：在垫体（吸收芯）成型环节按区域设计克重/密度/厚度分布的两种基础形态——**flat（平区，均匀垫）**与 **pocketed（袋区，局部下陷/加厚形成功能分区）**；2021 年 K-C 培训即把「Pad zoning flat versus pocketed」与「channel / void absorbent」列为正式讲题。

## 机理 / 结构拆解

1. **分区动因**：液体在芯体内的落点与扩散不均匀（单点摄入 + MD 方向扩散），均匀垫在落点区易饱和、在远端浪费容量 → 按摄入/扩散行为**分区给料**（克重、SAM 浓度、密度梯度）。
2. **flat（平区）**：成型鼓单一直径设计，工艺最简、换型成本低；性能上限依赖 ADL/面层去分布液体。
3. **pocketed（袋区）**：成型鼓做局部轮廓（浅袋/深袋），在袋区形成**加厚/高容量区**、非袋区减薄——培训原话是「learn about different forming designs. Add section on absorbent designs」，即多种成型设计族谱。
4. **相邻议题 channel / void absorbent**：议程批注提出「Should we add a couple slides to cover channel / void absorbent」——通道/空腔芯体（对应本库 [[Core Channel Pattern（芯体通道花型设计）]]）是分区思想的进阶形态。
5. **库内衔接**：本库的分区实践落在成型鼓工程（[[Patterned SAP Core Forming Drum（印花SAP芯体成型鼓）]]、[[81 Forming Drum Ups Selection（鼓距·端区·11 尺寸分配）]]）与分区设计概念（[[分区密度设计]]、[[毛细梯度设计]]）。
