# APAO（非晶态聚α-烯烃）

> One-line definition 一句话定义：以 **Ziegler-Natta 催化**无规聚合得到的、**结晶度极低**的丙烯/乙烯/丁烯类低分子量聚烯烃；在热熔胶中曾长期作为廉价主体聚合物，现多作为**加工与粘附调节组分**。

## Definition / Mechanism 定义与机理拆解

1. **"非晶"是市场名，不是严格意义**：来源记录 Bostik 内部实测表明，市场上以 "amorphous poly-alpha-olefins" 出售的牌号**并非完全非晶**，DSC 熔融焓普遍**< 25 J/g**（最高实测值 20.4 J/g，Vestoplast® 708；REXtac RT2730 为 9.4 J/g）。
2. **历史沿革**：热熔胶最早用 **APP（无规聚丙烯）**（晶态聚丙烯的溶剂萃取副产物），随后出现**有目的生产**的 **APAO**，以 Ziegler-Natta 催化、可用丙烯/乙烯/丁烯等多种单体，得到**宽分子量分布的无规聚合物**。
3. **作为主聚合物的两个致命短板**（来源原文）：
   - **缺高温耐热（尤其抗蠕变）** → 不能用于弹性粘合，只能做结构粘合（无纺布—PE 膜）；
   - **喷涂性差（poor sprayability）** → 弹性粘合几乎全部走喷涂设备，且要求更高温、更高涂布量、更精准的落点。
4. **在现代聚烯烃热熔胶中的新角色**：作为**低结晶度次级聚合物**（结晶度 ≤250 J/g，可低至 ≤25 J/g）来调节黏度、粘附、低温/高温耐受、压敏性与老化，而不显著损害粘结强度。
5. **与 OBC 的对照**：OBC 是**嵌段**（专门造结晶区）、窄分布；APAO 是**无规**、宽分布——来源明确二者"不可视为等价"。

## 经验教训

> ✅ 验证（2026-09-29，来源 [[EP2456819B1 Olefin Block Copolymer Hot Melt Adhesive (Bostik)]]）：来源同时记录了 **APAO 的标签不精确性**（"非晶"牌号实测仍有 <25 J/g 的熔融焓）与**供应商与权利人使用同一判据线**（30 J/g）区分非晶/半结晶。本页据此把"APAO"表述为**市场名 + 实测判据**双重口径，与来源一致。

- **教训一（历史坑）**：APAO 曾被排除在弹性粘合之外，原因不是粘性不足而是**抗蠕变与喷涂性**——评估任何"聚烯烃替代 SIS"的方案时，这两项应作为首要门槛。
