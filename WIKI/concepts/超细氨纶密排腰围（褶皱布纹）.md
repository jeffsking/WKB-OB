# 超细氨纶密排腰围（褶皱布纹）Dense Ultra-Fine Spandex Waistband (Crinkle Texture)

## Definition 定义

以**多根超细氨纶丝平行密排**（丝径 10–80 D、间隙 0.01–0.1 mm）替代「少根粗橡筋」的腰围路线：拉伸 1–3× 后热熔胶粘接，回缩时外层无纺布形成**自然褶皱布纹**。三个卖点（来源原文逻辑）：丝间间隙流通空气（透气、随呼吸伸缩）、多根细分担受力（无集中力线 → 无勒痕）、褶皱形态随拉伸展开（贴服）。

## Parameter window 参数窗口（两件专利对照，逐字）

| Parameter 参数 | CN 114376803 A（米卫杭州，A 公开 2022-04-22） | CN 222018549 U（湖州因爱伟大，U 授权 2024-11-19） |
|---|---|---|
| 氨纶规格 | 10–80 D（捻丝/包覆丝，氨纶 15–95%+锦纶/棉包覆 5–85%） | 70–620 dtex（约 63–558 D，量纲不同仅供参考） |
| 根数 | 未限定（横向平行密排） | 10–300 根 |
| 间隙/间距 | 0.01–0.1 mm | 1–2 mm |
| 拉伸倍率 | 1–3×（1× 浅褶、3× 深褶） | 拉伸状态下焊接（倍率未量化） |
| 褶皱成因 | 回缩自然成褶 | **拉伸状态下超声波/热熔焊接点**（横 2–5 mm、纵 6–10 mm）强制成褶 |
| 透气机制 | 丝间间隙 | ——（本件未主张透气，主打省工序） |

（表头中文对照：间隙 = gap between strands；拉伸倍率 = stretch ratio；褶皱 = crinkle/pleat。）

## Two ways to make crinkles 两种成褶路径

1. **被动成褶**（米卫）：密排细丝 + 高倍拉伸粘接 → 回缩时无纺布自然皱缩成布纹。
2. **主动成褶**（因爱伟大 CN 222018549 U）：局部弹性复合层在**拉伸状态下**按焊接点阵（超声波或热熔胶）粘合 → 回缩后在焊点间形成规则褶皱，跳过「氨纶丝→弹性布材」预加工工序。

两条路径的共性结论：**褶皱 = 弹性余量在无纺布上的空间储备**，兼具外观（布纹质感）与功能（均匀受力、可展开）。
