# Hook-and-Loop Strength Test（粘扣系统强度测试）

> 一句话定义：纸尿裤**粘扣（hook）与环抱腰贴（loop）** 系统的一族拉力测试，按"力加在哪两个界面、往哪个方向拉"分为四项——**剥离（peel）**、**剪切（shear）**、**粘扣-主体结合（bond）**、**loop-外层粘连（lamination）**；四者试样与读数口径各不相同，**不可互相替代**（中文：同一个粘扣系统要四个方向都测）。

## 机理 / 结构拆解 Mechanism

1. **四个界面 / 四个问题**：
   - 剥离（[[STM-00075 剥离.docx]]）：粘扣从腰贴上"掀开"需要多大力 → **使用体验与重复开合**；
   - 剪切（[[STM-00076 剪切.docx]]）：粘扣沿平面被"推走"需要多大力 → **抱紧可靠性**；
   - 结合（[[STM-00071 粘扣结合强度.docx]]）：粘扣本身会不会从尿裤上被拽下 → **复合牢度**；
   - Loop 粘连（[[STM-00240Loop 粘连强度测试.docx]]）：loop 与外层的复合牢度 → **材料/胶层失效诊断**。
2. **共用的三个标准动作**：
   - 机械滚轮压合一周（模拟穿着时腰贴被压贴）——剥离与剪切共用；
   - 拉力仪夹具气压 ≤0.6 MPa（三项拉力测试共同上限）；
   - 样品不得被预先施压、不得有弯曲/皱褶/角度。
3. **读数口径分三种，这是最容易出错的地方**：剥离取**平均值**、剪切取**最大值**、结合取**最大值**、loop 粘连取**按宽度归一化的 g/mm（最大值 + 失效点 + 胶失效点）**。
4. **失效模式是粘扣类方法的诊断层**：只有 [[STM-00240Loop 粘连强度测试.docx]] 定义了 7 类失效模式（SBT / OCT / CP / AOC / APA / PT / PD），说明"力够不够"之外还要回答"坏在哪一层"。
5. **时效约束**：STM-00075 明确"滚轮处理后 1 h 内完成测试"；STM-00076 原文未写同等窗口（差异点）。

## 经验教训 Lessons

> ✅ 验证（2026-09-29，来源 [[STM-00075 剥离.docx]]、[[STM-00076 剪切.docx]]、[[STM-00071 粘扣结合强度.docx]]、[[STM-00240Loop 粘连强度测试.docx]]）：四份方法互证"粘扣系统需多界面分别标定"的结构性事实；四者**夹具距离与读数口径各不同**，且剥离/剪切为同日修订的第 4/5 版，证实二者是成对标定的一对。

- **教训一（口径）**：**引用粘扣力值前必须写清界面与方向**（粘扣-腰贴 vs 粘扣-主体 vs loop-外层），否则数值无意义。
- **教训二（口径）**：**剥离读平均、剪切读最大**——同一套试样、同一次滚轮压合，只是读法不同；跨方法比较前须换算或统一。
- **教训三（诊断）**：**loop 粘连必须记录失效模式**。只报 g/mm 无法区分"胶弱"与"材料弱"（AOC/APA 指胶的归属，SBT/OCT/PT/PD 指材料破坏）。
- **待补 `[待验证]`**：四项方法的通过门槛；loop 粘连的方法号；STM-00076 是否也有 1 h 时效要求。
