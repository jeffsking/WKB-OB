# 氨纶干法纺丝（Spandex Dry Spinning）

> **Definition 定义**：**干法纺丝（dry spinning）** 是全球氨纶（spandex / elastane）的主流生产工艺，占全球产能 95% 以上；纺丝原液经喷丝板挤入圆形纺丝甬道，由热空气带走溶剂、纤维固化。纸尿裤腰围 / 腿围 / 侧边弹性体用氨纶全部来自这一工艺族。

## Mechanism / process steps 机理与工序

| Step 步骤 | Content 工艺内容 | Key parameters 关键参数 |
|---|---|---|
| ① 预聚 Prepolymer | PTMG/PTMEG 与 MDI 按约 1:2 摩尔比反应 | 60–80 ℃，无水无氧 |
| ② 扩链 Chain extension | 预聚物与二胺类扩链剂反应 | 扩链程度决定**硬段含量**，影响回弹性 |
| ③ 原液配制 Dope preparation | 预聚物溶于 DMAC/DMC，调粘度 | 浓度 15–20%，粘度 3,000–8,000 cP |
| ④ 干法纺丝 Dry spinning | 原液经喷丝板挤出，进入圆形纺丝甬道，热空气带走溶剂 | 甬道 150–200 ℃，氮气保护 |
| ⑤ 上油 Finish application | 凝固纤维上油 | 含油率约 6.5%（抗静电、润滑、抗粘连） |
| ⑥ 热牵伸 Hot drawing | 高温下拉伸取向 | 300–500%，决定**弹性回复率** |
| ⑦ 机械假捻 False twist | 高速假捻加捻（扭结）赋予弹性 | 捻度影响弹性模量 |
| ⑧ 卷绕 Winding | 卷绕为丝饼（spool） | 卷绕张力均匀性影响后续加工 |

1. **硬段比例是抗蠕变的杠杆**：提高 MDI（二异氰酸酯）含量 → 增加硬段比例 → 提高氢键化水平 → 增强抗蠕变。华峰 HDS 的差异化正是沿此路径（"硬段强化 + 氢键网络增强"）。
2. **表面工程是第二条改性路径**：在常规油剂体系之外，可通过添加功能助剂做**物理改性增强表面交联**；另一极是**完全取消油/粉**（无油无粉表面处理）。
3. **溶剂回收能力决定残留与合规空间**：DMAC 是核心溶剂，回收技改水平直接决定成品残值与出口合规成本（见 [[DMAC（N,N-二甲基乙酰胺）残留与 REACH 限制]]）。
