# 低熔点聚丙烯（LMP-PP，Low Melting Point Polypropylene）

> 一句话定义：通过共聚改性/立构规整度调控把 PP 熔点从均聚的 160–165°C 下探到 **135–150°C** 区间，使之能在较低温度下热粘合的一类聚丙烯树脂；在本库中特指 **TBCW 底层替代 Bico、以及全 PP 皮芯（EPC）纤维皮层树脂** 两条应用路径。

## 机理 / 结构拆解

1. **熔点由结晶能力决定，而结晶能力由聚合端锁定**。i-PP 是可结晶主体（熔点 160–170°C），a-PP 完全不能结晶；乙烯共聚单体进入 PP 链会「显著改变分子链性质」，直接带来熔点下降。因此**所有降熔点路线的本质都是破坏等规序列、抑制片晶完善度**——这是必须从聚合端入手、而非纺丝线回调的根本原因。
2. **四条技术方向**（按开发难度与落地速度排序）：
   - **①无规共聚（RCP）路线**——最成熟首选。乙烯 1–8%（甚至 5–8% 以上），配合茂金属催化剂，可做出熔点 130–150°C 的低熔点 PP；工业化最现实。
   - **②立构规整度调控路线**——通过催化剂与聚合条件改变立构规整度及分布，可控降低结晶度（sPP 或等规度受限 i-PP）；技术门槛在催化剂体系，适合差异化牌号，不适合快速落地。
   - **③共混/弹性体路线**——向 PP 中共混 PE、茂金属塑性体或 EPDM（TPO/ICP 思路，ICP 含 45–65% 乙烯相）；低成本见效快，但降低的是**热粘合软化点而非真正熔点**，分子级分散差时纺丝稳定性是风险点。
   - **④皮芯复合路线**——不追求 PP 本体熔点大幅下降，而是做皮芯结构：皮层用低熔点组分、芯层用常规 PP/PE（方案 C 的思路）。
3. **方案 C 的三个叠加手段**（目标皮层熔点 135–150°C）：共聚单体打满上限（≈10 wt%，配合丁烯效率高于乙烯）+ 掺入 5–30% 低等规组分 + **反向禁用成核剂**（成核剂助结晶、会提熔点）。
4. **结构性死结**：强度靠「取向 + 结晶」，低熔点靠「少结晶」，二者在同一条单组分纤维上互斥——这是强度必须外包给芯层（皮芯方案）的根本理由。

## 经验教训

> ✅ 验证（2026-09-27，来源 [[2026年上半年国内茂金属催化剂突破]]）：国内 mPP 催化剂已进入多装置复制推广，「催化剂不可得」不再是立项障碍；但公开牌号均为通用高端料，**尚无「熔点 135–150°C + 纤维级 MFR」的低熔点卫材纤维级牌号**——本项目的空档成立。

- **要点**：行业里大量「低熔点」需求实际是被皮芯结构的低熔点组分解决的，独立低熔点 PP 树脂牌号远少于低熔点 PE；谈判与选型时应先确认对方指的是「树脂本体低熔点」还是「皮芯皮层低熔点」。
- **待补 `[待验证]`**：熔点—乙烯含量的定量关系（本库未覆盖）；各家低熔点 PP 牌号完整 TDS 对比。
