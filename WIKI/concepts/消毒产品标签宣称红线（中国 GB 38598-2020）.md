# 消毒产品标签宣称红线（中国 GB 38598-2020）

> 一句话定义：中国**强制性**国标 GB 38598—2020 对消毒产品标签/说明书的通用要求，其中最关键的是**第 7.4 条禁用宣称清单** —— 湿巾不得标「抗菌/抑菌/杀菌」，卫生湿巾名称不得含「抗菌」，卫材品类标签不得标「消毒/灭菌/除菌」。

## 机理 / 结构拆解 Mechanism

1. **强制属性**：GB（无 /T），ICS 11.080 / CCS C50，国家卫健委提出并归口；2020-11-17 发布、**2021-12-01 实施**；**不适用于不在国内销售和使用的出口消毒产品**。
2. **两套要求并行**：**必标项**（7.1，分级到湿巾/卫生湿巾/其他卫生用品）+ **禁标项**（7.4，五类清单）。很多合规事故来自只查必标、漏查禁标。
3. **「性能可测 ≠ 可以写」**：产品可能实测杀菌率 ≥90%（GB 15979），但**湿巾标签仍不得出现「抗菌/抑菌/杀菌」字样** —— 这是两条独立的合规轨道。
4. **第 1 号修改单（2024-04-29 批准，2025-05-01 实施）**：抗（抑）菌制剂须加**黑体警示说明**「本品不是药品，不具有治疗、护理、保健作用」；字体高度由「>1.8 mm」改为「**≥1.8 mm**」；商标不得以谐音名/图形暗示疾病治疗、护理、保健作用。

| **卫生湿巾** | 灭菌、消毒、抑菌、除菌、药物、高效、预防性病、治疗疾病、减轻或缓解疾病症状、抗炎、消炎；**产品名称不得标注「抗菌」** | 7.4.4 |
| 卫生巾/护垫/卫生纸/**尿布（垫、纸）/隔尿垫/尿裤** | 消毒、灭菌、除菌、止带、除湿、润燥、抗炎、消炎、杀精子、避孕；**名称不得含「药物」** | 7.4.5 |
| 抗（抑）菌制剂 | 抗炎、消炎、治疗疾病、减轻或缓解疾病症状、描述或解释疾病症状、预防性病；适用于破损皮肤/黏膜/伤口；高效、消毒、灭菌、除菌、杀精子、避孕；用于足部、眼睛、指甲、腋部、头皮、头发、鼻黏膜、肛肠部位；×天为一疗程、遵医嘱、防止复发、有利于伤口愈合、辅助配合药物治疗 | 7.4.1 |
| 隐形眼镜护理用品 | 全功能、高效、灭菌、除菌；治疗疾病、减轻或缓解疾病症状、辅助配合药物治疗 | 7.4.2 |

**必标项差异（7.1）：**

| 对象 Object | 追加必标项 Additional Mandatory |
|---|---|
| 湿巾（j） | 产品规格、主要原料名称、执行标准编号 |
| 卫生湿巾（k） | 产品规格、主要原料名称、执行标准编号、挤出液主要有效成分及含量、杀灭微生物类别、使用范围 |
| 其他卫生用品（l） | 杀灭/抑制微生物类别（抗菌/抑菌卫生巾护垫纸）、产品规格、主要原料名称、执行标准编号；**消毒级**另标「消毒级」+ 消毒方法 + 消毒日期 |

**其他数值口径：** 字体高度 **≥1.8 mm**（修改单后）；有效成分含量范围：稳定的 ≤中心值 **±10%**、不稳定的 **±15%**；净含量允差按《定量包装商品计量监督管理办法》。

> ⚠️ **过渡期（修改单原文）**：该标准实施之日后至修改单实施之日前生产或进口的产品，其标签说明书在符合当时规定的前提下，**可销售至产品标示的有效期限为止**。

## 经验教训 Lessons

1. **最常踩的坑是「湿巾标抗菌」**：GB 15979 允许测抗菌性能，但 GB 38598 禁止湿巾标签出现该词 —— 市场文案与法规文案必须分开审。
2. **「卫生湿巾」名称不能叫「抗菌卫生湿巾」**（7.4.4 明确），命名阶段就要规避。
3. **消毒级要在两个标准里都标注**（GB 15979 §9.2 + GB 38598 7.1 l），缺一处即不合规。
4. **修改单的警示说明须用黑体或更大字号**（抗抑菌制剂），排版环节容易漏。
