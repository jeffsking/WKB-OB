# CD Pants Converting Process（CD 裤式产品加工工艺）

> 一句话定义：**裤式（CD Pants）产品的加工工艺，本质是把"吸收插入体（insert）"与"腰围片（panel）"两条支线分别做成，再把 insert 转向 90° 从 MD 变成 CD 后组合**。（中文：**"CD"不是营销词，是工艺事实**——`insert applicator` 的唯一主目的就是把产品方向 **由 MD 转为 CD**，这一步决定了整线为何是"五层、很复杂"。）

---

## 机理 / 结构拆解 Mechanism

1. **两条支线 + 一次转向**：
   - **Insert 线**：绒毛浆成型 → 面层/导流层层合 → 护围/外覆层层合 → 折边并层合腿围弹性体 → **切断 → applicator 转向 MD→CD**。
   - **Panel 线**：内外腰围片材料 + 腰围弹性体层合 → **弹性体 chopping（切断）** → 分条 → 与 insert 层合 → **对折（bi-folding）** → 封合 → 最终切断。
2. **转向是枢纽**：*"The main purpose is to change CD pants product direction from MD to CD."* —— 这一步之后才有"裤式"形态。
3. **腰围弹性体自身也转 90°**：*"Panel elastics web path is changed from the vertical position to horizontal position with a twisted angle which is 90 degree."*
4. **成型靠真空分区 + 轮廓段**：成型鼓 **5 个真空区**用于**芯体成型与释放**；**contour segments & forming screen** 按芯形配置。
5. **克重变异由 scarfing 系统控制**，不由成型鼓承担。
6. **质量门集中在三处**：**insert cut off**（与 panel 组合前的关键工序）、**panel sealing**（获得足够封合强度的关键工序）、**insert-to-panel 层合**（取决于胶型宽度 + 间歇胶的电磁阀控制）。
7. **相位是链式的**：`Leg Die cutter → Insert Cut off → Side Panel seaming → Insert Repitch → Insert Cut off → Pad Cut off → Channel Embosser → Forming Drum → Machine "0" position → LEO`；**机器相位**与**胶相位**分开控制，但都以 **buttonbox 由白变紫**选中。

## 经验教训 Lessons

1. **"CD"来自 MD→CD 转向** —— insert applicator 是整线枢纽，决定了裤式与开放式在**产线形态**上的根本差异。
2. **"很复杂"是结构性的** —— 五层布局来自两条支线 + 转向 + 包装，**不是布局没优化好**。
3. **插入体切断是组合前的关键门** —— 源文明写 *"critical process before combining with panel material"*。
4. **封合强度是独立质量门** —— 且**换材料即换工艺设定**（SMS / TABCW）。
5. **间歇胶 = 电磁阀控制** —— insert-to-panel 质量**取决于胶型宽度 + 间歇控制**，不是只取决于胶量。
6. **对折可调但只能调"间隙差"** —— wheel screw 按前后腰围片 **gap difference（mm）** 调整，**是补偿不是设计变量**。
7. **相位链不可单点调** —— 从 Forming Drum 到 Side Panel seaming 全链联动；机器相位与胶相位**分开**但**耦合**。
8. **胶相位正负号有强定义** —— 起点与长度两套符号，**"+"远离 / "−"靠近**，写反会导致胶位偏移。
9. **材料工程能力是空白** —— 培训材料自身的工程能力矩阵中**唯独 Material Engineering 为 TBD**。
10. ⚠️ **2016 年时点** —— 21 台资产、5 区成型鼓、Optima 包装等**均为当年快照**。
