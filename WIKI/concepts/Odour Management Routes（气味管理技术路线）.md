# Odour Management Routes（气味管理技术路线）

> 一句话定义（Definition）：**气味管理（odour management）** 指对卫生用品使用后的异味进行干预的技术族；按机理分三条路线——**掩盖（masking）**、**物理捕捉（physical capture，含中和与吸附）**、**化学捕捉（chemical capture）**。三者的分水岭是**是否改变异味物质的化学性质**。

## 机理 / 结构拆解（Mechanism）

1. **为什么有味道**：某些化学成分**挥发性强**，挥发后到达嗅觉即产生气味感受 → 干预点要么是「换一个更好闻的挥发物」，要么是「降低该物质的挥发/存在」。
2. **掩盖（masking）**：引入**挥发性更强**、气味可接受物质，抢先占据嗅觉；**不改变原异味物质**。
3. **物理捕捉（physical capture）**：与异味物质**物理结合**（隐蔽或绑定），**不发生化学反应、不改变其化学性质**，但因其物理性质被改变，气味表现也被改变。**气味中和（neutralisation）与气味吸附（attraction/adsorption）都属物理捕捉**。
4. **化学捕捉（chemical capture）**：加入带**化学反应机理**的物质（本批为天然物质），与异味物质发生反应而消除。供应商口径下由**日本团队**研发，**载体是热熔胶**。
5. **载体与位置决定效果**：化学捕捉物质被加入**热熔胶**，再涂布（或施胶）于无纺布基材；效果取决于**产品结构设计、基材选择、成品上的涂布量**。
6. **评价方法的固有局限**：VOC 探针只测**挥发性物质的总量/成分**，不能等价于人的气味感受；**必须与专家小组（panel）盲测结合**。常温下的可分辨率有限，加热后差异才明显。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 去味粉入芯体的样品设计与工程化卡点）

> 来源：[[COCO V6 Trial Code Design & Process Alignment（录音纪要 2026-08-17）]]（2026-08-17 ASR 转写）。本批只**追加**样品设计与工程化卡点，不修改既有结论。

**样品设计（已决，本批新增）：** 借 COCO V6 芯体机试验同步制备三款 odour-control（气味控制）样品：

| Code 编号 | Design 设计 | Note 备注 |
| --- | --- | --- |
| ① | 现有 control + 上层芯体混 **0.25 g** 去味粉 | 单侧低量 |
| ② | 上层芯体混 **0.5 g** 去味粉 | 单侧高量 |
| ③ | 上下层各混 **0.25 g**（合计 **0.5 g**） | 双侧分布，与②总量相同、分布不同 |

→ 三款的对比可分离「总量效应」与「分布效应」。

**工程化卡点（本批新增，均为待决 / 未决）：**

1. **预混主体**：倾向由 SAP 供应商（诺尔）代混；若本方自混，存在实验室**污染**、**均匀度**、**EHS 粉尘管控**三重问题。
2. **最小混量**：约 50–200 kg [待验证]；现有 SAP 存量约 140 kg 量级（转写口径）[待验证]。
3. **投料方式**：芯体机料罐为**间断式抽吸上料**（低于液位自动补料），理论上可手动倒料，但需现场确认罐盖密封性、可否人为打开、管路是否易拆。下料口可密封后用泵间断抽送 → 出料侧「问题不大」。
4. **真正的卡点在称重段**：人工称重必然开口 → 粉尘如何预防尚未有方案；密封 coupling 可做，但「称好重后如何导入混合机」未解。
5. **自动进料称重设备**：投入量级为**数十万元人民币**（转写称 60–70 万元以上），判定「为这个实验没必要」→ 本轮不投。
6. **物性匹配**：去味粉按现有 SAP 粒径制作，粒径接近；**密度是否接近待确认**（影响抽吸上料可行性）[待验证]。
7. 替代思路（讨论中，未采纳）：把芯体拆开后撒粉再复合 —— 视实验目的而定，未决。

## 追加：Meeting Minutes 批 2（2026-09-29 追加 · 五路线分类法与"消臭型 SAP 一体化"的定量目标）

> 来源：[[Diaper NPD Workshop Prep — Absorbency, Skin Health & Comfort Feature Map（2026-06-05）]]（Workshop 准备材料 v1.0，2026-06-05）。本批只**追加**，不修改既有结论。

**臭味物质的范围（本批新增）：**

- 材料列出**九种臭味物质**：**氨 / 胺类 / 短链脂肪酸 / 硫化物**等（其余未列全）→ 说明消臭不是单一靶点问题，**单一机理难以全覆盖**。

**五大技术路线（本批新增，含机理分类）：**

| 路线 | 机理 | 备注 |
| --- | --- | --- |
| ① **化学中和** | 有机酸中和氨 | 靶点明确（针对碱性气体） |
| ② **物理吸附** | 沸石 / 活性炭 | 与 [[Zeolite Odour Control（沸石除臭载体）]] 同源 |
| ③ **生物酶解** | **尿素酶抑制** | 从源头阻断氨的生成 |
| ④ **香味掩盖** | 微胶囊缓释 | 不改变臭味本身 |
| ⑤ **消臭型 SAP 复合一体化** | 在 **SAP 聚合过程中引入消臭官能团** | **前沿方向**，把功能做进主体材料 |

**消臭型 SAP 的定量目标（本批新增）：**

- **氨气吸附量 > 200 μg/g**（目标）；成本增量 **+5–8%** vs 普通 SAP。
- **消费者侧测试需求**：① 臭味强度评分（**感官评价**）；② 氨气浓度衰减曲线（**GC-MS 验证**）。
- → 判据是**"仪器 + 感官"双轨**：只有 GC-MS 不够，必须补感官评价。

**由此得到的认知（本批新增）：**

1. **五条路线的作用层级不同**：掩盖（④）不改变量；吸附（②）与中和（①）在发生后处理；酶解（③）在**生成前阻断**；一体化（⑤）把功能**内建到主体材料**。层级越靠前，技术难度越高但持续性越好。
2. **"消臭型 SAP"是把功能从"添加剂"上移到"主体材料"** —— 与库内其他"母粒/纤维端功能化"的思路同构，也同样面临**添加量少 → 效果有限**（参见 [[Skin Health Treatment on Nonwoven（无纺布护肤处理）]]）的质疑 → 因此**必须先给出 200 μg/g 这样的量化靶点**。
3. **消臭被 Workshop 识别为市场空白机会点**（"目前市场少见"）→ 差异化价值高于其性能价值。

## 追加：FEI 批（2026-09-29 追加 · FEI 四通道框架与 eNose 筛选结论）

来源：[[IPC BCC FEI Update（IA2.0 · 2026-06-22）]]。FEI 的除臭项目卡把技术方案组织为**四通道**（与既有路线分类法并列，不取代）：

1. **Capture 捕集**：Trap VOCs in structure（结构内捕集 VOC）
2. **Alter 转化**：React with VOCs（与 VOC 反应）
3. **Microbial 微生物**：Healthier odor environment（更健康的气味环境）
4. **Perception 感知**：Sensorial reassurance cue（感官安抚线索）——即"技术解决 + 情绪解决"双轨

- **平台清单（FEI 口径）**：AqFresh liner / film · Carbon-based odor control · Zeolite catalyst / particles。
- **筛选方法学结论**：**eNose 是快速、低成本的筛选工具，与人体感官测试趋势一致**；Danson SAM、carbon surge、AqFresh 处理面层三项优于对照，已选入人体 Panel。
- **消费侧权衡（FEI 原话）**：除臭需与"知道何时更换（尤其 BM 后）"平衡——即本库 [[Urine Indicator vs BM Indicator（尿湿指示 vs 便指示）]] 与 [[Odour-Control Granular Interference（除臭颗粒干扰）]] 讨论的同款矛盾。
