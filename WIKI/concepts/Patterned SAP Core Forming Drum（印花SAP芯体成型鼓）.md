# Patterned SAP Core Forming Drum（印花SAP芯体成型鼓）

> One-line definition 一句话定义：**用一个鼓体 + 可换套筒族，把 SAP 按图案（pattern）双面印花到芯体上，并在换码时保持套准**——其设计原则可浓缩为一句：**"相位在鼓体，尺寸在套筒"**。（中文：不是"一台机器做一种码"，而是"一个鼓 + 两套 ups + 22 个套筒做 11 个码"。）

## Definition 定义与设计原则

| 项 | 值 | 出处 |
|---|---|---|
| 鼓径 | **Ø882 mm**（周长 2,771 mm，NW 中平面） | [[One Drum Two Ups 11 Sizes 1000 ppm（单鼓双ups 11码 1000ppm 芯体印花方案）]] |
| Ups | **6-up（4 码）+ 7-up（7 码）** | 同上 |
| 节拍 | **1,000 ppm**；鼓面 **396 / 462 m/min** | 同上 |
| 套准 | 仿真 **in-spec ≥99.99%** | 同上 |
| **设计原则** | **决定相位的都在鼓体上；决定尺寸的都在套筒上** | 同上 |

> 中文：这条原则意味着——**换码不换鼓、不换扇区、不换电机、不换压合间隙**；只换 **2 个套筒 + 下料槽宽度嵌件 + 配方**（NB/S 再加刀嵌件）。

## Mechanism 机理

### 1. 为什么"ups"是唯一杠杆

鼓距 `P = πD / n`（D 鼓径、n 每转芯体数）。**鼓径固定 + ppm 固定时，改变鼓距的唯一方式是 n**。

| 项 | 6-up | 7-up |
|---|---|---|
| 鼓距 | **461.8 mm** | **395.8 mm** |
| 鼓速 | 166.7 rpm | 142.9 rpm |
| 表面速度 | **462 m/min** | **396 m/min** |
| 离心场 | **13.7 g** | **10.1 g** |
| 每度时间 | 1.00 ms | 1.17 ms |

> **机架节距由下游伺服再分距转塔解耦**（比例 **0.85–1.40**）。**剪切滑移（cut-and-slip）不可用**——它需要比值 **≥~1.03** 且**只能加速**，而 **Open NB 的比值为 0.99**（芯体比机架节距长），会失败。

### 2. 真空扇区：角度固定 → 停留时间随 ups 变化

扇区**按角度固定**，因此 **7-up（慢 17%）在每个区都多 17% 的时间**。

| Zone | Arc | 6-up | 7-up | 真空 |
|---|---|---|---|---|
| NW wrap & pocket | 60° | 60 ms | 70 ms | −2…−3 kPa |
| **SAP forming** | **65°** | 65 ms | 76 ms | **−8…−12 kPa**（配方项） |
| Land clean | 25° | 25 ms | 29 ms | 仅凹槽 |
| Glue + hold | 54° | 54 ms | 63 ms | −4…−5 kPa |
| Nip / transfer | 18° | 18 ms | 21 ms | 皮肤 +1…+3 / 聚乙烯 −4 kPa |
| Return | 138° | 138 ms | 161 ms | 0 / 气刀 |

> **关键判据**：**保持力从来不是限制**——13.7 g 下 230 gsm 床层仅需 **~39 Pa**，而保持区给出 **~4,000 Pa**。因此**配方改的是成形真空与气刀压力，而不是扇区几何**。

### 3. 套筒：22 件，一种构造

- **11 码 ×（皮肤面 + 聚乙烯面）= 22 件**，pocket-and-land 浮雕，**端区也是"封堵凸台"**（故芯体之间无 SAP）。
- **凸台高 0.45 mm**（= 通道 + 端区）；**凹槽 = SAP 图案**，全部 n 个节距一致、**±0.02 mm**；**网板 Ø0.6–0.8 mm，开孔 30–40%**；**销 + 锥面载体，换套筒 ≤15 min/鼓**。
- **配对规则**：**图案可不同，但每条需粘合的通道必须在两个套筒的同一位置存在** → **按一个 CAD 文件成对设计并成对制造**。

### 4. 套准：MD 可自校正，CD 必须销定位

| 项 | 值 |
|---|---|
| 规格 | **│MD│ ≤1.0 mm，│CD│ ≤0.5 mm**（保持 ≥90% 通道粘合面积） |
| Cpk MD / CD | 6-up **2.43 / 1.39**；7-up **2.49 / 1.39** |
| 换码后 | **MD 约 17 片（1 s）自校正**；**CD 必须销定位** |
| 换码后 MD 偏移 | 销定位 **±0.05 mm**；仅配方补偿 **0.6 mm**；无补偿 **2.5 mm** |

> 中文：**MD 有反馈回路（UV 相机 + 相位微调，仅对聚乙烯鼓），CD 没有**——因此 **CD 只能靠机械销定位把误差"锁死"**，这是套筒接口公差（±0.02 mm）如此严格的直接原因。

### 5. ⚠️ 两套 "in-spec" 不可混引

| 指标 | 值 | 由什么决定 |
|---|---|---|
| **套准 in-spec** | **≥99.99%** | **Cpk**（机械/伺服） |
| **SAP 落点 in-spec** | **99.996% → 92.7%**（chute 未随 ups 重设时） | **落料速度匹配** |

> ⚠️ 二者是**不同指标**。详见 [[SAP Dosing Speed Matching（SAP 落料速度匹配与容差）]]。

## Lessons Learned 经验教训

> ✅ Verification（2026-09-29，source [[One Drum Two Ups 11 Sizes 1000 ppm（单鼓双ups 11码 1000ppm 芯体印花方案）]]）：本页机理与参数逐条对应源文，未作外推；**鼓距换算（461.8 / 395.8 mm）与 86 号规范的独立复算一致 ✓**。

- **Lesson 1（把变量收敛到可换件上）**：11 个码的复杂度没有被"分摊"到整机，而是被**收敛到套筒与配方**——**鼓体/扇区/电机/压合全部不变**。这是多码共线能成立的根本原因。
- **Lesson 2（相位与尺寸分离）**：**"相位在鼓体、尺寸在套筒"**是可复用的设计哲学——凡是需要频繁切换的产品维度，都应落到**可换件 + 配方**，而非整机参数。
- **Lesson 3（MD 与 CD 的纠错能力不对称）**：**MD 有反馈回路可自校正（~17 片），CD 没有** → **CD 必须靠机械精度锁死**，因此套筒接口公差与配对设计（同一 CAD 文件）是硬约束。
- **Lesson 4（静默失效排第一）**：五大风险中**"chute 速度留在另一个 ups 上"排第一**——因为它是 **recipe 项、改错不报警、只悄悄降质量**。对策必须是**系统强制**（recipe-locked + 相机报警 + 套筒 ID 联锁），不是操作纪律。
- **Lesson 5（按更苛刻的工况选型）**：施胶到压合时间 54 ms → 63 ms，**胶要按更长的 63 ms 选**；同理 SAP 粒径要同时满足 396 与 462 m/min 下的边缘锐度。
- **待补 `[待验证]`**：Δp 口径与滑移实测；床高 vs 松密度对账；SAP 边缘锐度的图像分析算法与报警阈值；流动性 ≥10 g/s 的测试方法；仿真 in-spec 率的产线验证。

## 追加：Open Innovation 批（2026-09-29 追加 · 84 号套筒规格：land 体系、屏规格冲突与防错）

> 追加来源 `[[84 Sleeve 工程规格与换装防错设计]]`（2026-09-22 派生工程笔记，B 级目标值）。本段**只补"套筒作为尺寸载体的规格化细节"，不改动上文任何设计原则、机理、参数表与经验教训结论**。

### 1. Land 高度体系：把"尺寸载体"落到可制造规格

| 结构 | 定义 | 屏孔 |
|---|---|---|
| **Pocket（凹坑）** | SAP 沉积区，对应 pattern | **仅此区开孔** |
| **Land（凸台）** | 所有需「无 SAP + 可与对侧粘合」的区域 | 无 |
| **端区（30–116 mm）** | **也是 land** —— 保证相邻两芯之间无 SAP | 无 |

- **床高 → land 高映射**：**160 gsm → 0.31 mm**；**230 gsm → 0.44 mm**（标称 **0.45 mm**）。
- **设计判据**：**land 高 ≥ 该 sleeve 自身床高**，使压合时**先由 land 接触（land-to-land）**，SAP 床不被过压；两侧 gsm 可以不同（如 **230 skin / 160 poly**），**各取自身床高**。
- ⚠️ **关键判定**：**land 高是逐片变量，不是全局常量** —— 0.45 mm 只是 **230 gsm 工况**的标称值；**160 gsm sleeve 的取值源文件未给**。

### 2. ⚠️ 床高 vs 松密度对账（上文待补项仍未闭环）

| 口径 | 值 |
|---|---|
| 由床高反推体积密度 | 160/0.31 = **0.516 g/cm³**；230/0.44 = **0.523 g/cm³**（**源文件内部自洽 ✓**） |
| SAP 规格松密度 | **0.62–0.70 g/cm³** |
| 用规格反算床高 | 160 gsm → **0.229–0.258 mm**；230 gsm → **0.329–0.371 mm** |
| **差距** | **约 20–35%**，方向为「实际床高比按松密度预测的**更厚**」 |

> ⚠️ **上文 Lesson 5 与本条的关系**：上文已把"床高 vs 松密度对账"列为 `[待验证]`。**本批仍未闭环**——只给出反推值、可能原因（自由堆积状态 / land 浮雕基准差异 / 两套假设独立得出）与影响（**若松密度真落在 0.62–0.70，床比设计更薄、land 相对偏高 → 压实余量变大**），**须用实测床高替代计算值**（STM-00305 / STM-4597 方法）。

### 3. ⚠️ 屏规格的两套口径（差约 2×，并列不合并）

| 来源 | 孔型 | 孔径 | 开孔率 | 层积 |
|---|---|---|---|---|
| **本方案（84 号 / One_Drum P9）** | 未注明 | **Ø0.6–0.8 mm** | **30–40%** | 未注明 |
| **既有 Nichidai 丝网口径** | **六边形孔** | **≥1.4 mm（下限）** | **60 / 70 / 80%** | **0.1 mm 层积蚀刻，有锥度方向** |

- **可能原因（未验证）**：面向的**成型机制不同**——Nichidai 为**传统整幅成型**（大孔高开孔率通过纤维/浆料），本方案为 **pattern-SAP 干法沉积**（小孔以在 land 边缘形成**锐利边界**、抑制 stray SAP）。
- **硬要求**：**22 片屏规格必须完全一致**——屏决定穿透风速与压损，任何差异都会让**同一 recipe 在换型后工艺窗口漂移**，从而**无法用单一 recipe 覆盖 11 尺寸**。
- **历史事故**：**锥度装反会导致 SAP 堵塞**（已发生）；因此**锥度方向是不可逆的装配依赖**，须纳入 ID 防错编码。

### 4. 公差体系与「等节距 = 同一相位适配全部」

| 项 | 公差 |
|---|---|
| Pattern 节距等距性 | **±0.02 mm over 2,771 mm**（全部 n 个节距） |
| 引脚相位 → 编码器零点 | **±0.02 mm（规格值）** |
| 换型后引脚实际相位 | **±0.05 mm（实操值）** |
| Sleeve 间索引重复性 | **±0.02 mm** |

- **机理**：若某 sleeve 的 n 个节距不等，则**无法用单一相位偏置把全部 n 个 pattern 对齐到对侧鼓**；而本架构的视觉闭环**只能整体 trim、不能逐 pattern 修** → 因此 **±0.02 mm 等距是结构前提，不是"精度越高越好"**。
- ⚠️ **±0.02 vs ±0.05 差 2.5 倍**（前者为制造+装配规格，后者为换型后整机实际分散）—— **是套准公差链的关键输入，未澄清前无法闭合**。

### 5. 防错：ID 粒度是本架构的隐含短板

- 源文件的防错只**阻止错误 ups 的 recipe**；但**同一 ups 组内有多个尺寸**（7-up 组含 Open NB/S/M + Pant L/XL/XXL/XXXL 共 7 个尺寸）。
- ⚠️ **若 ID 只区分 ups，组内尺寸错装不会被拦截**，而**后果与 ups 错装同级**（pattern 长度错 → 端区错 → 套准与切断全部失配）。
- **要求（本件推断，未与 PLC 供应商确认）**：**ID tag 须逐片唯一（22 个），编码 尺寸 + 侧别 + 版本**，且**未读到时 fail-safe 拒绝启动**；防错须同时覆盖 **skin/poly 装反**与**锥度装反**。
- ✅ **与上文 Lesson 4 呼应**：上文已指出"**静默失效排第一、对策必须是系统强制**"；本批把这一原则**具体到 ID 粒度**——**系统强制的前提是 ID 编码足够细**。

### 6. Skin / poly 成对规则（与上文 Lesson 3 呼应）

| 规则 | 内容 |
|---|---|
| R1 | 凡需粘合的通道**必须在对侧同位置存在** |
| R2 | **同一 CAD 文件设计一对并同时制造两片** |
| R3 | pattern 本身**可以不同**（skin ≠ poly） |
| R4 | **通道位置是成对的定义域；SAP 布局是各自的自由度** |

> **通道粘接成立 ⇔ (a) 两侧通道同位置存在 ∧ (b) 相位偏差在公差内**。若 (a) 不成立，**无论套准多好都无法粘合** —— 这是 **R2 不可替代**的原因，也是上文"**CD 必须靠机械精度锁死**"的另一面。

### 7. 换装工时口径分歧（30 倍）

| 口径 | 值 |
|---|---|
| 源文件（整片 sleeve 含承载体） | **≤15 min/鼓**，两鼓并行 |
| 既有 Nichidai 记录（仅丝网，卡簧快换） | **30 s/网** |

> ⚠️ 可能来自 (a) **换装对象不同**、(b) **是否含对相与验证**、(c) **供应商口径为纯动作时间**。**并列，不得择一。**

## 追加：Open Innovation 批（2026-09-29 追加 · 85 号套准公差链与 Cpk 体系）

> 追加来源 `[[85 双层pattern芯体套准工程规格]]`（2026-09-22 派生工程笔记，B 级仿真值 + 大量推断）。本段**只补"套准为什么是架构级质量门、误差预算如何分配"，不改动上文任何设计原则、机理、参数表与经验教训结论**。

### 1. 为什么套准是「失效即架构失效」的门（✅ 与上文 Lesson 3 同向）

- 本架构的**通道不是切出来的，而是两侧 land 对压粘出来的**（源文件 P7：*"raised lands bond channels in register"*）。
- **失效链**：错位 → land 与 land 不正对 → 通道粘接面积下降 → **润湿后开胶** → 通道丧失导流 → **本架构相对传统芯体的核心优势（湿态开孔、防凝胶阻塞）消失**。
- **推论**：套准是**唯一一个"失效即架构失效"的质量门**。

### 2. 公差与「≥90% 通道粘接面积」的换算（本件重构，须反验）

| 方向 | 规格 | 重构特征尺寸 | 量级 |
|---|---|---|---|
| **MD** | **\|MD\| ≤ 1.0 mm** | l = 1.0 / 0.10 = **10.0 mm** | MD 向 land 特征长 ≈ **10 mm** |
| **CD** | **\|CD\| ≤ 0.5 mm** | w = 0.5 / 0.10 = **5.0 mm** | 通道宽 ≈ **5 mm** |

> **模型**：重叠率 ≈ (特征尺寸 − \|δ\|) / 特征尺寸；允许 **10% 面积损失**。⚠️ **源文件只给端点结论（公差 → ≥90%），未给换算式** —— 本重构**须用 sleeve 图纸的 fishbone 骨宽/横肋长反验**；若量级不符，**0.5/1.0 mm 必须重新推导**。

### 3. 误差预算：由 Cpk 反解隐含 sigma（独立交叉验证）

| 方向 | ups | USL | Cpk | **σ_implied** |
|---|---|---|---|---|
| MD | 6-up | 1.0 mm | 2.43 | **0.137 mm** |
| MD | 7-up | 1.0 mm | 2.49 | **0.134 mm** |
| CD | 6/7-up | 0.5 mm | 1.39 | **0.120 mm** |

- **CD 是整线约束项**：MD 与 CD 的 **sigma 同量级**（0.134 vs 0.120），但 CD 的 Cpk 差得多，**纯粹因为 CD 的 USL 只有 MD 的一半**。
- **反解值与源文件自洽**：CD 失效率 = 2[1−Φ(0.5/0.120)] ≈ **31 ppm** → **in-spec ≈ 99.9969% ≥ 99.99% ✓**；MD 侧 ~10⁻¹³ 可忽略 → **in-spec 率 100% 由 CD 决定**。
- **MD 残差 82% 不在相机**：σ_cam = 0.1/√3 = **0.058 mm**，σ_other = √(0.137²−0.058²) = **0.124 mm** → **升级相机几乎无益**，须先量化 **σ_mat（材料/张力）与 σ_thermal（热漂移）**（两者今均缺）。
- **误差源状态**：σ_pin（±0.02 vs ±0.05，**口径冲突**）、σ_pattern（±0.02 mm over 2,771 mm）、σ_cam（±0.1 mm）已知；**σ_mat / σ_thermal / σ_cd 全部未量化**。

### 5. MD 自纠 / CD 钉死（✅ 深化上文 Lesson 3，未修正）

| | MD | CD |
|---|---|---|
| 偏差性质 | **一个相位标量**（对所有 n 个 pattern 同一偏置，前提是节距等距） | **一个轴向几何量**（硬件属性） |
| 可否伺服修正 | ✅ 叠加在 poly 鼓力矩电机（1/n rev + trim），**纯软件** | ❌ **无轴向伺服轴** |
| 视觉覆盖 | ✅ UV 相机读 skin 侧（胶含 UV 示踪剂） | ❌ **开环量** |
| 收敛 | **~17 片（≈1 s）** | **必须一次做对** |

- **附带推论（可辨识性）**：**只在 poly 侧 trim** —— 若两侧都修，**一个观测量对应两个自由度 → 解不唯一**。固定 skin 为基准是把 2 DOF 降为 1 的必要手段。
- **工程结论**：CD 公差链"一次做对、事后不可补救" → 必须 (a) 作**到货验收项**、(b) 设计阶段**预留收紧**、(c) **不把 CD 期望寄托在视觉升级上**。

| 数值 | 场景 |

## 追加：Open Innovation 批（2026-09-29 追加 · 81 号：ups 选型方法论与端区判据）

> 追加来源 `[[81 Forming Drum Ups Selection（鼓距·端区·11 尺寸分配）]]`（2026-09-22 派生工程笔记，B 级一阶模型值，Gap G1）。本段**只补"鼓距/端区从哪来、为什么选 Ø882 + 6/7-up"，不改动上文任何设计原则、机理、参数表与经验教训结论**。

### 1. 五式：ups 是唯一杠杆的推导链

| 式 | 关系 | 中文 | 因果含义 |
|---|---|---|---|
| (1) | **P = πD / n** | 鼓距 = 周长 ÷ ups | 一圈鼓面等距容纳 n 个 pattern |
| (2) | **rpm = ppm / n** | 转速与 ups 成反比 | **换 ups 就必须改转速**的根源 |
| (3) | **v = P × ppm / 1000** | 鼓面线速 | **ups 一变、线速必变** → 86 号 SAP 落料速度须重设 |
| (4) | **t_deg = 166.667 / rpm** | 每度时间 | 停留时间的换算基准 |
| (5) | **a/g = (2π·rpm/60)²·(D/2)/9.80665** | 离心场 | 决定 SAP 落料后是否被甩飞，真空设定的力学依据 |

> 与上文「鼓距 461.8 / 395.8 mm、鼓速 166.7 / 142.9 rpm、表面速度 462 / 396 m/min、离心场 13.7 / 10.1 g」**逐项一致 ✓** —— 上文表格是这五式在 Ø882 上的取值。

### 2. 端区判据：30 mm 是「下限」不是「目标」

- **定义** `E = P − L_pattern`（式 6）；端区在 sleeve 上即 **land**（不开孔、不上 SAP），对应 84 号的 land 体系。
- **物理来源（两项取大者）**：① **端封**——芯体两端须有无 SAP 的 land 供包覆 land-to-land 压合封端，防 SAP 端部逸出；② **切断**——切刀须在相邻两芯的净空区下刀。
- **方向性（易错点）**：端区越小 → 包覆浪费越少 → 越省材料。**故端区要"贴着下限走"，不是"做大"** → 选型规则 = **取满足 E ≥ 30 mm 的最小鼓距**（n 由小到大试，取第一个使 E ≥ 30 的 n）。

### 3. A / B / C 三方案与否决理由（上文未记的落选路径）

| | **A（推荐）** | B | C |
|---|---|---|---|
| 鼓径 / 周长 | **Ø882.0 / 2,771 mm** | Ø889 / 2,792.9 mm | Ø1,014 / 3,185.6 mm |
| ups | **6-up + 7-up** | 6-up + 8-up | 7-up + 9-up |
| 端区均值 | **52 mm** | 76 mm | 69 mm |
| 否决理由 | — | **pants（355–365 mm）落在夹缝区**：Ø889/8-up（349.1 mm 鼓距）装不下 → 退 6-up（465.5 mm），**每片白扔 100–110 mm 包覆** | **鼓径越出 800–900 mm 硬窗口** |

- ⚠️ **源文案勘误**：源写「9 of 11 sizes ≤ 42 mm」，但同页又写「只有 NB/S/open L 三个长」；按 P5 表逐项重算 **≤42 mm 者为 8 个、>42 mm 者 3 个** → 「9」应为「**8**」，**以数据表为准**。

### 4. ⚠️ 最紧一档：Pant XL/XXL/XXXL 余量仅 0.8 mm（本批新增风险）

- **E = 395.8 − 365 = 30.8 mm**，仅比判据高 **0.8 mm（2.7%）**，是全方案最紧的一档，且是 **Pant XL 转 7-up 后仍合格的唯一原因**。
- **sleeve 图纸公差本身不构成威胁**（±0.02 mm over 2,771 mm）；**真正的风险在芯长/pattern 长度侧的产品公差** —— 若芯长规格为 **365 ±1 mm**，上偏差侧 **E = 29.8 mm < 30 mm，判据失效**。
- **闭合校核式**：`E_min = P − (L_nom + tol_upper) ≥ 30 mm`；若不能闭合，只能 (a) 三尺寸退回 6-up（端区变 41.8 mm，需重算 repitch 与浪费）或 (b) 放宽 30 mm 判据并给出端封/切断的替代方案。
- 等级：**推断**（式 6 的敏感性分析，未实测）；源件未提示该风险。

### 5. 端区 ↔ 包覆浪费：量级结论（修正"端区是主成本"的直觉）

- 单片浪费 `W = E × W_core × gsm_wrap / 10⁶` → 方案 A 逐规格 **37 – 116 mg/片**（SMS 10 gsm，CD 100/110/120）。
- **相对单片 SAP（4.5–11.6 g）占比 <1%** → **在方案 A 内部，端区不是包覆材料的主成本项**；真正为此付代价的是方案 B（pants 100–110 mm 端区 ≈120 mg/片且同时损失产能）。
- ⚠️ 口径：上式为「按鼓距放卷、端区全部留存」的**上界**；实际还取决于 chip trim 是否切除端区（NB/S 切 56/22 mm 后回到 60 mm 端区，见 82 §5）。

### 6. 可外推的一般结论

> **多规格共鼓的主要代价不在尺寸跨度，而在尺寸在鼓距网格上的落点。** 任何尺寸族若在「某 ups 的鼓距」处形成聚集（本例 pants 355/358/365 聚在 10 mm 带内），会集体被推向相邻 ups 而产生**系统性浪费**。

## 追加：Meeting Minutes 批（2026-09-29 追加 · FOCUS 真空成型工程实验）

> 本节为 **S5_Areas_Meeting Minutes_01 批次** 编译时的追加记录，**不改动上方既有结论**。本批提供的是**一次工程可行性实验（FOCUS）** 的一手结论与未验证项。

### 1. Process conclusions 工艺结论

- **成型方式**：**forming on the substrate（在基材上成型）+ 受控均匀真空**；与部分 OEM 的「shift」方式相比，**chamber 方式更好** —— 它给 SAP 提供了成型空间，对 SAP 分布的均匀性更有利。
- **真空条件**：约 **20+**（单位 `[待验证]`）的真空可支持 **1,200 ppm** 的车速；约 **200 GSM**（对应约 6 g SAP）在该条件下跑通。
- **SAP loading 的甜点区**：约 **190 GSM** 时分布、channel 强度与手感最好，**CV 优秀**；**超过 190 GSM 后 CV 明显漂移**，片间差异变大，forming 已不稳定。
- **施胶方式比胶量更关键**：胶喷在**布上 vs SAP 上**、**spiral 小螺旋 vs summit vs signature** 对 **free SAP** 影响极大；由 signature 改为 **summit** 后 **pad integrity 明显改善**。胶量可由 10+ GSM 降到单层约 **6 GSM**（双层约 12 GSM）。
- **可成型形状边界**：圆弧形可做，**尖角形做不到**（尖角处 SAP 分布不均）。

### 2. Open engineering risks 未验证的工程风险

- **高速下的三项未知**：① SAP 克重漂移（400 / 450 / 500 m/min 各是多少）；② 圆形大盘承接 SAP 时 **free SAP 比例在高速下的波动**；③ **单一成型鼓在高速下最大能 hold 住多少 SAP 添加量**。
- **pattern 复杂度 → 工艺风险**：ND/CD 方向 **registration** 挑战；air-knife 的 on/off 频率（如 6 次 × 800 片）与 SAP 流尾、solar valve / 气吹频率是否匹配 —— **待验证**。
- **胶枪布置**：若把胶枪放进腔道内，清洗与防污染问题未解。
- **长期运行**：污染与磨损情况**从未评估**。
- **实验性质声明**：本实验**不是 performance / mass production qualify 实验**，**未做 R（重复性）**，结论只作工程方向参考。

## 追加：Meeting Minutes 批（2026-09-29 追加 · COCO V6 code 1–9：开孔孔径均匀性与裆部加密的机理边界）

> 来源：[[COCO V6 Trial Code Design & Process Alignment（录音纪要 2026-08-17）]]（2026-08-17 ASR 转写）。本批只**追加**机理边界与设备能力限制，不修改既有结论。

**核心机理（本批新增，属讨论中的判断，非已验证结论）：**

1. **开孔孔径全域一致 → 改 shape 不等于裆部加密**：现有芯体机 forming screen 的开口（screen 密度/孔径大小）在全域是一致的，并未按裆部把 airflow 做得更大。跌落辊跌落速度不变、单位时间从跌落辊跌落的 SAP 量不变的前提下，改变 screen 的 shape（如大扇尾/哑铃形）只是把**平均** SAP 密度重新分配到新形状上，并不会把更多 SAP 密度分配到 crotch（裆部）。
2. **若要裆部加密，原则上的工艺条件**：forming 开孔孔径在 notch（裆部）处**大于**两端正常尺寸，才可能产生更高的局部线密度。这一点为工艺侧原理判断，⚠️ **现有芯体机无能力验证** → 标 `[待验证]`。
3. **密度稳定性是性能的前置条件**：性能与稳定性相关，而芯体机精度不足以判定局部密度。判据示例 —— 中部若能稳定在约 380 则 OK；若在 360–400 之间来回波动，则数据只具有趋势意义，**不足以支撑结论**。
4. **鼓上密度调整必须单独开鼓**：code 3/4/5 因需整体调 SAP 密度（鼓上密度），无法与只改花型的 code 共用同一个鼓 → 这构成实验排程的硬约束（可合并的 code 组合必须让鼓上密度一致）。

**本批新增参数表：**

| Item 项目 | Value 数值 | Note 备注 |
| --- | --- | --- |
| screen 开孔孔径 | 全域一致（未按 crotch 差异化） | 限制裆部定向加密 |
| 跌落辊跌落速度 | 一致（不随 shape 变） | 单位时间下料量不变 |
| 中部密度稳定性判据 | 稳定 ≈380 → OK；360–400 波动 → 仅趋势 | [待验证]，芯体机精度不足 |
| 裆部加密的前提条件 | notch 开孔孔径 > 两端 | 现有设备无法验证 |
| code 3/4/5 SAP add-on | 上下层各 6.8 g（code 3）；6 g 起（code 4/5） | 需单独开鼓 |

## 追加：Meeting Minutes 批（2026-09-29 追加 · SAP 输送距离与颗粒破碎的因果关系）

> 来源：[[Precision Rotary Die & Module Supplier Review — Stretch Cutting, SAP Dosing & Layer Config（公司介绍与业务交流）]]（供应商交流会 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**问题诊断（本批新增）：**

现行布置为「**SAP 先在某单元计量 → 再输送**」，该组合被判定为**两个关键问题的根因**：

1. **输送过程中 SAP 颗粒破碎**（particle breakage）—— 因输送摩擦所致；
2. **计量偏差**（inconsistent dosing deviation）—— 由材料在到达目的地前的行为不一致造成。

**改进方案（本批新增）：**

| Item 项目 | 改进内容 | Note 备注 |
| --- | --- | --- |
| 思路 | 把**混合位置前移**，使混合在更靠近下游处发生 | — |
| 输送距离 | 缩短至约 **2–3 米** | 原距离更长 |
| 预期收益 | 显著减少颗粒破碎 + 计量更精确一致 | — |
| 状态 | **本月起全面安装与测试** | — |
| 数据 | ⚠️ **没有实测数据**，仅"理论上成立" | 本方已明确追问，对方无数据 |

**待决（本批新增）：**

- 改造后能否**保证同样的 SAP 投加速率（dosing rate per second）** —— 本方提出，对方未给出结论。
- 落地产线编号为 **TJ 21** [待验证]。

**实践含义（本批新增）：**

1. **SAP 输送距离是一个独立的设计变量** —— 它同时影响颗粒完整性与计量精度，而这一点在只看"成型鼓参数"时容易被忽略。
2. **"缩短距离"这类改进是可先行的低成本动作** —— 但它必须有实测数据闭环，不能停留在"理论上应减少损伤"。
3. 颗粒破碎会同时伤害**吸收性能**（粒径变化）与**计量一致性**，是成型段的隐性质量瓶颈。

## 追加：Resources/Open Innovation 批（2026-09-29 追加 · 2026-07 IPC FEI & OI：真空即模板、Particle Sizer 与多鼓分摊）

> 来源：[[Patterned SAP Core 6（印花·分区·成形 SAP 芯体开发目标与收益 · 2026-07）]]（IPC FEI & OI，2026-07）。

1. **第一性原理的最简表述** —— 「**SAP only allocated on area where has vacuum**」：**有孔有风 ⇒ 有 SAP；无孔无风 ⇒ 无 SAP**。因此**洁净通道是"没落上去"的结果，不是压出来的**；花型与通道**同一工艺同时得到**。
2. **定量是连续量而不是档位** —— 「More air flow leads to more SAP, less air flow results in less SAP」：**同一套成形鼓即可实现 MD 分区 / CD 分区 / MD+CD 复合分区 / 图案**（all-in-one）⇒ **分区 know-how 落在风量分布与孔型设计，而非机械换型**。
3. **可控真空的来源是三件套** —— **成形风机 + 变频（inverter）与磁耦合（magnetic coupling）+ Nichidai 网技术**；各真空段压力**可在环内（in-loop）由 SAP 重量传感器与压力传感器实时调节**。
4. **网的硬限制被量化** —— **当前能力下最小孔心距 0.14 mm**；路线为**支撑蚀刻**与**多层层压蚀刻网**；相对 **Innovent 带框网**的优势是**开孔面积更大**。
5. **COV 的头号机理是颗粒自身的不均一（Particle Sizer Effect）** —— 「**Denser particles travel further than lighter ones, destroying targeted basis weights**」。两条对策：**① 窄粒径分布（Narrow PSD）SAP 对 COV 友好得多**（材料侧）；**② 单鼓 SAP 添加量越小越易控**（设备侧）。**据此，"定量偏差"应首先在 PSD 上找原因，而不是先怀疑计量装置。**
6. **多鼓分摊是高速化的结构性解法** —— **固定整片总定量**的前提下用 2–3 个鼓分摊，**每鼓添加量变小 ⇒ 气流精度更易保证 ⇒ 高速下 COV 改善**；**第三鼓可专用于高装载定点分区**。代价是**多鼓同步**与**套准**成为新风险。
7. **两种 SAP 错峰被写进设备规格** —— 双 poly 侧 SAP 计量系统的目的明确是**不同溶胀速度以规避凝胶阻塞**；**设备能力直接服务于吸收机理**。
8. **"去绒毛浆"不等于"零绒毛浆"** —— HCH 方案在 poly 侧保留 **40 gsm / 约 1.2 g 每片**绒毛浆，**功能是 MD 分布加速器（增加毛细）而非吸收**。
9. **节材量级值得单独立项** —— **单片省 1 g SAP**，在 **800 PPM、日产 1,152,000 片、利用率 75%、年产 311,040,000 片**下 = **单线年省 311 吨**。**这是把"少放一点 SAP"从成本项升级为结构创新收益项的换算**（⚠️ 1 g 为假设输入，非实测）。
10. **产业能力分层** —— 本国供应商 **Chuanyue** 已交付 **100 m/min** 演示线（KC 天津平台），但**用类 Innovent 常规网 + 自设计成形鼓，不掌握 Nichidai 网技术**；中试能力：**单层 SAM 定量 50–300 gsm、喷幅 50–280 mm（图注另写 70–280 mm）、喂入精度 ±2.5%**。**"能做出图案"与"能高速稳定地做出图案"是两代能力。**
11. **REL 同形模切是收益与加工的正面冲突** —— 图案 SAP **理想上要求 REL 同图案模切**（保留通道 → 尿液分布 + 透气 + 视觉线索 + 便于 LSN/PSN 通道压花）；但**蓬松热风粘合材料**带来**切断质量差、修边排废真空不足、CD 收缩与张力不稳**三大问题，**双调速真空辊能否抵消张力偏差效果未知**。
12. **落料方式仍是未收敛的岔路** —— **chute / 喷管**（需更大真空）vs **SAP 重力瀑布式落料**（**更小真空、更高精度**）；这条选择直接决定 **100% SAP 图案成形能否跑高速**。
