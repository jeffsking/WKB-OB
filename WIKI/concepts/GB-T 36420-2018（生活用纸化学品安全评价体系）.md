# GB/T 36420-2018（生活用纸化学品安全评价体系）

> 一句话定义：生活用纸与纸制品企业的**化学品/原料安全管理评价体系标准**——管的是「流程与台账」而非法定限值；其资料性附录给出 2018 年代的建议性化学品禁用/限用清单，是 GB 43631-2023 强制限值出台前最系统的卫品化学品参考底表。

## 机理 / 结构拆解

1. **体系闭环七环节**：供应商评价（MSDS 或 CAS 级成分清单）→ 企业内部安全评价小组逐项评估 → 合格清单 + 使用工艺文件 → 采购验收（COA 核验 + 抽检）→ 贮存/领用登记 → 使用记录 → 可追溯 + 年审。
2. **原料红线（3.2.2.2.1）**：纸巾纸、厨房纸巾、卫生巾、纸尿裤、湿巾**禁回用原料**；卫生纸/擦手纸可有条件回用（禁废弃生活/医疗/包装用纸来源，印刷品须脱墨）——GB 43631-2023 回料禁令的前身。
3. **附录定位（资料性/建议性）**：禁 CMR 与剧毒/有毒类（欧盟 R 危险组表述）、致癌芳胺染料；工艺化学品禁 APEO；湿巾另禁 MIT/MCI。限值清单按产品族分表。
4. **与 GB 43631-2023 的关系（关键）**：36420 是**建议性管理基线**，43631 是**强制性法定下限**；两者数值存在版本差（见下表），**以 43631 为合规终裁，36420 作体系与预警参考**。

## 关键参数表 Key Parameters（建议性限值 vs 强制限值差异）

| 指标 | GB/T 36420-2018 附录（建议） | GB 43631-2023 表 1（强制） | 差异判定 |
|---|---|---|---|
| 湿巾甲醛 | ≤20 mg/kg | ≤6 mg/kg | **收紧 3 倍+**，以 43631 为准 |
| 纸尿裤甲醛 | ≤20（婴儿）/≤75（成人）mg/kg | ≤6 mg/kg | **大幅收紧** |
| 湿巾邻苯 DBP+BBP+DEHP | 未单列 | ≤0.0012% | **43631 新增强口径** |
| 纸尿裤邻苯 DBP+BBP+DEHP | ≤0.1% | ≤0.1% | 一致 |
| 丙烯酰胺（湿巾） | ≤0.1 mg/kg | ≤0.1 mg/kg | 一致 |
| 1,4-二噁烷（湿巾） | ≤30 mg/kg | 未列 | 36420 独有（建议） |
| 溶剂四项（湿巾） | 各 ≤20 mg/kg | 各 ≤20 mg/kg | 一致 |
| 湿巾防腐剂 | 苯氧乙醇 ≤1.0%、IPBC ≤0.01%（禁婴儿湿巾）、氯己定 ≤0.3%、聚氨丙基双胍 ≤0.3%、苯扎氯铵 ≤0.1% | MIT/MCI 不应检出；其他按化妆品规范 2015 | 36420 给了**具体浓度**参考 |
| 二辛基锡（纸尿裤） | ≤0.1%（以锡计） | 未列 | 36420 独有（建议） |
| 生效状态 | 2019-01-01 实施；2026-09-29 记录：生效中 | 2025-01-01 实施；2026-09-29 记录：生效中 | — |

> ⚠️ 上表「一致/差异」仅为**数值对照**，两文件法律属性不同（GB/T 推荐性 vs GB 强制性），合同引用时必须写明依据哪个文件。
