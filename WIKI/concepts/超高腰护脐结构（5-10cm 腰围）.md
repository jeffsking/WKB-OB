# 超高腰护脐结构（5-10cm 腰围）Super-High Umbilical-Protecting Waistband (5–10 cm)

## Definition 定义

把裤型腰围高度抬高到 **5–10 cm**（常规腰围「到不了肚脐」），配合内/外腰围均复合氨纶丝（20–50 根），使腰围上沿覆盖肚脐；再在内腰围中部复合**护脐贴**（水刺布喷涂中药草植物提取液，烘干后短切 25–100 cm²，热熔胶贴合）。卖点逻辑：保暖防受凉 + 有效成分穿戴中持续挥发、经肚脐吸收（保健宣称）。

## Key parameters 关键参数（CN 117379257 A，逐字）

| Parameter 参数 | Value 数值 |
|---|---|
| 腰围高度 | 5–10 cm |
| 氨纶丝根数（内/外腰围各） | 20–50 根 |
| 护脐贴材料 | 水刺布 + 中药草植物提取液 |
| 护脐贴面积 | 25–100 cm² |
| 固定方式 | 热熔胶复合于内腰围中部 |
