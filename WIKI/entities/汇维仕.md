# 汇维仕（Huvis）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | 三大产品线：**LMF**（低熔点聚酯纤维，普通聚酯 + 改性低熔点 Co-PET 共轭纺丝）、**Hygiene bico**（Purever，皮芯烯烃类低熔点，PE/PP 或 PE/PET）、**MINIMAX**（切断短纤，MINIMAX-A 以 Hygiene bico 制空气铺网） |
| 产地 / 基地 | 韩国全州；中国（四川汇维仕）；美国；研发中心大田 |
| 产能 | **年产能约 60 万吨纤维材料**；约 709 名员工（2025） |
| LMF 规格 | 纤度 2/4/6/10/15 dtex，切断 32~102 mm，熔点可选 **110/130/150/180/200 ℃**，光泽 SD/棕/米/红；LMD 4/6 dtex、38~64 mm、熔点 110/150 ℃；RMF 结晶耐热 4dtex/64mm/164℃ |
| 市场地位 | 韩国聚酯纤维（短/长纤）市占第一；**2024 年全球市占率约 20%**（双组份低熔点纤维）；早期中国高端低熔点复合纤维的主要进口供应方之一 |
| 在本库中的角色 | CoPET 供应基盘中的**全球龙头 + 价格上界参照**；本批采购文档将其标为「高价预警」对象 |

> ⚠️ **口径要点（原文明确）**：Hygiene bico 系列（Purever）为 **PE/PP 或 PE/PET 烯烃 ES，不是 CoPET**；只有 **LMF 才是 Co-PET/PET 低熔点粘结纤维**。询价与对标时不可混用。

## 合作与供货历史

- **2026-07-09（背调）**：在两份 CoPET 供应基盘背调中被列为韩国最大化纤及差别化纤维企业之一，明确生产销售 CoPET/低熔点聚酯皮芯双组分纤维及 ES 类热粘纤维。详见 [[CoPET 供应基盘背调汇总（26 家企业·联系方式版）]]。
- **2026-07-09（市场与供应商）**：列入全球/海外头部（双组份纤维成品商）——"全球领军，2024 市占约 20%；MINIMAX 为卫材 bico 短切纤维（airlaid）"。详见 [[CoPET 双组份热粘合纤维市场与供应商（供应链分层·明细表）]]。
- **2026-07（采购蓝图）**：在 [[CoPET 采购蓝图：成本拆解与供应分层]] 的 Layer A 诊断中被标为 **「High-Price Warning（高价预警）」**——质量与地位确立，但携带最高的进口溢价。
- **2026-07（ADL 转型蓝图）**：在 [[CoPET ADL 转型蓝图（皮层聚合物替代评估）]] 的供应层级图中列入 Tier A，并作为价格带上界出现。
- **2026-07-09（应用）**：LMF 强调环保（110 ℃ 即可热粘、替代胶粘剂）与"优良粘结/混合/成型/弹性恢复"；下游含床垫、土木/建筑（隔音隔热）、卫生材料（纸尿裤/卫生巾）粘合、绗缝/填充、汽车内饰、过滤器。

## 价格与商务要点

> ⚠️ 商务敏感信息只记要点与区间，不落完整价格表。每条标注记录日期。

- **记录日期 2026-07**：本厂 CoPET 低熔点纤维处于**国产/进口价格带的上界**——进口区间约 9,500–11,000 元/吨，高端/特殊熔点档位更高；相较国产下沿（约 8,900）溢价明显。→ 详见 [[CoPET 与 PET 成本差异对比（2026 年 7 月）]]。
- **记录日期 2026-07**：采购文档的核心判断是——**国产替代窗口已开**：国内 A 层专精厂（盐城/嘉兴）+ B 层切片（桐昆）放量后，在成本与交期上占优；缩小价差的可操作路径是**把量从进口转向国内专精厂**。→ 详见 [[CoPET 采购蓝图：成本拆解与供应分层]]。
