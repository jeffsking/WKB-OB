# LUGH Liner Program（LUGH 面层项目）

## 基本盘 Basics

| 项目 Item | 内容 Content |
|---|---|
| 定位 | 与 [[GRIFFIN Rewet Program（GRIFFIN 超低回渗项目）]] 并行的**面层（liner）降回渗**项目，同属 Depend / 成人失禁品类回渗改善管线 |
| 技术方向 | 以 **Fibertex** 纺粘（SB）面层替代现方案，并评估克重与表面活性剂/柔软体系（surfactant/softness package）两个变量 |
| 关键节点 | HUT 结果已回 → 2025-08-28 ACLT 决定继续推进的面层 → 三阶段认证 → **2026 年 1 月上市** |
| 推荐方案 | **12 gsm 带印花（12gsm with print）** |
| 角色 | 本库"面层克重—柔软度—回渗"三者取舍的证据来源 |

## 试验记录 Test Records

| 变量 Variable | 结果 Result | 备注 Note |
|---|---|---|
| **12 gsm Fibertex SB vs 对照** | 回渗低于对照，但**幅度随测试而异**：R25-0274 0.44→0.35；R25-0491 0.36→0.33；R25-0927 0.28→0.25 | 方向可复现、幅度不可复现 |
| **14 gsm Fibertex SB** | **更柔软，但回渗高于 12 gsm 对照** | 原因是**克重更高** |
| 克重—柔软度冲突 | **无法在降低克重的同时保持柔软度** | 明确记录的取舍 |
| **表面活性剂/柔软体系变更** | 14 gsm Fibertex 回渗由 **0.41 → 0.28 g**，与对照 0.28 g 持平 | 160% TL13、639 g RC、Fem Lar DPU2 ATCA 条件 |

## 关键取舍 Trade-off

> **克重 ↑ → 柔软度 ↑ 但回渗 ↑**；**克重 ↓ → 回渗 ↓ 但柔软度 ↓**。破局点不在克重而在**表面活性剂/柔软体系**——更换体系后 14 gsm 也能做到与对照同水平回渗（0.28 g），说明**表面化学是独立于克重的第二杠杆**。
