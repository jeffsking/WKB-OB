# Rengo Nonwoven Products

## 基本盘 Basic profile

| 项目 | 内容 |
|---|---|
| 官网 | www.rnp.co.jp |
| 角色 | 电气石（tourmaline）功能纤维三方架构中的**日方伙伴**：与 K-C、闽瑞（Minrui）共同持有/开发该技术 |

## 技术方案 Technology

| 项目 | 内容 |
|---|---|
| 技术内容 | 与日本伙伴联合开发的功能纤维技术——将**细磨电气石掺入树脂基纤维** |
| 应用 1 | 早产儿（IPC）床垫：技术接近 ready，量有限 |
| 应用 2 | 纸尿裤 / 一次性卫生用品：量大，但需进一步材料优化 |
| 三方架构 | K-C + Minrui + 日方伙伴；KC 寻求**婴儿卫生与一次性卫生品类的排他** |
| 排他触发 | **以"技术可用性确认"触发**，而非合同签署触发 |
| 近期动作 | 先签 MOU 明确排他、保密、范围与限制，同时推进材料验证；验证通过后再签正式 JDA |
| 签约主体建议 | **APAC 实体**（覆盖现有与未来应用的地域范围） |
