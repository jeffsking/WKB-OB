# 美鑫达（XDM）

> 品牌标识：XDM 美鑫达™；产品线商标为 MXD™。资料来源仅为本批两份技术数据表（TDS），企业基本信息（注册地、产能、成立时间）**本批未涉及**，标 `[待验证]`。

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | 可生物降解 **PGA（聚乙醇酸）树脂** |
| 产品线 | **MXD™ G-100**（注塑 + 挤出）、**MXD™ G-101**（注塑） |
| 产地 / 基地 | `[待验证]`（TDS 未标注） |
| 产能 | `[待验证]` |
| 包装 / 储运 | 铝箔袋密封，建议仓库环境 **< 25 ℃** |
| 认证 | 工业堆肥 + 家庭堆肥（**DIN Geprüft**，编号 7W0814；另有 **BPI** 标志） |
| 在本库中的定位 | **可堆肥无纺布路线的 PGA 候选来源**（作高熔点芯层）；同时是 PGA 材料参数的一手锚点 |

## 合作与供货历史

- **（TDS 版本 rev1，发布日期未标注）**：本批首次入库 G-100 TDS，明确其「可直接用于注塑与挤出加工，也可与其它可降解材料共混改性以提升机械强度、阻隔性能与降解性」——即供应方将其定位为**独立加工树脂 + 共混改性组分**双重用途。
- **（日期未标注）**：G-101 TDS 入库，定位为同族**高流动性注塑牌号**（MFR 20~40），熔点、密度、水分、弯曲强度、缺口冲击与 G-100 完全一致。
- **（方案侧引用，日期未标注）**：在 PPC-P 基 TABCW 皮芯纤维方案中，PGA 被列为**芯层候选材料**（约 220 ℃、刚性、易纺、海洋可降解、FDA 认证），成本口径记「低于 RMB 20 / kg」。见 [[PPC&PGA 基无纺布开发方案（第二版）]]。
