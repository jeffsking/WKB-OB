# Formosa Plastics（台塑）

> 一句话定位：SAM/SAP 的**候选供应商**，成本与可持续选项兼具，但源文明确标注其 **OTIF（准时交付）不可靠**，且多数牌号**需重新配方**。（中文：便宜，但交付与配方适配是两道硬门槛。）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | SAM 牌号：BC283FAN、BC283GAN、BC283HA、BC283UT、BC383GA、BC388SDA、BC586G、BC683G (OC)、BC8002、BC8010（Sheet 1）；BC583FAK / BC283GAN / BC283HA（Global v2） |
| 在用品种与使用地区 | **BC583FAK** — Taiwan；**BC283GAN** — Mexico；**BC283HA** — China / Indonesia / India |
| K-C 使用标记 | **BC283HA → FC**；**BC283FAN → AC** |
| SAM type | Balanced（BC283FAN / BC283GAN / BC283UT）；High Capacity（BC283HA / BC388SDA 等） |
| 角色 | 候选（非"Current Grade"） |

## 关键事实（均注日期）

- **2025（数据库年份待验证）**：性能取值（Sheet 1）——BC283GAN CRC 34 / AUL 16 / GBP 11 / Vortex 76；BC283HA CRC 41 / AUL 8 / **GBP 0** / Vortex 50；BC283UT CRC 33 / AUL 21 / GBP 18 / Vortex 60；BC586G CRC 31 / AUL 24 / GBP 20 / Vortex 60。
- **2025**：**替换含义**——BC583FAK 与 BC283GAN 标注 **Requires Reformulation（需重新配方）**；BC283HA 标注 **Increased add-on required（需提高添加量）**。中文：**均非 drop-in**。
- **2025**：强项记为 **Cost** 与 **Has sustainable option**；机会与风险记为 **Quality**、**Unreliable (OTIF)**、**Innovation**。
- **2025**：Global v2 中 BC283FAN 记为 CRC 32 / AUL 12（AC 口径，KCC-YJ 表）；BC283HA 记为 CRC ~32（Mexico 口径）——**同一牌号跨表数值不一致，照录不合并**。

> ⚠️ **并列记录（2026-09-29）**：源文同时把台塑的强项列为 Cost，又把 **OTIF 明确标为 "Unreliable"**——**成本低与交付不可靠并存**，本页照录，不裁决其对采购决策的净影响。
