# Intellego Technologies AB

## 基本盘 Basics

| 项目 Item | 内容 Content |
|---|---|
| 主营 | 基于**光致变色（Photochromic）**技术的颜色指示器；产品含**湿敏指示器（Wetness Indicator，用于纸尿裤）**、UVC 剂量计（验证紫外线消毒）、UV 指示器（SmartSunBand，防晒与健康监测） |
| 性质 | **瑞典上市科技公司**（股票代码 **INT**） |
| 产地 / 基地 | 瑞典；在**印度**等地设有生产设施 |
| 产能 | 未公开具体产能；**据财报 2025 年 Q2 净营业额约 2.17 亿瑞典克朗，正为卫生用品行业大幅扩充印度工厂产能** |
| 角色 | 变色油墨供应基盘中的**国际标杆**梯队（与 [[CTI（Chromatic Technologies Inc.）]]、[[Matsui Shikiso (松井)]] 并列），适合顶级卫品品牌 |

## 合作与供货历史 Cooperation History

- **2026-06-12（[[Hygiene Chromic Ink Supplier Landscape（卫生护理变色油墨供应商调研 · 2026-06-12）]]）**：被列为全球卫生护理变色油墨 7 家核心供应商之一，属国际标杆梯队；主要客户为国际知名纸尿裤制造商、医疗消毒服务提供商及相关代工厂。
- **2026-06-12（同上）**：报告记录其**正为卫生用品行业大幅扩充印度工厂产能**——是本库可见的、唯一有明确扩产动作的变色油墨国际供应商。
