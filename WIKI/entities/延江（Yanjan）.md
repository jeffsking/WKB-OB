# 延江（Yanjan）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | 卫材面层与复合纤维：PE/PET 双组分（ES）纤维、面层网材（Liner） |
| 产地 / 基地 | 本批交付站点为**天津**与**川越**（Chuanyue/Chunayue） |
| 产能 | 未在本批来源中出现 `[待验证]` |
| 角色 | **COCO V6 试产 Liner 的指定供应商**；2D / 4D Bico PE/PET 纤维提供方（三叶形 3D 由福地提供） |

## 合作与供货历史

- **2026-09-11**：在 COCO V6 试产原料准备会中被列为四大供应商之一（Yanjan / Minrui / Nuoer / Unikorn），负责 Liner 三个方案——**Code 1（50 gsm）**、**Code 2-A（30 gsm，优先）**、**Code 2-B（30 gsm，视异型纤维样本量）**。详见 [[COCO V6 试产原料准备会（英文版，2026-09-11）]]。
  - Code 1 构造：上 25 gsm = 10% 三叶形 + 90% 2D Bico PE/PET；下 25 gsm = 50% 三叶形 + 50% 4D Bico PE/PET；入口宽 102 mm。
- **2026-09-18（ETA）**：Code 1（>100 m）到天津；Code 2-A / 2-B（各 6 km，宽 82 mm）到川越。
- **2026-09 试产实测**：Liner-1（Yanjan Code 1，标称 50 gsm）实测 adv 均值——**基重 45.222 gsm、厚度 1.721 mm、STT 0.874 s、返渗 0.0382 g、层间剥离强度 115.276 N、pH 7.112**。详见 [[CI-06 COCO V6 第三轮试产测试结果]]。
  - Code 2-A（川越）在数据导出时**仍未到货、未测试**。
- **项目侧**：在 [[IPC BCC OI 项目清单 2026 v2（2026-09-17）]] 中对应 **OI-25 Liner Nonwoven Development**（"ATB dual-card 50 gsm；30% trilobal MD grooves"）与 **OI-04 PVA/PTT REL (COCO V6)** 的放大环节；2026-09-18 中文汇报稿记其为 OI-25「基材/2D/4D ES」与 OI-04「放大」。

## 追加：Meeting Minutes 批（2026-09-29 追加 · 延江材料在韩国卫生巾项目上的负反馈）

> 来源：[[Low-GSM Pulp-Meltblown Core Wrap Review — Strength, Dual Colour & Cost（尿裤包覆层材料探讨）]]（供应商现场交流 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论；内容为**第三方转述**，非延江自述，可信度按中等处理。

**转述要点（本批新增）：**

- 韩国金佰利（Yuhan-Kimberly 系）用**延江**的同类熔喷-木浆复合材料做了一款**妇女卫生巾**的形体材料（ASR 作"形体/芯体"）[待验证]。
- 反馈的两个问题：① **强力相对来说还是不太够**；② 生产过程中的**克重稳定性不太好**。
- 该韩国客户知道本次交流的供应商也做同类产品，**已拿其材料在测试**（切换/二供评估中）。
- 上下文：延江的**结构与本次供应商的结构不一样**（同为低克重复合路线，但构型不同）。

✅ **验证记录（2026-09-29）**：以上为竞争/同行供应商在会上的转述，**未经延江或韩国客户确认**，属二手信息；引用前须回溯原文。参见 [[Coform Composite Nonwoven（熔喷-木浆复合非织造）]]、[[Meltblown Nonwoven（熔喷非织造布）]]。

## 追加：Meeting Minutes 批 2（2026-09-29 追加 · 作为双梳理打样方的角色与排产约束）

> 来源：[[V6 & Be Max Materials Alignment — Profiled Fibre, Colour Spunbond & SAP Layering（录音纪要 2026-08-06）]]（K-C 内部项目对齐会 ASR 转写，2026-08-06）。本批只**追加**，不修改既有结论。

**角色（本批新增）：** 延江（ASR 作「岩浆 / 沿江」）被安排承担**第一梳理、第二梳理的打样**（即 ATB 双梳理面层的分层铺设），本方的异形纤维方案确定后"直接丢给婷婷去延江打样"。

**排产约束（本批新增）：**

- 打样时间 **2026-09-21** 已定；进口纤维（南京提供）最快 **8 月底 / 9 月初** ready → **只能赶 9 月 20 日那一轮**。
- 因此必须**尽早给延江打样方案**，并确认纤维用量，才能让纤维提供方备足量。

**供应商选择上的纠结（本批新增，反映延江的定位）：**

- 本方原排的是延江，但**巴西项目的 code list 用的是俊富 / 冠宏 / 华龙**；从操作难度上"找一家搞定会简单一点"。
- 但延江被视为"**未来目标的供应商**"，且商业化的成本约束下，"延江、大源这些……他应该核算过成本，不太行"。
- 结论未定，留待次日与相关方开会决定。

✅ **验证记录（2026-09-29）**：以上为会中讨论；"延江核算成本不太行"为**转述判断**，非延江自述 [待验证]。参见 [[ATB双梳理面层（Dual-Card Topsheet）]]、[[三叶形截面纤维（Trilobal Fibre）]]、[[COCO芯体平台]]。

## 追加：Meeting Minutes 批 3（2026-09-29 追加 · 作为"高成本面层来源"的降本动因）

> 来源：[[Be Max Platform — Trilobal Fibre Ratio, Ultrasonic Bonding & MD Distribution Target（纤维加工温度与成本验证）]]（跨团队技术交流，英文 ASR 转写，会议日期 [待验证]）。本批只**追加**，不修改既有结论。

**降本动因（本批新增）：**

- 会中明确："**currently we are buying lots of the expensive liner from the Yanjan**" → 目前**大量从延江采购较贵的面层（liner）**。
- 因此 Be max 平台（异形纤维 + 超声波 bonding）的一个明确目标是：**为成本敏感国家提供比"买延江面层"更低的成本路径**。
- 该项目由 **FBI 团队与开放创新团队**共同推进；目标市场提到**巴西**（预计 **2028** 采用）。

**由此得到的定位（本批新增）：**

- 延江在本方的供应版图中是**高性能 / 高成本**的一极 —— 其面层被当作**成本基准（benchmark）**来对比，而不是低成本来源。
- 这与本页此前记录的"延江核算成本不太行"（商业化成本约束下）互相印证：**延江的成本竞争力是其在成本敏感市场落地的主要障碍**。
