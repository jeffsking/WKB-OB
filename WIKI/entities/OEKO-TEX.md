# OEKO-TEX（国际环保纺织品协会）

## 基本盘

| 项目 | 内容 |
|---|---|
| 性质 | 由 18 个国际检测和认证机构组成的协会 |
| 总部 | 苏黎世 |
| 主营 | 面向纺织品/化学品/工厂的多标签认证体系 |
| 在本库中的角色 | 卫生用品出口合规的**第一优先认证**来源机构 |
| 官网 | oeko-tex.com |

### 旗下标签体系

| 标签 | 核心定位 | 卫生用品场景适用性 |
|---|---|---|
| STANDARD 100 by OEKO-TEX | 对最终产品及其每个组件做有害物质检测；覆盖 100+ 项指标 | **最常用**于无纺布面层、婴儿纸尿裤整体认证；欧洲婴儿产品市场的事实准入基准 |
| LEATHER STANDARD | 针对皮革制品 | 不适用 |
| STeP by OEKO-TEX | 工厂级认证（Sustainable Textile and Leather Production），六大模块 | 适用（与 bluesign 定位部分重叠） |
| MADE IN GREEN | 产品级溯源标签，须基于 STANDARD 100 和/或 STeP | 适合面向欧洲终端消费者的品牌产品 |
| ECO PASSPORT | 纺织化学品（染料、助剂、整理剂）认证 | 适用于向 STANDARD 100 认证工厂供应助剂的化工企业 |

## 合作与供货历史

- **2026-09-27（记录日期）**：据 [[卫生用品认证体系完全指南]]，STANDARD 100 的限值通常比 REACH 更严格、领先法规 1–3 年；**每年更新限值（通常 4 月发布）**，2023 年版本新增了更多 PFAS 和双酚类物质。有效期 1 年，须每年更新检测并支付年费；配方或供应商变更时须重新评估是否需补充检测。

## 关键规格要点

> 以下为认证技术要求要点，均来自 [[卫生用品认证体系完全指南]]。

| 维度 | 说明 |
|---|---|
| 测试物质覆盖 | 100+ 项，涵盖 PFAS、重金属、甲醛、农药、邻苯二甲酸酯、荧光增白剂、偶氮染料等 |
| 产品分级 | Class I（婴幼儿 0–3 岁）/ Class II（皮肤直接接触）/ Class III（非皮肤直接接触）/ Class IV（装饰材料）——**纸尿裤属 Class I** |
| 认证单元 | 须对产品**每个组件**分别认证，不能只认证整体而跳过组件；整体标签须所有组件均通过 |
| 有效期 | 1 年 |
