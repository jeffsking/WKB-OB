# 宁波大发（宁波大发化纤）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | 低熔点皮芯复合短纤维（low-melt PET 鞘层 / 聚酯芯层）；再生涤纶短纤（100+ 规格） |
| 产地 / 基地 | 浙江宁波（余姚 / 慈溪 / 杭州湾）；占地约 30 万 ㎡ |
| 产能 | **总产能约 15 万吨/年**（7 条国内线）；员工 1,100+；总资产约 6 亿元 |
| 规格 | 低熔点 4080：鞘层改性低熔点 PET **熔点约 110–180 ℃**、芯层普通 PET **约 256–260 ℃**；常见 2D/51 mm、4D/51 mm |
| 技术资产 | 2023.6 新产品"**2~4D×51mm 芯层为再生聚酯的低熔点皮芯复合短纤维**"列入宁波重点工业新产品；行业标准《低熔点聚酯(LMPET)/再生聚酯(RPET)复合短纤维》主要起草单位 |
| 市场地位 | 中国再生涤纶短纤龙头之一；低熔点皮芯复合短纤（含再生 PET 芯）技术领先，环保循环属性突出（废旧纺织品醇解再生） |
| 在本库中的角色 | **"再生 PET 芯 + 低熔点 PET 皮"路线的国内代表**，正是本批提出的降本杠杆（rPET 芯）的现成能力位点 |

## 合作与供货历史

- **2026-07-09（背调）**：在两份 CoPET 供应基盘背调中被列为"明确生产"——低熔点皮芯复合短纤维（low-melt PET 鞘层/聚酯芯层），典型 low-melt PET 粘结纤维。详见 [[CoPET 供应基盘背调汇总（26 家企业·联系方式版）]]、[[CoPET 供应基盘背调汇总（布局核实精简版）]]。
- **2023-06**：新产品"2~4D×51mm 芯层为再生聚酯的低熔点皮芯复合短纤维"列入宁波重点工业新产品。
- 应用领域（来源口径）：无胶棉、软/硬质棉（热粘非织/填充）、汽车内饰、沙发家具填充、床上用品、仿丝棉、隔音板、棕榈床垫、毛绒玩具；**偏填充/家纺/汽车内饰**，非纸尿裤 ADL 主线 `[待验证]`。
