# 赛得利（Sateri）

## 基本盘

| 项目 | 内容 |
|---|---|
| 主营 | 纤维素纤维（莱赛尔等） |
| 产地 / 基地 | 常州、南通、山东（均有项目落地） |
| 莱赛尔产能 | **60 万吨**（本库当前来源口径）；山东 60 万吨项目**一期已投产** |
| 角色 | 国产莱赛尔**量最大**的一家；国产替代的主力供给方 |
| 品牌线 | 优可丝、纤生代、赛得利莱赛尔（三条） |

## 合作与供货历史

- **2026-09-18（原文发布日）**：据 [[天丝为什么突然这么难买]]，赛得利是国产莱赛尔产能最大的一家，量上已具规模。
- **技术方向**：行业媒体指出莱赛尔最大的应用瓶颈在**染整环节**，赛得利在这一块做了**底层技术突破**。原文评价「这个方向是对的，因为莱赛尔真正难的地方一直不在纺丝，在染整」。
