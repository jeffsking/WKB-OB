# EP 0 776 645 A1 Disposable Diaper with Visual Wetness Indicator (Unicharm)

## One-line positioning 一句话定位

**尤妮佳（UNI-CHARM CORPORATION）的欧洲专利申请**（EP 0 776 645 A1，公开日 1997-06-04）。它回答的是一个**被忽略的工程问题**：湿显指示做出来了，**尿液怎么 reliably 到达指示层？** 解法是三层结构——**亲水基片 + 含二氧化硅/氧化铝的显色第一涂层 + 含同类无机粒子的遮蔽第二涂层**，干态靠**光散射**呈白色把图案"盖住"，湿态散射被抑制、遮蔽层变透明，图案**显出本色**。配套的关键工艺约束是**热熔胶必须间断涂布、不含油分、覆盖面积 ≤ 图案面积的 70 %**，且基片留 **≥10 mm 未粘合边**。

## Abstract 摘要（逐字摘录）

(54) **Disposable diaper with visual wetness indicator**。
(57) 逐字要点：一次性尿裤设有**指示器（18）**，其在被排出的尿液润湿时**显形（revealed）**，以告知母亲婴儿已排尿。该指示器（18）包含**亲水基片（21）**、形成于基片（21）一面、**在指示器（18）被尿液润湿时显现其本色（develop its proper colour）**的**第一涂层（19）**，以及形成于基片（21）另一面或第一涂层（19）上表面、并**间断地粘合到背层（3）内表面**以**遮盖第一涂层（19）**的**第二涂层（22）**；**第二涂层（22）在指示器（18）被尿液润湿时变为透明**。

### Problem / solution 问题与解法

| Item 项目 | Content 内容 |
|---|---|
| 指出的在先技术 | **日本实开平 3-58416**（Japanese Laid-open Utility Model Application No. Hei3-58416）：在背层内表面设变色层 + 覆盖其上的着色渗透层 |
| 在先技术的问题 | ①指示层做在**疏水聚乙烯膜**上，**尿液难以润湿**指示层及其周边；②若用亲水胶把指示层粘到吸收芯上，**没有能满足尿裤高速生产节拍的快固化胶**；③聚乙烯背层**不吸收颜料**，印刷后需长时间干燥，**严重限制生产效率** |
| 本案解法 | ①指示层做在**亲水基片**上，与背层**分开制造**（原文明确"不影响生产率，因为指示器可由独立于尿裤主制造工序的工艺制造"）；②基片留 **≥10 mm 未粘合边**，可变形并保持与芯体接触；③或**波纹状（undulated）**结构——波峰触芯、波谷粘背层；④或芯体开**高密度沟槽**把尿快速导到远处指示器 |

## Key claims 关键论断

- **这是"显形"而不是"变色"**：干态两层都因**无机粒子光散射**呈白，图案被"盖住"；湿态散射被抑制 → 遮蔽层透明 → 图案**显出本色**。整条链路**不依赖 pH 指示剂或无色染料体系**，与 [[Wetness Indicator Glue]]（pH/树脂溶解型）和 [[Water-Activated Ink（水变／湿变油墨）]] 是**三条不同的物理化学路径**。→ [[Light-Scattering Masking Wetness Indicator（光散射遮蔽型尿湿指示）]]
- **真正的发明点在"如何让尿到达指示层"**：说明书用了大量篇幅讲**未粘合边 ≥10 mm**、**波纹结构**、**芯体高密度沟槽**三招。这与本库 [[Diaper Microclimate]] 讨论的"把内部状态可靠地传出去"是同一类工程难题。
- **一个容易被忽略的工艺地雷**：用于粘接的**热熔胶本身会让遮蔽层变透明**（相当于"误报"）。故要求 **间断施胶 + 无油分 + 覆盖 ≤ 图案面积 70 %**。这是把"胶"当作**潜在失效源**来设计，值得转化端注意。
- **"不影响生产率"是明确的权利要求级主张**：原文说指示器可由**独立于主线的工艺**制造，直接回应了在先技术的干燥瓶颈。→ 与 [[Wetness Indicator Ladder（尿湿指示阶梯）]] 中"图案化/载量仪表"路线相容（本案图案可为花卉图案或整面涂层，权 5、权 6 允许多个第一涂层间断排列）。
