# Nanocellulose Technology Roadmap for Hygiene Materials（纳米纤维素卫材应用技术路线图 V1）

## 一句话定位 One-line Positioning

本批**纳米纤维素（nanocellulose）在卫材领域的方向筛选与分阶段落地总纲**：把三大类材料（CNF/CNC/BC）映射到八大应用方向，用可行性-价值矩阵排出梯队，并给出三阶段实施与风险应对。是本库回答「纳米纤维素先做哪个方向、什么时候做、卡点在哪」的主索引。

## 摘要 Summary

路线图 V1.0（2026-05-13，来源标注为 bryan tang 前期探究 + WB 技术评估）先定义材料：CNF（纤维素纳米纤丝，宽 5–50 nm、长微米级，成膜性好、保水强）、CNC（纤维素纳米晶体，宽 3–20 nm、长 100–500 nm，结晶度高、力学强度优）、BC（细菌纤维素，纳米纤维网络，纯度极高、生物相容性好）。核心优势列为五项——可再生可降解、比表面积 50–200 m²/g、拉伸强度可达 GPa 级、表面羟基丰富易改性、生物相容。行业驱动力归纳为「去绒木浆化、超薄化、可持续化、功能化、成本优化」五条。

八大应用方向按优先级排布：**方向一 SAP 增强**（第一优先级；CNF/CNC 作物理交联点或共聚组分，提高凝胶强度、减少回渗 Rewet）、**方向二 Foaming Core / ADL / 半芯体**（第一优先级；泡沫稳定、导流锁液、部分替代绒毛浆）、**方向五 亲水涂层 / Core Wrap / SMS 涂层**（第一优先级；投入小见效快，可替代 PE/PP 膜做全可降解方案）、**方向四 增强粒子→超薄无纺布**（第二梯队；先从热轧切入再向 SMS 进阶）、**方向七 水凝胶防侧漏大坝**（第二梯队；自适应密封、零压迫感）、**方向三 Lotion 分散剂**与**方向六 护肤品载体**（第三梯队）、**方向八 三联结构改性／智能功能性尿裤**（远期储备）。综合评级把方向 1/2/5 列入第一梯队（Q2–Q3 立即启动）。

实施分三期：Phase 1 快速验证（Q2–Q3 2026，涂层小试 + SAP 联合小试 + 热轧无纺布试生产目标减薄 10%）、Phase 2 中试（Q4 2026–Q2 2027，半芯体放大、水凝胶原型、Lotion 兼容性）、Phase 3 产业化准备（Q3 2027 起，Pilot 量产 + PCT 专利布局 + 锁定长期供应协议）。风险表列出供应（CNF 产能有限、优质供应商少）、成本（CNF $5–20/kg vs 绒浆 ~$1/kg）、技术（分散均匀性）、法规（婴儿用品认证周期长）、IP（竞对先行布局）五类，并给出应对策略。末章给出按方向的供应商适配表（含直径 <30 nm、羧基 <0.5 mmol/g、结晶度 >80%、模量 >140 GPa、固含量 1–3%、稳定期 >6 月等参数需求）。
