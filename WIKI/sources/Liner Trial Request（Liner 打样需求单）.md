# Liner Trial Request（Liner 打样需求单）

## 一句话定位

延江（厦门延江）Liner 打样的正式需求单，定义三组 Code 的克重配比、幅宽与卷材规格，是三叶草异形纤维在面层的应用落地依据。

## 摘要

Liner 打样需求单，向延江提出三个 Code 规格。**Code 1（50 gsm）**：上层 25 gsm（10% 三叶草截面纤维由 KC 提供 + 90% 2D Bico PE/PET 由延江提供）、下层 25 gsm（50% 三叶草 + 50% 4D Bico PE/PET），幅宽 102 mm，卷材 3" core、卷径≤700 mm。**Code 2-A（30 gsm，优先方案）**：上层 15 gsm（10% 三叶草 + 90% 2D Bico）、下层 15 gsm（50% 三叶草 + 50% 4D Bico），幅宽 82 mm，芯管长 ≤600 mm、卷径 ≤700 mm。**Code 2-B（30 gsm）**：具体取决于异型纤维的用量。整体呈现明显的「上层少量异形、下层大量异形」配比策略。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注（口径 Caliber） |
|---|---|---|
| Code 1 总克重 | 50 gsm | 上层 25 + 下层 25 |
| Code 1 上层配比 | 10% 三叶草 + 90% 2D Bico PE/PET | 三叶草由 KC 提供，Bico 由延江提供 |
| Code 1 下层配比 | 50% 三叶草 + 50% 4D Bico PE/PET | 异形含量显著高于上层 |
| Code 1 幅宽 | 102 mm | 卷材3" core、卷径 ≤700 mm |
| Code 2-A 总克重 | 30 gsm（优先） | 上层 15 + 下层 15 |
| Code 2-A 上层配比 | 10% 三叶草 + 90% 2D Bico | — |
| Code 2-A 下层配比 | 50% 三叶草 + 50% 4D Bico | — |
| Code 2-A 幅宽 | 82 mm | 芯管长 ≤600 mm、卷径 ≤700 mm |
| Code 2-B | 30 gsm | 取决于异型纤维的用量 |

## 关键论断（key_claims）

- Code 1：50 gsm——上层 25 gsm（10% 三叶草截面纤维 KC 提供 + 90% 2D Bico PE/PET 延江提供）、下层 25 gsm（50% 三叶草 + 50% 4D Bico PE/PET）；幅宽 102 mm
- Code 2-A：30 gsm（优先）——上层 15 gsm（10% 三叶草 + 90% 2D Bico）、下层 15 gsm（50% 三叶草 + 50% 4D Bico）；幅宽 82 mm
- Code 2-B：30 gsm，具体取决于异型纤维的用量
