## Positioning 一句话定位

A technical review matrix for biodegradable through-air nonwovens: a PPC/PBAT sheath evaluated against four core polymers (PET / PLA / PGA / PLGA) across five dimensions, with a layered-bet strategy and a six-item verification清单. （中文：可降解热风无纺布的技术评审矩阵——PPC/PBAT 皮层对四种芯层（PET/PLA/PGA/PLGA）的五维评估、分层下注策略与验证清单。）

## Summary 摘要

The document converts the "make through-air nonwoven biodegradable" goal into an **architecture choice**: keep the sheath as the bonding medium (and the certified compostable fraction) and select the core for the balance of process window, spinnability, shelf life, degradation narrative and supply. The decisive parameter is **ΔTm between core and sheath** — the core must survive spinning while the sheath melts and flows in through-air bonding at 120–145 °C.

Recommended structure: **PPC/PBAT sheath + PLA core as the volume line** (tunable Tm, safe shelf life, available fibre grades), **PPC/PBAT + PGA as the premium line** (seawater degradation story, shelf-life verification first), **PLGA as a tuning lever/pre-research**, and **PET core only as a backup** (most stable process, halved environmental claim).

### 关键物性与 ΔTm Key thermal data

| Core 芯层 | Tm | ΔTm vs 皮层 | Note 评价 |
| --- | --- | --- | --- |
| PET | 255–260 °C | ~130 °C | 窗口最宽、芯层最安全；但纺丝温度 ~280 °C，皮层有高温降解风险，需小试验证汇合区停留时间与皮料分子量保持 |
| PLA | 155–170 °C（D/L 比例可调） | 30–60 °C | 旋光比精调熔点（PDLLA 无定形 → PLLA 170 °C → sc-PLA 230 °C），可按需定制 ΔTm；熔体温度更低，对皮层热冲击更温和 |
| PGA | 高（库内无纤维级 TDS 数值） | 待核 | 无熔点调节杠杆；信息缺口：需纤维级 TDS |
| PLGA | 单体比例可调 | 可调 | 降解速率可连续调控，但熔点/结晶行为随组成变化复杂，工艺开发量最大 |

### 货架期/水解 Shelf life and hydrolysis

| Core 芯层 | Behaviour 水解行为 | Risk 风险评估 |
| --- | --- | --- |
| PET | 不水解 | 无风险（但也不降解） |
| PLA | 结晶区挡水，水解慢；PDLLA 无定形态 3–6 个月快水解 | PLLA 高结晶 = 天然货架期保护；**12–24 月货架期基本安全** |
| PGA | 家族最快：海水 28 天降解 **75.3%**；缝合线体内 2–4 周失强 | 干态仓储无水不水解，但高湿海运/南方梅雨须做加速老化（**40 °C/90% RH × 4/8/12 周** CD 拉伸保持率） |
| PLGA | 介于两者之间，随 GA 比例加快 | 需按具体配比验证 |

### 可降解叙事 Degradation narrative

| Core 芯层 | Claim 口径 |
| --- | --- |
| PET | 不降解；芯层占 50–60%，环保卖点被砍半，只能讲「皮层部分可降解」 |
| PLA | 堆肥 **180 天（58 °C 工业堆肥）**；土壤 1–3 年、海水极慢——「需要工业堆肥」会被自然降解认证挑战 |
| PGA | 海水 28 天 **75.3%**，家族最快，可作差异化数据；瞄准欧盟 2028 法规方向与「可自然降解」认证 |
| PLGA | 可调——在 PLA 芯中掺 GA 单元给「降解速度」做梯度 |

### 皮层通用风险（四芯共担）Shared sheath risks

1. **粘合点内聚强度**：拉伸 10.6 MPa / 伸长 162%，PPC-P 相增脆，粘结点强度与柔韧性大概率低于 PE 皮；小试须做 CD 拉伸对标，门槛 **9.0 N/50 mm**。
2. **维卡 60.2 °C 仓储风险**：夏季集装箱 50–60 °C 时皮层先软，布卷层间粘连；需 **60 °C × 72 h** 卷材模拟验证。
3. **亲水整理重做**：表面化学从聚烯烃换成聚酯族，现有亲水剂配方体系不适用。
4. **PPC 在皮内占比建议 ≤20%**：无定形无清晰熔点，摊宽熔融窗口、降低粘合一致性。
5. **Delta T 管理**：热风设定温度与实际温度差须逐线实测，找「强度够用的最低加工温度」。

### 分层下注策略 Layered bet

| Tier 层级 | Structure 方案 | Positioning 定位 |
| --- | --- | --- |
| 主线（量产） | PPC/PBAT 皮 + PLA 芯 | 熔点可调、货架期安全、供应链现成；韧性靠 PBAT 皮 + 芯层 PLA/PCL 共混兜底 |
| 高端线 | PPC/PBAT 皮 + PGA 芯 | 「海水 28 天 75%」极致降解叙事，出口欧洲高端/限量；前置货架期验证 |
| 调节杠杆（预研） | PLGA 梯度 | PLA 芯内掺 GA 单元连续调控降解速率 |
| 对照/备份 | PPC/PBAT 皮 + PET 芯 | 工艺最稳但环保叙事打折；仅当 PLGA/PGA 验证失败时保留 |

### 验证清单 Verification list（方法学）

1. 皮料粘合点对决：LX-T55 皮 + 各芯 vs 标准 PE/PET ES，同工艺热风，比 CD 拉伸、剥离强度、粘结点 SEM——对标 **9.0 N/50 mm**；
2. 皮料高温耐受：各芯层纺丝温度工况下皮层分子量保持（IV/GPC）——决定 PET 芯路线是否可行；
3. PGA 芯货架期加速老化：40 °C/90% RH × 4/8/12 周 CD 拉伸保持率 vs PET 芯对照；
4. 仓储模拟：60 °C × 72 h 卷材层间粘连 + 粘合点强度保持；
5. 亲水剂适配：聚酯表面润湿持久性（多次穿透后接触角）。

## Key Claims 关键论断

1. **ΔTm is the governing variable ΔTm 是支配变量** — 芯层必须在纺丝温度下存活、皮层必须在热风 120–145 °C 下熔融流动；PLA 因旋光比可调熔点而成为唯一「可定制 ΔTm」的芯层。
2. **PLA core is the volume answer PLA 芯是量产答案** — 工艺窗口 ★★★、纺丝 ★★★、货架期 12–24 月安全、纤维级牌号现成；短板只在降解叙事（需工业堆肥）。
3. **PGA core trades shelf life for narrative PGA 芯用货架期换叙事** — 海水 28 天 75.3% 是最强差异化数据，但必须先用 40 °C/90% RH 加速老化证明仓储可行。
4. **PET core halves the environmental claim PET 芯把环保卖点砍半** — 芯层占 50–60% 且不降解，只能讲「皮层部分可降解」。
5. **The sheath, not the core, decides bondability 决定粘合性的是皮层** — PPC-P 增脆（10.6 MPa / 162% vs 纯 PBAT >600%）把 CD 拉伸 9.0 N/50 mm 变成硬门槛，且维卡 60.2 °C 引入仓储粘连风险。
6. **Biodegradability changes surface chemistry 可降解化改变表面化学** — 聚烯烃 → 聚酯族意味着现有亲水剂体系整体失效，须重做配方与持久性验证，见 [[亲水整理耐久性]]。
7. **PPC ≤20% in the sheath PPC 皮内占比 ≤20%** — 无定形无清晰熔点会摊宽熔融窗口、降低粘合一致性。
