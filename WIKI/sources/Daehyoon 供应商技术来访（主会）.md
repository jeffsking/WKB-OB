# Daehyoon 供应商技术来访（主会）

## 一句话定位

韩国供应商 Daehyoon 的主会技术来访纪要，核心议题是旋转刀具 + 拉伸开孔（pinhole）工艺的可行性，及该工艺在 YK 产线的既有验证状态。

## 摘要

KC 团队与韩国供应商 Daehyoon 就旋转刀具 + 拉伸 + 开孔（pinhole）工艺展开技术交流。KC 侧询问工艺可实现的最小孔尺寸（当前示例为 6×9 mm，疑似 6 mm×9 mm），并提出 liner 某些区域需要 die cut 大孔、另一些区域需要小孔的分区需求（一半一半或 40% 大孔 + 60% 小孔）。供应商确认有不同设计，并提到 KC 也开发过张力控制模块或 T-channel 模块，因此可提供完整解决方案。供应商澄清该工艺不是一次完成——后端也做第二次拉伸，可在第二次拉伸时微调总张力。关键商业背景：供应商与 Yuhan Kimberly（YK）关系紧密，YK 占其业务近 50%，与 KC Global 业务很少、KC China 目前无实际业务。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注（口径 Caliber） |

| 第二次拉伸 | 后端另做（数值转写不清：5%、70%？） | 可在第二次拉伸时微调总张力 |
| 模块化拉伸量 | 约 10% | 供应商确认 KC 提到的模块 10% 拉伸 |
| YK 占供应商业务 | 近 50% | KC Global very little，KC China 无实际业务 |
| KC IPC 覆盖区域 | 韩国、大中华区、澳大利亚、新西兰、印尼 | 通过开放创新机制引入已验证工艺 |

## 关键论断（key_claims）

- 供应商与 Yuhan Kimberly（YK）关系紧密，YK 占其业务近 50%；与 KC Global 业务很少，与 KC China 目前无实际业务
- 旋转刀具 + 10% 拉伸开孔 + 复合工艺已被 YK 产线验证；KC 中国正在评估类似开孔/拉伸工艺但 pattern 未定
- 该工艺不是一次完成：后端也做第二次拉伸，可在第二次拉伸时微调总张力
- KC IPC 团队希望通过开放创新机制，把该供应商在 YK 已验证的工艺/模块能力引入韩国、大中华区等IPC 国家
