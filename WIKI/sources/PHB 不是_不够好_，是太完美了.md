# PHB 不是_不够好_，是太完美了

PHB 不是"不够好"，是太完美了
作者: 绿塑分子社
发布时间: 2026年8月3日 20:00
发布地点: 北京

S1E02 细菌塑料工程笔记 · PHA 第一课
一条不断链的因果链：分子结构 → 单体选择 → 代谢通路 → 原料采购

PHA 家族的分类轴不是化学家画的，是合成酶的底物特异性画的。这就是为什么在 PHA 这里，"选材料"和"选原料"从来不是两个决策——它们是同一个决策。

为什么这个问题重要

上一期我们停在一个颗粒上。这一期要处理的是一个更实际的问题：当你需要一种柔性 PHA 时，你到底在选什么？

大多数人以为这是个牌号问题——翻一翻手册，找一个断裂伸长率够高的型号。但如果你真的走完采购流程，会发现事情不对劲：能提供柔性 PHA 的供应商很少；报价比 PHB 高出一截；而且几乎所有人都在告诉你同一句话——"我们的产能受原料影响"。为什么一个高分子的力学性能，会和原料供应绑得这么死？这一期就是回答这个问题。答案会从晶体学一路走到期货市场，中间不断链。

一、先破一个执念：PHB 的问题是"太完美"

行业里习惯说"PHB 有缺陷"。这个说法方向就错了。

PHB 的分子链，几乎是高分子化学能想象的最理想状态：
第一，立构完美。 上一期讲过，PHA 合成酶严格 (R)-立体专一，所以生物合成出的 PHB 是百分之百全同立构。工业上通过 Ziegler-Natta 或茂金属催化剂苦苦追求的立构规整度，细菌不费力就做到了极致。
第二，序列完美。 均聚物，单一重复单元，链上没有任何化学不规整点。

这两条加起来的结果是：链段可以毫无障碍地折叠进晶格。于是结晶度可以爬到 55–80%，球晶长得又大又完整。

而对力学性能来说，这是一场灾难：

完美之处 / 直接后果
全同立构 + 均聚 / 结晶度 55–80% → 硬、脆（新鲜样断裂伸长率 6%~12%）
高结晶 + 成核密度低 / 球晶尺寸大 → 球晶界面成为裂纹源
Tg 约 4 ℃，室温高于 Tg / 二次结晶持续进行 → 存放数周后降至 2%~5%
Tm 175–180 ℃，热降解显著起始约 200 ℃ / 加工窗口仅二三十摄氏度

请注意第三行：同一个样品，放几周，断裂伸长率掉一半以上。这不是测试误差，是二次结晶在室温下持续进行的结果。所以本系列有一条铁律——任何 PHA 力学数据，不标存放条件即无效。

常规高分子有三把破坏规整性的刀：调立构、加共聚单体、引支化。PHA 一上来就被没收了第一把——立构规整度由酶锁死，无法调节。这句话值得停一下。它意味着 PHA 的全部改性史，本质上是一部想尽办法引入化学缺陷的历史。第二把刀（共聚）成了主战场，第三把刀（支化/扩链）是加工端的补救。

别再说"PHB 不够好"。准确的说法是：PHB 太完美了，完美到不能用。

二、分类轴是酶画的：scl / mcl / lcl 的真实含义

教科书给的分类是按碳数：
scl-PHA（短链，C3–C5）：3HP、3HB、4HB、3HV、5HV
mcl-PHA（中链，C6–C14）：3HHx、3HO、3HD、3HDD
lcl-PHA（长链，>C14）：罕见，基本停留在文献层面

问题是：C5 和 C6 之间，为什么要划一条线？化学上并没有什么突变发生在这里。

答案在酶上。这条线是 PhaC 底物结合口袋的尺寸画出来的：

合成酶类别 / 代表菌 / 亚基构成 / 底物偏好 / 实际产出
Class I / Cupriavidus necator / PhaC 单体 / scl / PHB、PHBV、P34HB
Class II / Pseudomonas spp. / PhaC1 / PhaC2 / mcl / mcl-PHA
Class III / Allochromatium vinosum / PhaC + PhaE / scl / —
Class IV / Bacillus megaterium / PhaC + PhaR / scl / —

一个 Class I 合成酶，喂它 C6 底物，它基本不接受；一个 Class II 合成酶，喂它 3HB-CoA，掺入率极低。碳数分界，本质是一个酶学分界。

硬推论：想做 scl 与 mcl 单体的共聚物（如 PHBH），第一步不是调发酵，是先解决合成酶的底物特异性。事实上，PHBH 之所以能走到量产，前提就是找到并利用了一类底物谱较宽、能同时接受 3HB-CoA 和 3HHx-CoA 的合成酶，把它装进产量更高的底盘菌里。（具体菌株与酶来源留到 S2E01。）

酶工程拓宽底物口袋，至今仍是 PHA 材料创新最上游的闸门。记住这一点——本期后面所有的"能"与"不能"，源头都在这里。

三、被忽略的第二个轴：羟基在第几位

碳数不是唯一变量。真正被普遍忽略的，是羟基位置。

对比两个单体的主链结构：
3-羟基丁酸（3HB）：重复单元 —[O—CH(CH₃)—CH₂—C(=O)]—，主链每单元 4 个原子，带一个甲基侧基
4-羟基丁酸（4HB）：重复单元 —[O—CH₂—CH₂—CH₂—C(=O)]—，主链每单元 5 个原子，没有任何侧基

一个羟基位置的挪动，带来两个变化：主链变长、侧基消失。结果如下：

PHB (P3HB) / P4HB
羟基位置 / C3 / C4
侧基 / 甲基 / 无
Tm / 约 175–180 ℃ / 约 60 ℃
Tg / 约 4 ℃ / 约 -51 ℃
断裂伸长率 / 新鲜6%-12%; 存放数周后2%-5% / 约1000%（压制膜）
材料属性 / 硬而脆 / 高韧性热塑体，接近弹性体
产业地位 / 难以独立成材 / PHA家族中唯一拥有成熟植入级临床应用的成员

同一个家族。一个羟基位置的差别。从"敲上去会碎"，到"拉伸十倍不断"。

但请注意样品形态：P4HB 约 1000% 的断裂伸长率，对应的是压制膜。同一材料做成取向纤维后，断裂伸长率反而降到 10%–100% 量级。这不矛盾——取向让分子链沿受力方向排齐，用伸长率换来了强度。这恰恰是它能做成可吸收缝线的原因：缝线要的是强度，不是能拉多长。

所以"P4HB 的断裂伸长率是多少"这个问题，没有唯一答案。压制膜与取向纤维的两组数据不可混用。不标注样品形态的力学数据，在 PHA 这里一律无效。

这张表同时说明了三件事：
"PHA 很脆"这个说法本身就是错的——脆的是 PHB，不是 PHA。
柔顺性的来源不止一个：降结晶度是一条路，改主链拓扑是另一条路。P4HB 走的是后者。
医用领域为什么偏偏选中 P4HB——不只因为它柔，还因为它的降解产物 4-羟基丁酸是哺乳动物体内已有的内源性代谢物。

顺带纠一个常见错误：不要以为"碳数越大越柔"。P4HB 是 C4，比 C6 的 3HHx 共聚物柔得多。碳数与羟基位置是两个独立的轴，不能互相替代。

四、核心物理：第二单体能不能进晶格

既然必须靠共聚引入缺陷，问题就变成：加什么共聚单体？加多少？

行业里普遍的直觉是"加得越多越柔"。这个直觉是错的，而且错得很有代价——1980 年代第一次 PHA 商业化尝试，很大程度上就栽在这个直觉上。

真实的规律只有一条：第二单体能否进入 PHB 晶格，决定了共聚有没有用。能进 → 与 3HB 共结晶 → 结晶度维持高位 → 增韧效果远低于预期。被排斥 → 作为链缺陷阻断结晶 → 结晶度真实下降 → 增韧有效。

而能不能进，有一条相当好用的经验规则：侧链 ≤ 乙基 → 可被部分容纳；≥ 丙基 → 被排斥。（有文献支持；4HB 属另一机制——主链长度失配，即使无侧基也被排斥。实际是否共晶还受组成、结晶条件与序列分布影响。）

代入三个主力体系：
体系 / 第二单体 / 侧链 / 是否进晶格 / Tm 随组成 / 结晶度 / 增韧
PHBV / 3HV / 乙基 / 部分共结晶（同晶现象）/ 先降后升，赝共熔点约 30 mol% HV / 全组成维持高位 / 远低于预期
PHBH / 3HHx / 丙基 / 排斥 / 单调显著下降 / 显著下降 / 有效
P34HB / 4HB / 无侧基，主链失配 / 排斥 / 单调下降 / 随组成连续可调 / 有效，可调幅宽

关于 PHBV 的"同晶现象"：这是整个 PHA 材料学里最反直觉的一个现象。3HV 的乙基侧基虽然比甲基大，但仍小到可以被 PHB 晶格部分容纳。低 HV 含量时，3HV 单元可部分进入 PHB 晶格；高 HV 含量时反过来，3HB 单元进入 PHV 晶格。两侧晶型在中间某个组成附近交接，Tm 呈现"先降后升"的 V 形，谷底就是赝共熔点。Bluhm 等 1986 年的经典工作将其定位在约 30 mol% HV（该研究的组成考察范围为 0–47 mol% HV）。

后果是致命的：你加了大量共聚单体，付出了前体成本，Tm 降下来了，但结晶度基本没降。材料依然硬、依然脆。

那次商业失败，根子在晶体学：1980 年代，PHBV 是 PHA 第一次真正的商业化尝试，也确实做出过消费品包装。但它最终未能持续。复盘时通常归因于三条：成本过高（3HV 需要喂丙酸/戊酸类奇数碳前体）、性能不足、以及当时缺乏政策驱动。这三条里，第二条的根因就在上面那张表的第一行。这不是工艺没优化好，不是配方没调对——是晶体学不允许。投再多研发经费，也改不了 3HV 的乙基能被 PHB 晶格部分容纳这件事。

这是本系列想反复示范的一种分析方式：把商业结果追到物理层面。一个技术路线的成败，往往在分子设计阶段就已经写定，只是要等十年才被市场读出来。

五、收网：为什么柔性 PHA 会锁死你的碳源

第四节告诉我们：想要真正的柔性，必须用被晶格排斥的第二单体——3HHx 或 4HB。现在把这个结论接回代谢通路，因果链就闭合了：

想要的单体 / 必经通路 / 必需碳源或前体 / 现实代价
3HB / 通路I（乙酰-CoA从头）/ 任意糖/油脂/C1 / 最自由、最便宜
3HV / 通路I + 奇数碳前体 / 丙酸、戊酸 / 前体贵，有毒性、抑制细胞生长
4HB / 外源前体，或工程通路 / γ-丁内酯、1,4-丁二醇（多为石油基）；或工程化的琥珀酸→4HB路线 / 前体成本高；生物基化仍在攻关
3HHx / 通路III（β-氧化 + PhaJ）/ 必须为脂肪酸/植物油 / 碳源被锁死
mcl 单体 / 通路II（PhaG，可用糖）或通路III / 糖（掺入受限）或油脂 / —

于是我们得到本期的核心推理链：
要柔性 → 要低结晶度 → 要"被晶格排斥"的第二单体 → 3HHx → 只能走 β-氧化通路 → 必须投喂脂肪酸 → 碳源锁定为植物油 → 成本与油脂市场联动，不由PHA行业自己掌控。

这就是开头那个问题的答案。柔性 PHA 的供应之所以受原料牵制，不是因为供应链管理不善，而是因为分子设计在源头就决定了它只能吃这一种饭。

但结论不能停在这里。如果只讲到"锁定=劣势"，就片面了。油脂路线还有另一面：
糖路线 / 油脂路线
碳源单价 / 低 / 高
碳收率（g PHA / g 底物）/ 较低 / 显著更高
综合成本 / 不能只看原料单价——收率优势可部分抵消单价劣势 /

原因不难理解：糖代谢到乙酰-CoA 要脱掉两个碳变成 CO₂，而脂肪酸经 β-氧化进入时碳损失小得多。"柔性 PHA 一定更贵"是一个未经计算的直觉。

这也回答了本期的标题——想做柔性 PHA，你确实得先去看油脂的价格。但看完之后，还得再算一遍收率，才知道贵不贵。

六、落差：150 种单体，6 类商品

文献里常说 PHA 家族"已发现 150 余种单体"。这个数字被引用了无数次——而它的来历，比数字本身更值得看。

年份 / 报告数量 / 出处
1995 / 91 种 / Steinbüchel & Valentin, FEMS Microbiol. Lett., 128, 219-228（摘要原文为 "91 different hydroxyalkanoic acids"）
2003 / 150 余种 / Steinbüchel & Lütke-Eversloh
2013 / 155 种 / Agnew & Pfleger, Chem. Eng. Sci., 103, 58-67
2020 / 140 余种 / 综述统计

三件事值得注意。
第一，最常被引用的"150 余种"出自 2003 年，不是 1995 年。大量资料把它挂在 1995 年那篇名下，而那篇原文写的是 91 种。这是一次典型的引用漂移——数字和出处在传播中脱钩了。
第二，这个数字在 2013 年之后不升反降。155 → 140 余。如果它是一个"已发现单体"的累积计数，只应该增加。它会下降，说明它本质上是一个随统计口径浮动的估计值：什么才算一种独立单体？报道过就算，还是必须有确证的掺入证据？不同作者的门槛不同。
第三，也是最要紧的——这个数字和你能买到的东西，几乎没有关系。

真正商业化的，约 6 类：
PHB / PHBV——商业化最早，目前仍有产品在售，但已非增长主线
P(3HB-co-3HHx)（PHBH）——当前柔性 PHA 的主流
P(3HB-co-4HB)（P34HB）——组成可调幅度最宽
P4HB 均聚——医用专用
无定形 PHA（aPHA）——主要作为改性/共混组分
mcl-PHA——小规模，多为特种用途

150 : 6。这个落差本身，就是 PHA 行业最值得读的一份数据。

落差从何而来：四道闸门
1 前体成本与毒性——3HV 的教训：能做出来，不代表养得起菌。
2 掺入率低、组成随发酵波动——实验室能做出目标组成，规模化时批间一致性达不到下游要求。对加工厂来说，组成波动 ±2 mol% 就意味着工艺参数要重调。
3 认证周期长——食品接触、医用、可降解认证都是按牌号做的。新品种进入已认证的应用，周期以年计。
4 没有碳源支撑的单体，只能停在论文里。 一个单体如果需要昂贵前体、且没有任何天然通路能从廉价碳源产出，它的产业化概率接近于零。

这四道闸门里，第四道是本期的落点。判断一个新 PHA 品种有没有产业前途，最快的方法不是看它的力学数据，是问一句：它的碳从哪来？
