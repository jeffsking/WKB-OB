# CN 117379257 A（具有护脐功能的超高腰婴儿纸尿裤及其生产工艺·江西安秀）

## One-line positioning 一句话定位

A 2024 manufacturer application combining a **5–10 cm super-high elastic waistband**（护住肚脐防受凉）with a **TCM-extract-loaded spunlace patch**（护脐贴，挥发+脐部吸收的保健宣称）。对本库的价值主要是**腰围高度的量化区间（5–10 cm）与 20–50 根氨纶丝的配置**，保健功效宣称无任何实验数据支撑，引用时只记「来源宣称」。

## Technical breakdown 技术拆解

1. **高弹腰围**：内腰围+外腰围重合，均复合氨纶丝 20–50 根；高度 5–10 cm；贴合腰腹护住肚脐。
2. **护脐贴**：水刺布喷涂中药草植物提取液 → 烘干 → 短切 25–100 cm² → 热熔胶复合于内腰围中部。
3. **芯体**：引流层 / 植物纤维吸收层（竹/棉/木浆）/ 高分子吸收层（五系 SAP 任选）；本体下部两侧弹性隔漏边。
4. **工艺**：S1 本体复合 → S2 护脐贴制备 → S3 腰围制备 → S4 贴护脐贴 → S5 总复合。

## Key claims 关键论断

- **腰围高度 5–10 cm 是「超高腰」的可引用量化区间**，与常规腰围的高度差即其全部卖点基础 → [[超高腰护脐结构（5-10cm 腰围）]]
- **天然高分子系 SAP（淀粉/纤维素/甲壳质/聚丙烯酸/聚乙烯醇衍生物）作为从属权利要求出现**，说明「生物基 SAP」在 2023 年的国内申请里已是常规选项 → [[Biodegradable SAP（可降解高吸水树脂）]]
- **中药挥发-脐部吸收为无数据宣称**（无药效、无安全性实验），不构成任何保健结论 → 只记来源原话。
