# BNC 技术分享讲稿（中文，20260908）

## 一句话定位

[[BNC 技术分享（英文完整版，20260911）]] 的**中文讲稿版**（20 页，含附录术语表与工艺全图）。中文口径更完整地保留了「卡点」「护城河」「开放问题清单」等管理语境，是中文检索的优先入口。

## 摘要

内容与英文完整版同源，按「基础篇 → 供应与成熟度 → 六条应用路线 → 行动计划」四部分展开。基础篇给出生物合成路径（菌种 Komagataeibacter / Acetobacter xylinum）、三类纳米纤维素横向对比表、与绒毛浆/SAP 的定位对比，以及产业化三道坎（发酵长周期低浓度、干燥能耗与塌孔、成本参考价待验证）。供应篇给出拜科瑞画像（尾水资源化利用率 99.6%、综合成本比糖基路线低 80%+、15 项专利、8 大核心技术）与产能节奏（千吨级已投产 / 300 万元中试线日产约 50 kg / 5,000 万元万吨车间仅处可研）。成熟度篇指出两个硬门槛（表面孔隙差、受压无回弹）与 IP 风险（与 SAP 供应商的保密与排他条款）。路线篇给出 A–F 六赛道与优先级矩阵，行动计划给出六项动作（三条有时限）、第 16 届 F2F 会议建议锁定的三件事，以及三道决策门。附录含术语表（BNC/BC、CNC、CNF、AUL、CRC、rewet、horrification、PSD、pellicle、TABCW）、拜科瑞工艺流程 S1–S4（原料 → 发酵 → 后处理 → 成型）与数据来源清单。
