# 智能尿裤功能层专利地图（BNC 嫁接视角）

## 一句话定位

把「BNC 干颗粒作为可嫁接载体」与「尿裤智能功能层需求」连起来的专利地图，覆盖四大功能层并逐层评估 BNC 嫁接可行性——**本库智能尿裤 / 功能化方向的唯一专利情报来源**。

## 摘要

报告按四大功能层组织。**①湿态指示**分三条路线：热致变色（体温触发，US5197958 已过期、US8273939B2 P&G 有效、CN116327488B 露乐有效）、电子/导电回路（US11013641B2 K-C 有效、Ontex Orizon 量产）、pH/化学比色（CN114209501A 纳米纤维膜）。**②压力传感**：电容/压阻织物阵列已有扎实的纤维素基文献路线（BC 定向织物、BC-CuNW 双层膜），但尿裤内置无量产 → 蓝海。**③抗菌除臭**：被判定为 BNC **最优切入点**，因 CN117024899A 的氨基化 CNC 改性 SAP 工艺与 BNC 干颗粒几乎同构，且 Ag@BC 授权专利族存在。**④导电加热**：印刷导电油墨柔性加热已量产（JABIL US11304263B2），但尿裤集成加热尚无量产整机。报告最后给出法律状态速查与 BNC 嫁接路线小结表。

## 提炼的数字与结论

**四大功能层总览**

| 功能层 | 主要技术路线 | 载体形态要求 | 成熟度 | BNC 嫁接契合度 |
|---|---|---|---|---|
| ①湿态指示 | A 热致变色 / B 电子导电回路 / C pH 化学比色 | 印刷油墨涂层、导电墨带、纳米纤维膜 | 量产（尿显线）→ 原型 | 中（pH 比色路线为高） |
| ②压力传感 | 电容/压阻织物阵列；穿戴张力指示 | 织物基底 + 导电条 | 实验室→原型；**尿裤内置无量产** | 高（BC 定向织物/BC-CuNW 文献扎实） |
| ③抗菌除臭 | 纳米 Ag/ZnO/TiO₂ 复合 SAP/面层；吸附/中和/微胶囊 | SAP 核壳、面层涂层、颗粒分散 | 量产（抗菌 SAP 已商品化） | **高（最优切入点）** |
| ④导电加热 | 印刷导电油墨柔性加热；尿裤专用加热结构 | 保形基材 + 逐层印刷 | 量产（发热服/面膜）；尿裤集成早期 | 中-高（文献级） |

**压力量程参考（原文在库数据）**

| 场景 | 压力 |
|---|---|
| 尿裤内实际压力 | 0.1–3 psi（约 0.7–20 kPa） |
| 仰卧平均 | 0.71–1.12 psi |
| 坐姿峰值 | 2.0–2.8 psi |
| 局部峰值 | 可达 9–12 psi（疑传感器弯曲假象） |
| 服装松紧影响 | 平均压 ±38–53% |

**抗菌除臭关键专利（BNC 最优切入点）**

| 专利/文献 | 要点 | 状态 | BNC 映射 |
|---|---|---|---|
| CN117024899A（中国制浆造纸研究院 + 中轻晋江） | 氨基化 CNC 与 SAP 缩合改性 → 负载抗菌/除臭剂 → 100–120°C 干燥 → 核壳抗菌除臭 SAP；抑菌 99%、异味去除 98%（氨 98%/醋酸 95%） | 申请公开（2023-11-10），授权状态待查 | **几乎同构**：CNC → BNC 干颗粒；100–120°C < BNC 预估耐温 200–280°C |
| US8367089 / US9200086 | 纳米银涂覆细菌纤维素（Ag@BC） | 授权族存在，细节待补核验 | 直接同构（BC 本体） |
| CN118718062A | 纳米 ZnO 抗菌面层 | 公开 | BNC 作 ZnO 载体 |
| CN114149650A | 纳米 TiO₂ 抗盐抗菌 SAP | 公开 | 同上 |
| [在库] 七-1 | Ag-SiO₂ 插层石墨烯 SAP：吸水 >50 g/g、抑菌 >98%、回渗 <0.75g | 在库 | 载体替代 |

**除臭四路线（[在库]《纸尿裤异味控制与消除》综述）**：①物理吸附（活性炭 → 无机多孔载体膨润土/蒙脱土/硅藻土）；②化学中和 + 生物抑制（乳糖酸/柠檬酸/醋酸锌中和氨、壳聚糖/丝兰抑发酵）；③缓释微胶囊（多孔壳聚糖芯 + 植物精油、季铵盐壳聚糖壁）；④消臭 SAP / 布料一体化。

**BNC 嫁接路线小结**

| 功能层 | 建议嫁接形态 | 可行性 | 依据 |
|---|---|---|---|
| 湿态指示（pH 比色） | BNC 膜/静电纺纤维作指示载层 | 高 | CN114209501A 纳米纤维膜路线 |
| 湿态指示（导电回路） | BNC 导电浆料印刷墨带 | 中-高 | Orizon 石墨油墨量产对标 |
| 压力传感 | BNC 膜/纸/织物作电容/压阻介质层 | 高（实验室级） | BC 定向织物 / BC-CuNW 文献在库 |
| **抗菌** | **BNC 干颗粒氨基化/硅烷化后负载 Ag/ZnO/季铵盐** | **高（最直接）** | CN117024899A 同构工艺 + 100–120°C 兼容 |
| 除臭 | BNC 多孔干颗粒负载酸调节剂/精油微胶囊 | 高 | 异味控制综述路线①③④ + 多孔形态匹配 |
| 导电加热 | BNC 纸基导电发热层或 PTC 油墨填料 | 中-高（文献级） | BC-CuNW 膜 / 纤维素纸电热膜 |
| 共性平台 | BC/PEG 置换干颗粒中间体（复水成胶、干态无菌） | 高 | 拜科瑞在推进 |

## 关键论断（key_claims）

- **抗菌除臭是 BNC 的首选落点** —— 工艺同构 + 温度兼容 + 形态匹配 + 量产参考四重条件同时满足。支撑页：[[BNC功能层嫁接可行性对比]]、[[细菌纳米纤维素]]
- **指示层在非皮肤面，安全要求相对低** —— 这降低了 BNC 在湿态指示方向的准入门槛。支撑页：[[智能尿裤功能层]]
- **压力传感是蓝海但有门槛** —— 纤维素基路线文献扎实，但尿裤内置无量产；须覆盖 0.1–3 psi 且耐非平面弯折。支撑页：[[智能尿裤功能层]]
- **FTO 是硬约束** —— 有效专利需规避，报告已列出必补核验清单。支撑页：[[智能尿裤功能层]]
- **共性平台思路** —— BC/PEG 置换干颗粒中间体可作通用嫁接平台（复水成胶、干态无菌），一次开发多方向复用。支撑页：[[细菌纳米纤维素]]
