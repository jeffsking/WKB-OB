# STM-00075 剥离.docx

## 一句话定位 One-line Positioning

纸尿裤粘扣系统**180° 剥离强度**的成品方法（第 4 版）：机械滚轮压合一周后，在拉力仪上 180° 剥离，取拉力平均值（gf）。是粘扣系统四件套（剥离 / 剪切 / 结合 / Loop 粘连）中"掀开难易度"的口径。

## 摘要 Summary

本方法用于测量婴儿纸尿裤粘扣与环抱腰贴的 180° 剥离强度，用 gf 表示。测试前打开拉力仪并检查压力表（夹具气压不超过 0.6 MPa），选择方法 STM5563-1、夹具距离调为 3 英寸。样品需从包装取出后标记左右端（前后左右均为穿着方向）：在距环抱腰贴下边缘 1 英寸处沿产品 CD 方向标记并剪下作为腰贴样品（不得施加外力、不得分开吸收部分）；沿底膜外边缘剪下粘扣。随后抬起机械滚轮支架，将腰贴样品底膜向上放置并按左右端对齐规则定位（测左端粘扣时样品左边折痕线对齐支架右臂内侧边缘，测右端时反之）；粘扣中心与滚轮压合面中心线对齐后轻放在腰贴上（粘贴位置应在环抱腰贴绒毛 MD 方向的中心位置，绒毛较短时尽量贴到绒毛上）。启动滚轮转完一周后取出样品，1 h 内完成拉力测试：粘扣手捏边一端夹上夹具（不得对粘贴部位施力），自由悬挂清零后把腰贴末端夹下夹具，确保无弯曲、皱褶和松弛，点击开始，记录拉力平均值即为剥离强度。

## 测试方法要点 Method Specification

| 项目 | 口径 |
|---|---|
| 拉力仪方法 | STM5563-1 |
| 夹具间距 | 3 英寸 |
| 夹具气压 | ≤0.6 MPa |
| 试样取材 | 环抱腰贴：距下边缘以下 1 英寸沿 CD 剪下；粘扣：沿底膜外边缘剪下 |
| 预压合 | 机械滚轮压合一周 |
| 夹持方式 | 粘扣手捏边 → 上夹具；腰贴末端 → 下夹具 |
| 读数口径 | **拉力平均值**（gf） |
| 时限 | 滚轮处理后 1 h 内完成测试 |

**定位对齐规则 Alignment rule**

| 测试对象 | 对位 |
|---|---|
| 测试产品左端粘扣 | 腰贴样品左边折痕线对齐支架**右**臂内侧边缘 |
| 测试产品右端粘扣 | 腰贴样品右边折痕线对齐支架**左**臂内侧边缘 |
