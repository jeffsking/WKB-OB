# CN 1330679 C（两性离子高吸水树脂及其制备方法·中国林科院林化所）

## One-line positioning 一句话定位

A 2007 **granted** patent claiming a **cellulose-grafted zwitterionic SAP**（纤维素接枝两性离子 SAP）：在同一网络里同时引入阴离子（—COO⁻）、阳离子（季铵）、非离子（酰胺）与纤维素单元，用**两性静电缔合被盐屏蔽**的机理换耐电解质性能。对本库的价值：① 0.9% NaCl 115 g/g 是本批纤维素系 SAP 里**最高的生理盐水口径**；② 其耐盐机理段是库内解释「两性 vs 阴离子 SAP 盐敏性」最完整的一段。

## Technical breakdown 技术拆解

1. **配方窗口（对单体总质量）**：AA 30–65%、水溶性纤维素 5–30%、AM 10–35%、阳离子单体 10–25%；引发剂 0.5–3%、交联剂 0.1–0.5%；固含量（除水外）20–50%。
2. **阳离子单体选项**：甲基丙烯酰氧乙基三甲基氯化铵（DMC）或甲基丙烯酸二甲氨乙酯季铵盐（DMAEMA 季铵化）。
3. **引发体系**：过硫酸铵/过硫酸钾/过氧化氢/硝酸铈铵，可与亚硫酸钠、硫酸亚铁、L-抗坏血酸组成氧化还原对。
4. **实施例数据**（茶袋称重法）：Ex.3 AA55/CMC6/AM35/DMC10 + APS/亚硫酸氢钠，N₂ 保护 60 °C×45 min → 785/405/115 g/g；Ex.4 AA60/HEC7.5/AM25/DMC15 + KPS/VC + PEG 交联 → 768/400/113 g/g；Ex.5 用乙二醇双缩水甘油醚交联。

## Key claims 关键论断

- **两性耐盐机理**（缔合-屏蔽-舒展）是本件对库内最直接的概念贡献，可用于解释任何阳离子改性 SAP 的耐盐收益 → [[两性离子高吸水树脂（纤维素接枝耐电解质）]]
- **0.9% NaCl 115 g/g @ 2005 年纤维素系**显著高于本批其他纤维素 SAP 的盐水口径（CN112851860A 蒸馏水口径、CN101787101A 130 g/g 但未注明浓度）→ [[SAP性能指标（CRC AUL GBP Vortex）]]
- **凝胶强度高/抗霉解**来自纤维素系主链，与蒙脱土补强（CN101787101A）是两条不同的强度路线 → [[Biodegradable SAP（可降解高吸水树脂）]]
