# Intake Systems Tech Pipeline - Archive（摄入系统技术管线·汇编存档）

## 一句话定位 One-line positioning

本库**摄入（Intake）议题的"档案柜"**：一份文件同时给出材料侧（resilient surge / MOJAVE）、功能侧（皮肤健康处理剂与 BM 捕获）、方法侧（解剖位与污渍遮蔽）与区域侧（女性护理 POV + LAO 试验）四条线索。它最重要的价值是**把"性能提升"与"加工代价"放在同一张表里**——MOJAVE 把回渗砍掉七成的同时也让断头翻倍，这条取舍线是本批多条议题的底色。

## 摘要 Summary

**① 摄入材料开发管线（NA PC - Tech ICT - ADT）**：以「Resilient Surge + Standard Liner」为主轴，服务 Skin Health / Inge Dryness / Urine Protection / BM Protection 四类消费者利益。核心材料命题是**用 PET 驱动使用中表现**：PET 越多 → 表现越好、成本越低，但纤网越弱。牌号端给出 MOJAVE（40% PET）与 CT5（100% PET）的**成本—强度对照**，以及二者与两类芯体（SAM/Fluff 与 AT hybrid）组合后的摄入/回渗档位（CT5 在含浆芯体上摄入与回渗均"最佳"）。随后是 MOJAVE 的完整故事：为什么做（对 HPP/PICASSO 的干爽优势）、换来的代价（断头/粉尘/幅宽波动）、MOJAVE 2.1 的问题排查表与配方调整，以及下一步（接头强度一致性、Poise 紫色 MOJAVE、用 2.0d 替代 1.5d bico 消除 neps、在 T4 POME 与 GFM 中替换 HPP、优化克重、**认证 coPET 纤维的第二货源**）。

**② 3D 材料感知基准与皮肤健康**：正在完成 3D 材料的感知基准（全球商品化牌号 + 近期开发；结果于 7 月中旬可分享，Workstream owner Kerry Clemmer）。皮肤健康部分给出四类成分（**ZnO、pH 调节剂、凡士林、调理剂+益生**）的利益与法规定位、**全球项目总表**（BITS / MAGIC / MAGIC 2.0·VERA·ACTIMEL / ProBalance / CHITOSAN（**已停止**）/ ZEN / ZENSHIELD / DERMACARE 1.0 / KNIGHT II / KNIGHT III / Firenze / IVORY / WHITE / WHITE 2.0 / RIDDLER）与**供应商能力矩阵**（Internal / Fitesa / Avgol / Shalag / YanJan / Dayuan / Textor，1–5 分），并明确指出：**内部已有皮肤健康处理能力但未在 KCNA 开发中被使用**。

**③ BM 测试方法**：提出两个具体的"方法不正确"案例——平板定位压塌大孔材料、平板法无法区分 BM 在导流层的上/下侧——并给出解剖位 cradle 与污渍遮蔽图像分析两个解法。CleanShield 4U 段给出 sprint 式攻关：20 个原型、以**高/低压回渗**为筛选指标、变量含纤维配方/花型/克重/重复长度，基准为 BCW 80 gsm 与现行 CleanShield。

**④ 女性护理（Menses）摄入 POV**：由 Richmond Cohen、Jaime Braverman、Andrew Baker 基于 **76 篇以上文档**（多来自 KC Database - Research Files）完成。给出牛顿/非牛顿流体背景（经血为非牛顿、剪切变稀，因此台架测试用盐水会系统性失真）、问题定义（面层液体转移 / 再润湿阻隔层 / 芯体分布与持留）、假设解（高开孔面层 + Z 向毛细梯度 + 无缝界面 + 稳定回弹的吸收结构）、1997 年纺粘面层研究的三条结论（处理量下限、旦数效应、泡沫 vs WEKO）、现状各区域摄入/回渗数据、PLAN 1-3Q 目标与可选表面活性剂清单。

**⑤ Rosa Parks 试验（CTI，LAO）**：给出女性护理产品级方法族（**WBRC TTM 629** 全血持留、**DSL TTM 0004** 解剖位吸收、**Heated Intake TTM 000386** 解剖位摄入、**20° Runoff TTM 490**、**水平侧向压缩 TTM 676**、**Mannequin STM 843**、**10,000 步女性护理假人 TTM 344**）与 CODE A–K 的一页纸结果，并以三条假设收尾：**可冲散（Flushable）方案与使用 PHA 的 Athena 方案均劣于对照；把 SAM 换成 LG 406 ND 则达到同等（parity）表现**。
