# ND33 改造可行性评估 · 推进计划（v1.0 · 2026-10-28）

## Positioning 一句话定位

A 13-working-day plan whose main design decision is **to promise less**: physical feasibility plus an economic range now, process-worthiness in 2027 Q2 — and a pre-agreed degrade path so the team can say "not yet available" without losing the decision.

一份 13 个工作日的计划，最核心的设计决定是**主动少承诺**：现在只给物理可行性 + 经济区间，工艺值不值得装等到 2027 Q2——并预置降级路径，让团队敢说「还没拿到」而不丢决策。

## Headline 一句话结论

> **13 个工作日内可以给出「物理可行性 + 经济区间」的确定结论，但「工艺是否值得装上去」要等到 2027 Q2。**
> 本次交付定性 = **【条件决策】**，不是完整评估。任何要求 11 月中三闸全绿的方案，只能靠供应商口述，等于把决策权交出去。

## Gate Ladder 四道闸门

| 闸门 | 判据 | 时点 | 出口物 |
|---|---|---|---|
| **Gate 0** | 基线口径三方签字 | 10/28 | 基线口径确认书 |
| **Gate 1** | 六个数 + 两个快检，**只判过 / 不过** | 11/13 | 物理可行性结论 |
| **Gate 2** | 260 GSM / 双层配准精度 / 速度-密度曲线 | 待证至 **2027 Q2** | 空白项 + 补证计划 |
| **Gate 3** | 完整口径 capex ±30% 对比北京新建 | 11/13（纸面） | 经济区间 |

**Gate 1 六个数（实测，不许估）**：可用空间净尺寸（含维护通道）｜层高净空｜地坪承重｜真空余量（风量+静压）｜电容量余量｜除尘风量余量
**两个快检**：主机机械最高速（≥1000×1.2 = 1200 PPM）｜150 RPM 下振动与 runout
**门槛写法**：门槛 = 双鼓布置净需求 + 20% 维护通道余量；速度门槛 = 目标速度 × 1.2。**由 Rocky 与 Schaefers 在 11/2 数据会当场写入，不得单方设定**。

## Three Options 三案六维度

| 维度 | 为什么重要 |
|---|---|
| **产能损失（首要）** | ND33 仍承担实际 Blizzard 产量，停产即真实商业损失，其余维度都在此之下 |
| 单轮试验周期（天） | 决定工艺迭代速度，比 capex 更影响 2029 基线 |
| 单轮试验成本 | pilot 的核心 KPI 是「试一次多贵」 |
| 可试验配置数（鼓规格数） | 11 个尺寸能不能覆盖 |
| 与量产机相关性 | ND33 是量产机相关性高；北京是专用 pilot 可控性高 |
| 不可逆性 | 拆了 Blizzard 回不去，这是风险不是成本 |

## Decision Rules 决策规则（会前认可，评审只填数）

| 情形 | 结论 |
|---|---|
| Gate 1 不过 | **选北京**，ND33 退出，不再研究 |
| Gate 1 过 + Gate 2 过 + capex ≤ 北京 60% + 交期早 ≥6 个月 | **选 ND33**，但必须可逆化改造 |
| Gate 1 过 + Gate 2 不过 | **优先北京**（可按最终工艺定制，不必迁就 ND33 约束） |
| Blizzard 产能无替代方案 | **ND33 降为受限改造**，或直接否决 |

## capex 九项口径

装备本体｜拆旧（Blizzard 拆除与处置）｜场地与结构（地坪/层高/钢结构）｜公用工程增量（真空泵/除尘/冷却/电气容量）｜控制与信息系统｜安装调试与试产废料｜**停产损失与产能替代**｜备件与培训｜可逆化预留

> 经验上**设备本体只占总装机成本约一半**，其余四散在拆改、公辅、安装与停产损失。只报设备价，决策层看到的数就是偏低的。

## 11/5 Checkpoint 中途检查点

| 11/5 结果 | 动作 |
|---|---|
| 输入到位 ≥9 项 + Gate 1 六个数拿到 | **Go**：按三案对比走 |
| 输入 5–8 项，或 Gate 1 缺 2 个以上数 | **Degrade**：只交 Gate 1 结论 + 补证计划，砍掉三案 capex 对比 |
| 输入 <5 项，或空间/速度两个关键数拿不到 | **Stop**：明确告知需延期及原因，别硬凑 |

## Not Doing Now 现在明确不做

- ✕ 不下设备订单、不签 HCH 合同（Gate 2 未过）
- ✕ 不真拆 Blizzard（评估用纸面 + 临时移机）
- ✕ 不按「全部拆除」发 RFQ（**最容易漏的一条**）
- ✕ 不在 ND33 上做实物打样（鼓规格没收敛，打出来没有代表性）

11 月下旬：鼓规格收敛（11 尺寸 → 目标 8 种鼓）+ pad 长度可调空间 → Jerry｜12 月：天津线三段式筛网试验方案 + KCPX 双 SAP 多配置 → 工艺+材料｜2027 Q1：开孔率↔密度定量关系 → 工艺+工程｜2027 Q2：速度-密度 trade-off 实测量化 → 工艺+天津线。
