# CN 116327488 B（便于识别吸湿状态的吸收性物品及其方法·露乐健康科技）

## One-line positioning 一句话定位

**露乐健康科技股份有限公司的中国授权发明专利**（CN 116327488 B）。它把本库通常讨论的"湿了没有"问题，推进到**"吸饱了没有"**：在吸收芯体与第二表层之间放一张**饱和度显示层**，用**中部可逆温敏变色部数"次数"**、**端部不可逆温敏变色部记"总量"**，再用一张**示温记录标签**给出第三条信号，最后用**三条判据任二成立**的逻辑判定是否饱和。是本库少见的、把"更换时机判断"写成**算法式判据**的专利。

## Abstract 摘要

发明名称：**一种便于识别吸湿状态的吸收性物品及其方法**。结构为：第一表层 / 吸收芯体 / 第二表层，其中吸收芯体夹在第一、第二表层之间；**在吸收芯体与第二表层之间增设饱和度显示层**。该显示层由**基底 + 第一温敏变色部 + 第二温敏变色部**构成，两者**平铺在基底朝向吸收芯体的一面**：**第一温敏变色部（可逆）位于基底中部**，接触温度较高的排泄物后变色、**排泄物温度降低时恢复初始颜色**，用于**记录排泄次数**；**第二温敏变色部（不可逆）位于基底端部**，接触排泄物后变色并**保持变色状态**，用于**获知排泄量**，进而结合排泄次数判断是否吸收饱和。此外还有一层**示温记录标签**位于饱和度显示层与第二表层之间，在**低于 T₂ 与高于 T₂** 两个温度范围分别显示第一颜色与第二颜色，用于获知排泄量。可见性由结构保证（权利要求 6）：**第二表层设为透明或设透明窗口**，且**示温记录标签与第一、第二温敏变色部错开**。判定规则（权利要求 8）为：在每次变色一段时间后判断 n ≥ N、a ≥ A、t < T₂ 中**任两者**是否成立，若任两者成立则判为**吸收饱和**；其中 **n** 为第一温敏变色材料的变色次数（或示温标签显示温度超过 T₁ 的次数），**N** 为正常情况下可吸收的次数，**a** 为第二温敏变色材料变色明显部分的面积占比，**A** 为吸收饱和时该面积占比的 **90–100 %**，**t** 为示温标签显示温度，**T₁** 为未吸收或不饱和时的**最高**温度，**T₂** 为未吸收或不饱和时的**最低**温度。

## Key claims 关键论断

- **两个变色部用"可逆性"分工，这是本案最巧的一点**：中部可逆部负责**次数**（每次来一次就变一次、凉了又回来），端部不可逆部负责**累计量**（变了就不再回来）。一条"次数"、一条"总量"，两者互补。→ [[Wetness Indicator Ladder（尿湿指示阶梯）]]
- **"是否饱和"被写成三条判据的任二成立**：n ≥ N（次数）、a ≥ A（变色面积占比）、t < T₂（温度）——这是把更换时机判断**逻辑化**而非靠单一阈值。→ [[Wetness Indicator Ladder（尿湿指示阶梯）]]
- **温色阶梯给了可执行的分档**：<20 / 20–25 / 25–30 / >30 ℃ 四档四色（权 5），且权 9 把 T₁/T₂ 默认值钉在 **28–32 ℃** 与 **18–22 ℃** —— 与人体温及环境温同一量级。→ [[Thermochromic Microcapsule (Leuco Dye System)]]
- **可读性是被结构保证的**：第二表层透明或开窗口，且三处读数**相互错开**——这与本库 [[Diaper Microclimate]] 讨论的"如何把内部状态呈现到外部"是同一个工程问题的不同解法。→ [[Water-Activated Ink（水变／湿变油墨）]]
