## Key decisions 决策要点

1. **SAP 选型方向（已明确）**：
   - 以**诺尔**为主、**卫星石化**为次；中国区对烟台万华可能在接触 [待验证]。
   - 除非出现**颠覆性**的新东西，否则基本以这两家为主。
   - 选型时机：**等 COCO V6 材料验证（9 月底）出样、本方心里有底之后**，再一起去诺尔定型号。
   - 选型前置条件：需让供应商出具**书面承诺**（专用料/新开发料的保护）。
2. **三叶草纤维的验证方案（已定做法）**：
   - 在延江（产线）上，以**设定温度为基准往下调**，连续运行时分段收样（例：130 / 128 / 126 ℃ 各收一批），送实验室测**拉伸强度**；只要 bonding strength 可接受，**低温更值得**（低温能保住异形形态）。
   - 若延江侧对烘箱能力有信心（如设定即 130 ℃），也应**额外做出更低温度的样品**做对照。
3. **层结构方案（已形成倾向）**：上层加 **10% 三叶草 + 90% ES**，ES 部分拆成 **50/50**（用福地的 ES）；另有一"最优解"方案涉及某供应商的三叶草 + ES 组合，需看成本决定 [待验证]。
4. **项目止损（已决）**：
   - 日本的**可降解**项目 → **不做**；
   - sonic 类项目 → **不做**；
   - 北京（中科院方向）优先级不高，有空再聊；
   - **海南纳米纤维素**尽快联系推进。
5. **优先级排序（已明确）**：先跑掉**容易的（REL、liner）** → **SAP 是重中之重** → master batch / 温变 / 可穿戴等宏大平台后置。
6. **组织分工方向（已定方向）**：材料方向由小团队承接；其中一位同事定位为**行业关系网 / 前哨监控**（新材料风声）+ **database 与 paperwork 的维护**；另一人以方向性判断为主。
7. **时间节点（已定）**：**11 月**的会上先把相关方向"吹出去"（占位）。

## Open issues 待决问题

1. **设定温度 vs 实际温度的 delta 未量化**：只能监控设定温度；实际烘箱温度与设定之间可能差 **2–5 ℃**，而这正是三叶草是否被流平的关键。需让延江给出**实际工艺温度**。
2. **"流平"是三叶草方案的最大风险**：加异形纤维是为了**增加比表面积**，若在高温下被流平变圆则"白加"；但温度降低又会损害 bonding strength —— **强度与形态的平衡点待验证**。
3. **熔点参照不同材料差异大**：PE 约 **130 ℃**、PBT 约 **185 ℃**、PET 约 **220 ℃**。若用 PET，温度稳定性好但 **bonding 全靠 ES，强度可能偏低** → 是否加 PET 待定。
4. **成本未知**：三叶草方案与现方案的成本差需核算；已知"10% 就算贵也贵不到哪里去"，但**最优解方案要看成本**。
5. **苏州某 master batch 供应商的适用性**：该美资公司可做 **PP / PE / PET / PA** 料，与 K-C 有三四十年合作，亚太最大实验室在孟买；**缺点是贵**。是否采用未定。
6. **纳米研磨供应商未定**：需要一家能把电气石 / 火山石 / 玉石 / 石墨烯 / 沸石 / 氧化锌等磨成**纳米级**粉的供应商；已有一家候选（北方，专做 grinding），需评估。
7. **矿物粉—功能对照表待建立**：需要一张"什么粉 → 有什么作用 / 至少有什么 claim"的清单；会中明确指出**"不一定真有作用，但市面上有人相信"** —— 功能与宣称需分开看待。
8. **温变粉做成 master batch 的可行性存疑**：把温变材料（无论微胶囊还是蜡包裹）放到 master batch 里做挤压溶出，**成功概率低**。两个关键影响因子：① **nano 粒径分布**过大 → 纤维太脆；② **capsule 对压力与温度的敏感度** → 可能在加工中**预破**。
9. **湿变是否适用同一平台未定**：湿变因为"包起来融化不了"，可能不适用；但也有可能在硬做的情况下可行 —— 待验证。
10. **可穿戴方向时机未到**：现有可穿戴多在健康/医疗领域（To B：病房、医院、养老院；To C：血糖类）；本行业**一次性使用成本压力极大**，故判断"现在做有点早"，但应**占位**。
11. **静电纺丝/纳米纤维素平台**：价格吃不住（美国价格亦吃不住）→ 对本行业意义有限，暂缓。
12. **SAP 的"不想让诺尔全知道"的矛盾**：以诺尔为依托打样最方便（其国内市占率高、打样快、还做自己的芯体产品），但存在**信息外泄顾虑** → 需留后手；会中已调整对外话术（只谈打样，配方留在本方）。
13. **外部供应商配合度问题**：某些供应商（如某十字/异形纤维厂）**不做小样**（商业化生产为主），量太小无法配合；只能等其 ready，或退而用福地方案先"透个底"。
14. **北美"So comfort"线的优先级未定**：由 Jerry 推动，是否真如其所说重要尚存疑；当前按"just start"处理。
15. **IP 布局建议（讨论中）**：若跑出样品，可考虑写专利，权利要求**写宽一些**（不局限于 liner，写成"在尿裤体系中应用的含异形纤维扩散无纺布"），便于后续扩展到 LSN 等部件 —— 属讨论建议，未形成决定。

## Background 背景

本次为内部材料团队的工作讨论，围绕三件事展开：① SAP 选型策略与供应商节奏；② liner 上加三叶草（异形）纤维的工艺验证路径与温度窗口；③ 更宏大的材料平台构想（矿物纳米粉 + 纺丝 master batch + 温变/湿变/可穿戴）。同时梳理了项目止损清单与团队内部分工。
