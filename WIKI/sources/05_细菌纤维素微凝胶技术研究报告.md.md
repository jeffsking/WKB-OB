## Technical Principles 技术原理

### 微凝胶定义
微凝胶（microgel）：生物聚合物经交联构成的三维网络胶体粒子，粒径 100 nm–100 μm。

### BC 微凝胶核心特性（BC 微凝胶核心特性）

| 特性 | 参数 | 优势 |
| --- | --- | --- |
| 粒径 | 1-10 μm（可调） | 易分散、稳定性好 |
| 比表面积 | 高 | 负载能力强 |
| 含水率 | 70-95% | 保湿好 |
| 生物相容性 | 优异 | 适合医药 |
| 可降解性 | 完全降解 | 环境友好 |
| 刺激响应 | pH/温度敏感 | 可控释放 |

### 交联方式
共价交联（化学交联剂）、离子交联（可逆网络）、氢键交联、疏水相互作用。骨架为 BC，常复合壳聚糖、海藻酸钠，负载药物/香精/营养物。

## Preparation Processes 制备工艺

### 化学交联法
BC 分散 → 功能材料混合 → 交联剂 → 搅拌 → 均质。典型配方：BC 分散液（1%）10-30%、壳聚糖溶液（1%）70-90%、四硼酸钠 1-3%、活性成分 0.1-5%。参数：搅拌 500-1000 rpm / 2-12 h；均质 8000-10000 rpm / 2-5 min。

### 阳离子改性法（专利示例）
BC 分散（4800 r/min, 15 s）→ 25% NaOH 混合室温 1 h → 加 2,3-环氧丙基三甲基氯化铵室温 30 min → 62°C 7 h → 水洗至中性。BC:改性剂 = 1:3.5（质量比）。

### 物理法
超声破碎（粒径均匀）、高压均质（连续生产）、喷雾干燥（干粉）。

### 载药微凝胶最优条件（载药微凝胶最优条件）

| 参数 | 值 |
| --- | --- |
| BC:壳聚糖 | 10:90 (v/v) |
| ST（四硼酸钠） | 2% |
| ε-聚赖氨酸（PL） | 0.4 mg/mL |
| 均质转速 | 10000 rpm |
| **包封率** | **48.23%** |
| 粒径 | 1423 nm |
| PDI | 0.25 |
| Zeta 电位 | 33.26 mV |

## Industrialization 产业化（产业化现状）

| 领域 | 阶段 | 形态 |
| --- | --- | --- |
| 化妆品 | 商业化 | 精华液、面膜 |
| 医药 | 中试/临床 | 药物载体 |
| 食品 | 研发 | 活性成分包埋 |
| 农业 | 研发 | 缓释肥料 |

**四大挑战**: 批量化生产（实验室规模为主→连续流反应器）、粒径控制（分布宽→微流控）、长期储存稳定性、成本控制。

## Cost & Price 成本与价格（成本与价格）

| 构成 | 占比 |
| --- | --- |
| BC 原料 | 30-40% |
| 功能材料（壳聚糖等） | 20-30% |
| 加工（均质、纯化） | 20-25% |
| 包装储运（含冷链） | 10-15% |
| 其他 | 5-10% |

价格：化妆品级 BC 微凝胶原料 **200-500 元/kg**；医药级载药微凝胶 **1000-5000 元/kg**；化妆品成品溢价 30-100%。

## Applications 应用方向
- **化妆品（核心）**: 精华/乳液（包埋视黄醇、VC、神经酰胺 + 透明质酸保湿）；面膜（纳米纤维网络贴合、透气、高载液量）。
- **医药**: 口服缓释、透皮贴剂、注射微球、局部凝胶；抗菌材料（负载 ε-聚赖氨酸/银离子，对大肠杆菌、金黄色葡萄球菌有效——伤口敷料、抗菌涂层）。
- **食品**: 益生菌包埋、香精缓释、营养素保护。
- **农业**: 缓释肥料、农药载体、种子包衣。

## Suppliers & Research 供应商与科研
- **原料供应商**: 桂林奇宏科技（BC 分散液）、南京天禄纳米（BC 原料）。
- **科研**: 南京工业大学（ε-聚赖氨酸抗菌 BC 微凝胶）、浙江轻工业品质量检验研究院（性能检测/标准）、中科院（药物载体专利）。
