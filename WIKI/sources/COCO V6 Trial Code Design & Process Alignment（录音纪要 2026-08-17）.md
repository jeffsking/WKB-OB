## Key decisions 决策要点

1. **code 1–9 方案成形（作为实验计划提交）**：本轮共 9 个 code（其中 1 个归属其他同事，本团队实质 3–4 个 code 的制作量）。各 code 定义如下：
   - **code 1 / 2**：整体形状沿用上一轮「大扇尾」（前 110 mm / 后 135 mm），差别在导流槽方向（后端向后、前端向前），做平行对比，目的为验证导流槽的引流与横向扩散是否改善吸收时间与回渗。
   - **code 3 / 4 / 5**：不做花型变化，只变 SAP add-on —— code 3 按现有 X pad 密度核算（上下层分别 6.8 g）；code 4 / 5 探究密度上下限（先拍脑袋取值 6 g / 上层，含后续按现场趋势动态调整的约定）。
   - **code 6 / 7 / 8**：幅宽口径统一为前后均 135 mm（PSN 155、IEL 140、LSN 200 维持不变），验证前/后漏；code 7 在 code 6 基础上剪短导流槽前端长度；code 8 在 code 7 基础上于前端增加一条**横向导流层**，验证其对冲到前端的液体的格挡与向两侧扩散作用。三者 SAP add-on 与胶密度均不变（15.5 g）。
   - **code 9**：长方形对照样品，上下层各 8.1 g（均分），长度按密度折算（365 mm 内含 16.2 g），用于与 P&G 系样品平行对比。
2. **本轮所有 code 均加中间 bonding**；导流槽使用 8 mm 浆板。
3. **code 顺序可合并与打乱**：不存在「必须等某个 code 结果才能做下一个」的硬依赖。已确认可合并的组合为 code 1+2、code 6+7+8+9；code 3/4/5 因需整体调 SAP 密度（鼓上密度），**必须单独开**。
4. **合并不做的前提**：code 3/4/5 因需整体调整鼓上 SAP 密度，无法与其他 code 共用同一鼓。
5. **Be max 不进入 COCO V6**：Be max（另一名称为 affordable manner）定位为「买不起 3D++ 的客户」的低成本路线，不为 COCO V6 路线；宽幅统一一事也不再因 Be max 而推进。
6. **亲水胶（清水胶）实验排程调整**：8 月聚焦「最佳 pattern 筛选」，9 月在筛选出的 pattern 上加亲水胶；不再为亲水胶单独新增无 channel 对照 code（无 channel 的验证改由 DNC 在产线穿插做 ISR）。
7. **旧料报废**：旧料与石灰粉报废确认（具体数量 [待验证]）。
8. **实验编号登记**：code 相关实验编号需在 share 盘系统登记，相关文件同步放置于 share 盘。
9. **材料复用**：上一轮未退库的包裹材料、IEL 胶可继续使用；SAP 需重新调一包（上一包不再用）；胶需再领一批（已用完）。
10. **去味粉样品方案（三款）**：借本次 COCO V6 芯体机实验同步制备 odour-control（气味控制）样品 —— ① 现有 control + 上层芯体混 0.25 g 去味粉；② 上层芯体混 0.5 g；③ 上下层各混 0.25 g（合计 0.5 g）。

## Open issues 待决问题

1. **中间收窄 80 mm 是否保留？** 中间收窄有利合身性，但液体易在折叶处积聚、离芯体边缘过远，侧躺漏尿风险上升；现有 CD 约 75 mm，若再收窄至 80 mm 中间、边缘留 14 mm，有效宽度仅约 52 mm。结论依赖侧躺人偶测试数据（当日下班前出）：若无差异 → 维持大扇尾；若 banking 有差异 → code 9（甚至前 8 个 code）改回长方形对照。
2. **裆部（crotch）SAP 密度无法定向提高**：现有芯体机 forming screen 开孔孔径全域一致，跌落辊跌落速度一致，改变 shape 只把平均 SAP 密度重分配到新形状上，并不会把更多密度送到 crotch。若要实现裆部加密，原则上需 notch 处开孔孔径大于两端 —— **目前芯体机无能力验证**，属待验证机理。
3. **中间收窄区的密度稳定性**：供应商口径为下料均匀，收窄后该区 SAP 密度理论上高于后端大扇尾区；但稳定性未知（若能在 380 稳定则 OK，若在 360–400 波动则只具趋势意义）。芯体机精度不足以判定。
4. **去味粉与 SAP 的预混方式未定**：倾向由诺尔 / SAP 供应商代混；若自混，则存在实验室污染、均匀度、EHS 粉尘管控三重问题；最小混量约 50–200 kg 待确认；投料方式（人工称重 + 软管密封导流 vs 自动进料称重设备）尚未定案。
5. **去味粉物性与 SAP 是否匹配**：供应商称依据现有 SAP 粒径制作，粒径接近；但密度是否接近待确认（影响抽吸上料可行性）。
6. **芯体机上料方式可行性**：料罐为间断式抽吸上料（低于液位自动补料），理论上可手动倒料，但需现场确认罐盖密封性、可否人为打开、管路是否易拆。
7. **传越 embosser（压花设备）交付**：报价本周到；PO 后预计 9 月第三周交付；安装位置需与传越确认（可能需拆折叠板）。
8. **超声波 bonding vs 胶 bonding 的毛细差异**：超声波 bonding 不提供毛细，胶 bonding 自带一定毛细渗透 —— 拟在 9 月用两个压辊 / 两个 code 做对比验证。
9. **汉高胶信息空白**：现有信息显示与 2820 一致，中国区未做专门研究，降低胶量无明确数值。
10. **LSN 降本替代**：若吸水粉（SAP）量增加，LSN 是否可用更便宜材料；需结合性能与成本评估（现有 38 g 全天胶方案外的选择）。
11. **诺尔新高 GBP 牌号**：GBP 接近 40（对比现有 24–28），牺牲少量 CRC，参数上 promising；待韩国出差回来（9 月中）后再快速过混合量评估。
12. **三叶草（三叶形）纤维打样米数与温度窗口**：需跑不同温度以平衡强度与纤维形态；具体米数与温度点 [待验证]。
13. **南京取 2000 片可乐 / 手工样面层与导流层是否够用**：数量是否足以支撑本轮实验待确认。
14. **code 9 与 P&G 系样品的平行对比宽度**：P&G 系样品在 120 mm 宽度上做，本轮基于大扇尾宽度（135 mm）；为可比性是否需跑 120 mm 仍存疑（倾向沿用 135 mm，P&G 侧可加宽音色宽度至 145 mm）。
15. **V6 面层 / 后续实验可能不跑 ISR**（视资源与结论而定）。
16. **concept 与 claim 的对齐顺序**：当前目标是「基于性能找最佳 design」，而非「为 concept 改 pattern」；若最佳 design 挖不出想要的落地概念，如何对齐尚待讨论。

## Background 背景

本轮为 COCO V6 芯体机第二轮实验（第一轮 7 月已完成，难度最高，pattern 已定），目标是在已定 pattern 平台上量化 shape（大扇尾 vs 长方形）、SAP add-on 上下限、导流槽长度与横向导流层、以及去味粉/亲水胶等变量的影响，最终在 Q3/Q4 沉淀为可交 DNC 落地的 design 框架与 guideline。同期还需为 odour-control 与亲水胶两条材料路线准备样品，因此本次芯体机试验被多方「搭车」使用。
