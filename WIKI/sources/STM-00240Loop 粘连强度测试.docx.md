# STM-00240Loop 粘连强度测试.docx

## 一句话定位 One-line Positioning

**Loop 与外层的粘连强度** 方法（第 0 版，2012-08-28；正文编号写作 STM-000240，与标题 STM-00240 不一致）。它测的不是粘扣与腰贴的撕开力，而是 **loop 复合到外层上的牢度**，并以 7 类失效模式给出"坏在哪里"的诊断。

## 摘要 Summary

这是一种测量 loop 与外层粘连强度的成品测试方法，使用拉力仪测试 loop 与外层的粘合强度，左右两侧可以在同一片 loop 上测试，当剥离到 loop 的中心时测试完成。拉力仪参数设定为夹具速度 250±10 mm/min（10±0.4 in/min）、夹具间距 38±1 mm、满量程适中以使测试值落在满刻度负载的 5–95% 之间、单位 gf、断裂值 110%。样品制备：从包装取合格产品并标记 loop 左右；视觉检查 loop 边缘未粘连距离，若 loop 有 <3 mm 的区域无胶则不测试；在 loop 后边 25 mm（1 英寸）处剪下样品（剪切时不得按压 loop），记录 loop 的 MD 长度。测试时将 loop 两侧未粘连部分折起，把未粘连部分插入上夹具（有胶面朝测试者），外层朝测试者、把剩余外层与耳贴插入下夹具后开始测试。遇到外层布撕破、外层布与底膜被撕开、或 loop 中间处与外层几乎没胶时停止测试。试验完成后需找到"几乎没胶区域的最小峰值点"记为 A 并记录数值、找到失效点记为 F 并记录数据、记录失效现象并保存样品数据。最终记录最大值（g/mm）、失效时负载（g/mm）、胶的失效值（g/mm）、loop 宽度（mm）以及每片样品的失效模式。

## 测试方法要点 Method Specification

**拉力仪参数 Tensile tester settings**

| 参数 | 设定 |
|---|---|
| 夹具速度 | 250±10 mm/min（10±0.4 in/min） |
| 夹具间距 | 38±1 mm（1.5±0.04 英寸） |
| 满量程载荷 | 使测试值落在满刻度负载的 5–95% 之间 |
| 单位 | gf（结果另按 g/mm 归一化） |
| 断裂值 | 110%（失效标准） |

**失效模式 Failure modes（本方法核心产出）**

| 代号 | 含义 |
|---|---|
| SBT | 外层材料撕破：外层分层或与底膜分层，外层材料撕破 |
| OCT | 整个外层结构破：外层与底膜未分开，有材料撕破，可能两者一起破 |
| CP | 没胶：外层完全没有破，但 loop 被撕下来 |
| AOC | 胶在外层上：loop 很容易撕下，胶留在外层而未留在 loop 材料上 |
| APA | 胶在 loop 上：loop 很容易撕下，胶在 loop 上而非外层上 |
| PT | Loop 撕破：测试中 loop 被撕破 |
| PD | Loop 分层：不是整体撕破，而是 loop 材料分层导致的破损 |

**记录项 Record items**

| 记录项 | 单位 |
|---|---|
| 最大值 | g/mm |
| 失效时负载 | g/mm |
| 胶的失效值 | g/mm |
| Loop 宽度 | mm |
| 失效模式 | 代号（SBT / OCT / CP / AOC / APA / PT / PD） |
| Loop MD 长度 | mm |
