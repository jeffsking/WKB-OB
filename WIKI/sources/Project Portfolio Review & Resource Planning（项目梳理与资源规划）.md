## 一句话定位

把团队手上全部在研项目按**组件类别 + 技术平台**重新归档，并逐项敲定优先级、卡点与下一步；同时暴露出两类共性瓶颈（masterbatch 改性、复配配方）与若干待价而动的材料机会（PTT、Lyocell、SEBS）。

## Key decisions 决策要点

> 只记会上明确「定了/就这么做」的事项。

1. **项目清单的组织方式定案**：按**组件类别**（topsheet / liner / ADL / REL / core wrap / chassis / elastic 等 7–9 个）分 deck；**一个项目一张 slide**；tracking 走 **Excel / 数据库化的小型 ERP**，对外 demo 仍用 PPT（以「哪一款尿裤用了哪些新材料」呈现，而不是以单个纤维/材料为主角）。
2. **技术平台的抽出门槛**：只有当 **≥3 个组件共用同一技术**（例：打孔工艺同时用于腰围与 liner）时，才把该技术平台单独拎出来做一张 summary；只有 1–2 个且无法 scale up 的，不做，避免浪费时间。打孔（perforated nonwoven process）被点名为可成立的平台候选。
3. **纳米纤维素首期方向定为热熔胶路线**：BNC 水凝胶 → PEG 置换 → 干态 master batch → 掺配成芯体胶；**PEG 作主体（>60 ℃ 液态、冷却即固化），PCL 作固化剂调 open time**；施胶窗口约 **60–80 ℃**（远低于常规热熔胶 150–175 ℃）。**甘油方案被否决**（任何温度都是液态、无法固化、且带颜色）。
4. **SAP 表面交联路线的替代方案**：不把纳米纤维素交给 SAP 供应商做表面交联（会绑定供应商、IP 落不到我方），改用**自制的纳米纤维素热熔胶**在芯体内实现同样的「隔离 + 导流」效果。
5. **除臭痛点与施加位置定案**：消费者痛点是**胶水与塑料袋的气味**，不是尿便味（尿便方向继续做但不作为重点）；除臭粉以**悬浮液形式混入油剂**，喷在 **outcover 侧、贴 film 的那一面**（由膜挡住，避免粉体跌落）。
6. **REL 项目申请专利**，发明人排序以管理层为第一发明人为原则 `[待验证]`（转写表述不完整）。
7. **新人尽快进入实干**：orientation 已做，后续把项目交接给新同事推进（原文：「最主要是还要让科雷亚尽早的进入进来干活」）。
8. **出差排程定案**：十一节后第二天去福建线——**米润 kick off → 福地（三叶草喷丝板）→ 起风（喝茶/顺访）**；北方线与巴西项目冲突时优先巴西。

## Open issues 待决问题

- **REL 的 PVA 纤维**：非水溶性 PVA 按 **8%** 添加，目的为**亲水 + resilience（回弹、保住 void volume）**；等**天津实验室数据**，以**第 3 次 intake speed** 是否明显提升作为判据 → **未出结论**。PVA 的**卷曲（crimping）由谁落地、何时落地**需 procurement 定周期。
- **PVA 的非水溶性处理工艺**：传统缩醛法可能有残留风险；供应商（沈工侧）称其用**常规溶剂法**，但水溶性/亲水效果可能打折 → **待核**。
- **三叶草纤维的路线未定**：现用 **bico PE/PET 三叶草**，希望转 **mono PET**；候选供方为**福地**（已有三叶草喷丝板，白口，可改成全 PET/双组分改 PET）、**米润/闽瑞**、**中纺**（唯一能 scale up 且成本最低）。是否换供方、是否改喷丝板 → **未定**。
- **PTT 的价格门槛未到**：现价仅能用于 REL；若降到约 **1.1 万元/吨** 或 **约 PP 价格的 3 倍**，才是做 PTT 熔喷/纺粘弹性布的 **kick-off point**。当前 REL 用约 **20% 的 PTT + PET 并列复合纤维**，其中约 **14%** 落在 REL 里（当弹簧用）。
- **Lyocell（莱赛尔）**：中纺报价显著低于南京（约低 3.5–4 千元/吨），且技术同源（南京工程师团队被香港咨询公司引入中纺）；南京的优势是**溶剂回收率约 98%**。水刺路线（王晶/诺邦）现 Lyocell 比例仅约 **10%**（因贵）→ 是否上量、是否先申请专利绑定 → **未定**。
- **除臭的两个验证点未验证**：① 悬浮液在特定浓度下是否**堵塞油剂喷嘴**；② 经过多辊后粉体是否在 **KC 机器上跌落（build-up）**。两点解决后才能谈应用；粉的纳米级别与悬浮液浓度需设定 n 个 code 做梯度。
- **SAP 分区**：计划把芯体分为 **5 个区**，SAP 只在关键区（转写：clutch / front / rear 区域）高度分布，其余区不加 → 省钱方向；要求**一次性实现**并在高速线实验。**混料均匀度**是已识别的风险（诺尔混料 0.2 g/g 级添加难以控准，除非有在线 dosing）。
- **两类共性瓶颈（本批新识别）**：
  1. **masterbatch 改性**：找到能研磨到纳米级的矿物粉后，**国内缺少便宜的改性母粒供应商**（KC 曾推荐苏州一家，价格偏贵）→ 是矿物粉功能化的 bottleneck；
  2. **复配（配方）供应商**：温变/湿变/尿显等功能油墨与胶的复配能力薄弱，现有供应商「口径很窄、不一定配得出」，BM（蛋白酶型）更难。
- **力致变色的低成本路线可行性未验**：不用分子级结构色，改用**褶皱无纺布预先印两色、拉开后露出内层色**——成本最低，但**如何控制褶皱 pitch 与印刷对位**工艺挑战极大。
- **在线 hook（超声波在 SMS 上直接打出 hook 形状）**、**在线喷 SEBS 做皮筋/折页**均列为**明年投入**方向，未决策。
- **可降解 SAP**：优先级定为 **low**，作为澳洲/欧洲法规储备；外部已有北美竞品声称可降解 SAP 上市。
- **PVA 价格未锁定**（转写约 2 万元/吨），需 procurement 出正式报价 `[待验证]`。

## Background 背景

团队项目数量增长后，原有按项目罗列的方式不利于跨团队（marketing、FEI、DNC）对接与复用，故重新按材料/组件类别归档；同时借新同事入职做一次全量盘点，顺带把各项目的卡点、供方与价格门槛过一遍。
