## 2. 关键概念索引

- Smart materials — 能在特定刺激下、以可预测方式改变物理化学外观、性质与结构的材料；本论文收窄为可在内外刺激下中等程度重组结构的聚合物。(出现章节 Intro, 原文行号 544–549)
- Liquid crystals (LCs) — 兼具液体般部分流动性、又因短程过渡有序而似固体的中间态物质，介于经典三态之间的第四态。(Intro, 583–585)
- Thermotropic / Lyotropic LCs — 热致液晶（取向由温度决定）与溶致液晶（由加入溶剂决定）两大成因分类。(Intro, 606–608)
- Nematic phase — 最简单常见液晶相；分子近液态随机平动但长轴沿指向矢同向排列，电场/磁场可调控。(Intro, 615–619)
- Cholesteric / chiral nematic phase — 手性向列相（胆甾相）；仅手性分子可形成，层间方位角螺旋扭转。(Intro, 621–625)
- Smectic phases — 分子沿某轴取向并排成明确层状（SmA 垂直、SmC 倾斜），通常出现在比向列相更低温度。(Intro, 651–654)
- Columnar phases — 盘/锥状分子堆叠成柱，柱间成二维六方/四方/矩形/斜方晶格；盘状液晶典型相。(Intro, 675–678)
- Calamitic / Discotic molecules — 液晶分子两大几何形态：棒状（calamitic）与盘状（discotic）。(Intro, 712–713)
- Mesogen (介晶基元) — 赋予聚合物液晶特性的刚性取向单元，嵌入骨架或侧链，其位置与形状决定液晶行为。(Intro, 804–808)
- Main-chain LCP (MC-LCP) — 介晶基元嵌入聚合物主链、由柔性间隔基分隔的液晶聚合物，用于光敏微胶囊。(Intro, 811–812)
- Side-chain LCP (SC-LCP) — 介晶基元作为侧基连接在聚合物主链上的液晶聚合物，用于质子导电膜。(Intro, 814–815)
- α-methylstilbene (mesogen) — 用作主链液晶聚酯的光活性刚性介晶核心，E 式呈棒状可形成液晶，Z 式弯曲破坏液晶性。(Ch1, 1362–1365)
- E–Z (trans–cis) photoisomerization — 芪双键在 UV 下的反–顺异构，是光响应（消晶、润湿变化、触发释放）的根本机制。(Ch1, 1367–1368)
- Interfacial polyesterification (phase-transfer-catalysed) — 两相界面以季铵盐为相转移催化剂进行界面缩聚，是获得高分子量产物的成功工艺。(Ch1, 1457–1459)
- Nematic mesophase / Schlieren texture — 向列相偏光显微镜下的纹影/丝状织构，是判定液晶相的主要实验判据。(Ch1, 1987–1988)
- Irreversible photochromic properties — 4-甲基芪类主链聚合物的光致变色通常不可逆（无热回反应），需双波长实现"消光—复相"循环。(Ch1, 1391–1393)
- Spacer (间隔基) — 连接介晶的柔性/刚性间隔基（癸二酰、戊二酰、间苯二甲酰），调控 Tg、结晶与液晶稳定性。(Ch1, 1815–1818)
- Glass transition temperature (Tg) — 玻璃化转变温度；共聚引入不对称单元可显著降低 Tg（P4 降至 45 °C）并抑制结晶。(Ch1, 1805)
- Photoactive microcapsules / light-triggered release — 以液晶聚合物为壳材的光触发释放微胶囊，是可控释放载体平台。(Ch1, 2471–2474)
- Wettability / static contact angle (CA) — 以静态水接触角量化膜表面润湿性；E–Z 异构使表面更亲水。(Ch1, 2418)
- Photochromic molecules (stilbene / azobenzene) — 光照下可逆改变结构的分子，E–Z 异构改变分子长度与极性，是植入光响应性的基本单元。(Ch2, 2723–2726)
- Microencapsulation — 用壳（膜）包覆芯材的技术，可经机械损伤、温度、pH、离子强度、电场、磁场或光等刺激触发释放。(Ch2, 2731–2733)
- Light-triggered release — 用光照（UV/可见/近红外）远程、非接触地开启微胶囊释放通道，波长选择取决于应用场景。(Ch2, 2753–2760)
- Phase-inversion precipitation (PIP) — 均相聚合物溶液刮涂于支撑体后浸入非溶剂凝固浴，借溶剂/非溶剂交换成膜/成囊的工艺。(Ch2, 2830–2834)
- Asymmetric membrane — 具"致密皮层 + 海绵状多孔支撑亚层"双层结构的膜，由延迟分相形成。(Ch2, 3040–3041)
- α-methylstilbene moieties (E vs Z) — E 构型分子长 9.1 Å、Z 构型 6.8 Å（收缩约 25%），并伴随偶极矩升高。(Ch2, 3145–3148)
- RMS roughness / surface topography — rms 粗糙度等量化膜面形貌；光照后 rms 下降约 24%，与释放通道打开一致。(Ch2, 3125–3126)
- Stilbenes — 二苯乙烯类（乙烯桥连双苯环）化合物，以独特光化学（尤其 trans–cis 光异构）著称。(Ch3, 3691)
- Liquid crystallinity (rod-like / linear form) — trans 态伸展棒状可形成液晶；cis 态失去线性几何而丧失液晶性，是光致各向同性转变根源。(Ch3, 3700–3702)
- Periodic boundary conditions (PBC) — 用周期性边界条件的量子化学计算模拟聚合物体相结构，衔接分子前体与微胶囊壳形貌。(Ch3, 3834–3835)
- HSEh1PBE (HSE06) hybrid functional — Heyd–Scuseria–Ernzerhof 短程杂化泛函，在周期性体系兼顾精确交换与能带隙定量。(Ch3, 3858–3859)
- Conical intersection — 势能面锥形交叉点，是激发态经无辐射衰变回到基态并完成异构化的通道。(Ch3, 3814)
- Discotic liquid-crystal polymer — 侧基为盘状/锥形液晶基元、可自组装成柱状相的聚合物，用于构筑质子导电膜。(Ch4, 4830)
- Tapered minidendritic side groups — 锥形迷你树状侧基；锥角决定超分子构筑，使聚合物形成圆柱状大分子并排列为柱状晶格。(Ch4, 4898–4901)
- Homeotropic orientation — 柱状取向垂直于膜表面；垂直取向带来更高离子电导率各向异性，是跨膜定向输运前提。(Ch4, 5300)
- Hexagonal columnar lattice / mesophase — 圆盘/树状基元沿一维堆叠成柱、柱间六方排列的二维晶格。(Ch4, 4916)
- Baking process — 加热至清亮点以上、以极慢速率（~0.5 °C/min）冷却的热处理工艺，用于诱导垂直取向。(Ch4, 5342–5348)
- Proton conducting membrane — 燃料电池/人工光合系统关键部件，负责选择性跨膜质子输运；Nafion 是传统基准。(Ch4, 4865)
- Cation antiport mechanism — 质子与剥离相阳离子按反向共转运，输运受阳离子尺寸与多醚通道尺寸匹配控制，故具尺寸选择性。(Ch4, 5576–5579)
- Ionic cable — 取向柱在阳离子通过时趋向形成束状聚集体，构成可定向传导离子的"离子电缆"。(Ch4, 5658)
- Water-independent proton conductivity — 膜在 5%–100% RH 全湿度范围电导率基本不变，区别于依赖水合的 Nafion。(Ch4, 4951–4952)
- Tobacco Mosaic Virus (TMV) self-assembly / exo-recognition — 自然原型：TMV 通过锥形蛋白外识别自组装为螺旋圆柱，是仿生离子通道设计灵感。(Ch4, 4892–4896)
- Proton Exchange Membrane (PEM) — 质子交换膜是人工光合与 PEMFC 核心部件，决定性能、选择性与耐久性。(Ch5, 5963–5964)
- Columnar Mesophase (Col / Colh) — 盘状芳核沿一维堆叠成柱、柱间六方/四方排列；构筑离子传输通道的结构基础。(Ch5, 5994–5995)
- Homeotropic alignment — 柱列方向垂直于膜表面，通过高于清亮点温度熔融后缓慢冷却实现，是离子跨膜传输所需取向。(Ch5, 6387–6399)
- PAZE — poly[2-(aziridin-1-yl)ethanol] — 侧链液晶聚合物基体，按接枝树枝体比例定义改性度（40%/72%），决定柱相形成与结晶倾向。(Ch5, 6229–6230)
- Dendron (树枝体) — 接枝到 PAZE 的盘状液晶树枝体，含长链十二烷氧基与芳核，提供 π–π 堆积与柱相稳定。(Ch5, 6020)
- Anodised Aluminium Oxide (AAO) — 阳极氧化铝无机支撑模板，具规整圆柱孔（0.02/0.2 μm）与电绝缘性，提供机械强度与诱导垂直取向。(Ch5, 6041–6042)
- Nanoconfinement (纳米限域) — 利用纳米孔道约束盘状分子自组装，在支撑孔内生长柱列相，是"孔内成线"核心策略。(Ch5, 5980–5984)
- π–π stacking — 相邻芳核间 π–π 堆积使柱内分子有序堆叠，是单根连续聚合物线得以形成的结构性原因。(Ch5, 6568–6570)
- Ion-conducive channels — 柱列取向直接决定离子（质子）传导通路的生成；无序则无通道。(Ch5, 6009–6010)
- Hopping mechanism / Water-free transport — 通道无酸、靠主链氮原子电子供体载流，质子以"跳跃"方式传输而无需水。(Ch5, 6026–6027)
- Methanol crossover — 传统膜中甲醇透过导致选择性下降的缺陷；低甲醇吸收杂化膜正针对此问题。(Ch5, 5969–5970)
- Hydrophobicity / Contact Angle — 取向度越高表面越疏水（86°→168°），由疏水侧基外露、极性内核被屏蔽所
