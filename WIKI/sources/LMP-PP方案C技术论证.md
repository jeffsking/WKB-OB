# LMP-PP 方案 C 技术论证（皮芯皮层树脂路线）

## 一句话定位

把「低熔点 PP」需求落到**全 PP 皮芯（EPC）复合纤维的皮层树脂**这一具体开发对象上，并给出牌号对标、供应商格局、熔点下探手段、四条工艺雷区与验收口径——本库 LMP-PP 项目**方案 C 的完整技术依据**。

## 摘要

笔记分四层推进。第一层给行业判断：真正商业化的低熔点 PP 纯树脂牌号稀少，主流走「高乙烯/乙烯-丁烯无规或三元共聚 + 茂金属催化剂」路线，但定位几乎全在**热封膜**市场（MFR 普遍 <10），与卫材纺丝所需的纤维级 MFR（30+）不是一回事。第二层给卫材实况：卫材的「低熔点组分」本质是 ES 纤维的皮层料，PE/PP 型皮层熔点约 130°C（低粘合点型可到 105–110°C），PP/PP 型（EPC）约 140°C。第三层给方案 C 定义：开发皮层熔点约 140–155°C、芯层用常规 PP（约 165°C）的全 PP 皮芯纤维皮层树脂，替代 PE 皮方案，实现「100% 聚丙烯、利于回收、界面与 PP 骨架同源」。第四层给落地细节：树脂端三个压熔点手段（共聚单体打满 ~10 wt%、掺 5–30% 低等规组分、反向禁用成核剂）叠加使用，同时警惕四条工艺雷区。

**熔点下探三手段（方案 C 全部叠加）**

| 手段 | 操作 | 依据 |
|---|---|---|
| 共聚单体打满上限 | 乙烯或 C4–C10 α-烯烃 ≈10 wt%，配合丁烯（降熔点效率高于乙烯） | 0.8–10 wt% 可把 Tm 从 160–165°C 降到 153–158°C |
| 掺入 5–30% 低等规组分 | 低等规度组分（五元组 30–60%）改善低温流动与柔软手感 | 高性能纤维级允许的加工性调节 |
| 反向禁用成核剂 | 零成核剂，把结晶度压到 60% 以下 | 成核剂的功能是加速结晶/降收缩，与降熔点目标相反 |

**方案 C 四条工艺雷区**

| # | 雷区 | 机理与后果 | 对策 |
|---|---|---|---|
| 1 | 二甲苯可溶分失控 | 可溶分是低结晶度伴生物；热风线 100–180°C 运行，皮层发黏则整线开不了车 | 锁死可溶分 <6 wt%；用催化剂做嵌段化控制而非「无规稀释」 |
| 2 | 淬火不足 → 预结晶或发黏 | 低结晶倾向物料结晶慢，淬不透将在拉伸段断丝 | 冷辊 + 骤冷风强化，淬火终温控制在 Tg（≈−10°C）至 Tg+15°C |
| 3 | 热定型窗口极窄 | 135°C 熔点皮层料，定型可用窗口比常规 PP 窄得多 | 定型温度整体下移，不可照搬常规线参数 |
| 4 | 拉伸倍率需重标定 | 常规两段拉伸按均聚设计；低熔点皮层 110°C 即接近软化区 | 一段拉伸下限温度与倍率重做 DOE |

## 关键论断（key_claims）

- **热封膜级 ≠ 纤维级** —— 膜级低熔点 PP 的 MFR 普遍 <10，卫材纺丝需 MFR 30+ 与窄分子量分布，自研必须按纤维级重设，不能直接搬参数。支撑页：[[低熔点聚丙烯]]、[[熔融指数与化学降解]]
- **行业「低熔点」的真身是皮芯结构** —— 真正独立低熔点 PP 粒子牌号稀少，多数需求由皮芯的低熔点皮层解决。支撑页：[[皮芯复合纤维]]
- **可溶分是方案 C 的头号风险** —— 它同时决定纺丝操作性与热风线开车可行性。支撑页：[[低熔点PP技术路线对比]]
- **结构设计可给树脂减负** —— 皮芯比例降到 30:70 甚至更低，皮层熔点要求可放宽到 145–150°C（只要芯层 165°C 留足窗口）。支撑页：[[皮芯复合纤维]]
- **验证路径已清晰** —— 中石化技术中心/镇海或茂名中试装置试产高乙烯 RCP 或 mPP → 仪征化纤或德福伦做皮芯复合纺验证，对标 Lumicene MR 2002。
