# LAE抑菌剂产品介绍（Ethyl Lauroyl Arginate HCl）

## Positioning 一句话定位

The supplier's technical dossier on **LAE** — a cationic surfactant preservative whose regulatory footprint (FDA GRAS, EFSA E243, China NMPA 2020) is far stronger than its antimicrobial potency, which is measurably **weaker than CTAB** on the very strains the deck benchmarks. Read it as a **compliance-first** option, not a potency-first one.

本页是供方关于 **LAE** 的技术资料——一种阳离子表面活性剂型防腐剂，其**法规足迹**（FDA GRAS、EFSA E243、中国 NMPA 2020）远强于其抑菌效力：在与 CTAB 的同表对标中，五个菌株**全面落后**。因此应把它读作**合规优先**选项，而非效力优先选项。

## Identity 物质身份

| 项 | 内容 |
|---|---|
| 化学名 | 月桂酰精氨酸乙酯盐酸盐（Lauroyl arginate ethyl ester HCl） |
| INCI | Ethyl Lauroyl Arginate HCl |
| 外观 / 溶解性 | 白色粉末，易溶于水/乙醇 |
| pH 稳定范围 | 3–7 |
| 类别 | 阳离子表面活性剂、广谱防腐剂 |
| 合成 | L-精氨酸（氨基酸）+ 月桂酸（天然脂肪酸）+ 乙醇 |

## Mechanism 四步破膜机理

1. **静电吸附**：带正电的亲水头部被带负电的细菌细胞膜强烈吸附（阳离子–阴离子精准结合）。
2. **插入膜结构**：疏水长链如「楔子」插入脂质双层，破坏有序排列，流动性与稳定性丧失。
3. **通透性剧增**：选择透过性下降，钾离子/蛋白质/核酸大量外泄。
4. **代谢终止**：能量代谢与物质合成停滞，细胞快速死亡。

## MIC Spectrum 最小抑菌浓度（ppm）

| 微生物 | MIC (ppm) | 相对难度 |
|---|---|---|
| 金黄色葡萄球菌 Staph. aureus | **15** | 最易 |
| 枯草芽孢杆菌 Bac. subtilis | **15** | 最易 |
| 白假丝酵母 Can. albicans | 50 | 中 |
| 黑曲霉 Asp. niger | 100 | 中 |
| 大肠杆菌 E. coli | **200** | 最难 |
| 铜绿假单胞菌 Ps. aeruginosa | **200** | 最难 |
| 产黄青霉 Pen. chrysogenum | 200 | 最难 |

> **13 倍差**（15 vs 200）：对革兰阳性菌高效，对革兰阴性菌需大幅提量。这是配方设计的第一约束。

## Concentration–Efficacy 浓度-抑菌率（LAE vs CTAB）

| 菌株（ATCC） | 抑菌剂 | 5 mg/L | 10 mg/L | 20 mg/L | 30 mg/L |
|---|---|---|---|---|---|
| 金黄色葡萄球菌 6538 | LAE | 64.73 | 89.14 | **100.00** | 100.00 |
| | CTAB | 78.85 | 100.00 | 100.00 | 100.00 |
| 大肠杆菌 8099 | LAE | 39.31 | 63.69 | **100.00** | 100.00 |
| | CTAB | 78.44 | 100.00 | 100.00 | 100.00 |
| 枯草杆菌 6633 | LAE | 53.62 | 87.73 | **100.00** | 100.00 |
| | CTAB | 58.15 | 99.60 | 100.00 | 100.00 |
| 白色念珠菌 10231 | LAE | 5.39 | 45.59 | 81.43 | **90.71** |
| | CTAB | 93.68 | 100.00 | 100.00 | 100.00 |
| 绿脓杆菌 15442 | LAE | 27.28 | 63.14 | 94.15 | **99.62** |
| | CTAB | 82.77 | 100.00 | 100.00 | 100.00 |

**读法**：20 mg/L 是细菌类 100% 的门槛；**白色念珠菌即使 30 mg/L 仍只有 90.71%**（真菌是短板），绿脓杆菌 30 mg/L 为 99.62%（未达 100%）。

## Regulatory Moat 法规护城河

| 机构 | 状态 |
|---|---|
| 美国 FDA | GRAS（公认安全），可用于多种食品领域 |
| 欧洲 EFSA | 食品添加剂官方目录，编号 **E243** |
| 国际食品法典 CAC | 批准为食品加工助剂 |
| 欧盟 EC（2009） | 化妆品防腐剂，常规 **≤0.4%**；肥皂/去屑洗发水/非喷雾除臭剂最高 **0.8%** |
| 中国 NMPA（2020-12） | 第 141 号公告批准为化妆品原料 |
| 其他 | 加拿大、墨西哥、澳大利亚、日本等 20+ 国家 |

## Toxicology 毒理四保障

| 项 | 数据 |
|---|---|
| 急性经口（大鼠） | LD50 **>1,800 mg/kg**（低毒） |
| 急性经皮（大鼠） | LD50 **>1,802 mg/kg** |
| 刺激性/致敏性 | 正常使用浓度下对皮肤与眼黏膜无刺激，无接触性致敏 |
| 遗传毒性 | 无致突变 / 无致畸 / 无致癌 |
| 代谢 | 快速分解为月桂酸 + 乙醇 + 精氨酸，无累积 |

## Beyond Antimicrobial 三项附加价值

| 价值 | 机理 | 卫生用品意义 |
|---|---|---|
| 强效除臭 | 抑制产臭菌 + 表活吸附分解异味分子 | 经期/排泄/失禁场景的异味控制 |
| 抗静电 | 阳离子吸附于 PP 无纺布表面中和静电 | 改善手感、避免粘肤 |
| 表面活性 | 乳化分散与润湿渗透，帮助活性物附着纤维 | 提升抑菌/祛味持效性，优化配方稳定性 |
