# BNC PCM-Free Thermoregulation v1（无微胶囊温控·细菌纳米纤维素）

## 一句话定位

**"用细菌纳米纤维素（BNC）纳米纤维网络本身做热管理层，不用相变微胶囊"的技术评审（英文）**。本库价值：它是 [[PCM-Free Thermoregulation]] 概念页的**主论证源**——把"温控"从一招拆成**四个可分离的物理功能**，并据此论证**微胶囊对多小时微气候舒适是冗余的**。

## 摘要

**问题框定 · 微胶囊税（The Microcapsule Tax）**：相变微胶囊解决一个热尖峰，却从四个方向收费——① **+gsm / +cost**（每单位额外材料与转化工序）；② **壳层脆弱 → 破裂与批次差异**（破胶囊污染 SAP、放宽过程控制限）；③ **液态 PCM 泄漏 → 皮肤刺激 + 回渗/气味恶化**；④ **多供应商链 → 库存与 QA**（特种包埋增加一层脆弱且带可持续负担的供应层级）。

**功能分解（核心方法论）**：**温控不是一招，而是四个可分离的物理功能**——**隔热**（阻导热流，高 R 值）、**缓冲**（提高热质量，降低 dT/dt）、**消散**（蒸发与辐射路径把热移走）、**尖峰吸收**（在设定点用潜热吸收一次离散热事件）。**其中 3 of 4 是结构性的，不是化学性的。** 而**多小时穿着舒适是一个稳态问题**（隔热 + 缓冲 + 消散），**尖峰吸收只在温暖排尿后最初 ~60 s 才重要**。

**BNC 结构表征**：自组装 **sub-100 nm 带状纤维毡**——fibril ribbon 宽 **≈50–100 nm**、inter-fiber pore **≈20–200 nm**、孔隙率 **≈85–95%**、比表面积 **≈100–200 m²/g**、接触形式为**点接触（tortuosity τ ≈1.5–3）**、持水 **≈100× 干重**。**"其几何即其热机制"**。

**结构 → 热性能映射（五条）**：① ≈90% 孔隙率 → 捕获静止空气（k_air ≈0.026）→ 有效导热极低；② 纳米孔 **≈20–200 nm ≈ 空气平均自由程（≈68 nm）** → **Knudsen 效应抑制气相导热**；③ 点接触纤维网络 → 最小固相导热路径 + 声子边界散射；④ 富羟基表面 → 结合水 = 大感热热质量；⑤ 纳米纤维毡 → 红外散射、低发射率热路径。

**四条热通路 + 两个消散回路**：固相导热（点接触骨架 + 声子散射）｜气相导热（Knudsen 抑制）｜辐射（IR 散射、低发射率曲折路径）｜对流（亚毫米封闭孔阻断层内空气运动）；**Loop A · 结合水感热缓冲**（羟基结合水提高热质量，**不用潜热**即可减缓 dT/dt）；**Loop B · 蒸发消散**（湿态下透湿排热）。

### BNC-only vs BNC+PCM 全账本

| 维度 | BNC-only | BNC + PCM 微胶囊 |
|---|---|---|
| 机制 | **结构内生** | 潜热添加剂 |
| 覆盖功能 | 隔热 + 缓冲 + 消散 | + 尖峰吸收 |
| 能量密度 | 感热（低） | 潜热 **≈100–200 J/g** |
| 增加克重 | **0**（用既有 BNC） | **+≈15–40 gsm** |
| 单位成本增加 | 0 | **+≈$0.008–0.015** |
| 泄漏 / 破裂风险 | **无** | 壳层脆弱 |
| 供应链 | 更简单（纤维素） | 多供应商 |
| 可持续性 | 可冲散、生物基 | 石化壳层、微塑料风险 |
| 设定点精度 | **无（结构性）** | 在 Tm 处锐利 |
| 裁决 | **对稳态舒适冗余** | **仅对瞬态有边际价值** |

### 用结构而非化学补差距（五条设计杠杆）

1. **Z 向孔隙率梯度**（致密贴肤侧 / 蓬松芯侧）——进一步减缓皮肤侧 dT/dt（承接既有 REL 工作）；
2. **贴肤区提高 BNC 克重**——在关键处增加感热热质量；
3. **结合水管理（保湿剂调节）**——把缓冲窗口延伸到排尿事件之后；
4. **透气背层 + ADL 协同**——用蒸发消散抵消急性尖峰；
5. **REL 增强层**——在不增 gsm 的前提下提供机械鲁棒性。
> 净结论：**PCM-free 的对等性可在现有纤维素材料集内实现，无需新化学**；五条结构杠杆与三条残余差距一一对应。

### 决策与 Gate / 验证路线

| 结论档 | 方案 | Gate |
|---|---|---|
| **RECOMMENDED** | **BNC-only（稳态）** | AUL/CRC ≥ 现况；回渗 ≤ 现况；皮肤模型 ΔT/dt ≤ 目标 |
| **NOT ALONE** | BNC-only（急性尖峰） | 需结构补偿；Gate = 梯度 + 蒸发 DOE 通过试穿 |
| **FALLBACK** | BNC+PCM 混合 | 仅当上述 Gate 失败；Gate = 规模化成本可接受，否则回到结构迭代 |

**验证路线 P1–P4**：P1 材料表征（k_eff、DSC 结合水、SSA）→ Gate：k_eff ≤ 0.04、结合水 ≥ 目标；P2 台架热测试（防护热板 + 皮肤模型 ΔT/dt）→ Gate：ΔT/dt ≤ 目标 vs 对照；P3 产品集成 DOE（孔隙率梯度 + 透气协同）→ Gate：AUL/CRC/回渗保持；P4 试穿 / 假人 → Gate：舒适度与 PCM 基准对等。
