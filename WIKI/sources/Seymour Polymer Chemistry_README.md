# Seymour Polymer Chemistry — 项目说明

## 一、项目概述

本项目基于 Frederick W. Seymour 等编著的《Polymer Chemistry and Physics》（Wiley-Interscience，2001）一书（原书约 750 页，18 章），围绕 SAP（高吸水性树脂）与 PP（聚丙烯）卫材业务 展开系统化深度阅读，产出：

- 18 章逐章 Deep-Dive 章节报告
- 3 批次核心概念汇总
- 3 批次原文摘选索引
- 1 份全局合成报告
- 1 份合并原文索引
- 1 份项目说明（本文）

同时与 Ebewole《Polymer Science & Technology》（15 章，工程视角）形成对照与互补，构建卫材业务所需的高分子化学与物理知识体系。

### 3.1 卫材业务推荐阅读顺序（6–8 周）

第 2–3 周 → Ch.6 → Ch.7 → Ch.8 → Ch.9    合成机理：缩聚 → Z-N(PP) → 自由基(SAP)

### 3.3 使用 Ebewole 作为互补读物

- 改性配方：优先使用 Ebewole Ch.5（ABS/SBR/EVA 改性案例）
- 共聚实用化：Ebewole Ch.8 的 Mayo-Lewis 方程与组成漂移讲解更直观
- 表面处理与偶联剂：Ebewole 的处理更系统
- Seymour 不可替代部分：Ch.10（天然聚合物）、Ch.7（离子聚合与 Z-N 催化）
