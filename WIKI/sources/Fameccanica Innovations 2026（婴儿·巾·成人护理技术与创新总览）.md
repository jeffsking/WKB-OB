# Fameccanica Innovations 2026（婴儿·巾·成人护理技术与创新总览）

## 一句话定位

设备商 **Fameccanica（Angelini Technologies， fameccanica 法麦凯尼卡）** 2026 年创新路线总览（中文：婴儿 / 卫生巾与轻失禁 / 成人失禁三条产品线的技术清单）。本库价值在于提供**工艺侧的外部参照系**：去绒毛浆、去胶化、在线成形三条主线，可与自研的 [[Multilayer SAP Core（多层SAP芯体）]]、[[Patterned SAP Core Forming Drum（印花SAP芯体成型鼓）]]、[[Ultra-Low Add-On Adhesive Application（超低添加量施胶）]] 路线对读。

## 摘要

材料按**品类 × 技术**双维组织。婴儿线六项：① **Multilayer SAP Core**（把 SAP 夹在两层高蓬松热风无纺布之间、无胶固定，示例构型为水刺 35 gsm + 胶 3 gsm + 高渗透 SAP 200 gsm + 高蓬松热风 50 gsm + 胶 3 gsm + 高保水 SAP 200 gsm + 高蓬松热风 50 gsm + 胶 3 gsm + 水刺 35 gsm，即 C 折双层 SAP 结构），可切换**无绒毛浆双 SAP 层 / 单 SAP 层 / 单 SAP 层 + 绒毛浆混合芯体**三种构型；② **在线 3D 非织造成形**；③ **在线粘扣（hook）成形**（超声波局部熔融成钩，钩型由砧面孔型决定）；④ **Ari-El 弹性化方案**（可用 310 dtex 弹性丝、断丝率下降）；⑤ **Glueless™ cuffs 与窄 cuffs**；⑥ **Glueless™ ADL 贴合**。巾类与轻失禁线五项：高密度绒毛浆芯体、在线 3D 非织造、**在线打孔（Holex-in 专利）**、Multilayer SAP Core、高速单片包（450 m/min、双通道、2 片/袋）。成人线六项：桉木浆可持续方案、「Colosseo」腰围方案（在线弹性膜贴合 + 同步打孔）、内裤化产品特征、Ari-El、Glueless 弹性包覆、在线三层超声波复合（无纺布 + 弹性膜 + 无纺布，无胶）。

工艺参数层面：在线 3D 成形为**针辊机械变形 → 高真空稳定 → 热风穿透（可选，赋予记忆）→ 超声波焊接定型**，单层热风 30 gsm（另测 18/20 gsm）、双层热风 20 gsm，均实测至 **450 m/min**；厚度结果 **0.37 mm → 1.02 mm**。在线打孔原理为**两根不同速的加热沟槽辊摩擦熔融开孔**，方孔 **0.6 × 0.6 mm**，材料为柔软双组分热风 PP/PE 20–25 gsm、梳理非织造，幅宽至 200 mm，实测 450 m/min。Glueless cuffs 材料窗口：SMS 13–20 gsm、弹性丝 680–800 dtex 同花型可用。Glueless ADL 剥离力 **>0.6 N/50 mm**（即目标值），可焊性前提是**面层与 ADL 含同种或相容聚合物**（例：PP 基面层 + 含 PP 的双组分热风 ADL）。

## 关键论断（key_claims）

- **去绒毛浆与去胶化是同一条工艺主线（在线成形 + 焊接/热封替代胶）** —— 支撑页：[[Multilayer SAP Core（多层SAP芯体）]]、[[Glueless Bonding（无胶粘合工艺族）]]
- **在线 3D 成形的价值主张是「厚度/柔软度提升 + 成本下降」同时成立** —— 支撑页：[[In-line 3D Nonwoven Formation（在线三维成形非织造）]]
- **高密度绒毛浆芯体把单位厚度的浆量上限从 100 gsm/mm 抬到 170 gsm/mm** —— 支撑页：[[High-Density Fluff Core（高密度绒毛浆芯体）]]
- **可焊性的前提是同聚合物体系，不是粘合工艺本身** —— 支撑页：[[ADL（导流层）]]、[[SMS复合结构]]
