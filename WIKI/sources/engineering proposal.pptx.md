## Modifications 改造项（改造项）
1. **SAP×2 混合腔**（50 kg 容量）。
2. **通道压花单元（channel embossing unit）**：橡胶剥离花型辊 + 钢砧辊，保持花型柔性；成型鼓花型塑形胶带保留；背板空间原设计已预留。（提案编制中。）

## HCH 1200PPM Pattern Core Process 工艺方案（1200PPM pattern core 工艺方案）

- **Poly 侧成型鼓**真空成型；**skin 侧 SAP 计量系统**适配高交联延迟吸收 + 高 GBP SAP。
- 每鼓分区真空，压力可在环内在线调整（SAP 重量传感器 + 压力传感器、磁耦合 + 变频独立成型风机）。
- PSN/LSN 等基材包覆鼓外承接 SAP。
- **双 poly 侧 SAP 计量**：可加注两种溶胀速度的 SAP，避免 hydro-gel block（凝胶阻塞）。
- **150 kg 锤磨机**：40 gsm 绒毛加注，poly 侧每片约 1.2 g，作 **MD 分布加速器（增毛细）**。
- Liner 侧成型鼓真空分区：高真空（H）/ 持续真空（S）/ 真空释放（R=zero）。
- **A1 功能颗粒加注位**：odor control（BM/尿液）或 PCM 温度调节——双用途预留。
- Web 路径：REL/LSN/PSN/Fluff 四路退绕 + 芯体收集。
