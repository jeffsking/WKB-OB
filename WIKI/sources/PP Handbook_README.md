## 业务关联重点（卫材非织造布方向）

本报告特别关注 PP 在卫生用品非织造布中的应用：
- Spun-bonded（纺粘）工艺 — 见 Ch.2 §2.9.1
- Melt-blown（熔喷）工艺 — 见 Ch.2 §2.9.1
- 热粘合性能（thermal bonding / calender bonding）
- PP 纤维特性（纤维密度 0.9 g/mL、结晶性、熔融温度）
- 第1章 §1.3 明确指出 "significant gains in spun-bonded fibers" 作为 PP 纤维增长的主要方向
