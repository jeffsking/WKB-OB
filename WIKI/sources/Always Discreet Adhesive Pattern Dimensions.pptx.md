# Always Discreet Adhesive Pattern Dimensions.pptx

## Basic Information 基本信息
- **Title**: Always Discreet Adhesive Pattern Dimensions
- **Date**: 2025-08-07（样品 Collected at HSBL）
- **性质**: 竞品（Always Discreet, P&G）surge attachment 施胶花型尺寸实测
- **Domain**: Performance / Rewet / Surge-Liner Interface —— 竞品拆解测量

## Line 80 – CF Swirl（XL 码）尺寸（CF Swirl 花型尺寸）

| 参数 | 估计值 |
| --- | --- |
| Swirl 直径 | 1.5 – 2 cm |
| Swirl 宽度 | 1 – 1.5 cm |
| Swirl 列间距 | 1 cm |
| Swirl 间距 | 0.5 cm |

## Line 82 – Slot Coat（S/M 码）尺寸（Slot Coat 花型尺寸）

| 参数 | 估计值 |
| --- | --- |
| 中带厚度 | 0.2 cm |
| 侧带厚度 | 0.1 cm |
| 带间距 | 0.6 cm |
| 外带间距 | 1 cm |

## Line 83 – Slot Coat（L 码）
- **与 Line 82 产品尺寸完全相同**（中带 0.2 / 侧带 0.1 / 带间距 0.6 / 外带间距 1 cm）——同一 slot 花型跨 S/M 与 L 码复用。

## HSBL Codes 试验编码花型
- **Code 8 / Code 9**: 8 mm、13 mm、13 mm 间距标注。
- **Code 6 / 6B**: 花型图见原文（无尺寸文本）。
