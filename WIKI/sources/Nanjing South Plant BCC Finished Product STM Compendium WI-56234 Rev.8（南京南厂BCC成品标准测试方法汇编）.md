# Nanjing South Plant BCC Finished Product STM Compendium WI-56234 Rev.8（南京南厂BCC成品标准测试方法汇编）

## 一句话定位

本册是**南京南厂 BCC（Baby & Child Care，婴幼儿护理）成品标准测试方法汇编**（Document# WI-56234，Rev. 8，生效日 2025-08-25），一篇 PDF 内并列约 50 个测试方法；是本库回答「某个成品指标用什么方法、什么口径测」时的**第一锚点与口径基准**。

## 摘要

文件以 Kimberly-Clark 作业指导书（WI, Work Instruction）格式编排，每个方法独立成节，节内固定为「实验目的 → 测试前准备 → 样品准备 → 测试步骤 → 操作注意事项 → 操作安全 → 紧急处理」。方法编号体系分三族：**STM-00xxx**（Standard Test Method，通用/全球方法）、**TTM-00xxx**（地区或专项方法）、**China-STM-0x / TTM-02 / TTM-03**（中国区针对 COCO 复合芯体产品专门开发的判读方法）。

吸收性能主线由四法串成：滞留能力（STM-00034 系列，14 ± 1 inH₂O 外压）、回渗（STM-00059）、表面干爽性（TTM-00302，FIFE 板 + 177 g 压板）与 Cradle 摄入时间（TTM-00148）。四法共用同一套液体口径（0.9% NaCl、37 ℃、亮蓝染色）与同一张 Size–Volume 分档表，因此**跨方法的数据可以直接对齐比较**。

结构强度主线用拉力仪（夹具气压 ≤ 0.6 MPa）测端封/侧封（STM-00078）、粘扣动力分离力（STM-00076）、180° 剥离（STM-00075）、粘扣与主体结合（STM-00071/00072）、腰围拉断（STM-产品拉断新），全部以 gf（gram-force，克力）为峰值载荷单位。

弹性系统单独成族：90% 伸长下的拉伸强度（STM-00070，校准杆大腿 90 mm）、澳洲版 Creep（STM-00065 腿部 / STM-00066 腰围，37.8 ± 2 ℃ × 90 ± 1 min，判定标准 150 mm）、以及用无水酒精浸润剥离后测的安装拉伸倍率（Installed elongation = 70/Fn，五点法剪取 70 mm）。

COCO 专属族是本册最独特的部分：China-STM-01 产品气味、China-STM-02 面层暴露凝胶颗粒、China-STM-03 SAM Island / SAM Heavy Lane（判据为纵向连续或累计长度 > 吸收体总长一半）、China-STM-04 Free SAM in Pad（REL 下层自由 SAM，精度 0.01 g）、China-STM-05 REL Width / LSS Width / SAM Width in REL、TTM-02 芯体九点分区密度（D = (W1i − W2i)/[π × 2.40² × (T1i − T2i)]，取样刀半径 2.40 cm 口径）、TTM-03 SAM Amount Below REL。这些方法把「复合芯体是否成型良好」从主观拆解变成了可量化指标。

### 全册通用口径（Universal Test Conditions 通用测试条件）

| 项目 Item | 口径 / 数值 | 备注 Note |
|---|---|---|
| 测试液 Test liquid | 0.9% NaCl（生理盐水）+ 亮蓝染料 | 0.1 g 蓝色食品级粉末定容 100 mL，取 4 mL 加入 1 L 0.9% 盐水 |
| 液温 Liquid temperature | 37 ℃（水浴加热） | Cradle / FIFE / 30° 滑渗 / 滞留 / 回渗 通用 |
| 更换频次 | 每 30 片样品更换一次；不足 30 片则每班更换 | 滞留能力法明文规定 |
| 加压外压 Applied pressure | 14 ± 1 英寸水柱（inH₂O）真空 | 滞留能力 STM-00034、回渗 STM-00059 |
| 厚度测试压力 Thickness pressure | 0.2 PSI | 厚度法；脚踏管路压力 ≥ 60 psi（413 ± 21 kPa）、≤ 65 psi |
| 夹具气压 Clamp pressure | ≤ 0.6 MPa | 所有拉力仪法 |
| Size–Volume 分档（mL） | NB 50 / S 60 / M 70 / L 85 / XL 100 / XXL 100 | ± 0.5 mL；FIFE、Cradle、30° 滑渗共用 |
| Cradle 泵设定 Flow rate（mL/min） | NB 600 / S 720 / M–XXL 900 | DISP 60 s；Insult Rate 10/12/15/15/15/15 mL/s |
| 注液点距产品中心（mm，通用） | NB 55 / S 65 / M 75 / L 85 / XL 90 / XXL 92 | 男 75/85/95/105/110/112；女 35/45/55/65/70/72 |
