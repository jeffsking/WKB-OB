## 一句话定位

COCO V6 第二轮实验数据的逐条复盘会：确认「减 SAP + 增大开槽面积」这条路走不通，把设计约束收敛为「**下层 SAP 维持 7 g、channel 只加长不加宽**」，并暴露出哑铃形的重量波动与熔喷 core wrap 的强度风险。

## Key decisions 决策要点

> 只记会上明确「定了 / 达成共识」的事项。

1. **下层 SAP 添加量维持约 7 g**：再往下调虽对回渗影响不大，但**U 型回渗会出现明显劣势** → 定为下限口径。
2. **channel 不加宽（会上一致反对）**：① 对扩散方向不利；② 宽度越大、局部无 SAP 区域越大，**CD 方向毛细更差**（侧漏风险）；③ **channel 对 cradle 本身是负面影响**，中间越宽负面越大。
3. **channel 加长可以继续考虑**，但必须匹配 SAP 的能力（且实际减量是「均匀减」，中心区域的 SAP 也会一起降低）。
4. **三叶草纤维打样温度压到 139 ℃ 以下**：实测**142 ℃ 以上异形截面会流平**（丧失截面形状）。
5. **熔喷 core wrap 的强度问题要立项**：若方向成立，需尽快组织 project team 解决材料在高速下的强度问题。
6. **SAP 的实验策略调整**：实验阶段**不要只等现有供应商开发**，可先把其他家的 SAP 拿来证明 concept 可行，再让现有供应商跟进。

## Open issues 待决问题

- **减 SAP 的假设被数据否定**：假设「有 SAP 处 density 与 5.6 一致 + 开槽面积增加 → 可减量且性能维持」，实测**回渗/高低压无大影响，但第二轮 cradle intake 与第三轮 input 明显变差**（某 code 时间远超 CTRL 与 code 2）。→ 该路径**未走通**。
- **哑铃形的重量波动原因未定义**：最窄模块（5 号）实测值明显低于理论值，其余模块趋势一致偏低。候选解释：① **负压**（切掉处无负压，SAP 撒上去后往两边跑、没被吸住）；② 面积；③ geometry。需设计实验区分。另一观察：code 10 的波动远小于 code 4。
- **大范围（哑铃形/两头加宽）的价值未证实**：带来约 **4.8%** 的成本上涨（REL、PSN、IL 与包裹部加宽至前后 130），但**第二轮侧漏测试未看出对前后漏有帮助**。
- **侧漏测试的统计强度不足**：第二轮为节约时间**每人只测 6 片**（CTRL 为第一轮 12 片，且 100% 漏）。code 6 的漏点相对平均，CTRL / code 2 / code 10 均在同一位置漏。
- **版型差异 unexplained**：不同版型（L 码 vs 另一版型）的侧躺数据差异达量级（约 168–230 vs 310+），推测与**折页结构**和**腰部环形包裹**有关 → 待验证。
- **三叶草在卫材成品上的有效性未验证**：在服装行业能大幅提高导流，但**在本品上是否同样有效待验证**；且平台要求热风供应商**双梳理 + 每个梳理双投料**，对供应商要求高。现用白口（拿来主义），后续拟切 Home PET；上层可能加约 10% 粘胶三叶草，下层 20–30% Home PET。
- **熔喷 core wrap 的强度风险**：20 g 在高速下强度风险大（CD 方向要求口径约 1,600；1,000 以下基本会断）`[待验证]`。可选方案：试 25 g、或上层用熔喷 + 下层用 SMS。
- **SAP 供应商选择的开放性问题**：现有供应商（诺尔）的优势在**后道表面交联技术手段多**（三条工艺路线可改善外壳强化）；会议建议引入 satellite、住友（日系）等做 concept 验证。**住友在纯水数据上很好，但生理盐水测试无强优势**。
- **混合 SAP 的分层风险**：运输过程中会上下分层，导致生产端到产品有差异；国内以提高性能为目的的混合 SAP 厂商不多。
- **PSN / LSN 的使用率差异**：有观点认为芯体**下方 PSN 的毛细使用率大于上方 LSN**；若成立，侧漏时应优先强化 PSN 侧的毛细（从周边做 secondary 保护）。**无 X-ray/核磁手段直接观测液体分布** → 待验证。

## Background 背景

COCO V6 第一轮已确认 channel 设计八条规则；第二轮把「能否靠增大开槽面积来减少 SAP 用量」作为核心假设做验证，同时并行评估哑铃形、三叶草纤维与熔喷 core wrap 三个新材料/结构方案。

| 项目 | 数值 / 结论 | 备注 |

## 关键论断（key_claims）

- **「减 SAP + 加大开槽面积」不成立：省下的 SAP 会在第 2/3 次摄入时以 cradle intake 恶化还回来** —— 支撑页：[[COCO芯体平台]]、[[Core Channel Pattern（芯体通道花型设计）]]
- **channel 的设计约束是「只加长、不加宽」，因为宽度同时伤害扩散、CD 毛细与 cradle** —— 支撑页：[[Core Channel Pattern（芯体通道花型设计）]]
- **异形截面纤维有热窗口（142 ℃ 流平），这是三叶草方案的隐形工艺约束** —— 支撑页：[[三叶形截面纤维（Trilobal Fibre）]]
- **熔喷 core wrap 的毛细优势与强度风险是同一枚硬币的两面** —— 支撑页：[[Meltblown Nonwoven（熔喷非织造布）]]
- **SAP 选型应先用别家牌号证明 concept，再倒推供应商开发** —— 支撑页：[[诺尔（Nuoer）]]、[[SAP（高吸水树脂）]]
