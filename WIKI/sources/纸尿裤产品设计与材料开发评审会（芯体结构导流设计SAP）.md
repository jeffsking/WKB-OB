# 纸尿裤产品设计与材料开发评审会（芯体结构/导流设计/SAP）

## 一句话定位

纸尿裤产品设计与材料开发评审会纪要，含哑铃型版型、分叉导流设计、侧漏分析，以及 SAP/导流层面/IEL-PVA 三大材料开发方向。

## 摘要

会议评审三大材料开发方向。①**哑铃型版型与撒粉均匀性**：需复核最窄区域负压/镂空面积优化方案，验证抓粉上限。②**分叉导流设计测试**：建议中间树干部分做细槽（如上方叉 8、下方叉 4），兼顾对位容差（MD 方向 2 mm 偏差可接受）与上下绑定强度。③**侧漏分析与体形对比**。**材料开发计划（核心工程验证三大方向）**：SAP（吸水树脂）——分层配比 7–8 个 code 实验推进，验证「上层高 GBP/AUL + 下层高 CRC」逻辑，同步接触住友、巴斯夫、触媒索取样品做 concept 验证；导流层/面层（Liner + 三叶草纤维）——上层 10% 探索、下层 50%，搜寻单组分 PPT 三叶草纤维供应商并引导开发；IEL/PEVA 纤维（28 克方案）——本周到货后开卷测试，分析分切后厚度衰减，确认 safety 评估结果（溶剂为水性，预计风险不大）。另有 Channel 加长方案设计（不加宽），待材料二、三轮测试后启动。

## 关键论断（key_claims）

- 分叉导流设计：建议中间树干部分做细槽（如上方叉 8、下方叉 4），兼顾对位容差（MD 方向 2 mm 偏差可接受）与上下绑定强度
- SAP 分层配比 7–8 个 code 实验推进，验证「上层高 GBP/AUL + 下层高 CRC」逻辑；同步接触住友、巴斯夫、触媒索取样品做 concept 验证
- 三叶草异形纤维打样验证（上层 10% 探索、下层 50%），搜寻单组分 PPT 三叶草纤维供应商并引导开发
- 28 克 IEL/PVA 方案本周到货后开卷测试；分析分切后厚度衰减；确认 safety 评估结果（溶剂为水性，预计风险不大）
- 哑铃型版型：需复核最窄区域负压/镂空面积优化方案，验证抓粉上限
