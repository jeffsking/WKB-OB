# STM-00076 剪切.docx

## 一句话定位 One-line Positioning

纸尿裤粘扣系统**剪切力（动力分离力）** 的成品方法（第 5 版）。与 [[STM-00075 剥离.docx]] 共享同一套制样与滚轮压合流程，区别只在拉力方向与读数口径：剪切取**最大值**。

## 摘要 Summary

该测试用于测量粘扣系统的动力分离力，用 gf 表示。测试前打开拉力仪并检查压力表（夹具气压不超过 0.6 MPa），选择方法 STM5564-1、夹具距离调为 3 英寸。样品准备与 STM-00075 一致：标记左右端；在距环抱腰贴下边缘以下 1 英寸处沿 CD 标记并剪下作为腰贴样品（不施加外力、不分开吸收部分）；沿底膜外边缘剪下粘扣；清理机械滚轮测试区。抬起滚轮支架，将腰贴样品底膜向上、端封外边缘朝内平整放于滚轮基座，使端封外边缘与滚轮支架内侧边缘对齐，并按左右端对位规则调整（测左端粘扣时样品左边折痕线对齐支架右臂内侧边缘，测右端时反之）。放下支架后，把样品测试端的粘扣在 HOOK 两端 CD 中心处标记，保持与穿着方向相同，使中心标记与滚轮压合面中间对齐，粘于腰贴中心位置（不施压），启动滚轮转完一周后取出样品。测试时拉力仪清零，把 NBL 或粘扣重叠部位夹在上夹具夹面中间（不对粘贴部位施力），样品自由悬挂清零后把腰贴末端夹到下夹具，确保无弯曲、皱褶和松弛，点击开始拉伸，记录最大值即为粘扣与腰贴的剪切强度。

## 测试方法要点 Method Specification

| 项目 | 口径 |
|---|---|
| 拉力仪方法 | STM5564-1 |
| 夹具间距 | 3 英寸 |
| 夹具气压 | ≤0.6 MPa |
| 试样取材 | 距腰贴下边缘以下 1 英寸沿 CD 剪下；粘扣沿底膜外边缘剪下 |
| 预压合 | 机械滚轮压合一周 |
| 标记 | 粘扣在 HOOK 两端 CD 中心处标记 |
| 夹持方式 | NBL 或粘扣重叠部位 → 上夹具；腰贴末端 → 下夹具 |
| 读数口径 | **拉力最大值**（gf） |

**与 STM-00075 的逐项对照 Item-by-item vs STM-00075**

| 项目 | STM-00076 剪切 | STM-00075 剥离 |
|---|---|---|
| 拉力仪方法号 | STM5564-1 | STM5563-1 |
| 夹具间距 | 3 英寸 | 3 英寸 |
| 试样制备 | 同 | 同 |
| 滚轮压合 | 同 | 同 |
| 读数 | 最大值 | 平均值 |
| 上夹具夹持 | NBL / 粘扣重叠部位 | 粘扣手捏边 |
