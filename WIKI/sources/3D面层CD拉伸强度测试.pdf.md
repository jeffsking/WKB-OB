# 3D面层CD拉伸强度测试.pdf

## 一句话定位

**3D 面层（3D topsheet）CD 向拉伸性能专用方法（英文：CD tensile strength test for 3D topsheet）**：只测 3D 面层材料 CD 方向（中文：横向）的拉伸力与拉伸率，仪器 QA-056-01，方法号 WI-67343 第 0 版（2025-08-25）。

## 摘要

方法范围明确限定于 3D 面层 CD 方向，不覆盖 MD。准备阶段要求确认拉力仪合适量程（负重单元）、安装无杂质/无压痕损伤的夹具，操作夹具气压设为 60 psi。样品沿 CD 方向切割，宽度 2 英寸、长度大于 2 英寸即可，边缘须平滑整齐、无缺口或锯齿。测试选用拉伸程序 STM-5668，夹具高度调至 2 英寸，力与夹具清零后对称装样（样品与夹具面垂直、不得倾斜或有皱褶），启动拉力仪，结束后夹具自动返回，记录拉伸强度、延伸率等指标。
