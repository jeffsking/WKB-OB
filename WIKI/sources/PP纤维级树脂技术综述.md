# PP 纤维级树脂技术综述（Patsnap Eureka）

## 一句话定位

Patsnap Eureka Materials 平台发布的 PP 纤维级技术综述，系统覆盖分子参数、纺丝与牵伸工艺、机械性能与行业应用四大板块——**本库 PP 纤维级树脂参数的英文权威参照源**，与 LMP-PP 项目任务书的参数体系直接对应。

## 摘要

综述从分子组成讲起：纤维级 PP 包含均聚与无规共聚，其与通用 PP 的分别在于分子量分布（PDI 2.8–4.5）与等规五元组分数（主组分 ≥95%）的规格化控制。晶态上，纺丝与牵伸使分子链高度取向，形成拉长的 shish-kebab 晶体，与注塑件的球晶形貌截然不同；由此推出纤维的关键指标（dpf ≤5000、结晶取向 ≥90%、非晶取向 ≥85%、二甲苯可溶分均聚 <6 wt%/共聚 <10 wt%）。工艺部分覆盖熔体挤出（200–320°C）、纺丝牵伸比（5×–150×）、淬火（Tg ≈−10°C 至 Tg+15°C）、两段拉伸（一段 110–160°C/4×–14×；二段 80–135°C/1.2×–3×，张力 1.50–5.00 cN/dtex）、热定型（80–135°C，成核剂 10–2000 ppm，117°C 带载收缩 <5%）。最后给出三档强度、工业纺织品（绳网、土工布、混凝土增强）与卫材无纺布的应用要求，并附五家代表企业的技术成果表。

## 提炼的数字与结论

**关键分子参数**

| 参数 | 规格 |
|---|---|
| 等规五元组分数 | 主组分 ≥95%；可掺 5–30 mass% 低等规组分（五元组 30–60%） |
| MFR | 纤维级 2–50；纺粘 6–150 g/10min（ISO 1133，230°C/2.16 kg） |
| 分子量分布 PDI | 2.8–4.5 |
| 重均分子量 Mw | 高强应用 ≥7.0×10⁵ |
| 共聚单体 | 乙烯或 C4–C10 α-烯烃 0.8–10 wt% |
| 熔点 | 均聚 160–165°C → 无规共聚 153–158°C |
| 二甲苯可溶分 | 均聚 <6 wt%；共聚 <10 wt% |

**纺丝与牵伸工艺窗口**

| 工序 | 参数 |
|---|---|
| 熔体挤出温度 | 200–320°C（配抗氧剂：受阻酚 + 亚磷酸酯，0.1–0.5 wt%） |
| 纺丝初牵伸 | 5×–150× |
| 淬火终温 | Tg（≈−10°C）至 Tg+15°C |
| 一段拉伸 | 110–160°C，4×–14× |
| 二段拉伸 | 80–135°C，1.2×–3×，张力 1.50–5.00 cN/dtex |
| 总牵伸比 | 5×–15× |
| 热定型 | 80–135°C；成核剂 10–2000 ppm |
| 收缩验收 | 117°C 带载 <5% |

**强度与晶态**

| 档位 | 强度 | 对应条件 |
|---|---|---|
| 标准纤维级 | 4–6 cN/dtex（350–525 MPa） | 通用纺织与无纺布 |
| 高强级 | 7–8 cN/dtex（612–700 MPa） | 优化牵伸 + 分子量控制 |
| 超高强级 | ≥12.5 cN/dtex（>1090 MPa） | 受控冷却 + 多段牵伸 + 精密张力管理 |
| 结晶度 | 60–75% | 高于模塑件 50–60% |
| 弹性模量 | 100 至 >130 cN/dtex（8.7–11.3 GPa） | 与结晶取向和结晶度正相关 |
| 断裂伸长 | 10–30% | 取向与结晶度高所致 |

**无纺布专用改性（与 LMP-PP 项目直接相关）**

| 手段 | 参数 |
|---|---|
| 化学降解（Vis-Breaking） | 前体 MFR 0.5–50 → 最终 6–150；最终/初始比 1.5–60 |
| 皮芯/鞘层功能化 | 鞘层含添加剂（如 0.1–0.6 mass% 硫酸钡抗静电），芯层保持高纯度承载力学 |
| 纺粘线速 | 可超 4000 m/min |

**代表企业技术成果（原文附表）**

| 企业 | 方向 | 技术成果 |
|---|---|---|
| 三菱丽阳 | 工业纺织（绳网、承载结构） | 强度 ≥7 cN/dtex、结晶取向 ≥90%、非晶取向 ≥85%，模量 ≥100 cN/dtex |
| Basell Poliolefine Italia | 卫材纺粘（尿裤面层、医用纺织） | 化学降解达 MFR 6–150、纺速 >4000 m/min、Tm ≥153°C、可溶分 <10 wt% |
| 江苏苏博特 | 混凝土增强纤维 | 亲水改性（无定形硅 1–5 wt%）、强度 >450 MPa、模量 >5000 MPa、耐碱 ≥95% |
| 东洋纺 MC | 超高强工业应用 | 断裂强度 ≥12.5 cN/dtex、伸长 ≥15%、模量 ≥130 cN/dtex |
| 东丽 | 膨体与手感改性纺织 | 异形截面 M 值 1.2–3.0 |

## 关键论断（key_claims）

- **纤维级 ≠ 通用级**：分别在于分子量分布与立构规整度的**规格化**，不是简单的牌号高低。支撑页：[[低熔点聚丙烯]]
- **纤维晶态决定性能上限**：shish-kebab 取向结构是强度来源，模塑球晶结构不具备。支撑页：[[应力诱导取向与结晶]]
- **强度-取向-分子量的三元条件**：结晶取向 ≥90% + 非晶取向 ≥85% + Mw ≥7.0×10⁵，三者同时满足才能稳定 >7 cN/dtex。支撑页：[[应力诱导取向与结晶]]
- **化学降解比是核心控制量**：提 MFR 的同时必须保住残存分子量，否则纤维完整性受损。支撑页：[[熔融指数与化学降解]]
- **鞘层承载功能、芯层承载力学** —— 皮芯结构的通用设计原则（0.1–0.6 mass% 硫酸钡抗静电等）。支撑页：[[皮芯复合纤维]]
