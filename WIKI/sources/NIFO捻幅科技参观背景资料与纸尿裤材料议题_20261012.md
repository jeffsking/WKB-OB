# 三、与纸尿裤材料开发相关的议题

## A. 技术迁移议题：四个可行方向

方向1：焕新标 → 可复用卫材（最顺的迁移）
焕新标"累积使用+耐水洗"特性直接对口布尿裤、经期裤、可洗失禁垫。行业底稿现成：US 5,197,958 / 5,389,093就是"可复用布尿裤+外表面热致变色指示"，已届满可自由实施；微胶囊配方（leuco dye:酚:脂肪酸≈1:5:50、45%wt胶囊slurry、水基binder）可免费借鉴。核心问题：能否按洗护次数建模变色周期（类似毛巾30次模型）。

方向2：温感标 → 一次性纸尿裤尿显（需大改）
行业范式：
- 隔热层干态挡热/湿态导热 + 外表面温变，阈值优选 >87°F（≈30.6°C），灵敏度1~2°C
- 或底膜外侧印刷，95~104°F（35~40°C）触发
- 卫材目标窗口：30~37°C激活、响应≤120s、循环≥10次

FTO红线（必谈）：
- P&G US 8,273,939 B2（窗口+可移除温度指示贴片）有效至约2027年
- 露乐健康 CN 116327488 B（可逆记次数+不可逆记量组合）2023年已授权，组合计数方案需规避
- NIFO若无卫材专利储备，需谈联合FTO设计

方向3：安心标 → 卫材开封/防伪指示（最快落地）
"首次使用即显色"逻辑天然适配纸尿裤单片独立包装、湿巾盖贴、正品溯源，技术迁移成本最低。

方向4：光护盾 → UV暴露/包装指示
婴儿外出UV提示、湿巾UV暴露指示、开封即显色防伪膜（行业对标：UV 365nm触发不可逆光致变色）。

当面核实的技术门槛：NIFO是纤维基材料出身，纸尿裤是SAP/无纺布/PE膜体系。行业经验：微胶囊印在蓬松热风无纺布上触发不明显，PE底膜是首选承印面；湿敏油墨遇水由无色/黄变青/蓝，用于底膜内侧。Slepto睡眠巾的技术路线、触发机制、量产状态是判断其卫材适配度的试金石。

## B. 工艺路线议题

1. 形态问题是第一问：NIFO现在交付的是标签（缝制/烫印），纸尿裤需要可在线印刷的油墨/涂层形态。行业路线对照：
- 热熔尿显胶：占市场约84%，与现有转换产线完美适配（Bostik / Henkel / H.B. Fuller）
- 水性/溶剂型油墨直接印PE透气膜：环保、简化工艺、图形定制度高
- 问NIFO能否出油墨形态 + 微胶囊耐加工性数据（剪切、热、压）
2. 集成位置选项：
- 底膜外侧印刷：不改芯体结构，当前产线可直接集成（印刷/粘贴/熔融均可施加）
- 芯体与第二表层间涂层（CN 116327488 B路线）
- 背膜开窗 + 可移除传感器贴附（P&G路线，注意FTO）
- 丝网印刷是低成本大批量施印方案
3. 微胶囊化是共性使能技术：决定色变稳定性、耐迁移性、印刷适性，是供应商能力分水岭。问NIFO微胶囊自产还是外购、壁材是否含甲醛（行业警示：Matsui部分产品含微量甲醛，不推荐婴儿直接接触）。
4. 视觉设计借鉴：重复卡通图案既美观又限定变色区域，解决"脱衣找指示点"痛点；干态浅色底衬 + 激活高对比色（tan→blue逻辑）。

## C. 成本议题

1. 现状基准（我方真实数据）：尿显胶Bostik H9570约115元/kg，单片用量0.01~0.04kg，单片成本约1.4~4.4分（T4.5~T7规格，2022年9月中国BOM价）。任何替代方案都拿这个数对标。
2. NIFO成本未知，现场必问：单片标签单价、MOQ起订量、打样费/制版费、变色周期定制是否加价。毛巾/内裤场景宣称"轻薄标识不增加产品成本负担"，但纸尿裤是分钱级成本敏感产品，不可直接外推。
3. 功能成本对标：行业参考——芯体PCM相变调温功能（微胶囊添加5~8g/片）成本约+0.3元/片，属于"低单价高感知"卖点定位。变色功能层应在厘/分钱级才有意义。
4. 隐性成本清单：
- 卫材级合规：不含BPA、皮肤无刺激测试、严禁色料外渗；SGS/OEKO-TEX已有但卫材需补项
- 溶剂型油墨=危化品物流成本
- 精度与良率：国产变色材料成本极低但精度稳定性与日美有差距；松井Aqua Indicator Hot Melt直接对标尿显但价格高

# 四、现场提问清单（6问）

1. 卫材经验：Slepto睡眠巾用的哪条技术线？触发机制、量产状态、渠道？纸尿裤/卫生巾有无落地案例或打样？
2. 形态与产线：能否提供油墨/涂层形态适配高速在线印刷（丝印/柔印/凹印）？还是只能标签形态？微胶囊自产/外购？壁材含甲醛吗？
3. 触发调校：温感标能否定制30~37°C窗口（32/34/36°C三档）？响应时间、循环寿命、精度？能否做"尿液液体触发、一次性不可逆"的湿敏版本？（行业基线：响应≤120s、循环≥10次）
4. 合规：卫材级报告（皮肤刺激、BPA-free、甲醛未检出、EN71/RoHS、可迁移荧光物）能否提供？
5. 成本：单片成本/油墨单价/MOQ/制版费/打样周期——直接对标尿显胶115元/kg、单片1.4~4.4分。
6. IP与FTO：发明专利清单能否提供？愿不愿意配合纸尿裤方向做FTO联合设计（绕开P&G US 8,273,939 B2、露乐CN 116327488 B）？
