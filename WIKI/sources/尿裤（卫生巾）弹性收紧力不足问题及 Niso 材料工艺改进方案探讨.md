# 尿裤（卫生巾）弹性收紧力不足问题及 Niso 材料工艺改进方案探讨

## 一句话定位

针对尿裤/卫生巾弹性收紧力不足问题的方案研讨会，形成五个备选方案，其中熔喷短丝在线复合工艺为重点，美国市场合作走技术许可路线。

## 摘要

会议围绕弹性收紧力不足问题，提出三个解决方案并深入讨论与美国市场合作的四种模式，最终形成**第五方案（重点）：熔喷短丝在线复合工艺**；第四方案细节为无自粘弹性丝（对标华丰橡筋）。**美国市场四模式判断**：①直接出口捏塑材料到美国——需承担关税+运费，不可行，成本无法消化；②只做丝（无自粘性弹性丝）出口——上次方田看到的方案，可行方向；③赴美国建厂——投资很大，可能性不大；④技术许可——提供全套复合技术与设备由对方自行生产，配方仍留在自己手里，只赚「数字（许可费）的钱」，可行，且安庆工厂设备已被搬空、美方有产能需求。**待办要点**：确认旧纺丝设备可否重启以复制无粘弹性丝样品；设计 240D/470D 等效弹性所需旦数（预计 320D 左右）方案；准备样丝二三十卷（每卷 6000~7000 米，初期可 1000~2000 米）；制作渐变式非均匀排布分丝板样品（解决不等分收卷发抛问题）；用压力传感器 + 硅胶娃娃模型实测腰围/裆部受力（按 1~3 泡尿加载）；重新核算 320D 用量增加后与 5000 元/吨价差的成本平衡。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注（口径 Caliber） |
|---|---|---|
| 样丝准备量 | 二三十卷，每卷 6000~7000 米 | 初期可 1000~2000 米 |
| 等效弹性目标旦数 | 预计 320D 左右 | 对应 240D/470D 规格 |
| 测力方法 | 压力传感器 + 硅胶娃娃模型 | 按 1~3 泡尿加载，测腰围/裆部受力 |
| 聚合物粘度 | 调整至熔喷级别 | 参考 6800 CPS 先例；需验证加 PP 手感 |
| 分丝板样品 | 渐变式非均匀排布 | 解决不等分收卷发抛问题 |
| 价差参照 | 5000 元/吨 | 与 320D 用量增加后重新核算成本平衡 |
| 设备投资 | 争取老李出资 | 涉及改造/熔喷头/刺毛辊 |

## 关键论断（key_claims）

- 五种合作模式对比中，第五方案「熔喷短丝在线复合工艺」为重点；第四方案为无自粘弹性丝（对标华丰橡筋）
- 与美国市场合作的四模式判断：直接出口捏塑材料到美国不可行（关税+运费无法消化）；只做丝出口可行；赴美建厂可能性不大；技术许可可行（配方仍留在自己手里，只赚许可费），安庆工厂设备已被搬空、美方有产能需求
- 需设计 240D/470D 等效弹性所需旦数（预计 320D 左右）方案
- 需确认旧纺丝设备可否重启，复制无粘弹性丝样品；用压力传感器 + 硅胶娃娃模型实测腰围/裆部受力（按 1~3 泡尿加载）
- 重新核算 320D 用量增加后与 5000 元/吨价差的成本平衡；设备投资争取老李出资
