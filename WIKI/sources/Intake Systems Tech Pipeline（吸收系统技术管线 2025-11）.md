# Intake Systems Tech Pipeline（吸收系统技术管线 2025-11）

## 一句话定位

**K-C 北美个人护理（NA PC – Tech ICT – ADT）的吸收系统技术管线图**，由 Kerry Clemmer 与 Bernardita Quesada Gonzalez 维护（尿/便线 **2025-11-11** 更新；Resilient Performance **2026-04-15**；经期线 **2024-05**）。本库价值：它把**材料、机理、项目代号与商业化时点**放进同一张图——**既能读出「现在用什么」，也能读出「下一步押什么」**。

## 摘要

管线按**性能域**组织（Dryness / Resilient / Softness / 3D-Apertured / Skin Health / Menses），每域给出 **Commercial → Near-Term（FEI/IMF，2025–2026）→ Long-Term（2027+）** 三档时点。

**干爽域（Dryness）**：Surge（Resilient Surge：MOJAVE / REXHA / VONN；ATACAMA+ CT5）→ Liner-Surge Embossing（LSE）→ Capillary Network（ATACAMA+ / BUFF BABY / ARTEMIS）→ Liner（Resilient + Converting / Hollow Bico / Capillary Surge）→ Rewet Fundamentals；**未规划（not yet planned）**：Surge Liner B SB Liners、BUFF BABY ARTEMIS、Core Wrapsheet GRIFFIN SMS、ActivTech Hybrid、以及 **Rewet Fundamentals 的一致性与变异降低（Depend）+ 统一方法**。

## 提炼的数字与结论

### 干爽域：当前市场格局

- **多数品牌**通过**改进导流层设计 + 面层-导流层压花（LSE）**来降低回渗；
- **当前回渗最优的导流层是 Depend CT5（ATACAMA+），但它在加工（converting）上有权衡**；
- **其他品牌使用 MOJAVE 系列导流层，但将被中空双组分（hollow bico）取代** —— **中空双组分可在降低克重（降本）的同时改善加工性**。

### ★ 六条下一步假设（**每层一条，可直接转成 DOE**）

| 层 | 假设 |
|---|---|
| **Liner 面层** | **粗纤维（fat fibers）**形成更大孔径 → 减少截留液 |
| **Liner-Surge 贴合** | **胶**可以形成孔网连通，**且没有 LSE 的副作用** |
| **Surge 导流层** | **收窄孔径分布**可消灭"最后几滴"残液 |
| **Wrapsheet 包裹层** | **SMS 可能在抬高回渗——原因未知** |
| **Fluff 绒毛浆** | **卷曲纤维 / 绒毛浆混合**可能改善摄入 ⇒ 从而**允许导流层降克重** |
| **SAM** | **新的 APAC SAP** 可能有助于回渗 |

> 📌 **MicroCT 的直接证据**：*"MicroCT scan of Depend wetted surge/liner shows **more water in the liner (band of white at the top) than the surge (network of fibers below)**"* ⇒ **面层持液多于导流层**，为「下一步主攻面层」提供**影像学依据**（注意：[[Rewet Principles History and Opportunity（2025-03-04 回渗总纲与历史沿革）]] 中亦登记"水与非织造布射线透射率相同"的判读限制）。

### 高/低压回渗的分工

- **BCC 正在把其他平台的 LSE 学习用于降低低压回渗**；未来成人护理（AC）的学习也可反向迁移；
- **高压回渗需要改动吸收芯体**；ADT 正通过 DOE 学习 **ActivTech Hybrid 各变量对回渗的影响**。

### 柔软度升级（跟随外覆层策略）

**路线**：Soft TABCWs / Microfibers / Chemistry / Loft；Affordable Softness：SpunATB / Expanded SB / GNW S3 / Soft Spunmelts。

**2024 领先候选**：**GNW S3 技术族（TITAN、SENSTION、ECHO 等）**、**Avgol High Loft SB**、**中国超细纤维 BCW**、**Shalag 超细纤维 BCW**、**GNW 超细纤维 BCW**。

### 3D / 打孔材料

**现状**：**目前仅 T5 POME 与 T6 尿裤使用 3D 贴身侧材料**；部分项目（**T7 尿裤、ARTEMIS**）**只想要花型以驱动感知线索**。

**下一步（DOS）**：下一个 **T5 POME 项目（DOS）**希望**改善消费者感知并可能带来技术收益**；路径包括**借用 KCA 的 LeakShield（PICTORIC）学习**、**KC 设计团队与 Textor 的花型联合开发**。

| 指标 | **YanJan Naxos** | **Textor AC4** | **DOS（目标）** |
|---|---|---|---|
| 稀便性能 · 台架假人 | **方向性至统计性更差** | **方向性至统计性更好** | 方向性至统计性更好 |
| 稀便性能 · 小样本研究 | 无研究者可察觉的积液 | 同左 | 同左 |
| 稀便性能 · HUT 渗漏 | 统计等效 | 统计等效 | 统计等效 |
| **尿液 · 回渗** | **最低** | 居中 | **最低** |
| 尿液 · HUT 渗漏 | 统计等效 | 统计等效 | 统计等效 |
| **成本 $/m²** | **0.518** | **0.412** | **≤0.412** |
| 加工 · 可运行性 | 良好（目前） | **存在一些问题** | 良好至有些问题 |

> 📌 **读法**：**Textor AC4 在稀便上更好且更便宜，但回渗居中；YanJan Naxos 回渗最低但稀便更差且更贵。DOS 的目标是「回渗 = Naxos 水平 + 稀便 = AC4 水平 + 成本 ≤ AC4」** —— 即**同时取两家之长**，这是**当前尚未被任何单一材料满足的组合**。

### 皮肤健康：BCC（婴儿）vs AFC（成人）两条路线

**BCC —— 氧化锌 + 酸，走「刺激物中和」**：

| 技术 | 低 pH | ZnO | 备注 | 区域 |
|---|---|---|---|---|
| **ZEN** | ✓ | ✓ | **Textor 独家**，对刺激物有效 | KCA、KCNA |
| MAGIC 2.0 | ✓ | ✓ | 未商业化，因生产问题停止 | EM（欧洲） |
| **ZinCAre** | ✓ | ✓ | 开发中，**目前唯一的非 BCW 方案** | IPC（巴西） |
| FIRENZE | ✓ | ✓ | 乳液 + d-Panthenol，效果温和 | IPC（韩国） |
| KNIGHT III | ✓ | ✓ | 乳液 + SymRepair，**无有效性数据** | IPC（中国） |

**AFC —— 酸 + 益生/后生元，走「健康微生物组」**：

| 项目 | 主导区域 | 供应商 | 成分 | 状态 |
|---|---|---|---|---|
| **ACTIMEL (BioCare)** | IPC-ANZ 主导，KCNA 跟进 | YanJan | 柠檬酸喷涂（3%） | 预计 1Q26 |
| **ProBalance 1.0** | 中国主导 | Dayuan | SymReboot 益生菌喷涂（0.1–0.2%）、柠檬酸纤维处理、蔓越莓纤维处理 | **已商业化** |
| **ProBalance 2.0** | 中国主导，KCNA/IPC-巴西跟进 | YanJan | 柠檬酸喷涂（3%）、Cluster dextrin 喷涂、Postbiolift 后生元喷涂 | 预计 3Q25 |

> 📌 **未来方向**：可能加入 **d-Panthenol、SymRepair、Cluster Dextrin** 等更高级成分。
