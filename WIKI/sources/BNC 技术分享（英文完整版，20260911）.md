# BNC 技术分享（英文完整版，20260911）

## 一句话定位

本批**技术路线的总纲（英文 20 页版）**：把 BNC 的材料基础、供应端成熟度、六条卫品应用路线与决策门合成一份管理层可决策的文档。是回答「BNC 能不能用、先做哪条路、卡在哪」的一手依据。

## 摘要

文档以「拜科瑞（Baikerui）访厂复盘 + 技术路线评估」为题，20 页分四部分。**基础篇**：BNC 由醋酸杆菌属（Komagataeibacter / Acetobacter xylinum）以葡萄糖为原料生物合成（葡萄糖 → UDP-葡萄糖 → 纤维素合成酶催化 → β-1,4-糖苷键聚合），细菌在发酵液中直接「吐出」并组装纳米纤维，经氢键交联成三维网络（pellicle 膜），**先天连续、无需后天成网**；与植物纤维素相比无木质素、半纤维素、果胶，纯度 >99%。关键参数：纤维直径 20–100 nm（主流 40–60 nm 带状纤维，由 50–80 根 3–4 nm 微纤组成）、结晶度 84–89%（文献区间 60–90%）、杨氏模量可达 78 GPa、拉伸强度约 826 MPa 量级、吸水/持水 200–1000× 自重、孔隙率 >90%。**定位判断**：BNC 不是 SAP 替代品——绝对吸水倍率仍有差距，但可完全降解、无凝胶阻塞（SAP 颗粒吸水堵死通道，BNC 网络本身就是通道），正确角色是「结构骨架 + 导液网络 + 功能平台」。**产业化三道坎**：①发酵（托盘 7 天仅得 2 wt% 水凝胶，98% 是水）；②干燥（脱除 98% 水分能耗巨大且易塌孔，氢键再交联不可逆）；③成本（99.9% BNC 参考价约 5 万元/吨，须按干燥工艺重新验证）。**供应端**：拜科瑞以屠宰/食品/消毒尾水为培养基，8 大自研技术（尾水培养基持 5 项专利）、15 项专利、过程零化学试剂零固废；海南千吨级智能产线已投产，在建中试线投入 300 万元、日产约 50 kg，规划 1 万吨/年车间（预计投资 5,000 万元，**可研阶段未立项**，公司口径 2027/2028 达产）。**成熟度与缺陷**：发泡 BNC 当前主用于刚性包装，已在与恒安合作开发卫生巾垫片、涂覆无纺布样品手感软，但两个硬门槛——表面孔隙差/水渗透慢（内部亲水性其实很好）、蓬松发泡体受压完全无回弹（纸尿裤芯体全程受压，无回弹即不可单独构成吸收层）。**路线篇**：A 绒毛浆≥60% + BNC 发泡复合（首选，厚度需收敛到 0.5–0.8 mm）、B BNC 基 SAP 表面交联（高价值，卡在排他条款）、C 粉体 2–4% 添加增强（最快可试，5 kg 粉约 1 个月）、D BNC:PEG 母粒与芯体胶（供应链自主，排第 4）、E 功能接枝与 F 缓释涂层（中长期）。**行动篇**：六项动作、三道决策门（Gate 1 样品 → Gate 2 材料/成本模型 → Gate 3 供应/JDA），并列出 6 个待指定 owner 的开放问题。

## 提炼的数字与结论

### 材料本征参数

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| 纤维直径 | 20–100 nm（主流 40–60 nm 带状） | 由 50–80 根 3–4 nm 微纤组成，长度数微米 |
| 结晶度 | 84–89%（文献区间 60–90%） | 显著高于植物纤维素 |
| 杨氏模量 | 可达 78 GPa | — |
| 拉伸强度 | 约 826 MPa 量级 | 纳米纤维本体强度远超常规卫材纤维 |
| 吸水/持水 | 200–1000× 自重 | 孔隙率 >90% |
| 纯度 | >99% | 无木质素/半纤维素/果胶，可完全降解 |
| 表面羟基 | 天然分子挂钩 | 可接枝亲水/疏水、抗菌、离子吸附、传感 |

### 产业化三道坎与干燥路线

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| 发酵产率 | 托盘 7 天 → 2 wt% BNC 水凝胶（98% 是水） | 需脱色 + 自动化收获 |
| 干燥代价 | 脱除 98% 水能耗巨大，易塌孔 | 氢键再交联不可逆 |
| 99.9% BNC 参考价 | 约 RMB 50,000/t | **需按干燥工艺重新验证，不可直接进成本模型** |
| 冷冻干燥 | 抗塌孔最好 / 效率低 | 实验室、高值品路线 |
| 超临界 CO₂ | 抗塌孔好 / CAPEX 高 | 中试验证选项 |
| 闪蒸蒸馏 | 够用 / 效率平衡 | **工业化平衡方案（源文标★）** |
