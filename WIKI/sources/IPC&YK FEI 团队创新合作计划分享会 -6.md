### 4. 天然提取物/微胶囊除臭护肤技术（Life Science）及跨市场落地（00:15:01–00:21:55）


合作背景：与 Life Science 合作，针对 odor inhibition（抑制气味/除臭）、soothing（舒缓）、skin barrier（皮肤屏障） 等功能，使用天然提取物（naturally extract），可能存在 critical event（关键问题）。技术路线之一是把成分放入 capsule（微胶囊）。


历史与材料：2021 年曾有 stable material 很难的情况；YK 保留大量 M（材料）。使用 CD stretch 更容易切割，不用像 SPA module 那样担心 stretch（说话人有相关专利）。


弹性材料在线问题：中间弹性材料固定，在线张力下会破坏表面，成为 inactive（失活）。Pampers 曾有类似：弹性材料在这里，拉伸时破坏 nonwoven facing，使其 inactive；实际是 poorly bonded（弱粘合） 的 nonwoven facing。


三层结构实现方式：三层 nonwoven（PP / PP / 弹性聚合物），正常 PP 无拉伸因为粘合；若某处 PP 断裂，弹性层暴露。即 PP 不是 regular SP，是 poorly bonded，易破；弹性聚合物温度低于 PP（PP 约 118℃，弹性材料选 130/150℃），超声波打孔熔合即可自动成孔。常见方块点/芝麻点 pattern 未 bond，若要做也可以但成品能摸到 film，有点丑。


### 10. V7 Blade Air Knife、MD 曲线（离散到积分）与 SAP/尿液分布（01:15:56–01:21:02）


V7 讨论：李彤彤、凯莎（Kai Sha）和 Jerry 讨论 version seven：blade air knife 目前是方形（square），MD 非常 rigid（刚性），正在寻找 curved（曲面） 方案以改进 MD，即“把离散做成积分”。


保密与可行性：彤彤担心此时释放过多信息，北美团队（他们更 close 且想接更多人）可能拿走；理论上 curved 可行，只需投入制作。但是否已能制作？说话人认为还不能；密度演示中只是缩小方块，并非 zone density；调整密度可通过 screen depth（pocket） 实现。


目标：创建更高的 capacity zones 并配合 U accumulation（尿液积聚）。若真要提高 pad 利用率、更均匀分布，关键是能否移除 set（same？）使用这种 z；若能，则成功，否则仍失败。


理想分布：不希望尿液只停留在一处，而是分布到整个 pad（如 400 mm pad 全部利用）。更好液体分布和 pad utilization 有助于 fit、减少下垂（zag in dro?）、更薄。结合 Coco V6 和材料开发，设计有效快速分布尿液的方法是基本课题。若能做到 100% 利用会很好。

### 9. 全球定位、Active Tech 2.0/3.0 资本支出与地区推进（01:07:40–01:15:56）


全球定位疑问：在 Syntax 期间 Bob Geyser 来推动大家对齐 2.0，但这是否是 global position 存疑；应建 platform 并与所有市场需求对齐。若半数市场不认同、不满足需求，则无意义。需要明确 global R&D 未来 core 方向由谁决定。


北美/全球方案：7 月去北美（NA）时，北美方向也展示；global 团队试图提供覆盖方案（solution 是 14 mm），但这不能解决问题，他们只是没放弃，继续看该技术表现并与产品结合。能否做出所需 pattern 存疑；应把设计提供给对方，让对方做。


放弃时机：彤彤/何叶几乎已放弃，但现在不是告诉全球团队的好时机；10 月后可能是合适时机。Active 2.0 约 40 万（400k）capex，要求各国采用；2.0 较便宜，但初始 code 若包含中国等国家，中国可能不采用？一开始 US 给的 code 不含 FS board 工程。是否所有人都对齐 2.0？没有。


平台开发观点：Li X 观点，开发平台甚至不了解产品，只是从他们角度做技术准备。


2.0 与 3.0 清理 screen：对方在 PD 机器上有非常简单的机械手扫出（sweep out）；而 2.0 系统非常复杂用气吹（air reliable?），实际用于 screen 清洁。Active Tech 2.0 与 soft text 机器不兼容，必须移除整个 society（？），因此重新开发 2.0 是两难。Latin America 尚未决定推进，北美开发的 2.0/1.0? 各方都有 visit。
