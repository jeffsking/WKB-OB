以下是四者主要 SAP 性能参数对比（注：AUL 口径与 CRC/保水口径在不同来源不一致，我统一标注；附件"新 Code X"仅给出保水率、0.9psi、GBP、吸收速度、粒径分布，无 DI 吸水倍率/1min 吸纯水/残单数据）：


|参数（口径）|KC 511|NR-610S|NR-950|新 Code X（20kg样品 20260831）|
|---|---|---|---|---|

|离心保水率 / CRC-盐水 (g/g)|30.9|30.8|36.7|28.8（保水率）|

|吸水倍率 DI 自由溶胀 (g/g)|59.4|60.8|62.5|—|

|AUL 0.7psi (g/g)|18.4|12.1|19.4（最高）|—|

|AUL 0.9psi (g/g)|—|—|—|22.2|

|GBP (Darcy)|24（最高）|6|8|55.3|

|吸收速度 / Vortex (s) ↓|29|19（最快）|51（最慢）|33|

|1 min 吸纯水 (g/g) ↑|145|227（高）|117|—|

|30–50 目 / 粒径分布 (%)|76.9|65.1|88.6|见图下|

|残单 (ppm)|154|156|156|—|

|角色定位|快吸顶层（高 GBP）|极快吸 / 低 GBP|高 CRC / 高 AUL 储库|高 GBP 新品（疑似诺尔高 GBP 目标方向）|


新 Code X 粒径分布：>850μm 0.0%｜850–600μm 10.2%｜600–300μm 77.8%｜300–150μm 11.6%｜150–45μm 0.4%｜<45μm 0.0%


### 几点直说的判断


Code X 就是奔着"高 GBP 上层"去的：GBP 55.3、0.9psi AUL 22.2、保水 28.8、速度 33s——对照 7 月诺尔拜访定的开发目标（GBP≈40、AUL≥20、保水 28–29、速度约 60s），除速度（33s 远快于 60s 目标）外，GBP/AUL/保水三项都达标甚至超标。


Code X 的 GBP 55.3 ≈ KC511(24) 的 2.3 倍、610S(6) 的 9 倍，且主粒径 600–300μm 占 77.8%，接近诺尔 PSD 目标（300–600μm 约 80%）


口径警告：Code X 的 0.9psi=22.2 与 KC511/610S/950 的 0.7psi 值不能直接横比；Nuoer 口径 AUL 是 0.7psi，而 Code X 给的是 0.9psi 。另 KC511 的 GBP 跨源有 24/25/26/35 四个值，本表取 S1 PDF 实测口径 24 。


对比 950：Code X 保水 28.8 < 950 的 36.7，容量明显让步换渗透——正是"顶层求快不求多"的逻辑
