## 提炼的数字与结论

### 为什么要减胶（五条驱动）

| 驱动 | 具体影响 |
|---|---|
| **成本压力** | **胶约占纸尿裤总重 3%**，单价较高 ⇒ 减胶 = 直接降本 |
| **轻薄化趋势** | **超薄芯体（<2 mm）**要求各层同步减薄，**胶层厚度直接影响整体厚度** |
| **舒适度提升** | 少胶 → 降低**硬点（hard spot）** → 改善触感 |
| **可持续性** | 少用原材料 = 降低碳足迹与全生命周期环境影响 |
| **生产效率** | 少胶 = 更少熔融能耗 + **更少喷头堵塞风险** |

### 三条技术路线

1. **A 设备创新（硬件驱动）** —— **当前最成熟**

3. **C 工艺参数优化（过程驱动）** —— 图案设计 / 温压窗口精细化

### ★ UFD 纤维化喷涂：原理与实测

**原理对比**：
- **传统**：熔融胶 → 高压雾化 → **液滴喷洒 → 堆积成膜**（厚、不均、浪费大）
- **UFD**：熔融胶 → **层压板微孔 → 单丝胶线 → 热空气拉长 → 极细纤维铺设**（薄、均、省胶）

> 📌 **核心机理（原文）**：加热空气把单丝状胶线拉长为极细纤维（直径可控），以 **Omega 有序图案**或**随机无序图案**铺设到基材上。**三维纤维网的「机械互锁效应」远优于二维胶膜的「面粘接」——这是同等粘接力下用量骤降的核心原因。**

| 对比维度 | 传统螺旋喷涂 | **UFD 标准型** | **UFD Equity 型** | **UFD 高速型** |
|---|---|---|---|---|
| **节胶比例** | 基准 100% | **↓20–50%** | **↓高达 70%** | ↓30–50% |
| **最低上胶量** | ~2–5 g/m² | **0.1 g/m²** | **0.02 g/线性米/股** | 0.1 g/m² |
| **最高产线速度** | ~400 m/min | 500 m/min | 400 m/min | **700+ m/min** |
| **响应时间** | ~15–20 ms | ~5 ms | ~5 ms | **3.5 ms** |
| **循环频率** | ~2000 次/min | ~4000 次/min | ~4000 次/min | **6000 次/min** |
| **幅宽范围** | 受限 | 单股 ~5 m 可调 | 单股 ~300 mm | 可定制 |

| 图案类型 | 结构特征 | 适用场景 | 胶量效率 |
|---|---|---|---|
| **Omega（Ω）** | 有序波浪形纤维束 | **结构胶**（需定向强度） | ★★★★☆ 高效 |
| **Random** | **无序分布三维纤维网** | **弹性胶**（各向同性粘接） | **★★★★★ 最高效** |
| Spiral | 传统圆锥喷雾轨迹 | 通用型（旧工艺基准） | ★★★☆☆ 基准 |

### 温/湿响应结构胶：理想四阶段与技术路径

**理想场景**：**[生产]** 常温施胶 → 强粘接 ｜ **[存储]** 常温干燥 → 稳定（不变脆/不离层）｜ **[穿着-干态]** 体温 + 低湿 → 维持粘接 ｜ **[穿着-尿湿]** 体温 + 高湿 → **粘接力自适应↑增强（防止结构松散导致侧漏）**

| 路径 | 材料体系 | 机制 | 可行性 |
|---|---|---|---|
| **湿度响应（亲水凝胶）** | **PVA / PVP / PEG 接枝热熔胶** | **吸湿溶胀 → 接触面积↑ → 粘接力↑** | **⭐⭐⭐⭐ 近期可行性最高** |
| 温度响应（SMP） | 聚氨酯 / 聚己内酯形状记忆聚合物 | **Tg/Tm 附近模量突变 → 粘接力切换** | ⭐⭐⭐ 中期可行（3–5 年） |
| 双重响应 | SMP + 水凝胶复合体系 | 温 + 湿协同响应 | ⭐⭐ 中长期研发目标 |
| 离子响应 | 含羧基 / 氨基高分子电解质 | 尿液中 Na⁺/NH₄⁺ 引发交联密度变化 | ⭐⭐⭐ 概念有趣、挑战大 |

### 光控可逆粘接（面向循环经济）

**案例**：广岛大学 **Imato 团队**，*Nature-Polymer Journal* 2024，**螺吡喃（SP）光控可逆粘合剂（PSPA 系列）**：

- **UV 365 nm** → SP 转化为**部花青（MC）** → **极性由 4–6 D 跃升至 14–18 D** → **粘接力大幅提升（内聚破坏模式）**
- **Vis 525 nm** → MC 回复 SP → **粘接力下降（界面破坏模式，可无损剥离）**

**愿景**：纸尿裤使用后进入回收线 → **UV 光照 → 智能胶失去粘接力 → 无损分离**为面层 / 芯体 / 背胶 / 弹性材料 → 各组分分别回收再利用。
