# Gate 0 · 基线口径确认书（ND33-COCOV6-G0-001）

## Positioning 一句话定位

A one-page firewall: it authorises the *calculation* without authorising the *demolition* — the difference between "we evaluated ND33 assuming Blizzard is gone" and "we decided to remove Blizzard".

一页防火墙：它授权的是**计算**，不是**拆除**——「我们在假定 Blizzard 已移除的前提下评估 ND33」与「我们决定移除 Blizzard」之间的那道界线。

## Baseline 评估基线（CONFIRMED）

| 编号 | 基线内容 | 定级 |
|---|---|---|
| **B-1** | 双鼓 COCO V6 与现有 Blizzard（2 套 SAM hopper）在 ND33 同一空间内共存：**不可能** | 已定，不再讨论 |
| **B-2** | 旁路 core collector、ND33 制芯后离线供其他 KC 机台：**不可能**（空间限制） | 已定，不再讨论 |
| **B-3** | 空间与布局评估以「ND33 移除全部 Blizzard、转为 COCO V6 专用」为基线 | 已定，**仅评估用** |

## Scope 基线适用范围（签署重点）

本基线仅用于**空间、布局、公用工程与设备清单**的可行性评估，**不构成**：
1. Blizzard 设备的拆除授权；
2. 最终实施方案（须另做可逆性评估）；
3. RFQ / 询价包的配置输入。

**补充约束**：ND33 仍承担实际 Blizzard 产量 → ① 评估期间**不得安排任何实际拆除动作**（含不可逆临时移机）；② **停产损失与产能替代**为决策包必填核心项，承接方案未定时不得进入评审。

## Reversible Retrofit 五条硬性要求

1. **Blizzard 设备不处置**：封存、标识、登记，评估「恢复到可用」所需工时与备件。
2. **保留原机接口**：安装基座、真空与管路接口、电气柜预留位一律不动。
3. **设可断开点**：双鼓系统与下游之间，机械 / 真空 / 控制三路均可快速断开。
4. **恢复路径入图**：恢复工时、外委项、验证项写入方案正文，**不放附录**。
5. **可逆化成本单列**，不摊入总价。
