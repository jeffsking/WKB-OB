# 诺尔集团供应商拜访纪要_Visit_Report_20260720153001.pptx

## Basic Information 基本信息
- **Event**: 2026-07-19 · 山东东营 · 诺尔集团（SAP 与复合芯体）供应商拜访
- **同源说明**: 与 [[诺尔集团供应商拜访会议纪要_含流程图.docx]] 为**同一次拜访的两份纪要**。主体内容（产能 56 万吨、六阶段后中和工艺、牌号矩阵、上下层搭配路线、即时打样）已在 docx 版页面化并回填 [[诺尔（Nuoer）]]，**本页不重复**，仅记录 docx 版未覆盖的增量信息。

## Increment: Company Profile 公司沿革与原料（公司沿革 · 增量）

| 项 | 内容 |
| --- | --- |
| 2003 | 成立诺尔化工（聚丙烯酰胺起家） |
| 2011 | 成立诺尔生物（东营港区），进军 SAP |
| 原料自给 | 丙烯酸 20 万吨 + 精酸 24 万吨；明年计划新增 8 万吨 |

## Increment: Capacity Planning 产能规划（产能规划 · 供应商自述）
- **2028**: 新增 5 万吨**新工艺** SAP。
- **2029-30**: 新增 10 万吨**吸水纸**（两期）——向吸收制品材料下游延伸的信号。
- **下游代工**: 7 条卫生巾线 + 2 条经期裤线，以 OEM 代工为主（自有品牌运营）。

## Increment: Grade Parameters 牌号参数细化（牌号参数细化）
- **511（KC 专供）**: AUL 18-19（0.7 psi）、保水 31.5、吸速 27 s——通液性最均衡。
- **N8**: CRC 39-40（极高保水）、AUL 12、吸速 45 s——**仅作下层兜底**。
- **951**: 快吸 + 高保水，优于老牌 610S；950 上层 / 959 上下层通用。

## Increment: 60GBP Benchmark 60GBP 对标（60GBP 对标 LG 804）
- 诺尔新品目标对标 **LG 804**（标称 GBP 53）：宣称可调**内外交联与表面处理**达 **GBP≈40 / AUL≥20 / 保水 28-29 / 吸速≈60 s**。
- **口径警示**: LG 804 绝对值存疑（非同实验室数据），但高 GBP 方向获双方认可。
- GDP 提升两路径（docx 版已记其一）：多价金属盐涂层（GBP 上限约 40，降保水为代价）；无机粉末添加（大线具备能力，需综合平衡——二氧化硅/纳米级/吸味材料均可，设备密封）。

## Increment: Follow-ups 后续行动（后续行动）
1. 即时打样：基准全 511 vs 上层 511 + 下层 951+N8 预混（13.5 g/片），当晚测吸速/反渗/通液（→ [[SAM_511_分析汇报.pptx]] 实验线的起点）。
2. 高 GBP 上层专用 SAP 研发：8 月内出小试。
3. 蓝湾工厂参观（次日）：吸水纸 + SAP 产线；**DCS 仅看不可发**（保密约束）。
4. 资料调阅：三大雅 + 住友常规配方、SAP 配比实验数据库。
5. GDP 验证：多价金属盐 / 无机粉末 / 吸味材料拓展实验。

## Reliability Note 可靠性提示
产能、规划与对标参数均为**供应商自述口径**，未与第三方核实；LG 804 标称值为跨实验室比较，仅作方向参考。
