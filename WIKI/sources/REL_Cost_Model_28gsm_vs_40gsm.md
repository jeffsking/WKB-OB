# REL_Cost_Model_28gsm_vs_40gsm（28 gsm 轻量化 REL 成本模型）

## Positioning 一句话定位

The project's **living cost model** for the 28 gsm lightweight REL — and, in this iteration, the first version whose derived values are actually **auditable**: cached results make the crossover grammage (**34.93 gsm**) computable rather than merely asserted. The headline reverses last week's verdict: with the 40 gsm baseline restated at **0.692 元/m²**, both the design and the measured web now **beat** the baseline.

本页是 28 gsm 轻量化 REL 的**活页成本模型**——本次迭代也是第一版派生值真正**可审计**的版本：带缓存结果让临界克重（**34.93 gsm**）从「断言」变成「可计算」。核心结论推翻了上周判断：把 40 gsm 基线重述为 **0.692 元/m²** 后，设计克重与实测成网**双双重优**于基线。

## Version Iteration 版本迭代

| 项 | 10-23 版（前版） | **10-24 版（本页主件）** | 影响 |
|---|---|---|---|
| 传统 40 gsm 基线全成本 | 0.5775 元/m² | **0.692 元/m²** | 基线抬高 → 结论反转 |
| 加工费 ATB | 4,500 元/t | **5,000 元/t** | 新 REL 自身变贵 |
| PTT 添加比例 | 22 % | **24 %** | 配方成本上升 |
| 设计克重 | 28.8 gsm | **28 gsm** | 目标更激进 |
| 派生值缓存 | **无**（公式未缓存） | **有**（可复算） | 结论可审计 |
| 结论 | 实际 33 gsm **反超**基线 | 实际 33 gsm **仍优于**基线 5.5 % | **反转** |

> 两版差异不是「算错改正」，而是**基线口径与工程参数同时更新**。做决策引用时必须写明版本，否则会得出相反结论。

**临界克重（与基线打平）= 34.93 gsm；实测 33 gsm 超出临界 −1.93 gsm（即尚有 1.93 gsm 余量）。**

## Decision Implications 决策含义

1. **业务案的支点是克重，不是纤维价。** 吨价溢价 +14.5%（19,810 vs 17,300）只能靠 −27% 的质量节省对冲；一旦实际成网越过 34.93 gsm，对冲失效、结论翻转为亏。
2. **1.93 gsm 的余量太薄，必须当作质量管控指标写进技术协议**（而非成本表格里的一个假设）。按 +1 gsm = +0.0198 元/m²，余量耗尽只相当于 3.8% 的成本上浮——工艺波动足以吃掉。
3. **采购谈判的让价空间应以「临界克重 − 实测克重」度量**，而不是以元/t 让价度量。
4. **中空 ES 13,500 是最大单点不确定**：若降至 12,000，全成本再降约 0.0043 元/m²。
5. **未含项须计入**：3–5% 工艺损耗、分切废料、打样摊销、关税与 ISCC 认证；锦琪昶常规品类加工费另可能 +10%。
