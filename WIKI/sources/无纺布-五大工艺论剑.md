# 无纺布·五大工艺论剑（系列终篇）

## 一句话定位

《无纺布工艺与材料实验室》系列第五篇，把水刺 / 纺粘 / 熔喷 / 热风 / 针刺五大成型工艺放到同一张对比表里，回答「面对具体产品需求该选哪种工艺」——本库目前**跨工艺选型的唯一总表来源**。

## 摘要

文章先逐篇回顾五种工艺的核心特征，再给出覆盖固结方式、材料结构、性能表现、化学风险画像、典型应用五个板块的十四维度核心对比矩阵，并进一步转成八维度星级评分。星级分布显示三类性格：水刺与纺粘属「均衡型」，熔喷是「单项冠军」（过滤精度领先但强度与蓬松度垫底），热风与针刺是两个极端（热风蓬松柔软但强度弱，针刺强度拉满但毫无手感）。由此引出复合结构（SMS、热风棉+SAP+底膜、水刺+纺粘、针刺+树脂加固毡）的设计逻辑。风险部分把前四篇的残留风险汇总，指出含氟拒水剂（PFAS）与重金属残留是跨工艺共性问题。最后给出九类终端产品的工艺决策框架。作者为公众号「无纺无妨」，系列定位为工艺认知层，与《全球卫生用品法规地图》系列（合规层）互补。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注 |
|---|---|---|
| 熔喷纤维直径 | 1–5 μm（超细） | 唯一能高效过滤 0.3 μm 颗粒物的工艺 |
| 纺粘纤维直径 | 7–30 μm | 效率最高 |
| 纺粘典型克重 | 10–120 g/m² | 五大工艺中最低区间起点 |
| 针刺典型克重 | 100–2000 g/m² | 覆盖范围最宽 |
| 热风 / 熔喷典型克重 | 20–200 g/m² | 二者区间重合 |
| 水刺典型克重 | 30–80 g/m² | |
| 单位成本排序 | 纺粘低 → 热风低-中 → 水刺/熔喷/针刺中 | 熔喷成本含驻极工序 |
| 生产线速 | 纺粘、熔喷「高」；针刺「中-低」 | |
| 卫生用品典型应用 | 湿巾/敷料（水刺）· 面层/SMS骨架（纺粘）· 过滤层（熔喷）· 芯体包覆层（热风）· 工业辅材（针刺） | |
| 针刺卫生用品直接应用 | 有限 | 主战场为土工布/汽车内饰/地毯基布/工业过滤 |
| 复合结构已列类型 | 4 类（SMS、热风棉+SAP+底膜、水刺+纺粘、针刺+树脂加固毡） | |

## 关键论断（key_claims）

- **没有全能工艺，复合结构才是答案** —— 支撑页：[[无纺布五大工艺对比]]、[[SMS复合结构]]
- **PFAS 风险不只在「防水」宣称里**：熔喷驻极助剂含氟电荷俘获剂是隐藏来源，常规质检思路易遗漏 —— 支撑页：[[SMS复合结构]]
- **针刺法的原料包容性即风险来源**：无特殊原料要求 → 回收/再生纤维易混入 → 全成分可追溯性须列为强制审查项 —— 支撑页：[[无纺布五大工艺对比]]
- **芯体包覆层首选热风法**：蓬松结构提供导流空间，双组分纤维兼顾强度与柔软 —— 支撑页：[[热风粘合无纺布]]、[[亲水-疏水梯度设计]]
- **面层首选纺粘（皮芯复合）**：需强度支撑液体快速穿透，皮芯复合改善手感偏硬 —— 支撑页：[[皮芯复合纤维]]
