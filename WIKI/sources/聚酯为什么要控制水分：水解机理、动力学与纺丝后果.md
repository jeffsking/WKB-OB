# 聚酯为什么要控制水分：水解机理、动力学与纺丝后果

## 一句话定位

从酯键化学出发，把「聚酯为什么要干燥」讲成一条从化学反应 → 动力学 → 分子量 → 流变 → 纺丝稳定性的完整因果链——**本库 PET/PLA 类材料加工规范的机理依据**。

## 摘要

文章的核心翻转是：水分在聚酯熔融加工中不是惰性杂质，而是**参与主链断裂的化学试剂**。水解是缩聚的逆反应（P–COO–P′ + H₂O → P–COOH + HO–P′），早期表现为分子量下降而非失重。机理上，酯基羰基具极性，水分子氧作为亲核体攻击羰基碳，经四面体中间体 → 质子转移 → 酰氧键断裂四步。动力学上，水解可能因羧基端基而自催化（rₕ = (k₀ + kₐ·CCOOH)·CE·Cw），速率常数服从 Arrhenius。分子层面，每发生一次随机断链，链数增加一条，1/Mₙ 与断链数近似线性，同时羧基与羟基端基等量增加。流变层面，由于 η₀ ∝ Mw³·⁴，分子量小幅下降即造成熔体黏度显著下降，进而影响挤出、喷丝与拉伸稳定性。这就解释了为何高特性黏度 PET 对水解更敏感，以及「同样的含水量，室温切片无碍、高温熔体快速降解」。

## 提炼的数字与结论

| 项目 | 数值 / 公式 | 含义 |
|---|---|---|
| 缩聚 / 水解 | P–COOH + HO–P′ ⇌ P–COO–P′ + H₂O | 水解是缩聚的逆反应 |
| 断链与分子量 | 1/Mₙ = 1/Mₙ,₀ + nₛ/m | 随机断链数与 1/Mₙ 近似线性 |
| 端基变化 | [COOH]ₜ = [COOH]₀ + s；[OH]ₜ = [OH]₀ + s | 羧基/羟基端基增加是水解的直接化学证据 |
| 自催化速率式 | rₕ = (k₀ + kₐ·CCOOH)·CE·Cw | 羧基端基提高局部酸性 → 自催化 |
| 温度依赖 | kₕ = A·exp(−Eₐ/RT) | 同含水量在高温熔体中危害骤增 |
| 特性黏度 | [η] = K·Mᵥᵃ（Mark–Houwink） | Mᵥ↓ ⇒ [η]↓ |
| 零剪切黏度 | η₀ ∝ Mᵥʷ³·⁴ | Mw 降 10% ⇒ η₀ 降约 30%（0.9³·⁴ ≈ 0.70） |
| 水分指标 | wH₂O(ppm) = (mH₂O/mpolymer)×10⁶ | 0.004 wt% = 40 ppm |
| 工艺口径 | 干燥后 PET 切片水分 <约 0.004 wt% | 不同产品/设备/停留时间对应内部规格不同 |

**水分影响的完整逻辑链（原文表述）**

| 层面 | 内容 |
|---|---|
| 化学层面 | 水参与酯键逆缩聚，造成随机断链，增加羧基与羟基端基 |
| 动力学层面 | 温度越高水解速率常数越大；羧基端基可能形成自催化 |
| 分子层面 | 链数量增加，Mₙ、Mw 与特性黏度下降 |
| 流变与工艺层面 | 熔体黏度、弹性和拉伸承载能力下降，压力、喷丝流量、纤度均匀性与断头状态随之变化 |

**传导链（原文图式）**：水分↑ → 水解断链↑ → 分子量↓ → 特性黏度↓ → 熔体黏度与熔体强度↓ → 挤出、喷丝与拉伸稳定性变化。

- **高特性黏度更敏感** —— 分子量基数越大，相同断链数的相对损失越显著。支撑页：[[聚酯水解与水分控制]]
