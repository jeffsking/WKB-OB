# CN 116731354 A（快速吸水自膨胀纳米纤维素材料及其制备方法和应用·华东师范大学）

## One-line positioning 一句话定位

A university application claiming a **chemically crosslinked, compressible, ultra-fast-swelling nanocellulose material**（化学交联·压缩态·遇水 2–30 秒膨胀 3000–90000%）with hemostat / weight-loss / cell-culture demonstrations. 对本库的意义：它是「纳米纤维素替代/补充 SAP」专利证据链里**速度指标最强的一件**（2–30 s 对 SAP 典型涡流法的数十秒量级），但**应用例未涉及纸尿裤芯体**。

## Technical breakdown 技术拆解

1. **原料谱系最宽**：提取/再生/化学改性（磺酸化、羧甲基化、TEMPO 化、磷酸化，取代度 0–3 优选取 0–0.8）/细菌纳米纤维素（醋酸菌属、土壤杆菌属、根瘤菌属、八叠球菌属）均可。
2. **交联剂谱系**：甲醛/尿素、柠檬酸、乙二醛、戊二醛、硅烷偶联剂、酸酐偶联剂、环氧氯丙烷；CNF(干):交联剂 = 1:(0.0001–10)，优选 1:0.01–1。
3. **工艺自由度**：先交联后干燥 / 先干燥后交联 / 干燥中交联均可；再加工（裁剪、切割、粉碎、压缩）任意组合。
4. **实施例数据**：CMC-NFC+柠檬酸 85 °C/12 h → 压缩球 8.2 s 膨胀、8600%；CMC-NFC+环氧氯丙烷 90 °C/6 h → 12.1 s、8400%；CMC-NFC 粉末 100 °C 干燥交联 → 2.6 s、4100%；TEMPO-NFC+戊二醛 60 °C/6 h → 10.5 s、8100%。

## Key claims 关键论断

- **速度与倍率指标强，但芯体场景缺席**——实施例全是止血/培养/减肥，无吸收芯体、无回渗、无含盐液体（尿液模拟液）数据 → [[快速吸水自膨胀纳米纤维素材料（华东师大）]]
- **「吸水后保持整体性」靠共价交联**，与 BCNF-SAP 替代可行性讨论中「纳米纤维素材料力学完整性」问题直接相关 → [[纳米纤维素（CNC、CNF、BNC）]]
- **交联剂体系与 SAP 表面交联（柠檬酸/环氧类）同源**，工艺移植门槛低 → [[SAP（高吸水树脂）]]
