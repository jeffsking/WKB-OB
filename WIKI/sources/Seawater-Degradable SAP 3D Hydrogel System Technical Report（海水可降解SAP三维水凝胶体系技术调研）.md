## 原文要点 Original Key Points

### 1. 背景与问题定义

- 全球 SAP 年产量 **>300 万吨**，约 **70%** 用于卫生用品；传统 SAP 以 **PAA/PAM** 为主链，不可生物降解。
- UNEP 2024 数据：**每年约 800 万–1000 万吨塑料入海**，一次性卫材贡献相当比例的微塑料来源。
- 法规驱动：欧盟 **SUP 指令（2019/904）**、美国各州禁塑令、中国"限塑令"升级版；**2024 年欧盟提出将卫生用品纳入"海洋可降解认证"监管，目标时间表 2030 年**。

### 2. 海水降解 vs 土壤降解（关键差异表）

| 维度 | Soil 土壤降解 | Seawater 海水降解 |
|---|---|---|
| 温度 | 15–35 °C（变化大） | **10–25 °C（相对恒定）** |
| pH | 5.5–7.5（中性偏酸） | **8.0–8.3（弱碱）** |
| 盐浓度 | <0.1% | **~3.5% NaCl** |
| 微生物 | 丰富多样 | **以海洋细菌为主，种类较少** |
| 氧含量 | 波动大 | 表层饱和、深层缺氧 |
| 测试标准 | ISO 17556 / ASTM D5988 | **ASTM D6691 / ISO 16204** |
| 认证门槛 | 180 天 ≥90% CO₂ 转化 | 180 天 ≥90% CO₂ 转化 |
| 技术难度 | 较低（成熟） | **较高（盐抑制 + 低温）** |

### 3. 六条技术路线（A–F）

| 类别 | 代表体系 | 成熟度 | 海水降解潜力 | 成本 | 吸水性能 |
|---|---|---|---|---|---|
| **A 多糖接枝共聚** | starch-g-PAA / cellulose-g-PAA / CMC-g-PAA | ★★★★☆ | ★★★☆☆ | **低** | 高 |
| **B 聚氨基酸** | γ-PGA-co-PASP / PASP / PGA | ★★★☆☆ | ★★★★★ | **很高** | 中高 |
| **C 聚酯缩合** | PES/PBS + 长链二元羧酸共聚 | ★★★☆☆ | ★★★★☆ | 中高 | 中 |
| **D 水溶性粒子复合** | PVA/PLA 共混 / PEO/PHBV / PVOH/PCL | ★★★★☆ | ★★★★☆ | 中 | 中 |
| **E 天然高分子 IPN** | 海藻酸盐 / 壳聚糖 / 明胶 IPN | ★★★☆☆ | ★★★★★ | 低中 | 中 |
| **F 生物基单体合成** | PLA 基 / PHA 基 / 改性大豆蛋白 | ★★☆☆☆ | ★★★★☆ | 高 | 中 |

> 中文注解：**每条路线都在"成熟度 / 降解潜力 / 成本 / 吸水"四者间取舍**——A 最便宜最成熟但降解潜力仅三星；B/E 降解潜力五星但 B 成本"很高"、E 强度不足。

### 4. 四条重点路线详解

**4.1 Nagase（最接近商业化）**
- 主体：日本 **Nagase ChemteX**（制造）+ **Nagase Viita**（原林原商事，2024 更名）。
- 路线：**淀粉基高生物质含量 SAP**，经改性获得海洋可降解性。
- 里程碑：2023-02 宣布开发成功 → **2024-04 新等级通过第三方 ASTM D6691** → 目标 **FY2026** 上市。
- 性能：**180 天海洋降解率 ≥90%**（生物质比例未公开）。
- 目标应用：**卫生巾、轻失禁**（初期不做纸尿裤，因性能要求更高）。
- 意义（源文口径）：全球首个公开宣称达到海洋可降解认证标准的 SAP 产品。

**4.2 PVA/PLA 共混（Huang & Hu, Polym. Degrad. Stab. 2020）**
- PLA 在海水中 180 天失重 **<5%**；引入水溶性 PVA 后**显著提高**失重率。
- 机理：PVA 先溶解 → 形成孔隙与缺陷 → 比表面积增加 → 酶攻击位点增多 → 链式降解。
- 同时用 **ADR 4370S** 增容剂改善 PVA/PLA 界面相容性。

**4.3 γ-PGA-co-PASP（Zhao Jianbo et al., BMC Biotechnol. 2023）**
- 前体 **PSI（聚琥珀酰亚胺，~100 kDa）** + 枯草芽孢杆菌发酵的 **γ-PGA 发酵液**（省纯化降本）+ **EGDGE** 交联剂。
- 条件：**pH 4.8–5.0、50 °C、12 h**；最佳液固比 **PSI:γ-PGA = 2:1** → 吸水 **223 g/g**。
- 主链为**肽键**，理论上可被蛋白酶完全降解。

**4.4 PES/PBS 长链二元酸共聚（Kumagai et al., Polymer Journal 2024）**
- 基础聚合物 PES/PBS，引入 **C6–C12 二元羧酸（DCA）**共聚；两步熔融缩聚，催化剂 **TTIP**。
- **DCA 碳数是决定海水降解性的主因子：C≥8 有效，C≥10 显著**。
- **阈值效应**：仅 **5–6 mol% C12** 即可达 60 天 **~55%** BOD 降解率；**PESDDD20（23 mol% DDDA）** 60 天约 **80%**，诱导期 **<5 天**。
- 机理推测：Tg 降低 → 链段运动增强 → 结晶破坏 → 脂酶亲和力提升。

### 5. 降解机理与认证标准

- **两阶段**：① 解聚（水解/氧化/光降解 + 胞外酶）→ 短链低聚物；② 矿化（微生物代谢 → CO₂ + H₂O + 生物质）。
- **标准清单**：**ASTM D6691-24**（海水，28–180 天 CO₂ 转化）、**ISO 16204:2012**、**OECD 306**（28 天 BOD >60%）、**ISO 14851:1999**、**ASTM D5988:2021**（土壤，180 天 >90%）、**EN 17033:2018**。

### 8. 挑战与风险（源文评级）

| 挑战 | 具体问题 | 严重度 |
|---|---|---|
| 性能差距 | 吸水/保液低于 PAA 系 **20–50%** | ★★★★★ |
| 成本劣势 | 为传统 SAP 的 **1.5–4 倍** | ★★★★★ |
| 耐盐性不足 | 高盐环境下吸液能力骤降 | ★★★★☆ |
| 降解速度控制 | **使用期内稳定 vs 废弃后快速降解**的矛盾 | ★★★★☆ |
| 安全性验证 | 婴幼儿接触类需严格毒理与皮肤刺激性测试 | ★★★★★ |
| 供应链不成熟 | 上游生物基单体产能有限、品质不稳 | ★★★☆☆ |
| 标准缺失 | 海洋降解 SAP **尚无专门行业标准** | ★★★☆☆ |
| 消费者教育 | 终端不理解"海水降解"价值主张 | ★★★☆☆ |

1. **六条路线 vs 库内四条路线**：本源给出 **A–F 六条**（多糖接枝/聚氨基酸/聚酯缩合/水溶性粒子复合/天然高分子 IPN/生物基单体），而库内既有对比页 [[Degradable SAP Routes（可降解 SAP 四路线对比）]] 给出 **四条**（PGA/PLGA+多糖、PVA 基 IPN、PASP 基、PDA 型）。**两者分类粒度不同、并非一一对应**（例如 PDA 型在本源六类中无直接对应项）。本页**照录、不合并、不换算**。
2. **成本倍数两处不一致**：§2.1 表给"可降解 SAP 成本 1.5–4.0×"（以传统为 1.0× 基准），§九给"1.5–4 倍"，§8.2 场景一给"成本增加 50–150%"（即 1.5–2.5×）。**三处口径区间不完全一致**，源文未说明是否不同场景，**不取代表值**。
3. **SFC 单位**：本源用 **10⁻⁷ cm³·s/g**（与 GBP 的 Darcy 不可换算）——库内 [[SAP性能指标（CRC AUL GBP Vortex）]] 已记录该单位冲突，本页**沿用源文单位，不换算**。
4. **"海洋降解 SAP 尚无专门行业标准"** 与 §2.3/§5.3 引用 ASTM D6691 / ISO 16204 并存——**标准是"通用塑料海洋降解方法"而非"SAP 专用标准"**，本页按源文照录。
5. **Nagase 生物质比例未公开**、Planet Smart 仅为小规模上市——二者**不等于可批量供货**，需人工核验当前状态。
