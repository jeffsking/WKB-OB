# STM-00232布质外层与loop的粘连强度（人工方法）.docx

## 一句话定位

**布质外层-loop 粘连强度人工分级法（英文：manual loop-to-fabric-outer bond rating）**：主观感受 loop（魔术贴勾面）与外层材料的粘连强度（中文：照片对比 1–5 级），NJ 厂 STM-00232 第 1 版——**无拉力机、输出等级而非 gf**。

## 摘要

样品从包装取出，标记穿着方向（左右）。操作：打开尿裤外层面朝操作者，一手拇食指拿住尿裤前部（loop 端）并捏住耳朵；另一手捏住 loop 无胶区域（不得破坏 loop 与外层的连接），从尿裤**右侧快速撕开 loop**，方向为 180° 剥离，撕到 loop 中间位置停止；左侧重复。按标准照片评定 1–5 级：1 级——易撕开，loop 无破损、外层无无纺布掉落；2 级——loop 完全撕掉但 CD 向撕破或分层起毛 <25.4 mm；3 级——撕破面积 >25.4 mm；4 级——撕掉面积 >50%；5 级——全部材料撕破。原文附不同 loop 材料（无纤维/中等纤维/全部纤维）撕开后的等级图，实际主要参考 2# 与 3#。
