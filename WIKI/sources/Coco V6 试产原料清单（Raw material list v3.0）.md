# Coco V6 试产原料清单（Raw material list v3.0）

## 一句话定位

COCO V6 试产的**物料主清单（I. Full Core Material List v3.0，含面层）+ SAP 四牌号性能横评附页**——把「试产要备哪些料、向谁要、要多少、什么时候到」与「四支 SAP 到底怎么排序」固定在同一份表里。

## 摘要

Sheet1 为含面层（Topsheet）的全芯体物料清单 v3.0，共 13 个条目，落在 **4 个结构位置**：Liner（Code 1 50gsm／Code 2-A 30gsm 优先／Code 2-B 30gsm 备选）、REL（单一方案，Minrui）、SAP（Nuoer 610s／950／High GBP trial code，另列 50%+50% 两种混配）、Core Wrap（LSN MPM 200mm／PSN MPM 150mm，Unikorn；另列三叶草粘胶 LSN 王金 与 亲水胶 3059 Henkel）。Liner 采用「双组分 PE/PET 皮芯 + 三叶形截面纤维」的上下各 25gsm 双层构造，三叶形纤维按 10%/50% 配比分布在上/下层。Sheet2 为 **四支 SAP 的性能横评**（KC 511 基准 / NR-610S / NR-950 / 新 Code X），并附原文自带的四条直白判断与三条口径警告。原文明确：Code X 除吸收速度（33 s，远快于 7 月诺尔拜访定的约 60 s 目标）外，GBP／AUL／保水三项均达或超标；其 GBP 55.3 约为 KC511 的 2.3 倍、610S 的 9 倍；主粒径 600–300μm 占 77.8%，接近诺尔 PSD 目标。原文同时警告 Code X 的 AUL 口径为 0.9 psi、其余三支为 0.7 psi，**不可直接横比**；并指出 KC511 的 GBP 跨源有 24/25/26/35 四值、本表取 S1 PDF 实测 24。

**原文自带的三条口径警告（务必随数字一起引用）**

1. Code X 的 AUL 为 **0.9 psi**，KC511/610S/950 为 **0.7 psi**，**不可直接横比**。
2. KC 511 的 GBP **跨源有 24 / 25 / 26 / 35 四个值**；本表取 S1 PDF 实测口径 **24**。
3. AUL 口径与 CRC／保水口径在不同来源不一致，原文已统一标注；附件「新 Code X」**仅**给出保水率、0.9psi、GBP、吸收速度、粒径分布，**无** DI 吸水倍率／1 min 吸纯水／残单数据。
