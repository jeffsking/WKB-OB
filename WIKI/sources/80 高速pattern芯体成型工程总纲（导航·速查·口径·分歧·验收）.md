## §1 传统成型 ↔ pattern 成型：分野说明

| 维度 | 传统成型（08）| pattern 成型（本层）| 中文 |
|---|---|---|---|
| **SAP 布局** | 与绒毛浆**均匀混合**成整幅 | **分区沉积**（skin / poly 两层各自图案）|
| **尺寸定义载体** | 成形鼓**筛网段** + 段位排列 | **可换 sleeve**（尺寸载体），**鼓体固定** |
| **多规格手段** | 换鼓 / 换网 / 调速 | **换 ups（n） + 换 sleeve**；**P = πD/n** |
| **相位基准** | 相对宽松（整幅无图案对齐）| **严格：双层 pattern 互套** |
| **关键质量门** | 芯体完整性、SAP 分布均匀度 | **套准 Cpk + 通道湿态粘接 + 边缘锐度** |
| **后道耦合** | 直接由砧辊切断 | **必须经 repitch 单元**把鼓距解耦成产品节距 |
| **成型真空** | 通幅恒定 | **6 区固定角度**，逐区设定，且随 ups 改停留时间 |
| **仿真对象** | 纤维气流铺网 | **颗粒轨迹 + 相位误差统计 + 气流场** |

> **使用建议（源文）**：凡问题涉及「pattern 分区、多规格共鼓、套准、repitch」→ 走本层；涉及「纤维化、混合、Debulking」→ 仍走 08。

## §4 独立复核结论（**仅算术闭合性，不含物理正确性**）

> 源文声明：*"本节只验证算术闭合性与表间一致性，**不验证任何物理模型**（气流、颗粒轨迹、误差统计）的正确性。上述「闭合」**不等于「实测成立」**。"*

### ✅ 闭合项（独立重算）

| 项 | 复核 |
|---|---|
| 鼓距 = πD/n | 2,770.8/6 = **461.80 ✓**；/7 = **395.83 ✓** |
| 鼓面线速 = 鼓距 × ppm | 461.8 × 1000 = **461.8 m/min ✓**；395.8 → **395.8 m/min ✓** |
| 时间/度 = 60/(rpm×360) | 166.7 rpm → **1.000 ms ✓**；142.9 → **1.166 ms ✓** |
| 离心场 = ω²r | **13.70 g ✓**；**10.07 g ✓** |
| 全部 11 个端区 | 逐规格重算与 P5 表**完全一致 ✓**（Open XL 461.8−420 = 41.8 → 42 ✓；Pant XL 395.8−365 = 30.8 → 31 ✓）|
| 全部 11 个 repitch ratio | **完全一致 ✓**（Open NB 390/395.8 = 0.985 → 0.99 ✓；Pant XL 495/395.8 = 1.251 → 1.25 ✓）|
| SAP g/片 与 kg/h | Open M（358×110、160 gsm）= 0.03938 m² × 160 = **6.30 g ✓**；×1000×60 = **378 kg/h ✓** |
| 风机轴功 | 22 m³/min = 0.3667 m³/s × 15 kPa = 5.5 kW 水力 /0.65 = **8.46 kW ≈ 8.5 kW ✓**（隐含效率 **~65%**）|
| 鼓惯量 | 270 kg 全质量在 r = 0.441 m → J = mr² = **52.5 kg·m² ✓**（薄环上限假设，**保守**）|
| 扇区角度合计 | 60+65+25+54+18+138 = **360° ✓** |

### ⚠️ 两处软点（建议在 RFQ / 中试中核实）

1. **保形压力 ~39 Pa 的推导未闭合** —— 裸算惯性压力 = 0.230 kg/m² × 134.3 m/s² ≈ **31 Pa**；反推 39 Pa 需等效 **17.3 g** 或 **290 gsm**，或按「扣除 land 后的净图案面积」口径（÷~0.77）→ **40 Pa**，与 39 Pa 吻合。**源文件未给出推导细节**。
   - *结论稳健性*：保形段给 **~4,000 Pa**，无论 31 还是 39 Pa，**余量都是两个数量级**，故「保形从不是瓶颈」不受影响。
2. **3 s 停车扭矩与稳态运行扭矩口径不一致（约 −15%）** —— 由 6-up ≈455 Nm、7-up ≈410 Nm 反解，隐含 J·α 项为 **302.5 / 259.3 Nm**，两者差 **43.3 Nm ≈ 52 × (5.818−4.986) ✓**（两 ups 之间自洽）；但隐含的摩擦/运行扭矩为 **≈152 Nm**，与 P12 表列稳态 **180 Nm** 差约 **15%**。
   - *处置*：**按 455 Nm 峰值 × 安全系数取，不要用 180 Nm 反推峰值；要求设备商提供停机曲线**。

## 教训 Lessons

1. **"知识缺口"本身要被记录** —— 本层存在的理由是 `references/08` 覆盖的是 2021 年**绒毛浆 + SAP**体系，而 **COCO-v6 已改为全 SAP + REL**，**架构变了但工程方法没跟上**。
2. **尺寸载体从"筛网段"变为"可换 sleeve"** —— 这是 pattern 成型相对传统成型最本质的变化，牵出 **P = πD/n** 与"换型只动 sleeve/recipe"。
3. **角度是几何、停留是 recipe** —— 扇区角度换 ups 不动，但**停留时间与真空必动**；混淆二者会在换规格时漏改参数。
4. **chute 不重设 → in-spec 从 ≥99.99% 塌到 92.7%** —— 一个 recipe 项的遗漏造成**两个数量级**的合格率差。
5. **MD 可伺服自纠、CD 必须机械钉死** —— 换型收敛 **MD ≈17 片（~1 s）自纠**，CD 无自纠路径。
6. **"算术闭合 ≠ 物理成立"** —— 本层显式声明只做算术复核（10 项闭合），**不验证气流/颗粒/误差模型**。
