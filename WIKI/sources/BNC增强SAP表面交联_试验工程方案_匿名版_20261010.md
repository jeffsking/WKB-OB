# 第一部分 可行性论证

## 1.1 高分子机理基础——方向成立的理论依据

SAP表面交联的本质：SAP是携带解离离子官能团的疏松交联三维网络（吸水>15倍自重）。先进SAP普遍采用"本体交联+表面交联"双轨：表面交联是后聚合固化形成高交联壳层+低交联内核的核壳结构，是纸尿裤/卫生巾用SAP的核心后处理工艺。表面交联的直接作用是形成"硬壳"，受压时凝胶不塌陷——这正是AUL的核心机制。

BNC参与表面交联的分子逻辑（乙方技术主张+高分子化学交叉验证）：
1. 共反应成壳：纤维素羟基可与多元醇/碳酸亚烃酯/环氧化物等SAP表面交联剂共反应，BNC纤维（50 nm×2 μm）以网络形态共价并入交联壳；
2. 刚性撑壳：BNC结晶纤维素网络（杨氏模量78 GPa、拉伸强度826 MPa）为壳层提供远超有机交联层的机械强度，直接支撑AUL与耐破度；
3. 亲水导液：BNC孔隙率>90%、持水200–1000倍自重，在壳层形成主动导液通道——区别于传统表面交联"致密化阻碍进水"的固有矛盾。

交联密度-性能平衡（Flory-Rehner框架）：低交联（大Mc）吸水高但凝胶强度低；高交联（小Mc）相反；交联剂0.1–1 mol%对应Mc约5000–50000 g/mol；不均匀网络溶胀较理论低约20%。行业共识（含内部培训）：核壳/梯度非均匀交联才能兼顾低负载与高负载吸收，均匀交联做不到。BNC表面壳层本质上是"梯度交联的工程化实现"——内核保留低交联保CRC，表面BNC增强壳保GBP/AUL。

## 1.3 工程与供应链支撑——产线可落地

- 丙方釜式后中和工艺：产物孔隙结构适合表面交联，后处理线具备计量绞龙（DCS连锁按产量加料）、高速混合机（八九十桨）、浆液干燥机130℃二次干燥、冷却筛分全套工段，且设备密封设计具备固体粉末添加能力；
- 乙方已与某SAP供应商进行BNC表面交联开发（样品验证中），技术主张已跑通实验室链路；排他核查2周内出结论；
- BNC干态运输双轨方案（PEG母粒/自膨胀干粉）解决含水98%水凝胶无法长途运输的工程障碍。

## 1.4 风险与瓶颈（必须正视）

|风险|内容|应对|
|---|---|---|
|CRC-AUL-GBP三角|表面交联↑→GBP↑但CRC↓（现行底材S-511: 31→28触薄芯底线）|核壳梯度交联、BNC用量DOE限幅|
|AUL基础不足|现行底材AUL仅14.7–15 g/g，高GBP需AUL≥18|BNC刚性壳+刚性基团内交联+MMT选项|
|GBP-Vortex矛盾|高交联外壳阻碍进水（GBP 65时Vortex 70s+）|BNC亲水导液网络恰是对冲手段；表面微裂纹/发泡|
|涂覆均匀性|工业级每颗粒均匀涂覆难|双流体精密雾化+NIR在线监测|
|IP/排他|乙方与现有SAP商排他条款；第三方自膨胀专利FTO|2周核查+JDA锁定；规避设计|
|成本|BNC约5万元/吨 vs SAP约1000美元/吨|只做增强（0.05–1%用量），不做替代|
|安全|戊二醛/环氧氯丙烷/TMCS类不可用于婴儿产品|交联剂锁定多元醇/碳酸酯/环氧化物+柠檬酸，禁用名单写入原料规范|
|用量区间|表面处理先例提示最优可能低至0.01–0.1%量级，内添先例0.3%峰值|DOE下探至0.05%，五档扫描不遗漏低用量最优区|

## 1.5 可行性结论

机理成立、先例充分、产线可挂靠、风险可控，建议按本方案启动。核心创新点（BNC网络并入交联壳）无直接竞品专利障碍（乙方首创用法可与联合申请），主要不确定性集中在：①排他条款结论；②BNC用量-性能响应面；③涂覆均匀性。这三项均为试验可解问题，不构成方向性否决。

# 第二部分 工艺路线（丙方产线）

## Phase 0｜前置门（第0–2周）

1. 乙方出具与现有SAP供应商排他条款核查结论，确认可否与丙方直接联合开发
2. 三方协议：乙方NDA（2026-02-09已签）延续、NNN已签、SAP交联赛道JDA签署；丙方NDA/CDA签署
3. 丙方技术对齐：表面交联工段能力（交联剂体系、单次/多次、温度时间窗口）、雾化喷涂能力、改造CAPEX

## Phase 1｜BNC形态制备（乙方，第2–6周）

- 主线A：PEG置换母粒——水凝胶PEG置换90%水→挤压→干燥成干颗粒（可运输、遇水复水）；同步完成PEG分子量筛选（400–20000窗口，重点2000/4000/6000三档）与复水速度验证（目标≤60 s）
- 对照线B：自膨胀干粉——羧甲基化BNC（取代度0.2–0.35）+柠檬酸（配比1:0.02–0.08）共混→100℃干燥中交联（或冻干+85℃×12 h对照）→粉碎成粉；复水时间目标≤30 s
- 同步验证：干态含水率、复水后分散性、130℃热稳定性、取代度、残留物

## Phase 2｜复水与分散液制备（丙方线前段新增）

- 连续复水罐：干态中间体（母粒/干粉）计量进罐→水/0.9% NaCl复水→BNC分散液（目标固含2%，即4900%持水，落在自膨胀可控区间）
- 出料控制：粒径均质、无结块；泵送粘度在线监测

## Phase 3｜表面交联液配制

- 主体系：BNC分散液+多元醇/碳酸亚烃酯/环氧化物交联剂（参考公开专利配方骨架：PEGDGE Mn≥300+丙二醇/碳酸乙烯酯，比2.5:1–1:2.5）
- 交联剂用量：相对SAP 0.01–1 wt%（优选0.1–0.5%），多元醇包覆0.005–2 wt%
- 可选叠加：聚胺+多价金属盐（Al³⁺/Ca²⁺）离子涂覆组分（公开专利路线，丙方已有实验能力）

## Phase 4｜丙方后处理线涂覆与固化

流程：SAP半成品(固含≈96-97%) + BNC分散液+交联剂液(计量绞龙DCS连锁按产量注入/双流体精密雾化) → 高速混合机(八九十桨, 表面涂覆) → 浆液干燥机130℃二次干燥(交联固化, 固含恢复≈96%) → 冷却 → 最终筛分(粗料返研磨, PSD 300-600μm占比≈80%) → 成品罐(按需喷抗结块处理)

参考工艺窗口：热处理120–180℃（优选130℃），停留≥10 min（工业规范10–30 min）

## Phase 5｜材料级验证（甲方实验室）

- 四指标矩阵：CRC / AUL(0.7–0.9 psi) / GBP(SFC) / Vortex
- 专项：rewet、多次Insult液体传导、可提取物、PSD复测

## Phase 6｜芯体级验证与DOE优化

- 芯体打样13.5 g/片基准，对照全S-511基线
- DOE五档扫描：BNC用量（0.05/0.1/0.3/0.5/1.0% 对SAP）×交联剂用量（0.1/0.3/0.5%）×温度（120/130/140℃）×离子涂覆（有/无）
- 第一轮先用BNC用量单因子五档扫出响应面，再进入全因子

## Phase 7｜放大与量产门槛

- 丙方小试100 kg级→中试1 t级；SPC控制图、CPK≥1.33为量产准入门槛
- 多批次一致性：批内/批间CV%追踪

# 第三部分 参数设计（核心表）

|工序|参数|目标值/范围|
|---|---|---|
|BNC纤维|尺寸|50 nm×2 μm（乙方BNC）|
|化学改性|羧甲基化取代度|0.2–0.35（安全窗0–0.8）|
|预交联（对照线B）|交联剂/配比|柠檬酸，NC干重:交联剂=1:0.02–0.08|
|干态复水|复水时间|母粒≤60 s / 自膨胀粉≤30 s；目标分散液固含2%|
|表面交联剂|体系|多元醇/碳酸亚烃酯/环氧化物；参考PEGDGE+丙二醇/碳酸乙烯酯(2.5:1–1:2.5)|
|交联剂用量|对SAP|0.01–1 wt%（优选0.1–0.5%）|
|BNC用量|对SAP干重|DOE五档：0.05/0.1/0.3/0.5/1.0%|
|离子涂覆（可选）|聚胺+多价盐|Al³⁺/Ca²⁺，浓度按公开专利窗口|
|涂覆|计量绞龙DCS / 双流体雾化|按产量加料，NIR在线监测均匀性|
|热处理|温度×时间|130℃（窗口120–180℃），≥10 min|
|固含|二次干燥后|≈96%|
|PSD|最终筛分|300–600 μm占比≈80%|
|目标指标|高GBP目标口径|GBP≥65、CRC≥28、AUL≥18、Vortex≤35（分阶段：先45–55再叠加）|
|量产门槛|SPC|CPK≥1.33|

BNC用量窗口设计说明：0.1–1%区间参考"聚合内添路线"的有效窗口（0.1–0.7%，0.3%处0.9%NaCl吸液135 g/g为峰值）；但该数据为内添场景，表面处理场景先例用量更低（0.01–0.1%量级喷洒至树脂颗粒表面），且BC晶须存在"低用量最优、过量团聚性能下降"的普遍规律，故DOE下探至0.05%并设五档，避免遗漏低用量最优区。本窗口为试验起点，须以实测响应面收敛。

# 第五部分 保密与知识产权

1. 排他核查前置：乙方2周内确认与现有SAP供应商排他条款，确认前不与丙方启动技术细节交流
2. 协议体系：乙方NDA（2026-02-09已签，范围基础）→按SAP交联赛道升级JDA；丙方NDA/CDA Phase 0签署
3. IP归属：BNC表面交联配方（多元醇/碳酸酯/环氧化物+BNC网络壳）为联合开发成果，通过JDA锁定自主可控；PEG干态中间体用法为乙方首创，联合申请专利
4. FTO：第三方自膨胀复水专利仅作机理参考，产线方案做规避设计（柠檬酸+不同干燥路线）；丙方高GBP项目按甲方内部安全审查流程执行
5. 信息分层：乙方与丙方之间仅流通规格化物料与工艺参数（用量、温度、目标指标），配方核心（改性方式、交联剂、配比）由甲方+乙方持有；与第三方卫品企业（发泡方向）合作信息严格隔离
6. 安全红线：禁用TMCS类、戊二醛、环氧氯丙烷、甲醛于婴儿产品体系；柠檬酸为默认安全交联剂

本方案由甲方创新研发部编制，参数为试验起点设计，DOE窗口（BNC用量、交联剂用量）须以试验实测收敛。
