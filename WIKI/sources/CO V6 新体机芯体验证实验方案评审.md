# CO V6 新体机芯体验证实验方案评审

## 一句话定位

COCO V6 新体（pattern）芯体验证实验的完整方案评审，覆盖 Code 1–9 设计、清水胶、去味粉、Be Max 三叶草纤维四条线，是 V6 结构探索的主干纪要。

## 摘要

评审了 COQ V6 新体机芯体验证实验的 Code 1–9 设计要点与合并方案，确定材料幅宽与库存处置，并就清水胶、去味粉、Be Max 三叶草纤维三条并行议题形成议定。会议明确导流槽方向须具备引流作用（后端向后、前端向前），并把清水胶实验从八月的最佳 pattern 筛选中拆出、推迟到九月与原材料筛选合并。实验合并方案落定：Code 1 与 2 合并、Code 6/7/8/9 合并（Code 2 形状与 678 不同但属边缘问题，可现场判断），Code 3/4/5 必须单独开因为要调 SAP 密度、整辊都会变。导流槽继续采用浆板 8 mm 设计。去味粉因实验室无大规模混料能力且涉EHS 粉尘管控，改为委托诺尔预混。

## 提炼的数字与结论

| 项目 | 数值 / 结论 | 备注（口径 Caliber） |
|---|---|---|
| 导流槽浆板厚度 | 8 mm（实际槽 10 mm） | 较贴纸边界更清楚，本轮图纸均按 8 mm 绘制 |
| 前后幅宽 | 135 / 135 mm | 此前曾口头说过 135，需再确认避免记成 130 |
| 大扇尾材料 | PSN 155 / IEL 140 / LSN 200 | IEL 在 110 时改用 115（多 5 mm） |
| Code 3 SAP add-on | 上下层各 6.8 克 | 参照现有 X pad 的 SAP 密度核算 |
| Code 4/5 SAP add-on | 上下层各 6 克 | 用于探究 SAP 密度上下限，属拍脑袋预设，待现场趋势出来后动态调整 |
| 清水胶实验规模 | 8 Code → 4 Code | 含 1 个 control，另取 2 个胶量变化档；若沿用婷婷现有数据可再减至 3 个 |
| 清水胶评估维度 | 导流扩散、吸收时间为主 | 其他性能同步评估 |
| 去味粉三款 | 0.25 g 上层 / 0.5 g 上层 / 上下各 0.25 g | 合计 0.5 g 版本为款 3 |
| 诺尔预混参考比例 | 1 kg 颗粒配 200 kg 吸水粉 | 供应商最低混合量约 200 kg（吨袋边小型装置），实验室约 50 kg |
| Code 9 排产 | 一辊四个（365 mm 宽） | 按密度计算长度，辊上跑长一些、剪切时剪短 |

## 关键论断（key_claims）

- 导流槽方向须有引流作用：后端向后、前端向前，下轮以 Code 平行对比验证「中间槽两侧再加导流槽」能否提升横向扩散
- 实验合并议定：Code 1+2 合并，Code 6/7/8/9 合并，Code 3/4/5 必须单独开（需调 SAP 密度，整辊都要变）
- 导流槽采用浆板 8 mm 设计（实际导流槽 10 mm），因浆板边界比贴纸清楚，本轮图纸均按 8 mm 绘制
- 清水胶（芯片胶）实验推迟至九月与原材料筛选合并，实验规模从 8 个 Code 缩减为 4 个（若 control 沿用婷婷现有数据可再减至 3 个）
- 去味粉三款设计：上层 0.25 g／上层 0.5 g／上下层各 0.25 g（合计 0.5 g）；手工混料受 EHS 粉尘管控限制，首选委托诺尔预混
- 汉高反馈该胶与 2820 使用情况一致，中国区在胶量与胶型上均无研究，属信息空白
